# GLOSSARY — 《分析与思考》共享术语词典

> 黄奇帆的特定用法。与姊妹卷词典（strategy-and-path/docs/GLOSSARY.md）互通。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **问题—结构—对策** | 作者自述的核心研究范式：找问题结构性/体制性/机制性短板，改变联系方式与边界条件使其转化（后记） | 不是作文套路；书架已有 five-step-structural-analysis 是其操作化展开 |
| **汇兑本位制** | 作者对人民币现行发行制度的诊断命名：外汇占款主导投放（峰值 83%），实质间接锚美元 | 不是教科书术语，是"介于联系汇率与主权信用之间"的诊断标签 |
| **金融本质三句话** | 为有钱人理财为缺钱人融资；信用—杠杆—风险把握度；为实体经济服务 | 不是行业定义，是异化检验的三重程序 |
| **六种杠杆黏结工具** | 高息揽储、刚性兑付、资金池、错配、通道、嵌套——纵横组合"十八般武器" | 不是监管术语，是乱象的底层部件清单（乱象=组合） |
| **GDP 1:1 标尺** | M2、政府债务、股市市值、房地产市值与 GDP 之比正常 ≤1:1，1.5:1 严重泡沫 | 经验标尺非定理；储备货币国须分国校准 |
| **债务三级上限** | 国债余额/GDP：良性 70%、危机 100%、致命 150%——判据是付息+到期吞噬全年财政收入 | 不是国会法定上限，是经济上限体系 |
| **三零** | 零关税、零壁垒、零补贴——中间品 70% 时代的 FTA 规则方向；"不等于统统归零" | 不是 WTO 现行规则，是趋势与谈判筹码 |
| **危机后移** | 用吹大另一个泡沫对冲当前危机：股市→房地产→政府债务 | 不是危机解除，是风险的时间转移 |
| **六分之一理论** | 房租≤月收入 1/6；6-7 年家庭收入买一套房；地产投资≤固投 25%、≤GDP 1/6 | 重庆治理实践的经验系数，非国际统计口径 |
| **五个蓄水池** | 人民币国际化五条水道：跨境结算、本币互换、离岸市场、"一带一路"、大宗计价 | 不是官方表述，是经常项下不依赖资本开放的路径归纳 |
| **三链** | 产业链集群、供应链纽带、价值链枢纽（结算点）；"结算枢纽即财富中心" | 跨书术语，与 chain-power-analysis 词典挂接 |
| **资本招商** | 政府以定增入股+撬动贷款+共享成长的招商方式（京东方：210 亿定增、收益超 200 亿） | 不是补贴招商；政府从让利方变股东方 |
| **数字锚** | 作者设想的第三套锚：锚定算力、存储、通讯等数字化能力指数 | 想象大于论证的设计构想，引用时须标注其 speculative 属性 |
| **五个旧特点→五个新特征** | 开放阶段坐标：出口导向→双向投资、沿海先行→东西南北中、适应规则→制定规则等 | 不是开放程度评分，是阶段定位坐标系 |
