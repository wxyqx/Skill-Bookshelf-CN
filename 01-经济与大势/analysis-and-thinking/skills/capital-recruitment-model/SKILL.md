# 资本招商范式

## R — 原文 (Reading)

> 重庆京东方定增210亿+银行118亿，16个月投产，政府股票收益超200亿——政府与市场双赢的资本招商范式。
>
> — 黄奇帆，《分析与思考》第2讲（案例要点）

---

## I — 方法论骨架 (Interpretation)

传统补贴招商（给地、给钱、免税）把政府变成纯让利方，且招来的常是套利者。资本招商把招商重构为股权投资：

1. **入股而非补贴**：政府平台以定增等方式成为项目公司股东——京东方案：重庆 210 亿定增+撬动 118 亿银行贷款，16 个月建成投产；
2. **共享成长而非让利**：收益来自股票增值与产业带动，退出通道前置设计——政府股票收益超 200 亿，远超任何补贴额度；
3. **撬动结构**：政府资本金是引子，真正的开发资金靠"资本金→银行贷款→滚动开发"的杠杆结构（浦东三管齐下：土地批租+三大公司股份制引入外资+上市融资，3000 万开办费撬动十年 5000 亿开发资金）；
4. **失败处置前置**：股权投资必有失败项目，核销、重组、退出的机制要在入股前设计（与债转股重组法配套）。

适用对象：地方政府、园区平台、大型产业集团的重大项目引进。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 京东方重庆线（第2讲）
- **问题**: 面板项目投资数百亿，财政补不起也补不起多少轮。
- **方法论的使用**: 定增 210 亿（政府协调出资）+银行 118 亿贷款，股权结构绑定双方利益。
- **结果**: 16 个月投产、政府股票收益超 200 亿、产业落地。

### 案例 2: 浦东三大开发公司（附录）
- **问题**: 市政府只给 3000 万开办费，百亿级开发钱从哪来？
- **方法论的使用**: 土地划转作资本金（财政空转、土地实转）→45% 股权引外资（中国银行香港分行、招商局、人保等）→1993 年上市。三管齐下解决资本金，再以资本金撬动贷款。
- **结果**: 到 2000 年三公司各成实际投资七八百亿、资产上千亿的主体。

3. 讨论"合肥模式""深圳模式"等政府风投话题

### 与相邻 skill 的区分

- 与 `capital-market-health-diagnosis` 的区别：资本市场的制度环境是本范式的前提（定增、上市退出通道），制度诊断是环境评估，本范式是操作模式。
- 与 `source-governance-thinking` 的区别：招商内卷（补贴竞赛）是广泛长期问题，源头解法之一即把让利改成入股——本范式是其在招商领域的具体化。

## E — 可执行步骤 (Execution)

1. **算补贴账**：把传统方案（土地+补贴+税收返还）的让利总额算出来
   - 完成标准: 让利总额与换来的承诺（投资额、税收、就业）有对照
2. **改股比结构**：设计政府出资作为股权（定增/基金份额）+撬动贷款的杠杆结构
   - 完成标准: 资本金、贷款、总投资的比例结构成文
3. **定收益与退出**：政府收益来自股权增值/分红/税收的测算，退出通道与期限前置
   - 完成标准: 收益测算含保守/中性/乐观三档
4. **设失败处置**：核销、重组、股权让渡的预案
   - 完成标准: 失败情形的处置与止损线成文
   - 判停条件: 项目无法接受股权形态（如要求固定回报兜底）→ 回归纯让利谈判并下调规格，不做隐性担保

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把资本招商当万能——它要求政府有投行能力与市场化的项目甄别，能力不足处会变成新的坏账源
- 用政府信用给项目隐性兜底——那就退化为风险更大的补贴变体

### 作者在书中警告的失败模式

- 财政资金直接补贴式的"招商引资竞赛"——同质竞争、产能过剩（ce05 同族），且吸引来的是套利者
- 只讲成功案例不讲失败处置——京东方是幸存者叙事，政府股权投资组合必须按组合管理而非单案神话

### 作者的盲点 / 时代局限

- 对政府投资决策机制的专业性要求着墨少（谁来甄别、谁担责）；重庆案例有自证色彩
- 地方债务约束下的出资能力未纳入框架

### 容易混淆的邻近方法论

- 与新加坡淡马锡模式：淡马锡是常设国资运营，资本招商是项目级引入——规模、目标、治理都不同
