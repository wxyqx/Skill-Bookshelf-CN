# 贸易失衡的价值链拆账法

## R — 原文 (Reading)

> "组装加工收入只有60美元，区区12%的代工附加收入，让美国跨国公司获取了丰富的中国制[造业比较利益]"；中国对美出口的产品，60%是美国企业在华生产的产品返销美国。
>
> — 黄奇帆，《分析与思考》第12讲

---

## I — 方法论骨架 (Interpretation)

贸易差额是海关口径，利益分配是价值链口径——两者严重错位，拆账法把争议从叙事拉回数字：

1. **拆一笔代表性商品**：把总价分解为原材料零部件（250）、品牌研发（110）、物流销售（80）、组装加工（60）——各段归谁、各自增加值多少。500 美元笔记本中国代工只得 60 美元（12%）。
2. **算三笔结构账**：①返销占比——中国对美出口 60% 是美企在华生产返销（顺差里有对方自己的成分）；②增加值率——代工组装的本地增加值远低于账面出口额；③统计口径差——双方对逆差数字本身有分歧（4000 亿 vs 3000 亿）。
3. **追深层原因**：逆差的根源清单——对方储蓄率不足（1.8%）、产业互补、跨国公司布局、出口管制（10 大类 3000 多种）、储备货币国输出美元的必然。
4. **出结论**：把"谁吃亏"改写成"各环节各得了多少、错位在哪一段"。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 驳"入世美国吃亏论"（第12讲）
- **问题**: 中美贸易逆差 4 倍增长是美国吃亏吗？
- **方法论的使用**: 拆账——60% 返销+12% 代工增加值+对方出口管制自断出口，账面逆差的实际利益大多归美方企业。
- **结论**: 逆差是结构结果不是单向损失。

### 案例 2: 结算枢纽的隐性利益（第10讲）
- **问题**: 加工贸易的钱被谁赚走？
- **方法论的使用**: 中国 1.8 万亿美元加工贸易结算在境外（新加坡 4000 亿、香港 3000 亿）——连结算环节的金融利益也在境外。
- **结论**: 价值链拆到金融环节才完整。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分析贸易摩擦新闻中"谁吃亏"的争论，写有数字的评论或报告
2. 代工/品牌企业谈判利益分配（代工费、品牌溢价）
3. 评估本地招商引资项目的真实增加值（防"过路财神"）
4. 理解"账面顺差大但赚钱少"的产业现象

### 语言信号 (用户的话里出现这些就应激活)

- "贸易战谁吃亏""顺差逆差""代工能赚多少""关税谁买单"
- "trade deficit" / "value capture" / "附加值"

### 与相邻 skill 的区分

- 与 `three-zeros-trade-rules` 的区别：拆账法算利益分配（钱谁赚了），三零算规则结构（关税怎么加）——一个微观利益一个宏观规则。
- 与 `chain-power-analysis` 的区别：链权法定性权力位置（为什么品牌拿大头），拆账法量化利益（大头是多少、在哪段）。

## E — 可执行步骤 (Execution)

1. **选代表品**：挑出争议贸易额中占比高、结构典型的 1-2 种商品
   - 完成标准: 代表品有 BOM（物料成本）或价值链拆分数据来源
2. **拆价值段**：原材料/核心零部件/品牌研发/物流销售/组装加工各段金额与归属方
   - 完成标准: 每段有金额、归属方与依据
   - 判停条件: 关键段数据缺失 → 用区间估计并标注不确定性，不得只算可得段
3. **算错位**：账面顺差/逆差 vs 本地增加值、返销占比、结算流向
   - 完成标准: "名义数字"与"实际利益"的错位有量化对比
4. **重写结论**：把叙事性争论改写为结构结论
   - 完成标准: 结论可被反方用同样拆账法检验（可证伪）

## B — 边界 (Boundary) ★

### 不要在以下情况用此 skill

- 把"增加值低"直接等同"吃亏"——就业、税收、配套生态是组装段的另一面收益，要一起算
- 单品拆账外推全行业——不同品类价值链结构差异大，需分层抽样

### 作者在书中警告的失败模式

- 只看海关口径的总量差额就下"谁吃亏"结论（方法针对的核心错误）
- 驳论时立场先行（作者自己也难完全避免）——拆账的价值在可证伪，别把拆账变成新叙事

### 作者的盲点 / 时代局限

- 拆账只算了商品价值链，未算技术封锁下的替代成本与安全溢价
- 对中国代工环节的升级路径（从 12% 到更高）着墨少

### 容易混淆的邻近方法论

- 与增加值贸易核算（TiVA/OECD）：TiVA 是国家层面的统计体系，本法是单品/单争议的快速拆算工具
