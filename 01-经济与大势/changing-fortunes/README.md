# 时运变迁 · [`changing-fortunes/`](./)

- **作者**：保罗·沃尔克 & 行天丰雄 · 1992（Changing Fortunes: The World's Money and the Threat to American Leadership；美联储前主席 × 日本大藏省前财务官的双当事人回忆录）
- **主题**：国际货币体系 / 危机管理 / 承诺与信誉 / 谈判与协调
- **一句话**：战后国际货币体系的兴衰反复证明，稳定的货币秩序只能来自"纪律 + 承诺 + 大国协调"，三者缺一都不可持续——特里芬难题、广场协议、拉美债务危机是同一条主线的三种面孔。
- **Skills**：14 个（全部通过跨域/预测力/独特性三重验证与独立盲测压力测试，84/84 用例通过）
