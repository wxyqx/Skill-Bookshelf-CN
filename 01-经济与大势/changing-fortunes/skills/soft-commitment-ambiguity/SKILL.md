# 软承诺与模糊工程——公开模糊、内部锚定，防投机攻击

## R — 原文 (Reading)

> 他们普遍赞成双方都要尽力把汇率"波动"幅度保持在5%，即上下各2.5%的范围。如果汇率变化超出上述范围，七国将采取一致性外汇市场干预……为了保护汇率，七国保证将提供120亿可动用款。
>
> — 保罗·沃尔克，第9章（1987年2月卢浮宫协议——从未公开承认的软目标区）

---

## I — 方法论骨架 (Interpretation)

对市场或对手敏感的承诺，精确公开本身就是制造攻击靶子：公布了精确底线，对手只需测试一次边界就能对你做"单向打赌"。解法是把承诺拆成两层：

1. **公开层刻意模糊**：目标范围不公布、不书面确认、保持"有限制的、暂时的、未被承认的"状态；公报措辞逐词软化（"某些"、"有秩序"、"当有帮助时"）。
2. **内部层精确锚定**：精确数字只放在不公开的副手级文件里，供决策者自己掌握行动阈值。
3. **响应规则非机械**：越界先启动协商与政策重估通道，而非机械式全面保卫——保留解释权。
4. **调幅纪律**：每次调整的幅度远小于宣称波幅的宽度，让试探者无法从你的响应中反推出精确边界、无法押注单边。
5. **公报期望值管理**：没有真正重要的内容就不发公报；仪式化地重复同一场承诺会透支它的可信度，等到真需要表态时市场已经不听。
6. **承认代价与前提**：模糊的代价是约束力弱——软承诺既躲开了投机靶子，也失去了真承诺的约束效果；且模糊只对"真心打算守"的承诺成立，若本不打算兑现，市场测试一次即穿。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1985年9月广场公报的措辞工程
- **问题**: 五国要联合引导美元贬值，但公报若写出精确目标价与干预上限，市场会立刻围绕数字做单向押注。
- **方法论的使用**: 公报逐词谈判——"某些"升值保留直率余地、"有秩序"由联储坚持加入以排除无序贬值的解读；精确数字（贬值10-12%的幅度、180亿美元干预上限）只放进不公开的副手报告。
- **结论**: 公开层只给方向与决心，精确锚留在内部。
- **结果**: 市场读到的是五国一致意图的强信号，却没有可攻击的数字靶子；六周内美元对日元贬12%。

### 案例 2: 1987年2月卢浮宫协议——从未公开承认的软目标区
- **问题**: 广场后美元跌过头，协调重心转向稳定汇率，但公开目标区会给投机者提供过于诱人的靶子。
- **方法论的使用**: 设定未公布的中心价±2.5%参考范围，无书面确认，"有限制的、暂时的、未被承认的"；越范围先协商修改而非机械保卫，公报只说"需要重新评价政策"。
- **结论**: 模糊设计自始内含弱点——约束力完全依赖各国基本面承诺是否真诚。
- **结果**: 美国财政承诺自签署起就无意兑现（宣誓2.3%、实际3.2%），德日亦不配合，数周后日元升破范围，协调实验在黑色星期一后收场——模糊躲开了靶子，却也没有产生任何真约束。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户为关键系统/关系设定"红线"或底线（安全红线、价格底线、回撤线、违约阈值），担心精确公开后会被逐级试探。
2. 用户在起草公报、公告、联合声明，逐词纠结措辞软硬，或纠结"精确数字写不写进去、写在哪一层"。
3. 用户被要求"再发一次声明稳住预期"，但并没有新实质内容，纠结发不发。

### 语言信号 (用户的话里出现这些就应激活)

- "这条红线一公布，对面肯定先试探一下边界"
- "精确数字要不要写进公告/写进书面？"
- "措辞再软一点，别把话说死，留有余地"
- "没有新进展还要不要再发一次声明？"
- 英文: keep them guessing / strategic ambiguity / don't publish the number / soft target

### 与相邻 skill 的区分

- 与 `strong-commitment-intervention` 的区别: 那个靠高调、宏大、公开打包的强度压垮预期；本 skill 靠刻意模糊不给对手靶子。判断依据：市场需要的是"压垮旧预期的强信号"（选强承诺）还是"防止被单向测试"（选模糊）。
- 与 `commitment-device-design` 的区别: 那个追求可信的硬约束（断退路、制度化、同日互证），本 skill 是自知无硬约束时的防御性模糊——两者的取舍点是"你守这个承诺的诚意与能力"。
- 与 `eliminate-exit-leverage` 的区别: 那个是关闭对手退路制造强制力；本 skill 是隐藏自己的底牌不被测试，属防御而非强制。

## E — 可执行步骤 (Execution)

1. **判定承诺是否属于"敏感型"**
   - 检验：公开精确值是否会让对手只需测试一次边界就获得可下注的确定性？
   - 完成标准: 明确回答"是/否"；若否（对手需要精确度才能合作，如合同、技术标准），不适用本 skill。

2. **设计两层结构**
   - 公开层：方向性、软措辞、不书面确认；内部层：精确锚（数字、阈值）放在非公开文件，仅决策层掌握。
   - 完成标准: 产出两层文本——对外公报稿与内部阈值表，且对外文本不含可下注的精确数。

3. **设定非机械响应规则**
   - 越界动作 = 先启动协商/重估通道，而非自动全面反击；每次实际调整幅度刻意小于宣称波幅宽度。
   - 完成标准: 写出"越界→响应"流程图，且响应档位之间不可被外部反推。

4. **公报纪律**
   - 无实质内容不发公报；同一承诺不仪式化重复宣示。
   - 完成标准: 给出发布/不发布的判断标准（有无新增行动或新信息）。

5. **真诚校验（判停）**
   - 问：我们真打算守住这个模糊承诺吗？若内部已决定不守，模糊只是掩盖。
   - 判停条件: 若不打算守，停止使用本 skill——不真诚的软承诺被测试一次即穿（卢浮宫教训），转而要么用 commitment-device-design 建立真承诺，要么公开调整立场。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 目标是建立自身长期信誉：制度性承诺需要精确、公开、断退路（金本位锚、货币局、公开的通胀目标），模糊恰恰是信誉的敌人——此时应使用 `commitment-device-design`。
- 合作方依赖你的精确承诺才能行动（合同条款、接口规范、赔付标准）：模糊会把不确定性转嫁给合作方。
- 需要市场压垮旧预期的高调一揽子出击：见 `strong-commitment-intervention`。

### 作者在书中警告的失败模式

- **承诺不真诚 + 模糊 = 一次即穿**（第9章，ce15）: 卢浮宫美国宣誓赤字降到GNP 2.3%实则无意兑现（实际3.2%），软目标区数周即被日元升破——模糊的约束力完全依赖真诚，作者当面质疑贝克只得到"必须重申总统立场"。
- **模糊既躲开靶子也失去真约束**（第9章）: 软目标区防住了投机者的单向打赌，却让德日得以推诿，协调实验无疾而终——模糊的代价不是免费的。
- **公报透支**（第8-9章）: 协调公报后行动持续落空，市场期望被透支，后续声明失去移动市场的能力（1987年"圣诞公报"收场）。

### 作者的盲点 / 时代局限

- **对软目标区的评价受写作时点限制**: 作者仍寄望以更真诚的软目标区/宽幅目标区稳定汇率，对欧洲货币联盟乐观（认为区域货币一体化可提供更硬的锚）——随后 ERM 危机与欧元区主权债务危机部分证伪了这条路径的乐观预期。
- **透明度环境的变迁**: 1992年前"不书面确认、副手报告"的模糊操作在后来的高透明度监管与即时信息环境下可维持性大幅下降，作者未讨论模糊策略对公众问责的副作用。
- **视角局限**: 模糊的成本由市场参与者与小国承担（他们无法知晓真实政策意图），双作者的决策精英视角未充分讨论这一点；未涉及中国等新兴市场定价者的出现。

### 容易混淆的邻近方法论

- `commitment-device-design`: 硬承诺建信誉 vs 软承诺防试探，方向相反的两种承诺设计。
- `strong-commitment-intervention`: 公开强打包 vs 公开模糊，市场沟通光谱的两端。
- `paradigm-failure-discipline`: 那个处理旧工具失效时换范式，本 skill 处理承诺的公开方式，不在同一层。
