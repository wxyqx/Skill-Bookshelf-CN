  type: framework
  source_chapter: Ⅰ第二讲
  source_quote: |
    科尔奈四分法：行政协调（ⅠA 直接行政控制／ⅠB 间接行政控制）与市场协调（ⅡA 无宏观控制的市场协调／ⅡB 有宏观控制的市场协调）——作者取ⅡB。
  summary: |
    为经济体定位的四象限坐标：按资源配置的协调方式（行政 vs 市场）与宏观控制有无（直接/间接、无/有）分四象限。改革目标=ⅡB（有宏观控制的市场协调）。配套计划经济两隐含前提检验（完全信息假定+单一利益主体假定不成立→信息/激励成本无限大）。用于判断一国改革所处象限与目标象限的差距。
  tags: [core-theory, comparative-systems]

- id: f02
  title: 行政性分权 vs 经济性分权
  type: framework
  source_chapter: Ⅰ第七讲、Ⅱ第二章
  source_quote: |
    行政性分权仍是行政协调，经济性分权使企业独立——1958、1970 年两次"体制下放"皆以混乱和再集中告终，"放—乱—收—死"。
  summary: |
    分权类型学的关键区分：行政性分权（中央向地方层层放权，不改变行政协调本质）必陷"放—乱—收—死"循环；经济性分权（微观决策权还给面向市场的企业）才是效率来源。分权制三前提：统一市场为基础、三大总量权（财政金融外汇）归中央、财政收入与企业隶属脱钩。用于诊断央地关系改革反复的根源。
  tags: [core-theory, decentralization]

- id: f03
  title: 改革战略三阶段
  type: framework
  source_chapter: Ⅱ第二章
  source_quote: |
    三阶段：1958-1978 行政性分权；1979-1993 增量改革；1994 至今整体推进——增量改革战略"不动国有存量，在体制外发展民营经济"。
  summary: |
    中国改革战略的分期框架：①行政性分权期（放乱收死）；②增量改革期（不动存量、体制外生长民营经济——近似科尔奈战略 A 有机发展而非 B 加速私有化）；③整体推进期（1994 起价税财金贸配套）。每阶段的成就与隐患不同：增量改革成功催生民营经济，但双轨制租金结构埋下权贵资本主义。
  tags: [reform-strategy, periodization]

- id: f04
  title: 增量改革与双轨制寻租
  type: framework
  source_chapter: Ⅱ第二章、第十一 章；Ⅰ第四讲
  source_quote: |
    学者估算中国租金总额占 GDP 20%-30%，年达 4 万亿-5 万亿元——行政管制创租、寻租、设租的恶性循环。
  summary: |
    增量改革的双面性分析：正面（存量稳定、民营生长、阻力最小化）与代价（双轨并存=权力货币化=寻租环境；官倒凭批条外汇额度暴富）。寻租恶性循环：管制创租→寻租→设租→更多管制。租金/GDP 比率是腐败程度标志。两条收敛前途：法治的市场经济 or 权贵资本主义。
  tags: [rent-seeking, reform-strategy]

- id: f05
  title: 国企改革两难（放权让利的失败）
  type: framework
  source_chapter: Ⅱ第四章；Ⅰ第三讲
  source_quote: |
    "放权则内部人控制、收权则改革落空"——不改变国有制基本制度框架而试图改善治理，必然陷入两难。
  summary: |
    国企改革的诊断框架：①传统国企四大特点（国家辛迪加基层单位、多重目标、五龙治水、软预算约束）→"不存在本来意义上的企业"；②放权让利三种形式（下放/扩权/承包）共同失败机制=剩余控制权与索取权错配、剩余权被内部人分享；③出路三配合（民营企业成长+国资退出+公司治理），公司治理五件套与两类代理问题；④"剥离上市"的治理缺陷（存续企业掏空上市公司）。
  tags: [soe, corporate-governance]

- id: f06
  title: 增长模式转变（粗放→集约）
  type: framework
  source_chapter: Ⅲ第一至四章
  source_quote: |
    苏联现象：一方面是庞大的教育研究和开发体系，一方面是越来越低的增长率和全要素生产率——庞大的研发体系在缺乏适宜制度条件的情况下无法提供足够激励。
  summary: |
    增长模式的分析框架：①早期增长（资本深化驱动，列宁-霍夫曼-哈罗德多马理论只适用此阶段）vs 现代增长（效率驱动，索洛余量/TFP 主导）；②ICOR 递增=资本驱动不可持续的判据（东亚危机前 5 倍、中国 5-7 倍）；③效率三大源泉（与科学相关的技术、服务业尤其生产性服务业、ICT 改造）+共同制度基础（科研制度化+法治）；④粗放回潮的四项体制遗产（政绩考核、政府配置权、财政分成、要素价格扭曲）与六项消极后果。
  tags: [core-theory, growth]

- id: f07
  title: 出口导向战略的成败条件
  type: framework
  source_chapter: Ⅲ第五章
  source_quote: |
    以汇率低估为特征的出口导向政策的延续，使中国外部经济失衡加剧——台湾"太迟又太少"的升值导致万点泡沫腰斩。
  summary: |
    出口导向战略的动态评估框架：①成功条件（刘易斯拐点前、剩余劳动力充足、技术成长初期）；②微观代价（加工贸易锁定低端、Made in China ≠ Made by China、罗技鼠标 3/40 美元）；③宏观传导链（顺差→升值压力→央行购汇→高能货币超发→资产泡沫/通胀→系统性风险）；④东亚镜鉴（日本、台湾"太迟又太少"的升值）；⑤动态比较优势 vs 静态比较优势（斯蒂格利茨：专业化锁定削弱长期增长）。
  tags: [trade-strategy, exchange-rate]

- id: f08
  title: 整体协调改革论
  type: framework
  source_chapter: Ⅰ第六讲、第十二讲
  source_quote: |
    经济不能"停机修配"，但可分步骤、每步保持协调；"异体排斥"——交通规则只能全体统一改向，不能部分右行部分左行。
  summary: |
    改革方法论：①整体协调论（横向：企业-市场-宏观同步配套；纵向：前后衔接；分两步走——先搭框架后完善）；②四大反对（单项突破、普遍试点〔合成谬误〕、区域推进、双轨制过渡）；③随机控制批判（"过黄河长江须造船建桥"而非摸石头）；④宽松环境论（"管住货币，放开价格"——总供求大致平衡是配套改革前提）；⑤大道定理（宁绕路上高速）。
  tags: [reform-methodology]

- id: f09
  title: 法治的市场经济（两种前途）
  type: framework
  source_chapter: Ⅱ第十一章；Ⅲ第六章
  source_quote: |
    转变增长模式最终取决于政府自身改革的成效——越位、错位和不到位；法治三要件：法律是惩罚唯一依据、无人凌驾于法律之上、法庭是个人权利最后防线。
  summary: |
    改革前途的判断与建设框架：①两种前途（法治的市场经济 vs 权贵资本主义）取决于政府改革；②有限政府（限制配置资源与微观干预的权力；非禁即入）+有效政府（四职能：法治环境、宏观稳定、社保公平、补市场失灵）；③法治三要件 ≠ 法家 rule by law；④双轨既得利益与受损弱势的"合流"风险（前者要管制保特权、后者被误导反市场化）。
  tags: [rule-of-law, government, core-theory]

  title: 金融压制与股市功能错位
  type: framework
  source_chapter: Ⅱ第六章
  source_quote: |
    股市功能定位为国企圈钱＋审批制监管——合规性监管（强制披露）与实质性审批两条路线的对立；"政府托市、国企圈钱"。
  summary: |
    金融体系的诊断框架：①麦金农-肖金融压制/深化与斯蒂格利茨金融约束的光谱（利率管制的双重效应）；②股市病灶=功能定位错误（融资服务国企）+股权分置+审批制催生寻租与庄家→"狂热—恐慌—崩盘"循环；③监管路线之争：合规性监管（强制披露）vs 实质性审批；④银行改革的对内开放缺位（民营银行准入）。
