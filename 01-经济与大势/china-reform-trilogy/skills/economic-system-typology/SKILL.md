# 经济体制四象限（科尔奈四分法）

## R — 原文 (Reading)

> 科尔奈四分法：行政协调（ⅠA 直接行政控制／ⅠB 间接行政控制）与市场协调（ⅡA 无宏观控制的市场协调／ⅡB 有宏观控制的市场协调）——作者的目标模式取ⅡB。
>
> — 吴敬琏，《中国改革三部曲》Ⅰ第二讲（要点组织）

---

## I — 方法论骨架 (Interpretation)

讨论"计划还是市场"前，先用四象限给经济体精确定位：

1. **两维坐标**：横轴=资源配置的协调方式（行政协调 vs 市场协调）；纵轴=宏观控制的形态。四象限：ⅠA 直接行政控制（苏联式命令经济）、ⅠB 间接行政控制（匈牙利式——行政机构用经济杠杆做微观干预）、ⅡA 无宏观控制的市场协调（自由放任）、ⅡB 有宏观控制的市场协调（作者的目标模式）；
2. **计划经济的两隐含前提检验**：命令经济要运转必须①完全信息（计划机关掌握一切供需变量）②单一利益主体（全社会利益一致）——两者都不成立，故信息成本与激励成本"几乎无限大"，低效是制度性的；
3. **ⅠB 的陷阱**：匈牙利案例——不放掉微观干预只换干预手段（"部长的电话代替指令性计划"），价格越扭曲→再分配越广→价格越扭曲的恶性循环。改革的分水岭不是手段软硬，而是微观决策权是否还给企业；
4. **ⅡB 不等于ⅡA**：有宏观控制的市场协调承认市场失灵五论（外部性、公共品、周期波动等），宏观管理是总量管理而非一户一率的微观干预。

## A1 — 书中的应用 (Past Application)

### 案例 1: 苏东改革的象限诊断（Ⅰ第二讲、Ⅱ第一章）
- **问题**: 苏东各国改革为什么普遍失败？
- **方法论的使用**: 象限定位——苏联留在ⅠA，南斯拉夫跌入变形的ⅡA（无所有者的所有制+多中心割裂市场），匈牙利困在ⅠB（间接行政控制）——没有一个真正到达ⅡB。
- **结论**: 失败的共同点是未确立竞争性市场+硬预算约束。

### 案例 2: 兰格-布鲁斯-锡克理论谱系（Ⅰ第二讲）
- **问题**: 市场社会主义理论为何逐级演进？
- **方法论的使用**: 兰格（信息机制：模拟市场）→布鲁斯（决策机制：分权模式）→锡克（利益机制：完整市场）——每代理论补上前一代的短板，逼近ⅡB。
- **结论**: 模拟市场走不通，利益机制是市场协调的根基。

## E — 可执行步骤 (Execution)

1. **测协调方式**：微观决策（生产、投资、定价）实际由谁做出
   - 完成标准: 行政协调占比与市场协调占比有证据
2. **测宏观控制**：总量管理是否存在、是直接指令还是参数调节
   - 完成标准: 四象限定位完成（ⅠA/ⅠB/ⅡA/ⅡB）
3. **验两前提**：检查是否仍以"完全信息+单一利益主体"假定运行政策
   - 完成标准: 政策文本中的隐含假定被识别
   - 判停条件: 定位为ⅡB → 检查目标达成度后终止
4. **给差距与路径**：当前象限→目标象限（ⅡB）的迁移障碍清单
   - 完成标准: 障碍按"决策权归属、价格体系、预算约束"三类列出

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把四象限当静止标签——经济体常处于象限间的混合态，定位要注明"主要协调方式"
- 用ⅡB 概念为任何"有管理的市场"背书——ⅠB 与ⅡB 的区别恰在微观干预之有无，这是最易被滥用的模糊地带

### 作者在书中警告的失败模式

- 匈牙利式ⅠB 陷阱：间接行政控制被误认为市场化（qe01）
- 兰格式模拟市场：用计算机求解价格而无利益机制——信息机制不能替代激励机制

### 作者的盲点 / 时代局限

- ⅡB 中"宏观管理"与行政干预的边界无可操作判据（作者自认），政府参数论隐含政府仁慈理性假设
- 对混合象限（现实中多数经济体）的动态迁移机制刻画不足

### 容易混淆的邻近方法论

- 与"社会主义市场经济"官方表述：官方表述是目标宣示，四象限是定位工具——宣示≠定位
