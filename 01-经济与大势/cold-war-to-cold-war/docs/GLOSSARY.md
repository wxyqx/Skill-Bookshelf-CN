# GLOSSARY — 《从"老冷战"到"新冷战"》共享术语词典

> 温铁军（冷战系列）的特定用法。与八次危机卷词典同源互通，与黄奇帆两卷体系不同。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **全球化三阶段** | 殖民主义（贸易白银）→产业资本（原材料市场，"在国化"）→金融资本（货币体系与话语权）；切换由危机驱动 | ≠ 一体化进程；是竞争烈度递增的三个阶段 |
| **在国化** | 产业资本以国家为单位积聚并受幅员局限；生产过剩必外转，极端形式是战争 | ≠ 国产化；是产业资本与国家主权的绑定 |
| **金融法西斯主义** | 金融不参与生产却占数十倍收益、排斥一切实体、以文化制度手段使剥夺"自然化" | ≠ 批判修辞；有排斥性+话语包装+军工复合体的机制定义 |
| **需要而非强迫的剥夺** | 各国因需要美元结算与产业转移而"自愿"被剥夺 | ≠ 军事殖民；更大量更隐蔽更稳固 |
| **非货币化** | 苏东体制：计划调拨物资，货币不承担交易与获利工具职能 | ≠ 没有货币；是货币不承担金融职能 |
| **定价收益** | 无定价资产被硬通货低价收购后重新货币化的巨额收益 | ≠ 投机利润；是"定价权差"的系统性占有 |
| **鲸落** | 苏东体系崩溃养肥 90 年代西方高增长与新经济（军事技术解密民用=机会收益） | ≠ 危机外溢；强调单向收益转移 |
| **驾辕** | 三驾马车的主从结构：内需/外需/投资轮番主引擎（中国 80/90/新世纪） | ≠ 三驾马车并列；强调主从与切换条件 |
| **荷兰病** | 一个行业的暴利（金融）把另一个行业（实体）挤死 | ≠ 一般产业空心化；强调暴利虹吸机制 |
| **资源性资产货币化** | 主权可控的生态/资源资产转为可交易实体资产；人民币改锚国内资产 | ≠ 土地财政；是货币增发条件的内移 |
| **文明冲突论** | 西方把对华竞争描述为体系外文明冲突的意识形态划界；应对是客观归纳自身多元性 | ≠ 文化差异描述；是话语战场的划界行为 |
