## 1. 结构 (Structural)

### 类型
方法论 / 实操手册（财报分析框架体系）

### 一句话主旨
把三张财务报表从"会计数字"还原成"企业故事"：先看战略与资源（钱从哪来、投向哪），再看效益质量与现金含量，最后落到风险与前景，全程以母公司报表与合并报表的对照为根基。

### 骨架（主要论点及其关系）

1. **基础认知（第 1-4 章）**：三张报表各自讲什么（底子/面子/日子，实力/能力/活力）；企业设立与经营业务如何逐笔进入三表；传统比率分析法（杜邦体系、美国经验值）对解释企业竞争力存在困局，必须突破。
2. **八看体系（第 5-12 章）**：看战略（资产结构定战略类型）→ 看经营资产管理与竞争力（两头吃、周转链条）→ 看效益和质量（三个净利润分工、三支柱两减值、核心利润获现率 1.2~1.5 倍）→ 看价值（入资三重效应、股权定价）→ 看成本决定机制（治理—决策—管理—核算四层）→ 看财务状况质量（资产质量三层面、补偿机制）→ 看风险（金融负债率拆解、过度融资五信号、治理风险）→ 看前景（三表勾稽、五途径）。
3. **综合示范（第 13 章）**：以恒瑞医药为例完整演示四阶段分析流程（背景分析→审计意见与会计分析→比率+战略八步→前景预测）。

**论点之间的关系**: 递进 + 并列——第 1-4 章立地基（母公司报表为基础、业务-报表联动），第 5-12 章八个视角并列展开，第 13 章收束为可复制的全流程。

### 作者要解决的核心问题
现有财报分析体系（比率分析、美国经验值）只能算数字、不能解读企业管理质量与竞争力——如何建立一套"从报表结构反推企业战略、管理、风险、前景"的可操作方法？

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法，详见 GLOSSARY）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 经营资产/投资资产 | 母公司报表口径下资产二分：与企业自身经营相关 vs 对外控制性/非控制性投资 | 不是会计科目分类，是按功能重分类 |
| 经营主导型/投资主导型/投资与经营并重型 | 按资产结构对企业战略类型的三分 | 战略不在年报文字里，在资产结构里 |
| 控制性投资 | 母公司对子公司的长期股权投资，在合并报表被"展开" | 母公司报表数字≠合并报表数字的原因 |
| 核心利润 | 母公司口径：营业收入-营业成本-税金及附加-销售管理研发财务费用（三支柱两减值体系的核心） | 区别于营业利润/净利润，剔除杂项收益 |
| 核心利润获现率 | 经营活动现金流量净额 / 核心利润，健康区间 1.2~1.5 | 检验利润现金含量的本书独创比率 |
| 两头吃 | 同时占用上游供应商货款与下游经销商预收款 | 无偿占用上下游资金的竞争力信号 |
| 越合并越小 | 母公司报表资产大于合并报表资产的现象（子公司亏损或被抽空） | 与"合并>母公司"直觉相反的诊断信号 |
| 财务状况质量 | 资产质量、资本结构质量、利润质量、现金流量的系统质量观 | 不是"好不好看"，是有没有水分与造血力 |

### 核心命题（用自己的话）
1. 战略写在资产结构里：经营资产与投资资产的比例直接对应经营主导/投资主导战略，先判型再分析。
2. 母公司报表是分析的基础，合并报表是集团全景——只看合并报表会漏掉扩张效应与母公司空心化。
3. 有利润不等于有现金：核心利润必须被 1.2~1.5 倍的经营净现金支撑，否则是纸面利润。
4. 风险的根源常在治理而非财会：大股东占款、过度融资、保壳重组要按报表指纹识别。
5. 前景预测 = 现有盈利能力 + 还没打的牌（重组、并购、投资五途径）。

### 论证链
每个视角都按"报表特征 → 管理含义 → 案例（上市公司真实数据）→ 操作化清单"展开；案例以迈瑞医疗（贯穿）、格力、美的、海尔、恒瑞、乐视（反例）等为主。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 案例多为中国 A 股上市公司（2015-2023 数据），跨境、非上市、金融类企业适用性未展开。
- 经验阈值（1.2~1.5 倍、70% 负债率、其他应收款 1%）来自作者经验归纳，行业差异未系统检验。

### 作者的立场盲点
- 立足外部报表读者视角，对内部管理会计工具（预算、作业成本）着墨少。
- 假设读者能拿到母公司报表——但部分市场（美股）不披露母公司个别报表，方法适用面受限。

### 未被证明的假设
- 报表粉饰是"少数企业"的行为（作者虽给识别法，但未讨论系统性失真下的方法失效）。
- 资产结构能稳定映射战略（跨界转型期企业可能长期混合）。

### 最强反对意见
传统比率分析并非无用：对流动性监管、信用评级等场景它仍是行业标准；本书的"八看"对普通投资者成本偏高，且经验阈值缺乏统计显著性证明。
