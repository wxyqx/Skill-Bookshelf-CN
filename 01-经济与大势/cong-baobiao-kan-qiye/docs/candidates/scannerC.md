# Scanner C（第7-9章）候选

## 第一部分：章节 digest

### 第7章 看效益和质量
本章讨论如何看企业效益与利润质量。核心论点：在有子公司的情况下存在三个净利润（母公司净利润、合并净利润、归属于母公司所有者的净利润），各有分工——分红看母公司净利润（受较低者规则约束）、看集团盈利能力用合并净利润、每股收益与定价用归母净利润；看整个集团效益应主要关注合并报表的核心利润。作者提出利润表分层次认识（毛利→核心利润→营业利润→净利润），并把营业利润结构概括为"三支柱两减值"（核心利润、其他收益、杂项收益＋资产减值损失、信用减值损失），以此判断企业营业利润由什么支撑、产品是否有市场竞争力。利润质量从三方面考察：实现过程（营业收入质量三问：卖什么、卖给谁、靠什么；费用质量强调效用而非片面节约）、利润结构（结构质量、利润与资产的对应、利润与现金流的对应——周转超2次时核心利润应带来1.2～1.5倍经营净现金流量）、利润结果（利润的结果是资产）。重要结论：营业利润与营业收入直接对比的"销售利润率"会严重误导；存货积压可虚增当期利润但埋下亏损隐患；利润必须带来相应现金流量。

### 第8章 看价值
本章讨论非证券交易条件下股东权益价值的确定。框架是把企业股权价值分为入资时的价值和入资后的价值。入资有三重效应：为盈利能力奠定基础、对潜在债务提供保证、协调股东间利益关系；非现金入资的评估增值幅度直接影响股权结构与股东利益。评估方法上，成本法符合资产负债表逻辑但忽略表外资源，适用于表外资源少或表外资源不产生盈利的企业（企业生命周期初始期、没落期）；收益法考虑表内表外资源整合与未来发展，适用于稳定发展期企业，但本质是对未来的估计，质量取决于评估师专业判断与良知；另有市盈率法、市净率法。股权交易定价应站在买方立场，按"整体价值→比例价值→控制权溢价→买方身份与持有目的"四步思考。辅仁药业案例贯穿全章：2017年控股股东以入资式并购强化控制，导致资金占用、债务违约，2023年退市——股权结构重大变化既可能是机遇也可能是不归路的开始。最后给出小金库的三个识别迹象。

### 第9章 看成本决定机制
本章回答成本水平由什么决定。企业成本首先受外部因素影响，内部则由四个层次的因素决定。治理因素：治理层在极大范围内影响企业基本成本费用水平，控制权之争、控股股东违规占用资金与担保造成的损失根源是治理问题而非管理问题（中炬高新、辅仁药业）。决策因素：董事会关于对外投资布局、子公司技术装备与固定资产等资源配置、人力资源薪酬政策、产品质量标准与市场定位的决策，决定了企业未来成本的基本框架，管理层只能在既定框架内挖潜。管理因素：新员工与干部培训（最大人力成本是用错人）、集团资金集中或分散管理（丽珠集团vs中国联通）、班时与差旅等日常管理（苹果汁厂缩短班时）。核算因素：生产成本费用分摊标准的选择是专业判断而非唯一正确，成本是一个范围而不是一个点；资产减值与信用减值的确认同样是专业判断，可能被用于择机调节利润（世纪华通商誉减值）。结论：远离高商誉并购的企业；财报分析能力让投资者远离财务陷阱。
