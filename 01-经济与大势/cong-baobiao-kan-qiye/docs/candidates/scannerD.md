# Scanner D（第10-13章）候选

## 第一部分：章节 digest

### 第10章 看财务状况质量
本章是全书方法论的收束章，核心论点：财务报表分析的落脚点是判断企业"财务状况的质量"，而资产质量必须从整体、结构、个体三个层面考察。整体质量看资产能否为股东权益的非入资性增值（利润积累+其他综合收益）做贡献；结构质量看经营资产系统优化（固定资产—存货—核心利润—经营净现金四环节适配）与控制性投资、业务板块的盈利能力优化；个体质量的标准是"满足需求"——资产物理质量再好，满足不了企业特定需求就是不良资产。作者随后给出五大分析基础原则（历史成本、公允价值、客观性、重大性、稳健性），并强调融资保障用公允价值、绩效评价用历史成本。接着逐项展开货币资金（付款全过程控制）、商业债权（规模结构比较、债务人构成、内部经手人"谁干的"）、其他应收款（三分法：正常<1%、子公司占用、母兄弟公司占用）、存货（三张报表联动的"三个脱节"）、流动资产（"两头吃"竞争优势）、无形资产（自创成本与受益期难定导致表内资源表外化）、投资资产（成本法/权益法泡沫利润、地域/业务/持股结构）、资本结构（股权结构决定战略、负债与项目对应性、"四度"分析）。本章还提出重组财务效应分析（三种效应，核心是持续盈利能力）、税务规划效应（递延所得税所在方向有含义），并给出独创的现金流量表分析起点——投资活动现金流出量的补偿机制，以及合并报表的四大特征（合并主体不存在、比率常失意义等）与财务比率运用的科学性检查。重要结论：权益法投资收益永远是泡沫利润；核心利润获现率（经营净现金/核心利润，存货周转>2次时应达1.2~1.5倍）是利润质量的试金石。

### 第11章 看风险
本章建立以报表为基础的风险识别框架。核心论点：报表风险分经营风险与财务风险两类，分别对应两条线——"经营资产→核心利润→经营净现金"和"控制性投资→子公司经营资产→子公司核心利润→子公司经营净现金"。经营风险看流动资产负债关系（实质是上下游关系管理）、毛利率、存货周转率、核心利润率、核心利润获现率；财务风险看资产负债率、债务结构（贷款与商业负债）、综合盈利能力。作者提出重要修正：资产负债率70%是实践中重要的风险界限；但预收款项等经营性负债含毛利会夸大真实负债，真正可怕的是资产金融（有息）负债率；利息保障倍数实际衡量的是贷款融资效用而非偿债能力；经营风险与财务风险不割裂——经营风险低的企业财务风险不可能高，银行放贷看"三品"（人品、产品、押品）本质是治理、盈利能力与保障手段。本章进一步提出利润结构与资产结构的对应分析（三支柱两减值：核心利润、杂项收益、其他收益），用结构性报酬率找出盈利能力弱的资产区域；总结过度融资、过度投资的五项财务表现（"企业不是饿死的，而是撑死的"）；提出四类惯性依赖风险（上下游、组织文化"企业皇帝"、竞争环境、核心业务）与治理风险（股权结构变化、核心人员变更）；最后系统讲解五种审计意见类型及关键审计事项的风险信号价值。结论：治理风险是企业最应关注的风险，审计师的强调段与关键审计事项往往直接标示企业主要风险点。

### 第12章 看前景
本章篇幅短小，是前景预测的方法论收口。首先重申三张报表的勾稽关系：现金流量表是对资产负债表中货币资金变化的展开说明，利润表是对股东权益中未分配利润、盈余公积、资本公积部分内容的展开说明，三张表的核心是资产负债表，因此前景预测以资产负债表为核心。方法分两块：一是基础分析七观察——以母公司资产负债表看资产总规模及"四大动力"归因、经营资产与投资资产比重及控制性投资扩张效应、主要资产变化的方向性含义、主要不良资产区域（闲置固定资产、含潜亏投资、周转缓慢存货与债权）、流动资产对流动负债的保障（看"两头吃"能力而非流动比率）、负债融资发展潜力（重点金融负债率，银行"三品"表明融资能力关键在盈利能力）、母公司与合并三表结合分析集团管理特征与效率。二是前景预测三步法：从经营活动看前景（优化经营资产结构、减少不良占用）、从投资活动看前景（重点是控制性投资，其规模可从合并报表与母公司报表之差看出）、从融资重组并购等手段看前景，后者细分为五种途径：增量贷款（盈利能力强企业的首选）、债转股、股东增量入资（非现金入资要关注估价公允性）、控制权变更与核心人力资源变动、资产置换（可彻底变换行业以提高盈利能力）。结论：前景判断的本质是判断现有资产质量能否支撑良性循环，以及企业还有哪些发展手段可用。

### 第13章 综合案例分析
本章以恒瑞医药2022年年报为对象，演示作者完整的财务状况质量综合分析方法，分析顺序为四阶段流水线：（1）背景分析——综合浏览年报，关注行业、经营战略表述、竞争环境、控制性股东、发展沿革；（2）会计分析——不单独做，通过审计意见类型与措辞间接判断会计质量（本案为标准无保留意见）；（3）战略视角下的财务分析——先做财务比率分析（偿债、盈利、营运三大类，其中核心利润率、资产金融性负债率、核心利润获现率是针对中国报表的独创比率），再做战略与竞争力八步分析：以母公司资产负债表看资产总规模与"四大动力"归因→判定经营主导型/投资主导型/并重型并确定控制性投资规模→主要资产变化的方向性含义→主要不良资产区域（看减值准备）→负债与股东权益的四大动力结构→流动资产对流动负债保障→负债融资潜力（金融负债率）→母公司与合并三表结合看集团管理特征。本案关键演示：剔除战略后备军货币资金后判定恒瑞为经营主导型；测算控制性投资74.94亿元仅撬动子公司增量31.25亿元，扩张效应不大（部分子公司为母公司配套服务）；通过母子公司报表差额还原母公司以其他应收款向子公司提供资金32.77亿元；四大动力排序为利润积累、经营性负债、股东入资、金融性负债，企业可不融资实现自我循环。作者同时示范比率计算的诸多陷阱（减值准备集中披露导致周转率失真、五项目共同推动营业收入使应收账款周转率失真、总资产周转率无意义）。（4）前景预测——总体评价后从三方面预测：强化经营盈利能力、通过控股并购实现产品结构丰富化与地域扩张、以债务融资为主的融资能力改善。
