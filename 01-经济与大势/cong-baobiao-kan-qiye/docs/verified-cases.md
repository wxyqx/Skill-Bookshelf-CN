- id: e03
  type: counter_example
  title: 机械套用美国比率体系及其经验值（流动比率2:1等）会完全误判中国企业
  source_chapter: 第4章、第5章
  source_quote: |
    "该公司流动资产与流动负债的比率（流动比率）约为1.1∶1，远远小于一般美国教材中强调的2∶1这一比较安全的经验数值。"
  summary: |
    警告：把美国教材的经验数值（流动比率2:1、速动比率1:1、资产负债率70%警戒线）当安全标准直接套用于中国企业，会得出"偿债能力差、风险大"的完全错误结论——教学实验中七名学过报表分析的研究生对一家竞争优势极其明显的优质公司正是这样误判的（流动比率约1.1、速动比率约0.9、资产负债率约80%被读成高经营风险高财务风险）。更深层的原因有二：其一，美国主流比率分析基于美国资本市场以合并报表为主的披露特征、服务于投资者估值，从设计目的上就不回答"企业管理得好不好、竞争力在哪里、风险在何处"的问题，用错工具问错问题；其二，经验值没有考虑行业、经营周期、上下游占款能力等中国情境。孤立计算的流动比率、周转率、资产负债率等传统比率脱离企业实际、无法揭示战略，本章的经营资产/投资资产与资本引入框架即是对这一失败模式的替代方案。
  tags: [counter_example, ratio-analysis, experience-value, purpose-mismatch]

- id: e04
  type: counter_example
  title: 比率计算的口径陷阱：原值/净值、合并/母公司与中国披露模式障碍
  source_chapter: 第4章、第6章、第13章
  source_quote: |
    "有的不知道应该用合并报表的数据计算还是用母公司报表的数据计算（如存货周转率）；有的不知道是用原值计算还是用净值计算（如固定资产周转率）。"
  summary: |
    失败模式：传统比率分析只给公式不给口径，面对真实中国上市公司处处踩坑。①固定资产周转率必须用原值：净值随折旧递减会使周转率虚增，极端情况下净值为零但仍在使用时周转速度无穷大，明显不合逻辑，而许多教材故意不写明用原值还是净值；②面对集团公司不知道该用合并报表还是母公司报表数据（如存货周转率），母公司资产中大量货币资金与投资资产还会使总资产周转率、流动资产周转率彻底失去意义；③中国"集中披露"模式只在地主表给减值净额、明细在附注，直接用净额算周转率会错（应回到附注看减值前原值，不可得时宁可近似说明或不算，恒瑞案例中作者对失真大的应收账款周转率选择不计算）。警告：脱离口径教育的比率公式训练培养不出真实分析能力，硬算失真比率不如不算。
  tags: [counter_example, ratio-analysis, caliber, china-context]

- id: e05
  type: counter_example
  title: 杜邦分析体系对投资主导型企业立即失效
  source_chapter: 第4章
  source_quote: |
    "有的公司自己并不从事经营活动，而是从事投资管理活动。在这种情况下，企业利润表的利润支撑点肯定是投资收益，而总资产周转率、毛利率、销售净利率等均没有了计算的数据基础。"
  summary: |
    杜邦体系以净资产收益率为塔尖展开周转率、利润率、负债度，隐含前提是企业以产品或服务经营为主。一旦企业是投资管理型（自身不经营），总资产周转率、毛利率等失去数据基础，体系立即失灵。警告：任何分析方法都有其适用的资产结构前提，选方法前先看企业类型。
  tags: [counter_example, dupont, applicability-limit]

  title: 只算融资成本不算融资收益，误判企业家的股权融资选择
  source_chapter: 第5章
  source_quote: |
    "有的学者做了研究，认为中国企业家的行为很奇怪：在获得同样的融资规模时，不去进行债务融资而是去搞股权融资。……其实这些专家犯了一个根本性、常识性的错误——仅仅从数量上关心融资成本问题，而没有关注融资收益问题。"
  summary: |
    警告：评价融资方式不能只算债务融资节税不稀释的账面成本，证券市场融资带来的融资能力、声誉、联盟资源等"收益"难以计算却可能远超成本（如3亿净资产的企业上市一次募资10亿，还改善当地生存环境）。按纯成本逻辑会把企业家的股权融资选择误判为不理性。
  tags: [counter_example, financing-cost, financing-benefit, misreading]

## 独立 skill 打包建议（从反例池可独立成 skill 的 4 个）

1. **财报造假信号识别**（候选名："财报舞弊信号清单"）
   - 素材：e01（造假发生于盈利不佳、违反常识总纲）、e17（减值择机三手法）、e19（数字积压即造假）、e28（收入与应收背离）、e25（小金库三迹象）、e14（预付款项通道、粉饰随关注度迁移）+ 案例 c21、c48、c50、c57、c59、c75。
   - 理由：六条反例共享"报表粉饰/造假识别"场景，信号均可独立操作化（不依赖全书框架），对投资者避坑与尽调场景跨域性最强，是最值得独立成 skill 的一包。

2. **并购与商誉风险识别**（候选名："并购财报风险扫描"）
   - 素材：e13（高商誉纸面资产与业绩反噬）、e34（零商誉风险转移隐蔽科目）+ 案例 c25、c33、c41、c76。
   - 理由：两条反例构成"高商誉/零商誉"正反两面完整决策清单（看溢价在全部资产科目的分布、看承诺期后、看关键审计事项），主题自洽，独立于通用报表分析。

3. **比率分析避坑指南**（候选名："财务比率常见误用"）
   - 素材：e03（美国经验值失灵）、e04（口径三陷阱）、e05（杜邦失效前提）、e12（应收账款周转率公式级错误）、e16（自由现金流误用）、e18（营业利润率误导）、e23（利息费用失配）+ 案例 c08、c21。
   - 理由：七条反例全是"用错比率"这一单一失败模式，读者群明确（学过传统财务分析的人），每条都给出替代动作，可打包成查错型 skill。

4. **大股东占款与治理风险识别**（候选名："从报表看治理风险"）
   - 素材：e07（占款链条与报表指纹）、e10（股东驱动型预警）、e33（不信人品信治理）、e29（保壳式重组）+ 案例 c14、c15、c44、c49、c50、c69。
   - 理由：五条反例共同指向"风险根源在治理而非财会"，识别信号（其他应收款、股权结构突变、内斗、重组三效应）自成体系；与第 1 包的区别在于第 1 包针对报表粉饰手法，本包针对治理结构性风险。

另注：e08（过度融资五项表现）、e35（现金过多战略困惑）、e09（两头吃双向误读）三条与"风险信号"主题也高度相关，若不想开四个 skill，可将第 4 包扩为"财务风险信号总集"吸收这三条；但按主题聚焦原则，建议维持上述四包切分，e08/e35 归入主 skill 的"风险信号"A 段素材。
