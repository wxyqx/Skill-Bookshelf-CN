  summary: |

  title: 三表通俗定位与一体关系（底子、面子、日子）
  source_chapter: 第1章、第2章
  absorbed: [f06, p07]
  source_quote: |
    “我们可以把资产负债表概括为底子，即企业的家底；把利润表概括为面子，即企业有没有面子看利润表；把现金流量表概括为日子，即企业日子过得怎么样要看现金流量表。”
  summary: |
    每张报表的通俗定位：资产负债表=实力/底子（家底，能用货币表现的资源与权益归属），利润表=能力/面子（资源运用产生的盈利能力），现金流量表=活力/日子（资金的来路与花法、实际生存状态）。作者21世纪初在《解读财务报表——案例分析方法》中提出、被业内广泛采用。推论：企业家在意“脸面”，财务造假的主战场一定是利润表；底子和日子则更难粉饰，故看企业要三表互证，构成对企业“有没有家底、能不能赚钱、日子过得活不活”的递进式快速判断。三表一体的展开关系（吸收f06）：资产负债表是特定时点的存量综合反映，利润表解释股东权益中盈余公积与未分配利润从期初到期末的变化，现金流量表解释资产第一项“货币资金”年度内的变化——任何报表（含股东权益变动表）都是资产负债表某组项目的展开说明，分析以资产负债表为纲，前景预测也以资产负债表为核心。同时注意（吸收p07）：同一概念在三张报表中口径不同（如“投资”在资产负债表与现金流量表内涵不同、现金流量表的现金及现金等价物≠资产负债表货币资金），不能跨表直接划等号。

  title: 控制性投资识别与扩张效应测算（合并-母公司差额法）
  source_chapter: 第3章、第5章、第13章

### 各 skill description 雏形

1. **`eight-lens-statement-analysis`**（f01、f51、f54、p45）：当用户拿到一家公司年报或全套报表，要求"系统分析这家公司""按什么步骤/框架读财报"，或需产出完整分析报告时调用（含四阶段流程、八步清单、比较基准规则）。当用户只问单一报表项目、单一比率或单一风险点时不调用，改用对应专项 skill。
2. **`strategy-from-asset-structure`**（f02、f03、f11、f12）：当需要判断企业战略类型（经营/投资主导）、扩张路径、钱与资源从哪来、评估表外实力、判断该不该上市融资时调用。当只问盈利、偿债等数字结论时不调用。
3. **`capital-source-four-drives`**（f14、p16、p52）：当分析负债与权益来源结构、企业发展动力类型、分红政策是否合理、降杠杆路径时调用。当问题出在资产方（资产质量、周转）时不调用。
4. **`governance-stance-analysis`**（f13、f16、p30、p38）：当怀疑大股东/关联方侵占、发现企业行为与声称战略不符、评估股权与控制权变化影响、需要平衡看待关联交易时调用。当纯讨论经营效率时不调用。
5. **`parent-vs-consolidated-statements`**（f08、f17、f18、f31、p18、p46）：当任何问题涉及母公司报表与合并报表的对比、集团扩张效应测算、"越合并越小"、集团管理模式判别、三个净利润的分工、合并口径比率可用性时调用。当目标是非集团单一主体报表时不调用。
6. **`two-end-eating-working-capital`**（f19、p23、p21、p51、p31）：当评估企业对上下游的占款与议价能力、解读流动比率小于1、分析应收/预收/合同负债/存货周转与结算方式、判断产品是否卖不动时调用。当涉及固定资产等长期资产或负债风险时不调用。
7. **`asset-quality-triage`**（f39、f30、f20、f23、p42、p54、p55）：当需要逐项体检资产质量（货币资金、预付、其他应收款、长期股权投资）、定位不良资产区域、分析资产与利润的结构对应时调用。当问题主要在利润表或现金流量表本身时不调用。
8. **`income-statement-structure-analysis`**（f26、f27、f28、f29）：当需要拆解利润从哪来、判断盈利结构与可持续性（三支柱两减值）、追问收入质量三问时调用。当只问偿债或现金流充分性时不调用。
9. **`core-profit-cash-conversion`**（f21、f22、p19、p20、p44、p57）：当判断利润有没有现金支撑（核心利润获现率 1.2~1.5 倍）、经营净现金够不够用、纠正周转率口径（原值、五大结算项目）时调用。当分析负债结构与偿债风险时不调用。
10. **`valuation-ma-equity-pricing`**（f25、p26、f32、f33、f34、p43）：当遇到并购/增资/出售股权的估值定价、高商誉公司风险评估、评估报告（成本法/收益法）合理性判断时调用。当做日常经营与报表分析时不调用。
11. **`cost-determinants-impairment-attribution`**（f37、f38、p29、p32、p33、p34）：当追问成本费用为什么高、减值损失该归因于决策还是管理、检验研发与费用有效性、识别减值集中计提的利润调节时调用。当分析收入端问题时部分相关但不优先。
12. **`financial-risk-debt-quality`**（f45、p47、p48、p49、p50）：当评估偿债能力与财务风险、判断高资产负债率是否可怕（拆金融负债率）、使用利息保障倍数、评估融资能力时调用。当分析资产质量或扩张冲动时不调用。
13. **`overexpansion-risk-signals`**（f40、f47、f48）：当判断企业是否融资过度/投资过度（"撑死"五信号）、投资支出能否被补偿、存在哪些惯性依赖风险时调用。当只看存量负债结构时用 skill 12。
14. **`prospect-forecast-growth-options`**（f52、f53、f41、f44）：当需要预测企业前景、"还有什么牌可打"（五途径盘点）、识别保壳式重组、审阅项目可研/投资论证报告时调用。当只做历史业绩分析时不调用。
15. **`audit-report-risk-reading`**（f49、p05、p06）：当读审计意见与关键审计事项、怀疑报表造假（常识反查法）、发现现金流量表"其他"项异常时调用。当做与报表可信度无关的常规经营分析时不调用。
16. **`business-to-statements-deduction`**（f05、f07、p03）：当需要推演业务如何进入三张报表（逐笔业务过三表）、解释利润与现金为何背离、建立三表"底子/面子/日子"基础认知时调用。当用户已具备基础、只要分析结论时不调用。
