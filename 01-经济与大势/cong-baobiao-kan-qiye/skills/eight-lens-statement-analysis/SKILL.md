# 八看总纲：一套报表到一份企业诊断的全流程调度

## R — 原文 (Reading)

> "从八个方面利用财务报表对企业进行分析，也可以简称为'八看'：看战略、看效益和质量、看风险、看前景。"
>
> — 张新民，第4章

> "背景分析……会计分析……战略视角下的财务分析……对企业发展前景进行预测。"
>
> — 张新民，第13章

> "以母公司资产负债表为基础，观察资产总规模及其变化……经营主导型、投资主导型还是并重型？"
>
> — 张新民，第12章

> "（1）与同行业平均水平比……通常没有意义。（2）与特定对象比……永远会有意义。（3）与自己比更有意义。"
>
> — 张新民，第10章

## I — 方法论骨架 (Interpretation)

传统财报分析以美国比率为中心，只能算数字，读不出企业的管理质量与竞争力。本书的替代方案是**八看体系**——八个维度各看报表的一个侧面，合起来透视企业全貌：

1. **看战略**：钱投向了哪里（资产结构→经营主导/投资主导/并重型）。
2. **看经营资产管理与竞争力**：上下游关系（两头吃）与周转链条。
3. **看效益和质量**：三个净利润分工、三支柱两减值、核心利润获现率。
4. **看价值**：入资三重效应、股权定价与并购对价。
5. **看成本决定机制**：治理—决策—管理—核算四层归因。
6. **看财务状况质量**：资产质量三层面、现金流补偿机制。
7. **看风险**：经营/财务两条线、金融负债率、过度扩张五信号、治理风险。
8. **看前景**：现有盈利能力 + 还没打的牌（融资/重组/并购五途径）。

八看落地为**四阶段全流程**（第13章操作化收口）：
- 阶段一 **背景分析**：浏览年报，掌握行业、战略表述、控制性股东、发展沿革。
- 阶段二 **会计分析**：通过审计意见类型与关键审计事项间接完成，不必单独做。
- 阶段三 **战略视角下的财务分析**：先算三大类比率（失真大的宁可不算，比较基准**与自己比最有意义**——与历史比三年看方向、与目标比查管理；同行业"平均水平"无人认真计算，通常没有意义），再做战略与竞争力八步分析（母公司资产总规模→判型→主要资产变化方向→不良资产区域→四大动力→两头吃→融资潜力→母并对照看集团管理）。
- 阶段四 **前景预测**：从经营活动、投资活动、重组并购手段三方面预测。

本 skill 的角色是**总纲与调度器**：八看中的任何一"看"深挖时，转交对应专项 skill；本 skill 负责保证流程完整、维度不漏、顺序正确（判型在前、比率在后、前景收尾）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 恒瑞医药——四阶段全流程综合示范（c79）
- **问题**: 用完整流程诊断恒瑞医药 2022 年年报，企业靠什么发展、整体质量如何？
- **方法论的使用**: 背景分析后进入战略视角八步：剔除"战略后备军"货币资金 133.30 亿元，259 亿元战略资产中投资资产 115.34 亿元，经营资产过半判为经营主导型；四大动力排序为利润积累、经营性负债、股东入资、金融性负债。
- **结论**: 企业发展不依赖债务融资、靠利润积累自我循环，金融负债占比极小，负债融资空间大；74.94 亿元控制性投资仅撬动子公司增量 31.25 亿元，扩张效应不大（部分子公司为母公司配套）。
- **结果**: 全流程收口为"经营主导 + 内生驱动 + 融资空间充裕"的整体画像，并提示闲置货币资金的发展态势需持续关注。

### 案例 2: 恒瑞医药——母并对照还原集团管理（c80）
- **问题**: 全流程第八步"结合母公司与合并报表分析集团管理特征"，能读出什么？
- **方法论的使用**: 逐项对比母子报表：合并营业成本反而小于母公司，说明部分子公司为母公司提供配套；合并销售费用大于母公司，说明对外销售主体在子公司；母公司其他应收款大于合并数 32.77 亿元是向子公司提供资金的规模；母公司货币资金小于合并数且整合力度小。
- **结论**: 恒瑞母公司具备完备研产销体系，子公司以配套服务为主，资金管理以分散为主；作者建议集中管理更有助于发展。
- **结果**: 证明母并对照是全流程不可跳过的一步——只看合并报表会漏掉集团管理模式与子公司真实角色。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一家公司整套报表或整份年报，要求"做一次系统/全面/综合的分析"或出一份完整分析报告。
2. 面试、尽调、投研、课程作业等需要"从头到尾诊断一家企业"的任务，用户不确定从哪张表开始。
3. 用户只给一句"这家企业整体怎么样？三张表都在这"，没有点明单一维度。

### 语言信号 (用户的话里出现这些就应激活)

- "系统分析/全面分析/综合分析""完整报告/整体诊断""从头到尾看一遍"
- "三张报表一起看""有没有分析框架/分析体系""按步骤分析这家公司"
- "这家企业整体怎么样""八看""张氏分析框架"；英文场景 "comprehensive statement analysis" "full-scope diagnostic"

### 与相邻 skill 的区分（总纲 vs 专项的调度关系）

- 与 `parent-vs-consolidated-statements` 的区别：后者解决"两张报表怎么对照、差额怎么解读"的**专项技术**问题；本 skill 只在流程第八步把"母并对照"作为八步之一调用它。用户只问"为什么合并数比母公司还小"→ 直接用后者；用户要完整报告 → 本 skill 调度并在相应环节引用后者。
- 与 `strategy-from-asset-structure` 的区别：后者是"看战略"这一看内部的判型专项（二分资产、剔除货币资金、定型）；本 skill 在八步分析第二步触发它，但不替它做判型细节。用户只问"什么战略类型"→ 用后者；用户要全维度诊断 → 本 skill 统筹并把判型环节交给后者。
- 与 `core-profit-cash-conversion` 的区别：后者专项检验利润现金含量（1.2~1.5 倍获现率、泡沫利润）；本 skill 在"看效益和质量"维度调度它，自己只保证这个维度不被漏掉。用户只问"利润有没有水分"→ 用后者。
- 调度总规则：**单点问题直接进专项，全流程问题才启动本 skill**；本 skill 输出的应是流程与综合结论，不是替专项产出深度细节。

## E — 可执行步骤 (Execution)

1. **阶段一·背景分析**：浏览年报，记录行业、经营战略表述、竞争环境、控制性股东、发展沿革
   - 完成标准：能用 3-5 句话写出企业背景画像；判停条件——若用户拿不出年报只有零星数字，先声明分析受限，不硬套流程。
2. **阶段二·会计分析**：读审计意见类型与关键审计事项，标注风险区域
   - 完成标准：给出审计意见类型 + 关键审计事项指向的科目清单；非标准意见时先升级为风险主线再继续。
3. **阶段三·比率+八步**：先算核心利润率、核心利润获现率、资产金融性负债率等可用比率（比较基准与自己比，看三年趋势；失真大的比率宁可不算），再按八步过一遍（母公司资产总规模→判型→资产变化方向→不良资产区域→四大动力→两头吃→融资潜力→母并对照）
   - 完成标准：每一步有一句结论；判型、获现、母并差额等深挖点分别调度 `strategy-from-asset-structure`、`core-profit-cash-conversion`、`parent-vs-consolidated-statements`。
4. **阶段四·前景预测**：从经营活动、投资活动、重组并购手段三方面给出前景判断
   - 完成标准：三条预测各有一句方向性结论并注明依据；深挖时调度 `prospect-forecast-growth-options`。
5. **收口·综合诊断**：把八看结论合并成一页式企业画像（战略—竞争力—效益—风险—前景），明确列出最大亮点与最大隐患
   - 完成标准：画像中每个论断都能回溯到三表中的具体项目或流程某一步。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问单一维度（判型、利润含金量、偿债、造假、口径）——直接调度专项，启动全流程是浪费且稀释答案。
- 用户要的是行业分析、股价走势、交易建议——本流程止步于企业基本面画像。

### 作者在书中警告的失败模式

- 用合并报表做判型——控制性投资已被还原，几乎总是误判为经营主导型；判型必须以母公司报表为基础。
- 机械套用美国经验值和"行业平均水平"——很多比率源于美国报表体系，与"平均水平"比通常没有意义，失真大的比率宁可不算。
- 跳过背景与会计分析直奔数字——审计意见是免费的风险地图，不读它等于放弃捷径。

### 作者的盲点 / 时代局限

- 案例与阈值来自 2015-2023 年中国 A 股观察，跨境、非上市、金融类企业适用性未展开；部分市场（如美股）不披露母公司个别报表，全流程第一步就可能缺数据。
- 全流程对普通投资者成本偏高，经验阈值（1.2~1.5 倍、1% 等）缺乏统计显著性证明；传统比率分析在流动性监管、信用评级场景仍是行业标准，不应全盘否定。

### 容易混淆的邻近方法论

- 杜邦体系：本书不排斥但主张判型后再用——投资主导型企业套杜邦失效；本流程的判型步骤恰是判断杜邦是否适用的前提。
- 传统信用/流动性比率分析：场景不同（监管与评级 vs 管理质量透视），互补而非替代。
