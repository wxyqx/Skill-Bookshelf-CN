## I — 方法论骨架 (Interpretation)

本 skill 是一套"报表可信度排查"方法，分三层：先读审计报告定风险基调，再用常识反查找疑点，最后按红旗清单逐项核对。

**第一层：审计报告是免费的风险地图。** 读年报先读审计报告，是会计分析的捷径——普通读者不必自行评估会计政策与估计，通过审计意见类型与措辞间接完成会计分析。五种意见按风险严重度递增：①标准无保留意见——字面上无风险信号，但要核对报告满足的条件，并进一步读**关键审计事项**：那是注册会计师标示的最重要风险区域（如关键审计事项指向并购形成的固定资产、无形资产评估增值，说明商誉为零不等于并购风险低，只是风险转移到更隐蔽科目）；②带强调事项段的无保留意见——强调事项往往就是主要风险点（如流动资产不抵流动负债、子公司破产清算），但须先看流动负债结构再定性；③保留意见——指向具体资产或事项的质量疑问，烈度介于强调事项与否定之间；④否定意见；⑤无法表示意见——两者意味着治理、经营、内控、信息质量与前景都要高度警惕。读非标意见时逐条解析"形成审计意见的基础"，每条都是具体风险点。

**第二层：识别假账先懂真表——常识反查法。** 识别假表不需要高深技术：把高质量报表的特征（结构与勾稽常理）搞清楚，反常即疑点。造假多发生于盈利状况不佳之时——企业形象如妆容，外在预期难以维持时修饰就出现；造假最普遍的特征是**绩效变化违反常识**，重点核对报表间勾稽关系与业务常识匹配度，逆行业、逆周期、逆勾稽的高增长尤需警惕。

**第三层：造假/粉饰红旗清单。** ①**收入与应收背离**：收入高增长伴随应收账款相对显著增长、经营现金流长期不跟进，是最基本的舞弊线索；配套次级信号——审计报告称收入真实性无法核实、欠账方名单"团伙化"（多家欠账方出现相同商号）。②**数字积压**：账面存货有数字无实物（已卖出却不结转成本）不是管理问题而是造假；识别路径——核心利润与经营净现金缺口大、存货周转异常放缓时，必须核对实物与账面一致性（实物积压透支未来利润属管理问题，数字积压属造假，两者要分开）。③**减值择机三手法**：过高计提压低净值、利润丰厚年或不可逆亏损年集中计提一次性出清、该提不提延迟确认——被收购企业业绩下滑通常是渐进的，上年减值为零当年巨额计提就要追问"太巧合"；防范是回附注看原值，对比减值年度分布与资产变化的渐进性。④**小金库三迹象**：业务流转与信息流转脱节中断（边角料收入不入账）、异常高的资源消耗（投入产出比偏离内控目标与一线经验）、报表效益与员工待遇显著反差——报表差而员工感觉好即信号。⑤**科目粉饰随关注度迁移**：监管与市场对其他应收款警惕后，关联方占用改走"预付款项"——预付款项与经营规模不匹配、母公司预付款项越合并越小却无正常采购逻辑时，应怀疑其为占用通道；警惕性要跟着科目迁移。⑥**现金流"其他"项异常**：三类现金流量各有"其他"项，金额大或内涵不清，意味着分类能力弱甚至有意模糊，必须追问构成，不能跳过。

## A1 — 书中的应用 (Past Application)

### 案例 1: 紫金矿业——关键审计事项暴露并购风险的隐蔽去向
- **问题**: 紫金矿业2020年三项非同一控制并购几乎不产生商誉，并购风险就低吗？
- **方法论的使用**: 读关键审计事项（固定资产、无形资产账面价值）反推风险真实所在——交易对价都刚好等于评估价值，评估增值集中在无形资产与固定资产上。
- **结论**: 商誉为零不等于并购便宜或安全，风险只是转移到更隐蔽、同样需要减值测试的科目。
- **结果**: 若被收购企业业绩不达预期，减值风险将集中在固定资产、在建工程、无形资产和商誉几个项目。

### 案例 2: 四个审计意见案例的风险烈度排序（顾地科技/联创股份/圣莱达/未来股份）
- **问题**: 不同审计意见分别传递什么风险信号？
- **方法论的使用**: 逐条解读各意见类型及其"形成基础"——顾地科技强调事项段（流动负债高于流动资产、子公司破产清算，须先看负债结构再定性）；联创股份保留意见（原子公司收入成本核算错误、4200万购债款无法取证、并购标的涉合同诈骗，尚非全局性风险）；圣莱达否定意见（累计亏损3.7亿、88个项目收入成本真实性无法验证）；未来股份无法表示意见（应收账款13.39亿远超当年收入1.10亿、货币资金仅134万，报表已基本失去可信基础）。
- **结论**: 五种意见构成风险烈度递增的标尺；无法核实收入真实性+应收远超收入，正是收入与应收背离红旗的极端形态。
- **结果**: 对否定与无法表示意见企业，治理、内控、前景全面高度警惕，投资者面临重大损失风险。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到年报先翻审计报告，看到带强调事项段/保留意见/关键审计事项，问"这说明什么、风险多大"。
2. 发现一家公司业绩"漂亮得反常"：收入高增长但应收涨得更快、现金流不跟进，或减值计提时点诡异，怀疑虚增收入/利润操纵。
3. 并购尽调、投资避坑前，想系统排查目标企业报表有没有假账、账外小金库、粉饰通道。

### 语言信号 (用户的话里出现这些就应激活)

- "审计意见""强调事项段""保留意见""无法表示意见""关键审计事项"
- "虚增收入""假账""造假""粉饰""调节利润""洗大澡""小金库""账外"
- "收入涨但应收涨得更猛""减值太巧了""报表差员工待遇倒好""现金流量表其他项很大"

### 与相邻 skill 的区分

- 与 `governance-stance-analysis` 的区别：本 skill 识别的是**报表粉饰手法**（数字怎么被做出来、哪些信号暴露造假）；后者分析的是**治理端侵占**（股权结构、控制性股东动机、掏空与占款的治理根源）。同样是"其他应收款/预付款项暴增"，问"这是不是粉饰手法、在报表上怎么识别"找本 skill，问"大股东为什么占、治理结构怎么导致的"找后者。
- 与 `asset-quality-triage` 的区别：本 skill 处理**造假信号**（违反常识即疑点，指向故意失真）；后者处理**资产水分的正常范围**（逐项体检资产值不值那么多钱、减值计提是否充分，属质量评价而非舞弊指控）。用户问"这个资产是不是虚了但企业没造假故意"找后者，问"这是不是假账"找本 skill。
- 与 `core-profit-cash-conversion` 的区别：后者检验利润现金含量的常规质量（1.2~1.5 倍获现率），是健康度诊断；本 skill 在背离出现后进一步指向**舞弊怀疑**。先质量检验、后造假排查，前者通常是本 skill 的前置筛。

## E — 可执行步骤 (Execution)

1. **读审计报告定基调**：确认意见类型（五种之一），非标意见逐条解析"形成基础"与强调事项，按烈度标尺定位风险等级；标准无保留意见则细读关键审计事项，把它当注册会计师免费提供的风险地图
   - 完成标准：给出意见类型 + 风险等级结论 + 至少 2 个从"形成基础/关键审计事项"里读出的具体风险点；判停条件——用户问的是并购估值或商誉定价，转 `valuation-ma-equity-pricing`。
2. **常识反查**：把绩效变化与行业景气、周期位置、报表勾稽对照，标记逆行业、逆周期、逆勾稽的反常；同时确认企业是否处于盈利不佳、保壳、对赌等粉饰动机高发情境
   - 完成标准：列出"哪些数字违反常识"的具体清单，无反常则明确说"未发现常识性疑点"。
3. **跑红旗清单**：逐项核对六类信号——收入与应收/现金流背离、存货数字积压（查实物与账面一致性）、减值择机（回附注看原值、对比减值年度分布）、小金库三迹象、科目粉饰迁移（预付款项/其他应收款与经营规模匹配度、母公司越合并越小）、现金流"其他"项内涵
   - 完成标准：每项给出"触发/未触发+证据"，触发项注明数据来源（附注、审计报告、现金流量表）。
4. **交叉验证并收敛结论**：把触发项组合成证据链（单一信号可能是经营问题，多信号共振才指向造假），区分"管理问题/质量水分/疑似造假"三档，并声明本方法只能提出质疑、不能定性
   - 完成标准：给出三档结论 + 证据链 + 建议的进一步核实动作（查附注原值、函证、实地盘点）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是大股东占款的治理根源、股权结构与控制人动机——那是治理端问题（→ `governance-stance-analysis`），本 skill 只管报表端的手法与信号。
- 用户要对单项资产做正常范围的水分体检、减值充分性评价——属资产质量分析（→ `asset-quality-triage`），不要把质量疑问升级为造假指控。
- 没有任何报表/审计报告数据，只凭新闻舆情问"这家公司是不是骗子公司"——本 skill 是报表可信度排查法，不是舆情审判工具。

### 作者在书中警告的失败模式

- 把"流动负债高于流动资产"一概当风险：经营性负债高且能持续"两头吃"是竞争优势，要看负债结构再定性。
- 只看减值后的净值：过高计提会让债权规模、周转、趋势分析全部失真，关键项目必须回附注看原值。
- 警惕性固定在老科目上：市场紧盯其他应收款后占用改走预付款项，粉饰随关注度迁移，盯死一个科目必被绕过。
- 混淆两种存货积压：实物积压是管理问题，数字"积压"才是造假，处置方式完全不同。
- 把"其他"项跳过去：金额大或内涵不清的"其他"项正是编制质量乃至有意模糊的照妖镜。

### 作者的盲点 / 时代局限

- 作者的立场是：多数企业不会造假，但识别能力必须有——方法论据此定位于"提出质疑"而非"定罪"，其经验阈值与红旗来自 A 股观察，对系统性失真环境（多数报表都粉饰时）方法会失效；对非上市、跨境、金融企业的适用性未验证。审计意见本身也非绝对可靠（注册会计师可能未发现舞弊），"标准无保留"不等于无风险。

### 容易混淆的邻近方法论

- 资产质量减值分析：减值不充分是质量问题，减值**择机**才是操纵信号，分界在"时点是否与利润周期巧合"。
- 利润现金含量检验：获现率低是纸面利润警告，配合应收激增与常识违反才升级为舞弊怀疑。
