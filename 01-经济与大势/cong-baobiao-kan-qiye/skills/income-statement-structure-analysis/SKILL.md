# 利润从哪来：盈利结构与可持续性分析

## R — 原文 (Reading)

> "毛利，即营业收入减去营业成本，反映产品的初始盈利能力。"
>
> — 张新民，第7章（f26 利润表分层次认识）

> "支持营业利润的三个支柱是：1.核心利润……2.其他收益……3.杂项收益。"
>
> — 张新民，第7章（f27 三支柱两减值）

>

## I — 方法论骨架 (Interpretation)

看利润不是看一个总数，而是回答"利润从哪来、能不能一直来"。本书的方法分三步走。

**第一步：分清三个净利润各回答什么问题。** 母公司净利润回答"母公司自身赚多少、分红的首要基础是什么"；合并净利润回答"整个集团的综合盈利能力"（合并时剔除了内部交易、子公司按公允价值并入，所以不等于母子公司简单相加，不是假账）；归属于母公司所有者的净利润是每股收益的计算基础，承担资本市场定价功能。先确定用户问的是分红、集团盈利还是股价定价，再决定看哪个数。

**第二步：沿四层结构逐层下钻，拆出营业利润的支撑结构。** 利润表分四层：毛利（产品初始盈利能力）→ 核心利润（经营活动盈利能力）→ 营业利润（混入了非传统经营成分）→ 利润总额与净利润（最终结果）。每层都问"上一层的盈利够不够覆盖下一层的消耗"：毛利能否覆盖四项费用，核心利润是否构成营业利润的主体。营业利润用"三支柱两减值"拆解——

- **三支柱**：①核心利润（收入减成本、税金及附加、四项费用，代表真实经营）；②其他收益（以政府补贴为主）；③杂项收益（利息收入+投资收益+公允价值变动收益等）。
- **两减值**：资产减值损失与信用减值损失——规模大说明资产或债权质量出了问题，并可上溯历史经营决策。
- **结构判读**：核心利润主导=产品有市场竞争力，是最健康、最可持续的结构；靠其他收益支撑=补贴依赖，政策一变利润就塌；靠杂项收益支撑=主业不振、靠资金运作和账面浮盈撑门面（公允价值变动收益尤其虚，随行就市可正可负）。资产处置收益处置一项少一项，只作偶发因素，不纳入结构性盈利能力——靠卖楼保壳或"小项目力挽狂澜"，恰恰证明核心业务出了问题。

**第三步：用收入质量三问和"过程—结构—结果"路径判断可持续性。** 收入三问：卖什么（业务结构与战略的关系、对单一业务/单一客户的依赖、收入增长靠自建还是并购）；卖给谁（地区经济后劲、政治经济与国际环境）；靠什么（靠政府、靠关联方还是靠市场——靠市场获得的竞争优势最有持久生命力）。三维路径：看利润实现过程（收入质量+费用的效用而非片面节约）、看利润结构（三支柱两减值）、看利润结果——利润最终沉淀为各项资产，利润质量必须落脚到资产质量上检验。三者联动后才能下可持续性结论：核心利润占主体+收入靠市场+利润沉淀为好资产，才是真可持续。

## A1 — 书中的应用 (Past Application)

### 案例 1: 科大讯飞——政府补贴撑起营业利润
- **问题**: 科大讯飞 2021-2022 年营业利润的结构透露什么？
- **方法论的使用**: 用三支柱两减值拆解营业利润——其他收益（政府补贴）占营业利润比重极高，剔除后营业利润是较大负数；两项减值规模大；公允价值变动收益由 +3.3 亿转为 -2.5 亿冲击杂项收益。
- **结论**: 在收入有规模的情况下核心利润对营业利润几乎无贡献，意味着产品缺乏显著市场竞争力，盈利高度依赖补贴，可持续性存疑。
- **结果**: 提示关注补贴退坡后的真实盈利能力，与迈瑞的核心利润主导结构形成对照。

### 案例 2: 蓝帆医疗——杂项收益撑门面
- **问题**: 蓝帆医疗 2020-2022 年收入有规模，盈利能力为什么在恶化？
- **方法论的使用**: 拆解利润构成——2020-2021 年资产减值损失巨大（重大并购决策失误），2022 年核心利润显著为负，营业利润靠杂项收益（2021 年公允价值变动收益近 11 亿）与政府补贴支撑。
- **结论**: 收入有规模却产生不了核心利润，产品竞争力在迅速下降；杂项收益撑门面的结构掩盖了主业的塌陷。
- **结果**: 与迈瑞（两减值合计仅 1 亿余、营业利润几乎全由核心利润支撑）的正反对照，验证了三支柱两减值判读竞争力的有效性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一份利润表，问"这家公司靠什么赚钱""营业利润里有大量政府补贴/投资收益，正常吗"。
2. 投资决策前评估盈利可持续性："这个利润明年还在吗""产品还有没有竞争力"。
3. 问收入质量："它的收入主要靠哪些产品、哪些地区、靠什么拿到的订单"。

### 语言信号 (用户的话里出现这些就应激活)

- "利润结构""营业利润构成""三支柱两减值""核心利润占比""靠什么撑利润"
- "政府补贴依赖""投资收益/公允价值变动撑利润""利润质量""盈利可持续性""卖楼保壳"
- "收入质量""卖什么卖给谁靠什么""产品竞争力""收入结构单一"

### 与相邻 skill 的区分

- 与 `core-profit-cash-conversion` 的区别：后者管利润**有没有现金支撑**（核心利润获现率 1.2~1.5 倍、应收存货追查），本 skill 管利润的**结构与可持续性**（利润从哪个支柱来、收入靠什么）。用户问"利润是纸面的吗、有现金吗"找后者；问"利润从哪来、明年还在吗"找本 skill。
- 与 `parent-vs-consolidated-statements` 的区别：本 skill 会用到三个净利润的分工做分析起点，但**口径细节与两张报表的对照技术**（内部交易剔除、孰低规则、越合并越小）在后者。用户问"归母净利润和母公司净利润为啥不一样、该看哪个数的技术细节"找后者。
- 与 `asset-quality-triage` 的区别：本 skill 看利润来源结构，后者逐项体检资产水分。利润结构分析发现两减值规模大、需追问"哪些资产出了问题"时，转后者。

## E — 可执行步骤 (Execution)

1. **分清口径与问题**：确认用户问的是分红基础、集团盈利能力还是每股收益/定价，对应母公司净利润、合并净利润、归母净利润
   - 完成标准：明确声明本次分析以哪个净利润口径为准；口径技术细节问题转 `parent-vs-consolidated-statements`。
2. **四层下钻**：毛利→核心利润→营业利润→净利润，逐层算金额、毛利率与核心利润占营业利润的比重
   - 完成标准：四层数据齐全，能回答"毛利够不够覆盖四项费用、核心利润是不是营业利润主体"。
3. **拆三支柱两减值**：列表给出核心利润、其他收益、杂项收益、两项减值各自的金额与占比，判定主导支柱
   - 完成标准：每个支柱有金额与占比；给出"核心利润主导/补贴主导/杂项主导"的明确判读；资产处置收益单列为偶发因素。
4. **收入质量三问**：结合分部报告回答卖什么（业务依赖）、卖给谁（地区环境）、靠什么（政府/关联方/市场）
   - 完成标准：三问各有基于数据的答案，并指出最大的依赖风险点。
5. **可持续性结论**：按"过程—结构—结果"联动收口——利润是否沉淀为好资产，需否结合资产负债表与现金流量表验证
   - 完成标准：给出可持续性判断+至少 1 个反证信号（两减值激增、补贴占比、浮盈依赖等）；若用户追问现金含量，明确转 `core-profit-cash-conversion`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户真正想问的是利润的现金含量、获现率、赊销水分——那是 `core-profit-cash-conversion` 的问题。
- 用户要的是估值定价、股价预测、行业景气分析——与本 skill 无关（估值→ `valuation-ma-equity-pricing`）。
- 只有合并利润表且用户关心的是母子口径技术差异，而非结构判断。

### 作者在书中警告的失败模式

- **"此营业非彼营业"**：营业利润早已不是"营业"的利润——它包含政府补贴、投资收益、公允价值变动等非传统经营成分，直接拿营业利润当经营能力会严重误判。
- **"小项目力挽狂澜"**：靠资产处置收益（卖学区房保壳）、营业外小项目维持利润，处置一项少一项，恰恰证明核心业务盈利能力出了问题，不能纳入结构性盈利能力。
- **不对单一项目下结论**：如母公司净利润高于合并净利润可能只是子公司分红多，不代表母公司盈利强；不能就利润表论利润表，必须三表联动。

### 作者的盲点 / 时代局限

- "核心利润主导=健康"的判读经验来自中国 A 股 2015-2023 样本；金融类企业利润表结构完全不同，补贴对战略性新兴产业是否该一票否决，书中未展开。
- 收入三问依赖分部报告披露质量，披露粗糙的公司三问会退化为定性猜测。

### 容易混淆的邻近方法论

- 杜邦分析（净利润率×周转×杠杆）：解释的是 ROE 的数学分解，不回答"利润从哪个支柱来"；三支柱两减值是它的前置结构检查。
- 会计上的"营业利润"科目口径：作者的分析口径是对构成成分的功能重分类，与准则列报顺序一致但判读目的不同。
