## I — 方法论骨架 (Interpretation)

集团企业天然有两套报表：母公司个别报表与合并报表。两套数字的差额不是"误差"，而是集团结构信息的富矿。本 skill 把对照与测算本身作为一门技术，含五块内容。

**1. 控制性投资为什么会被合并"还原"。** 母公司报表上的长期股权投资，在编制合并报表时被还原为子公司具体的资产（减负债）——剔除母子公司间投资、资金往来、内部购销利润等重复因素后逐项相加。所以合并报表上几乎看不到"对子公司的投资"，母公司大额长期股权投资"消失"在合并数字里；子公司净资产中非控制性股东的份额以少数股东权益/损益单列。理解了还原机理，就明白母公司数减合并数的差额为什么恰好指向控制性投资。

**2. 扩张效应差额测算。** 四步：①区分经营资产与投资资产；②考察行业对经营资产结构的影响；③用长期股权投资、其他应收款、预付款项等项目中"母公司数减合并数"的差额，确定控制性投资占用资源的基本规模（这只是报表推断的大致数，精确须账簿）；④用合并资产总计减母公司资产总计，得到控制性投资撬动的子公司资源，即综合投资效应（杠杆倍数）。差额法之所以成立，是因为母公司不追加投资也能靠三条杠杆放大：子公司吸纳少数股东入资、子公司独立负债融资、子公司自身经营积累（含"两头吃"占用上下游）。扩张效应大小取决于四个因素：子公司吸纳少数股东入资的状况、子公司自身贷款规模、子公司业务规模与两头吃能力、子公司盈利累积。倍数低不一定是坏事——若控制性投资以系统整合盈利为目的而非铺摊子扩张，应转看合并与母公司利润表的盈利能力变化。

**3. "越合并越小"诊断。** 合并数只反映集团与外部主体的业务，用母子相同项目的差额方向和幅度反推内部往来：其他应收款、预付款项越合并越小，差额一般是母公司向子公司提供资金的规模（子公司占用）；债务越合并越小，意味着本公司占用子公司资金；长期股权投资与投资收益越合并越小，差额表明子公司累计分红规模；存货、营业收入、营业成本越合并越小，涉及集团内部销售。注意与合并数大于母公司数（越合并越大）的方向相反解读。

**4. 集团管理模式判别。** 三个维度各有常见三模式：债务筹资——看母公司贷款类项目与利息费用占合并数的比重（母公司筹资为主/子公司筹资为主/各自为战）；货币资金——母公司其他应付款扣除常规部分即母公司整合子公司资金的基本规模，母公司其他应收款与合并数的差异反映向子公司拨付资金，区分集中/分散/集分结合；业务关系——看母子公司收入成本费用结构（母公司对市场销售/各自对市场/子公司代母公司销售）。

**5. 三个净利润各司其职与比率可用性。** 母公司净利润是分红的首要基础（受母公司净利润与归母净利润孰低规则约束，防止集团整体亏损下过度分红）；合并净利润反映整个集团的综合盈利能力（看集团效益用合并口径核心利润，且公式中直接减利息费用；合并数与母子公司简单相加对不上并不是假账，是内部交易抵消与公允价值并入所致）；归属于母公司所有者的净利润是每股收益的计算基础，具资本市场定价功能，并参与分红基础确定。比率把关：效益类比率（净资产收益率、总资产报酬率、毛利率、核心利润率、费用率、核心利润获现率）可直接用于合并口径；展示单项资产活力的比率（存货周转率、固定资产周转率）以及流动比率、资产负债率在合并条件下常失去意义——合并主体只是会计意义上的主体，与谁做交易就看谁的报表。

## A1 — 书中的应用 (Past Application)

### 案例 1: 恒瑞医药——74.94 亿元控制性投资仅撬动 31.25 亿元
- **问题**: 恒瑞母公司报表上大量长期股权投资和其他应收款，到底撬动了多大的集团盘子？
- **方法论的使用**: 剔除战略后备军货币资金后，用长期股权投资差额加其他应收款差额（32.77 亿）算出控制性投资基本规模 74.94 亿元；合并总资产减母公司总资产得增量 31.25 亿元。
- **结论**: 扩张效应不大，部分子公司是为母公司提供配套服务的；经营资产过半，属经营主导型而非靠并购铺摊子。
- **结果**: 顺势逐项对照两表还原业务关系——合并营业成本反而小于母公司（子公司向母公司供货）、合并销售费用大于母公司（对外销售主体在子公司）、母公司货币资金整合力度小（资金分散管理），作者建议集中管理更有助于发展。

### 案例 2: 海尔智家——3.93 倍扩张效应的对照组
- **问题**: 同样的差额法，换一家公司结果差多远？
- **方法论的使用**: 长期股权投资差额 282.16 亿加其他应收款差额 114.73 亿，控制性投资约 396.89 亿元；合并与母公司总资产差 1562.18 亿元即撬动资源，约 3.93 倍。
- **结论**: 高倍数来自四个因素齐备——子公司吸纳少数股东入资、子公司独立贷款、两头吃能力强、盈利持续累积。
- **结果**: 与恒瑞（低倍数、配套型）对照展示同一技术的两种诊断输出：扩张型集团看杠杆与风险，整合型集团看盈利能力变化。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上同时有母公司报表和合并报表，发现同一项目两个数差很多，想知道差额说明什么、控制性投资到底撬动了多少资源。
2. 问"母公司净利润、合并净利润、归母净利润到底看哪个"——分红、估值、集团效益各用哪个数。
3. 要判断这家集团是集权还是分权（谁筹资、谁管钱、谁对外销售），或想知道合并报表上的比率能不能直接用。

### 语言信号 (用户的话里出现这些就应激活)

- "母公司报表/合并报表/个别报表""合并数比母公司数大/小""差额说明什么"
- "控制性投资""扩张效应""以小博大""撬动""越合并越小"
- "少数股东权益/损益""归母净利润""分红看哪个利润""合并口径能不能算周转率/资产负债率""集团是集权还是分权"

### 与相邻 skill 的区分

- 与 `strategy-from-asset-structure` 的区别：该 skill 用母子报表差异**得出战略结论**（经营/投资主导判型），本 skill 是**对照与测算技术本身**——怎么逐项对照、差额怎么算、哪个数字回答哪个问题。用户问"这是什么战略类型"找前者；问"这个差额怎么算、说明什么、哪个数能用"用本 skill。实践中本 skill 常为前者提供数据底座。
- 与 `governance-stance-analysis` 的区别：本 skill 解释母子差异的**技术含义**（向子公司提供资金、子公司分红规模、内部销售）；后者判断差异背后的**立场正当性**（控股股东是否侵占小股东、关联占用是否不良）。"越合并越小"若指向子公司且子公司经营正常，是正当财务支持，留在本 skill；若怀疑母公司/兄弟公司占用、大股东掏空，转后者。
- 与 `income-statement-structure-analysis` 的区别：追问合并利润表内部结构（三支柱两减值、收入质量）找后者；区分三个净利润口径与分红基础是本 skill 的事。

## E — 可执行步骤 (Execution)

1. **并表对照准备**：取同一报告期母公司与合并的三张报表，逐项目并排列出；若只有合并报表，先声明受限（美股等市场常不披露个别报表）。
   - 完成标准：母子对照表建成；缺哪张表明确声明。
2. **测算控制性投资与扩张效应**：对长期股权投资、其他应收款、预付款项算"母公司数减合并数"差额求和控制性投资基本规模；再算合并总资产减母公司总资产得撬动资源与杠杆倍数，并按四因素（少数股东入资、子公司贷款、两头吃、盈利累积）归因。
   - 完成标准：给出两个差额数、杠杆倍数和至少两项因素归因；倍数低时提示"整合型 vs 扩张型"两种解读。
3. **逐项"越合并越小/越大"诊断**：对其他应收款、预付款项（资金提供）、债务（占用子公司资金）、长期股权投资与投资收益（子公司分红）、存货与收入成本（内部销售）逐项解释差额方向。
   - 完成标准：每个显著差额都有一个业务解释，无法解释的项目列为待查疑点。
4. **利润表口径分工与管理模式判别**：按三个净利润分工回答用户问题（分红看母公司净利润受两数孰低约束、集团效益看合并核心利润减利息费用、每股收益看归母）；从筹资、货币资金、业务关系三维度给出集权/分权判断。
   - 完成标准：每个利润问题对应到正确的数字；管理模式有至少两个维度的报表证据。
5. **比率可用性把关**：对用户想算或已算的比率逐个标注——效益类可直接用合并数；存货/固定资产周转率、流动比率、资产负债率在合并口径下谨慎或不算；母子公司费用率对比不得草率下结论（业务结构、薪酬政策、固定费用刚性、付款者与受益者脱节都会干扰）。
   - 完成标准：输出"能算/慎算/不算"三档清单并说明理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非集团单一主体：没有子公司、只有一张个别报表的企业，无从对照，本 skill 不适用。
- 目标是对集团内**个别企业**的决策（授信、交易、考核子公司）：必须看个别报表，不能拿合并数凑合。
- 用户要的是战略类型结论或治理侵占判断：转 `strategy-from-asset-structure` 或 `governance-stance-analysis`。

### 作者在书中警告的失败模式

- 把合并报表当作一个真实存在的企业来分析：合并主体只是会计意义上的主体，子公司资源不能在集团内任意调动，常规比率经常失去意义。
- 草率比较母公司与合并报表的费用率并直接下"子公司费用失控"的结论。
- 三个净利润张冠李戴：拿合并净利润谈分红、拿归母净利润谈集团经营盈利能力。
- 见到合并净利润与母子公司相加对不上就怀疑假账——内部交易抵消与公允价值并入是正常原因。

### 作者的盲点 / 时代局限

- 方法假设读者能拿到母公司个别报表，美股等不披露个别报表的市场适用受限；经验界限（如其他应收款 1%）来自 A 股观察；对多层嵌套集团（孙公司、结构化主体）的差额解读展开有限。

### 容易混淆的邻近方法论

- 母公司报表与合并报表的使用场景混淆（分析基础用母公司、集团全景用合并、对个别企业决策用个别报表）。
- "越合并越小"的正当资金支持与关联方占用：差额方向相同，定性取决于资金去向（子公司 vs 母公司/兄弟公司）与子公司经营质量。
