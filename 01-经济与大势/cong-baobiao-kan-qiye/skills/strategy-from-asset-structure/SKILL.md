# 从资产结构看战略定位

## R — 原文 (Reading)

> "把资产按照对利润的贡献方式分成经营资产和投资资产……这种分类对于财务报表分析意义重大。"
>
> — 张新民，第1章

---

## I — 方法论骨架 (Interpretation)

传统资产负债表按流动性分流动/非流动，看不出企业在干什么。本书的改造是：**以母公司报表为基础**，把资产按"对利润的贡献方式"重新分成两类——

- **经营资产**：货币资金、债权（应收票据/账款/款项融资/预付/其他应收款）、存货、固定资产类、无形资产类。靠自身日常经营贡献利润。
- **投资资产**：交易性金融资产、债权投资、长期股权投资等（还可能藏在预付款项、其他应收款等通道里）。靠对外投资贡献利润。

两个操作前提：①必须用母公司报表——合并报表编制时控制性投资已被"还原"成子公司经营资产，合并报表几乎总是经营资产占主体，判型会全部失效；②母公司货币资金很大时先剔除再分类——货币资金没有战略色彩，属于"战略后备军"。

分类后按剔除货币资金的经营/投资资产相对比重给企业定型：
- **经营主导型**：自身经营赚钱，对应专业化战略。分析主线：经营资产 → 核心利润 → 经营净现金。
- **投资主导型**：靠子公司/对外投资收益，对应多元化或一体化扩张战略。分析主线：母公司控制性投资 → 子公司经营资产 → 子公司核心利润 → 合并经营净现金。
- **经营与投资并重型**：两条线并举。

企业类型决定了利润表的支撑点和哪些比率有意义（投资主导型企业套杜邦分析、算总资产周转率都是错配）。配套两个延伸视角：报表只列货币化资源，品牌、客户、人力等**表外资源**（资本/市场/人力/其他四类）可能是企业更值钱的部分；企业发展路径可按**产品市场（走）与证券市场（飞）**双轮定位，判断该不该走上市融资。

## A1 — 书中的应用 (Past Application)

### 案例 1: 迈瑞医疗——经营主导型
- **问题**: 迈瑞医疗的资产结构透露什么战略？
- **方法论的使用**: 母公司报表中经营资产占绝对主体，投资资产比重很小。
- **结论**: 典型经营主导型企业，靠自身研产销赚钱。
- **结果**: 适用"经营资产—核心利润—经营净现金"主线分析其竞争力。

### 案例 2: 海尔智家——投资主导型
- **问题**: 海尔智家母公司报表为什么"不好看"？
- **方法论的使用**: 母公司报表中大量长期股权投资，经营资产比重低；利润主要来自子公司分红与投资收益。
- **结论**: 投资主导型企业，母公司是控股平台，分析必须转向"控制性投资—子公司经营—合并报表"主线。
- **结果**: 解释了为什么母公司利润表与合并利润表面貌迥异。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一份年报/资产负债表，问"这家公司是什么战略""是多元化还是专业化"。
2. 分析母公司报表与合并报表差异巨大，想知道企业扩张方式（自建 vs 并购）。
3. 评估企业真实实力，怀疑"资产少=没实力"，需要盘点表外资源。

### 语言信号 (用户的话里出现这些就应激活)

- "资产结构""经营资产/投资资产""母公司报表 vs 合并报表"
- "经营主导型/投资主导型""多元化还是专业化""扩张方式"
- "表外资源""品牌的估值""真实资源""该不该上市"

### 与相邻 skill 的区分

- 与 `capital-source-four-drives` 的区别：本 skill 看资产的**投向**（资产方结构→战略类型）；后者看钱的**来源**（负债与权益结构→发展动力与分红）。用户问"钱从哪来"找后者。
- 与 `asset-quality-triage` 的区别：本 skill 用资产结构定性战略；后者逐项体检资产有没有水分。用户问"这个资产值不值这么多钱"找后者。
- 与 `parent-vs-consolidated-statements` 的区别：本 skill 用母子报表差异得战略结论；后者专门处理"怎么对照两张报表、扩张效应怎么算"的技术问题。问题核心是判型时用本 skill，核心是报表口径与测算时用后者。

## E — 可执行步骤 (Execution)

1. **取母公司资产负债表**，列示全部资产项目
   - 完成标准：拿到母公司口径数据；若只有合并报表，明确声明判型受限。
2. **剔除大额货币资金，按贡献方式二分**为经营资产与投资资产（注意识别藏在预付/其他应收款中的投资通道；投资性房地产属经营资产）
   - 完成标准：两大类各有一个金额与占比；判停条件——若用户问的是子公司单体经营问题，转 `parent-vs-consolidated-statements`。
3. **计算相对比重并定型**（经营主导型/投资主导型/并重型），写出对应的利润支撑点与分析主线
   - 完成标准：给出战略类型结论 + 该类型下应重点核查的利润表位置。
4. **补充表外资源盘点与双市场定位**（资本/市场/人力/其他四类；产品市场"走"vs 证券市场"飞"）
   - 完成标准：至少指出 2 项报表看不见但影响企业实力的资源，并给出一句话战略画像。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只有合并报表、没有母公司报表数据时（如分析美股公司）——判型前提缺失，只能做提示性讨论。
- 用户要的是行业分析、股价涨跌预测、估值定价——与本 skill 无关（估值→ `valuation-ma-equity-pricing`）。

### 作者在书中警告的失败模式

- 用合并报表判型——控制性投资已被还原，几乎总是误判为经营主导型。
- 不剔除大额货币资金——会把"战略后备军"算进经营资产，误导判型。
- 把投资性房地产当成投资资产——它名带"投资"实为经营资产。

### 作者的盲点 / 时代局限

- 经验阈值来自作者对中国 A 股的观察，跨界转型期企业可能长期混合，判型存在模糊地带；非上市/金融企业适用性未验证。

### 容易混淆的邻近方法论

- 传统流动/非流动分类（偿债视角）：与本分类互补，不能互相替代。
- 杜邦分析：对投资主导型企业失效，本 skill 的判型恰是判断杜邦是否适用的前提。
