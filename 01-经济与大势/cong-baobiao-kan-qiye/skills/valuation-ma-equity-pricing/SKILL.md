# 看价值：并购、增资与股权交易的估值定价

## R — 原文 (Reading)

> "股东对企业入资至少有三重效应：为盈利能力奠定基础、对潜在债务提供保证、股东间的利益关系协调。"
>
> — 张新民，第8章

> "成本法……只能适用于表外资源较少……的企业；收益法……适用于盈利能力较强、发展状况较好的企业。"
>
> — 张新民，第8章

> "首先，要把公司所有者权益的整体价值确定下来……最后，要解决的关键问题是买方是谁，买方的持有目的是什么。"
>
> — 张新民，第8章

> "（高商誉）意味着买方的高预期……意味着卖方的高业绩对赌……意味着买方的高风险。"
>
> — 张新民，第6章

> "对于中小投资者而言，最简单的办法是：远离高商誉并购的企业。"
>
> — 张新民，第6章

> "风险一点都没有降低，只不过转移到了更加隐蔽的无形资产和固定资产那里了。"
>
> — 张新民，第11章

> "当某项资产用于对企业的债务进行保证时，就要用公允价值……绩效评价时，应该更多地考虑历史成本。"
>
> — 张新民，第10章

## I — 方法论骨架 (Interpretation)

传统"评估报告说了算"的估值讨论缺了三层：入资效应、方法边界、买方视角。本书把一笔股权交易拆成四套互相校验的工具。

### 1. 入资三重效应——先验交易质量，再谈价格

无论是增资扩股还是以整个企业作为入资内容的并购，评估一笔入资看三件事：①入资资产是否与业务有关、能否持续贡献盈利能力；②是否为企业债务提供扎实保证——注册资本不实、非现金资产评估虚高都会削弱担保能力；③如何改变股东间利益格局：非现金资产的估价与折股方法直接决定各方股权比例。交易完成不等于价值实现，三重效应要分开验；控股股东以非现金资产高价折股入资，是最常见的利益格局扭曲入口。

### 2. 成本法/收益法适用边界——与企业生命周期匹配

两种评估方法的差异不是谁更科学，而是适用范围不同。成本法基于"净资产=资产-负债"，只反映历史沉积的表内资源，忽略品牌、客户、人力等表外资源——适用于初创期、没落期，或表外资源虽丰富但不能贡献盈利的企业；收益法把未来盈利折现、兼顾表内表外——适用于稳定发展期、盈利能力较强的企业。判断评估结果合理性，先看方法与企业生命周期、表外资源盈利贡献是否匹配，而不是机械要求两法结果一致。使用警惕：收益法本质是对未来的估计，参数弹性大，评估质量取决于评估师的专业判断、更取决于评估师的良知——评估增值既可能反映真实表外价值，也可能是利益输送通道（如向大股东高价收购其资产）。对非现金入资与高增值并购，要盯住评估师角色与增值幅度。配套的价值尺度规则：融资担保场景用公允价值（债权人看现在与未来），绩效评价与常规决策用历史成本——一味强调公允价值会把资产"泡沫化"。

### 3. 股权交易定价四步——卖方要站买方立场

①确定股东权益整体价值；②按比例折算拟出售份额；③叠加控制权转移溢价；④关键一步——搞清买方是谁、持有目的是什么。买方是上市公司，可借证券市场市盈率放大效应定价；短期持有可抬价，长期持有按未来净利润与买方最低回报率倒推最高出价，战略布局还要算非货币因素。核心心态：企业家常用"卖产品"的思维卖股权（只看自己的账面价值和对方委托的评估价）而吃亏——应以未来盈利能力为基础定价，追求双赢而非一方利益最大化。

### 4. 高商誉与零商誉：一枚硬币的两面风险清单

**高商誉三含义**：商誉=支付对价-可辨认净资产公允价值，高商誉同时意味着买方的高预期（财务/战略/声誉）、卖方的高业绩对赌、买方的高风险。商誉不摊销、年末减值测试的制度安排，既维持承诺期内利润表象，也为用减值调节利润留下空间。风险清单：承诺期后业绩变脸；减值集中爆发反噬利润；商誉与无形资产评估增值是"纸面资产"，不能推动被收购企业收入增长；并购当年的收入、利润增长可能掩盖核心盈利能力并未实质改善。

**零商誉≠低风险**：交易对价刚好等于评估值时商誉趋零，但评估增值可能全部进入无形资产、固定资产等更隐蔽科目——风险没有消失，只是转移。要把并购溢价在全部资产科目间追踪，并结合审计报告的关键审计事项判断未来减值落点（固定资产、在建工程、无形资产、商誉）。

**投资者最简操作**：不为高商誉并购注入资本、呐喊助威——从需求端抑制企业的高商誉并购冲动。

## A1 — 书中的应用 (Past Application)

### 案例 1: 蓝帆医疗——高商誉并购的承诺期后反噬
- **问题**: 蓝帆医疗发行股份收购 CB Cardio，约60.5亿控制性投资产生63.61亿商誉（被收购企业净资产23.31亿被评估为-0.52亿），这笔并购的风险有多大？
- **方法论的使用**: 高商誉三含义分析＋减值压力测算：商誉不摊销、只做年末减值测试，承诺期内利润"看上去很美"（2018-2019年超额完成对赌）；按10年摊销测算，年摊销6亿以上就足以让企业由盈转亏。
- **结论**: 高对价并购即使有业绩对赌，承诺期后仍可能反噬——"纸面"商誉对收购方持续高质量发展是巨大威胁。
- **结果**: 2020年业绩承诺不达标，当年计提商誉减值17.55亿、2021年再提16.98亿（2022年外币折算再增3.15亿），减值总额远超被并购企业三年净利润之和。

### 案例 2: 朋友出售51%股权——站买方立场重新定价
- **问题**: 朋友企业年净利润1000万、账面权益4000万，买方（香港上市公司）委托的成本法评估仅4500万，原打算开价3000万、底价2500万，该不该卖？
- **方法论的使用**: 定价四步＋站买方立场：按行业最低市盈率8倍，整体价值至少8000万，51%值4000多万，再加控制权溢价更高；买方委托的评估报告有压价嫌疑。
- **结论**: 用卖产品的思维卖股权会吃亏——从他带给对方的价值和证券市场放大效应看，按原方案成交就是亏了；应以未来盈利能力为基础、追求双赢。
- **结果**: 按市盈率逻辑重估后避免了远低于买方获得价值的成交；配套引例（北方制药厂同一股权四个价值：账面1.2亿、成本法1.6亿、收益法3亿、成交价3.6亿）说明评估方法决定估值逻辑，成交价才体现交易博弈。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户是卖方或买方，面对一笔股权交易/增资方案要定价格或核价格（含对赌条款设计）。
2. 用户拿到资产评估报告，成本法与收益法两个数差好几倍，问该信哪个、增值是否离谱。
3. 用户分析一家靠并购扩张的上市公司，问商誉会不会暴雷、对赌到期后业绩会不会变脸、溢价去了哪里。

### 语言信号 (用户的话里出现这些就应激活)

- "并购估值""股权卖多少钱/买多少钱""增资入股""作价""定价"
- "评估报告""成本法/收益法""评估增值""增值好几倍""评估师"
- "商誉""高商誉""商誉减值""业绩承诺/对赌""承诺期后变脸""控制权溢价""溢价去了哪个科目"

### 与相邻 skill 的区分

- 与 `asset-quality-triage` 的区别：本 skill 处理**交易场景**（定价、评估方法采信、并购溢价追踪）；后者是**日常资产体检**（逐项看资产有没有水分、定位不良资产区域）。用户问"这家公司资产有没有水分"且无交易背景→找后者；问"这笔并购/增资值不值这个价"→用本 skill。
- 与 `financial-fraud-detection` 的区别：本 skill 看估值定价与商誉减值风险本身；后者看业绩承诺期**造假信号**（收入与应收显著背离、承诺期业绩精准踩线、虚增收入再减值）。若用户怀疑"标的在凑对赌业绩"，即使话题是并购也优先转后者。
- 与 `prospect-forecast-growth-options` 的区别：并购只是企业发展五途径之一；"这企业还有什么牌可打"的全景盘点、保壳式重组识别找后者，聚焦单笔交易的估值定价与商誉风险用本 skill。

## E — 可执行步骤 (Execution)

1. **识别交易场景与结构**：增资/收购股权/出售股权？是否控制权转移？双方身份（上市公司/非上市、是否关联方）？
   - 完成标准：一句话写清交易类型、双方与关联关系；若用户只是想了解概念，到此收口。
2. **用入资三重效应验交易**：入资资产能否持续贡献盈利？对债务保证是否扎实（非现金资产估价是否虚高）？股东间利益格局如何被重新划分？
   - 完成标准：三问各有一个明确结论；对非现金入资单独标注估价公允性判断。
3. **审评估报告**：评估方法与企业生命周期、表外资源盈利贡献是否匹配？增值幅度与评估师角色（谁委托、评给谁看）？
   - 完成标准：给出"采信/存疑/建议换方法"的结论及理由；判停条件——若发现标的疑似造假凑业绩，转 `financial-fraud-detection`。
4. **定价或核价（站买方立场）**：整体价值→按比例折算→控制权溢价→买方身份与持有目的修正（市盈率放大/回报率倒推）。
   - 完成标准：给出整体价值、份额价值、溢价调整、买方目的四个要素的量化区间，并与评估价/账面价对照说明差异来源。
5. **商誉与减值风险清单**：算商誉规模（或追踪零商誉下评估增值去了无形资产/固定资产等哪些科目）；测算摊销/减值压力（若按年限摊销是否由盈转亏）；列出跟踪点——业绩承诺进度、年末减值测试、关键审计事项。
   - 完成标准：给出"是否远离"（投资者）或"调整对价/条款"（交易方）的明确建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无交易背景的日常经营报表分析（问盈利、周转、上下游占款）——用八看各专项 skill。
- 问某项资产"值不值钱、有没有水分"但不涉及任何交易定价——转 `asset-quality-triage`。
- 二级市场股价涨跌预测——本 skill 面向交易定价与并购风险，不做证券投资建议。

### 作者在书中警告的失败模式

- **高商誉反噬**（蓝帆医疗）：发股融资→高对价并购→承诺期业绩"看上去很美"→承诺期后变脸、减值集中爆发，减值总额远超被并购企业三年净利润之和；不能被并购当年的收入、利润增长迷惑，要看核心盈利能力是否实质改善。
- **零商誉隐蔽转移**（紫金矿业）：对价刚好等于评估值、几乎不产生商誉，但评估增值大量进入无形资产与固定资产——代价并不低，风险只是转移到更隐蔽的科目；要用关键审计事项定位减值落点。
- **静态思维评价动态发展**：评估价值与整合后的实际价值会因企业发展而脱节（作者推动改用成本法的并购案，一年多后企业与过去"完全不可比"）。

### 作者的盲点 / 时代局限

- 案例与经验来自 A 股及非上市中国公司，跨境并购、金融类标的、无形资产密集行业的估值特殊性未展开。
- 批评收益法"参数弹性大"成立，但书中未给出折现率、增长率等技术取值的替代方法，落地仍靠常识与谈判博弈。

### 容易混淆的邻近方法论

- 商誉 vs 无形资产评估增值：两者都是并购溢价，只是落点科目不同，风险等价，不能只盯商誉科目。
- 账面价值、评估值、成交价是三个不同的数：评估方法决定估值逻辑，成交价才体现交易博弈与买方视角。
- "远离高商誉"不等于"商誉都是坏"：未减值说明企业对业务有信心（如美的收购库卡，财务贡献虽不突出但改善了收入形象与估值基础）——最终落点是后续盈利能力检验。
