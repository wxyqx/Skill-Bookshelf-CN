## 这本书在讲什么

传统财务报表分析教给你一堆比率:流动比率 2:1 安全、资产负债率低于 50% 稳健、净利润高就是盈利强。张新民和钱爱民这本书,就是冲着这套"比率信仰"来的。用传统指标看,格力电器流动比率长期只有约 1.1、资产负债率 80% 以上,妥妥的"高风险企业";可它没有有息贷款、盈利和获现能力极强、现金分红大方——董明珠反问:"业务增长、无贷款、盈利强、高现金分红,这是风险吗?"(第 7 章)。再看另一头:某 ST 公司靠卖两套学区房(成本两百多万、售价两千多万)抹平亏损、保壳摘帽,按"数量维度"确实扭亏为盈,按任何质量标准,盈利能力毫无起色(第 4 章)。比率只度量利润的数量维度,而误判恰恰发生在质量维度上。

作者的答案可以概括为两个关键词:**项目质量**与**战略视角**。前者要求把每张表拆到项目层面,逐项问"这个资产实际发挥的效用,和预期效用吻合吗?这个利润里有多少是真金白银?"——为此作者自创了"核心利润"(剔除投资收益、公允价值变动、政府补助等与营业收入无关的项目)和"核心利润获现率"等标尺;后者要求把资产负债表左边读成资源配置战略(经营主导还是投资主导)、右边读成资本引入战略(靠上下游、靠银行、靠股东还是靠自身利润),让报表数字连回企业的经营选择。

为什么值得听这套说法?因为张新民是"财务状况质量分析理论"的创立者,这套框架不是评论,而是可操作的程序:全书以一家公司(北陆药业 2019 年报)从第 1 章走到底 7 章,每个资产项目都配好了"分析切入点 + 常见操纵手法 + 真实案例"的三件套。作者自己说得很清醒:"财务报表分析既是一门科学,也是一门艺术。"(第 1 章)——本书教的是那门科学的部分。

## 一、报表是生产条件的产物:先读"出厂说明书"

拿到报表直接算比率,是多数人犯错的第一步。报表数字是在会计假设、权责发生制、历史成本这些"生产条件"约束下造出来的,天生带着局限:表外资源(人力、账外无形资产、客户资源)不反映,历史成本把不同时点的钱简单相加,会计政策差异让纵横比较都失真,而且管理层可以"你想看什么我提供什么"(第 7 章的四大局限清单)。所以在算任何数之前,有两个入口动作。

### 方法 1:审计意见定基调,附注还原项目

**它解决什么问题**:你无法亲自查账,怎么在最短时间内判断这份报表的会计质量是否可信、哪些项目值得细看?

**核心逻辑**:审计报告是报表的"质量鉴定书",五种意见按严重程度排序——标准无保留 < 带强调事项段无保留 < 保留意见 < 无法表示意见 < 否定意见——先用它给整份报表定基调。然后按**重要性原则 + 例外原则**圈定"重大项目与异动项目"(规模占比高的、突然剧烈变动的),再回到附注还原:附注约占年报一半篇幅,是解读每个项目背后管理活动的唯一入口,只有用附注解读,分析才能达到"个性化"的境界。

**书中的用法**:秋林集团 2018 年报被出具**无法表示意见**——这就是基调本身。接着作者对其其他应收款连环追问:账面近 40 亿元、99% 以上已计提减值,欠款方集中于几家珠宝公司且"全军覆没";为什么 9 人欠 2000 万也能 100% 计提?为什么账龄两年内就迅速认定无法收回?(第 3 章)追问的每一层都靠附注和披露细节展开,最终指向的已不是会计问题,而是内控失效、不排除大股东掏空。

**什么时候会失效**:审计意见本身带有人为估计因素,审计失败时这条防线直接失守;附注也是管理层写的,披露不足时框架落地能力骤降。

### 方法 2:常用比率先修正、再使用

**它解决什么问题**:教科书比率在真实报表上"反直觉"——龙头企业的流动比率低得吓人、周转率算出来"不换设备反而更快"——是公司有问题,还是比率有问题?

**核心逻辑**:多数失灵是口径问题,有修法可循。流动比率 2:1 只是美国经验值,龙头企业靠经营性负债(无息占款)运营,低流动比率反而是竞争力(OPM 悖论);应收票据大时,应收账款周转率要改用**商业债权周转率**;周转率一律用**计提减值前的原值**;固定资产周转率用原值而非净值;对外投资占比大时,总资产口径被稀释,应改用经营性资产口径;利息保障倍数被作者重新定义——还利息靠现金不靠利润,它只能从股东角度评价借债政策是否合算。

**书中的用法**:格力电器应收票据占比大,直接用应收账款周转率会严重失真,应改用"应收票据+应收账款"合并的商业债权回收期(第 7 章)。一修正,格力从"指标可疑"变成"指标失灵的受害者"。

**什么时候会失效**:修正规则本身基于制造业/贸易信用场景,对金融企业、新收入准则下的企业未必成立。

## 二、资产质量:逐项过"三性"标尺,逐项对操纵手法

这是全书的发动机。资产质量不是"资产值多少钱",而是"资产在**特定企业**中实际发挥的效用与预期效用的吻合程度"——同一项资产在不同战略下质量不同,所以永远是相对的、情境化的。作者给每个项目统一配三维标尺:**盈利性**(赚不赚钱)、**周转性**(转得快不快,闲置即低质)、**保值性**(会不会减值)。更实用的是,每个项目都有固定的操纵手法,质量分析 = 项目 + 手法 + 案例的配对。

### 货币资金:运用、构成、生成三维诊断

**它解决什么问题**:账面货币资金很多,就是支付能力强、财务安全吗?"存贷双高"(存款借款都高)到底是优势还是隐患?

**核心逻辑**:看三维。①**运用质量**——规模是否与业务规模、行业特点、战略投资机会匹配;②**构成质量**——币种构成 + **受限资金占比**(保证金、被质押、被冻结的部分要剔除,"自由度"才是真支付能力);③**生成质量**——钱来自经营、投资还是筹资,经营性流入占比高说明造血功能强。存贷双高有三种解释:票据保证金、分权管控下资金分散、融资环境扭曲——第三种叠上"短贷长投",就是资金链断裂的经典剧本。

**书中的用法**:北陆药业货币资金几乎全部可自由支用,经营每年净流入较大——三个维度全优,判定质量很高(第 3、5 章);对照反面,比亚迪式的存贷双高需要回到三种解释逐项排除(第 3 章边栏)。

**什么时候会失效**:集团资金集中管理下,单体报表的货币资金不归自己支配;受限信息依赖附注披露。

→ 深入: [`cash-quality-funding-risk`](../skills/cash-quality-funding-risk/SKILL.md)

### 应收款项:三步检验 + 其他应收款占款识别

**它解决什么问题**:应收账款急增是生意火爆还是虚构收入挂账?资金被大股东占用在报表上长什么样?

**核心逻辑**:应收账款三步走——**规模**(与收入、资产规模对比,急升即警报)、**周转性**(账龄 + 债务人六维分析:行业/区域/所有权性质/关联度/稳定性/集中度)、**保值性**(坏账政策与计提比例对照行业均值)。两个高危点:账龄可以人为"洗短"(给债务方资金让其还款再赊出);**其他应收款**是造假者"更安全的账户"——户数多、金额小、难查证,数额过高即不正常,重点排查大股东占用。第 3 章称大股东占用是"中国资本市场最大的毒瘤"。有一个重要例外:集权式资金管理下,母公司对子公司的大量其他应收款是正常安排,要看合并报表差额。

**书中的用法**:秋林集团其他应收款近 40 亿、计提 99% 以上——作者从计提行为反推:表面是会计随意,深层是治理失效、不排除掏空(第 3 章)。三达膜的启示:应收账款相对规模急剧上升而常理解释不了,要警惕虚构收入挂账。

**什么时候会失效**:债务人与关联关系信息依赖披露;集团内部资金往来易被误杀为占用。

→ 深入: [`receivables-and-funneling`](../skills/receivables-and-funneling/SKILL.md)

### 存货与毛利率:抓住"低转成本"的对账关系

**它解决什么问题**:毛利率突然大幅提升、或常年高于同行,是竞争力还是造假?

**核心逻辑**:存货四维看——构成(原材料/产成品比例的管理含义)、盈利性(毛利率水平与走势)、周转性(并非越高越好,与债权回款此消彼长;差异化战略靠毛利率、成本领先战略靠周转率)、保值性(跌价准备,防潜亏挂账)。识别操纵的对账关系:**营业成本 + 期末存货 = 可供出售成本,两者此消彼长应大体恒定**——"低转成本"把已售成本留在存货里,虚增毛利;所以毛利率巨幅波动本身就是操纵的显性证据。注意"高转成本"反向操作可为来年扭亏埋伏笔。

**书中的用法**:蓝田股份、银广夏通过低转成本把已售成本藏进存货,既虚增毛利率,还顺手做大存货抵押贷款的筹码(第 3 章)。识别路径就是毛利率异常波动 + 营业成本与期末存货相对规模的异常变动。

**什么时候会失效**:行业周期、产大于销(囤货)也会推高毛利率,需归因排除后才能定性。

→ 深入: [`inventory-and-margin`](../skills/inventory-and-margin/SKILL.md)

### 长期资产:权益法泡沫、不转固的在建工程、商誉洗大澡

**它解决什么问题**:长期投资有利润没现金、在建工程长期挂账、商誉说减就减——长期资产这边每个项目都藏着更隐蔽的利润调节器。

**核心逻辑**:逐项配对。**长期股权投资**:权益法确认的投资收益会同时虚增收益与投资账面值(泡沫大小取决于被投资方分红),成本法下才有现金支撑;减值不得转回,操纵被推向计提时点。**在建工程**:已投用却不竣工决算有三大好处——继续资本化利息、推迟折旧、费用鱼目混珠,核查办法是对工期。**商誉**:虚拟资产、双刃剑,减值测试高度依赖管理层判断——计提 100% 还是 60% 是两种完全不同的报表叙事。**无形资产**:自创支出费用化导致账外"游离",账面值只是最低可收回金额,账面小不等于质量差。

**书中的用法**:万福生科造假专挑虚增**在建工程和预付账款**两个"安全"科目(第 3 章边栏);普洛药业因医药政策变化,对山西优胜美特的 919 万元商誉**全额**计提减值——一次亏个够,还是此前计提不足?计提比例本身就是管理层的态度表达(第 3 章)。

**什么时候会失效**:减值参数(现金流预测、折现率)不披露或披露笼统时,只能定性怀疑,无法定量拆穿。

## 三、战略透视:资产负债表左右两半各藏一个战略

逐项看完质量,要把项目合回结构看战略——这是本书区别于所有传统教材的立论:报表结构是战略实施的结果,可与年报里的"战略承诺"对照验证。

### 资源配置战略三分类:左边看企业把钱押在哪

**它解决什么问题**:这家公司到底是干什么的——靠自身经营赚钱,还是靠投资子子孙孙赚钱?战略说到,资金做到了吗?

**核心逻辑**:把资产按**利润贡献方式**(不是会计科目)重分类为经营性资产与投资性资产(现金归经营性;被关联方占用的预付款、其他应收款归投资性)。两者比重分出**经营主导型、投资主导型、经营与投资并重型**。判断入口在**母公司报表**:经营性资产与控制性投资(长期股权投资 + 母公司向子公司提供的资金)的对比。再检验战略吻合性——利润结构与资产结构是否大致对应,经营主导型企业看核心利润,投资主导型企业看投资收益。

**书中的用法**:普洛药业母公司报表里没有应收票据、应收账款、存货,固定资产占比极小——经营主体全在子公司,典型的**投资主导型 + 相关多元化**(中间体及原料药占收入 73.42%)(第 3 章);卫光生物则相反,经营主导、专业化,核心竞争力突出但战略稍显保守。

**什么时候会失效**:并重型是个兜底类别;跨行业集团、金融企业与轻资产平台型企业,经营/投资的边界本身就模糊。

→ 深入: [`asset-allocation-strategy`](../skills/asset-allocation-strategy/SKILL.md)

### 资本引入五型与四大动力:右边看钱从哪来

**它解决什么问题**:负债率高就危险吗?净资产增长就说明企业变强了吗?

**核心逻辑**:把资本按来源重分类为**四大动力**——经营性负债(上下游占款,源于议价能力,基本无息)、金融性负债(有息有期限)、股东入资、利润积累,对应**五种资本引入战略**(经营驱动/举债驱动/股东驱动/利润驱动/并重驱动)。三个推论:①用金融性负债÷总资产算**资产金融性负债率**,它比资产负债率更能揭示真实偿付压力;②权益增加要区分**输血性**(股东入资)与**盈利性**(自身盈利)——同样是净资产增加,信号完全不同;③经营性负债居高不下有两种截然相反的解释:龙头议价力,或经营困难周转不灵。

**书中的用法**:卫光生物金融性负债为零、资产负债率 8.18%,四大动力排序为股东入资第一、利润积累第二——股东驱动型,偿债无忧但未用杠杆,未来债务融资空间大(第 3 章);北陆药业的排序是利润积累 > 股东入资 > 经营性负债,作者称之为"自力更生、艰苦奋斗"(第 7 章)。

**什么时候会失效**:经营性负债被视为"无息红利"的前提是供应链关系稳定——渠道模式被击穿时,高占款企业的风险会瞬间显性化。

## 四、利润质量:先分层,再验金

利润表上的"高利润"不等于"强盈利能力"。作者的方法分三步:先分层定位利润的真实来源,再验含金量,最后按三维打分。

### 核心利润:把利润拆到与营业收入真正同源的层次

**它解决什么问题**:净利润被投资收益、公允价值变动、政府补助、资产处置撑大时,与营业收入相比的任何"利润率"都没有意义;扭亏保壳的成色怎么验?

**核心逻辑**:利润表分层阅读——毛利 → **核心利润** → 营业利润 → 利润总额 → 净利润,毛利、核心利润、营业利润是"利润的三大支柱"。核心利润 = 毛利 − 税金及附加 − 销售/管理/研发费用 − 利息费用,只反映企业**自身经营活动**的成果;只有核心利润与营业收入相比才有意义。非经营项目逐项过堂:政府补助看四要点(业务关联度、政策研究能力、主营业务竞争力、政策阶段性);投资收益做现金回款还原;公允价值变动是浮盈,可能消失;类别转换收益是纯账务处理,一分钱现金也不带来。

**书中的用法**:开篇那个 ST 公司卖两套学区房抹平亏损——处置收益是非经常、一次性的,核心利润纹丝未动,扭亏成色为零(第 4 章)。反面加深一层:长安汽车 2018 年其他收益(政府补贴)28.73 亿元,当年营业利润为 −2.01 亿、净利润 7.23 亿——**没有补贴即为亏损**;而且新能源补贴 27.28 亿挂在其他应收款上尚未收回,最长账龄近 4 年——补贴连现金都不即时。作者由此断言:"完全靠政府持续补贴生存的企业不会有持续的竞争力。"(第 4 章)

**什么时候会失效**:利息费用计入核心利润的扣减项,对高杠杆企业和金融企业口径会扭曲;减值金额大时归入核心利润的处理本身带主观性。

→ 深入: [`profit-quality-3d`](../skills/profit-quality-3d/SKILL.md) · [`non-operating-income-quality`](../skills/non-operating-income-quality/SKILL.md)

### 收入三问与利润三维:数量之外加质量

**它解决什么问题**:收入和利润的"持续性"与"战略匹配"怎么判断?为什么同样 10 亿利润,两家公司质地天差地别?

**核心逻辑**:收入按**三问**拆——卖什么(品种构成,警惕主导产品单一化)、卖给谁(地区 + 客户集中度)、靠什么(关联交易 + 行政手段)。利润整体按**三维**评价——**含金量**(利润带来现金的能力,下一节用获现率量化)、**持续性**(成长性 + 波动性)、**战略吻合性**(利润结构与资产结构是否对应)。数量维度回答"赚了多少",三维回答"这份利润值不值钱、明年还在不在"。

**书中的用法**:北陆药业 2019 年非经常性损益占净利润 51.36%(主要是世和基因股价带来的 1.73 亿公允价值浮盈 + 1398 万类别转换收益),剔除后"真实"业绩约 1.67 亿;收入端对比剂占 80.98%——作者判定"主导产品单一化",建议向"主导产品下的多元化"转型;三维打分:经营主导 + 适度投资,经营性资产报酬率约 20%,吻合度高(第 4 章)。

**什么时候会失效**:经验判据(收入增速 10%/30% 分生命周期)无统计依据;"大致相当"的吻合性基准缺乏独立标准。

→ 深入: [`revenue-quality-three-questions`](../skills/revenue-quality-three-questions/SKILL.md)

### 核心利润获现率:给利润验金的量化标尺

**它解决什么问题**:利润是不是收到了钱?"有利润没钱"的五类缺口怎么归因?

**核心逻辑**:核心利润获现率 = 经营活动现金流量净额 ÷ 核心利润,经验底线**至少大于 1**(传统行业 1.2~1.5 倍更佳)。小于 1 时按五类原因排查:收款不正常减少、付款不正常增加、不恰当资金运作、主要与关联方往来、报表编制错误。注意"同口径"调整:核心利润要加回折旧摊销等非付现费用、减去所得税,才与现金流量净额可比。

**书中的用法**:北陆药业获现率从 1.22 降至 0.85——是否恶化?作者结合销售费用大增 46%(开拓市场的主动投入)、无利息负担、资本开支小,判定经营现金流量仍充裕,0.85 属正常波动(第 5、7 章)。同一个数字,归因不同,结论完全不同——这正是"质量分析"与"比率计算"的区别。

**什么时候会失效**:作者明言该标准"不考虑行业差异和企业所处发展阶段",而房地产等行业现金与利润分布严重错期,同一标尺难以两头兼顾。

→ 深入: [`cash-quality-funding-risk`](../skills/cash-quality-funding-risk/SKILL.md)

## 五、现金与集团:用现金验证利润,用差额读懂集团

### 现金流量三性:禁止只看净额正负下结论

**它解决什么问题**:经营现金流量净额为负就是坏事、为正就是好事吗?剧烈波动哪些属正常、哪些是危险信号?

**核心逻辑**:三类活动各有各的质量维度。**经营活动看三性**:充足性(净额能否支撑简单再生产并超过核心利润)、合理性(流入看营业收入与应收/预收余额变化的匹配,流出看营业成本与应付/存货变化的匹配,有无过度支付)、稳定性(规模结构不剧烈波动,流入以销售收现为主——波动本身就是操纵线索)。**投资活动看战略吻合**:对内"购建 vs 处置"判扩张/收缩/置换,对外"投资 vs 收回"判结构调整。**筹资看行为恰当性**:主动融资还是失控后的被迫输血。先归因(行业、发展阶段、战略),再定性。

**书中的用法**:乐视网 2016—2018 年经营净额从 −10.68 亿一路恶化到 −54.65 亿,持续靠巨额筹资流入输血(2017 年筹资净流入近百亿)——不用算任何比率,纯做质量分析,资金链断裂的剧本已写在表上(第 5 章章末案例)。

**什么时候会失效**:初创期、转型期经营现金为负可能是正常状态;三性的"合理性、稳定性"判断没有可复制的阈值,依赖行业经验。

→ 深入: [`cash-flow-three-activities`](../skills/cash-flow-three-activities/SKILL.md)

### 差量分析法:合并报表"消失"的资金才是信息

**它解决什么问题**:合并报表是会计主体的"混合物",不反映任何现存企业——偿债、分红、付酬、缴税等真金白银的决策必须回到母公司报表;那两套报表放在一起,还能读出什么?

**核心逻辑**:把合并报表与母公司报表**逐项相减**。"越合并越小"的项目藏着答案:资产端差额 = 母公司对子公司的**控制性投资**(长期股权投资、其他应收款、预付款项都可能藏),负债端差额 = 子公司汇交母公司的资金。控制性投资撬动的合并资产增量,除以控制性投资规模 = 扩张倍数,再按子公司四大动力(经营性负债/金融性负债/少数股东入资/利润积累)归因扩张好坏。还能反推资金管理模式(母公司"三高"——利息、借款、其他应收款都高 = 集权)和母子业务关系(一致对外 / 母销子售 / 子为母配套)。

**书中的用法**:普洛药业母公司其他应收款 5.57 亿 vs 合并 0.73 亿、长期股权投资 17.43 亿 vs 合并 1.22 亿——"消失"的 20 多亿资金就是对子公司的控制性投资(第 6 章引例)。更锋利的是卫光生物:控制性投资 1.87 亿,但合并资产仅比母公司多 **808 万**——撬动效果"显然不够理想",归因四查显示子公司不对外赊销、零金融负债、少数股东贡献仅 80 万、自身亏损(第 6 章)。

**什么时候会失效**:受减值准备、母子往来干扰,作者自认只能"粗略估计";集团行业跨度大、企业结构复杂时,简单对比难以反映管理实际。

→ 深入: [`differential-analysis`](../skills/differential-analysis/SKILL.md) · [`consolidation-pitfalls`](../skills/consolidation-pitfalls/SKILL.md)

## 六、收口:四步综合路径

所有单项方法最终要落成一条拿到年报就能走通的路径:**背景分析 → 会计分析(审计意见)→ 战略视角财务分析(先比率、后八步战略与竞争力检查:四大动力归因 → 扩张战略类型 → 主要资产变动含义 → 不良资产区域 → 负债与权益结构 → 流动性保障 → 融资潜力 → 双表对照)→ 前景预测(经营性资产、投资性资产、重组并购三条线)**。北陆药业 2019 年报从头走一遍:标准无保留意见 → 盈利营运偿债均强但获现率下滑、大量货币资金闲置拉低报酬率 → 纯经营型、自力更生型资本结构 → 结论"经营主导、专业化、现金流畅顺",建议强化主业 + 通过控制性投资适度多元化。

格力电器的引例为整条路径定调:单看比率判为高风险的企业,放进经营性负债的议价力、盈利与获现的造血能力里重新评价,结论反转——**比率的科学性,有待研究**。

## 陷阱与反例

**1. 低转成本虚增毛利(蓝田、银广夏)**。机制:把已售产品的营业成本留在期末存货里,毛利率立刻抬高,存货还能做贷款抵押。人为什么掉进去:只看毛利率走势,从不做"营业成本 + 期末存货 = 可供出售成本"的对账。预警信号:毛利率巨幅波动或常年偏离同行,且存货增速与营收增速脱钩。

**2. 洗大澡(秋林)**。机制:在关键年份集中计提巨额减值("让它一次亏个够"),把历史包袱一次出清,为来年轻装扭亏铺路。秋林 2018 年资产减值损失 40.83 亿,是上年 3366 万的 **120 倍**——要么此前严重计提不足,要么当年过度计提,两头都说明利润被会计估计支配(第 4 章)。预警信号:减值损失突然放大数十倍、发生在亏损/保壳年份。

**3. 其他应收款占款**。机制:其他应收款科目户数多、金额小、难查证,是大股东掏空上市公司和关联方资金输送的"更安全的账户"。预警信号:单体报表其他应收款规模与业务不匹配;合并层面仍巨大(集团内部往来的那部分可豁免)。

**4. 虚构收入的消化路径(三达膜教训)**。机制:虚构收入挂在应收账款上,日后以**销售退回或坏账核销**消化,业绩跳水只是时间问题。预警信号:应收增速持续大幅超过收入增速、账龄结构异常、向债务方提供资金让其还款再赊出的"账龄洗短"。

**5. 利润质量恶化十二信号清单(第 4 章)**。扩张过快("过快成长等于加速灭亡")、过度举债、审计师频繁变更或报告异常、变更会计政策恰好利好利润、应收应付不正常增长、存货周转过慢、无形资产/开发支出不正常膨胀(费用资本化虚盈实亏)、依赖非经常性损益、期间费用反常、反常压缩研发广告培训等酌量性支出、有钱不分红——单条出现是观察,多条交叉命中就是预警。

**6. 好指标 ≠ 好状态**。北陆药业偿债能力"极强"的另一面,是经营理念保守、财务杠杆未用、净资产收益率本可更高;迎合再融资监管的大规模现金分红,也不等于利润质量高(第 3、7 章)。机械追求"漂亮比率"同样是一种陷阱。

## 作者的局限 (读这本书要打的折扣)

**1. 保值性评价存在循环论证风险**。三性标尺中,盈利性、周转性有量化指标,保值性却高度依赖减值数据——而作者自己反复强调减值计提恰恰是被操纵的环节。用可能被操纵的数据评价质量,是这套框架最深的一处裂缝;作者给了警觉清单,没有给穿透操纵的独立验证手段。

**2. 对附注与审计意见的可信度过于乐观**。几乎所有框架(账龄、债务人构成、受限资金、商誉参数)都要求附注披露充分,但附注同样是管理层写的;"以审计意见替代会计分析"是成本节约,审计失败情形下没有第二道防线。

**3. 经验数值无统计依据**。含金量 1.2~1.5 倍、获现率底线 1、收入增速 10%/30% 的生命周期判据,作者都标注为经验数据、不考虑行业差异——跨行业照搬有风险,对房地产等利润与现金严重错期的行业尤其如此。

**4. 案例证据单向**。反面案例(秋林、乐视)都是事后追溯——减值发生了才看出问题,框架的**事前**预警能力未被独立检验;正面案例北陆药业与作者方法同源,缺少独立基准。且案例集中于 2019 年前后的 A 股制造业/医药企业,对互联网平台、金融企业的适用性,作者只以脚注承认"新商业模式对传统方法提出很大挑战"。

## 关键术语速查

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 资产质量 | 资产在特定企业中实际效用与预期效用的吻合程度 | 不是资产本身好坏,是情境化的、相对的 |
| 三性 | 每个资产项目的盈利性、周转性、保值性三维标尺 | 常识只看值多少钱;作者看赚不赚、转不快、贬不贬 |
| 核心利润 | 毛利−税金及附加−销售/管理/研发费用−利息费用 | 不是净利润也不是营业利润;剔除非经营项目 |
| 核心利润获现率 | 经营现金流量净额÷核心利润,经验底线 >1 | 检验利润是不是真收到了钱 |
| 经营性/投资性资产 | 按利润贡献方式重分类;现金归经营性 | 与准则的"投资性房地产"等科目分类完全不同 |
| 控制性投资 | 母公司为取得控制权投入的资源,可藏于其他应收款/预付款 | 比报表"长期股权投资"口径大 |
| 四大动力 | 金融性负债、经营性负债、股东入资、利润积累 | 资产负债表右边的独特读法 |
| 资产金融性负债率 | 金融性负债÷总资产,"真杠杆" | 比资产负债率更能揭示真实偿付压力 |
| 输血性/盈利性变化 | 净资产增加靠股东入资还是自身盈利 | 同样是净资产增长,信号完全不同 |
| 差量分析法 | 合并与母公司报表逐项相减,差额反推集团管理与战略 | 不是会计准则术语,是作者招牌方法 |

## 如果只带走三句话

1. **别拿净利润和营业收入的比率当盈利能力**:把利润表分层到核心利润,剔掉投资收益、公允价值浮盈、政府补助,再用经营现金流量净额验金——核心利润获现率上不了 1,利润再多也是纸面富贵。
2. **每个资产项目都有固定的操纵手法**,分析 = 项目 + 手法 + 案例配对:毛利率异常去对账"营业成本+期末存货",应收急增去查账龄与债务人,在建工程查工期,商誉问计提比例。
3. **资产负债表左右两半各藏一个战略**:左边是资源配置(经营主导/投资主导),右边是资本引入(四大动力、五种类型);拿报表结构对照年报里的战略承诺,说到没做到,一目了然。
