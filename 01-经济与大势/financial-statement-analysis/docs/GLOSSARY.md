# 术语词典 (GLOSSARY) — 《财务报表分析(简明版·立体化数字教材版)》

本词典收录张新民、钱爱民在本书中**特有或特用**的概念：既有作者自创的术语（核心利润、差量分析法、四大动力等），也有被作者赋予特殊定位或用法的常规概念（商誉、持续经营、审计意见等）。所有定义**一律以作者用法为准，非字典义**：同一个词在别处可能有更宽或更窄的含义，本词典只回答"在本书里它指什么、作者拿它做什么"。加粗术语为作者自创或明确宣称原创的概念。

---

## 一、资产质量类

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| **资产质量** | 资产在特定经济组织中实际发挥的效用与其预期效用的吻合程度（借克劳士比"质量就是符合要求"改造），分项目个别质量、资产结构质量、资产总体质量三层 | 不是资产本身值多少钱，而是情境化的、相对的：同一资产在不同企业、不同时期质量不同 |
| **三性（资产）** | 逐项资产的三维评价标尺：盈利性（能否带来经济利益）、周转性（利用效率，闲置即低质）、保值性（未来不发生减值的可能性，对固定资产等尤为关键） | 常识只问"值多少钱"，作者还问赚不赚钱、转得快不快、减不贬值；注意与现金流量的另一组"三性"同名不同物 |
| **经营性资产与投资性资产** | 按利润贡献方式对资产的战略性重分类：经营性资产（货币资金、商业债权、存货、固定资产、无形资产）创造核心利润，投资性资产（各类金融投资、长期股权投资）带来投资收益 | 不是会计科目分类：货币资金被特意归入经营性资产；被关联方占用的预付款项/其他应收款理论上归投资性；拒绝"金融资产"称谓以免与会计口径混淆 |
| 不良资产区域 | 资产质量的"减法"视角：坏账、呆滞存货、被长期占用的其他应收款、亏损的长期股权投资、闲置固定资产等，通常已计提减值；通过两减值损失规模考察新增不良 | 不看资产原值看减值——减值的规模、结构与趋势就是不良资产的显影；但减值计提有主观性，须防"洗大澡"或计提不足 |
| **造血功能** | 经营活动创造货币资金的能力。造血正常的企业，经营战略与规模未变时货币资金应持续上升 | 同样"账上钱变多"，来源不同信号完全不同：靠经营流入是造血（茅台、格力式），靠筹资或处置资产是输血维持（乐视式），是企业质地的分水岭 |
| 低转成本 | 作者点名的造假术语：已售产品成本不转入营业成本、仍留在存货，虚增毛利率与存货，还可放大抵押贷款筹码 | 识别组合拳=存货余额异常增长+毛利率偏离行业均值且巨幅波动（产品结构未变时）；蓝田、银广夏为书中点名案例 |
| **泡沫资产** | 权益法下按被投资企业净利润份额确认投资收益、同步做大长期股权投资所形成的"不能用于支付或分配"的账面成分，大小取决于对方分红程度 | 有利润没现金的典型：分析长期股权投资只认实际分红回流的现金，因权益法确认收益导致的投资增加"难以产生实质性正面贡献" |
| 合同资产与合同负债 | 作者对新收入准则科目的风险视角解读：合同资产除信用风险外还承担履约风险；合同负债与预收款项有本质区别，须从履约义务维度理解 | 预收款项/合同负债规模变化被视为来年业绩晴雨表；偿付只需发货（差一个毛利），含大额预收款企业的真实偿付能力远强于流动比率所示 |
| 商誉 | 典型的**虚拟资产**：只证明过去发生了溢价并购，本身不直接带来未来收益；双刃剑——高估协同效应则成为未来负担；还降低资产负债率、虚化偿债能力 | 控股合并下商誉只在合并报表列示（母公司无、合并有），是差量分析典型对象；减值计提比例有操纵空间，"程序合规≠没有操纵"（普洛案例） |

## 二、利润与现金类

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| **核心利润** | 作者自创、全书分析基石：核心利润=毛利−税金及附加−销售费用−管理费用−研发费用−利息费用，纯粹反映企业自身经营活动的成果 | 不是净利润也不是营业利润——投资收益、公允价值变动、政府补助、资产处置收益等与营业收入无关的项目全部剔除；立论起点："与营业收入无关的项目除以收入没有分析意义" |
| **同口径核心利润** | 为与经营活动现金流量净额可比而做的口径调整：核心利润+折旧摊销等非付现费用−所得税费用 | 直接拿核心利润与经营现金净流量比会有口径差；作者先"对齐口径"再比较，稳定发展条件下两者应大体相当 |
| **利润质量** | 含金量+持续性+战略吻合性的三维综合属性，建立在"资产创造利润，利润带来现金流量"的逻辑之上 | 不是"利润高=盈利强"；利润质量恶化是缓慢隐蔽的过程，但有 12 种可观察的外在表现，可以清单化扫雷 |
| 利润的含金量 | 利润质量三维之一：主要利润构成项目获得现金流量的能力。分项目操作：核心利润对经营现金净流量、投资收益对"取得投资收益收到的现金"、其他收益对补贴回款 | 作者的核心隐喻——利润像金属，含金量指其中由真实现金支撑的成色；回款付款正常时利润与现金流应保持大体稳定比例，比例失稳本身就是警报 |
| **核心利润获现率** | 经营活动现金流量净额÷核心利润×100%，本书方法论的标志性指标。经验底线：至少大于 1；传统行业达 1.2~1.5 倍即含金量充足 | 分子分母都只反映经营活动（不与净利润比），保证口径一致；获现率<1 须按五类原因排查（回款不足、付款异常、资金运作、关联往来、编制错误），先找原因再下结论 |
| 利润的战略吻合性 | 利润质量三维之三：母公司口径下"经营性资产:投资性资产"与"核心利润:投资收益"两个比例长期大致相当，即为战略实施效果好的证据 | 盈利能力评价被连回战略——利润结构不只是结果，还是战略执行是否到位的证据；控制性投资规模大时改用三分类口径 |
| 非经常性损益 | 作者强调这是**资本市场的监管概念**而非会计准则概念（证监会四次界定，须实质性判断），并给出按经营/投资/筹资活动的识别清单 | 剔除非经常性损益后的净利润才是跨期可比的"真实"业绩；北陆 2019 年该项占净利润 51.36%，直接动摇当年利润的持续性 |
| **类别转换收益** | 作者对投资收益三分法（持有/处置/类别转换）之一：持股比例变化导致核算类别转换（如长期股权投资转入公允价值计量金融资产）时产生的收益 | 纯粹是变更时的账务处理：零现金流、一次性、不具持续性，应全部作为非经常性损益剔除（北陆世和基因转换收益 1398 万元即典型） |
| 其他收益（政府补助的"营业内升格"） | 2017 年报起与日常活动相关的政府补助从营业外收入"升格"为其他收益、构成营业利润支柱，故专设四要点质量分析（政策关联度、政策研究能力、主营竞争力、政策阶段性） | 补贴收入的持续性取决于政策连续性；且补贴不总带来即时现金——长安 28.73 亿其他收益中 27.28 亿长期挂账，"有补贴收入、无补贴现金" |
| 酌量性支出 | 管理层可自主决定规模的支出（研发、广告、培训等），效益多不在当期实现，一定时期内应相对稳定 | 作者用它做反向预警："反常压缩"酌量性支出是为保当期利润的蓄意行为，往往预示利润质量将进一步恶化 |
| 洗大澡 | 业内俗称被纳入分析工具箱：在亏损年、换帅年或扭亏前一年集中、过度计提减值，一次性出清历史风险，轻装上阵或为下年扭亏预留空间 | 识别信号是减值损失年度间数量级突变（秋林 2017 年 2000 多万对 2018 年 37.4 亿）且与经营惯性不符；与"巨额摊销""潜亏挂账"同族 |
| 商业债权周转率 | 作者的修正指标：赊销净额/（平均应收账款+平均应收票据），用坏账准备前原值、分子考虑增值税销项；配套商业债务平均付账期使用 | 传统应收账款周转率在应收票据占比大的企业（如格力）严重失真；作者自认票据与账款回收保障不同、直接相加不完全恰当，须以附注账龄补充 |
| **现金流量质量** | 分活动的多维属性：经营活动看充足性、合理性、稳定性与战略支持力度；投资活动看流出与战略的吻合性；筹资活动看适应性及融资行为恰当性 | 质量不是"现金多"，而是现金的来路、去路与结构对企业发展有利；禁止只看净额正负符号下结论 |
| **三性（现金流量）** | 经营活动现金流量的三维标尺：充足性（正常时应大于核心利润）、合理性（流入顺畅、流出恰当）、稳定性（年度间规模结构不剧变，剧变可能意味着人为操纵） | 与资产质量的"三性"同名不同物；正的经营净流量之外，初创期、转型期、危机期之外持续为负才是警报 |
| 现金（现金流量表的严格口径） | 库存现金及可随时用于支付的银行存款，即"货币资金"中真正可随时支取的部分；保证金、法定准备金、受管制外币等受限部分剔除 | 账面货币资金与真实支付能力之间隔着"自由度"——必须查受限资金占比，这也是"存贷双高"判读的前提之一 |
| "大进大出" | 作者描述投资活动流量态势的行话词汇表：对内大进大出=长期经营性资产置换优化；对外大进大出=投资结构调整；流出远大于流入=扩张；流入明显大于流出=收缩 | 作者否定投资活动流入流出的"匹配性"分析（投资回收有滞后性），代之以战略吻合性解读，效果用以后期间核心利润与经营现金流检验 |

## 三、资本与战略类

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| **经营性负债与金融性负债** | 体系中最重要的负债二分法：经营性负债源于经营活动与议价能力（应付票据账款、预收、其他应付款），综合成本低；金融性负债取自金融机构/资本市场，有固定利息与确定还款日 | 传统分析把"负债"一刀切当风险，作者按取得途径分性质；该二分是解释"高负债率≠高风险"的概念基础，贯穿四大动力与资本引入战略 |
| **资产金融性负债率** | 作者明确宣称"本书作者创立并倡导使用"：金融性负债总额÷资产总额，又称资产有息负债率，是"真杠杆" | 比资产负债率更能揭示真实偿付压力：只有金融性负债构成确定偿付压力；解释了格力"高负债率低风险"与北陆"资产负债率 10.67% 但该指标为 0"的悖论 |
| **强制性负债** | 对流动负债的再分层：强制性债务（应付票据账款、短期借款等）构成现实偿付压力；非强制性部分（预收款项、沉淀性的应付薪酬与税费）不必当期或不必用现金偿付 | 不分层直接用流动比率，会系统性高估流动性风险；预收款偿付只差一个毛利，真实压力远小于账面 |
| **输血性变化与盈利性变化** | 所有者权益增加的两种性质：靠股东入资（输血）vs 靠自身盈利（造血），资产结果相似、质量信号截然不同 | 净资产增加不等于企业变好——输血性变化的资产盈利方向难以预料，盈利性变化才预示可持续发展 |
| 资本结构质量 | 作者的核心拓展：资本结构=融资结构+股权结构+控制权结构的多层概念；质量=与企业当前及未来发展的适应性，按五个关注点评价（成本匹配、期限协调、财务弹性、控制权治理、利益相关者和谐） | 不是"负债率越低越好"：过度举债是灭顶之灾，过度权益融资则控制权旁落（"野蛮人"），资本结构直接决定治理结构 |
| **资本引入战略（五型）** | 跳开传统负债/权益分类，按经营性负债、金融性负债、股东入资、留存收益四类资本的比重大小分五型：经营驱动、举债融资驱动、股东驱动、利润驱动、并重驱动 | 读资产负债表右边即知企业的发展道路与风险性格；经营驱动型须防把经营困难误判为行业主导，利润驱动型过于保守恐成"野蛮人"猎物 |
| **发展的"四大动力"** | 读资产负债表右边的独特框架：金融性负债、经营性负债、股东入资、利润积累四类资本来源的贡献结构，即资本引入战略，可反推治理特征与发展模式 | 教科书看"资产负债率"一个数，作者看四个动力的排序与消长；第 6 章延伸为子公司发展四大动力归因，诊断控制性投资扩张效果 |
| **资源配置战略三分类** | 把资产负债表左边读成战略宣言：按经营性/投资性资产相对比重分经营主导型、投资主导型、并重型；资产规模与结构就是资源配置战略的实施结果 | 资产结构不是"数字"而是战略实施结果，可与年报"战略承诺"对照检验吻合性；判断入口在母公司报表 |
| 类金融模式（OPM） | 龙头企业凭议价能力占用上下游资金（商业债务远大于商业债权），即"用别人的钱"；账面流动比率偏低但恰是竞争力体现 | 流动比率 2:1 的教科书标准会把格力式强势企业误判为高风险；商业信用的利用不是被动结果而是主动战略安排 |

## 四、集团报表类

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| **控制性投资** | 母公司为取得并维持对子公司控制而投入的全部资源：法定形态是长期股权投资，实际常以其他应收款、预付款项"隐藏"于报表；关键命题"母公司的控制性投资就是子公司的经营性资产" | 口径比报表"长期股权投资"大：通过母公司与合并报表的"越合并越小"项目差额识别；其效益取决于子公司经营成果而非母公司分红政策 |
| **差量分析法** | 作者招牌方法、自称合并报表分析"所特有的"：合并报表与母公司报表逐项相减，在差额基础上反推集团资源分布、母子关联、管理质量与扩张效果 | 差额是"信息"而非"误差"——口诀是"越合并越小"项目的差额=母公司投入子公司的资源（资产端）或子公司汇交母公司的资金（负债端） |
| **两种"三高"** | 作者原创的口诀化术语：母公司"三高"（利息费用高、长短期借款高、其他应收款高且合并数远低于母公司）=集权资金管理模式；合并"三高"（货币资金高、借款高、财务费用高）=分权模式 | 不读附注也能从报表形态快速判断集团资金管理体制；集权可降低融资成本、提高资金使用效率 |
| 合并报表、汇总报表与个别报表 | 用两把尺子区分三种报表：范围依据（行政隶属 vs 控制关系）与数据形成方法（简单加总 vs 抵销后合并）；合并报表主体只是会计主体而非法律主体 | 广泛流传的"汇总"思维正是误用合并报表的根源；分红、偿债、纳税等真金白银的决策必须回到母公司个别报表 |
| 合并财务报表与双重披露制 | 合并报表=经济主体整体信息，母公司报表=法律主体自身信息；我国实行双重披露制，两套报表同时提供 | 作者把中国分析者拥有两套报表视为"制度红利"——"是否恰当利用母公司报表和合并报表"被上升为决定分析结论质量的大问题，是差量分析的制度前提 |

## 五、分析方法类

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| **财务状况质量** | 2001 年首次提出的全书母概念：企业质量（治理与管理活动的综合结果）最终沉淀为财务状况质量，故可从公开报表反推企业"质地"；分资产、资本结构、利润、现金流量四个分项质量加整体质量 | 不是"财务状况好坏"的静态打分，而是"符合既定标准或目标的程度"；普通读者看规模与比率，作者看四个质量的合成与传导 |
| 狭义与广义的财务报表分析 | 作者的概念划界：狭义=报表内分析（偿债、盈利、营运+重点项目质量）；广义=加上表外信息的战略分析、管理质量分析、行业竞争与风险价值分析；作者明确主张广义概念 | 只做比率计算在作者看来不构成完整的财务报表分析；项目质量分析法是报表分析与战略分析之间的桥 |
| 盈利能力的数量维度与质量维度 | 二维定义：数量维度=绝对规模+相对规模（各种报酬率）；质量维度=含金量、持续性、战略吻合性；作者断言全部传统盈利比率"没有摆脱仅用数量维度衡量的束缚" | 这一"数量+质量"双维是贯穿全书的方法论总纲（资产、资本结构、利润、现金流量四个质量领域通用），扭亏为盈也须双重翻转 |
| 持续经营假设 | 作者的三重特殊用法：①权责发生制的理论基础；②健康标准——年审核心内容，甚至决定审计意见类型；③制度变量——2020 年新《证券法》以其取代"持续盈利能力"作为上市条件 | 不只是教科书假设，而是会随制度环境变化、直接改变报表分析重心的活概念 |
| 货币计量假设 | 作者用它解释报表的三类系统性盲区：表外资源不可见（人力、数据、客户资源）、历史成本与公允价值的两难、高通胀时期信息贬值 | 对人力资本、数据资产驱动型企业，报表天然"低估值"，必须主动补充非货币信息——这是"非会计信息日益重要"主张的概念源头 |
| 实质重于形式原则 | 作者把它用活为两把钥匙：一是合并范围的确定标准（看实质性控制权而非持股比例）；二是识别"名为 X 实为 Y"交易（明股实债、代持、通道安排）的钥匙 | 不只是会计原则，更是本书"从报表看控制权与战略"整体思路的概念支点，预示第 6 章控制性投资概念 |
| 客观性原则（两层含义） | 作者的操作性拆解：①可验证性（账证、账账、账表、账实一致）；②对必须估计的事项只要求估计过程合法合规合理 | 据此把报表数据分成"有凭证的硬数据"与"靠估计的软数据"两类——后者是操纵高发区，分析时可信度权重应区别对待 |
| 审计报告与审计意见 | 以审计意见类型与措辞**替代单独的会计分析**的初筛程序：标准无保留意见快速过关；非标意见、报告异常长、异常措辞、频繁换所、年报推迟公布都是恶化信号 | 它是报表可信度的"质量鉴定书"但非担保（专业判断带人为估计因素）；高效而粗糙，遇到非标意见才升级为逐项会计分析 |
