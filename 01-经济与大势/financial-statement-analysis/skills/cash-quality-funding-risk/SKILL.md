# 货币资金质量与获现率诊断

## R — 原文 (Reading)

> "货币资金质量主要涉及货币资金的运用质量、货币资金的构成质量以及货币资金的生成质量。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第3章第3节

> "一般情况下，在企业经营状况正常时，经营活动现金流量净额都要大于核心利润。"
>
> — 同书第5章第2、3节

> "在某些情况下，尽管利润表上反映的经营业绩很可观，但企业有可能处于财务困境，由于现金短缺而无法偿还到期债务。"
>
> — 同书第5章第1节

> ""短贷长投"更是企业应尽量避免的，因为稍有不慎企业就有可能因资金链断裂而破产。"
>
> — 同书第3章第5节

---

## I — 方法论骨架 (Interpretation)

作者主张:利润是权责发生制加估计的产物,现金才是检验;诊断分两条线——先看"钱的存量"是真是假(货币资金质量),再看"利润换回了多少现金"(含金量)。

1. **货币资金三维质量**:①运用质量=规模恰当性,按交易性/预防性/投机性三种持有动机,结合资产业务规模、行业特点、战略与投资机会、外部筹资能力判断——过大货币资金意味着生财无道或另有隐情;②构成质量=查受限资金占比(票据保证金、质押、司法冻结),"自由度"才等于真实支付能力,账面货币资金≠可动用的钱;③生成质量=区分经营/投资/筹资三渠道流入,经营性流入占比高说明造血功能好,茅台、格力是货币资金靠自身经营持续上升的典型。
2. **"存贷双高"不是造假标签**:货币资金充裕却同时大量借款,至少有三种非造假解释——票据保证金等受限资金、集团分权管控下资金分散在各子公司、融资环境扭曲下企业提前储备;要逐项排除后再怀疑,且存贷双高一旦叠加短贷长投(短借长用支持长期资产),就是资金链断裂的定时炸弹——信贷收紧→续贷断裂→资金链断裂→破产,期间高财务费用还侵蚀利润。
3. **核心利润获现率=经营活动现金流量净额÷核心利润**(分子分母都用核心口径,不能拿净利润凑合)。因核心利润扣除了折旧摊销等非付现费用,正常经营的现金净额理应更大:经验底线大于1;存货周转率大于2次/年的传统行业达到1.2~1.5倍即含金量充足。
4. **获现率<1 的五类归因追查**:①收款不正常减少(回款不足、放宽信用冲收入);②付款不正常增加(要区分真恶化与战略性囤料囤地——后者会提升未来含金量);③不恰当资金运作("支付其他与经营活动有关的现金"异常巨大);④主要与关联方往来(可操纵性强);⑤现金流量表编制错误。
5. **现金购销比率**(购买商品接受劳务支付的现金÷销售商品提供劳务收到的现金)应大体对应利润表的营业成本率,过大过小都要警觉,结合应付款项与存货变化定位成因——这是利润表与现金流量表逐项"对表校验"的代表性工序。

整个检验的逻辑:存量(三维质量)管"钱真不真",流量(获现率+归因树)管"利润实不实",两者互为佐证。

## A1 — 书中的应用 (Past Application)

### 案例 1: 北陆药业 2019 年报——获现率<1 的正面归因
- **问题**: 获现率由1.22降至0.85,跌破经验底线,利润含金量是否恶化?
- **方法论的使用**: 走五类归因,发现缺口系销售费用等付现费用大增(开拓市场)所致,不属收款异常或关联往来;同时核对货币资金附注——几乎全部可自由支用,受限极少,构成质量高;经营每年净流入较大,生成质量好。
- **结论**: 获现率虽<1,但归因于主动扩张的付现投入,且无利息负担、资本开支小,经营现金流量仍属充裕,现金流畅顺。
- **结果**: 判定财务状况与盈利能力较好且敢于连续分红——同一比率数字,归因后结论与"含金量恶化"截然相反。

### 案例 2: 乐视网——"有利润没钱"的反面推演
- **问题**: 利润表业绩可观的表观繁荣下,如何从现金端提前看出难以为继?
- **方法论的使用**: 检验生成质量——2016—2018经营现金净额从-10.68亿持续恶化到-54.65亿(按表中数据口径),造血功能枯竭;全靠巨额筹资流入(2017年筹资净流入达95.9亿级别)输血维持,融资行为的恰当性存疑。
- **结论**: 利润与现金严重背离,是典型的"有利润没钱"陷阱:权责发生制的账面盈利掩盖了现金短缺。
- **结果**: 作者以此示范:现金维度才是利润质量的试金石,不用算比率、直接做质量分析即可发现端倪。

### 案例 3: 比亚迪的存贷双高语境——先排除非造假解释
- **问题**: 货币资金充裕与大量借款并存,是否必然造假?
- **方法论的使用**: 用三种非造假解释逐项核对(票据保证金、集团分权管控、融资环境),同时警惕组合信号:短期借款远超经营所需+长期资产高速扩张+货币资金大量受限=短贷长投高危画像。
- **结论**: 存贷双高本身未必造假,但叠加期限错配即成高危——推演链条是信贷收紧→续贷断裂→资金链断裂。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到"净利润很高但经营现金流很低/为负"的报表,问利润可不可信、"钱去哪了"
2. 质疑账面货币资金的真实支付能力(受限、保证金、冻结),或看到"存贷双高"想判断是不是造假
3. 拿到获现率/含金量类数字想诊断,或企业大量借短债做长期投资,想推演资金链风险

### 语言信号 (用户的话里出现这些就应激活)

- "有利润没钱""利润是纸面富贵""赚的钱是不是真收到了"
- "存贷双高""货币资金那么多为什么还借这么多钱""受限资金/自由度"
- "核心利润获现率""利润含金量""造血功能""短贷长投"

### 与相邻 skill 的区分

- 与 `cash-flow-three-activities` 的区别: 那是经营/投资/筹资三类活动现金流量的整体质量框架(三性、战略吻合、融资恰当性);本 skill 聚焦货币资金科目+含金量检验这一个诊断程序,获现率与五类归因是核心武器
- 与 `profit-quality-3d` 的区别: 那个给利润定口径(核心利润是什么)与三维评价(含金量/持续性/战略吻合性);本 skill 专做其中的现金验证环节,把"含金量"这一维做成可执行的诊断树
- 与 `project-quality-entry` 的区别: 那是通用单科目质量入口;本 skill 只深挖货币资金及与现金流量表的对表校验
- 与 `capital-structure-four-forces` 的区别: 那个从负债端看期限结构与财务弹性;本 skill 从资产/现金端推演同一资金链断裂链条

## E — 可执行步骤 (Execution)

1. **第一步:货币资金存量三维体检**
   - 运用质量:货币资金占总资产/收入比重与行业及自身历史比,按三动机+四因素判断规模是否过大;构成质量:查附注受限明细(保证金/质押/冻结),算"自由度=可随时支用部分";生成质量:看本期货币资金增量来自经营、投资还是筹资流入
   - 完成标准:给出三维各自的判断(高/中/低)+受限金额清单;若附注缺失,明确标注"自由度无法核实"
2. **第二步:获现率计算与底线判定**
   - 获现率=经营活动现金流量净额÷核心利润;严格比较可用同口径核心利润(核心利润+非付现费用−所得税费用)
   - 完成标准:报出获现率数值,并对照判据分级:>1.2(传统高周转行业)含金量充足;1~1.2 达底线;<1 触发归因树
3. **第三步:获现率诊断树(<1 时逐支排查)**
   - ①收款端:收入现金比率、应收/应收票据/预收余额变化→回款是否异常;②付款端:付现增长性质→战略性囤货(会提升未来含金量)还是真恶化(竞争加剧、信用下降);③"支付其他与经营活动有关的现金"是否巨大→不当资金运作;④关联方往来占比→可操纵区;⑤现金流量表编制错误→差错更正线索
   - 完成标准:五支逐一给出"排除/坐实"结论,坐实项有报表证据;全程用现金购销比率对表——它应大体对应营业成本率,偏离即补充定位(预付占款/偿付前期应付/主动囤料)
   - 判停条件:发现大额关联往来或编制错误→终止比率解读,输出核查建议
4. **第四步:存贷双高与资金链推演**
   - 三种非造假解释逐项排除(保证金/分权管控/融资环境);若短期借款远超经营所需+长期资产高速扩张+资金大量受限,按"信贷收紧→续贷断裂→资金链断裂"推演,并估财务费用对利润的挤压
   - 完成标准:输出三段式结论——货币资金质量判定+含金量判定(含归因)+资金链风险等级,每条结论可追溯到具体报表数据

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是三类活动现金流量的整体质量评价(经营三性/投资吻合/筹资恰当)——那是 `cash-flow-three-activities` 的框架,本 skill 只做货币资金+含金量切片
- 对象是金融企业(银行/保险)或现金流与利润严重错期的行业(如预售制房地产):"获现率>1"的判据明言不考虑行业与发展阶段差异,照搬会误判
- 只有单月/单季数据:获现率的稳定性判断与归因树需要至少年度数据

### 作者在书中警告的失败模式

- "有利润=有支付能力":权责发生制的估计成分可使账面盈利与现金严重背离,乐视即此陷阱
- 只看现金流量净额正负符号下结论:作者明令禁止,净额为负在初创/转型期可能正常,必须进入归因
- 一见存贷双高就喊造假:三种非造假解释不排除完,判断就不成立;真正的标签是"存贷双高+短贷长投"的组合
- 分子分母口径错配:拿经营现金净流量÷净利润,把非经营项目混进检验,会误判

### 作者的盲点 / 时代局限

- 1.2~1.5 倍的经验数值无统计依据,且明言不考虑行业差异与发展阶段,跨行业照搬有风险
- 经营现金净流量与核心利润"计算口径并非完全一致",作者只说"需要一些调整"却未给出统一调整程序——不同分析师各自调整会破坏可比性
- 五类归因中的"关联往来、异常运作"只给名单不给识别技术,识别主要靠附注和资产负债表佐证,而附注同样出自管理层之手

### 容易混淆的邻近方法论

- 自由现金流(FCF):资本开支后的可支配现金概念,不回答"利润是否收到钱";获现率检验的是利润与现金的对应,不是投资回报
- 净现比(经营现金净流量÷净利润):口径错误的近似做法,缺核心利润的"剔非经营"程序
- 杜邦体系的现金版改造:仍是数量拆解;本 skill 是"逐项归因"的质量程序,输出的是异常定位而非比率排名
