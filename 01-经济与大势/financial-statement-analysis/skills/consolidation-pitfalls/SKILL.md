# 合并报表的局限与比率失真

## R — 原文 (Reading)

> "母公司和子公司的债权人对企业债务的求偿权是针对法律主体而非经济主体的。"

## I — 方法论骨架 (Interpretation)

作者主张:合并报表是经济意义上会计主体的报表,是母公司和各子公司数据的混合物,不反映任何现存企业的财务状况——而世界上真正借钱的、分红的、发工资的、缴税的,全是法律主体。

1. **求偿权针对法律主体**:母公司和子公司各自对自身债务负责,子公司的债权人追索不到母公司的资产;集团资源也不能不顾少数股东利益任意划拨。因此合并数读不出任何一个法律主体的偿债能力,仅当存在交叉担保或集团整体授信时,合并口径才对债权人有参考价值。
2. **真金白银决策回到母公司报表**:分派股利、支付报酬、偿付债务、缴纳税金——凡是涉及资金真实流出的决策,必须以母公司个别报表为基础,合并数字只有"汇总味道",失去了"鲜活味道"。
3. **可验证性天生残缺**:个别报表有"报表—账簿—凭证—实物"的验证链条;合并报表在账外抵销加工,这条链条不存在,编制质量仅体现逻辑关系的正确性,外在表现"弹性化"。怀疑合并数有错时,不能像审个别报表那样追凭证。
4. **常规比率在合并层面的三大失真**:①偿债类——合并流动/速动比率再高,也高估了集团实际可动用的偿债资源;②风险类——子公司融资走"母公司担保"还是"母公司转贷",抵销后合并报表完全相同,风险却不同,合并数无法区分;③营运类——不同行业资产相加后,周转率两边都不代表,多元化聚合掩盖行业差异,未实现损益的全额抵销还使存货与销售成本同少数股东权益不配比。
5. **中国双重披露制是制度红利**:同时披露合并与母公司两套报表,意味着分析者永远不必只靠合并数——正确姿势是"两套都用好":合并数只作全景参考,判断下探到法律主体层面。

## A1 — 书中的应用 (Past Application)

### 案例 1: 普洛药业 2019——"越合并越小"的资金
- **问题**: 母公司其他应收款 5.57 亿、合并报表只有 0.73 亿;母公司长期股权投资 17.43 亿、合并只有 1.22 亿——近 20 亿资金在合并中"消失",是不是公司出了问题?
- **方法论的使用**: 先按"混合物"原理定性——合并数是抵销后的产物,不能直接解读;差额不是资金丢失,而是母公司对子公司的控制性投资(含通过其他应收款提供的资金占用)在合并时被抵销。
- **结论**: 合并数与母公司数的差本身就是信息;"消失"的资金指向母公司对子公司的资源投入,应转入差额层面继续追查,而不是对合并数直接下结论。
- **结果**: 该引例成为第 6 章差量分析法的出发点,示范了"合并数不直接用、差额才含信息"的纪律。

### 案例 2: 母公司外贸+子公司房地产——合并存货周转率两边都不代表
- **问题**: 一家母公司做对外贸易、子公司经营房地产的集团,合并存货周转率还能不能用于营运能力对标?
- **方法论的使用**: 按"多元化聚合失真"检验——两类存货的性质与流动性完全不同,周转的合理标准也不同,相加后的比率没有任何一个单一主体与之对应。
- **结论**: 该比率既不反映母公司也不反映子公司,叠加未实现损益全额抵销导致存货与销售成本同少数股东权益不配比。
- **结果**: 开出的药方是降低信息聚合度、回到母子公司个别报表分别对标——合并比率只作参考。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 债权/投资决策中想用集团合并数评估偿债能力、和同行比率对标,不确定口径对不对
2. 面对双重披露的两套报表,不知道偿债、分红、付酬、缴税这类判断该看哪一套
3. 评估集团整体风险(尤其涉及子公司融资、担保安排)时,只有合并数在手

### 语言信号 (用户的话里出现这些就应激活)

- "合并报表能不能用来算偿债能力/流动比率""合并比率和同行比有意义吗"
- "合并报表和母公司报表用哪套""看分红/还债/发工资应该看哪个口径"
- "集团风险怎么看""母公司担保和转贷有什么区别""合并报表可信吗"

### 与相邻 skill 的区分

- 与 `differential-analysis` 的区别: 那是正面方法,教"两套报表的差额怎么解读"(控制性投资、资金集分权、业务关联度);本 skill 是负面清单,讲"直接用合并数的陷阱"。判断题("能不能用/用哪套")归本 skill,差量解读归 differential-analysis,两者互补
- 与 `ratio-revision-rules` 的区别: 那是单一比率的口径修正规则(OPM 悖论、原值周转率等),不限于合并情境;本 skill 专攻合并层面比率系统性失真的机理
- 与 `project-quality-entry` 的区别: 那是单一科目(如其他应收款、长期股权投资)的质量分析方法;本 skill 站在报表整体口径层面谈"合并数能不能直接用"

## E — 可执行步骤 (Execution)

1. **第一步:定决策类型与口径**
   - 把用户的判断任务归类:真金白银流出型(偿债、分红、付酬、缴税)→ 强制以母公司报表为基础;集团全景参考型 → 合并数可用但只作参考
   - 完成标准:明确输出"该用母公司报表/合并数仅作参考"的口径结论,并说明理由(求偿权针对法律主体)
   - 判停条件:用户只有合并数、拿不到母公司报表 → 标注"结论置信度受限",输出必须补的数据清单,不假装能下单体结论

2. **第二步:偿债类比率降级处理**
   - 合并流动比率、速动比率、资产负债率一律降级为参考值;偿债结论下探到母公司与关键子公司个体层面的可动用资源(存量现金、授信、可变现资产)
   - 唯一例外:存在交叉担保或集团整体授信时,合并口径对债权人有参考价值——须先核实其存在
   - 完成标准:每个偿债结论都注明依据的是哪个法律主体的哪张报表

3. **第三步:区分担保融资与转贷融资**
   - 对子公司大额融资逐笔标注:母公司担保 / 母公司借款转贷 / 未知;查年报附注的担保信息与母公司报表的借款、其他应收款
   - 完成标准:给出"两种安排抵销后合并数相同、但担保式下集团要为少数股东应占份额兜底、风险更大"的明确提示;标注"未知"的列出查证位置
   - 判停条件:附注与母公司报表均不可得 → 明示该风险维度不可见,而非默认无差异

4. **第四步:营运与盈利比率的聚合度检查**
   - 集团行业跨度大(如母公司外贸+子公司房地产)时,合并周转率/报酬率拒绝直接对标同行;改用分部报告或个别报表分别计算
   - 同步检查未实现损益全额抵销造成的"存货与销售成本同少数股东权益不配比"是否影响结论
   - 完成标准:每个跨行业合并比率要么已拆开计算,要么被明确标注"不代表任何单一主体"

5. **第五步:可验证性纪律**
   - 对合并数异常不在"凭证—账簿"层面追查(该链条不存在),而在差额与逻辑层面检验:抵销是否完整、"越合并越小"能否解释、用个别报表交叉验证
   - 完成标准:输出"逻辑自洽/存在未解释差额"的结论;未解释差额清单移交 differential-analysis 做正面解读

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是两套报表差额的正面解读(资金去哪了、母子业务关系、扩张效果)——用 differential-analysis
- 用户问的是单一比率的一般口径修正(格力 OPM 悖论、原值周转率)且不涉及合并情境——用 ratio-revision-rules
- 分析对象是没有子公司的单一企业——不存在合并问题
- 分析对象是金融企业集团(银行/保险):"控制性投资""经营性负债"等口径按一般企业设计,合并局限的结论方向虽通用,具体比率失真机理需重新评估

### 作者在书中警告的失败模式

- 合并报表是唯一"全套"披露,分析者顺手就算——把单一企业比率分析直接照搬到合并报表
- "合并流动比率>1、速动比率>1,集团短期偿债能力应该不错"——忽略母公司对子公司债务仅以投入资本为限,高估可动用偿债资源
- 集团风险评价只看合并数——担保式与转贷式融资抵销后报表相同,风险不同,合并数看不出差别
- 对母子公司自身决策误用合并数:分派股利、支付报酬、偿付债务、缴纳税金必须以母公司个别报表为基础

### 作者的盲点 / 时代局限

- **抵销过程中的操纵空间几乎未讨论**:既然合并报表只重逻辑正确性、缺乏可验证链条,如何借抵销粉饰(内部交易定价、抵销完整性)是天然疑问,作者基本未展开
- **利益相关者视角不完整**:论证合并报表的价值时只面向母公司股东、管理层与债权人;子公司少数股东、子公司债权人该不该用、怎么用合并信息,着墨很少
- **未证明的假设**:"子公司负债通常由母公司担保""子公司资产由母公司控制"被用来论证合并报表的增量价值,但未举证其在实践中的普遍性
- **差量归因是粗略估计**:同一项目差额可能有多种成因,作者的归因是假设而非验证

### 容易混淆的邻近方法论

- **差量分析法**:同章的正面方法,把差额当信息源;本 skill 是它的前提论证("为什么不能直接用合并数"),两者是同一枚硬币的两面
- **汇总报表**:按行政隶属简单加总的报表,与以"控制"为基础的合并报表分属不同逻辑——把汇总报表的毛病安到合并报表头上是范畴错误
- **Pro forma(模拟/备考)合并报表**:并购完成前模拟拼合的报表,可验证性比法定合并报表更弱,不得套用本 skill 之外还给它合并报表的信任
