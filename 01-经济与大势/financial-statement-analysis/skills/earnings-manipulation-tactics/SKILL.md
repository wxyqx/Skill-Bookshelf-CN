# 利润粉饰手法识别(十法)

## R — 原文 (Reading)

> "该企业往往会在来年通过销售退回方式撤销这些虚构交易,或者在日后某一年份通过核销坏账的方式对其进行消化。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第3章第3节

> "在银广夏事件和郑百文虚构销售记录被发现之后,财务造假者倾向于更安全的造假手段,'爱上了'其他应收款账户。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第3章第3节

> "企业为了减少研究和开发支出对利润表的冲击而利用这些虚拟资产将费用资本化,从而形成'虚盈实亏'的现象。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第5节

## I — 方法论骨架 (Interpretation)

作者主张:每个资产、负债、权益项目都有固定的操纵手法,质量分析=项目+手法+案例的配对。十法不是并列清单,而有一条演化主线——**收入端手法最易被识破(函证与现金流会穿帮),被识破后手法向审计难度大的资产端迁移,再向负债权益端与费用确认端渗透**。逐项手法与核查动作:

1. **虚构收入挂账应收**:虚增收入没有现金对应,只能挂应收账款;消化路径是来年销售退回或日后核销坏账——查应收增速是否系统性高于收入与资产增速、退回与核销是否集中于上年激增的客户、核心利润获现率是否长期<1;退回+核销正是旧账出清,"恢复正常增长"可能只是伪像。
2. **低转成本虚增毛利**(蓝田/银广夏):已售成本滞留在存货→毛利率虚高、存货虚增、抵押贷款筹码一石三鸟;查毛利率与同行对照、存货周转天数逐年拉长、存货抵押披露;粗估虚增规模=存货异常增量×同行正常毛利率。
3. **造假转向资产端**(万福生科):虚增在建工程与预付账款——审计难度大、可长期沉淀逐年消化;查预付对象的工商信息与商业合理性、期后是否结转入库、在建工程工期与实际投产状态、资金是否最终流向关联方。
4. **在建工程不决算三重好处**:工程是真的、操纵在时点——利息继续资本化压低财务费用、推迟计提折旧、当期费用混入工程成本;查投产公告日期与转固时点的时间差、利息资本化起止与"达到预定可使用状态"是否匹配。
5. **其他应收款"安全账户"与大股东占用**:户数多、单笔小、查证成本高,大股东占款"中国资本市场最大的毒瘤";用"金额大+时间长+来自关联方"三要素筛,再用母公司/合并报表差额区分正常资金下沉与体外占用,并以经营现金流对照——占用之下的"正常"现金流随时可被抽干。
6. **存货潜亏挂账**:把冷背呆滞商品、残品及违规开支压在存货中,亏损后移;反直觉信号:毛利率平稳恰是嫌疑(该提的减值没提);查计提比例同业对照、计提政策是否突变、存货担保抵押披露;与"洗大澡"方向相反,同一科目两套手法要分开识别。
7. **应收账款账龄人为洗短**:向债务方提供资金供其还旧账再重新赊出;账龄孤证不可信,与应收周转率、收现比、坏账计提比例交叉验证,同时背离即判定粉饰;偿付资金来自关联方的直接涉嫌。
8. **频繁前期差错更正(三要素)**:频度+方向单一(均调增业绩)+与业绩压力时点(对赌/考核/融资)吻合;查所有者权益变动表"前期差错更正"栏——追溯调整不进当期利润表,披着合规外衣。
9. **预计负债确认阈值的操纵弹性**:可能性高且金额可靠估计→确认(同时确认费用),约50%或金额不可靠→仅披露;这条主观判断线就是操纵线——查历史或有事项处理的一贯性与同业计提惯例,"零计提"虚增利润、"集中补提"可能是洗大澡储备,两端都要追问。
10. **费用资本化虚盈实亏**:收入不足以弥补当期花费时,把研发等支出资本化为无形资产/开发支出——现金已流出,利润靠资本化"造"出来;查资本化比例与同业对照、研究/开发阶段划分证据、摊销年限设定,联动核心利润获现率看现金与利润的背离度。

## A1 — 书中的应用 (Past Application)

### 案例 1: 万福生科——造假从收入端迁往资产端
- **问题**: 银广夏、郑百文式直接虚构销售被函证和现金流识破之后,后来的造假者把科目藏到哪里?
- **方法论的使用**: 作者指出财务造假者"倾向于更安全的造假手段",万福生科选择虚增在建工程和预付账款——这两个科目审计难度大、资金流向不易核实,且与"在建工程预示利润增长点"的正面叙事天然兼容。
- **结论**: 资产端科目可以长期沉淀、逐年消化,异动的核查优先级应高于收入端;预付对象工商核查+与在建工程联动是标准动作。
- **结果**: 该案例成为"手法迁移"演化逻辑的书内锚点。

### 案例 2: 蓝田股份、银广夏——同一手法的三连画像
- **问题**: 毛利率显著高于同行,能直接说造假吗?
- **方法论的使用**: 两家公司都用了"低转成本":毛利率虚高+存货虚增+抵押筹码放大,三个信号单独看都有无害解释,组合出现才是显性证据。
- **结果**: 书中以此示范"毛利率巨幅波动是操纵的显性证据",以及用存货异常增量估算虚增规模的路径。

### 案例 3: 秋林集团——其他应收款"全军覆没"
- **问题**: 其他应收款账面余额近40亿元、99%以上已计提减值,欠款方集中于珠宝公司,怎么读?
- **方法论的使用**: 作者连环追问——为何集体不还钱、9人欠2000万也100%计提、两年内账龄为何迅速认定无法收回,判定表面是会计随意,深层是内控缺失与治理失效,不排除大股东掏空。
- **结果**: 结论落在"关键信息(控制人行为)可能根本不在报表里",手法核查要连接治理尽调。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 贴出(或描述)一家公司的财务数据,直说"我怀疑它造假/利润是做出来的",要求逐项排查
2. 看到新闻或监管处罚(证监会立案、财务造假通报)后,想拿类似特征的公司自查一遍"它会不会也这样"
3. 尽调/投资中面对"业绩好得不像话"的公司,想要一份按手法组织的核查清单而不是泛泛的红旗警告

### 语言信号 (用户的话里出现这些就应激活)

- "怀疑造假/做假账/利润是粉饰的/收入是虚的"
- "帮我查查它怎么造的假/有哪些手法/逐项排查"
- "万福生科/蓝田/银广夏那种手法现在还有吗"

### 与相邻 skill 的区分

- 与 `profit-deterioration-sweep` 的区别: 那是"外在表现清单"扫雷(12条恶化信号分级:命中几组、恶化到什么程度),回答"有没有病";本 skill 是"手法机理与核查动作"(怎么造的+怎么查),回答"病怎么造出来的"。先扫雷后验尸,两者可串联。
- 与 `receivables-and-funneling` / `inventory-and-margin` / `long-term-asset-quality` 的区别: 那些是常规科目质量分析框架,各自内含单一操纵切入点;本 skill 是跨科目的系统排查,把手法按"造假面"重新编队,不限于单一科目。
- 与 `revenue-quality-three-questions` 的区别: 那是中性评估收入质量(卖什么/卖给谁/靠什么);本 skill 在预设造假的语境下工作。

## E — 可执行步骤 (Execution)

1. **第一步:怀疑对象分类(定造假面)**
   - 按演化主线把怀疑分入四面:收入端(应收/营收/毛利)、资产端(存货/在建工程/预付/其他应收款/无形资产与开发支出)、负债权益端(预计负债/权益变动表差错更正栏)、费用端(资本化边界/期间费用走势)
   - 完成标准:每个怀疑落到具体报表科目与附注位置,形成"怀疑面清单"

2. **第二步:逐面对应手法核查表**
   - 收入端→手法1/2/7:应收增速vs收入资产增速、退回与核销的客户重合度、毛利率与存货周转同行对照、账龄三指标交叉验证
   - 资产端→手法3/4/5/6:预付对象工商核查与期后结转、投产与转固时点差、其他应收款三要素筛+母合并差额、存货计提比例同业对照
   - 负债权益端与费用端→手法8/9/10:差错更正三要素、预计负债一贯性双向追问、资本化比例同业对照
   - 完成标准:每条手法给出"命中/未命中/证据不足"三档结论并附证据位置

3. **第三步:交叉验证**
   - 三条独立线核对:①现金流线——核心利润获现率是否系统性<1(虚构收入没有现金对应);②时序线——退回/核销/更正/补提是否集中于业绩压力时点;③同业线——毛利率、计提比例、资本化比例与可比公司横向对照
   - 完成标准:至少两条独立线互相印证后才输出"涉嫌"结论,单一信号只列为待查项

4. **判停条件**
   - 审计意见为无法表示意见/否定意见,或公司自陈无法核实关键事项(秋林式前提失效)→手法核查让位于治理尽调
   - 无附注明细(账龄、预付对象、资本化划分)→输出"需补充资料清单",不凭总账数字下造假结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没表达任何怀疑,只想要中性整体评估——用 strategic-analysis-path
- 用户只要"恶化信号外在表现"的分级扫雷,不需要手法机理——用 profit-deterioration-sweep
- 只问单一科目的常规质量怎么分析(不预设操纵)——用对应科目 skill
- 对象是金融企业或新业态平台:十法按制造业/一般企业的科目体系设计,适用性存疑(作者仅以脚注承认新商业模式挑战)

### 作者在书中警告的失败模式

- **清单式扫雷误伤成长期企业**:应收账款增加、存货增加、减值集中计提等信号既可能是操纵迹象,也可能是正常商业决策(如囤原材料、战略性扩张);命中单项不下结论,必须走交叉验证,否则机械扫雷会把高成长企业错判为造假
- **账龄孤证陷阱**:反向的失败是轻信——"账龄变好=质量变好"是默认假设,恰恰可以被资金循环人为制造
- **"决算流程慢"的借口迷惑性**:拖延转固以中性流程事件的面目出现,不做时点核查就会放过

### 作者的盲点 / 时代局限

- 书中反面案例(万福生科、蓝田、银广夏、秋林)均为**事后追溯**——造假被查处、减值发生后才回看出手法,十法的事前预警能力未被独立检验
- 框架高度依赖附注披露充分且可信,但附注同样出自管理层之手;造假企业连披露环节都可控时,核查动作的可落地性下降
- 保值性评价依赖减值数据,而减值恰是被操纵的环节,存在循环论证风险

### 容易混淆的邻近方法论

- **舞弊三角理论(压力-机会-借口)**: 解释"为什么造假",是动机侧框架;本 skill 是手法侧框架,回答"怎么造的、怎么查",两者互补但不可互相替代
- **法证会计(Forensic Accounting)**: 以取证与司法程序为目标;本 skill 是报表分析者的排查程序,输出的是核查线索而非法律证据
- **审计师的风险导向审计**: 面向审计意见发表、有函证监盘等程序权限;报表分析者只能用公开信息做外部核对,本 skill 全部动作以公开报表+附注为边界
