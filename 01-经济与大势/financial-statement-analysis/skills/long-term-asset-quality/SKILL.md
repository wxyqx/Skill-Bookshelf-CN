## I — 方法论骨架 (Interpretation)

作者对每项长期资产都用"盈利性、周转性、保值性"三性标尺判读,并为每个科目配对好了固定的操纵手法。五条核心机理:

1. **长期股权投资的"泡沫"机理**:权益法按被投资方净利润份额确认收益并同步做大长投账面;对方只要不全额分红,收益就缺现金支撑——泡沫大小=分红程度的函数。成本法(对子公司)只有分红才确认收益,收益才有现金支撑。推论:以控制性投资为主体的母公司,报表业绩取决于子公司分红政策而非子公司真实效益。
2. **固定资产的"原值"口径**:周转率必须用原值而非净值计算——折旧年限与减值计提的差别会使净值口径在同行间完全失真,甚至得出"越旧越快"的荒谬结论;原值周转率大幅偏离同行,指向虚增收入或虚增固定资产二选一。会计政策三操纵点:借款费用资本化、折旧政策、减值政策。
3. **在建工程"不决算"的三重好处**:已达到预定可使用状态仍挂账不转固,可同时①利息继续资本化、②推迟计提折旧、③让当期费用鱼目混珠计入工程成本——三条通道都虚增当期利润。该科目审计难度大、叙事天然"正面",是造假高发区。
4. **无形资产"账内皆外购"的披露结构**:自创无形资产支出全部费用化且成功后不资本化,自创成果游离于资产负债表之外——账面无形资产基本都是外购的。所以账面值小≠质量差,必须转看开发支出、费用化研发投入与人力资本等账外资源;账面值也只是减值后的最低可收回金额而非实际价值。
5. **减值"不得转回"把操纵推向计提时点**:非流动资产减值一经计提不得转回,准则堵住了"利润高时多提、利润差时冲回"的通道;但何时提、提多少仍属主观判断——第三年提100%还是60%本身就是利润安排。谨慎性原则由此成为双刃剑:挤水分的工具同时可以是注水的工具,集中巨额计提是"洗大澡",长期计提不足是虚增业绩。

整个科目族的判读逻辑:三性给出评价维度,操纵手法配对给出警觉方向,减值数据本身要在"计提恰当性"层面被二次审视。

## A1 — 书中的应用 (Past Application)

### 案例 1: 北陆药业 2019 年报——长投/固定资产/在建工程的正面示范
- **问题**: 一家医药公司的长期资产质量如何逐项落地判断。
- **方法论的使用**: 长投四家标的均属精准医疗战略布局、有协同意义,但权益法投资收益881万元仅占营业利润约2%,盈利性尚不理想(泡沫之外看贡献);世和基因因稀释股权由权益法转为公允价值计量;固定资产增长31%低于收入增长34%、周转率提高、未计提减值;在建工程沧州工厂如期转固。
- **结论**: 长期资产整体结构良性——投入方向与战略吻合、产能扩张与收入匹配、在建工程按期决算。
- **结果**: 作者以此示范"健康"的长期资产该长什么样,作为反面案例的对照基准。

### 案例 2: 普洛药业——商誉全额减值的计提比例问题
- **问题**: 被并购方因医药政策变化盈利能力弱化,年末对919万元商誉全额计提减值。
- **方法论的使用**: 用减值双刃剑原理审视:商誉减值测试高度依赖管理层主观判断,计提100%还是60%本身就是操纵空间;计提了减值的项目保值性堪忧且不可逆。
- **结论**: 该次全额计提既可读作"挤水分"(一次出清),也可读作为未来业绩预留空间的安排——计提比例的选择权在管理层手里。
- **结果**: 作者点明商誉是虚拟资产,其保值性取决于被并购企业盈利与协同效应的兑现,不能只看当期分录。

### 案例 3: 万福生科——虚增在建工程的造假解剖
- **问题**: 造假者为什么选在建工程和预付账款作为虚增载体。
- **方法论的使用**: 用"不决算三重好处"的机理解剖:该科目审计难度大、工程进度外部人难以核实、叙事上天然"正面"(在建=在成长),虚增的资产还能借决算与折旧慢慢消化。
- **结论**: 在建工程是高危科目,长期挂账必须给出合理解释并以附注明细与投产证据验证。
- **结果**: 成为中国资本市场标志性的造假案,印证了科目-手法配对的预警价值。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 母公司/并购方权益法投资收益巨大但现金回流很少,问长投质量或"泡沫"
2. 固定资产、在建工程、无形资产、商誉出现异动:周转率偏离同行、投用不转固、研发大而账面无形小、并购后集中计提减值
3. 判断某次大额减值是"挤水分"还是"洗大澡",或减值政策变更的含义

### 语言信号 (用户的话里出现这些就应激活)

- "权益法/投资收益没收到钱/长投泡沫/对方不分红"
- "固定资产周转率怎么算/在建工程一直不转固/利息资本化"
- "商誉全额减值/洗大澡/减值不得转回/无形资产账面太小了吧"

### 与相邻 skill 的区分

- 与 `earnings-manipulation-tactics` 的区别: 那是跨科目、全链条的系统性造假排查;本 skill 是科目族质量分析,操纵手法只作为本科目判读的配对知识出现
- 与 `asset-allocation-strategy` 的区别: 那个把资产重分类后看整体结构定战略类型(经营/投资主导);本 skill 看单个长期资产项目的效用与减值,不做战略分类
- 与 `ratio-revision-rules` 的区别: 那个负责"比率该怎么算"(如原值口径本身);本 skill 用算对口径后的数字做质量结论
- 与 `project-quality-entry` 的区别: 那是流动资产与通用项目质量入口;本 skill 专注长期资产五个科目族及其减值

## E — 可执行步骤 (Execution)

1. **第一步:分科目定位与异动识别**
   - 从资产负债表及附注摘出长投(区分成本法/权益法、母公司与合并口径)、固定资产(原值/净值/折旧政策)、在建工程(明细、进度、决算状态)、无形资产与开发支出、商誉及减值准备
   - 完成标准:五个科目各有一行"规模+同比变化+口径说明",口径错误(如用净值算周转)在此步拦截
2. **第二步:逐项三性判读**
   - 长投按四因素(目的方向、年内重大变化、所运用资产种类、收益确认方法)判盈利性,用分红回款检验泡沫;固定资产查配置三标准并按原值重算周转率;在建工程核对已投用未决算挂账;无形资产转看账外研发资源;商誉核对被购方业绩承诺兑现
   - 完成标准:每个科目给出盈利性/周转性/保值性三维结论,数字带口径
3. **第三步:减值计提恰当性二次审视**
   - 对每笔减值问三个问题:计提时点是否集中在关键年份、比例选择(100%还是60%)是否极端、此前年度是否长期计提不足
   - 完成标准:输出"挤水分/洗大澡/计提不足"三档判断及依据;判停条件:附注披露不足以支撑判断时,明确标注置信度受限并给出需补充的信息清单
4. **第四步:汇总成科目族质量结论**
   - 把逐项结论与战略方向(是否吻合主业)合并,输出"质量结论+主要隐患+后续跟踪点"
   - 完成标准:每条结论可追溯到第二步或第三步的具体证据

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是全面造假排查(问"这家公司是不是在骗我")——那是系统排查问题,用 earnings-manipulation-tactics
- 用户问的是资产结构与资源配置战略类型(经营主导/投资主导)——用 asset-allocation-strategy
- 分析对象是金融企业或互联网平台企业:本书科目框架按一般企业设计,作者仅以脚注承认新商业模式对传统方法构成挑战

### 作者在书中警告的失败模式

- 用固定资产净值算周转率得出"越旧越快"的荒谬结论,进而误判同行效率
- 只看账面无形资产规模就判"轻资产、质量差",漏掉游离表外的自创无形资源
- 见到巨额减值就单向解读为"资产实了",漏掉洗大澡与平滑利润的反向可能(秋林集团:减值损失为上年120倍,要么此前计提严重不足,要么当年过度计提)
- 混淆"子公司效益"与"母公司报表业绩":子公司不分红时母公司净利润"惨不忍睹"不代表真实效益

### 作者的盲点 / 时代局限

- **保值性的循环论证风险**:三性框架中,盈利性与周转性有量化标尺,保值性却依赖减值数据——而减值计提恰恰是管理层操纵的环节;作者给出了警觉清单,但未提供穿透操纵的独立验证手段,用被操纵的数据评价质量存在循环论证
- 反面案例均为事后追溯(减值发生了才看出问题),框架的事前预警能力未被独立检验;正面案例(北陆)与作者方法同源,缺少独立基准
- 框架高度依赖附注披露充分且可信(工程进度、商誉参数、减值测试假设),作者自己也承认商誉信息披露不够充分

### 容易混淆的邻近方法论

- 传统"固定资产减值=利空出尽"的股市解读:只看一次性出清,不看计提时点与比例背后的利润安排
- 资产评估中的重置成本法/收益法:为交易定价服务;本书框架是为报表判读服务,账面值只是"最低可收回金额"
- 杜邦体系的总资产周转率:混入投资性资产且常用净值口径,与作者"经营性资产+原值"的修正口径不同(见 ratio-revision-rules)
