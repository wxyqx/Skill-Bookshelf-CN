- id: Cc01
  title: 美国的贸易赤字（"双赤字"的三十年）
  type: case
  source_chapter: 第6章 6.2节 案例研究
  source_quote: |
    由于政府预算和贸易余额大约同时出现赤字，这种情况被称为双赤字（twindeficits）。……美国贸易赤字的历史表明，这一统计数据本身并不能告诉我们太多经济中发生的事情。
  summary: |
    真实事件：1980s-2010s美国持续巨额贸易赤字（2016年4520亿美元，GDP的2.8%），从世界最大债权国变为最大债务国。
    方法论主题：用S-I恒等式分阶段诊断——80年代里根减税+支出未减→预算赤字→国民储蓄下降→"双赤字"；90年代末预算转盈但IT繁荣使投资曲线上移，赤字未减；2000年代减税+战争支出→储蓄降至历史低点、赤字至历史高点；2006年后房价下跌→住房投资下降→赤字收缩。
    启示：单一统计量不含因果信息，必须深入到储蓄、投资及其背后的政策与事件。
  tags: [贸易赤字, 双赤字, 储蓄与投资]

    启示：多因并存时的诚实表达方式；相关变量纠缠（税率与工会化率正相关）导致难以分离效应。
