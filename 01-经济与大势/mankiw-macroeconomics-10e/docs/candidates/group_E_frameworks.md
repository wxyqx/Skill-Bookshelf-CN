- id: Ef01
  title: IS冲击/LM冲击二分法（IS-LM冲击诊断流程）
  type: framework
  source_chapter: 第12章 12.1节
  source_quote: |
    由于IS-LM模型说明了国民收入在短期是如何决定的，我们可以用这个模型来考察各种经济扰动是如何影响收入的。……我们可以把其他扰动归为两类：对IS曲线的冲击和对LM曲线的冲击。对IS曲线的冲击是产品与服务需求的外生变动。
  summary: |
    解决"一场经济波动从哪里来、会走向哪里"的诊断问题。流程：任何外生扰动先归类——影响产品与服务需求的归为IS冲击（投资、消费的外生变动），影响货币需求的归为LM冲击；再判断曲线向哪边移、均衡收入与利率同向还是反向变动。
    判别表：IS左移→收入降、利率降；LM上移→收入降、利率升。收入与利率的组合方向本身就是识别冲击来源的证据（大萧条分析即用此法）。
    作者还强调：波动不是宿命，政策可以抵消冲击——诊断的目的是为了对冲。
  tags: [IS-LM, 冲击诊断, 经济波动]

- id: Ef02
  title: "央行反应三情形"框架（政策相互作用的决策树）
  type: framework
  source_chapter: 第12章 12.1节
  source_quote: |
    财政政策的影响取决于美联储所采取的政策——取决于它是保持货币供给不变、利率不变还是收入不变。更一般地说，在分析一项政策的变动的任何时候，我们都必须对它对其他政策的影响作出假设。
  summary: |
    解决"评估一项政策的效果时另一个政策制定者在干什么"的问题。任何财政变动的影响都不是唯一的，必须先假设央行的反应函数，分三种情形推演：①央行保持货币供给不变→增税引起衰退但利率下降；②央行保持利率不变→货币供给跟着收缩，衰退更深；③央行保持收入不变→货币扩张抵消紧缩，无衰退但利率大降、消费被抑制而投资受刺激。
    用法：分析任何政策变动前，先问"另一只手会怎么动"，把政策组合而非单一政策作为分析对象；最合适的假设取决于具体情形与政治背景。
  tags: [IS-LM, 政策组合, 央行行为假设]

- id: Ef03
  title: 作为总需求理论的IS-LM（AD曲线的推导）
  type: framework
  source_chapter: 第12章 12.2节
  source_quote: |
    总需求曲线通过表示任何给定价格水平上的均衡收入概括了IS-LM模型的结果。总需求曲线向右下方倾斜是因为更低的价格水平增加了实际货币余额，降低了利率，刺激了投资支出，从而提高了均衡收入。
  summary: |
    解决"总需求曲线为什么向下倾斜、什么使它移动"的理论基础问题。AD曲线不是独立假设，而是IS-LM均衡点的集合：固定M，P升高→实际货币余额M/P下降→LM上移→利率升、收入降，把每个P对应的Y画出来就是AD。
    两层用法：①解释AD斜率的微观机制（货币市场渠道）；②对AD做比较静态——任何给定价格水平下使IS-LM收入增加的事件（货币扩张、财政扩张）都使AD右移，反之左移。这把第10章的AD-AS图与第11-12章的IS-LM打通成同一套理论。
  tags: [总需求曲线, IS-LM, AD-AS]

  type: framework

    这两个方程包含了三个内生变量：Y、P和r。为了使该系统完整，我们需要第三个方程。凯恩斯主义的方法是用固定价格的假设来完成模型……古典方法是用产出达到自然水平的假设完成模型……哪一个假设最恰当呢？答案取决于时间范围。

- id: Ef06
  title: 通货紧缩效应分析（稳定渠道 vs 不稳定渠道）
  type: framework
  source_chapter: 第12章 12.3节
  source_quote: |
    经济学家提出了两种理论来解释价格下降如何抑制而不是增加收入。第一种称为债务-通货紧缩理论，它描述了未预期到的价格下降的效应。第二种理论解释了预期到的通货紧缩的效应。
  summary: |
    解决"物价下跌是好事还是坏事"的机制分解问题。稳定渠道两条：实际货币余额增加使LM右移；庇古效应（实际余额是财富）使IS右移——价格下降把经济推回充分就业。不稳定渠道两条：①债务-通缩——未预期到的降价把财富从高支出倾向的债务人再分配给低支出倾向的债权人，总支出净减少；②预期通缩提高实际利率（r=i−Eπ，Eπ<0），抑制投资。
    用法：评估通缩环境时，逐渠道清点方向相反的力量，而不是笼统说"降价利好消费者"；关键变量是财富结构（谁欠债）与预期是否已调整。
  tags: [通货紧缩, 庇古效应, 债务-通缩, 实际利率]

- id: Ef08
  title: 蒙代尔-弗莱明模型（IS*-LM*：小型开放经济的IS-LM）
  type: framework
  source_chapter: 第13章 13.1节
  source_quote: |
    蒙代尔-弗莱明模型是IS-LM模型的近亲。这两个模型都强调了产品市场与货币市场之间的相互作用。……它们的关键区别是，IS-LM模型假设一个封闭经济，而蒙代尔-弗莱明模型假设一个开放经济。
  summary: |
    解决"开放且资本自由流动的小国里政策如何起作用"的问题。核心假设r=r*：资本完全流动使国内利率被钉在世界利率上，任何利差都会被资本流动瞬间抹平。产品市场方程加入净出口NX(e)得IS*（汇率-收入空间向下倾斜），货币市场M/P=L(r*,Y)因汇率不进入方程而退化为一条垂线LM*。
    用法：均衡由IS*与LM*交点同时定出收入与汇率；分析任何政策先画IS*/LM*移动方向，再按汇率制度（浮动/固定）读出哪个变量调整。它同时就是小型开放经济的总需求理论——让价格变动即可推出开放经济的AD曲线。
  tags: [蒙代尔-弗莱明, 开放经济, 汇率, IS-LM]

- id: Ef09
  title: 汇率制度×政策效果矩阵（先问制度再判效果）
  type: framework
  source_chapter: 第13章 13.3-13.4节
  source_quote: |
    货币政策与财政政策影响总收入的效力取决于汇率制度。在浮动汇率下，只有货币政策影响收入。财政政策通常的扩张性影响被通货的升值和净出口的减少抵消了。在固定汇率下，只有财政政策影响收入。
  summary: |
    解决"同一种政策在不同货币制度下为什么效果相反"的问题。用法是一张2×3查表：浮动汇率下——货币扩张有效（贬值促净出口）、财政扩张无效（升值挤掉净出口）、贸易限制无效（NX不变）；固定汇率下——正好反转，财政扩张有效（央行被迫随之一同扩张货币）、货币扩张无效（货币供给自动回位）、贸易限制有效且增加NX。
    深层逻辑：浮动汇率把货币供给留作政策工具、让汇率吸收冲击；固定汇率把汇率钉死、让货币供给内生化。作者给出极端化记忆法（大型开放经济取两者平均），并把它用于解读欧元区、中国汇率等现实争论。
  tags: [汇率制度, 政策有效性, 蒙代尔-弗莱明]

  title: 不可能三角形（三选一决策框架）
  type: framework
  source_chapter: 第13章 13.5节
  source_quote: |
    一国（或地区）不可能同时拥有自由的资本流动、固定汇率和独立的货币政策。这一事实表示在图13-12中，它常常被称为不可能三角形，有时也被称为国际金融三难困境。一国（或地区）必须选择这个三角形的一边，放弃对角的制度特征。
  summary: |
    解决"一国该在开放金融、汇率稳定、货币自主之间怎么取舍"的问题。三角三个顶点——自由资本流动、固定汇率、独立货币政策——至多取二：选项1（美国）取资本流动+货币自主，汇率必须浮动；选项2（中国香港）取资本流动+固定汇率，实质上输入他国货币政策；选项3（中国内地）取固定汇率+货币自主，必须管制资本流动。
    用法：看到任何汇率之争（人民币、欧元、港币），先辨认该国占了三角形的哪条边、牺牲了哪个角；评价一国汇率制度是否可持续，先看它与三角形的组合是否自洽。
  tags: [不可能三角形, 汇率制度, 资本流动]

- id: Ef11
  title: 风险贴水扩展模型（r=r*+θ与预期的自我实现）
  type: framework
  source_chapter: 第13章 13.4节
  source_quote: |
    我们假设我们的小型开放经济中的利率是由世界利率加一个风险贴水θ所决定的：r=r*+θ。……关于汇率的预期部分地是自我实现的。……通货未来将贬值这一预期会引起该通货现在贬值。
  summary: |
    解决"为什么新兴市场危机中利率、汇率会失控"的问题。把利率条件放松为r=r*+θ，θ由感知政治风险与预期汇率变动决定。θ上升→国内利率上升→投资受抑（IS*左移）且货币需求下降（LM*右移）→货币贬值；模型纯逻辑甚至预测收入上升，但现实中三条反向渠道（央行收缩货币护汇率、进口涨价、居民增持安全货币）通常使收入下降。
    最关键的推论是预期自我实现：市场相信会贬值→索取更高风险贴水→利率升、货币真贬值。用法：诊断货币危机时先找θ飙升的源头（政治事件、银行坏账），再看固定汇率能否扛住储备流失。
  tags: [风险贴水, 货币危机, 预期, 蒙代尔-弗莱明]

  type: framework

  source_quote: |
    有一种有用的概算法有助于你确定政策如何影响大型开放经济而不必记住这个模型的全部细节：大型开放经济是封闭经济和小型开放经济的一种平均。要找出任何一种政策如何影响任何一个变量，只要找出两种极端情况的答案，取其平均值就可以了。

- id: Ef13
  title: 短期总供给方程与两大理论基础
  type: framework
  source_chapter: 第14章 14.1节
  source_quote: |
    最终的目的地是如下形式的短期总供给方程：Y=Ȳ+α(P−EP)。这个方程是说，当价格水平偏离预期的价格水平时，产出就会偏离其自然水平。
  summary: |
    解决"短期总供给曲线为什么向上倾斜、产出为什么偏离自然水平"的问题。方程Y=Ȳ+α(P−EP)把繁荣与萧条统一为一句话：只有"出乎意料的价格"（P≠EP）才让产出偏离自然水平；1/α是曲线斜率。给它微观基础的是两个平行理论：①黏性价格模型——部分企业提前按预期定价，意外需求变化只能由弹性定价企业吸收；②不完备信息模型——供给者把一般物价上涨误认成自己产品相对涨价而多生产。
    用法：任何"经济为何过热/为何衰退"的追问，最终都落到"现实价格与预期价格的缺口"上；两个理论不互斥，可叠加。
  tags: [总供给, 黏性价格, 不完备信息, 预期]

- id: Ef14
  title: 菲利普斯曲线三力量分解
  type: framework
  source_chapter: 第14章 14.2节
  source_quote: |
    现代形式的菲利普斯曲线告诉我们，通货膨胀率取决于三种力量：预期的通货膨胀率；失业对自然率的偏离，被称为周期性失业；供给冲击。
  summary: |
    解决"当前通胀由什么决定、政策能把它们各自怎么动"的问题。π=Eπ−β(u−u*)+v：通胀=预期通胀+需求拉动项（周期性失业，负号）+成本推动项（供给冲击v）。它由总供给方程经三步代数（加供给冲击、转成通胀率、奥肯定律换算失业）推出，与总供给曲线是同一思想的两种写法。
    用法：看到一轮通胀，先做三路归因——预期是否已抬高（工资物价螺旋）、需求是否过热（失业低于自然率）、成本是否被推升（油价）；判断它会不会自我延续，关键看预期项。政策制定者能直接操纵的只有总需求，即沿这条曲线选点。
  tags: [菲利普斯曲线, 通胀归因, 需求拉动, 成本推动]

  title: 适应性预期与通货膨胀惯性（NAIRU形式）
  type: framework
  source_chapter: 第14章 14.2节
  source_quote: |
    人们根据最近观察到的通货膨胀来形成他们的通货膨胀预期。这种假设被称为适应性预期。……通货膨胀有惯性。……这种惯性的产生是因为过去的通货膨胀影响对未来通货膨胀的预期，这些预期又影响人们设定的工资与价格。
  summary: |
    解决"通胀为什么一旦起来就赖着不走"的动力学问题。令Eπ=π₋₁，菲利普斯曲线变成π=π₋₁−β(u−u*)+v：除非发生衰退、供给冲击或政策改变，通胀将自我延续——像运动中的物体需要外力才能停下。这一形式下自然失业率被称为NAIRU（非加速通货膨胀的失业率）。
    用法：预测通胀走势时先默认惯性，再找"外力"——压通胀必须接受一段u>u*的高失业；要打破惯性则须让预期下移（可信的紧缩或有利的供给冲击）。该框架的反面（理性预期）在第14章由 Ef17 处理。
