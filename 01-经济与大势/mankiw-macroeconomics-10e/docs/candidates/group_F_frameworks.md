- id: Ff01
  title: 动态AD-AS模型：五方程短期波动总框架
  type: framework
  source_chapter: 第15章 15.1-15.2节
  source_quote: |
    动态总需求和总供给模型融合了五种经济关系：一个产品市场的方程，它将需求量与实际利率联系起来；费雪方程，它将实际利率和名义利率联系起来；菲利普斯曲线方程，它决定着通货膨胀；预期通货膨胀方程；一个货币政策规则，中央银行根据这一规则将名义利率设定为通货膨胀和产出的函数。
  summary: |
    解决什么问题：IS-LM只决定产出、菲利普斯曲线只管通胀，需要一个能同时解释产出、通货膨胀、实际利率、名义利率如何随时间互动的统一模型。
    核心逻辑：五个方程——需求方程（Y随自然产出增长、随实际利率下降、受需求冲击ε影响）、费雪方程（r=i-Eπ）、菲利普斯曲线（π取决于预期通胀+产出缺口+供给冲击ν）、适应性预期（Eπt+1=πt）、货币政策规则（央行按通胀缺口和产出缺口设定名义利率）——共同决定五个内生变量的时间路径；上期通胀是前定变量，通过预期把一个时期与下一时期联系起来。
    怎么用：分析任何宏观事件时，先把它归类为四个外生变量（自然产出、需求冲击、供给冲击、通胀目标）之一的变动，再追踪产出的即时反应与逐期回归路径。这是通向DSGE模型的阶梯，也是各地中央银行实际使用的分析框架的简化版。
  tags: [动态AD-AS, DSGE, 短期波动, 模型构造]

  type: framework
  source_chapter: 第15章 15.1节
  source_quote: |
    本模型的最后一个部分是货币政策方程。我们假设中央银行采用下面的规则基于通货膨胀和产出来设定名义利率i的目标。
  summary: |
    解决什么问题：把"央行在做什么"从黑箱变成一个可写出、可估计、可讨论的方程：i=π+ρ+θπ(π-π*)+θY(Y-Yn)。

- id: Ff03
  title: DAS/DAD曲线：从五方程到产出-通胀两曲线的推导法
  type: framework
  source_chapter: 第15章 15.2节
  source_quote: |
    我们把这条向上倾斜的曲线叫做动态总供给曲线（dynamic aggregate supply curve），或者DAS曲线。动态总供给曲线和第14章的总供给曲线相似，区别在于纵轴表示的是通货膨胀而不是价格水平。
  summary: |
    解决什么问题：五个方程太抽象，需要在二维图上直观分析；传统AD-AS的纵轴是价格水平，动态版本纵轴改为通货膨胀率。
    核心逻辑：DAS由菲利普斯曲线代入适应性预期直接得到（π=πt-1+φ(Y-Yn)+ν），向上倾斜，位置由过去通胀、自然产出和供给冲击给定；DAD由需求方程+费雪方程+货币政策规则联立消元得到，向下倾斜——通胀上升使央行按规则加息且加息幅度超过通胀，实际利率上升、需求下降。DAD是"相对于给定的货币政策规则"而非给定货币供给绘出的。
    怎么用：把冲击和政策变化翻译成"哪条曲线移动、移动多少"，用A→B→C…的轨迹讲故事。
  tags: [动态AD-AS, 总供给, 总需求, 图形分析]

- id: Ff04
  title: 长期均衡基准：用古典二分法校验动态模型
  type: framework
  source_chapter: 第15章 15.2节
  source_quote: |
    长期均衡代表经济围绕其波动的正常状态，也就是没有冲击（ε=ν=0）并且通货膨胀稳定（π=π-1）时的状态。这个模型的长期均衡反映了两个相关的原理：古典二分法和货币中性。
  summary: |
    解决什么问题：分析短期波动前，需要先确立"经济围绕什么波动"的锚点。
    核心逻辑：无冲击且通胀稳定时，Y=Yn、r=ρ、π=π*=Eπ、i=ρ+π*；央行目标通胀率π*只影响通胀、预期通胀和名义利率这三个名义变量，不影响产出与实际利率——动态模型长期均衡是古典模型的镜像。
    怎么用：任何动态分析先算长期均衡作为起点与归宿；凡是"长期"结论，用古典二分法检查；凡是"短期"结论，承认货币非中性。这也是检验新模型是否自洽的底线。
  tags: [长期均衡, 古典二分法, 货币中性]

- id: Ff05
  title: 冲击分析流程：一次只动一个外生变量
  type: framework
  source_chapter: 第15章 15.3节
  source_quote: |
    本模型的四个外生变量是自然产出水平Y、供给冲击ν、需求冲击ε和中央银行的目标通货膨胀率π*。为简单起见，我们将假设经济开始总是处于长期均衡，然后其中一个外生变量发生了变化。
  summary: |
    解决什么问题：如何系统地用动态模型做"事件→结果"分析，而不是一次性塞进所有变化。
    核心逻辑：标准作业程序——(1)从长期均衡出发；(2)让一个外生变量变化（其余不变）；(3)确定即时影响（哪条曲线动、经济移到哪一点）；(4)追踪后续时期（预期通胀随实际通胀调整→DAS逐期移动→经济缓慢回归）；(5)画出关键变量的脉冲响应路径。四种实验分别对应：长期增长、供给冲击（滞胀）、需求冲击（繁荣后衰退）、目标通胀变动（反通胀）。
    怎么用：分析任何新闻事件（油价、刺激、央行加息）时照此流程走一遍，区分"当期效应"和"跨期动态"。
  tags: [冲击分析, 动态分析, 比较静态]

- id: Ff06
  title: 脉冲响应函数：用数值模拟展示模型动态
  type: framework
  source_chapter: 第15章 15.3节（参考资料）
  source_quote: |
    冲击发生后变量的时间路径图形（如图15-7、图15-9和图15-11所示）被称为脉冲响应函数（impulse response function）。"脉冲"（impulse）这个词是指冲击，"响应函数"（response function）是指内生变量随着时间的推移如何对冲击作出反应。
  summary: |
    解决什么问题：静态图看不出"冲击之后几年会发生什么"，需要一种展示时间路径的方法。
    核心逻辑：先校准参数到现实值（见案例Fc05），再对1个百分点的冲击求解模型，把每个内生变量（产出、通胀、实际利率、名义利率）在冲击后各期的取值画成时间序列。脉冲响应函数是"阐述模型如何起作用的一种方法"：冲击如何发生、变量随后如何调整、彼此如何随时间关联。
    怎么用：评估政策或冲击的完整后果时，不只问"上升还是下降"，还要问"什么时候到峰值、多久回归、路径形状如何"。这是现代宏观实证（VAR等）与央行预测的标准表达。
  tags: [脉冲响应, 数值模拟, 动态分析]

- id: Ff08
  title: 泰勒原理：通胀稳定性的判别准则
  type: framework
  source_chapter: 第15章 15.4节
  source_quote: |
    动态AD一AS模型得出了一个很强的结论：为了稳定通货膨胀，中央银行对通货膨胀的上升作出的应对必须是将名义利率提高更多。这一结论有时候被称为泰勒原理（Taylor principle）。
  summary: |
    解决什么问题：通胀上升时央行跟着加息，为什么有时还不够、反而失控？需要一个稳定性判据。
    核心逻辑：通胀升1个百分点，名义利率必须升超过1个百分点（θπ>0），实际利率才会上升、需求才会收缩；若θπ<0，DAD曲线向上倾斜，一次性需求冲击会触发"通胀↑→预期通胀↑→实际利率反降→需求更旺→通胀再升"的自我强化螺旋。泰勒原理是货币政策设计中的稳定性边界。
    怎么用：诊断通胀失控风险时，估计央行反应函数的θπ是否大于0（见案例Fc04大通胀的实证）；个人理解"为什么央行必须显得强硬"也靠这条。
  tags: [泰勒原理, 通胀稳定, 货币政策规则]

  type: framework

  source_quote: |
    第一，货币政策与财政政策应该在努力稳定经济中积极作为，还是应当保持消极？第二，政策制定者应该自由地运用他们的斟酌处置权以应对经济状况的变动，还是应该承诺遵循政策规则？
  summary: |

    怎么用：评价任何政策主张时，先定位它在2×2中的位置，再逐项检验其依据（时滞、预测力、时间不一致、政治过程）。

- id: Ff10
  title: 内在时滞与外在时滞：政策工具的"响应速度"诊断
  type: framework
  source_chapter: 第16章 16.1节
  source_quote: |
    长的内在时滞是运用财政政策稳定经济的核心问题。在美国尤其如此。……货币政策的内在时滞比财政政策更短，因为中央银行可以在不到一天的时间内决定并实施政策变动，但货币政策的外在时滞更长。
  summary: |
    解决什么问题：为什么"看到衰退就刺激"说来容易做来难？需要拆解政策从意图到生效的时间结构。
    核心逻辑：内在时滞=冲击→政策行动（财政因立法程序长，货币因央行独立决策短）；外在时滞=政策行动→影响经济（货币因投资计划提前安排而约需6个月，财政的自动稳定器几乎为零）。两种时滞的长度组合决定了各工具适合的角色。
    怎么用：给稳定化任务选工具时做两栏核对表：这个工具决策多快？生效多快？时滞长且多变的工具搞"微调"容易变成顺周期（见Fk04），时滞短的自动稳定器优先。
  tags: [时滞, 财政政策, 货币政策, 政策设计]

- id: Ff11
  title: 卢卡斯批判：政策评估必须内生化预期
  type: framework
  source_chapter: 第16章 16.1节
  source_quote: |
    卢卡斯认为，传统的政策评估方法——例如依靠标准宏观计量经济模型的方法——没有充分考虑到政策对预期的这种影响。这种对传统政策评估的批评就是著名的卢卡斯批判（Lucas critique）。
  summary: |
    解决什么问题：用历史数据估计的模型参数（如牺牲率）能直接用来预测新政策的效果吗？卢卡斯说：不能。
    核心逻辑：预期影响行为（消费看未来收入、投资看未来盈利），而预期本身取决于政府实行的政策；传统计量模型把历史政策环境下估计的参数当作不变的"深层结构"，一旦政策规则改变，人们预期方式改变，参数随之失效。
    怎么用：两层用法——狭义：评估任何新政策先问"它会改变人们的预期吗？"；广义：政策评估是困难的，要谦虚（见Fp09）。它也解释了为什么可信的反通胀可能比牺牲率估计值便宜。
  tags: [卢卡斯批判, 预期, 政策评估]

  type: framework

- id: Ff13
  title: 时间不一致性：为什么承诺比灵活更好
  type: framework
  source_chapter: 第16章 16.2节
  source_quote: |
    固定政策规则优于斟酌处置政策的一个论据是政策的时间不一致性（time inconsistency）问题。在某些情况下，政策制定者可能愿意提前公告他们将遵循的政策，以影响私人决策者的预期。但是，后来……这些政策制定者可能会受到某种诱惑而违背自己的公告。
  summary: |
    解决什么问题：即便政策制定者明智且仁慈，斟酌处置为什么仍可能是坏制度？这是本卷最重要的博弈论洞见之一。
    核心逻辑：三段结构——(1)事前公告低通胀以塑造私人预期；(2)私人按预期定价后，央行有激励食言制造意外通胀以压低失业；(3)公众看穿这一激励，一开始就不信公告，结果预期通胀居高、公告无效。人质谈判（"绝不与恐怖分子谈判"）、专利、父母惩罚、教授考试同理。
    怎么用：任何"承诺可信性"问题都可套用：谁想让谁相信什么？食言的诱惑在哪里？解法是取消斟酌处置权、代之以可信承诺（规则、宪法、独立机构）。
  tags: [时间不一致性, 可信承诺, 政策规则, 博弈]

- id: Ff14
  title: 三种货币政策规则的比较框架
  type: framework
  source_chapter: 第16章 16.2节
  source_quote: |
    如果美联储对货币政策规则作出承诺，那么，它应该选择什么规则呢？让我们讨论一下不同经济学家提倡的三种政策规则。
  summary: |
    解决什么问题：接受了"按规则办事"之后，选哪条规则？
    核心逻辑：三种候选——(1)货币主义规则：货币供给按稳定比率增长，缺陷是流通速度不稳时反而失稳；(2)名义GDP目标制：央行盯住名义GDP路径，自动容纳流通速度变动；(3)通货膨胀目标制：盯住通胀目标，同样隔离流通速度冲击，且政治优势是易于向公众解释。共同点：都用名义变量表示；用实际变量（如失业率5%）当目标很危险，因为自然率不可知（见Fk09）。
    怎么用：给央行（或任何承诺机构）设计目标时，问三点：能否吸收中途的冲击？是否易于向公众解释问责？目标变量是否是自己能控制且可知的？
