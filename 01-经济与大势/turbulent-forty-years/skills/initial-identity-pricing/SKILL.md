# 初始身份安排的远期定价法

## R — 原文 (Reading)

> 他没有像很多同一代的企业家那样受到产权归属的困扰，其原因便在于12年前的那次企业登记，他去领了一本"身份低贱"的执照。
>
> — 吴晓波，《激荡三十年》1988 年章（王文京与用友）

---

## I — 方法论骨架 (Interpretation)

企业诞生时填的那张登记表，是对未来几十年的定价合同。当时看起来体面或便利的身份（集体帽、挂靠、借名、代持），本质是从未来借来的便利——偿还物是退出日的产权官司、清算风险与融资障碍；当时看起来"低贱"但清晰的登记（个体执照、独资），远期反而免除产权纠纷、畅通上市。

一般化规则：初始体制依附度 = 未来产权风险敞口。为回避争议而放弃的清晰登记、为拿资源而依附的母体、 startup 时接受的公开承诺，都会沉淀为日后的产权地雷或政商约束。

决策标尺不是"当下哪扇门好进"，而是倒推法：假设十年后要融资、上市或退出，今天的身份选择是否让你打得清官司？挂靠省下的准入成本应记作借款而非收入，用退出情景计价。

适用范围不限于登记身份：一切"起步时为换取眼前好处而让渡名分"的安排——租来的品牌、借来的牌照、代持的股权——都适用同一定价逻辑。名分可以过渡，绝不能当承重墙。

## A1 — 书中的应用 (Past Application)

### 案例 1: 王文京领"身份低贱"的执照（1988）
- **问题**: 创办用友时，私营企业身份含争议，登记哪个口？
- **方法论的使用**: 被拒绝后"转身走进了旁边的个体科"，两小时领到个体工商户执照——选择当下身份最低但权属最清晰的登记；1990 年再登记为私营企业，逐步升级。
- **结论**: 屈辱的清晰身份远期优于体面的模糊身份。
- **结果**: 2001 年用友核准上市，王文京间接持股 55.2%，是极少数不受产权归属困扰的第一代企业家。

### 案例 2: 红帽子捐产的远期账单（1989-2002）
- **问题**: 治理整顿恐慌中，私企要不要把产权挂到集体名下换安全？
- **方法论的使用**: 王廷江、蒋锡培等把私产无偿捐给集体换"集体所有制"红帽子与政治身份——初始依附度瞬间拉满；名分让渡、控制权留在家族，是恐慌定价的临时交易。
- **结论**: 帽子可戴须预设赎回条款；初始身份的代价在登记多年后才到期。
- **结果**: 蒋锡培 2002 年回购股权、恢复私产，此时资产已超 10 亿——赎回成功者仍被"定价"了十三年。

### 案例 3: 联营挂靠"儿子吃掉老子"（1986-1999）
- **问题**: 国营企业出租品牌与技术搞联营，图短期收入。
- **方法论的使用**: 作者把联营定性为"饮鸩止渴"——初始的依附安排（品牌租用、无管控）决定了日后沈阳双喜收 500 万品牌费超过自身产销利润的空心化结局，租用方苏泊尔自立后反超。
- **结论**: 初始依附结构双向埋雷：出借方空心化，借名方始终面临被废弃的路径依赖。
- **结果**: 双喜让出整个市场，联营模式整体退场。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新公司注册：选个体/个独/有限公司，还是挂靠国企/高校/协会平台换补贴、牌照与背书？
2. 创业者被建议用亲友或投资人名义代持股权、借名登记，问这样"起步快"有没有后患。
3. 拟以集体、合作社等名义注册以回避行业准入限制，问十年后融资上市会怎样。
4. 早期图省事把公司注册在别人名下，现在要融资、股改或上市，想预判这笔远期账单。

### 语言信号 (用户的话里出现这些就应激活)

- "注册身份怎么选，挂靠国企平台好不好"
- "代持股权/借名登记有没有风险，以后退出麻烦吗"
- "起步时图方便/省事，现在后悔了" / "registration identity, nominee holding, future IPO"

### 与相邻 skill 的区分

- 与 `property-rights-timing` 的区别: 本 skill 在出生时点做前瞻定价（还没穿上衣服选什么料）；property-rights-timing 管企业已存在、产权已不清时如何界定与赎回——一个是预防，一个是治疗。
- 与 `red-hat-structure-decision` 的区别: 红帽子 skill 管恐慌期"要不要戴帽、协议怎么签"的完整交易结构（收益/代价/赎回窗口），适用于已运营企业的临时挂靠决策；本 skill 覆盖一切初始登记身份的定价，重点在"远期退出情景倒推"而非交易设计。
- 与 `marginal-zone-entry` 的区别: 边缘切入管"在哪里/从哪里进入"，本 skill 管"以什么身份出生"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认时点与选项清单**
   - 完成标准: 确认用户处于诞生/注册时点（企业尚未运营或运营极早期），列出全部候选身份（个体/个独/有限公司/合伙/挂靠/代持/借名）及其当下的准入收益（补贴、牌照、背书、税收）。
   - 判停条件: 若企业已运营多年且产权纠纷已成事实，转 property-rights-timing。

2. **按退出情景倒推定价**
   - 完成标准: 对每个选项写出十年后退出/融资/上市/清算四个情景下的产权状态（官司打得清吗、权属证据链完整吗、审批会卡在哪），把挂靠省下的准入成本记为负债而非收益。

3. **给出定价结论与升级接口**
   - 完成标准: 输出"清晰身份优先"或"确需依附时必须写入归还条款（何时、何对价、何程序落回自己名下）"的明确建议；任何依附安排均标注为过渡结构、不得作为承重墙。

4. **列出远期地雷清单**
   - 完成标准: 把所选身份的已知失败模式（红帽子清算期定罪风险、联营空心化、代持纠纷）列为未来需定期复查的检查点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 存量企业已经戴上帽子、正在纠结怎么摘——那是 property-rights-timing 的领地，本 skill 的前瞻标尺会答非所问。
- 恐慌期"要不要捐产戴红帽"的完整交易账（三项收益/三项代价/两个赎回窗口）——归 red-hat-structure-decision。
- 用户只问注册流程、注册资本认缴、核名等行政手续——无方法论含量，直接答即可。

### 作者在书中警告的失败模式

- 联营陷阱：出租品牌方"饮鸩止渴"空心化，租名号方始终面临被当药渣废弃（双喜 vs 苏泊尔）。
- 红帽子清算风险：清算时集体身份使企业家成为"贪污罪主体"——初始依附度最高的那种死法。
- 早年"身份低贱"的个体户与私营业主在历次整顿中首当其冲——清晰身份不是免费的，它当时支付的是政治歧视价。

### 作者的盲点 / 时代局限

- 幸存者偏差: 王文京"12 年无困扰"是成功者滤镜；同期绝大多数个体户死于市场与环境而非身份，作者用极少数幸存者证明登记策略的远期价值，样本严重不对等。
- 归因摇摆: 作者把用友的顺畅归给"12 年前那次登记"，但又承认环境松紧才是生死主线——身份变量与周期变量在叙述中权重不定。
- 时代边界: 写于 2018，公司认缴制、负面清单、注册便利化之后，"个体科两小时执照"的语境已不可平移；但"退出情景倒推定价"的标尺仍可迁移。

### 容易混淆的邻近方法论

- property-rights-timing：治疗 vs 预防，时点不同。
- red-hat-structure-decision：完整挂靠交易设计 vs 一般性初始定价。
- latecomer-resource-borrowing：借资源是运营策略，借身份是产权安排——后者才属于本 skill。
