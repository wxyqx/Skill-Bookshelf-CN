# 红帽子交易与产权赎回决策

## R — 原文 (Reading)

> 蒋锡培在捐产后也同样当选为全国劳模和全国人大代表，他在2002年通过回购股权，又成为企业的资产所有者，据估算当时他的资产已超过10亿元。
>
> — 吴晓波，《激荡四十年》1989年章

---

## I — 方法论骨架 (Interpretation)

红帽子是私产挂靠集体/国有以换取安全与身份的交易安排。这套方法把它当作一笔需要完整记账的交易，而不是权宜之计：

1. **收益三项**: 政治上避打击（换安全）、经济上享优惠（信贷、原料、税制）、运营上获信任（客户与官方的关系身份）。
2. **代价三项**: 产权的正式名分让渡（控制权与名义所有权分离）、公开承诺沉淀为长期政商约束、清算时点身份可能使企业家本人成为"贪污罪主体"——最后一项最致命。
3. **定价规则**: 借身份的价格按"清算情景"而非"获取情景"计算——不要问"挂靠能帮我拿到什么"，要问"如果有一天关系破裂或企业清算，这个身份会让我失去什么、承担什么罪名"。
4. **赎回窗口只有两个**: 自身声誉顶峰期（政府乐于给干成事的人放权，鲁冠球1988年以15%公共积累完成赎回式界定）与自身或环境的最低谷期（各方都需要出路时交易最易达成）。两个窗口之外的时点不强攻。
5. **结构底线**: 借身份之前先写好归还条款（何时、以何对价、经何程序落回自己名下）；身份只可作过渡的桥，不可当企业的承重墙。

## A1 — 书中的应用 (Past Application)

### 案例 1: 恐慌定价的捐产交易（1989）
- **问题**: 治理整顿的恐慌中，私企老板面临身份性打击，如何自保？
- **方法论的使用**: 王廷江捐价值420万元的白瓷厂外加180万元资金，随即任村委会主任、获全国劳模与全国人大代表身份；蒋锡培捐180万元电缆厂换"集体所有制"红帽子——产权名分让渡，实际控制权留在创始家族，且这是一笔按恐慌定价的临时交易。
- **结论**: 交出名分、保住控制，等待环境逆转赎回。
- **结果**: 环境逆转后批量赎回：蒋锡培2002年回购股权，资产超10亿；绝大多数"私产归公"企业日后恢复原产权性质。

### 案例 2: 鲁冠球的顶峰期赎回（1988）
- **问题**: 万向已成名企，集体身份的产权隐患如何解除？
- **方法论的使用**: 选择自身声誉顶峰期（政府乐于放权给标杆）提出产权界定，以"基数定额上缴"等对价置换政府干预，完成赎回式界定。
- **结论**: 顶峰期是唯一政府愿意"花钱买不管"的窗口。
- **结果**: 万向成为乡镇企业产权清晰的先行者，为日后上市扫清障碍；对照仰融戴国营资本红帽子"得益于先而倾辙于后"，身份壮大后被反噬。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 民企想借国资平台/混改挂靠/股权代持换取行业准入或融资便利，要决策这笔身份交易值不值。
2. 企业当年为求生存捐给集体或挂靠国有，现在环境已变，用户想知道何时、以何对价、走何程序把产权赎回。
3. 用户被建议把公司股权代持在国有名下以获得背书，要评估清算情景下的风险敞口。
4. 用户要审现有交易结构：借来的身份是否已被当成承重墙（上市主体、融资抵押、对外担保）。

### 语言信号 (用户的话里出现这些就应激活)

- "红帽子/戴帽/摘帽"
- "挂靠国企、股权代持、借国资背书"
- "这笔身份交易划算吗？以后赎回来难不难？"
- "当年捐给集体了，现在怎么拿回来？"
- "red hat, nominal ownership, buy back, affiliated with SOE"

### 与相邻 skill 的区分

- 与 `property-rights-timing` 的区别: 那个 skill 管存量企业产权清晰化的整体路径与时机（分空饼、灰色MBO vs 另起炉灶、见光死）；f07 专管"借身份"这笔交易本身的记账、归还条款与赎回窗口。戴帽前问 f07，摘帽后的路径选择问 f08。
- 与 `initial-identity-pricing` 的区别: f09 管新设主体注册身份的选择（个体执照 vs 挂靠的远期定价），是出生时的决策；f07 管存量私产与体制之间的挂靠交易与赎回，是存续期的决策。
- 与 `half-step-rights-reform` 的区别: 半步走管产权诉求的形态设计（分红权/增量分成），不处理身份挂靠的赎回窗口。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **记完整交易账**
   - 完成标准: 列出收益三项（避打击/优惠/信任）与代价三项（名分让渡/承诺沉淀/清算期定罪风险）的对照表，并按"清算情景"而非"获取情景"给出定价结论——明确写出关系破裂或清算时用户会失去什么。

2. **设计归还条款**
   - 完成标准: 若决定借身份，成文写出归还条款要点——何时赎回、以何对价、经何程序落回自己名下、违约时的争议解决机制；无归还条款的挂靠方案必须标注为高危并要求补齐。
   - 判停条件: 若对方不接受任何书面归还安排，且身份将被用于承重结构，建议放弃并给出替代方案（合资而非代持等）。

3. **选定赎回窗口**
   - 完成标准: 判断用户当前处于哪个窗口——声誉顶峰期（标杆地位、政府乐于放权）或最低谷期（各方需要出路）；两个窗口之外给出"等待+准备"清单，不强攻赎回。

4. **承重结构审查**
   - 完成标准: 检查借来身份是否承担长期结构功能（上市主体、融资抵押、核心资质持有者），输出"去承重化"整改建议——确保身份可退出而不动摇企业结构。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一般性的股权激励、融资结构、VIE 架构设计——不涉及与体制的身份挂靠交易。
- 国企自身的混改合规流程咨询——那是程序性合规，不是借身份的利弊账。
- 用户问的是新公司注册身份怎么选——转 initial-identity-pricing。

### 作者在书中警告的失败模式

- **把身份当护身符**（禹作敏，1993）: 体制授予的典型身份被误读为豁免权，"局长算个球"式的自我认知畸变，对抗调查组后被清算——身份不能兑换法律责任。
- **得先倾辙于后**（仰融，1991）: 戴国营资本红帽子先行得益，企业壮大后身份反噬控制权，最终出走——红帽子下的控制权安排无法承受成功。
- 书中警告：身份只可过渡不可当承重墙；绝大多数捐产企业日后赎回，但"绝大多数恢复原产权性质"的代价是十年以上的名分悬置期。

### 作者的盲点 / 时代局限

- **当代人写当代史的二次建构**: "恐慌定价的临时交易"是作者对1989年捐产潮的事后定性叙事，当事人在多年后的回忆中重构了动机，作者自认这是价值观支配下的二次建构。
- **幸存者偏差**: 蒋锡培赎回成功、资产超10亿被书写；未能赎回、清算期以身份被定罪或终身失去产权的企业家在书中只有零星剪影，"绝大多数恢复原产权性质"缺乏统计基础。
- **数据口径问题**: 捐产金额、赎回对价等数字多为转述与估算，未经独立核验。
- **重个人轻结构的归因摇摆**: 时而把赎回成败归因于企业家与地方官员的个人关系，时而归因于1990年股份合作制等制度安排，归因口径不一。
- **2018年写作的时代边界**: 1989年的红帽子语境（治理整顿、身份性打击）与此后的混改、代持监管环境不可简单类比；套用"两个赎回窗口"时应按当期制度环境重新校准。

### 容易混淆的邻近方法论

- `red-hat-structure-decision` 与 `business-government-distance`: 前者是产权名分的交易设计；后者是企业家的公共姿态与政商距离选位。接受荣誉与身份表态属后者，让渡股权名分属前者。
