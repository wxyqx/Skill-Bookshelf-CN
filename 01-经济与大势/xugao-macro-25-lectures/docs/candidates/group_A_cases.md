- id: Ac01
  title: 猪价与CPI：一次供需分析预判央行行为
  type: case
  source_chapter: 第1讲 1.2.1节
  source_quote: |
    2015年8月7日中国人民银行发布的《货币政策执行报告》的第52页说得非常清楚：
    “货币政策并不针对个别商品价格变化进行调整”，表明货币政策不会因为猪价的
    上升而收紧。……我们甚至可以在央行申明之前就预判央行的行为。
  summary: |
    方法论主题：价量判别框架（Af03）+ 原则“供给冲击型通胀不反应”（Ap03）
    的完整示范。
    案例内容：猪肉占CPI篮子近3%、是占比最大单一商品，价格波动又剧烈，故
    “CPI通胀是一块猪肉引发的焦虑”。生猪出栏量与猪价高度负相关→波动来自
    供给→货币政策（需求管理工具）无力也无需应对→2015年央行确实不因猪价
    收紧。作者强调：对投资者，提前预判央行即意味着回报，而预判只需简单运用
    供需分析。
  tags: [猪价, CPI, 货币政策预判]

- id: Ac02
  title: 房地产调控为何“价跌量涨”注定落空
  type: case
  source_chapter: 第1讲 1.2.1节
  source_quote: |
    房屋销量和房价之间存在明显的正相关关系（房屋销量还领先房价）。用供需分析
    的框架来看，这清楚地表明中国房地产市场的波动主要由需求因素所引发。因为
    中国土地供应由政府垄断，导致土地及房屋的供给受限。
  summary: |
    方法论主题：价量判别框架（Af03）+ 原则“压价必须扩供给”（Ap04）的
    第二次示范。
    案例内容：21世纪以来多轮房地产调控试图打压需求抑制房价，同时想保住地产
    投资（占固定资产投资约1/4）——即“价跌量涨”目标。但70城房价与销售面积
    正相关，证明波动来自需求侧（根源是政府垄断土地致供给受限）；需求调控必然
    价量同跌。而真正可行的扩土地供给又因减少地方土地财政收入而“为政府所不喜”，
    于是楼市在反复需求调控中震荡、目标始终无法达成。
  tags: [房地产调控, 土地垄断, 政策可行性]

- id: Ac03
  title: 苹果悖论：一场两小时也争不清的争论被数学一步化解
  type: case
  source_chapter: 第1讲 1.2.2节
  source_quote: |
    只要更严格地把苹果悖论中的两句话表述出来，就能发现悖论的产生只是因为自然
    语言不够精确，在两句话之间发生了不易觉察的概念偷换。
  summary: |
    方法论主题：双向翻译框架（Af10）——为什么经济学要用数学。
    案例内容：“苹果需求上升，苹果价格上升”与“苹果价格上升，苹果需求下降”
    各自无矛盾，合起来却像推出“需求不变”的悖论，学生可争论两小时莫衷一是。
    用供需图与数学（Q=a-bP）严格表述后即化解：前一句“需求”指偏好（曲线
    整体右移），后一句指需求量（沿曲线移动），同一个词两种含义。教训：自然
    语言的模糊是许多伪争论的根源，数学化让模糊无所遁形。
  tags: [苹果悖论, 概念偷换, 数学化]

- id: Ac04
  title: 中国GDP总量赶超两千年：从占世界1/3到不足5%再到重回第一
  type: case
  source_chapter: 第1讲 1.1.1节
  source_quote: |
    大概从公元1500年开始，中国经济总规模就超过了印度，跃居世界第一。到1820年，
    中国几乎占到了世界经济总量的1/3。……1978年改革开放的前夕，中国占世界
    经济的比重不足5%。
  summary: |
    方法论主题：问题地图之“增长问题”（Af04）——用长时段历史数据把“为什么
    增长”变成最重大的问题。
    案例内容：麦迪逊《世界经济千年史》估算：1500年起中国超印度居世界第一，
    1820年占世界经济约1/3，此后百年下坡，1978年前夕不足5%；改革开放后回升，
    2008年（PPP）达17.5%接近美国，IMF估算2014年（PPP）已超美国。人类历史
    两千年只见证两次世界第一更替，而“跌落后浴火重生”从未有过——中国正在
    改写历史。这为“改革开放做对了什么”这一关键问题提供历史坐标。
  tags: [GDP赶超史, 麦迪逊, 长时段比较]

- id: Ac05
  title: 复利的力量：改革开放前后25年，人均GDP差出近3倍
  type: case
  source_chapter: 第1讲 1.1.1节
  source_quote: |
    在复利的作用下，每年几个百分点增速的差异会在多年后累积成经济绩效的巨大
    差异。……2003年中国人均真实GDP水平则是1978年的7.3倍。如果把时间拉到
    2017年，这一年中国人均GDP水平差不多是1978年的24倍。
  summary: |
    方法论主题：增长与波动的二分中“增长更为重要”的量化论证（Af04）。
    案例内容：1953-1977年25年间中国人均真实GDP增速平均仅4.3%，1977年人均
    GDP只是25年前的2.5倍；1978-2016年平均增速8.6%，同样25年后的2003年
    达到7.3倍，到2017年约24倍。几个百分点的增速差经复利累积成绩效鸿沟——
    这就是为什么宏观经济学把长期增长列为第一问题，也把“中国做对了什么”
    列为第一个关键问题。
  tags: [复利, 增长重要性, 改革开放前后对比]

  source_chapter: 第1讲 1.1.1节
  source_quote: |
    巴西和阿根廷分别在20世纪70年代和20世纪60年代达到了1万美元左右的人均
    收入水平。但从那之后，这两个南美国家陷入了经济增长低迷、收入水平停滞的

  summary: |

    阿根廷分别在70/60年代达1万美元左右后停滞几十年。同一收入水平、两种命运，
    引出“中国如何避开陷阱、延长高增长”的关键问题。
  tags: [中等收入陷阱, 国际比较, 增长前景]

- id: Ac07
  title: 四万亿刺激：用三驾马车拉动分解读懂危机与应对
  type: case
  source_chapter: 第2讲 2.3.3节；第1讲 1.1.2节
  source_quote: |
    仅仅因为净出口的收缩，中国GDP增速就会损失6个百分点之多。这便是次贷危机
    带给中国的冲击。……中国投资对GDP增长的拉动在2008年大幅上升了3个百分点，
    在一定程度上抵消了外部冲击对我国经济的影响。
  summary: |
    方法论主题：拉动分解原则（Ap08）的现实应用——从“三驾马车”拉动变化中
    识别经济波动的冲击来源。
    案例内容：2017年6.9%的增速中消费拉动4.1、投资2.2、净出口0.6个百分点；
    回溯次贷危机时，净出口收缩单项可拖累增速约6个百分点，是中国所受冲击的
    主渠道；2008年“四万亿元刺激”使投资拉动上升3个百分点，部分对冲外需
    塌方，带来2009年“V字形”复苏（克强指数创20年高点）。同时也示范：占比
    仅2%的净出口因波动巨大而成为关键变量。
  tags: [四万亿, 三驾马车, 拉动分解]

- id: Ac08
  title: 苏联扭曲价格的虚高GDP：价格失真则GDP与福利脱节
  type: case
  source_chapter: 第2讲 2.2.3节
  source_quote: |
    苏联为了转嫁军备竞赛的负担，大幅提高了国内生活品的价格。结果，苏联生产的
    低质量电视机（甚至有爆炸的可能）却在国内卖出了高价。这种扭曲价格下的虚高
    GDP并未带来苏联居民福利的相应提升，引发了苏联民众的不满。
  summary: |
    方法论主题：GDP的人本定义（Ag09）的边界条件——GDP靠市场价格把居民偏好
    加总进来；价格信号被扭曲时，GDP与福利的联系断裂。
    案例内容：1970年代苏联大幅提高生活品价格转嫁军备负担，低质量（甚至可能
    爆炸的）电视机卖出高价，虚高GDP未带来福利提升，民怨积累成为苏联解体的
    重要原因。教训：看到高GDP数字先问“价格是否真实反映偏好”，市场经济中
    GDP才以人为本。
  tags: [苏联, 价格扭曲, GDP与福利]

- id: Ac09
  title: 伊甸园思想实验：GDP为零而福利无穷大
  type: case
  source_chapter: 第2讲 2.2.2节
  source_quote: |
    让我们假设苹果的初始禀赋为无穷大……当苹果消费的边际效用趋近于0时，消费者
    显然不愿意牺牲自己的闲暇去生产更多的苹果，所以此时劳动的供给量l=0，经济中
    的GDP为0。尽管此时GDP是0，但消费者的效用会因为无穷的苹果消费而趋近于
    无穷大。
  summary: |
    方法论主题：极端情形思想实验用于界定概念（Af08建模法的变体）。
    案例内容：把苹果禀赋推至无穷（伊甸园，资源不再稀缺），苹果边际效用趋零，
    无人愿意牺牲闲暇劳动，GDP=0而效用趋无穷——证明GDP衡量的不是财富或效用
    本身，而是“所有降低资源稀缺性的生产活动的总价值”；稀缺性消失，GDP概念
    即失去意义。配套证据：模型中禀赋c0从0升至0.4，GDP从0.58降到0.46，
    效用却从-0.48升到-0.19。同理，雾霾催生空气净化器产业反而推高GDP。
  tags: [思想实验, 稀缺性, GDP定义]

- id: Ac10
  title: 用香港数据矫正内地虚假贸易：交叉比对的实战样本
  type: case
  source_chapter: 第2讲 专栏2-1
  source_quote: |
    中国海关公布的中国内地对中国香港的出口额大于同期香港发布的香港从中国内地
    的进口额。用香港的数据来矫正内地的数据，就能规避虚假贸易对分析的影响。
  summary: |
    方法论主题：数据交叉验证原则（Ap10）的可操作示范。
    案例内容：2012-2013年内地出口企业通过高报出口货值向境内转移资本，造成
    内地海关公布的对港出口额大于香港统计的从内地进口额——同一笔贸易的两个
    独立口径出现缺口即暴露造假。用交易对手方（香港）数据矫正内地数据，即可
    规避虚假贸易对分析的污染。作者以此说明：抱怨数据质量差不如做好数据
    比对“功课”。
  tags: [虚假贸易, 数据交叉验证, 热钱]

- id: Ac11
  title: 克强指数：次贷危机后中国实体波动加大的证据
  type: case
  source_chapter: 第1讲 1.1.2节
  source_quote: |
    2009年，在国内“四万亿元刺激”政策的带动下，中国实体经济实现了“V字形”
    复苏，克强指数的同比增长率创下了20年的高点。而在2015年底……下滑至0附近，
    创出20年中的最低水平。
  summary: |
    方法论主题：波动问题的提出（Af04之“波动”类）+ 绕开低质量统计的指标
    选择术（Ap10）。
    案例内容：克强指数=信贷、发电量、铁路货运量三个不易造假指标的同比增速
    平均，对实体经济跟踪灵敏度高于统计局工业增加值。用它观察：2009年四万亿
    带动V形复苏、指数创20年高点；2015年底刺激减弱、指数近零，低于1998年
    亚洲金融危机与2008年次贷危机低谷——证明次贷危机后中国经济波动明显加大，
    引出“该不该用政策托底”的波动类关键问题。
  tags: [克强指数, 经济波动, 指标选择]
