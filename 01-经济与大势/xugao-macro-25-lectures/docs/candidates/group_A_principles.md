# 阶段1 候选提取 — A组 原则（principle）
# 来源：front.txt（总序+前言+目录）、lect01.txt（第1讲）、lect02.txt（第2讲）

- id: Ap01
  title: 用经济学答案，是因为它最好，而不是因为它姓“经济学”
  type: principle
  source_chapter: 第1讲 1.2节
  source_quote: |
    我们在这里会给出这样或那样的经济学答案，并不是因为它们是经济学给出的答案，
    而是因为经济学的答案是我们能找到的对这些问题的最好解答。……这门课会追问的
    很多问题在书本里并没有现成的答案。
  summary: |
    可直接套用的规则：接受任何经济学结论前，把它当作“目前最好的候选解答”
    而非权威教条；同时不指望从书本里直接查到现实问题的现成答案——要基于对
    现实的理解、用有效方法严密推理，再用现实证据验证。这是使用本书全部方法
    论的元态度。
  tags: [元态度, 反教条, 验证]

- id: Ap02
  title: 方法普适、结论特殊：不可将得自西方的结论视为圭臬
  type: principle
  source_chapter: 第1讲 1.2.3节；前言 §2
  source_quote: |
    尽管必须运用现代经济学的分析方法来分析中国经济问题，但绝不可将得自西方的
    结论视为圭臬，看作不变的真理。正确的做法是运用经济分析的方法，结合中国的
    实际，得出契合中国实情的结论。
  summary: |
    可直接套用的规则：每当把产生于西方的理论结论用于中国，必须先检查其隐含
    假设（西方市场的特性被当成了理所当然）在中国是否成立；假设不成立时结论
    即不可用。正确流程是“普适方法+中国约束条件→重新推演出契合中国实情的
    结论”，而不是直接搬运结论。
  tags: [中国视角, 隐含假设, 结论移植]

- id: Ap03
  title: 供给冲击型通胀：货币政策最优应对是不做反应
  type: principle
  source_chapter: 第1讲 1.2.1节
  source_quote: |
    面对供给减少带来的猪肉价格上涨，以及随之而来的CPI上涨时，货币政策不具有
    直接调控的能力。所以，对于这种猪价带来的CPI通货膨胀，货币政策最优的应对
    方式是不做反应。等到猪肉供给自然恢复后，猪肉价格自己就会下去。
  summary: |
    可直接套用的规则：每当CPI上涨由供给侧波动（如猪价）引发，紧缩货币并不能
    增加供给，只会误伤需求——正确应对是等待供给自然恢复。操作步骤：先用价量
    相关性判别波动来源（供给还是需求），再决定政策是否反应。此规则可用于预判
    央行行为（央行明确申明“货币政策并不针对个别商品价格变化进行调整”）。
  tags: [猪价通胀, 货币政策, 判别再行动]

- id: Ap04
  title: 平抑房价且保量稳：必须扩大供给而非打压需求
  type: principle
  source_chapter: 第1讲 1.2.1节
  source_quote: |
    如果真的想要在平抑房价的同时又保持房地产销售和投资的稳定增长，政府应该
    加大土地供给，通过供给的扩大来压低房价。
  summary: |
    可直接套用的规则：在需求主导波动（价量同涨同落）的市场里，打压需求的
    调控必然“价跌量也跌”，无法实现“价跌量涨”；要同时压价与保量，唯一的
    出路是扩大供给（土地供给）。附带推论：由于增加土地供给会减少地方政府
    土财政收入，调控目标受制于财政利益——分析调控政策时要问供给方的激励。
  tags: [房地产调控, 供给扩大, 土地财政]

- id: Ap05
  title: 数学是渡河之舟，终点是用大白话讲清逻辑
  type: principle
  source_chapter: 第1讲 1.2.2节
  source_quote: |
    数学只是我们的渡河之舟。在我们运用数学工具理清了思路之后，应该可以完全
    抛开数学，将逻辑用平实的大白话讲述出来，让人信服。只有这样，问题才算得到
    了真正的解答。
  summary: |
    可直接套用的规则：每当完成数学推导，必须做一次“下船”检验——能否完全
    抛开公式，用平实的自然语言把经济逻辑讲得让普通人信服？公式写得精美不代表
    问题回答得漂亮；最重要的是数学所呈现的经济逻辑。不能复述成大白话，说明
    还没有真正理解。
  tags: [数学工具观, 大白话检验]

- id: Ap06
  title: GDP是手段而非目的，忘记这一点就看不清问题本质
  type: principle
  source_chapter: 第2讲 2.1节
  source_quote: |
    这便是现在用GDP来衡量国民财富的历史源头，也是我们应该关心GDP的原因——
    它是我们间接推算福利的最佳指标，提升GDP也就是在提升居民福利。如果我们
    忘记了这个历史源头，忘记了GDP只是手段而非目的，那就无法看到许多经济
    问题的本质。
  summary: |
    可直接套用的规则：每当评价经济表现或设定目标，先回溯GDP与终极关切
    （居民福利）的联系：GDP之所以值得关心，仅因它是间接推算福利的最佳可观测
    指标。因此“提升GDP”只有在它确实对应福利提升时才是正当目标；价格被
    扭曲、偏好未入市的场合，这一对应会断裂。
  tags: [GDP观, 手段与目的, 福利]

- id: Ap07
  title: 谈结构好坏，先问“恰当的标准是什么”
  type: principle
  source_chapter: 第2讲 2.4节
  source_quote: |
    当我们在谈论中国存在消费不足，需要改变的时候，需要首先明确比较的标准，
    应该首先问出这个问题：对中国来说，恰当的消费占GDP的比重是多少？
  summary: |
    可直接套用的规则：每当断言某结构指标（消费占比、投资占比、杠杆率等）
    “过高/过低”，必须先给出比较的标尺并论证标尺本身——“低于国际平均”不
    等于“不好”。标尺要从经济学终极关切（居民效用最大化）出发推出来，再
    对照现实找差距与缺失的机制。没有标尺的结构判断只是情绪。
  tags: [比较标尺, 结构判断, 消费转型]

- id: Ap08
  title: 占比小不等于不重要：用拉动看各部分对增长的贡献
  type: principle
  source_chapter: 第2讲 2.3.3节
  source_quote: |
    有些组成部分可能占比并不高，但增长很快，因而能够在总体的增长中占据较大
    份额。而由于我们关心的往往是增长，所以并不能仅仅因为某些组成部分的占比
    小就忽视它们。
  summary: |
    可直接套用的规则：分析总量指标的构成时，不要按占比权重看重要性，要计算
    各组成部分对总体增长的“拉动”（ΔA/C）。占比低但增速高的部分可能贡献
    一半以上的增长（如存货与净出口占比各仅2%却常是波动来源）。操作：增长
    率分解为各部分拉动之和，逐项追踪。
  tags: [拉动分解, 数据分析]

- id: Ap09
  title: 说增速必指真实增速：扣掉物价再比较
  type: principle
  source_chapter: 第2讲 2.3.1节
  source_quote: |
    当我们通常说GDP增速时，指的都是扣除了物价因素之后的真实增速。……这个
    翻一番是用扣除了价格因素的真实GDP来计算的，而不是通过制造通货膨胀，把
    物价搞高点就能容易达到的。
  summary: |
    可直接套用的规则：每当比较、设定或考核任何经济规模指标（GDP、GDP翻番
    目标、收入水平），一律使用扣除价格因素后的真实/不变价口径；名义值的增长
    可能纯属通胀。真实增速也叫实际增速、不变价增速。
  tags: [真实与名义, 数据口径]

- id: Ap10
  title: 数据有系统性误差也能用：看走势+交叉比对
  type: principle
  source_chapter: 第2讲 专栏2-1
  source_quote: |
    只要统计数据中的误差是系统性的，就不妨碍我们用数据来把握经济运行的走势。
    ……通过仔细比对这些数据，能够发现数据中的不实之处，从而规避其对分析的
    影响。
  summary: |
    可直接套用的规则（两条）：①把统计数据当“标尺不太准的温度计”——水平值
    可能高估或低估，但系统性误差在计算变化率时会被消除，故增速/走势可信；
    ②对可疑数据，找不同来源（统计局、央行、海关、交易对手方、境外数据）
    交叉比对，用独立口径矫正偏差，如用香港数据矫正内地虚假贸易。
  tags: [数据质量, 交叉验证, 走势分析]

- id: Ap11
  title: 永远把关切投向数据背后的鲜活之人
  type: principle
  source_chapter: 第1讲 1.3节
  source_quote: |
    对于我们这些学习经济学的人来说，在关注经济现象和数据的时候，还必须将
    关切投向现象和数据背后的鲜活之人。
  summary: |
    可直接套用的规则：每当分析宏观指标，提醒自己任何数据都由活生生的人构成
    ——0.1个百分点的失业率意味着几十万人丢掉工作。这不仅是情怀，更是分析
    动力与判断标尺的来源：经济理论的真正使命是让这些人获得幸福。作者以义乌
    母女捡方便面碎屑的照片为此原则的具象化。
  tags: [福利关切, 经济学使命]
