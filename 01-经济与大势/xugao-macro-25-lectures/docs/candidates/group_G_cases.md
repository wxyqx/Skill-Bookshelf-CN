# Group G 案例候选（第15-16讲）

- id: Gc01
  title: 2013年6月"钱荒"：央行收紧超储的威力
  type: case
  source_chapter: 第15讲 15.1.3节；第16讲 16.4.2节
  source_quote: |
    2013年6月20日的盘中交易时，银行间隔夜回购利率甚至达到了30%（年率）的高位，
    创下了历史纪录。……"钱荒"之所以会发生，是因为中国人民银行为了清查影子银行，
    而大幅收紧了基础货币的供应。
  summary: |
    方法论主题：超额存款准备金是终极支付工具+央行对其的强控制力（并引出融资贵）。
    央行为清查影子银行大幅收紧基础货币，短期利率飙至历史纪录，证明央行收准的威力
    可瞬间冻结资金面；钱荒后长期利率同步抬升，演变为实体经济"融资贵"，成为后文
    预算软约束分析的起点事件。用法：作为"央行通过超储闸门可直接制造金融压力"的
    极端案例，提醒分析者不可低估央行收紧的潜在冲击力。
  tags: [钱荒, 央行政策, 终极支付工具]

- id: Gc02
  title: 2015年A股大牛市与股灾：流动性堰塞湖的戏剧性体现
  type: case
  source_chapter: 第15讲 15.5节
  source_quote: |
    从2014年下半年开始，上证综指却与财新PMI背道而驰，打破了过去十年来的相互关系。
    ……社会融资总量长期处在同比少增的格局……银行间市场的成交量却大幅增加。
  summary: |
    方法论主题：流动性堰塞湖+流动性效应。两组证据锁定泡沫性质：其一，上证综指与
    财新PMI近十年高度正相关，2014下半年起背离；其二，社融同比少增（实体资金萎缩）
    与银行间成交量暴增（金融资金泛滥）同时出现。结论：牛市是定向宽松阻塞传导后
    金融市场的过剩流动性推起的股价泡沫，2015年6-7月股灾随之而来。用法：示范
    如何用"实体融资指标 vs 金融体系资金指标"的背离来给牛市定性，作者2014年
    文章《牛市与流动性堰塞湖》有预见性地给出了这一论断。
  tags: [A股牛市, 股灾, 流动性堰塞湖]

- id: Gc03
  title: 定向宽松政策（2013-2015）：人为制造的钱与需求的错配
  type: case
  source_chapter: 第15讲 15.5节
  source_quote: |
    农业和小微企业因为规模、风险等因素而对资金的吸纳能力有限。而房地产和基建两个
    传统的资金需求大户又受到融资的限制。……要钱的地方不给、要给钱的地方又给不出去。
  summary: |
    方法论主题：货币政策传导阻塞的行政成因。央行主动向三农、小微倾斜，同时地产调控
    加码、43号文压城投融资，导致最大资金吸纳方（地产+基建，合计约半数投资）被
    行政性挤出融资市场，而政策倾斜的对象吸纳能力有限，流动性被迫淤积金融体系。
    用法：示范"总量政策被当结构性政策用"的传导后果——愿望是精准投放，结果
    是堰塞湖；分析任何定向型政策时先问目标对象的资金吸纳能力。
  tags: [定向宽松, 传导阻塞, 政策错配]

- id: Gc04
  title: 城投债与产业债的倒挂：低回报者挤出高回报者
  type: case
  source_chapter: 第16讲 16.1节
  source_quote: |
    这上千家城投公司的平均总资产回报率……在2014年甚至不足3%。而这些城投公司所发行
    债券（城投债）的平均票息率超过6%。……从2013年年初到2014年上半年，城投债的发行量
    都明显超过同期产业债。
  summary: |
    方法论主题：刚性兑付/预算软约束的挤出效应。城投公司ROA不足3%却以超6%成本融资，
    回报覆盖不了利息；而ROA更高的产业公司融资份额反被挤压，尤其在2013年6月钱荒
    后利率大幅上扬期间。原因在隐性担保使城投债在投资者眼中近乎无风险。用法：作为
    "市场把更多钱配置给低效主体"的实证样本，检验融资收紧时软约束主体占比上升的
    模型推论（Gf09）。
  tags: [城投债, 刚性兑付, 所有制歧视]

- id: Gc05
  title: 超日债违约（2014年3月）：打破刚兑的代价落在民企头上
  type: case
  source_chapter: 第16讲 16.4.3节
  source_quote: |
    上海超日太阳能科技股份有限公司发布公告，称自己无法按时兑付利息。这让其发行的
    "超日债"成了中国债券市场第一只实质性违约的债券。……这些事件主要发生在民营企业
    身上。
  summary: |
    方法论主题：打破刚性兑付的执行偏差。刚兑打破的呼声没动摇有政府兜底的城投
    （基建稳增长不能停），却率先在民企身上兑现——违约集中于民企使其债的风险溢价
    上升，投资者转而更追捧城投债，民企被挤出更严重。用法：示范"名义上中性的改革
    在软约束环境下非中性"——评估打破刚兑时必须问违约落在谁头上，模型推论是民企
    成功概率下降反而抬高政府项目融资占比。
  tags: [超日债, 违约, 刚性兑付]

- id: Gc06
  title: 欧央行2011年后的流动性积压：传导阻塞的国际例证
  type: case
  source_chapter: 第15讲 15.2.2节
  source_quote: |
    欧洲中央银行在2011年欧债危机之后，曾经大量向货币市场投放流动性。但这些流动性
    大部分积压在欧洲中央银行的账户上，并未带来实体经济货币量和通货膨胀水平的相应
    扩张。
  summary: |
    方法论主题：宽松货币不必然带来广义货币扩张。商业银行放贷能力受损（银行自身
    稳健性问题）或实体融资需求不足时，基础货币淤积在央行账户，广义货币与通胀
    都不响应。用法：说明市场分割/流动性淤积不是中国特有，银行体系受损后的发达
    经济体同样出现；比较中欧情形可见阻塞点可以不同（行政错配 vs 银行与需求端
    瘫痪），机制同构。
  tags: [欧央行, 传导阻塞, 国际比较]

- id: Gc07
  title: 春节前的"年末效应"：现金需求抽紧资金面
  type: case
  source_chapter: 第15讲 15.1.2节
  source_quote: |
    当经济中对现金的需求比较大时——我国每年春节之前都是这样——现金需求的扩张就会
    导致金融市场超额存款准备金减少，金融市场资金面抽紧。
  summary: |
    方法论主题：资产负债表分析法的日常应用。储户提现使银行消耗超额存款准备金换取
    库存现金，现金需求季节性放大（春节前）即造成资金面季节性抽紧。用法：季节性
    资金波动的标准解释模板，也说明央行常在春节前投放流动性对冲；可推广到任何
    "非央行因素导致的超储消耗"（缴税、缴准等）的分析。
  tags: [现金需求, 年末效应, 资金面]

- id: Gc08
  title: 国发[2014]43号文与地方债置换：从金融端到财政端的纠偏
  type: case
  source_chapter: 第16讲 16.1节、16.4.1节
  source_quote: |
    在2014年10月出台的《国务院关于加强地方政府性债务管理的意见》（国发[2014]43号）
    中，政府明确要求："坚决制止地方政府违法违规举债"。……从2015年开始，政府已经
    意识到了这一点，因此启动了"地方债置换"项目来用国债替换之前地方政府融资平台
    发出的各种债务。
  summary: |
    方法论主题：软约束的化解路径及其副作用。43号文剥离平台融资功能、压城投债
    发行，本是硬化预算约束的正确方向；但财政责任未同步接上时，它同时阻塞了基建
    融资与货币政策传导，催生流动性堰塞湖（2015牛市）。2015年起地方债置换用国债
    替换平台债务，是财政开始承担责任的转折。用法：完整呈现"金融端清理软约束
    →传导阻塞→财政端接手"的政策演化链，验证Gf12改革次序框架。
  tags: [43号文, 地方债置换, 财政与金融]

- id: Gc09
  title: 2013下半年至2014年的"融资贵"：利率长期高于合适水平
  type: case
  source_chapter: 第16讲 16.4.2节
  source_quote: |
    从2013年下半年到2014年，10年期国债收益率长时间大幅度地高于估计出来的合适利率
    水平。这段时间也是各方普遍感受到融资贵的时期。
  summary: |
    方法论主题：合适利率基准+软约束压低利率敏感性。作者用费雪方程式式计量模型
    （10年期国债收益率对CPI、工业增加值、7天回购利率回归）估算"合适利率"，
    发现2013下半年至2014实际利率长时间高于拟合值；解释是钱荒后城投占比上升，
    融资需求对利率不敏感，回归力量减弱。用法：示范如何把"融资贵"从感受变成
    可检验的计量命题，并绑定软约束机制而非货币总量来解释。
  tags: [融资贵, 合适利率, 计量检验]

- id: Gc10
  title: 中国存贷款利率管制下的真实利率逆周期：费雪方程式的中国失效
  type: case
  source_chapter: 第15讲 15.2.1节
  source_quote: |
    我国存贷款基准利率长期为政府所管制。导致的结果是名义存贷款利率的变化幅度远远
    小于通货膨胀波动的幅度。这使我国的真实利率逆周期波动。
  summary: |
    方法论主题：费雪方程式的隐含前提与中国的偏离。若真实利率由资本边际产出决定，
    应顺周期波动；但管制利率下通胀涨得比名义利率快，经济越热真实利率越低，进一
    步刺激信贷、放大过热——形成向过热或过冷两极偏离的正反馈。用法：作为"名义
    变量受管制时价格信号失灵并放大波动"的案例，也说明信贷市场无法出清时必须
    配合信贷额度等行政管理手段。
  tags: [利率管制, 逆周期, 正反馈]
