  title: 货币政策三层次体系（最终目标—中介目标—工具）
  type: framework
  source_chapter: 第17讲 17.1节
  source_quote: |
    用一句话来概括，货币政策通过调控货币政策工具来影响货币政策中介目标，进而实现货币政策最终目标。在这里，有最终目标、中介目标和工具三个层次的概念需要分别阐明。
  summary: |
    解决"央行每天的操作如何与'稳定物价、促进增长'这类宏大目标挂钩"的问题。核心逻辑是把货币政策拆成三层传导链：工具（每日操作，如公开市场操作、准备金率）→中介目标（央行较可控且与最终目标相关的指标，如M2增速）→最终目标（物价稳定、经济增长等）。央行只对工具和中介目标有较强掌控力，对最终目标只有影响力。用法：分析任何央行动作时，先定位它处在哪一层、意图作用于哪一层，再看层次间的传导是否顺畅，避免把单一工具动作直接解读为最终目标变化。
  tags: [货币政策, 目标体系, 传导链]

  title: 货币政策中介目标选取三条件
  type: framework
  source_chapter: 第17讲 17.1.2节
  source_quote: |
    货币政策中介目标的选取有三个条件：第一，中介目标必须与货币政策最终目标指标有相关性……第二，中介目标必须是中央银行相对可控的指标……第三，中介目标应该是可被比较精确统计的指标。
  summary: |
    解决"央行该盯住哪个指标"的选型问题。三条件：相关性（变动能传导到最终目标指标）、可控性（央行有较强决定力）、可测性（能精确及时统计）。核心洞察是三条件之间会冲突：M1与增长和通胀相关性更强但央行掌控力低，M2相关性弱一些却因贷款派生存款而更可控——所以中国选M2而非M1做中介目标。用法：评估任何"央行应盯住X"的主张时，逐一检验三条件，尤其警惕只拿相关性说话的论证。

  title: 超额存款准备金中心论：货币政策真正调控的对象
  type: framework
  source_chapter: 第17讲 17.1.3节
  source_quote: |
    超额存款准备金是商业银行相互之间的支付工具……超额存款准备金的多寡就决定了金融市场中可用的"钱"的多少……要改变超额存款准备金的数量有两种办法。第一是改变存款准备金（也就是"其他存款性公司存款"）的数量，第二是改变存款准备金率。
  summary: |
    解决"庞杂的货币政策工具到底共同指向什么"的问题。核心逻辑：法定存款准备金=存款总量×准备金率，给定存款规模，央行调控超储只有两条路——改变基础货币总量，或改变准备金率切分法定/超储的比例。超储是银行间支付与交易的工具，其数量决定金融市场流动性的松紧；中国超储总量不到2万亿元，却决定约170万亿M2体系的流动性，货币政策因此是"四两拨千斤"。用法：判断任何政策动作对金融市场的松紧含义，最终都要折算成对超储数量的影响。
  tags: [超额存款准备金, 流动性, 准备金率]

- id: Hf05
  title: 泰勒准则：利率必须内生于经济状况
  type: framework
  source_chapter: 第17讲 17.2.2节
  source_quote: |
    为了阻断这种正反馈机制，名义利率的变化幅度应该比通货膨胀预期的变化幅度更大，以便形成顺周期运动的真实利率……这就是货币政策调控的泰勒准则（Taylor principle）。
  summary: |
    解决"央行能否把利率固定在某个水平以求稳定"的问题。核心逻辑：用新凯恩斯模型（新凯恩斯菲利普斯曲线+动态IS曲线）证明，若名义利率固定，通胀预期上升会压低真实利率、推高产出与通胀，形成发散的正反馈。阻断办法是让名义利率变动幅度大于通胀预期变动幅度，使真实利率顺周期。深层结论：央行并不具有任意选择名义利率的能力，利率政策必须内生于经济状况、相机调整。用法：这是判断一国利率政策是否"稳定型"的判据，也是理解中国利率调控为何被指"放大波动"的基准。
  tags: [泰勒准则, 利率政策, 新凯恩斯模型]

  type: framework
  source_chapter: 第17讲 17.2.1节
  source_quote: |
    如果存在稳定的货币需求方程，那么货币政策既可以主要以数量（货币总量）为调控工具，也可以主要以价格（名义利率）为调控工具。但在现实中……主要原因是货币需求方程并不稳定，会受到一些其他因素的扰动。
  summary: |
    解决"央行该控货币量还是控利率"的选择问题。核心逻辑：从MIU模型的货币需求方程出发，货币流通速度与名义利率正相关（中国数据亦验证）。当货币需求存在随机冲击时，若央行固定货币总量增长，利率和消费会大幅波动；若保持利率稳定、让货币量吸收冲击，金融与实体更平稳，且利率可随时精确观测、便于调控。因此多数国家央行以名义利率为主要调控工具。用法：理解各国央行从数量型转向价格型的普遍路径，以及数量调控何时仍然合理（如需求冲击较小时）。
  tags: [货币需求, 数量型调控, 价格型调控]

  title: 利率走廊机制
  type: framework
  source_chapter: 第17讲 17.3节
  source_quote: |
    从2015年开始，美联储引人了利率走廊（interest rate corridor）机制，同时设定联邦基金利率的上限目标值和下限目标值。美联储承诺在上限目标利率水平上会无限量地向市场提供基础货币。
  summary: |
    解决"如何把市场利率更牢地锁定在目标区间"的问题。核心逻辑：央行承诺在上限利率上无限量放钱（想借多少就能借到多少），在下限利率上无限量收存款，两相夹逼，市场利率只能落在走廊内；这比单点目标值增强了对短端利率的掌控。走廊的本质是用两个"无限量"承诺把政策利率变成真实成交的有效利率。用法：评估一国短端利率调控成熟度时，看其是否具备走廊结构与无限量承诺；练习题进一步提示，走廊的可行性还受融资主体预算软约束的制约。

  type: framework

  source_quote: |

- id: Hf12
  title: 流动性陷阱与名义利率零下限
  type: framework
  source_chapter: 第18讲 18.2.1节
  source_quote: |
    虽然名义利率不能比0低（所谓名义利率的零下限），但实体经济名义投资回报率却可以是负的。所以当名义投资回报率下降到了0以下之后，常规货币政策对实体经济就无能为力了。
  summary: |
    解决"利率降到零后货币政策为何失效"的问题。核心逻辑：持有现金的选项使名义利率存在0附近的下限；而实体名义投资回报率=真实回报率+通胀预期，通缩或投资过剩均可使其为负。一旦融资成本无法降到回报率之下，宽松便无法刺激融资，货币需求弹性无穷大——即凯恩斯流动性陷阱。货币政策因此不对称：收紧（缰绳拉马）总能奏效，宽松（缰绳推马）在零下限处失灵。用法：判断常规宽松还有无空间，就看名义投资回报率与零下限的相对位置。
  tags: [流动性陷阱, 零下限, 货币政策不对称]
