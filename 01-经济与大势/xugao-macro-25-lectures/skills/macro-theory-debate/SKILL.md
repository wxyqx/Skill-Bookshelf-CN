# 宏观理论之争：新古典综合 vs 非正统——世界观考古与理论选型

> 来源：徐高《宏观经济学二十五讲：中国视角》第23-24讲

---

## R：原理（Rationale）

当代宏观经济学是两大阵营之争，争的不是技术细节，而是对"市场力量"的世界观。世界观是先行于观察的有色眼镜：

> 原文引用：「世界上最难打破的墙，是我们根本就没有意识到的墙。」（23.1）

### 正统阵营：新一新古典综合（信市场）

一句话世界观：

> 原文引用：「经济是一个被掺了沙子的市场体系。」（23.1）

其结构是"有效市场内核 + 短期摩擦"三层：

1. **最深内核——萨伊定律**：供给创造自己的需求，需求不会成为长期瓶颈。
   > 原文引用：「生产的目的不是生产，而是为了满足生产者的需求。」（23.2.1）
   现代教材不再讲萨伊定律，但其精神内嵌在拉姆齐模型中（鲁滨逊经济等价）。
2. **需求面结构——欧拉方程排除消费不足**：消费/储蓄由跨期优化决定，储蓄只是手段。
   > 原文引用：「储蓄只是在未来获取消费的手段，消费才是消费者最终的目的。」（23.3.3）
   在此结构上不存在消费不足、储蓄过剩的空间——新古典观察者对中国消费不足"视而不见"，不是看不见数据，而是框架里没有这个位置。
3. **波动二分与政策观**：波动分两类——产出缺口冲击（需求侧，政策应对有效）与潜在产出冲击（供给侧，经济已最优调整）。
   > 原文引用：「周期性的宏观政策应该对第一类冲击做出反应，但应该对第二类冲击保持沉默。」（23.3.1）
4. **长期增长——供给面唯A论**：生产函数 y=AF(k,l) 中只有外生的技术水平A能持续推高人均收入；财政货币政策只是周期工具，够不着长期轨迹。

### 非正统阵营：需求不足论传统（疑市场）

由魁奈、马尔萨斯、马克思、凯恩斯到剑桥学派组成的松散同盟，共同内核只有一条：否认萨伊定律、对市场自动出清心存疑虑。

> 原文引用：「它们最主要的共同点在于它们都不接受新一新古典综合（及其古典前身）的框架。」（24.2）

1. **有效需求二成分（源头在马尔萨斯）**：需求=购买力×购买愿望，而购买力分布取决于收入分配。
   > 原文引用：「有效需求由两个成分构成，即购买力和购买愿望」（24.2）
   需求不足不是心理问题（欲望无穷），而是分配结构问题。
2. **卡尔多定律——宏观反馈回路**：微观上收入决定支出，宏观上某些部门的支出反过来变成自己的收入。
   > 原文引用：「资本家挣到他们所花的，工人花掉他们所挣的。」（24.2）
   这是把家庭"量入为出"逻辑套到国家财政之所以是层次错误的原因，也是乘数与财政赤字创造需求的机制。
3. **剑桥模型（香蕉图）——需求的正反馈**：利润正比于投资（剑桥方程），预期自我放大，经济有高、低两个稳态，低水平稳态不稳定如刀锋——经济要么收敛于繁荣，要么滑入自我强化的收缩，而非围绕趋势波动。
4. **推论——需求约束经济中政策须长期托底**：产能过剩、需求不足时不存在自动回稳机制，放任下滑只会让下滑力量自我强化直至危机。

### 元镜片：如何裁决两派

1. **思想史的正反合**：古典（正）→凯恩斯（反）→新古典综合（合）；凯恩斯主义（正）→卢卡斯/哈耶克（反）→新一新古典综合（合）。思潮是对重大事件的反应（大萧条、滞胀、次贷危机），不是随意时尚。
2. **价量相关性判别法**：把微观价量判别推广到宏观——增速与通胀正相关指示需求面主导（该用凯恩斯工具），负相关指示供给面主导（该用古典工具）。
   > 原文引用：「市场中的交易量和交易价格如果同向变化……表明市场波动的源头是需求」（23.2.4）
3. **分岔钥匙在"市场信仰"**：
   > 原文引用：「是否相信存在需求不足，关键在于是否相信市场的力量。」（24.2）
   需求不足在逻辑上不是经验问题而是前提问题——先定位一个人对市场有效性的隐含信任度，多数宏观争论即已解出。

## I：指令（Instruction）

面对任何宏观理论、流派主张或学者的政策论证，按四步操作：

### 第一步：世界观考古——先问信不信市场
- 其框架是否隐含萨伊定律式假设（供给自动创造需求）？是否隐含所有储蓄由在乎回报率的消费者做出（欧拉方程结构）？
- 若信市场力量 → 正统阵营：预期其否认持续性需求不足、主张政策只管短期、长期只认供给面。
- 若疑市场力量 → 非正统阵营：预期其从收入分配结构找需求问题、允许政策长期发力。
- 两位经济学家的中国政策分歧，多半在第一步就已注定——先定位双方的隐含信任度，再看表面论据。

### 第二步：数据检验——用价量相关性等判据测适用性
- 算增速-通胀相关性：正相关（价量同向）→ 需求面主导，正统框架的"政策保持沉默"失灵；负相关 → 供给面主导，古典工具有效。
- 查摆荡形态：经济是围绕潜在产出小幅波动（符合新古典），还是在过热/过冷两极长期摆荡、无法稳定于中间区域（符合剑桥模型正反馈）？
- 中国的经验特征：增速-通胀同向、产能过剩与"一放就活、一活就乱"的活乱循环——指向需求约束型经济。

### 第三步：教条套用检查——识别"致命自相矛盾"
- 检查论证者是否承认"中国与框架所描述的世界不一样"，却又用该框架的结论批评中国政策——中国的不同本身就证明了框架的边界，这是逻辑死结。
- > 原文引用：「既然中国的状况与新一新古典综合明显有差异，又怎么能用新一新古典综合的结论来批评中国的宏观政策呢？」（23.4）
- 任何引用主流结论分析中国之前，必须先论证其前提条件在中国成立。

### 第四步：按需选工具——为问题选锤子，而不是拿锤子找钉子
- 先过三问：理论的**前提假设**是什么？**应用边界**在哪？眼前问题的条件是否落在边界内？
- > 原文引用：「在我们分析现实世界时，一定要追问自己借助的理论有什么样的前提假设，应用的边界在什么地方」（24.4）
- 分工：市场机制基本健全、供给面主导的经济 → 正统框架（波动二分 + 供给面长期增长）够用；产能过剩、需求自我强化的经济 → 非正统框架（需求正反馈 + 活乱循环 + 政策长期托底）。
- 工具箱多元主义：目标不是选边站，而是让每套框架管自己擅长的那段——只握一把锤子的人，看什么都是钉子。

## A1：应用场景一 — 书中案例：中国债务危机论的推论与失灵

**问题**：中国债务规模这么高，会不会爆发债务危机？（23.4）

1. **推论从哪来**：做世界观考古——"中国必爆发债务危机"正是新一新古典综合框架的推论：在储蓄者在乎回报率的框架里，债务规模过高必然让储蓄者停止借贷、危机爆发。
2. **前提在中国成立吗**：不成立。中国的高债务源于储蓄过剩的经济结构，且相当一部分储蓄者（国企、融资平台）存在预算软约束、未必在乎回报率——"储蓄者用脚投票"的机制不存在。
3. **错误药方的后果**：结构未改前强行抑制债务扩张，只会让实体经济失去稳定；压制"债务向国内投资转化"反而催生规避监管的新资金通路，酿成金融乱象——乱象是抑制政策与结构未改的派生物，不是独立病灶。
4. **对照案例（活乱循环）**：中国数十年在过热/过冷间摆荡、无法稳定于中间区域，与"围绕潜在产出波动"的新古典世界观不符，却与剑桥模型的高低稳态+刀锋正反馈吻合——宋国青比喻：宏观政策是把乒乓球击打回中间区域的两个拍子。由此裁决：解释中国样态，剑桥模型更贴切。

## A2：应用场景二 — 未来触发：两类高频争论

**场景1："某经济学家说，中国经济该出清了，阵痛忍忍就过去"——怎么判断？**
1. 考古：出清崇拜隐含市场自动出清假设 → 正统阵营的推论。
2. 检验：中国价量同向、产能过剩、活乱循环——需求约束型特征明显，"放任下滑迎来自动平稳"的前提不在场；放任下滑只会触发正反馈收缩。
3. 查自相矛盾：若其承认中国结构特殊、仍用出清逻辑开药方，即第三步的致命自相矛盾。
4. 选工具：需求约束期政策托底是长期职责，不是短期应急；根治靠结构改革而非更好的调控。

**场景2："供给侧还是需求侧？"——立场之争如何裁决？**
1. 先定性后开方：这是对潜在产出（供给）的冲击，还是对产出缺口（需求）的冲击？定性决定应对方式，定不准时明示不确定性。
2. 用价量相关性等数据辅助定性，而不是先选立场再找论据。
3. 注意框架内规则：长期增长只认技术水平A（研发、改革提效率），别指望需求管理改变长期轨迹——除非经济处于需求约束状态，那才是非正统框架接管的地界。

**与相邻 skill 的区分**：
- 与 `six-levels-thinking`：本 skill 处理**理论流派之争**（信不信市场、用哪套模型），六层思维处理**观点的认识层次**（一篇中国评论处在唯GDP到道路自信的第几层）。同一个"该出清"主张，本 skill 考古其理论出身（萨伊定律），六层思维定位其认识层次（第二层天真的市场派）——两问可以连问，但不可互相替代。
- 与 `second-best-transition`：本 skill 管**理论内容**（哪套宏观世界观为真、适用边界在哪），次优转轨管**转轨方法**（约束未消除时怎么改革、阵痛信号怎么处理）。问"新古典药方对不对"用本 skill；问"改革该怎么推"用次优转轨。

## E：边界与反例（Edge Cases）

### E1：教条式套用的"致命自相矛盾"
- 承认中国与框架不符、却用框架结论批评中国——作者点名的逻辑死结，且危险性极高：
- > 原文引用：「这种对新一新古典综合的教条式运用已经成为中国经济在次贷危机之后面临的最大风险。」（23.4）

### E2：成为体系的奴隶
- 不了解所依凭体系的来龙去脉与边界，就会把镜片折射的幻象当现实。
- > 原文引用：「否则自己就会成为体系的奴隶，把镜片所折射出来的幻象也当成了现实。」（23.4）
- 自查信号：从未尝试用对立框架解释同一现象、把教科书结论当先验真理。

### E3：RBC 式荒谬解释——拟合成功不等于解释为真
- RBC 模型能逼真模拟宏观动态，却推出"失业是工人在劳动与闲暇间的最优选择"：
- > 原文引用：「没有人会相信大萧条时期美国25%的失业率是因为美国工人嫌工资低，主动休假所造成的。」（23.2.3）
- 教训：模拟逼真与因果为真是两回事；过于理想化的假设在极端事件前现形。

### E4：方法导向的堕落——以可解性选问题
- > 原文引用：「以模型是否能够求解、易于求解来作为自己建模的重要考虑。」（24.1）
- DGE 时代研究选题被求解难度反向筛选，学科对真实世界的鲜活重要问题视而不见——警惕"方法筛选问题"的倒挂（包括在自己领域）。

### E5：锤子乱砸——单一框架暴力解释一切
- > 原文引用：「而不至于用锤子乱砸一气，把屋子砸塌了也不知道为什么。」（24.4）
- 诊断分析失败时先查是否工具错配（用A理论的标准审判B结构的现实），而非执行不力。

### E6：论域张力提醒
- 第23讲是在框架**内**陈述正统政策观（政策只管短期），第24-25讲是在框架**外**质疑其对中国的适用性——这是论证的层次递进，不是作者自相矛盾；引用时须分清论域。

## B：适用边界（Boundary）

### ✅ 适用场景
- 判断某个理论、某位经济学家的主张属于哪个流派、隐含什么世界观
- "中国适合哪套宏观理论"的理论选型问题（用价量判据+摆荡形态裁决）
- 宏观思想史问题（凯恩斯vs古典、理性预期革命、次贷危机对正统的挑战）
- 中国政策辩论（出清、刺激、供给侧vs需求侧）的"世界观考古"层
- 为具体分析挑选宏观工具时的前置检查

### ⚠️ 谨慎使用
- 流派定位只是起点：选对框架不等于论证完成，具体分析仍要落到具体模型（均衡求解、消费储蓄、货币传导等各归其位）
- 剑桥模型是 ad hoc 模型（预期外生、未过卢卡斯批判），作者以此为自觉代价换取新古典装不下的洞察——用它解释中国可以，当普适真理不可以
- 非正统不是统一体系，只是"疑市场"的松散同盟——不要把马尔萨斯、马克思、剑桥学派的观点混为一谈
- 第23讲与第24-25讲论域不同，勿把作者的框架内陈述与框架外批判读作立场摇摆

### ❌ 不适用场景
- 给一篇中国经济评论做认识层次定位、评价论证水平 → 用 `six-levels-thinking`
- 转轨策略选择、改革阵痛处理、次优条件分析 → 用 `second-best-transition`
- 消费不足的机制诊断与政策设计 → 用 `china-underconsumption`
- 非中国语境的教科书宏观技术问题（模型求解、数据查询）→ 各对应技术 skill
- 用"流派站队"代替论证本身——考古完世界观，活还得模型干

## 关联 Skill

- `six-levels-thinking`（上游元框架：理论之争背后的认识层次谱系；六层思维的理论底座即本 skill 的两派之争）
- `second-best-transition`（平行的转轨方法框架：本 skill 裁决理论内容，它裁决约束下的改革路径）
- `china-underconsumption`（本 skill 最重要的下游实例：需求不足论在中国的具体化——欧拉方程排除消费不足 vs 分配结构决定购买力）
- `price-quantity-diagnosis`（本 skill 第二步的核心数据工具：价量相关性判别供需约束）
