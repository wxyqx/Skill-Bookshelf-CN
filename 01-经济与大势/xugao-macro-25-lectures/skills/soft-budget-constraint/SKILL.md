# 预算软约束分析：刚性兑付与挤出

> 来源：徐高《宏观经济学二十五讲：中国视角》第16讲

---

## R：原理（Rationale）

徐高用软约束博弈解释"为什么低回报项目反而能挤占高回报项目的融资"。

### 1. 软约束的生成机制（Dewatripont-Maskin 式博弈）
政府项目（基建）有不可货币化的外部性 E，项目失败后政府出于社会总收益必然再融资兜底；项目好坏是项目经理的私人信息，兜底预期让本不该启动的"坏"项目也伪装启动——软约束是激励结构的均衡结果，不是态度问题。
> 原文引用：「政府的补贴带来了预算软约束问题——项目的投资者可以不为自己的失败买单。」（16.2）

### 2. 政府行为三条件（软约束为何顽固）
- **事后再融资条件**（F+E−1>L）：项目上马后救助优于清算，兜底必然发生；
- **事前不经济条件**（F+E<2）：明知社会总收益覆盖不了两轮融资，项目本不该上马；
- **政府参与条件**：若政府承诺不救，连"好"项目也无人启动，外部性全失——政府无法退出博弈。
> 原文引用：「……做出不给失败项目提供再融资的承诺，也是一个"不可信的威胁"。」（16.2.2）

### 3. 挤出链条：无风险利率被抬升 → 利率不敏感者挤出敏感者
隐性担保让城投债在投资者眼中近乎无风险，其高票息成了事实上的无风险利率基准；无风险利率被抬高后，有风险的民企债只能在此之上再加风险溢价。软约束主体对利率不敏感（反正有人兜底），占比越高，融资需求弹性越低，利率越难向与实体利润率匹配的"合适水平"回归。
> 原文引用：「当无风险利率被城投公司推升到这个高位时，民营企业发债就需要付出更高的利息率。」（16.4.1）

### 4. 化解之道：财政接权 + 金融卸责（改革次序）
市场高效运行的前提是参与者对自己的决策百分之百负责，软约束打破了这个前提；利率市场化的前提因此是消除软约束。政府项目的外部性归财政（发国债）承担，融资平台从金融市场剥离；金融端（打破刚兑）只做配套。
> 原文引用：「利率市场化改革的前提应当是消除金融市场中预算软约束的存在。」（16.4.1）
> 原文引用：「在财政没有承担起自己应该承担的这个责任时，清理融资平台就只能是按下葫芦起了瓢。」（16.4.1）

## I：指令（Instruction）

分析融资市场扭曲/利率异常/民企融资问题时，按四步走：

### 第一步：识别软约束主体
- 两个观察标志：**事前不划算仍上马**（回报覆盖率低于融资成本还在扩张融资）、**事后必被救助**（有政府隐性担保、违约预期极低）。
- 常见对象：地方融资平台/城投、有兜底预期的部分国企。注意算"广义回报"：微观 ROA 低不等于社会回报低，外部性未货币化会压低账面回报。

### 第二步：用政府行为三条件检验软约束是否成立
1. 事后救助是否优于清算（救助必然发生）？
2. 事前社会总收益是否覆盖不了全成本（本不该上马）？
3. 政府是否因外部性而无法退出（不救会连好项目也扼杀）？
- 三条同时满足 → 软约束成立，且靠"表决心、立规矩"消除不了——任何只改变表态、不改变事后激励的政策都是不可信威胁。

### 第三步：分析挤出
- 路径：隐性担保 → 城投债变成"无风险资产" → 其票息抬高无风险利率基准 → 真有风险的融资者须再叠风险溢价 → 融资成本全面上升。
- 关键不对称：软约束主体**对利率不敏感**，利率再高照借；利率敏感的民企在高利率下退出——**利率不敏感者挤出敏感者**。紧缩（供给收紧、利率上行）反而会提高软约束主体在融资中的占比：市场纪律不是淘汰劣者，而是奖励劣者。

### 第四步：政策定位——财政接权 + 金融卸责
- **财政接权**：项目外部性归财政，用国债承担初始融资与再融资，把平台从金融市场剥离（地方债置换即此思路）。
- **金融卸责**：打破刚兑只作配套，且必须与剥离平台兜底**同步**；违约风险的分布要问"落在谁头上"。
- 警惕"只破不立"的走样：只压金融端融资、财政责任不接手 → 基建融资与货币传导同时被阻塞，扭曲换个地方冒头。

## A1：应用场景一 — 书中案例：城投债与产业债倒挂、超日债违约

**案例一：城投债与产业债利率倒挂**（16.1）
- 2014年城投公司平均总资产回报率不足3%，发的城投债平均票息率却超过6%——回报覆盖不了利息，仍在加速融资（2013年初至2014上半年城投债发行量明显超过产业债）。
- 机制：隐性担保使城投债在投资者眼中近乎无风险，低回报者凭软约束挤出高回报的产业公司，尤其钱荒后利率上扬期间挤出更甚——市场把更多钱配置给了低效主体。

**案例二：超日债违约——打破刚兑的代价先落在民企头上**（16.4.3）
- 2014年3月超日债成为中国债市第一只实质性违约债券；打破刚兑的呼声没动摇有政府兜底的城投，却率先在民企身上兑现。
- 后果：违约集中于民企使其风险溢价上升，投资者转而更追捧城投债——名义上中性的改革在软约束环境下非中性，民企被挤出得更严重。
- 政策链印证：43号文压城投（方向正确）→ 财政责任未接上 → 传导阻塞催生堰塞湖 → 2015年起地方债置换（财政接手）——"金融端清理 → 传导阻塞 → 财政端接权"的完整演化。

## A2：应用场景二 — 未来触发场景

**场景一："打破刚兑为什么先违约的是民企？"**
1. 推演：刚兑的实质是谁被保护——软约束主体（城投）受稳增长逻辑保护，打破刚兑的执行只能落在无兜底的民企头上；违约集中民企 → 风险溢价上升 → 资金涌向城投，挤出加剧。
2. 诊断问题不是"该不该打破刚兑"（该），而是"违约风险实际落在谁头上、兜底是否同步剥离"。
3. 与 **china-debt-financial-chaos** 的区分：那里管**债务总量与宏观图景**——杠杆率会不会崩、债务膨胀的猫鼠博弈生成机制、债权方行为修正；本 skill 管**微观激励结构**——钱在融资市场上被谁、以什么机制分错。问"债务炸弹会不会爆"→ chaos；问"谁挤出了谁、为什么利率失灵"→ 本 skill。

**场景二："融资贵的原因是什么？"**
1. 推演：利息归根结底来自实体利润，利率本应向"合适水平"（与通胀、产出匹配）回归；回归机制的前提是融资需求对利率敏感。软约束主体利率不敏感、占比上升 → 需求曲线失去弹性 → 利率长期高于合适水平且难回落。书中用费雪方程式式计量模型验证：2013下半年至2014十年期国债收益率长时间高于拟合的合适利率，恰是融资贵最烈的时期。
2. 归因纪律：不笼统归咎"央行放水太多"或"银行贪利"，去查融资主体结构（软约束占比）。
3. 与 **monetary-transmission-blockage** 的区分：那里管**总量传导**——央行放的水能不能到实体、堰塞湖淤在哪、资产价格为何反常；本 skill 管**结构配置**——到了金融市场的钱在软约束与硬约束主体之间怎么分错。43号文压城投引发堰塞湖属 blockage；城投抬高无风险利率挤出民企属本 skill。与 **china-monetary-practice** 的区分：那里讲央行操作与利率市场化"怎么做"（政策工具与进程），本 skill 讲利率市场化"该先做什么"（前提诊断）。

## E：边界与反例（Edge Cases）

### E1：放开利率管制 ≠ 利率市场化大功告成
- 判据不是"管制取消"而是**配置结果**：自由浮动的利率能否引导资金流向回报更高的企业。软约束未消除时放开价格，低回报城投凭隐性担保挤压高回报民企，效率不升反降。
- 同理警惕"市场化=放开价格管制"的教条：市场高效运行需要前提（参与者对决策百分之百负责等），前提缺失时放开价格是"劣币驱逐良币"。

### E2：打破刚兑 ≠ 必然理顺金融市场
- 打破刚兑方向正确，但在城投受保护、违约落在民企头上的环境里，效果适得其反。评估此类政策先问：违约风险的分布变了吗？平台兜底剥离了吗？

### E3：城投 ≠ 庞氏骗局，"压掉就行"是误诊
- 城投回报率低是因为回报大量体现为不可货币化的外部性，微观账本低估了社会回报；金融扭曲的根源在财政制度，不在城投本身。
- 只压融资不接财政责任 = "按下葫芦起了瓢"：扭曲不会消失，只会换个地方冒头（堰塞湖、明股实债、隐性负债）。

## B：适用边界（Boundary）

### ✅ 适用场景
- 解释民企/国企融资条件差异、"融资贵"的成因与顽固性
- 评估城投债、地方债、融资平台政策与打破刚兑类改革
- 判断利率市场化改革的成效与次序（先硬化约束、后放开价格）
- 预测紧缩/去杠杆期融资结构变化（软约束占比上升、挤出加剧）

### ⚠️ 谨慎使用
- 城投/国企并非铁板一块：软约束是"预期结构"不是所有制标签，需逐类主体检验三条件
- 微观 ROA 低不等于项目无价值——先核算含外部性的广义回报，再下"低效"判断
- 软约束只是利率决定的一个因素，短期利率方向还取决于传导顺畅度（配合 monetary-transmission-blockage 使用）

### ❌ 不适用场景
- 债务总量、杠杆率与债务危机的全景判断（用 china-debt-financial-chaos）
- 央行放水到实体的传导阻塞与资产价格（用 monetary-transmission-blockage）
- 央行具体操作工具与利率市场化进程本身（用 china-monetary-practice）
- 非中国的融资市场问题（模型是普适的，但本 skill 的案例与政策诊断绑定中国语境）
