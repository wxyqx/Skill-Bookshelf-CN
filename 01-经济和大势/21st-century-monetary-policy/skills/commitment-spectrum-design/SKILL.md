# 承诺设计光谱——时间依赖 vs 状态依赖、门槛≠触发

## R — 原文 (Reading)

> 重要的是，这些新的、更明确的条件只是门槛，而不是触发因素，投资者和外部评论人士有时似乎忽略了这一区别。我们并没有说当失业率降到6.5%时一定会提高利率……
>
> — 本·伯南克，第七章《货币政策的演化：QE3和缩减恐慌》

---

## I — 方法论骨架 (Interpretation)

对外承诺"未来将如何行动"有两种结构，各配一种适用条件。**时间依赖承诺**（"至少到某日为止"）简单直接、冲击力强，适合需要戏剧性扭转预期的场合；但它在写下那一刻就固定了对未来的预测——预测错是常态，于是你被困在两难里：遵守承诺就是执行错误政策，修改承诺就是公开承认失效，每次顺延都是一次信誉损耗。书中称之为"日历绑架"（2012年"至少到2014年底"随后被顺延到2015年中）。

**状态依赖承诺**（"失业率回到6.5%之前不考虑加息"）把校准外包给可观察指标，自动吸收预测误差，无需公开改口；代价是触发条件容易被误解。为此必须区分**门槛与触发**：门槛是"启动评估的条件"，触发是"机械执行的开关"。"失业率降到6.5%之前不考虑加息"只排除了过早紧缩（单侧排除），绝不承诺到点必加——发布时若不显式声明这一点，市场就会把下限当按钮定价，事后偏离即是意外。

选型判据：预期严重脱锚、需要确定性冲击时选时间式；正常波动期、需要自我校准时选状态式。

## A1 — 书中的应用 (Past Application)

### 案例 1: QE3 的失业率 6.5% 门槛（时间→状态的转向）
- **问题**: 前瞻性指引从"至少到2013年中"式日期承诺不断顺延，信誉持续损耗。
- **方法论的使用**: 2012年12月采纳埃文斯方案——失业率高于6.5%且通胀预测≤2.5%之前维持近零利率；伯南克专门公开澄清"只是门槛不是触发"，预留双向解释空间。
- **结论**: 状态承诺自动随经济校准，消除日历绑架。
- **结果**: 指引奏效，实际加息拖到失业率5%才发生（说明门槛本可更有力）；但"门槛与触发被市场混淆"的隐患在2014年暴露，被迫重新设计。

### 案例 2: 时间依赖承诺的顺延代价（反面对照）
- **问题**: 2012年1月承诺"至少到2014年底"后，经济持续不及预期。
- **方法论的使用**: 只能再次顺延"到2015年年中"——每次顺延都是"承诺失效"的公开确认，还给"永远宽松"的批评供弹药。
- **结论**: 日期承诺把预测误差变成信誉事故。
- **结果**: 直接推动向状态依赖指引切换。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 向董事会/市场承诺"何时恢复分红/回购/发版"，纠结用日期还是用条件，担心业务波动时被自己的数字绑架。
2. 对客户设计SLA/服务承诺/价格保护条款：想给确定性又不想在极端情形下被机械条款反噬。
3. 设计任何"到某条件就自动如何"的公开规则（升级机制、退出条款、恢复条款），需要判断该写成门槛还是触发。
4. 直接问书中场景：时间依赖与状态依赖指引的区别、6.5%门槛到点后为什么没加息。

### 语言信号 (用户的话里出现这些就应激活)

- "定日期还是定条件 / 承诺到什么时候 / time-dependent / state-dependent / calendar-based"
- "会不会被数字绑架 / 到点必须执行吗 / 门槛 / 触发 / threshold vs trigger"
- "承诺怎么写才不会被反噬 / SLA / 恢复条件 / 到什么程度我们就动手"

### 与相邻 skill 的区分

- 与 `bounded-discretion-design` 的区别: 承诺光谱管**单次承诺的结构参数**（时间/状态、门槛/触发）；有限制的自由裁量权管**整个决策制度**的规则-相机平衡。前者是写一个条款，后者是立一部宪法。
- 与 `guidance-credibility-design` 的区别: 承诺光谱管承诺的**结构**；guidance-credibility-design 管指引的**类型选型**（德尔菲式告知预期 vs 奥德赛式约束承诺）与可信度四支柱。先由后者判断要不要承诺，再由本 skill 设计承诺长什么样。
- 与 `signal-engineering` 的区别: 本 skill 管承诺写什么（结构），后者管承诺怎么发布（形式）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断预期状态**
   - 完成标准: 判断对方预期是否严重脱锚（已按"永不恢复/永远宽松"类极端假设定价）。脱锚→时间式给确定性；正常波动→状态式。写出判断依据。

2. **按形式设计承诺结构**
   - 完成标准: 时间式须附预测误差的应急说明（防止日历绑架）；状态式须选定可观察、不可操纵的指标与数值，并写出"为什么是这个数"（如6.5%对应当时的评估）。

3. **门槛/触发声明（状态式必做）**
   - 完成标准: 显式声明承诺的单侧排除性质——它排除什么（如过早紧缩）、不承诺什么（如到点必动作），并给出"到点后实际怎么决策"的一句话说明。禁止只给数字不给解释。
   - 判停条件: 若对方明确要求刚性机械执行（要的就是触发器而非门槛），确认其理解后果后按触发器设计，并说明不可逆风险。

4. **双向解读预演**
   - 完成标准: 预演两种情形的解读——指标先到（市场会不会当成按钮）与指标迟迟不到（承诺会不会被读成失效），各配口径预案；检查是否需要免责条款或故意留白。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方要求的是刚性、不可协商的机械条款且你完全能控制结果（如内部自动扣款规则）：无需光谱设计，直接写触发器即可。
- 承诺内容找不到任何可观察的状态变量，且日期也不可预测：两种形式都不成立，应改用条件式留白（"视情况评估"）并说明其代价。
- 问题是要不要做承诺（承诺的增量价值判断）：转 guidance-credibility-design。

### 作者在书中警告的失败模式

- **门槛被当按钮**（第七章、ce12）：量化的状态条件被市场机械读成"到点必动作"，实际行动远滞后于门槛值，措辞精确性反而制造新的沟通债务。
- **日历绑架**（第七章、ce10）：日期承诺反复顺延直至透支，每次顺延都是承诺失效的公开确认。
- **缩减恐慌的连带教训**（第七章、ce11）：开放式承诺的心态与内部犹豫外泄叠加，说明承诺设计必须先在内部对齐口径。

### 作者的盲点 / 时代局限

- "门槛≠触发"的区分连专业投资者都会弄错（作者自己承认），说明该设计对受众有内生的高要求；作者未给出更鲁棒的措辞方案（如双列声明"本条件排除什么/不承诺什么"的标准化格式）。
- 2021年后状态依赖承诺与FAIT非对称框架的互动（预期脱锚时状态条件如何失效）在书成时尚未复盘；R*与u*等门槛所依赖的不可观测参数的漂移风险，书中仅在"凭星导航"处间接承认。
- 自辩色彩：对"到点不加息"造成的2014年预期混乱，归因偏向市场误读而非门槛设计的局限。

### 容易混淆的邻近方法论

- `bounded-discretion-design`：单次条款 vs 制度宪法，见 A2。
- `guidance-credibility-design`：结构设计 vs 类型选型与四支柱，见 A2。
- `signal-engineering`：写什么 vs 怎么发，见 A2。
