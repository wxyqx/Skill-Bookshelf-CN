# 德尔菲/奥德赛指引二分与可信度四支柱

## R — 原文 (Reading)

> 介绍了"德尔菲式前瞻性指引"和"奥德赛式前瞻性指引"之间的区别。……德尔菲式指引……的目的只是告知、帮助公众和市场更好地了解决策者对经济前景的展望和政策的临时计划。
>
> — 本·伯南克，第十一章 2008年之后美联储的工具箱

---

## I — 方法论骨架 (Interpretation)

任何"我们未来会怎么做"的公开沟通，先分两种类型：德尔菲式是**告知预期**——公布你对形势的判断和临时计划，任何时点都有用、几乎无副作用；奥德赛式是**约束承诺**——主动绑住自己未来的手脚来移动对方预期。后者的增量价值只在一个特定状态下存在：对方预期已经脱锚、且你恰好需要把预期往某个方向拉（书中场景是利率触及有效下限时拉低市场对未来利率的预期）。不在这个状态，承诺只有成本没有收益。

奥德赛式承诺有个内置两难：写得越具体越可信，但越难应对意外。所以实务上通常配免责条款和故意留白。

承诺凭什么被相信？四根支柱：可核验的措辞（能事后对账）、机构声誉（前任的承诺也算数）、共识性框架（个案承诺嵌在公认规则里而非拍脑袋）、独立性（说话的人有兑现的自由）。发布之后，用对受众的直接调查验证预期锚是否真的移动——不能只看资产价格，价格里混着太多别的信息。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2013年缩减恐慌——奥德赛式承诺的可信度前提崩塌
- **问题**: 开放式QE3需要"不离不弃"的承诺心态，2013年5月22日伯南克在国会证词中暗示"接下来某次会议可能放慢购债"，到9月10年期国债收益率上升整整1个百分点，新兴市场"脆弱五国"遭溢出冲击。
- **方法论的使用**: 事后归因发现承诺的可信度支柱先塌了——委员会内部对QE成本收益的分歧被市场察觉，任何含糊措辞都被按最不利方向解读；同时市场情报渠道单一（一级交易商调查），造成"预期已对齐"的虚假确认，事前没发现预期根本没对齐。
- **结论**: 言行一致性比信息精确性更根本；奥德赛式承诺在内部分歧外泄时必然失效，缩减标准一开始就该精确量化。
- **结果**: 9月被迫意外按兵不动，12月才正式减速；教训直接塑形了耶伦"油漆干燥"式缩表设计与鲍威尔对缩减的前置铺垫。

### 案例 2: 第十一章的工具箱系统评估
- **问题**: 伯南克离任后系统复盘非常规工具哪些有效、哪些名不副实。
- **方法论的使用**: 把前瞻性指引拆成德尔菲/奥德赛两型分别评估——德尔菲式（公布预测与计划）低风险常态化使用；奥德赛式（"至少到2014年底""失业率6.5%之前不加息"）在有效下限处贡献显著，但每次兑现偏离都累积沟通债务。
- **结论**: 奥德赛式是特定状态下的重武器，不能当日常沟通用；四支柱是其成立前提。
- **结果**: 这一二分成为学界（埃文斯等）与美联储评估自身沟通的标准分类学。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创始人/项目负责人要发布未来路线图或经营预测，纠结该给"确定性日期"还是"描述条件"，以及这话被市场/团队记住后兑现不了怎么办。
2. 组织处于信任受损期，有人提议用"永不裁员""无限期支持"式的强承诺稳住人心，需要评估这类承诺的增量价值与刚性成本。
3. 用户困惑"我们明明公布了计划，为什么对方预期根本没动"——需要检查承诺可信度的前提而非加大音量。
4. 设计某机构（央行/平台/行业协会）的政策沟通框架，需要一套"承诺何时可信"的核查清单与发布后的验证方法。

### 语言信号 (用户的话里出现这些就应激活)

- "预期脱锚""市场/团队不相信我们的承诺"
- "前瞻指引""forward guidance""德尔菲""奥德赛"
- "该不该承诺""承诺会不会反噬""兑现不了怎么办"
- "预期锚没动""说了等于没说"

### 与相邻 skill 的区分

- 与 `commitment-spectrum-design` 的区别: f06 解决"承诺用什么形式写"（时间依赖/状态依赖/门槛≠触发）；本 skill 解决"该不该承诺、承诺凭什么可信"（类型选型+四支柱前提+发布后验证）。用户问措辞形式找 f06，问选型与可信度找本 skill。
- 与 `signal-engineering` 的区别: f04 是单次重大宣布的形式工程（戏剧性 vs 铺陈）；本 skill 是跨期承诺的可信度结构。宣布怎么做找 f04，承诺可不可信找本 skill。
- 与 `credibility-capital-management` 的区别: f03 管信誉资产的长期存取与折旧；本 skill 是单次指引沟通的设计与验证，是 f03 在沟通环节的实例化。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判型：告知预期还是约束承诺**
   - 完成标准: 明确输出"德尔菲式/奥德赛式"的选型及理由，写清这次沟通要改变对方的哪一项预期。
   - 判停条件: 若对方预期并未脱锚、常规信息发布即可，则停用奥德赛式——跳到步骤 4 走德尔菲式路线（书中结论：多数"强承诺安抚"场景的正确答案是德尔菲式）。

2. **查四支柱（仅奥德赛式）**
   - 完成标准: 可核验措辞、机构声誉（含前任承诺的继承义务）、共识性框架、独立性——每根支柱有具体证据或补强方案；任一支柱缺失即标记承诺高危。

3. **具体度校准**
   - 完成标准: 承诺文本明确标注哪些是硬承诺、哪些保留弹性（免责条款、留白）；同时检查内部口径是否一致——缩减恐慌的教训是内部分歧本身会被定价。

4. **发布后验证**
   - 完成标准: 用对受众的直接调查（问他们预期的变化）验证预期锚是否移动，而非只看资产价格反应；调查覆盖面要含非传统受众。

5. **归档到信誉账本**
   - 完成标准: 承诺内容与兑现记录写入组织的信誉资产台账，供下次承诺的可信度评估引用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯信息发布、数据解读、例行汇报——德尔菲式日常沟通不需要四支柱全套仪式，套用会把简单沟通复杂化。
- 对方预期并未脱锚时的"表态安抚"——书中明确结论是此时强承诺只有刚性成本（状态剧变无法兑现即摧毁声誉）而无增量价值。
- 用户问的是"宣布当天用什么形式"（signal-engineering）或"承诺写日期还是写条件"（commitment-spectrum-design）。

### 作者在书中警告的失败模式

- 内部分歧会被定价：公开措辞与委员会内部共识的模糊度不一致时，任何含糊都按最不利方向解读（2013年缩减恐慌，10年期收益率一个百分点量级重定价）。
- 市场情报失真：预期调查覆盖面窄于实际受众结构时，会产生"预期已对齐"的虚假确认——央行以为在传递小信息，市场听到的是立场反转。

### 作者的盲点 / 时代局限

- 书中主张"用调查直接验证预期锚"，但2013年恰恰因情报渠道单一而误判，作者把复盘止于"教训"，未解释为何事前没有执行自家验证纪律——自辩色彩。
- 2021年"暂时论"是德尔菲式沟通的失败（告知的预期本身错了），书中对该失误的复盘明显不足；对奥德赛式承诺的刚性成本仅以FAIT框架"受通胀考验"带过。
- 对 QE 成本侧的沟通责任（预期管理的边界）全书仅以"可控"概括，缺乏量化。

### 容易混淆的邻近方法论

- `bounded-discretion-design`：那是规则与相机抉择的制度总纲（目标+参照系+解释义务）；本 skill 是单次指引的选型与可信度工程，是总纲在沟通场景的落地。
