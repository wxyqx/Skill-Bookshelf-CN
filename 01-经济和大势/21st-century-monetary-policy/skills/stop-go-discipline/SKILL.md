# 决心原则：时断时续比不紧缩更糟

## R — 原文 (Reading)

> 这种"时断时续"的模式——在通胀飙升时收紧政策，但在失业率开始上升时又立即放松，结果被证明是无效的，并导致通胀和通胀预期逐步上升。
>
> — 本·伯南克，《21世纪货币政策》第二章

---

## I — 方法论骨架 (Interpretation)

门外汉的直觉是"做一半总比不做强""走走停停更稳妥"。本书给出一个反直觉的不对称判断：**摇摆比不作为更糟**。机制在于预期是前瞻的——公众从政策的历史模式而非当期宣言推断未来。一旦"紧缩必将在阵痛出现时被放弃"的模式被识别，所有定价都会按"紧缩不可持续"外推：每一次半途而废既消耗已投入的真实效果，又向所有人证明下次也会放弃，于是紧缩的边际效果递减而痛苦照付，两个目标同时落空。

三条操作纪律：

1. **检查触发器的性质**：方向反转的依据是"痛苦已发生"（失业率上升、业绩变难看）还是"目标已达成"（通胀回落、杠杆达标）？以前者为触发器的节奏必然构成时断时续。
2. **把拖延计为最大风险项**：在风险评估表中，"再等等"不是零成本的中性选项，而是与"行动风险"同列甚至更大的风险源——拖延本身制造本想避免的代价。
3. **以行动划界**：当施压使语言必然被解读为立场博弈时，坚持只能用行动表达。

## A1 — 书中的应用 (Past Application)

### 案例 1: 伯恩斯的"时断时续"与大通胀固化（1970s，反面）
- **问题**: 通胀抬头就紧缩、失业一升立即放松，尼克松施压之外，以"上一次的痛"为节奏的摇摆模式本身成为主因——尼克松辞职后伯恩斯仍未转向。
- **方法论的使用**: 反面印证：每次紧缩前都为退出找好政治台阶，紧缩的痛苦（失业）一出现触发器就启动放松，紧缩从不坚持到起效的时滞尽头。
- **结论**: 既没有实现低通胀，也没有实现持续的低失业——双目标尽失，通胀与预期螺旋上升至1979年的13%。
- **结果**: 伯恩斯1979年"央行的痛苦"演讲自我承认：在新的政治共识形成前央行无能为力——摇摆模式耗尽了机构的行动能力。

### 案例 2: 沃尔克的坚持到底（1979-82，正面）
- **问题**: 抗胀战役遭遇拖拉机围堵美联储总部、建筑商邮寄木板、1984年财长当面警告勿选举前加息、弹劾威胁——每一步都有充分理由"松一口气"。
- **方法论的使用**: 预先认定"犹豫不决和拖延本身就是最大风险"，不以上一次紧缩的痛苦为节奏，被施压时一言不发离场然后用继续加息划界。
- **结论**: 1981-82年失业率峰值10.8%是信誉的买价；坚持到紧缩的时滞兑现为止。
- **结果**: 通胀从约13%降至1982年的4%，此后整个任期通胀稳定，预期锚定带来数十年的"大稳健"红利。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 去杠杆/降本/改革推行数月，指标恶化、抱怨集中，团队与上级都在劝"先暂停缓一缓再说"。
2. 复盘时发现：上一轮收紧太痛导致放松，指标刚恶化又想再收紧——同一周期已出现第二次方向反转。
3. 一个周期性动作（加息、清库存、砍产品线）的启动条件总是"痛苦已发生"而非"目标已达成"。
4. 正确决定必然带来阵痛，说服材料里"再等等看"被当作零成本选项摆上桌。

### 语言信号 (用户的话里出现这些就应激活)

- "先松一口气再说 / 缓一缓再推进"
- "走走停停是不是更稳妥"
- "上一轮太痛了，这次要不要放松一点"
- "坚持还是暂停 / 半途而废 / stop-go"

### 与相邻 skill 的区分

- 与 `preemptive-strike-policy` 的区别: 那是行动启动时点的选择（要不要在证据确凿前提前开始）；本 skill 是行动开始后的中途纪律（开始了要不要坚持到底）。两者常在同一段叙事中出现（2021年既是放弃先发制人也是中途摇摆），但决策问题不同。
- 与 `credibility-capital-management` 的区别: 那是把信誉当资产做跨周期管理（存取核算、兑现前任承诺）；本 skill 聚焦一个具体摇摆决策的结构判断——什么时候"灵活"实际上是"时断时续"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定是否处于"半途而废诱惑点"**
   - 核对信号：阵痛是否已显现、劝停意见是否来自痛苦承受方、"缓一缓"是否被包装为中性选项。
   - 完成标准: 明确判断当前是"摇摆诱惑"还是正常的新信息评估，并给出依据。

2. **把拖延计入风险表**
   - 对"暂停/放松"选项计算拖延成本（预期脱锚、重来成本、模式被识别后的信誉折扣），与阵痛成本并列呈现。
   - 完成标准: 决策材料中"再等等"不再是无代价基准项，而是带量化或定性估计的风险源。

3. **检查反转触发器的性质**
   - 逐一列出本周期每次方向反转的依据，分类为"痛苦已发生"或"目标已达成"。
   - 完成标准: 若同一周期反转≥2次且触发器均为前者，明示已构成时断时续模式，纠正方向是改触发器而非微调节奏。
   - 判停条件: 若存在反转≥2次但每次依据均为"目标已达成/新信息"，则不构成摇摆，退出本 skill 纪律，按常规决策处理。

4. **把坚持写进公开承诺**
   - 将"坚持到底的条件（目标达成前不转向）"预先声明，压缩为退出找政治台阶的空间。
   - 完成标准: 存在可被外部检验的坚持声明，而非仅内部口头共识。

5. **遇施压以行动划界**
   - 对施压不辩论、不承诺，维持既定行动节奏；必要时以程序化输出（定期公开数据）替代回应。
   - 完成标准: 施压事件后行动路径未偏离；回应纪律（不评论、不人身回击）已执行。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 新证据证明当初的前提错了（成本是结构性的而非周期性的）——因数据而修正不是摇摆，此时"坚持"是固执不是决心；先做前提复核再谈坚持。
- 行动尚未启动、还在选时点——那是先发制人的问题域。
- 完全可逆、低沉没成本的小决策——摇摆的真实代价来自预期机制与重来成本，小事不构成。

### 作者在书中警告的失败模式

- 摇摆的预期固化机制（ce01）: 公众按政策历史模式外推，"紧缩必将被放弃"一旦被定价，紧缩边际效果递减而失业成本照付——警告信号：触发器是"痛苦已发生"、同周期两次以上反转、每次紧缩前先找退出台阶。
- 承诺反复修改的近亲（ce10）: 时间依赖承诺因经济不及预期被一次次顺延，每次顺延都是一次"承诺失效"的公开确认——日历绑架与时断时续共享同一信誉损耗机制。
- "等确凿证据再行动"的拖延陷阱（ce17）: 2021年"暂时论"把行动标准设为"观察到通胀证据"，而观察指标本身滞后于压力积累——拖延被误当作稳健。

### 作者的盲点 / 时代局限

- 对坚持的社会代价着墨不足: 沃尔克式坚持的10.8%失业率的分配效应（谁承担了"信誉的买价"）只用一句"买价"带过，决心原则在此缺乏成本公平性的约束维度。
- "耐心"与"拖延"的边界未给出可操作判据: 作者支持2020年的框架性"耐心"，又批判2021年的拖延——何时等是理性、何时等是时断时续的起点，书中没有给出现象出现前的判别标准（只有事后复盘）。
- 自辩色彩: 作者自身任内的中途调整（如2010-11年对宽松节奏的犹豫）未被置于同一"摇摆"标尺下检验。

### 容易混淆的邻近方法论

- "贵在坚持"的常识励志: 常识版本只有"要坚持"，本 skill 的价值在于不对称判断（摇摆比不作为更糟）与可检验的触发器标准——没有这两点会退化为说教。
- 敏捷迭代的"快速转向": 迭代场景中预期机制弱、重来成本低，转向是信息更新；本 skill 适用于预期敏感、沉没成本高、受众会为模式定价的场合。
