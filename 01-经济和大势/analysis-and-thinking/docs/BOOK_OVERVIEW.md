## 1. 结构 (Structural)

### 类型

政策方法论讲稿——比姊妹卷更聚焦**金融**（货币、资本市场、杠杆与风险），分析套路与姊妹卷同源（作者在后记自命名为"问题—结构—对策"）。

### 一句话主旨

金融是现代经济的核心，其本质是"为有钱人理财、为缺钱人融资，把握信用—杠杆—风险的度，为实体经济服务"——围绕这个本质，用"问题—结构—对策"的范式逐一拆解中国的杠杆、货币制度、资本市场、房地产与开放博弈问题。

### 骨架 (主要论点及其关系)

1. **杠杆与风险（第 1-3 讲）**：宏观去杠杆的病灶在企业负债 160%；金融乱象=六种杠杆工具叠加；P2P 是伪金融必须禁止，规范数字信贷有五原则
2. **货币制度（第 4-5 讲）**：货币制度的根本区别在"锚"；人民币现行汇兑本位制须转向有刚性纪律的主权信用货币制（四原则+三套锚）
3. **资本市场（第 6-7 讲）**：三大功能弱化的病根在基础性制度（九问题九建议），制度红利可对冲宏观杠杆
4. **房地产（第 8-9 讲）**：十大失衡的治理靠五大基础性制度与量化标尺（六分之一理论等），未来十年总量降档、模式换轨
5. **开放与贸易（第 10-12 讲）**：中间品贸易 70% 催生三零规则与 FTA（"第二次入世"）；驳贸易摩擦五谬论，做好自己的事
6. **底线与博弈（第 13-14 讲 + 附录）**：美国危机后移链条指向债务危机与金融战（2015 法案十大措施）；应对是人民币国际化五个蓄水池+补短板+盾牌；附录以浦东开发、钻石交易所等亲历案例示范制度设计

**论点之间的关系**: 并列中递进——六专题各自独立成讲，但都从"金融本质三句话"与"问题—结构—对策"两个元框架展开；资本市场与杠杆两讲互为对冲（做大股权融资=去杠杆）。

### 作者要解决的核心问题

明线：去杠杆背景下中国金融体系的风险诊断与制度改革路径。
暗线：示范"问题—结构—对策"的研究范式——找到问题的结构性短板，通过改变联系方式与边界条件使问题转化。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 问题—结构—对策 | 作者自述的核心研究范式：找问题结构性/体制性短板，改变联系方式与边界条件使其转化（后记） | 不是"提出问题分析问题解决问题"的作文套路；结构=体制机制制度短板 |
| 货币锚 | 货币发行的基础或储备，兼具支撑发行与约束规模两功能 | 不是汇率锚定专指；锚的选择定义整个货币制度 |
| 汇兑本位制 | 人民币现行制度的作者命名：外汇占款主导基础货币投放，实质间接锚定美元 | 非教科书术语；作者对"联系汇率与主权信用之间"状态的诊断标签 |
| 金融本质三句话 | 为有钱人理财为缺钱人融资；信用—杠杆—风险把握度；为实体经济服务 | 不是行业描述，是评判一切金融创新是否异化的三重检验 |
| 六种杠杆黏结工具 | 高息揽储、刚性兑付、资金池、错配、通道、嵌套——纵横组合拼出全部金融乱象 | 不是监管术语，是作者对乱象底层部件的归纳 |
| 三链 | 产业链集群、供应链纽带、价值链枢纽（结算点）；控制三链者即龙头 | 与姊妹卷同源；本书补充"结算枢纽即财富中心"（1.8 万亿加工贸易结算在境外） |
| 三零 | 零关税、零壁垒、零补贴——中间品贸易 70% 时代的 FTA 规则方向 | 不是 WTO 现行规则，是作者判断的规则演进方向 |
| GDP 1:1 标尺 | M2、政府债务、股市市值、房地产市值与 GDP 之比正常不超 1:1，1.5:1 严重泡沫 | 经验标尺而非定理；配三个参考比值（股市 100/150%、房地产 2:1/3:1、企业债务 1:1） |
| 债务三级上限 | 良性 70%、危机 100%、致命 150%（判据：付息+到期债务吞噬全年财政收入） | 不是国会法定上限，是作者的经济上限体系 |
| 五个蓄水池 | 人民币国际化的五条水道：跨境结算、本币互换、离岸市场、"一带一路"、大宗定价 | 不是官方表述，是作者对人民币国际化路径的归纳 |
| 六分之一理论 | 房租≤月收入 1/6；一生买房支出≤工作年限收入 1/6；房地产投资≤固投 25%、≤GDP 1/6 | 来自重庆治理实践的经验系数体系 |
| 危机后移 | 用下一个更大的泡沫对冲上一个危机：股市→房地产→政府债务 | 不是周期论，是"把危机推向未来"的传导诊断 |

### 核心命题 (用自己的话)

1. 中国宏观杠杆的要害不在总量在结构：企业负债 160%（美 60%），病灶是融资结构（90% 债权）
2. 金融创新的乱象都能拆成六种杠杆工具的组合；识别伪金融看五重违规机制
3. 货币制度的分野在锚：人民币的汇兑本位制不可持续，须转主权信用制但必须先立刚性纪律（四原则、70% 国债上限）
4. 资本市场的病根是基础性制度（退市、长期资金、注册制），制度红利本身就是去杠杆
5. 房地产十大失衡须从供给侧五大制度治理；住房负担有六分之一标尺；未来十年总量降档是长周期判断
6. 中间品贸易 70% 的世界必然走向三零规则，中国应主动介入 FTA（第二次入世）
7. 美国深层的债务危机会经危机后移链条外溢为金融战（2015 法案十大措施）
8. 人民币国际化是化解金融战的进攻面：五个蓄水池逐个做深
9. 开放本身是安全：你中有我使对手打一拳自伤七成；资本项下管制是盾牌，开放次序不可乱

### 论证链

与姊妹卷同源：**数据立题 → 结构分解（把总量拆成结构） → 国际比较/历史复盘 → 机制解释 → 量化标尺/分级对策**。本书特色是金融视角更强：大量用"与 GDP 之比"的标尺族、结构分解法（250% 拆成政府 50/居民 50/企业 160）、案例拆账法（500 美元笔记本、宝能杠杆放大链、蚂蚁 ABS 循环）。

## 3. 批判 (Critical) ★

### 时代局限

- 授课于 2018-2019：美元危机预言（"2023 年 30 万亿、大概率事件"）其后未兑现；美国债务与股市继续膨胀
- "金融必须独立建构"等断言被支付宝生态、香港虚拟资产政策等后续演进削弱
- 华为"化危为机"叙事写于 2020 年初，未预见其后制裁烈度

### 立场盲点

- 对重庆实践（地票、网络小贷、京东方）有自证色彩，缺第三方检验
- 驳斥美方五谬论时立场先行，对中国产业补贴等真实关切未正面回应
- 对行政管控（IPO 开关、指数管理）与市场化的张力处理双重标准

### 未证明的假设

- 70% 国债红线是经验数字，与美国自身超 110% 现实矛盾
- "货币量与 GDP 对应即可稳定"忽视金融深化与流通速度变化
- 多处万亿元级红利推算为拉弗式推算（恰是他批评供给学派之处）

### 最强反对意见

这是政策讲稿而非学术著作：概念体系自洽精彩，但关键阈值（70%、1:1、六分之一）多为经验归纳，且预测部分（美元危机、指数点位）已被时间证伪一批——其稳定价值在结构分析工具而非预测结论。
