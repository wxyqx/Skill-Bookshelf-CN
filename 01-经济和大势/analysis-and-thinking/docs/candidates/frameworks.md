- id: f01
  title: 宏观杠杆四指标与结构分解
  type: framework
  source_chapter: 第1讲
  source_quote: |
    M2/GDP=2.1:1，美国0.9:1；企业债务/GDP 160%，美国60%；2017年新增融资18万亿，股权不到10%。
  summary: |
    诊断一个经济体杠杆的四指标：M2/GDP（货币生态）、金融业增加值/GDP（脱实就虚）、
    政府+居民+企业债务/GDP（总量）、新增融资中股权占比（结构）。总量 250% 再分解为
    政府 50/居民 50/企业 160，找到主病灶（企业）后再定位融资结构病根（股权太少）。
    判断杠杆风险要看"负债率+债务用途+融资结构"，不只看总量。
  tags: [leverage, macro, diagnosis]

- id: f02
  title: 金融乱象六工具识别
  type: framework
  source_chapter: 第1讲、第3讲
  source_quote: |
    高息揽储、刚性兑付、资金池、错配、通道、嵌套（抽屉协议/优先劣后），纵横组合可拼出全部金融乱象。
  summary: |
    一切金融创新乱象可拆成六种杠杆黏结工具的组合：高息揽储、刚性兑付、资金池、期限错配、
    通道、嵌套。宝能 70 亿万能险放大到 450 亿、蚂蚁 30 多亿资本金 ABS 循环 40 次成 3600 亿，
    都是工具叠加。识别一个金融产品时逐项检查用了哪几件、杠杆放大了几层。
  tags: [finance, risk, detection]

- id: f03
  title: P2P 式伪金融五重违规机制
  type: framework
  source_chapter: 第3讲
  source_quote: |
    对比英美 P2P 仅几十家与中国上万家——众筹资本金、向网民高息揽储、无场景放贷、资金池庞氏、无负面清单。
  summary: |
    识别庞氏结构金融的五重机制：①众筹式资本金（无真实资本）；②向不特定公众高息揽储；
    ③无场景无信用依据放贷；④资金池滚动（借新还旧庞氏结构）；⑤游离于负面清单之外。
    五条中招三条即高度可疑。与 f02 配套：f02 看杠杆怎么放大，本框架看盘子是不是骗局。
  tags: [fraud-detection, fintech, risk]

- id: f04
  title: 数字信贷五原则
  type: framework
  source_chapter: 第3讲
  source_quote: |
    资本信用、信用规范、信用杠杆（总杠杆约1:10不超1:20，ABS循环5—6次封顶）、放贷征信、大数据处理。
  summary: |
    评估规范网络小贷/消费贷业务的五原则：高资本金门槛（资本信用）、资金来自合规渠道
    （银行/中票/ABS）、杠杆上限（1:10-1:20、ABS 循环 5-6 次封顶）、必须有场景或产业链征信、
    大数据风控支撑低不良率。反面标尺即蚂蚁案：30 亿资本金循环 40 次、杠杆上百倍。
  tags: [fintech, credit, compliance]

- id: f05
  title: 金融本质三重检验
  type: framework
  source_chapter: 第1讲、附录
  source_quote: |
    "为有钱人理财，为缺钱人融资；（2）金融企业的核心要义就在于信用、杠杆、风险三个环节，要把握好[度]"。
  summary: |
    检验任何金融机构/产品/创新是否异化的三问：①底层是否在为有钱人理财、为缺钱人融资
    （还是自我循环）；②信用—杠杆—风险的度是否匹配（信用越高可承受杠杆越高）；
    ③是否服务实体经济（还是自弹自唱）。三问有一答不上，创新大概率是异化。
  tags: [finance, essence, evaluation]

- id: f06
  title: 货币锚与发行制度诊断
  type: framework
  source_chapter: 第4讲
  source_quote: |
    "汇兑本位制"；美、日、英等发达国家在布雷顿森林体系解体之后一直坚持"主权信用货币制度"。
  summary: |
    分析一国货币制度先问"锚是什么"：金本位（实物锚，通缩缺陷）、主权信用（以税收 GDP 为
    底、需纪律）、联系汇率（锚他币，放弃独立货币政策，只宜小经济体）。人民币被作者诊断为
    "汇兑本位制"——外汇占款曾占央行资产 83%，实质间接锚美元。诊断步骤：查央行资产负债表
    结构→判断锚类型→评估锚与经济体量的匹配度。
  tags: [currency, monetary-system, diagnosis]

- id: f07
  title: 主权信用货币的刚性纪律
  type: framework
  source_chapter: 第5讲、第13讲
  source_quote: |
    四条刚性原则：①发行增速=GDP增速+通胀率+平减系数；②赤字国债只能二级市场发行；
    ③国债余额/GDP≤70%；④绝不零利率负利率。
  summary: |
    主权信用货币制的前提是四条纪律：锚定 GDP+通胀的发行公式、央行绝不购一级市场赤字债、
    国债余额三级上限（良性 70%/危机 100%/致命 150%——判据是付息+到期债务吞噬全年财政收入）、
    绝不零利率负利率。评估任何 MMT 式主张或货币超发风险时逐条对照，三条被突破即进入危
    险区。配套三个参考比值（股市市值/GDP 100 成熟 150 泡沫、房地产 2:1 绝不超 3:1、企业债务 1:1）。
  tags: [monetary, discipline, mmt]

- id: f08
  title: 宏观泡沫四指标
  type: framework
  source_chapter: 第13讲、第5讲
  source_quote: |
    "不超过1∶1……当达到1.5∶1或更高时，表明经济出现严重泡沫，可能会出现剧烈震荡甚至市场崩溃"。
  summary: |
    泡沫诊断标尺族：M2、政府债务、股市总市值、房地产总市值与 GDP 之比——正常不超 1:1，
    1.5:1 严重泡沫。历史崩盘点佐证：美国 2000 年股市 183% 崩盘、2007 年房地产 173% 崩盘。
    用于快速判断"某市场贵不贵"：先算比值，再对标历史崩盘点与合理区间。
  tags: [bubble, valuation, macro]

- id: f09
  title: 资本市场三功能诊断
  type: framework
  source_chapter: 第6讲、第7讲
  source_quote: |
    GDP 从2000年十几万亿增至80多万亿（8倍），上证指数2000多点仍在2000多点——晴雨表失灵。
  summary: |
    诊断一个股市健康度的三功能：晴雨表（指数与 GDP 是否同步）、投入产出（市盈率与实体
    回报率是否匹配）、资源优化配置（上市/退市是否进退平衡、资金流向优质企业）。病根若在
    基础性制度（退市率、长期资金占比、发行制度），修制度而非调点位——美国退市/上市约 1:1
    维持 3000 家是进退平衡的标尺。
  tags: [capital-market, diagnosis]

- id: f10
  title: 危机后移链条
  type: framework
  source_chapter: 第13讲
  source_quote: |
    2001年股市危机靠房地产对冲化解，却引起2008年更大级别危机；十年靠财政举债放水化解次贷。
  summary: |
    大国危机的传导诊断：每一次危机靠吹大另一个泡沫对冲——2001 股市崩盘用房地产对冲、
    2008 次贷用政府举债+QE 对冲、下一站是政府债务/美元信用。分析"下一个危机在哪"时：
    找当前正在膨胀的对冲工具（谁在加杠杆接盘），它的崩点就是下一场危机的震中。
  tags: [crisis, macro, forecasting]

- id: f11
  title: 三零原则与中间品贸易时代
  type: framework
  source_chapter: 第10讲
  source_quote: |
    货物贸易中产成品占比从1980年代70%降至2018年中间品70%以上；"零关税、零壁垒、零补贴"。
  summary: |
    判断贸易规则演进方向的框架：产成品贸易时代关税合理；中间品占 70% 后一件商品多次跨境、
    关税重复计征，三零（零关税/零壁垒/零补贴）成为 FTA 规则方向。零壁垒=营商环境国际化
    八条，零补贴防扭曲。分析任何贸易摩擦或协定新闻时先问：该商品是产成品还是中间品贸易？
    三零走到哪一条了？
  tags: [trade, fta, rules]

- id: f12
  title: 贸易失衡的价值链拆账法
  type: framework
  source_chapter: 第12讲
  source_quote: |
    "组装加工收入只有60美元，区区12%的代工附加收入，让美国跨国公司获取了丰富的中国制[造业利益]"。
  summary: |
    分析贸易顺差/逆差真实利益分配的方法：把一件争议商品的总价拆开——原材料、品牌研发、
    物流销售、组装加工各占多少、归谁。500 美元笔记本中国代工仅得 60 美元（12%）；中国对美
    出口 60% 是美企在华返销。账拆开，"谁吃亏"的叙事之争就变成数字问题。
  tags: [trade, value-chain, analysis]

- id: f13
  title: 人民币国际化五个蓄水池
  type: framework
  source_chapter: 第14讲、第10讲
  source_quote: |
    2010年跨境人民币交易清算量不到1000亿美元，2019年跨境人民币交易量达到7万亿元人民币。
  summary: |
    人民币国际化的五条水道：①跨境贸易人民币结算（2019 年约 1 万亿美元）；②与大国本币互
    换协议；③离岸人民币市场（香港+伦敦约 2 万亿元）；④"一带一路"人民币直接投资与计价；
    ⑤大宗物资人民币计价定价权。评估人民币国际化进展或本币结算机会时逐池查水位。配套
    防守面：汇率战三边界（美认定操纵的触发条件），结算普遍展开即不触碰。
  tags: [rmb, internationalization]

- id: f14
  title: 进口大国五条强国理由
  type: framework
  source_chapter: 第11讲
  source_quote: |
    进口大国与经济强国绑定：消费能力强→外汇充裕→定价权→本币成硬通货→本币计价权。
  summary: |
    判断"顺差好还是逆差好"的递进框架：进口大=消费力强→外汇充裕→大宗商品定价权→本币
    成为硬通货→本币计价权（收铸币税）。美国靠逆差输出美元即此逻辑。配套判断开放阶段的
    五个旧特点→五个新特征坐标（出口导向→双向投资、沿海先行→东西南北中、适应规则→制定规则）。
  tags: [trade, open-economy]

- id: f15
  title: 资本招商范式
  type: framework
  source_chapter: 第2讲、附录
  source_quote: |
    重庆京东方定增210亿+银行118亿，16个月投产，政府股票收益超200亿——资本招商范式。
  summary: |
    招商引资的资本化路径：政府不以补贴、土地让利招商，而以资本金入股（定增）+撬动银行
    贷款帮项目落地，共享企业成长收益（股票增值退出）。浦东三管齐下（土地批租+股份制引
    外资+上市融资）以 3000 万开办费撬动百亿开发是同源方法。适用于产业项目落地方案设计。

- id: f16
  title: 住房负担六分之一标尺
  type: framework
  source_chapter: 第8讲、第9讲
  source_quote: |
    房租≤月收入1/6；一生买房支出≤工作年限收入1/6（6—7年家庭收入买一套房）。
  summary: |
    住房可负担性的经验标尺族：房租不超过月收入 1/6；6-7 年家庭收入买一套合理房价的房；
    推论房地产投资≤固定资产投资 25%、≤GDP 1/6。重庆治理实践归纳，与"三个总量"（人均
    住房 40-50㎡、每 2 万元 GDP 1㎡写字楼、每㎡商铺 2 万元零售额）配套。判断某城市房价
    泡沫或个人购房负担时套算。
  tags: [housing, affordability, real-estate]
