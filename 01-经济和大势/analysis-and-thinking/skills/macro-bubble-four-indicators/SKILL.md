# 宏观泡沫四指标

## R — 原文 (Reading)

> "不超过1∶1……当达到1.5∶1或更高时，表明经济出现严重泡沫，可能会出现剧烈震荡甚至市场崩溃，从而矫正修复相关指标，回到1∶1以内。"
>
> — 黄奇帆，《分析与思考》第13讲

---

## I — 方法论骨架 (Interpretation)

宏观资产贵不贵，不看单资产 K 线，看**与 GDP 的横断面比例族**：

1. **四大指标**：M2/GDP、政府债务/GDP、股市总市值/GDP、房地产总市值/GDP——正常时各不超 1:1；某项达 1.5:1 或更高即严重泡沫。
2. **历史崩盘点校准**：美国 2000 年股市市值/GDP 达 183% → 崩盘；2007 年房地产 173% → 崩盘；泡沫的顶部都远高于 1.5:1，但 1.5:1 是"剧烈震荡区"的入口。
3. **三个参考比值细化**：股市市值/GDP 100% 算成熟、150% 是泡沫线；房地产总市值/GDP 合理 2:1、绝不超 3:1（中国峰值 400% vs 日泡沫前 391%、美 169%）；非银企业债务/GDP 约 1:1。
4. **合成判断**：单指标超标是局部过热；多指标同时逼近或超过阈值（共振）才是系统性泡沫——共振时回看危机后移链条，找传导路径。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 美国 2000 与 2007 的标尺读数（第13讲）
- **问题**: 怎么在事前看出泡沫？
- **方法论的使用**: 2000 年读数：债务 55%、房地产 81%、M2 70% 均安全，唯独股市 183% 超标 → 局部泡沫崩盘；2007 年：房地产 173% + 股市 135% 双超标 → 系统性危机。
- **结论**: 标尺族的事前读数与事后崩盘对应良好。

### 案例 2: 中国房地产的标尺读数（第5讲）
- **问题**: 中国房地产总市值 400% GDP 意味着什么？
- **方法论的使用**: 对照合理 2:1、极限 3:1 与日美历史读数（391%/169%）。
- **结论**: 已在历史极值区，须用长效机制缓慢矫正而非继续膨胀。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断"现在股市/楼市贵不贵"的宏观横断面问题
2. 跨资产（股、房、债、货币）风险扫描与配置再平衡
3. 解读"总市值超过 GDP"类财经新闻的含义
4. 评估某国资产价格的系统性风险

### 语言信号 (用户的话里出现这些就应激活)

- "总市值超过 GDP 了""泡沫大吗""楼市/股市贵不贵"
- "资产价格""bubble" / "market cap to GDP" / "系统性风险"

### 与相邻 skill 的区分

- 与 `macro-leverage-four-indicators` 的区别：四指标杠杆版看债务侧（谁欠了多少），本版看资产市值侧（资产标价多少）——一债一资产构成完整体检；M2 与政府债务两项两版共用。
- 与 `housing-affordability-one-sixth` 的区别：六分之一是家庭可负担视角，市值/GDP 是总量泡沫视角。

## E — 可执行步骤 (Execution)

1. **取四数**：M2、政府债务、股市总市值、房地产总市值各除以 GDP
   - 完成标准: 四个比值有数据来源与时间戳
2. **对标尺**：逐项对照 1:1 / 1.5:1 与三个参考比值的细分阈值
   - 完成标准: 每项标注"安全/偏高/泡沫区"
3. **查共振**：统计超标项数量与同向性
   - 完成标准: 局部过热（单项）或系统性（多项共振）有判定
   - 判停条件: 全部低于 1:1 → 结论"宏观横断面无泡沫"，终止
4. **接传导**：若共振，调用危机后移链条推演传导路径
   - 完成标准: 脆弱项与传导假设明确，输出观察清单

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 储备货币国硬套 1:1——美元资产被全球持有，美国 M2/GDP 天然低、股市上限天然高，须分国校准（作者自己处理美国读数时也做了此调整）
- 用作择时信号——泡沫可以在极值区维持很久，标尺给的是风险评估不是卖出指令

### 作者在书中警告的失败模式

- 单指标唱空：2000 年美国只有股市超标，其他都安全——崩的是超标的那一项，不是全部
- 用"这次不一样"忽略比例回归——历史崩盘点（183%、173%、391%）都是比例回归的注脚

### 作者的盲点 / 时代局限

- 标尺未考虑利率环境（零利率下市值/GDP 天然上移）与结构变化（科技股占比）
- 房地产总市值口径（存量×市价）对交易不活跃市场的估值噪音敏感

### 容易混淆的邻近方法论

- 与巴菲特指标（股市市值/GDP）：巴菲特指标是单项，本法是四指标共振族——单项超标常见，共振才危险
