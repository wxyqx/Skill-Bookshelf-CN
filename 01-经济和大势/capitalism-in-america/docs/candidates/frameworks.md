- id: f08
  title: 活力衰退诊断（权益挤出）
  type: framework
  source_chapter: 第十二章
  source_quote: |
    权益支出占 GDP 从 4.6% 升至 14.6%，等额挤出国内储蓄→资本存量→生产率；州际移民率较 1948-71 均值降 51%，新企业占比 14.6%→8.3%。
  summary: |
    诊断经济体"活力衰退"的六症状清单：①地域流动率下降②创业率下降③IPO 与上市公司数下降④包容失败程度下降（破产文化）⑤基建投资不足⑥企业集中度上升与前沿公司技术扩散放缓。主因假说：权益（福利）支出挤出储蓄与投资（统计稳定性惊人的等额关系）；次因：监管爆炸（《联邦公报》年增 7.3 万页、30% 工作需许可证）。配套三排除（教育领先丧失说、IT 失望论、劳动力萎缩论各被反驳）。
  tags: [core-theory, diagnosis, vitality]

- id: f09
  title: 政策药方设计（瑞典范本+资本金替代监管）
  type: framework
  source_chapter: 引言、大结局
  source_quote: |
    瑞典公共支出占 GDP 从 67% 降至 49%，债务从 70% 降至 37%——固定缴费型福利+退休年龄与预期寿命挂钩+自动平衡机制；银行应以 25-30% 资本充足率替代《多德-弗兰克》式细则监管。
  summary: |
    药方设计的两个范本：①福利改革（固定缴费制自动解决资金来源、退休年龄指数化、福利按物价而非工资指数化——瑞典"蓬佩里波萨效应"）；②金融监管（高资本充足率替代规则细则，历史依据：1870-2017 银行股本回报稳定于 5-10% 可吸收高资本+以打击欺诈取代行为细则）。"铁笼 vs 沼泽"：钥匙存在论。
