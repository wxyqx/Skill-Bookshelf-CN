# 诊断先行——区分问题性质（流动性 vs 偿付能力；不能 vs 不愿；净转移）

## R — 原文 (Reading)

> 从债务危机一开始，一个主要的概念性错误就是这样一种观念：那些出现问题的国家属于缺乏短期的流动资金，对此，所有需要做的就是制定18～24个月的短期稳定计划。……一个又一个的稳定计划终将以失败而告终。
>
> — 侯德兹（IMF），第7章/附录1（拉美债务危机复盘）

---

## I — 方法论骨架 (Interpretation)

处置任何危机之前先做定性诊断，因为误诊是代价最大的错误——诊断错了，后面每一步"正确执行"都是在错误方向上加速。四个诊断动作：

1. **流动性 vs 偿付能力**：流动性问题是暂时性资金周转错配（借钱换时间有效）；偿付能力问题是债务存量超过偿还能力（任何稳定计划都会一个个失败）。关键修正：现实世界几乎不存在纯粹的流动性问题，重大流动性危机背后总有偿付能力因素——所以二分法不是二选一，而是判断偿付能力因素占多大比重。
2. **不能 vs 不愿**：同样是紧缩失败，"没有能力做"和"不愿付代价"的解法完全不同——前者补工具，后者换激励或换人。
3. **净转移检验**：评估债务负担不看总量、看净转移——在政治可接受的最低增长前提下，这个主体能向外支付的最大净资金流出是多少、何时转负。总量大不等于不可持续，净转移持续为负才是危机的实质。
4. **资金纪律**：官方/新钱只做有明确偿还来源的过渡性桥梁贷款，绝不用公款（或新投资人的钱）直接偿还旧债权人的退出——否则私人损失社会化，道德风险从资金入口涌入。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1982年8月墨西哥危机处置
- **问题**: 墨西哥宣布无力偿债，全球银行体系面临连锁崩溃，直接风险是把它误诊为简单的流动性缺口。
- **方法论的使用**: 沃尔克等先做定性判断——偿付停顿争取时间但立即启动IMF计划与银行新融资绑定；央行联合过渡贷款18.5亿美元只用于结清支付体系（"一匙一匙地喂入"防储户抽逃），且官方资金只做桥梁、绝不用公款偿还私人银行贷款。
- **结论**: 诊断决定资金形态——桥梁贷款可以给，替代私人债权人承担损失的新钱不能给。
- **结果**: 危机未演变为全球金融崩溃；逐案+关键主体模式复制到多国。

### 案例 2: 贝克计划的误诊延续与布雷迪的转向
- **问题**: 1982年后拉美债务战略把偿付能力问题当作18-24个月流动性缺口处理，连续推出短期稳定计划。
- **方法论的使用**: 侯德兹复盘承认这是"最大的概念性错误"；格瑞亚的净转移框架揭示贝克计划实为"借小钱还全额利息"的敷衍策略，负向净转移从未治理。
- **结论**: 误诊的处方（新融资换时间）不触及病根（净转移不可持续、无结构改革），每一轮计划的失败都比上一轮更消耗耐心。
- **结果**: 拖延十年"失败的十年"，直到1989年布雷迪计划承认必须削减债务存量、市场化自愿减债，市场信心才回归。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一家企业现金流断裂来借钱/求救，用户（债权人、投资人、母公司、政府）在纠结"桥贷放不放、要不要续贷"。
2. 用户发现自己或对方已经连续多轮"借新还旧"，每一轮方案存续期都比预测短，怀疑病根没找到。
3. 用户在评估一份救助/重组方案，需要判断它是在换时间还是在拖延病根（净转移有没有被治理）。

### 语言信号 (用户的话里出现这些就应激活)

- "再借一笔过桥就能撑过去吗？"
- "它到底是缺现金还是真的还不起了？"
- "这是能力问题还是压根就不想动？"
- "债务规模很大，但到底能不能持续？"
- 英文: is it liquidity or solvency / bridge loan decision / debt unsustainable / net outflow

### 与相邻 skill 的区分

- 与 `crisis-management-sequence` 的区别: 那个是诊断之后的治疗顺序（止血→争取时间→改革→减债）；本 skill 是治疗之前的大门——先定性，结论决定走序列的哪一段、是否需要减债。
- 与 `unilateral-default-trap` 的区别: 那个评估"威胁性限付/违约"这一具体策略的自我失败；本 skill 不处理谈判策略，只处理问题定性。
- 与 `confidence-fragility-check` 的区别: 那个定位体系中可瞬间逆转的快变量（信心/资金流入）；本 skill 定性债务问题的性质，两者常在债务危机中先后使用。

## E — 可执行步骤 (Execution)

1. **流动性 vs 偿付能力定性**
   - 检验单位经济模型/基础现金流是否成立：若无债务压力下业务本身能否产生可持续现金流。同时接受混合现实——判断偿付能力因素的比重而非二选一。
   - 完成标准: 给出定性结论（纯流动性/偏偿付能力/混合）+ 判断依据。
   - 判停条件: 若结论为"偏偿付能力"，任何"新融资换时间"方案都不应再作为主方案，直接进入减债/重组议题（交 `crisis-management-sequence` 后段）。

2. **不能 vs 不愿甄别**
   - 区分：缺工具/缺能力（补工具、给技术支持）vs 有工具但不愿付代价（换激励结构、改变决策者面临的压力）。
   - 完成标准: 明确指出失败属于哪一类，处方据此分叉。

3. **净转移测算**
   - 在"维持最低可接受运转（如不裁员/基本公共服务）"前提下，测算每月/每年最大可持续净流出、何时转负。
   - 完成标准: 得到一个数字化的净转移路径表，替代"债务总量大不大"的直觉讨论。

4. **资金纪律审查**
   - 对拟议中的每一笔新钱提问：偿还来源是什么？是否在直接偿还旧债权人的退出？
   - 完成标准: 每笔资金标注"桥梁（有明确偿还来源）"或"置换（新钱偿旧债）"；置换类一律要求重新设计。

5. **输出诊断结论**
   - 把四步结论合成一页诊断书：问题性质、意愿状态、净转移路径、资金纪律边界，并指明后续应走的处置路径。
   - 完成标准: 用户能依据诊断书直接选择进入 `crisis-management-sequence` 的哪一段。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 处置顺序问题（先救谁、怎么排序、减债怎么谈）：诊断已完成时应转入 `crisis-management-sequence`。
- 用户在评估单方面限付/威胁违约作为谈判筹码：那是 `unilateral-default-trap` 的边界判断。
- 问题其实是市场信心挤兑而非债务可持续性（如银行挤兑但资本充足）：资金流入的中断机制分析见 `confidence-fragility-check`。

### 作者在书中警告的失败模式

- **误诊为流动性、拖延成十年**（第7章/附录1，ce01）: 把偿付能力当作18-24个月流动性问题，"借小钱还全额利息"，一个又一个稳定计划接连失败，每轮消耗更大。
- **警告者困境污染诊断信息**（第7章，ce11）: 墨西哥总统向银行家求证风险得到"不担心"，警告官员被解职；危机前利差还在下降——诊断依据若来自利益相关方必然失真，警讯渠道必须独立。
- **监管豁免拆掉预警防线**（第7章，ce10）: 10%贷款限额被"所罗门式决定"架空，敞口在危机前系统性积累——诊断不能依赖可被法律技术拆解的规则。

### 作者的盲点 / 时代局限

- **经验基础偏向拉美**: "从未遇到纯粹流动性问题"来自主权债务经验，对真正的短期流动性挤兑（后来2008式的批发融资挤兑）可能过度倾向偿付能力诊断而拒绝提供桥梁资金。
- **银行家自辩色彩**: 债务危机一章以美国/IMF决策者视角叙述，对债务国承受的紧缩代价、误诊给其人民造成的损失着墨少；"净转移"框架直到危机后期才被采纳，作者的叙述淡化了自己早期同样参与误诊的事实。
- **未涉及中国等高储蓄新兴经济体**: 净转移框架默认依赖外部融资的债务国情形，对储蓄输出型经济体的债务问题结构没有覆盖。

### 容易混淆的邻近方法论

- `crisis-management-sequence`: 定性诊断（本 skill）→ 处置序列（那个），先后衔接而非竞争。
- `confidence-fragility-check`: 快变量定位是诊断的信息输入之一，但对象是信心结构而非债务性质。
- `paradigm-failure-discipline`: 连续加码无效时换范式；本 skill 的"连续稳定计划失败"可作为触发它的证据，但两者层级不同。
