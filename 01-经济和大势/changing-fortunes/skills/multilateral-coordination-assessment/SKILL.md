# 多边协调的成熟度评估与组织设计

## R — 原文 (Reading)

> 美国以为建立某些明确的目标并为我们的宏观经济表现制定目标是可行的，这是一个原则性的错误。比如说，规定日本接受精确的6.7%的增长目标。客观的讲，谁能保证一个拥有1.2亿人口国家的经济按如此精确的增长速度发展？
>
> — 行天丰雄，第5章（1978年波恩峰会"火车头"战略复盘）

---

## I — 方法论骨架 (Interpretation)

评估任何多边协调机制，先用四条件检查表打分：①参与各方紧密相互依赖；②对协调成果有共同理解；③协调过程制度化并可持续；④各方承认这是正和博弈。缺一不可，而现实中往往只有第一条达标——依赖彼此，但对成果的理解、对过程、对收益分配各怀心思。若只有第一条达标，这个机制大概率停留在象征层面。

组织设计四原则：①小规模、保密、非正式的高层渠道产出大于大规模论坛（四人的图书馆会议胜过一百五十人的C-20）；②合作分层递进——信息交流→减少意外→危机互助→真协调，先做低层次合作、不越级承诺；③协调目标停留在方向性层面，精确数量目标写进公报等于预订违约；④内嵌快速调整机制，因为谈判时滞本身会吞掉协调价值——等协议走完程序，形势早已改变。

## A1 — 书中的应用 (Past Application)

### 案例 1: 波恩"火车头"协议——精确目标与时滞的失败
- **问题**: 1977-78年美国压德日扩张内需充当世界需求火车头，用克莱恩模型为据设定精确目标。
- **方法论的使用**: 反面演示全部四条原则——目标以小数点精度写进公报（日本6.7%增长、德国GNP 1%财政扩张），违反"方向性目标"原则；从倡议到执行耗时一年以上且无调整机制，恰逢第二次石油冲击油价再涨一倍，各方在通胀加剧时被迫执行扩张计划。
- **结论**: 协调的内生矛盾是计划与谈判总以年计，而经济形势以月变；精确目标在主权国家层面本不可控。
- **结果**: 协议执行时形势已变，协调反而放大了通胀，事后被德日视为高代价错误；此后如此雄心勃勃的协调再未重演。

### 案例 2: 贝克-宫泽旧金山密谈——小圈子设计正例
- **问题**: 1986年多边协调在德日拒绝扩张处全面卡壳，七国论坛推不动。
- **方法论的使用**: 缩小规模（两国财长）、高度保密（记者送花逐店打听会场）、非正式渠道；先做双边、做出既成事实后再向多边推广——不越级承诺，用小渠道产出撬动大论坛。
- **结论**: 小规模、保密、非正式的高层渠道是协调有效产出的组织前提。
- **结果**: 1986年10月双边公报落地（日降息+财政刺激、美承认汇率与基本面吻合），为1987年2月七国卢浮宫协议铺路。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要评估一个拟议的跨国/跨组织协调机制（安全联盟、行业标准联盟、数据/AI治理框架、联合研发计划）能否有实质成效，而不是只看参与方阵容。
2. 用户在设计一个新协调机制：定章程、设目标、选参与范围、定决策程序。
3. 用户在决定要不要投入某个现有论坛/联盟，怀疑它"只会发公报不会办事"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个联盟/机制/论坛最后会不会沦为走形式、发公报？"
- "各方对'合作要达成什么'的理解根本不一致，还谈得下去吗？"
- "要不要把具体指标写进联合声明？"
- "参与方越多越好，还是先搞个小圈子？"
- 英文: will this coalition actually deliver / MOU with numeric targets / multilateral framework design

### 与相邻 skill 的区分

- 与 `negotiation-structure-design` 的区别: 那个是赢得一场具体谈判的操作序列（先攻谁、程序杠杆、议题重构）；本 skill 是评估与设计可持续的协调机制本身，时间尺度是制度而非战役。
- 与 `strong-commitment-intervention` 的区别: 那个设计一次联合行动的打包与时机；本 skill 评估的是行动背后的机制是否具备持续产出的条件。
- 与 `crisis-diagnosis-first` 的区别: 那个诊断危机性质；本 skill 诊断的是合作机制成熟度，对象是制度不是债务。

## E — 可执行步骤 (Execution)

1. **四条件检查表打分**
   - 逐条核验：相互依赖程度、成果共同理解、过程制度化与可持续性、正和承认。
   - 完成标准: 四条各给出"达标/不达标+证据"；若仅第一条达标，明确预测"该机制将停留在信息交换层面"。

2. **组织设计裁决**
   - 缩小规模、保密、非正式高层渠道；必要时先双边/小圈子做出既成事实再向多边推广。
   - 完成标准: 给出参与方名单（≤5人量级决策渠道）与正式论坛的关系说明。
   - 判停条件: 若问题只是一场谈判怎么赢，跳转 `negotiation-structure-design`。

3. **合作分层排期**
   - 把合作目标按"信息交流→减少意外→危机互助→真协调"分层，从当前可达层次起步，不越级承诺。
   - 完成标准: 四层中标注当前层次与下一层次的具体动作。

4. **目标设定纪律**
   - 协调目标写方向性表述；拒绝把精确数量目标写进公报（=预订违约）。
   - 完成标准: 公报/章程草案中无小数点级承诺；若必须量化，改用区间+复盘条款。

5. **内嵌快速调整机制**
   - 协议中预置定期复盘与修订通道，抵消谈判时滞。
   - 完成标准: 写明复盘频率、触发修订的条件与修订权限归属。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 目标是赢一场具体的、有明确对手的谈判：那是 `negotiation-structure-design` 的操作序列，本 skill 的检查表不提供谈判战术。
- 单一组织内部的项目协调会/例会设计：四条件检查表面向主权级/组织级对等合作，内部科层协调不适用。
- 用户只想要某个国际组织的历史信息：纯信息查询不激活方法论。

### 作者在书中警告的失败模式

- **精确目标+长时滞=放大灾害**（第5章，ce08）: 波恩协议的6.7%精确增长目标在第二次石油冲击到来时从公共品变成通胀放大器。
- **承诺不真诚与监督缺位**（第9章，ce15）: 卢浮宫美国宣誓2.3%实际3.2%，德日不按美国意图扩张——机制没有监督与执行手段时，签署只是姿态。
- **以威胁代替正和共识**（第9章，ce14）: 1987年美国以放任美元下跌威胁德日扩张，协调崩塌催生黑色星期一——不承认正和博弈的"协调"是用汇率当武器。

### 作者的盲点 / 时代局限

- **对制度化方向的低估**: 作者推崇非正式小圈子（G7模式），未预见后来G20扩容、常设秘书处与统计监督机制在更大规模上的必要性；"统计指标与专门秘书处作用有限"的判断在更大经济体量下未必成立。
- **对欧洲货币联盟的乐观**: 写于1991-92，认为区域货币一体化可深化协调，随后 ERM 危机与欧元区债务危机部分证伪——货币联盟恰恰暴露了"制度化承诺缺少财政正和共识"的深层问题。
- **未涉及中国等新兴经济体**: 四条件检查表与G7小圈子设计建立在美欧日同质精英的基础上，对异质体制大国的协调设计无覆盖。

### 容易混淆的邻近方法论

- `negotiation-structure-design`: 一场谈判的战术 vs 一个机制的制度评估。
- `soft-commitment-ambiguity`: 公报措辞工程是本 skill 目标设定纪律的下游工具（方向性表述如何措辞）。
- `strong-commitment-intervention`: 一次联合行动的打包设计 vs 行动平台的持续成熟度。
