# 谈判结构与顺序设计

## R — 原文 (Reading)

> "很清楚，隐含的威胁是投机压力将迫使所有货币实行浮动，这将带来严重无序和相互对抗的风险。"
>
> — 沃尔克 & 行天丰雄，第4章（1973年2月环球谈判）

---

## I — 方法论骨架 (Interpretation)

多边谈判的结果在很大程度上由谈判的组织方式预先决定，因此要把"怎么谈"当作独立的设计对象。操作序列有六件工具。一，顺序设计：先攻最关键且最可争取的一环，把初始同盟组好，再拿"已成局的联盟"去压最强硬者——对最强硬者最后出牌，比先啃硬骨头成功率高得多。二，分而治之：孤立最大顺差方或最强抵制方，避免各抵制方事前串通共同要价。三，程序杠杆：对方官员以"未获本国授权"拖延时，用议程设置、时限压力把回避变成一次显性决策——要么授权要么公开说不，二者都比无限拖延对己方有利。四，议题重构：分配僵局常常源于度量口径之争，重新定义度量单位（如把"对美元双边升值"重构为"贸易加权的有效汇率变动"）可以给小方留出台阶，让各方都能向国内交代。五，先例意识：以"这一单将约束所有后续交易"的标准设计每一单妥协——宁可个案化、粗糙化，也不要留下可供援引的精确基准。六，双边先行、多边跟进：先在最小范围谈成既成事实，再拿去多边场合扩大。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1971 年史密森谈判技术包（第3章）
- **问题**: 尼克松冲击后需要各主要货币对美元升值，欧共体声称需集体协商、日本顾忌国内压力，谈判随时僵住。
- **方法论的使用**: 对欧共体用程序杠杆——要求其当场授权而非回去请示；对小国用议题重构——发明贸易加权"有效汇率"算法（对 OECD 整体约 8%），给"维持现平价即实际小幅贬值"的台阶；对日本用水田的"17% 不吉利"历史包袱反向压价成交于 16.88%；顺序上先施密特（最可同情）后吉斯卡德（最强硬）。
- **结论**: 谈判结构本身把僵局逐个拆除。
- **结果**: 史密森协议达成（日元+16.9%、马克+13.57%）——虽因幅度与承诺不足终告失败，但其谈判技术成为范本。

### 案例 2: 1973 年 2 月环球闪电谈判（第4章）
- **问题**: 美元需第二次贬值，缺口在日元与欧洲之间的分配。
- **方法论的使用**: 带着成型的"十对十"方案环球飞行：先东京（最关键缺口方），再波恩施密特（最可能同情者），最后巴黎吉斯卡德（最强硬者）——每到一处都用"已被组好的局"压下一站；并以结构化隐含威胁（达不成协议则所有货币无序浮动）替代摊牌；对爱知揆一给"浮动而非正式重估"的无责台阶。
- **结论**: 顺序+隐含威胁+台阶三者配合。
- **结果**: 达成第二次贬值与日元上浮安排；行天自述"沃尔克已巧妙地把欧洲组成团伙来反对我们"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 组建行业标准联盟/联合采购体/行业自律组织，成员立场分化，不知按什么顺序逐个谈。
2. 多方协议磋商中，某方代表反复以"未获授权""需回去请示"拖延，议程要被拖死。
3. 分配比例/成本分摊僵局：各方在"按什么口径算"上顶死，数字本身谈不动。
4. 准备让步方案时，担心这一单会被对手援引为下一单的基准；或在双边与多边两条线之间抉择先走哪条。

### 语言信号 (用户的话里出现这些就应激活)

- "先找谁谈"、"顺序怎么排"、"分而治之 / divide and rule"
- "对方说没获得授权/要回去请示"、"议程被拖死"
- "口径谈不拢"、"给个台阶下"、"这单会不会成为先例 / precedent"

### 与相邻 skill 的区分

- 与 `eliminate-exit-leverage` 的区别: 那是开桌前改变对手选择结构的破局动作（关闭退路）；本 skill 在桌上做顺序与程序设计，不改变任何人的选项集，两者常先后接力（1971 先关窗口，再进史密森程序）。
- 与 `multilateral-coordination-assessment` 的区别: 那是事前评估多边协调机制本身成不成熟（四条件检查表）；本 skill 假设谈判必须开，解决怎么组织。
- 与 `soft-commitment-ambiguity` 的区别: 那处理协议文本的模糊化与公报措辞；本 skill 处理谈判进行时的结构，是文本工程的上游。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画谈判桌地图**
   - 列出全部参与方，按"关键程度 × 可争取度"分类：最关键缺口方、最可争取的同情者、最强硬抵制方、可给台阶的小方。
   - 完成标准: 每一方有明确标签，且对"谁必须最后压、谁必须先拿下"有结论。

2. **排定接触顺序**
   - 先关键可争取者→串联成初始同盟→用既成局的同盟压最强硬者；必要时双边先行、谈成既成事实再多边跟进。
   - 完成标准: 有带先后次序的接触计划，最强硬者被安排在最后且面对的是同盟而非散沙。

3. **设置程序杠杆**
   - 针对每个可能拖延的方：设计议程时限、当场决策要求、把"未获授权"转化为显性表态的机制。
   - 完成标准: 每个拖延点有对应的程序动作；"说不"的成本被抬高而"点头"有台阶。

4. **议题重构化解分配僵局**
   - 当数字谈不动时，检查是否口径之争：重新定义度量单位或加权方式，使各方按新口径都能向国内交代。
   - 完成标准: 至少提出一个替代口径及其给各方的台阶；若僵局与口径无关，跳过并说明。
   - 判停条件: 若僵局根源是对手握有安全退路（拖延零成本），程序杠杆无效，转入 eliminate-exit-leverage 先破局。

5. **按先例标准设计每一单妥协**
   - 每项让步问一句"这将成为永久先例吗"；优先个案化、模糊化处理，避免留下可援引的精确基准。
   - 完成标准: 方案中每项让步标注先例属性；有被引用风险的数字已个案化处理。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 双边一对一谈判：分而治之、同盟串联等工具无对象，属普通谈判方法。
- 对手拖延的根源是安全退路而非程序：先破局（关退路）再设计顺序，否则程序杠杆全部落空。
- 目标是评估某国际机制/联盟值不值得参加：那是成熟度评估问题，不是单场谈判的组织问题。

### 作者在书中警告的失败模式

- 精确目标+漫长周期的协调（第5章，波恩火车头协议）：把协调定成 6.7% 式精确数量目标是"原则性错误"，从倡议到执行耗时一年以上，形势已变、协调反成灾害放大器——谈判结构设计要为协议内嵌快速调整机制。
- 外压依赖反噬互信（第9章，行天反思）：频繁借助外部压力推动国内改革，短期高效，但对方把施压工具化、本国共识建设萎缩，合作关系退化为筹码交换——程序设计不能替代国内的共识建设。
- 威胁武器反噬持械者（第9章，1987 贝克）：用汇率下跌作公开威胁的前提是市场相信你控制着它，与央行立场冲突的公开威胁招致"无锚"定价——隐含威胁必须保持结构化与克制。

### 作者的盲点 / 时代局限

- 写于 1991-92，多边谈判经验取自 G7 小圈子，未涉及中国等新兴力量入场后"多极化谈判桌"的结构变化；对欧洲一体化乐观，假设欧洲始终能以协商口径出现（此后 ERM 危机部分证伪）。
- 立场盲点：小国在书中只是"给台阶"的对象而非主体，其主动的谈判结构策略（发展中国家债务人卡特尔等）未被认真分析。
- 书中的成功案例高度依赖美国当时的霸权地位与沃尔克的个人声望，照搬顺序模板时容易低估"先例资本"这一未列明的变量。

### 容易混淆的邻近方法论

- `eliminate-exit-leverage`：开桌前破局 vs 桌上组织，先判拖延根源再二选一。
- `multilateral-coordination-assessment`：机制成熟度评估（四条件），与单场谈判设计层次不同。
- `soft-commitment-ambiguity`：文本模糊工程，是本 skill 产出协议后的下游工序。
- `crisis-management-sequence`：危机处置的排序逻辑形似（先止血），但对象是处置工具而非参与方。
