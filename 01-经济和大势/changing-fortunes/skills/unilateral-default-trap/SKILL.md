# 单方面威胁性违约是自我失败

## R — 原文 (Reading)

> "在1987年的一段时间，他实际上真的暂停了利息支付，却只是发现虽然他在前面通过取消支付利息而节省下资金，但更多的资金正通过后门流出。"
>
> — 保罗·沃尔克，第7章

---

## I — 方法论骨架 (Interpretation)

这条原则是一条谈判策略的适用边界，而不是泛泛的道德劝诫。

1. 先看主体性质：一个依赖资本、货款、订单、人才持续流入的主体（国家、企业、平台），其偿付记录同时也是自己人的产权预期——对外违约的信号对内就是"征收"信号。
2. 单方面限付或威胁违约的机制是：短期账面上省钱/施压，但本国（本组织）的富人、供应商、核心伙伴会立刻重新定价风险——收紧账期、要求预付、转移资产、启动备选。前门省下的钱从后门流出，净效果为负。
3. 因此"强硬施压可获让步"这类直觉对这类主体基本不可用：越依赖持续流入，威胁式谈判越自我失败。
4. 正路是：谈减免、重谈条款，必须以维护债权人/对手方权利为前提——自愿重组、展期、抵押担保交换，让对手在保留体面的情况下让步。
5. 反过来，若主体不再依赖该关系（决定清算退出），这条边界不适用——边界取决于依赖结构，不取决于行为本身的道德色彩。

## A1 — 书中的应用 (Past Application)

### 案例 1: 巴西暂停付息（1987）
- **问题**: 巴西福纳若政府面对 900 亿美元外债的利息压力，选择单方面暂停付息，预期以此施压银行让步。
- **方法论的使用**: 作者按依赖结构推演：不尊重债权人权利的信号惊吓了巴西国内的富人，资本外逃加速——前门省下的利息远少于后门流出的资本。
- **结论**: 威胁式违约对依赖外资流入的经济体是自我失败。
- **结果**: 巴西沦为拉美主要债务国中的落后者；暂停付息未换来任何让步。

### 案例 2: 秘鲁限付与墨西哥对照（1985-87）
- **问题**: 秘鲁加西亚单方面宣布付息不超过出口收入的 10%，短期政治得分且看似"自主路线"；同期墨西哥选择走 IMF 协议、维持债权人权利的谈判路线。
- **方法论的使用**: 对照检验：加西亚限付后本国资本外逃加剧，任期未满经济即崩溃，且无人仿效；墨西哥路径虽痛苦，却保住了重返资本市场的资格，反而最先恢复借款能力。
- **结论**: 自愿重组优于单方面限付；债权人权利同时保护着国内储蓄者的预期。
- **结果**: 两个独立反例 + 一个对照组，威胁策略在依赖外资的经济体中被证伪。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司现金流紧张，内部有人提议威胁集体拖欠供应商货款/暂缓付款来压价或回血，用户来评估这招行不行。
2. 主权债务/大额债务重组讨论中，有人主张单方面宣布只还一部分、限付利息，以增加谈判筹码。
3. 创业公司或平台想用"威胁撤单/拖款/下架"逼合作方让步，用户担心反噬。
4. 评估某个机构或国家领导人的"强硬违约"言论会带来什么实际后果。

### 语言信号 (用户的话里出现这些就应激活)

- "能不能先拖着不付，逼他们让步？"
- "有人建议宣布只还一部分债务，说是谈判筹码，怎么看？"
- "强硬一点、先违约再谈，会不会反而对我们有利？"
- "他们说不怕违约，我们还真拿他没办法吗？"

### 与相邻 skill 的区分

- 与 `eliminate-exit-leverage` 的区别：消灭退路是己方主动关闭对手的替代选项来创造谈判强制力（1971 关黄金窗口），全程不毁约；本 skill 是同一谈判杠杆主题的边界警告——当己方依赖持续流入时，威胁式毁约这个杠杆恰恰不可用。
- 与 `crisis-management-sequence` 的区别：危机序列讲处置顺序（止血→争取时间→改革→减债）与工具演进；本 skill 只回答一个策略选择问题——重谈条款时该走自愿重组还是单方面限付。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画依赖结构**
   - 完成标准: 列出己方依赖哪些持续流入（资本、货款、订单、人才、流量）及各自占比，并明确每一项谁握有"用脚投票"的权利；若己方已决定彻底退出、无持续依赖，判停并转入一般谈判策略。
2. **威胁策略压力测试**
   - 完成标准: 逐一推演每个利益相关方（供应商、债权人、客户、核心员工、本国富人）看到违约信号后的第二阶反应（收紧账期、要求预付、撤资、启动备选），并标注哪些反应不可逆。
3. **核算前门-后门流量**
   - 完成标准: 给出量级对比——单方面拖欠省下的金额 vs 预计外逃/流失的金额，并说明净效果为负的机制（对外违约信号=对内征收信号）。
4. **替换为尊重权利的重谈方案**
   - 完成标准: 给出自愿重组/展期/部分担保交换的替代谈判设计，明确以维护对方权利为前提、让对手在保留体面下让步，并指出该方案对己方重返市场/修复关系的价值。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 己方已决定彻底退出合作关系（清算式收尾）——不再依赖持续流入，威胁/毁约的代价结构完全不同。
- 用户问的是违约的法律后果、征信影响、追偿程序——那是法律与合规咨询。
- 对方已单方面毁约、己方是受害方——问题是追偿与自保，不是评估己方威胁策略。

### 作者在书中警告的失败模式

- **对抗性违约的自我失败（第7章，秘鲁/巴西）**: 秘鲁限付出口收入 10%、巴西暂停付息，短期政治得分，但不尊重债权人权利吓坏本国富人，资本加速外逃；秘鲁经济在加西亚任内崩溃，巴西沦为拉美债务国的落后者。警讯：违约策略由领袖出于意识形态或民意直接推动、本国私人资本外流与违约同步启动、号召联合行动无人响应。
- **对照组的教训（第7章，墨西哥）**: 维持债权人权利的谈判路径反而最先重返市场——痛苦但可持续。

### 作者的盲点 / 时代局限

- 本章有银行家自辩色彩：作者把秘鲁/巴西的失败几乎全部归因于"不尊重债权人权利"，低估了债务国净转移不可持续、外部冲击等结构性成因——违约的动机本身值得同情分析。
- 写于 1991-92：未预见此后主权债重组的制度演进（集体行动条款、主权债重组机制 SDRM 讨论），把"逐案+自愿重组"当作近乎终局答案；对债务国获得对等谈判地位的可能性估计不足。
- 全书未涉及中国等新兴经济体后来成为主要债权国的结构性变化，债权人结构假设停留在 80 年代商业银行叙事。

### 容易混淆的邻近方法论

- `eliminate-exit-leverage`（关闭退路创造杠杆）与 `crisis-management-sequence`（危机处置顺序）——见 A2 区分；另与 `incentive-symmetry-check` 易混：后者评估制度规则对强弱双方的激励对称性，本 skill 评估单个主体的违约策略可行性，不涉及规则设计。
