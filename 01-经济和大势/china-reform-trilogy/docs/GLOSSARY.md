# GLOSSARY — 《中国改革三部曲》共享术语词典

> 吴敬琏的特定用法。与黄奇帆卷（市场取向改革的实操层）、温铁军卷（代价视角）同属中国改革叙事但概念体系不同。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **科尔奈四分法** | ⅠA 直接行政／ⅠB 间接行政／ⅡA 无宏观控制的市场／ⅡB 有宏观控制的市场协调——目标取ⅡB | ≠ "计划 vs 市场"二分；四象限谱系 |
| **行政性分权/经济性分权** | 前者换婆婆不改协调方式（放乱收死）；后者把微观决策权还给企业 | 分权的性质比程度重要 |
| **增量改革** | 不动国有存量、体制外生长民营（近似科尔奈战略 A） | ≠ 渐进=慢；是空间双轨而非速度 |
| **粗放/集约增长** | 粗放=要素投入堆积；集约=TFP 效率驱动 | 是增长源泉之分，非投资多少 |
| **苏联现象** | 庞大科研体系+逐年下降的 TFP——制度条件缺失使投入无效 | ≠ 投入不足；是激励与共同体缺失 |
| **ICOR** | 增量资本产出率；递增=投资报酬递减=不可持续判据 | ≠ 投资率；是边际效率指标 |
| **整体协调改革论** | 分阶段整体配套（横向企业-市场-宏观同步+纵向衔接） | ≠ 激进休克；是"分步的整体" |
| **宽松环境论** | 配套改革须在总供求平衡中推出——"管住货币，放开价格" | ≠ 紧缩万能；紧缩是改革前提非目标 |
| **后发劣势** | 技术模仿捷径回避制度变革，牺牲长久繁荣（杨小凯） | ≠ 后发优势论；制度滞后风险 |
| **两种前途** | 法治的市场经济 vs 权贵资本主义——分岔口在政府改革 | ≠ 意识形态口号；是租金结构的两种均衡 |
| **有限政府+有效政府** | 限制配置资源权力+履行法治/宏观/社保/补失灵四职能 | ≠ 小政府；也 ≠ 全能政府 |
| **非禁即入** | 公民有权从事一切法律未禁止的活动——权力由人民授予 | ≠ 审批制的"法无授权不可为"（后者约束政府） |
| **金融压制/金融约束** | 麦金农-肖压制与斯蒂格利茨约束构成政策光谱 | ≠ 好坏二分；是光谱定位 |
