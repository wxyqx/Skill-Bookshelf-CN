# candidates/principles.md — 《中国改革三部曲》阶段 1 原则提取

```yaml
- id: p01
  title: 凡是广泛长期存在的问题从体制找原因
  type: principle
  source_chapter: Ⅰ第一讲
  source_quote: |
    中国落后的病根在体制——原有体制不能有效配置资源；双重体制对峙不能久拖。
  summary: |
    （与姊妹卷源头治理同构）经济落后的诊断指向体制而非资源或文化：日本"政府扶植市场"vs 俄国"抑制市场"的对照说明关键在资源配置体制。
  tags: [diagnosis]

- id: p02
  title: 先立后破，边立边破
  type: principle
  source_chapter: Ⅰ第四讲
  source_quote: |
    仅解除管制不够，须组织市场、建立秩序，"边立边破""先立后破"，反"破字当头"。
  summary: |
    改革的操作规则：市场不能靠"放"自发形成，须政府"立"（组织市场、建立秩序、立法）；打破旧秩序前先建新秩序。
  tags: [reform-methodology]

- id: p03
  title: 管住货币，放开价格
  type: principle
  source_chapter: Ⅰ第十二讲
  source_quote: |
    通货膨胀下"噪音淹没信号"，须"管住货币，放开价格"（弗里德曼论艾哈德奇迹）。
  summary: |
    价格改革的总需求前提：宏观紧平衡（管住货币）与微观放开（放开价格）必须配套——通胀环境下放开价格只会让噪音淹没信号。
  tags: [price-reform, macro]

- id: p04
  title: 利益与风险不可分割
  type: principle
  source_chapter: Ⅰ第九讲
  source_quote: |
    休伊特命题：市场机制利益与风险不可分割，只取利益面拒风险面则改革失败；锡克忠告——改革初期不可过快提高生活水平。
  summary: |
    改革的利益规则：放权让利造成"利益超前、风险滞后"→双膨胀→滞胀；受益者须同时承担风险；改革初期勿透支生活水平预期。
  tags: [incentives, reform]

- id: p05
  title: 非禁即入
  type: principle
  source_chapter: Ⅲ第六章
  source_quote: |
    公民有权从事一切法律所未禁止的活动——公民从事不侵犯他人权益的权力是与生俱来的，而不是政府恩准赐予的。
  summary: |
    市场准入的法治原则：行政许可法定（只有人大与国务院可设）；政府权力由人民授予（不可颠倒）；中关村条例为范本。
  tags: [rule-of-law, market-entry]

- id: p06
  title: 企业是创新的主体
  type: principle
  source_chapter: Ⅲ第六章
  source_quote: |
    企业才是技术创新的主体——不能靠政府指令，也不能靠优惠政策补贴；政府重要的是建立有效竞争制度。
  summary: |
    创新政策的角色规则：政府抓重点攻关只在目标清晰的少数赶超领域有效（两弹一星），普遍技术进步须靠市场竞争压力+盈利激励+知识产权保护+竞争前研发补贴（非定向选企业）。
  tags: [innovation, government-role]

- id: p07
  title: 教育赶超必须先行
  type: principle
  source_chapter: Ⅲ第六章
  source_quote: |
    日本在明治维新以后不久就开始了教育的赶超，经过几代人的努力，才奠定了经济上赶超先进国家的人力资本基础。
  summary: |
    人力资本先行的次序规则：教育赶超先于经济赶超（日本明治案例）；九年义务教育的落实是人力资本积累的底线。
  tags: [education, sequencing]

- id: p08
  title: 公共研究不应一概企业化
  type: principle
  source_chapter: Ⅲ第六章
  source_quote: |
    公共研究开发支出每增加 1%，全要素生产率就增加 0.17%，高于商业性研发的 0.13%——不加区别地要求科研机构转制为企业，无异于杀鸡取卵。
  summary: |
    科研体制规则：基础研究的公共物品性质决定其应由科学共同体以优先权竞争激励，转制企业化削弱公共知识生产；政府补贴重点放在"竞争前研发"。
  tags: [r-and-d, institutions]
```
