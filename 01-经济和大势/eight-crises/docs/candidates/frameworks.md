  title: 成本转嫁分析（危机代价归属）
  type: framework
  source_chapter: 前言、第一章（贯穿全书）
  source_quote: |
    "成本，只能对内转嫁给社会大众，造成数千万国企工人下岗、农民收入增速连续3年下降和数万起'群体事件'"。
  summary: |
    分析任何危机/改革/大项目的三问程序：①代价总量与形态（财政、就业、通胀、环境）；②代价归属——沿权力与制度通道落在谁头上（对外转嫁：殖民地/发展中国家；对内转嫁：三农、下岗工人、环境）；③转嫁通道是否存在及其制度前提。配套软/硬着陆的真判据：代价能转嫁=软着陆（体制维持），不能转嫁=硬着陆（制度变革）。
  tags: [core-theory, cost-attribution]

- id: f02
  title: 发展陷阱与外资中辍风险
  type: framework
  source_chapter: 第一章
  source_quote: |
    "'原住民'过亿的人口大国，且是未经西方那种对外侵略就完成工业化原始积累、进入产业资本扩张的发展中大国"。
  summary: |
    后发国家的发展陷阱三要件：资本极度稀缺+外资依赖+无对外转嫁渠道。机制链：复制宗主国模式→亲外资制度干犯主权→外资中辍→危机转嫁无门→经济/政治灾难。中国的对冲是"去依附"——外资中辍后以大规模劳动投入替代零资本（L 替代 K）延续工业化。
  tags: [development, foreign-capital]

- id: f03
  title: 外资—债务—危机周期律
  type: framework
  source_chapter: 第一章、第四章
  source_quote: |
    60年4次引进外资各伴生2次危机；判定标准为危机发生时起作用的因素是内生赤字还是外需波动。
  summary: |
    中国 60 年周期律：每次大规模引进外资（设备技术）→外债与结构偏斜→外资中辍或还债期→财政赤字爆发→危机；且引资内嵌对应上层建筑（苏式/西方模式），投资中断即政治动荡。判定工具：区分内生性危机（赤字主导，前 6 次）与输入型危机（外需骤降主导，后 2 次——要件：外向依存度高、外部金融风暴、无规则定制权）。
  tags: [foreign-capital, crisis-cycle]

- id: f04
  title: 政府行为三阶段（财政决定政府）
  type: framework
  source_chapter: 第一章、第四章
  source_quote: |
    "政府进入了以经营垄断性金融收益为主的'白领政府'阶段"；以地套现："高投资＋高负债＝高增长"。
  summary: |
    解读地方政府行为的框架：资本稀缺期=蓝领政府/亲资本（招商引资优先）；资本过剩期=白领政府/亲民生（公共服务导向）；财政税收决定政府行为方式。配套"以地套现"闭环：廉价征地—土地抵押融资—城市扩张—营业税增收——解释地方政府为何热衷征地扩张而非民生投入。
  tags: [government-behavior, land-finance]

- id: f05
  title: 政府退出/进入循环
  type: framework
  source_chapter: 第三、四章
  source_quote: |
    "'政府进入'是中国应对输入型危机的主要经验"。
  summary: |
    危机应对的两模式循环：政府退出（甩包袱：大包干、下岗分流、教育医疗产业化——收益留微观、成本社会化）→内需下降与外需依赖→输入型危机→政府进入（以国家信用逆周期投资：国债基建、三农新政）。两种模式各有代价归属：退出的代价由被甩包袱者承担，进入的代价由未来财政与货币持有者承担。
  tags: [crisis-response, government]

- id: f06
  title: 三农缓冲机制（三池调节）
  type: framework
  source_chapter: 第一、四章
  source_quote: |
    "蓄水池的功能日渐衰败，即将不复存在"。
  summary: |

  tags: [rural, buffer, urbanization]

- id: f07
  title: 双重过剩诊断
  type: framework
  source_chapter: 第四章
  source_quote: |
    "双重过剩条件下的恶性循环"——产能过剩和资本过剩。
  summary: |
    结构锁定诊断：劳动力过剩与制造业产能过剩互相压缩（工资被压→内需不足→更依赖外需→产能更过剩）；叠加金融资本过剩后为"三大过剩"。判据：一个经济体若同时存在劳动力过剩+产能过剩，其增长必然外需依赖型且脆弱。2008 年的中国过剩+美国的金融过剩=双重产能过剩碰撞。
  tags: [excess-capacity, structural]

- id: f08
  title: 再依附分析
  type: framework
  source_chapter: 第五部分
  source_quote: |
    "再依附"关系之后剩余向外输送的过程。
  summary: |
    分析一个后发大国在金融化全球化中的依附结构三构成：①金融赋权——本币金融资产的合法性需霸权国市场认可；②资源通道——进口依存度过半的通道在对方掌控中；③对冲增发——霸权国增发、本国被动对冲，分摊其通胀。配套"资源约束"检验（二八开→四六开：20% 人口西式现代化即突破地球资源容量）。对照"去依附"：内部化（乡土稳态）+外围通道多元化。
  tags: [geopolitics, dependency]

  type: framework
  source_chapter: 第五部分

  summary: |
