## 1. 结构（Structural）

### 类型
方法论教科书：一套"如何像宏观经济学家一样思考"的模型工具箱。不是故事书，核心内容是可以迁移的分析框架。

### 一句话主旨
宏观经济现象必须按时间范围选模型来分析——长期用价格弹性的古典理论（产出由要素与技术决定，货币只决定价格），短期用价格黏性的波动理论（需求决定产出，政策能稳定经济），政策评估则要同时看清两个时间范围的效应。

### 骨架（5 篇 19 章 + 结束语，按时间范围递进）

1. **导言（Ch1–2）**：宏观经济学研究什么 + 三大数据（GDP、CPI、失业率）怎么读、怎么失真
2. **古典理论——长期（Ch3–7）**：弹性价格下，产出由生产要素与技术决定；货币数量论解释通胀；开放经济的储蓄-投资与汇率；失业的自然率
3. **增长理论——超长期（Ch8–9）**：索洛模型（资本积累、黄金律、人口）、技术进步与内生增长、增长核算
4. **经济周期理论——短期（Ch10–14）**：黏性价格下 IS-LM 决定总需求、蒙代尔-弗莱明加入汇率、总供给与菲利普斯曲线、大萧条案例
5. **专题（Ch15–19）**：动态 DSGE 模型、稳定化政策之争（积极vs消极、规则vs斟酌处置、时间不一致）、政府债务多视角、金融系统与危机、消费与投资的微观基础
6. **结束语**：四大共识启示（①长期产出取决于供给能力/生产率 ②短期总需求影响产出 ③长期通胀是货币现象且不影响失业 ④短期政策面临通胀-失业权衡）+ 四大未解决问题（如何促进自然产出增长、是否/如何稳定经济、债务该多大规模、通胀目标制是否最优）

**论点之间的关系**：递进 + 互补。核心组织原则是"时间范围决定模型选择"（古典二分法把长期与短期分开），每一篇给一个时间范围配一组模型；专题篇再补上政策争议与微观基础。

### 作者要解决的核心问题
如何用一个模型工具箱（而非单一模型）解释三大宏观经济变量（产出、物价、就业）在短期、长期、超长期的运动，并评估政策干预的效果与边界。

## 2. 解释（Interpretive）

### 关键术语（作者本人的用法）

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| 模型（model） | 为揭示外生变量如何影响内生变量而简化现实的理论；"经济学的艺术在于判断简化的假设什么时候阐明思考、什么时候误导我们" | 不是"对现实的完整描述"，而是"针对问题的简化装置"——同一现象允许并存多个"都对"的模型 |
| 内生/外生变量 | 模型要解释的变量 / 模型视为给定的变量 | 常识不分；作者把它作为选模型的第一步：先问"这个问题里什么是我要解释的" |
| 价格弹性 vs 价格黏性 | 长期分析假设价格有弹性（市场出清），短期分析假设价格黏性 | 常识以为只有一种"经济规律"；作者认为两种假设各自描述不同时间尺度 |
| 古典二分法 | 实际变量（产出、就业、实际利率）与名义变量（物价、货币量）在长期中可以分离分析 | 日常直觉把通胀和失业绑在一起想，长期中恰恰要分开 |
| 自然失业率/自然产出水平 | 经济趋向的长期正常水平；失业围绕它波动 | "自然"不是"好"或"合理"，而是"趋势水平" |
| 节俭悖论/挤出 | 在短期（IS-LM），想多储蓄反而可能压低收入使储蓄不增；长期古典模型中政府赤字挤出投资 | 直觉认为"多储蓄总是好事"——两个时间范围答案相反 |
| 货币中性 | 长期中名义货币量只影响价格等名义变量，不影响实际变量 | 短期中货币政策真实有效，长期中无效——同一工具两种结论 |
| 可贷资金模型 | 实际利率使储蓄=投资出清，是长期利率的决定框架 | 与"央行决定利率"的日常印象互补而非相同 |
| 时间不一致性 | 事先宣布的最优政策在执行时点不再可信（相机抉择的系统性缺陷） | 常识认为"政策灵活应变更好"；作者展示灵活性本身制造通胀偏差 |
| 李嘉图等价 | 若家庭有前瞻性，减税（赤字融资）不减消费，只是推迟税收 | 直觉认为"减税刺激消费"；作者给出正反两派观点而非定论 |

### 核心命题（用自己的话）

1. **没有单一"正确"的宏观模型**——模型库 + 按问题和时间范围选模型，才是经济学家的做法。
2. **GDP 同时是总收入和总支出**（循环流恒等），读经济数据先分清存量/流量、名义/实际。
3. **所有统计指标都有系统偏差**（CPI 的替代偏差/新产品/质量变化、就业的家庭调查vs机构调查背离），读数必须带误差意识。
4. **长期中，生产率（要素+技术）决定收入水平**；收入分配由要素边际产量决定。
5. **长期通胀是货币现象**——货币数量论、费雪效应；通胀的成本主要是鞋底成本、菜单成本、相对价格扭曲、税收扭曲、不确定性（还有任意再分配）。
6. **短期中，总需求决定产出**——IS-LM：财政与货币政策通过产品市场与货币市场联动影响收入。
7. **菲利普斯曲线只是短期权衡**——通胀-失业替代只在预期未调整时成立；长期垂直。
8. **开放经济下，政策效果取决于汇率制度**（蒙代尔-弗莱明：浮动汇率下财政政策失效、货币政策有效；固定汇率相反）。
9. **相机抉择有系统性缺陷（时间不一致）**——政策可信性本身是资源，规则与承诺有价值。
10. **政府债务的代价存在争议**——传统观点（挤出资本）与李嘉图观点（代际转移中性）等并存，要按具体参数判断。
11. **金融危机是宏观风险的主要来源之一**——杠杆、期限错配、影子银行、挤兑螺旋；监管压力测试是防御工具。
12. **消费与投资决策是跨期最优问题**（生命周期/永久收入假说；托宾 q、融资约束）——预期是消费与投资波动的核心。
13. **宏观经济学既有大量共识也有未解之谜**（四大启示/四大问题），承认无知是学科成熟的表现。

### 论证链
数据先行（Ch2）→ 每篇先立基准模型（假设明确、图形+代数双轨）→ 用模型推政策比较静态 → 用案例研究检验（大萧条、日本失落的十年、2008 金融危机、德国超通胀等）→ 结束语汇总共识与分歧。全书用"模型是工具不是真理"贯穿：同一问题常给两个对立模型（如政府债务的传统vs李嘉图观点），教读者自己评价。

## 3. 批判（Critical）★

> 以下批判直接成为下游 skill 的 Boundary (B) 字段来源。

### 作者的时代局限
- 教材基于 2019 年前的数据与经验（大萧条、70 年代滞胀、2008 金融危机是主要案例库），未覆盖 2020 后的零利率+QE 常态化、疫情供应链冲击型通胀等新经验（第十版已加入负利率讨论，但仍有限）。
- 强调"通胀-失业权衡"，对"预期锚定下的低通胀高就业并存"（2019 前的美国）着墨较少。

### 作者的立场盲点
- 视角以美国/发达经济体为中心，案例多为美国数据；小型开放经济、新兴市场（资本突然停止、货币错配）只占次要篇幅。
- 假设家庭与企业大体理性最优化，行为经济学只在 Ch19（即时满足模型）轻微出现——现实中的预期形成与反应远更粗糙。
- 制度与政治经济学（央行的实际独立性、财政纪律的政治约束）作为外生背景处理。

### 未被证明的假设
- 价格黏性的微观基础（菜单成本、交错合同）是假说而非定论。
- 自然率假说（长期菲利普斯曲线垂直）在计量上难以精确检验。
- 李嘉图等价依赖家庭有前瞻性、无借贷约束——作者自己也承认这是极端基准。

### 最强反对意见
"曼昆式的综合框架看起来全面，实际上是'各打五十大板'——对每一个争议都展示两方观点却不给判断，读者学完仍不知道该信哪派。政策辩论需要的是有立场的模型，而不是模型清单。"（回应：作者明确把"教读者自己评价"当作教学目标，且结束语给出了经济学家的共识边界——这是教科书而非政策立场的自觉选择。）
