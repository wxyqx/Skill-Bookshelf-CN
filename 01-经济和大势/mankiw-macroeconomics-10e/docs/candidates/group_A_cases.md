  title: 案例研究：美国经济百年体检（三大指标）
  type: case
  source_chapter: 第1章 1.1节 案例研究"美国经济历史上的表现"
  source_quote: |
    三个至关重要的宏观经济变量是实际国内生产总值、通货膨胀率和失业率。……第一，人均实际GDP随时间的推移而增长。现在的人均实际GDP比1900年增长了8倍以上。……第二，虽然人均实际GDP在大多数年份是增长的，但这种增长并不是稳定的。
  summary: |
    方法论主题：用少量核心指标给整个经济做"体检"，数据先于理论。
    本案例展示三大指标的百年轨迹：人均实际GDP增长8倍以上但被衰退（严重则为萧条）打断；失业率不存在长期趋势但逐年波动大，衰退期飙升；通胀率大起大落。作者声明后面各章将"先讨论这些变量如何衡量，再建立理论解释它们为何这么运行"。
    怎么用：分析任何经济体先拉这三条曲线——增长看人均实际GDP、物价看通胀率、就业看失业率；先描述事实，再谈解释。
  tags: [经济数据, GDP, 案例研究, 美国经济史]

- id: Ac02
  title: 每一个时代都有自己的经济问题：总统与宏观议题
  type: case
  source_chapter: 第1章 1.1节
  source_quote: |
    每一个时代都有自己的经济问题。20世纪70年代，理查德·尼克松（Richard Nixon）、杰拉尔德·福特（Gerald Ford）和吉米·卡特（Jimmy Carter）总统都竭力制止通货膨胀率的上升但徒劳无功。
  summary: |
    方法论主题：历史为理论提供动机与检验——宏观理论是对时代问题的回应。
    书中沿年代列举：70年代通胀、80年代赤字、90年代盈余与股市繁荣、2001年减税与赤字复活、2008年金融危机；并总结"宏观经济学的基本原理不会每十年就发生变化，但必须灵活而有创造性地运用"。
    怎么用：学习任何模型时了解它诞生于什么时代问题（如IS-LM之于大萧条）；分析当下新闻时寻找历史相似期作为参照。
  tags: [经济史, 问题驱动, 理论动机]

- id: Ac03
  title: 2008-09金融危机与"大衰退"
  type: case
  source_chapter: 第1章 1.1节
  source_quote: |
    在2008年和2009年，财政部、美联储和其他政府部门的官员们全力以赴地采取各种措施来防止这种结果重现。在某种程度上，政策制定者取得了成功；失业率最高值只是2009年的10%。
  summary: |
    方法论主题：衰退的代价与政策防线的检验。
    房价下跌、按揭拖欠上升、大型金融机构破产引发危机，人们担心重演大萧条（当时四分之一想工作的美国人找不到工作）；政策全力应对后失业率峰值"仅"10%，但2006-2016年总收入年均增长只有1.3%，远低于历史正常的3.2%，复苏极慢并催生了后来的政治变化。
    怎么用：把2008-09当作"政策干预下的小号大萧条"参照系，讨论危机应对、复苏缓慢与经济状况对政治的影响。
  tags: [金融危机, 经济衰退, 政策评估]

- id: Ac04
  title: 美国通胀史的两阶段：通缩曾是常态
  type: case
  source_chapter: 第1章 1.1节（图1-2）
  source_quote: |
    在20世纪前半叶，通货膨胀率的平均值仅略高于零。价格下降称为通货紧缩（deflation），这样的时期与价格上升的时期几乎同样普遍。与此相反，在过去半个世纪，通货膨胀是常态。
  summary: |
    方法论主题：用长历史破除"物价永远上涨"的直觉；通胀是有制度成因的变量而非自然常数。
    数据显示三个时期：20世纪前半叶通缩与通胀几乎同样普遍；70年代后期价格以近10%的年率上涨；近年约2%的"相当稳定"。不同时期对应不同的货币与政策环境。
    怎么用：判断通胀前景时先问"货币与制度环境处于哪个历史形态"，不要线性外推；同时记住通缩在历史上并非怪物，只是当代人不熟悉。
  tags: [通货膨胀, 通货紧缩, 长期数据]

- id: Ac05
  title: 案例研究：2016年GDP及其组成部分
  type: case
  source_chapter: 第2章 2.1节 案例研究"GDP及其组成部分"
  source_quote: |
    2016年，美国的GDP总计约18.6万亿美元。……我们得到2016年的人均GDP——平均每个美国人的支出数量，等于57638美元。……因此，2016年平均每个美国人从国外借款-1613美元。
  summary: |
    方法论主题：用 Y=C+I+G+NX 恒等式把天文数字拆成可感的结构。
    18.6万亿÷3.23亿人=人均57638美元；其中消费约占三分之二（人均39677），投资9461，政府购买10113（含国防2256），净出口-1613——进口大于出口意味着"平均每个美国人通过从外国人那里贷款来为这一差额融资"。
    怎么用：看任何国家GDP先除以人口、再按四桶分解；贸易赤字不是抽象概念，而是"人均向外国借了这么多钱"的另一种说法。
  tags: [国民收入核算, 恒等式, 贸易赤字]

- id: Ac06
  title: 案例研究：男性、女性和劳动力参与率
  type: case
  source_chapter: 第2章 2.3节 案例研究"男性、女性和劳动力参与率"
  source_quote: |
    第二次世界大战刚结束时，男性和女性的经济角色差异很大：只有34%的女性在工作或寻找工作，而男性的百分比是86%。自那时起……2016年的数据显示超过56%的女性成为劳动力，男性的百分比则是69%。
  summary: |
    方法论主题：长期社会变化会沉淀在统计数据里，数据是社会的体温计。
    女性参与率从34%升至56%——归因于家电等新技术减少家务时间、生育控制、政治与社会态度改变；男性从86%降至69%——在校更久、更早退休、更多父亲留在家中；最近十年两者齐降的很大一部分原因是婴儿潮一代退休。
    怎么用：见到参与率变化不要只找经济周期原因，还要找技术、人口、观念等慢变量；同一数据用多因素分解解释。
  tags: [劳动力参与率, 社会变迁, 数据解读]

- id: Ac07
  title: 2001-2003"失业型复苏"之谜：两个调查的背离
  type: case
  source_chapter: 第2章 2.3节（机构调查）
  source_quote: |
    从2001年11月至2003年8月，机构调查显示就业人数下降了100万；而家庭调查显示增加了140万。一些评论家说，经济那时正在经历"失业型复苏"（jobless recovery），但是这一描述只适用于机构调查数据，而不适用于家庭调查数据。
  summary: |
    方法论主题：同一指标的两个独立测度互相矛盾时，先查口径再下结论。
    家庭调查问个人"有没有工作"（自雇算就业、两份工作算一人），机构调查数工资名单（自雇不算、两份工作算两次），另有初创企业遗漏与人口规模估计误差；2001-03的背离"仍然是一个谜"，有研究建议取两调查的平均值。
    怎么用：重要的单一数字尽量找第二种测度交叉验证；背离本身就是信息——或口径差异、或数据质量问题。
  tags: [就业统计, 数据交叉验证, 衡量误差]

- id: Ac08
  title: 1995年CPI专门小组报告：把衡量误差变成数字
  type: case
  source_chapter: 第2章 2.2节（CPI夸大了通货膨胀吗？）
  source_quote: |
    1995年，参议院财政委员会任命一个由经济学家组成的专门小组来研究CPI衡量误差的规模。该小组的结论是，CPI每年向上偏离了0.8～1.6个百分点，向上偏离的数量的"最佳估计"是1.1个百分点。这一报告导致了CPI计算方法的某些变化，因此现在人们认为误差低于1个百分点。
  summary: |
    方法论主题：指标偏差不仅可以指出，还可以被系统量化并推动校正。
    因为许多法律与私人合约含生活成本津贴（COLAs）条款、随CPI自动调整，1个百分点的偏差意味着巨额的指数化支出失真；专门小组给出0.8-1.6个百分点的区间估计与1.1的"最佳估计"，促成计算方法修改。
    怎么用：对关键指标的偏差问三件事——方向（高估/低估）、量级（几个百分点）、是否已推动修正；涉及指数化支出或合约时考虑偏差的再分配后果。
  tags: [CPI, 衡量误差, 指数化]

- id: Ac09
  title: 罗伯特·肯尼迪论GDP：衡量一切的数字漏掉了什么
  type: case
  source_chapter: 第2章 问题与应用第10题（引罗伯特·肯尼迪1968年竞选演讲）
  source_quote: |
    它衡量一切，但并不包括使我们的生活有意义的东西，……罗伯特·肯尼迪的话正确吗？
  summary: |
    方法论主题：GDP的衡量边界——只计市场交易的产品与服务，不计健康、教育质量、闲暇、分配与精神价值。
    该章习题完整引用了肯尼迪1968年演讲的著名段落：（GDP）"没有考虑到孩子们的健康、他们的教育质量或者玩耍带给他们的快乐。它没有包括我们的诗歌之美好或婚姻之力量……它既没有衡量出我们的勇气与智慧，也没有衡量出我们对祖国的热爱"。作者随后设问："肯尼迪的话正确吗？如果正确，我们为什么要关注GDP？"——引导读者自己论证GDP量什么、不量什么、为何仍有关注的价值。
    怎么用：引用GDP谈国富民强时先声明它量什么、不量什么；理解"超越GDP"的批评针对的是边界而非构造，可与GDP互补使用。
  tags: [GDP边界, 福利衡量, 批判思维]

- id: Ac10
  title: 季节性周期：Q4到Q1实际GDP平均下降约8%
  type: case
  source_chapter: 第2章 2.1节（季节性调整）
  source_quote: |
    所有这些收人衡量指标都表现出一种有规律的季节性变动模式。在一年间经济的产出逐步增加，在第四季度（10月、11月和12月）达到顶点，然后在下一年的第一季度（1月、2月和3月）下降。……从第四季度到第一季度，实际GDP平均下降约8%。
  summary: |
    方法论主题：数据里混着多种周期，读波动前先剥离可预测的部分。
    产出有稳定的季节形态（Q4峰值、Q1回落约8%），一部分源于生产能力（冬季建房难），一部分源于季节性偏好（度假、圣诞购物）；因此大多数报告的统计数字都经过季节性调整——减去仅凭季节就能预测的变动。
    怎么用：使用已调整数据时别把季节因素当作经济变化；自己分析原始数据时先剔除季节成分再看剩余波动。
  tags: [季节性调整, 时间序列, 数据清洗]
