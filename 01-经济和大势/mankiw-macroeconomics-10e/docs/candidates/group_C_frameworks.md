# 第6-8章 框架类候选（group C）

- id: Cf01
  title: 净出口与资本净流出恒等式（S-I=NX）
  type: framework
  source_chapter: 第6章 6.1节
  source_quote: |
    这种形式的国民收入核算恒等式说明，一个经济的净出口必须总是等于其储蓄和投资之间的差额。……国民收入核算恒等式表明，为资本积累融资的资金国际流动和产品与服务的国际流动是同一枚硬币的两面。
  summary: |
    解决什么问题：开放经济中一国支出可以不等于产出，贸易差额从何而来、意味着什么。
    核心逻辑：从 Y=C+I+G+NX 移项得 S-I=NX。净出口（贸易余额）恒等于储蓄减投资，即资本净流出。
    贸易盈余=对外净放贷（储蓄>投资），贸易赤字=对外净借款（投资>储蓄）；产品流出与资金流出是同一枚硬币的两面。
    怎么用：想判断或预测一国贸易余额，不要只盯进出口数据，先看它的储蓄和投资如何变动。这是全章分析的总纲，也是后面所有政策比较静态的基础。
  tags: [开放经济, 国民收入核算, 贸易余额]

- id: Cf02
  title: 小型开放经济的储蓄-投资模型
  type: framework
  source_chapter: 第6章 6.2节
  source_quote: |
    在小型开放经济中，实际利率等于世界利率。贸易余额是由在世界利率水平时储蓄和投资之间的差额决定的。
  summary: |
    解决什么问题：利率接受者的小国（完全资本流动性，r=r*），贸易余额由什么决定、对政策如何反应。
    核心逻辑：NX=(Y-C(Y-T)-G)-I(r*)，即贸易余额=世界利率水平下储蓄曲线与投资曲线的垂直距离。
    比较静态：本国财政扩张（G增/减税）→S降→贸易赤字；大国外财政扩张→世界利率升→本国I降→贸易盈余；投资需求上移→贸易赤字。
    怎么用：判断任何政策对贸易余额的影响，先问它移动的是S、I还是世界利率r*；作者明示该假设"有用并不要求它是现实性的"，美国要用附录的大型开放经济模型。
  tags: [小型开放经济, 储蓄与投资, 政策分析]

- id: Cf03
  title: 名义汇率与实际汇率的区分
  type: framework
  source_chapter: 第6章 6.3节
  source_quote: |
    名义汇率（nominalexchangerate）是两个国家通货的相对价格。……实际汇率（realexchangerate）是两国产品的相对价格。也就是说，实际汇率告诉我们，我们能按什么比率用一国的产品交换另一国的产品。
  summary: |
    解决什么问题：媒体报道的"汇率"与真正影响贸易竞争力的"汇率"不是一回事。
    核心逻辑：名义汇率e是通货的相对价格；实际汇率ε=名义汇率×价格水平比率（e×P/P*），即贸易条件。
    实际汇率高→本国产品相对贵→净出口少；实际汇率低→本国产品相对便宜→净出口多，故 NX=NX(ε) 负相关。
    怎么用：分析贸易竞争力、判断币值是否高估时必须用经过价格水平调整的实际汇率，不能只看名义汇率；两者关系式是连接货币（价格）与贸易的桥梁。
  tags: [汇率, 实际汇率, 净出口]

- id: Cf04
  title: 实际汇率的决定模型（外汇市场供求图）
  type: framework
  source_chapter: 第6章 6.3节
  source_quote: |
    因为低实际汇率使国内产品相对便宜，所以，表示净出口与实际汇率之间关系的曲线是向右下方倾斜的。因为储蓄和投资都不取决于实际汇率，所以，代表储蓄超过投资部分（S-I）的曲线是垂直的。这两条曲线的交点决定了均衡实际汇率。
  summary: |
    解决什么问题：实际汇率在什么水平出清、政策如何改变它。
    核心逻辑：把外汇市场看作供求——垂线S-I是用于换成外币的美元供给（资本净流出），NX(ε)是外国人购买本国净出口的美元需求；交点定均衡实际汇率。
    比较静态：国内财政扩张→S-I左移→实际汇率升值；国外财政扩张→r*升→I降→S-I右移→贬值；投资需求增加→升值。
    怎么用：与Cf02的贸易余额模型拼合使用，可同时得出贸易余额和汇率对任一政策的反应；"垂线是供给、斜线是需求"的读图法便于迁移。
  tags: [汇率决定, 供求模型, 政策分析]

- id: Cf05
  title: 购买力平价（一价定律的国际应用）
  type: framework
  source_chapter: 第6章 6.3节
  source_quote: |
    应用于国际市场的一价定律被称为购买力平价（purchasing-powerparity）。它是说，如果国际套利是可能的，那么，1美元（或任何一种其他通货）在每个国家都必须有同样的购买力。
  summary: |
    解决什么问题：长期中汇率由什么锚定。
    核心逻辑：套利者"低价买进、高价卖出"使同物同价；推广到国际市场⇒实际汇率固定在购买力相等的水平。模型上的表现：NX(ε)曲线极端平坦，储蓄/投资变动不影响实际（和名义）汇率，名义汇率的所有变动都来自价格水平变动。
    怎么用：作为长期基准或粗略指南使用（巨无霸指数是其通俗版）；作者同时给出边界——不可贸易品（理发）与产品不完全替代使PPP并不精确，实际汇率仍会有小幅或暂时波动。
  tags: [购买力平价, 一价定律, 套利]

  source_quote: |
    这个方程表明，稳定状态失业率U/L取决于离职率s和人职率f。离职率越高，失业率就越高；人职率越高，失业率就越低。

  type: framework

  source_quote: |
    一个处于稳态的经济会停留在那里。此外，同样重要的是，一个处于非稳态的经济将走向稳态。也就是说，无论经济初始的资本水平如何，它最终会达到稳态资本水平。在这一意义上，稳态代表经济的长期均衡。

- id: Cf16
  title: 向黄金律稳态过渡的代际权衡分析
  type: framework
  source_chapter: 第8章 8.2节
  source_quote: |
    当经济从高于黄金律开始时，达到黄金律使得所有时点的消费都更高。当经济从低于黄金律开始时，达到黄金律要求最初减少消费以增加未来的消费。
  summary: |
    解决什么问题：即使知道黄金律在哪，转型路径本身是否可取。
    核心逻辑：两种起点截然不同——资本多于黄金律：降储蓄率使每一时点消费都提高（无代价的改进）；资本少于黄金律：提储蓄率要求当代人先减消费，子孙后代受益，故政策制定者面对不同世代福利之间的取舍（"黄金律"之名的伦理含义）。
    怎么用：评估任何"提高国民储蓄"的政策前，先判断资本在黄金律的哪一侧，再问转型期的消费代价由谁承担。
  tags: [黄金律, 代际权衡, 转型动态]

- id: Cf17
  title: 人口增长效应与收支相抵投资
  type: framework
  source_chapter: 第8章 8.3节
  source_quote: |
    我们可以把（δ+n）k项看成是定义了收支相抵的投资（break-even investment）——保持人均资本存量不变所需要的投资量。……人口增长减少人均资本积累的方式与折旧类似。
  summary: |
    解决什么问题：把劳动力增长纳入索洛模型后，稳态与政策结论如何变化。
    核心逻辑：Δk=i-(δ+n)k。收支相抵投资(δ+n)k=折旧δk（磨损）+nk（给新工人装备资本）。n上升使收支相抵线上移→稳态k*与人均产出y*下降（水平效应，不改变稳态人均增长率）；有人口增长的黄金律条件变为MPK-δ=n。
    怎么用：①解释"人口增长快的国家更穷"的机制；②跨国比较时用有效投资率s/(δ+n)；③区分总量增长（以n增长）与人均增长（稳态为零，需技术进步解释）。

- id: Cf18
  title: 人口增长的两种对立模型（马尔萨斯vs克莱默）
  type: framework
  source_chapter: 第8章 8.3节
  source_quote: |
    马尔萨斯把人口增长看作生活水平提高的威胁，而经济学家迈克尔·克莱默（MichaelKremer）提出世界人口增长是促进经济繁荣的关键驱动力。
  summary: |
    解决什么问题：人口增长对生活水平是威胁还是动力——同一变量、两个方向相反的模型。
    核心逻辑：马尔萨斯——人口增长持续超过食物生产→人类注定贫困（渠道：自然资源约束；已被两个世纪的事实证伪，技术进步抵消了人口压力）。克莱默——人口越多→科学家/发明家/工程师越多→技术进步越快（渠道：创新；证据是历史增长率随人口增长，以及孤立地区人口越少技术越落后）。
    怎么用：示范"同一变量可经由不同渠道产生相反效应"；判断哪个模型适用要看技术条件与市场规模。
  tags: [人口增长, 技术进步, 对立模型]
