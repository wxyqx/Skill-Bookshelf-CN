# 模型工具箱思维：建模方法论

> 来源：曼昆《宏观经济学（第十版）》Ch1、Ch2 章首、Ch3.2

---

## R：原理（Rationale）

曼昆全书的方法论底盘：**模型是简化的理论，不存在单一"正确"的模型，建模是一门判断简化何时阐明了思考、何时造成误导的艺术**。

- **工具箱思维**：模型像木匠的工具，一个模型只解释经济的一个特定方面；结论相反的模型可以并存且都"对"，裁决标准是假设是否匹配手头的问题。
  > 原文引用：「正如木匠用不同的工具做不同的任务一样，经济学家用不同的模型来解释不同的经济现象。」（Ch1）
- **内生/外生二分是建模第一步**：模型是一台机器——外生变量是投入，内生变量是产出；"模型的答案"就是外生变动如何传导为内生变动。
  > 原文引用：「外生变量来自模型以外，是模型的投入，而内生变量则在模型之内决定，是模型的产出。」（Ch1）
- **简化程度由研究目的裁决**：简化不是缺点而是模型的本质；同一假设在这个问题里阐明思考，在那个问题里就会误导。
  > 原文引用：「经济学的艺术在于判断简化的假设什么时候阐明了我们的思考和什么时候会误导我们。」（Ch1）
- **使用模型有纪律**：结论只在假设范围内有效；总量结论还必须与微观个体逻辑一致（微观基础可以是隐性的，但不能违背）。
  > 原文引用：「经济学家在运用一个模型处理问题时必须记住模型的基础假设，判断这些假设对手头所要研究的问题是否合理。」（Ch1）
  > 原文引用：「由于总量只是描述许多个别决策的变量之和，所以，宏观经济理论是建立在微观经济基础之上的。」（Ch1）
- **模型必须回到数据**：理论—观察—检验的侦探循环，理论与事实一致才算理解；宏观做不了受控实验，历史数据就是案卷。
  > 原文引用：「他们建立理论以试图理解他们所看到的正在发生的事情。然后，他们转向更系统的观察，以便判断理论的正确性。」（Ch2 章首）

**论点关系**：五个部件构成一个循环——先分内生/外生立起模型，按目的定简化，用前查假设，比较静态出结论，最后用数据裁决；数据反驳理论时修改理论，而不是歪曲事实（章首福尔摩斯引言的警告）。这是全教材每一章反复重演的动作，也是其余宏观 skill 共同的"使用说明书"。

## I：指令（Instruction）

面对"要建模分析问题 X"或"评估某模型结论"的任务，按五步执行：

### 第一步：分清内生与外生
- 先问"这个问题里我要解释什么"——它就是内生变量（模型的产出）
- 其余暂时视为给定，设为外生（模型的投入）；不解释的变量明确交代"留给别的模型解释"
- 产出形态固定为：「外生变量 A 变动 → 内生变量 B 如何变」

### 第二步：按研究目的定简化程度
- 列出打算忽略的细节，逐项问：它对这个问题重要吗？
- 不重要 → 保持简单；重要 → 加复杂度或换模型
- 被批"模型太简单/不现实"时，先回到研究目的再辩护或修正，不为现实而现实

### 第三步：用模型前检查假设
- 写下模型的基础假设清单（如：价格弹性、市场出清、单一价格、理性预期）
- 逐条对照手头问题：明显冲突的假设 = 换模型，而不是硬套
- 下钻一层做微观基础检查：总量结论背后，是哪个个体在什么约束下做了什么选择？

### 第四步：比较静态推结论
- 一次只动一个外生变量 → 判断它移动哪条曲线、朝哪个方向 → 求新均衡 → 与旧均衡比较
- 读出全部受影响的内生变量的方向；方向不一致恰好暴露冲击的性质（需求冲击 vs 供给冲击）
- 模型给不出方向的变量，老实说"本模型无法确定"，不硬编答案

### 第五步：回到数据检验
- 明确说出自己的"理论预测"是什么，再主动找数据核对（历史事件、别国经验都是证据库）
- 理论与数据冲突 → 修改假设或换模型；绝不反过来修数据迁就理论
- 个体见闻互相矛盾时，把争论升级为数据——"见闻"的复数是"数据"（Ch2 章首）

## A1：应用场景一 — 书中案例：比萨饼市场与柯布-道格拉斯——两条建模路线

**案例一：比萨饼市场模型（Ch1）——全教材一切市场模型的原型，自带"简化何时阐明、何时误导"的说明书**
- **立模**：三件套——需求 Q^d=D(P,Y)、供给 Q^s=S(P,Pm)、均衡条件 Q^d=Q^s；内生变量是比萨饼的价格与数量，外生变量是总收入与原料价格
- **比较静态示范**：总收入增加 → 需求右移 → 价升量升；原料价格上升 → 供给左移 → 价升量减。两个内生变量方向不一致时，模型立刻暴露冲击的性质
- **阐明与误导只隔一个问题**：
  > 原文引用：「如果我们的目的是解释奶酪的价格如何影响比萨饼的平均价格和销售量，那么，比萨饼价格的多样性大概就不重要了。」（Ch1）
  > 原文引用：「如果我们的目的是解释为什么有10个比萨饼店的城镇的比萨饼价格比只有2个比萨饼店的城镇低……这个简单模型就不是那么有用了。」（Ch1）
- **教训**：问题的性质从"给定结构看价格"变成"结构本身为何如此"（店铺数量）时，被忽略的细节就成了研究对象，必须换模型——作者用这个模型自我示范了误用

**案例二：柯布-道格拉斯生产函数（Ch3.2）——从经验事实反推模型的逆向工程**
- 道格拉斯先确认稳固的经验规律：
  > 原文引用：「国民收入在资本与劳动之间的划分在长时期内大体上不变。」（Ch3）
- 再倒逼函数形式：
  > 原文引用：「什么生产函数（如果有的话）能产生不变的要素份额？」（Ch3）
- 柯布给出的答案 Y=AK^(1/3)L^(2/3)（α≈1/3 由数据校准）此后贯穿索洛模型与全书——不是先设模型再找数据支持，而是让待解释的经验事实"逼"出模型形式

## A2：应用场景二 — 未来触发：把五步循环用在书外

**场景一：「帮我建模分析 X」（如：限购令如何影响城市房租）**
1. 内生=房租与成交量；外生=限购政策、居民收入（收入本身留给别的模型解释）
2. 假设清单对照问题：租客能自由流动吗？房东统一调价吗？——"单一价格"假设在多房源竞争问题里可能致命（比萨饼教训）
3. 比较静态：政策动的是供给还是需求哪条曲线 → 推方向 → 交数据检验

**场景二：与 macro-timeframe-selection 的分工（最易混淆的边界）**
- 用户问「分析明年的产出波动，该用弹性价格还是黏性价格模型？」→ 这是"选哪类模型"的问题，先调 `macro-timeframe-selection`（明年 → 短期 → 黏性价格族）
- 类别选定之后，「这个模型怎么用、它的假设是否匹配我的具体问题」才回到本 skill
- 一句话分工：**时间范围框架回答"用哪一类工具"，本 skill 回答"怎么把一件工具用好"**

## E：边界与反例（Edge Cases）

### E1：简化踩掉关键特征 → 结论失真
- 作者明确警告：
  > 原文引用：「如果模型的假设抛弃了对要处理的问题至关重要的经济特征，那么，它们可能误导我们得出在现实世界不成立的结论。」（Ch1）
- 自查动作：接受模型结论前，把假设清单里对本题致命的省略找出来（如用"单一价格"模型研究多店竞争、用完全流动假设研究限购）

### E2：假设与研究目的错配 → 换个问题就用错
- 比萨饼店数量问题：为"奶酪价格→均价"设计的模型，被硬用到"店多的城镇为何价格更低"上失效——问题的性质变了，模型没跟着换
- 典型变体：把市场出清模型用于短期波动——劳动合约锁定三年工资、杂志价三四年一改，短期里许多价格是预先确定的：
  > 原文引用：「对研究诸如实际GDP和失业的逐年波动这类短期问题而言，价格弹性的假设就不是那么合理了。」（Ch1）
- 其中"长短期与模型类别错配"的判断归 `macro-timeframe-selection` 管，本 skill 负责更一般的"假设-目的匹配"审查

### E3：期待模型给出精确预测
- 作者给学科定位划界：
  > 原文引用：「宏观经济学家预测经济事件未来走向的能力并不比气象学家预测下一个月天气的能力强。」（Ch1）
- 两个对称错误：因预测不准而全盘否定模型；因模型存在而迷信单点预测
- 正确定位：模型的产出是机制与方向性结论，区间表述比单点数字更诚实

### E4：宏观叙事没有微观基础
- "大家都不花钱是因为信心崩了"这类总量叙事，若说不出是哪个个体在什么约束下做了什么选择，就要警惕
- 微观基础允许是隐性的，但不能与个体最优化逻辑矛盾（Ch1）

## B：适用边界（Boundary）

### ✅ 适用场景
- 要动手建模或评估他人模型：变量分类、假设审查、简化辩护、比较静态
- 争论"该用哪个模型"，或质疑"模型太简单/太理想化/不现实"
- 模型结论与数据冲突时，定位问题出在假设、简化还是数据
- 作为所有具体模型 skill 的使用说明书（怎么把一件工具用好）

### ⚠️ 谨慎使用
- "该用长期还是短期模型"的类别选择 → 先调 `macro-timeframe-selection`，本 skill 在其定位之后接管
- 模型类别已定、需要该模型内部机制细节时 → 转对应专题 skill（如 `is-lm-demand-management`）
- 侦探循环的"观察与检验"环节需要口径正确的数据 → 数据读数与换算交给 `macro-data-literacy`

### ❌ 不适用场景
- 纯数据口径与指标解读（"实际增速怎么算"→ `macro-data-literacy`）
- 计量/统计的技术操作（回归怎么跑、软件怎么用、代码怎么写）
- 个人理财或企业经营的具体操作建议
- 不涉及模型的经济新闻闲聊
