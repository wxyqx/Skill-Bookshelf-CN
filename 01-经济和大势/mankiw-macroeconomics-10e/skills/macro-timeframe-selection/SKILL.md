# 时间范围选择元框架

> 来源：曼昆《宏观经济学（第十版）》Ch1、Ch10.2、Ch12.2、结束语

---

## R：原理（Rationale）

曼昆全书的第一分岔：**没有单一"正确"的宏观模型，先按时间范围选模型**。

- **长期（价格弹性，古典理论）**：市场出清，产出由生产要素与技术决定，货币只影响名义变量（货币中性）。
  > 原文引用：「价格的弹性对研究长期问题是一个好的假设。」（Ch1）
- **短期（价格黏性，波动理论）**：许多价格固定在预先确定的水平上，总需求决定产出与就业。
  > 原文引用：「在短期，总需求影响一国生产的产品与服务的数量。」（结束语·启示2）
- **四大启示构成 2×2 地图**：长期看供给能力（启示1）、短期看总需求（启示2）、长期货币定通胀不定失业（启示3）、短期政策面临通胀-失业权衡（启示4）。
  > 原文引用：「在长期，货币增长率决定通货膨胀率，但它并不影响失业率。」（结束语·启示3）

**论点关系**：同一经济现象在两个时间范围的答案可以相反（如节俭悖论、政策效果），这不是矛盾，而是价格调整速度不同。

---

## I：指令（Instruction）

面对任何宏观问题，按三步执行：

### 第一步：识别时间范围
- 决策期/影响期是月-年级别 → **短期**框架（AD-AS、IS-LM、蒙代尔-弗莱明）
- 十年及以上 → **长期**框架（古典模型、增长理论、货币数量论）
- 问"最终/趋向来" → 长期；问"接下来/当下" → 短期

### 第二步：按范围选模型
| 问题类型 | 短期工具 | 长期工具 |
|---|---|---|
| 产出与就业 | AD-AS、IS-LM | 生产函数、索洛模型 |
| 物价 | 菲利普斯曲线、总供给 | 货币数量论、费雪效应 |
| 政策效果 | 需求管理、乘数 | 可贷资金、挤出效应、货币中性 |

### 第三步：双时间范围作答
1. 分别给出短期结论与长期结论
2. 显式指出两者差异及转换机制（价格从黏性到弹性、预期从适应到调整）
3. 若两范围答案冲突，说明取舍取决于决策者所处的时间尺度

## A1：应用场景一 — 书中案例：减税的双重身份

**问题**：减税刺激经济的效果如何评估？（Ch11 与 Ch17 的对照）
- **短期（IS-LM）**：减税增加可支配收入 → 消费增加 → 乘数放大 → 产出上升（肯尼迪减税 1964 被作为需求管理成功案例）
- **长期（可贷资金）**：减税若不削减政府购买 → 国民储蓄下降 → 利率上升 → 挤出投资（Ch17 传统观点）
- **结论模板**：同一政策在两个范围效果相反；里根减税之争（Ch17）正是因为争论双方各站在一个时间范围。

## A2：应用场景二 — 未来触发：货币政策新闻解读

**问题**：「央行降息放水，会通胀吗？」
1. 短期：利率下降 → 投资与消费增加 → 总需求扩张 → 产出与物价同升（菲利普斯曲线短期权衡）
2. 长期：若货币增速持续超过产出增速 → 通胀按货币数量论上升；一次性降息长期只改价格路径不改实际变量
3. 显式回答：「短期内刺激产出、物价温和上升；若演变成持续的货币扩张，长期通胀会等比例上升」——两个答案都给，并说明分界在价格与预期的调整速度。

## E：边界与反例（Edge Cases）

### E1：把长期模型用于短期会误判
- 用货币中性否定短期刺激的必要性（凯恩斯警告：把古典理论用于短期会把人引入歧途）
- 用市场出清模型解释失业——失业率上升时它只会说"工资没降够"，忽略需求崩塌

### E2：把短期权衡当永久菜单
- 以为可以永远用高通胀换低失业——预期调整后菲利普斯曲线垂直（弗里德曼-费尔普斯）
- 2008-09 通缩预言落空：适应性预期外推在锚定预期下失灵

### E3：时间范围判断本身可以出错
- 价格黏性的程度因行业而异（杂志 3-4 年一改价 vs 电商实时调价），机械二分会有误差
- 预期锚定可以缩短"短期"——可信的央行让长期结论更快到来

## B：适用边界（Boundary）

### ✅ 适用场景
- 解读宏观政策新闻（降息、QE、财政刺激、减税）的长短期效果
- 判断经济指标走势（房价、通胀、汇率、就业）的时间尺度
- 识别辩论双方的"鸡同鸭讲"（一方谈短期、一方谈长期）
- 作为其余宏观 skill 的定位层（先定范围，再调具体工具）

### ⚠️ 谨慎使用
- 超长期增长问题（30 年+）应直接调用增长分析工具，本框架只做定位
- 开放经济问题需叠加汇率制度维度（蒙代尔-弗莱明），本框架不单独给结论

### ❌ 不适用场景
- 个人理财的具体操作（房贷、存款选择需要财务规划而非宏观框架）
- 企业层面的微观决策（定价、雇佣）
- 纯数据查询（"现在的 GDP 是多少"）
