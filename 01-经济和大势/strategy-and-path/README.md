# 战略与路径：黄奇帆的十二堂经济课 · [`strategy-and-path/`](./)

- **作者**：黄奇帆 · 2022（上海人民出版社；2018-2021 复旦大学经济学院授课讲稿）
- **主题**：宏观经济战略 / 结构性分析 / 政策方法论
- **一句话**：在 2020-2035 窗口期，用"数据→边界条件→结构机制→量化推演→分级对策"的结构性思维拆解中国十二个重大战略议题——议题会过时，这套分析工具不会。
- **Skills**：19 个（全部通过跨域/预测力/独特性三重验证与压力测试）
