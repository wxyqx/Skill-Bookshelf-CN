# GLOSSARY — 共享术语词典

> 黄奇帆的特定用法。所有 skill 引用这些术语时以本词典为准，防止"字典义"污染。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **内循环/双循环** | 外贸依存度 64%→32%→25% 演进下的大国主动转轨，强国方略 | 不是封闭内卷、不是疫情权宜之计 |
| **超大规模单一市场** | 全门类×超大规模×"单一"（规则统一）三位一体；摊薄六项成本、引力场效应 | 不是"人口多市场大"；"单一"才是关键 |
| **边界条件** | 框定行业长期走势的慢变量约束集合；触顶即结构拐点 | 不是周期因素（可逆波动） |
| **链主/链头企业** | 掌握三链（定标准、控纽带、集中结算）的生态顶端，可无产能 | 不是营收大的龙头，也不是代工龙头 |
| **产地销/销地产** | 跨国产能布局仅有的两种基本盘，二者必居其一 | 不是泛指出海建厂 |
| **五全基因** | 平台的全空域/全流程/全场景/全解析/全价值禀赋，颠覆力的机制来源 | 不是"数字化程度高" |
| **先立后破** | 退出节奏由新系统建成进度决定+爬行钉住+安全冗余 | 不是保守拖延 |
| **兵棋推演** | 逐项双向算账（我方冲击/对方反冲/相对代价）+按发生可能性分级 | 不是口号式站队；分级≠危害度排序 |
| **要素市场化** | 商品市场 97% 市场化后的第二层次改革，"不花钱的红利型改革" | 不是政府退出一切（确权与监管是其一部分） |
| **三次分配** | 一次讲效率兼顾公平（基础）、二次讲公平兼顾效率（关键）、三次讲自愿道德激励（配套） | 不是慈善主导的分配观 |
| **制度基因** | 可遗传、难复制、经危机验证的制度组合（香港=六大自由+十大税制+三大法治） | 不是优惠政策；与"血脉"（外部输血）分开归因 |
| **滚雪球战略** | 以存量协定为雪核、由易到难逐层扩大、以存量规模为筹码 | 不是多点开花式谈判 |
| **都江堰** | 香港（汇率稳定+资本自由）与内地（货币自主+汇率稳定）两个不可能三角的互补缓冲结构 | 不是一般的金融窗口 |
| **五张牌** | 市场=王牌、产业链=王牌中的王牌、资本管制=盾牌、自主创新=关键牌、开放=底牌 | 不是报复工具清单，是可持久筹码盘点 |
| **楼面地价** | 按建筑面积折算的单位地价；标尺：不超过当期房价 1/3 | 不是土地出让单价 |
