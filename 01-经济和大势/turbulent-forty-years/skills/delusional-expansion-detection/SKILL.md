# 狂想式扩张识别与多元化失控诊断

## R — 原文 (Reading)

> 没有人去深思这种旋风式承包的可行性以及所蕴含的经营风险，没有严谨的实地调研，充满随意性的承包基数，没有资源整合
>
> — 吴晓波，《激荡三十年》1987 年章（马胜利承包百家造纸厂）

---

## I — 方法论骨架 (Interpretation)

单厂成功者最容易犯的错，是把个人经验当成可无限复制的管理模式。识别狂想式扩张有三套可操作的识别器：

一是速度三问：尽调做了吗、整合资源跟得上吗、管理/人才/技术能输出吗？三者缺任何一项，"归大堆"式归并签的只是名号不是企业，规模越大崩塌越快。马胜利两个月签 27 家、48 小时签贵阳厂、承包基数随意定，三项全缺。

二是舆论反指：当外界把决策速度本身当美德歌颂（"48 小时签约是改革的颂歌"），恰是决策质量最危险的时刻；首富登顶、地方立像、媒体报告量与经营基本面脱钩，是行业景气峰值的逆向指标。媒体的赞美措辞本身是可量化的反向信号。

三是产融结合死线：测算维持股价与利息的年成本相对主业利润之比——德隆 3 亿利润对 40 亿年耗，成本超过造血的那一刻，无论叙事多完整，游戏开局即注定崩盘；扩张的新项目若只为制造新抵押物续命，已是晚期症状。

对内的诊断动作是：多元化业务定期用外部人视角+全周期盈亏合并计算检验，新业务必须有独立于集团输血的竞争力；增长目标一旦被印在广告里对外传播，它就从经营目标变成了公关负债。

## A1 — 书中的应用 (Past Application)

### 案例 1: 马胜利承包百家造纸厂（1987-1989）
- **问题**: 靠单厂承包成名后，如何在承包制被推上神坛的年份消化"承包百家"的神话预期？
- **方法论的使用**: 作者复盘其扩张操作——无尽调、无基数评估、无管理/人才/技术输出，纯"归大堆"；48 小时签约被媒体当决策美德歌颂。
- **结论**: 速度三问全缺+舆论反指拉满，扩张速度远超管理与资源输出能力。
- **结果**: 四个月后接连失利，年底 16 家退出，1989 年初旗下 2/3 亏损，集团崩盘。

### 案例 2: 三株 900 亿狂想规划（1995-1998）
- **问题**: 营销神话期如何设定增长目标？
- **方法论的使用**: 作者引用其五年规划——增长率按 1600%→400%→200% 递减的"曲线"被印在报纸广告上；为追速度膨胀出 300 多家子公司、15 万人销售大军，管理带宽彻底失配，夸大功效的终端行为以诉讼形式回传总部。
- **结论**: 规划变成广告之日，就是目标变成负债之时；组织规模超过管理带宽后，单个终端恶行即成系统性风险。
- **结果**: 一例（后胜诉的）消费者诉讼引爆全盘，80 亿帝国瓦解。

### 案例 3: 德隆"头寸会"（2001-2004）
- **问题**: 产业+金融双轮扩张的系统能否持续？
- **方法论的使用**: 作者用产融死线检验——护盘"老三股"是刚性支出、质押融资是唯一收入，总裁每天的工作是按黑板上的头寸逐笔救火；扩张新项目的主要动机是制造新抵押物。
- **结论**: 成本>造血，扩张不是出于机会而是出于续命，宏观紧缩是天然死线。
- **结果**: 2004 年断血即崩，206.8 亿流通市值数周蒸发近 160 亿。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 董事会/投资人怀疑自己的公司扩张过速：并购频繁、新业务一个接一个、目标增速离谱，要做一次"扩张体检"。
2. 看到竞对或标的公司"48 小时闪电签约""一年千店""生态化反"类新闻刷屏，要在投不投、跟不跟之前识别狂想。
3. 多元化新业务持续烧钱，纠结砍不砍——需要独立竞争力检验与全周期盈亏合并计算。
4. 发现公司每天高层会议的主要议题是资金调度而非经营，怀疑晚期症状。

### 语言信号 (用户的话里出现这些就应激活)

- "扩张是不是太快了，该不该刹车"
- "盲目多元化/归大堆式并购怎么判断"（blind expansion, hypergrowth risk）
- "媒体都在夸它扩张神速，我怎么觉得不对劲"

### 与相邻 skill 的区分

- 与 `media-deification-cycle` 的区别: 舆论反指是本 skill 的输入信号之一，但输出是对内扩张体检与刹车决策；media-deification-cycle 管企业家外部光环的负债管理与姿态降级——同一篇赞美报道，本 skill 读出"决策质量警报"，后者读出"光环风险警报"。
- 与 `bubble-exit-discipline` 的区别: 本 skill 诊断单个企业的经营扩张，bubble-exit-discipline 诊断行业/资产价格的群体狂热并设定头寸退出时点。
- 与 `policy-cycle-positioning` 的区别: 调控周期管宏观风向位置，本 skill 管企业微观决策质量。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **跑速度三问**
   - 完成标准: 对每项扩张/并购逐一回答：尽调做了吗、整合资源（资金/供应链/账期）跟得上吗、能否向被并方输出管理/人才/技术？输出三问核对表，任一缺项即标红。
   - 判停条件: 若三问全部通过且增速在管理带宽内，判定非狂想式扩张，转常规增长管理建议。

2. **核查舆论反指**
   - 完成标准: 检索媒体对目标企业扩张速度的措辞——"闪电签约""效率惊人"式赞美出现即记为反向信号；同步核查首富/典型荣誉、报告量与基本面脱钩度，给出周期位置评级。

3. **测算产融结合死线**
   - 完成标准: 计算维持股价（护盘、对赌）与利息的年成本相对主业利润之比；>1 即判定开局已定；并核查新项目动机是否"制造抵押物续命"、高管例会是否以资金调度为主题。

4. **输出刹车/止损方案**
   - 完成标准: 按诊断结论输出：收缩清单（砍哪些归大堆业务）、独立竞争力检验计划（新业务断奶期限）、增长目标内部化（撤回一切对外传播的增速承诺），并给出复查时点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是"怎么做一次规范的并购尽调/投后整合"——那是通用战略咨询，本 skill 只做狂想识别与诊断，不教尽调操作。
- 行业或资产价格整体过热的判断与逃顶——那是市场层面的群体狂热，归 bubble-exit-discipline。
- 个人职业选择"要不要加入一家高速扩张的公司"——风险主体不同，方法论不迁移。

### 作者在书中警告的失败模式

- 亚细亚式连锁失控：单店模型未验证就全国复制，各地商场无一赢利仍继续开店，供应商挤兑在荣誉墙下拉横幅。
- 巨人式豪赌：主营现金牛全部资金与象征性工程绑定、多线同时放血，缺 1000 万即全盘崩塌。
- 乐视式没有奶牛的狂奔：烧钱业务清单长于造血清单且无明确输血者，应收款暴增粉饰报表，信心资产瞬间归零。

### 作者的盲点 / 时代局限

- 事后归因/幸存者偏差: 作者只解剖崩盘者（马胜利、三株、德隆、乐视），同样高速扩张而成功的企业未作对照组——"快"与"狂想"的边界事实上由结局倒推，存在结果偏差。
- 数据口径: 三株 900 亿规划、德隆 206.8 亿市值等数字多为媒体报道口径，未经独立核验，识别器的定量阈值只能示意。
- 当代人写当代史: 作者自认"二次建构"，对贾跃亭等人物的"战略的空虚"式判词含价值观前置，诊断时应剥离修辞只取信号。

### 容易混淆的邻近方法论

- media-deification-cycle：共享舆论反指信号，输出分野在对外姿态 vs 对内刹车。
- bubble-exit-discipline：企业层 vs 市场/资产价格层。
