# 产权自救"半步走"——不碰红线的渐进变革

## R — 原文 (Reading)

> 他深知在当前的国情下，股权清晰到人是一块"熔化中的黄金"，既诱人又毁人，他不甘心无所作为，也绝不铤而走险。
>
> — 吴晓波，《激荡四十年》1994 年章（潘宁）

---

## I — 方法论骨架 (Interpretation)

制度窗口没有打开时，产权诉求（把股权清晰到人、管理层收购、员工持股）不是"做或不做"的单选题，而是"走半步还是走整步"的分岔题。半步方案只触碰收益与增量，不触碰所有权名分：分红权、增值权、利润分成、子公司层面引入私人合资者、代持但书面缓议转正——这些都可逆、可解释、可收缩；整步方案（挪用资金购股、绕开审批的激进 MBO、把国资直接装进个人兜里）一步到位但不可逆，一旦遭遇清查即成刑事证据。

书中的经验分布极其残酷：走半步者穿越周期（柳传志趁资产未显性化分"纸上的饼"、鲁冠球"花钱买不管"以定额上缴置换干预、TCL 用增量量化契约过关），走整步者多系狱（郑俊怀挪用资金曲线 MBO 获罪）。操作规则有两条：第一，接受次优方案——半步的价值在"可升级的接口"而不在"一步到位"；第二，把"一步到位"的冲动压制到窗口开启日，接口条款写明何时、以何对价、经何程序转正。半步不是不做，而是让每一次不彻底的动作都成为下一步的合法台阶。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 潘宁的"熔化中的黄金"（1994，容声/科龙前身）
- **问题**: 镇集体所有制企业容声业绩极强，管理层对产权归属不甘心，但地方控股结构下股权清晰到人在当时既无政策依据又极度敏感。
- **方法论的使用**: 潘宁把股权清晰到人定位为"熔化中的黄金"——既诱人又毁人，选择"不甘心无所作为，也绝不铤而走险"的半步姿态：在能争取的范围内做机制改良、不碰所有权名分。
- **结论**: 窗口未开时最优策略是可进可退的次优安排，而非孤注一掷的整步动作。
- **结果**: 潘宁本人在任内未因产权问题获罪；但书中同时警示：集体控股结构下管理层终究无产权话语权（其继任者李经纬三套方案皆被否、潘宁无理由辞职），半步方案救急不救穷，窗口一旦彻底关闭仍需另寻出路。

### 案例 2: 郑俊怀整步 MBO 获罪 vs TCL 增量量化契约过关（1997-2004）
- **问题**: 同样面对国资控股企业的产权诉求，伊利郑俊怀与 TCL 团队都要解决"贡献与名分不匹配"。
- **方法论的使用**: 郑俊怀选择走整步——挪用公司资金曲线 MBO 购股，游走灰色地带；TCL 则走半步——以增量资产量化契约定管理层收益，不动存量所有权，外部边界清晰、绕开最敏感的个人股份地带。
- **结论**: 同一诉求下，半步（增量分成、契约量化）可升级可解释，整步（挪用购股、激进 MBO）不可逆且随时可被追诉。
- **结果**: 郑俊怀 2004 年案发入狱；TCL 集团整体上市，管理层激励落地。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 国资/集体控股公司的创始团队或管理层想做股权激励或 MBO，但现行政策、审批口径不允许，正在犹豫"要不要绕"。
2. 用户已有一个灰区产权方案（挪用资金购股、代持绕审批、阴阳协议）来征求意见，需要风险定性。
3. 受限行业公司想给核心员工持股，因牌照/外资比例/所有制限制无法直接登记股权，需要替代结构。
4. 企业做过半步安排（分红权、代持、虚拟股权），现在问"怎么设计窗口开启后的转正接口"。
5. 管理层被劝"先忍忍别动手"，需要论证"半步不是躺平"的行动清单。

### 语言信号 (用户的话里出现这些就应激活)

- "政策不让做员工持股，但团队必须要激励，怎么办？"
- "曲线 MBO / 绕一下审批 / 先私下把股份定了"
- "股权清晰到人是不是太敏感了？"
- "先签个代持协议，等政策开了再转正"
- "虚拟股权 / 分红权 / 持股平台替代直接持股"

### 与相邻 skill 的区分

- 与 `property-rights-timing` 的区别: 那是判断产权改革的整体时机与路径矩阵（是不是现在改、走哪条大路、错过窗口怎么办），本 skill 是窗口确认未开时的方案形态设计——先有时机判断，后用半步设计。
- 与 `red-hat-structure-decision` 的区别: 那是"要不要借集体/国有身份"的挂靠交易账（借身份的收益与赎回），本 skill 是"已有产权诉求但窗口未开"的自救设计；一个向外借身份，一个向内做安排。
- 与 `institutional-leverage-negotiation` 的区别: 与审批方的豁免谈判属于"争取窗口"的动作，本 skill 处理"窗口不开时怎么办"；两者可先后衔接。

## E — 可执行步骤 (Execution)

1. **定性诉求与窗口状态**
   - 明确产权诉求的完整形态（谁、多少、以何对价），并核对现行政策与审批口径，判定窗口"未开、半开、已开"。
   - 完成标准: 一页诉求书+窗口状态结论；窗口已开则转 `property-rights-timing`，本 skill 退出。

2. **拆解收益权与所有权**
   - 把"清晰到人"的诉求拆开：哪些利益可通过收益安排实现（分红、增值、超额利润分成），哪些必须等所有权名分。
   - 完成标准: 产出一栏"可半步实现"、一栏"必须等窗口"的拆解表。

3. **拼装半步方案**
   - 从菜单（分红权/增值权/增量量化契约/子公司合资/代持缓议）中选择组合，确保不动存量所有权、不挪用资金、可解释可收缩。
   - 完成标准: 方案通过三项测试——合法性（不构成挪用/贪贿证据）、可逆性（政策突变可退回）、解释性（能以一句话向监管描述）。
   - 判停条件: 若任何一项测试不通过而用户坚持整步方案，明确出具风险警示（郑俊怀式结局）并终止参与设计。

4. **写入转正接口**
   - 在协议中明确"待窗口开启"的转正条款：触发条件、对价公式、程序路径，使半步安排成为台阶而非终点。
   - 完成标准: 用户得到含接口条款的方案文本，及一份"窗口开启日动作清单"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 制度窗口已开、产权改革可以公开推进——此时需要的是整体时机与路径决策（`property-rights-timing`），半步方案反而会浪费窗口。
- 诉求本质是"要不要挂靠/借身份"以换取准入与安全——那是红帽子交易账（`red-hat-structure-decision`），对象是身份而非股权。
- 用户希望与主管部门谈判争取试点授权——转 `institutional-leverage-negotiation`；本 skill 假定谈判空间已评估完毕。

### 作者在书中警告的失败模式

- 郑俊怀走整步（挪用公司资金曲线 MBO）获罪（j30_2002）——灰区产权诉求的整步形态在清查面前就是现成的刑事证据链。
- 郎咸平风暴中的"见光死"（j30_2004）：几乎所有涉国资的改制方案经不起公开审查，"只能做、不能说，一说全是错"——半步方案同样要执行媒体静默纪律。
- 健力宝李经纬（j30_1998/2002）：集体控股下管理层无产权话语权，发动舆论战反而把政府逼进墙角——半步走不等于拖延到最后用对抗摊牌。
- "宁与外客，不与家人"（j30_2002）：官员为避国资流失问责宁可卖给外来资本，管理层等待观望可能等来的是出局而非转正——接口设计要评估"窗口开启日自己还在不在场"。

### 作者的盲点 / 时代局限

- 作者自认当代人写当代史、基于事实的二次建构——半步走叙事主要由过关者（柳传志、TCL）与本书同情的悲剧者（潘宁）构成，中间大量不彻底安排的平淡结局未被呈现，存在幸存者偏差。
- 数据与案例口径：书中改制案例多为事后叙述与媒体材料，交易对价、审批过程等关键数据未经独立核验，"TCL 过关、郑俊怀获罪"的对照有简化之嫌。
- 归因摇摆：作者在赞半步者之智与叹制度之困之间摇摆（重个人轻结构/重结构轻个人），使用时应区分"方案设计问题"与"窗口根本不存在问题"。
- 时代边界：成书于 2018 年，混合所有制改革、注册制下的员工持股新规等窗口形态与书中年代不同，"熔化中的黄金"的温度需按当下政策重新校准。

### 容易混淆的邻近方法论

- `initial-identity-pricing`：若用户问的是公司注册时选什么身份（个体 vs 挂靠）对未来的远期定价，那是初始身份问题；本 skill 处理已成立企业的存量产权诉求。
- "延迟满足/渐进改革"常识：门外汉只说"别激进、慢慢来"，本 skill 的独特处在于半步方案菜单、三项测试（合法性/可逆性/解释性）与转正接口的非对称设计。
