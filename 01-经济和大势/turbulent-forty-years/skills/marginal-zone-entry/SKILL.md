# 边区效应选址法——旧体制疏于防范处突破

## R — 原文 (Reading)

> 温州十大市场大多坐落在水陆交通都不是很便利的地方……在那些地方，"左"的思潮相对薄弱，计划经济的束缚相对较弱……中国改革的经验证明，对旧体制的最初突破，往往发生在旧体制最疏于防范的地方。
>
> — 吴晓波引温州研究者张仁寿语，《激荡四十年》1983年章

---

## I — 方法论骨架 (Interpretation)

制度突破有空间规律：同一门生意，罪与非罪取决于落在哪里。选址决策分三层：

1. **政治安全优先于商业便利**: 灰色或创新业务应优先落在监管半径大、地方主官有改革声誉且敢担责的"政策凹地"，而不是监管最密、商业资源最好的中心城市。义乌、温州的山谷市场交通极不便利却成大市，决定变量是观念宽松度而非区位。
2. **行为定性的地域函数**: 同为倒卖，王石在深圳倒玉米发财，牟其中在别处倒钟入狱——同一商业行为的合法性由所在地的政策环境定义。选址前先调查候选地对该行为的既往执法记录与默许程度。
3. **蜂群效应与撤离时钟**: 凹地不是资产而是消耗品。窗口打开后套利者指数级涌入（海南半年新增872家公司），凹地必然被填平；模式跑通、同行扎堆之日，就是撤离或升级合规之时——必须提前写死撤离触发条件。

## A1 — 书中的应用 (Past Application)

### 案例 1: 山谷里的温州市场（1983）
- **问题**: 个体贩运在观念未解冻的环境里随时可能被取缔，市场落在哪里才能活？
- **方法论的使用**: 温州十大市场选址在"左"的思潮薄弱、计划束缚较弱的水陆交通不便之地——放弃商业便利，换取政治安全。
- **结论**: 旧体制最疏于防范处即最优选址。
- **结果**: 市场在历次整肃中存活并壮大，再生腈纶衣裤等巨量商品从极不便捷之地贩进运出。

### 案例 2: 海南——凹地的失控与查处（1985）
- **问题**: 中央特殊政策放权给海南，凹地红利有多大、能持续多久？
- **方法论的使用**: 半年内全岛新增872家公司、签发8.9万辆汽车进口批文——蜂群效应使原定1.3万辆的规模彻底失控，凹地被填平。
- **结论**: 凹地被蜂群填平后必然招致查处，'政策'变现为'真金白银'的窗口关闭。
- **结果**: 新华社通电定性"严重违法乱纪"，雷宇撤职，全岛疯狂被清算。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一项处于监管灰区的新业务（类金融、跨境、数据交易等）要选落地区域，用户在监管严的中心城市与敢担责的边缘地区之间纠结。
2. 某地主官主动招手"可以先干起来"，用户要评估这个地方的政治安全性是否可信、主官的担责记录如何。
3. 同行纷纷扎堆某个试点区/自贸区，用户要判断这个"政策洼地"还剩多少窗口、何时该撤或转正规。
4. 用户要评估把业务迁往凹地的迁移成本与迁移时机。

### 语言信号 (用户的话里出现这些就应激活)

- "这个业务落在哪里最不容易被打？"
- "政策洼地/监管洼地/试点区还能吃多久？"
- "当地领导说让我们先干，靠谱吗？"
- "同行都搬过去了，我们要不要跟？"
- "regulatory haven, which jurisdiction, gray-zone location, when to exit"

### 与相邻 skill 的区分

- 与 `latecomer-resource-borrowing` 的区别: f17 管资源劣势下的竞争——借外脑、借淘汰设备、切巨头不屑做的缝隙市场（商业维度的切入）；f05 管空间维度的选址——政治安全性优先于商业便利。缝隙市场不一定在洼地，洼地里也要选缝隙。
- 与 `policy-signal-capture` 的区别: f01 是"何时动"的时间决策，f05 是"落在哪"的空间决策；同一次抢跑既需要时机判断也需要选址判断，两者组合使用。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画监管半径地图**
   - 完成标准: 对候选地逐个评估——地方主官的改革声誉与担责记录、当地对该业务的既往执法与默许记录、监管半径（离监管中心的距离与关注度），按"政治安全>商业便利"输出候选地排序。

2. **行为定性预判**
   - 完成标准: 对同一商业行为在候选地的罪与非罪/管与不管做对照表（引用当地既往个案），明确"同样的事在 A 地没事、在 B 地有事"的历史证据。
   - 判停条件: 若业务在所有候选地均完全合法或均明确非法，本 skill 不适用，转一般合规或放弃评估。

3. **预设蜂群时钟**
   - 完成标准: 写死撤离/升级合规的触发条件——如"模式被跑通验证后多少个月内""同业进入数量阈值""当地执法动作升级"，并明确凹地填平后的两个去向（撤离到新凹地，或转正规化）。

4. **输出迁移与撤离预案**
   - 完成标准: 给出迁移成本清单（资质重办、团队、客户迁移）与撤离时限安排，确保撤离触发条件触发时可在预定周期内执行完毕。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯商业维度选址（人才、租金、物流、贴近市场）为主导、业务不处于监管灰区——常规选址分析即可，政治安全变量无权重。
- 用户问的是"政策什么时候出"的时间问题——那是 policy-signal-capture 或 policy-cycle-positioning。
- 业务完全合法，只想争取地方补贴优惠——属于政策申报，不是灰区选址。

### 作者在书中警告的失败模式

- **凹地变失控现场**（1985 海南案）: 放权凹地引来蜂群指数级涌入，规模失控后凹地被查处收回——洼地的红利与清算是同一枚硬币，书中定性此为"中央放权→地方草船借箭→失控→中央查处"循环的原型。
- **洼地无规范则退化**（1986 温州抬会）: 监管缺位的凹地里，民间金融退化为几何级数庞氏结构，30万人卷入、8万多户破产——洼地不是法外红利区，失去约束的游戏以雪崩收场。

### 作者的盲点 / 时代局限

- **当代人写当代史的二次建构**: "边区效应"是作者对张仁寿论断的引用与文学化放大，作为一个"规律"其证据主要来自温州个案，作者未做跨地区系统检验。
- **幸存者偏差**: 存活壮大的温州市场被书写；选址相似但被取缔的市场（历年整顿中大量关闭的边缘市场）没有进入统计，"政治安全选址"的成功率被高估。
- **数据口径问题**: "十大市场""半年872家公司"等数字为书中转述，未经独立核验。
- **重个人轻结构的归因摇摆**: 时而把边缘地区成市归因于地方官员个人胆识（雷宇式清官叙事），时而归因于观念结构，两种归因在章节间摇摆。
- **2018年写作的时代边界**: 写作时点后的监管趋势（全国统一执法、金融科技持牌、反垄断全国一盘棋）系统性压缩了"监管洼地"的存在空间，旧地图上标注的凹地机制未必仍然成立。

### 容易混淆的邻近方法论

- `marginal-zone-entry` 与 `dormant-clause-interpretation`: 后者告诉你在文本层面"原则上"是否留口，前者告诉你在空间层面"哪里执行最松"——先读文件再选地方，常需连用。
