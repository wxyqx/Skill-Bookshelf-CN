# 产权界定路径与时机决策

## R — 原文 (Reading)

> 今天看来，我们做了一件非常重要而又聪明的事。因为当时大家分的是一张空饼，谁也不会计较，如果在今天，已经形成了一张真实的饼，再来讨论方案就会困难100倍了。
>
> — 吴晓波，《激荡三十年》1994 年章（柳传志追述联想分红权方案）

---

## I — 方法论骨架 (Interpretation)

产权清晰化的可行性随资产显性化程度递减：饼还是纸上的字时，各方不计较，方案好谈；饼一旦做实，每个百分点的既得利益都会变成谈判死结。所以第一个决策变量是时机——抢在资产显性化之前界定，错过了就没有"早知道"。

窗口关闭后只剩两条路，且都必须直面其代价：一是灰色 MBO（挪用/变通资金购股），高曝光且触碰国资，历史上多获罪；二是退出再创业、引入外部合法资本走上市，慢但活得成。同一制度环境下的对照（郑俊怀 vs 牛根生）证明：路径选择本身决定生死，经营业绩不构成豁免。

路径设计上，可行方案共享一个诀窍：外部边界清晰、内部边界模糊——先用"花钱买不管"、子公司引进私人合资者、增量增值量化等结构绕开最敏感的"个人股份"地带，留出日后升级的接口。

传播纪律是硬约束：涉国资处置的方案"只能做、不能说，一说全是错"，公开审查之下几乎全部经不起推敲。正确顺序是先做制度论证、争取上层背书，执行期媒体静默。

谱系规律用于预估窗口宽度：小企业易改大企业难改，亏损企业易改赢利企业难改——越知名、越赢利，窗口越窄；业绩暴涨时反而应做减法（新设主体承接增量），而不是加速推进界定。

## A1 — 书中的应用 (Past Application)

### 案例 1: 联想"分一张空饼"（1994）
- **问题**: 中科院全资的联想因身陷重围、账面利润未兑现，员工与院方都把"资产"当作纸上财富；产权如何界定而各方都不跳起来？
- **方法论的使用**: 柳传志趁"未来混沌而黯淡"、数字尚是"纸上财富"时，推动员工分红权方案——在饼未烙成时切分比例，各方机会成本最低。
- **结论**: 先分空饼锁定比例框架，把"个人股份"争议推迟到结构已立之后。
- **结果**: 2000 年该方案基础上 35% 分红权升级为股权，联想资产清晰"百转千回，终于水到渠成"。

### 案例 2: 郑俊怀曲线 MBO vs 牛根生另起炉灶（1998-2004）
- **问题**: 同处产权不清的伊利系，管理层如何取得本应属于自己的企业控制权？
- **方法论的使用**: 郑俊怀把国企做到年利税数亿、身居改革人物特写主角，仍选择挪用公司资金曲线 MBO 购股——窗口已关、业绩越显性、灰色购股越致命；被免职的牛根生出走创蒙牛，引摩根士丹利等 6000 万美元投资、签对赌、走合法外部融资。
- **结论**: 产权不可得时，"退出再创业+国际资本"优于"内部灰色赎买"。
- **结果**: 郑俊怀入狱；蒙牛 2004 年香港上市。

### 案例 3: 郎顾之争——见光死的总爆发（2004）
- **问题**: 1998 年以来的产权改制方案被郎咸平置于公开财务审查之下。
- **方法论的使用**: 对照各方应对——顾雏军高调研讨会+广告自证成唯一炮灰；海尔产权未清只能隐忍；产权早解决的联想敢在同期 12.5 亿美元收购 IBM PC。
- **结论**: 改制方案"经不起公开审查"是普遍规律，传播禁忌本身就是方法论的一部分。
- **结果**: 春兰等改制方案批量搁置，产权清晰化运动进入总清算。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 集体/国有控股企业的创始人或管理层问：现在想明晰股权、做 MBO 或股改，晚不晚？走什么路径？
2. 体制内企业业绩暴涨，创始人纠结"趁现在有钱有声誉把产权的事办了"，需要判断窗口实际在收窄。
3. 改制方案被媒体或对手公开质疑，问要不要出面自证、要不要宣传改制成果。
4. 新设主体还是改造旧主体：增量业务该放哪里，才能绕开存量产权死结。

### 语言信号 (用户的话里出现这些就应激活)

- "产权不清/产权纠纷，管理层持股（MBO）该怎么做"
- "国企/集体企业股改、混改，现在明晰股权晚不晚"
- "改制方案被质疑国资流失，怎么回应" / "ownership clarification, MBO timing"

### 与相邻 skill 的区分

- 与 `initial-identity-pricing` 的区别: 本 skill 管企业已存在、产权已不清时的"补救性界定"（时机与路径）；initial-identity-pricing 管企业诞生时的注册身份前瞻定价——一个是后验摘帽，一个是先验避坑。
- 与 `half-step-rights-reform` 的区别: 本 skill 判断"窗口开没开、走哪条大路"；half-step-rights-reform 在窗口未开时设计可升级的次优方案（分红权/增量分成/留接口），是本 skill 结论"此路暂不通"之后的落地工具。
- 与 `red-hat-structure-decision` 的区别: 红帽子管"要不要戴上帽子"的挂靠交易结构；本 skill 管帽子已戴上或从未摘干净时的界定与赎回时机。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **测绘产权现状与窗口宽度**
   - 完成标准: 列清企业所有制属性、实际控制人、国资/集体成分占比、资产显性化程度（利润、估值、知名度、上市与否）；按"小易大难、亏易盈难"给出窗口宽度评级（宽/窄/已关闭）。

2. **判定路径菜单**
   - 完成标准: 窗口宽→列出"分空饼"式即时界定方案（增量量化、花钱买不管、子公司合资）；窗口窄或已关→明确只剩灰色 MBO（标红为高危）与另起炉灶+外部资本两条，用郑俊怀/牛根生对照说明各自结局，不做第三种幻想。
   - 判停条件: 若企业为纯私营且登记清晰，判定无产权界定问题，结束并转出。

3. **套用传播与结构纪律**
   - 完成标准: 给出执行顺序——先制度论证与上层背书、执行期媒体静默、被质疑时绝不高调自证；方案设计中体现"外部边界清晰、内部边界模糊"，绕开个人股份敏感带并预留升级接口。

4. **输出时机建议**
   - 完成标准: 给出"现在做/推迟/做减法（新设主体承接增量）"三选一的明确建议及触发条件（如业绩暴涨期建议做减法而非推进界定）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯私营、工商登记清晰的企业谈"产权改革"——它没有这个问题，讨论股权激励请走通用公司治理。
- 用户只是问工商注册流程、材料、核名——那是行政事务，不涉及政商博弈。
- 新公司尚未诞生时的身份选择——那是 initial-identity-pricing 的前瞻场景，用本 skill 会把"预防"误诊为"治疗"。

### 作者在书中警告的失败模式

- 郑俊怀式灰色 MBO：窗口关闭后挪用资金购股，游走灰色地带终获罪——业绩与声誉不构成豁免。
- 万宝式"改革合法性≠产权合法性"：越级借更高部门搞试点短期可行，直接产权人握人事权的反噬必然到来（邓韶深身败名裂，死后才获审计正名）。
- 见光死：顾雏军高调自证成唯一炮灰；几乎所有改制方案经不起公开审查。

### 作者的盲点 / 时代局限

- 幸存者偏差: 柳传志"聪明事"是成功者的追述叙事，同期分饼失败或被拒的方案几乎没有留存记录，"抢空饼窗口"的有效性由幸存者反推。
- 归因摇摆: 作者时而把产权悲剧归于个人选择（郑俊怀"游走灰色"），时而归于制度结构（"宁与外客不与家人"的官员免责理性），人物与结构的权重在不同章节漂移。
- 数据口径: "国资流失"金额多来自论战双方（郎咸平 vs 企业方）各自口径，未经独立核验，不宜当作定量依据。
- 当代人写当代史: 作者自认"基于事实的二次建构"，对顾雏军、李经纬等人物的褒贬已含价值观支配，引用其因果归纳时应保持中立距离。

### 容易混淆的邻近方法论

- half-step-rights-reform：半步方案是本 skill 在"窗口未开"结论下的配套工具，不是并列的替代路径。
- business-government-distance：政商距离管企业家公共姿态，不直接回答"产权怎么界定"。
