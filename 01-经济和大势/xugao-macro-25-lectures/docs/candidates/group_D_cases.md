# 候选·案例（case）— 第7-9讲 消费与储蓄三部曲（均绑定方法论主题）

- id: Dc01
  title: 中国居民消费占比低于世界平均约两个标准差（PWT 数据）
  type: case
  source_chapter: 第7讲 7.1.2（图7-1）
  source_quote: |
    图中，横轴是以购买力平价（PPP）计算……的人均GDP水平。……很明显，中国在人均收入水平提升的过程中，消费占比明显下滑。目前，这个比重已经低于世界平均水平20多个百分点。
  summary: |
    方法论主题：基本事实的读法（Df01）。宾州世界表数据把各国居民消费占比对人均收入画
    散点，世界均值加正负两个标准差构成参照带；中国随收入增长消费占比不升反降，目前已
    低于国际均值 20 多个百分点、约两个标准差。用途：演示如何用"跨国横截面+分布带"把
    一个模糊印象（中国消费低）变成有参照系、有距离度量的事实陈述，同时保持"偏低≠不足"
    的纪律。
  tags: [消费占比, 跨国比较, 基本事实]

- id: Dc02
  title: 中日韩同受儒家文化影响但消费占比迥异——排除文化解释
  type: case
  source_chapter: 第7讲 7.1.2（图7-2）
  source_quote: |
    中国这种低消费状况不能归因于重节俭的儒家文化。图7-2将中国的消费比重与同样受到儒家文化影响的日本和韩国做了对比。这里同样可以看到中国的消费占比远远低于其他两个东亚国家。
  summary: |
    方法论主题：控制变量式的归因排除。日韩与中国同属儒家文化圈，若文化是低消费的原因，
    三国消费占比应相近；数据显示日韩消费占比远高于中国，文化解释被排除。用途：示范"找
    到共享该解释变量的反例组来证伪单一文化/习惯解释"的归因技术，为后续把原因定位到所
    有制与分配结构扫清竞争性假说。
  tags: [儒家文化, 归因排除, 跨国比较]

- id: Dc03
  title: 中国国民总储蓄率 40%+ 与世界（不含中国）约 20% 的对照及部门构成
  type: case
  source_chapter: 第7讲 7.1.2（图7-3、图7-4）
  source_quote: |
    在2000年之后，中国国民总储蓄占GDP的比重常年维持在40%以上。次贷危机前的最高点甚至超过了50%。而剔除中国后的世界各国家和地区的平均储蓄率则一直稳定在略高于20%的水平。
  summary: |
    方法论主题：储蓄的部门分解框架（Df06）。WEO 数据给出总量反差（中国 40%+ 对世界
    20%+）；资金流量表进一步分解：居民与非金融企业储蓄各占 GDP 近 20%，政府约 5%
    （多数国家政府是负储蓄者），金融机构 2%-3% 可忽略。用途：演示"总量差异→部门定位"
    的标准动作——把"中国储蓄高"落到"居民、企业双高"上，为第9讲的诊断提供数据入口。
  tags: [国民储蓄, 部门分解, 资金流量表]

- id: Dc04
  title: 居民储蓄与企业储蓄的跨国负相关及中国的离群点
  type: case
  source_chapter: 第7讲 7.1.2（图7-5）；第9讲 9.1（图9-1）
  source_quote: |
    第一，在除开中国和OPEC国家的世界各国中，居民储蓄和企业储蓄占比之间有一个非常清楚的负相关关系……第二，中国以同时较高的居民储蓄和企业储蓄占比而与其他国家区别了开来。
  summary: |
    方法论主题：刺穿企业帷幕的经验对应物（Dp03）。剔除 OPEC 国家（经济结构畸形）后，
    世界各国居民储蓄与企业储蓄占比显著负相关（回归线 y=-0.30x+13.35），这正是"两者都
    是居民财富、此消彼长"的幕帷机制在数据中的投影；中国同时双高，成为唯一系统性离群
    点。用途：一张图同时完成理论预言的检验与中国特殊性的定位，是"模型推出可检验含义→
    数据验证"的示范。
  tags: [刺穿企业帷幕, 负相关, 跨国比较]

- id: Dc05
  title: 第三次全国经济普查：国企占企业部门资产 54%，居民分红微乎其微
  type: case
  source_chapter: 第9讲 9.1（图9-2、图9-3）
  source_quote: |
    中国第二和第三产业企业所拥有的200多万亿元的资产中，有54%为国有企业所有，10%为外资及港澳台资企业所有。包括民营企业在内的其他所有制企业占比仅为36%。……中国居民部门从企业部门获得的分红收入微乎其微。
  summary: |
    方法论主题：资本所有权判据（Dp05）的数据落地。2011 年三经普显示国企占企业部门资产
    超过一半；资金流量表显示居民从企业获得的分红近于零，说明居民与企业部门的产权联系
    很弱。用途：把"资本是否归居民所有"的抽象判据变成两个可查的统计口径（资产所有制构
    成、部门间分红流），示范如何为理论判据匹配数据代理变量。作者强调：仅凭此即可预言
    消费不足，无须再看消费数据。
  tags: [国有企业, 资本所有权, 经济普查]

- id: Dc06
  title: 国资委考核指标（保值增值率+收入增长率）塑造国企"做大规模"目标
  type: case
  source_chapter: 第9讲 9.1
  source_quote: |
    国资委最核心的考核指标是国有资本保值增值率和主营业务收入平均增长率。……都对应着企业规模的增长率。所以从国有企业的考核导向来看，国有企业的目标之一是"做大规模"。
  summary: |
    方法论主题：企业目标偏离框架（Df10）的制度证据。依据国资委《中央企业负责人经营业
    绩考核暂行办法》，考核核心是资本增值率与收入增长率，两个指标都是规模指标；于是即
    使资本回报率低于居民要求的回报率，国企仍有动力继续投资。用途：示范"从考核制度读
    出组织的目标函数"的方法——分析任何非典型企业行为，先找它的实际激励来自哪个考核
    体系，而非套用教科书式利润最大化假设。
  tags: [国资委, 企业目标, 激励制度]

- id: Dc07
  title: 数量模拟：θ=0.5 时储蓄率由 -29.8% 升至 5.4%、消费显著下降
  type: case
  source_chapter: 第9讲 9.3（含第8讲 8.5.1）
  source_quote: |
    假设θ=0.5，用Excel的"规划求解"功能可以解出c1=0.95，c2=1.10，k1=1.05。储蓄率为5.4%。当资本更多地为国有企业所拥有时，全社会的储蓄率确实上升了，而居民消费则相应下降了。
  summary: |
    方法论主题：模型数量模拟与比较静态（Df09）。两模型同参数（CRRA σ=2、β=0.98、
    柯布-道格拉斯 α=0.4），私有经济模型第1期储蓄率 -29.8%（末日临近所致），国有经济
    模型（θ=0.5）储蓄率 5.4%、两期消费均更低。用途：演示"同一模型只改一个约束、同参
    数对照求解"的模拟纪律，使结论差异可完全归因于该约束（企业所有权），而非参数选择；
    同时示范 Excel 规划求解这类低工具门槛的做法。
  tags: [数量模拟, 比较静态, 国有经济模型]

- id: Dc08
  title: 中国企业利润占比与居民消费占比的负相关（1992 年以来资金流量表）
  type: case
  source_chapter: 第9讲 9.4.2（图9-7）
  source_quote: |
    当中国企业部门的利润占GDP的比重上升时，中国居民消费占GDP的比重就下降——两个比重呈现出此消彼长的负相关关系。……这种企业部门与居民部门的割裂，是中国消费不足的主要原因。
  summary: |
    方法论主题：帷幕失效的时间序列证据（Dp03 的中国反面）。跨国截面上居民与企业储蓄负
    相关是帷幕有效的表现；中国时间序列上企业利润占比与居民消费占比负相关，则是帷幕失
    效的表现——企业收入增加不再转化为居民收入与消费。用途：演示同一理论关系在"有效/
    失效"两种制度下给出相反的数据形态，可用数据形态反推制度状态。
  tags: [企业利润, 居民消费, 割裂]

- id: Dc09
  title: 中国消费之谜：理论利率应约 17%-20% 而现实真实存款利率仅约 0.2%
  type: case
  source_chapter: 第8讲 8.5.2；第9讲 9.4.3
  source_quote: |
    而在2000—2016年这17年中，我国居民消费平均真实增速为8.4%。将这些数据代入上面的方程，可以算出我国的真实利率水平应当接近20%！而同期我国真实存款利率……平均下来只有约0.2%。
  summary: |
    方法论主题：欧拉方程数量对账（Df12）。Modigliani 等（2004）所称"中国消费之谜"：
    以 σ=2、ρ=2% 和消费增速 7.7%-8.4% 代入欧拉方程，理论要求真实利率约 17%-20%，
    现实仅 0.2%，相差一个数量级；含义是"相对这么低的利率，储蓄太多了"。且欧拉方程只
    关乎居民优化、与企业无关，故矛盾不能推给企业。用途：示范如何用对数近似的欧拉方程
    做最小成本的数量检验，并把"模型—现实差距"转译为下一步研究的靶点。
  tags: [消费之谜, 真实利率, 欧拉方程]

- id: Dc10
  title: 苏联东欧私有化的内部人控制与政策性负担教训
  type: case
  source_chapter: 第9讲 9.5.2
  source_quote: |
    在其国企私有化浪潮中，国企内部人利用其信息优势低价攫取国有资产，从而变成了巨富，又进一步成为操纵经济和社会的寡头。……一些国有企业在私有化之后，政府所需提供的补贴反而大幅上升。
  summary: |
    方法论主题：政策方案的反事实检验（Df11 的论证支撑）。私有化看似是恢复所有权竞争的
    直路，但两个机制使其后果恶劣：内部人利用信息优势低价攫取资产（如低报油田储量）造
    成国有资产流失与寡头化；政策性负担未消除时私有化，补贴直接进私人口袋、反而膨胀。
    用途：示范评估改革方案要看转型过程的激励与信息结构，而非只比较起点与终点的所有制
    标签——与"休克疗法之弊"的次优理论一脉相承。
  tags: [私有化, 内部人控制, 政策性负担]
