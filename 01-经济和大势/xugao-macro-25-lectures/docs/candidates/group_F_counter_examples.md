# 候选·反例（counter-example）— 第12-14讲 作者明确警告的误区

- id: Fk01
  title: 把储蓄等同于货币，认为储蓄多寡由货币政策决定
  type: counter-example
  source_chapter: 第13讲 13（开篇）
  source_quote: |
    有人在现实中看到居民储蓄都是以银行存款、现金等形式存在的，因而错误地认为决定储蓄多寡的是货币政策。这就是没有认识到储蓄的本质——储蓄是通过牺牲当前的消费而换取未来的消费。
  summary: |
    作者在货币经济开篇点名的错误：因储蓄以存款、现金形式持有，就把储蓄问题归结为
    货币发行问题。病根是混淆了概念层次——储蓄的本质是跨期消费配置（真实变量），
    货币只是其持有形式（名义外衣）。作者借此说明"先在无货币模型中看清本质、再进
    货币环境"的方法论次序。中国语境的变体即"储蓄过剩=货币发太多"论（第12讲开篇
    同样点名批评）。
    警示：分析任何名义量之前，先还原其背后的真实变量。
  tags: [储蓄, 货币幻觉, 概念混淆]

- id: Fk02
  title: 把李嘉图等价当作普适真理
  type: counter-example
  source_chapter: 第12讲 12.5
  source_quote: |
    绝大多数估计值都显著地不为0，并且有相当多的估计结果超过了1。这一数量结果表明，李嘉图等价在现实中普遍不成立。毕竟，李嘉图等价的结论出自一个相当理想化的设定。
  summary: |
    作者明确裁决：李嘉图等价是从理想化设定（一次总付税、完全理性预期、政府长期
    预算约束被民间完全内生化）推出的基准结论，现实中税收多为扭曲性、预期随政策
    调整，财政乘数估计普遍显著非0、很多超过1。正确用法是把等价视为一种"约束"
    而非"定律"——它随产能利用率上升而收紧（Fp02），而不是在任何状态下都成立。
    警示：理想化模型结论直接搬到现实前，先核对其前提条件。
  tags: [李嘉图等价, 误用, 理想化假设]

- id: Fk03
  title: 因凯恩斯理论不符合理性预期就抛弃财政乘数（长颈鹿愚人）
  type: counter-example
  source_chapter: 第12讲 12.5
  source_quote: |
    如果我们真的因为凯恩斯的理论不符合理性预期，就抛弃财政乘数的观念，那就变成索洛所说的不相信长颈鹿有长脖子的愚人了。
  summary: |
    与Fk02对称的反向误区：用理论缺陷否定经验事实。凯恩斯乘数的微观基础不牢（边际
    消费倾向估计注定徒劳），但财政乘数显著非0是经验事实，不能因为"理论是渡河之舟"
    不完美就把船和彼岸一起扔掉。作者由此给出双向检验原则：既不把理想化结论当真理
    （Fk02），也不因理论不完善否认现象存在。
    警示：理论与证据的冲突是研究课题，不是弃用理由。
  tags: [财政乘数, 理论与证据, 索洛]

- id: Fk04
  title: 用非黑即白二分法在凯恩斯与李嘉图之间选边
  type: counter-example
  source_chapter: 第12讲 12.5
  source_quote: |
    真实的世界不是用非黑即白的二分法所能描述的。市场有效的程度时高时低，并不总是有效的，也并不总是无效的。政府对经济的影响力不能说没有，但也绝非无限。政府与市场之间不是有你无它的相互排斥，而是必须相互协作。
  summary: |
    作者对"站队式"经济争论的警告：把凯恩斯与李嘉图当成必须二选一的真理之争是错误
    提问方式。市场有效程度是连续变量、随状态变化；两派融合正在进行（新凯恩斯主义
    吸收理性预期，新古典纳入摩擦）。正确姿势是就具体问题抓最本质的逻辑线索——
    "是技术，更是艺术"。
    警示：任何"政府vs市场"的抽象站队式论证，都应被还原为状态依赖的具体判断。
  tags: [二分法谬误, 政府与市场, 凯恩斯之争]

- id: Fk05
  title: 把IS-LM等直接假设的数量关系当作稳定规律使用
  type: counter-example
  source_chapter: 第12讲 12.3
  source_quote: |
    IS一LM模型在理性预期革命之前提出，其建模的方法论思想会受到卢卡斯批判。……我们重申，类似IS一LM这样直接假设的宏观经济变量间的数量关系是不稳定的，使用时需要注意其局限性。
  summary: |
    作者使用IS曲线时的自我设限：IS-LM直接假设宏观变量间的数量关系（而非从微观
    最优化推出），属理性预期革命之前的建模方式，受卢卡斯批判——政策改变时这些
    数量关系本身会变。因此本课程仅把它当作"阐述凯恩斯思想的语言"，不能当作稳定
    的政策测算工具。
    警示：凡未经微观基础、直接拟合出来的宏观数量关系，用于政策评估前都要过卢卡斯
    批判这一关（对照Fp19：基于生产函数的关系不受批判）。
  tags: [IS-LM, 卢卡斯批判, 模型局限]

- id: Fk06
  title: 在满负荷经济中套用破窗理论/挖坑填坑式刺激
  type: counter-example
  source_chapter: 第12讲 专栏12-1
  source_quote: |
    但是，如果经济中所有资源都正被满负荷使用呢？也就是说，修窗工的工作计划已经排得完全饱和了。这时，要去修被砸坏的窗户，他就必须放下手里正在干的活计。此时，砸破窗户并未带来总需求的扩张，反而是对之前资源高效配置的一种干扰。
  summary: |
    作者给破窗理论（及凯恩斯挖坑填坑政策）加的硬前提：经济必须处在需求不足、供给
    过剩状态。资源满负荷时，破坏性支出只是把劳动从高效用途挤到低效用途——财富净
    损失加配置干扰，毫无"创造需求"可言。这一反例同时划清了凯恩斯政策的适用边界
    （与Fp02呼应）。
    警示：一切"灾害重建拉动经济""战争刺激增长"式论证，先查砸窗之前的产能利用率。
  tags: [破窗理论, 适用前提, 产能利用率]

- id: Fk07
  title: "货币超发必然通胀/必然危机"的机械观点
  type: counter-example
  source_chapter: 第13讲 13.1.2
  source_quote: |
    有人相信这是中国通货膨胀和资产价格泡沫的最终来源，并认为越来越高的货币存量最终会引发经济危机。不过，尽管我国货币总量看上去已经不小，但在次贷危机之后曾出现过长时间的实体经济"融资难"。
  summary: |
    作者点名的机械推理：见M2/GDP高企就断言通胀或危机将至。反常事实是货币总量不小
    的同时实体融资难、2013年钱荒利率飙升——总量与"放水"效果之间隔着传导结构
    （市场分割、流动性堰塞湖，第15讲展开）。机械观点的病根是把交易方程式的恒等
    关系当因果，且默认货币流通速度不变、货币均匀流入实体。
    警示：货币总量论证必须补上"货币如何流向哪里"的机制分析。
  tags: [货币超发, 机械推理, 传导机制]

- id: Fk08
  title: 在现实中执行弗里德曼最优货币数量规则
  type: counter-example
  source_chapter: 第13讲 13.4.3
  source_quote: |
    弗里德曼的最优货币数量在真实世界中不可行。……真实世界中这种价格调整的非对称性，使得经济一旦陷人通货紧缩就很难通过自发的调整走出来。……真实世界中没有任何一个国家以最优货币数量为货币政策调控目标。
  summary: |
    理论最优不等于政策可行：最优货币数量要求持续通缩（名义利率0），但现实中价格
    调整非对称——涨价易、降价难（加薪3%易、降薪3%难），经济陷入通缩难以自发走出；
    且名义计价债务在通缩中实际负担加重，引发债务-通缩式长期萧条。故没有国家执行
    该规则，现实取"温和正通胀+与通缩保持安全距离"。
    警示：把福利最优点直接当政策目标，可能因名义刚性而滑向灾难（对照第13讲对
    通缩非对称性的分析）。
  tags: [最优货币数量, 通缩, 可行性]

- id: Fk09
  title: 把货币中性当成立事实，认为货币政策无关紧要
  type: counter-example
  source_chapter: 第13讲 13.4.1
  source_quote: |
    实证研究发现，现实世界中的货币对实体经济是有影响的一一货币中性及超中性的结论在现实中并不成立。尽管如此，古典两分法作为我们分析货币经济的起点，仍然有其价值。
  summary: |
    与Fk07相反方向的误区：把模型里推出的货币中性当成对现实的描述。实证（包括VAR
    识别的货币冲击）表明货币短期显著影响实体经济，中性结论只是价格灵活假设下的
    基准。作者同时给出中性结论的正确用途：作为分析起点，提示"现实中货币的影响力
    必然来自价格的非灵活变动"，从而锁定货币经济学的研究重点。
    警示：模型基准结论与现实观测冲突处，应去找缺失的摩擦假设，而不是两头取舍。
  tags: [货币中性, 实证证据, 模型基准]

- id: Fk10
  title: 随意更改效用函数以"解释一切"
  type: counter-example
  source_chapter: 第13讲 13.2
  source_quote: |
    只要选用了不同的效用函数，我们便能解释我们想解释的一切。但这实际上什么也解释不了。所以，凡是要更改效用函数的形式，都必须有非常合理的解释。
  summary: |
    作者点名的建模恶习：为了得到想要的结论而定制偏好。效用函数决定一切经济分析

    默认使用几种标准形式，确需改动必须提供独立的微观故事（如MIU的"货币就是
    时间"）。
    警示：读模型先读效用函数；结论若依赖非常规偏好，说服力需重估（与Fp15互为
    正反两面）。
  tags: [效用函数, 建模恶习, 方法论]

- id: Fk11
  title: "宏观经济不过是微观经济的加总"陷阱
  type: counter-example
  source_chapter: 第14讲 14.1
  source_quote: |
    但必须要注意，虽然都叫供给曲线或者需求曲线，微观层面的供给曲线或需求曲线与宏观层面的供给曲线或需求曲线不是一回事。换言之，宏观层面的供给曲线和需求曲线不是微观曲线的简单加总。这是一个很多人都会落人的陷阱。
  summary: |
    作者点名的宏观错误认知头号根源：直觉上把微观供给曲线（必然向上倾斜）加总成
    宏观总供给曲线。加总的逻辑死结是"相对价格不可比"——不同商品的相对价格无法
    排上同一数轴；宏观曲线的纵轴是以货币计的总体价格水平，是另一个概念。
    警示：一切"微观上如此，故宏观上也如此"的推理（供给曲线、竞争、均衡）都是
    陷阱候选；宏观命题需要独立的宏观逻辑（与Ff15、Fp16配套）。
  tags: [加总谬误, 总供给曲线, 直觉陷阱]

- id: Fk12
  title: "宽松货币政策总能刺激增长，央行应一直宽松"
  type: counter-example
  source_chapter: 第14讲 14.3
  source_quote: |
    如果通货膨胀预期一直等于实体通货膨胀（π=π），那么实际产出就将一直等于自然产出水平（y=y），货币政策就将对实体经济没有影响，回到货币中性的状态。
  summary: |
    作者在练习题14.2(b)中设为判断题的流行观点，理论上不成立：货币刺激只通过"超
    预期"起作用，民众不会永远被欺骗；持续的宽松只会让预期追上操作，产出回到自然
    水平而通胀系统性抬高（通胀偏差，Fk14）。货币政策是短期稳定工具，不是长期增长
    引擎——长期增长由供给面决定。
    警示：把短期的总需求管理效果外推为长期增长药方，是黏性价格模型最直接的滥用。
  tags: [宽松货币政策, 理性预期, 政策外推]

- id: Fk13
  title: 拿西方理论当锤子在中国经济中乱捶
  type: counter-example
  source_chapter: 第14讲 14.5
  source_quote: |
    如果中国经济运行的规律与上面的阐述有偏差，那么用这些理论得到的结论来指导中国经济的实践就会导致偏颇。这是我们在把西方的经济理论运用到中国现实时必须时时注意的。
  summary: |
    作者以"锤子与钉子"谚语点名的误用：不检验理论前提与适用范围就把西方货币理论
    （倾斜总供给、菲利普斯曲线机制）直接用于中国政策。中国的反例证据是逆时针螺旋
    （Fc13）——机制有实质差异，照搬结论会导致偏颇。正确流程：掌握理论→核对前提→
    找中国对应物检验→保留警惕地借鉴。
    警示："理论正确"与"理论在此适用"是两个命题，后者才是政策应用的门槛。
  tags: [理论误用, 中国视角, 适用范围]

- id: Fk14
  title: 相机抉择的货币政策制造无谓的通货膨胀
  type: counter-example
  source_chapter: 第14讲 14.4
  source_quote: |
    如果政府不能做出这样可信的（且自己无法违背的）承诺，而只能相机决策，民众就会知道，政府总有动机制造一些通货膨胀以推高产出水平。考虑到这一点，民众就总会预期一些通货膨胀。这只会无谓地带来高通货膨胀。
  summary: |
    动态不一致模型的核心反例：保留相机抉择权（不承诺）的政府陷入更差均衡——民众
    预期通胀使实际通胀=预期，产出钉在潜在水平，社会却白白承受高通胀；福利严格低于
    可信承诺零通胀的情形。这解释了为何央行行长总表现得厌恶通胀、为何要通胀目标制
    与央行独立性（Ff20）。
    警示：任何"给自己留操作空间"的政策安排，都要算一下公信力损失这笔账。
  tags: [通胀偏差, 相机抉择, 承诺价值]
