  title: 财政政策的三大关键问题框架
  type: framework
  source_chapter: 第12讲 12.2
  source_quote: |
    关于财政政策，我们可以提出三个关键问题……第一，是否应该运用财政政策来平滑经济周期？……第二，财政的可持续性如何判断？……第三，政府怎样最优地收税，以降低对经济运行的干扰？
  summary: |
    解决"讨论财政政策应该从哪里入手"的问题。作者把财政政策分析拆成三个层次：一是
    有效性问题（财政支出有没有乘数、能否平滑周期，凯恩斯与李嘉图的分歧所在）；二是
    可持续性判断（短期赤字靠发债或铸币弥补，长期必须收支平衡）；三是最优税收（如何
    征税对经济干扰最小）。三个问题难度递增：第一个用乘数模型即可讨论，第二个要把
    货币引入后才能分析（财政与货币密不可分），第三个要等次优理论。
    用法：分析任何财政政策争论时，先定位它在回答哪个问题，避免把三个层次的问题混在
    一起谈。
  tags: [财政政策, 问题分解, 分析框架]

- id: Ff02
  title: 财政自动稳定器机制
  type: framework
  source_chapter: 第12讲 12.1.2
  source_quote: |
    财政收人的顺周期性和财政支出的逆周期性，合在一起就导致了财政盈余（财政收人减去财政支出）的顺周期性。财政盈余的顺周期性让财政政策成为经济周期的稳定器，有平抑经济波动的倾向。
  summary: |
    解决"财政政策为何天然具有平抑周期功能"的问题。核心逻辑是收支两侧的周期性叠加：
    经济上行时税基扩大、财政收入自动增加；经济下行时补贴类支出（如失业救济）自动
    增加。两者相减使财政盈余顺周期——好年景财政收紧、坏年景财政放松——从而部分
    对冲经济波动。在自动稳定器之外，政府还可主动调整支出力度放大或缩小稳定器效应，
    也可反其道而行之（如欧债危机后的被迫紧缩）放大下行。
    用法：评估一国财政立场时，先区分"自动的部分"与"主动的部分"，再判断主动操作
    是顺周期放大波动还是逆周期平抑波动。
  tags: [财政政策, 经济周期, 自动稳定器]

- id: Ff03
  title: 凯恩斯交叉/IS曲线与财政乘数推导
  type: framework
  source_chapter: 第12讲 12.3
  source_quote: |
    凯恩斯认为，经济中的实际支出（actual expenditure）是居民、企业和政府实际花在产品和服务上的数额。而计划支出（planned expenditure）则是……计划花费在产品和服务上的数额。在一个封闭经济中，可以把计划支出（E）用下式表示出来 E=C(Y-T)+I+G 这就是IS曲线
  summary: |
    解决"财政支出如何放大总需求"的问题。核心逻辑：令实际支出等于计划支出（Y=E），
    配线性消费函数 C=c̄+c(Y-T)，解出 Y=[c̄-cT+I+G]/(1-c)。由于边际消费倾向
    0<c<1，乘数 1/(1-c)>1：政府花1元，收入增加1元，其中 c 部分再被消费掉，形成
    "支出→收入→消费→收入"的无限反馈链条，几何级数加总得乘数。
    用法：注意该推导只刻画需求侧，隐含"供给不是瓶颈"（存在非自愿失业）的前提；且
    IS-LM式的数量关系受卢卡斯批判，只能作为阐述凯恩斯思想的语言，不能当稳定规律用。
  tags: [凯恩斯, 财政乘数, IS曲线]

- id: Ff04
  title: 李嘉图等价的拉姆齐模型机制
  type: framework
  source_chapter: 第12讲 12.4
  source_quote: |
    有着理性预期的居民会将政府的预算约束考虑进来，会了解政府最终会用未来的税收来偿付其发行的政府债券。因此，在政府支出路径已经给定的前提下，政府为支出融资的方式（税收、发债）并不影响消费者的决策，也不影响宏观经济的总需求和总产出。
  summary: |
    解决"政府融资方式（税 vs 债）是否影响实体经济"的问题。在两期拉姆齐模型中（居民
    拥有企业、一次总付税、政府支出不进效用与生产函数），把政府两期预算约束代入居民
    预算约束，消去税收 t1、t2 和债券 b 后，刻画均衡的方程中完全不出现这些变量——
    融资方式被完全消掉。机制：今天减税=明天增税，理性居民把减税额储蓄起来（部分买
    国债）备缴未来税款，故税收乘数为0、政府债券不是净财富。
    用法：检验李嘉图等价是否成立的三个关键前提——税收非扭曲、预期理性、政府长期
    预算约束被民间内生化；任一前提松动，等价即失效。
  tags: [李嘉图等价, 拉姆齐模型, 理性预期]

  type: framework

  type: framework

  source_quote: |
    消费者因为征税所损失的福利0.69（=-1-（-1.69））大于政府的税收收人0.5。所以此时全社会因为扭曲性税收损失了福利。
  summary: |

  type: framework
  source_chapter: 第13讲 13.2
  source_quote: |
    而要在一般均衡模型中引人货币，关键是要设定出促使人愿意持有货币的那种动机。……所谓现金先行（cash in advance，简称CIA），就是要求消费者在购买商品（通常是购买消费品）时，需要用货币来支付。因此，消费者的消费品购买总额受其货币持有量的约束 Pc≤M
  summary: |

    要记住它是一种"建模取巧"，更根本的动机刻画要用搜寻模型。

- id: Ff10
  title: 货币的搜寻（search）模型：交换媒介的内生出现
  type: framework
  source_chapter: 第13讲 13.2
  source_quote: |
    无论是CIA，还是MIU，都只是引人货币的建模取巧之举。更加符合直觉的建模方式是用搜寻模型。在模型中设定多个消费者，将其搜寻产品的过程给表现出来。然后对比在没有货币作交换媒介（media of exchange）时的搜寻均衡，以及有货币时的搜寻均衡，找出货币的价值。
  summary: |
    解决"货币的价值能否从交易摩擦中内生导出而非外生假设"的问题。在多主体搜寻环境
    中（Kiyotaki-Wright 1989），以物易物需要需求的二重耦合、极难达成；对比有无货币
    两种搜寻均衡，可内生化货币作为交换媒介的价值。作者承认它最符合直觉，但因处理
    复杂、难与常规宏观模型结合而未在课程中展开。
    用法：评价一个货币模型时，可按"取巧程度"排谱系：搜寻模型最根本，CIA/MIU是
    便捷近似；讨论货币的微观基础时应知道近似的来路。
  tags: [货币理论, 搜寻模型, 微观基础]

- id: Ff11
  title: 古典两分法的模型推导：真实块与名义块分离
  type: framework
  source_chapter: 第13讲 13.3.4-13.4.1
  source_quote: |
    前三个方程中只包含真实变量，靠它们可以完全确定模型中的真实内生变量。最后一个方程包含货币增长率，但它只影响名义变量。所以在这个模型，可以将实体经济（真实变量）与货币经济（名义变量）分开来分析。在宏观经济学中，这叫做古典两分法（classical dichotomy）。
  summary: |
    解决"货币到底影不影响实体经济"的可操作判定问题。在MIU两期模型中，刻画均衡的
    四个方程自然分成两块：三个只含真实变量（欧拉方程+两期资源约束）独立决定消费、
    储蓄、产出；一个货币增速方程单独决定通胀与真实货币存量。价格灵活时两块解耦，
    货币存量不影响真实变量（货币中性）、货币增速也不影响（货币超中性），上一讲的
    李嘉图等价等结论全部保留。
    用法：把模型方程按"是否含名义变量"分块，是检验任一货币模型中货币是否中性的
    通用手法；分块失效之处，就是货币非中性（摩擦）进入之处。
  tags: [古典二分法, 货币中性, 一般均衡]

- id: Ff13
  title: 弗里德曼最优货币数量：名义利率归零规则
  type: framework
  source_chapter: 第13讲 13.4.3
  source_quote: |
    人们为了获得持有货币而带来的好处，宁可接受货币的0回报……名义利率就衡量了货币带给人的边际收益……既然货币的边际成本是0，那么最优的货币数量就应该让货币的边际收益也是0，即名义利率也是0。
  summary: |
    解决"货币发多少才最优"的福利问题。逻辑三步：持币的边际收益由放弃的利息（名义
    利率）度量；纸币印制成本≈0；按"边际成本=边际收益"的最优化通则，最优货币量
    应使名义利率为0。由于真实利率为正，这要求通胀率为负、货币增速为负——政府须
    不断回收货币制造温和通缩。MIU模型稳态推导验证了这一直觉（R=0 时持币边际效用
    为0），且结论不限于MIU。
    用法：它是"通胀不是越低越好"讨论的福利基准；现实不可行（见反例Fk08），但为
    各国选择温和正通胀目标提供了对照点。
  tags: [最优货币数量, 弗里德曼, 福利分析]

- id: Ff14
  title: 交易方程式：货币、价格与产出的会计恒等式
  type: framework
  source_chapter: 第13讲 13.1.3
  source_quote: |
    经济学家习惯用如下这个叫做交易方程式（equation of exchange）的公式来把货币、价格和产出联系在一起 MV=Py。……货币流通速度（V）越快，同样数量的货币总量就能支撑起更高的交易总量。
  summary: |
    解决"货币总量如何与名义经济规模挂钩"的梳理问题。MV=Py 中 M 是货币总量、
    P 价格水平、y 真实产出、V 流通速度；恒等式本身不给出因果，关键问题是 M 的
    变化如何分解到 P 与 y 上。取 Py 为名义GDP后，1/V=M2/GDP，于是"M2/GDP
    持续升高"与"货币流通速度持续变慢"是同一事实的两种说法。
    用法：把它当作组织货币问题的坐标系——任何"货币超发"讨论都要回答 V 是否稳定、
    M 的增量去了 P 还是 y；流通速度的异动是通胀或资产泡沫的前哨问题。
  tags: [交易方程式, 货币流通速度, M2/GDP]
