# 阶段1 候选提取 — I组 反例（counter-example）
# 来源：lect20.txt（第20讲）、lect21.txt（第21讲）、lect22.txt（第22讲）
# 每条均为作者明确警告的误区/流行错误推理

- id: Ik01
  title: 误区："M2/GDP高=货币超发=会引发通胀"
  type: counter-example
  source_chapter: 第22讲 22.3.3节
  source_quote: |
    面对居高不下的M2占GDP的比重，正确的问题不是问中国为什么会有这么多货币，
    而是问中国这么多的货币为什么没有被花出去。……中国的货币存量不过是实体经济
    储蓄的货币表现形式，而并非央行超发的货币。
  summary: |
    作者明确称这种流行说法"似是而非"。M2/GDP 持续上升是储蓄过剩的表现：储蓄率
    高→购买力未转化为名义总需求→沉淀在金融体系中，货币增速才能持续高于通胀率。
    机械推理跳过了"货币是否被花出去"这一环节。正确问法是问货币为何沉淀，答案在
    实体收入分配结构而非央行印钞。这是全书批判频率最高的误读之一。
  tags: [货币超发, M2/GDP, 储蓄过剩]

- id: Ik02
  title: 误区："房价上涨是货币现象，紧货币就能控房价"
  type: counter-example
  source_chapter: 第21讲 21.3.2节
  source_quote: |
    但如果仅仅因为这种相关性，就把房价上涨看成一个货币现象，那就错抓了重点。房价
    持续上涨的最重要原因是地方政府对土地供应的垄断。
  summary: |
    作者明确警告"错抓了重点"。社会融资与房价的正相关是真实的（信贷决定需求），但
    从相关性直接跳到"房价=货币现象"的因果结论是错误的：货币是全国性的，房价涨幅
    却在一二三线城市间明显分化（一线累计涨近80%），分化只能由地方土地供给解释。
    只做货币文章无法扭转长期趋势。
  tags: [房价, 货币现象, 相关因果]

- id: Ik03
  title: 误区："通货膨胀推高房价，控通胀即控房价"（2007年流行逻辑）
  type: counter-example
  source_chapter: 第21讲 21.1.3节
  source_quote: |
    有人认为，中国的通货膨胀不管是什么原因造成的，都推高了房价。……但在次贷
    危机之后，中国的房价在CPI基本保持平稳的背景下大幅波动了几轮，且在波动中对
    CPI有一定的领先性。这让通货膨胀引发房价上涨的说法不那么流行了。
  summary: |
    作者用事实证伪该逻辑：次贷危机后房价在 CPI 平稳背景下独立波动数轮且领先 CPI，
    "通胀引发房价"的传导并未发生。教训：两个变量同为货币宽松的结果时容易混淆
    因果方向；用后视数据（房价领先CPI）即可检验。2007年的流行说法是当时基于误
    判的政策收紧理由。
  tags: [通胀与房价, 因果方向, 证伪]

- id: Ik04
  title: 误区：用弗里德曼定义把结构性通胀排除在"通货膨胀"之外
  type: counter-example
  source_chapter: 第21讲 21.1.2节
  source_quote: |
    事实上，确实有人基于弗里德曼给出的定义，认为中国的结构性通货膨胀不算通货
    膨胀。但问题并不会因为将中国的结构性通货膨胀被排除在通货膨胀定义之外而消失。
  summary: |
    作者指出这是定义层面的回避而非解决：结构性通胀与货币增速在数据中正相关，若
    认定其为货币现象则与"长期货币中性"矛盾，若认定无关则相关性成谜——两头都
    得有人给出解释。正确做法是构建中间传导机制（劳动力市场渠道），而不是靠重新
    定义消掉问题。教训：语义辨析替代不了机制解释。
  tags: [弗里德曼, 结构性通胀, 定义回避]

- id: Ik05
  title: 误区："人民币低估造成中国消费不足，升值可平衡经济"
  type: counter-example
  source_chapter: 第20讲 20.5节
  source_quote: |
    而我们在之前对中国经济结构失衡的分析也表明，中国的消费不足主要是收人分配格局
    所导致，并非源于人民币汇率的低估。……人民币的升值并不会自动平衡中国经济。
  summary: |
    作者明确反驳国外观察者与施压政府的这一主流逻辑：消费不足的根源在收入分配（第
    9讲），升值只会打击出口、降低投资回报率，而投资回报率下降不会自动转化为消费。
    教训：把内部结构问题归因于外部价格变量，药方（大幅升值）只会带来总需求收缩。
    这也是"汇率 tool 用错了问题"的典型。
  tags: [汇率低估, 消费不足, 施压逻辑]

- id: Ik06
  title: 误区："资本管制失效→必须让人民币自由浮动"（二元论推论）
  type: counter-example
  source_chapter: 第20讲 20.4.2节、20.5节
  source_quote: |
    就算跨境资本流动的管制失效，人民银行也完全可以通过外汇冲销操作来同时实现国内
    货币政策的独立和固定汇率。也就是说，通过浮动汇率来实现国内货币政策独立的迫切
    性并不强。
  summary: |
    作者指出二元论（dilemma）论述忽略了冲销选项：不可能三角并非绝对，顺差国可用
    外汇干预+冲销同时保住汇率稳定与货币政策独立。由"管制失效"推不出"必须浮
    动"，中间漏掉了第三条路。教训：三角框架要用全——先检查冲销可行性（国际收
    支方向、储备存量），再谈机制选择；811汇改的代价进一步佐证仓促浮动的风险。
  tags: [二元论, 不可能三角, 冲销]

- id: Ik07
  title: 误区："高房价归咎于分税制造成的财权事权不平衡"
  type: counter-example
  source_chapter: 第21讲 21.4节
  source_quote: |
    于是，有人将中国的高房价归咎于地方政府对土地财政的依赖，以及造成这一局面的
    地方政府财权事权不平衡的局面。……所以这个逻辑的后半截说不通。
  summary: |
    作者明确判定该流行因果链"后半截说不通"：土地财政因垄断供应而生，就算地方没
    有收支缺口，面对能卖高价的土地照样高价卖地——"无他，经济规律使然"。因而"
    平衡财权事权以遏制房价"的药方无效。教训：归因前先做反事实检验（去掉假定的
    原因，行为是否改变）；且评价分税制不能只看其与高房价的表面共时性。
  tags: [财权事权, 土地财政, 反事实检验]

- id: Ik08
  title: 误区："中国债务高企，将重演欧债/债务危机"（找错参照物）
  type: counter-example
  source_chapter: 第22讲 22.3.2节
  source_quote: |
    把欧债危机硬往中国身上套，是没有看懂中国经济，找错了参照物。
  summary: |
    作者的直接判语。欧债危机是表现为债务危机的国际收支危机——边缘国家国内储蓄不
    足、依赖外部融资，资本突然断流即崩；中国恰相反：储蓄过剩、对外净资产约1.8
    万亿美元（占GDP15%），债务是对应国内储蓄的内债。债务危机风险的关键在债权方
    是否外生，而不在债务比率本身。教训：套用危机叙事前先核对储蓄-投资与国际收
    支结构。
  tags: [欧债危机, 内债外债, 参照物]

- id: Ik09
  title: 误区：用只看债务方的标准可持续框架直接裁决中国需要去杠杆
  type: counter-example
  source_chapter: 第22讲 22.3.1-22.3.2节
  source_quote: |
    不过，这是对中国债务问题的一种误解。之所以说它是误解，并不是因为这一思路框架
    内部存在什么逻辑问题，而是因为这个框架的一个重要前提假设在中国并不成立。
  summary: |
    作者对"主流看法"的精确批评：国际通行的债务可持续框架（dratio 四条出路）本身
    没有逻辑错误，错在隐含假设——债权人在乎回报率、回报过低即断供——在中国不成立
    （存在只储蓄不消费的刚性储蓄者）。框架没坏，是适用条件不满足。教训：套框架
    前先审前提假设；"框架正确"与"框架适用"是两回事。
  tags: [债务可持续, 前提假设, 框架适用性]

- id: Ik10
  title: 误区："打压房价以抑制债务增长、降低宏观杠杆率"
  type: counter-example
  source_chapter: 第22讲 22.3.4节
  source_quote: |
    因此，似乎很容易就能得出结论：应该打压房价来抑制全社会债务总规模的增长。不过，
    数据显现的逻辑正好相反——房价上升（而非下降）更有利于中国宏观杠杆率的下降。
  summary: |
    作者点名的方向性错误：只盯杠杆率分子（债务），忽视分子分母联动——房地产是实
    体最重要的投资引擎，压房价压投资，名义GDP（分母）收缩得比债务更快，杠杆率
    反升，政策陷入"去杠杆→杠杆率上升→更强去杠杆"的自我强化陷阱。教训：任何
    比率型目标都要先画分子分母的联动结构，再评估政策方向。
  tags: [去杠杆, 房价, 分子分母]

- id: Ik11
  title: 误区："城投公司高息低回报=庞氏骗局，应切断其融资"
  type: counter-example
  source_chapter: 第22讲 22.3.2节
  source_quote: |
    至于城投公司，它们其实是一种有道理并可持续的商业模式，并非庞氏骗局。
  summary: |
    作者明确否定庞氏判定：城投项目微观现金回报低是公益性属性使然，其回报的大头是
    落在政府账上的外部性（地铁推升地价房价、活跃经济、创造税收）；政府以隐性补贴
    （注入土地）支持其融资合理，土地升值保证其资产负债率稳定。教训：用单一企业
    现金回报率评判准公共主体的偿债能力会系统性误判；资产负债表的稳定本身是重要
    证据。
  tags: [城投, 庞氏骗局, 外部性回报]

- id: Ik12
  title: 误区："放任人民币一次性大幅贬值以释放压力"
  type: counter-example
  source_chapter: 第20讲 专栏20-1、进一步阅读指南
  source_quote: |
    尽管当时有不少放任人民币一次性大幅贬值的呼声，但最后中国政府还是决定要维护
    人民币汇率的稳定。……徐高于2016年初发表的《人民币一次性贬值是下策》这篇
    文章可作为切入当时那场政策讨论的一个角度。
  summary: |
    作者以文章标题直接定性"下策"：一次性大幅贬值非但释放不了压力，反而坐实贬值
    预期、触发贬值-资本外流-再贬值的恶性循环（811汇改后外储半年流失约4000亿美
    元即为代价）。教训：在单边预期已成型的市场，"让价格出清"的教科书直觉可能
    引发预期螺旋；汇率市场的出清逻辑与普通商品市场不同。
  tags: [一次性贬值, 811汇改, 预期螺旋]

- id: Ik13
  title: 误区："通过管控融资流向倒逼实体经济结构转型"
  type: counter-example
  source_chapter: 第22讲 练习题22.2
  source_quote: |
    有观点认为可以通过对融资流向的管控来"倒逼"实体经济的结构转型。……你认为
    这种"倒逼"能起作用吗？可能会带来什么样的副作用？
  summary: |
    作者以练习题形式警示该流行主张：按本讲逻辑，金融体系内生于实体经济结构，储
    蓄向投资转化的势能不因管控消失，只会改道更隐蔽的渠道（影子银行、杠杆资金）；
    用融资管控倒逼转型，大概率得到的是金融乱象加结构未变。教训：政策评估题要问
    二阶后果——副作用清单比宣称的目标更能判定政策优劣。
  tags: [倒逼转型, 融资管控, 副作用]
