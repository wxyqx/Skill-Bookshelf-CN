# 步步高经营实战（上）：产品—品质—渠道—激励的落地打法

## I — 方法论骨架 (Interpretation)

这是一套从代工小厂做到品牌帝国的**落地打法**：产品（自研）、品质（负责制）、销售（链一体）、激励（全员股）、赛道（鸡肋原则）、渠道（统一价）六个机制互相咬合。骨架如下：

1. **品牌门槛：先问"有没有自己的产品、品牌和技术"**——代理、组装、贴牌这类"没有根"的生意不做，因为赚的是辛苦钱，攒不下长期资产；宁可进成熟市场靠技术优势切，也不做无品牌的搬运工。
2. **品质用数字管：返修率 0.3% + 负责制**——同行返修率 30%，段氏把它压到千分之三，且不是喊口号，而是责任到人：出了质量问题就追究到负责人。质量是生命线，用制度而不用觉悟来保证。
3. **销售链一体观：工厂只是链上的一环**——供应商、代理商、零售商、消费者都是同一条链，任何一个环节出问题全链受损。所以渠道政策的出发点是让每个环节都有钱赚、有保障，而不是把风险压给下游。
4. **激励用真股份，不用期权**——非上市公司期权没有用；员工没钱买股，就自己借钱给员工买、日后用分红和股息偿还（"借钱送股"，不白送）。机制设计围绕"员工真持有、真分利"，而非纸面许诺。
5. **赛道用鸡肋原则选**——不与大公司硬碰硬；找大公司"没兴趣加大投入、丢了又可惜"的项目，用局部优势在巨头顾不上的地方做深做透（步步高做 VCD、学习机均循此例）。
6. **渠道做减法：统一提货价 + 现款现货 + 取消销售部**——经销商不分大小一个价，杜绝层层加价、囤货炒价和讨价还价；省级代理持股绑定忠诚度，代理商闲资存厂付息。把复杂的销售体系简化到"不用整天讨价还价"——"（做到）简单不容易"，这套系统花了整整 3 年推行。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小霸王品质负责制与销售链改制的由来
- **问题**: 当国产游戏机大多靠进口散件组装、各品牌返修率普遍很高（有的达 30%）时，小霸王如何立足；广告爆红后订单如潮，全国总经销制又导致提货排队、客户私自涨价、各地价格混乱。
- **方法论的使用**: 一手把返修率硬压到 0.3% 并推行质量负责制（出问题追究到人）；一手提出"销售是一条链"的判断，随后改革销售体系——省级代理与工厂股份合作、现款现货、统一提货价、取消销售部。
- **结论**: 品质用制度保，渠道用机制顺；链上每个环节都不能出问题。
- **结果**: 小霸王产品质量赢得市场认同，营销体系效率与品牌形象显著强化。

### 案例 2: 全员股份制"借钱送股"（机制留人）
- **问题**: 创办步步高时员工没有钱购买股份，专家建议改用期权制度。
- **方法论的使用**: 段永平否决期权——"如果不是上市企业，期权没有用"；他稀释自己的股权，员工从他这里借钱买股、不用还本金，只需日后用股份利润或股息偿还，并明确每年利润分配与股份稀释的规则。
- **结论**: 激励的有效性在"真持有、真分利"，而不是纸面期权；老板让股是机制成立的前提。
- **结果**: 建成当时罕见的全员持股企业（同类知名企业只有华为），骨干长期稳定。

### 案例 3: 鸡肋原则选赛道（VCD 与学习机）
- **问题**: 步步高资金、体量都无法与巨头正面竞争，进什么市场？
- **方法论的使用**: 用鸡肋原则筛选——VCD 利润薄、外国企业"既看不上，又舍不得抛弃，一直当鸡肋对待"，国内虽 200 家混战，但步步高判断自己技术、生产、市场经验不弱于任何国内对手，全力以赴即可突围；学习机同理，切入大公司没有兴趣加大投入的项目。
- **结论**: 避开硬碰硬，在巨头顾不上的"鸡肋"项目上发挥局部优势。
- **结果**: 步步高在 VCD 与学习机市场脱颖而出，成为国内外品牌夹击中的胜出者。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 做产品的创业者纠结"要不要先做代理/贴牌赚快钱，还是自建品牌"。
2. 设计质量管理体系或销售政策：返修率怎么管、要不要多层经销、代理政策怎么定（价格、账期、囤货乱价）。
3. 设计员工激励与持股方案（尤其是非上市公司该不该用期权）。
4. 中小企业选赛道：巨头环伺下做什么、不做什么。

### 语言信号 (用户的话里出现这些就应激活)

- "自研品牌/自有品牌""要不要做贴牌、代理、组装""代工转品牌"
- "返修率""质量控制""责任到人""质量负责人"
- "代理商""经销商""销售渠道""窜货/乱价/囤货""提货价""现款现货"
- "员工持股""期权""股份激励""让员工入股"
- "鸡肋原则""大公司看不上的项目""焦点法则"
- "取消销售部""销售链""渠道改革"

### 与相邻 skill 的区分

- 与 `profit-above-profit-consumer-focus` 的区别：后者是**价值观取舍**（要不要打价格战、利润之上的追求、多元化 vs 专注的理念）；本 skill 是**落地机制**（价格战理念落到渠道政策，就是统一提货价怎么设计）。问"为什么不打价格战"→ 后者；问"渠道价格体系怎么设计"→ 本 skill。
- 与 `bbk-business-philosophy` 的区别：后者是经营理念层（速度观、宁小勿大、员工尊严、广告是工具）；本 skill 是产品/渠道/激励的具体打法。广告与产品关系属理念（→ bbk-business-philosophy），但广告爆红后渠道怎么承接属本 skill。
- 与 `corp-culture-people-system` 的区别：选人用人、放权、企业文化三件套归后者；"给多少股份、怎么给"这类激励**机制设计**归本 skill。若问题重心是"该不该放权给这个人"，→ corp-culture-people-system。

## E — 可执行步骤 (Execution)

1. **画品牌门槛线**：盘点当前业务中"代理/组装/贴牌"成分，评估是否在积累自己的产品、品牌与技术
   - 完成标准：写下"我们真正拥有的资产"清单；若答案是零自有产品/品牌，制定转自研的时间表或明确不做此类生意。
2. **立品质数字与责任人**：为产品设定一个可考核的返修率/质量指标，并为每道质量环节指定唯一责任人
   - 完成标准：指标写进制度（如段氏的 0.3%），每类质量问题都有明确的追责路径与处理记录，而非只有口号。
3. **审销售链各环节利益**：沿"工厂→供应商→代理商→零售商→消费者"逐环节检查：谁在吃亏、谁在加价、谁可能囤货乱价
   - 完成标准：画出全链利益图，列出至少一处"某环节吃亏导致链条受损"的风险及修正方案（如统一提货价、现款现货）。
4. **设计真股份激励**：非上市公司优先考虑直接持股（分红/股息偿还式借款购股），不依赖期权
   - 完成标准：方案写清"谁出钱、股份从哪来（老板稀释）、怎么还、利润怎么分"四要素；若方案依赖上市预期才成立，推倒重设计。
5. **用鸡肋原则选赛道**：对照"大公司没有兴趣加大投入、丢了又可惜"的标准筛目标市场，评估自己的局部优势
   - 完成标准：每个候选市场写出"大公司为什么不会重兵投入"+"我们的局部优势是什么"两行答案；两行都答不出则放弃该赛道。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题本质是经营价值观取舍（要利润还是要用户体验、要不要价格战、要不要多元化）→ `profit-above-profit-consumer-focus`。
- 问题涉及用人、放权、企业文化、接班安排 → `corp-culture-people-system`。
- 问的是"该不该现在进入某市场"的时机判断（后发制人）→ `dare-to-be-later`；本 skill 的鸡肋原则解决"选哪类赛道"，不解决进入时机。

### 作者在书中警告的失败模式（反例池 F10/F11 家族）

- **重营销轻产品、标王魔咒（e20/e21）**：与步步高竞争标王的企业（如爱多 2.1 亿夺标）不少很快垮掉——没有产品与品质支撑的广告增长必然崩塌。本 skill 的品牌与品质打法是标王魔咒的解药；若用户问的是"广告该扮演什么角色"的理念问题，转 `bbk-business-philosophy`。
- **粗放扩张、忽视管理（e21）**：只管卖出多少货、收回多少钱，不管返修率与责任归属——小霸王同期同行普遍如此，高返修率（30%）即其代价。
- **渠道失控（编者叙述，源文核实）**：层级过多层层加价、客户提货后私自涨价、爆款被恶意囤积操控市场——对商家、经销商和消费者三输；统一提货价+现款现货正是针对这三个病灶。
- **机制留不住人（e24 小霸王陨落，正反配对 c22 股改被否）**：骨干没有股份、股改被否，出走成潮、母公司营收下滑——"借钱送股"全员持股恰是段氏在步步高给出的反向解法。
- **生搬硬套西方制度（e25）**：照搬期权等"现代制度"而不问适用条件（非上市、成长性不足则期权无用），画虎不成反类犬。

### 作者的盲点 / 时代局限

- 这套打法成型于 1990 年代中国家电/视听市场：统一提货价、层层代理、省级代理持股依赖当年线下分销结构，对电商直营、DTC 模式需重新演绎而非照抄。
- "借钱送股"要求老板愿意大幅稀释自身股权且有垫资能力，资源受限的创始人难以完全复制；书中也未讨论员工中途离职的股份回购细节。
- 鸡腿原则（原书称鸡肋原则）适用于巨头视角下的"低利润小市场"；在技术平台型行业（赢家通吃）里，大公司"没兴趣"的市场可能真的没市场，须先判断赛道属性。

### 容易混淆的邻近方法论

- **期权激励（硅谷式）**：期权绑定上市预期与高成长；段氏"借钱送股"绑定分红现金流——非上市公司抄期权作业恰恰是段氏明确反对的。
- **价格战/薄利多销**：统一提货价不是低价倾销，而是全链一个价、消灭渠道套利；与"不打价格战"（f25）配合使用，勿混为一谈。
- **焦点法则（巴菲特投资语境）**：同源不同域——投资语境讲能力圈内下注，经营语境（鸡肋原则）讲避开巨头主战场，引用时注明场景。
