# 利润之上的追求：消费者导向、不打价格战、专注有限产品

## R — 原文 (Reading)

> "绝大部分企业最后大概只能达到'市场导向'的地步，因为大部分企业都是'利润导向'的，而要做到'消费者导向'需要有'利润之上'的追求……只有极少数的企业是真的在骨子里具有'消费者导向'，同时又具备实现'消费者导向'的能力的，这些公司最后往往会被人们称为伟大的公司。"

> — 【段】段永平，下册 经营篇（消费者导向与利润之上的追求，p27 单元；引文以"……"处为编者节略）

> "要知道创业的过程是非常艰难的，没有利润以外的追求很难走远。"

> — 【段】段永平，下册（谈投身创业公司，f24 单元）

> "我们不少企业太短视，动不动就是价格战，说是'薄利多销'，其实是低水平竞争的表现。把利润都打没了，就没有可能推动产品创新、研究开发，从长期看，消费者也是受害者……你看，可口可乐和百事可乐，从来都不是互相比降价，而是创造差异化的消费者价值。"

> — 【段】段永平，下册（谈 vivo 手机定价策略，f25 单元；引文以"……"处为编者节略）

> "但凡你能做好一样东西，你为啥还要做很多做不好的东西呢？……人的精力是有限的，聚焦的人或公司最后会变得很厉害，这也是我喜欢苹果的原因。""诺基亚需要用很多品种才能做到消费者导向，而苹果用一个品种就做到了，这里面的功夫差很多啊。"

> — 【段】段永平，下册（谈多元化与品种单一，p28 单元；两句合引，第二句为编者节略）

## I — 方法论骨架 (Interpretation)

这是经营价值观层面的决策框架，回答三个经典纠结：要利润还是要用户？要份额还是要价值？要多产品线还是少而精？本书给出的统一答案：**企业的高度取决于它在利润之上还追求什么**。

1. **导向分层：利润导向 < 市场导向 < 消费者导向**：市场导向盯"现在什么好卖"，消费者导向盯"消费者的真实体验"。消费者往往只根据现有产品决定喜好、显得短视，所以总跟着"好卖"走的企业更容易陷于短视；注重消费者体验的公司眼光更长远，做出伟大产品的概率大得多。
2. **"利润之上的追求"是消费者导向的前提，不是口号**：做到消费者导向需要能放弃一些短期利益，把产品做到最好来满足消费者真实需求。没有利润之上的追求，就不会真有消费者导向的文化；有的企业多少也有这种追求但能力没到，看起来不那么强大，生命力却往往比人们想象的强。
3. **分层判据自检**：① 只有利润导向——走不远；② 有追求但能力不足——不强大但活得久；③ 骨子里有消费者导向且有能力实现——伟大公司的种子。注意伟大的公司也不是一成不变的，时间可能让它退回去。
4. **价格战是"利润导向"的必然产物，且长期看消费者也是受害者**：把利润打没了，就没有钱做研发和创新，产品价值越做越低——买的人便宜，拿到的东西价值也低。可口可乐与百事的对照：从来不是互相比降价，而是创造差异化的消费者价值。原则是"至少不主动打价格战，有时降价属于被动降价"，着眼长远走提升价值之路。
5. **多元化的病根是"以为做成了一个好东西就啥都能做好"**：人的精力有限，能做好一样就别做很多做不好的。反盲目多元化不等于永远只做一个产品，而是只做自己能做好的、有消费者价值的事。
6. **品种单一是最难的功力，不是保守**：单一品种效率高、质量一致性好、成本低、库存好管理；诺基亚要用很多品种才能做到消费者导向，苹果用一个品种就做到了——功夫差很多。做很多品种的诱惑是覆盖不同细分市场、上下夹攻对手，代价是一大堆库存和品质失控。注意：从投资侧看，这正是"商业模式"的输入——消费者导向文化与专注度最终体现为护城河与定价权。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小霸王与步步高的"品种单一"传统（专注有限产品）
- **问题**: 学习机/游戏机市场竞争者众多，普遍用多机型、多型号铺市场。
- **方法论的使用**: 段永平自述"我从做小霸王时就追求品种单一，特别知道单一的好处和难度"——把少数产品做到极致（小霸王学习机以游戏机约 1/4 的价格切入、返修率 0.3% 对比同行 30% 的质量功力），而不是靠品类数量取胜。
- **结论**: 品种单一需要把产品做到极致的功力，"因为难，大部分人喜欢多品种"——难恰恰是壁垒。
- **结果**: 小霸王两年做到约 2 亿产值、80% 份额；这一传统延续到步步高系的产品线设计。

### 案例 2: vivo 不打价格战（提升价值之路的兑现）
- **问题**: vivo 作为后入者进入竞争白热化的国内手机市场，外界普遍预期它会低价抢市场；出海后也有人预期大幅降价换国际竞争力。
- **方法论的使用**: 段永平明确支持 vivo 的定价策略——"至少做到不主动打价格战"，不靠降价赢得竞争，走提升价值之路（对国内品牌动辄"薄利多销"式价格战的批评见 R 段第三条引文）。vivo 手机不便宜，还推出了五六千元的旗舰机型。
- **结论**: 价格战是低水平竞争：利润打没→无力研发→产品价值下降→长期消费者受害。差异化消费者价值才是正路。
- **结果**: vivo 多年未以降价方式赢竞争，以差异化产品线在市场立足。（注：本案例主体为沈炜/vivo，属"步步高系实践例证"，与段氏原则的关联按案例池备注如实定位。）

### 案例 3: 小天才电话手表（消费者导向的产品切入）
- **问题**: 儿童手表已是红海，比拼价格的空间看似有限。
- **方法论的使用**: 不从"什么好卖"出发，而从儿童的真实需求出发——以社交功能（孩子之间互加好友）切入，做用户体验导向的产品，定价 798 元不做低价倾销。
- **结论**: 消费者导向的落点是"满足消费者真实需求"而非"跟随现有好卖的东西"；真实需求撑得起价值定价。
- **结果**: 当年销量 107.6 万部，成为品类头部。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 经营中纠结"要利润还是要用户体验"：短期利益与用户价值的取舍（如质量成本、售后成本、要不要砍研发）。
2. 想打价格战/降价抢份额，或被对手的价格战逼到墙角不知是否跟进。
3. 想四处扩张：什么火做什么、铺产品线、上马与主业无关的新业务，犹豫要不要。

### 语言信号 (用户的话里出现这些就应激活)

- "消费者导向""用户第一还是赚钱第一""利润之上的追求""做企业为了什么"
- "要不要打价格战""薄利多销行不行""对手降价了我跟不跟""降价换市场份额"
- "要不要多元化""什么火做什么""多铺几个产品线""专注/聚焦/砍品类""品种单一"

### 与相邻 skill 的区分

- 与 `bbk-product-channel-playbook` 的区别：本 skill 是价值观取舍（要不要打价格战、要不要多元化这类"该不该"）；后者是落地打法（品牌、返修率、渠道、股份激励这类"怎么做"）。
- 与 `dare-to-be-later` 的区别：本 skill 处理"做什么与不做什么"的价值取向（消费者导向、专注）；后者处理"什么时候进入市场"的时机问题（敢为天下后）。
- 与 `bbk-business-philosophy` 的区别：两者同为经营理念，但本 skill 专管"利润与用户、价格战、多元化"三题；速度观、规模观、同行关系、营销与产品等归后者。
- 与 `business-model-moat-checklist` 的区别：后者是投资侧拆解"这家公司有没有护城河"；本 skill 是经营侧"如何养成有护城河的文化"。差异化概念相通，方向相反。

## E — 可执行步骤 (Execution)

1. **给企业定位导向层级**：审视近期重大决策实际依据——是"什么好卖"（市场导向/利润导向）还是"用户真实需求"（消费者导向）
   - 完成标准：列出最近 3 个产品/定价决策，逐个标注决策依据；多数是"好卖/跟风"则判定为利润导向，先承认现状。
2. **检查有无"利润之上的追求"**：能否说出为了用户愿意放弃哪些短期利益（贵一些的物料、慢一些的周期、少一些的品类）
   - 完成标准：至少写出 1 条"为用户放弃的短期利益"并已执行；写不出则说明消费者导向还只是口号。
3. **价格战自检**：任何降价动作先问——是"主动降价抢量"还是"被动降价"（成本下降/清库存等有价值理由）
   - 完成标准：降价决策书面写明理由与对研发投入的影响；凡以"对手降了我也降"为唯一理由的主动价格战，一票否决。
4. **提升价值路线图**：把准备投入价格战的钱，列成研发/品质/体验的投入清单
   - 完成标准：形成至少 3 项差异化消费者价值的具体投入项与预算，替代降价方案。
5. **品类做减法**：盘点全部产品线，标注"我能做到很好"与"做不好/勉强"两类
   - 完成标准：对"做不好"的品类给出退出或停止追加投入的时间表；新增品类立项必须回答"为什么我能把它做好"而非"市场有多大"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是品牌、渠道、返修率、股权激励等落地打法——转 `bbk-product-channel-playbook`。
- 用户纠结的是"现在这个市场该不该进、什么时候进"——转 `dare-to-be-later`。
- 用户在投资侧分析某公司有没有护城河/定价权——转 `business-model-moat-checklist`。

### 作者在书中警告的失败模式（反例池 F10 家族为主）

- **薄利多销陷阱（f25 反面）**："动不动就是价格战……其实是低水平竞争的表现"——利润打没→无力研发→消费者长期受害，是利润导向企业的典型死循环。
- **标王魔咒（e20，与 c25 配对）**：爱多花 2.1 亿夺央视标王最终垮掉——营销驱动的重广告轻产品路线，与"用差异化消费者价值竞争"背道而驰；对照步步高"广告是技术不是艺术"、有产品支撑的标王竞标（c25）。
- **粗放扩张与忽视管理（e21，编者概括降权引用）**：无产品与质量支撑的增长必然崩塌——多元化铺摊子的系统性风险。
- **国产手机热潮溃败（e22，编者背景降权引用）**：靠低价与渠道冲量的国产手机厂商批量退场，是价格战路线的历史注脚。
- **电商假货与补贴战（e23，编者背景降权引用）**：以补贴和低价换增长伴随假货横行——"买得便宜但价值也低"的当代版本；引用时注明为背景对照而非段氏判断。

### 作者的盲点 / 时代局限

- "利润之上的追求"以企业已有正现金流为隐含前提——生存期企业在生死线上的利润取舍，本书未给出阶梯式指导；把"放弃短期利益"绝对化可能变成烧钱情怀。
- 段氏对多元化的否定针对"做不好的多元化"，苹果本身也有多产品线（Mac/iPad/手表）；读者易把"专注有限产品"误读为"永远只做一个产品"。
- 品种单一需要极强功力与供应链掌控，书中承认"我们现在也根本做不到这一点"——普通企业模仿单一品种策略前须先掂量功力。

### 容易混淆的邻近方法论

- **消费者导向 vs 用户至上主义/烧钱补贴**：后者常用补贴买"用户体验"，实为价格战变体；段氏的消费者导向以正毛利支撑研发为前提。
- **不打价格战 vs 不降价**：段氏明确"有时降价属于被动降价"——反对的是把价格战当竞争战略，不是反对一切价格调整。
- **专注 vs 鸡肋原则（→ bbk-product-channel-playbook 的 f34）**：鸡肋原则讲"挑大公司没兴趣的细分切入"的选择策略；本 skill 讲"为什么不能什么都要"的价值取向。两者常配套但层次不同。
