# 不为清单与风险底线：先保证活下来，再谈赚多少

## R — 原文 (Reading)

## I — 方法论骨架 (Interpretation)

段氏体系里风险控制不是"如何管理风险"，而是**一张事前写好的不为清单**：把会致命的动作直接从选项里删掉，而不是等出事时指望自己机智应对。骨架五层：

1. **风险管控只有一条纲**：不冒不该冒的风险（不对的事不做），不冒冒不起的风险（输光了翻不了身的赌注不做）——两问过滤一切"机会"。
2. **致命动作一刀切**：做空、杠杆/借贷、非闲钱，这三件事的共同点是**一次错误足以致命**——收益有上限、风险无下限的不对称游戏不参与；"不负债是可以活得长些"，活得长才等得到复利。
3. **用闲钱是心态的前提**：不是"闲钱收益更好"，而是只有闲钱才有平常心；动用救命钱或近期要用的钱，人会被期限逼成投机者。
4. **守正不出奇**：靠不出大错赢，不靠妙手赢——整天想着出奇制胜，犯错概率就上升；本分钱睡得着，睡得着才拿得住、活得长。
5. **错了马上改，是清单的执行机制**：Stop Doing List 的最后一环——一旦发现自己在做清单上的事（或买入逻辑错了），马上停，"不管多大的代价，到最后往往是最小的代价"；拖，才是最大的代价。

## A1 — 书中的应用 (Past Application)

### 案例 1: 巴菲特午餐——"三个不"的来处
- **问题**: 2006 年段永平以 62.01 万美元拍下巴菲特午餐，带黄峥同去；这顿饭到底学到了什么？
- **方法论的使用**: 他自述收获的不是选股技巧，而是最朴素的纪律——**不做空、不借钱、不做不懂的东西**。这三条后来直接写进他自己的不为清单。
- **结论**: 大师给的最值钱的东西不是"该做什么"，而是"不做什么"——风险底线的价值在于避免致命伤，而非提高收益率。
- **结果**: 这三个"不"成为其投资体系的地基，此后无一次杠杆或做空操作。

### 案例 2: 10 周年"犯错少所以活着"（守正不出奇的兑现）
- **问题**: 企业经营/投资十年，如何与更聪明、更激进的对手竞争？
- **方法论的使用**: 段永平把胜负归因于"我们犯的错比较少"——不追求出奇制胜的妙手，只坚持守正：不做不对的事，把基本的事情做对，赚本分钱。
- **结论**: 长期赛局里比的不是谁跑得快，而是谁不摔致命的跤；犯错机会下降本身就是复利的来源。
- **结果**: 步步高系与个人投资均以"活得长"著称，10 周年表述成为守正不出奇的标志性自述。

### 案例 3: UNG 认赔——知错马上改的学费
- **问题**: 段永平自述曾对不懂的标的 UNG（天然气 ETF）出手，判断被证伪且越亏越多（自述"多亏 4 倍"的教训）。
- **方法论的使用**: 承认"我不懂这个东西、这笔做错了"，不抱侥幸、不加仓摊平，清仓认赔离场——哪怕代价难受。
- **结论**: "发现错了马上改"不是理论，是要真金白银执行的；认赔的代价永远小于抱侥幸的代价。
- **结果**: 止损离场，把这次亏损记为学费，此后更严格执行"不懂不做"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在考虑**放大收益的高危动作**：做空某只股票、融资/配资上杠杆、借钱甚至抵押房子炒股。
2. 在纠结**该动哪笔钱**：手头紧但"机会难得"，想动用救命钱、生活费或半年后要用的钱入市。
3. 在**错与侥幸之间**：持仓逻辑已经坏了（或明知自己方法不对），却因为亏着不肯认、想等回本；或者总想搞点"出奇制胜"的高难度操作证明自己。

### 语言信号 (用户的话里出现这些就应激活)

- "想做空/融个券做空""上点杠杆/配资""借钱炒股""抵押房子""负债投资"
- "这笔钱是准备结婚/买房/救急用的，先拿来搏一把""闲钱还是全部身家""睡不着觉"
- "守正不出奇""不想慢慢赚，想出个奇招""都不这么干怎么赚大钱"
- "我知道错了但亏太多不甘心""等回本再说""再给它最后一次机会""马上改/止损认错"

### 与相邻 skill 的区分

- 与 `buy-sell-discipline` 的区别：卖出纪律回答"这笔持仓该不该卖"（买入理由是否消失、成本心态）；本 skill 回答"手段与筹码本身是否被禁止"——做空/杠杆/非闲钱是清单直接划掉的动作，与持有逻辑无关。跌了想赌反弹抄底属本 skill（"不抄底"在清单上）。
- 与 `concentrated-few-bets` 的区别：集中回答"出手多少次、仓位多大"的进取结构；本 skill 是风险底线，底线不随机会好坏松动。集中度取舍归前者，致命手段归本 skill。
- 与 `hold-long-term-mindset` 的区别：因波动拿不住、睡不着是心态问题归后者；因用了不该用的钱而睡不着是本 skill（换钱，不是修炼心态）。
- 与 `benben-do-right-things` 的区别：后者是"做对的事情"的哲学底座与人生/事业层面方向选择；本 skill 是它在投资操作上的落地清单——哲学讲"为什么不做"，本 skill 讲"具体哪几条不做、错了怎么办"。

## E — 可执行步骤 (Execution)

1. **过不为清单**：把计划中的操作对照清单逐项检查——做空？杠杆/借贷？非闲钱？投机/抄底？不懂的东西？
   - 完成标准：每项得到明确的"是/否"；任何一项命中即直接否决该操作，不再讨论收益。
2. **两问过滤剩余机会**：这是不是不该冒的风险（不对的事）？是不是冒不起的风险（最坏情况发生我能否承受、能否翻身）？
   - 完成标准：能用一句话写出最坏情形及其后果，且确认后果不致命（不毁生活、不失去再来的资格）；写不出或承受不起，放弃。
3. **资金分级**：把资金分成"十年内确定用不到的闲钱"与"有用途/有期限的钱"，只允许前者入市。
   - 完成标准：入市资金的来源、期限写成书面清单；任何救命钱、生活费、一年内要用的钱在清单外。
4. **守正自查**：检查策略是否依赖"出奇"——高难度择时、妙手操作、异于常识的高收益路径。
   - 完成标准：赚钱逻辑能用"本分钱"一句话说清（生意赚的钱而非对手兜里的钱）；说不清即降级或放弃。
5. **认错机制**：预先写下每笔投资的"错误信号"（买入理由被证伪的情形），触发即离场，不等回本。
   - 完成标准：错误信号在买入时写成文字；触发时按"马上改=最小代价"执行，不与盈亏数字谈判。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题只是"这笔持仓该不该卖/要不要落袋为安"——转 `buy-sell-discipline`（本 skill 不处理成本心态与卖出时点）。
- 问题只是仓位集中/分散、出手次数的取舍——转 `concentrated-few-bets`。
- 有闲钱却因行情波动恐慌、拿不住——转 `hold-long-term-mindset` 或 `ignore-market-noise`。

### 作者在书中警告的失败模式（反例池 F2/F1 家族）

- **做空百度（e04）**：亏 1.5~2 亿美元并耗尽储备金——"做空有无限风险，一次错误足以致命"；正与 c10 午餐"三个不"强对照。
- **杠杆与借贷（e05）**："一夜回到解放前""借钱可能会让你再也没有机会"——杠杆消灭的不是这笔收益，而是你留在牌桌上的资格。
- **非闲钱/抵押房屋（e06）**：动用有期限、有用途的钱，人被期限逼着动作变形，平常心与睡眠一并失去（t18 平常心挂钩）。
- **投机与博傻（e01/e02）**：想着牛熊市、赌接盘侠，就是守正的反面——出奇的尽头是灰姑娘舞会，钟声十二响必然有人站岗。
- **知错不改（p04 反面）**：明知是错却抱着侥幸拖下去——注意与 e17 边界：圈内看懂的公司拿住是纪律，明知逻辑坏了还死扛是灾难。

### 作者的盲点 / 时代局限

- "10 年闲钱"的门槛对多数普通工薪者偏高，本书未提供闲钱之外的渐进路径；完全照做可能长期踏空。
- 绝对不负债/不杠杆在机会成本上是保守的——可能跑输通胀或错过低息环境下的合理机会，段氏接受这一代价，读者须自知。
- "发现错了马上改"依赖判断力：什么算"错"没有外部标准，频繁改错与死扛不改之间没有算法，只有自己的功课质量兜底。

### 容易混淆的邻近方法论

- **止损线（价格止损）**：段氏体系没有"跌 X% 止损"——上游候选中此类条目已被剔除；段氏的"马上改"针对**逻辑错误**（买入理由消失），不是价格回撤。价格跌了逻辑没坏反而该买（见 p09）。
- **风险分散**：教科书用分散降低风险，段氏用不为清单删除致命动作+能力圈集中——两者机制不同，且"不搞多元化的分散投资"恰在其清单上。
- **保守=低收益**：本 skill 的目标是活得长而非赚得快，"最后还是会赚很多钱"是活得长的结果，不是牺牲收益的美德叙事。
