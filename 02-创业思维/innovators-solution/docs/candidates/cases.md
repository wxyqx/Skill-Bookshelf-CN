  summary: |

  outcome: 十年损失约500亿美元，股东价值严重受损；成为"为增长而增长摧毁价值"的标志性反例。

  type: case
  source_chapter: 第3章
  source_quote: 研究员们在一家餐厅连续待了18小时，对购买奶昔的人进行了仔细记录。……这项研究得出了一项令人吃惊的结果，就是将近一半的奶昔是在清晨被卖掉的，并且顾客经常是只购买一杯奶昔，多半是打包带走。
  summary: |
    某快餐连锁店按消费心态细分市场改进奶昔（更浓/更巧克力/更便宜）却无效。另一批研究员改为观察"顾客雇奶昔做什么"：清晨近半销量是长途通勤者单杯打包——任务是用一只手、不脏手地打发20分钟无聊车程，竞争对手是百吉饼、香蕉、甜甜圈和"无聊"本身；晚间则是父母"通情达理"地安抚孩子，该任务下奶昔常常失败。据此改良方向清晰：更浓、拌入果粒、设自助机加快购买。
  bound_to:
    - 任务理论（雇用产品完成任務）
    - 市场细分方法（按情境而非属性分类）
  outcome: 揭示同一产品身兼两个互斥任务；按任务细分给出明确改良路径与增长来源，成为全书任务理论的招牌案例。
  tags: [奶昔研究, 任务理论, 市场细分, 快餐]

    - 任务理论（雇用产品完成任務）
    - 新市场破坏与零消费者
