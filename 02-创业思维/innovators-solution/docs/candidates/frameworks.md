  type: framework
  source_chapter: ch03
  source_quote: "他们的思考程式始于'发现自己需要做一些事情'，然后他们就开始'雇用'能够帮他们有效地、便捷地、便宜地完成这一任务的东西。……关键的因素是客户的购买条件，而非客户本身。"

    可迁移为一般沟通/变革原则：同一信息在争取资源时与在执行时应当使用不同框架，两种框架可以并存于不同阶段。

- id: f12
  title: 模块化外包三条件检验（互依性三条件）
  type: framework
  source_chapter: ch05
  source_quote: "必须满足三个条件。第一，供应商和客户都应该了解产品的专项指标，即哪几项产品功能是系统必须具备的……第二，供应商必须十分熟悉产品属性的衡量标准……第三，在客户和供应商之间的接口处不能出现任何误解或具有不确定性的依赖关系。"
  summary: |
    决定外包/分包/联盟前逐条检验接口成熟度：①专业性——双方明确哪些功能指标是系统必需、哪些无关大局；②可衡量性——供应商熟悉产品属性的衡量标准，能按规格交付；③可预测性——接口处无任何不确定的相互依赖。
    三者齐备才是有效的模块化接口，分散协作才有效率；条件不成熟时强行分包注定失败（CLEC 的 DSL、早期 WAP 阵营）。
    推论：行业标准与联盟策略只在功能可靠性达标后的情境有效，过早标准化是真实的浪费。
  tags: [外包决策, 接口设计, 联盟时机, 三条件检验]

  type: framework

  source_quote: "在价值链上的任何地方只要发生了货品化现象，就会有一个与之相互左右的反货品化力量在价值链的某处产生影响。……那些将自身定位在'不够完善'的价值链区间的企业就能够赢利。"

- id: f14
  title: RPV 能力审计与组织匹配矩阵
  type: framework
  source_chapter: ch07
  source_quote: "这三个等级或三个因素可用来定义一个组织胜任的业务范围，即资源、流程和价值观，我们称之为RPV框架（resources，processes，values）。"
  summary: |
    评估组织能否胜任新业务时分三层盘点：资源（人、现金、技术、品牌——能做什么，可买卖）；流程（为特定任务而生的互动/决策模式——怎么做，跨任务即失灵）；价值观（优先级标准——不做什么）。
    用价值观双阈值反推盲区：毛利率门槛随市场升级不断上移、规模阈值随企业变大不断抬升，据此预测组织会对哪些机会"视而不见"。
    按流程×价值观匹配度选结构：双双匹配→并入主流；流程不符→重量级团队；价值观不符→独立成本结构部门；双双不符（破坏性）→自治组织。
    并购扩展：先问"我买的究竟是资源还是流程/价值观"——为资源则并入消化，为流程/价值观则保持独立并注入资源。
  tags: [组织能力, RPV, 自治组织决策, 并购整合]

  title: 高管参与度的情境判断规则
  type: framework

  source_quote: "高管需要一个健全的基于情境的理论作为'参政指南'——用这种方式来辨别，在何种情况下需要亲自参与，以及在何种情况下应授权给他人。……在破坏性创新的情况下，当权的高管必须亲自参与。在延续性创新的情况下，授权他人即可有效完成任务。"
