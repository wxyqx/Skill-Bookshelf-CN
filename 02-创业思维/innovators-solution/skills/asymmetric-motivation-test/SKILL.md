# 不对称动机检验（对所有在位者是否都是破坏）

## R — 原文 (Reading)

> 破坏性创新往往能使领先企业遭受瘫痪性打击。由于它们的资源分配流程往往是为了延续性创新而设计完善的……它们的目光总是看着高端市场，几乎从未考虑过保卫新市场或低端市场的阵营……我们称这种现象为"不对称动机"。
>
> — 克里斯坦森 & 雷纳，第2章《破坏性创新的不同模式》

---

## I — 方法论骨架 (Interpretation)

不对称动机不是"双方资源不对等"，也不是"对手犯错"，而是一种可预测的自然经济力量：面对同一个创新，在位者与新入者的理性选择方向系统性相反。在位者的资源分配流程是为延续性创新设计的，它的目光总盯着更肥的高端市场，几乎从不考虑保卫低端或新市场阵营；因此它"逃跑"比"迎战"更理性。

操作上，本 skill 要求你把构想放进每一个在位者的成本结构与业务流程里去判断：对它是破坏还是延续？只要对其中任一重要在位者只是延续性改良，它就会全力反击，而新入者无胜算——此时应退回计划阶段，而不是正面对抗。

再向前一步，预测在位者的理性反应：它必然迎合最重要的客户、把资源投向利润最丰厚的领域。如果你的目标市场在它的成本结构下"形同鸡肋"（规模太小、毛利太低），它会主动撤退。于是胜负不是来自对手犯错，而是来自对手"正确地"跑了——你可以在出手前就判定战场是否值得。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小型钢铁厂上攻，大型综合钢厂逐级"理性退让"
- **问题**: 小型钢厂凭约20%成本优势从钢筋市场切入，大型钢厂会反击还是退让？
- **方法论的使用**: 逐一扫描在每个产品层级（钢筋7%毛利、条钢12%、结构钢18%……）大型钢厂的成本结构与资源分配：这些低毛利市场对它们"形同鸡肋"，其资源会被导向更高端的钢板、汽车板等肥市场。逐级判断的结果都是"对在位者不构成吸引，因而会主动撤退"。
- **结论**: 每一级都被判为对在位者非破坏性威胁，因此新入者可胜。
- **结果**: 2000家大型钢铁企业无一成功投资小钢厂技术，小钢厂最终占北美钢产量一半，Nucor 市值超过 US Steel。

### 案例 2: TCC寓言——供应商的不对称动机逐级向上吞食
- **问题**: 模块化PC组装商TCC的自制/外包边界该划在哪？
- **方法论的使用**: 反向使用不对称动机：对组件供应商而言，每接手一块"TCC的核心竞争力"（电路板、主板、组装、供应链、设计），都是它自己沿价值链向上迁移、赚更多钱的机会。逐级判断每项业务"对供应商是延续性上攻还是鸡肋"——答案是持续上攻。
- **结论**: 供应商有强烈的、可预测的不对称动机逐级吞食，TCC每次剥离都是在给它搭梯子。
- **结果**: TCC只剩品牌空心躯壳，利润被供应商沿价值链逐级吞走；提醒提问"这项工作也不是他的核心竞争力，他为什么要？"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 进入一个已有巨头的市场前，先判断"巨头会反击还是让路"。
2. 大企业内部评估某个破坏性方向：主流业务部门会不会用资源和价格战把它掐死。
3. 面对投资人/董事会的质疑"凭什么你能赢过在位者"，需要给出基于对手动机的论证而非"我们更快更拼"。
4. 已选定细分市场，需要确认"这块对在位者是否鸡肋到它会主动撤退"。

### 语言信号 (用户的话里出现这些可能激活)

- "巨头为什么不打我们？"
- "在位者会跟进还是会放弃这块市场？"
- "会不会被大厂用价格战碾压？"
- "Will the incumbents retaliate or retreat?"
- "我们凭什么在它眼皮底下活下来？"

### 与相邻 skill 的区分

- 与 `three-stone-tests` 的区别: 本 skill 是那三关里"第三关（对称动机）"的深度展开；当你只纠结"对每个在位者是否都被破坏、它会怎么反应"时用本 skill，而不是重跑整三关。
- 与 `commoditization-positioning` 的区别: 对方用不对称动机预测利润沿价值链**迁移到哪个环节**（供应商逐级上攻、该定位在哪个"不够好"的子系统），本 skill 预测**在位者对新入者的行为**（反击或撤退）。
- 与 `channel-motivation-test` 的区别: 对方把"渠道"当客户审计它的不对称动机（能否靠你的产品向高端迁移）；本 skill 的对象是产品市场上所有主要竞争者/在位者。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **枚举目标市场的所有重要在位者**
   - 完成标准: 列出一份清单，含直接竞争者与"会被同一任务波及"的相邻强者，并注明各家的主力客群与利润重心，不遗漏任何一家可能出手的玩家。

2. **逐家把构想放进其成本结构与业务流程判断性质**
   - 完成标准: 对清单中每一家给出"破坏 / 延续"的判定，并说明依据（是否争夺其核心高毛利产能、是否需要它放弃现有客户、是否能利用其品牌与分销网络）。

3. **执行否决规则**
   - 完成标准: 若存在任一重要在位者会被判定为"延续性改良"（它会反击），即标记该战场为高危，结论应为"退回计划阶段重塑构想"。
   - 判停条件: 若全部在位的判定都为"破坏" → 进入步骤 4。

4. **预测在位者的理性反应**
   - 完成标准: 对被判为"破坏"的在位者，写明它最可能的动作——迎合最重要客户、把资源投向最肥市场、放弃低毛利/小规模市场，并给出"它是否会主动撤退"的判断及理由。

5. **输出战场结论**
   - 完成标准: 给出可执行的单一结论——"值得出手（对手会正确地逃跑）"或"退回重塑（会被反击）"，并列出使结论成立所需的关键假设与仍需核实的证据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只做单一竞品的功能对标（"竞品有什么我们也加什么"）——这是属性军备竞赛，不是动机检验。
- 纯技术路线/架构选择，或与消费需求的匹配问题——那属于互依性-模块化或任务理论。
- 泛泛的行业竞争分析（五力、SWOT）——本 skill 只问一个很窄的问题：对每个在位者是破坏还是延续。

### 作者在书中警告的失败模式

- **把破坏性技术硬塞进主流市场（威胁-僵化）**：在位者感知到威胁后会本能地保卫客户基础、把技术做成延续性产品塞进主流价值网络，与现有产品自相残杀，既错失新市场又被破坏者歼灭（ce02）。这正是不对称动机的反面印证。
- **用"核心竞争力"话术做外包决策**：供应商主动愿意接手你的"非核心"业务，往往正是其不对称动机向高端上攻的信号（ce07、ce09）。

### 作者的盲点 / 时代局限

- 结论建立在 2003 年前美国上市大企业样本上，对平台/生态型组织、强监管行业、非上市耐心资本、扁平小团队的适用性未经验证。
- "在位者几乎总是向高端迁移""几乎从不保卫低端"属"几乎总是"类结论，受案例选择影响，未必对所有市场成立。
- 对在位者成本结构、资源分配真实规则的判断需要大量内部信息，外部人往往只能近似估计；需求线与动机的观测精度有限。
- 书中"破坏的相对性"（同一互联网对戴尔是延续、对康柏是破坏）等前瞻对照未经时间检验。

### 容易混淆的邻近方法论

- 与"先发优势/规模壁垒"式竞争观：后者把胜负归因于企业属性，本 skill 归因于创新类型与环境（在位者动机）的匹配。
- 与"对手会犯错"叙事：本 skill 的胜负恰恰来自对手"正确地"做了对自己最有利的事。
