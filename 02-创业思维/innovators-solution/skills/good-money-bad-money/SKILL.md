# 好钱坏钱诊断与死亡螺旋五步自检

## R — 原文 (Reading)

> 如果强迫他们承诺高成长率，也就等于迫使他们在宣布战略时，必须表现出有充分的信心将创新项目带入现有的大型市场，并维持其成长规模。
>
> — 克里斯坦森 & 雷纳, 第9章 钱能载舟，亦能覆舟

---

## I — 方法论骨架 (Interpretation)

判断资金好坏，不看出资人身份（风投 vs 企业资本、公募 vs 私募），而看这笔钱隐含的**投资者期望结构**，用两个维度问：

- 这笔钱要求多快**做大**？（对成长的耐心）
- 这笔钱要求多快**赢利**？（对利润的耐心）

早期破坏性业务最理想的组合是"**耐成长 + 急利润**"：允许慢慢长大，但要求尽快赚钱。急迫赢利是良药——它倒逼真实付费测试、压低成本结构，并在核心业务失血时让新业务因"缺了它更糟"而免于被砍。反之"急成长 + 耐利润"是坏钱，会逼公司在立足点未明前承诺高增长，为兑现承诺放弃零消费市场、转攻主流客户。接受投资前应先谈判期望结构，钱到手即锁定。

**死亡螺旋五步自检**：①核心业务成功并聚焦 → ②成长缺口（华尔街把增长预期贴现进股价，要求超过预期） → ③价值观门槛抬升，只有"能快速做大"的项目过审 → ④为兑现承诺巨额投入、忍受长期亏损 → ⑤亏损引发收缩回核心，而后回到第三步，循环加剧。预警：用理论模式识别（零消费切入、竞争基础迁移、模块化对系统化）而非滞后财务数据判断失速。

## A1 — 书中的应用 (Past Application)

### 案例 1: 强生双组对照——破坏性收购年增 43% vs 平台收购 4%
- **问题**: 1993 年强生消费品组与医疗设备组（MDD）规模均约 50 亿美元，为何十年后成长率天差地别？
- **方法论的使用**: MDD 组收购具破坏性潜力的早期业务（爱惜康内窥镜、Cordis 血管成形术等），消费品组则溢价收购成熟平台（Neutrogena 等）。
- **结论**: 收购成熟平台只抬高收入平台高度，收购早期破坏性企业才拉高成长斜率。
- **结果**: MDD 组自 1993 年起年增 43%，带动整组年增 11% 以上；消费品组年增仅 4%。

### 案例 2: 本田 SuperCub——缺钱逼出好钱
- **问题**: 1958 年本田进军美国，日本大藏省只批 25 万美元外汇（仅 11 万现金），押注大车型的计划几乎破产。
- **方法论的使用**: 现金耗尽逼出应急型战略：员工日常骑 SuperCub 引来体育用品店询购，索性转向创造越野摩托新市场（价格约为大哈雷的 1/4）。
- **结论**: 稀缺、对成长有耐心的小钱反而催生更卓越的应急能力；缺钱不是坏事，期望结构才是关键。
- **结果**: 从几乎破产到开创全新细分市场，成为新市场破坏经典正面案例。

### 案例 3: 90 年代末风投泡沫与贝恩资本
- **问题**: 经验丰富的风投为何把巨额资金投给尚无产品和客户的早期企业？
- **方法论的使用**: 钱变多后价值观改变，必须要求被投企业迅速做大，和企业内部资本已无区别，落入死亡螺旋第三至第五阶段。
- **结论**: 坏钱既可来自风投也可来自企业内部投资，与出资人身份无关。
- **结果**: 泡沫破裂；对照贝恩资本随自身规模变大主动停止天使投资、转为后期私募，继续表现优异。

### 案例 4: 耐普罗与 StallPoints 的失速研究
- **问题**: 为何成长停滞的企业几乎无法重启？
- **方法论的使用**: 《失速点》研究显示，成长停滞企业中仅约 4% 能重新启动增长超过 GNP 增速 1%；成长放缓会抬升价值观门槛，全面叫停破坏性项目。
- **结论**: 用理论模式做失速预警，而非等财务数据恶化。
- **结果**: 说明好钱变坏钱的可预测机制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 初创或新业务在评估一笔投资/融资条件，对方隐含"快速做大"要求，用户拿不准该不该接。
2. 新业务长期靠母公司补贴、多年亏损，团队以"先赔几年是常态"为由持续投入。
3. 高管/创始人感觉被"成长缺口"绑架，为了兑现承诺被迫放弃零消费市场、转攻主流大客户。
4. 想判断某笔钱的期望结构是否健康，或想设计早期最理想的投资期望。

### 语言信号 (用户的话里出现这些就应激活)

- "这笔钱该不该拿？投资人要求三年做到 XX 规模。"
- "新业务先烧几年再说是常态吧？"
- "为了兑现增长承诺，我们是不是只能去打大客户了？"
- "怎么判断这笔投资是好钱还是坏钱？"
- "good money bad money / 成长缺口 / 死亡螺旋 / growth gap"

### 与相邻 skill 的区分

- 与 `growth-engine-cadence` 的区别: 本 skill 诊断某笔资金/投资环境的期望结构是否健康（被动诊断）；后者是主动政策——趁核心健康时按既定节奏持续启动新业务。
- 与 `emergent-deliberate-strategy` 的区别: 后者判断战略流程用应急还是谋划；本 skill 判断资金背后的耐心结构如何扭曲战略选择。
- 与 `resource-allocation-audit` 的区别: 后者审计组织内部资源分配过滤器；本 skill 聚焦外部/内部投资者期望结构对破坏性业务的挤压。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **给这笔钱打两个耐心坐标**
   - 完成标准: 明确回答"要求多快做大（对成长的耐心）"与"要求多快赢利（对利润的耐心）"，定出四象限中的位置。
   - 判停条件: 若是"耐成长+急利润"，判定为好钱，可跳到步骤 4 做加固建议。

2. **识别坏钱的具体压力**
   - 完成标准: 指出"急成长+耐利润"如何逼企业放弃零消费/低端立足点、转攻主流客户。

3. **跑死亡螺旋五步自检**
   - 完成标准: 逐条核对①成功聚焦→②成长缺口→③价值观门槛抬升→④巨投入忍亏→⑤收缩回核心，标出企业当前处于哪一步。

4. **重新谈判或设计期望结构**
   - 完成标准: 给出"耐成长+急利润"的具体条款/考核动作（如尽早赢利、按模式而非收入考核），并说明钱到手后如何锁定期望。

5. **建立失速预警**
   - 完成标准: 用理论模式识别（零消费切入、竞争基础迁移、模块化对系统化）设定预警指标，替代滞后财务数据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在做常规财务估值、融资条款法律审查，不涉及投资者期望结构与破坏性战略的匹配。
- 用户问的是"该按什么节奏持续启动新业务"——应使用 growth-engine-cadence。
- 成熟核心业务的常规资本预算问题，与"好钱坏钱"的破坏性情境无关。

### 作者在书中警告的失败模式

- **过早追求规模与上市（强迫承诺高增长）**（ce15）：新业务被要求第一年就做出可观收入，迫使团队承诺服务大客户而非零消费/低端客户，背离破坏性初衷。
- **长期补贴新业务、忍受多年亏损**（ce16）：误以为"先赔几年"是常态，团队不急于验证真实付费意愿，成本结构被抬高，错误策略被长期放任。
- **资本市场只看短期指标**：坏钱逼出"公布不切实际成长率"，不愿者被愿意者替换。

### 作者的盲点 / 时代局限

- 案例与资本市场语境集中于 2003 年前的美国（华尔街成长贴现机制），对非上市耐心资本、主权基金、家族企业、中国式产业资本的适用性需打折。
- "对成长有耐心、对利润没耐心"的期望结构在现实中难以精确写入合同并执行，可操作性弱于其诊断价值。
- 4% 重启率、强生 43% vs 4% 均来自有限样本，结论受案例选择影响，作者自承可预测性存在未消除的不确定性。
- 死亡螺旋是若干企业的归纳机制，未必普适于平台型/网络效应型企业（其成长逻辑与贴现方式不同）。

### 容易混淆的邻近方法论

- 精益创业的"烧钱率/跑道"讨论：关注现金耗尽时间，本 skill 关注期望结构而非单纯的资金量。
- VC 分阶段投资理论：关注里程碑与稀释，本 skill 从"利润耐心"角度补充早期赢利的战略价值。
