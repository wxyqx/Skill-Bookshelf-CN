# 零消费者甄别（真零消费 vs 无任务）

## R — 原文 (Reading)

> 你如何辨别当前的"零消费者"是否会被打动，开始消费你的产品？……一个产品如果定位于帮助"零消费者"完成他们并不急于完成的工作，那么这个产品是不太可能取得成功的。……人们想要完成某项工作，但是因为现有的产品太贵或者太复杂……这类"零消费市场"就是绝佳的成长机会。
>
> — 克里斯坦森 & 雷纳，第4章《我们的产品最适合哪些客户》

---

## I — 方法论骨架 (Interpretation)

"零消费者"不是"买不起的人"，而是"有任务要完成、却因现有方案太贵或太复杂而尚未找到满意解法的人"——他们勉强用不便的、昂贵的或满意度低的方式凑合。这两者必须分开。

因此遇到一个"零消费市场"，第一件事不是问"他们买不买得起"，而是用**任务问题**甄别：这些人有没有一项要完成的工作，而现有方案无法胜任？答案若是"有任务、无满意方案"，就是绝佳成长机会；答案若是"根本没有相应任务"，那么再便宜再简单也不会被消费，注定失败。只凭"人口基数大"或"少数人在用"判断都会误判。

第二件事是问**参照基准**：客户拿什么做比较？若他们拿"没有产品"做对比（如从未通电的地区），简单、便宜、可靠即能取悦，性能门槛极低；若他们拿主流产品做对比，则必须做得更好才卖得动，游戏规则完全不同。真实的竞争对手在某些情况下就是"零消费状态"本身。

## A1 — 书中的应用 (Past Application)

### 案例 1: 索尼晶体管收音机/电视——瞄准真零消费者
- **问题**: 索尼进入美国消费电子市场，面对 RCA 等真空管巨头的成熟台式收音机市场。
- **方法论的使用**: 索尼不去抢台式收音机用户，而是甄别出一群"有任务、无方案"的人：买不起真空管收音机的青少年（任务=远离父母和朋友一起听摇滚乐）、住在小套间放不下立式电视的人（任务=拥有自己的电视）。这些人以"没有电视/收音机"为参照基准，因此简单低端产品即可取悦，技术门槛与研发成本都低。
- **结论**: 这是真零消费（有任务无方案），而非无任务型零消费。
- **结果**: 便携晶体管收音机与12英寸黑白电视取得巨大成功，为新市场破坏取得立足点。

### 案例 2: 血管成形术 / 太阳能——两类零消费的甄别
- **问题**: 如何判断医疗与能源领域的零消费是不是真机会？
- **方法论的使用**: 血管成形术面向"大部分承受心脏病痛苦却只能默默忍受"的患者——有任务（治疗动脉硬化），但原有方案（高成本外科手术）太复杂昂贵，属真机会；太阳能面向南亚非洲约200万无电网人口，参照基准是"没有电"而非电网，故便宜、免审批、可靠即取悦，也是真机会。对照无效案例：低价上网终端、便宜电脑面向"无相应任务"的人群，注定失败。
- **结论**: 同是"未消费人群"，有无任务、参照基准是什么，决定截然不同的成败。
- **结果**: 血管成形术创造巨大新市场；太阳能在小规模零消费立足点上方能缓慢上攻高阶市场。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到一群人"还没买过/用不起某个东西"，想判断这到底是不是可做的成长机会。
2. 市场论证只有"这个人群基数很大"或"买不起所以是蓝海"，缺少任务缺口证据。
3. 决定产品的性能标准与定位：客户是拿"没有产品"还是比较高端产品做对比。
4. 需要区分"真零消费"与"无任务型零消费"以避免投入注定失败的市场。

### 语言信号 (用户的话里出现这些可能激活)

- "这群人买不起，是不是我们的机会？"
- "下沉市场/农村市场值不值得做？"
- "他们还没有用过类似的产品，算不算未被满足的需求？"
- "How do I identify true nonconsumption vs no need?"
- "我们的产品只要比'没有'好一点就够了"

### 与相邻 skill 的区分

- 与 `hire-product-theory` 的区别: 对方是任务理论总纲（发现任务与竞争集合）；本 skill 把"任务问题"专门用于甄别零消费人群真伪，是更窄的甄别工具。
- 与 `three-stone-tests` 的区别: 对方的第一关（新市场两问）给出"是否面对零消费"的粗判；本 skill 对那一关的人群做真伪与参照基准的细筛。
- 与 `new-market-disruption-pattern` 的区别: 对方用四要素塑造完整的新市场破坏计划（零消费者是其中第一要素）；本 skill 只负责把"零消费者"这个要素甄别清楚。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确"零消费"定义并圈定人群**
   - 完成标准: 用"有任务要完成、因现有方案太贵或太复杂而未获满意解法"的口径锁定目标人群，明确排除了"单纯买不起"和"已在正常消费"的人。

2. **执行任务问题甄别**
   - 完成标准: 对目标人群逐一回答"他们要完成的工作是什么、现在用什么方式凑合、这个方式为何不满意"；给出"有任务无方案 / 无任务"的分类证据。
   - 判停条件: 若证据显示"无相应任务" → 判为伪机会，结论为不做，不要转向价格论证。

3. **查验现有凑合方式的真实痛点**
   - 完成标准: 记录他们目前"勉强使用的不便、昂贵或满意度低的方式"，确认存在可感知的痛点与付费/改用意愿，而非仅凭人口规模推断。

4. **确定参照基准**
   - 完成标准: 明确客户拿什么做比较——"没有产品"还是主流产品；据此给出性能门槛的判断（前者简单便宜可靠即可，后者必须显著更好）。

5. **输出机会判定**
   - 完成标准: 给出单一结论（真机会 / 伪机会）及支撑证据，并列出产品为满足该任务所需达到的最低性能与可达性要求。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 目标客户已经在正常消费、你想从在位者手里抢低端客户——那是低端市场破坏，用 `three-stone-tests` 的第二关，而非零消费甄别。
- 纯定价/补贴设计问题——本 skill 不回答"该定多少钱"，只回答"这群人有没有任务"。
- 已确证有任务、只需执行产品落地——甄别阶段已过，转任务理论与四要素。

### 作者在书中警告的失败模式

- **把"无任务型零消费"误当成长机会**：把"买不起/没买过"直接等同于零消费，忽视其中一部分人根本没有相应任务，于是投入注定失败的市场；仅凭"少数人在用"或"人口基数大"都会误判（ce05）。
- **试图让客户改变任务**：若零消费人群并无该任务，产品再便宜也不会被消费；不能靠教育客户创造需求（ce04）。

### 作者的盲点 / 时代局限

- 样本集中于 2003 年前的美国上市大企业，对平台/生态型组织、非上市耐心资本、扁平小团队的适用性未经验证。
- "需求线"/是否真的没有满意方案难以精确观测，任务甄别高度依赖定性判断与访谈质量。
- "零消费市场是成长沃土"类结论受案例选择影响（成功的太阳能、血管成形术与失败的上网终端并存），存在幸存者偏差。
- 对新兴经济体零消费市场的乐观推演（如中国空调零消费）属前瞻判断，未经长时间检验。

### 容易混淆的邻近方法论

- 与"未满足需求/蓝海"口号：本 skill 要求先证明"有任务"这一硬条件，而不是把"未被消费"直接当成机会。
- 与按购买力分层（金字塔底层市场）：本 skill 的判据是任务缺口，不是收入水平。
