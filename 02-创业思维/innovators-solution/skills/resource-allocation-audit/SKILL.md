# 资源分配过滤器审计（实际战略是资源分配的输出）

## R — 原文 (Reading)

> 英特尔公司董事长安迪·格鲁夫劝告说："要了解公司的实际策略，就要注意公司管理者的行动，而不是他们的言论。"……按我们的说法，这意味着一个企业的策略是资源分配流程的结果，而不是其成因。
>
> — 克里斯坦森 & 雷纳，第8章《战略开发流程的管理》

---

## I — 方法论骨架 (Interpretation)

企业的实际战略不是高层写下的宣言，而是资源分配流程的输出。预测一个组织"实际上"会执行什么，要盘点那些决定创意能否上浮的过滤器，而不是听它宣称要做什么。

过滤器由几股力量组成：中层管理者的筛选标准（要可靠的市场规模数据、要重点客户反馈、要在任期内见回报、要顾及职业风险）；成本结构决定的毛利率门槛；企业规模决定的规模阈值；高潜人才2-3年轮岗周期带来的短视；以及销售团队的激励补偿与客户账单（客户才是真正的账单支付者，往往比高管更能控制资源流向）。

这些过滤器会把好点子系统性地"磨平"：中层为让创意过审，按"类似过去成功案例"的模板重新包装，把面向零消费/低端的破坏性构想改写成服务现有主流客户的延续性计划。诊断动作很简单：对比高管宣称的投入与资金/产能的真实流向——看行动不看言论。预测动作：把创意放进四标准，预判它会被磨成什么样。

头号杠杆是**初始成本结构**：新业务启动时先设定低固定成本结构（成本结构会迅速固化为价值观），使零消费/低端客户的小订单在过滤器中"够格"——否则理想客户的订单在内部永远过不了审批。

## A1 — 书中的应用 (Past Application)

### 案例 1: 英特尔退出DRAM——中层资源分配先于高管战略
- **问题**: 英特尔从DRAM生产商转型为微处理器公司，是高管战略决策的结果吗？
- **方法论的使用**: 生产调度员每月按单位用料毛利率为产品排产能。80年代初日本厂商压价使DRAM毛利率垫底，而微处理器毛利最高，产能就被有序转移给微处理器。与此同时高管仍把2/3研发预算投给DRAM。用过滤器审计看资源配置的**实际流向**，再对比高管宣言，二者严重背离。
- **结论**: 实际战略由中层的日常资源分配决策决定，高管只是事后追认。
- **结果**: 1984年财务危机后，摩尔与格鲁夫"走出旋转门再走进来"，正式放弃DRAM；英特尔成功转型，但转型是资源分配流程的产物而非高管谋划的结果。

### 案例 2: BIG创意集市 vs 大型玩具公司——同一批创意的不同命运
- **问题**: 大型玩具公司多年抱怨"没有振奋人心的创意"，问题真在创意匮乏吗？
- **方法论的使用**: BIG在全国办"创意集市"征集玩具创意，专家评审、买断版权、打磨雏形再授权；大型玩具公司买它打磨好的创意却仍屡屡失败。用过滤器审计：大型企业内部的中层筛选（市场规模数据、任期内回报、职业风险）与包装流程系统性磨平了破坏性创意，让其"销声匿迹"。
- **结论**: 不是人才缺乏创造力，而是塑造过程磨平了创意。
- **结果**: 同一批创意在BIG系统开花结果、在大型玩具公司内湮灭，证明失败源于塑造过程与资源分配过滤器。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司宣称重视创新/新业务，但资金、产能、人才实际都流向主流业务，想知道"实际战略"是什么。
2. 有个破坏性好创意总在审批环节被要求补数据、被改成服务现有客户的计划，想诊断磨平机制。
3. 要预判某个创意在组织内部会被"包装"成什么样子，以及能否拿到资源。
4. 新业务即将启动，需要设计让它"够格"的初始成本结构。

### 语言信号 (用户的话里出现这些可能激活)

- "战略定了，但下面执行不下去。"
- "资源永远给不到新业务。"
- "好创意一到中层就变味/上不了会。"
- "How do I see the real strategy of my org?"
- "看行动不看言论"

### 与相邻 skill 的区分

- 与 `executive-engagement-rules` 的区别: 对方决定"高管何时必须亲自介入"；本 skill 先揭示资源分配流程这个"信息纵向不对称"的黑箱，是前者预警信号的理论基础。
- 与 `new-market-disruption-pattern` 的区别: 对方主动设计一条**平行**的模式评审流程来保护破坏性创意；本 skill 诊断**现有**过滤器会怎么处理它、实际战略是什么。
- 与 `emergent-deliberate-strategy` 的区别: 对方判断该用应急型还是谋划型战略流程；本 skill 关注资源分配这一具体机制的实际流向与筛选标准。
- 与 `good-money-bad-money` 的区别: 对方按投资者期望结构诊断资金好坏与死亡螺旋；本 skill 关注组织内部过滤器对创意的塑造与磨平。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **建立过滤器清单**
   - 完成标准: 列出该组织实际存在的筛选标准，至少覆盖——中层四标准（市场规模数据、重点客户反馈、任期内回报、职业风险）、毛利率门槛、规模阈值、高潜人才轮岗周期、销售激励与客户账单。

2. **对比宣称与真实流向（看行动不看言论）**
   - 完成标准: 用资金、产能、研发预算、人员配置的真实分配数据，与高管宣称的投入做逐项对照，标出背离处；给出"实际战略"的一句话描述。
   - 判停条件: 若真实流向与宣言一致且充分支持新业务 → 结论为过滤器暂未构成障碍，本 skill 可收尾。

3. **把目标创意放进四标准做预判**
   - 完成标准: 逐条说明该创意在四标准下会被如何要求、如何被包装改写；明确写出"它可能被磨成什么样的延续性计划"。

4. **定位初始成本结构杠杆**
   - 完成标准: 为新业务设计低固定成本结构，逐项核对理想客户（零消费/低端）的小订单在该成本结构下能否赢利、能否过毛利率门槛与规模阈值，并说明成本结构会如何固化为价值观。

5. **设计让创意"够格"的通道动作**
   - 完成标准: 给出至少一条具体动作（如设独立单元、改销售激励、设平行审批标准），使破坏性创意不被现有过滤器磨平；注明该动作的负责层级与验证方式。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只是撰写战略文案/愿景宣言——本 skill 刻意不信任宣言。
- 单个已获批准项目的常规预算编制——过滤器审计针对的是"创意能否上浮"这一机制层面。
- 组织能力该放哪个部门的问题——那是 RPV 审计（`rpv-capability-audit`）。

### 作者在书中警告的失败模式

- **把破坏性创意包装成延续性计划（磨平机制）**：中层按"类似过去成功案例"重新包装，把面向零消费/低端的构想改写成服务现有主流客户、塞满现有客户与渠道的计划；好点子不是没有，而是在上报环节被系统性改造（ce01）。
- **为提升ROA层层剥离资产，陷入死亡旋涡**：剥离决策被ROA/资产负债表驱动而非竞争情境，用"聚焦核心竞争力"解释每一次外包，最终只剩品牌空心躯壳（ce09）。

### 作者的盲点 / 时代局限

- 样本集中于 2003 年前的美国上市大企业，其"成本结构固化为价值观""规模阈值随企业变大抬升"的机制对平台/生态型组织、非上市耐心资本、扁平小团队的适用性未经验证。
- 过滤器清单属作者特定操作化，不同行业/治理结构的实际过滤器可能大不相同；外部观察者难以获得资金与产能真实流向的内部数据。
- "看行动不看言论"近于常识，其诊断力高度依赖数据的可得性与解读者的判断；"几乎总是"类磨平结论受案例选择影响。
- 书中若干前瞻推演未经时间检验；后续的精益创业、OKR 等实践可能已改变部分过滤器的形态。

### 容易混淆的邻近方法论

- 与"战略解码/平衡计分卡"：后者从目标向下分解，本 skill 从资金与产能的实际流向往上反推实际战略。
- 与"预算管理"：本 skill 不优化预算本身，而是把预算当作洞察真实战略的证据。
