# RPV 能力审计与组织匹配矩阵

## R — 原文 (Reading)

> 一个组织不能进行自我破坏，其原因在于，成功的组织自然只能优先考虑那些相对其目前成本结构来说，能够带来更大利润率的创新。
>
> — 克里斯坦森 & 雷纳, 第7章 你的组织是否有能力实现破坏性成长

---

## I — 方法论骨架 (Interpretation)

组织能否胜任一项业务，不看"谁来做"或资源多少，而按三层盘点：

- **资源（Resources）**——人、现金、技术、品牌、关系。看得见、可买卖、可转移。
- **流程（Processes）**——为特定任务而生的互动与决策模式。怎么做事；换个任务往往就失灵，且难以挪用到新情境。
- **价值观（Values）**——优先级标准，即组织"不做什么"的准绳，由成本结构与规模阈值驱动。

能力会随成功从资源向流程、价值观、文化沉淀，因此成熟组织天然排斥低毛利、小规模的新业务。用价值观双阈值反推盲区：毛利率门槛随市场升级上移、规模阈值随企业变大抬升，据此可预测组织会对哪些机会"视而不见"。

匹配矩阵决定结构：
- 流程与价值观**双双匹配** → 并入主流组织；
- **流程不符、价值观符** → 用重量级团队重建流程；
- **价值观不符、流程符** → 独立成本结构部门；
- **双双不符（典型破坏性）** → 自治组织，关键在流程自由 + 独立成本结构，而非地理/法律上的分离。

并购同理：先问买的是资源还是流程/价值观——为资源则并入消化（丢弃对方不成熟流程），为流程/价值观则保持独立并注入资源。

## A1 — 书中的应用 (Past Application)

### 案例 1: 嘉信理财的自治组织
- **问题**: 在线经纪是低客单价、新模式业务，放主流组织会因成本结构不匹配而做不成。
- **方法论的使用**: 设为完全自治组织：在线交易 29.95 美元，而电话/网点经纪均价近 70 美元，独立成本结构使低价仍有利可图。
- **结论**: 组织不能自我破坏，须建独立成本结构的新部门承载破坏性业务。
- **结果**: 18 个月后公司反过来把主流业务并入新组织，价值观随成功破坏而更新。

### 案例 2: 思科的收购之道
- **问题**: 并购后该如何整合，才能既借力母公司又不毁掉被收购方的价值？
- **方法论的使用**: 用 RPV 判断价值所在——收购成立不到两年的小公司，价值在资源，插进母公司成熟流程并丢弃对方不成熟流程；1996 年收购更成熟的 StrataCom，价值在流程与价值观，保持独立并注入资源。
- **结论**: 买资源则并入，买流程/价值观则独立。
- **结果**: 思科收购整合成功率远高于同行（对照戴姆勒-克莱斯勒式的强行合并）。

### 案例 3: Woolco 被主流价值观同化
- **问题**: 伍尔沃斯把 Woolco 的管理、采购、后勤融入主体，期望共享固定费用。
- **方法论的使用**: 主流价值观按伍尔沃斯赢利模式要求 Woolco 利润率高达 34%、存货周转降至每年 4 次——与折扣店模式根本冲突。
- **结论**: 破坏性机遇需保持独立；延续性机遇才并入主流。
- **结果**: 不到一年 Woolco 关门大吉。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 企业要孵化一项低客单价/快迭代/新成本结构的新业务，纠结放哪个部门、要不要单设组织。
2. 计划并购一家公司，需要决定并入消化还是保持独立经营。
3. 组织内部有人问"我们到底有没有能力做这件事"，需要客观审计资源/流程/价值观的匹配度。
4. 新业务在主流体系内被要求套用母公司的毛利率/规模门槛/协同 KPI，出现"水土不服"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个新业务该放在哪个部门？"
- "要不要单设一家独立公司 / 独立成本结构？"
- "并入母公司还是让它独立经营？"
- "组织能力够不够做成这件事？"
- "RPV / autonomous unit / 能力错配 / 重量级团队"

### 与相邻 skill 的区分

- 与 `executive-engagement-rules` 的区别: 本 skill 决定"组织该用什么结构承载新业务"；后者决定"高管本人该不该亲自挂帅、介入多深"（按情境而非规模）。
- 与 `resource-allocation-audit` 的区别: 本 skill 审计组织能力三要素并选结构；后者审计资金/产能流向与中层筛选标准，看真实的战略是什么。
- 与 `interdependence-modularity-match` 的区别: 后者划定业务范围；本 skill 决定承载该业务的组织形态。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出新业务的成功所需能力**
   - 完成标准: 明确新业务要赢需要哪些资源、哪些流程、哪些优先级判断。

2. **逐层审计主流组织的 RPV**
   - 完成标准: 分别判断主流组织在资源/流程/价值观三层是否匹配，并列出不匹配的具体证据（如毛利率门槛、规模要求、协同 KPI）。
   - 判停条件: 若三层全部匹配，直接建议并入主流，可跳到步骤 5。

3. **用双阈值预测盲区**
   - 完成标准: 说明主流组织的毛利率门槛与规模阈值会如何让该新业务"视而不见"或被改造。

4. **按匹配矩阵选择结构**
   - 完成标准: 输出结构建议（并入主流 / 重量级团队 / 独立成本结构部门 / 自治组织），并说明自治的关键是流程自由+独立成本结构而非地理或股权分离。

5. **若涉及并购，判定买的是资源还是流程/价值观**
   - 完成标准: 给出"并入消化"或"保持独立并注入资源"的明确建议及依据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是个人选谁当新业务负责人——应使用经验学校类选人方法（本 skill 处理组织层，不处理个人履历匹配）。
- 用户只问高管要不要亲自出面——应使用 executive-engagement-rules。
- 用户在做纯法律/股权架构设计，不涉及流程与价值观匹配。

### 作者在书中警告的失败模式

- **在主流组织内孵化破坏性业务（被价值观同化）**（ce11）：破坏性项目沿用母公司毛利率与规模门槛，最终被抬价做延续性或被砍（Woolco 并入伍尔沃斯即关门）。
- **按"胜任者特征/履历光环"选新业务领导人**（ce12）：最受信赖、在核心业务一路成功的管理者反而最不适合新业务（Pandesic 即例）。
- **把破坏性业务放进主流组织评估**：耐普罗 Novaplast 的 6 家工厂试用，4 家 4 个月内退回，因为主流流程与价值观把它过滤成延续性技术。

### 作者的盲点 / 时代局限

- 案例集中于 2003 年前的美国上市大企业；"组织不能自我破坏"主要有个案支撑，对平台/生态型组织、扁平小团队、强监管企业的适用性未验证。
- 在数字原生企业或快速重组的文化中，"流程与价值观不可挪用"的刚性可能被削弱。
- 匹配矩阵给出的是否决式判据，正面设计自治组织的具体治理细节（考核、激励、资源分配）仍需自行摸索。
- 自治组织与主流组织的接口管理在实践中极易失败，书中着墨有限。

### 容易混淆的邻近方法论

- 钱德勒"结构追随战略"：宏观组织史；本 skill 给出可操作的 RPV 三层与匹配矩阵。
- 克里斯坦森《创新者的窘境》的"独立机构"主张：本 skill 明确了自治的关键在流程与价值观自由。
