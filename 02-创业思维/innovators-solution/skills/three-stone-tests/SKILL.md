# 三块试金石检验（破坏性机会的三关问句）

## R — 原文 (Reading)

> 第一组问题可以探测其是否能成为新市场破坏策略……第二组问题可以测知低端市场破坏策略……第三块试金石：这个创新策略是否能破坏业内所有的主要先入者？如果对其中一家或几家重要竞争对手来说，这个策略只是延续性创新，那么先入者就会占上风，而后来者则无胜算可言。
>
> — 克里斯坦森 & 雷纳，第2章《如何将业务构想塑造成破坏性策略：三块试金石》

---

## I — 方法论骨架 (Interpretation)

一个构想刚出现时既不带破坏性也不带延续性，它的性质取决于被塑造成什么。三块试金石就是把构想依次过三关的检验顺序。

第一关（新市场）：问两个问题——过去是否有一大群人因缺资金/设备/技术而"放弃或外包"这件事？客户是否必须跑到一个集中的、不方便的地点才能使用该产品或服务？两问至少一问为"是"。

第二关（低端）：问两个问题——低端客户是否乐意以更低价格买"性能不那么完美"的产品？我们能否设计出一种业务模式，在低毛利下靠低管理费用+高资产周转仍赚钱？两问皆为"是"才过。

第三关（对称动机）：这个策略是否对业内所有主要先入者都是破坏？只要对其中任何一家重要对手只是延续性创新，先入者就会反击而你有败无胜。

任一关不过就退回计划阶段"重新塑造构想"，而不是直接放弃——磨的是构想，不是判断力。低端破坏另配一道算术：ROCII＝毛利率×库存周转次数，"低毛利×高周转"同样能追平在位者的资本回报，低端破坏才真赚钱。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小型钢铁厂四级上攻（钢筋→条钢→结构钢→钢板）
- **问题**: 电弧炉小型钢厂能否进入钢铁业并持续成长？
- **方法论的使用**: 第一关：钢筋客户（建筑用螺纹钢）过去被大型综合钢厂以高价集中供应，小型钢厂以废钢炼钢获得约20%成本优势，7%毛利仍可切入——构成低端市场破坏；第二关：低毛利但高资产周转，ROCII 可追平大厂；第三关：对每一级产品，大型钢厂都因"低毛利形同鸡肋"而理性退让，符合对称动机关。
- **结论**: 这是标准的低端破坏，每一级都能过三关。
- **结果**: 小型钢厂逐级上攻至钢板，最终占北美钢产量一半，Nucor 市值超过美国钢铁，伯利恒钢铁破产。

### 案例 2: 施乐能否破坏惠普喷墨打印机 / 空调业 / 网上银行（书中三组对照推演）
- **问题**: 作者用同一套三关去检验三个构想，示范"过关"与"不过关"的分野。
- **方法论的使用**: 施乐若能做一种可随时接笔记本的廉价打印机，满足"笔记本用户移动打印"这一过去未被满足的任务→过新市场关，且对惠普属小市场形同鸡肋→过对称关；空调业日立若只做"更安静更节能"的新品，属于服务现有客户的高端性能改进→第一、二关皆不过，只能靠低劳动力成本短暂取胜；网上银行则既无"因缺资金技术而不开户"的人群，又不具备低端独立赢利模式，两关皆不过。
- **结论**: 三关给出的是分类与排序，不是"技术是否先进"。
- **结果**: 网上银行被判定只能作为在位者的延续性工具，无法成为破坏性新成长的基础。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创业者或大企业创新小组手上有一个具体的产品/业务构想，想知道它到底是破坏性机会还是延续性改良。
2. 投资人做尽调，需要一套可核对的问题清单把"声称破坏性"的标的与真正的破坏性区分开。
3. 已有成型业务，被要求做"新市场破坏 vs 低端破坏 vs 延续性"的分类，以决定资源与组织安排。
4. 团队为"能不能颠覆某个在位者"争论不休，需要一个排序化的检验关而不是各自举例子（第三关直接回答）。

### 语言信号 (用户的话里出现这些就应激活)

- "这个创意能不能做成破坏性业务？"
- "它是新市场破坏还是低端破坏？"
- "怎么判断这个方向值不值得下注？"
- "Is this a disruptive opportunity / How do I screen this idea?"
- "这里面哪一关过不了？"

### 与相邻 skill 的区分

- 与 `asymmetric-motivation-test` 的区别: 本 skill 是"三关整流程"（新市场→低端→对称动机）；对方只把第三关展开成"逐一扫描每个在位者是否都被破坏"的深度审计，当你已经确认前两关、只纠结"会不会被巨头反击"时用对方。
- 与 `new-market-disruption-pattern` 的区别: 本 skill 是"判定能不能成为破坏"，对方是"用四要素把已判定的新市场破坏塑造成可评审的业务计划"（含模式评审式预算）。
- 与 `nonconsumer-screening` 的区别: 本 skill 的第一关给出"是否面对零消费"的初步判断；对方专门甄别"零消费到底是有任务无方案还是无任务"，是更细的甄别工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认构想形态与目标客户群**
   - 完成标准: 用一句话写清"给谁、在什么场景、用什么产品/服务、替代掉什么现状"，且能对应到具体客群规模描述。

2. **过第一关：新市场两问**
   - 完成标准: 对"过去是否有人因缺资金/设备/技术而放弃或外包此事"与"客户是否须到集中不便处消费"分别给出是/否及证据。
   - 判停条件: 两问皆否 → 记录"新市场关不过"，进入步骤 4 前先按低端关检验；若低端关也不过则跳步骤 6。

3. **过第二关：低端两问**
   - 完成标准: 对"低端客户是否愿以低价买刚好够用的产品"与"能否设计低毛利仍赢利的业务模式"分别给出是/否；若两问为是，补算 ROCII＝毛利率×库存周转次数，验证能否追平在位者资本回报。
   - 判停条件: 两问非皆为是 → 该构想在低端关不成立。

4. **过第三关：对称动机关（粗筛版）**
   - 完成标准: 列出目标市场所有重要在位者，逐一初判"对它是破坏还是延续"，确认无一家仅被延续性冲击；若存在这样的在位者，标注为高危。
   - 判停条件: 需要对每个在位者做深入的动机与反应预测 → 移交 `asymmetric-motivation-test`。

5. **判定并回写构想**
   - 完成标准: 输出结论三选一（新市场破坏 / 低端破坏 / 延续性），注明过了哪几关、哪关不过、需要重塑的环节。

6. **不过关则重塑后重跑**
   - 完成标准: 至少给出一条"把构想重新定位到零消费/低端立足点"的具体改写，并重跑 2-4 步；确认"磨的是构想不是放弃机会"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 构想已明确是延续性性能改良（服务现有高端客户、比对手更好）——这不是"能不能过三关"的问题，而是三关本就不该套用。
- 单纯的技术先进性/研发难度评估——三关与技术水平无关，破坏性是相对在位者价值网络的概念，技术激进反而是常见误读。
- 把它当成个人职业选择或投资标的基本面判断工具——它只判断"作为破坏性业务是否成立"。

### 作者在书中警告的失败模式

- **把破坏性技术硬塞进主流市场（威胁-僵化）**：在位者出于本能把破坏性创新定义为威胁，全力保卫现有客户，把焦点放在保护客户基础上，结果既错失新市场又让破坏者壮大（ce02）。三关的第三关正是为提前识别这种反击风险。
- **逻辑明显却仍反向而行**：先入者明知零消费逻辑，仍选择在成熟市场与装备齐全的竞争者正面搏杀，投入巨额资金且常常失败（ch04）。

### 作者的盲点 / 时代局限

- 理论样本集中于 2003 年前的美国上市大企业，对平台/生态型组织、非上市耐心资本、扁平小团队的适用性未经验证。
- "几乎总是"类结论受案例选择影响；6%→37% 的成功率差来自有限样本，不应被当作精确概率。
- 需求线（是否过度服务）难以精确观测，三关的证据常依赖对客户情境的定性判断而非硬数据。
- 书中"施乐破坏惠普""日立进入空调"等前瞻推演未经时间检验，属示范性推演而非已验证事实。

### 容易混淆的邻近方法论

- 与"核心竞争力"话语：后者是静态属性分类，本 skill 是动态的情境检验；用"我们擅长什么"回答三关会答错。
- 与常规市场吸引力/ROI 评估：本 skill 刻意不先看市场规模数字，因为破坏性机会在萌芽期本就"看不清市场"。
