## 2. 类型判定与一句话主旨

**类型判定**：非虚构·商业方法论经典。框架定义清晰、概念体系自洽、每章即一个方法论模块，属于"理论框架 + 作者亲历案例 + 跨行业案例"三合一的方法论体系书，非纯故事书、非工具手册。

**一句话主旨**：新创企业（任何在极端不确定性下开发新产品/新服务的机构）的成功不靠天赋与运气，而可以通过一门可学习、可复制的"创业管理"科学来实现——用"开发—测量—认知"反馈循环、最小可行产品和创新核算，以经证实的认知取代虚荣指标，尽早判断转型还是坚持，从而杜绝"高效地做根本不该做的事"这一最大浪费。

## 3. 结构骨架（三篇 14 章与递进逻辑）

**第一篇 愿景（ch1-4）：确立学科地基 —— 创业需要管理，进展=学习**
- ch1 开端：创业管理。传统管理不适用于极端不确定环境；"想做就做"也不行；汽车驾驶 vs 火箭发射的隐喻；愿景—战略—产品三层结构。
- ch2 定义：谁才是创业企业家；新创企业定义（人组成的机构 + 极端不确定 + 开发新产品/新服务）；Intuit/SnapTax 与"七千人的精益创业"证明大企业同样适用。
- ch3 学习：经证实的认知（validated learning）。IMVU 的 IM 附加产品战略失败全过程；价值 vs 浪费的重新定义；"零的愚勇"。
- ch4 实验：把新创企业视为一揽子实验；价值假设与增长假设；Zappos、惠普志愿服务、柯达影廊、印度乡村洗衣 VLS、政府 CFPB 案例铺开"实验也是产品"。

**第二篇 驾驭（ch5-8）：循环的操作细节 —— 假设→MVP→核算→转型决策**
- ch5 飞跃：信念飞跃式假设（价值假设/增长假设）；类比与反证；现地现物（genchi gembutsu）与"走出办公大楼"；顾客典型；分析瘫痪症。
- ch6 测试：MVP。Dropbox 视频式 MVP、桌上美食贵宾式 MVP、Aardvark 绿野仙踪测试、IMVU 瞬间转移；质量观（"不知谁是顾客，就不知什么是质量"）；法律/竞争/品牌/士气四大减速路障。
- ch7 衡量：创新核算三步（定基准线→调引擎→转型或坚持）；同期群分析、对比测试、漏斗衡量；可执行指标 vs 虚荣指标（IMVU 每天五美元广告、Grockit 案例）。
- ch8 转型还是坚持：转型的定义与勇气；Votizen 四次转型全案例（放大式/客户细分/平台转型）；跑道=剩余转型次数；转型数量决定新创公司跑道。

**第三篇 加速（ch9-12）：规模化后仍保持循环速度 —— 精益生产工具的创业迁移**
- ch9 批量：小批量/单件流；装信封实验；IMVU 持续部署与"产品免疫系统"；大批量的死亡螺旋；拉动而非推动。
- ch10 成长：三种增长引擎——黏着式（流失率/复合率）、病毒式（病毒系数）、付费式（LTV vs CPA）；可持续增长规则（新顾客由以往顾客的行为带来）；产品/市场契合的量化重述；引擎停滞。
- ch11 适应：自适应组织；"五个为什么"根因分析与按比例投入；五大罪状陷阱；自动速度调节器；IGN 案例。
- ch12 创新：成熟企业内部创新——三种架构特征（稀少但稳定的资源/独立开发权/与绩效挂钩的个人利益）；创新沙盒；管理组合（四阶段业务）；"创业企业家"作为职业头衔；丰田主查制。

**收尾**
- ch13 尾声·杜绝浪费：泰罗《科学管理原理》百年对照——21 世纪的浪费是"把工作浪费在错误的东西上"；警惕精益创业自身的教条化与伪科学；提议新创企业实验室与长期股票交易中心（LTSE）。
- ch14 参与精益创业运动：资源指南（聚会、实践圈、必读书目：布兰克《顿悟的四步》、克里斯坦森、丰田系著作等）+ 致谢。

**递进逻辑**：为什么（愿景：创业=管理，进展=认知）→ 怎么做（驾驭：BML 循环四要素逐一展开）→ 怎么做大之后仍然做到（加速：批量/增长/组织/内部创新），最后以历史定位（泰罗线）与运动号召收束。

## 4. 核心概念与关键术语清单（以实际文本为准）

**定义级概念**
- 新创企业：由人组成的机构，在极端不确定情况下开发新产品或新服务（ch2，全书基石定义）
- 创业者无处不在 / 创业即管理 / 经证实的认知 / 开发—测量—认知 / 创新核算 —— **精益创业五项原则**（引言明确列出）

**方法论核心工具**
- 经证实的认知（Validated Learning，ch3）：以真实顾客实证数据为基础的进展单位
- 开发—测量—认知反馈循环（Build-Measure-Learn，ch5 篇首/第二篇总纲）：计划顺序与执行顺序相反
- 信念飞跃（Leap-of-faith）假设；**价值假设**与**增长假设**两大最重要假设（ch4/ch5）
- 最小可行产品 MVP（ch6）：视频式 MVP、贵宾式 MVP（concierge MVP）、绿野仙踪测试（Wizard of Oz）、冒烟测试
- 创新核算（Innovation Accounting，ch7）：三大认知阶段性目标——确定基准线→调整引擎→转型还是坚持
- 可执行指标 vs 虚荣指标（ch7）；同期群分析（cohort analysis）、对比测试、漏斗式衡量指标
- 转型（Pivot，ch8）：有条理的方向性改变；具体模式出现的有：放大式转型、客户细分市场转型、平台转型（另提及渠道转型等家族）；跑道=剩余转型次数

**第三篇工具**
- 小批量/单件流、持续部署、安灯拉绳、"产品免疫系统"、大批量的死亡螺旋（ch9）
- **三种增长引擎**：黏着式（流失率、复合率）、病毒式（病毒系数>1）、付费式（LTV/CPA、边际利润）（ch10）；可持续增长规则：新顾客由以往顾客的行动带来（口碑、衍生效应、有资金来源的广告、重复购买）
- 自适应组织、"五个为什么"、按比例投入、五大罪状、（ch11）
- 创新沙盒、管理组合（四阶段）、三种架构特征（ch12）

**支撑概念/术语**
- 顾客开发（Steve Blank）、现地现物（genchi gembutsu）、走出办公大楼、顾客典型、早期使用者 vs 主流顾客、类比与反证、认知阶段性目标（learning milestones）、增长引擎（engine of growth）、调整引擎、愿景—战略—产品层次、产品/市场契合（马克·安德森）、持续式创新 vs 颠覆式创新（克里斯坦森）、泰罗科学管理对照线、"零的愚勇"、"升平戏院"（伪新创企业）

## 5. 方法论形态判定

**判定：理论+案例体系型（强方法论）。** 理由与对后续阶段的要求：
- 概念均为作者原创定义且反复精确重述（如新创企业定义在 ch2/ch7 等处逐字再现），术语间有明确层级：五项原则 → BML 循环 → 各章工具 → 组织落地。
- 章节即方法论模块，章与章之间存在显式前向引用（"将在第七章说明虚荣指标""转型在第八章详述"），extractor 拼装时应保持章际引用关系。
- 案例服务论证而非独立成章：每个案例都绑定一个概念（Votizen↔转型、Dropbox↔MVP、Grockit↔虚荣指标、IMVU↔几乎全部概念）。
- **建议按五池提取**：① 心智/原则池（五项原则、泰罗线、质量观、创业即管理）；② 框架/流程池（BML 循环、创新核算三步、三个阶段性目标、五个为什么、创新沙盒规则）；③ 工具/技巧池（MVP 变体、同期群/对比测试、小批量、持续部署、增长引擎指标）；④ 判据/清单池（四大减速路障、三大架构特征、可持续增长四来源、柯达四问）；⑤ 案例/反例池（IMVU、Zappos、Groupon、Dropbox、Votizen、Intuit 等）。
- 触发条件/适用边界在文中多以"当……时"出现（如引擎停滞之时、进退维谷状态），适合规则化。

## 7. 目标读者与适用场景

**目标读者**（引言与各章明示）：
- 车库型创业者与早期创业团队（第一受众）；
- 大企业内部的创业企业家 / 负责新业务与创新部门的职业经理人（ch2"马克"、ch12 全章专门服务此群体）；
- 支持与考核创新者的高管、CFO、投资人、董事（创新核算与阶段性认知目标的问责对象）；
- 延伸读者：政府机构与非营利组织创新负责人（CFPB、惠普志愿服务案例），以及任何"在极端不确定性下开发新产品或新服务"的团队。

**适用场景**：新产品/新业务从 0 到 1 的假设验证阶段（找方向）、早期增长引擎选择与指标体系搭建、创业公司与成熟企业的转型/坚持决策、大企业内部创新机制设计（沙盒、组合管理）、以及把快速实验文化引入政府/教育/服务业等非软件行业。不适用场景（书中自限）：风险与不确定程度已知、仅靠执行即可推断成败的常规copycat型小生意（ch2 明确排除），以及已验证引擎下的纯优化运营阶段（作者称其收益来自持续式创新工具而非精益创业）。
