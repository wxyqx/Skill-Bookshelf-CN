# 反浪费纪律：识别新浪费，防止方法论教条化

## R — 原文 (Reading)

> "精益的思维方式把价值定义为'向顾客提供利益'，除此之外的任何东西都是浪费。……在这几个月中，我们所做的若和学习认知无关，便是一种浪费。有没有可能少花一点力气学到一样的东西？当然是有可能的。"
>
> —【作】埃里克·莱斯，第3章

> "这种浪费并非来自低效的工作组织，而是把工作浪费在错误的东西上，并且还是工业层面的大规模浪费。"
>
> —【作】埃里克·莱斯，第13章

> "没什么比高效地做一件根本不该做的事更加徒劳的了。"
>
> —【引】彼得·德鲁克（作者于第13章转引点题）

> "后来的每次管理革命都包含了泰罗的核心理念：即工作能用科学的方法进行研究，并能通过严格的实验手段得以提高。"
>
> —【作】埃里克·莱斯，第13章

> "作为一项运动，精益创业必须避免教条主义和僵化的思想体系。我们必须避免把科学描摹成公式的样子，或意味着在工作中缺乏人性。"
>
> —【作】埃里克·莱斯，第13章

## I — 方法论骨架 (Interpretation)

这个 skill 处理两个"元层面"的问题：**手头的事该不该做**（浪费判定），以及**用来判断事情的方法论本身是否已经僵化**（反教条自查）。它不教你某个环节怎么执行，而是站在所有执行工具之上。

1. **新创企业的浪费需要新定义**：精益生产把价值定义为"向顾客提供利益"，但新创企业里谁是顾客、什么有价值都是未知数，照搬工厂定义会失灵。于是需要一个新判据——**与新创企业学习认知无关的努力就是浪费**。
2. **21 世纪的新浪费是"做错事"而非"做得慢"**：泰罗时代针对的是体力劳动的低效；如今生产能力已远超"知道该造什么"的能力，大问题从"能不能制造出来"变成"应不应该制造出来"。当代最大的浪费是工业规模地、高效率地做错误的事——组织越高效，浪费越大。
3. **泰罗百年对照线**：泰罗 1911 年"体系置前"的思想造就了 20 世纪繁荣，却被庸俗化为时间动作研究、差别计件工资等有害技巧；精益生产重新发现工人智慧，把效率观从个人工作引向整个企业。每次管理革命都包含泰罗的核心理念——工作可用科学方法研究并经严格实验提高；精益创业是这一谱系在创新领域的延伸。
4. **但泰罗的下场是前车之鉴**："体系第一"很快被抛诸脑后，酿成僵化恶果——体系僵化到用不上人的适应力、创造力与智慧，过分强调计划、预防和过程，使组织只能在静态世界里出成果。精益创业运动不能落入同样的简化论窠臼。
5. **体系置前，不削弱传统创业精神**：管理创新是提高成功概率的系统化方式，但不能取代远见卓识、大胆冒险与直面问题的勇气；体系是放大器，不是替代品。
6. **警惕新伪科学**：不能让运动的成功催生围绕转型、MVP 等概念的新伪科学——挂着科学之名却机械压倒人性、把科学描摹成公式，实质是在做无法被数据推翻的事。科学恰恰是人类最有创造力的追求之一。
7. **"该不该做"的元判断优先于"怎么做"**：任何执行优化（更快地做、更便宜地做）都只对"值得做的事"才有意义；方向判断本身错误时，执行效率越高，沉没成本越大。

## A1 — 书中的应用 (Past Application)

### 案例 1: IMVU 的互通工程浪费反思（ch03，作者亲历）
- **问题**: IMVU 早期为让产品能在市面十几种 IM 网络上互通而开发了互操作性，投入巨大；事后作者反思：这个决定只是为了测试一个战略假设，却做得远超所需。
- **方法论的使用**: 用"学习无关即浪费"的新定义回看——覆盖更少网络也能得到相同的验证反馈；追问"有没有可能少花一点力气学到一样的东西？"答案是肯定的。
- **结论**: 错误战略假设造成的浪费本可避免；浪费的根源不是执行不力，而是没先问"这件事对验证假设有没有贡献"。
- **结果**: 这一反思成为"价值 vs 浪费新定义"的直接来源，写入本书第 3 章。

### 案例 2: 字母能源的"该不该做"裁决（ch09）
- **问题**: 清洁技术新创企业字母能源按原假设推进，概念到实物周期极长；目标电力公司以低风险承受度直接否决了原假设。
- **方法论的使用**: 团队没有抱着已投入的方案继续"高效执行"，而是停下来做"该不该做"的元判断——用 3 个月调查重新定位，承认原方向不该继续。
- **结论**: 及时承认"根本不该做"并止损，胜过在错误方向上继续提升效率。
- **结果**: 公司仅用约 100 万美元就完成了这次方向修正，避免了更大的沉没成本。

### 案例 3: 泰罗的钢铁切割实验（ch13，历史对照）
- **问题**: 20 世纪初的体力劳动全凭经验，无人用科学方法研究"工作本身该怎么干"。
- **方法论的使用**: 泰罗在伯利恒钢铁厂做了 25 年以上、2 万多个单独的实验来研究切割钢铁这门手艺——既无学术背景，又无政府的研发预算，靠严格实验把经验变成可检验的体系。
- **结论**: "工作能用科学的方法进行研究，并能通过严格的实验手段得以提高"——这是精益创业整个谱系的源头；作者同时以泰罗制后世僵化的教训自我警醒：科学方法不能被庸俗化为压人性的公式。
- **结果**: 科学管理奠定 20 世纪繁荣，但其两大后遗症（体系僵化、只能在静态世界出成果）正是本书要避免的方向。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 组织里人人忙碌、流程效率不错，但业务没有起色——怀疑大家在高效地做根本不该做的事，想做一次浪费审计。
2. 团队或外界质疑"你们这套精益/实验流程搞久了越来越像走形式、写报告交差"——需要判断方法论是否已教条化、伪科学化，并做纠正。
3. 面对一长串需求/项目排期，想判断"哪些根本不该做"——要的是"该不该"的元判断，而不是"怎么做得更快"的执行建议。

### 语言信号 (用户的话里出现这些就应激活)

- "浪费""新浪费""不该做的事""高效地做错事""工业规模的浪费"
- "该不该做这件事""这件事值不值得做""砍掉哪些工作""学习无关"
- "泰罗""科学管理""泰勒制""体系僵化""百年对照"
- "教条主义""走形式""新伪科学""方法僵化了""把方法用成了公式""传统创业精神"

### 与相邻 skill 的区分

- 与所有执行类 skill（2-12）的区别：它们回答"某个环节怎么做对做快"；本 skill 回答"这件事该不该做""方法本身是否僵化"——站在工具之上的元判断。用户问"怎么做"→转对应执行 skill；问"该不该/是否走样"→本 skill。
- 与 `innovation-accounting` 的区别：后者管"进展怎么证明"（核算框架与里程碑）；本 skill 管"做的事与学习无关即是浪费"的定性判断。问"怎么证明有进展"→后者；问"哪些工作根本白干"→本 skill。
- 与 `pivot-or-persevere` 的区别：后者是数据齐了之后的**方向裁决**（转型还是坚持）；本 skill 是裁决之前的浪费定性与方法论自查，两者常先后发生但问题不同。
- 与 `small-batch-acceleration` 的区别：后者解决"做得慢、反馈晚"（低效型浪费）；本 skill 解决"做错了事"（方向型浪费）——组织越快越要先过本 skill 的"该不该"关。
- 与 `lean-startup-five-principles` 的区别：后者是入门判断"该不该用精益创业这套体系"；本 skill 假设已在用，审的是"用得对不对、有没有用僵了"。

## E — 可执行步骤 (Execution)

1. **用"学习无关即浪费"给工作清单定性**：把团队近期在做的事逐项列出，为每项标注它服务于哪个待验证假设
   - 完成标准：每项工作都能写出一句话归属（"这项工作在验证假设 X"）；写不出的项标为浪费候选，并追问"有没有可能少花一点力气学到一样的东西？"
2. **区分"做得低效"与"做错事"**：对每个浪费候选，先问"这件事本身该不该做"，再问"做的方式是否高效"
   - 完成标准：清单二分为"方向性浪费（不该做）"与"执行性浪费（该做但做得低效）"；方向性浪费项直接进入砍掉/暂停决策，不许用"先优化流程"来回避。
3. **对照泰罗线做体系体检**：检查组织的实验/管理体系是否已出现泰罗制后遗症——规则僵化到用不上人的创造力、过分强调计划/预防/过程、只能在"静态世界"里运转
   - 完成标准：能对每条症状举出本组织的具体证据（或确认不存在）；至少回答一次"我们这套流程是为极端不确定设计的，还是照搬了为稳定运营设计的模板？"
4. **做方法论反教条自查**：检查精益实践是否退化——把原理当技巧合集抄、把科学描摹成公式、在数据图表上挑拣片段强加因果、拿"学习"当失败借口
   - 完成标准：列出本组织的 3 个"形式化信号"（如实验报告无人再看、转型/MVP 成了口号）；每个信号对应一条纠正措施（回到原理层重讲"为什么"）。
5. **重建平衡并收口**：砍掉方向性浪费项，纠正教条化做法，同时显式保留传统创业精神的分量——远见、冒险与直面问题的勇气不交给流程代管
   - 完成标准：一份带负责人和时限的审计决议（砍什么、改什么、保什么）；砍掉项的释放资源有明确去向（通常投入下一轮验证循环→ `bml-validated-learning`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是某个执行环节的具体做法（选 MVP 形态、搭指标、做根因分析、压缩批次……）——转介对应执行 skill；本 skill 只做元判断，给不出环节级操作。
- 用户问"进展怎么证明"——那是创新核算的问责框架问题，转 `innovation-accounting`。
- 组织处于已验证引擎下的纯优化运营阶段，效率问题主导——先转 `small-batch-acceleration` 等工具，本 skill 的"该不该做"审计只在方向不确定时才有杠杆。

### 作者在书中警告的失败模式（按家族速查）

- **e01 火箭式计划（F1）**："成功地执行一项无意义的计划是导致失败的致命原因"——计划执行得再完美，方向错误就是最大浪费。
- **e06 把"学习"当借口（F3）**："你无法把学习拿去银行"——与"学习无关即浪费"是同一枚硬币的两面：既不能做与学习无关的事，也不能把一切都记在"学习"账上。
- **e11 产品开发的伪科学（F4）**：在总指标图表上挑拣数据、突出己见、强加因果，"就是在做一件伪科学的事"——挂着实验名义的方法论退化，正是"新伪科学"的典型形态。
- **e22 泰罗制的两大后遗症（F11）**：业务体系僵化到无法利用人的适应力、创造力和智慧；过分强调计划、预防和过程，组织只能在几乎静态的世界里出成果——精益创业若被庸俗化将重蹈覆辙。
- **e23 三种古老"解决之道"（F11）**：归咎于项目天生高风险、主张放慢节奏少做做精、相信天生的大师——这些 19 世纪式方案拒不承认"创业失败是可研究、可管理的流程问题"，安慰人心但不减少失败。

### 作者的盲点 / 时代局限

- 第 13 章是全书收尾的历史反思与自我警醒，论述偏哲学与宣言性质：它给出了"学习无关即浪费"的判据，却没有给出可直接打分的审计量表——"该不该做"的最终裁决仍依赖使用者的判断，本 skill 的 E 段步骤是其操作化补充而非书中原装工具。
- "21 世纪的新浪费"是对生产能力过剩时代的宏观断言（2011 年成书），在产能约束、强监管或极端不确定的行业，"做错事"与"做得慢"的权重比例需要因地制宜，不能机械套用。
- 对泰罗的"平反"（理念被庸俗化而非理念本身之过）是一家之言，管理学界对科学管理的评价远为分化；使用百年对照作论证时应注明这是作者的谱系叙事。

### 容易混淆的邻近方法论

- **精益生产的七大浪费（大野耐一系）**：针对已知顾客、稳定运营的效率浪费（搬运、库存、等待等）；本 skill 的浪费定义专为"谁是顾客尚且未知"的新创企业重设——把工厂浪费清单直接套在创新业务上会漏掉"方向性浪费"这个最大的坑。
- **六西格玛/全面质量管理**：以减少波动和缺陷为目标，默认"做的东西是对的"；对极端不确定的新业务，先于"做对"的应该是"做的东西该不该存在"。
- **泰罗式科学管理（庸俗化形态：时间动作研究、差别计件工资）**：表面同源（都讲"用科学方法研究工作"），实质是把为静态执行世界设计的标准化工具压到创新工作上，正是本书警示的后遗症。
- **个人效率方法论（GTD、时间管理等）**：优化个人的任务执行顺序与专注度，但默认任务本身合理；"高效做不该做的事"在个人层面同样成立，需要先用本 skill 过"该不该"关。
