# BOOK_OVERVIEW —《小米创业思考》

- **书名**：小米创业思考
- **作者**：雷军 / 徐洁云（执笔）· 2022（中信出版集团）
- **类型**：创始人方法论自述（历程复盘 + 方法论体系 + 实践 + 生态 + 演进；附录含 IPO 公开信与四篇演讲）

## 一句话主旨

小米 12 年只做了一件事——用互联网方法改造制造业、推动效率革命：把"感动人心、价格厚道"从口号变成可计算的模型（ROI=利润率×周转）、可执行的纪律（七字诀）和可制度化的承诺（硬件净利率红线），方法论的价值超过公司本身。

## 一级论点骨架（5 条，递进关系）

1. **历程的教训**（第 1-4 章）：奇迹期的唯一原因是产品力与用户参与感；低谷的根源是能力不足而非环境（增长掩盖膨胀与失焦）；逆转靠"补课"（交付、创新、质量）而非新故事；制度化的价值观（净利润率写进董事会决议）才能超越创始人任期。
2. **互联网七字诀**（第 5-6 章）：互联网是观念不是技术；专注=把鸡蛋放一个篮子+核心业务一元化；极致=每个技术世代做到自身能力极限的最优解；口碑=超预期是唯一来源、是先于销量利润的第一指标；快=洞察/响应/决策/改善四能力，"战略积累快不得、战术演进慢不得"。
3. **效率是唯一主轴**（第 9-11 章）：爆品是模式与体系的结果而非营销结果（单款、精品、海量、长周期四特征）；效率公式 ROI=（毛利率–费用率）×周转次数打破"好产品必然贵"的不可能三角；新零售的本质是效率革命，货权归属决定厂商与渠道是合作还是博弈。
4. **生态与制造**（第 12-13 章）：生态链=投资+孵化+赋能（占股不控股、竹林效应），用别人的专注成就自己的生态；智能制造的破局点在扶持装备商（"制造的制造"），制造是手段不是目的。
5. **方法的演进**（第 14 章+后记）：世界上只有溢价与性价比两种公司模型；方法论从流量经营转向用户闭环经营（规模不经济陷阱）；终局思维决策法（造车：业务终局→行业终局→用户期待）；高端化=不做高溢价但做高用户价值。

## 关键术语（作者特定用法，全量见 GLOSSARY.md）

- **七字诀**：专注、极致、口碑、快——互联网思维的操作化表达，核心是效率与信任。
- **爆品**：单款、精品、海量、长周期——四项是结果指标而非原因；爆品靠体系打造不靠营销。
- **铁人三项**：硬件+新零售+互联网服务的复合模型；硬件贴成本获客、互联网服务赚"小费"。
- **性价比**：比较优势（同等性能价格最低）而非绝对低价；是商业修养不是竞争手段。
- **效率革命**：中国商业的问题是 90% 的运营/交易成本而非 10% 的生产成本；小米模式=创新+效率。
- **口碑**：超过用户预期才产生；是衡量产品与服务的终极标准、与业务形成正循环的第一要件。
- **生态链模式**：投资不控股+产品定义/设计/供应链/渠道赋能，"兄弟公司舰队"而非控股帝国。
- **终局思维**：决策的三层推论——对公司业务终局的影响→行业终局形态→根本检验依据是用户期待。
- **技术为本**：第一属性是科技公司；关键不是自产零组件而是对关键技术环节的把控力。
- **和用户交朋友**：互联网时代的群众路线；不是粉丝经济而是信任经营。

## 核心命题（重述，10 条）

1. 商业的第一性原理是效率，效率给最多的人带来最大幸福。
2. 核心业务必须一元化；资源有限时聚焦是最大竞争力。
3. 极致是"做到自己能力的极限"，最高境界是认知领先全行业；1% 的落后要用 100% 的努力换。
4. 只有超预期才有口碑；口碑领先于销量和利润，是正循环的第一要件。
5. 战略积累快不得，战术演进慢不得；快是核心素养不是目的。
6. 高性价比不是定价策略而是产品战略，必须有高效率的完整体系支撑。
7. 单款海量长周期把固定成本分摊到极低——研发分摊成本是效率指标而非投入指标。
8. 渠道赚不赚钱是 ROI 问题（周转次数×净利差）不是单品毛利率问题。
9. 把价值观写成法律文件（净利润率≤5%），才能保证价值观超越创始人任期。
10. 做新业务要用创业团队心态，规避认知错位、惯性思维、偶像包袱三大坑；每一次转行过去的知识与声望大部分清零。

## 批判（作者局限，直接作为 B 字段来源）

1. **幸存者叙事（全书性）**：作者自认的"成功者复盘"，方法论由自身与生态链成功案例归纳，"最优解""超预期"判定依赖事后结果；失败项目（盘古、澎湃芯片挫折、红米一代重做）多被整编为"认知升级"素材。
2. **立场预设**：效率是商业唯一目的、溢价模型是"不归路"、口碑永远对——均为价值宣示，对品牌溢价支撑创新、口碑失真（水军、信息茧房）的严肃反例处理不足。
3. **数据口径**：效率数据（效率高一倍、成本 1/3）均出自小米自述无第三方口径；"研发投入超科技巨头同期"对比口径模糊；附录为品牌传播文本，决策细节经叙事化修剪。
4. **时代与验证边界**：写于 2022，高端化、造车、小米之家万店均为进行时的未验证假设；铁人三项"地狱立方"的作者自认可复制性存疑；移动互联网窗口期红利（2010 换机潮+电商+社交媒体）被弱化。

## 应用潜力（skill 化评估）

**适合 skill 化**（本书最富矿：效率模型 / 爆品判定 / 口碑与用户关系 / 大额新业务决策）：
- 七字诀的操作化（专注的一元化检验、极致的最优解追求、口碑的超预期设计、快的四能力）
- 爆品模式判定与打造（四特征、三条件、80/80 取舍）
- 效率公式 ROI 算账（毛利-费用率×周转；定价五分项；渠道 ROI vs 单品毛利率）
- 价值观制度化（承诺写进治理文件的设计）
- 低谷补课与逆转（先补能力再谈故事）
- 货权归属与厂商-渠道关系设计
- 生态链投资模式（占股不控股+赋能清单）
- 终局思维三层推论（大额新业务决策）
- 新业务三大坑（认知错位、惯性思维、偶像包袱）
- 技术投入的路径选择（比决心更致命的是路径；"志存高远，不好高骛远"）

**不适合 skill 化**：创业史叙事、演讲文本的励志内容——作 example 原料。

**预估 skill 数量**：12-16 个。
**优先级排序**：效率模型与 ROI 算账 > 爆品判定 > 口碑与用户信任 > 七字诀决策规则 > 生态链与赋能 > 终局决策。
