# GLOSSARY —《小米创业思考》共享术语词典

> 本词典整理自候选术语池（candidates/glossary.md，20 条）。本书大量术语与日常用法存在系统性偏差（如"性价比≠低价""风口上的猪≠投机"），下游 skill 调用前应先以本词典校准语义；各 SKILL.md 的 R/E/B 环节引用术语时，以本词典的定义为准。

---

### 七字诀

- **本书语境定义**：互联网思维的最高概括——专注、极致、口碑、快。四字之间有因果链：资源有限→专注→极致→打动用户形成口碑→快速响应改善；核心表达是效率，落脚点是信任。
- **与常识用法的差异**：≠"互联网公司才适用的行业口号" / =既有商业准则（边际成本递减、免费、注意力经济）在新技术条件下的极致放大，是一套可操作化的决策规则集，适用于一切行业。
- **为什么下游 skill 需要它**：七字诀是几乎所有下游 skill 的主轴；不澄清"观念非技术、四字有因果链"，各 skill 会把四字当成并列口号而失去推理结构。

### 爆品

- **本书语境定义**：产品力超群、一流口碑、海量长销。可观察特征为"单款、精品、海量、长周期"四项，且四项是"体检指标"（结果）而非原因；爆品靠完整模式和体系打造，不靠营销。
- **与常识用法的差异**：≠出货量大、性价比高、技术领先、标王式营销热卖（四个认知误区） / =单款海量长周期+全面优秀外加至少一方面杰出的体系结果。
- **为什么下游 skill 需要它**：爆品判定 skill 的核心判据；效率模型、生态链、新零售 skill 均引用"四特征是结果非原因"这一澄清，否则会误把销量当目标反推打法。

### 铁人三项

- **本书语境定义**：硬件+新零售+互联网服务的复合商业模式。以用户为核心形成闭环飞轮：硬件贴近成本定价获客，互联网服务赚"小费"提供利润，本质是互联网效率对三个环节的贯通。
- **与常识用法的差异**：≠"三块业务并列经营" / =以用户为中心的交叉补贴闭环模型，硬件是获客载体、服务是利润来源，缺一环即不成立。
- **为什么下游 skill 需要它**：效率模型、定价、生态链、造车决策等多处 skill 引用；须澄清"飞轮闭环"属性，避免下游把小米误读为多元化集团。

### 性价比

- **本书语境定义**：同等性能价格最低的比较优势，而非绝对低价；"便宜"须有理由。性价比不是定价策略而是产品战略与商业修养，必须有高效率的完整体系支撑才能成立。
- **与常识用法的差异**：≠便宜、低价、性价比=偷工减料 / =比较优势（性能/价格比在同档显著领先），是能力与修养问题而非竞争手段。
- **为什么下游 skill 需要它**：澄清"小米=低价"是全书最高频误读；定价、高端化、爆品 skill 都依赖"比较优势+体系支撑"双重限定。

### 效率革命

- **本书语境定义**：中国商业的普遍问题不是生产成本（仅约 10%），而是运营/交易成本（约 90%，定倍率高达 5-20 倍）；效率革命即砍中间环节与定倍率，而非压榨供应商。小米模式="创新+效率"的加强型性价比模型。
- **与常识用法的差异**：≠降本增效、压低成本 / =向 90% 的交易成本开刀的结构性改造，"好东西越做越便宜"是伟大公司的共性。
- **为什么下游 skill 需要它**：全书第一性原理（效率给最多人带来最大幸福）的载体；ROI 算账、新零售、行业诊断 skill 均以此为总纲，须区分"10% vs 90%"的诊断对象。

### 口碑

- **本书语境定义**：只有超过用户预期的产品/服务才产生口碑（预期是相对值，须对同业可比档位保持显著比较优势）；口碑是衡量产品与服务的终极标准，领先于销量和利润，是与业务形成正循环的第一要件；口碑=产品+服务+沟通全触点的总和（全栈口碑）。
- **与常识用法的差异**：≠好产品自动有口碑、≠营销出来的好评 / =超预期的结果，且是"第一指标"而非销量利润的滞后结果。
- **为什么下游 skill 需要它**：口碑与用户信任 skill 的核心；"超预期是唯一来源"与"全触点总和"两个澄清直接决定下游 skill 的诊断与设计规则。

### 生态链模式

- **本书语境定义**：用"投资+孵化"（占股不控股）把小米模式复制到 100 个行业：小米输出产品定义、设计、供应链、渠道赋能，创业者保持独立，"用别人的专注成就自己的生态"，是"兄弟公司舰队"而非控股帝国。
- **与常识用法的差异**：≠控股收购、财务投资、代工贴牌 / =占股不控股+全方位赋能的共生结构（竹林效应），双方各取所长。
- **为什么下游 skill 需要它**：生态链与赋能 skill 的基座；"占股不控股+赋能清单"是可迁移的治理设计，不澄清会被误读为普通战略投资。

### 终局思维

- **本书语境定义**：大额新业务决策法，三层推论：①该业务对公司业务终局的影响；②行业终局形态的判断；③决策的根本检验依据是用户期待。造车即由此推论：手机存量竞争、汽车消费电子化终局前五名拿 80% 份额、用户期待"敢造必买"。
- **与常识用法的差异**：≠长期规划、≠"风口跟风" / =从终局形态倒推当下必答性（why now）的结构化决策程序，根本检验锚在用户期待。
- **为什么下游 skill 需要它**：大额新业务决策 skill 的核心框架；须强调"用户期待是根本检验依据"这一层，否则会退化为普通行业分析。

### 技术为本

- **本书语境定义**：小米第一属性是科技公司，安身立命之本必须是技术。关键不是拿来主义拼贴供应商方案，而是吃透、主导关键技术环节；是否自产零组件并非关键，对关键技术环节的把控力才是关键。
- **与常识用法的差异**：≠自研一切、自产零组件 / =对技术方向、设计方案、关键细节的主导权与把控力（可联合定制、可借上游）。
- **为什么下游 skill 需要它**：技术投入路径 skill 与三大铁律推导链（技术为本→工程师文化→极致产品→爆品→性价比模型→用户信任）的起点；防止把"技术为本"误读为全栈自研。

### 和用户交朋友

- **本书语境定义**：互联网时代的群众路线。用户天然不信任商家但信任朋友，故把商业关系重构为朋友关系：明码实价、只赚"小费"式合理利润、不坑人；检验标准是"敢不敢让用户知道你赚了多少钱"。不是粉丝经济，而是信任经营。
- **与常识用法的差异**：≠粉丝经济、流量经营、营销话术 / =群众路线式的信任经营，动作（社区、参与感）可复制，长期一致的诚意不可速成。
- **为什么下游 skill 需要它**：用户关系、口碑、新媒体运营类 skill 共用的价值基座；"朋友≠粉丝"的区分决定下游 skill 是做转化设计还是信任设计。

### 定倍率

- **本书语境定义**：零售价/成本的倍数。行业参考值：服装 10-20 倍、鞋 5-10 倍、化妆品 20-50 倍。定倍率衡量一个行业的效率损耗空间，定倍率异常高的行业即是效率革命的机会区。
- **与常识用法的差异**：≠毛利率、≠加价率（财务口径） / =行业级效率诊断工具（零售价/成本），用于定位"中间环节损耗"。
- **为什么下游 skill 需要它**：行业诊断与 ROI 算账 skill 的入口工具；给出具体参考倍数，可作为下游 skill 的量化判据。

### 分摊成本

- **本书语境定义**：商品定价由五项分摊成本+利润构成，关键在"分摊"而非绝对值。爆品的单款海量长周期把固定成本分摊到极低，量大则边际成本近乎免费；研发分摊成本是效率指标而非投入指标。
- **与常识用法的差异**：≠绝对成本、≠研发投入总额 / =固定成本被销量摊薄后的单位成本，"量大则边际成本近乎免费"。
- **为什么下游 skill 需要它**：反驳"小米低价=没研发投入"的关键澄清；定价、爆品、创业后发制人（不被巨头投入规模吓倒）类 skill 都依赖此区分。

### 货权归属

- **本书语境定义**：看零售链条中货是谁的：货权在厂商手中，厂商与渠道商才是合作而非博弈关系，才能做到交易即数据、实时管理、高周转低容错；货权层层转移（压货模式）必然沦为博弈，以牺牲用户利益和累积系统风险为代价。2018 年线下扩张失败主因之一即货权外放。
- **与常识用法的差异**：≠渠道管理技巧、加盟政策 / =判定厂商-渠道关系本质（合作 vs 博弈）的第一变量，是数据、周转、管控的制度前提。
- **为什么下游 skill 需要它**：新零售与渠道设计 skill 的核心判据；"先看货权"是一个可迁移的单一诊断动作，下游 skill 必引。

### 竹林效应

- **本书语境定义**：生态链企业的生长类比竹林：以投资为纽带输出方法论+全方位赋能（产品定义、设计、供应链、渠道），让每个团队专注在一件事上，用并行的小团队而非单一大组织实现最快业务布局；单根竹子生命周期有限，竹林则生生不息、快速蔓延。
- **与常识用法的差异**：≠集团多元化、内部事业部 / =投资纽带+独立团队+方法论复制的生态生长方式，与"占股不控股"配套。
- **为什么下游 skill 需要它**：生态链 skill 解释"为何不自己做"的组织逻辑；与生态链模式术语配套，避免下游把生态链误读为品类扩张。

### 小费模式

- **本书语境定义**：互联网商业是"厚予薄取"：像开市客以低毛利+会员费盈利一样，先建立服务信任，再赚取用户愿意支付的"小费"式合理利润；硬件贴成本获客、互联网服务提供利润即此逻辑。
- **与常识用法的差异**：≠免费模式、≠羊毛出在羊身上的隐形收费 / =先予后取、明示的合理利润，与"和用户交朋友"（敢让用户知道赚多少）互为表里。
- **为什么下游 skill 需要它**：商业模式与用户信任 skill 引用；澄清"小费=主动克制的利润"而非隐蔽收费，是信任叙事成立的前提。

### 参与感

- **本书语境定义**：把用户变成"10 万人规模的开发团队"：100 个梦想赞助商、用户投票决定功能优先级、爆米花奖与猪头奖的即时奖惩、内测/开发/稳定三版分级；新媒体时代全员（合伙人到工程师）硬性规定直面用户，参与感带来归属感，先有倾听与参与才有"自来水"式口碑。
- **与常识用法的差异**：≠用户运营活动、社群营销 / =让用户进入产品创造过程的机制设计，是口碑与信任的杠杆源头。
- **为什么下游 skill 需要它**：冷启动、社区运营、口碑类 skill 的机制库；须澄清其"生产机制"属性而非"营销手段"，否则下游会做成活动策划。

### 风口上的猪

- **本书语境定义**：被普遍误读的作者原话。本意是放低姿态、顺势而为、苦练基本功——风口只属于有准备且有能力的企业；猪的比喻重心在"把握时机需要积累的能力"，而非"运气+投机"。
- **与常识用法的差异**：≠投机跟风、躺赢运气 / =顺势而为的前提是苦练基本功，"风来了猪能飞"是自嘲式的谦辞而非方法论。
- **为什么下游 skill 需要它**：全书最高频被断章取义的词；机会判断、顺势而为类 skill 必须先纠正本义，否则会输出与作者本意相反的投机建议。

### 不可能三角

- **本书语境定义**：产品感动人心、价格极其厚道、公司有合理盈利——传统认为三者只能取二；小米模式的解是复合模型而非单点取舍，核心公式为投资回报率=（毛利率–费用率）×年周转次数，靠硬件+新零售+互联网交叉补贴打破。
- **与常识用法的差异**：≠"三选二"的死局 / =用复合商业模式+周转效率打破的伪三角，解在模式设计而非单点妥协。
- **为什么下游 skill 需要它**：效率公式与定价 skill 的理论支点；"ROI 公式是三角的解"这一联结是下游算账 skill 的推理核心。

### 溢价模型 / 性价比模型

- **本书语境定义**：世界上只有两种公司模型。溢价模型依赖信息不透明与超额利润，高溢价必然导致高成本低效率，作者判定为"不归路"；性价比模型克制贪婪、艰难但一旦领先极具韧性和穿越周期能力（沃尔玛、开市客、优衣库、宜家）。小米是"创新+效率"的加强型性价比模型，性价比还是创新的加速器。
- **与常识用法的差异**：≠按行业/产品分类 / =按"利润来源"对公司做二分：靠信息不透明+超额利润 vs 靠效率+克制贪婪；高端化=不做高溢价但做高用户价值。
- **为什么下游 skill 需要它**：公司模型判断框架是下游多个 skill 的元框架；"高端化≠溢价"的区分直接支撑小米高端化战略 skill 的立论。

### 三大铁律

- **本书语境定义**：2020 年 8 月十周年半年大反思的产出：技术为本、性价比为纲、做最酷的产品。回答"企业靠什么活、走什么路、靠什么赢"三个根本问题，铁律"永不更改"；配套三大策略（重新创业、互联网+制造、行稳致远）则随势而变。推导链：技术为本→工程师文化→极致产品→爆品→性价比模型→用户信任。
- **与常识用法的差异**：≠价值观口号 / =从"企业生存之问"推导出的不变约束，与"随势而变的策略"构成两层制度设计。
- **为什么下游 skill 需要它**：价值观制度化 skill 的范本（铁律 vs 策略的分层）；推导链同时是七字诀、性价比、技术为本等术语的结构性索引。
