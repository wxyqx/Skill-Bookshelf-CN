- id: f01
  title: 效率公式 ROI 算账（毛利率–费用率×周转次数）
  type: framework
  source_chapter: 第十章 高效率模型
  source_quote: "投资回报率=年利润/年投资额=利润率×年收入/年投资额=利润率×年周转次数=（毛利率–费用率）×年周转次数"
  summary: |
    把盈利判断从"单品毛利率"改写为"（毛利率–费用率）×年周转次数"的组合优化。
    用法：评估任何定价、渠道或商业模式时，先拆出毛利率与费用率之差，再乘年周转次数算真实 ROI；
    低毛利若伴随低费用率和高周转，回报可以远超高毛利低周转模式。
    适用：零售/渠道谈判（反驳"卖 X 不赚钱"话术）、定价决策、库存与资金流速管理。
  tags: [效率, ROI, 定价, 财务模型]

- id: f02
  title: 定倍率诊断法（识别效率革命机会区）
  type: framework
  source_chapter: 第十章 高效率模型
  source_quote: "定倍率=零售价/成本，比如100元成本的东西卖500元，定倍率就是5。通常而言，服装行业的定倍率是10~20，鞋子是5~10倍，化妆品行业是20~50。"
  summary: |
    用"零售价/成本"的定倍率给一个行业做体检：定倍率异常高，说明中间环节损耗大、效率空间大。
    用法：进入一个行业前先测其定倍率水平并与同类行业基准比较；高定倍率行业=效率改造的机会区，
    同时也是"不合理溢价粉碎机"的靶点。配套追问：溢价来自制造商贪婪还是流通环节损耗？
  tags: [效率, 行业分析, 定价, 机会识别]

- id: f03
  title: 定价五分项分解法
  type: framework
  source_chapter: 第十章 高效率模型
  source_quote: "任何商品的定价都是由五部分组成的：•制造和服务分摊成本。•研发分摊成本。•市场推广及广告分摊成本。•销售及渠道分摊成本。•利润。"
  summary: |
    把任何商品价格拆成制造服务/研发/市场推广/销售渠道四项分摊成本加利润。
    用法：分析定价争议或"便宜=没研发"之类质疑时，先拆五分项再逐项对标；
    优化方向是压缩分摊（尤其渠道与推广）而非砍绝对投入。注意各项都是"分摊"而非绝对值。
  tags: [定价, 成本结构, 效率]

- id: f04
  title: 分摊成本判据（研发分摊是效率指标而非投入指标）
  type: framework
  source_chapter: 第十章 高效率模型
  source_quote: "事实上，分摊体现的是利用效率，抛开效率谈绝对投入毫无意义。举个简单的例子，一款手机的研发成本是固定的，但是卖出10万台、100万台和1000万台，研发分摊成本的差距就大多了。"
  summary: |
    评估创新力看"分摊效率"（固定投入/销量）而非投入绝对值。
    用法：判断一家公司/一款产品是否"真有研发投入"时，用研发总额除以预期销量；
    创业方用它对冲"巨头投入规模吓人"的叙事——量大则边际成本近乎免费，高效创新可后发制人。
    反向约束：上重大固定投入前必须先验证销量假设。
  tags: [成本结构, 研发, 规模效应]

  type: framework

  title: 爆品打造四要素流程
  type: framework
  source_chapter: 第九章 爆品模式
  source_quote: "总结下来，我认为需要做好以下四个方面：•找准用户需求。•超预期的产品。•惊喜的定价。•效率制胜。"

  type: framework
  source_chapter: 第六章 互联网七字诀·专注
  source_quote: "第一，一个明确而且用户迫切需要的产品，更容易找到明确的用户群。这样，产品研发出来后不容易走偏。……第四，解决明确问题的产品，容易跟用户说清楚，推广也会相对简单。"

- id: f12

  type: framework
  source_chapter: 第六章 互联网七字诀·专注
  source_quote: "对于每一项业务，我们要反复问自己三个问题：1.我的业务增长为公司核心战略贡献了什么样的价值？2.我的业务增长是否带动了公司包括核心业务在内的其他业务持续连带增长？3.我的业务消耗了公司哪些资源？"

    （虚胖、GMV 陷阱），列入收缩或重构候选。与 OKR 对表机制配套使用。

- id: f13
  title: 一元核心律（把"+"改成"×"）
  type: framework
  source_chapter: 第六章 互联网七字诀·专注
  source_quote: "把加号改成乘号，是首先突出核心业务，同时强调不再是“简单相加”，而是乘数效应。所以，公司的核心业务和核心方向、核心目标一定是一元的，不存在二元甚至多元的可能。"
  summary: |

    独立增长指标而失焦，应改为主从乘数结构（A×B）：明确谁是核心，其他业务以放大核心为职责
    （"手机+AIoT"改"手机×AIoT"的纠偏即此）。
    用法：审视战略表述里的连接词——并列加号是失焦信号，改写为乘数结构并定义主从。
  tags: [专注, 战略结构, 失焦纠偏]

- id: f14
  title: 最优解极致方法论（更简化或更集成）
  type: framework
  source_chapter: 第六章 互联网七字诀·极致
  source_quote: "我们发现，最优解本身往往并不在于性能指标（按照摩尔定律，性能指标总是会不断提升的），而是源自基于用户需求的更简化或者更集成的实现方法。"
  summary: |
    极致的操作定义：每个技术世代、每品类、每需求都存在一个"最优解"=当下的最大化用户价值；
    最优解不在性能参数，而在基于用户需求的"更简化"（如 MIUI 3 步发短信）或"更集成"
    （如百变主题）的实现。
    用法：①做产品时问"这个交互/方案的最优解是什么，现有人做到哪一步"；②寻找尚无公认
    最优解的领域=最大机会；③一次性做对，避免"来回拉抽屉"。
  tags: [极致, 产品方法, 最优解]

  type: framework

  source_quote: "•我们追求的极致是不是用户真正需要的？•我们追求的极致是不是能成为产品/服务的核心竞争力？•我们追求的极致是不是能形成长期可持续的竞争壁垒？"

    宝石/哥窑瓷机身）；三问全过才是真极致，不过则是噱头或溢出浪费。
  tags: [极致, 决策刹车, 反自嗨]

- id: f16
  title: 超预期口碑设计（口碑=全触点总和）
  type: framework
  source_chapter: 第六章 互联网七字诀·口碑
  source_quote: "好产品不一定能带来口碑，便宜的产品不一定能带来口碑，又好又便宜的产品也不一定能带来口碑，只有超过预期的产品才能带来口碑。……一家公司与用户所有触点的表现总和，才是口碑。"
  summary: |
    口碑的唯一来源是超预期（预期是相对值：绝对体验向最高标准看齐、相对同业可比档位保持
    显著比较优势）；且口碑不只在产品——产品+服务+沟通所有触点表现的总和才是口碑。
    用法：①设计体验时先标定用户预期基准，再找超预期点；②全触点排查：定价、包装、客服、
    发票、售后任何短板都会拉垮整体口碑；③口碑领先于销量利润，是正循环第一要件。
  tags: [口碑, 超预期, 用户体验]

  source_quote: "经过反复讨论，我们总结出了大公司做新业务的三个大坑：认知错位、惯性思维、偶像包袱。"
