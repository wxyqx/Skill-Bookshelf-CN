# 效率算账（ROI 公式与定价分解）

## R — 原文 (Reading)

> 投资回报率=年利润/年投资额=利润率×年收入/年投资额=利润率×年周转次数=（毛利率–费用率）×年周转次数……而充分考虑到这一点，就不会囿于性价比模型带来的单件产品的低利润率疑虑，从而让“感动人心的产品、厚道定价和企业合理利润”的三角架构更加稳固。
>
> — 雷军，《小米创业思考》第十章 高效率模型

---

## I — 方法论骨架 (Interpretation)

这门方法论把"赚不赚钱"的判断，从门外汉直觉的"单品毛利高=赚钱"，改写成一个可计算的复合公式：**ROI =（毛利率–费用率）×年周转次数**。毛利只是原料，扣除费用率后剩下的净利差才是每一周转真正赚到的部分，再乘以一年资金/货品跑几圈，才是真实回报。

四个配套工具：

1. **定倍率体检**：用"零售价÷成本"给一个行业做体检。定倍率异常高（远超同类行业基准）说明中间环节损耗大，恰恰是效率改造的机会区，而非"高毛利好行业"。压缩方向是砍交易损耗，不是压生产投入或压榨供应商。
2. **定价五分项**：任何商品价格 = 制造服务分摊 + 研发分摊 + 市场推广分摊 + 销售渠道分摊 + 利润。应对"便宜=没研发"类争议或自查定价健康度时，逐项拆解对标；优化方向是压分摊（尤其渠道与推广），不是砍绝对投入。
3. **分摊成本判据**：评估创新力看"研发总额÷预期销量"的分摊效率，不看投入绝对值。量大则单位固定成本近乎免费——这是后发者不被巨头投入规模吓倒的算账依据；反向约束是上重大固定投入前必须先验证销量假设。
4. **提回报的优先杠杆**：压费用率、提周转，而非提毛利。单品低毛利在高周转+低费用率下完全可能跑出高 ROI。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小米之家的渠道算账——年周转 17 次、ROI 30%
- **问题**: 渠道商普遍抱怨"卖小米不赚钱"，用单品毛利率视角看小米产品利薄。
- **方法论的使用**: 小米用 ROI 公式反驳单品毛利率话术：小米之家是一层零售结构，中间环节费用率约 10%（传统模式 23%~33%），配合爆品组合把年周转拉到 17 次，（毛利率–费用率）×周转的总账远超传统渠道。
- **结论**: 渠道赚不赚钱是 ROI 问题，不是单品毛利率问题；厂商持有货权、实时数据化是高周转的前提。
- **结果**: 2021 年小米之家模式年周转 17 次、投资回报率 30%，中国区门店破万家完成县域覆盖。

### 案例 2: 分摊账支撑"接近成本定价"（爆品+电商+新媒体）
- **问题**: 硬件要贴成本定价，研发、制造、营销的钱从哪来？
- **方法论的使用**: 拆五分项逐项压缩分摊：爆品单款海量把研发制造成本摊到极低；新媒体营销+爆品自带流量把推广分摊压到接近零；电商直销砍掉渠道分摊；自我约束硬件净利率≤5%。
- **结论**: "看起来是三件事，其实是一件事，本质都是效率"——低毛利与高回报由分摊和周转同时供给。
- **结果**: 小米模式形成"感动人心、价格厚道"仍能健康盈利的正循环。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 渠道/经销商谈判中对方说"你这款毛利太低，我卖你的货不赚钱"，需要算总账反驳或重设合作结构。
2. 评估一个新品定价、一次降价/提价决策，或回应"你卖这么便宜肯定没研发投入"的质疑。
3. 考察是否进入某个行业做性价比改造（如发现某行业零售价是成本的十倍以上），判断是否是效率机会区。
4. 面对巨头"年研发投入 X 百亿"的叙事，判断自己该不该恐慌、如何用分摊逻辑对冲。
5. 库存、资金流速管理：周转慢了想诊断该压费用还是调结构。

### 语言信号 (用户的话里出现这些就应激活)

- "毛利率/费用率/周转率/资金效率"（gross margin, expense ratio, turnover, capital efficiency）
- "单品不赚钱/卖得多才赚钱/薄利多销划算吗"
- "定倍率、加价率、中间环节、渠道层级"
- "研发投入到底多少、分摊、量大成本摊薄"
- "定价怎么拆、便宜是不是等于没研发"

### 与相邻 skill 的区分

- 与 `impossible-triangle-model` 的区别：本 skill 是**算账工具**（有公式有数字）；对方问的是"感动人心/厚道/盈利如何兼得"这类**模式设计题**（互斥目标的结构解）时用后者；两者常连用——先设计复合模式，再用本 skill 验证 ROI。
- 与 `new-retail-efficiency` 的区别：本 skill 只算费用率×周转的总账；涉及"货是谁的、压货博弈、渠道关系怎么设计"等产权与关系结构问题交给后者。
- 与 `cost-performance-philosophy` 的区别：对方在争论"性价比是不是低价内卷、该不该做性价比"的**理念/战略立场**时用后者；本 skill 只负责把立场兑现成数字。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先问清四个输入数**
   - 毛利率、费用率（或可估算的中间环节费用率）、年周转次数、销量/预期销量。
   - 完成标准：四个数要么来自用户提供，要么给出行业合理估计区间并明确标注为估计。

2. **套 ROI 公式算总账，并与对比方案并列**
   - ROI=（毛利率–费用率）×年周转次数，对"现状 vs 备选方案"各算一行。
   - 完成标准：输出对比表，指出哪一行 ROI 更高、差距来自毛利/费用/周转哪个因子。
   - 判停条件：若用户问题只是定价沟通（如回应"没研发"质疑），跳到步骤 4。

3. **给出提回报的杠杆排序**
   - 优先评估"压费用率、提周转"两杠杆，最后才考虑动毛利/价格；每个杠杆给出量级估算。
   - 完成标准：至少给出 2 个可执行杠杆及其对 ROI 的影响估算。

4. **需要时启用子工具：定倍率体检 / 五分项拆解 / 分摊判据**
   - 定倍率：零售价÷成本，与同类行业基准（服装 10–20 倍、鞋 5–10 倍、化妆品 20–50 倍量级）比较，高则提示机会区并追问溢价来自制造还是流通。
   - 五分项：把价格拆成制造服务/研发/推广/渠道四项分摊+利润，逐项对标找畸高项。
   - 分摊判据：研发总额÷销量与对手同口径比较，评估单位研发密度。
   - 完成标准：明确说出用了哪个子工具、得出什么结论、对决策的影响。

5. **校验反向约束**
   - 凡结论依赖"量大摊薄"，必须检查销量假设是否已验证；未验证的固定投入要提示风险。
   - 完成标准：结论末尾附一条"该账成立的前提"，注明哪些数字是估计值。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是纯会计/报表/税务处理——本 skill 是经营决策工具，不是财务合规工具。
- 用户尚未确定要不要做性价比路线、在争"该不该走低价路线"的战略立场——先用 `cost-performance-philosophy` 澄清立场，否则算账没有前提。
- 问题核心是渠道关系与货权设计（"要不要给渠道账期/退换货"）——交给 `new-retail-efficiency`，货权结构变了本公式的费用率与周转输入才成立。

### 作者在书中警告的失败模式

- **"单品毛利率"误导**：忽视费用率与周转次数两个因素，渠道商会拿单品利薄压价，厂商会被诱导提毛利而错失效率杠杆（第十一章原话："'单品毛利率'误导最大的问题就在于忽视了费用率和周转次数这两个重要因素"）。
- **绝对低价内卷**：没有技术创新与效率体系的低价是"制造业的低效内卷"，厂商与消费者双输——低价必须由本 skill 的分摊与周转账支撑，而非减配。
- **把"拧毛巾"当唯一手段**：过度压缩内部费用（如研发）伤害长期产品力；优先做模式优化（砍中间环节），压缩空间有限的项目慎压。

### 作者的盲点 / 时代局限

- **幸存者叙事**：ROI=30%、周转 17 次等账目由成功后的小米自述，失败时点的账（如 2016 危机前）较少以同口径呈现。
- **数据口径出自小米自述**：费用率、周转、效率对比（"效率高一倍、成本 1/3"）均无第三方审计口径，套用书中的具体倍数时应作为示例而非行业事实。
- **性价比立场的价值宣示色彩**："溢价模型是不归路"是作者立场，毛利驱动的生意（奢侈品、品牌溢价支撑研发创新）在书中的反例处理不足，不要把本公式当成对所有行业的一票否决。
- **进行时假设**：书中账目多基于 2018–2022 高周转红利期（电商渗透、爆品周期），环境变化后周转假设需重估。

### 容易混淆的邻近方法论

- 传统财务的"投资回报率"：本公式的关键增量是把费用率从毛利率中显式拆出、并乘周转次数，用于反驳单品毛利直觉，不是财务教科书 ROI。
- 波特的低成本战略：本书强调压缩的是交易/流通成本（约 90%），不是生产成本（约 10%）——降本对象不同。
