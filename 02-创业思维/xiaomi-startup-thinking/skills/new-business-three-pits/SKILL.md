# 大公司新业务三大坑自检：认知错位、惯性思维、偶像包袱

## R — 原文 (Reading)

> 认知错位就是错误地预估了行业复杂度和自己的能力。……很多成绩实际上是由所在平台长期积累而成……认知错误最大的危险之处，就是会导致对新领域缺乏足够的敬畏之心，陷于不知己也不知彼的危险境地。
>
> — 雷军，第十四章 小米方法论的演进思考（造车复盘）

---

## I — 方法论骨架 (Interpretation)

作者复盘造车决策与历次转行经验，把成熟组织做新业务最常掉进去的坑归纳为递进的三类：

1. **认知错位**：把平台的成就误认为团队自身的能力——过去赢了，常常是母公司的品牌、渠道、资金在起作用；进入新行业时高估自己、低估行业复杂度，缺乏敬畏。
2. **惯性思维**：把旧行业的经验、姿态、流程照搬过来——大预算铺张、甲方姿态找供应商、层层汇报的决策节奏，在新行业里全部失灵甚至有毒。
3. **偶像包袱**：放不下身段向新行业的头部玩家学习，加上"第一款产品就要全面颠覆"的速胜论叙事压力。

配套对策是一组"创业团队心态"机制：转行即清零——预设过去的知识、经验、声望大部分失效；大胆设想、小心求证；保持对生存的恐惧（用创业公司的资源约束纪律约束自己）；先做好产品再谈颠覆；给团队设定明确的清零期与学习对象。

## A1 — 书中的应用 (Past Application)

### 案例 1: 造车项目启动前的三大坑自检
- **问题**: 小米决定造车后，作为手机行业的成功者进入汽车业，最容易重蹈大公司新业务的覆辙。
- **方法论的使用**: 在项目组织上主动规避三坑——以全资子公司+创业团队心态运作而非事业部级孵化；先做充分调研与拜访（85 场业内拜访、200 多位资深人士）承认行业复杂度（反认知错位）；不预设"第一款车颠覆行业"，以做好产品为先（反偶像包袱）；雷军亲自带队押上声誉，保持生存压力（反惯性思维的组织保障）。
- **结论**: 三大坑可以被制度化规避，但需要一把手亲自下场而非口头强调。
- **结果**: 造车项目以 10 年 100 亿美元的资源确定性启动（进行时，成效书中未验证）。

### 案例 2: 澎湃芯片——低估难度与路径一步登天
- **问题**: 2014 年组建松果公司造芯，热情与投入决心不缺。
- **方法论的使用**: 事后复盘正是三大坑的技术版——对芯片业务理解不够深刻、错误估计了业务难度（认知错位），不到 20 人的团队直攻最高难度的手机 SoC（惯性思维：沿用"先干再说"的互联网节奏预期硬件研发），后期转向 ISP/充电芯片等易成败的细分品类以战养战（补敬畏、补路径）。
- **结论**: 路径选择错误比决心缺失更致命；新领域须从难度阶梯的低阶开始积累。
- **结果**: S1 之后陷入僵局、松果改组；2021 年起澎湃 C1/P1 等细分芯片在高端机量产交付。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 大厂/成熟公司团队内部孵化新业务（机器人、硬件、出海），立项会需要风险自检清单。
2. 管理层从成熟行业跳到陌生行业（传统企业做互联网、互联网公司做制造），需要评估组织姿态是否失当。
3. 新业务首发产品背负"必须颠覆行业/一鸣惊人"的叙事压力，需要评估该目标是否为速胜论。
4. 收购或整合跨行业团队，原班人马带着旧经验与新声望进入，需要设计清零机制。

### 语言信号 (用户的话里出现这些就应激活)

- "大公司做新业务 / 大厂病 / corporate innovation pitfalls"
- "我们有钱有人有品牌，还怕做不成 X 吗"
- "跨行 / 进入陌生行业该注意什么 / 清零"
- "第一款产品就必须颠覆行业，这个要求合理吗"

### 与相邻 skill 的区分

- 与 `endgame-reasoning` 的区别: endgame 论证"要不要进入"（三层终局推论），本 skill 处理"决定进入之后"的心态与打法自检。问"该不该做"归 endgame，问"进去后会踩什么坑"归本 skill。
- 与 `sunk-cost-restart` 的区别: restart 是损失已发生后的止损判定；本 skill 是事前预防。澎湃案例归属按主诉：问"当年哪里错了"归本 skill（认知错位复盘），问"烧了 10 亿该不该继续"归 restart。
- 与 `minority-stake-empowerment` 的区别: minority-stake 是用投资+孵化借外部团队做新领域（不自己下场）；本 skill 是自己下场时的心态纪律。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **认知错位自检**
   - 逐项追问: 过去的成绩里，哪些是平台给的（品牌、渠道、资金、流量）？新行业的复杂度我们评估过几层？有没有敬畏的证据（调研量、请教过谁）？
   - 完成标准: 产出"平台依赖清单"与"行业复杂度评估"，二者分离；没有平台光环的裸能力被明确标出。

2. **惯性思维自检**
   - 把母公司的预算模式、决策流程、供应商姿态、招聘打法逐条过筛：哪些在新行业失效甚至有毒？
   - 完成标准: 至少列出需清零的惯性项（如大预算铺张、甲方姿态）及替代做法；预算与人员配置与验证阶段匹配而非与母公司惯性匹配。

3. **偶像包袱自检**
   - 检查: 是否公开表示过对新行业头部玩家"不屑学习"？首发产品是否背负"全面颠覆"叙事？
   - 完成标准: 有明确的学习对象与对标清单；首发目标改为"先做好产品"的单点目标，颠覆叙事被书面降级。

4. **对策落地**
   - 建立创业团队心态的机制：预设清零期（知识与声望归零的时长）、保持对生存的恐惧（资源约束纪律）、大胆设想小心求证的节奏。
   - 完成标准: 对策清单有责任人与检查时点。
   - 判停条件: 若三坑全中且团队无纠正意愿（以"我们有钱有人"回应所有质疑），建议缓启动或换团队，再进入执行。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 初创公司的第一次创业——三大坑针对"带着成功包袱的成熟组织"，初创公司的风险主要是资源不足而非包袱，套用会错焦。
- "要不要进入该业务"的论证本身——归 endgame-reasoning；本 skill 假定进入已决定。
- 外部投资/孵化别人的团队做新领域——归 minority-stake-empowerment（帮忙不添乱），不是自己下场的心态问题。

### 作者在书中警告的失败模式

- **认知错位**（第十四章原文）: 错误预估行业复杂度与自身能力，"不知己也不知彼"。
- **路径一步登天**（澎湃芯片）: 新技术业务首个目标直接对标行业最难项，以激情合理化团队规模与目标难度的数量级差距。
- **速胜论叙事**: 首发产品被"必须全面颠覆"绑架，为叙事牺牲产品节奏与务实目标。

### 作者的盲点 / 时代局限

- **归纳自成功者复盘**: 三大坑是在造车（进行时）与澎湃挫折（被整编为认知升级素材）的复盘上建立的，失败组织未能自检出三坑的案例不可见——清单的判别力未经失败样本检验。
- **小米自身未必免疫**: 生态链 1.0 后期 SKU 过冗、2018 年线下无序扩张说明同一组织在同一书内也反复踩坑，方法不是一次掌握终身有效。
- **造车对策未经充分验证**: "创业团队心态+一把手带队"能否在汽车业成立是 2022 年的进行时假设；且该对策高度依赖雷军个人的声誉与亲力，普通组织缺此资源。

### 容易混淆的邻近方法论

- 创新者窘境（克里斯坦森）: 都谈在位者做新业务之难；本书归因于心态三坑（可自检可规避），而非价值网络与低端颠覆的结构性困局——归因层次不同，不宜混用结论。
- 空降高管失败学: 相近的"清零"建议，但本 skill 的对象是组织级新业务而非个人职业转换。
