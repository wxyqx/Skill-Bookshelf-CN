# 新零售效率三件套：货权归属、渠道 ROI、试点养店纪律

## R — 原文 (Reading)

> 这并非只是一个理论模型，2021年，中国区的小米之家模式已经能够做到年周转17次，投资回报率能达到30%，这是非常可观的数字。这就是我们一再强调厂商持有货品、全面实时数据化的原因。
>
> — 雷军，第十一章 新零售

---

## I — 方法论骨架 (Interpretation)

本 skill 把第十一章新零售的方法浓缩为三个可操作组件：

1. **货权归属判定**：评估任何分销/零售体系，第一个问题不是扣点和覆盖率，而是"货是谁的"。货权留在厂商→渠道与厂商是合伙人关系，交易即数据、可实时管理、高周转低容错；货权层层转移给渠道→必然滑向压货博弈（渠道赚返点、厂商失真数据），且以牺牲用户利益（层层加价）和累积系统风险为代价。货权外放必须有系统级强管控配套，否则失控。
2. **渠道 ROI 算账**：把"出厂价→用户价"的差价拆成中间环节费用率结构做层级对比（传统多层省包地包 30%~33%、全国省代 23%~26%、一层零售约 10%），再结合周转次数算渠道真实回报——渠道赚不赚钱是（毛利率−费用率）×周转的 ROI 问题，不是单品毛利率问题；层级越少费用率越低，费用率差距本身就是定价空间与护城河。
3. **试点养店纪律**：新模式可以低成本快速试错（选址不必完美、先跑起来），但"试错"与"复制"是两个独立阶段——放量前必须验证清单全绿：单店模型跑通、管控手段（尤其货权与系统支撑）到位、有人对区域总体结果负责。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小米之家——货权在厂+一层零售的 ROI 正循环
- **问题**: 渠道商普遍抱怨"卖小米不赚钱"，传统渠道模式下小米线下阵地薄弱。
- **方法论的使用**: 用 ROI 公式反驳单品毛利率话术：小米之家一层零售结构费用率约 10%（传统省包地包 30%~33%、全国省代 23%~26%），货权留在厂商使渠道从压货博弈变为共同运营，2021 年做到年周转 17 次、投资回报率 30%；面对习惯 17%~23% 利润空间的渠道商，靠算总账（低费用率×高周转）而非提高单件毛利说服。
- **结论**: 货权归属+费用率结构共同决定渠道关系与回报。
- **结果**: 2021 年中国区门店破 10000 家、完成县域覆盖（进行时数据，出自小米自述）。

### 案例 2: 安阳模式教训——验证不充分即复制的四重叠加错误
- **问题**: 2017 年"河南大会战"以安阳为中心下沉拓店成绩亮眼，打法被总结为"安阳模式"后全国铺开。
- **方法论的使用**: 事后用三件套逐项对照——试点验证不充分就急于复制（违反纪律三）；货权全部外放给不具备系统管控能力的渠道商（违反组件一）；鼓动无零售经验的米粉开"小米小店"且无系统支撑；小米之家、区域分公司、运营商渠道各自为战，无人对区域总体结果负责。对照：同期印度 PPP 模式（网格独家+严格输出政策）成功。
- **结论**: 试点成功≠模式成立；复制速度超过管控系统建设速度时，扩张本身制造失控。
- **结果**: 2018 年线下无序扩张失败，成为小米渠道最大弯路；2020 年重启变革，14 种渠道归并为 3 种、货权收回小米。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 渠道谈判：区域连锁/KA 卖场要求"账期+无条件退换货+高扣点"换入驻，需要判断接受后货权与关系性质的变化。
2. 渠道冲突诊断：渠道商抱怨"卖你的货不赚钱"、靠返点补贴而非动销盈利，需要用费用率结构+周转算总账回应。
3. 扩张决策：单店/试点爆火（排队、网红效应），资本或管理层催铺开，需要放行清单判断能不能复制。
4. 渠道体系设计/改造：设计分销层级、自建 vs 加盟、货权集中还是外放的政策选择。

### 语言信号 (用户的话里出现这些就应激活)

- "货权 / 压货 / 退换货 / 账期 / 库存是谁的"
- "渠道不赚钱 / 扣点太高 / 中间环节"
- "要不要放开加盟 / 直营还是加盟 / channel partner"
- "试点店火了，能不能快速复制扩张"

### 与相邻 skill 的区分

- 与 `efficiency-accounting` 的区别: efficiency-accounting 是通用 ROI 公式（（毛利率−费用率）×周转）与定价五分项的推导和任何场景的代入；本 skill 是渠道场景的三件套（货权判定、层级费用率结构、试点纪律）。用户问"公式怎么用"或纯定价毛利问题归 efficiency-accounting，问渠道体系怎么设计/渠道该不该答应归本 skill。
- 与 `minority-stake-empowerment` 的区别: minority-stake 是对生态链公司"投资不控股"的股权赋能结构；本 skill 的对象是零售/分销渠道的交易与货权关系，不涉股权。
- 与 `impossible-triangle-model` 的区别: impossible-triangle 处理"感动人心+厚道定价+合理盈利"的复合模式设计；本 skill 是其在渠道环节的具体执行工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画货权流转图**
   - 从厂商到最终用户，逐环节标注货物所有权归属、库存风险承担方、数据可见性。
   - 完成标准: 货权在每一环节的归属清晰；识别出货权转移的次数与位置。

2. **画层级-费用率结构图并算渠道 ROI**
   - 把出厂价→用户价的差价拆到各环节的费用率，与基准对比（一层零售约 10% 量级）；对各渠道方案分别计算（毛利率−费用率）×年周转次数。
   - 完成标准: 每个候选渠道有费用率结构与 ROI 数字；"卖 X 不赚钱"类主张被换算成总账检验。

3. **关系判定与对策**
   - 按货权图判定关系性质：货权在厂商=合伙人（共同运营、数据共享）；层层转移=博弈（压货-返点-加价）。
   - 完成标准: 明确选择——货权留厂（自建/合营/强系统授权）或外放+系统级强管控清单；若外放但给不出管控手段，判定为不可行并回退。
   - 判停条件: 若货权必须外放且当前无系统与数据管控能力→不铺开，回到试点阶段补管控。

4. **扩张前验证清单**
   - 对试点到复制的放量决策核对三项：单店模型跑通（模式指标）、管控手段与系统支撑到位（风控机制）、有且只有一方对区域总体结果负责（组织能力）。
   - 完成标准: 三项全绿方可放量；任一项缺失则列出缺口与补齐计划，扩张暂缓。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 与渠道无关的定价、毛利、研发分摊问题——归 efficiency-accounting / cost-performance-philosophy。
- 单店运营细节（选址动线、陈列、店员培训的具体操作）——本 skill 管体系结构与放行纪律，不管单店运营手册。
- 电商投放与流量采买的 ROI 优化——那是线上获客问题，非渠道货权与层级问题。

### 作者在书中警告的失败模式

- **压货博弈模式**（传统渠道通病）: 货权层层转移后渠道靠返点盈利、厂商看到的是库存转移而非动销，延迟失真的操盘在市场波动时连环爆仓。
- **安阳四重叠加错误**: 试点未验证即复制+货权外放无管控+志愿者承担专业职能+多团队各自为战，2018 年线下无序扩张失败。
- **渠道单一依赖**: 纯电商时期忽视线下（电商仅占行业零售约 30%），增长天花板与侧翼失守同来。

### 作者的盲点 / 时代局限

- **数据出自小米自述无第三方口径**: 周转 17 次、费用率 10%、ROI 30%、门店破万等关键数字均为小米一方表述，无独立审计或行业对照；引用时须注明口径。
- **进行时假设**: 小米之家万店与县域覆盖成效写于 2022 年，模型长期健康度未经周期（尤其下行周期）检验。
- **货权集中模式的复制门槛被弱化**: 厂商持货要求极强的资金实力、库存周转能力与数字化系统，书中把模式先进性归因于理念，对小玩家无法复制该模式的结构性约束着墨不足。

### 容易混淆的邻近方法论

- 传统渠道管理（扣点、返利、 coverage）: 谈的是博弈参数；本 skill 先判关系性质（货权）再谈参数，顺序不可反。
- DTC（直面消费者）模式论: DTC 是本框架下"层级最少、货权归厂商"的一个特例，但本 skill 同样覆盖授权/合营等中间形态，不等同于"一律直营"。
