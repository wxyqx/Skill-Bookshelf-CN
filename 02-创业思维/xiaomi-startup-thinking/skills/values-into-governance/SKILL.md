# 价值观制度化——把承诺写进法律文件并预留风险缓冲

## R — 原文 (Reading)

> 2018年4月25日，小米上市前夕，小米董事会通过了一条决议：小米硬件综合净利润率永远不会超过5%，如有超出部分，将以合理方式全部返还给用户。
>
> — 雷军/徐洁云，《小米创业思考》第三章 重回增长

---

## I — 方法论骨架 (Interpretation)

一个价值观（比如"克制利润贪婪"）如果只靠创始人自律维持，就必须先问一个检验问题："如果有一天我不做 CEO 了，它还能不能坚持？"答案只有一条路：写进董事会决议等治理文件，而不是官网声明或演讲口号，并配套公开披露，让财报和公众成为监督者——约束才有法律效力与外部压力。

设计约束条款时必须预留经营风险缓冲：作者原想定 3% 红线，考虑到国际化公司汇率稍有波动就可能亏损，放宽到 5%。没有弹性的完美红线，反而会被真实经营环境击穿，届时失信的代价远大于当初留出的弹性。

方法论要点：①确认该承诺有真实取舍（放弃什么）；②选对制度载体（治理文件＞公关口径）；③引入外部监督；④留弹性缓冲并论证弹性来源；⑤准备好向利益受损方（如投资人）销售这套价值观的说服方案。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 上市前夕董事会决议——硬件综合净利润率永不超 5%
- **问题**: 上市使小米成为公众公司，面临资本对超额利润的要求，与"价格厚道"的使命直接冲突。
- **方法论的使用**: 把使命固化为法律文件——董事会决议写明红线与超出部分返还用户；原想定 3%，考虑国际化汇率波动放宽到 5%；刻意选在上市前划定，正是为了上市后接受财报公众监督。
- **结论**: 约束必须制度化+公开化+留缓冲，三件套缺一不可。
- **结果**: 投资人最初炸锅（"还想不想上市"），多轮紧急电话会几近谈崩，最终以"优秀的公司赚取利润，伟大的公司赢得人心"说服全体投资人；成为史上第一家以法律文件约束硬件综合净利润率的上市公司，2018-2021 连续 4 年财报披露低于 5%，手机均价与利润反而双双提升。

### 案例 2: 三大铁律与三大策略的分层设计（2020 年十周年反思）
- **问题**: 价值观如何区分"永不更改"与"随势而变"，避免口号化。
- **方法论的使用**: 从"企业靠什么活、走什么路、靠什么赢"三问推导出技术为本、性价比为纲、做最酷的产品三大铁律（不变约束层），与随势而变的三大策略（重新创业、互联网+制造、行稳致远）明确分层。
- **结论**: 制度化不仅是写下来，还要在文件结构上区分不变层与可变层。
- **结果**: 铁律"永不更改"成为组织级约束，策略层保持演进弹性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创始人想把某条价值观固化（如"不接氪金游戏业务""不做某些数据生意""公益捐赠不低于 X%"），担心自己卸任或公司易主后被推翻。
2. 公司筹备融资或上市，团队争论"初心会不会被资本逼着变形"，讨论要不要提前用治理文件锁定承诺。
3. 企业在"写一份公开承诺声明"与"写一条董事会决议"之间犹豫，或已在设计红线条款、讨论要不要留弹性空间。

### 语言信号 (用户的话里出现这些就应激活)

- "把承诺写进公司章程/董事会决议，不靠创始人自觉"
- "价值观怎么制度化、怎么落地，防止后任推翻"（institutionalize / governance）
- "利润红线/业务禁令要不要留弹性，投资人会不会反对"

### 与相邻 skill 的区分

- 与 `endgame-reasoning` 的区别: 那是回答"该不该做某个大额新业务"的终局推论决策法；本 skill 处理的是已确立的价值观如何固化为治理约束，不涉及新业务取舍。
- 与 `one-core-business` 的区别: 那是核心业务聚焦的战略结构问题；本 skill 是治理文件与监督机制设计，对象是承诺而非业务组合。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **检验价值观的真实取舍**
   - 完成标准: 明确写出这条承诺放弃什么（多少利润、哪些机会），说不出取舍的不值得制度化。

2. **选定制度载体**
   - 完成标准: 确定载体层级（董事会决议/公司章程/对外合同）与具体条款文本，拒绝仅停留在官网声明或讲话稿。
   - 判停条件: 若用户只想做内部文化宣导、无真实约束意图，则停止并说明本 skill 不适用。

3. **配套公开披露与外部监督**
   - 完成标准: 明确披露渠道（财报/年报/公告）、披露频率与违反后果（如超出部分返还方案）。

4. **预留风险缓冲**
   - 完成标准: 给出弹性区间及其论证——列出最可能击穿红线的环境变量（汇率、周期、监管），并说明缓冲宽度如何覆盖。

5. **准备向利益相关方销售价值观**
   - 完成标准: 针对最大反对者（通常是投资人）备好异议应答，包含长期信任收益的逻辑（参照"优秀的公司赚取利润，伟大的公司赢得人心"）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 日常企业文化活动、团建口号、雇主品牌文案——无真实取舍，写进法律文件只会制造空头支票。
- 法律法规已强制要求的合规事项——那是义务不是价值观，不需要"制度化"动作。
- 具体某个业务做不做的战略评估——先走决策类 skill，结论出来后才谈约束固化。

### 作者在书中警告的失败模式

- 只发声明不进文件：价值观停留在公关口径，上市后资本压力一到即被击穿（书中投资人最初反应"还想不想上市"即此张力）。
- 红线不留弹性：作者原定 3%，意识到国际化汇率波动就可能致亏才放宽到 5%——刚性约束反被环境击穿。

### 作者的盲点 / 时代局限

- 幸存者叙事：5% 决议作为成功故事呈现，对"承诺反而束缚转型/被竞对利用"的反面场景无讨论。
- 价值宣示色彩：该承诺同时承担 IPO 传播功能，附录为品牌传播文本，决策细节经叙事化修剪，实际谈判过程（几近谈崩）仅有单方口径。
- 进行时假设：承诺的长期有效性（跨周期、跨创始人任期）截至 2022 年尚未经充分验证。

### 容易混淆的邻近方法论

- 终局思维决策法（endgame-reasoning）：管"做不做新业务"，本 skill 管"承诺怎么固化"。
- 一元核心律（one-core-business）：管业务结构聚焦，本 skill 管治理约束设计。
