# GLOSSARY — 共享术语词典

> 由 `candidates/glossary.md`（22 条，全部经词频与原文核实）整理提升而来。所有 skill 一律按布朗 & 基利的用法使用这些术语；下游引用"结论""论证""价值观假设"等词时取此义而非通用义。
> 来源标注为中文章节。完整提取记录见 [candidates/glossary.md](./candidates/glossary.md)。

## 核心词典

| # | 术语 | 书内定义（布朗 & 基利） | 与常识的差异 | 关联 skill |
|---|---|---|---|---|
| g01 | 批判性思维 | 三要素：一套环环相扣关键问题的意识 + 恰如其分提出并回答这些问题的能力 + 积极主动利用它们的强烈愿望。 | ≠ 批评/挑刺——目的是找出最佳决断；意愿与能力并列，缺一不可。 | 全部 22 个（总纲词） |
| g02 | 关键问题 | "通往合理结论的道路往往从问题开始，并且一路都有问题相伴"——那张固定顺序的审查清单的专称。 | ≠ "重要的问题"——专有名词，特指论题→结论→……→备选结论的有序清单。 | `critical-question-master-list`、`pan-for-gold-reading` |
| g03 | 海绵式思维 | 如海绵吸水般逐字逐句吸收记忆，记住作者说了什么但不评价。 | ≠ 贬义的死读书——是必要起点（淘金盘里得先有东西）；唯一致命缺点是无法取舍。 | `pan-for-gold-reading` |
| g04 | 淘金式思维 | 带着既定问题清单积极主动地与材料互动，在页边批注、随时准备辩驳，找出最佳判断。 | ≠ 爱抬杠——目标是最佳判断而非驳倒对方；与海绵式互补而非对立。 | `pan-for-gold-reading` |
| g05 | 弱势/强势批判性思维 | 弱势：用批判技巧捍卫已有立场；强势：用同一套问题评估一切主张，尤其是自己的。 | 常识以为"会批判=会驳倒别人"；强势的检验问句是"我有没有可能是错的呢？"。 | `strong-sense-self-audit`（并作为全部审查 skill 的 B 段依据） |
| g06 | 价值观 | 人们认为有价值而没有明说的抽象观念，充当衡量行为品质的行为准则。 | ≠ 具体喜好；≠ 个人独有——"价值观本质上是所有人共有的"，差异只在冲突时给谁的优先级高。 | `value-assumption-mining`、`critical-thinker-values` |
| g07 | 一厢情愿（似是而非） | 喜欢自己希望为真的，回避已证明为真的；"希望什么是真的，干脆就宣布它是真的"。 | ≠ 乐观——是让事实迎合愿望的认知姿态；变体有奇迹式思考。作者称之为批判性思维的最大劲敌。 | `wishful-feeling-check` |
| g08 | 论题（描述性/规定性） | 引起对话或讨论的争议问题；描述性问"是什么"，规定性问"该不该、对错好坏"。 | ≠ 一般话题——必须能定位成争议问题；类型决定后续全部评价方式。 | `locate-issue-conclusion` |
| g09 | 结论 | 作者或演说者希望你接受的信息，由分析推理逐步得出；无证据支撑的只是"纯观点"。 | ≠ 任意观点；≠ 数据、例句、背景——这些不可能作结论。操作抓手：指示词+首尾位置+"所以呢？"。 | `locate-issue-conclusion` |
| g10 | 理由 | 用来支撑或证明结论的看法、证据、隐喻、类比等陈述；"理由是模具，结论据此成型"。 | ≠ 结论的翻版（"因为我就是这样认为的"不算）；"薄弱的理由必然导致薄弱的推论"。 | `identify-reasons` |
| g11 | 论证 | 结论与支持它的理由之间的结合；论证=推理，是有目的、质量有高低之分的机制。 | ≠ 争吵抬杠——缺理由的交流既非论证也非推理，无从谈逻辑错误。 | 全部审查类 skill 的作用对象 |
| g12 | 歧义 | 一个词在论证上下文里让人捉摸不透、需进一步解释才能判断推理是否恰当。 | ≠ 查字典式一词多义——判据是"换义替换后理由支撑结论的效度是否改变"；谁说服谁负责澄清。 | `ambiguity-loaded-words` |
| g13 | 附加感情色彩的词语 | 激发强烈情感反应的术语，"暂时让思维短路，绕过描述性的意义通道"。 | ≠ 夸张修辞——机制是直接接通情绪线路（死亡税vs遗产税）；识别动作：问它想让我产生什么感情。 | `ambiguity-loaded-words`、`fallacy-three-questions` |
| g14 | 价值观假设 | 特定情形下没有明说的、宁要一种价值观超过另一种的偏向。 | ≠ 罗列价值取向清单——人人共享同一批价值观，钥匙只在冲突时宁要哪个；且随情境改变。 | `value-assumption-mining` |
| g15 | 描述性假设 | 对世界过去/现在/未来"是什么样"的未言明信念；含定义性假设（想当然认定多义术语取某一义）。 | ≠ 价值观假设（"应该是什么样"）；≠ 把理由换个说法贴"假设"标签——要找的是连接理由与结论鸿沟的隐形纽带。 | `descriptive-assumption-mining` |
| g16 | 谬误 | 推理中的欺骗手段；三种花招：依赖错误假设、无关信息分散注意力、循环论证。 | ≠ 背名称清单——作者明言不必识记名称，给的是三问判别法；名称只是事后交流的标签。 | `fallacy-three-questions` |
| g17 | 事实断言 | 对世界曾是什么样/现在是什么样/将来是什么样的看法，可出现在结论、理由或假设中。 | ≠ 已核实的事实——第一问"我为什么要相信它？"；无证据的叫孤立论断。 | `evidence-grade-triage` |
| g18 | 证据（八类效力分级） | 持论者告知的、用来证实事实断言可靠性的明确信息；"证据的质量主要取决于证据的类型"。 | ≠ 有没有证据的二元判断——直觉/个人经历/典型案例/证词偏弱，研究较强但仍"只能支撑不能证明"，没有一样证据能一锤定音。 | `evidence-grade-triage`、`expert-opinion-audit`、`research-survey-audit`、`analogy-evaluation` |
| g19 | 替代原因 | 对同一结果言之成理的替代解释；相关至少有四种解释，"在这之后"不等于"因为这个"。 | ≠ 罗列多种因素——特指针对同一因果断言的竞争性解释；替代原因越多，原断言确定性越低。 | `rival-causes-audit` |
| g20 | 统计数据 | 用数字表达的证据；"统计数据能，而且经常会，撒谎！" | ≠ 数字即客观——来历、平均值三种、数据-结论错位、百分比/绝对数互换、相对/绝对风险五个检查点。 | `deceptive-data-check` |
| g21 | 重要的省略信息 | 将影响你该不该被论证说服的信息；"不完整的推理在所难免"。 | ≠ 信息不全就拒绝判断——省略有五种原因，第一优先追问"潜在的长期负面效果是什么？"。 | `omitted-info-probe` |
| g22 | 二分式思维 | 把可能存在多种答案的问题假设成只有两个答案；"过度限制我们的视野而破坏了推理的进程"。 | ≠ 谨慎的利弊权衡——解药是条件句（何时/何地/为何目的精确）与问题重述；护栏是"不是所有结论都生来平等"。 | `alternative-conclusions` |
