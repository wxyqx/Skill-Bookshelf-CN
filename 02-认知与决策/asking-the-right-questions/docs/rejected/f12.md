# rejected/f12 — 反串法（换立场检测）

## 候选原文

- **id**: f12
- **title**: 反串法（换立场检测）
- **type**: reasoning-method
- **source_chapter**: 第4-5章
- **内容摘要**: 站到对方（或反方）视角重新推演论证——第4章用它找歧义（反方会怎么定义这个词），第5章用它挖假设（持相反立场的人会关心什么），写作时用它发现自己没意识到的模糊表述。

## 不独立成 skill 的原因

**通过 V1（第4章与第5章两个独立语境）与 V3（有专门名称 reverse role-playing，本质是通过角色互换暴露"我以为显而易见、其实依赖我的立场"的隐含预设，非常识），但败在调用场景分配**：

1. 它在第4章是歧义排查（→s11）的辅助手段之一，在第5章是价值观假设（→s12）三线索之第三条、描述性假设（→s13）五线索之第三条——**没有任何一个用户场景会"只想反串"而落入其他挖掘流程之外**。
2. 若独立成 skill，其 description 必须写"想找歧义/假设时"——与 s11/s12/s13 的 trigger 完全重叠，部署后必然互相抢调用，违背原子化初衷。

## 处置

- 降级为 **s11 / s12 / s13 的共用技巧**：在三个 skill 的执行步骤（E 段）中分别作为一条操作出现。
- 原候选内容保留在 candidates/frameworks.md 中备查。
