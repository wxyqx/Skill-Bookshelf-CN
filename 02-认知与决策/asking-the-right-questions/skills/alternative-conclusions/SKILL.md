## I — 方法论骨架 (Interpretation)

二分式思维把可能存在多种答案的问题压缩成是/否、该/不该（"要么国家塑造孩子，要么父母塑造孩子"）——用过度简化换确定性，代价是错过全部中间结论。第6章的"虚假两难"是它在谬误层的先遣形态；第12章给的是**生成侧**的工具：

1. **条件句生成**: 对候选结论加"什么时候 / 什么地方 / 为什么目的"的限定——"应该，当……时"。条件句让"这取决于"成为可行动的立场而非和稀泥：前提是把"取决于什么"写出来。
2. **问题重述**: 把"该不该做乙"重述为"该怎样处理乙问题"——从站队问题变成求解问题。"要不要关闭市中心酒吧"重述为"该怎样解决部分大学生酒精中毒"，答案立刻从"关闭"扩展到"严格执行饮酒年龄、对卖酒给未成年人的酒吧罚款"。
3. **备选结论长在理由上**: 先确认理由，再问"这套理由还能支撑什么结论"——支持死刑的理由（惩罚狱中杀人者、以命偿命才公平）同样支持"仅对已判终身监禁者杀害狱友时执行死刑"。
4. **收尾制衡**: 不是所有结论生来平等。罗列完仍要按推理标准（理由支持强度、与证据的相容度）挑出最站得住的——多元是手段，最强判断才是产出。
5. **姿态**: 用好奇而非逮错的口吻提出备选——第12章收尾处对第1章谈话策略的重申。

## A1 — 书中的应用 (Past Application)

### 案例 1: 向儿童做广告应否非法——同一套理由，三个结论
- **问题**: 论证主张"宣布面向儿童的广告为非法"，理由是孩子不能客观评价广告、等于给父母戴上紧箍咒。
- **方法论的使用**: 即使理由全部可信，也不必然得出这个结论——条件句生成三个备选：若企业被视为"人"则享有含广告权的言论自由；只有证明儿童确实无法评价广告才应禁止；也可只规范广告内容而非取缔。
- **结论**: 不考虑备选结论，决策质量就会大大缩水。
- **结果**: 本章旗舰示范：结论要从理由里重新长一遍，而不是照单全收。

### 案例 2: 死刑与市中心酒吧——两个生成器各显一次
- **问题**: 保留死刑的理由有两条（惩罚狱中杀人者、以命偿命才公平）；"要不要关闭市中心酒吧"看似只有"要"一个答案。
- **方法论的使用**: 前者问"这套理由还能推出什么"——"仅对已判终身监禁者杀害狱友看守时执行死刑"同样被完全支撑；后者用问题重述——"该怎样解决部分大学生酒精中毒"打开了严格执行饮酒年龄、处罚违规酒吧等一排答案。
- **结论**: 同一理由集可以支撑多个合理结论；重述把"站队"变成"求解"。
- **结果**: 全书以"更多可能的结论，更多可能的自由选择"收束；同时提醒结论不生来平等，仍须挑最强。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 人生决策二分："该不该考研/辞职/分手"——被"要不要"卡住时。
2. 团队站队：会议把方案之争压成"做 A 还是做 B"。
3. 论证分析：读到结论斩钉截铁、没有任何限定条件的文章。
4. 写作：议论文默认"必须二选一站队"（干细胞论文场景）。
5. 谈判僵局：双方各持一端，需要"这取决于……"的中间结构。

### 语言信号 (用户的话里出现这些就应激活)

- "该不该 / 要不要 / 是不是 / A 还是 B"
- "只有两个选择吗 / 还有别的可能吗 / 有没有第三条路 / 换个问法"
- 英文信号: either or、only two options、are there alternatives、third way、reframe the question

### 与相邻 skill 的区分

- 与 `omitted-info-probe` 的分界（钦定）：s21 找**被隐藏的**信息（补全输入）；本 skill 造**还可能的**结论（扩展输出）。
- 与 `rival-causes-audit` 的区别：s19 针对因果断言生成竞争**解释**；本 skill 针对规范性问题生成竞争**结论**。
- 与 `fallacy-three-questions` 的区别："不是……就是……"的虚假两难在谬误层被识别后，生成本身是本 skill 的活。
- 与 `charity-before-judgment` 的区别：施惠是按最强形式重构**对方已有的**论证；本 skill 是在理由之上生成**新的**结论。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别二分结构**
   - 指出当前问题的答案空间（是/否？A/B？）及压缩痕迹（"唯一的选择""不是……就是……"）
   - 完成标准: 二分压缩被点名；**判停条件**: 问题本身开放，或属于真二值事实问题（只有一个正确答案）时，说明本 skill 不适用并停止
2. **重述问题**
   - 把"该不该乙"改写为"该怎样处理乙问题"
   - 完成标准: 重述后的问句向用户复述确认；问题从"站队"转为"求解"
3. **条件句生成**
   - 产出"如果……那么……"/"当……时"结构的备选结论；必要时用三问（何时/何地/为何目的）加限定
   - 完成标准: 至少 2 个备选结论，每个都挂靠在材料已给出的理由上（不凭空造选项）；每个都写明成立条件
4. **择优收尾（制衡）**
   - 按推理标准（理由支持强度、与证据相容度）给备选结论排序
   - 完成标准: 明确"当前最强"及其成立条件；**判停红线**: 严禁输出"都差不多"；声明条件变化时排序可变

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 真二值事实问题（"水在标准大气压下沸点是不是 100°C"）——硬造备选是伪开放
- 用户已做出决策、只需执行支持——此时生成选项是干扰
- 应急场景时间只够二选一执行——先决断，复盘时再扩展

### 作者在书中警告的失败模式

- **廉价多元/和稀泥**: 列出几个备选就宣布"都差不多"，或用"许多专家不同意"把论证拉平——直接违反"结论不生来平等"，是本 skill 的头号滥用
- **二分思维换装继续在场**: "看情况"但不写明取决于什么——没有条件内容的"这取决于"不是备选结论
- **为造而造**: 没有理由支撑的选项只是纯观点（第2章判据在此复用）——备选必须长在理由上

### 作者的盲点 / 时代局限

- 双过程研究（系统 1/系统 2）表明快直觉是判断默认，条件句思考是高耗能操作——作者对"勤于练习"的回应停留在意愿层面，未给行为设计；本 skill 步骤已压缩到四步，仍依赖用户愿意慢下来
- 隐含决策者有充分的反思时间与试错空间；高压、时限、高风险场景下"生成备选"可能被现实否决
- 自我应用（把备选生成对准自己珍视的结论）依赖强势批判性思维，但书中未给身份认同与证据冲突时的程序性出路

### 容易混淆的邻近方法论

- **折中方案/和稀泥**: 条件句生成的是"不同条件下各自最优"，不是各让一半的平均数
- **"看情况"敷衍**: 区别只在是否写出"取决于什么、何时成立"——写不出条件的"这取决于"是空话
- **脑暴发散**: 脑暴求多不求准；本 skill 求多之后必须按推理标准收敛
