# 类比评价与自造

## R — 原文 (Reading)

> "任意两个事物之间你几乎总能找出一些相似点。因此，类比推理并不会仅仅因为有很多相似点就具有说服力。"（第8章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第8章

> "类比既能激发深刻的见解同时又能蒙蔽我们。"（第8章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第8章

> "过度情绪化的类比遮蔽了论证中的真正论题。"（第8章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第8章

## I — 方法论骨架 (Interpretation)

类比论证的结构是："我们对甲所知甚多，乙看起来与甲在某些重要方面相似，所以乙很可能在其他方面也相似。"它可能是极富洞见的推理（科学里的动物实验外推、法学里的判例比较都是类比），也可能是披着论证外衣的操纵。评价它的核心是一个对称的两维程序：

1. **找出相关的相同点**：注意"相关"二字——相同点必须与类比想展示的**潜在原则**直接相关，而不是数量越多越好。任意两事物总能找出相似点，相似点堆砌本身毫无证明力。
2. **找出相关的不同点**：这是判断的胜负手。类比两端在关键属性（能力、权利、反馈机制、可退出性）上不对称时，一个致命不同点就足以瓦解整个类比。相关的相同点占比越大、相关不同点越少，类比越强。

配套两个延伸工具。**可替代类比**：为同一个现象找一个不同的类比，看它是否推翻原类比的结论——如果"公司是船"与"公司是球队"推出相反结论，说明原类比在替结论说话而非支撑结论。**框架类比识别**：有些比较不只是解释一件事，还在预设讨论的方向和情绪基调（把一场战争比作越战还是二战，立场早已写进比喻里）；带情绪内涵的比较（"死亡专案小组"）会直接绕过实质论题。

从"审"到"造"是对称的：作者给生成类比的三步法——先识别你要解释的情况的主要特征，再开动脑筋找出多种有相同特征的熟悉情况，最后判断熟悉的情形能否真的提供洞见。自造类比时同样要主动找自己的致命不同点。

最后校准预期：从某种意义上说所有类比都是"错误的"——它们都假设一两个方面的相似会推广到其他重要方面。即使最好的类比也只提供暗示；用类比得出结论的人，应该再补上支撑那个核心相似点的进一步证据。

## A1 — 书中的应用 (Past Application)

### 案例 1: 狗与女儿的宵禁——一个类比的完整拆解
- **问题**: 一位父亲论证："我不会让自己的狗在附近乱跑惹麻烦，所以我为什么不能对 16 岁的女儿强加八点钟宵禁？"
- **方法论的使用**: 先找相关的相同点：狗与女儿都不是完全行为责任人，家长都对二者的安全负责。再找相关的不同点：女儿有认知能力、能分辨对错，并且作为人拥有权利与自主权——狗做不到的这些事恰恰与"是否该限制自由"的结论直接相关。
- **结论**: 不同点在权重上压倒相同点，类比不能支撑结论——这正是错误类比谬误的定义形态（类比中存在重要而相关的不同点）。
- **结果**: 同一方法被用来拆掉开篇两个类比："冷冻快餐没消灭下厨，所以互联网不会消灭报刊"（阅读报刊并不提供烹饪那样的乐趣）；"一枚臭鸡蛋糟蹋一锅汤，所以该清退问题学生"（学生会成长改变，臭鸡蛋不会——把人当不变物体的假设大有 problem）。

### 案例 2: 伊拉克战争该比作哪场战争——框架类比的现场对照
- **问题**: 2004 年美国大选中，反对者把伊拉克战争比作越南战争，支持者把它比作第二次世界大战——同一场战争，两个类比给出相反的情绪定调。
- **方法论的使用**: 识别这是框架类比：它不只解释事件，还在设定讨论方向；两个类比各自携带正面/负面色彩，把听众的反应往特定目标引导。
- **结论**: 遇到框架类比要先问"这个比较想让我的反应往哪边走"，再回到论题本身找证据。
- **结果**: 确立识别线索——一个对比如果"不仅解释一个要点，还影响讨论的方向"，就按框架类比处理。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 老板/政客/家人用一个响亮的比喻立论（"公司是船""国家就是大家庭""养孩子像种树"），用户觉得不对劲但说不出哪里不对。
2. 会议或辩论中双方各执一个类比，用户要当裁判。
3. 用户自己写文章/做提案，想用一个类比让抽象主张落地，又怕被别人拆。
4. 新闻评论里出现历史类比（"这就是另一个 XX 事件"），用户想评估它带了多少框架与情绪。
5. 产品/方案介绍用"我们的产品就像 XX"来解释，用户要判断这个比方有没有超越解释、偷偷替结论背书。

### 语言信号 (用户的话里出现这些就应激活)

- "打个比方 / 就像 / 好比 / 相当于 / 无非是另一个 XX"
- "这个比喻恰当吗 / 类比能不能成立 / 他这个比方有什么问题"
- "我该找个什么比喻来说服他们"（生成侧）
- 英文信号: analogy、metaphor、it's like、think of it as、compares X to Y

### 与相邻 skill 的区分

- 与 `evidence-grade-triage` 的区别：s15 分诊直觉/经历/案例/证词四类；"类比"作为第八类证据在本 skill 专查，总入口遇到"就像/好比"结构应直接移交。
- 与 `rival-causes-audit` 的区别：类比是"拿相似比"，不是"找别的解释"——甲乙相似不产生因果断言，与替代原因无重叠。
- 与 `fallacy-three-questions` 的区别：错误类比谬误只是结论标签；本 skill 给的是两维评价与三步生成的完整工序，而非三问判别。
- 与 `ambiguity-loaded-words` 的区别：框架类比携带情绪内涵，但排查对象是"比较结构"而非单个关键词——词被审是 s11，比被审是本 skill。
- 与非论证的比喻区分：文学修辞、日常口语里的比喻若不充当理由支撑结论，不需要启动本 skill（见 B 段）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别类比与其功能**
   - 找出类比的两端（熟悉物甲/被解释物乙）与它要支撑的具体结论；判断它是纯解释性还是充当理由
   - 完成标准: 一句话写出"作者想借甲乙相似推出乙的什么结论"；若比较还携带情绪定调或预设讨论方向，标记为框架类比
2. **两维评价**
   - 列出相关的相同点（与潜在原则直接相关的）与相关的不同点（关键属性上的不对称：能力、权利、可退出性、反馈机制）；必要时构造一个可替代类比看结论是否翻转
   - 完成标准: 相同点与不同点各成一列且逐条标注"与结论相关/无关"；能明确判定"不同点是否压倒相同点"
   - **判停条件**: 找到一个直接击穿潜在原则的致命不同点时即可停止列举，输出"类比失效（错误类比）"
3. **对框架类比做去框架处理**
   - 问"这个比较想把讨论引向哪里"，重述不带类比的原论题，再看结论是否还有证据支撑
   - 完成标准: 用户获得"比喻剥离后剩多少论证"的判断
4. **生成侧自查**（仅当用户在构造类比）
   - 三步走：识别待解释情况的主要特征 → 头脑风暴多个有相同特征的熟悉情况 → 检验熟悉情况能否真正提供洞见；再主动给自己的类比找致命不同点，并记住"最好的类比也只提供暗示"——关键相似点还需要进一步证据
   - 完成标准: 产出的类比附有一行"本类比的已知局限"

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 文学鉴赏、修辞赏析、日常语言中的比喻（"忙得像陀螺"）——不充当理由的比喻没有评价对象
- 用户只是在求表达建议（"这句话怎么写更形象"）且不涉及论证支撑
- 论证核心是数字或因果，类比只是装饰性引子——应转对应 skill 审主结构

### 作者在书中警告的失败模式

- **错误类比谬误**: 只陈列相似点、从不问"哪里不同"——狗与女儿都被"不完全负责"笼罩，但女儿的权利与认知直接击穿宵禁结论
- **相似点堆砌**: 任意两事物总能找出相似点，"相似点很多"给人已证明的错觉
- **框架类比预设结论**: 伊战比作越战还是二战，情绪定调先于论证；"死亡专案小组"式情绪化类比直接遮蔽真正论题
- **把类比当完备论证**: 类比至多提供暗示，用类比下结论者仍欠"进一步证据"——不补证据就是把修辞当证明

### 作者的盲点 / 时代局限

- 作者承认类比在科学与法理推理中富有成效，但全章火力集中在防欺骗，对"如何有纪律地用类比生成新知"只给了三步法的骨架，缺少可操作的练习
- 框架类比在算法推荐与短视频时代被工业化使用（热梗、标签化对照、历史梗图），其传播效率远超书稿年代；识别工具仍适用，但"一遍拆穿"的从容在情绪传播场景里难以维持
- 美国政治案例（伊战、医保）为背景，框架类比的本地化识别需要熟悉本国政治隐喻库

### 容易混淆的邻近方法论

- 金字塔原理/MECE 等结构化方法：那是组织自己论证的工具，不处理"别人用比喻替结论背书"的场景
- 隐喻认知理论（Lakoff 式"我们靠隐喻思考"）：那是解释隐喻为何普遍的框架；本 skill 是逐个比喻的质量检验工序，两者层次不同
