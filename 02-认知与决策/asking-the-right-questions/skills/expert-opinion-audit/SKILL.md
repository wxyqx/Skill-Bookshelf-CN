# 专家意见四查

## R — 原文 (Reading)

> "我们要问的问题是：'我们为什么要相信这个专家呢？'"（第7章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第7章

> "当一个专家准备从他提倡的某些行动中获得较大的经济利益时，我们就要特别加以小心。"（第7章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第7章

> "这些引证给人一种支撑证据的幻象但是却绕过了一个最基本的问题。"（第7章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第7章

---

## I — 方法论骨架 (Interpretation)

现代生活迫使每个人依赖专家——我们不可能样样精通。所以问题从来不是"要不要信专家"，而是"**这个专家的意见该给多大分量**"。作者给的工序是四查：

1. **专长对口**：该专家在这个**具体主题**上有多少训练、研究年限或一手经历？皮肤科医生的背书救不了营养学断言，"有名"不等于"对题"。
2. **渠道层级**：他处在能接触一手事实的位置，还是只转述别人的东西？涉足事件、掌握第一手资料的专家比二手转述者更可取——报纸杂志是二手渠道，研究型期刊才更接近一手。
3. **歪曲风险**：个人需求、早先预期、职位立场、价值观都会影响证据的呈现方式。最锋利的一问是："他从自己提倡的东西里获利吗？"公立大学校长谈教育经费、靠注射赚钱的医生谈注射产品，都属于高歪曲风险。
4. **同行验证**：持不同观点、不同预期、不同利益的专家们是否也同意？靠"经常做出可靠断言"立名声的专家，比只有惊人之语的可信。

配套两个特别动作。其一，**拆穿引用套引用**：媒体引媒体、通讯社引通讯社、"某人说"——层层转引制造出"证据很多"的幻象，实际无人核查过原始断言，等于把同一篇文章读了一遍又一遍还指望得到新信息。其二，**防过枉**：不能因为怀疑专家的利益偏向就毅然抛弃断言——四查后按查得的结果给分量，"许多专家不同意"这句话本身也须先查明那些专家凭什么反对。

## A1 — 书中的应用 (Past Application)

### 案例 1: 专家也会翻车——审查的目的是校准而非贬低
- **问题**: 《专家如是说》记录的真实预言：IBM 主席 1943 年断言全世界电脑市场"至多卖得出去五台"；福斯电影公司总裁断言录像机六个月内全面失守。专家的可信度究竟该怎么预期？
- **方法论的使用**: 把"专家永远正确"与"专家都是骗子"两个极端都放到一边，转而检查他们当时的断言是否基于对口专长与一手渠道——两人的失败恰恰说明头衔不担保判断。
- **结论**: 专家内部也常常意见不统一，"该给多大分量"必须逐个断言去查，不能用身份整体授信。
- **结果**: 为四查提供了校准基调：信的是查得过的判断，不是查不到的名头。

### 案例 2: 整形医生为保妥适背书（歪曲风险现场演示）
- **问题**: 一位整形医生在文章中宣称某注射美容产品没有任何副作用，论述看似专业流畅。
- **方法论的使用**: 走四查：她的专长（整形医学）虽对口，但她靠执行这类注射赚钱（个人利益即偏见线索），且支持该立场的机构本身就由整形医生组成（同行结构单一）——第三、四查都亮红灯。
- **结论**: 专业身份不能豁免利益审查；"无任何副作用"这种绝对化断言进一步提示歪曲风险。
- **结果**: 确立了"专家+利益"组合的默认警觉：先查获利方式，再决定给观点多少分量。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 广告、带货、健康建议中出现"三甲医生推荐""院士研发""某国专家认证"，用户在决定信不信。
2. 媒体报道里出现"据某专家""研究表明某学者认为"式背书，用户想知道这个背书值多少钱。
3. 职场中客户、领导引用行业大 V 或咨询机构的观点，用户要评估再转述。
4. 用户自己在写作时准备引用权威，想自查引的是真专家还是幻象。
5. 群聊/评论区吵"专家又出来了"，用户想比"信"与"不信"更有分辨力的立场。

### 语言信号 (用户的话里出现这些就应激活)

- "这个专家可信吗 / 权威说的还能有错 / 名人推荐的靠谱吗"
- "为什么相信这个专家 / 他是哪个领域的 / 有没有别的专家反对"
- "媒体都转发了 / 官方机构认证的"
- 英文信号: expert opinion、authority、endorsement、according to Dr. X、cited by

### 与相邻 skill 的区分

- 与 `evidence-grade-triage` 的区别：总入口按证据类型分流——提供者靠**专门知识**发言（医生、学者、机构、名人）→ 本 skill；靠日常亲历发言（朋友、买家、病友）→ s15。
- 与 `research-survey-audit` 的区别：专家**转述**研究结果时，审完专家身份还要审研究本身（样本、调查）→ s17；本 skill 只管"人"这一环。
- 与 `fallacy-three-questions` 的区别：见"诉诸权威"不能自动判谬（书中明确警告廉价驳回）；本 skill 的四查是给分量，不是一票否决。
- 与 `keep-dialogue-alive` 的区别：质疑专家时的语气管理（好奇而非逮错）由对话策略承接，本 skill 只产出审查结论。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **还原断言与来源链**
   - 摘出专家的原始断言、他的身份头衔、信息经过的转述层级
   - 完成标准: 能一句话说出"原始专家到底断言了什么"；若发现引用套引用、匿名"某人说"或转述版本比原始版本更强，标记为证据幻象并降级
2. **执行四查**
   - 专长对口（这个具体主题上他有什么训练/经历）→ 渠道层级（一手还是二手）→ 歪曲风险（从提倡的行动中获利吗？职位立场是什么？）→ 同行验证（不同立场的专家是否同意？他有无可靠名声？）
   - 完成标准: 四项各有"通过/存疑/不过"的明确标注，不是整体印象分
3. **按查得结果给分量**
   - 四项全过→可作为较强证据，仍建议与系统化研究互证（转 `research-survey-audit`）；任一不过→降低分量并说明缺哪项；三、四查皆不过→按带利益倾向的宣传处理
   - 完成标准: 输出"该专家意见在本论题上的可信分量"及理由
   - **判停条件**: 若四查中可查信息为零（完全匿名来源），不再追问细节，直接标注"不可追溯，按幻象处理"
4. **防过枉检查**
   - 反问：利益可疑是否等于断言为假？有没有不同专家支持同一断言的独立理由？
   - 完成标准: 用户得到的结论是"分量判断"，而非"因为是可疑专家所以反着听"；若用户在学术写作场景，提醒转向同行评审研究标准

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 证据根本不是"以专门知识发言的人"（朋友的体验、买家的见证→ `evidence-grade-triage`）
- 用户只想查某专家的履历事实（纯信息查询）
- 用"很多专家不同意"一句话想压倒对方——这是廉价驳回，先让两边理由到场再谈

### 作者在书中警告的失败模式

- **诉诸可疑权威**: 让对论题并无专门知识的机构背书（书中例：艾滋病患者协会为药物审批做证），头衔与专业错位
- **引用套引用**: 报纸引报纸、通讯社引通讯社、"某人说"——支撑证据的幻象绕过了原始断言可信度这一根本问题
- **个人利益不被追问**: 从所提倡的产品/行动中获利的人，其证词被默认当独立意见使用
- **名人证词混入**: 名人只有日常消费者的资格，其背书属于当事人证词而非专家意见（分诊回 s15）

### 作者的盲点 / 时代局限

- 书中默认读者有能力接触一手来源并查证专家利益关系；现实中信息不对称使四查常常只能查到一半，skill 判停规则部分弥补这一点，但"查不到"与"没问题"的区分需要额外练习
- 成书于社交媒体与算法推荐前夜：付费软广、伪装成专业人设的营销号、"专家"头衔的通货膨胀（认证证书产业）未被覆盖
- 美国媒体生态为背景（《纽约时报》《新闻周刊》例），在媒体公信力结构不同的文化语境中，"大报=更谨慎"的默认排序需要本地化重估

### 容易混淆的邻近方法论

- 人身攻击谬误：攻击专家的品格/立场替代对其理由的审查是谬误；四查针对的是"该专家在此断言上的证据地位"，两者对象不同——查利益是为了定分量，不是为了否定人格
- 勒索式质疑（"收钱了所以是假的"）：四查的输出是概率性的分量，不是阴谋论式的判决
