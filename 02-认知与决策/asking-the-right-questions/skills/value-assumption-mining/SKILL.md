# 价值观假设挖掘

## R — 原文 (Reading)

> "所谓价值观假设，就是在特定情形下没有明说出来的喜欢一种价值观超过另一种价值观的偏向。"（第5章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第5章

> "价值观本质上是所有人共有的东西。"（第5章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第5章

> "价值观假设随情境的改变而改变。"（第5章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第5章

---

## I — 方法论骨架 (Interpretation)

规定性论证里，理由自己撑不起结论——中间垫着一层没明说的取舍：两种人人都认的价值观，说话人默认冲突时宁要其中一个。挖到它，争论才能从"谁对"变成"这个情境下哪个价值更重、为什么"。

三个反直觉要点决定挖法。第一，**列价值清单无用**：价值观人人共享（公平、自主、诚实、集体责任……），差异只在冲突时给谁更高优先级——要找的不是"他重视什么"，而是"他宁可牺牲什么"。第二，**假设长在理由到结论之间**：换一个价值偏好，同一条理由立刻撑不住结论——这正是验证取舍是否承重的手法。第三，**取舍随情境漂移**：同一个人此处重个人自由、彼处可能倒向集体幸福，所以挖出的取舍是"这个论证里"的偏向，不是说话人的人格标签。

三条挖掘线索：看说话人的**背景**（职业、立场暗示他站在哪一侧）；看论证**偏爱的后果**（问"为什么这个结果对他可取"，从后果反推被优先的价值）；**反串**——站到相反立场问"持相反结论的人在同一情境下会关心什么价值"。

收尾规则：**价值取向也需要理由**。把隐藏取舍摆上台面后，双方都要回答"冲突时宁要这个的理由是什么"——回答不了，立场就还没成形。

## A1 — 书中的应用 (Past Application)

### 案例 1: 乱丢垃圾论证——集体责任还是个人责任（第5章开篇）
- **问题**: "人们不会积极主动地遵纪守法，因此城市警察必须采取行动"——乍看无懈可击，却说不出哪里需要前提。
- **方法论的使用**: 作者做关键一转：如果你认为制止乱丢垃圾是个人的责任而非政府的责任，这条理由立刻撑不起结论——论证成立的前提是未言明的"集体责任重于个人责任"。
- **结论**: 不挖出这一层，人会"不知不觉相信一些稍加考虑就绝不会接受的观点"。
- **结果**: 确立价值假设的逻辑位置：理由与结论之间的隐藏取舍。

### 案例 2: 竞争与合作的工作场所之争（第5章专节）
- **问题**: 差别工资制（按个人绩效涨薪）与团队协作制（按资历涨薪）两种立场针锋相对，各自理由都成立。
- **方法论的使用**: 作者分别为两方列出结论、理由与价值观假设（竞争＞合作 vs 合作＞竞争），示范反串提问"如果采取相反立场他们会关心什么"；并提醒同一人穿国旗服装时重个人自由、面对种族歧视演说时可能倒向集体幸福。
- **结论**: 涉及规定性论题的完整推理离不开理由和价值观假设。
- **结果**: 三条线索（背景、后果、反串）成为可复用的挖掘程序。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队/组织分歧吵不出结果：远程办公、绩效考核、打卡制度——双方理由都对，却在"可控 vs 自主"上暗中对撞。
2. 读社论、听演讲对政策议题表态：禁枪、教育、移民——规定性论证必藏价值取舍。
3. 家庭争论（管教 vs 自由、储蓄 vs 享受）想找到真正的分歧点而不是吵架。
4. 自己要写规定性文章或做决策陈述，想预判反方会拿哪个价值来攻击自己。

### 语言信号 (用户的话里出现这些就应激活)

- "分歧到底在哪 / 我们到底在争什么"
- "他其实更看重什么 / 冲突时他保哪个"（value conflict / which value wins）
- "这是个价值观问题 / 立场问题，不是事实问题"

### 与相邻 skill 的区分

- 与 `descriptive-assumption-mining`：本 skill 只管"应该怎样"的价值取舍（规定性论证）；"世界如何运作"的事实性隐含信念归对方。
- 与 `fallacy-three-questions`：价值假设不是花招，是论证结构里的合法缺口；理由本身有毛病才是谬误。
- 与 `strong-sense-self-audit`：挖完对方还要把自己放进去——自己的结论同样垫着取舍（强势批判）；只挖别人不挖自己会退化为护短工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认论题类型**
   - 操作: 判断结论是否规定性（该不该/对错好坏）
   - 完成标准: 一句话写出结论 + 类型标注；判停：描述性论题 → 转 `descriptive-assumption-mining`，本 skill 停止
2. **摆出结构并从后果反推价值**
   - 操作: 登记结论与理由；对每条理由问"为什么这个后果对说话人可取"，从偏爱的后果反推被优先的价值；结合说话人背景核对
   - 完成标准: 写出至少一对冲突的价值（"价值 A vs 价值 B"，如管理可控性 vs 员工自主性）
3. **反串验证**
   - 操作: 站到相反立场重新推演——持相反结论的人在同一理由下会关心什么价值？再验证承重性：把挖出的取舍换掉，理由是否立刻撑不起结论
   - 完成标准: 能用"他默认冲突时宁要 A 压过 B"句式写出假设；判停：写出的"假设"与理由逐字相同或人人同意 → 属贴标签失败，回步骤 2 重找
4. **上台面与检验**
   - 操作: 把取舍摆上台面，争论改写为"该情境下哪个价值更重"；用"价值取向也需要理由"检验双方；提醒取舍随情境变，不当人格标签；自查侧——把自己的结论也过一遍同套审查
   - 完成标准: 输出两项——隐藏取舍陈述 + 双方各自还需给出的理由

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 描述性论证（"X 导致 Y"）——事实性缺口归 `descriptive-assumption-mining`
- 纯事实争议（数据对不对、有没有发生）——那是证据审查的事
- 用户只想给某人贴价值观标签（"他就是不重视员工"）——本书明确反对：列价值清单无用且不公平，只找冲突取舍

### 作者在书中警告的失败模式

- 把"他重视 X"当分析终点——人人共享同一批价值观，这种"发现"没有信息量；真正的问题是冲突时宁要哪个
- 把理由复述一遍贴上"价值观假设"标签——制造完成感的自我欺骗，实际没有产出任何新联系
- 把价值取舍当稳定人格——价值观假设随情境改变，同一人在不同议题上取舍可以完全相反

### 作者的盲点 / 时代局限

- 隐含读者有闲暇逐篇审查、且对话双方都讲理；权力不对等的场景（上级、客户、舆论场）里把价值取舍摆上台面未必被受理
- 书中的价值冲突对（集体/个人责任、竞争/合作）来自美国争议语境，跨文化使用需先本地化价值对

### 容易混淆的邻近方法论

- 个人价值观清单测评（职业规划类）——那是"我认哪些价值"；本 skill 是"论证里没明说的取舍"，产出物完全不同
- 立场/受众画像——画像描述对方的价值取向；本 skill 定位取舍在论证中的逻辑位置（理由到结论之间）
