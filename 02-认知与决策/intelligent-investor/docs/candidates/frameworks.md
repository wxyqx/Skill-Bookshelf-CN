title: 幸存准则判别与策略更新机制
type: framework
source_chapter: 卷首 投资策略
source_quote: |
  主要与证券类型相联系的准则没用了。而那些与人性和人的行为相联系的准则生存了下来。后者类似于陈腐格言，但是相当有用。以其中的三个为例：1. 如果投机，最终你将(可能)失去钱。2. 当大多数人(包括专家)悲观时，买;而当他们相当乐观时，卖。3. 调查，然后投资。
summary: |
  把一条投资准则是否可持续放到一个分类检验上：它依附于"证券类型"还是依附于"人性与人的行为"。
  与证券类型挂钩的准则（如"债券比股票安全""第一抵押权债券比无担保债券更安全"）会随条件失效；与人性行为挂钩的准则长期存活。
  配套的更新机制是"条件变化是策略变化的根据"：作者主动撤回自己1949年"买高等级债券是愚蠢的"的忠告，示范当收益关系逆转时应放弃旧建议。
  用法：定期追问某条规则约束的是市场结构还是人的行为，前者须随环境重校准，后者可长期依赖。

title: 投资/投机判别框架（三判据+三非理性检验）
type: framework
source_chapter: 第1章 投资和投机的区别
source_quote: |
  投资操作是基于全面的分析，确保本金的安全和满意的投资回报。不符合这些要求的操作是投机性的。
summary: |
  任何一笔操作先过三道判据：是否基于全面的分析、能否确保本金安全、能否带来满意回报，缺一即属投机。
  再配三个非理性投机检验：意识不到自己在投机；缺乏足够知识和技巧却严重投机；动用超过自己承受损失能力的资金。
  操作出口：若确想投机，拿出一定比例的资金专作此用且比例越小越好；保证金操作天然是投机，热门股购买即赌博。
  用法：在操作上和思想上都把投资与投机分开记账、分开管理。

title: 进攻型五路超额收益评估排除法
type: framework
source_chapter: 第1章 进攻型投资者将能获得什么
source_quote: |
  我给出5种标准方法，进攻型投资者可用来赚取超额利润。1. 普通交易——全面参与市场活动，就像“平均指数”反应的那样。2. 有选择的交易——选择在一年左右时间中比一般股票在市场上表现更好的证券。3. 买低卖高——当价格及行情较不乐观时入市，等到两者都上升时卖出。
summary: |
  把"想赚超额收益"拆成五条标准路径逐一评估：普通交易、有选择的交易、买低卖高、长线选择成长股、廉价购买。
  前两条被明确否定——它们依赖预见力和比大量竞争者更聪明，本质是投机；第三条注重已有价值而非市场下一步，只在特殊情形可行。
  第四条受"好前景已被贴现"公理约束，需小心不为许诺支付太多；第五条（购买经可靠衡量价格大大低于真实价值的证券）是作者推荐的着力点。
  用法：先列全可能的路径，再按"是否依赖预测、是否要求比大众更聪明"逐条排除，剩下的才是可投资路径。

title: 差异化公理与独立判断双刃
type: framework
source_chapter: 第1章 进攻型投资者将能获得什么
source_quote: |
  如果一个公司前途明显比较好，那几乎肯定已经在当前的股票价格中得到反映——经常过分贴现。你买这样的股票，就像在赛马比赛中下赌注，机会可能在你一边，但结果往往并非如此。你可以把这当作一条公理：在华尔街，如果总是在做显而易见或大家都在做的事，你就赚不到钱。
summary: |
  把"超额收益从哪里来"归约为一条公理：好前景几乎必然已反映在股价中且经常被过分贴现，所以跟随共识必然无超额。
  推论：策略必须与大众不同，且一旦判断正确，差异化给出丰厚收益。
  同时警示其双刃性：在别人都错时判断正确的能力几乎不存在，这种预见力不能被看作理性投资的特点。
  用法：差异化要求的是"依据分析的不同"，而非"为不同而不同"；每一步不同都要有独立的分析支撑。

title: 所有者思维模型
type: framework
source_chapter: 第1章 作为证券持有人的投资者
source_quote: |
  投资者作为一个整体不是也不能是证券交易商。他们是国家更大的企业的主人。他们不是从同伴手中赚钱，而是通过企业赚钱。因此，作为投资者，他们主要的精力和智慧应该——至少在理论上如此——用于确保公司的良好运行。
summary: |
  把投资者的身份从"交易者"切换为"企业整体的主人"：收益来自企业而非来自同伴的钱包。
  由此推出投资者作为整体的主要精力应投向确保公司得到诚实良好的管理；"如果你不喜欢管理，那就卖掉你的股票"被斥为愚昧且有害——它不改善管理，只降低股价并转移所有权。
  该思维模型是后续管理低效三信号、股利政策举证、接管正当性等治理框架的起点。
  用法：持有任何股票前先自问"我是在做企业合伙人，还是在等下一位出价者"。

title: 市场先生应对法
type: framework
source_chapter: 第2章 企业估值和股市估值
source_quote: |
  假设你拥有某一私营企业1,000美元的小额股份。你的一个同伴，不如称为Market先生，非常乐于助人，每天告诉你关于他对你的股份价值的想法，另外根据他所告诉你的情况提出购买你的股份或是卖出你的一些股份。
summary: |
  把市场报价人格化为情绪不定的合伙人"Market先生"：他每天报出想法，并愿意按其报价买你的股份或卖股份给你。
  应对规则：在他报出高得不可思议的价格时高兴地卖给他，在他报出极低价格时同样乐意从他手里买，其余时候按公司运营与经济状况的报告形成自己的判断。
  推论：真正的投资者很少被迫出售，报价下跌若不反映内在价值损减就不构成真实损失；让报价决定自己的看法等于把有利条件变成不利条件。
  这是一个可迁移的"报价=服务而非指令"思维结构。

title: 波动二义性与下跌检视流程
type: framework
source_chapter: 第2章 企业估值和股市估值
source_quote: |
  从根本上讲，价格波动对真正的投资者只有一个重要的意义：当价格大幅下跌后，提供给投资者购买机会；当价格大幅上涨后，提供给投资者出售机会。而其他时候，他如果忘记股票市场而把注意力放在股息收入和公司运作状况上，将会做得更好。
summary: |
  先立判据：价格波动对真正投资者只有两个意义——大跌是买入机会，大涨是出售机会，其余时候忽略报价。
  面对下跌有一套检视流程：设阈值——跌幅大于1/3或反映企业地位恶化才需要在意；未过阈值则复核自己的计算，若研究结果是明确的，就有权把下跌当作暂时的反复无常而忽视，甚至动用资金与勇气买更多。
  配套行为格言："股票剧涨后莫买，股票暴跌后莫卖"；不因某一股票上涨就购入、下跌就抛出。
  浮盈兑现的幻觉另条处理（再购买测试）。

title: 浮盈不可兑现律（再购买测试）
type: framework
source_chapter: 第2章 价格波动是投资效益的指示计
source_quote: |
  在一个持续的规划中，不会实现市场利润，除非后来的重新投资确实发生，交易收益的真正度量是前面卖出价格与新买入价格之间的差。
summary: |
  定义检验"波段成功"的判据：卖出利润只有在后来以更低价格重新买入时才真正实现。
  交易收益的真正度量=前面卖出价格与新买入价格之差，而不是卖出价与原始成本之差。
  由此推出：在上升市中卖出后市场"离"自己而去、无法低位买回，等于没有实现利润，只暴露了踏空风险。
  用法：评估任何择时操作或择时公式的历史战绩时，一律改用此度量，防止账面差价自我安慰。

title: 时机之路与价格之路分岔
type: framework
source_chapter: 第2章 市场波动是投资决策的向导
source_quote: |
  所谓时机，就是要致力于预测股票市场的行动——当认为将来市场进程是上升时，买入并持有，而当进程是下降时卖出或不买。所谓价格，就是应致力于当报价低于合理价格时买进股票，而当上升到超过该价格时卖出股票。
summary: |

  作者的确信判断：走价格之路的理性投资者最后会收到满意回报；在预测的基础上把重点放在时机上的人，最后会变成投机者并得到投机者的结果。
  对时间的态度是分水岭：投机者等待信号成本高昂，投资者等待无关紧要——除非等待使他能以低得多的价格再买入。

title: 流行即失效定律
type: framework
source_chapter: 第2章 市场波动是投资决策的向导
source_quote: |
  那些日益被人们接受和看重的准则之所以如此，是因为在一段时期内它们一直运行很好，或有时仅仅是因为它们似乎适合以前的统计记录。但是随着其日益被接受，其可信度也逐渐降低。
summary: |
  交易准则的固有特性：它被看重是因为一段时期运行良好，但随其被日益接受，可信度反而降低。
  两个机制：其一，旧准则不再能适用新情况；其二，准则本身的流行会改变市场行为——追随者的集体行动削弱信号，甚至制造危险。
  实证：道氏理论1899-1938年10次购入9次真利，1938年后7次购买全部买贵；阻力点技术1933年后10次中8次无利可图。
  用法：评估任何方法时必问"它有多流行、被消化多久"；对刚被普遍接受的赚钱方法尤其要警惕。

title: 市场水平评估框架（股债信号+多方法对照）
type: framework
source_chapter: 第3章 1964年股市与前些年股市的比较
source_quote: |
  历时多年，这一现象为股份危险的高水平的出现提供了一个极其可靠的线索。确实，它不能用来预测几周或几月内牛市的结束，从而被投资者和股票交易商所注意
summary: |
  两个互补的市场温度计。其一，股息率与高等级债券收益率的对比：历史上普通股收入比债券高1/3到1/2，牛市中股息率降至接近或低于债息，即为危险水平的可靠线索。

  教训：一个需要七年才被验证的信号不能作为实际投资指南；老方法1985-1964年失效本身也是证据，参数须随利率与制度环境重校准。

title: 不确定性优先策略与谨慎三准则
type: framework
source_chapter: 第3章 小结
source_quote: |
  我认为，不管选择的方法多么复杂和微妙，投资的策略应注重不确定性，而非确定性。因此，在这一转变和多变的时代，投资者的投资目标一定要准备应付各种情况。他决不能断了自己的后路，也不能把一切冒险都基于对股市未来进程的乐观或悲观态度上。
summary: |
  在无法判定牛市延续还是崩溃、通胀还是通缩时，把策略立足点从"确定性"改为"不确定性"：目标不是预测哪种前景，而是保证两种前景下都不致命。
  操作化为谨慎三准则（按重要性排序）：不借贷购买或持有证券；不增加投入普通股的资金比例；必要时把普通股降到组合最多50%，资金收益转投一等债券或储蓄。
  对执行美元成本平均者：可在危险水平暂停新开计划，因为新计划执行后价格立即危险上涨会摧毁坚持计划的耐心。
  元规则：决不留后路、决不把一切押在单一市场前景上。

title: 三层认知过滤（事实/可能性/不可能性）
type: framework
source_chapter: 第3章 1964年股市行情（开篇）
source_quote: |
  我认为在这里，就像在其他地方一样，区别是：（1）事实；（2）足够的可能性，从而确保可依此作出决策；（3）一定会在脑中出现，但不可能引导我们的可能性。
summary: |
  面对市场前景判断，把脑中念头分成三层：已确立的事实；足以支持决策的足够可能性；会出现但不应引导行动的可能性。
  前两层分别用于"校准现实"与"制定应对"，第三层必须被识别出来并排除在决策输入之外。
  这是对抗预测瘾的排序方法：先问这是事实还是可能性，再问该可能性是否充分到能承受据此行动的后果。
  用法：写下自己对市场的每个判断，逐条贴层，只允许前两层进入操作。
