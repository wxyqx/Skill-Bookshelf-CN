# 超额收益路径选择（Excess-Return Path Selection）

## R — 原文 (Reading)

> "在华尔街，如果总是在做显而易见或大家都在做的事，你就赚不到钱。"（卷首）
>
> "如果一个公司前途明显比较好，那几乎肯定已经在当前股价中得到反映——经常过分贴现。"（第5章"成长股和防御型投资者"）
>
> — 本杰明·格雷厄姆

---

## I — 方法论骨架 (Interpretation)

超额收益在逻辑上不可能来自跟随共识：明显更好的前景几乎必然已在价格中，且经常被过分贴现。
格雷厄姆把"超额收益从哪来"变成一道排除法程序，五条标准路径逐一评估：
- 普通交易与有选择交易：依赖对市场或个别股票的预见力，要求"比大量同样聪明的竞争者更聪明"——出局；
- 买低卖高（对市场整体）：1949 年后整体失效，等待可证明的熊市会让公式投资者永远离场——出局；
- 长线成长：23 种成长股基金 10 年 270% 仍输给次级股票的 278%，连专职机构都做不好——出局；
- 只剩**廉价购买系**：买价格远低于内在价值的证券。
其下的三个正面领域——相对不流行的大公司、廉价证券、特别情况——各自所需的知识与气质不同，必须三选一而非全铺。
配套一条双刃警告：差异化本身不保证正确，"在别人都错时判断正确的能力几乎不存在"——既与大众不同又有分析依据（双倍价值）才是完整要求。

## A1 — 书中的应用 (Past Application)

### 案例 1: 威森伯格 23 种成长股基金对照（c32）
- **问题**: 专业机构按"前景最好的公司"选股能否战胜普通市场？
- **方法论的使用**: 1954–1963 年 23 种多样化成长基金总回报 270%（价格 226%＋股息 44%），对照标普 500 综合指数的 278%（分红再投资后 318%）。
- **结论**: 23 种成长基金中仅约 5 种胜过对应的非标准股票部分；1962–1963 单年增长基金 -3% vs 标普 +11%。
- **结果**: 长线成长路径被排除出推荐清单，给出两种解释（市场有效定价 / 按前景挑公司不问价格的方法缺陷）——普通投资者"几乎不会希望自己能作出比全国最优秀的分析家更好的选择"。

### 案例 2: 新泽西标准石油 1960（c03）
- **问题**: 被市场冷落的大公司是否经常提供真正的低估机会？
- **方法论的使用**: 1960 年市场因丧失对石油收益预期的信心抛售大石油股，新泽西标准石油跌到仅 12 倍利润——公司地位未恶化，只是缺乏"性吸引"。
- **结论**: 1963 年公司利润创历史最高，股价较 1960 年低点翻倍——"许多股票廉价是因为不受欢迎而非地位下降"。
- **结果**: 差异化路径（相对不流行的大公司领域）的成功标本：与大众反向且以分析数据（利润倍数）为据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问"怎么跑赢市场/取得超额收益/做出 alpha"，需要先被套上路径选择的框架而非直接给技巧；
2. 用户问"大家都说某股必涨，现在上车晚不晚"——需要差异化公理把提问方向反转成"市场哪里看错了"；
3. 用户自认愿意投入大量研究，在普通交易/精选交易/买低卖高/买成长/买廉价之间犹豫，需要五路排除；
4. 用户在冷门大公司、廉价证券、特别情况三个领域间不知道选哪个，需要按知识气质匹配。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么跑赢大盘/市场？beat the market？outperform？"
- "超额收益从哪来？alpha 怎么做？"
- "进攻型投资者该走哪条路？"
- "大家都买/都在说必涨，现在上车晚不晚？"
- "跟风能赚钱吗？和大众反着来行不行？"
- "冷门股、廉价股、套利，我该选哪个方向？"

### 与相邻 skill 的区分

- 与 `aggressive-negative-list` 的区别：C9 是路径开始前的**排除动作**（不碰什么），本 skill 是**正面路径选择**（走哪条、为什么）；
- 与 `neglected-large-cap-strategy` / `bargain-issues-net-nets` / `special-situations-arbitrage` 的区别：C11/C12/C13 是三域各自的具体技术（怎么筛、怎么估值、怎么操作），本 skill 只负责排除、选择与气质匹配，选定后移交对应 skill；
- 与 `defensive-stock-selection` 的区别：防御型接受平均结果（全取样是第一选项），本 skill 明确以超过平均为目标——前提是身份已是进攻型；
- 与 `investor-identity-matching` 的区别：C5 管"你是谁"（身份二分与努力预算），本 skill 假定进攻型身份后管"走哪条路"；努力与预期矛盾时先回 C5。

## E — 可执行步骤 (Execution)

1. **确认进攻型身份与努力预算**：愿意投入大量研究、接受"回报与明智努力相称"而非"与风险相称"。
   - 完成标准：用户明确接受研究投入要求与"决不购买未经自己研究的证券"的第一原则。
   - 判停条件：不愿投入或每天只有几分钟 → 回身份匹配（C5），其大概率正确答案是防御型路径（C7），本 skill 终止。
2. **五路排除**：对普通交易、有选择交易、买低卖高、长线成长、廉价购买逐路写出排除/保留理由。
   - 完成标准：依赖预见力或"比大量竞争者更聪明"的路径被明确出局；长线路径须面对基金实证（c32：270% vs 278%）。
   - 判停条件：用户坚持成长股路径 → 要求回答"凭什么比专职机构做得好"，答不出即回步骤 1 重新校准身份。
3. **三域气质匹配**：冷门大公司（需耐心、对统计规律的信心）、廉价证券（需报表分析与估值能力）、特别情况（需"非同寻常的知识与设施"）。
   - 完成标准：选定唯一主领域，并写出自身知识/气质/资源与该领域要求的对应关系；明示差异化双刃警告（在别人都错时判断正确的能力几乎不存在）。
4. **移交领域 skill**：进入 C11/C12/C13 之一做具体操作。
   - 完成标准：路径选择结论＋对应 skill 的引用落档。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 防御型或不愿研究的用户——其正确答案是接受平均结果（C7 全取样），强行进入本 skill 只会诱导越界冒险；
- 已选定领域后的具体筛选与估值问题——归 C11/C12/C13，本 skill 不重复其内容；
- 问"某条具体规则/因子还能不能依赖"——归 C2 准则可靠性；
- 问"哪些证券不碰"——归 C9。

### 作者在书中警告的失败模式

- **共识方法失败（x20/c32）**：拥有最好分析家的成长股基金长期跑输标普 500——"按前景挑公司而不问价格"是方法缺陷；
- **差异化的双刃**：与大众不同却不掌握分析依据，只是换个方向赌——"在别人都错时判断正确的能力几乎不存在"；必须同时满足"不同"与"有分析依据"（双倍价值）；
- **太简单太容易的方法必然结束（x07）**：把超额收益押在任何被普遍掌握的公式上终将失望。

### 作者的盲点 / 时代局限

- 冷门股/廉价股因子在 1970 年代后经历长期失效期并被量化策略收割，"冷门即低估"的预期收益在当代大打折扣；
- 对成长股"前景必然已贴现"的强度过度保守，排除了"以合理价格买成长"的中间方案；
- 全书证据链（基金跑输、精选无效、换股无益）最自然的结论是普通投资者应指数化——他把主动路径留给"愿意付出多得多的运用和智慧并经自我检验的少数人"，但这道防火墙在实践中常被高估自己的人跨过。

### 时效警示

**1964 年快照，估值锚/绝对门槛/税收论证须按当期重查，无指数基金时代约束。** 基金对照口径（威森伯格 1954–1963）、"买低卖高对市场整体失效"的时段判断、三域的预期收益均绑定当年市场结构；今天低成本指数基金使"接受平均"的成本趋近于零，主动路径的举证门槛更高，五路排除与三域参数使用前须按当期重查。

### 容易混淆的邻近方法论

- C9（负面清单）：排雷动作 vs 路径选择，先 C9 后 C10；
- C5（身份匹配）：你是谁 vs 走哪条路；
- C11/C12/C13：领域内技术，C10 只做移交；
- C2（准则可靠性）：路径框架本身的时效检验归 C2。
