# 投资/投机过筛与商业原理自检（Invest vs Speculation Filter）

## R — 原文 (Reading)

> "投资操作是基于全面的分析，确保本金的安全和满意的投资回报。不符合这些要求的操作是投机性的。"……"但在许多情况下，投机是非理性的，尤其是以下三种情况：（1）意识不到自己的投机行为；（2）缺乏足够的知识和技巧，严重投机；（3）动用比你能承受的损失更多的资金。"
>
> — 本杰明·格雷厄姆，第1章"投资和投机的区别"（定义转引《证券分析》）

---

## I — 方法论骨架 (Interpretation)

格雷厄姆把"投资"从资产类别改成操作属性：一笔操作是不是投资，与买什么无关，只看三件事——是否基于全面的分析、是否确保本金安全、是否取得满意回报。三条缺一，即降格为投机。于是在他的用法下，拖欠的债券可以是投资，用保证金买"安全"的证券反而是投机。

他不把投机当道德污点：市场需要有人承担风险，也存在理性投机。他真正打击的是三种非理性——意识不到自己在投机、没有足够知识却下重注、投入超出承受能力的钱。对想投机的人，出路不是"戒掉"，而是专款隔离：单设一小笔资金，比例越小越好，操作上与思想上都不和投资混淆。

对"准投资"操作，再用四大商业原理自检：知道自己在做什么；不让别人（消息链、推销术）经营你的业务；没有可靠计算就不做；有勇气按自己的结论行动。收束句：普通投资者把抱负限于能力之内，"取得一般的投资结果比大多数人预期的更容易"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1948 年联储调查——便宜时视为投机、昂贵时视为投资（c04）
- **问题**: 公众对"投资/投机"的感知与真实风险正好颠倒：1948 年超过 90% 受访者反对买普通股（一半认为"不安全、是赌博"），而彼时恰是战后低价区；1962 年 6 月权威金融杂志又在暴跌后刊文唱空，市场随即大涨。
- **方法论的使用**: 格雷厄姆拒绝按证券类型定性，立起与类型无关的三判据操作性定义，并配套三种非理性投机检验与专款规则。
- **结论**: 华尔街语言中投资/投机的区别已经消失，而这种消失正是危险所在——危险价位买入的人反而自称"投资者"。
- **结果**: 该定义成为全书概念体系的起点，并在第16章与安全边际试金石（无"可证明的顺差"即投机）闭环。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问某笔具体操作算不算投资、该不该做：上杠杆、买热门股/meme 股、跟"接近内幕"的消息单。
2. 用户自称"长期价值投资"，但行为是频繁交易、追涨杀跌，需要身份与操作一致性校验。
3. 用户坦白"我就是想拿一小笔钱投机玩玩"，问怎么安排才不伤害本金。
4. 用户带来别人的推荐/小道消息，求"跟不跟"的判断。

### 语言信号 (用户的话里出现这些就应激活)

- "这算投资还是投机" / "is this investing or speculating"
- "能不能上杠杆 / 用保证金买" / "margin"
- "有消息/内幕/朋友说这只票要涨，跟不跟"
- "我就是想玩玩，赚了就跑"
- "热门股现在上车晚不晚"

### 与相邻 skill 的区分

- 与 `margin-of-safety-core` 的区别: C1 是**定性判定**（这笔操作是不是投资，三判据过筛）；C18 是**定量判定**（顺差多大、由什么数据证明）。过了三关只说明"性质"，是否真有"安全"还要 C18 算；用户已在算估值/覆盖倍数时归 C18。
- 与 `investor-identity-matching` 的区别: C5 定"你是谁、该用哪类策略"（身份与投入匹配）；C1 定"这笔操作是什么性质"（单笔准入闸门）。
- 与 `market-mr-volatility-discipline` 的区别: C3 处理已持仓位涨跌后的反应纪律；C1 是买入之前的定性关卡。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **三判据逐条过筛**
   - 完成标准: 对"全面分析？本金安全？满意回报？"各给出 是/否/存疑 及一句依据；任一为"否"→定性为投机，进入第 2 步；三条全过→进入第 3 步。

2. **投机处置检验（仅当定性为投机）**
   - 三非理性逐条问：意识到自己在投机吗？有足够知识技巧吗？资金在承受能力之内吗？
   - 完成标准: 给出"理性投机/非理性投机"标签；非理性部分给出专款处置建议（专设小额资金、比例越小越好、与投资分账分记）。

3. **商业原理四问自检（对"准投资"操作）**
   - 四问：知道自己在做什么吗？是否让别人在经营你的业务（消息链/推销术）？有可靠计算吗？敢按结论行动吗？
   - 完成标准: 四问各有答案；任一问不过 → 退回投机定性或"不做"。
   - 判停条件: 三判据全过且四问全过、用户只问"算不算投资" → 输出结论即停，不做估值定价（那属于 margin-of-safety-core）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要计算一笔买卖的价格/顺差（→ margin-of-safety-core）——C1 只定性不计价。
- 需要确定长期身份与策略骨架（→ investor-identity-matching）。
- 禁止把它用作"类型标签机"：按"买股票=投机、买债券=投资"分类是对本方法的直接误用（格雷厄姆判据与证券类型无关）。

### 作者在书中警告的失败模式

- x01 把投机当投资的身份误判：华尔街通俗语言里凡买证券皆称"投资者"，危险价位的购买反而被叫作投资；"投机使人着迷，如果你在这个游戏中获利，你就会更加着迷"。
- 按保守观点，每个用保证金操作的非专业人士事实上都是投机者；投机资金必须专款化、比例越小越好。

### 作者的盲点 / 时代局限

- "满意回报"与"全面分析"仍需主观尺度与估值能力；对无估值能力的普通人，闸门可能空转（他未给出普通人的默认出口——后来由指数化补全）。
- 大萧条亲历者的深度悲观影响过筛温度：对成长股几乎全盘排斥，会把大量"准投资"推入投机侧。

### 容易混淆的邻近方法论

- 安全边际试金石（第16章）是 C1 的**回扣**而非重复：三判据回答"性质"，试金石回答"顺差能否被证明"。
- 投资者身份二分（第1、5、7章）是 C1 的上游：身份未定时空谈单笔定性意义有限。

### 时效警示（全集群通用，必须内嵌）

**1964 年快照，估值锚/绝对门槛/税收论证须按当期重查，无指数基金时代约束。**
- 本 skill 涉及的"满意回报"锚定 1964 年股息率 2.92% vs 债息 4.42% 的利率环境，引用前按当期重查；
- "专款比例越小越好"无统一数字，按当期承受力自定；今日普通人可用低成本指数化满足"全面分析"的最低要求，这在 1964 年不存在；
