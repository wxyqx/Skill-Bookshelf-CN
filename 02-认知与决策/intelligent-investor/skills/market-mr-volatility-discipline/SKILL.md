# 市场先生波动纪律（Market Mr. Volatility Discipline）

## R — 原文 (Reading)

> "假设你拥有某一私营企业1,000美元的小额股份。你的一个同伴，不如称为Market先生，非常乐于助人，每天告诉你关于他对你的股份价值的想法，另外根据他所告诉你的情况提出购买你的股份或是卖出你的一些股份。"……记住格言："股票剧涨后莫买，股票暴跌后莫卖。"
>
> — 本杰明·格雷厄姆，第2章"企业估值和股市估值"

---

## I — 方法论骨架 (Interpretation)

核心动作是把报价从"价值向导"降格为"仆人式服务"。市场先生每天报出一个情绪化的价格，他的报价只对你有一个重要意义：大幅下跌提供买入机会，大幅上涨提供卖出机会；其余时候按公司运营状况形成自己的判断，忘掉市场更好。

配套三律。其一，检视阈值：跌幅超过 1/3 或企业地位恶化才触发检视；否则无权恐慌——先复核自己的计算再说，恐慌本身即"未做计算"的信号。其二，浮盈不可兑现律：账面利润不是真利润，交易收益的唯一真度量是卖出价与新买入价之差。其三，风险重定义：风险只指价值损失（被迫在不适宜时卖出、公司地位急剧恶化、与内在价值相关的过分支付），价格波动本身不是风险。

两条路的分岔：把重点放在"时机"（预测市场进程）上的人最后会成为投机者并得到投机者的结果；"价格"之路（低于合理价买、高于时卖）才与投资相容。

## A1 — 书中的应用 (Past Application)

### 案例 1: A&P（大西洋和太平洋茶叶公司）1938 年贱卖（c05）
- **问题**: 美国最大零售企业之一、多年良好收益记录，股价从 1929 年 494 美元跌到 1938 年 36 美元新低——持有者如何对待浮亏？
- **方法论的使用**: 复核计算：优先股+普通股总市值仅 1.26 亿美元，而账上现金 8500 万、净流动资产 1.34 亿——整个企业卖得比清理值还低；三个下跌原因（连锁店特别税威胁、盈利暂时下滑、市场萧条）无一永久。
- **结论**: 只要计算无误，跌幅超过 1/3 也不构成卖出理由，反而应忽视波动甚至利用便宜加买。
- **结果**: 1939 年股价升到 117.5 美元；此例成为市场先生寓言与企业估值/市场报价之分的现实底本。

### 案例 2: 投资级股票波动剧化：宾州铁路与通用电气（c06）
- **问题**: 一战前"忽视报价"的老式投资态度为何在战后不再适用？
- **方法论的使用**: 汇编 1901–1962 年道琼斯铁路指数与个股高低价对照：旧时代投资级股票波动很小；1920 年代后宾州铁路 110→6.5、通用电气 110→8.5。
- **结论**: 1920 年后投资级股票本身的大幅波动成为常态，波动不等于价值损失，但投资者必须预先建立对待波动的正确态度。
- **结果**: 此表成为市场先生概念的经验起点，为"波动≠风险"提供历史证据。

### 案例 3: "中性市场"11 年投资结果测试（c07）
- **问题**: 如何客观衡量一段时期的投资成败？
- **方法论的使用**: 用中性起止日期（1936.12–1947.12）并计入股息：11 年中阿波特实验室总收益 311.2%，宾州铁路亏损；而后续两个上升段里美国钢铁与阿波特的相对业绩完全反向。
- **结论**: 过去记录不能简单外推为未来导向；忽略报价波动的中性时段测试比追逐趋势更可靠。
- **结果**: 该测试法被推广用于基金比较与"成长股 vs 低估股"对照。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 持仓大跌（超过或不及 1/3），恐慌、失眠、求安抚或求卖出决策。
2. 大涨后兴奋，问要不要追加点仓、"再不上车就晚了"。
3. 想止盈落袋为安，或卖出后打算等回调再买回。
4. 空仓纠结"现在进还是等暴跌"。
5. 想评估某择时服务/自己的交易战绩的真实性。

### 语言信号 (用户的话里出现这些就应激活)

- "跌了/涨了 X%，怎么办" / "panic / sell off"
- "止盈 / 落袋为安 / take profit"
- "等回调 / 等暴跌再进 / wait for a pullback"
- "踏空 / 追高 / 怕错过"
- "浮盈算不算赚 / 账面利润"

### 与相邻 skill 的区分

- 与 `margin-of-safety-core` 的区别: C3 管"涨跌之后怎么反应"（行为纪律）；C18 管"这笔买卖的顺差多大、由什么数据证明"（定量）。跌幅超阈值触发检视时，检视的算术部分交给 C18。
- 与 `mechanical-allocation-dca` 的区别: C4 是事先约定的机械程序（比例带/定投），把波动应对外包给规则；C3 是对波动本身的态度与判断。用户已有 50:50 纪律问"要不要执行"→C4。
- 与 `rule-reliability-trend-skepticism` 的区别: 问"道氏理论还能用吗"（规则寿命）→C2；问"我现在慌不慌/动不动"→C3。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **触发判定**
   - 完成标准: 明确"触发/未触发"——跌幅 >1/3 或企业地位恶化 → 触发检视；未触发 → 明示"无权恐慌"。
   - 判停条件: 未触发且无新基本面信息 → 不给买卖建议，只做心理校准输出即停。

2. **复核计算（触发后）**
   - 完成标准: 重新核算内在价值/盈利能力是否受损——必须落在算术上，不是感觉上（算术部分衔接 margin-of-safety-core）。

3. **风险三来源检验**
   - 完成标准: 三问逐一回答——是否被迫卖出？公司地位是否急剧恶化？当初是否过分支付？风险结论只认价值损失，不认波动。

4. **度量与动作**
   - 完成标准: 拟议的止盈/换仓全部改用"卖出价−再买入价"度量，无法以更低价格买回的时段利润清零；输出可执行动作（持有/买更多/忽略报价），并声明波动的两义——大跌=机会，大涨=卖点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要精确估值定价（→ margin-of-safety-core）。
- 已有机械比例规则、只问执行（→ mechanical-allocation-dca）。
- "该不该买这只票"的准入定性（→ invest-vs-speculation-filter）。

### 作者在书中警告的失败模式

- x09 浮盈幻觉：账面利润不算数——"直到他以好的利润兑现时，那才是真的，除非他肯定不购买股票——一个不可能的故事"；真正的度量是卖出价与新买入价之差。
- x26 恐慌抛售：A&P 持有者把他人错误判断形成的报价当成自己的损失，"错误地把自己的有利条件变成了不利条件"；真正的投资者很少被迫出售。
- 把重点放在时机上的人"最后会成为一个投机者，从而得到投机者的结果"；等待极低点的成本是损失大笔股息与机会。

### 作者的盲点 / 时代局限

- "忽视报价"预设投资者有能力独立估计企业价值——无此能力者可能从"忽视报价"滑向"忽视风险"。
- 他自己的 1953/1959 谨慎判断被随后牛市证伪——阈值规则也不保证对市场水平的择时正确。

### 容易混淆的邻近方法论

- 机械再平衡（C4）与市场先生态度（C3）互为表里但分工明确：一个是程序，一个是判断；程序存在时优先执行程序。

### 时效警示（全集群通用，必须内嵌）

**1964 年快照，估值锚/绝对门槛/税收论证须按当期重查，无指数基金时代约束。**
- 1/3 检视阈值与"牛市价常为熊市价 2–3 倍"的波动常态（Kress 案例）按当期波动结构重查；
- 无指数基金时代约束——今日可先用低成本指数化消除"个股波动是否要反应"的大半问题，再谈个股检视（1964 年只能道指式全取样）；
