# 淘汰：潜能蓄积期 / 失望谷地

- **候选 id**: f03（framework-extractor 单池提取，无原则池对应条）
- **出处**: 第1章 微习惯的惊人力量
- **挂在哪项**: V2 预测力（主）+ V3 独特性（辅）
- **原因**:
  - V2：其自称的判据"我是没进步，还是没度过蓄积期？"无法回答——临界点不可观测，该框架无法区分"正处于蓄积期"与"方法本身错误"，对外推问题（如"三个月没涨粉该坚持还是换？"）给不出非平庸、可行动的答案，只产生"再坚持一下"的安慰，属危险的非答案。
  - V3："坚持到突破/突破前最难熬"是自助领域常识（冰块/竹子比喻已广泛流传，与 Godin《The Dip》同型）；术语虽为克利尔自创，但任务口径下"独特术语"须搭配可操作技术群与判据，此处没有。
- **降级去向**: S13（tracking-and-accountability）"看不到效果"分支的期望管理话术素材；c03 冰块叙事作视觉锚点。配套反例 x03（失望谷地前放弃）随行引用。
