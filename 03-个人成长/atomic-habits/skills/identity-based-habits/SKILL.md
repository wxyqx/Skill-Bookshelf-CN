# 基于身份的习惯（三层模型 + 投票模型）

## R — 原文 (Reading)

> "这会导致我们养成基于最终结果的习惯。正确的做法是培养基于身份的习惯。……你采取的每一个行动都是投票给了你想成为的那个人。……你不需要全体一致投票才能赢得选举；你只需要多数即可。"
>
> — 詹姆斯·克利尔，第2章《你的习惯如何塑造你的身份》

---

## I — 方法论骨架 (Interpretation)

行为改变发生在三个层次：最外层是结果（你得到什么），中间层是过程（你做什么），最内核是身份（你相信自己是谁）。多数人从外向内改——先定目标、再列计划，却从不触碰"我是谁"，所以注定反弹：行为与自我认知不符时，旧身份会在背后持续把人拉回原点。

克利尔主张反过来，从内向外：先决定"我想成为哪类人"，再用日常小行动给自己投票。每个行动都是一张选票，习惯就是身份证据的累积——你不是先成为跑步者才去跑步，而是靠一次次跑步攒出"我是跑步者"的证据。

关键豁免在投票模型：你不需要全票通过才能赢下选举，只需多数票。一次破戒、一次缺席不构成身份否决，第二天再投一票即可。于是改变的核心问题从"我要达成X"变成"这类人每天会做什么？我今天投了几票？"

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 棒球棒重伤后的重建（作者自述，前言）
- **问题**: 高二最后一天被棒球棒击中面部，颅骨多处骨折、被置于诱导昏迷，康复后被校队除名，整个高中生涯只上场11局——重新站起来的起点不是某个大目标，而是"我是谁"。
- **方法论的使用**: 进大学后不先定"重返巅峰"式目标，而是持续投票：每晚早睡、保持宿舍整洁、改善学习习惯、每周举重几次——每一次都投给"那种自律的运动员"。
- **结论**: 身份由证据累积而来，微小、可重复的行为就是选票；多数票即可扭转自我定义。
- **结果**: 体重从170磅增至200磅，大二赢得投手首发位置，大三任队长，大四入选ESPN学术全美队（全国仅33人）。

### 案例 2（跨章复用）: 记分卡的身份判据（第4章）
- 习惯记分卡给行为标好/坏时不看道德与健康，只问一句："这种行为是否有助于我成为我希望成为的那种人？"——同一身份框架被用作行为评估的底层判据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 反复"下决心→坚持→失败"，把失败归因于意志力或方法，但从未想过自我定义问题。
2. 全部表述都是结果与数字（减20斤、存10万、读完50本书），问不出"想成为谁"。
3. 破戒一次就自责崩盘（"又抽烟了，我就是没救了"），需要多数票豁免与 slips 协议。
4. 开启新计划前想先"定方向"，问该从哪里入手。

### 语言信号 (用户的话里出现这些就应激活)

- "我要减肥/存钱/戒烟""我想变得自律""我想成为一个……的人"
- "坚持不下来，是不是我这个人不行/意志力差""破戒了怎么办"
- 英文: identity / become the type of person who / vote for your future self / relapse / willpower

### 与相邻 skill 的区分

- 与 `habit-loop-four-laws`: S03 只回答"卡在回路哪一环"（机制诊断），不回答"往哪个方向改"；用户已有明确习惯但执行卡壳时走 S03。
- 与 `start-new-habit`: S04 教"何时何地做什么"的启动技术（执行意图/叠加），前提是身份方向已定；方向未定时先用本 skill。
- 与 `identity-flexibility`: S02 处理"身份已经存在但太紧/角色消失"（防固化与改写）；本 skill 处理"从零建立身份证据链"。
- 与 `tracking-and-accountability`: S13 管"已开始但断链"的追踪问责与恢复协议；本 skill 的投票豁免是那张恢复协议的理论依据，不是追踪系统本身。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **改写目标句为身份句**
   - 让用户写出当前目标，再追问身份两问："你想成为哪类人？""这类人会做什么？"
   - 完成标准: 得到一句"我是那种……的人"（不是数字结果句），并列出 2-3 个这类人每天都做的小行为。

2. **设计今日投票**
   - 把 2-3 个小行为落到今天可执行（可借 start-new-habit 的执行意图写法定时定点），每票越小越好。
   - 完成标准: 用户能说出"今天投哪几票"，且每票启动成本不超过两分钟。

3. **写下降级协议（多数票豁免）**
   - 明确"错过一次 = 少一票，不是身份崩塌"的书面规则：破戒后的自我话术 + 次日最小票安排。
   - 完成标准: 用户能说出"破一次不算输，明早再投一票"级别的表述，并定好下一次投票时间。
   - 判停: 若用户的实际困难是"不知道卡在哪一环"或"第一步根本做不到"，分别移交 habit-loop-four-laws / two-minute-start。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只需要一次性决策或信息查询，不涉及重复行为与自我定义——套投票模型是杀鸡用牛刀。
- 成瘾、抑郁、创伤后重建等临床情境：身份叙事可能无效甚至有害，应建议专业支持，本 skill 至多作辅助框架。
- 用户身份方向明确、只缺具体执行技术——直接走对应定律的技术 skill。

### 作者在书中警告的失败模式

- x04 "我正在戒烟"式失败：只改结果层与过程层，"正在戒"在语义上仍承认"我是吸烟者"，旧身份持续投票导致反弹。判据：把"我正在戒"改写为"我不抽烟了"式身份陈述。
- x05 负面标签锁死行为："我不是早起的人""我数学不好"被年复一年复述成身份，行为上限随标签固化——这是身份机制的反向用法。

### 作者的盲点 / 时代局限

- 本书 2019 年出版，行为科学证据仍在更新；三层模型与投票说法在书中未给出实验出处，案例为幸存者样本（作者本人即成功案例）。身份改变的临床适用边界（成瘾、抑郁、创伤）书中未划定——作者自认身份是"双刃剑"却未给出何时失效的判据。重要健康/心理决策应结合专业意见。
- 克利尔为商业作者，科学细节有简化；身份主张对结构受限人群（可变日程、无私人空间）的适用性讨论不足。

### 容易混淆的邻近方法论

- `identity-flexibility`（S02）: 同一身份框架的两端——本 skill 是"投入身份"（投资期），S02 是"松开身份"（防固化期）。用户问题若是角色消失或拒绝更新旧自我，转 S02。
- 杜希格《习惯的力量》的"核心习惯": 那是解释性框架（习惯为什么存在），不涉身份层，术语不可混用。
