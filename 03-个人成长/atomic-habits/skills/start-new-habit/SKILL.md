# 开始一个新习惯（记分卡 → 执行意图 → 习惯叠加）

## R — 原文 (Reading)

> "他们填写的句子被研究人员称为执行意图，亦即你事先就何时何地行动制订的计划。……我将在[时间]和[地点]做[事]。……许多人认为他们缺乏做事的动力，但实际上他们真正缺乏的是明确的计划。"
>
> — 詹姆斯·克利尔，第5章《培养新习惯的最佳方式》

---

## I — 方法论骨架 (Interpretation)

启动新习惯的第一杠杆不是打鸡血，而是把模糊意图转写成有明确提示的计划。三层工具按序使用：

(0) 觉察前置（可选）：先用习惯记分卡花一天盘点现有行为，逐项标"+"（好）"−"（坏）"="（中性），只观察不评判；好坏判据是"是否有助于我成为我希望成为的那种人"。

(1) 执行意图："我将于[时间]在[地点]做[行为]"——用时间与地点这两个最稳定的提示绑定行动，行动时刻无需再做决定，也不必等"有感觉"。248人实验中执行意图组91%每周锻炼，只读励志材料的动力组仅35-38%。

(2) 习惯叠加："继[当前习惯]之后，我将[新习惯]"——借既有行为的尾部当提示，适合没有固定时间的场景。三条成败校验：提示具体且可立即执行、频率一致（每日习惯锚每日事件）、匹配动线（顺路而非绕路）。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 狄德罗的红袍（第5章）
- **问题**: 一个行为如何成为下一个行为的提示？
- **方法论的使用**: 作者从狄德罗换红袍后连锁升级家具的效应中看到"行为触发行为"的关联结构，不把它当消费陷阱讲，而是反转为工具：既然每个动作都连着下一个动作，就把新习惯挂接到既有习惯上。
- **结论**: 习惯叠加公式"继[当前习惯]之后，我将[新习惯]"——狄德罗效应的积极版本。
- **结果**: 新习惯不再需要新的时间块，直接搭上既有生活动线。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "我想养成X习惯，但总是忘记/坚持不了几天"——计划缺失型。
2. "我每天时间不固定，没法定点做"——无稳定时间，适合叠加事件锚。
3. "收藏了一堆干货还是没开始"——酝酿代替行动，需要一句可执行计划。
4. 用户拿着"每日打卡"式目标来问怎么落地。

### 语言信号 (用户的话里出现这些就应激活)

- "养成/培养""新习惯""从哪开始""帮我定个计划"
- "记不住/总是忘""没时间/时间不固定""什么时候做"
- 英文: build a new habit / start / when and where / keep forgetting / no fixed schedule / habit stacking / anchor

### 与相邻 skill 的区分

- 与 `habit-loop-four-laws`: 用户不知道卡在哪一环时先诊断；本 skill 默认断点在"提示/计划"，或用户已明确决定要开始。
- 与 `two-minute-start`: 本 skill 管"何时何地做什么"；S10 管"第一步小到不会失败"。可组合：先定时定点，嫌难再缩步。
- 与 `quit-bad-habit`: 正反分开——本 skill 全部动作都是给好行为加提示与计划，不做提示移除与增阻。
- 与 `environment-design`: S05 布置空间让提示显眼，是本 skill 的物理配套；问"放哪/怎么布置"转 S05，问"什么时间做"留在本 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **（可选）记分卡觉察**
   - 列出一天惯常行为清单，逐项标 +/−/=，当天不做任何改变；用身份判据复评"好"项。
   - 完成标准: 不少于 15 项的清单与标注；从中挑出 1-2 个可当锚点的既有习惯。

2. **写执行意图**
   - 套"我将于[时间]在[地点]做[行为]"；检查时间、地点、行为三要素齐全，无"大概/有空/左右"。
   - 完成标准: 一句话计划，含具体时间点或时段 + 具体地点 + 具体行为。
   - 判停: 若用户没有固定时间，跳到步骤 3 用事件锚，不用钟点。

3. **习惯叠加 + 三校验**
   - 套"继[当前习惯]之后，我将[新习惯]"；逐条校验：提示具体可立即执行？频率一致（每日锚每日）？匹配动线？
   - 完成标准: 锚点是每天必然发生且界限清晰的事件，叠加句通过三条校验（参照作者"午休时做俯卧撑"因提示模糊而失败的教训）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 戒除坏习惯——那是提示移除与增阻（quit-bad-habit），方向相反。
- 用户的问题实际是"第一步太大"——转 two-minute-start。
- 临床性启动困难（ADHD、抑郁相关执行功能障碍）——模板只是辅助，应建议专业支持。

### 作者在书中警告的失败模式

- x06 动机被高估：动力组（35-38%）败给计划组（91%），"等有感觉了再开始"是被实验证伪的路径。
- x07 提示模糊（作者自错自纠）："当我午休时做十个俯卧撑"因不知饭前饭后、在哪儿做而断裂，改"合上笔记本电脑之后"才成功——叠加句出现"大概/有空"即预警。

### 作者的盲点 / 时代局限

- 91% 实验周期仅两周、行为门槛低（每周锻炼一次即算达标），长期维持证据不足。
- 叠加法假设用户有稳定日常动线——轮班工作者、照护者、无固定居所者可能找不到"每天必然发生"的锚点，需自建锚（闹钟+固定地点）并接受更低成功率。
- 本书 2019 年出版，行为科学证据仍在更新，重要健康/心理决策应结合专业意见；克利尔为商业作者，科学细节有简化。

### 容易混淆的邻近方法论

- BJ·福格"小习惯"（Tiny Habits）: 本书叠加公式源自福格但并入执行意图体系，术语按克利尔用法（福格用"锚点时刻"，克利尔用"当前习惯"）。
- 杜希格习惯回路：解释框架，无计划模板。
