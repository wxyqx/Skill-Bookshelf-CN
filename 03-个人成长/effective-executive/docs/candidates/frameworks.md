```yaml
  type: framework
  source_chapter: 第2章（L611–635；L663–724）
  source_quote: |
    "1.首先要找出什么事根本不必做……问：'这件事如果不做，会有什么后果？'……

    时间。三问分别对应取消、授权、修己三个方向，是德鲁克式"时间审计"的可执行判据。
  tags: [time, checklist, diagnostic]
```

```yaml
  type: framework
  source_chapter: 第2章（L663–724）
```

```yaml
- id: f05
  title: 集中整块自由时间法
  type: framework
  source_chapter: 第2章（L730–769）
  source_quote: |
    "时间分割成许多段，等于没有时间。时间如果能集中，即使只有一个工作日的1/4，也足可
    办理几件大事。……有效的管理者，第一步应先估计究竟有多少'自由时间'……然后保留出
    相当分量的一段连续性的整块时间来。"
  summary: |
    先承认事实（高级主管真能自由运用的时间大概只有 1/4），再执行三步：①估算自由时间
    总量；②保留出连续整块（一周内留一天在家工作、把例行工作排在固定两天、以 90 分钟
    为单元等）；③一旦发现被"蚕食"就重新分析时间记录、再筛掉次要工作。德鲁克强调
    集中的"方法"倒在其次，重要的是时间如何用法；且这事不能一劳永逸。
  tags: [time, practice]
```

```yaml
- id: f06
  title: 贡献自问法（"我能贡献什么"）
  type: framework
  source_chapter: 第3章（L782–811；L805）
  source_quote: |
    "有效的管理者一定注重贡献……他常自问：'对我服务的机构，在绩效和成果上，我能有
    什么贡献？'他强调的是责任。"
  summary: |
    把"我做什么/我管多少人"的自我叙述，换成"我在绩效和成果上贡献什么"。管理顾问的
    实证：多数主管答职务（"我主持会计业务"），少数答贡献（"我的任务是向经理提供
    他所需的资料，使他能做正确的决策"）。此问的作用是"挖掘工作中尚未发挥的潜力"
    （代理部从文件处理变成推销部门），并把人从专长、技术、部门的限制里拽出来。
  tags: [contribution, question, core]
```

```yaml
- id: f07
  title: 贡献三领域（成效的三条线）
  type: framework
  source_chapter: 第3章（L813–827）
  source_quote: |
    "一般机构对成效的要求往往表现在以下三个方面：直接成果；树立新的价值观及对这些
    价值观的重新确认；培养与开发明天所需要的人才。如果在成效中缺少这三方面中的任何
    一个方面，那么机构就会衰败甚至垮台。"
  summary: |
    任何组织的成效都有三条互不替代的线：直接成果（企业=销售利润，医院=护理治疗）、
    价值观的承诺与实现、明天需要的人才。德鲁克用营养比喻：直接成果像食物，价值观像
    维生素和矿物质；只看一条线必然失衡（英国国营航空公司三种直接成果混淆导致一种
    都没得到；美国农业部在两种价值观之间摇摆）。管理者要按自身处境决定三者的比重。
  tags: [contribution, diagnostic, core]
```

```yaml
- id: f09
  title: 用人所长四原则
  type: framework
  source_chapter: 第4章（L1040–1120）
  source_quote: |
    "1.卓有成效的管理者不会将职位设计成只有上帝才能胜任。……2.……职位的要求要严格，
    而涵盖要广。……3.……在用人时，会先考虑某人能做些什么，而不是先考虑职位的要求
    是什么。……4.……在用人之所长的同时，必须容忍人之所短。"
  summary: |
    择人任事的四步结构：①职位必须由常人可胜任（先后两三人失败即重新设计，别找天才）；
    ②职位要求严格但涵盖要广（否则人被框死、年轻人变"老油条"）；③先看此人能做什么
    （评估以绩效与长处为重心，而不是职位说明书）；④容忍短处——短处通过组织手段使其
    不产生作用，而不是改造人。四原则共同指向"让平凡人做出不平凡的事"。
  tags: [people, strength, core]
```

```yaml
- id: f10
  title: 绩效考评四问
  type: framework
  source_chapter: 第4章（L1100–1118）
  source_quote: |
    "（1）哪方面的工作他确实做得很好？（2）因此，哪方面的工作他可能会做得更好？
    （3）为了充分发挥他的长处，他还应该再学习或获得哪些知识？
    （4）如果我有个儿子或女儿，我愿意让我的子女在他的指导下工作吗？"
  summary: |
    德鲁克式的考评不问缺点问长处：先列出对某人的期望贡献，再把实际绩效与之对照，然后
    问四问。前三问完全以长处与绩效为重心（区别于医生找毛病式的传统考评）；第四问是
    唯一涉及品格的否决项——下属会以上司为楷模塑造自己，故缺正直者没有资格做管理者。
  tags: [people, appraisal, checklist]
```

```yaml
- id: f11
  title: 管理上司法
  type: framework
  source_chapter: 第4章（L1176–1201）
  source_quote: |
    "有效的管理者常问：'我的上司究竟能做些什么？他曾有过什么成就？要使他发挥他的长处，
    他还需要知道些什么？他需要我完成什么？'……与其说是'提什么建议'的问题，倒不如说
    是'如何提出这一建议'的问题。"
  summary: |
    把"管理上司"当作下属的责任：不问上司不能做什么，只问他能做什么、需要知道什么、
    需要我完成什么；再按上司的类型（读者型/听者型、要一页纸还是要 60 页推演、要
    早了解还是要成熟报告）设计建议的呈现顺序。核心不是唯命是从，而是"从正确的事情
    着手，并以上司能够接受的方式向其提出建议"。
  tags: [people, upward-management, communication]
```

```yaml
  type: framework
  source_chapter: 第6章（L1475–1488）
  source_quote: |
    "1.要确实了解问题的性质，如果问题是经常性的，那就只能通过一项建立规则或原则的决策

    步骤希波克拉底、亚里士多德、伽利略早已提出。
```

```yaml
- id: f17
  title: 问题四分类（经常性的优先假说）
  type: framework
  source_chapter: 第6章（L1492–1554）
  source_quote: |
    "有效的决策人首先需要辨明问题的性质：是一再发生的经常性问题呢，还是偶然的例外？"
    （四类：真正经常性问题／特殊情况下偶然发生但实质经常的问题／真正偶然的特殊事件／
    首次出现的"经常事件"）
  summary: |
    按"是否重复出现"而非"大小急缓"给问题分类：第一类（库存、管道接头）表面各别实为

    只能个别处置；第四类是"经常事件的首次出现"。除第三类外都需要规则/政策/原则式
    决策。有效决策者总是先假定问题是经常性的，除非证实为偶发。
  tags: [decision, classification, diagnostic]
```

```yaml
- id: f18
  title: 边界条件探求
  type: framework
  source_chapter: 第6章（L1558–1586）
  source_quote: |
    "通常，探求边界条件的方法，是探求'解决某一问题应有什么最低需要'。……（斯隆）'
    如果解除各独立部门的自主权，能满足本公司的需要吗？'他的答案是不能。……边界条件
    变了，罗斯福总统真是反应敏锐。"
  summary: |
    边界条件=决策必须满足的最低规范。探求方法：追问"最低需要是什么"（斯隆由此发现
    问题是组织结构而非人事协调）；检验方法：问"如果这个临时办法被长期执行下去，我会
    愿意吗？"（防"暂时措施永久化"）；危险辨识：凡"唯有在一切顺利的情况下才可能达成"
    的决策最危险。边界条件不清则决策无效；边界条件变了，就应像罗斯福 1933 年那样
    断然换掉整个计划（"复兴"→"改造"）。
  tags: [decision, boundary, core]
```
