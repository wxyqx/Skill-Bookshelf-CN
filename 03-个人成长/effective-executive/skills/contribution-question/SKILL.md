# 贡献自问法："我能贡献什么"

## R — 原文 (Reading)

> "有效的管理者一定注重贡献，并懂得将自己的工作与长远目标结合起来。他常自问：'对我服务的机构，在绩效和成果上，我能有什么贡献？'他强调的是责任。"
>
> — 第3章，L782

> "一个人如果只知道埋头苦干，如果老是强调自己的职权，那不论其职位有多高，也只能算是别人的'下属'。反过来说，一个重视贡献的人，一个注意对成果负责的人，即使他位卑职小，也应该算是'高层管理人员'，因为他能对整个机构的经营绩效负责。"
>
> — 第3章，L790

> "在以工作或任务为主的环境下，如果我们不能有所成就，那就算我们能与人和谐相处，愉快交谈，又有什么意义呢？"
>
> — 第3章，L899

---

## I — 方法论骨架 (Interpretation)

德鲁克给出的不是一套流程，而是一句要反复问的自问句："对我服务的机构，在绩效和成果上，我能有什么贡献？"它的作用是把自我叙述的坐标从"我做什么、我管多少人、我有多辛苦"换成"谁因为我得到了什么成果"。

他有一份管理顾问式的观察作证：问主管"你在贵公司自认为应该做些什么"，多数人答的是职务定义（"我主持本公司的会计业务""我负责销售部门""我要管 800 多人的工作"），很少人答贡献（"我的任务是向经理提供他所需的资料，使他能做正确的决策"）。前一种回答把人锁在专长、部门与内部事务里；后一种回答把人拉向外部成果。

这个问句还有三个连带效果。其一，它划出了心态的分界：只强调职权与勤奋的人，职位再高也"只能算是别人的下属"；而以成果负责的人，位置再低也在对整个机构的绩效负责。其二，它是"挖掘尚未发挥的潜力"的工具——同一份工作，问过贡献之后可能整个重新定位。其三，它是一套人际关系的替代标准：有效人际关系的四项要求（互相沟通、团队合作、自我发展、培养他人）都由"着眼于贡献"自然满足，而"自认为有管理天赋的管理者，往往并没有良好的人际关系"。

用法上要注意两点：这问句是自我要求，不是向上邀功的话术；它的答案必须能指出具体的受益者与成果，否则还是职务定义换了个说法。

## A1 — 书中的应用 (Past Application)

### 案例 1: 公立科研所出版部主任——"为我们写"与"把我们当写的对象"

- **问题**: 某颇具规模的公立科学研究所，出版部主任退休。他既不是科学家，也不擅长笔墨，主持的书刊常被批评缺乏学术水准；继任者是一位科学家，书刊面貌一新、学术水准大为提高。
- **方法论的使用**: 前任主任常自问"我能为本所贡献些什么"，并把答案定为"引发外界年轻科学家对本所研究工作的兴趣，吸引他们来参加本所的工作"。于是他特别强调研究所内的重大事件、重大决策乃至内部争执，虽屡次引起所长不满甚至正面冲突，仍坚持这一原则。
- **结论**: 他的判断标准是使用者的成果而非同行的观感——"我们的出版品是否成功，不在于'我们'爱不爱看，而在于有多少年轻而素质良好的科学家，因读过我们的书刊而愿意前来应征工作"。
- **结果**: 出人意料的是，一向阅读该所书刊的科学团体在新主任上任后停止订阅；一位关系密切的大学教授点出原因："你们的前任出版部主任，出版的书刊都是'为'我们而写的，而现在的新主任，却把我们当成了写的对象。"

### 案例 2: 商业银行代理部——从文件处理变成最成功的推销部门

- **问题**: 某商业银行的代理部工作单调：代理各大公司办理股票债券登记及交易，定期填送通知、发放股息，要求高度准确但不需要想象力。
- **方法论的使用**: 新经理上任后提出"我们代理部究竟能做出什么贡献？"他由此发现：代理部经常与各大公司的高级财务主管来往，而这些人握有存款、贷款、投资与退休金拨存的决定权。
- **结论**: 本职工作（准确高效的文件处理）必须先做好，但在此基础上存在一项尚未发挥的潜力——该部门可以成为银行其他部门的"推销员"。
- **结果**: "本来只是一个文件处理性质的部门，一下子变成了该银行最成功的推销部门了。"

### 案例 3: 医院里的"白莉安原则"——贡献问句被制度化

- **问题**: 某医院新任院长第一次院务会议上，一项棘手事情看似已达成各方满意的解决办法。
- **方法论的使用**: 忽然有人提出："这办法能使白莉安护士满意吗？"会议立刻掀起热烈辩论，直到研究出另一个更积极的解决办法。白莉安是资深护士，并无特殊才能、连护士长都没当过，但每逢有关病人护理的决定，她都要问："我们对病人是否已尽了最大努力？"
- **结论**: 凡事都先自问"为贯彻本院的宗旨，我们真是做出了最大的贡献吗？"——这一问句成为全院的标准（"白莉安原则"）。她主管病房的病人痊愈得特别快。
- **结果**: 白莉安退休十年后，她所制定的标准仍为院中上下同仁所信守，并在新任院长的会议上直接改变了决议。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户被提名加入一个委员会/秘书处/跨部门项目，纠结要不要接受。
2. 用户写述职、年度总结、晋升材料时，只能列出"做了什么"，说不出"谁因为我的工作得到了什么成果"。
3. 用户自认勤奋、加班很多，却总觉得没有被组织看见，甚至抱怨没有职权。
4. 用户与同事/上下级关系反复摩擦，靠"和气"维持但成果不佳，想换一个共同标准。
5. 用户怀疑某份工作/岗位的潜力未被挖掘，想问"这份工作还能变成什么"。

### 语言信号 (用户的话里出现这些就应激活)

- "我该不该接这个委员会/项目"/"should I take this role"
- "我能贡献什么"/"what can I contribute"
- "我付出了这么多，为什么没人认可我"
- "我不知道我的述职该写什么成果"
- "做得好也没用，没有职权所以推不动"

### 与相邻 skill 的区分

- 与 `three-domains-of-contribution` 的区别: 本 skill 是那句自问与心态转换；一旦要检查"直接成果/价值观/人才"三条线的配比与缺口，交给它。
- 与 `make-output-usable` 的区别: 本 skill 问"贡献什么"；那个 skill 负责把产出按使用者的语言、形式与时机交付出去，是贡献在专业场景的落地。
- 与 `results-outside-the-organization` 的区别: 后者是"成果只能在组织外部产生"的结构定律（视角）；本 skill 是可反复使用的自问句与评估标准。
- 与 `strengths-based-staffing` 的区别: 前者是把贡献当标准；后者是"用人的判据"（他能做什么）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **把"职务定义式回答"与"贡献式回答"分开**
   - 动作: 先让用户用一句话回答"你在这个位置上应该做些什么"。若答的是职务范围（管什么、负责哪块），标注为"职务定义"；继续追问"那么谁因为你的工作能得到什么成果？"
   - 完成标准: 得到一句包含**具体受益者 + 具体成果**的贡献陈述（如"我的任务是让经理拿到他做决策所需的资料"）。
   - 判停条件: 若说不出任何受益者与成果，转入步骤 2 反查；不进入后续评估。

2. **反向检验：换掉"勤奋/职权/待遇"指标**
   - 动作: 检查用户的自我叙述是否依赖三类替代标准——加班与辛苦、职权与管辖人数、组织是否亏待自己。任一命中，指出它属于"只能算是别人的下属"的心态信号。
   - 完成标准: 用户能看出自己的叙述在哪一处被替代标准占据，并愿意改用成果语言重写一遍。

3. **做"潜力挖掘"追问**
   - 动作: 对现有工作问"看起来成绩辉煌，但与潜在贡献比起来是否微不足道？"；列出这份工作与外界/使用者的接触点，找出未被利用的潜力（如代理部发现自己天天接触握有决定权的财务主管）。
   - 完成标准: 至少列出一条此前未发挥的潜力，并写明它对谁有价值。

4. **把贡献问句落到关系与自我发展上**
   - 动作: 用四项要求逐条自检：是否双向沟通（我会主动问下属/合作者"组织该期望你有什么贡献"）、是否促成团队合作（谁需要我的产出）、自我发展是否有方向、是否在培养他人。
   - 完成标准: 四项各有一句基于事实的判断；对缺口给出一个可执行动作（如在下一次一对一中先问对方的贡献设想）。

5. **形成可复述的贡献声明**
   - 完成标准: 用户能用三两句话说明"我在绩效和成果上贡献什么、由谁使用、下一步要补什么"，且不再以勤奋与职权作为主要论据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是谈判话术与薪酬策略：贡献问句是自我要求与成果定向，不是邀功工具。
- 用户处于明显被边缘化、存在结构性歧视或被挤压的环境：把"你能不能说出成果"当作唯一解释会变成"你没有成果是因为你不学德鲁克"式的二次伤害；须先承认权力与机会分配的现实约束。
- 用户只是想被表扬：本 skill 的答案指向使用者与成果，不指向情绪安抚。

### 作者在书中警告的失败模式

- **重勤奋轻成果、计较职权与亏待**（ce11）: "他们重视勤奋，但忽略成果。他们耿耿于怀的是：所服务的组织和上司是否亏待了他们……他们抱怨自己没有职权，结果是做事没有效果。"
- **以职务定义冒充贡献**: 管理顾问式提问下多数主管只答职务（"我主持会计业务""我要管 800 多人的工作"），把注意力锁在专长与部门里。
- **用融洽替代成果**: 以和谐相处、愉快交谈为关系标准，而不是彼此有成果（第3章对"良好人际关系"的重新定义）。

### 作者的盲点 / 时代局限

- **价值中立假象**: 书中把"重视价值观"写进成效标准，却不讨论"谁的价值观"；本 skill 追问"贡献什么"时，须承认组织目标本身可能存在冲突，贡献方向不一定有唯一正确答案。
- **高管与秘书假设**: 案例默认管理者有可调动的部门与助手（"我要管 800 多人的工作"式问法、代理部经理可改造部门定位）；无职权者对"贡献"的可操作空间远小于书中人物。
- **性别与时代语境**: 全部正面案例为男性管理者（出版部主任、银行代理部经理、连锁店总经理），"白莉安原则"中的女性角色是护士——只能作历史语境引用，不能推论女性适用的贡献路径不同。
- **证据等级**: 顾问观察与轶事为主（"我从未见过一位……"式归纳），无对照组与统计检验。

### 容易混淆的邻近方法论

- "以客户为中心"/用户思维: 方向相近，但德鲁克的特有结构是把贡献问句作为**个人责任感与心态分界的开关**（职位低也可以是"高层管理人员"），并要求它制度化（白莉安原则）。
- 绩效对话/OKR 对齐: 面向目标层层分解；本 skill 面向"成果由谁使用"的反向追问，起点不是目标分解而是责任转向。
- 职场情商/沟通技巧: 强调关系处理；德鲁克明确把人关系的基础放在贡献而不是融洽上。
