# 从时间开始：记录规范与三步总纲

## R — 原文 (Reading)

> "有效的管理者并不是一开始就着手工作，他们往往会从时间安排上着手。他们并不以计划为起点，认识清楚自己的时间用在什么地方才是起点。然后他们管理自己的时间，减少非生产性工作所占用的时间。最后，再将'可自由运用的时间'，由零星而集中成大块连续性的时段。"
>
> — 第2章，L493

> "重要的是，必须在处理某一工作的'当时'立即加以记录，而不能事后凭记忆补记。……有效的管理者往往以连续三四个星期为一个时段，每天记录，一年内记录两三个时段。"
>
> — 第2章，L607–609

> "只有时间，是我们租不到、借不到，也买不到，更不能以其他手段来获得的。……时间也完全没有替代品。"
>
> — 第2章，L503、L507

---

## I — 方法论骨架 (Interpretation)

德鲁克把时间管理的起点从"计划"挪到了"测量"。理由有两条：一是时间是最稀缺且完全不可替代的资源（租不到、买不到、不能贮存）；二是人对时间的感觉最不可靠——心理学实验证明，凭记忆的估计与实测"相去甚远"，因为记忆会把"应该花时间的工作"记成"已经花掉了"。

所以第一步不是列待办，而是采集数据：像科学管理记录工时那样，在处理工作的**当时**记录实际耗用，而不是事后补记、更不是回忆估计；采样规范是连续三四个星期为一个时段，一年做两三个时段。这段记录不是给人看的日志，而是供分析的原始数据样本。

有了样本才进入后两步：管理（逐项剔除无贡献的活动与制度性浪费）与统一安排（把剩余的自由时间并成整块并持续防守）。三步合起来是一个循环——因为记录会被新的忙碌侵蚀，需要定期重做。

注意"认识你的时间"是对"认识你自己"的可操作改写：前者任何人只要肯做就能做到，后者太难；所以德鲁克把它称为通向贡献与有效性之路的起点。

## A1 — 书中的应用 (Past Application)

### 案例 1: 某董事长的"时间三等分"被六周实测推翻

- **问题**: 某公司董事长十分肯定地告诉德鲁克，他的时间大致分成三个部分：1/3 与高管研讨业务、1/3 接待重要客户、1/3 参加社会活动，并自诩记忆力很强。
- **方法论的使用**: 德鲁克请他先凭记忆把时间使用做个估计写下来，同时由秘书对他实际耗用的时间做记录；六周后，把原来的估计与记录对照。
- **结论**: 在上述三个方面，他"几乎没花什么时间"——记忆告诉他的是他认为"应该"花时间的工作。记录显示，他的时间大部分花在调度工作上：处理自己认识的顾客的订单、打电话给工厂催货；而且由于他的干预，本来可以顺利处理的订单反而不能准时交货。
- **结果**: 董事长起初"简直一点儿都不能相信"，秘书又做了几次记录之后，他才相信自己的估计靠不住，开始以记录为准。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说"一天没干正事""不知道时间去哪了"，但手上只有印象与估计，没有数据。
2. 用户正想开始做时间记录，需要具体规范（什么时候记、记多久、记几轮）；或以前的记录是事后补写的。
3. 用户在做计划表/待办清单，但屡屡落空，纠结"会不会先测量更靠谱"。
4. 远程办公、混合办公、跨时区协作之后时间感紊乱，需要重新采样。
5. 用户要求"审计我的时间"，但还没有现成的样本。

### 语言信号 (用户的话里出现这些就应激活)

- "记录时间 / 时间记录 / 时间日志 / 时间审计"、"time log / time audit / how should I track my time"
- "我的时间到底花在哪了"/"where does my time actually go"
- "先做计划还是先记录？"/"should I plan first or log first"
- "我感觉我一半时间可以自己支配"（凭感觉的时间分配断言）
- "记了几次就断了"（记录维持问题）

### 与相邻 skill 的区分

- 与 `time-diagnosis-questions` 的区别: 本 skill 只负责把数据采到手并给三步总纲；一旦记录在手、要逐项决定"取消/授权/问下属"，交给它。
- 与 `consolidate-free-time` 的区别: 本 skill 是采集与总览；"把零碎自由时间并成整块并防守"是它的第三步的展开，深做用那个 skill。
- 与 `time-waste-institution-scan` 的区别: 本 skill 的对象是个人时间样本；制度性病灶（重复危机、会议 1/4、人员 1/10）由它处理。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确认起点不是计划**
   - 完成标准: 用户接受"先测量再管理"，并同意暂缓做新的计划表/待办系统；若用户坚持先要计划，先说明计划落空的两个原因（时间属于别人、估计不可靠），再回到本步骤。

2. **建立记录规范**
   - 动作: 用最轻的方式（纸、文档、计时器均可）在**当时**记录，不补记；连续三四个星期为一个时段，每天记；一年安排两三个时段。
   - 完成标准: 用户能说出"何时记、记多久、一年几轮"，并开始第一轮；记录里包含"用途类别"而非只有时长。

3. **加入周期复检**
   - 动作: 每个时段结束后对照一次，标记"与我原来的估计差在哪儿"。
   - 完成标准: 每轮至少产出一处"估计 vs 实际"的显著差异。
   - 判停条件: 若用户无任何时间自主权，改用 B 段替代动作（碎片式记录、只记录不受控时段），并明确记录的目的是找可改的一小块，而不是自我谴责。

4. **把样本交到分析环节**
   - 动作: 提醒三步的后两步，并按需要转交：逐项筛除 → `time-diagnosis-questions`；制度病灶 → `time-waste-institution-scan`；整块时间 → `consolidate-free-time`。
   - 完成标准: 样本有明确的下一步去向，且已约定重做记录的时点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已有一份可分析的记录，要的只是"怎么砍"或"怎么合并整块"——直接进入对应 skill，别重复讲记录规范。
- 记录被用作监控/考核工具（对下属或对伴侣）：这不是本方法的用途，且会摧毁"敢说真话"的前提。
- 用户要求工具选型（推荐 App）或日程排版：本 skill 给的是采样规范，不是工具清单。

### 作者在书中警告的失败模式

- **凭记忆管理时间**（ce03）: 用估计代替记录。人会把"应该花时间的工作"记成"已花时间的工作"；高管对"自己能支配一半时间"的自信，实测通常只剩约 1/4。
- 把时间记录做成一次性的仪式：记录的目的是被分析并被反复重做（"对时间的控制与管理不能一劳永逸"），半途而废等于没有。

### 作者的盲点 / 时代局限

- **秘书与助手假设**: 1966 年语境默认管理者有秘书代记（第 8 章："时间的记录，并不一定要由管理者本人自己动手，最好是交由秘书或助手来做"，L1904）。无秘书的当代工作者须自行简化并坚持。
- **无时间自主权岗位的替代动作（强制声明）**: 对护理、客服、流水线、外卖、育儿等时间已被他人排满的岗位，本方法退化为"只记录能自主的那一小段 + 不做自责式结算"；不要把"记录—削减—集中"整套动作套上去，否则只会带来挫败。
- **技术前提过时**: 无远程办公、无即时通信语境。即时消息把"时间属于别人"这一命题变得更真，但也让"不被中断的记录与整块"更难获得；需要自己设计采样方式（如只记"被打断次数"）。
- **证据等级**: 心理学实验与董事长案例均为转述与轶事级证据，无对照实证；采样频率（3–4 周、一年 2–3 次）是经验建议，非统计结论。

### 容易混淆的邻近方法论

- 番茄钟/时间块（time blocking）/日历审计类工具: 它们管理的是"打算做的事"或自动采集的屏幕行为；德鲁克要的是工作发生当时的**用途样本**，且用途类别比时长更重要。
- GTD 的"收件箱与下一步行动": 属于任务流程管理，不处理"时间实际流向"。
- 绩效工时统计（考勤/工时表）: 为考核而记，本方法为自我诊断而记，两者的记录者动机与用途正相反。

## 相关 skills

本 skill 是时间链的起点：记录产出是下游三项动作的共同原料。`time-diagnosis-questions` 与 `consolidate-free-time` 依赖本 skill 的记录产出（在它们的文件中记为 depends-on）；本文件按"先后配套"记为 composes-with。

**depends-on**（使用前提）: 无 — 时间链从本 skill 开始；整体诊断路径上服从 `effectiveness-five-habits` 的路由。

**contrasts-with**（同境况二选一）: 无 — 与下游三项是接力而非二选一。

**composes-with**（配合使用/先后接力）:

- `effectiveness-five-habits` — 总纲把"采集时间"定为第一个动作，具体记录规范由本 skill 给出。
- `time-diagnosis-questions` — 记录到手后的下一步：逐项过"不做会怎样 / 能否代做 / 在浪费谁的时间"三问（它依赖本 skill 的产出）。
- `time-waste-institution-scan` — 另一条去向：若怀疑是制度病灶（重复危机、会议 1/4、人员 1/10），记录即检修证据。
- `consolidate-free-time` — 三步总纲的第三步：用记录估算自由时间总量，再把零碎时间并成整块（它依赖本 skill 的产出）。
