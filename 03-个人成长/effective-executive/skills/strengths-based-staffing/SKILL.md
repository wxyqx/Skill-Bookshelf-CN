# 用人所长四原则（职位设计 → 择人 → 容忍短处）

## R — 原文 (Reading)

> "1.卓有成效的管理者不会将职位设计成只有上帝才能胜任。职位必须由人来担任，是人都可能犯错。……一个职位，如果先后由两人或三人担任都失败了，这就肯定是一个常人无法胜任的职位，这个职位就必须重新设计。"
>
> — 第4章，L1042、L1048

> "有效的管理者从来不问：'他能跟我合得来吗？'他们问的是：'他贡献了什么？'他们从来不问：'他不能做什么？'他们问的是：'他能做些什么？'"
>
> — 第4章，L1004

> "不管是谁，如果他在任用一个人时只想避免短处，那他所领导的组织最终必然是平平庸庸的。……才干越高的人，其缺点也往往越多。有高峰必有深谷。"
>
> — 第4章，L996

---

## I — 方法论骨架 (Interpretation)

德鲁克把"用人"的默认方向整个倒转：不是补短板、不是找完人、不是改造人，而是**发现并运用长处，同时让短处不产生作用**。理由有两层——人的卓越天然是单点的（才干越高缺点越多，"有高峰必有深谷"），而人的短处几乎不可改变；组织存在的价值恰恰是"把个人的长处变成生产力，同时屏蔽其短处"。

据此有四条原则，按用人顺序排列：

1. **职位为常人设计**。职位要由人来担任，人都会犯错；若先后两三人上任都失败，那是职位设计的问题，必须重设，而不是去找天才来坐。按"非常人物"的气质定岗，只会得到"坑人的职位"。
2. **要求严、涵盖广**。严=对才干构成挑战；广=能把与任务有关的优势转化成成果，并在职位要求变化时仍有适应余地。涵盖过窄的职位会冻结年轻人的热情，也无法让人及早检验自己是否适合。
3. **先看此人能做什么**，而不是先看职位说明书。评估以绩效与长处为重心；对能力的说法必须具体到"能否完成某项任务"，不笼统说某人是个"能人"。同时"重视长处"意味着对绩效提出要求——真正懂用人的上司往往是"苛求"的上司。
4. **容忍短处**，且用组织手段使其不产生作用（第一流的税务会计不指派去当经理，让他自设办公室；小企业家式的人才在合适规模的组织里才有产出）。配套边线：提升只给经得起绩效考验的人；听到"少不了某人"就应尽快调职（那通常意味着某人不行、或主官不行、或掩盖了严重问题）；不称职者应调职，且任命者要负责为他找到合适的岗位。

最后一条贯穿全局：管理者的任务不是改变人，而是运用每一个人的才干。

## A1 — 书中的应用 (Past Application)

### 案例 1: 林肯的两段教训——从"无缺点"将领到格兰特

- **问题**: 南北战争前期，林肯先后选用三四位将领，标准都是"必须无重大缺点"；虽北军拥有人力物力绝对优势，1861–1864 年却毫无进展。相反，南方李将军手下的将领"几乎没有一位不是满身都是大小缺点"，但李将军善用各人之长。
- **方法论的使用**: 林肯由此转向"求其人能发挥所长，而不求其人是个'完人'"。当有人告格兰特嗜酒难当大任时，林肯回答："如果我知道他喜欢什么酒，我倒应该送他几桶，让大家共享"——他并非不知酗酒可能误事，而是知道北军将领中只有格兰特能运筹帷幄。
- **结论**: 用人时只想避免短处，组织必然平平庸庸；"所谓'样样皆通'，实际上可能是一无是处"。
- **结果**: 林肯麾下每一位"无缺点"的将领，一个一个都被李将军手下拥有"一技之长"的将领击败；而格兰特的受命"正是南北战争的转折点"。

### 案例 2: 马歇尔——无名将官的提拔、巴顿的辩护与"不称职即调职"

- **问题**: 1930 年代中期，美国陆军几乎没有堪当重任的年轻将官；同时军中对不称职的主管常以"找不出继任人选"为由拖延处置。
- **方法论的使用**: 马歇尔用人只自问"此人能做些什么"：二战期间经他提拔、后来升为将级军官的多是当时籍籍无名的年轻将官（艾森豪威尔在 1930 年代还只是少校）。他反复为巴顿辩护——不因"缺少做幕僚应有的气质"而否认他是一位优秀将军；又不是完全不顾弱点：把年轻的艾森豪威尔安插到作战计划部门，让他补上战略知识的短板。对不称职者，他的立场是立即调职，且"某人不称职，只是不称'此'职……选派某人出任这个职务，是我的错误，我应该负责再给他找到适合的工作"。
- **结论**: 用人是"抓住某人长处"的合理赌注；对人短处的处理方式不是改造他，而是用工作与职位机会帮他绕开或补上。
- **结果**: "经他提拔的将领，几乎无人失败，而且他们都是第一流的人才。"他以原则提拔人才，被写成美国军事教育史上最辉煌的一页。

### 案例 3: 日本管理界的对话——因不能开除，所以只看人之所长

- **问题**: 德鲁克在日本主持管理发展研讨会时，发现日本大企业根本没有考评制度。
- **方法论的使用**: 日本高层的解释是："你们的考评制度，目的只是发现一个人的错误和弱点。但在我们日本，由于不能因为某人有缺点而把他开除或降级，我们自然对考评制度不感兴趣了。……我们想知道的，是他有什么优点，他能做些什么。"终身雇用使管理者被迫"闭上眼睛，不看人的缺点"。
- **结论**: 德鲁克并不完全同意日本制度（"大多数的人都将成为公司的负担"），但他主张西方应学其精神：见人之所长和用人之所长。
- **结果**: 该对话成为他批判西式"医生找毛病式"考评的起点，并直接引出绩效考评四问。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某个职位连续两三位任职者都失败，组织在讨论"是不是还要再找更强的人"。
2. 团队里有一位产出极高但脾气差/不服管的能人，其他人快受不了了。
3. 用户要任命或提拔一个人，讨论集中在候选人的缺点清单与"他是不是自己人"上。
4. 有人被说成"少不了他，离了他不行"，或某岗位长期无法轮换。
5. 用户想为一个特殊人才新设职位（因人设事），需要判断是否越线。

### 语言信号 (用户的话里出现这些就应激活)

- "他能力是强，但毛病太多/不好管"/"he's brilliant but impossible to manage"
- "我们已经换了三个人都没做成，是不是该找个更厉害的"
- "这人不够全面/没有短板吗"/"is he well-rounded"
- "少不了他 / 离了他不行"/"we can't do without him"
- "要不要给他专门设个岗"/"should we create a role for him"

### 与相邻 skill 的区分

- 与 `appraisal-four-questions` 的区别: 本 skill 管任命与职位设计的四原则；一旦进入具体面谈评估，用那套四问（前三问看长处，末问是正直否决）。
- 与 `manage-your-boss` 的区别: 本 skill 的下属/同事/上司中虽都覆盖，但"如何向上司提建议"的完整方法在那边。
- 与 `use-your-own-strengths` 的区别: 那边是把同一逻辑用于自己（工作习惯、长处盘点）；本 skill 用于对他人的人事决策。
- 与 `one-thing-at-a-time` / `priority-and-posterior` 的区别: 那些管事的选择；本 skill 管人的配置。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先查职位，不先查人（原则一）**
   - 动作: 若该职位已有两人或三人失败，暂停"另找能人"，检查职位设计：是否按某位非常人物的气质定制、是否内含互相冲突的性格要求。
   - 完成标准: 给出判断——职位需要重设，或职位本身合理（此时才进入择人）。
   - 判停条件: 若判定为职位问题，跳到步骤 5 输出重设方案。

2. **检查"严与广"（原则二）**
   - 动作: 看职位要求是否对才干构成挑战、涵盖是否足以把优势转化为成果、是否能让人在情况变化时仍适应。
   - 完成标准: 得出"要求够严/过宽"与"涵盖够广/过窄"的判断；对过窄职位给出扩展方向（避免冻结年轻人）。

3. **只看此人能做什么（原则三）**
   - 动作: 用"他在某方面是否确有长处？此长处是否确为任务所需？他担当此任务是否能表现得与众不同？"三问筛选；把评价落到具体任务（"他在完成某项任务方面是个能人"），不笼统谈"能人"；不看"是否合得来/是否顺从"。
   - 完成标准: 有一条与任务绑定的长处判断及其证据（过去的绩效事实）。
   - 判停条件: 若问不出任何与任务相关的长处，跳过该候选人，不做"或许能培养"式的赌注。

4. **容忍短处 + 设计屏蔽（原则四）**
   - 动作: 承认短处不可改变，改为**职位安排**使短处不产生作用（不让他带团队、允许自设工作方式、调整汇报关系）。同时检查两条边线：提升是否只给经得起绩效考验的人；是否出现"少不了某人"信号（三种坏原因之一，应尽快调职）。
   - 完成标准: 有一条具体的"使短处不产生作用"的安排；对人选给出"提升/调职/留任"的明确判断。
   - 判停条件: 若短处正好是该任务的核心能力（会直接破坏成果），则不是"容忍"问题，应另选人或重设职位。

5. **收束：写下任命依据与后续责任**
   - 动作: 记录这次任命的赌注是什么（长处假设），并写明三个月/半年后如何验证；若不称职，责任是"再给他找到适合的工作"，而非放任其留任——人事处置须依当地劳动法规与组织程序执行。
   - 完成标准: 有可复查的长处假设与验证时点；对处置动作有合规声明。
   - 判停条件: 若在任一环节出现正直问题（不诚实、以权谋私），跳过全部"长处/短处"权衡，按资格问题处理（参见 `appraisal-four-questions`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把人当可改造对象：本 skill 明确"管理者的任务不是改变人"，不适用于设计改变性格与缺点的培养计划。
- 在人事处置上跳过程序：调职、免职、降级须依当地劳动法规与组织程序；德鲁克的"无情调职"是管理判断，不是绕过程序的授权。
- 用于规避组织的公平义务：若"短板"实际是资源不足、培训缺失或结构性不平等造成的，用"短处不可改变"解释会掩盖组织责任。

### 作者在书中警告的失败模式

- **择人只求避免短处 → 组织必然平庸**（ce14）: 以"无重大缺点"为标准选人（林肯早期将领、只求"最不至于出差错"的候选人），拥有人力物力优势仍节节失败。
- **见人之短的人本身是弱者；因人设事**（ce15）: 把下属才干视为威胁而不用能人；为解决"职位不就人"而因人设事，"必将产生恩怨派系"（例外仅限凯特林/霍普金斯级的特殊天才）。
- **职位设计不当（坑人的职位）**（ce16）: 同一职位连续两三位任职者都失败，要求里含互相冲突的性格要求。
- **"少不了某人"**（ce18）: 三个坏信号之二三——主官靠某人才干勉强支撑、或该人掩盖着某项严重问题；处理办法是尽快调职。
- **留着不称职者**（ce19）: 以"人情"或"找不到继任者"保留已被证明不胜任的主管，对下属尤为不公（"主管无能，则不啻剥夺了下属发挥长处的机会"）。

### 作者的盲点 / 时代局限

- **高管视角（强制声明）**: 案例全部来自总统、将军、公司总裁级人事决策；对中层与基层，"重设职位"或"另找岗位"的权力往往不存在，需要把动作降级为"在可控范围内调整分工与汇报关系"。
- **日本终身雇用案例的浪漫化**: 德鲁克本人也承认"我也并不完全同意日本的办法……大多数的人都将成为公司的负担"，但仍以它作范例；该论据依附于 1960–90 年代日本雇用制度，只作历史语境引用，不作规范主张。
- **性别角色化石**: 本章人事案例中的被用人一律为男性（将领、副总裁、研究员），女性角色缺席；人事决策语言（"我有个儿子或女儿"是少见的例外）带有 1966 年语境。
- **"人员流动性"前提**: 全书以美国式雇用流动性为默认背景；在长期雇用、公职、家族企业等环境下，"调职再找合适岗位"的空间不同。
- **证据等级**: 全部为轶事与转述（林肯、马歇尔、日本对话），无对照实证；"几乎无人失败"属事后归纳，存在幸存者偏差。

### 容易混淆的邻近方法论

- 胜任力模型/人才盘点九宫格: 以能力项与潜力评级为中心；本 skill 明确反对评估"潜能"，且判据是任务绑定的绩效事实。
- 教练式管理/绩效改进计划（PIP）: 以改变行为为目标；本 skill 的默认方向相反——先找能做的事，再用职位安排让短处不产生作用。
- "因材施用"/因人设事（中文语境的褒义用法）: 常被当作人性化管理的体现；德鲁克视其为组织陷阱（仅对极少数特殊天才有例外）。
