- id: f01
  title: 影响圈与关注圈
  type: framework
  source_chapter: 第三章（习惯一）·关注圈与影响圈
  source_quote: |
    "积极主动的人专注于'影响圈'，他们专心做自己力所能及的事，他们的能量是积极的，能够使影响圈不断扩大。
     消极被动的人则全神贯注于'关注圈'……造成了影响圈日益缩小。"
  summary: |
    把一切事务划入两个同心圆：影响圈（我能直接掌控的言行与决定）与关注圈（我关心但无法掌控的他人与环境）。
    判断标准是观察时间和精力的投放位置：投向影响圈，圈会扩大；紧盯关注圈（他人弱点、环境问题），圈会缩小。
    用于任何"感到无力/受制于人"的处境诊断，先做圈层归位再行动。
  tags: [mental-model, agency, diagnosis]

  title: 刺激与回应之间的距离（选择的自由）
  type: framework
  source_chapter: 第三章（习惯一）；后记"答读者问"；第十一章
  source_quote: |
    "在遭遇（刺激）与对遭遇的回应之间，他有选择回应方式的自由或能力。"
    "刺激与回应之间存在一段距离，成长和幸福的关键就在于我们如何利用这段距离。"
  summary: |
    人不是"刺激—回应"的自动机：刺激与回应之间存在一段距离，人可以在其中调用四种独有天赋——自我意识、想象力、良知、独立意志——来决定回应。
    该模型把"情绪反应"重构为"被动选项"，把"主动回应"重构为"经过距离的处理"。
    后记进一步给出该习惯的进阶刻度（注意到距离→选择→回应→请求原谅→……→根本不动气）。
  tags: [mental-model, agency, emotion]

- id: f03
  title: 两次创造（心智创造先于实体创造）
  type: framework
  source_chapter: 第四章（习惯二）·任何事物都需要两次创造
  source_quote: |
    "我们做任何事都是先在头脑中构思，即智力上的或第一次的创造，然后付诸实践，即体力上的或第二次的创造。
     许多企业都败在第一次创造上——事先缺乏明确目标。"
  summary: |
    一切成果都要经过两次创造：第一次在头脑（愿景/蓝图/目标），第二次在现实（执行/施工）。
    推论：跳过第一次创造直接动手，执行得越快错得越远；"人生剧本"若未经自己有意识地第一次创造，就是被环境和他人代写的。
    用于启动任何项目、角色或人生转型前，先检查"第一次创造做过了没有"。
  tags: [mental-model, planning, leadership]

  title: 领导先于管理（做正确的事 vs 正确地做事）
  type: framework
  source_chapter: 第四章（习惯二）·领导与管理：两次创造
  source_quote: |

  summary: |

    用于判断个人或组织的处境：是在高效地爬梯子，还是先确认梯子搭对了墙。
  tags: [decision-framework, leadership, prioritization]

- id: f05
  title: 产出/产能平衡（金蛋与鹅）
  type: framework
  source_chapter: 第二章（概论）·效能的定义；第六章；第十章
  source_quote: |
    "真正的效能应该包含两个要素：一是'产出'，即金蛋；二是'产能'——生产的资产或能力，即下金蛋的鹅。
     重蛋轻鹅的人，最终会连这个产金蛋的资产也保不住。"
  summary: |
    效能=产出（P）与产能（PC）的平衡，适用于物质、金融、人力三类资产。
    结构性地识别一切"透支式失败"：为金蛋杀鹅（压榨业绩/信任/健康）或守鹅不取蛋（只养不产出）都是低效能。
    人际关系中的产能即信任（情感账户），身体即个人产能（习惯七）。
  tags: [mental-model, effectiveness, balance]

- id: f06
  title: 时间管理矩阵（四象限）
  type: framework
  source_chapter: 第五章（习惯三）·别让琐事牵着鼻子走
  source_quote: |
    "第二象限事务包括建立人际关系、撰写使命宣言、规划长期目标、防患于未然等等。人人都知道这些事很重要，
     却因尚未迫在眉睫，反而避重就轻。"
  summary: |
    按"重要/紧急"两轴把活动分为四象限：I 危机（重要且紧急）、II 重要不紧急（产能建设）、III 紧急不重要（常是别人的要事）、IV 不重要不紧急（逃避）。
    核心机制：多投 II 会减少 I 的数量；盯着 III 的人自以为在忙 I。
    用于解释"越救火越忙"的结构，并把精力从救火转移到防火。
  tags: [decision-framework, time, prioritization]

  title: 情感账户
  type: framework
  source_chapter: 第六章（人际关系的本质）
  source_quote: |
    "情感账户里储蓄的是人际关系中不可或缺的信任，是人与人相处时的那份安全感。

    用于关系问题的统一诊断：先查余额，再谈方法。
  tags: [mental-model, relationship, trust]

  title: 人际交往六模式
  type: framework
  source_chapter: 第七章（习惯四）·人际交往的六种模式
  source_quote: |
    "利人利己（双赢）●两败俱伤（输/输）●损人利己（赢/输）●独善其身（赢）●舍己为人（输/赢）●好聚好散（无交易）。"
  summary: |
    把一切交往结果分为六种模式，并给出各模式的来源与代价：赢/输来自家庭比较与学校排名的浸染；输/赢是老好人的压抑；输/输是报复的自杀式结局。
    判据：在相互依赖的长远关系中，非双赢终将两败俱伤；无交易（好聚好散）是双赢不可得时的合法出口。
    用于识别自己惯用的隐性模式，尤其"嘴上双赢、心里赢输"的错位。

- id: f14
  title: 先诊断后开方（移情聆听四阶段）
  type: framework
  source_chapter: 第八章（习惯五）·先诊断，后开方；有效的沟通
  source_quote: |
    "第一阶段是复述语句……第二阶段加入解释……第三阶段掺入个人的感觉……第四阶段是既加以解释，又带有感情，左右脑并用。"
  summary: |
    沟通程序：先诊断（理解对方的问题与情绪）后开方（给出建议），像医生一样——未经诊断就给眼镜/药方，是多数沟通失败的结构。
    操作分四阶段：复述语句→加入解释→掺入感觉→解释+感情，用后既理解对方又帮对方认清自己。
    前置纪律：识别并暂停四种自传式回应（价值判断/追根究底/好为人师/自以为是）。
  tags: [decision-framework, communication, listening]

  type: framework
  source_chapter: 第九章（习惯六）；第七章
  source_quote: |
    "低层次的沟通源自低信任度……中间一层是彼此尊重……统合综效意味着1+1等于8或16，甚至1600。

    冲突的出口不是"你的方案 vs 我的方案"，而是双方共创的第三选择；其先决条件=情感账户充足+双赢模式+先理解别人。
    精神内核是尊重差异："相同不是统一，统一和团结意味着互补。"
  tags: [mental-model, conflict, creativity]

- id: f18
  title: 责任型授权五要素
  type: framework
  source_chapter: 第五章（习惯三）·授权——高效能的秘诀
  source_quote: |
    "责任型授权的关注重点是最终结果。……预期成果……指导方针……可用资源……责任归属……明确奖惩。

  summary: |

    效果是杠杆放大（1 小时产生 10-100 倍成果）并培养对方的责任感；信任是前提也是产物。
    适用于育儿、管理与任何"自己干不如教人干"的两难。

- id: f21
  title: 习惯 = 知识 × 技巧 × 意愿
  type: framework
  source_chapter: 第二章（概论）·"习惯"的定义
  source_quote: |
    "本书将习惯定义为'知识''技巧'与'意愿'相互交织的结果。知识是理论范畴，指点'做什么'及'为何做'；

  summary: |
    把习惯拆解为三个正交成分：知识（what/why）、技巧（how）、意愿（want），任一为零则习惯不成。
    用于诊断"知道却做不到"卡在哪一项：不懂（知识）、不会（技巧）、不想（意愿）对应完全不同的干预。
    三者均位于影响圈内，都可主动投资。

  title: 转型者（代际行为模式的改写）
  type: framework

  source_quote: |
    "在你的家族中已经延续数代的趋势可以在你这里画上一个句号。你是一个转型者，连接着过去和未来，

  summary: |
    行为模式会代际遗传（虐待、冷暴力、消极脚本），但积极主动者可以成为"转型者"：识别继承的模式→有意识改进→不再传给下一代。
    "根和翅膀"：给孩子根（家族认同）与翅膀（摆脱消极遗传的自由）。
    用于家庭议题——把自己定位为链条上的断点或续点。
