# 人际交往六模式（Six Interaction Modes）

## R — 原文 (Reading)

> "双赢不是什么技巧，而是人际交往的哲学，是六个交往模式之一，这六个模式分别是：利人利己（双赢）、两败俱伤（输/输）、损人利己（赢/输）、独善其身（赢）、舍己为人（输/赢）、好聚好散（无交易）。"
>
> — 史蒂芬·柯维，第七章·人际交往的六种模式（fulltext.txt L4942-4952）

> "长远来看，不是双赢，就一定是两败俱伤，所以我们才说，只有双赢才是在相互依赖的环境中唯一可行的交往模式。"
>
> — 史蒂芬·柯维，第七章·哪一种最好（fulltext.txt L5048）

> "最好的选择必须依情况而定，关键是认清形势，不要教条地把某一种模式应用于每一种情况。"
>
> — 史蒂芬·柯维，第七章·哪一种最好（fulltext.txt L5038）

## I — 方法论骨架 (Interpretation)

把任何一次交往的结果分成六种模式，并给每种模式找到它的人格养成来源：

- **赢/输**（损人利己）：靠地位权势取胜。来源是家庭比较、学校排名、运动零和叙事、法律对抗的长期浸染——爱被附加条件后，自我价值只能靠比较实现。
- **输/赢**（舍己为人）：老好人，没标准没要求，以取悦换认同。它是赢/输的生存土壤；压抑的愤怒最终以更丑恶的方式爆发，且自我评价日趋低落。
- **输/输**（两败俱伤）：两个赢/输相遇、谁也不服，宁可自损也要报复——"谋杀等于自杀"。
- **独善其身**（赢）：别人输赢无所谓，只求自己得偿所愿；在竞争与对抗意义不大时是多数人的默认。
- **双赢**（利人利己）：把生活当合作台而不是竞技场。
- **无交易**（好聚好散）：双赢不可得时商定放弃，是一种宝贵的自由。

两个判据：在相互依赖的**长远**关系中，非双赢终将两败俱伤；模式的选择依情况而定，不可教条。成熟（敢作敢为与善解人意的平衡）决定一个人落在哪个模式上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 连锁商店总裁的"假双赢"
- **问题**: 总裁抱怨"双赢太理想化，商场现实无情"，称自己与商场业主谈租约时开诚布公却被当成冤大头。
- **方法论的使用**: 柯维追问："可你们为什么要选择输/赢模式呢？"总裁否认；柯维逐条指出其报价与谈判结构实际是让对方输——"那这不是输/赢模式是什么？"
- **结论**: 总裁意识到自己所谓的双赢实质是输/赢模式，非常震惊；长期效应是"平静的关系下面涌动着的是压抑的情感，被践踏的价值和隐藏的怨恨，最终将导致两败俱伤"。
- **结果**: 柯维给出替代路径——若真抱双赢态度，就多交流、听取意见并有勇气表达观点，直到结果让双方都满意（第三条道路）。

### 案例 2: 一万美元汽车以五十美元卖出
- **问题**: 一对夫妻离婚，法官要求丈夫将出售资产所得的一半分给妻子。
- **方法论的使用**: 用输/输模式解释其行为——丈夫把价值一万美元的汽车以五十美元出售，分给妻子二十五美元，并廉价出售了所有财产。
- **结论**: "为了报复，不惜牺牲自身的利益，却不问是否值得；只有不够成熟、掌握不了人生方向的人，才会这样。"
- **结果**: 报复是双刃剑，双方皆为输家；此例成为输/输模式的标准注脚。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 观察到自己或关系中的固定姿态：总在退让取悦（输/赢）、总要争个高下（赢/输）、互相拆台报复（输/输）、懒得理会他人（独善其身）。
2. 判断一场具体冲突的性质：对方得寸进尺、老好人突然翻脸、争端早已与利益无关只想扳回一局。
3. 孩子宁可输也不肯参与竞争，或"必须比过别人才有价值"——定位其被家庭比较/学校排名训练出的模式。
4. 自己嘴上说"双赢"，实际一路让步或一路占上风——识别名实不符。

### 语言信号 (用户的话里出现这些就应激活)

- "我是不是太软了 / 总是让着他 / 都听他的 / 老好人"
- "他得寸进尺 / 我就是咽不下这口气 / 我不好过也不让你好过"
- "他什么都想赢 / 一定要争个输赢 / 见不得别人好"
- "孩子不肯竞争 / 宁愿弃赛 / 这算双赢吗 / win or lose"

### 与相邻 skill 的区分

- 与 `win-win-five-dimensions` 的区别: 六模式做**识别与定性**（这次交往是什么模式、这个人默认什么姿态）；五要领做**结构与修复**（双赢推行卡在哪一层）。典型顺序：先定性，再决定是否值得进入五要领。
- 与 `win-win-or-no-deal`（p19）的区别: "好聚好散"本身是六模式之一；p12/p19 那个 skill 专讲何时以及如何行使退出权（含家族/友谊生意的退出条款），本 skill 只负责识别"当前处境属于哪个模式"。
- 与 `emotional-bank-account`（f08）的区别: 账户诊断关系的信任余额（介质问题）；六模式诊断交往的结果结构（姿态问题）。余额影响模式选择，但两者变量不同。

## E — 可执行步骤 (Execution)

1. **给本次交往/这段关系定性**
   - 完成标准: 从六模式中说出一个模式名，并给出至少一条行为证据（不是贴标签，而是引用具体言行）。
2. **追溯模式来源**
   - 完成标准: 指出该姿态可能的养成来源（家庭比较/学校排名/运动/法律对抗）至少一个；确实无法判断时明确说"来源不明"，不强行归因。
3. **检查勇气/体谅两轴**
   - 完成标准: 定位失衡方向——敢作敢为不足→滑向输/赢；善解人意不足→滑向赢/输；两轴皆弱→输/输或极端依赖。
4. **决定去向**
   - 完成标准: 明确三选一的下一步——(a) 关系是相互依赖的长远关系且值得投入→转入双赢五要领构建结构；(b) 双赢不可得→用好聚好散设计退出；(c) 一次性、无后续的场合→独善其身合法，不必强求。
   - 判停条件: 若识别出对方是深度赢/输且关系无后续价值，直接选 (c)，不要投入"改造对方"。
5. **对"名实不符"做对照陈述**
   - 完成标准: 若用户自称双赢，给出"你实际在用的模式是 X"的对照证据（连锁总裁式反馈），并说明长期后果。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 真正的零和竞技场（体育比赛、竞标、拍卖）——书中明确承认"在竞争激烈和信任薄弱的环境里，我们需要赢/输模式"；对这些场合强推双赢是教条。
- 紧急避险场景（孩子面临生命危险时"拯救高于一切"）——书中自己的例外。
- 把一切竞争上纲上线为"赢/输病态"——竞争"在生活中只居少数"，但存在且合法。

### 作者在书中警告的失败模式

- **赢/输的四大浸染源**: 家庭比较、学校正态分布、运动零和叙事、法律对抗不断训练"我赢=你输"（ce11）。
- **输/赢老好人的压抑与爆发**: 被压抑的情感累积后以更丑恶的方式爆发，主管与家长在两模式间摆荡——纪律松时强硬、内疚后纵容、再愤怒再强硬（ce12）。
- **输/输式报复**: 一万美元汽车五十美元卖掉；报复是双刃剑（ce13）。
- **以双赢之名行让步之实**: 缺勇气的"双赢"实际是输/赢（ce24）。

### 作者的盲点 / 时代局限

- 权力不对等被处理成个体品德课题：书中的处方（补勇气、换心态）对制度性弱势（劣迹雇主、歧视环境）可能失效；柯维甚至提醒法律手段"只应在最后关头发挥作用"，系统性救济被边缘化。
- 六模式的"长远看非双赢即双输"依赖"长远"这个词，但未给出时间尺度——品德高尚而失败、赢/输者长久成功的反例书中未处理。
- "非双赢即两败俱伤"是原则中心论的断言，其验证方式是循环的（凡持久的都被算作原则），在书内不可证伪。

### 容易混淆的邻近方法论

- 托马斯-基尔曼冲突五策略（竞争/回避/迁就/妥协/协作）——分类学上高度相似；柯维的增量是模式来源（家庭/学校/运动/法律）与品德判据（勇气×体谅），且把"无交易"纳入家庭哲学。
- 谈判学的零和/正和博弈——只分博弈结构，不分人格养成来源。
- 讨好型人格等心理学描述——只描述输/赢一端，无六模式全景与去向判断。
