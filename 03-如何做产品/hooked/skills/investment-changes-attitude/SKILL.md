# 投入改变态度的三心理机制

## R — 原文 (Reading)

> "我们对事物的投入越多，就越有可能认为它有价值，也越有可能和自己过去的行为保持一致。最后，我们会改变自己的喜好以避免发生认知失调。"
>
> — 第5章 投入改变态度（L1621）

> "结果表明，自己动手折纸的人对自己作品的价值评估是第二组价值评估的5倍……付出过劳动的人会给自己的折纸作品附加更多的价值，阿雷利将这种现象称为'宜家效应'。"
>
> — 第5章 我们总会高估自己的劳动成果（L1583）

> "我们的这类倾向会导致一种被称为'文饰作用'的心理过程，这一心理过程会令我们改变自己的态度和信念，从心理上进行调适。"
>
> — 第5章 我们总会避免认知失调（L1623）

---

## I — 方法论骨架 (Interpretation)

习惯的最后一环不是产品再给用户什么，而是用户往产品里放什么——而放进去的东西会反过来改写用户的态度。这条"投入→态度"链靠三个被实验反复证实的心理趋势驱动，且三者各有各的设计杠杆：宜家效应（让用户动手造，自己折的纸鹤估值是旁观者的 5 倍——劳动带来非理性偏爱）；行为一致性（先要一个小承诺，两周前贴过 3 英寸小标识的居民，76% 同意立起难看的大牌子，直接请求只有 17%——过去的微小行为预知未来行为）；避免认知失调（人会给已付出的成本找理由，"这 20 美元花得值，因为我已经为此花了时间"——狐狸把够不着的葡萄说成酸的）。

三者汇成的总效应叫文饰作用：**投入让用户自己说服自己**，比任何营销话术都便宜且牢固。使用时的分寸在于：三条机制是三条独立的设计杠杆——想让用户珍视成果就给他动手的机会，想促成大行动就先铺小承诺，想让它持久就要允许用户保留自我合理化的空间。注意本机制解释"为什么投入有效"，至于投入该在何时提出、拆多细，以及沉淀成哪类资产，分别由相邻单元处理。

## A1 — 书中的应用 (Past Application)

### 案例 1: 折纸实验与"小心驾驶"立牌实验
- **问题**: 投入真的会改变估值与后续行为吗？机制是什么？
- **方法论的使用**: 作者引两组实验：折纸实验让自折者与旁观者对同一作品竞投，测量宜家效应；立牌实验把"立大牌子"的大请求拆成"先贴 3 英寸小标识"的小请求，测量一致性的承诺放大。
- **结论**: 自折纸鹤估值是旁观组的 5 倍；小承诺使大请求的接受率从 17% 升至 76%——"那些微不足道的点滴投入，有可能导致未来行为发生巨大的变化"。
- **结果**: 两个实验成为第 5 章投入阶段的心理机制基础（L1579–1604），支撑"试用设计的目标是投入而非曝光"的处方。

### 案例 2: 谢尔评"黑手党战争"玩家的合理化
- **问题**: 玩家为何为一款文本网络游戏持续掏钱？
- **方法论的使用**: 游戏设计师杰西·谢尔复述玩家的心理过程：先承认游戏简陋，但"我已经为此花费了时间"，于是 20 美元"肯定物有所值，因为只有白痴才会白掏 20 美元"。
- **结论**: 这是文饰作用的现实展示——玩家为已付出的时间与金钱辩护，唯一的解决办法是继续投入。
- **结果**: 该例同时成为伦理警示素材：机制真实有效，但被 Zynga 用于榨取付费（L1625–1633），与第 6 章操纵矩阵的批评相呼应。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 试用/免费期转化设计：试用期该让用户"做点什么"才能提高付费转化，而不是只让他们看功能演示。
2. Onboarding 设计：新用户走完引导就流失，需要用早期投入建立"这是我的东西"的所有权感。
3. 态度与行为背离的解读：用户评价产品"一般"却持续使用，或轻量试用后立刻离开——判断投入链条断在哪。
4. 个人习惯养成：健身打卡、写日记、手账、整理房间——用小投入改变自己对这件事的态度。

### 语言信号 (用户的话里出现这些就应激活)

- "让用户有参与感 / 自己做出来的 / 所有权感"（sense of ownership, co-creation, user investment）
- "宜家效应 / 沉没成本 / 投入改变态度"（IKEA effect, sunk cost, investment changes attitude）
- "试用期怎么提高转化 / 免费用户该先让他做什么"（trial-to-paid conversion, what should users do during trial）

### 与相邻 skill 的区分

- 与 `f15-five-stored-values` 的区别：f14 是投入改变态度的**心理机制**（为什么用户会高估自己造的东西），f15 是投入沉淀的**资产清单**（沉淀成内容/数据/关注者/信誉/技能）。同一枚投入硬币的两面：一在心理，一在资产。
- 与 `f17-investment-timing-granularity` 的区别：f14 回答"投入为什么有效"，f17 回答"投入该在什么时候提出、拆到多细"（酬赏之后、小步开始）。设计 onboarding 时先有时机粒度规则，再谈机制加成。
- 与 `f12-three-variable-rewards` 的区别：f12 是产品给用户的反馈（酬赏），f14 是用户给产品的付出（投入）——方向相反，且行动求即时满足、投入期待长期回报（g14）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确希望改变的态度或行为**
   - 完成标准: 一句话写清目标（如"试用用户在付费前对产品形成'这是我的工作台'的所有权感"）。目标含糊则不进入机制设计。

2. **设计"动手造"机会（宜家效应）**
   - 完成标准: 至少安排一个用户亲手产出、可被看见的对象（建一个项目、写第一条笔记、配置一个面板）；产成品有个性化痕迹，不是系统自动生成。

3. **铺小步承诺链（行为一致性）**
   - 完成标准: 把目标行为拆成至少两级的承诺阶梯，第一级成本极低且几乎必然被接受（贴小标识级别），第二级指向真实的转化动作（付费/立大牌级别）；级差与间隔合理。

4. **保留自我合理化空间（文饰作用）**
   - 完成标准: 检查流程没有打断用户"为投入辩护"的环节——进度可见、成果可展示、无强制唱反调的提示；不主动戳破，也不利用其制造虚假价值（见红线）。

5. **伦理复核（判停条件）**
   - 完成标准: 过 f18 操纵矩阵两问；若发现机制落点是让用户为无价值产品辩护、或通过不可逆投入阻止其离开（恶意锁定），立即停止该设计——三机制的正当性前提是"投入真实提升后续服务质量"（g14）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 产品价值不成立时：宜家效应是估值偏差，不是价值证明；用"用户高估"掩盖产品本身的缺陷，是把心理效应当遮羞布。
- 退出权是核心诉求的场景：数据不可导出+文饰作用=恶意锁定；用户想走时的"舍不得"不该是被设计出来的。
- 欺诈式承诺升级：立牌实验的黑暗面是"登门槛技术"——用小承诺诱导大让步的推销术与诈骗手法，不属于本 skill 的正当用途。

### 作者在书中警告的失败模式

- 机制的反身性警示：作者展示"黑手党战争"玩家合理化时并未掩饰其操纵性质——投入机制的展示本身就是对读者的提醒：自检时同样会自我欺骗（ce18，"我怎么会操纵用户"的辩解可能正是文饰作用在起作用）。
- 一次性应用陷阱（ce14）的反面印证：无投入的应用下载后仅被使用一次——投入缺失时，新鲜感一过没有任何心理资产留住用户。

### 作者的盲点 / 时代局限

- 实验为转引的小样本研究（2011 年折纸实验等），写作期正值心理学复制危机发酵而书中未提；效应量与边界条件未验证（阶段 0 批判节）。
- 设计者本位：全书把"用户高估自己造的东西"当作可利用的设计资源，而非需要保护的认知偏差；未讨论用户为坏产品辩护的沉没成本之害。
- 未证假设：投入必然提升服务质量并不总成立——数据越多隐私风险越大，投入也可能是"被迫锁定"（阶段 0 批判节，对 f15 同样适用）。

### 伦理红线（投入机制专用）

**三机制不得用于绕过用户自主权、不得制造强迫性使用**：不得利用宜家效应制造虚假价值感、利用一致性设计诱导性承诺链、利用文饰作用阻止用户停止使用或离开；判据是"投入是否真实提升后续服务质量"（投入≠付费，g14）；凡以榨取持续付费为目的的投入设计（如"黑手党战争"式合理化榨取），落地前必须被 f18 操纵矩阵拦截。

### 容易混淆的邻近方法论

- 行为经济学"沉没成本谬误"通识：通识教你识别并避免沉没成本谬误，本书反其道给出三条**可分别设计**的机制杠杆（让用户动手造/小步承诺/允许合理化）——粒度超出"沉没成本让人舍不得"的常识层。
- `f15-five-stored-values` 与 `f17-investment-timing-granularity`：机制（f14）→ 资产（f15）→ 时机与粒度（f17），三者构成投入阶段的完整设计链。

## 相关 skills

本 skill 是投入阶段四件套中的"机制"件：解释投入为什么有效，与资产、时机粒度两件分工明确。

**depends-on**（使用前提）: 无。

**contrasts-with**（同境况二选一）: 无。

**composes-with**（配合使用/先后接力）:

- `five-stored-values` — 同一枚投入硬币的两面：本 skill 是心理侧（为什么用户高估自己造的东西），f15 是资产侧（实际沉淀成哪五类资产、迁移性如何）；"用户存的资产盘点"类问题归 f15。
- `investment-timing-granularity` — 先后配合：f17 先定投入"何时提、拆多细"（酬赏之后、小步开始），本 skill 再解释机制加成（宜家效应/一致性/文饰作用）如何放大设计效果；"该问多少、何时问"类问题归 f17。
- `manipulation-matrix` — E 段步骤 5 判停闸门：机制落点是让用户为无价值产品辩护、或通过不可逆投入阻止其离开（恶意锁定）时，设计必须被 f18 拦截。
