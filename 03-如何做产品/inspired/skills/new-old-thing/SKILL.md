# 新瓶装老酒

## R — 原文 (Reading)

> "成功的产品往往不是什么新鲜事物，只是新瓶装老酒，之所以成功，是因为这个"新瓶"做得更好、更方便、更便宜，改变了消费者对"老酒"的印象。……市场机遇无处不在，你要做的是挖掘需求，运用新技术解决用户的老问题。"
>
> — Marty Cagan，第33章《新瓶装老酒》

---

## I — 方法论骨架 (Interpretation)

"要成功就必须发现新热点、开拓新市场"——作者认为这是被媒体炒作（《The New New Thing》）放大出来的错误观念。他给出的替代判断是：成功的产品多半**需求是老的，瓶子是新的**。酒（用户需求）早就摆在那里，变量是瓶——更好的体验、更方便的获取、更低的价格，这些足以改变用户对老需求的满足方式。

想在成熟市场抢到一席之地，手握两件"法宝"：第一，**对目标市场了如指掌、对现有产品的缺陷洞若观火**——手段是可用性测试，而且要连竞争对手的产品一起测，缺陷清单越具体，切入越准；第二，**跟踪最新的技术趋势**，新技术会让之前无法实现的方案变得可能，"只要做到一次，你的产品将所向披靡"。两件法宝的交汇点就是作者反复强调的那句话：抓住**现有技术与用户需求的契合点**。

三条书内佐证把骨架撑满：第29章说"创新不是发现新问题，而是用新方法解决已有的问题"，观察人们对现有产品的不满就是创新的入口；第34章说"只要市场上还有蹩脚的产品，就有机会"；第16章反过来堵住捷径——Google、eBay、iPod、iPhone、Facebook、MySpace 没有一个是靠市场调研定义出来的，新瓶来自探索，不来自问卷。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 谷歌在"饱和"的搜索市场翻盘
- **问题**: 谷歌初入搜索领域时，AltaVista、Infoseek、Snap 等先行者林立，所有人认定搜索引擎市场已经饱和，"初出茅庐的谷歌想在这个领域分一杯羹几乎不可能"。
- **方法论的使用**: 谷歌没有去寻找新市场，而是盯住老需求（找到有价值的信息）换更好的瓶子——专注提供有价值的信息，厚积薄发。
- **结论**: "市场饱和"是错误前提；机会藏在先行者满足不了的老需求里。
- **结果**: "颠覆了整个市场格局"，成为新瓶装老酒最著名的例证。

### 案例 2: iPod 在上百种 MP3 中后发制人
- **问题**: 苹果推出 iPod 时，市场上的 MP3 播放器不下百种，看起来毫无空隙。
- **方法论的使用**: 苹果抓住现有技术与用户需求的契合点，"以其卓越的功能很快引领了市场潮流"——用卓越体验这个新瓶，装"随时随地听音乐"这坛老酒。
- **结论**: 关键不在市场新不新，而在是否抓住了契合点。
- **结果**: 后发的 iPod 引领了市场潮流，与谷歌并列成为"苹果和谷歌深谙此道"的证据。

### 案例 3: 第16章的反面印证——调研定义不出新瓶
- **问题**: 成功产品的方向从哪里来？能不能靠调研"读出"下一个赢家？
- **方法论的使用**: 作者逐一点名检查：Google、eBay、iPod、iPhone、Facebook、MySpace 的诞生方式。
- **结论**: "我从来没听说过仅仅通过市场调研就成功定义出来的产品"；成功基于两点认识——深入理解用户需求，以及明白什么样的方案在现阶段可行。
- **结果**: 老酒要靠洞察不满去找，新瓶要靠技术趋势和产品探索去造；指望调研报告直接产出契合点是死路。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队/老板/投资人说"这个领域已经有巨头了，别做了"，要判断成熟市场还进不进。
2. 自己的产品创意被批"这不就是 XX 吗？早就有人做过了"，需要回应"早就有"不等于"没机会"。
3. 新产品/新版本要找差异化定位，回答"凭什么用户切换到我们"。
4. 争论该找蓝海还是进红海，或有人把"开拓全新市场"当唯一出路。
5. 手上有新技术（如 AI），评估能不能拿来把某个老场景重做一遍。

### 语言信号 (用户的话里出现这些就应激活)

- "这个赛道已经饱和了/是红海了，还有机会吗？"
- "这想法早就有人做了，没新意" / "我们和 XX 比差异化在哪？"
- "用户为什么要放弃现有的产品换我们的？"
- "saturated market" / "red ocean" / "the new old thing" / "why would anyone switch?"
- "有没有新技术能把这个老问题重做一遍？"

### 与相邻 skill 的区分

- 与 `opportunity-assessment-ten-questions` 的区别：十问第⑤问"竞争格局"回答"市场里已有什么"；本 skill 回答的是它的进攻性后续——"已有玩家时凭什么还能进"。
- 与 `emotion-based-demand` 的区别：那个从情感需求辨认"老酒"到底是什么（真正的对手常是线下生活方式）；本 skill 解决找到酒之后用什么新瓶装、成熟市场怎么切入。
- 与 `irrational-user-signals` 的区别：那个教你去愤怒用户身上发现被放大的老需求；本 skill 是拿到需求后与新技术做契合、进入已有市场的打法。
- 与 `user-research-limits` 的区别：第16章"调研定义不出产品"的反证是本 skill 的证据之一；那个 skill 界定调研的能力边界，本 skill 给出边界之外的取胜路径。

## E — 可执行步骤 (Execution)

1. **把"没人做过"的执念换成"现有方案哪里烂"**：列出目标市场的老需求与现有玩家（含自家产品），用可用性测试或亲身体验逐一记录缺陷。
   - 完成标准：缺陷清单具体到体验层（慢、贵、繁琐、令人沮丧的具体环节），而不是"他们产品老旧"这类泛泛之词。
   - 判停条件：现有产品已无明显缺陷、用户普遍满意——此路不通，换一条老需求重新开始。
2. **盘点"让不可能变可能"的新技术**：跟踪技术趋势，问"哪些此前无法实现的方案现在变得可能"，与第 1 步的缺陷清单做交集。
   - 完成标准：至少得出一个"老需求 × 新技术"的契合点，能一句话说清"老酒是什么、新瓶好在哪（更好/更方便/更便宜）"。
   - 判停条件：所谓新瓶只是换界面、换皮，没有改变关键体验或成本结构——退回第 1 步找更痛的缺陷。
3. **用原型测试收口**：把契合点做成高保真原型，放到真实用户面前验证价值与可用性，并把"为什么是我们"写进机会评估结论。
   - 完成标准：连续的用户测试者理解并欣赏产品价值（衔接 `prototype-testing-playbook` 的判停标准）；竞争格局问题的答案从"我们也有"升级为"我们抓住了契合点"。
   - 判停条件：测试者始终无感——按 `product-validation-trio` 的纪律立马收手，放弃这个切入角度。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 全新品类的原始创新——需求本身未经市场验证，没有"老酒"可装，本 skill 无从下手（此时用 `opportunity-assessment-ten-questions` 过滤机会）。
- 给"模仿竞品"当挡箭牌——只复制表面功能的照猫画虎"形似神非"（第31章），没有契合点的新瓶只是山寨。
- 对自己现有产品的漏斗改进——那是 `metric-driven-improvement` 的地盘，本 skill 面向进入他人盘踞的市场。

### 作者在书中警告的失败模式

- 迷信"必须发现新的热点，开拓新的市场"，媒体炒作助长风气，"大家都在挖空心思寻找下一个热门产品"，反而忽视眼前的成熟市场（第33章）。
- 把新瓶理解成营销包装或功能堆砌，而不是体验、便利、价格的实质改变（第33章）。
- 只看技术不找契合点——"虽然谁都没有把握永远走在技术的前列"，为新技术而新技术的产品赢不了（第33章）。

### 作者的盲点 / 时代局限

- 案例全部是幸存者：谷歌、iPod 都是 2008 年前硅谷赢家；同样后发进入"饱和"市场而阵亡的玩家书中未列，两件法宝是必要条件而非充分条件。
- "跟踪新技术做到一次就所向披靡"低估了网络效应与生态壁垒——社交、操作系统类市场的后发难度远超搜索与 MP3。
- "新瓶"的维度（体验/便利/价格）写于 2008 年，未涵盖其后主导市场的数据、网络效应、平台补贴等新变量，套用时需补充现代分析维度。

### 容易混淆的邻近方法论

- 蓝海战略：蓝海主张开辟无人竞争的新市场；本 skill 的立场恰恰相反——机会多在有人竞争的成熟市场，是"红海进取法"。
- 颠覆式创新（克里斯坦森）：那是解释后发者为何能赢的理论模型；本 skill 是产品经理视角的两件可操作法宝，不预测行业结局。
- 快速跟进/微创新：那是节奏策略；本 skill 要求先拿出对缺陷的洞见与新技术契合，缺这两样的跟进只是照猫画虎。
