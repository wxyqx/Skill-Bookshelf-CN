# "了解"优先与示能/能指取舍

## R — 原文 (Reading)

> "为贴近用户，必须按照用户遵循的'了解'→'好、正确'的体验顺序来决定优先级。" / "设计师必须排除一切漂亮的设计，放弃让人觉得有趣的事情，集中精力告诉玩家该做什么。这才是对设计师最大的考验。"
>
> — 玉树真一郎，第1章《什么是贴近用户》/《比有趣更重要的事情》

---

## I — 方法论骨架 (Interpretation)

用户对任何东西的体验顺序永远是：先"了解"（这是什么、我此刻该做什么），再"好、正确"（它有多好）。但在体验发生之前，用户**无法感知**你的好与正确——无论多经典的游戏，玩之前都不显得有趣。所以传达决策必须按用户的顺序排优先级：宁可牺牲漂亮、有趣、全面，也要保证对方在几秒内明白该做什么。

操作上有两个工具。**示能**：一个东西让人浮现"要做××吗？"的可能性（它只在"东西×识别者"同时存在时成立，同一设计对不同人唤起不同行动）。**能指**：为传达示能而被特别处理的信息。设计流程是先用**语言素描**穷举描述（只记录"它传达了什么信息"，不用形容词），再逐项裁决：支持目标行动假设的留下，与之争夺注意力的"好、正确"元素删除或后移。

示能还可以嫁接在用户已有的共同记忆上（"木柴会燃烧"人人知道），且构成行动线索的信息**绝不能传达错**——宁可少给，不可给错。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《超级马里奥》开始画面
- **问题**: 最重要的规则（向右前进）不能写在画面上，怎么传达？
- **方法论的使用**: 马里奥站在左边面向右边、左边是堵住的山、右侧是明亮的草和云——所有能指只服务一个行动假设；"漂亮/有趣"被整体牺牲，所以孩子会说"看起来没意思"，却会自发开始玩。
- **结论**: 为传达示能，放弃有趣是设计师的必经取舍。
- **结果**: 全世界玩家迈出冒险第一步，无说明书。

### 案例 2: FC 十字键
- **问题**: 新技术"滚动"让世界变宽，但玩家得知道往哪走。
- **方法论的使用**: 画面与控制器融为一体——十字键"分明是用来调整上下左右方向的"，借助一看就懂的工具形态传达示能。
- **结果**: 滚动技术无障碍普及。

### 案例 3: 堀井雄二的产品外前置
- **问题**: RPG 指令复杂，游戏还没开始就劝退？
- **方法论的使用**: 在产品之外先解决"了解"：在《周刊少年JUMP》杂志上解说 RPG，再做一款练习指令输入的冒险游戏。
- **结果**: 《勇者斗恶龙》成功把 RPG 引入日本。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 首页/落地页/海报/演示第一屏堆满卖点、获奖、参数，但转化或行动率低。
2. 界面或文档信息完整，用户却说"不知道下一步点哪/该干嘛"。
3. 要给产品开场做减法，团队在"突出专业感"还是"突出易用"之间拉扯。
4. 写新品发布文案、活动入口、教程第一页，需要决定留什么删什么。
5. 分析竞品开场为什么有效/无效。

### 语言信号 (用户的话里出现这些就应激活)

- "用户不知道该做什么 / 下一步在哪 / 看不懂要干嘛"
- "首屏/开场/第一眼放什么"
- "卖点太多 / 信息太满 / 做减法"
- "该牺牲哪个 / 取舍 / 优先级"
- "what should the user do first / above the fold / affordance / 示能"

### 与相邻 skill 的区分

- 与 `primacy-frontload-first-timers` 的区别：本 skill 决定**传达什么**（信息取舍）；那个决定**何时教**（必学内容放开头、为第一次的用户设计）。首屏排布用本 skill，整个上手序列用那个。
- 与 `psychological-context-redesign` 的区别：那个先诊断"体验价值被什么心理脉络拉低"，可能得出改环境不改物的结论；本 skill 是诊断后重排信息时的具体取舍标准。

## E — 可执行步骤 (Execution)

1. **确定唯一的行动假设**
   - 完成标准：一句话填空"我希望对方第一秒浮现：'要做____吗？'"。判停条件：若填不出唯一答案，先别排版——退回去想清楚目标行为。
2. **语言素描**
   - 完成标准：把现有界面/页面/画面的每个元素逐项写成"它在传达××信息"的清单，禁止使用"美观/高级/有趣"等形容词。
3. **逐项裁决**
   - 完成标准：每个元素标记三选一——"支持行动假设：留"、"了解之后再感知：后移"、"与行动假设争夺注意力：删或弱化"；首屏只留第一类。判停条件：若删无可删仍传不出唯一行动，说明还没找到唯一示能，回到步骤 1。
4. **检查共同记忆与信息正确性**
   - 完成标准：每个行动线索都能回答"目标人群是否人人都具备这个记忆/认知？"；逐条核对线索无歧义误导（宁可少给，不可给错）。
5. **找个没见过的人测 5 秒**
   - 完成标准：对方 5 秒内说出"你觉得接下来该做什么"，且答案与目标一致；否则回步骤 2。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯品牌/审美场景**——画展、形象片的目的就是"好、正确"本身，套用"只传达该做什么"会杀死作品。
- **受众已越过"了解"阶段**——面向深度用户的更新日志、专业文档，堆细节反而是尊重。
- **多个行动同等重要时**——本 skill 强制唯一行动假设；若业务上确需多入口，先做优先级决策，别用本方法和稀泥。

### 作者在书中警告的失败模式

- 宣扬"好、正确"是设计师最大的陷阱——被"不被认可的不安"打败，把开场做得乱七八糟（ce05/ce12）。
- 显示了信息却不显示方法：画面有分数没有得分法，用户走投无路（ce04）。

### 作者的盲点 / 时代局限

- "排除一切漂亮"针对**第一秒**的注意力争夺，不是永远禁用美观；迁移时注意作者说的是开场阶段，别把整条产品线做丑。
- "共同记忆"假设来自全国同质化的日本市场；跨文化/细分人群产品需先验证记忆的普遍性（u03 的普通用户画像可辅助）。

### 容易混淆的邻近方法论

- Don Norman 的 affordance/signifier：同源概念；本书增量是"牺牲序"——为传达示能**必须**牺牲好看，这不是 Norman 的主张。
- 极简主义（minimalism）：极简是审美偏好，本 skill 是按用户体验顺序做的**功能性**取舍，标准是"是否支持唯一行动假设"，不是"元素少"。
