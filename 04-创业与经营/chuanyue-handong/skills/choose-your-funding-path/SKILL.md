## I — 方法论骨架 (Interpretation)

要不要融资不是一个"融资能力"问题，而是一个**资金来源的资格审查**问题：钱在进门前，先过三道闸——时机闸、红线闸、匹配闸。过不了闸的钱，代价高于收益。

1. **总闸门：先验证，后融资。** 任何外部资金——亲友的、银行的、风投的——在商业模式被验证之前都不该进门。验证期用最少的钱和最短的时间证明或否决设想（六个月止损）；风投擅长为已验证的模式做加速，不擅长修正被否决的模式。过早拿到大钱会掩盖问题、诱使过早扩张，反而置公司于死地。验证是融资的闸门：验证通过后融资水到渠成，被否决则尽早转向，别借钱续命。
2. **红线闸：四类永不触碰的钱。**
   - **退休金与孩子学费**：未证实的梦想不能押上不可再生的个人资产——生意失败可以重来，养老钱和孩子教育没了就没有第二次。
   - **与个人信用捆绑的贷款**：高息贷款会反咬你一口；凡是让公司失败变成"个人破产"的借法都在红线之内。
   - **亲友借款（撒旦的糖果）**：隐性代价有三层——股权不可流通、回报周期十年以上、一旦亏损关系永久变质。即使对方主动且理解风险，回答仍应是"不"。唯一例外：父母祖父母"提前继承遗产"性质的赠与——当礼物收，绝不定性为投资，公司成功后可用赠送股权替代偿还。
   - **贷款的边界**：只做与公司资产绑定的经营性贷款（存货、设备、应收账款抵押，或硬资产如房产抵押），公司关门即可清算止损；绝不碰与个人信用捆绑的消费贷、信用卡套现和高利贷。
3. **匹配闸：该不该碰风投的三道算术题。**
   - **资格线**：只有能证明三年内指数级增长、第三年年营收至少 5000 万美元的公司才该接触风投；做不到就调整预期，拿中小企业的商业计划敲风投的门是徒劳。
   - **时机**：准备好之前避开大牌风投——红杉级别的机构早期进来后若后续不跟进，等于向整个市场宣告"这家公司出了问题"，负面信号会吓跑所有其他投资人。
   - **资金方**：绝不拿竞争对手的钱——企业投资人出于战略而非回报投资；这家企业是你客户的竞争对手，钱再多也不要。
4. **替代路径：不融资怎么活。** 缺钱不是绝路，反而是纪律：选不需要大笔前期投入的业务（好企业靠时间和积蓄就能长起来）、用副业或全职工作养公司、与雇主协商过渡或请长假思考。你靠自己的钱走得越远，谈判地位越好——等真需要融资时，估值和条款都由从容的你来定。
5. **心态校准**：融资不是成功，只是工具；绝大多数公司本就不该走风投这条路。也别把"卖掉公司"当目标——专注把公司、员工和客户的事做对，退出只是副产品。

## A1 — 书中的应用 (Past Application)

### 案例 1: Little Passports——被 75 位投资人拒绝后的自力更生
- **问题**: 两位母亲创立订阅制公司，只想融 50 万美元，却被 75 位投资人连续拒绝 75 次，账上没有扩张的钱。
- **方法论的使用**: 关掉"必须融资"的执念，走替代路径：节俭运营、把每笔钱花在小型廉价实验上，后用 3 万美元投 Facebook 定向广告验证获客渠道。
- **结论**: 没拿到风投反而迫使公司建立严格的财务纪律；创始人原话——"对风险投资的依赖，就像依赖毒品一样"。
- **结果**: 8 年后做到每年 3000 万美元销售收入，无须向任何投资人低头。

### 案例 2: GitHub——四年不融资的副业项目
- **问题**: 创始人没有启动资金，也不知道产品能否成立，是借钱all-in还是慢慢做？
- **方法论的使用**: 副业起步路径：东拼西凑数百美元注册公司，靠咨询工作和全职薪水支付账单，4 年不进行任何形式的融资，先做到自身盈利再谈扩张。
- **结论**: 自筹资金＋副业节奏完全可以走到顶级退出；"需要大笔前期投资的梦幻项目"才需要急于融资。
- **结果**: 微软最终以 75 亿美元收购 GitHub——零融资期起步的公司撑起了史上最大收购之一。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在"要不要融资、现在融还是再等等"之间摇摆——想先搞清楚自己配不配融、该不该融。
2. 面对一笔具体的钱做取舍：亲戚要借钱、父母要投养老钱、银行要个人担保、竞争对手想战略入股、大牌风投抛来橄榄枝。
3. 融不到资或不想融资，想知道有没有不靠融资把公司做起来的路子（低投入业务、副业起步、自力更生）。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要融资""该不该拿这笔钱""现在是不是融资时机""再等等还是现在融"
- "亲戚/朋友/爸妈要借钱或投资给我""动用退休金/房子抵押/个人担保""竞争对手想投资"
- "融不到钱怎么办""不融资能创业吗""副业/业余时间做公司""缺钱是不是就做不成"
- "VC 会不会看不上我们这种公司""拿了风投的钱意味着什么"

### 与相邻 skill 的区分

- 与 `vc-dynamics-demystified` 的区别：**选路 vs 懂机器**。本 skill 回答"我自己该不该融资、这笔钱该不该拿"（时机、红线、替代路径）；那个 skill 回答"风投这台机器怎么运转、为什么拒绝我"。用户在选资金道路 → 本 skill；用户已上路想看懂对手 → 那个 skill。
- 与 `validate-before-you-build` 的区别：**验证是融资的闸门，不是替代品**。点子还没验证、要设计低成本实验、何时止损 → 那个 skill；验证已通过或已失败、问题变成"接下来钱从哪来" → 本 skill。若用户既没验证又在问融资，先激活验证闸门再谈钱。
- 与 `run-the-fundraising-process` 的区别：决定融资之后的执行（估值、渠道、跟进节奏）归那个 skill；"决定本身"归本 skill。
- 与 `vet-investors-and-advisors` 的区别：具体某个投资人/律师可信不可信的背调归那个 skill；本 skill 管资金来源类型层面的红线（竞争对手的钱、大牌风投信号风险）。

## E — 可执行步骤 (Execution)

1. **列资金来源清单，先过红线闸**
   逐一写下当前可得的资金来源，排除：退休金与孩子学费、与个人信用捆绑的贷款、亲友借款（父母赠与除外、且只当礼物）。
   - 完成标准：清单上每项标"可碰/不可碰"，四类红线钱全部划掉，没有例外申请。
2. **做风投匹配算术，决定是否打开风投选项**
   测算未来三年营收：能否证明指数级增长、第三年年营收是否至少 5000 万美元。
   - 完成标准：得出一个有依据的三年营收数字；达不到资格线 → 关闭风投选项，跳到第 4 步，不再浪费一周年年路演。
3. **过匹配闸：检查时机与资金方**
   三个问题各写书面答案：①商业模式验证完成了吗（未完成 → 先回验证，融资冻结）；②现在该不该避大牌风投（上升势头证明之前，是）；③这笔钱是否来自我客户的竞争对手（是 → 拒绝）。
   - 完成标准：三问均有明确答案，任何一问红灯即否决该笔资金。
4. **走替代路径，规划不融资的活法**
   二选一或组合：把业务改造成低前期投入的形态；或副业起步——用工资/咨询收入养公司、与雇主协商过渡期，写出现金流跑道。
   - 完成标准：有一份"靠自己的钱能走多远"的书面跑道测算（月开销 × 可支撑月数），并把缺钱转化为纪律——小实验、低成本试错。
5. **每季度复审一次**
   商业模式验证状态、三年营收测算、跑道余量都会变，算术要重做。
   - 完成标准：日历上设好季度复审；每次复审后更新"融资闸门"的开闭结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经决定融资，要准备路演材料、定估值或推进流程——转 `pitch-materials-that-land` / `run-the-fundraising-process`。
- 用户的问题是如何设计验证实验、判断需求真伪——那是融资的闸门，但闸门本身归 `validate-before-you-build`。
- 用户问的是风投如何赚钱、为何拒绝自己——机制理解归 `vc-dynamics-demystified`。

### 作者在书中警告的失败模式（融资来源家族反例）

- **亲友借款困境（"撒旦的糖果"）**：亲朋可能十年看不到回款，股权无人接手；一旦让他们亏钱，关系永久变质，家庭聚会都尴尬——即使对方理解风险，答案仍是"不"。
- **把风投融资当作成功象征**：媒体神化获投公司，现实是绝大多数初创企业满足不了风投对指数增长的要求，融资只是工具不是成就。
- **中国式个人担保**：早期投资人要求首次创业者个人担保，失败后深陷个人债务，再无第二次机会——签约前查清是否要求个人连带责任。
- **过早融资是过早扩张的主因**：Fab.com 拿 3.1 亿美元、月烧 1400 万美元仍被贱卖——钱只掩盖问题；70% 的创业公司至少在一个维度过早扩张。拿竞争对手（客户的对手）的钱则会被锁死业务。

### 作者的盲点 / 时代局限

- 风投中心视角：默认高增长风险创业是"正统"，对利润优先、生活方式企业着墨少；Basecamp 等 Bootstrapped 路线证明融资驱动只是路径之一。
- 判据基于 2012-2019 美国风投周期与低利率环境；"三年 5000 万美元"资格线是数量级经验值，寒潮期应整体下修预期而非机械套用。

### 容易混淆的邻近方法论

- **验证方法**（创新循环、六个月规则）：是本 skill 总闸门的"前一道工序"，归 `validate-before-you-build`，不要在本 skill 内展开。
- **风投赚钱算术**（2/20、退出规模）：解释"对手为什么不投你"，归 `vc-dynamics-demystified`；本 skill 只用其结论（资格线）做自筛。
- **资金红线 ≠ 投资人背调**：某个具体投资人是否可信、律师怎么选，归 `vet-investors-and-advisors`。
