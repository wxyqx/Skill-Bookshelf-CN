# 设计商业模式与护城河

## R — 原文 (Reading)

> "实际上只有两种真正行得通的商业模式：（1）客户直接付钱给你；（2）广告商付钱给你。所有其他的商业模式都是这两种模式的子集。"
>
> — 史蒂文·霍夫曼，第5章

> "真正重要的是这家公司是否能深度地将用户变现。下面让我们先来看一下四种非常受欢迎的将用户变现的方式：订阅、易耗品的销售、产品功能升级收费、平台。"
>
> — 史蒂文·霍夫曼，第5章

> "不要简单地选择某一种商业模式，然后不加权衡地直接采用该模式来运营自己的公司。……你需要对市场以及形成该商业模式的所有因素进行深入的分析。"
>
> — 史蒂文·霍夫曼，第5章

> "它们之所以能赢是因为与其竞争对手相比，它们拥有不公平的优势。如果你的公司与其他公司没有什么差别，你就不可能获取高额利润并主导整个市场。"
>
> — 史蒂文·霍夫曼，第6章

> "这两种方法是，要么你有比竞争对手好出很多个数量级的产品，要么你和其他人截然不同。如果这家创业公司没有按照这两者之一去做，它将永远无法取得成功。"
>
> — 史蒂文·霍夫曼，第5章

## I — 方法论骨架 (Interpretation)

商业模式设计的纪律：先回答"钱从谁来、为什么可持续、别人为什么抢不走"，再谈增长。本书给出一套从模式选择到护城河构建的完整操作系统：

1. **两种根本模式（10 分钟 MBA）**。只有两种行得通：客户直接付钱、广告商付钱，其余全是子集。客户付费模式要求生命周期平均支付显著高于获客成本加货物成本；广告模式有两个硬条件——数百万级活跃用户＋高参与度与留存，低频应用强行套广告模式注定失败。用法：一句话审视"我的钱到底从谁来、这个等式成立吗"。
2. **四种用户变现方式，投资人只看深度变现**。订阅（可预测收入、低门槛试用）、易耗品（复购，宜与高价一次性产品捆绑，如打印机与墨盒）、功能升级收费（仅适合升级空间近乎无限的产品）、平台（按交易抽成，网络效应最难复制、最强大）。一次性售卖对创业公司是次优模式——获客后客户不再付钱，克隆品会快速以低价压市。投资人在乎的不是行业，而是能否深度变现。
3. **照搬模式前的要素检验**。"我们就是 X 行业的优步/瓦尔比派克"式叙事容易拿融资，但先拆解原模式的成立要素再逐项核对：优步 8 要素（经常性收入流、高频高参与、生命周期价值大于获客成本加服务成本、平台网络效应、难以绕过平台直联、服务优于传统方案、客户可轻易反馈、良好用户体验）。缺失任一要素整个模式崩塌——这正是"优步化"倒闭潮的根源。模仿本身无罪（模仿是起点，创新是超越：每天优先使用竞争对手的产品成为超级用户，深挖其成败原因），错的是不加权衡地照搬。
4. **定价宁高勿低**。再优秀的产品也受市场与定价约束：小品类＋低定价＝赚不到钱；创新产品应定更高价格而非陷入价格竞争（戴森的教训）。定价必须依赖市场调研、测试和有经验的专家，而非感觉与情绪。
5. **设计优先与软硬件结构**。早期设计创新重于技术创新——多数创业公司没时间金钱开发核心技术，必须尽快进市场；Dropbox、Facebook、Pinterest 靠设计创新重新定义品类，设计是对使用者心理与情感需求的理解，不止是外观，雇一个顶尖设计师是创始人最佳投资之一。做硬件则用软件连接硬件（特洛伊木马原则）：纯硬件难以锁定客户、变现和获得反馈，用内置软件把硬件接入客户日常应用才能建立持续客户关系与扩张模式。
6. **25 种不公平优势清单（护城河盘点）**。赢家靠不公平优势而非公平竞争，逐项对照：网络效应、专有数据、资本、领先技术、提供最大价值、锁定客户、网上集市、品类定义、行业标准、规模经济、垄断、专利、关系、趋势、政府政策、进入速度、品牌、媒体关注、名人效应、领域专长、商业机密、退出陷阱、独家合伙、专用耗材、学习曲线、产品服务化、生态系统。一项都没有，建成独角兽将极其困难。锁定客户用时间投入判定：客户学习、定制、上传内容、装插件、集成工作流的投入越多，转换成本越高。
7. **反其道而行（重新制定规则）**。现有规则由在位大企业制定，遵循规则者赢不了。观察在位者做每件事的方式（渠道、合约、销售模式），逐项反着做以制造不公平优势——对手用零售分销你就找替代渠道；类比《大富翁》中对手已垄断酒店时，问"我该如何让这些物业变得毫无价值"。配套判据：撬开市场只有两条路——比对手好出数量级，或提供别处无法获取的价值；技术选型的唯一理由是它最佳满足客户需求，绝不为融资硬套热门技术。

## A1 — 书中的应用 (Past Application)

### 案例 1: 瓦尔比派克——模式颠覆成立，但成立要素不可复制
- **问题**: 眼镜市场被陆逊梯卡近乎垄断，垄断溢价使眼镜价格虚高，创业者想找到撬开这个品类的模式。
- **方法论的使用**: 照搬要素检验的反向运用——瓦尔比派克没有套用行业规则，而是反其道而行：以同样时尚、大幅低价的直销模式切入，绕开垄断分销；低价还鼓励消费者每年换镜，形成经常性收入。其成功依赖品类特有条件：垄断溢价空间（有大幅降价余地）＋高频复购结构。
- **结论**: 模式颠覆成立，但成立依赖品类条件——照搬此模式的数百家"X 品类的瓦尔比派克"大多失败。
- **结果**: 瓦尔比派克颠覆了眼镜市场；模仿者几乎全军覆没（仅美元剃须俱乐部等少数品类条件匹配者成功）。

### 案例 2: 戴森——5127 个原型、定价教训与护城河重建
- **问题**: 戴森做无袋旋风吸尘器时，球轮手推车产品因定价过低几乎不赚钱；后来因坚持自己的想法与外部投资人冲突，被踢出自己创立的公司，一度负债、身无分文。
- **方法论的使用**: 设计创新重于技术创新——5000 多个原型反复打磨核心设计；吸取定价教训，为创新产品定更高价格而非陷入价格竞争；靠日本授权与美国专利侵权诉讼重建防线，两年成为英国销量第一。
- **结论**: 卓越设计＋市场判断（宁高勿低）＋保持股权与控制权，是设计驱动型公司的模式根基。
- **结果**: 戴森身价约 60 亿美元，拥有公司 100% 股权。

### 案例 3: 劳斯莱斯——把喷气发动机变成服务
- **问题**: 航空发动机一次性售卖，客户决策只看采购价，竞争者靠降价即可侵蚀市场。
- **方法论的使用**: 模式改造＋不公平优势：不卖发动机而卖"按使用次数计费＋保养"的服务套餐，以高昂前期成本加长期服务合约锁定客户。
- **结论**: 产品服务化使竞争对手几乎无法进入该市场——复制模式太过昂贵；这是"产品服务化"类不公平优势的典型样本（同类还有吉列专用耗材、Adobe 学习曲线锁定）。
- **结果**: 劳斯莱斯发动机业务形成长期锁定的服务收入结构，对手难以复制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在设计或重估商业模式：钱从谁来、该选订阅/平台/一次性售卖哪种变现、广告模式适不适合自己的产品。
2. 想照搬某个成功模式（"我们就是 X 行业的优步/瓦尔比派克"），需要做成立要素检验。
3. 在定价格（尤其纠结该定低抢市场还是定高保利润）、做软硬件产品、纠结该做技术创新还是设计创新。
4. 想知道自己的模式靠什么挡住抄袭者：盘点不公平优势、设计护城河、或对在位巨头"反其道而行"。

### 语言信号 (用户的话里出现这些就应激活)

- "商业模式怎么设计""怎么变现""订阅还是一次性""平台抽成""广告模式能不能做"
- "照搬优步/复制某某的模式""我们就是 X 行业的某某""要素/前提成立吗"
- "该定什么价""定价太低赚不到钱""软硬件结合""物联网怎么变现""设计重要还是技术重要"
- "护城河""不公平优势""网络效应""客户锁定""别人抄我怎么办""反其道而行""差异化"

### 与相邻 skill 的区分

- 与 `think-like-a-unicorn-hunter` 的区别：本 skill 是**设计者视角**（造模式、建护城河，服务自己的决策）；后者是**评估者视角**（用独角兽标准给一家现成公司/赛道打分，如尽调或自审）。"我的模式该怎么设计"找前者；"这家公司值不值得投/过不过得了独角兽标准"转后者。
- 与 `market-and-grow-on-a-shoestring` 的区别：后者用 LTV-CAC 做**渠道级判断**（这个获客渠道值不值得投）；本 skill 做**模式级设计**（收入结构、定价、护城河）。若渠道算术整体不成立、要改模式，转本 skill。
- 与 `validate-before-you-build` 的区别：验证回答"需求存不存在"，本 skill 假设需求已验证，回答"怎么把钱赚回来、赚得可持续"。

## E — 可执行步骤 (Execution)

1. **先答两种根本模式之问**：用一句话写出"我的钱从谁来"——客户直接付钱还是广告商付钱
   - 完成标准：答案落定后完成对应判据检验——客户付费模式算出生命周期平均支付是否显著高于获客成本加货物成本；广告模式诚实回答活跃用户是否达数百万级且高频高留存，任一等式不成立即换分支。
2. **在四种变现方式中选定主模式**：对照订阅、易耗品、功能升级、平台四类，评估与自己产品的价值结构是否匹配；警惕一次性售卖
   - 完成标准：写出选定模式及理由，并明确说明为什么不选另外三种（尤其一次性售卖的克隆品风险如何规避）。
3. **若在照搬某个成功模式，做 8 要素逐项核对**：以优步清单（经常性收入、高频高参与、LTV>CAC+服务成本、网络效应、难以绕过、优于替代方案、易反馈、好体验）为模板逐项打分
   - 完成标准：8 项各标"具备/缺失/改造后具备"；有任何一项缺失且无法补足，放弃照搬或改造模式。
4. **定价校验**：审视定价依据是数据还是感觉，检查是否落入"小品类＋低定价"组合
   - 完成标准：有市场调研或测试数据支撑价格点；若属创新产品，给出高于竞品的定价理由而非降价跟随。
5. **盘点不公平优势并设计护城河动作**：逐项对照 25 种不公平优势清单，对每项已具备的优势设计强化动作（如软件连接硬件、产品服务化、锁定客户），对在位对手用"反其道而行"逐项生成差异化选项
   - 完成标准：清单打勾≥1 项且有强化计划；若一项都不具备，写出至少 3 个"反着做"候选方案并选定其一验证。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要从投资人视角用独角兽标准评估一家现成公司或赛道（评估主链、团队深挖、专利价值、市场第一判据）——转 `think-like-a-unicorn-hunter`。
- 需求真伪尚未验证就想设计变现——先回 `validate-before-you-build`，商业模式放大的是已验证的需求。
- 问题只是某个获客渠道值不值得加钱——那是渠道级算术，转 `market-and-grow-on-a-shoestring`。

### 作者在书中警告的失败模式（商业模式自查反例）

- **照搬模式不加检验**："优步化"倒闭潮——优步成功后数月内涌现的共享洗衣、洗车、家政、停车、按摩、冰激凌公司大多倒闭；数百家"X 品类的瓦尔比派克"几乎全军覆没。照搬前必须逐项核对原模式成立前提，每个品类有独有市场规则，缺一个要素模式即崩塌。
- **广告模式套低频应用必然崩溃**：一位创始人被问"用户多久用一次你的应用"，答案是"大概每两周一次"——这个模式不适合他的公司。选变现模式前先诚实回答使用频率与参与度。
- **一次性售卖＋硬件的双重脆弱**：花一年创新推出的酷产品，抄袭者几个月内就以更低价格销售同样的东西，利润被侵蚀后无力打造品牌；消费电子领域无高壁垒的一次性售卖难以存活。
- **凭感觉定价**：CB Insights 失败原因数据显示 18% 的失败公司出现定价及成本问题——创业者顺着情绪定价，过低导致成本超支，过高客户拒付。
- **订阅模式硬套不适用的产品**：把订阅/易耗品模式生搬到联网电灯泡、恒温器等设备上没有意义——订阅的前提是价值随时间累积，Nest 也未实现深度变现。

### 作者的盲点 / 时代局限

- 案例语境是 2012-2019 年的硅谷与中国一线互联网（优步、瓦尔比派克、Nest、区块链），平台经济与网络效应类优势被着重强调；对传统行业、慢生意、区域型小生意的不公平优势（区位、牌照、本地关系）着墨少。
- "定价宁高勿低"与"要么好出数量级、要么截然不同"是针对风投赛道的高风险高回报判据；做利润优先的中小企业时，"够好＋更便宜"在部分品类仍是可行策略，需自行权衡而非照单全收。

### 容易混淆的邻近方法论

- **"模仿是起点"（p09）≠ "照搬模式"（p54/f49）**：前者是学习对手做得对的事并在此基础上创新；后者是不加权衡地复制整个模式——判据是有没有逐项核对成立要素。
- **25 种不公平优势 ≠ 专利**：Jawbone 拿 9 亿美元融资加数百项专利仍破产，WhatsApp 零专利卖出 190 亿美元——专利对多数软件初创不构成护城河，只有半导体、制药等资本密集核心技术才值得早期投入（专利四问归 `think-like-a-unicorn-hunter` 展开）。
- **模式级 LTV>CAC ≠ 渠道级 LTV-CAC**：前者是商业模式成立的生死判据（钱从谁来），后者是单个获客渠道的投放判断，不可混用。
- **设计创新 ≠ 外观美化**：设计是对使用者心理与情感需求的理解，从包装到网站、App、视频都是产品的一部分；只改 UI 不叫设计优先。
