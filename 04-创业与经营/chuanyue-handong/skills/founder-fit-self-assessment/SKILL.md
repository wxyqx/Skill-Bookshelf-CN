# 该不该创业：错误动机排除与代价拷问

## R — 原文 (Reading)

> "你是不是已经准备好在这个世界上最专制、最苛刻的老板手下干活，尤其是如果这个老板就是你本人？"
>
> — 史蒂文·霍夫曼，第1章

> "首先，让我们一起看看10个你根本就不该去创业的理由。（1）成为自己的老板。（2）能够很快地成名或者富起来。"
>
> — 史蒂文·霍夫曼，第1章

> "我相信创业的正确理由应该是你想要解决某一个特定的问题。"
>
> — 史蒂文·霍夫曼，第1章

> "不要基于薪资、职位或者福利保障来选择你的工作，而是要看这份工作能不能让你以最快的速度成长起来。"
>
> — 史蒂文·霍夫曼，第1章

---

## I — 方法论骨架 (Interpretation)

创业决策是一道三重闸门：先排除错误动机，再过正面门槛，最后通过代价拷问；暂时过不了闸门的人，用"以学习效率择业"做准备期策略。

1. **十个错误理由（负面清单，命中任何一条即停下来重新审视初心）**：①成为自己的老板——你将发现员工问题比老板问题糟 10 倍；②快速成名致富；③逃避无聊的工作；④解决某个情感问题；⑤让另一个人满意；⑥跟风；⑦怕错过机会——机会总会再来；⑧为生活增添刺激；⑨让生活更有意义；⑩笼统地"改变世界"。
2. **唯一正确理由**：你想要解决某一个特定的问题——对这个问题有强烈的解决愿望，且你的解决方案有巨大的商业价值。"改变世界"之所以错是因为笼统，"解决特定问题"之所以对，是因为它具体、可验证，足以支撑你穿越漫长低谷。
3. **自我拷问清单（代价闸门，任何一项犹豫＝不该创业）**：能否没日没夜工作且乐在其中？能否心甘情愿放弃每一个周末和夜晚？能否接受最专制苛刻的老板就是你自己？能否押上一生积蓄？能否承受疏远家人朋友？能否忍受长期手头拮据和剧烈的情感波动？——所有题都必须给出肯定回答；任何一项犹豫，答案就是"不如去找一份普通工作"。
4. **打钩测试（正面准入门槛，诚实打钩，全部通过才放手创业）**：□ 有解决特定问题的强烈愿望且方案有巨大商业价值；□ 有能力处理极端不确定性；□ 清楚自己的强项和弱项；□ 有配偶等支持系统；□ 不在乎在这个项目上赌上所拥有的一切；□ 没有工作的情况下积蓄仍可维持至少一年生活；□ 享受运营企业的过程。
5. **暂不创业时的准备策略——以学习效率最大化择业**：不基于薪资、职位或福利选工作，而看职责、资源与自主决策范围能否让你最快成长；像拥有企业一样把控当前工作，主动增加价值，不怕失败或被开除，为"跨出那一步"做最充分的准备。

## A1 — 书中的应用 (Past Application)

### 案例 1: 马克·库班——把每份工作当作创业训练场
- **问题**: 库班在梅隆银行因主动越权做事触怒老板，意识到该离开，但尚未找到创业方向。
- **方法论的使用**: 在软件销售工作中刻意以学习效率最大化为目标——积累行业认知、了解个人电脑与软件行业、建立自己的客户群，把每份工作当作创业训练场。
- **结论**: 被解雇不可怕，停滞的平庸才是创业者的敌人；在职时积累行业认知与客户资源，时机成熟果断离职。
- **结果**: 他随后创办 MicroSolution（年营收 3000 万美元），售出后又创立 Broadcast.com，以 57 亿美元卖给雅虎。

### 案例 2: 萨拉·布莱克利——唯一正确理由的样本
- **问题**: 她顶着佛罗里达酷热穿连裤袜推销传真机，袜头在露趾凉鞋下外露，尴尬且难堪。
- **方法论的使用**: 动机排查命中"解决特定问题"而非"逃避/致富"：她剪掉连裤袜包脚部分发明塑身内衣，仅以 5000 美元启动资金创业，自己就是产品的第一客户。
- **结论**: 痛点即商机；创业理由是解决一个自己亲历的、具体的问题，小资金也足以启动验证。
- **结果**: 创立 Spanx 品牌，获全美女性的热烈追捧，她因此成为亿万富翁。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在职者纠结"要不要辞职创业"，怀疑自己是一时冲动，需要排查动机与承受力。
2. 用户自述创业理由（"想当自己的老板""想财务自由""不想打工了"），需要对照错误动机清单审视初心。
3. 用户决定暂不创业，想为将来做准备，问"现在的工作/下一个机会该怎么选"。

### 语言信号 (用户的话里出现这些就应激活)

- "适不适合创业""该不该辞职""要不要去创业""我适合吗"
- "创业理由""成为自己的老板""不想打工""怕错过风口""改变世界"
- "押上积蓄""卖房创业""一年生活费""家人不支持"
- "先积累经验""选工作看成长还是看工资""为创业做准备"

### 与相邻 skill 的区分

- 与 `validate-before-you-build` 的区别：本 skill 回答"**要不要创业**"（人是否该上场），后者回答"**点子怎么验证**"（上场后第一步做什么）。一句话若已默认创业、在问需求真伪与低成本验证方法，用后者。
- 与 `choose-your-funding-path` 的区别：本 skill 管创业资格闸门，后者管"该不该融资、钱从哪来、哪些钱碰不得"（退休金、亲友借款等资金红线）。先过人这一关，再谈钱。
- 与 `founder-resilience-and-learning` 的区别：决策前的自我评估（创业之前）vs 创业后挫折中的心理复原与学习机制。用户正被拒绝、自我怀疑时转后者。
- 与 `build-your-team-right` 的区别：本 skill 不处理选合伙人、组队与招聘问题。

## E — 可执行步骤 (Execution)

1. **动机排查**：逐条对照十个错误理由，写下自己真实的创业动机（一句话）
   - 完成标准：明确说出"我为什么要创业"；命中任何一条错误理由即得出"暂不创业"结论，停止后续步骤。
2. **代价拷问**：逐题回答自我拷问清单（工作强度、积蓄、家庭、收入、情绪波动）
   - 完成标准：每题都有明确的"能/不能"，不允许含糊；任何一项犹豫即判停——结论是"找一份普通工作或继续准备"。
3. **正面打钩**：完成七项打钩测试
   - 完成标准：全部打钩才进入下一步（带着具体点子转 `validate-before-you-build`）；有缺项则列出补齐计划（如攒够一年生活费、争取家人支持）并约定复核时间。
4. **准备期行动**：以学习效率最大化择业或重塑当前岗位
   - 完成标准：写出当前/目标岗位在职责、资源、自主决策范围三方面的对比，明确哪个选项成长最快，并给出一份可执行的能力补齐清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已有公司在运营，问的是经营、融资、增长或团队问题——转对应专项 skill。
- 用户已有明确点子，问的是需求真伪与验证方法——转 `validate-before-you-build`。
- 用户问的是"这笔钱该不该拿/从哪来"——转 `choose-your-funding-path`。
- 用户处于挫折与自我怀疑中，需要的是心理支持与坚持判断工具——转 `founder-resilience-and-learning`。

### 作者在书中警告的失败模式

- 为错误动机创业：成为自己的老板后发现员工问题比老板问题糟 10 倍；为快速致富入场者熬不过漫长低谷。
- 任何一项拷问仍在犹豫却强行创业——作者的判词是"不如去找一份普通工作"。
- 准备期只盯着薪资与职位择业，错过积累职责、资源与自主决策范围的机会。

### 作者的盲点 / 时代局限

- 风投中心视角：默认高增长风险创业是"正统"，对生活方式企业与利润优先路线着墨少——"全项打钩否则别创业"的二元门槛对兼职创业、小而美生意偏严。
- 案例与数据集中于 2012-2019 美国风投周期，利率与市场环境已变；"押上一切"式英雄叙事有幸存者偏差。
- 书中另给出"不动退休金/不向亲友借钱"的资金红线（归 `choose-your-funding-path`），与本 skill 的"敢押上一切"打钩项需配合使用，避免被误读为"押上退休金"。

### 容易混淆的邻近方法论

- 点子验证（创新循环、六个月止损）：是创业过闸后的第一步，归 `validate-before-you-build`。
- 融资决策与资金红线（撒旦的糖果）：是资格闸门之后的钱的问题，归 `choose-your-funding-path`。
- 挫折复原与学习（挫折不是失败）：是创业过程中的心态维护，归 `founder-resilience-and-learning`。
