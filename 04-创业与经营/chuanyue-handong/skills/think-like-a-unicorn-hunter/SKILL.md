# 像独角兽猎人一样评估

## R — 原文 (Reading)

> "有太多的投资人都掉进了常春藤联盟这个陷阱，他们把大学的名字和成功等同了起来，这使得他们对于某些最重要的东西视而不见。"
>
> — 史蒂文·霍夫曼，第5章

> "这家公司的CEO将核心知识产权归在了他个人的名下，而且并没有将这件事告诉任何人。事实上他误导了我们，这几乎等同于欺诈了。"
>
> — 史蒂文·霍夫曼，第5章

> "它从投资人那里拿到了9亿美元的融资，并且还拥有涉及面相当广泛的专利组合。……但最终因为质量控制问题、生产问题以及糟糕的产品设计而破产了。"
>
> — 史蒂文·霍夫曼，第5章

> "很快就出现了共享洗衣、共享洗车、共享家政、共享停车以及共享按摩，甚至还有共享冰激凌。……不幸的是，这些创业公司中的绝大多数现在都倒闭了。"
>
> — 史蒂文·霍夫曼，第5章

> "当客户开始把他们的时间和资源投入到你的产品中的时候，他们就被锁定在了这个产品上。"
>
> — 史蒂文·霍夫曼，第5章（f50 单元大意：学习、定制、上传内容、装插件、集成工作流的投入越多，转换成本越高）

## I — 方法论骨架 (Interpretation)

独角兽猎人的评估纪律：不是看故事多动听、头衔多光鲜，而是沿一条主链逐环打分，任何一环断裂都不投。本书给出一套从团队到尽调的完整评估操作系统：

1. **评估主链（独角兽猎人的打分顺序）**。团队（CEO 领导力与成员纽带）→ 市场规模 → 客户认知与数据验证（DAU/MAU、留存率）→ 是否顺应趋势 → 产品是否卓越 → 独特"秘诀" → 商业模式与变现 → 客户锁定 → 软硬件结构 → 专利价值 → 设计 → 媒体潜力 → 尽调透明度 → 团队文化。本章其余工具都是主链某一环的放大镜。用法：对任何一家公司按此顺序逐环打分，先断裂的环决定结论。
2. **CEO 与团队深挖（检验真实领导力而非简历光鲜度）**。投资人深挖五问：是否提出过原创想法？如何说服同事并管理团队？推进中遇到什么障碍、如何克服？是否有导致失败的决定、学到什么？如何说服员工放弃六位数薪水选股权？团队是 CEO 领导力的第一项测试——CEO 最重要的工作是招募，能仅凭言语和股权组建顶尖团队的 CEO 就拥有"神奇魔力"。筛人时个人品质重于名校与头衔：名校生与同分数段其他毕业生终生收入几乎无差别，深挖决策类型与承担的责任，宁选初级项目经理而非副总裁。
3. **团队"独特元素"观察法（文化即护城河）**。看成员身体语言与互动是否真诚；带团队参加集体活动观察互助与沟通。依据伯克利研究：运动队队友间友好身体接触次数与成绩直接相关——团队的纽带强度是可观察、可测试的评估变量。
4. **客户锁定判定标准（用时间投入度量转换成本）**。看客户是否把时间与资源投入产品：学习使用、定制配置、上传内容、装插件、集成进工作流。投入越多转换成本越高，离开越痛苦；高锁定带来高利润率与长期增长，同时构成对手的进入壁垒。锁定是主链上"商业模式与变现"环节的核心判据。
5. **专利价值评估四问（先验证后专利）**。是否构成进入壁垒？开展业务是否必需？能否阻挡对手或收取许可费？绕开难度多大？大多数软件初创的专利无价值——Jawbone 数百专利仍破产，WhatsApp 零专利卖 190 亿美元。只有半导体、制药等资本密集核心技术才值得早期投入；其余公司先验证商业模式，找到产品市场匹配准备扩张后再把专利纳入长期 IP 策略。
6. **市场第一判据与趋势时机（赛道审察）**。目标必须是市场第一——做不了第一就换赛道；尽早搭上趋势并成为社区核心，趋势红利用社区占位兑现。反面警示：优步成功后的"共享一切"公司大多倒闭，一窝蜂追同一趋势不等于站上趋势，赛道审察必须区分"趋势本身"与"拥挤的模仿者"。
7. **尽调透明度（评估的最后一环，也是双向测试）**。投资人对管理团队每位成员单独提相同问题、比较笔记检验一致性，再核查文档与数据权限。公司侧对策：全员口径一致、签 TS 前披露所有实质性信息——隐瞒等于说谎，细节终会浮出水面，越早披露代价越小；协议副本（股权结构表、章程、专利、雇用协议）集中存于云文件夹随取随用。透明度本身是评估变量：藏着掖着的公司直接出局。

## A1 — 书中的应用 (Past Application)

### 案例 1: WhatsApp——零专利卖出 190 亿美元
- **问题**: 一款即时通讯应用没有专利组合，投资人如何判断它的价值与防御力？
- **方法论的使用**: 跳出"专利=壁垒"的惯性判据，用锁定与网络效应环节打分：数亿高频活跃用户、极高的留存与参与、网络效应构成真正的进入壁垒——专利四问的第一个问题"是否构成进入壁垒"被其他更强的壁垒回答。
- **结论**: 对多数软件公司，专利不是护城河，客户锁定与网络效应才是。
- **结果**: WhatsApp 以 190 亿美元被 Facebook 收购，专利数为零。

### 案例 2: 客户锁定群像——WordPress、HubSpot、微软、SAP
- **问题**: 如何判断一家 B2B/平台公司的利润率能否持续、对手能否撬走它的客户？
- **方法论的使用**: 用时间投入判定锁定强度——客户在 WordPress 上建的站点与内容、在 HubSpot 里集成的营销工作流、企业对微软/SAP 生态多年的学习与定制投入，都是沉没在产品里的时间与资源，转换成本随使用深度滚雪球。
- **结论**: 高锁定→高利润率→长期增长→对手进入壁垒，这一环得分高的公司才具备独角兽的利润结构。
- **结果**: 这些公司均形成长期锁定带来的持续收入与行业地位。

### 案例 3: NBER 研究——顶尖创始人的平均年龄是 45 岁
- **问题**: 投资人习惯用名校与年龄筛创始人，这样的团队深挖起点对不对？
- **方法论的使用**: 用数据校准筛选偏差：顶尖 0.1% 高增长创业公司创始人平均年龄 45 岁，50 岁创业者获得巨大成功的可能性几乎是 30 岁者的两倍；名校录取看考试与课外活动而非领导力，名校生终生收入与同分数段其他学校毕业生几乎无差别。正确做法是深挖五问——原创想法、说服与管理、克服障碍、失败教训、如何让人放弃六位数薪水跟自己走。
- **结论**: 名校、头衔、年龄都是噪音，真实领导力证据才是团队环节的得分项。
- **结果**: 用此标准的评估者不会系统性错过大器晚成者与叛逆者（马云、乔布斯、戴尔、布兰森都非名校出身）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想用投资人视角评估一家现成公司："这家公司值不值得投/能不能长成独角兽"，需要一条完整评估主链。
2. 创始人自审："我的公司离独角兽标准还差哪几环"——为融资前自查或董事会议题做准备。
3. 评估一个赛道/方向："这个赛道能不能出独角兽、我是不是做不了第一、趋势窗口还在不在"。
4. 深挖一个团队："这个 CEO 靠不靠谱、这个团队有没有独特元素"，或尽调攻防（口径一致性、文档透明度自查）。
5. 判断某个具体要素的价值："我们的专利有没有用、客户锁定够不够深、留存数据说明什么"。

### 语言信号 (用户的话里出现这些就应激活)

- "值不值得投""能不能成为独角兽""帮我评估这家公司/这个赛道""尽调该看什么"
- "这个 CEO 行不行""团队靠不靠谱""怎么判断创始人的真实水平""头衔/名校说明什么"
- "客户锁定""转换成本""留存率/DAU/MAU 说明什么""壁垒够不够深"
- "专利值不值钱""要不要申请专利挡对手""市场第一""趋势来了没有/时机对不对"

### 与相邻 skill 的区分

- 与 `design-business-model-and-moat` 的区别：本 skill 是**评估者视角**（用独角兽标准给一家现成公司/赛道打分，如尽调或自审）；后者是**设计者视角**（造模式、建护城河，服务自己的设计决策）。"这家公司过不过得了独角兽标准"找本 skill；"我的模式该怎么设计/定价/建护城河"转后者。两 skill 共享锁定、专利等概念，但本 skill 用它们打分，后者用它们设计。
- 与 `build-your-team-right` 的区别：本 skill 做**团队评估**（CEO 领导力深挖、独特元素观察，回答"这个团队行不行"）；后者做**招聘与用人执行**（合伙人选择、委员会评分、十人法则、解雇流程）。评估结论落到"该招什么人/怎么招/怎么换"时转后者。
- 与 `vc-dynamics-demystified` 的区别：后者解释风投的赚钱逻辑与行为动机（为什么拒绝你、退出体量门槛）；本 skill 是对**公司本身**的评估打分。判断"我的公司配不配得上风投的账"先用后者做匹配，再用本 skill 做公司体检。
- 与 `choose-your-funding-path` 的区别：后者回答"要不要融资、这笔钱该不该拿"的资金决策；本 skill 假设评估对象已定，回答"这家公司/赛道本身质量如何"。

## E — 可执行步骤 (Execution)

1. **跑一遍评估主链打分**：按 团队→市场规模→数据验证（DAU/MAU、留存）→趋势→产品→秘诀→变现→锁定→软硬件→专利→设计→媒体潜力→尽调透明→文化 的顺序，对目标公司逐环写下证据与 1-10 分
   - 完成标准：14 环每环有具体证据（数据、访谈记录或观察笔记）和一个分数；标出最先断裂的两环——它们决定整体结论，任何一环断裂即给出"不投/不达标"警告而非总分平均。
2. **对 CEO 与团队做深挖面谈**：用五问清单（原创想法？如何说服与管理？遇到什么障碍、如何克服？有无导致失败的决定、学到什么？如何说服人放弃六位数薪水选股权？），刻意忽略名校与大公司头衔；用集体活动观察成员互动与身体语言
   - 完成标准：五问每问有具体事例级回答（非套话）；写出至少一条"头衔之外的领导力证据"和一条"独特元素观察记录"；若只能给出简历级答案，团队环节判不合格。
3. **量化客户锁定**：列出客户在产品中投入的时间与资源清单（学习成本、定制配置、上传内容、插件、工作流集成），估算转换成本
   - 完成标准：锁定清单≥2 类实际投入且能引用客户行为证据；若客户零投入、随时可走，在"变现与锁定"环节记低分并写出补锁定方案或降级结论。
4. **用四问评估专利与"秘诀"**：专利是否构成进入壁垒？是否必需？能否阻挡对手或收许可费？绕开难度多大？同时盘点公司真正的独特"秘诀"
   - 完成标准：四问各有明确答案；明确判断专利是真壁垒还是装饰（默认软件初创专利无价值，除非属半导体、制药等资本密集核心技术）；写出至少一项比专利更实的壁垒（锁定、网络效应、数据、速度）。
5. **审赛道位置与尽调透明度**：判断公司能否做到市场第一、是否站在趋势上并成为社区核心（排除"共享一切"式拥挤模仿）；同时做透明度自查——全员对关键问题口径一致、实质性信息提前披露、协议副本集中云端可随时发出
   - 完成标准：对"市场第一"给出可辩护的判断（做不了第一就明确说换赛道/换切口）；尽调材料包（股权结构表、章程、专利、雇用协议）已集中在一个云文件夹、链接可 5 分钟内发出；发现任何隐瞒事项立即按"越早披露代价越小"处理。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要设计商业模式细节（选变现方式、定价、照搬模式要素检验、护城河设计）——转 `design-business-model-and-moat`；本 skill 只用这些概念打分，不产出设计方案。
- 要执行招聘、解雇、薪酬股权方案（委员会评分、十人法则、12 步解雇）——转 `build-your-team-right`；本 skill 只回答"这个团队行不行"。
- 要决定"要不要融资、该不该拿这笔钱"——转 `choose-your-funding-path`；本 skill 评估公司质量，不做资金决策。

### 作者在书中警告的失败模式（评估判断反例）

- **名校与头衔的筛选陷阱**：用 CEO 就读大学和大公司履历做筛选，会错过马云、乔布斯、戴尔、布兰森；副总裁可能只是优秀执行者甚至办公室政治玩家而非冒险家。深挖决策类型与承担的责任，别让文凭代替尽调。
- **CEO 把核心 IP 藏在个人名下**：作者尽调中发现后直接断绝合作——隐瞒关键信息一旦暴露，失去的不止一笔交易而是声誉与全部融资渠道。尽调透明度是硬门槛。
- **专利不是护城河**：Jawbone 拿 9 亿美元融资加数百项专利仍因质量、生产与设计问题破产；别把"有专利组合"误算作壁垒环节的得分。
- **一窝蜂追趋势≠站上趋势**：优步成功后涌现的共享洗衣、洗车、家政、停车、按摩、冰激凌公司绝大多数倒闭——评估赛道时要区分趋势本身与拥挤的模仿者，市场第一判据在一窝蜂赛道尤其致命。
- **把"礼貌性认可"当数据验证**：客户与投资人的口头赞美都不是留存数据；主链"数据验证"一环只认 DAU/MAU、留存率与行动式承诺，不认"大家都说喜欢"。

### 作者的盲点 / 时代局限

- 评估语境是 2012-2019 年的硅谷与中国一线互联网，主链权重偏向指数增长、网络效应与风险投资匹配；对利润优先的中小企业、传统行业公司，这套独角兽标准本身就是错配（作者自己也说绝大多数公司不该碰风投），评估前先确认对象是否适用独角兽框架。
- "目标必须是市场第一"是风投赛道的狠判据；在利基市场做"小而美"的第一名之外的健康生意，不必因此被判死刑。
- 团队"独特元素"观察法（身体语言、伯克利身体接触研究）证据强度弱于数据环节，宜作辅助信号而非否决项。

### 容易混淆的邻近方法论

- **评估主链（f43）≠ 融资流程（f17）**：主链是给公司打分的静态检查单；融资十步是推进交易的动态管道。尽调只是主链最后一环，别把"跑完融资流程"误当成"通过评估"。
- **客户锁定（f50）≠ 用户活跃**：DAU/MAU 高不等于锁定深——高频使用但零投入（无定制、无集成）的产品转换成本依然很低；两个指标分别落在主链不同环节。
- **专利四问（f51）≠ 不做专利**：结论是"先验证后专利"的时序判断，不是永久放弃 IP；找到产品市场匹配准备扩张后仍应把专利纳入长期 IP 策略。
- **尽调透明（f52）≠ 全员统一口径说谎**：口径一致的前提是提前披露所有实质性信息；用一致口径掩盖隐瞒恰恰是主链最后一环的直接出局项。
- **个人品质重于头衔（p61）≠ 学历无用论**：判据是"别用头衔做筛选器"，具体评估仍要深挖决策类型与实际承担的责任。
