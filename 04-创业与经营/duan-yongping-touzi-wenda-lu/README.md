# 段永平投资问答录（全两册）

由孙力科编撰的《段永平投资问答录（全两册）》蒸馏出的一组**可被 AI Agent 调用的技能**（Skills）。

> 段永平用"买股票就是买公司"这一句话统摄全部投资哲学——以本分、平常心和能力圈为底色，用"毛估估"看懂企业未来十年，只在自己懂的好公司便宜时重仓出手，然后拿住不动。上册讲股票投资的"道与术"（认知门槛 → 买公司 → 估值 → 长线/集中/时机 → 心态与风控），下册讲理念的"来处与验证"（步步高创业史、经营哲学与人生观），两册互为表里。16 个技能按"投资第一性 → 估值与买卖 → 心性与风控 → 经营哲学 → 组织与人生"五组编排。

## 16 个技能

**投资第一性：世界观与资格闸门**
- [`benben-do-right-things`](skills/benben-do-right-things/SKILL.md) — **本分与做对的事情**：整个体系的哲学底座——先分对错再谈方法，本分＝说话算数/不占人便宜/有所不为，半目胜比谁犯错少。
- [`buy-stock-is-buy-company`](skills/buy-stock-is-buy-company/SKILL.md) — **买股票就是买公司**：第一原则——整公司收购检验、股票由每个买家自己定价、买前想好持有 10–20 年。
- [`circle-of-competence-homework`](skills/circle-of-competence-homework/SKILL.md) — **能力圈与做功课**：判断"我到底懂不懂这家公司"，不懂不做、独立判断不外包、只投守信用企业。
- [`ignore-market-noise`](skills/ignore-market-noise/SKILL.md) — **隔离市场先生**：不预测不择时、不看图不看线不看盘、不听华尔街不跟风、不代客理财（约法三章）。

**估值与买卖：选对与出手的纪律**
- [`business-model-moat-checklist`](skills/business-model-moat-checklist/SKILL.md) — **商业模式三查**：护城河（长期维持的差异化）、定价权/经济特许权、毛利率与长期净现金流，苹果四要素示范。
- [`rough-valuation-look-10-years`](skills/rough-valuation-look-10-years/SKILL.md) — **毛估估看十年**：估值是功夫不是公式——"看十年"定贵贱、存款利率类比＋打折法倒算、市盈率下行兜底。
- [`concentrated-few-bets`](skills/concentrated-few-bets/SKILL.md) — **集中投资少出手**：一生只出手 20 次、绝对集中（同时约三家）、巴菲特 25/5 法则、守株待兔空仓等待。
- [`buy-sell-discipline`](skills/buy-sell-discipline/SKILL.md) — **买卖判据**：买入理由消失才卖、"我已经赚钱了"不是卖出理由、不挣最后一个铜板、有好公司好价钱就满仓。

**心性与风控：拿得住、活得了**
- [`hold-long-term-mindset`](skills/hold-long-term-mindset/SKILL.md) — **拿住好公司的心法**：称重机信仰、拿住六要素自查、不设回报期望、大跌时舒服地买入。
- [`stop-doing-list-risk-control`](skills/stop-doing-list-risk-control/SKILL.md) — **不为清单与风险底线**：不做空不杠杆不负债、用闲钱、守正不出奇、发现错了马上改。

**经营哲学：步步高系的取与舍**
- [`profit-above-profit-consumer-focus`](skills/profit-above-profit-consumer-focus/SKILL.md) — **利润之上的追求**：消费者导向分层、不打价格战走提升价值之路、反盲目多元化。
- [`dare-to-be-later`](skills/dare-to-be-later/SKILL.md) — **敢为天下后**：后发制人、等看清了再进入、集中优势兵力快速切入、十年基本功是底气。
- [`bbk-business-philosophy`](skills/bbk-business-philosophy/SKILL.md) — **经营理念八大取舍**：安全抵达不是快速抵达、宁做赚钱的小公司、员工尊严高于业务利润、广告是技术不是艺术、利益链共盈。
- [`bbk-product-channel-playbook`](skills/bbk-product-channel-playbook/SKILL.md) — **产品渠道落地打法**：自研品牌、品质负责制（返修率 0.3%）、代理制一荣俱荣、借钱送股全员持股、鸡肋原则、渠道统一提货价。

**组织与人生：文化的长效与过程的乐趣**
- [`corp-culture-people-system`](skills/corp-culture-people-system/SKILL.md) — **企业文化与组织机制**：M/V/CV 三件套、造钟人摆脱个人依赖、内部反对派防一言堂、一分为三分拆放权、合适性优先于合格性。
- [`life-philosophy-wealth-view`](skills/life-philosophy-wealth-view/SKILL.md) — **人生哲学与财富观**：乐趣在于过程、陪伴家人比工作重要、快乐人生才是最大的财富、花钱比赚钱难、不剥夺孩子的获取过程。
