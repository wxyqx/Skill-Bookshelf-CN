# 买卖判据与成本隔离：让买入理由决定去留，让成本价闭嘴

## R — 原文 (Reading)

> "我也不知道啥时候卖好，当我买一只股票时，一定会有个买的理由，同时也要看到负面的东西，当买的理由消失了，或者重要的负面消息增加到我不能接受的时候，我就会离场。当然，太贵了有时也会成为离场的理由，如果真是特别好的公司，稍微贵一点未必要卖，不然往往买不回来，机会成本大。"
>
> — 【段】段永平，上册 ch04 / ch06（卖出三条件与成本隔离，f09 单元；两处复现）

> "无论什么时候卖都不要和买的成本联系起来。该卖的理由可能有很多，唯一不该用的理由就是'我已经赚钱了'。不然的话，就很容易把好不容易找到的好公司以便宜的价钱卖了。买的时候也一样，买的理由可以有很多，但这只股票曾经到过什么价位最好不要作为你买的理由。"
>
> — 【段】段永平，下册 ch04（成本价锚定之诫，f09/e12 单元）

> "老巴经常有现金，原因和他的生意模式有关。仅就投资而言，如果有好公司好价钱，你为什么要留现金？"
>
> — 【段】段永平，上册 ch05（好公司好价钱不必留现金，p14 单元；答"是否要学巴菲特留现金"之问）

> 编者叙述：投资者一定要见好就收，避免挣最后一个铜板——股价接近高位时不要总想着最高点，应提前做好撤退的准备。前华人首富李嘉诚也说过，他从来不会挣最后一个铜板。
>
> — 【编】编者叙述并已标注，转引李嘉诚（p15 单元，上册 ch06）

> 编者叙述：只要意识到股票的上涨无法支撑自己的投资回报需求，就应该及时脱手，甚至一开始就避而远之——继续投资还是撤资离场，都和企业内在价值评估有关。
>
> — 【编】编者叙述并已标注（p15 单元，上册 ch06）

## I — 方法论骨架 (Interpretation)

这套纪律解决两件事：**什么时候卖**（答案：回到买入理由，而不是账户盈亏），以及**钱怎么摆**（答案：好公司好价钱就满仓，不为"留余地"而留现金）。成本价在整套体系里是被刻意隔离的干扰项。

1. **卖出的唯一锚是买入理由，不是价格也不是盈亏**：段永平自承"不知道啥时候卖好"——他不需要知道。买的理由还在就拿住，理由消失了就离场；卖出决策在买入那一刻就已经写好了判据。
2. **卖出三条件**：①买入理由消失；②重要负面消息增加到不能接受；③太贵了（估值离谱）。前两条关于"公司变了"，第三条关于"价格疯了"——三条都是价值判断，没有一条与你的成本价有关。
3. **成本隔离是铁律**："'我已经赚钱了'是唯一不该用的卖出理由"——用成本盈亏做决策，会把好不容易找到的好公司在便宜价位卖掉；同理，"曾经到过什么价位"也不能作为买入理由（等回本/锚定历史价都是成本心态的变体）。
4. **不挣最后一个铜板（见好就收）**：最高点不可预测，接近高位时提前做好撤退准备，把最后一段留给别人——估值兑现后"让更了解的人去挣剩下的钱"，挣有把握的那一段。
5. **有好公司好价钱就满仓**：巴菲特留现金与其生意模式（保险浮存金）有关；个人投资者找到"很想买的公司+好价位"时，"实在想不出不全部投资购买它的理由"——留现金等回调本质上是择时投机。
6. **满仓≠加杠杆**：满仓说的是把自有闲钱全部放到看懂的好机会上；借钱上杠杆做这件事是另一回事，属于风险底线（stop-doing-list-risk-control）的禁区。
7. **稍贵与太贵的区分**：特别好的公司"稍微贵一点未必要卖，不然往往买不回来，机会成本大"——卖出纪律同样要过"好公司"这道门槛，别为了躲小回调把好公司丢了。

## A1 — 书中的应用 (Past Application)

### 案例 1: 创维低买高卖——全周期的卖出纪律样本
- **问题**: 创维股价跌至 0.29 港元时市场恐慌，之后股价大幅上涨，何时卖、要不要挣到最后一段？
- **方法论的使用**: 0.29 港元买入后不因波动动摇；随着估值兑现（公司价值向 200 亿靠拢），按"太贵了/理由兑现"分批卖出，把"剩下的钱让更了解的人去挣"。
- **结论**: 卖出决策全程没有参考成本价——0.29 的成本既不是"赚够了就跑"的依据，也不是"再拿拿"的依据；起作用的是价值兑现程度与估值判断。
- **结果**: 完整走完低买—持有—估值兑现—分批离场的周期，是"见好就收、不挣最后一个铜板"的可复用样本。

### 案例 2: 苹果 47 美元建仓——成本隔离下的"好公司好价钱就满仓"
- **问题**: 苹果账上现金充裕、市值低于内在价值（"值 5000 亿则 3000 亿就是便宜"），但买入后一度下跌超 50%，账面深度亏损。
- **方法论的使用**: 买入理由（商业模式+企业文化+价格便宜）始终未变，成本价被完全隔离——下跌反倒是加仓机会，越跌越买直至重仓。
- **结论**: 若按"我已经亏钱了/回本再说"操作，好公司会在最便宜处被卖掉；满仓建立在"好公司+好价钱"上，而不是"这笔交易浮盈浮亏"上。
- **结果**: 苹果成为其仓位最重的持股，数十倍回报。

### 案例 3: 腾讯四次加仓——买入理由仍在，跌了只是更便宜
- **问题**: 腾讯股价在 53.5、42.71、37.37 美元等价位持续下跌，接还是不接？
- **方法论的使用**: 每次下跌都回到"买入理由是否消失"自查：生意与护城河没变、价格更便宜，理由不但没消失反而更强，于是逐级加仓。
- **结论**: "该不该卖/该不该补"的答案都在买入理由里——同一套判据管买也管卖；历史价位（曾经 70 美元）不构成任何决策依据。
- **结果**: 多次加仓摊低而非"接飞刀"心态，与 e15"等抄底执念"形成正反对照。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手里有持仓，纠结"现在该不该卖"——尤其盈利后想落袋为安，或亏损后想"等回本再卖"。
2. 在用成本价、历史最高价、账户盈亏指导买卖决策（"我都赚 50% 了""还没解套呢"）。
3. 纠结仓位该不该满仓、要不要留一部分现金"等回调"或"留个余地"。

### 语言信号 (用户的话里出现这些就应激活)

- "该不该卖""卖出条件是什么""什么时候离场""要不要落袋为安"
- "我已经赚钱了，要不要先卖一部分""等回本我就卖""我的成本是 X 元"
- "这只股票曾经到过 XX 价""见好就收""最后一个铜板""太贵了该不该卖"
- "要不要留点现金""巴菲特都留现金，我要不要也留着""满仓会不会太激进"

### 与相邻 skill 的区分

- 与 `hold-long-term-mindset` 的区别：用户是"公司没变、纯粹被波动吓得拿不住"→ 心态问题归后者；用户是"想主动决定卖不卖、在用盈亏成本做判据"→ 归本 skill。菜单原话："跌了想卖是因为买入逻辑坏了（→ buy-sell-discipline）"。
- 与 `rough-valuation-look-10-years` 的区别：本 skill 给出"太贵了也是离场理由"的方向性判据；具体"怎么毛估估算贵贱"归后者。用户若问"帮我算算值不值这个价"，转后者。
- 与 `stop-doing-list-risk-control` 的区别：本 skill 管"现有持仓的去留与满仓决策"；做空/杠杆/借钱/认错纠错归后者。注意满仓≠杠杆的边界。
- 与 `buy-stock-is-buy-company` 的区别：后者是买什么（公司 vs 筹码）的决策框架与买前定价；本 skill 是买入之后的去留判据与资金摆布。
- 与 `concentrated-few-bets` 的区别：集中度、出手次数、空仓等待机会归后者；本 skill 只回答"这笔该不该卖、要不要留现金"。

## E — 可执行步骤 (Execution)

1. **写下买入理由**：翻出（或补写）当初买入的理由清单——生意、护城河、管理层、价格，逐条落纸
   - 完成标准：理由清单是关于公司的陈述，不含任何成本价、历史股价、账户盈亏字样。
2. **逐条核对理由是否消失**：对每条买入理由问"现在还成立吗？有没有重要负面消息增加到不能接受？"
   - 完成标准：每条给出"成立/消失"结论及证据；任何一条消失即触发离场评估，与当前是赚是亏无关。
3. **做估值兑现检查**：用毛估估判断当前价格是否进入"太贵"区间；区分"稍贵"与"太贵"——特别好的公司稍贵不卖（买不回来，机会成本大）
   - 完成标准：给出"理由仍在且不贵/理由仍在但太贵/理由消失"三选一结论；"太贵"时按见好就收分批撤退，不追求最高点。
4. **成本隔离自检**：检查拟议决策中是否混入成本价、"已经赚钱了""等回本""曾经到过什么价"等表述
   - 完成标准：最终决策理由里一个成本类字眼都没有；若发现，删掉后重推一遍，看结论是否改变——若改变，说明原决策是成本心态驱动的。
5. **决定资金摆布**：若结论是"好公司+好价钱且看得懂"，满仓买入不留现金；若只是"怕回调"，那不是留现金的理由而是没看懂的信号
   - 完成标准：满仓只用在"很想买的公司+好价位"上，且用的是闲钱（借贷加杠杆另行触发 stop-doing-list-risk-control）；留现金须能说出"在等什么更好的标的"，而非"等回调"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有具体持仓决策，只是被行情波动折磨得拿不住 → `hold-long-term-mindset`。
- 用户想赌反弹、抢抄底、上杠杆 → `stop-doing-list-risk-control`（抄底是投机概念）。
- 用户问的是"这个价格怎么算贵不贵" → `rough-valuation-look-10-years`。

### 作者在书中警告的失败模式（反例池 F5/F8 家族）

- **成本价锚定（e12）**："该卖的理由可能有很多，唯一不该用的理由就是'我已经赚钱了'"——用成本盈亏指导卖出，好公司会在便宜处被卖飞。
- **等回本再说（e13）**：把"解套"当目标，等于让过去的成本绑架未来的决策（停车场币实验：忘了成本，你还持有吗？）。
- **教条式永久持有（e17）**："买的理由消失了……我就会离场"——长期持有是理由仍在的结果，不是免死金牌；与 e08 的边界：圈内看懂拿住是纪律，理由消失还死扛是灾难。
- **高位买入伟大公司（e18，编者推论）**：好公司≠任意价格，"太贵了有时也会成为离场的理由"同样约束买入端——为伟大付任意价违背同一条纪律。
- **赌场资金效应（e14，行为金融学脚注，通条为编者叙述）**：把浮盈当"庄家的钱"去冒险，是成本隔离失败的另一面——账面盈利已是你真实的钱。

### 作者的盲点 / 时代局限

- "买入理由消失才卖"要求买入时就写下清晰可核验的理由，本书未给出理由清单的模板化方法，依赖投资者自身商业判断功底。
- p15"见好就收"系编者叙述与李嘉诚转引，段氏本人的卖出案例（创维）样本少；"太贵了未必要卖"与"见好就收"之间存在张力，如何把握"稍贵 vs 太贵"没有量化标准，实际依赖毛估估功力。
- "有好公司好价钱就满仓"隐含投资者有稳定的闲钱现金流与强大心理承受力；对需要流动性缓冲的普通人，机械满仓可能诱发被迫卖出。

### 容易混淆的邻近方法论

- **止损（技术分析意义）**：传统止损按"跌幅达到 X%"触发，本质仍是价格与成本锚定；段氏纪律按"理由消失"触发，两者机制完全不同——唯一的例外是买错了公司，那时"马上改"（p04）就是最好的止损。
- **止盈/目标价**：设目标价是预测最高点；段氏反对预测顶点，只按估值兑现程度与"不挣最后一个铜板"的原则分批离场。
- **仓位管理（机构风控）**：机构按波动率/回撤模型调仓；段氏满仓逻辑建立在"看懂+好价钱"上，二者前提与工具不同，勿混用。
