# 企业文化与组织用人：造钟，不报时

## R — 原文 (Reading)

> "企业文化就是企业里这帮人的Mission、Vision、Core Values，使命是为什么成立，远景是我们要去哪里，核心价值观是哪些事是对的，哪些事是不对的。"
>
> — 【段】段永平，下册 ch14（企业文化 M/V/CV 三件套，f23 单元）

> "我在公司里是个反对派，几乎做什么我都会提反对意见。如果连我的反对意见大家都不怕时，不管做什么我都会放心一些。我最怕的就是，老板说什么，大家都说'好'，那时公司就危险了。"
>
> — 【段】段永平，下册 ch14（内部反对派机制，f27 单元）

> "步步高有三个工厂，三个主要负责人，三群股东，分别集中精力做自己的产品，搞独立核算。"
>
> — 【段】段永平，下册 ch12（一分为三分拆放权，f36 单元）

> "我们选人的标准是合适性与合格性原则，合适性是指你对企业的核心价值观、理念是否认同。如果合格性不够，可以通过培训成长；如果非常能干，却不接受企业的理念，那他就会成为害群之马。"
>
> — 【段】段永平，下册 ch12（合适性优先于合格性，f37 单元）

> "放手去干，干好了分钱，干不好关门，别有负担。"
>
> — 【段】段永平，下册 ch12（影子董事长心法，p34 单元）

> 编者归纳：造钟的人会打造一套完善、高效、优秀的企业文化以及相应的制度，可以确保企业持续地运转下去（引自柯林斯《基业长青》）；产品和技术都可以模仿，而企业文化是内在生成的、无法被模仿，是基业长青之本。
>
> — 【编】编者转述并已标注（f22 单元引柯林斯、p31 单元）

## I — 方法论骨架 (Interpretation)

这套方法论回答两个问题：企业靠什么活得长（文化），以及人怎么选、权怎么放（组织）。核心是**造钟而非报时**——把企业从"靠老板个人"改造成"靠文化与制度自动运转"。

1. **文化先有操作性定义**：企业文化不是墙上的标语，就是这帮人的 Mission（为什么成立）、Vision（要去哪里）、Core Values（哪些事对、哪些事不对）——三件套缺一不可，说得出来才算有。
2. **文化是护城河的底座**：产品和技术都能被模仿，唯有文化是内在生成、无法模仿的；企业文化像木桶的底——底没了，板再长也装不了水。
3. **造钟人思维**：报时人靠个人能力报时，人一走钟就停；造钟人建文化与制度，人不在了时钟照样报时。基业长青的检验是"创始人离场后体系是否照转"。
4. **反对派机制防一言堂**：老板要主动当"反对派"，连老板的反对意见大家都不怕时，决策才让人放心；"老板说什么大家都说好"是公司最危险的时刻。真话通道必须由老板亲手打通。
5. **用结构解决规模问题——一分为三**：与其长成大企业病缠身的巨物，不如按"人随事走、股权独立、互无从属"分拆，独立核算、各做各的产品，老板只保留少量股权与影响。
6. **选人先问合适性**：合格性（能力）不够可以培训，合适性（认同核心价值观）没有就是害群之马——非常能干但不认同理念的人，能力越强破坏越大。
7. **放权建立在了解与信任上，且要真放**：放权渐进、因人而异，但一旦放出就"放手去干，干好了分钱，干不好关门"；老板退到"董事长"位置，做那个员工敢对他说真话的缓冲人，而不是垂帘听政。

## A1 — 书中的应用 (Past Application)

### 案例 1: 步步高一分为三（用分拆回答"接班与放权"）
- **问题**: 1999 年步步高做大后面临大企业病与接班问题：三个工厂三群股东，业务异质，一个总部管不动，也不该由一人管。
- **方法论的使用**: 按"人随事走、股权独立、互无从属"把公司拆为三家独立公司——视听归陈明永（OPPO）、通信归沈炜（vivo）、教育归黄一禾，段永平在各家只持约 10% 股份，不干涉具体业务。
- **结论**: 放权不是姿态而是结构：股权独立 + 独立核算让"放手"有了制度保障；老板从经营者变成造钟人。
- **结果**: 三家各自长成独立头部企业，段永平本人得以退居幕后做投资。

### 案例 2: 华强北放行 OPPO 做手机（握否决权却不用）
- **问题**: OPPO 要不要做手机，作为大股东/董事长，段永平握有一票否决权。
- **方法论的使用**: 他看懂团队、信任其判断，否决权放在手里却不行使，让更懂业务的人拍板；"放手去干，干好了分钱，干不好关门，别有负担"。
- **结论**: 影子董事长的要义是"有权不用"——否决权是安全网而非方向盘；优秀的投资者/老板不必掌控，让更合适的人领导。
- **结果**: OPPO 手机大获成功；与"8 个月等一个人才"（陈明永用人）同属步步高系放权信任的注脚。

### 案例 3: 8 个月等一个人才（合适性优先的选人样本）
- **问题**: 关键岗位需要人，候选人有能力但要不要将就？
- **方法论的使用**: 陈明永为合适的人等了 8 个月——换位思考、建立长期信任；依据正是"合适性优先于合格性"：理念不认同的能干人会成为害群之马，而合格性可以靠培训补。
- **结论**: 选人宁缺毋滥，缺的是"合适"而非"合格"；等人的成本远低于用错人的成本。
- **结果**: 长期信任换来核心团队的稳定与忠诚。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创业公司要建立或改造企业文化：说不清使命愿景价值观，或文化停留在墙上的标语。
2. 设计放权/接班机制：公司离了老板就转不动、想分拆事业部、纠结要不要放权和怎么放。
3. 选人用人的两难：来了个很能干但不认同公司理念的人；关键岗位是将就将就还是等。
4. 担心一言堂：开会没人反对、没人敢提意见、决策全靠老板拍板。

### 语言信号 (用户的话里出现这些就应激活)

- "企业文化""使命/愿景/核心价值观怎么写""文化是不是虚的"
- "造钟人""报时人""离了我就转不动""接班""传承"
- "放权""授权""分拆""独立核算""一分为三"
- "合适性""合格性""能干但不认同理念的人""要不要等对的人"
- "开会没人敢说真话""大家都说好""一言堂""反对意见"

### 与相邻 skill 的区分

- 与 `bbk-business-philosophy` 的区别：本 skill 处理组织与文化机制（文化定义、放权、选人）；后者处理经营理念取舍（速度与安全、规模与盈利、员工尊严、同行关系）。"怎么组织人"归这里，"怎么对待经营中的价值冲突"归那里。
- 与 `bbk-product-channel-playbook` 的区别：股权/期权激励机制的具体打法（全员股份、借钱送股）归后者；本 skill 讲的是放权与选人的人事结构，不是激励工具包。
- 与 `dare-to-be-later` 的区别：要不要进入新市场、什么时机进入归后者；本 skill 是进入之后"靠什么人和什么体系把它做好"。
- 与 `benben-do-right-things` 的区别：本分/做对的事情是价值观的哲学底座（道）；本 skill 是把价值观落成组织机制（术的层面——制度、选人、放权）。

## E — 可执行步骤 (Execution)

1. **给文化下操作性定义**：把 Mission（为什么成立）、Vision（要去哪里）、Core Values（哪些事对、哪些事不对）各写成一句能落地的表述，不许用"追求卓越"这类空话
   - 完成标准：三句话写完后，能拿任意一件真实决策事例检验"这件事在我们这里是对还是不对"，且答案无歧义；写不出判例即返工。
2. **做造钟人自查**：列出"离了我公司会停摆"的事项清单
   - 完成标准：每项停摆事项都对应一个文化与制度补丁（流程/授权/接班人）；三个月后清单不增长即算制度在生长。
3. **装上反对派机制**：老板对重要决策先自提反对意见，并公开奖励唱反调的人
   - 完成标准：上一次重要决策有书面记录的反对意见且未提出者未被惩罚；若"老板说什么大家都说好"出现，视为红色警报。
4. **按合适性选人**：对关键候选人先测理念认同（合适性），再评能力（合格性）
   - 完成标准：每次用人决策留下两栏记录——"认同我们的核心价值观吗 / 能力差距能否培训补足"；合适性不过关者一票否决，无论多能干；关键岗位宁可等（参照等 8 个月的耐心）。
5. **渐进放权并真放**：按了解与信任程度因人授权，放出后"干好了分钱，干不好关门"，否决权只作安全网
   - 完成标准：有一份书面授权清单（谁、放什么、什么底线）；过去一季度老板对已授权事项实际未行使否决/干预；干预了就收回授权清单重新谈，而不是暗中垂帘。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是经营理念取舍（要不要快、要不要做大、员工尊严、怎么对待同行）——转 `bbk-business-philosophy`。
- 用户问的是要不要抢先进入某市场/新产品的进入时机——转 `dare-to-be-later`。
- 用户要的是渠道、品牌、期权股份等具体激励与打法设计——转 `bbk-product-channel-playbook`。

### 作者在书中警告的失败模式（反例池 F11/F12 家族）

- **盲目认同的会议室文化（e26）**："我最怕的就是，老板说什么大家都说好"——一言堂不是忠诚而是公司危险信号；反对派机制是它的正面解。
- **个人英雄主义的脆弱性（e28，编者推论）**：报时人式企业离了关键人物就失向——对照造钟人框架（t22）理解，引用时注意此条为编者推论而非段氏原话。
- **雷曼文化变质（e27）**：150 年辉煌不能保证未来，文化变质先于业务崩塌——企业文化不是软话题，是生死线；与 c12（雷曼练手学费）互为投资侧镜面。
- **机制逐人（e24 小霸王陨落）**：股改被否、骨干出走、营收下滑——同一批人，段永平在步步高用全员股份与放权留住了，母集团的机制把人逼走了；与 c22/c26 正反配对。
- **生搬硬套西方制度（e25，编者概括）**：文化是内在生成的（p31），照抄别人的制度条文长不出自己的文化——"画虎不成反类犬"。

### 作者的盲点 / 时代局限

- 段永平的分拆放权以他个人对三位接班人长达十余年的了解与信任为前提——没有这种"了解存量"的普通公司照搬一分为三，容易变成失控的诸侯割据。
- "影子董事长"模式依赖老板本人已功成名就、无生存焦虑；处于生死线上的初创企业直接模仿"有权不用"风险极高。
- 书中案例均来自步步高系内部（OPPO/vivo/小天才），缺少"文化建坏了怎么修复"的负面样本与修复路径。

### 容易混淆的邻近方法论

- **企业文化 = 团建/标语**：段氏定义是 Mission/Vision/Core Values 三件套的实指，能拿来做对错判断；唱歌跳舞、口号横幅不是文化。
- **放权 = 授权 KPI 管理**：本 skill 的放权建立在"合适性选人 + 信任"之上，是人对人的托付；职业经理人式的 KPI 授权是另一套逻辑，缺了合适性前提会变成"非常能干的害群之马"。
- **分拆 = 业务多元化**：一分为三不是做多几门生意，而是把"三厂三负责人三群股东"的既成结构用股权与独立核算固化，防止大企业病；与多元化扩张方向相反。
