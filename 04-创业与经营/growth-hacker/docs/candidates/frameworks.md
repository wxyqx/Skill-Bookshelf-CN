type: framework
source_chapter: 第1章 什么是"增长黑客"
source_quote: |
  根据不同阶段用户参与行为的深度和类型，我们可以将增长目标拆分并概括为"AARRR"转化漏斗模型，即：Acquisition（获取用户）、Activation（激发活跃）、Retention（提高留存）、Revenue（增加收入）、Referral（传播推荐）。
summary: |
  全书的总骨架：把"增长"这个模糊目标拆解为获取→活跃→留存→收入→传播五个可分别优化、层层转化的环节，构成螺旋上升的使用周期闭环。
  用法：诊断增长问题时先定位卡在哪个环节，再对该环节单独设计实验，减少每环的不必要损耗。
  本书第3-7章即按此漏斗逐环展开，可作为任何产品增长问题的顶层分析框架。

title: A/B 测试基本规范
type: framework
source_chapter: 第4章 A/B测试，网站活跃率提升的法宝
source_quote: |
  A/B测试的基本思想包括：
  提供两个方案并行测试。
  不同方案之间只存在一个变量，排除其他干扰因素。
  以某种标准判定结果优劣，筛出最优方案。
summary: |
  实验三原则：双方案并行、单变量（方案优劣与适配环境密不可分，不能拿复杂变量对比）、预先设定判定标准。
  预期管理：微软仅 1/3 测试有效，谷歌 12000+ 次测试仅 10% 带来业务变化——"产品不息，测试不止"，失败结果同样有价值（终结无意义争吵、省下无效消耗）。
  陷阱警示：勿陷入点滴微优化而错过跃进式改变（谷歌 41 种蓝色）；移动端架构若限制实验方法，会导出失真结论（百姓网"投递简历"按钮胁迫点击的假象）。
