# 借势营销与"营销前置"思维

## R — 原文 (Reading)

> "当网络热点爆发后，聪明的产品懂得借势营销，将产品的推广融入到用户喜闻乐见的语境中，通过争夺用户的注意力加强自身的曝光和转化。聪明的借势可以事半功倍。"
>
> — 范冰，《增长黑客》第7章 7.3 借势营销，乘势而上

---

## I — 方法论骨架 (Interpretation)

社交网络时代信息爆发-衰减极快，热点是免费的注意力洪峰，但借势的成败取决于两件事：**时机**与**连接**。时机上，借势是"时机的艺术"——只在热点爆发期（信息扩散最快、全民都在讨论的窗口）把推广融进用户语境，热点降温后跟风只是自说自话。连接上，话题必须简明可转述（一句话就能复述清楚），且与自身产品价值有真实连接——生硬硬广式的蹭热点无法转化。比借势更高一层是"营销前置"：为可预测的节点（节日、周期性刚需如春运抢票）在产品研发阶段就预埋卖点与推广节奏，让产品版本本身为营销而设计，而不是临时跟风。追热点是被动反应，营销前置是主动设局。

## A1 — 书中的应用 (Past Application)

（本单元在聚类总表 A1 列为"—"，以下为 verified.md 单元 U19 内的三组书中证据。）

### 证据 1: 去啊 vs 去哪儿文案大战（第7章）
- **问题**: 行业话题战爆发期，小网站毫无预算参与曝光。
- **方法论的使用**: 顺势搭上"去啊/去哪儿"文案大战的语境，用同款句式让自家品牌在话题流里露脸。
- **结果**: 小网站以近乎零成本获得了原本买不到的曝光量——借势的本质是蹭话题自身的传播力。

### 证据 2: SegmentFault 光棍节程序员闯关秀（第7章）
- **问题**: 程序员社区如何借节点拉新。
- **方法论的使用**: 在光棍节节点策划"程序员闯关秀"活动，节点（全民话题日）× 人群（程序员自嘲文化）双重契合。
- **结果**: 活动使注册量翻 18 倍——节点营销对目标人群契合时的爆发力。

### 证据 3: 猎豹"春运抢票版"（第7章）
- **问题**: 浏览器已是老产品，如何制造新增长话题。
- **方法论的使用**: "营销前置"——在产品研发阶段就把抢票功能（实为预装插件）做进版本，春运到来时以"抢票版"名义发布，产品为营销而设计。
- **结果**: 老产品借周期性刚需节点翻红，"新版本"成为话题本身。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 热点事件正在爆发，团队在争论"追不追、怎么追、来不来得及"。
2. 为节日或周期性节点（双11、春节、高考、春运）提前规划营销节奏。
3. 评估一张借势海报/文案：是融入了语境还是生硬硬广。
4. 复盘"热点过了才反应过来"或"蹭了但没转化"的失败。
5. 问"怎么做到每次热点都能第一时间跟上"（引向营销前置）。

### 语言信号 (用户的话里出现这些就应激活)

- "蹭热点 / 借势 / 这个热点要不要追"
- "借势营销 / 热点海报 / 节日营销方案"
- "营销前置 / 提前为节点做规划"
- "热点来了怎么快速反应 / moment marketing"

### 与相邻 skill 的区分

- 与 `external-viral-loop` 的区别：借势是搭现成热点的顺风车（不改产品、不建活动体系）；在主产品外另做 H5 游戏/测试/漏洞话题来自己制造传播属于 external-viral-loop。两者可叠加（热点节点上发布体外活动）。
- 与 `content-marketing-engine` 的区别：内容营销是持续输出的常设引擎（引流/培养/转化三作用）；借势是围绕单一热点的瞬时爆发，两者是"常设"与"闪击"的关系。
- 与 `viral-k-factor` 的区别：借势不改变产品的传播结构，只争夺注意力曝光；产品内传播机制设计是另一层。

## E — 可执行步骤 (Execution)

1. **判断热点真伪与时机窗口**
   - 问三件事：热点是否处于爆发期（还在扩散上升而非衰减）？话题能否一句话转述？与产品价值有无真实连接？
   - 完成标准：给出"追/不追"结论 + 三问的具体答案。
   - 判停条件：无真实连接、或时机已过爆发期、或属灾难/悲剧类不宜借势的话题 → 明确不追，记录观察备档。

2. **把推广融入用户语境**
   - 用话题自身的句式/梗/情绪承载产品信息，让用户在消费热点时自然看到产品，而非打断式硬广。
   - 完成标准：产出文案/海报方案，且通过"一句话可转述 + 含产品价值点"双重检验。

3. **营销前置：节点预埋**
   - 把可预测节点（节日/周期性刚需）整理成节点-卖点映射表，在产品研发阶段就为节点预埋功能卖点与发布节奏。
   - 完成标准：产出至少覆盖未来两个季度的节点清单及对应的版本/内容安排。

4. **合规与风险自查**
   - 事实准确性、版权/肖像权、话题敏感度（灾难政治类禁蹭）。
   - 完成标准：方案过 `growth-ethics-redlines` 三道闸后放行。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 灾难、事故、悲剧事件强行借势——即使能换曝光，也在道德上输得一败涂地（转 growth-ethics-redlines 一票否决）。
- 与产品毫无连接的纯跟风海报：用户记住了热点，记不住你；曝光不等于转化。

### 作者在书中警告的失败模式

- 话题型打法生命周期极短，与 Bug 营销同属"短命爆发"：赌错时机或语境即白忙。
- 书中案例全是赢家（去啊大战、SegmentFault、猎豹），借势失败与无人喝彩的沉默大多数未被统计——幸存者偏差。

### 作者的盲点 / 时代局限

- **时效警示：2015 年快照。** 热点的传播节奏、爆发期时长与参与玩法已彻底改变（算法信息流、短视频、热搜机制取代了微博时代的文案接力），"爆发期几小时到一两天"等参数层**按当期重查**；本 skill 只保留判断逻辑层（时机判断 + 可转述性 + 真实连接 + 营销前置）。猎豹"春运抢票版"的插件预装手法也已触及当代应用商店与浏览器扩展政策红线。
- 与 `external-viral-loop` 的混淆点：若用户话题从"蹭这个热点"滑向"做个活动来传播"，应切换/叠加 external-viral-loop。
