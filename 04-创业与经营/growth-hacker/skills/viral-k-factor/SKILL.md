# 病毒循环 K 值设计器

## R — 原文 (Reading)

> "K因子，用于评判病毒传播的覆盖面。其公式为：K因子＝感染率X转化率。……1个K因子表示平均1个用户能带来1个新用户。……病毒循环周期，是指从用户发出病毒邀请，到新用户完成转化（如点击阅读、注册、消费的行为）所花费的时间。"
>
> — 范冰，《增长黑客》第7章 7.1 用病毒传播撬动增长的杠杆

---

## I — 方法论骨架 (Interpretation)

病毒传播不是玄学，而是由两个可测量的量刻画的系统：

- **K 因子**管覆盖面：K = 感染率（平均一个用户向多少人发出邀请）× 转化率（收到邀请的人里有多少真的完成转化）。K>1 意味着每个用户平均带来超过一个新用户，产品才算具备"不靠外力也能长大"的自增长能力。
- **病毒循环周期**管速度：从发出邀请到对方完成转化花多久。同样的 K 值，周期短一倍，增长速度快一倍。

设计顺序上，好的病毒机制是"产品用起来顺手、分享就是自然动作"，先在产品内埋下真实使用场景里的传播因子（邮件签名、分享解锁、邀请注册），再为分享动作匹配至少一种用户心理触发器（喜爱、逐利、互惠、求助、炫耀、稀缺、怕错过、懒惰八种）。诊断顺序上，用双指标拆解找瓶颈：感染率低→扩充邀请渠道；转化率低→优化落地页、缩短注册路径；周期太长→简化操作并制造紧迫感。底线判断：传播机制只是放大器，产品本身足够好才是最佳的传播因素。

## A1 — 书中的应用 (Past Application)

### 案例 1: Hotmail 邮件签名病毒营销（c01）
- **问题**: Hotmail 刚推出时反响平平，没钱投路边广告牌和电台，需要精准找到"已有邮件使用习惯的人"。
- **方法论的使用**: 放弃传统广告，在每封 Hotmail 发出邮件的末尾签名处加一行附言"快来 Hotmail 申请你的免费邮箱"——产品在使用它的动作里自带了传播因子，且每个接收者天然就是精准人群（本来就用邮件）。
- **结论**: 感染率和转化率同时最大化：邮件接收者即目标用户（高转化），发邮件是高频动作（高感染面）。
- **结果**: 6 个月获 100 万用户，一年半后卖给微软时全球用户达 1200 万（当时全球网民仅约 7000 万）。"病毒营销"术语由此诞生。

### 案例 2: LinkedIn 双重病毒循环（c10）
- **问题**: 上线初期高达 50% 的注册用户是沉默用户，用户量和活跃度止步不前。
- **方法论的使用**: 用 A/B 测试找出邀请好友的魔法数字"4"（少于 4 易被忽略、多于 4 让人焦虑）提高邀请转化率；开发 Outlook 插件导入本地通讯录提高感染率；再设计"双重病毒循环"——新用户带新用户的循环 + 新用户注册动作（好友请求、资料被浏览通知）唤回老用户的循环同时运转。
- **结论**: K 值优化不止一条腿：感染率（通讯录/渠道）、转化率（魔法数字 4、邮件文案讲清"对对方的价值"）分别有专门杠杆。
- **结果**: PV 提升 41%、站内搜索量提升 33%、资料页完成度提升 38%；2008 年累积 1300 万注册用户。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 邀请/推荐功能已上线但 K<1，问"为什么产品没有自增长、该改哪里"。
2. 设计新产品时想让"产品自带增长引擎"，讨论要不要加邀请奖励、分享解锁、签名推广。
3. 手上有 referral 数据（感染率、转化率、周期），要做瓶颈诊断。
4. 讨论八种用户心理与分享动作的匹配（为什么这个活动没人转发）。
5. 直接问 K 因子 / viral loop / 双重病毒循环等概念怎么算、怎么用。

### 语言信号 (用户的话里出现这些就应激活)

- "K 因子只有 0.3 / K factor 怎么算 / 病毒系数"
- "为什么用户不邀请朋友 / 邀请转化率太低"
- "想做个 referral program / 分享解锁功能"
- "自增长 / viral loop / 病毒式传播机制"

### 与相邻 skill 的区分

- 与 `external-viral-loop` 的区别：本 skill 管**产品内建**的传播机制（邀请、签名、分享解锁、K 值度量）；在主产品之外另做 H5 活动、Bug 营销、测试类传播属于 external-viral-loop。
- 与 `moment-marketing` 的区别：蹭热点借势是时机运营，不改变产品的传播结构；本 skill 改变产品本身。
- 与 `aarrr-funnel-diagnosis` 的区别：五环诊断先找漏斗哪一环卡住；已确认卡在传播环、要做传播机制设计时才用本 skill。
- 与 `activation-aha-magic-number` 的区别：魔法数字管新用户激活行为；但 LinkedIn 式"双重病毒循环"的第二环（注册动作唤回老用户）与激活交叉，可衔接。

## E — 可执行步骤 (Execution)

1. **量化现状：算出 K 与循环周期**
   - 完成标准：有当期实测的感染率、转化率、K 值和病毒循环周期，且口径明确（"转化"定义为注册还是付费）。
   - 判停条件：产品尚无可自然发生的使用场景分享点 → 跳到步骤 3 先设计内置传播因子，再回来测量。

2. **双指标拆解定位瓶颈**
   - 感染率低 → 扩充邀请渠道（通讯录之外的其他触达面）；转化率低 → 优化落地页与注册步骤、缩短操作路径；周期太长 → 一键分享 + 制造紧迫感（限时优惠）。
   - 完成标准：明确指出主瓶颈是哪一个指标，并给出对应的单项改动。

3. **为分享动作匹配心理触发器**
   - 将当前分享/邀请动作与八种心理（喜爱/逐利/互惠/求助/炫耀/稀缺/怕错过/懒惰）逐一对照，至少配一种；炫耀类触发器注意节制频次，避免透支社交货币。
   - 完成标准：写明选用的触发器及"为什么这个场景下用户愿意转"的理由。

4. **设计验证实验并设定 K 目标**
   - 完成标准：实验满足单变量原则、有预设判优标准，并给出 K 的目标值与复测时点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 产品未达 PMF、留存曲线持续走低时：K>1 只会让产品死得更快（坏口碑也加速传播）。先回 `retention-diagnosis` / `pmf-gate`。
- 用活动参与量冒充 K 值：H5 之类"体外"活动的参与人数与产品用户转化是两回事。

### 作者在书中警告的失败模式

- x17（追TA 整蛊游戏）：700 万人参与，广告条下载转化率仅 1%——参与量 ≠ 用户量；且玩法游走在平台规则边缘，渠道随时可能被一夜掐断。
- K 因子模型本身未讨论用户分层、衰减与自然饱和上限，指数增长假设是理想化的——不要据 K=1.2 推演"明年用户破亿"。

### 作者的盲点 / 时代局限

- 书中案例无统计严谨性（样本量、显著性缺席），转化率数据多为公司自述。
- **时效警示：2015 年快照。** 书中邀请渠道清单（通讯录导入、微博/QQ 空间开放平台）已被 ATT/GDPR/个保法与微信持续封杀诱导分享重塑，K 值基准与渠道参数**全部按当期重查**；本 skill 只保留判断逻辑层（双指标拆解 + 心理触发器匹配 + 循环周期速度观）。
- 与 `growth-ethics-redlines` 的关系：诱导分享、制造紧迫感等手法上线前先过道德三闸。
