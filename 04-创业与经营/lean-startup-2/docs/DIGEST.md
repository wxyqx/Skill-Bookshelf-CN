## 这本书在讲什么

如果说《精益创业》回答的是"一家初创公司该怎么做"，那么《精益创业 2.0》（The Startup Way）回答的是一个更难的问题：**一个已经成功的成熟企业，怎么把创业能力变成可以反复使用的制度，而不是依赖某位英雄 CEO 的一次性运动？**

作者的答案是一句立场鲜明的话：创业管理应当成为与一般管理并列的**第二套管理体制**——企业要像设立财务部一样设立"创业部"，把创业团队当作基本工作单元，用创新核算和里程碑式拨款来问责，分三个阶段走完一场可以反复进行的"二次创业"。这不是把"灵活、扁平、自由"的口号搬进公司，恰恰相反：整套体系比传统管理**更**强调责任制、计量与问责，只是把问责的矛头从人转向了假设。用作者的话说，创业管理"针对 21 世纪特有的不确定性"，它与传统管理针对确定性生产的机制并行不悖，缺的正是丰田人自己承认的"TPS 缺失的那一半"。

这本书的价值在于它把"创新"从天赋问题翻译成了**设计问题**：预算怎么拨、委员会怎么设、失败怎么讲、教练向谁汇报、审批规则怎么参数化——每一个都被拆成可执行、可复制、可审计的机制。本文按全书的四层骨架组织：**实验引擎**（方法本体）→ **资源与治理**（钱与问责）→ **组织与团队**（制度载体）→ **领导与文化**（人的行为与土壤），最后给出推进路径、陷阱反例与作者局限。

## 一、实验引擎 —— 假设 → 实验 → 学习 → 决策

这四个方法论共同回答："在没人知道答案的事上，工作该怎么推进。"核心动作只有一个：把"先做完整还是先测试"的纠结，变成一条永不空转的循环。

### 精益实验循环五步法

**它解决什么问题**：团队手里有完整计划（建站、开发、发布会），却说不清"这事到底该不该做"；或者项目跑了半年，老板问"进展呢"，团队只能报活动量。

**核心逻辑**：五步循环——把愿景拆成少数"必须为真"的**信仰飞跃假设** → 用 **MVP** 测最危险的假设 → 只认**验证式学习**（真实用户的行为数据）作进展单位 → 让每轮教训喂养下一轮（开发-测量-认知循环）→ 按节奏在**转型与坚持**之间做结构化决定。本书的增量在于四件组织附件：领导者两问、风险控制清单（限用户数、不贴商标、退款承诺）、终止受奖、预排期会议——剥离这四件，循环就退化成人人都会喊的"精益"口号。

**书中的用法**：GE 的"X 系列"发动机计划预定 5 年、数十亿美元，预测精确到 2028 年，但当作者问"相信这些数字的请举手"时无人举手——24 个市场假设团队只答得出 2 个。作者连续追问"分销网络什么时候建？只造一台要多久？"，团队自己把计划收缩为"半年内改造一台 616 型发动机测需求"。样机造出后立即拿到 5 份订单。计划从执行问题变成了假设问题——这就是循环的威力。

**什么时候会失效**：需求明确、可交付验收的执行型任务用它只会拖慢交付；成熟业务的渐进优化用传统计划-执行-考核更高效。它是第二套体制，不是替代品。

→ 深入：[`organizational-experiment-loop`](./organizational-experiment-loop/SKILL.md)

### 信仰飞跃假设审计

**它解决什么问题**：企业习惯先问"能不能造"（技术风险），从不问"该不该造"（商业风险）。

**核心逻辑**：动手之前，把"我们觉得会成功"的隐含前提写成"我认为……"式假设清单，按"最不舒服、最不了解"排序，先测排序最靠前的。假设是计划的承重墙，不是风险清单的装饰品；"假设越少越好"——只留极少数必须为真的。

**书中的用法**：GE 燃气涡轮团队在新产品研讨会前只有技术参数；被要求当场写下商业假设并排序后，团队发现自己最不敢碰的是"客户真的会为这个效率提升付钱吗"。先审计假设，再谈开发排期。

**什么时候会失效**：已有真实行为数据时直接看数据，不必走审计；假设已选定、只差测试载体时转用 MVP 三件套。

→ 深入：[`leap-of-faith-assumption-audit`](./leap-of-faith-assumption-audit/SKILL.md)

### 价值与增长假设二分，与好实验四特征

**它解决什么问题**：有用户但不付费、不留存，团队却想先拉新冲量；或者实验评审了一轮，没人能说清"什么结果算失败"。

**核心逻辑**：把假设收敛为两个根本问题——**价值假设**（用户用了会不会开心、愿不愿付出稀缺物）与**增长假设**（新用户是否源自老用户的行为）；顺序固定：**先价值后增长**。量化门槛必须能与财务模型对账，NPS 这类满意度代理变量不可当过关判据。实验的质量则用四特征评审：**可证伪、产生下一步、风险受控、绑定假设**——"失败了怎么办"要写成合同条款（限用户数、不贴商标、退款或补偿承诺）。

**书中的用法**：作者的 Newsletter 实验（5000 订阅无人付费）是价值假设未过的标准形态——此时把资源投给增长引擎等于给空壳加速；Dropbox 为 Paper 设的两条验收（扩散性看增长面、两周保留看价值面）则是二分假设的机构化用法。

**什么时候会失效**：已过产品市场匹配的成熟业务不必回到假设二分；合规与安全底线不可用"风险控制"绕过——风险控制解决的是商业风险，不是监管责任。

→ 深入：[`value-and-growth-hypotheses`](./value-and-growth-hypotheses/SKILL.md)、[`good-experiment-four-traits`](./good-experiment-four-traits/SKILL.md)

### MVP 三件套与"为学习，不为规模"

**它解决什么问题**：面对一个假设，团队只想到唯一方案（通常是最贵的那个完整产品）；或者 MVP 刚做完，评审会要求它也过高可用、安全、扩展性评审。

**核心逻辑**：第一条规则是**强制发散**——对同一假设同时想出现有版、镀金版、极简版（三者镜像等距），用记分卡按"单位成本换学习量"选型；裁决规则冷酷直接：**同一假设、不同经费，必淘汰贵者**。第二条规则是**挡住加码**——对每个加码要求先问"它增加什么学习"，无学习增量就用风险控制（限用户数/时限/退款承诺）替代工程加码；"为 100 倍规模做准备"在只有 50 个试点用户时是提前优化的经典失败模式。

**书中的用法**：MVP 的"最小化"由团队定义，但"可行"必须由用户说了算。GE 后备电源团队原计划"3 年投资 1000 万"，被压缩为 3 个月的图纸级 MVP，被用户连环拒绝后借高层支持完成转向，最终上市销售良好——方向与最初设计几乎无关。

**什么时候会失效**：已经验证、进入执行期的正式版本，质量就是价值本身；强监管场景的合规底线不可绕——但注意"合规 ≠ 高可用"，可谈的是把合规参数化，而不是放弃实验；也不准拿"这是 MVP"当借口逃避基本可用性。

→ 深入：[`mvp-trio-and-scorecard`](./mvp-trio-and-scorecard/SKILL.md)、[`mvp-for-learning-not-scale`](./mvp-for-learning-not-scale/SKILL.md)

### PRFAQ 逆向工作法与商业模式实验六问

**它解决什么问题**：想在投入开发或消耗政治资本之前，先知道真实意愿；或者产品卖不动，团队翻来覆去只有降价一招。

**核心逻辑**：**PRFAQ** 是比 MVP 更早的零代码闸门——先写"产品已上线"的虚构新闻稿与 FAQ（必须含发布日期与预估价格，说清"为什么比现有方案更好"），拿给真实用户收反馈：冷场 = 别提，追问 = 找到首批合著者，拒绝是最便宜的教训。**商业模式六问**则是在价值成立后重构收钱结构：产品记谁的资产负债表、产品/服务是否分界、能否按效果收费、能否承担中间环节、是否与用户利益对齐、能否找到新竞争位——每问对应一个可测试的结构杠杆。

**书中的用法**：GE 燃气涡轮把"收入算产品还是服务"的地盘之争提前升级到高层裁决，避免部门博弈葬送一单大生意；硬件团队发现瓶颈在经销商不愿改造陈列室后，把这项成本移到自己身上——非技术环节的周期缩短与技术创新同等重要。亚马逊的逆向工作法（新闻稿发布会）是 PRFAQ 的原型。

**什么时候会失效**：需求已明确的执行项目直接排期，写"新闻稿"是表演；PRFAQ 也替代不了行为验证——口头兴趣不等于付款，之后仍需 MVP。

→ 深入：[`prfaq-working-backwards`](./prfaq-working-backwards/SKILL.md)、[`business-model-six-questions`](./business-model-six-questions/SKILL.md)

### 转型/坚持会议节奏

**它解决什么问题**：决策从危机反应式走向日历化——"最后一分钟才转型"、项目每季度"就差一点儿"续命、团队疯狂建设从不停下问"策略还有效吗"。

**核心逻辑**：把"要不要转"从深夜焦虑改成**预排期的日历事件**——约一个半月一次，上限一个月、下限一个季度；每次只带证据（新尝试换回了什么学习），二选一输出：转型（愿景不变、策略变，生成一批新假设）或坚持（定下一版 MVP 门槛）。决策频率本身成为反沉没成本装置；会议间隔还产生二阶效应——成员会自问"眼下工作对下次会议有利吗"，从而自发收缩提前优化与过度建设。开会不等于承认失败，这是必须写进组织语言的重构。

**书中的用法**：GE 液体膨胀机团队在转型/坚持会议上自己宣布终止——这是全书的标志性场面：终止由创业者本人做出，而不是上级。

**什么时候会失效**：执行型成熟业务的日常经营复盘不属于它；没有愿景的团队谈不上转型（愿景不可讨价还价）；决定权者不在场时，节奏机制只是表演。

→ 深入：[`pivot-persevere-cadence`](./pivot-persevere-cadence/SKILL.md)

### 附：这套方法不限于"创业项目"

作者反复强调"你无法预知谁是创业者"：财捷一位高级行政助理在研讨会上用几天实验验证"教人报税"的假设，把报税辅导班从 500 个联谊会做到 13000 个；另一个五人小组先办一场模拟慈善舞会试运行，最终让晚宴捐款 app 当晚突破百万美元筹款目标；政府把"招聘技术人才"本身当实验做（"总统创新之友"）。这使方法论同时成为**人才发现机制**——谁在无人要求时自发测试假设，谁就是创业者。 → 深入：[`lean-for-non-startup-work`](./lean-for-non-startup-work/SKILL.md)

## 二、资源与治理 —— 钱、问责与裁决

这一组回答："循环要靠什么活下来。"没有下面这套账、会与钱，实验循环会在第一次预算季就死掉。

### 创新核算制度三层次

**它解决什么问题**：传统指标（收入、ROI、市场份额）在探索期必然失效——项目没有收入，怎么证明"在进步而不是瞎忙"？

**核心逻辑**：用三层次记账把学习翻译成财务语言：**L1 仪表板**（团队自己的行为领先指标）→ **L2 商业案例**（把学习换算成对商业模型的修正）→ **L3 净现值**（把项目当作"创新期货"估值）。核心动作是**为信息定价**：每次实验买回了什么信息、值多少钱。作者特意撇清："创新核算"不是"创新型会计"（那种会计会让人坐牢）——它是一套管理语言，不是逃税工具。

**书中的用法**：GE 油气集团用三层账把僵尸项目变成可裁决的组合；财务部门从把关者变成建设者——"说服市场增长不是偶然"。

**什么时候会失效**：NPV 层在 HR、文化类项目上书中从未真正走通（PD@GE 停在领先性指标层），止步于 L1/L2 即可；把核算做成新一轮绿灯黄灯表演，是它自己最想取代的东西。

→ 深入：[`innovation-accounting-three-levels`](./innovation-accounting-three-levels/SKILL.md)

### 审计对照过去，不对照梦想计划；宾果卡诊断矩阵

**它解决什么问题**：创新项目汇报时，审计基线是期初承诺的"梦想计划"——于是每个诚实项目看起来都像失败，每个会讲故事的项目都像成功。

**核心逻辑**：**把基线换成过去**——写环比学习曲线与被证伪的假设，按投资额分层要求证据（早期三五个学习指标即可）。配套的**宾果卡**是"三规模（团队/部门/公司）× 四阶段（实施→行为变化→用户影响→财务影响）"矩阵：每格是下一格的领先性指标，用法是逐格下钻直到出现不满意的一格、回退一格改设计——**跳格测量得到的全是噪声**（用部署率冒充行为变化是最常见的跳格）。

**书中的用法**：培训出勤率 95% 回答不了"效果怎么样"；宾果卡要求从实施格走到行为格——学员回到岗位后行为变了没有？没变就是卡在这一格，回退改设计，而不是继续办培训。

**什么时候会失效**：成熟业务的常规经营审计照用预算对照；宾果卡一旦变成 KPI 排名表就会诱发格格造数——它自称"只是一种聚焦工具"。

→ 深入：[`audit-against-past-not-plan`](./audit-against-past-not-plan/SKILL.md)、[`bingo-card-diagnostic`](./bingo-card-diagnostic/SKILL.md)

### 增长委员会 —— 可运作的内部风险资本基金会

**它解决什么问题**：创新项目死于三种手——危机时被没收资源、永远续命的僵尸项目、心软的老板被巧舌的下属反复说服。

**核心逻辑**：把风投董事会的机制移植进公司。**构成与节拍**（基德五条）：6-8 名决策层、至少每季度一开、**当场决定去留**、以团队拿出的证据而非委员心里的"正确答案"为准、**不出席者不投票**。**三大职责**：团队的**唯一问责点**（切断中层无休止索要进展的通道）、**创业信息中央交换所**、**资金把关人**。**铁律**：续命条件不是进度、不是故事，而是可审计的验证式学习。

**书中的用法**：GE 油气集团设委员会 9 个月，项目终止率从 10% 升到 50%——终止从政治事故变成常态，终止的主导权逐渐转回团队自己，"团队来开会就好像他们希望终止这个项目一样"。花旗的"交易日"每 6-8 周开一次，验证费只需几千美元，员工学会说"我不知道，但我出去找答案"。

**什么时候会失效**：只有一两个项目不必设常设机构；委员会若拿不到真实拨款权，会沦为表演——先修资金制度。

→ 深入：[`growth-board-design`](./growth-board-design/SKILL.md)

### 里程碑式资金拨付 vs 按指定用途拨款

**它解决什么问题**：年度预算"水龙头"——立项即续命，上市日期一推再推，谁也不敢提取消。

**核心逻辑**：一笔创新资金只有两种给法。**按指定用途拨款**（年度水龙头）的理性反应是延迟推出、堆积理由、为续命表演；**里程碑式拨款**则是：**"钱你随便花，但要争取更多资金就必须达到极其严格的标准，关键是看你验证式学习的结果怎么样。"** 期内不追问用途明细，复审只回答一个问题："用这笔钱验证了什么。"它的七项好处包括稀缺心态、失败责任转移、组合管理、政治压力小、聚焦"我需要学什么"、跨职能合作、中层干预减少。注意：里程碑是**学习里程碑**，不是日历节点。

**书中的用法**：全球创新基金把资助切成 23 万/230 万/1500 万美元三阶，早期"这笔钱是给你去学习用的"，学习与成果的资金配比从 8:2 渐变到 2:8；乌干达的 SafeBoda 第一阶段只回答一个假设——"大家真的会戴头盔吗？"。GE 印度医疗团队靠 650 万美元小种子+严格学习门槛，做出 20 美分一次的心电图机，四年销售从 3000 万做到 2.6 亿美元，最终长成 3 亿美元的新公司。

**什么时候会失效**：执行/承包类项目的里程碑就是交付节点，传统预算更高效；"给钱图省心、不设复审"比水龙头更糟——只给钱不给问责是全书反复痛批的独角兽式失误。

→ 深入：[`milestone-based-funding`](./milestone-based-funding/SKILL.md)、[`innovation-needs-constraints`](./innovation-needs-constraints/SKILL.md)

### 舞动宝剑与一页纸预批 —— 为实验开路的两件武器

**它解决什么问题**：试点团队被审批流程、跨部门障碍拖死——而团队真正的诉求往往不是钱。

**核心逻辑**：**舞动宝剑**把"求支持"改写成"做交易"——团队报出可交付成果（周期缩短、学习可审计、开支可控），一次性换取清障（政策豁免、专职人手、免于干预的承诺）；核心经验发现：**团队很少要钱，要的是清障**。**一页纸预批**则把规则参数化解决"每一批"的问题：用户数 X / 负债 Y / 成本 Z 三档（区间内即预批、超一档需签字、再超需面谈），并把文件本身当 MVP 向内部用户迭代压缩；参数还会**反向激励团队主动把实验做小**——每位用户都要过审时，团队会自发选择 100 人而非 10000 人的实验规模。

**书中的用法**：书中"谁是法务？"的故事——一个软件团队想在实验中收用户信用卡号，人人转述"法务绝对不同意"，却没人问过法务；一个电话把需求翻译成对方语言（"最坏情况下公司总负债 3000 美元"），首席法律顾问说"打这个电话浪费的时间都不止这个数"。这是宝剑的微观版。毕威拓把法务部做成"开源合规 MVP"、书中法务文件从十页压成一页，是预批的机构版。

**什么时候会失效**：没有筹码的交换是乞讨；风险不可参数化的重大安全伦理事项不适用预批；把关部门担着个人责任却不担延误责任时，参数化会失效——先修问责对称性。

→ 深入：[`wield-the-sword`](./wield-the-sword/SKILL.md)、[`one-page-preapproval`](./one-page-preapproval/SKILL.md)

### 只要有一个团队成功就是胜利

**它解决什么问题**：高层要求试点"一个都不许失败"，团队开始粉饰——汇报永远 7 绿 2 黄 1 红。

**核心逻辑**：上场前就对高层明示**组合式期望**：按组合评估，"只要有一个团队成功就是胜利"；要求 100% 成功率必然催生绿黄红表演与失败隐藏。反过来，全胜反而可疑——真实实验组合里有两三成成功已是好结果（花旗三四成首轮过关属正常）。失败要看是否留下可审计学习，而不是看是否"没做成"。

**什么时候会失效**：单团队的转型/坚持判断不属于它（那是节奏会议的事）；组合容错不能当无限续命——必须与增长委员会铁律成对使用；成熟业务的 KPI 问责不适用。

→ 深入：[`one-team-success-is-enough`](./one-team-success-is-enough/SKILL.md)

## 三、组织与团队 —— 制度载体与推进时序

循环有了、账本有了、钱和裁决机构有了，还需要**人怎么组织**。这一组回答："谁来干、向谁汇报、按什么顺序落地。"

### 创业团队是新的基本工作单元

**它解决什么问题**：成熟产品线要不要设"创新小分队"？实验做成了，成果归谁？

**核心逻辑**：**创业团队**必须同时拥有研发的科学严谨、销售营销的用户中心、工程部门的规范，**专职跨职能**、把项目当实验、可申请转型、直接向增长委员会汇报。它位于"实验-执行连续体"上，配比随成熟度移动——执行/实验是每个业务单元的配比问题，不是部门划分问题。本书的独有警告：**成功后的威胁比失败更大**——实验一旦做成，现有部门、孵化器、业务线都来认领（"企业重力"把一切拉回旧轨道），所以**落地路径必须在立项时就预先谈判**：被吸收还是长成新部门、谁来决定、按什么判据。

**书中的用法**：GE 可持续发展医疗的印度项目从边缘实验长成独立公司，靠的正是逐级谈判的落地路径；反面则是"创新实验室负责人很少对成功后怎么办做出规划"——强烈反应"来得很快（也会很致命）"。

**什么时候会失效**：执行型项目套"创业团队"名头会逃避执行问责；不是所有事务都该由创业团队打理；只建团队不做预谈判等于埋雷。

→ 深入：[`startup-team-basic-unit`](./startup-team-basic-unit/SKILL.md)、[`dedicated-cross-functional-teams`](./dedicated-cross-functional-teams/SKILL.md)

### 支持者三层结构与教练体系

**它解决什么问题**：创新项目该找谁要支持？"再找个高管"到底该找哪种？

**核心逻辑**：三层角色**不可互换**——**发起人**保项目（日常清障、特事特办）、**高层支持者**保工作法（CEO 级，能排除别人都排除不了的障碍）、**教练**保学习（非领导、非间谍，被严格培训、被正式考核、有职业路径）。找错层级等于没支持：拿制度性问题找发起人、或拿方法困惑找 CEO，都解决不了。演进时序：发起人先行 → 支持者第二阶段系统化 → 教练岗位化。教练体系有三个经典病：兼职拼凑撑不住、积极性最高的最先离职、每人只覆盖一个专长面而无人代表整套方法。教练一旦兼任监视者，团队只汇报好消息——**拒斥情报职能是制度条件，不是道德姿态**。而对拒绝新方法的固执老手，教练的武器不是辩论，是"假定你们是对的，我是错的"——不辩论，只设计一个封存预测、让现实做说服者的自证实验。

**书中的用法**：展会信封实验——一个能源团队极其自信、拒绝一切精益建议，教练只谈成一件事：把展会当实验，请每人写下预计销量、封进信封，展会后开箱；结果零成交，团队自己完成了转向，教练"几乎没说一句话"。这就是"不辩论，让现实做说服者"的完整演示。

**什么时候会失效**：用"找靠山"心态层层挂名是假的，支持是职能不是头衔；把教练当领导用（替团队决策）或当间谍用，两种滥用都会关闭学习通道；组织缺的若是制度资源，支持者替代不了制度。

→ 深入：[`three-tier-support-structure`](./three-tier-support-structure/SKILL.md)、[`coach-not-leader-not-spy`](./coach-not-leader-not-spy/SKILL.md)、[`coach-assume-they-are-right`](./coach-assume-they-are-right/SKILL.md)

### 培训要覆盖"能喊停的人"，把关部门要变成赋能部门

**它解决什么问题**：变革总在下一个审批口被旧标准击毙；法务、财务、IT 永远在拖后腿。

**核心逻辑**：只培训实践者不够——**否决权持有者不进教室，新方法就会在审批口被打回**。把法务/财务/HR/IT 的负责人先请进同一间教室，目的是**对齐风险语言、更新否决依据**（而不是逼表态、更不是批斗会）；中层不是坏人，是被旧标准武装的人。更进一步的制度工程是把把关部门整体改造成**赋能部门**：法务/财务/IT/HR/采购把自己当创业团队经营——访谈内部用户拿行为级痛点、用 MVP 方法重构自身流程（预批参数、模板迭代）、以一线行为指标验收。判断标准不是部门名称而是运作方式：同一法务部可以默认禁止（把关），也可以给出预批参数与红黄绿清单（赋能）。

**书中的用法**：GE 的 ERP 分类账合并把 500 套系统减到 90 套；移民局"洞穴"里的 I-90 流程从审批半年缩到两周；法务把合规做成 MVP。反面是"洞穴与针式打印机"——公务员把屏幕内容用矩阵针式打印机打出来、撕掉针孔装订进文件，2008 年的电子化项目上线后"比纸质还慢"，因为流程从未被实地观察，里程碑只划在"上线"。

**什么时候会失效**：以培训本身为目的的合规年训不属于它；把否决者请进教室当批斗会只会让否决转入地下；否决权持有者保留否决权——被更新的是他们依据的信息。

→ 深入：[`train-the-veto-holders`](./train-the-veto-holders/SKILL.md)、[`gatekeeper-to-enabler`](./gatekeeper-to-enabler/SKILL.md)

### 统一的创业理论与内部专人专责

**它解决什么问题**：公司的创新活动散落各处——新产品、内部 IT/HR 产品、并购、组织转型各归各管，创新头衔却常常只是封号。

**核心逻辑**：**统一创业理论**把四类活动（新产品、内部产品、企业发展、组织转型）统一归入创业职能，并给出**七项职责审计清单**判断"首席创新官"是实职还是荣誉头衔——重点核对**真实经营职责**（手里有没有支票本、对盈亏负不负责）。**变革必须内部专人专责**：外部顾问主导注定失败，无主变革=权力真空；变革必须由**真正懂得公司文化和变革方法的内部人**设计，外部人最多做教练。

**书中的用法**：GE 转型由内部团队全程主导、外部顾问退居配角；作者警告"如果你不指派专人，就等于告诉全公司这件事不重要"。

**什么时候会失效**：单个项目的实验问题不归它管；把"统一管理"理解成总部收权是误用——创业部是定标准、养人才、留政策口的职能部门，不替团队做资源决定。

→ 深入：[`unified-entrepreneurial-theory`](./unified-entrepreneurial-theory/SKILL.md)、[`internal-change-owner`](./internal-change-owner/SKILL.md)

### 转型三阶段路线图 —— 本书的推进总纲

**它解决什么问题**：变革该从哪一步入手？新 CEO 上任就想改考核薪酬，该支持还是劝阻？

**核心逻辑**：三阶段，每阶段有完成信号与入场券。**第一阶段·临界规模**：在边缘做异质试点、攒可展示的成功案例，允许特事特办，不碰任何制度。**第二阶段·扩大规模**：把成功做法铺成制度——培训、教练、里程碑拨款、增长委员会雏形；反对者正式登场，变革要么长出政治力量、要么偃旗息鼓。**第三阶段·深层机制**：逐个改造法务/财务/IT/HR/薪酬等把关部门。铁律：**过早触及深层机制等于自杀**——没有前两阶段攒下的政治资本就动薪酬考核，等于把转型送上断头台；但永远不动深层机制，一切变革只是暂时的。

**书中的用法**：联邦政府从医保网作战室急救（一阶段）到 USDS/18F 新机构（二阶段）再到移民局流程改造（三阶段）；GE 废除绩效考核五档制排在试点证据之后——先在三组内部用户中证伪"五档制不可动摇"、再做 20-100 人自愿实验、再逐级扩大，最后才动制度。

**什么时候会失效**：创业公司（没有深层机制可改）、正在流血的危机现场（先急救）、外部咨询主导的变革（先解决所有权问题）都不适用。

→ 深入：[`three-stage-transformation`](./three-stage-transformation/SKILL.md)

## 四、领导与文化 —— 语言、激励与移植规则

最后这一组是**土壤**：同样的机制，在不同语言、激励与姿态的组织里，会活成完全不同的样子。

### 领导者两问

**它解决什么问题**：下属来汇报坏消息，领导者的第一反应是"为什么没做到"——于是下次没人报坏消息。

**核心逻辑**：把开场白换成两问——**"你学到了什么？"**（把对话从人转向假设，允许坏消息以认知的形式登场）与**"你是怎么知道的？"**（证据审计，专防"我觉得下次会好"式假学习）。顺序不可交换：先打开，再校验。它适用于任何层级、任何"报告与预期不符"的场合——书中甚至用它处理亲子对话。

**书中的用法**：中欧销售区的季度业绩电话——新产品上市遇阻，高管忍住了多年的习惯（"把这个家伙的头拧下来"），改问两问，销售经理交出了真实情况：本土竞争者已有像样产品、母公司品牌在当地影响力不足。上市计划本身就是一场没人意识到的实验。高管据此重订计划，产品大获成功。

**什么时候会失效**：纯执行力问题（流程明确、无不确定性）套两问会变成纵容；紧急事故先止损；更不能用作假惺惺的话术表演——第二问就是防表演的。

→ 深入：[`leaders-two-questions`](./leaders-two-questions/SKILL.md)

### 责任制 → 方法 → 文化：因果链不能倒着走

**它解决什么问题**：价值观海报贴满墙、团建没少搞，大家该保守还是保守；培训做了、热情有了，回部门就格格不入。

**核心逻辑**：**文化是过去责任制与方法的残留，不是宣言。** 三层因果链：先改**考核什么、奖惩什么**（责任制），方法才会被理性的人采用并自组织更新，文化随之沉淀。贴海报处在因果链的输出端——改它无效；只培训个人不改文化，学员回部门就会"格格不入"（旧考核不认新方法）。要动的具体对象是员工脑子里那本账：**职业资产净值**——新工作法对我的绩效评估、晋升渠道、同行评价有什么影响？不调整考核与晋升就要求行为改变，等于要求员工自减资产，理性员工必然抵制。

**书中的用法**：GE 的 EMS 激励矩阵直接惩罚目标行为——工程师拒绝更优的并行开发方案，因为它增加"返工量"；PD@GE 的全程都在处理"废除五档制后，什么行为会被奖励"。

**什么时候会失效**：新组建的团队没有历史残留，直接设计责任制即可，不需要"改造"叙事；纯技能缺失用培训解决，动考核只会惩罚无辜；你无权触碰任何考核条款时，先攒政治资本（回到三阶段）。

→ 深入：[`accountability-method-culture`](./accountability-method-culture/SKILL.md)

### 奖励有益的失败，终止叙述权归创业者

**它解决什么问题**：项目黄了，全员大会上领导怎么讲？"拥抱失败"的口号与"失败就出局"的考核正面冲突。

**核心逻辑**：三个可执行的问题——**谁来讲、讲什么、奖给谁**。**谁讲**：终止的叙述权归项目创始人本人；让上级代讲"我把它毙了"，等于宣布杀项目的是权力而不是证据，下次没人敢提前终止。**讲什么**：三件事——测了什么假设、花了多少、省下了什么；技巧是**量化赞美**："3 万美元加 7 个月"对比"数百万美元加数年"。**奖给谁**：对照奖励/晋升/考核制度逐条检查信号一致性；终止团队的成员再配置而不是解散。奖励只给"有益的"失败——**讲不出所测假设的失败不受保护**（那是失败表演）。

**书中的用法**：GE 液体膨胀机团队证伪后自己宣布终止，全员受奖——"他们不必投入多年生产一款无法创造价值的产品"。亚马逊 Fire 手机失败后没有清算团队，而是把人员重新配置到 Echo/Alexa，后者相继成功。

**什么时候会失效**：确定性生产的质量事故仍是缺陷，六西格玛纪律照常；把"容错"当无限续命是对本书的误读——创业者恰恰要为结果负责。

→ 深入：[`reward-useful-failure`](./reward-useful-failure/SKILL.md)

### 行为先于工具，自愿率是领先性指标

**它解决什么问题**：上了新系统没人用，是软件不行还是人不行？新制度该强制全员切换还是双轨并行？

**核心逻辑**：**先小群行为实验（20-100 人）→ 迭代工具 → 分层自愿扩大**；工具先行得到的通常只有噪声——同一家公司里，行政命令强制使用的完成率 80%，真正自愿使用的不足 2%，后者才是有效信号。把**自愿迁移率**写成头号验收指标，替代部署率/覆盖率：强制切换只测出合规，还烧掉纠错信息（没人告诉你为什么不用）。制度怎么样才算被接受？——看有多少人**自愿**来用。

**书中的用法**：PD@GE 的推广全程走自愿：三组用户调研 → 20-100 人行为实验 → 逐级自愿扩大到 9 万人，最终 80% 按时完成（旧制不足 2%）。

**什么时候会失效**：安全、合规类必须全员执行的上线，"自愿"不适用；自愿率也不能替代后端测量——自愿的人多不等于用得好；自愿率低的先查入口成本与信息透明度，别急着判死刑。

→ 深入：[`behavior-before-tools`](./behavior-before-tools/SKILL.md)、[`voluntary-adoption-indicator`](./voluntary-adoption-indicator/SKILL.md)

### 公开创新与"用本公司语言重述"

**它解决什么问题**：新项目要不要先保密？"学 GE/学亚马逊"为什么学不像？

**核心逻辑**：**地下是保火种的过渡态，不是归宿**——长期保密等于资源与合法性双输，必须在下一个里程碑公开换取支持者（马汉冰箱项目从地下复活到公开转正的全程）。而**"复制"被作者直接判为不可能**——连 GE 自己都无法再次复制 FastWorks，"FastWorks 反映的是 GE 的文化与性格"；替代程序是三步：挑机制做本地实验 → 换成本组织的语言与工具 → 用本组织案例重写教材。本地化的对象必须是**机制**而非修辞——给旧做法换个新名词不是本地化。

**什么时候会失效**：合规与会计硬约束不参与"语言重述"；组织尚无任何实验能力时，"本地化"没有可供验证的载体；给旧做法换新名词的口号包装恰是本书批判的对象。

→ 深入：[`innovate-in-the-open`](./innovate-in-the-open/SKILL.md)、[`localize-dont-copy`](./localize-dont-copy/SKILL.md)

## 五、典型推进路径：试点 → 扩大 → 深层机制

把 36 个方法论组合起来，组织里的完整推进是一条可以复述的路径：

1. **个人与边缘起步**：`organizational-experiment-loop` 在任何角落都能跑通——列假设、做 MVP、收行为数据、开节奏会。同时用 `leaders-two-questions` 的语言与 `pivot-persevere-cadence` 的节奏保护循环存活。
2. **第一批试点**：用 `leap-of-faith-assumption-audit` 挑假设、`mvp-trio-and-scorecard` 选载体；上场前对高层锁定 `one-team-success-is-enough` 的组合期望；团队按 `startup-team-basic-unit` 与 `dedicated-cross-functional-teams` 配置；用 `wield-the-sword` 换取清障，用 `three-tier-support-structure` 配齐发起人。
3. **治理与资金进场（第二阶段）**：`innovation-accounting-three-levels` 建账、`audit-against-past-not-plan` 定基线、`growth-board-design` 立裁决机构、`milestone-based-funding` 换资金制度、`bingo-card-diagnostic` 逐格诊断推广；培训先覆盖 `train-the-veto-holders`。
4. **深层机制（第三阶段）**：`accountability-method-culture` 改考核与晋升，`gatekeeper-to-enabler` 逐个改造把关部门，`one-page-preapproval` 把豁免沉淀成制度，`unified-entrepreneurial-theory` 完成归口；全程 `internal-change-owner` 保证内部专人负责，`three-stage-transformation` 校验时序。
5. **文化收口**：`reward-useful-failure` 处理每次终止的叙事，`behavior-before-tools` + `voluntary-adoption-indicator` 决定推广方式与验收，`innovate-in-the-open` 与 `localize-dont-copy` 管姿态与移植。

几条关键的**组合关系**：没有创新核算，增长委员会退化成讲故事比赛；没有里程碑拨款，委员会只是建议团；没有顶层配合，预批文件会被下一道审批架空；没有两问与终止受奖，循环会在第一次失败时被文化杀死。

## 陷阱与反例

本书一半的价值在它警告的失败模式里。挑最有杀伤力的六条：

1. **把预测当问责工具（幻想计划的暴政）**。商业计划里的收入预测本是为融资编的故事，却被拿来考核：超额升职、未达标受罚——于是全体在明知是编造的数字上集体表演。预警信号：商业案例的曲棍球棒曲线在第 5 年后才起飞；团队答不出市场假设却对技术规格如数家珍；"相信预测的请举手"时没人敢不举。
2. **"只许成功，不许失败"文化**。桌上摆着"只许成功"的杯子，口号又喊"拥抱失败"——两套信号相反时，理性员工永远选择表演：项目汇报绿黄红比例惊人稳定，失败项目从宣传中"被消失"。机制：质量管理的统计前提（失败即缺陷）被误用到不确定性领域。
3. **水龙头式拨款与"给了钱没给问责"**。年度预算让项目"一上桌就死不了"：上市日年年后移、团队越招越多、无人敢提取消——延迟推出对个人最优（推迟失败、把后果留给继任者）。反面的独角兽式失误更糟：整笔钱不设任何复审。两者夹击下，创新组合真正需要的是"整笔预付+严格学习复审"。
4. **冒牌创业者与"被失败冲昏头脑"的人**。连续失败、每次都"学到了很多"，却说不清测过什么假设、指标变化是什么——失败本身不产生学习，叙事化的失败只是表演。奖励只给能出示审计证据的失败。
5. **洞穴与针式打印机：无人负责的制度性低效**。移民局 700 万份纸质申请的"洞穴"里，承包商把屏幕内容用针式打印机打出、撕边、装订归档；电子化项目上线后"比纸质还慢"——因为流程从未被实地观察，里程碑只划在"上线"。预警信号：数字化以"上线"而非"处理时间缩短"为里程碑。
6. **一口吃成胖子：提前投资可扩展基础设施**。只有 50 个试点用户却按 100 万用户设计架构——"以后重构代价太大"听起来永远正确，但它花掉的是验证学习的预算。对冲机制一半靠"为学习不为规模"的裁决规则，一半靠转型/坚持会议的自然收缩效应。

其他值得记住的还有：危机来临时"所有人都上"式动员会第一个抽干无收入团队；无代表权税收——"想掌控项目却不想投资"的部门是创新项目的隐形杀手；季度回报最大化的激励会绞杀任何长期实验。

## 作者的局限（读这本书要打的折扣）

1. **时代与结局**。成书于 2017 年，案例集中在 GE 数字化叙事的高峰期；GE 其后的崩塌与绩效革命回摆，使"FastWorks 拯救巨头"的说服力明显折损——书中的乐观没有经过事后检验。书中对远程组织、AI 辅助实验等后续变化零讨论。
2. **立场与证据强度**。作者自认与书中几乎每家公司有投资或合作关系（GE、财捷、长期证券交易所均深度绑定），存在系统性幸存者偏差；附录承认部分案例是"把几个故事合在一起讲"。所有大案例都是作者亲自主导的试点，没有对照组——这是最佳实践选集，不是经过对照检验的管理科学。
3. **未被证明的假设**。其一，"既要又要"假设：核心业务与颠覆业务可以互不侵蚀，书中靠组织隔离保证，但隔离失效时缺乏机制化讨论。其二，学习可跨部门通约成美元：HR、文化类项目在书中从未真正走通 NPV 层。其三，"员工会自愿拥抱实验文化"——案例里 3 万人自愿报名，对沉默多数的转化机制着墨不足。
4. **依赖一份常年有效的顶层支持**。GE 的转型耗时 5 年以上且依赖 CEO 级发起人；书中把"高层支持"当作默认可得的输入，而非需要论证的前提。自下而上、没有高层可找的路径，书中没有答案。

最强的一句反对意见是：创新核算概念优雅，但"把学习翻译成美元"的链条每一环都依赖主观建模，实际组织中很容易退化为**新的表演性指标**——正如它想取代的绿灯黄灯红绿灯表演。向任何人推荐这本书时都该带上一句：可迁移的是实验思维与问责设计，而不是"照抄 GE"。

## 关键术语速查

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 创业管理 | 针对极端不确定性的领导框架，与一般管理并列 | ≠ 创业公司专属；指任何人在不确定环境下的工作方式，严格程度不降反升 |
| 创业部（缺失的部门） | 与营销部、财务部并列的职能部门，监管公司"创业基因" | ≠ 创新实验室/臭鼬工厂；是制度性职能部门而非项目集合 |
| 创业团队（基本工作单元） | 专职、跨职能（科学严谨+用户中心+工程规范），项目本质是实验 | ≠ 临时项目组/委员会；要求专职、独立核算、直接向增长委员会汇报 |
| 信仰飞跃假设 | 计划成立所"必须为真"的最小假设集 | ≠ 风险清单；优先测最不舒服、最不了解的那条 |
| MVP | 面向真实用户、以最少成本换最大验证式学习的实验 | ≠ 粗糙产品初版；"你可以定义什么是最小化，但什么可行得由用户说了算" |
| 验证式学习 | 从真实用户行为变化做出的科学推理，是"进展单位" | ≠ 调研结论/感想；看用户做什么，不看说什么 |
| 转型（pivot） | "转型，愿景不变策略变" | ≠ 放弃/随意改方向；愿景是不可讨价还价的部分 |
| 创新核算制度 | 传统指标失效时衡量创新进度的方法 | ≠ "创新型会计"（作者特意撇清）；把学习换算成美元的三层账 |
| 里程碑式资金拨付 | "钱你随便花"，下一笔取决于验证式学习 | ≠ 阶段预算（阶段=日历时间）；它挂钩学习里程碑，且必须配复审 |
| 增长委员会 | "可运作的风险资本基金会" | ≠ 阶段门径评审会（敌对式过关）；基于证据当场决策、不出席不投票 |
| 企业重力 | 把所有项目拉回旧体制轨道的组织惯性 | ≠ 修辞性的"组织惰性"；是旧预算、旧审批、旧考核的具体合力 |
| 舞动宝剑 | 过堂会上成果换清障的条件交换 | ≠ 高层滥用权威；一剑劈开官僚制，且高层成为共同当事人 |
| 把关部门 / 赋能部门 | 前者以审查降效，后者帮团队提速 | 区分标准不是部门名称而是运作方式；法务部可以两者皆是 |
| 职业资产净值 | 新工作法对绩效评估、晋升、声誉资产的影响 | ≠ 薪酬；不调整考核就要求行为改变=要求员工自减资产 |

完整词典见 [GLOSSARY.md](./GLOSSARY.md)。

## 如果只带走三句话

1. **把"该不该造"放在"能不能造"前面，用行为数据而不是共识和故事当进展单位。**
2. **钱、账、裁决机构、支持层、考核——每一个都要为实验循环重新设计；只喊口号不改制度，理性的人永远选择表演。**
3. **转型按三阶段走：先用边缘试点攒证据，再铺制度，最后才动深层机制——过早触碰考核薪酬等于自杀。**
