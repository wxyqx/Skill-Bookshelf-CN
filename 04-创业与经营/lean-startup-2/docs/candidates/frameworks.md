- id: f01
  title: 精益实验循环五步法（LOFA→MVP→验证式学习→BML→转型/坚持）
  type: framework
  source_chapter: 第 4 章（行 1204-1212）
  source_quote: |
    "1.确定创业成功必须具备的信念。我们称之为'信仰飞跃假设'。2.设置实验来测试这些假设……
    3.像科学家一样思考……这种初创公司的'进展单位'我们称之为'验证式学习'。"
  summary: |
    在极端不确定下推进任何新事业的完整推理结构：先把愿景拆成必须为真的假设（LOFA），
    用最便宜的方式做实验（MVP），以用户行为变化为进展单位（验证式学习），
    走开发-测量-认知循环，并定期在"转型还是坚持"之间做结构化决定。
    本书把它从产品开发推广到企业内部一切不确定工作（含 HR、IT、商业模式）。
  tags: [framework, experimentation, decision-loop, core-method]

  title: 价值假设与增长假设二分
  type: framework
  source_chapter: 第 4 章（行 1337-1347）
  source_quote: |

    作者给出排序规则：先验证价值假设，再验证增长假设——先有少量真实用户，再谈扩大。
    第 9 章进一步把二者量化进商业案例（门槛=让电子表格说得通的数字）。
  tags: [framework, assumption, prioritization]

  title: 好实验四特征
  type: framework
  source_chapter: 第 6 章（行 2155-2163）
  source_quote: |
    "每个实验都应该有：一个清晰的可证伪的假设……清晰的下一步行动……严格的风险控制……

    必须预先设定风险控制（限制用户数、不贴企业商标、合规不打折、退款承诺、主动罚金）；
    至少绑定一个信仰飞跃假设。它把"做实验"从口号变成可验收的工作件。

- id: f04
  title: MVP 三件套头脑风暴与记分卡
  type: framework
  source_chapter: 第 4 章（行 1400-1418）
  source_quote: |
    "想出三种不同的最小化可行产品。我们从简单的那个开始……然后想一个好玩的——要花很多钱的
    那种（终极镀金版）……第三种……在简单程度方面与第一种产品有多远。"
  summary: |
    破"唯一方案"思维的工具：对同一假设强制想出三个 MVP——现有版、镀金版、极简版
    （极简版与现有版的距离=镀金版与现有版的距离），再用记分卡（学习价值/成本/时间）横向评估。
    核心洞见：不同 MVP 测同一假设时经费可相差数量级，此时应淘汰贵的那个。
  tags: [framework, mvp, brainstorming, cost-control]

  type: framework

    配套"创新场"：0→当前 IA 值→权益值→梦想计划，进步即向梦想计划端移动。

- id: f09
  title: 里程碑式资金拨付 vs 按指定用途拨款
  type: framework
  source_chapter: 第 3、7、9 章（行 1056-1075、2766-2809、3688）
  source_quote: |
    "里程碑式的资金拨付的原则是：钱你随便花，但要争取更多资金就必须达到极其严格的标准，
    关键是看你验证式学习的结果怎么样。"
  summary: |

    下一笔钱取决于验证式学习。后者带来七项好处（稀缺心态、失败责任转移、组合管理、
    政治压力小、聚焦"该学什么"、跨职能合作、减少中层干预）。
  tags: [framework, funding, incentive-design]
