## 1. 结构 (Structural)

### 类型
方法论 / 实操手册（营销战略）

### 一句话主旨
营销之争不在工厂也不在货架，而在潜在顾客的心智：定位就是让品牌在顾客心智中占据一个词、一个梯级，并为此管理认知、集中攻击、持续坚守。

### 骨架（主要论点及其关系）

1. **地基（第 1-5 章）**：传播过度的社会里，心智只容得下简单信息；认知即现实，不要试图改变心智，由外而内思考；心智按产品阶梯储存品牌，第一印象几乎不可逆转。
2. **基本打法（第 6-8 章）**：领导者防守（正宗货、拦截、多品牌）；跟随者找空位（尺寸/价格/性别/年龄/分销等维度，关联挂靠领导者）；找不到空位就重新定位竞争对手（攻击其弱点）。
3. **名字工程（第 9-13 章）**：名字是把品牌挂在心智阶梯上的钩子；无名陷阱（缩写）；搭便车与品牌延伸陷阱（跷跷板效应、橡皮筋、潜伏症），延伸何时有效的判据。
4. **应用场景（第 14-20 章）**：公司定位（孟山都）、国家定位（比利时）、产品定位（奶球）、服务定位（邮递电报）、机构定位（天主教会）、个人与职业定位（找马骑）。
5. **实施与素质（第 21-22 章）**：成功六步曲（从"你拥有怎样的定位"到"你符合自己的定位吗"）+ 局外人角色 + 定位游戏规则（理解文字与人、六要、他人导向）。

**论点之间的关系**: 递进——心智规律立公理 → 攻防策略与命名工程展开方法 → 多场景应用 → 收束为流程与实践者素质。

### 作者要解决的核心问题
传播过度导致信息互相淹没，产品做得更好并不能赢得市场——企业如何在潜在顾客心智中占据一个位置并守住它？

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法，详见 GLOSSARY）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 定位 | 在潜在顾客心智中为品牌占据一个位置，从产品开始，可以是一件商品/服务/机构甚至一个人 | 不是对产品做什么，而是对潜在顾客的心智做什么 |
| 心智阶梯 | 心智为每类产品设一个阶梯，品牌按序排列 | 品牌竞争是爬梯，不是比产品参数 |
| 一词占领心智 | 用一个词钉住品牌（沃尔沃=安全） | 不是广告语，是排他性心智资产 |
| 空位 | 心智阶梯上的空缺位置 | 在顾客脑中找，不在工厂里找 |
| 重新定位竞争对手 | 攻击现有品牌在心智中的位置，腾出空间给自己 | 不是贬低对手，是打破其承诺 |
| 跷跷板原则 | 一个名字在心智中的强项升起时弱项就下沉 | 知名度不等于可延伸性 |
| 橡皮筋 | 品牌名可拉伸但有限度，拉太长会失去原位置 | 与"品牌资产越大越好用"的直觉相反 |
| 正宗货 | 领导者用"正宗"身份防御——别的都是仿冒品 | 防御的不是市场而是心智中的第一性 |
| 二元法则 | 成熟品类最终只剩两个品牌主导 | 与"市场足够容纳多个玩家"直觉相反 |
| FWMTS | 忘记成功之道陷阱（Forgot What Made Them Successful） | 成功后偏离当初定位的系统性自毁 |

### 核心命题（用自己的话）
1. 认知大于事实：营销不是产品之争而是认知之争，接受方才是对的。
2. 心智容量有限：必须一词占领、聚焦、舍弃，靠简化赢。
3. 做不了第一就在新维度做第一：空位、关联、重新定位是跟随者三件套。
4. 名字是心智的钩子：起名和延伸的每个决策都在消耗或积累心智资产。
5. 定位是长期坚持：六步曲 + 局外人 + 六要，防的是组织自己的短期主义。

### 论证链
每个判据都配 2-4 个真实品牌案例（安飞士、七喜、泰诺、IBM、雪佛兰、大众等），正例反例对照；附录以中国案例（王老吉等）收尾。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 案例与美国 1960-80 年代广告业强绑定，数字化渠道、算法推荐、社交传播下的心智规律变化未覆盖（附录补了 2000s 中国案例但机制未重述）。
- "二元法则"在平台经济与长尾市场中的适用性存疑。

### 作者的立场盲点
- 立场偏广告/咨询视角，对渠道、供应链、成本等非心智因素权重系统性低估。
- 对"心智调研"的可信度批评他人，但自己的空位判断同样依赖直觉与个案。

### 未被证明的假设
- 心智阶梯结构对所有品类成立（低介入度品类可能没有阶梯）。
- 品牌延伸弊大于利（书中正例如拓宽用途也存在幸存者偏差）。

### 最强反对意见
现代增长实践（流量运营、私域、性价比路线如小米早期）证明在渠道红利期可以不先做心智定位；定位咨询案例的成功归因难以剥离品类红利。
