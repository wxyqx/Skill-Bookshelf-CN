## 四、独立 skill 打包建议

以下四个主题的反例与案例密度足以独立成 skill（反例作 B 段、案例作 A1 段）：

**1. 命名与改名决策（"名字是定位的容器"）**
- 反例：家族B全量——e04（多品牌命名混乱）、e21（通用名灾难）、e22（无意义名）、e24（放弃品类词）、e25（缩写陷阱）、e26（改错名字）、e38（拒绝改名）、e42（个人版依附命名）。
- 案例：c08、c25、c26、c48–c57、c60、c64、c67、c68、c73、c75、c85。
- 核心判据：名字须连接品类与购买理由；通用名/缩写/行业术语/数字代号四类死法；改名三条件（埃克森）与改名时机（Westar）；"新定位需要新名字"（雷克萨斯、Dockers）。
- 适用场景：品牌命名评审、公司更名决策、个人笔名/艺名/对外称谓选择。

**2. 品牌延伸判据（"跷跷板、橡皮筋与潜伏症"）**
- 反例：家族C全量——e11（多元化）、e12（Advent破产）、e23（自相残杀）、e27（由内而外病根与识别句式）、e28（兴奋剂效应：短期数据不可信）、e29（橡皮筋效应）、e30（自弃地位）、e31（潜伏多年）。
- 案例：c53–c83 中延伸类全部（c54、c55、c58–c70、c74、c76、c77、c79、c80、c82、c83），正反对照用 c71、c72（拓宽用途是唯一安全阀）。
- 核心判据：延伸前先计算将让渡的地位价值（e30）；识别"由内而外"句式（e27）；短期销量不作判据（e28/e31）；何时必须另起新名（c26/c64/c67/c73）。
- 适用场景：产品线扩张评审、子品牌命名决策、个人跨界接活的取舍。

**3. 定位方案的组织采纳（"向内推销"）**
- 反例：家族G全量——e02（自我导向/我能行）、e35（半途换人）、e36（董事长个人好恶）、e39（拒绝显而易见）、e45（战略与执行脱节）。
- 案例：c18（现实派胜过我能行派）、c19（韦尔奇自上而下推行）、c46（"长大"项目被代理否决）、c86/c35（比利时项目组织劫）、c88（奶球正反两面）、c91（主教拒绝福音教师）、c89（后任广告公司弃守）。
- 核心判据：方案必须"简单到显而易见"（e39/e45）；预先解决向最高层推销的问题（e36）；负责人长期投入与全员统一认识（e35）；销量与认识度双指标验证（e37+c89）。
- 适用场景：咨询/提案汇报、内部战略评审通过率、组织变革沟通。此 skill 是全书最不"营销"也最跨域的一组，对任何"好方案死在内部"的场景通用。

**4. 空位判据（"心智空位 vs 工厂空位 vs 技术空位"）**
- 反例：家族F全量——e13（迟到20年）、e15（工厂空位）、e16（技术陷阱）、e40（劳斯莱斯思维方式：孤高定位）。
- 案例：c29–c40 空位维度全集（尺寸/高价/低价/性别/年龄/时段/渠道/重度使用者），反例配套 c39（埃德塞尔）、c40（Frost 8/80）；正例方法见 c14（挂靠法）、c16（另立品类）、c17（既有位置挂钩）。
- 核心判据：空位只存在于心智中而非工厂/实验室/产品线里；空位只属于第一个占据者；独特性须与需求规模平衡。
- 适用场景：新品立项、细分市场选择、个人利基定位（"差异化但要有人买单"）。

（另：家族A"自弃定位/FWMTS"与家族D"正面进攻"证据充分，但更适合作主定位 skill 的 B 段而非独立成 skill——它们是定位核心命题的推论，独立打包会稀释主 skill；家族E/H/J 的条目同样并入主 skill 使用。个人定位主题由 c92–c97 + e42/e43/e44 构成，建议作为主 skill 的"个人应用"章而非独立 skill，除非后续发现个人场景需求占比很高。）
