# 由外而内/认知第一

## R — 原文 (Reading)

> "定位思想的本质在于，把认知当成现实来接受，然后重构这些认知，并在顾客心智中建立想要的'位置'。"
>
> — 里斯 & 特劳特，第1章、第12章

> "不要试图改变人类的心智成了定位理论最重要的原则之一。这是营销人员违背得最多的一项原则。"
>
> — 里斯 & 特劳特，第1章、第14章

> "定位需要从潜在顾客开始，而不是从自己开始。不要问自己是什么，要问自己在潜在顾客心智中是什么。"
>
> — 里斯 & 特劳特，第1章、第21章

> "这里的教训是：不要用事实来挑战认知，赢的总是认知。"
>
> — 里斯 & 特劳特，第5章

> "逻辑无懈可击。但实际情况往往是，逻辑未必就是应付人类心智的最佳战略。"
>
> — 里斯 & 特劳特，第7章、第17章

---

## I — 方法论骨架 (Interpretation)

这是全书的地基公理：**营销之争不发生在工厂和货架，而发生在潜在顾客的心智里；心智中已存的认知才是决策要面对的"现实"。** 五条推论：

1. **认知大于事实**：产品是谁不重要，顾客认为你重要。品牌不是在工厂里造出来的，而是在心智里打造出来的——同样的产品，挂在不同认知下就是不同的命运。
2. **接受方是对的**：传播者总觉得自己说清了，但只有接收端的认知算数。"你看到的是你想看到的，你尝到的就是你想尝到的"——认知塑造体验本身，顾客的"误解"就是你的真实处境。
3. **不要试图改变心智**：心智一旦形成几乎不可改变，砸钱教育市场是营销中被违背最多、也最昂贵的一条判废标准——凡以"纠正顾客误解"为前提的动作默认判废。
4. **由外而内 vs 由内而外**：由内而外从产品、名望、内部逻辑出发（识别句式："我们的名字顾客都知道，他们自然买我们的新品"），每步在内部都"合情合理"，却违背心智规律；由外而内从心智中已有的认知出发，一切定位工作的起点是回答："提到我的名字，普通人脑子里出现什么？"
5. **逻辑不是应付心智的最佳战略**：干白威士忌在逻辑上成立、在心智中不成立（威士忌就该是棕色的）。做传播不是与人辩论，逻辑自洽的方案照样输给认知现实——战略判断以心智现实为准，不以内部商业逻辑为准。

操作总纲：心智不会为全新事物腾出空位，只会沿已有认知挪动一格；新信息必须挂靠心智已有之物。

## A1 — 书中的应用 (Past Application)

### 案例 1: 新可乐灾难
- **问题**: 面对百事的挑战，可口可乐想用"更好喝"的新配方夺回市场份额。
- **方法论的使用**: 公司自调研显示盲测 3:1 偏好新配方，便试图用产品事实去"提升"顾客心智中"可口可乐=正宗经典"的认知——典型的由内而外+用事实挑战认知。
- **结论**: 认知决定味觉："你尝到的就是你想尝到的"。盲测的事实赢不了心智中的认知。
- **结果**: 看到商标后 4:1 的人偏好经典可乐，酿成营销灾难，被迫恢复经典配方。

### 案例 2: 米狮龙"堪称一流"
- **问题**: 米狮龙不是第一个高价进口啤酒（那是喜力），作为国产啤酒如何建立高档形象？
- **方法论的使用**: 不争辩"国产也能高端"的事实，改由外而内找心智空位——做"第一个高价国产啤酒"，用"米狮龙堪称一流"这句像交通标志一样直白的广告把位置钉进心智。
- **结论**: 成功的思考方向不是"我的产品是什么水平"，而是"心智阶梯上哪个位置还空着"。
- **结果**: 几年间成为美国销量最大、价格最高的啤酒之一（其后来放弃定位概念是 FWMTS 的另一教训）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "产品明明更好却卖不动"：评测数据、参数、盲测占优，就是输给认知里占位的对手。
2. 想用事实、数据、检测报告或公关去纠正顾客的既有印象（差评标签、"不耐用""不安全"的误解）。
3. 评审一个内部逻辑自洽的方案：团队推理步步成立、一致通过，市场却毫无反应。

### 语言信号 (用户的话里出现这些就应激活)

- "产品明明更好""用户对我们的印象是错的""我们要教育市场""用数据证明自己"
- "只要体验过就会喜欢""盲测/实测赢了对手""纠正误解"
- "从我们的角度看逻辑没问题""内部全票通过但市场没反应""顾客不了解我们"

### 与相邻 skill 的区分

- 与 `own-one-word-in-mind` 的区别：本 skill 判定"必须顺应认知、从心智找答案"这个方向；具体选哪个词、怎么一词占领由后者接管。认知地基判废在前，选词操作在后。
- 与 `positioning-game-rules` 的区别：由内而外也是心态病，若用户要的是实践者素质自检（他人导向、客观、敢犯错、不追风口），走后者；本 skill 处理的是具体战略判断"该顺应还是对抗认知"。
- 与 `first-in-mind-beats-better` 的区别：要不要抢"第一"、上市时机与心智次序容错度找后者；本 skill 是其下更底层的"认知大于事实"公理与判废标准。
- 与 `mental-ladder-diagnosis` 的区别：需要动手调研"我们在心智阶梯第几层"、设计含对手的问卷找后者；本 skill 只给思维方向与判废标准。

## E — 可执行步骤 (Execution)

1. **停止争论事实，先写下认知现状**：回答"提到我们的名字/品类，潜在顾客脑中出现什么？"
   - 完成标准：一句话写出心智中的既有认知（哪怕是偏见），注明依据（评价、口碑或调研），禁止用产品参数代替。
2. **判废对抗动作**：列出所有以"教育市场/纠正误解/证明我们更好"为前提的计划，逐项标记为高预算低成功率
   - 完成标准：凡以改变心智中已有认知为前提的动作全部判废或降级重组。
3. **由外而内重述问题**：把"我们想说什么"改写为"心智中哪个已有认知可以利用、哪个位置可以占据"
   - 完成标准：问题陈述以心智现状开头，而非产品清单开头。
4. **顺认知找挂靠点**：让新信息与心智已有之物建立联系（挂靠既有阶梯、借用既有品类认知）
   - 完成标准：方案中每个主张都能指出它借助的认知锚点，指不出即删。
5. **逻辑自检**：用"普通人听着顺不顺"而非"内部论证严密不严密"做终审
   - 完成标准：删除全部"逻辑成立但心智不成立"的干白威士忌式主张，评审通过以局外人视角复述无歧义为准。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 认知方向已判定、进入具体选词与聚焦阶段——转 `own-one-word-in-mind`。
- 要设计心智现状调研、阶梯位次摸底——转 `mental-ladder-diagnosis`。
- 产品事实确实存在硬伤（安全、质量事故）时，本 skill 不是遮羞布：先解决事实，再谈认知。
- 讨论实践者心态与素质养成——转 `positioning-game-rules`。

### 作者在书中警告的失败模式（自弃定位 / FWMTS 家族）

- **FWMTS 陷阱**：打赢定位战后"忘记成功之道"，转而宣传愿望而非事实——安飞士改口"要当第一"、七喜宣称"美国人人喝七喜"，均放弃使其成功的关联定位而份额下滑。
- **米狮龙偏离定位**：成功后改用"夜晚属于米狮龙"式空洞诗意诉求，丧失"一流"地位，错失跻身最畅销国产品牌的机会。
- **自己放弃地位最悲惨**：对手抢占你的地位已经够糟，自己松手（用品牌名延伸覆盖新业务、停掉已有定位诉求）更糟——评估任何动作先计算将让渡的地位价值。
- **定位经营不可中断**：Aim 放弃儿童定位后份额从 10% 崩到 0.8%；红牌伏特加因时机性羞怯回避俄罗斯定位，把"俄式正宗"拱手让给绝对牌。

### 作者的盲点 / 时代局限

- 立场偏广告/咨询视角，对渠道、供应链、成本等非心智因素权重系统性低估——"认知第一"在渠道红利期并非唯一开局路径（流量运营、性价比路线均可先跑起来）。
- 作者批评他人调研不可信，但自己的空位与认知判断同样依赖直觉与个案；"认知不可改变"被过度推广，可能沦为拒绝产品改进的借口——作者的本意是事实须通过认知起作用，不是事实不重要。
- 案例绑定美国 1960-80 年代广告环境；算法推荐与社交传播下认知形成的速度与机制变化未覆盖。

### 容易混淆的邻近方法论

- 泛泛的"以用户为中心/消费者洞察"：本 skill 有具体操作化（心智中的位置、词、阶梯），不是态度口号。
- "认知第一"≠"营销就是改变说法"：它的第一推论恰恰是不要试图改变心智，而是接受并利用认知。
- 公关/危机修复：临时舆情处理不等于心智定位，被钉进"失败者惩罚箱"后修补无效。
