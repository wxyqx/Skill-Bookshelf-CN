# 个人与职业定位

## I — 方法论骨架 (Interpretation)

个人定位与产品定位同律：找的不是"你想成为什么"，而是**你在他人心智中能占据的一个概念**。把定位五步用在人身上：

1. **定义自己**：用一个具体概念概括你，并靠这个职业确立和利用它。别指望别人替你下定义——你不动手，市场就随意定义你。自我标榜必须在他人心智中有可验证的依据（见 B 段"达拉斯最好的律师"）。
2. **要能犯错误**：值得做的事值得一试，不值得做的事根本不该做。等能做得尽善尽美才动手，就永远做不成。试过多次偶尔成功的人，名声反而好于只做有把握之事的人——错误是定位试错的入场费。
3. **名字要合适**：名字是个人定位的第一载体。名字与定位不匹配时果断更换（必要时像影星一样改名），但也别矫枉过正：政客用闻所未闻的名字有欺诈嫌疑，也犯不上起个"麦当劳"去开汉堡店。
4. **避开无名陷阱**：升职期需要的是名字不是首字母缩写——缩写只在人人都认识你之后才有效。先出名，后缩写。
5. **避开个人版品牌延伸陷阱**：依附强势名字是负债不是资产。"小"字辈名字带来先入为主的减分预期；独立形象必须从独立名字开始（政界家族品牌是少数例外）。

**找马骑（六匹马框架）**：人生的成功更多要靠别人为你做些什么——别人能做的事不要只靠自己硬干。六匹马按价值排序：
① **公司**：选成长性行业里超过平均水平的公司，跟随失败者，你再出色也无济于事；
② **上司**：永远为能找到的最精明能干的人工作，问"他有没有前程"；
③ **朋友**：定期维护商界朋友（人生重大转折多由商界朋友推荐促成）；
④ **好想法**：敢逆势而行、耐心等时机成熟，原理可行的标志是反对的强烈与持久；
⑤ **信心**：对别人及其想法有信心（麦当劳兄弟有好想法没信心，克洛克赢在信心）；
⑥ **自己**：最劣、最常被骑却最少成功的一匹。
最好的骑师赢不了比赛，赢的通常是骑着最好的马的那位。

**名气与 publicity 的取舍**：没名气是可蓄积的资源。无名之辈做 publicity 的边际效果远大于名人；出名的目的是在他人心智中建立定位，不是宣传本身。保存匿名资源直到准备好，使用时全力出击——定位未落就先上封面，等于把弹药提前打光。

## A1 — 书中的应用 (Past Application)

### 案例 1: 雷·克洛克骑上"信心"这匹马
- **问题**: 麦当劳兄弟发明了连锁快餐的好想法，但生意始终做不大；年近暮年、一事无成的克洛克凭什么翻身？
- **方法论的使用**: 兄弟俩骑的是"自己"那匹最劣的马——有好想法却没信心；克洛克对别人及其想法下了重注，凭外行人的勇气和恒心接手经营。
- **结论**: 有时候拥有想法的人和拥有信心的人是两拨人，最后赢的是敢骑"信心"那匹马的后者。
- **结果**: 兄弟俩没要几个钱就把想法连同名字卖给克洛克，克洛克把麦当劳办成连锁帝国，身价高达数亿美元。

### 案例 2: 罗伊·罗杰斯改名 vs 小弗兰克·西纳特拉的"小"字
- **问题**: 一个人如何在他人心智中建立清晰独立的个人形象？
- **方法论的使用**: 莱奥纳德·斯莱改名为罗伊·罗杰斯，几乎无人不识——名字与定位匹配是成为明星的重要一步；反向的小弗兰克·西纳特拉顶着"小"字入行，听众先入为主认定他不如父亲，果然唱得不行。
- **结论**: 名字要与定位匹配、依附性名字是负债；个人版品牌延伸借来的预期同时是枷锁。
- **结果**: 约翰·韦恩、科克·道格拉斯、拉尔夫·劳伦都靠改名确立形象；莉莎·米奈丽弃用母亲的姓反而声名超过母亲。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 职业方向抉择：努力多年升不上去、要不要跳槽/换赛道、选什么公司和上司——本质是"该换哪匹马"。
2. 个人定义与个人品牌：说不清"你是做什么的"、想给自己定一个词/一个标签、要不要改名或用英文名缩写。
3. 出名节奏决策：要不要接受采访/做公众号/上媒体——publicity 的时机与定位是否已落。

### 语言信号 (用户的话里出现这些就应激活)

- "个人定位""职业定位""定义自己""给自己贴标签""个人品牌"
- "找马骑""六匹马""选公司还是选努力""要不要跟这个老板"
- "要不要改名""英文名/缩写行不行""低调攒资源还是趁早出名"

### 与相邻 skill 的区分

- 与 `own-one-word-in-mind` 的区别：同样是"占一个词"，主体是**人**（我是谁）用本 skill；主体是**品牌/产品**（品牌等于什么词）找后者。个人词从职业与借力结构推导，品牌词从品类心智阶梯推导。
- 与 `company-institution-positioning` 的区别：个人在其中选公司、骑上司是本 skill；把公司/机构本身作为组织重新定位给公众是后者。"创始人个人 IP"与"公司品牌"要拆开处理。
- 与 `naming-that-hooks` 的区别：给产品/公司起名找后者；给"人"起名、改名、用缩写是本 skill。

## E — 可执行步骤 (Execution)

1. **定义自己**：写一句话概念——"我等于____"（一个词/一个短语，非罗列）
   - 完成标准：通过"达拉斯律师"自检——在目标人群心智中做一次想象调查，你的名字会因这个概念被提到；内心认定不算数。
2. **检查名字资产**：核对真名/常用名与定位是否匹配，有无依附性名字或不当缩写
   - 完成标准：名字无"小"字辈/借名依附；未出名阶段坚持用全名不用缩写。
3. **盘点六匹马**：逐项评估公司、上司、朋友、好想法、信心、自己——当前骑的是哪匹，哪匹值得换、怎么换
   - 完成标准：每匹马有一句现状判断；若结论是"再努力就行"，触发警觉——那正是最劣的一匹。
4. **设定试错行动**：挑值得做的事立刻动手，给出试错次数与止损线
   - 完成标准：有明确的"值得一试"清单；无"等做到完美再开始"的拖延项。
5. **规划公关节奏**：决定何时保持匿名、何时全力出击
   - 完成标准：一句话说出" publicity 是为落哪个定位服务的"；定位未落前不出名。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 给公司/产品做品牌决策（选词、起名、定位传播）——各自归 `own-one-word-in-mind`、`naming-that-hooks` 等对应 skill。
- 纯求职面试技巧、简历优化、技能硬实力提升——本 skill 管的是心智位置与借力结构，不管胜任力训练本身。
- 用户只想听"努力就会成功"的鼓励——本 skill 的结论恰恰是单靠努力（骑自己）最不可靠。

### 作者在书中警告的失败模式

- "我是达拉斯最好的律师"：把内心认定当心智事实。自我标榜若在他人心智中不可验证，就是泡沫。
- 不敢犯错者的下场：成功率96%的麦克斯·凯里无人记得，70%的泰·科布名垂青史；用"尽善尽美"给拖延辩护，永远做不成。
- "我们有最好的员工"式错觉：相信人的因素能替代战略思考，是回避换马的遮羞布。
- 依附性名字（"小"字辈）：借来的预期同时是枷锁；无名期乱用缩写则让名字根本挂不上心智。

### 作者的盲点 / 时代局限

- 案例取自美国 1960-80 年代的职场与媒体环境：层级制公司、杂志 publicity 机制；社交与算法传播下"匿名蓄势—全力出击"的节奏已大不相同。
- 作者建议过许多商界人士改名，至今无人接受——说明此原则落地阻力极大，不宜当轻率建议给出。
- "六匹马"排序基于作者个案经验，缺乏系统证据；对个人专业能力（骑术本身）的权重可能系统性低估。

### 容易混淆的邻近方法论

- 一般成功学/人脉学：本 skill 要求概念可验证、先定概念再借力，不是泛泛的"多认识人、多曝光"。
- 个人 IP 运营术：先解决"你等于什么"（定位），publicity 只是节奏工具；没有定位的曝光是浪费匿名资源。
