## I — 方法论骨架 (Interpretation)

定位游戏在潜在顾客的心智里展开，是长期博弈；比具体打法更先决的，是玩家本人的素质与组织能否让好方案活下来。全章收束为四层：

**第一层：理解游戏的材质——文字与人。** 词语是空容器，含义不在词里而在使用者身上，装不下某个概念就得换容器；词语同时是心智通货——人们用词思考，词语会反向塑造思维过程，但词与实际差得太远会被心智拒收。理解人，就是明白沟通是调用心智中已有含义，而不是灌输新含义。

**第二层：识破三种心态错觉。** ①万物恒变错觉——变的是表象，心智认知万变不离其宗；为追变化抛弃本位的项目尸横遍野，坚持自身最佳特点者反而胜出。②"我能行"精神——相信意志与努力能替代位置判断；位置错了，越努力耗散越快。③"我们有最好的员工"——单个士兵差距有限，人数一多平均能力持平，胜负取决于将军（战略）而非士兵。

**第三层：六项可练习的素质（六要）。** 要眼光：区分波浪与潜流，按五年十年定基础业务，不随每波浪潮转舵；要勇气：局势不明、众人观望时奋力抢占先机；要客观：排除自我意识，定位像乒乓球要两人打，好想法只在切磋中完善；要简单化：显而易见的才进得了心智，复杂巧妙恰恰可疑；要精明：在"独一无二"与"足够大的市场需求"之间找位置，警惕劳斯莱斯思维；要有耐心：资源有限就地域式、分人群、分年龄、分渠道滚动扎根，先在局部形成心智优势再放大。

**第四层：两个姿态补丁与一个否定项。** 全球视野：定位是可跨国搬运的资产，一国占有的位置可带入另一国，命名要经得起全球检验。他人导向：像将军巡视战场，盯对手的弱点与长处，而不是盯自己的决心与资源清单——这是对自我导向的纠偏。否定项：你不需要营销天才的名声，这份名声会诱使你把偶然成功复制到不成立的新战场。

**收束：好方案为何死在组织内，以及如何向内推销。** 定位的最后一段路在组织内部，方案常死于：崇尚复杂、不屑简单（显而易见被嫌"没水平"）；高层个人好恶一票否决；人事更迭后新班子不热心；部门政治夹带私货。对策是把向内推销当作项目的一部分预先完成：把战略简化到"广告自身就是战略"的程度，用心智事实而非内部审美来论证，让全员对战斗目标形成统一认识，并为负责人更迭准备好交接材料。

## A1 — 书中的应用 (Past Application)

### 案例 1: 通用电气：史密斯与琼斯——现实派胜过"我能行"派（第5章）
- **问题**: GE 已进计算机业，但 IBM 在心智中地位稳固，这块业务是继续攻坚还是退出？
- **方法论的使用**: 史密斯是典型的"我能行"式高管，接手后奋力攻坚仍无力回天（作者强调他是最出色的营销专家，谁也救不了）；琼斯客观评估"进入太晚、无法由此及彼"，建议退出。
- **结论**: 位置错了，才能和努力都无济于事；认清"无法由此及彼"并果断止损同样是正确的战略动作。
- **结果**: 计算机业务卖给霍尼韦尔止损；现实派思路在 GE 延续，韦尔奇以"数一数二，否则出局"将其推向极致，百年 GE 重续传奇。

### 案例 2: 比利时航空"五个阿姆斯特丹"（第15章）
- **问题**: 比利时航空沿用同行打法宣传美食与服务，但根子是"没人要去比利时"——国家在心智的国家阶梯上位居底层。
- **方法论的使用**: 以局外人的客观视角重新诊断，放弃供给侧卖点，改给国家定位：借《米奇林指南》权威背书（六个三星级城市五个在比利时），用"在美丽的比利时，有五个阿姆斯特丹"关联心智中已有的阿姆斯特丹。
- **结论**: 广告奏效，诊断正确；但项目最终成败不在战略，而在组织。
- **结果**: 部分成功——广告引来大量游客咨询（包括恼怒的荷兰旅游部长）；随后管理层更迭、新班子不热心，旅游局出于政治原因塞进非三星级城市，项目搁浅。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **团队/自我素质复盘**：战略屡败后怀疑问题不在打法而在心态——团队能不能客观、是不是被"我能行"和天才幻觉绑架。
2. **转型与风口决策**：行业都在喊 All in 新赛道，要判断"万物恒变"是错觉还是真潜流、该不该守住本位。
3. **组织采纳与向内推销**：定位方案内部评审通不过、被嫌"太简单"，或因换负责人、高层个人好恶而濒临夭折。

### 语言信号 (用户的话里出现这些就应激活)

- "只要够努力/够聪明就一定做得成""我们有行业内最好的人""去年那套打法复制过来就行"
- "大家都在追这个风口，我们不变是不是就死了""万变不离其宗还靠谱吗"
- "方案其实很简单，但评审都嫌太简单没水平""新领导一来项目就停了""怎么让老板/董事会点头"

### 与相邻 skill 的区分

- 与 `outside-in-perception-first` 的区别：那边是**认知方法论**——判断该顺应还是对抗顾客既有认知、能不能用事实反驳认知；本 skill 是**心态与素质**——对"人"的偏差做自检与纠偏。问"顾客的认知怎么办"找前者，问"我们自己哪里心态不对"用本 skill。
- 与 `positioning-six-question-process` 的区别：那边是**项目流程**——六问怎么走、预算与滚动节奏；本 skill 不走流程，只做素质自检与组织采纳。若六问卡在"勇气/坚持到底"，先来本 skill 排心态，再回流程。
- 与 `reposition-the-competitor` 的区别：凡涉及攻击对手、争夺概念的传播设计一律归对方；本 skill 只处理自身素质与组织内部采纳。

## E — 可执行步骤 (Execution)

1. **心态错觉排查**：对照四种错觉逐项自评——"我能行"精神、万物恒变、天才名声、"我们有最好的员工"
   - 完成标准：每项给出本组织近一年的具体言行证据，标出中招项；判停条件——全部无证据则转 `positioning-six-question-process` 查流程问题。
2. **六要逐项打分**：眼光/勇气/客观/简单化/精明/耐心各按现状打分并举例
   - 完成标准：每项一句话证据支撑；选出得分最低的 1-2 项定为改进重点。
3. **客观性重建**：为当前战略找"反弹板"——外部顾问、内部异见者，或刻意模拟局外人视角重审方案
   - 完成标准：方案至少被一个非利益相关方挑战过一轮；关键假设（顾客心智中的位置）用外部证据而非内部判断支撑。
4. **向内推销准备**：把战略压缩到一句话、显而易见的程度，预演最高层与关键反对者的质疑
   - 完成标准：战略陈述简单到可印在广告背面；对"太简单没水平""换个复杂思路试试"两类质疑备好心智事实论证；产出负责人更迭时的交接材料。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题出在"顾客怎么认知"而不是"我们什么心态"——去 `outside-in-perception-first`。
- 要启动或复盘完整定位项目（六问、预算、节奏）——去 `positioning-six-question-process`。
- 需要设计针对竞品的攻击传播——去 `reposition-the-competitor`。
- 素质清单中某一单项要专项展开：找空位技术（→ `challenger-follower-positioning`）、换名字换容器（→ `naming-that-hooks`）、分步推广节奏（→ `positioning-six-question-process`）。

### 作者在书中警告的失败模式（家族 G：组织采纳失败；家族 H：心态错觉）

- **崇尚复杂、不屑简单**：完整的"福音教师"定位方案被天主教会嫌"过于显而易见"全盘拒绝，教士们反而推崇无法在心智中存储的六角色复杂定义（e39）。
- **高层个人好恶一票否决**：奶球"大嘴"广告已扭转销量下滑，仅因董事长不喜欢这个形象就被取消（e36）。
- **人事更迭杀死项目**：比利时项目电视片制作中管理层换血，新班子不热心，好方案搁浅（e35）。
- **"我能行"精神与自我导向**：用意志、决心、努力替代对心智与对手的分析——越战、RCA 攻 IBM 皆是此病（e02）。
- **"我们有最好的员工"错觉**：以人的因素为成功关键是回避战略思考的遮羞布，胜负取决于将军而非士兵（e41）。

### 作者的盲点 / 时代局限

- 作者站在广告/咨询视角，对渠道、供应链、成本等非心智因素系统性低估；"素质决定成败"的论证同样依赖个案与直觉。案例取自美国 1960-80 年代的广告代理体制，现代组织（产品经理制、增长团队）中的"向内推销"路径需自行转译。

### 容易混淆的邻近方法论

- 领导力/执行力培训：本 skill 的素质清单全部以"心智与竞争事实"为锚，不是通用励志；脱离心智证据的打分没有意义。
- "由内而外思维"的句式诊断（e27）：那是品牌延伸决策的病根识别工具，归 `brand-extension-rules` 使用；本 skill 处理的是更上游的心态与组织采纳问题。
