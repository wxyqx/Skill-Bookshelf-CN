# 重新定位竞争对手

## R — 原文 (Reading)

> "通过评论竞争对手的产品，动摇并排挤心智中的旧观念，为新品类腾出位置。"
>
> — 里斯 & 特劳特，第8章

---

## I — 方法论骨架 (Interpretation)

空位稀少时，跟随者最基本的上位战略不是宣传自己，而是**重新定位对手**：把对手在心智中占住的旧观念排挤出去——旧理念一倒，顾客会主动寻找新理念补位。操作上有三条纪律：

1. **改认知，不改自述**：要改变的是潜在顾客对对手的认知，而不是把自己的产品说得更全更好。把对手的"强项"揭示为"弱点"——阿司匹林的强项是老牌，弱点是伤胃；李施德林的强项是药效，弱点是药味。
2. **两面性宣传**：有效攻击一句话同时立己破他——Scope 打"药味"，既确立自己清新，又把李施德林钉成难喝；汉堡王"想怎么吃就怎么吃"，既宣传定制化又暗示麦当劳标准化。
3. **公平与事实边界**：重新定位的效力建立在对对手产品的真实评论上；凭空贬低会适得其反（拜耳公开反驳泰诺，反而证实了"泰诺更安全"），还招致法律与舆论反噬。

两条心理杠杆：人们喜欢看神话破灭，冲突能让你一夜成名；对手教育好的品类认知可反转为攻击点，**对手广告费越多，你借力越大**（奶球打"棒状糖两三秒吃完"，好时广告越多越衬托它"耐吃"）。

完整四步（奶球示范）：①调研心智现状，确认对手占据的位置 → ②找对手结构性、难改正的弱点 → ③把弱点转成自己的定位概念 → ④戏剧化表达。

## A1 — 书中的应用 (Past Application)

### 案例 1: 泰诺重新定位阿司匹林
- **问题**: 泰诺作为止痛药新品牌，如何从阿司匹林主导的市场上位？
- **方法论的使用**: 不自夸"更温和"，而是揭示阿司匹林/ AP C 类产品的结构性弱点（伤胃、与 Reye 综合征关联的提示），把"医生的阿司匹林"变成"需要注意的阿司匹林"。
- **结论**: 旧观念被推翻后顾客主动寻找替代，泰诺顺势占据"不伤胃的止痛药"位置。
- **结果**: 泰诺成为全美头号止痛药，超过阿司匹林与布洛芬。

### 案例 2: 奶球（Milk Duds）
- **问题**: 小公司新糖果在传播过度的糖果市场毫无机会。
- **方法论的使用**: 调研确认心智现状=棒状糖；找弱点=两三秒吃完；转化成"耐吃的糖果"（盒装 15 颗可吃一下午），用"大嘴"广告戏剧化表达。
- **结论**: 答案不在产品里而在心智里；对手广告费为奶球打工。
- **结果**: 奶球以极小预算在儿童糖果市场建立"耐吃"位置。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 每个品类都有强手、找不到空位，想讨论怎么借攻击上位。
2. 已经写好/收到一条对比性广告或攻击文案，要评估有效性或合法性。
3. 对手占住一个有力概念（如"公平""环保"），要打议题战、换框架。

### 语言信号 (用户的话里出现这些就应激活)

- "重新定位对手""攻击性传播""对比广告能不能用""找竞品弱点"
- "借力打力""把对手拉下马""换说法/框架战"
- "这条文案会不会显得我们只会自夸"

### 与相邻 skill 的区分

- 与 `challenger-follower-positioning` 的区别：先决定"占哪个位置/用哪种跟随策略"找后者；位置已定、设计攻击传播时用本 skill。
- 与 `leader-defense-playbook` 的区别：领导者被攻击时怎么防（含要不要回应）找后者；本 skill 是攻击方视角。
- 与 `outside-in-perception-first` 的区别：认知地基问题（该不该对抗认知）找后者；本 skill 是具体的攻击方法。

## E — 可执行步骤 (Execution)

1. **确认对手心智位置**：调研目标品类心智现状，写出对手占据的词与承诺
   - 完成标准：一句话说出"对手在顾客脑中等于什么"。
2. **寻找结构性弱点**：优先找真实、难以改正、且与其强项绑定的弱点
   - 完成标准：弱点经事实核查成立；判停条件——找不到真实弱点，停止攻击（转 `challenger-follower-positioning` 找空位）。
3. **转化概念 + 两面性表达**：把弱点转成己方定位概念，一句话立己破他
   - 完成标准：概念排除自夸式对比（非"我们更强"句式）。
4. **预检反弹风险**：评估对手反驳空间、法律与舆论边界
   - 完成标准：通过"真实评论/公平"自检，有对手反噬的应对预案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 找不到对手真实弱点时的硬攻——自夸式对比广告有"既然你那么强，为什么还没发财"的心理漏洞。
- 用户是品类领导者——防御动作归 `leader-defense-playbook`。
- 产品与对手无真实差异维度可借力——先回 `own-one-word-in-mind` 聚焦。

### 作者在书中警告的失败模式

- 对比性广告冒充重新定位（罗列自家优越性），观众自动加"在它看来"。
- 凭空贬低或失实攻击，被对手公开反驳后反而坐实对方说法（拜耳 vs 泰诺）。
- 正面进攻地位稳固的领导者四连败（NCR 等）——本 skill 是排挤旧观念，不是实力对决。

### 作者的盲点 / 时代局限

- 案例取自美国 1960-80 年代广告环境；社交/算法传播下"冲突建名声"的机制变化未覆盖；攻击战的合规边界各国法律差异大。

### 容易混淆的邻近方法论

- 对比性广告（自夸式）：本 skill 的反例形态。
- 公关危机战：借的是负面事件，不是结构性弱点转化。
