## I — 方法论骨架 (Interpretation)

作者处理涉外投资问题有一条固定的判断链:**先定身份,再查准入,然后选结构与形式,最后看程序效力与管辖**。拆开是七件工具:

1. **身份认定看国籍,不看币种**:一个公司是内资还是外资,取决于股东国籍而非出资货币——外国人用境内人民币收入设立的公司仍是外资;反过来,外商投资企业再投资设立的公司是中国法人投资的企业(执照加注"外商投资企业投资"),也不是内资。港澳台个人和公司投资比照外资办理。历史框架下另有"25%待遇线":外资并购后外方出资比例高于 25% 才享受外商投资企业待遇,低于 25% 企业性质仍变更为外资但无待遇——性质与待遇是两个问题。
2. **准入穿透**:准入管制穿透到结构背后——外资企业再投资、内资壳代持、隐名安排,任何形式都不得绕开禁止/限制类领域;"外商投资企业再投资"不是内资化通道。规避准入的隐名投资协议直接无效;不规避准入的隐名投资协议原则上有效但只约束双方,且审批部门一般不轻易认可"显名",常须经股东确权之诉。
3. **境内自然人合资限制与变通菜单**(历史框架):当时原则禁止境内自然人直接与外方合资,合法变通有三条——①先设一人有限公司以公司名义合资(该壳公司此后不能注销,合资企业依赖其存续);②先按内资设立运营,再由外方增资变更为外资企业(保留自然人股东身份,经营不受影响);③在允许自然人合资的特定地区直接设立。选择变量是时间、审批与股东身份保留。
4. **形式选择——代表处 vs 分公司**:分水岭是"经营性质"。只调研不经营→代表处(手续极简、不纳税但不能签业务合同,有效合同须总公司签);要独立签约经营→分公司(须办境内境外投资手续+东道国登记,且分公司非独立法律实体,总公司对其合同承担全部责任)。试水市场先代表处,确认模式再升级。
5. **离岸公司注册地比较框架**:按四个参数比较离岸地——注册费/年费水平、文件认证便利度(有无中国大使馆)、银行开户可行性(如不同离岸地可开户银行不同)、中文名称可得性。离岸公司通常作境外/返程投资控股壳,注册地服务于后续用途而非单看价格。
6. **程序即效力——审批生效主义**(历史框架):当时外资并购协议须经审批才生效,"批则有效、不批则悬置",顺位是先报批后履行;未报批=效力悬置,价款可要求返还、损失按过错分担。公证不能替代审批。
7. **跨境争议管辖判断顺序**:先看当事人有无约定管辖法院(可约定中国或符合规定的外国法院);无约定的找连接点——投资合同签订地、被告住所地、被告可供扣押财产地任一在中国大陆,即可在大陆法院起诉。

## A1 — 书中的应用 (Past Application)

### 案例 1: 高博士合资三部曲——自然人不能做中方怎么办(第十章 问题198/199/200/210)
- **问题**: 海归高博士(美籍朋友持专利技术)想在园区设合资公司,但境内自然人原则上不能当合资企业中方,三次来信追问变通办法。
- **方法论的使用**: 律师先定性(除浦东等特定地区外不可行),再给结构菜单:①高博士先设一家一人有限公司,以公司名义与美方合资;②或由美方对该一人公司增资,将其变更为中外合资企业,高博士保留自然人股东身份;③若由美方先设独资企业再"合资",则是中国法人与中国自然人共同设公司,适用《公司法》而非合资企业法——但该独资企业再投资仍受准入管制,禁止类无解。股权赠与方式因审批部门难接受而不推荐。
- **结论**: 用"一人公司搭桥/外方增资变身"替代直接合资的直觉方案;壳公司是合资企业的存续依赖,不能事后注销——主体资格限制靠结构设计化解,而不是硬闯或隐名硬藏。

### 案例 2: 动漫公司未报批并购收尾案(第十章 问题234)
- **问题**: 澳籍华人韩某以 120 万元收购动漫公司大股东张某 50% 股权,协议签了、钱经公司账付了,但始终未开股东会、未办外资并购报批;韩某反悔,要求返还全部转让款。
- **方法论的使用**: 律师先定性——受让方是外国人,这不是普通股权转让而是外资并购,适用《公司法》之外还优先适用外资并购规定;审批生效主义下协议能否生效取决于审批结果。法院通常会询问其他股东意见并责令补办报批:获批则协议有效,韩某违约;不批则协议不生效,可返还价款。另指出两处硬伤:张某无权擅自处分公司财产(设备资产转让书无效),人民币付款须经外汇核准。
- **结论**: "签了+付了"不等于"生效了"——涉外交易的效力挂在程序上;定价、付款方式、审批顺位必须一开始就按外资并购的特别规则设计。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有外籍/港澳台身份的人要在中国投资开公司或与境内方合资,纠结"算内资还是外资""自然人能不能当股东""怎么搭结构"
2. 涉外方要受让境内公司股权、或境内公司要引入外资,问"协议签了算不算数""要不要报批""怎么定价付款"
3. 想出海设点(代表处/分公司/子公司)或注册离岸公司,比较形式与注册地;跨境合作合同要写管辖条款或已生纠纷想知在哪儿起诉

### 语言信号 (用户的话里出现这些就应激活)

- "外国籍/美籍/香港人/台湾同胞 开公司算什么性质/能不能做股东"
- "外国人用人民币出资/外资收购我们的股权/引入外资要不要审批/没报批有效吗"
- "代表处还是分公司/去香港还是 BVI 开曼注册离岸公司/返程投资"
- "和外国合作方发生纠纷,能在国内法院起诉吗/管辖条款怎么写"

### 与相邻 skill 的区分

- 与 `nominee-shareholding-risk` 的区别: 那是纯内资代持的一般风险设计;本 skill 聚焦涉外维度——规避准入的代持直接无效、外资隐名"显名"须过审批关。涉外代持先来本 skill 定准入合法性,再谈代持协议设计
- 与 `equity-transfer-pricing` 的区别: 那是股权转让定价与优先购买权的一般程序;本 skill 处理受让方是外国人时的特别定性(外资并购、审批效力、外汇支付、25%待遇线)
- 与 `entity-choice-incorporation` 的区别: 那是境内企业形式选择(合伙/有限/股份/独资);本 skill 是跨境形式选择(代表处/分公司/离岸地/控股壳)与准入判断

## E — 可执行步骤 (Execution)

1. **第一步:身份认定**
   - 逐一确认投资者国籍/注册地(护照、港澳台身份、境外公司注册地),按"国籍定内外资"输出性质判断;注明历史框架下"25%待遇线"只影响待遇不影响性质
   - 完成标准:给出每个投资主体的内外资定性表,并指出哪些主体比照外资办理
   - 判停条件:所有主体均为境内自然人/内资法人且无跨境安排时,停止本 skill,转 entity-choice-incorporation 或 nominee-shareholding-risk

2. **第二步:准入穿透检查**
   - 以目标行业查准入管制(书中为产业目录四分类——现行法下须改查负面清单),穿透检验拟用结构(再投资/内资壳/代持/隐名)是否试图绕开;涉及禁止类的直接给出"结构无解"结论
   - 完成标准:行业归类结论 + 穿透检验结论 + "可做/受限/不可做"三档判定

3. **第三步:结构与形式选择**
   - 自然人合资按变通菜单(一人公司搭桥/外方增资变身/特定地区直接合资)逐项过时间、审批、股东身份三变量;跨境设点按"能否独立签约"分水岭在代表处/分公司/子公司间选择;离岸注册地按费用/认证/开户/名称四参数比较
   - 完成标准:给出结构对比表与推荐路径,注明每条路径的存续依赖(如中方壳公司不能注销)

4. **第四步:程序效力与管辖风险检查**
   - 涉外交易核对"审批→履约"顺位(现行法下为负面清单准入许可与信息报告),提示未办程序的效力悬置风险与外汇支付要求;跨境合同先查有无管辖约定,无约定按连接点(签订地/被告住所地/可供扣押财产)判断
   - 完成标准:输出程序风险清单与管辖条款建议
   - 判停条件:用户要的是具体报批材料清单或现行审批流程细节时,停止引用书中程序(已废止),明确建议咨询涉外律师按现行法办理

## B — 边界 (Boundary) ★

### ★★★ 法律时效性警示——本章是全书时效风险最高的部分 ★★★

**本章(第 8、10 章)约七成操作细节已因制度更替而失效,只剩历史框架价值。使用本 skill 输出前必须读完本节。**

- **2020 年《外商投资法》废止外资三法**(中外合资经营企业法、外资企业法、中外合作经营企业法),本书引用的合资企业法条文、批准证书体系整体退出历史
- **负面清单取代产业目录**:《外商投资产业指导目录》四分类(鼓励/允许/限制/禁止)已被"准入前国民待遇+负面清单"取代,书中所有行业归类结论(法律咨询禁止、健身鼓励、房地产限制等)必须按现行负面清单重新查证
- **商务审批改信息报告制度**:"审批生效主义"已终结——外资并购不再逐案商务审批,协议不再因报批而生效;但"效力悬置"的分析框架可迁移至负面清单限制领域的准入许可与民法典报批条款规则
- **投资总额概念淡化**:书中投资总额/注册资本比例表(300 万美元 7/10 等)及配套的进口设备免税政策已随制度演进失去普遍适用意义,不得再按比例表设计资本结构
- **37 号文重构外汇登记**:境内居民境外投资外汇登记体系(37 号文)与本书所述外汇核准完全不同,返程投资的登记路径必须按现行外汇规则重走
- **CRS/经济实质法改变离岸地选择逻辑**:BVI、开曼等离岸地引入经济实质法,CRS 金融账户信息交换普遍化——书中"塞舌尔便宜、有中国大使馆方便认证、可起中文名、但不能在汇丰开户"这类比较结论既过时也不再构成充分的选地理由,现在的比较维度必须加入税务透明、经济实质要求与合规成本
- **保留价值**:本 skill 保留的不是操作细节,而是"准入穿透、身份认定(国籍≠币种)、程序即效力"这三个思维框架——它们在现行负面清单制度下依然成立
- **任何实际涉外安排(设点、合资、并购、返程投资、离岸架构)必须按现行法重新设计并咨询涉外律师**;本 skill 输出为方法论蒸馏,不构成法律意见

### 作者的盲点 / 时代局限

- **VIE/红筹空白**:成书正值 10 号令关联并购与协议控制(VIE)是跨境架构主流话题的年代,全书对 VIE、红筹上市架构只字未提——用户问及此类架构时本 skill 无书中素材可依,不得用书中框架硬套
- **几乎无税务维度**:境外转让方预提税、受赠股权个税、税收协定等仅一笔带过,涉外安排的税务成本与筹划需另行补足
- 案例全部化名并经律师转述,德国法部分作者自己标注"仅供参考,建议向德国律师咨询"——跨境部分对外国法的转述精度有限

### 容易混淆的邻近方法论

- 内资代持风险设计(nominee-shareholding-risk):一般代持协议原则上有效;涉外规避准入的代持直接无效——同一工具,准入语境下后果完全不同
- 境内组织形式改制(entity-choice-incorporation):"形式不能直接互变"是境内规则;跨境设点中代表处→公司是常规升级路径,两者不要互相套用
- "外资并购"与"外商投资企业再投资"是两套程序(书中问题227):前者是外国人直接并购境内企业,后者是中国法人投资——不要混为一个"外资流程"
