# 股权权益设计工具(表决/分红/技术股)

## R — 原文 (Reading)

> "它实际上是一种'劳务出资'，而不是我国公司法意义上的技术出资"
>
> — 杨春宝、王成兵，《创业投资法律手册》第一章 问题23

> "该入股技术必须经过评估以确认其价值以及所占的相应的股权比例，而且该技术必须转让给公司"
>
> — 杨春宝、王成兵，《创业投资法律手册》第一章 问题23

> "所谓'干股'一般只有分红权，并不享有其他股东权利"
>
> — 杨春宝、王成兵，《创业投资法律手册》第一章 问题24

> "虽然高博士只占50%股权，但是在公司章程中约定高博士享有60%的分红权"
>
> — 杨春宝、王成兵，《创业投资法律手册》第一章 问题24

> "股东按照实缴的出资比例分取红利；公司新增资本时，股东有权优先按照实缴的出资比例认缴出资。"
>
> — 杨春宝、王成兵，《创业投资法律手册》第二章 问题77

> "全体股东约定不按照出资比例分取红利或者不按照出资比例优先认缴出资的除外"
>
> — 杨春宝、王成兵，《创业投资法律手册》第二章 问题77

## I — 方法论骨架 (Interpretation)

作者的核心主张:有限公司兼具人合与资合属性,股权的各项权能(表决、分红、优先认缴)并非铁板一块——在法定默认比例之外,全体股东可以用协议和章程把各项权益"拆开重排"。设计按四层展开:

1. **表决权与分红权可以脱钩(设计的法律基础)**:有限公司默认按实缴出资比例分红、按出资比例行使表决权,但分红与优先认缴两项"全体股东约定不按出资比例"即可排除默认规则,表决权亦可由章程另行约定——这是人合性给的自由度。边界同样清晰:这套脱钩只在有限公司可行,股份公司同股同权是刚性约束;董事会表决一人一票更是强制性规定,不得按出资比例加权。
2. **技术贡献者多占权益的三种合法路径**:技术"能力"是劳务,法律明确禁止作价出资——想多给,只能靠结构。菜单:①其他股东签协议把部分股权的**分红权无偿转让**给技术方(类似干股,不改变股权结构);②在**章程中约定超额分红**(如出资50%约定分红60%),股东身份与工商登记不变;③其他股东**成立后无偿受让**股权给技术方,同时章程锁定表决权仍按原出资比例——即"分红多、表决不变"的完整权益切分。若技术方要成立时即持实股,可由其他股东代缴其出资份额并交付缴款凭证。
3. **技术股 vs 干股之分**:真正的"技术出资"须载体化(记载于载体、可转移、能独立创造价值)、经评估、并把技术权属转让给公司,换来的是与普通股完全同权的股权;"干股"不是法律概念,一般只含分红权、不登记、不能对抗外部——两者差别是"完整权能的股权"与"某项权能的让渡"。
4. **分红与优先认缴的章程约定空间(设计杠杆与边界)**:默认规则是实缴比例(注意:是实缴不是认缴,未实缴到位者分红权与优先认缴权都要打折扣),全体股东一致约定即可改变;引进外部投资人增资时,先处理原股东优先认缴的放弃或事先排除,否则增资程序有瑕疵。设计前先问三个问题:权益拆给谁、拆哪一项权能、用什么文件固定(协议/章程/登记)。

## A1 — 书中的应用 (Past Application)

### 案例: 高博士的"10%技术股"——E公司 60% 权益安排(第一章 问题23/24/26)
- **问题**: 高博士出资50万、另两位创始人沈先生、韩先生各出25万(注册资本100万)。高博士是技术好手且负责技术和业务经营,要求以技术出资多占10%达到60%股权;韩先生对"10%技术股"意味着什么有顾虑。
- **律师意见**: 高博士的技术特长属"劳务出资",法律不允许作价出资——技术"能力"本身不是股。想实现60%权益,按真实想法与默契度选菜单:①签协议由另两人将10%股权的**分红权无偿转让**给高博士;②章程约定高博士虽持股50%但**享有60%的分红权**;③成立后将10%股权无偿转让给他,但章程明确表决权仍按50%:25%:25%;若要成立时即享完整60%股权,可由另两人将各自出资中的5万元以高博士名义存入公司账户并交付缴款凭证(代缴出资)。若走真"技术出资"路线,则技术须评估、须转让给公司。
- **结论**: E公司最终采用"持股50%、分红60%"的章程安排(问题26回访证实:三人分别持股50%、25%、25%,"但是高博士的分红比例为60%")——不出资的技术贡献通过章程层权益切分合法落地,而不是虚设技术股。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队里有不出钱的技术合伙人/资源方,讨论"技术股""给多少、怎么给"
2. 想让某人"只拿分红、不管事"(或反过来"有表决权但少分红"),问分红比例能否与持股比例不同
3. 引进外部投资人增资,被提醒老股东有优先认缴权,问怎么安排

### 语言信号 (用户的话里出现这些就应激活)

- "他不出钱但出技术,想占30%,行吗/怎么给"
- "技术股/干股到底是什么,能不能写进工商登记"
- "分红可以不按持股比例吗/章程能约定他多分红吗"
- "只给他分红权,不给表决权/一票否决"
- "引进投资人,老股东的优先认缴权怎么办"

### 与相邻 skill 的区分

- 与 `capital-contribution-compliance` 的区别: 那是"什么东西能合法出资"及评估、权利转移程序(专利/设备/厂房入股);本 skill 是出资之外**权益结构怎么切**(分红/表决/路径菜单)——用户问"专利入股怎么评估"给前者,问"不出钱怎么多占股"给本 skill
- 与 `charter-governance-design` 的区别: 那是治理机构、授权清单、僵局条款的完整章程设计;本 skill 只覆盖股东权益(表决/分红/优先认缴)的拆分与落点,会议规则与权力清单归前者
- 与 `employee-equity-incentive` 的区别: 那是员工激励(干股协议、期权变通、离职收回);本 skill 面向创始团队/技术合伙人的权益安排,技术股三路径在激励语境下仅作衔接
- 与 `nominee-shareholding-risk` 的区别: 那是隐名投资的代持风险;本 skill 是显名股东之间的权益比例设计

## E — 可执行步骤 (Execution)

1. **第一步:需求定性——他到底要什么权能**
   - 逐项确认:技术/资源方要的是"利益"(分红)、"控制"(表决)还是"身份"(登记股东);明确三者的区别与可拆性
   - 完成标准:输出一张"权能诉求表"(分红/表决/优先认缴/登记身份,各打勾)
   - 判停条件:用户问的是"我的专利/设备怎么作价入股"这类出资合法性与评估程序问题,转 capital-contribution-compliance;问的是员工期权或离职收回,转 employee-equity-incentive

2. **第二步:路径选型——按默契度与紧迫度挑菜单**
   - 对照三路径选型:只要利益→分红权让渡协议或章程约定超额分红;要完整股权且互信→成立后无偿受让;要成立时即实股→其他股东代缴出资份额并交付缴款凭证;若手上有真正的可转让技术(载体化、可估价),才考虑技术出资路线(评估+权属转让)
   - 完成标准:每条路径附适用条件、配套文件清单与"干股不登记、技术出资必须转让权属"的边界提示

3. **第三步:章程与协议落点**
   - 把选定安排写对文件:分红权让渡用全体股东协议;超额分红与表决权锁定写入章程;成立时点安排核对优先认缴权的处理(放弃声明或章程事先排除)
   - 完成标准:每一项拆分都有明确的文件载体、生效时点与登记与否的说明;约定与工商登记文件不冲突

4. **第四步:反事检验**
   - 检查三条线:是否把"技术能力"直接当出资(违禁);分红脱离持股比例是否取得**全体股东**一致同意;未来增资/新股东进入时该安排是否会被稀释或触发优先认缴争议
   - 完成标准:三条线各有结论;不通过项回退第二步重选路径

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 股份公司的权益设计(同股同权是刚性原则,脱钩工具仅有限公司可用;本书视角是有限公司)
- 用户要现成协议/章程条款示范文本——本 skill 输出设计要点与路径选型,正式文本需律师起草
- 规避强制性规定的安排(如以权益切分包装代持规避准入,见 nominee-shareholding-risk)

### 作者在书中警告的失败模式

- **把技术能力当股**: "我负责技术所以该多占股"是劳务出资,法律禁止作价出资——不给结构(三路径)而口头承诺"技术股",纠纷时一文不值
- **分红的交付风险**: 约定了超额分红≠拿得到——分红须公司先作出分红决议,控制方通过"不分红决议+账面处理"即可让技术方的分红权落空;权益设计须与治理设计(知情权、僵局条款)配套
- 干股被误当完整股权: 只有分红权、不登记,主张股东身份或对外转让均无依据

### 作者的盲点 / 时代局限

- **法律时效性警示(必读)**: 本书为 2014 年版(2013《公司法》修正案语境)。2023 年《公司法》(2024-07 施行)已引入**类别股**制度(第144条:股份公司可发行优先/劣后分红、特殊表决权、转让受限等类别股)、授权资本制等,"同股不同权"的设计空间比书中大得多,但规则结构与本书完全不同——默认分红/优先认缴的"全体股东另有约定除外"弹性在新法下保留,具体条文、基数与程序须逐一对照现行法核实;本 skill 输出为方法论蒸馏,不构成法律意见,重大安排请咨询执业律师
- **无税务维度**: 无偿受让股权、超额分红、代缴出资的个税与折旧摊销成本,全书几乎未覆盖——而这往往是技术股方案谈判的核心变量,落地前必须补税务测算
- 案例全部化名经律师转述;上海园区语境,登记实践各地有差异

### 容易混淆的邻近方法论

- **优先股 / AB股(双重股权)等美国概念**: 优先股、超级投票权是境外公司法与投资条款语境的概念,2014 年中国法下并无对应制度(2023《公司法》类别股是其本土对应物,但规则不同)——不要把美国式 AB 股条款直接套进有限公司章程
- **对赌、领售/随售、期权池**: 投资条款工具,本书完全未覆盖,设计中勿混入并当作本书方法
- 与章程治理设计的关系: 权益拆分只是设计的一半,表决程序、授权清单、僵局条款归 charter-governance-design,两者须配套使用
