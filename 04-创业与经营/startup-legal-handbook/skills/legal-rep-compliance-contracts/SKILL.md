## I — 方法论骨架 (Interpretation)

作者的核心主张:法定代表人是"权力下放、责任不下放"的位置——对外一切行为的后果先归公司,但违法时"直接负责的主管人员"个人照样担行政、刑事责任。围绕这一位置,书内形成一组身份与交易的操作规则:

1. **概念纠偏(口语误用)**:把法定代表人简称"法人"是错的——法人是公司这个组织,法定代表人才是那个自然人;"董事长一定是法代"也不成立,取决于章程规定。
2. **人选规则**:法代只能由董事长、执行董事或经理三者之一担任(由章程确定),与是否股东、持股比例完全无关——40%股东可以当,100%大股东之外的经理也可以当。
3. **责任归属**:民事后果原则上归公司;但违法事务(抽逃、侵占、挪用、偷逃税、走私)即使非其亲自实施,作为"直接负责的主管人员"仍担行政/刑事责任——不参与经营不能自动免责。
4. **挂名法代的风险与自保**:挂名者不担出资不实与公司亏损的民事责任,但印章不受控时会被调查甚至起诉;书内自保方案=只任董事长(凭章程制约实际经营者)、让实际经营者(如总经理)担任法代、管住签章、留存不知情/未参与的证据。
5. **免职≠卸责**:股东会免职后未办变更登记,对第三人仍是法代(登记对抗),其持章行为公司仍须先承受再追偿;登报声明毫无意义。变更登记=免职文件+新任任职文件+变更登记申请书(原法代拒签的,由拟任者凭决议签署),自决议作出之日起30日内申请,逾期1万-10万罚款;被免职者的自救是推动登记+把免职决议复制件与免责声明发至工商、公司、各股东。
6. **真假董事长(内外效力两分)**:股东会决议管公司内部,工商登记管对外公示——相对方基于执照与"原法代"成交的,公司不得以内部变更对抗,只能承受后果再追责。
7. **合同风险防范三步清单**:订约前查对方执照与代理人授权委托书;订约时用书面形式、条款详尽全面、写明争议解决与管辖;履行中及时沟通、签补充协议、积极主张权利并留证据防诉讼时效。
8. **前端文件的效力光谱**:代签(有授权有效/知情不否认=默示追认/无权代理1个月催告期);冒名签约对被冒名者无约束力,构成欺诈可撤销、只赔信赖利益(缔约费用+履约准备+合理机会损失);意向书三档(排除约束力条款→不担违约但担缔约过失/具备基本条款且未排除+一方履行对方接受→转化为合同/约定同等效力→即主合同);备忘录按实际内容定命运。
9. **名称与资金红线**:企业名称经核准后在同区域同行业排他,"国际"字样仅限特定企业,许可他人用自己的名称=出租名称违法;公司资金炒股=转投资,须股东会同意,个人擅自动用即触挪用资金罪;企业间直接拆借当时被禁、可行通道是股东个人出借(民间借贷,利率当时上限为银行4倍)。法代兼任董事/经理的,还随身份负竞业禁止与归入义务(免职后另立门户不受限,见 v-A13);公司对外担保须决议,交易相对方应索要(见 v-A52)。

## A1 — 书中的应用 (Past Application)

### 案例 1: 周先生被免了职,却还背着法代责任(第二章 问题58 — 主案例)
- **问题**: 持股18%的周先生任董事长兼总经理兼法定代表人,小股东临时股东会解除其董事长、总经理职务,但未提名继任者、未办变更登记;周先生交出公章后"不能行使管理职权,却要承担法定代表人可能承担的责任",问责任能否减轻或免除。
- **律师意见**: 法代人选仅限董事长/执行董事/经理三者,免职后的周先生已不在范围;但变更登记须免职文件、任职文件和登记申请书,工商严格照章办事,他径自申请变更可行性甚微——应主动沟通尽快确定新人选并办登记;公司拖延的,可把免职决议复制件连同个人免责声明发至工商部门、公司和各股东;只要能证明对公司可能的违法行为不知情、未参与,或可减轻甚至免除日后责任。
- **结论**: 法代责任跟着登记走,不跟着职权走。被免职者的自保三件套=推动变更登记+书面声明留痕+保留不知情证据。

### 案例 2: 朱某免职风波——登报声明毫无意义(第三章 问题86)
- **问题**: 执行董事朱某被股东会免职后拒交公章,众股东报案登报声明"公章被盗"并另刻公章;朱某持营业执照与章程要求报社更正。
- **律师意见**: 股东会可解职不能胜任者,但变更法定代表人须办变更登记;未登记前对第三人朱某仍是法代,其持章对外行为公司不得主张无效,只能先担责再追偿;登报声明"毫无意义","与其刊登声明,不如办理变更登记";30日内须申请登记,逾期罚1万-10万。
- **结论**: 登记对抗第三人,"登报了"永远不等于"生效了"。

### 案例 3: 真假董事长,谁有诉讼代表权(第三章 问题93)
- **问题**: 股东会三个月前已任命新董事长,但未办变更登记;原董事长钱先生以公司名义起诉(诉状法代与执照一致),公司发现后由新法代申请撤诉。
- **律师意见**: 对内,股东会决议合法有效,新法代可代表公司撤诉(不影响交易安全时);对外,相对方基于营业执照信任钱先生所为的交易,公司不得以内部变更否定或撤销,必须承受结果或担责——所以必须及时办理工商变更手续。
- **结论**: 决议管内、登记管外;变更登记拖延一天,旧法代的"影子权力"就多存续一天。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被亲友邀请"挂名"当法定代表人(或已是挂名法代想脱身),问风险与自保
2. 公司换了掌权人/自己被免职,法代变更登记办不下来,旧法代还在外面签字盖章
3. 没有法务的创业公司要对外签约,问签合同前后该做什么功课;或拿着意向书/备忘录/被代签的合同问"这算不算数"

### 语言信号 (用户的话里出现这些就应激活)

- "让我挂名当法人/法定代表人,我不参与经营,有风险吗"
- "他已经被免职了/离职了,为什么还是法定代表人,怎么变更登记"
- "登报声明法代换了/公章作废,算数吗"
- "签合同要注意什么/对方业务员代签的合同有效吗/意向书能不能反悔"
- "公司账上的闲钱借给别的公司/拿去炒股,行不行"
- "别人注册了和我差不多的公司名字/公司名称里能用'国际'吗"

### 与相邻 skill 的区分

- 与 `charter-governance-design` 的区别: 那是章程层的授权清单与表决权设计(事前立法);本 skill 处理法代身份本身的责任风险与对外签约的执行合规——授权清单是它的上游
- 与 `veil-piercing-liability` 的区别: 那是股东滥用法人地位对公司债务连带(财产混同);本 skill 是法定代表人个人的行政/刑事责任边界与登记程序
- 与 `nominee-shareholding-risk` 的区别: 那是挂名股东(出资与股东资格风险);本 skill 是挂名法代(签章与"直接负责的主管人员"风险)——两者常同时出现但自保方案不同
- 与 `paper-validity-traps` 的区别: 那是识别"以为生效其实失效"的文件陷阱的通用方法;本 skill 聚焦经营场景(法代/合同/资金)并给出主动的风控动作清单

## E — 可执行步骤 (Execution)

1. **第一步:法代身份与签章风险体检**
   - 逐项确认:是否实际参与经营、印章与法定代表人章由谁掌控、章程如何确定法代人选、是否与实际控制人有书面约定
   - 完成标准:输出一份"民事/行政/刑事"三类敞口清单,并给出"继续担任/只任董事长让实际经营者任法代/尽快脱身"的明确建议
   - 判停条件:用户真正想解决的是隐名投资退出或股东资格纠纷时,转 nominee-shareholding-risk;是想夺回公司控制权时,转 charter-governance-design

2. **第二步:法代变更登记程序(免职/脱身场景)**
   - 按序:股东会/董事会作出免职与任命决议→备齐免职文件+新任任职文件→变更登记申请书(原法代拒签的由拟任者凭决议签署)→自决议作出之日起30日内向登记机关申请
   - 完成标准:登记完成;或公司拖延时,已把免职决议复制件+免责声明发至工商部门、公司、各股东并留痕(登报不作为替代手段)

3. **第三步:合同风险三步清单执行**
   - 订约前:查对方营业执照、非法代签约者验授权委托书(范围/期限/真实性);订约时:书面形式、权利义务与违约责任详尽、明确争议解决与管辖;履行中:问题及时沟通、签补充协议、积极主张权利并保留证据防时效
   - 完成标准:每份重要合同有清单核对记录;发现冒名签约时明确只能主张撤销+缔约过失赔偿,并自查己方查证过失

4. **第四步:前端文件定档**
   - 对意向书/备忘录/代签文件按效力光谱判档:有无排除约束力条款→是否具备基本条款且未排除+一方已履行对方接受(转化为合同)→备忘录按内容三分(磋商记录/补充协议/事实记录)
   - 完成标准:给出"这份文件现在能主张违约责任还是仅缔约过失、还是纯证据"的明确结论

5. **第五步:资金运用红线自查**
   - 每笔资金去向先定性:借贷/转投资/资本性投入——企业间拆借按现行法判断是否偶发+自有资金(不再按"一律无效");炒股等转投资须股东会同意,个人擅自动用触挪用资金罪;股东追加投入须有借款协议与凭证,否则清算时按股权处理
   - 完成标准:每笔资金有定性结论、决议/凭证齐备性检查结果;判停条件:涉及公司向股东支付股权转让款等抽逃出资场景时,转 capital-contribution-compliance / veil-piercing-liability

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 股份公司、上市公司或金融机构的法代与对外担保规则(监管口径与本书的有限公司视角不同)
- 已进入刑事侦查或诉讼的个案(需要辩护律师,不是方法论清单能解决的)
- 需要现行法条原文、地方登记实操细节的场景——本书是 2014 年语境,登记流程与文书要求已多次改革

### 作者在书中警告的失败模式

- 挂名法代以为"不参与就没事"——印章不受实际控制人掌控时,会利用其印章从事违法活动,挂名者面临被调查甚至起诉(问题107)
- 免职后不办变更登记就以为责任终结——对外仍是法代,登报声明毫无意义,公司对外先担责再追偿(问题86/58)
- 把法定代表人简称"法人"——概念混用导致签约、诉讼文件上的身份错乱(问题87)
- 凭经验和信任签约、不查执照与授权——冒名签约后只能追缔约过失,且己方未查证的过失显而易见(问题116)
- 未经股东会同意擅自动用公司资金"炒股"——触挪用资金罪(问题112)
- 许可他人使用自己企业名称"蹭品牌"——属出租名称,双方都违法(问题110)

### 法律时效性警示(必须读)

- **本书为 2014 年版(2013《公司法》修正案语境)。《民法典》(2021)已替代《合同法》《民法通则》**:无权代理追认(原《合同法》48条→民法典171条)、签字盖章前一方已履行主要义务合同成立(原37条→民法典490条)、欺诈可撤销(原54条→民法典148-151条)、缔约过失赔偿范围(原42条→民法典500条)——规则精神延续,但条文明引必须全部换算。
- **对外担保裁判规则已被《九民纪要》(2019)与民法典担保制度解释改写**:按"相对人善意+对决议的合理审查"判断效力,书内"章程未规定一律由股东会决"的简单版本不可直接引用(v-A52/v-B10)。
- **企业间借贷已被 2015《民间借贷司法解释》部分放开**:偶发、以自有资金出借的企业间借贷有效;利率上限由"银行同类贷款利率4倍"改为"LPR四倍"——书内"企业间拆借一律无效"只能作历史框架与通道思维使用(v-A55/v-B04)。
- **2023《公司法》(2024-07 施行)重构法定代表人制度**:法代由代表公司执行事务的董事或经理担任、其辞任视为一并辞去法代、法代行为后果归公司与越权代表规则成文化——涉及现行法的问题必须对照新法核实。
- **本 skill 输出为方法论蒸馏,不构成法律意见**,重大事项请咨询执业律师。

### 作者的盲点 / 时代局限

- 园区顾问视角:答案倾向"可以变通、再来找律师完善",对挂名法代的现实衍生后果(限制高消费、出入境边控、征信影响)与税务维度全书几乎未覆盖
- 案例全部化名、经律师转述,原始事实无法核对;"把免责声明发至工商部门"的建议,登记机关是否受理并无验证
- 合同部分只给原则清单,未提供条款示范文本;意向书"缔约过失赔多少"无量化方法

### 容易混淆的邻近方法论

- 挂名股东 vs 挂名法代:前者风险在出资责任与股东资格,后者在签章与"直接负责的主管人员"责任——常同时出现,自保动作不同(nominee-shareholding-risk)
- 越权代表 vs 无权代理:相对人善意保护是共同逻辑,但前者是机构(法代/董事)越权、后者是代理人无权(charter-governance-design 的授权清单是事前防线)
- 登报声明的功能因场景而异:公章遗失补办中是凭证环节,法代变更中完全无效力——"登报崇拜"是本书反复纠正的误区(paper-validity-traps)
