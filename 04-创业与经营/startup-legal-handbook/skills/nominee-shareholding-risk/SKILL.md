# 股权代持与隐名投资

## R — 原文 (Reading)

> "隐名投资协议只是双方的权利义务约定，不能对抗第三人。"
>
> — 杨春宝、王成兵,《创业投资法律手册》第二章 问题73

> "法院一般以公司其他股东明知该隐名股东之身份，且公司认可隐名股东以实际股东身份行使股东权利为条件"
>
> — 杨春宝、王成兵,《创业投资法律手册》第二章 问题73

> "如果有一半以上其他股东知晓，一般可以认定隐名投资成立。"
>
> — 杨春宝、王成兵,《创业投资法律手册》第二章 问题79

> "隐名投资人只能自行承担隐名投资行为的风险后果，不能请求法院认定股权转让协议无效"
>
> — 杨春宝、王成兵,《创业投资法律手册》第二章 问题79

> "因为何某是工商登记中记载的股东，而工商登记具有公示效果，因此，何某必须承担补足出资的责任"
>
> — 杨春宝、王成兵,《创业投资法律手册》第二章 问题73

> "如果其所投资的产业是中国法律限制甚至禁止外商投资的，这样的隐名投资是无效的。"
>
> — 杨春宝、王成兵,《创业投资法律手册》第十章 问题231

## I — 方法论骨架 (Interpretation)

作者的核心主张:代持不是"签个协议就安全"的私安排——隐名投资协议在**不规避法律强制性规定、无其他无效情形**时原则上有效,但它的效力**只约束隐名方与显名方两个人**,对外一律"不能对抗第三人"。"签了协议"与"拿稳了股权"之间隔着一整层风险,必须分层理解:

1. **效力边界(对内有效、对外不抗第三人)**:协议只在双方之间产生债权债务关系;工商登记公示的是显名股东,第三人只认登记。隐名方的股权从来不是"安全的股权",而是"一项对显名股东的债权"。
2. **显名股东擅自转让→善意受让人受保护**:显名股东背着隐名方把登记在其名下的股权转让给不知情的受让人,转让有效、不可追回——隐名方不能主张转让无效,只能依代持协议向显名股东索赔;连协议都没签的,只能要求返还投资款。事前防控是唯一可靠屏障,事后救济是残缺的。
3. **显名化(确权)门槛**:想从"隐名"变"显名"、进而对公司直接行权,须满足两个条件——其他股东(半数以上)知晓其实际股东身份,且公司认可其以股东身份行使股东权利;实际参与经营管理、留下行权痕迹可作确权佐证。隐名方拿着代持协议和转账记录直接起诉公司要求查账、分红,不会被支持——正确顺序是"先确权、后对公司行权"。
4. **代持协议设计六项清单**:①**权利归属**——写明股东的一切实体性权利(分红、增值、表决意志)均归隐名方;②**无条件配合**——隐名方任何时候要求显名或转让给第三方,显名股东在合法前提下无条件配合;③**限制显名股东管理权**——显名股东不得参与决策、不得表达自己的意愿,只能按隐名方指示行事;兼任公司职务时人事、财务等重要事项不得单独经手;④**违约救济**——约定侵犯或威胁隐名方实体权利时的救济与惩戒措施;⑤**内部公开**——除工商登记不显名外,在公司股东层面、管理层面让各方知晓隐名身份(这是未来显名化的前提工程);⑥**前置条件核查**——代持不得规避强制性规定,所投企业对股东无特殊资质要求,资金往来凭证留痕(书中更完整的版本还包括必要时要求显名股东提供担保)。
5. **规避外资准入的代持直接无效**:以代持规避外商投资准入限制/禁止规定的,协议连"对内有效"都保不住——直接无效,隐名方 investment 全暴露。
6. **名义股东自身的风险(硬币的另一面)**:因为工商登记的公示效果,显名股东是"对外的股东"——公司出资不足时,登记股东必须承担补足出资责任;对第三人的诉讼由显名股东第一线承担;兼任法定代表人的,公司违法经营时虽以"双罚制"追究实际行为人,但"直接负责的主管人员"条款与调查传唤的麻烦都落在挂名者头上——不参与经营就不要挂法代。

## A1 — 书中的应用 (Past Application)

### 案例 1(主): 江小姐的隐名股权被"黑吃"(第二章 问题79)
- **情境**: 江小姐多年前出资参股B公司,工商登记的是她表哥袁先生,股东会也一直由袁出面;袁在江小姐不知情时,把名下股权全部转让给了另一股东朱某。江小姐起诉主张转让无效、要求改登记。
- **律师意见**: 司法实践以"半数以上其他股东知晓"为隐名投资成立的一般标准;江小姐既未参与经营管理、又无充分相反证据,隐名身份无法确认;袁转让时朱某不知情,作为善意第三人其权利受保护——不能请求确认转让协议无效,股权已转让也无法再确权。
- **结论**: 隐名投资不因此无效,只是在双方之间仍有效——签过代持协议的,江小姐可向袁索赔;没签的,只能要求返还投资款。作者以此警示:隐名投资最大的风险是道德风险,必须事前按清单防控。

### 案例 2(主): 境外公司借名设内资公司后的显名确权(第十章 问题231)
- **情境**: 一家内资公司登记股东为夏某、王某两名中国人,实际出资与控制均来自某境外公司;境外公司现想把公司收回来变更为其独资子公司,问能否以1元象征价收购或赠与。
- **律师意见**: 先审查该隐名投资是否规避中国法律——所投产业属限制甚至禁止外商投资的,隐名投资无效;未规避的,1元价显名理论可行,但审批机关一般不会轻易认可隐名投资;更可行的是向法院提起股东确权之诉,凭生效判决办理审批与工商变更手续。
- **结论**: 借名出来的股权,显名要走"确权之诉→审批/登记"的链条,且以不规避准入为绝对前提——规避准入的代持连确权的资格都没有。

### 案例 3(辅): 外国公司借名持股的协议设计(第二章 问题73)
- **情境**: 外国ABC公司拟通过协议安排中国公民何某作为其在网上销售公司登记的股东,问双方权利义务能否"转让"给ABC公司、协议能否对抗第三人、ABC公司出资不足时何某是否补足。
- **律师意见**: 隐名关系下不存在"转让"问题,一切实体权利应约定归隐名方;显名股东须承诺无条件配合显名与转让;限制何某参与决策与单独经手人事财务;约定违约惩戒;并强调隐名方应在股东层与管理层公开身份以降低确权风险。同时提示:登记的公示效果决定何某须对外承担补足出资责任、对第三人诉讼由其承担。
- **结论**: 代持风险是双向的——隐名方靠"六项协议设计+内部公开"自保,显名方靠"管住身份与签章"自保。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **事前安排**: 准备让别人代持、替别人持股,或正在起草/审查代持协议——问"靠谱吗、怎么签才安全"
2. **纠纷处置**: 显名股东擅自转让/质押股权、隐名方想显名确权或对公司行权、名义股东(挂名股东/挂名法代)想退出——"股权被卖了怎么办""怎么证明我是真股东"
3. **规避准入型代持**: 想借中国人/内资名义规避外资准入或股东身份限制——"借我的名义开公司行不行"

### 语言信号 (用户的话里出现这些就应激活)

- "代持/隐名股东/显名/名义股东/挂名/替我持股/帮我持有股份"
- "他把我股权卖了/背着我转让了,能追回来吗"
- "怎么证明我是实际出资人/怎样显名/确权"
- "我不想挂名了/怎么从代持里脱身"
- "借个名字规避外资限制/外籍朋友用我名义开公司"

### 与相邻 skill 的区分

- 与 `equity-transfer-pricing` 的区别: 那是显名股东之间真实的转让程序、优先购买权与定价;本 skill 处理"登记股东与实际出资人分离"的关系与风险
- 与 `shareholder-qualification-registration` 的区别: 那是显名股东资格的五类证据与"名册生效、登记对抗"一般规则;本 skill 处理隐名关系下的确权显名与代持协议设计
- 与 `employee-equity-incentive` 的区别: 期权池/激励股权"暂放某人名下"是激励载体设计问题,归激励 skill;本 skill 面向投资型代持
- 与 `cross-border-foreign-investment` 的区别: 那判断外资准入与投资路径本身;本 skill 只处理"用代持绕准入"的效力与替代方案,两者常需协作
- 与 `legal-rep-compliance-contracts` 的区别: 挂名法定代表人的责任边界归该 skill;本 skill 在"名义股东"语境下只覆盖持股层面的风险

## E — 可执行步骤 (Execution)

1. **第一步:定性与合法性检查**
   - 确认三件事:有无代持合意(协议/聊天记录)与资金凭证?是否规避强制性规定(尤其外资准入负面清单、股东身份限制)?所投企业对股东有无特殊资质要求?
   - 完成标准:给出"代持有效性预判"结论(有效/存疑/无效)与依据
   - 判停条件:只有转账记录、无任何代持合意——可能被定性为借款或合伙出资,转 capital-contribution-compliance 或借贷定性分析;目的明确是规避外资准入——直接警示无效风险,转 cross-border-foreign-investment 设计合规路径
2. **第二步:按立场画像风险**
   - 隐名方:股权被擅自处分、确权失败、显名股东死亡/离婚导致股权被作为遗产/夫妻财产分割;显名方:对外补足出资、对第三人担责、法代身份的行政刑事风险;公司:股东结构不透明、治理与行权主体错位
   - 完成标准:对用户所处立场列出至少三项具体风险及触发条件
3. **第三步:代持协议六项清单落地**
   - 按权利归属/无条件配合/限制管理权/违约救济/内部公开/前置条件逐项给出条款要点;附"显名化证据工程"清单:股东会列席留痕、微信与邮件中其他股东知晓身份的记录、分红流向凭证、参与经营的痕迹
   - 完成标准:六项逐条有可写进协议的要点,且内部公开项有具体动作
4. **第四步:退出与救济预案**
   - 隐名方:平时留痕满足"半数知晓+公司认可"两条件;事发后按"向显名方索赔(有协议)/要求返还投资款(无协议)→起诉显名化"的路径走;显名方:催促履行→用查账权、要求返还公章证照等股东权利施压→诉讼三步
   - 完成标准:给出带时间线与证据清单的行动方案
   - 判停条件:用户只问挂名法代的责任边界而不涉及持股——转 legal-rep-compliance-contracts

## B — 边界 (Boundary) ★

### 法律时效性警示(使用前必读)

- **本书为 2014 年版(2013《公司法》修正案语境),代持规则系以《公司法司法解释三》为依据展开——该解释其后已经修改**(2020 年依民法典修正,实际出资人与名义股东合同效力、显名须经"其他股东半数以上同意"等条文的表述与适用以现行有效版本为准),引用具体条文前必须核对现行解释。
- **外资准入代持在《外商投资法》(2020)负面清单时代规则不同**:书中"规避产业目录/报批"的分析框架已整体切换——现行规则是违反负面清单禁止性规定的投资合同无效、限制领域须在规定期限内取得许可;第十章涉及审批的操作细节大半失效,只保留"规避准入即无效"的底层逻辑。
- 2023 年《公司法》(2024-07 施行)未系统规定代持,但股东名册、登记对抗、股东失权等配套规则有调整,显名化与行权路径须按现行法重排。
- **本 skill 输出为对 2014 年著作的方法论蒸馏,不构成法律意见**;代持安排在现行司法实践中的效力与税务、外汇后果请咨询执业律师。

### 不要在以下情况使用此 skill

- 上市公司、金融行业等有强制披露/持股透明要求场景的"代持"——违反披露规则的问题超出本框架
- 单纯的委托理财/委托投资(基金、专户)——那是委托合同关系,不适用股权代持框架
- 用户只需要章程如何配合代持安排——设计落到条款层面时转 charter-governance-design

### 作者在书中警告的失败模式

- 只签协议、从不公开身份、不参与经营 → 纠纷时确权失败,股权被"黑吃"只能索赔(江小姐案)
- 连协议都没签的隐名投资 → 显名股东翻脸时只能要求返还投资款,增值与分红全失
- 用代持规避外资准入 → 协议直接无效,investment 全暴露
- 名义股东以为"挂名而已" → 公司出资不足时对外须补足,兼法代的还可能被调查追责

### 作者的盲点 / 时代局限

- 案例全部化名、经律师转述,事实细节无法核对;答案倾向"可以变通、再找律师完善"
- 全书几乎无税务维度——代持还原、显名转让的税负是现实中最大的隐性成本之一,书中完全未覆盖
- 2014 年后的主流争议未覆盖:名义股东的债权人申请强制执行代持股权、实际出资人能否排除执行,股权激励代持,对赌回购触发下的代持等
- 部分结论绝对化("只要不规避强制性规定即有效"),实际效力认定还受合同具体内容与裁判口径影响

### 容易混淆的邻近方法论

- **合伙**: 只出资、不要求显名、共享收益的安排可能被认定为合伙而非代持——责任形式(无限连带)与权利归属规则完全不同,定性要先于设计
- **委托投资**: 委托合同下的"受托人取得财产归委托人"逻辑与代持"登记对抗第三人"逻辑不同,勿混用
- **干股**: 干股是分红权的协议让渡、根本不是股权,更不是代持;把"给干股"当"代持登记"会得出全错的操作
- **显名股东资格争议**: 已显名股东之间的名册记载、工商登记之争(付了款没变更等)归 shareholder-qualification-registration,不是隐名问题
