# "以为生效其实失效"的文件与程序陷阱

## R — 原文 (Reading)

> "在办理工商变更登记之前,对于公司外部的人员来说,朱某仍是公司的法定代表人"
>
> — 杨春宝、王成兵,《创业投资法律手册》第三章 问题86

> "众股东与其刊登声明,不如办理变更登记。"
>
> — 同上,第三章 问题86

> "除非公司章程或股东协议中对此有明确约定,否则该办法不可行,不产生任何法律效果。"
>
> — 第二章 问题67

> "或者催告其缴纳出资,若其在合理期间内仍未缴纳,公司以股东会决议解除赖先生的股东资格。"
>
> — 第二章 问题45

>

## I — 方法论骨架 (Interpretation)

作者贯穿全书的判断轴:**形式动作 ≠ 法律动作**。创业者完成了一个"看起来有法律味"的动作(登报、开股东会、用官方范本),就以为效力已经发生——纠纷时才发现那份文件什么也没改变。四类高频陷阱:

1. **登报崇拜**:登报声明公章作废、登报宣布换了法定代表人、登报催告失踪股东"逾期不回视为放弃股份"——这些公告均不产生其以为的效力。为什么踩:减资、清算确实要登报公告,创业者把"公告"这个形式当成了万能生效开关。正确做法:公章与法代对外以**工商登记**为准,免职决议只在公司内部生效,未变更登记前原法代持章签的合同公司照样担责;登报的真实功能只有两个——法定公告场景(减资、清算、催缴)中作为通知的补充,以及报案补刻时的凭证环节;对失踪股东,书内明确:除非章程或股东协议事先有约定,登报催告"自动放弃股份"不产生任何法律效果,正路是按除名/失权程序走。
2. **范本章程依赖**:用工商局或登记代理机构的免费范本章程 = 把公司法留给章程的自治空间全部放弃。为什么踩:注册图省事、"范本"自带官方认可的错觉。后果具体化为三颗雷:担保决策机构未约定(担保授权悬空)、无授权清单(执行董事/法代越权时连追责的请求权基础都没有)、无僵局条款(50/50 死锁时没有程序化出口)。正确做法:注册或趁无纠纷时修订章程(2/3 表决权通过),把缺失条款补上。
3. **多数决越权**:用一纸股东会决议直接剥夺股东资格——"2/3 通过,某股东即日起丧失股东资格""公告期满视为自动放弃股份"。为什么踩:把"我们是多数"当成"我们有权",把除名当成内部人事问题。正确做法:表决比例达标 ≠ 程序合法。书内程序(针对未出资股东):**催告缴纳 → 给合理期间 → 逾期仍不缴才可股东会决议解除资格**,且被除名者仍可诉;公司法没有"强制退股"通道,股权转让只能基于协商。2023《公司法》已将此升级为更刚性的失权制度(见 B 段)。
4. **伪造签名决议**:大股东自制或模仿小股东签名炮制"股东会决议"。核心原则:**程序合法性独立于内容合法性**——内容再"合理",签名伪造即程序瑕疵。为什么踩:"反正决议对他有利/他迟早会同意"的心理替代了程序。正确做法(受害方):书内语境下属可撤销决议,自决议作出之日起 60 日内向法院起诉撤销(除斥期间,一过即形式上有效——伪造者拖时间就是在吞掉救济),同时固定"非本人签名"证据、必要时并行刑事报案;注意即使撤销,也不及于已与善意第三人完成的交易。2023《公司法》体系下伪造签名未实际开会/表决的属"决议不成立",救济更强(见 B 段)。

## A1 — 书中的应用 (Past Application)

### 案例 1: 朱某公章案——"执行董事免职风波"(第三章 问题86,主案例)
- **情境**: S 市中贸公司股东会决议罢免执行董事朱某(兼法定代表人),另选夏某。朱某以章程载明"执行董事任期 3 年,3 年内不得无故解职"为由抗议、拒签会议记录,并从会计手中拿走公章拒交。众股东报案后凭派出所证明登报"公章遗失声明"并另刻公章;朱某持营业执照和真公章冲到报社要求更正,报社果然刊登了更正声明——一场公章罗生门。
- **律师意见**: ①股东会有权更换执行董事,朱某经营不善、亏损连连属"不能胜任",章程"3 年内不得无故解职"不阻却有因解职,决议内容与程序合法即有效;②但**法定代表人变更未经工商变更登记不得对抗第三人**——登记前朱某对外仍是法代,其持章以公司名义的行为公司照样担责,只能事后向朱某追偿;③公章并未被盗,遗失声明失实,"众股东与其刊登声明,不如办理变更登记"。
- **结论**: 免职决议在公司内部生效了,但对外效力要以变更登记为门;登报声明"毫无意义"。正确的动作序列是:股东会决议 → 30 日内申请变更登记 → 凭登记解决公章与对外关系。股东们恰恰把力气花在了登报和另刻公章上,一步正路没走。

### 案例 2: 失踪股东习某的股份(第二章 问题67)
- **情境**: 大股东习某身负巨债不辞而别,还卷走部分公司资金。在职股东商议:登报限期要求习某回公司协商,逾期不回即视为自动放弃全部股份,由在职股东重新分配。
- **律师意见**: 只要未办理股权转让手续,习某的股权当然存在、股东权利不受影响;公司可追讨卷走的资金,拒不履行判决可申请强制执行其在公司的股权;登报限期"自动放弃股份"的办法,除非章程或股东协议事先有明确约定,否则"该办法不可行,不产生任何法律效果";若习某持股超过 1/3,涉及重大事项的股东会决议因其缺席根本通不过。
- **结论**: 失踪不是失权。想收回股份只能走法定通道(追责+强制执行股权,或章程有约定的按约定程序除名),登报公告分股份是自创程序、零效力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公章/执照/法定代表人出了状况,当事人(或公司)已经登报或打算登报声明"作废/更换/除名",问这样够不够
2. 股东闹翻后翻出一份决议,发现上面有自己的"签名"但自己从没签过;或多数派直接开股东会把小股东"踢出局"、公告"视为自动放弃股份"
3. 纠纷发生后检查公司文件,发现章程一直是工商注册时的免费范本,出事后发现"无章可循",想知道手里这些文件还能不能用、怎么补

### 语言信号 (用户的话里出现这些就应激活)

- "登报声明公章作废/登报说他已经不是法代了/公告过了还算数吗"
- "登报限期让他回来,逾期就当自动放弃股份"
- "决议上的签名不是我签的/他模仿我的签名开了股东会"
- "我们用的是工商范本章程,现在才发现什么都没写"
- "股东会投票把他除名了,立即生效了吧"

### 与相邻 skill 的区分

- 与 `charter-governance-design` 的区别: 那是**事前设计**(怎么写章程、怎么搭结构让问题不发生);本 skill 是**事后识别**——文件已经做了、动作已经走了,判断"哪份文件其实没用"
- 与 `resolution-validity-procedure` 的区别: 那是决议效力争议的完整分析(无效/可撤销/不成立三分法、诉讼要件);本 skill 以陷阱清单快速识别"以为生效其实失效",伪造签名场景下两 skill 衔接
- 与 `shareholder-qualification-registration` 的区别: 那是股东资格取得与登记的全流程;本 skill 只回答"这个公告/决议/文件有没有产生你以为的效力"
- 与 `minority-shareholder-remedies` 的区别: 那是小股东救济工具箱全景;本 skill 聚焦文件效力这一个切面

## E — 可执行步骤 (Execution)

1. **第一步:文件效力盘点**
   - 让用户列出纠纷涉及的全部文件与动作(登报声明、股东会决议、免职决定、章程、催告函、公告),逐份问两个问题:"它想产生什么效力"vs"法律要求什么程序才产生该效力"
   - 完成标准:每份文件标注 有效/无效(无此效力)/效力内外有别 三类结论之一,并写明依据的动作通道
   - 判停条件:用户实际想问的是"章程该怎么从头设计",转 charter-governance-design
2. **第二步:公告类动作定性**
   - 对照法定公告场景清单(减资、清算、催缴失权公告等):属法定场景的,定位其真实功能(通知的补充/凭证),不因登报而豁免其他程序步骤;不属法定场景的,直接标注"不产生所期待的效力"
   - 完成标准:给出替代的正确程序动作(如:办变更登记/走除名程序),而非"再登一次报"
3. **第三步:决议程序审查**
   - 逐一核对通知、召集、召开、表决、签名五个环节;发现伪造/虚假签名的,确认受害方是否在救济期限内(2014 语境 60 日除斥期间;现行法下未实际开会/表决的可主张决议不成立,不受 60 日限制),提示证据固定(笔迹鉴定预案、原件保全)与紧迫性
   - 完成标准:给出救济通道+时限起算点+证据清单;提示撤销/不成立均不及于已与善意第三人完成的交易
   - 判停条件:用户要的是完整诉讼策略与起诉状要件,转 resolution-validity-procedure
4. **第四步:范本章程失效体检**
   - 对照三颗雷逐项检查:担保/对外投资决策机构有无约定、对执行董事/法代/经理有无授权清单、有无僵局条款与议事规则;同时查有无股东除名/失权的章程约定(有约定才有约定除名的通道)
   - 完成标准:输出"缺失条款清单"+修订建议(注明修订章程需代表 2/3 以上表决权的股东通过),并说明现行法下担保越权效力按相对人善意判断
   - 判停条件:用户要逐条起草章程文本,转 charter-governance-design

## B — 边界 (Boundary) ★

### 法律时效性警示(必读)

- **本书为 2014 年版(2013《公司法》修正案语境)**,以下规则已变,适用前必须对照现行法核实:
  - **除名/失权**:书中"催告缴纳→合理期间→股东会决议解除资格"的路径,已被 2023《公司法》(2024-07 施行)第 52 条**股东失权制度**取代并制度化:董事会核查催缴 → 书面催缴+宽限期(不得少于 60 日) → 逾期未缴发出**失权通知**,股东可异议之诉;程序门槛比 2014 年更刚性,"多数决直接踢人"在现行法下失效得更彻底
  - **伪造签名决议**:书中"60 日内诉请撤销"是旧二元救济(无效/可撤销);《公司法解释四》及 2023《公司法》已确立三分法,新增**决议不成立之诉**——伪造签名、未实际开会/表决的决议属"不成立",不受 60 日除斥期间限制,可随时主张;受害方拖过 60 日不再是绝路,但"不成立"的举证要求更高
  - **担保悬空**:书内"章程未规定担保决策机构则归股东会决"的结论,已被《九民纪要》(2019)调整为按**相对人善意与公司过错**判断越权担保效力
- 本 skill 输出为**方法论蒸馏,不构成法律意见**;涉及除名、失权、决议诉讼等程序,请执业律师按现行法办理

### 不要在以下情况使用此 skill

- 用户要的是事前的章程条款设计或治理结构搭建(转 charter-governance-design)
- 需要完整的决议效力之诉程序与起诉要件分析(转 resolution-validity-procedure)
- 股份公司/上市公司的公告制度(信息披露法定化,"登报崇拜"的判断轴完全不同)

### 作者在书中警告的失败模式

- 把形式动作当法律动作:登报≠生效、开会≠决议有效、签名有了≠程序合法、表决够了≠能剥夺资格
- 用公司内部文件对抗外部第三人:免职决议、内部公告在变更登记前对外一律无效力
- 自创退出/除名程序:"视为自动放弃股份"类公告是零效力文件,还可能反过来构成侵害股东权益的证据

### 作者的盲点 / 时代局限

- "登报毫无意义"等表述绝对化:在减资、清算、催缴公告等**法定公告场景**登报有真实效力,本书批评的只是把公告当生效开关的迷信
- 案例全部化名、经律师转述,事实不可核对;基于上海登记实践,各地登记口径有差异
- 无税务维度(除名、失权、股权强制执行的税负对决策影响不小,书中未覆盖)

### 容易混淆的邻近方法论

- **与 charter-governance-design 最易混**:那是事前把章程写对,本 skill 是事后识别哪份文件没用——同一份范本章程,前者回答"该怎么补设计",本 skill 回答"它现在到底能不能用"
- 决议撤销之诉 vs 决议不成立之诉:60 日除斥期间只约束"可撤销",不约束"不成立"(现行法三分法)
- 约定除名 vs 法定失权:章程除名条款须过实体+程序双重审查(内容违法仍无效),法定失权只针对未出资且须走催缴程序,两者通道不同
