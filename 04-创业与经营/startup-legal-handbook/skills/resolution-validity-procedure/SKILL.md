## I — 方法论骨架 (Interpretation)

作者的核心主张:决议的效力取决于"内容合法性"与"程序合法性"两条独立的线——内容合法救不了程序违法,程序合规也救不了内容违法。判断按以下分层展开:

1. **无效 vs 可撤销二分(2014 语境)**:决议**内容**违反法律、行政法规的强制性规定→**无效**,任何利害关系人随时可主张确认无效,不受时间限制;**召集程序/表决方式**违反法律、行政法规或章程,或者决议**内容违反章程**→**可撤销**,股东须自决议作出之日起 **60 日**内起诉,除斥期间一过,有瑕疵的决议在形式上确定有效。
2. **表决基数是易错点**:修改章程、增减资本、合并、分立、解散、变更公司形式等七类重大事项须经代表 **2/3 以上表决权**的股东通过,有限公司的基数是**全体股东所持表决权**而非出席者;普通决议同样须全体表决权过半数——"到场的人都同意"不等于决议有效。
3. **召集法定顺序不可跳**:设董事会者:董事会召集(董事长主持)→监事会→代表 1/10 以上表决权的股东自行召集;不设董事会者:执行董事→监事→1/10 股东。监事(会)召集的前提是执行董事**不能或不去**召集——执行董事在位履职时,监事的召集权被排除。**跳过顺序的决议,即使内容完全合法,也因召集程序违反强制性规定而可撤销**。
4. **送达与留痕是程序战的弹药**:开会须提前 15 日通知全体股东;1/10 股东提议临时会议必须**书面**递交并要求收件人签收注明时间,拒签则邮寄(挂号/EMS)甚至公证送达——这是证明董事会/监事会"不作为"、为自行召集铺路的关键证据。决议本身保存于公司,法律不要求送达缺席股东,但缺席股东可查阅、复制会议记录;有限公司开会临时增加议题不被禁止。
5. **伪造签名/未通知股东的后果**:大股东自制或伪造小股东签名的"决议",2014 语境下按程序违法走可撤销——但 60 日一过即"拖到洗白",受害者只能另追损害赔偿;现行法下此类"根本没开过会/没表决过"的情形改走**决议不成立**,不受 60 日限制。未通知股东的撤销期限起算点,现行法也已细化。
6. **原告资格与救济边界**:确认决议无效/请求撤销的主体须具备股东身份(决议作出时);决议被撤销或确认无效不能当然推翻已与善意第三人完成的交易(如已设立并登记的子公司不因决议被撤而消灭),对外后果另行按善意第三人规则处理。

## A1 — 书中的应用 (Past Application)

### 案例 1: 监事突袭召集临时股东会免掉执行董事(第三章 问题104)
- **情境**: C 公司两名股东:吴先生任执行董事兼经理(40%),阮先生任监事(60%)。阮先生速递寄送临时股东会通知,两天后开会并临时增加人事议题,当场免去吴先生执行董事及经理职务。吴先生指责"突然袭击",拒绝签字;阮先生以"过半数通过"主张决议有效。
- **律师意见**: 决议内容(人事任免)属公司自治范畴,不违反法律、行政法规,**不构成无效**;但召集顺序上,执行董事能履行职责时监事的召集权被排除——阮先生在无证据表明吴先生不能或不去召集的情形下,擅自自行召集并主持会议,违反《公司法》关于召集和主持程序的强制性规定,**决议可撤销**;吴先生应自决议作出之日起 60 日内起诉。(附带:有限公司开会临时增加议题,法律不禁止——但本案败在召集顺序。)
- **结论**: 内容合法+表决过半≠决议安全;召集顺序跳步即可撤销。"程序即效力"的典型反面教材。

### 案例 2: 大股东自制/伪造签名的股东会决议(第二章 问题50)
- **情境**: 大股东欧先生持股 80%,未与小股东陈小姐商量便合资设立子公司;假设他不开股东会,自己做一份没有小股东签名或只有虚假签名的股东会决议。
- **律师意见**: 陈小姐有权以决议不符合法定程序为由申请撤销;但即使决议被撤销,也不导致已设立的子公司被撤销——合资对方是善意第三人,不因公司内部决策程序瑕疵受损。
- **结论**: 伪造签名决议可主张撤销(2014 语境,须抢 60 日窗口;现行法走决议不成立),且撤销的效力只到决议为止,不及于对外已完成的交易。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 决议已作出,一方认为"被黑了"想翻盘:没被通知开会、召集跳步、表决基数不对、内容超出章程授权,问"还能不能撤销/来不来得及"
2. 一方想主动出手:小股东(≥1/10)或监事想召集临时股东会改选董事/罢免执行董事,问"怎么召集才不算白开""董事长不理我能不能自己开"
3. 发现决议文本上"自己的签名"是伪造/模仿的,或工商档案里躺着一份自己从没见过的决议

### 语言信号 (用户的话里出现这些就应激活)

- "这个决议有效吗/能不能撤销/60 天还来得及吗"
- "没通知我就开会/就贴了个通知/签名不是我签的"
- "我想自己召集临时股东会行不行/他跳过董事会开会有效吗"
- "2/3 表决权到底怎么算/出席的人过半数算不算数"

### 与相邻 skill 的区分

- 与 `charter-governance-design` 的区别: 那是事前章程设计,让瑕疵不发生;本 skill 是决议已作出后的效力判断与程序补救
- 与 `minority-shareholder-remedies` 的区别: 那是小股东综合救济工具箱(知情权、派生诉讼、退出阶梯);本 skill 只管决议效力与会议程序这一件武器
- 与 `paper-validity-traps` 的区别: 那是合同/公章/文件"以为生效其实失效"的广谱陷阱识别;本 skill 限于公司决议场景的法律分流(无效/可撤销/不成立)
- 与 `legal-rep-compliance-contracts` 的衔接: 决议被撤销后,法代变更登记、公章交接等对外后果归那个 skill 处理

## E — 可执行步骤 (Execution)

1. **第一步:瑕疵类型定性**
   - 逐项检查:决议内容是否违反法律/行政法规(→无效)?召集程序、表决方式是否违法或违章程?内容是否违反章程(→可撤销)?是否根本未开会、未表决、签名伪造(→现行法:决议不成立)?
   - 完成标准:把瑕疵归入"无效/可撤销/不成立"三类之一,并说明归类依据
   - 判停条件:用户问的是"怎么设计章程让这种事不发生"→转 charter-governance-design

2. **第二步:时限与可行性核算**
   - 确定起算点(2014 语境:决议作出之日起 60 日;现行法下未被通知股东有专门起算规则)与除斥期间是否经过;同步核对原告是否具备股东身份
   - 完成标准:给出"来得及/来不及+依据"的明确结论;来不及时明确告知撤销窗口已闭,并指出损害赔偿等其他可能救济(转 minority-shareholder-remedies)
   - 判停条件:时限已过且现行法下也无不成立路径→不输出撤销方案,只输出残余救济

3. **第三步:程序要件逐项过**
   - 核对:召集人是否按"董事会(执行董事)→监事会(监事)→1/10 股东"顺序?是否提前 15 日通知全体股东?表决基数是全体表决权还是出席者?重大事项是否达 2/3?签名是否本人所签?
   - 完成标准:缺陷点清单,每项注明对应的撤销/无效/不成立事由

4. **第四步:输出行动方案**
   - 被瑕疵方:起诉路径+证据清单(决议复印件、工商档案调取、通知送达记录、笔迹鉴定申请);召集方:补正或按法定顺序重新召集的操作清单(书面提议、签收、邮寄/公证留痕)
   - 完成标准:双方各有可执行清单;决议被撤销的,提示法代变更登记与公章处理衔接 legal-rep-compliance-contracts
   - 判停条件:用户诉求实为退出公司或追究大股东赔偿责任→转 minority-shareholder-remedies / exit-dissolution-liquidation

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 股份公司/上市公司股东大会决议(出席表决权计基数、召集规则不同,本书视角是有限公司)
- 用户需要的是"决议之后怎么把损失追回来"——那是赔偿与救济问题,本 skill 只判断决议本身
- 尚未发生的假设性章程条款设计(转 charter-governance-design)

### 作者在书中警告的失败模式

- 以"内容合法+过半数通过"自认安全 → 召集顺序跳步照样可撤销(问题104)
- 受害者不紧不慢 → 60 日除斥期间一过,程序瑕疵决议形式上确定有效(问题61/104)
- 伪造签名者靠拖延"洗白"决议 → 2014 年语境下这是真实漏洞,受害者只能另追损害赔偿(问题50)
- 自行召集前不留痕 → 无法证明董事会/监事会"不作为",自行召集反成程序违法(问题102)
- 以为决议被撤就能推翻对外交易 → 善意第三人的交易不受内部程序瑕疵影响(问题50)

### 法律时效性警示 ★(必须向用户申明)

- **本书为 2014 年版(2013《公司法》修正案语境),本章方法论的核心二分已被改写**:2023 年《公司法》(2024-07 施行)新增**决议不成立之诉**——未召开会议、未表决、出席人数/表决权或同意人数/表决权不符合法律规定等情形,决议"不成立"而非"可撤销",**不受 60 日除斥期间限制**;伪造签名、虚构会议等"根本没开过会"的情形,现行司法解释体系下走"决议不成立",不再受"拖过 60 日即洗白"漏洞之害
- **撤销期限起算点变化**:现行法对未被通知参加股东会的股东,撤销期间改为自其知道或应当知道决议作出之日起算,并设最长保护期——2014 年"决议作出之日起 60 日"的机械算法对这类受害者已不再是死限
- 引用任何具体期限与事由前,必须对照现行《公司法》及《公司法解释四》等司法解释逐条核实

### 作者的盲点 / 时代局限

- 本 skill 输出为**方法论蒸馏,不构成法律意见**;决议诉讼有严格的时限与证据门槛,重大争议务必请执业律师介入
- 全书案例均为化名且经律师转述,无法核对原始事实;原告资格、撤销范围等裁判口径随司法解释演进(如《公司法解释四》对原告资格、决议不成立的细化),书内结论勿直接照搬
- 作者重"事后救济路径",对决议瑕疵与公司外部交易效力的交叉地带(越权担保等)着墨不足,且该领域已被《九民纪要》口径改写
- 全书基于上海园区语境,工商档案调取、送达公证等操作各地实践有差异

### 容易混淆的邻近方法论

- 决议效力之争 vs 法定代表人登记对抗:决议有效不等于对外生效,法代变更须登记(问题93,见 legal-rep-compliance-contracts)
- 决议撤销 vs 决议内容所涉交易撤销:撤销决议 ≠ 撤销按该决议完成的合同或设立行为
- "程序违法" vs "内容违章程":二者都是可撤销事由,但审查对象不同,勿混为一谈
