## I — 方法论骨架 (Interpretation)

作者的主张:股东资格与股权变动不是"谁出钱谁就是股东"的一笔账,而是一条分层证据链加两级登记效力的程序问题。框架展开为六层:

1. **五类股东资格证据**:①载有股东姓名的公司章程(必载事项);②股东名册;③出资证明文件(出资协议、银行单据等);④出资证明书(公司成立后签发、转让后换发);⑤工商登记资料。孤立证据(如仅一张转账记录)证明力弱,纠纷时按五类逐项补链。
2. **证据的功能层级**:对公司主张股东权利以**股东名册记载**为门(名册是行使权利的依据);对股东之间的资格确认,名册+章程即有证明力;**工商登记只有公示对抗力**——未登记不影响股东间协议效力与内部股东地位,只是不能对抗善意第三人。反过来,"付了钱/协议生效"也不等于取得可对公司行使的权利(见下)。
3. **登记对抗主义**:股权变更、法定代表人变更均应自决议/转让之日起 **30日内**申请变更登记;逾期可被责令限期办理并罚款(1万-10万)。登记机关只做形式审查——不能指望工商把关,内部必须自保(留痕、凭证、及时登记)。
4. **出资瑕疵≠丧失股东资格**:未出资或未足额出资的股东,在资格被依法解除(催告→合理期限→股东会决议)之前仍是股东,只是权利可被合理限制(按实缴比例分红/认缴/表决)。多数决不能跳过程序直接"踢人"。
5. **股权继承办理步骤**:查章程有无禁止/限制→继承公证或法院判决/调解书确认继承资格(公司无法自行判断继承人范围)→向工商办理股东变更登记。**分红交付风险**:分红权依附股东身份,公司向任何一个"家属"径行交付分红都可能侵犯其他继承人——应冻结待凭证,谁经公证/判决取得股东权继承,谁取得分红分配权。继承的是股权,董事/董事长/法代职位由公司重新选任,不能继承。
6. **法定代表人变更的效力分界与公章证照被侵占的应对**:对内,股东会免职决议一旦合法作出即生效——原法代对内已无职权、也不能擅自持有公章;对外,变更登记前原法代仍是登记的法代,其行为公司先承受再追偿,登报声明改变不了这一点。公章证照被侵占走**双线**:①公司诉请返还(法代代表公司起诉,无须公章);②报案+登报遗失声明,持回执重新申领/刻制——第二条线不用等诉讼就能恢复经营能力。登报在此只是补领手续的凭证环节,不是"作废宣布"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 执行董事免职风波——公章、登报与变更登记的连环错(第三章 问题86,律师亲办案例)
- **情境**: 中贸公司股东会决议罢免执行董事朱某(兼任法定代表人),另选夏某。朱某援引章程"3年内不得无故解职"抗命,并从会计手中拿走公章拒交。众股东到派出所报案称"公章被盗",凭派出所证明登报遗失声明并私刻公章;朱某次日持营业执照和章程到报社要求更正,报社又登了更正声明——报社交替刊出两份对立声明。
- **律师意见**: ①朱某经营管理不善、不能胜任,股东会有权决议解职,章程"不得无故解职"挡不住"有故"解职;②法定代表人变更须办理工商变更登记,30日内申请;未登记前对第三人朱某仍是法代,其行为公司仍受拘束,公司只能担责后向其追偿;③众股东的遗失声明"毫无意义"——公章并未被盗,声明失实,且登报改变不了登记效力,"与其刊登声明,不如办理变更登记";④对内部而言,朱某既已被免职即不得擅自持有公章。
- **结论**: 罢免有效但登记缺位,登报救不了登记——正确动作是免职决议+30日内变更登记+对内要求交章,登报只在公章真实灭失时作为报案补领的凭证。

### 案例 2: 真假董事长——谁有诉讼代表权(第三章 问题93)
- **情境**: A公司股东会任命李先生为董事长兼法定代表人,钱先生卸任,但因疏忽未办工商变更登记。钱先生以公司名义、按营业执照记载的法定代表人身份起诉要求解除公司一份技术转让协议;公司发现后申请撤诉,新的法定代表人是否有诉讼代表权?
- **律师意见**: 股东会任命合法有效,对内新法代即有权代表公司;工商登记是对外公示方式,原则上不影响对内变更效力。钱先生的起诉既无实质代表权、又违背股东会真实意思;新法代持合法印鉴申请撤诉属不影响交易安全的单方行为,应予认可。
- **结论**: 对内决议/对外登记的双层效力——撤诉这类不涉交易安全的对内行为按决议认定;但登记具有公示公信力,若交易相对方基于营业执照信任钱先生并与之交易,公司不得以内部免职对抗,必须接受交易结果。教训:必须及时办理工商变更,避免损失。

### 案例 3: 小股东病故,妻子领走分红(第二章 问题70,辅以 问题67-69)
- **情境**: 持股2%的季某病故,公司分红决议后通知其妻子,妻、子共同领走六千余元分红;随后自称"大儿子"者到公司主张分红与股权继承,要求公司赔偿。
- **律师意见**: 公司无法判断继承人范围,让妻子领分红是草率的——第一顺序继承人含配偶、父母、子女,径行交付可能侵犯其他继承人;应要求继承人出具继承公证或判决书确定资格,分红与股东权继承统一处理;对"大儿子",公司可提供分红决议与领取记录,助其走司法确认。
- **结论**: 继承场景公司的动作是"查章程→收凭证(公证/判决)→办变更登记",在此之前分红冻结、不向任何家属个别交付。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **资格被质疑/要自证股东身份**:入伙多年没名字没登记、代签入股、只有转账记录,其他股东或公司不认。
2. **变动了但没登记**:股权转让/继承/增资/法代更换已完成或部分完成,工商登记没跟上,问后果与补救;或买受方发现卖方"一女二嫁"。
3. **证照与印鉴失控**:公章、营业执照、法定代表人章被罢免/闹翻的股东或前高管带走;原法代拒不配合变更登记。

### 语言信号 (用户的话里出现这些就应激活)

- "我是不是股东/怎么证明股东资格/名册上没我的名字"
- "没办工商变更登记/没去登记会怎么样/还来得及补吗"
- "股东名册和工商登记不一致/以哪个为准"
- "股权继承需要什么手续/死亡股东的分红该给谁"
- "公章/营业执照被(前)股东拿走了/法定代表人不配合变更/登报声明作废有用吗"

### 与相邻 skill 的区分

- 与 `nominee-shareholding-risk` 的区别: 那是显名/隐名双方的代持安排与确权(先确权、后对公司行权);本 skill 处理一般股东资格证据链与登记效力,隐名方对公司的请求权仍以确权为前提——确权之后回到本 skill 的证据与登记框架。
- 与 `equity-transfer-pricing` 的区别: 那是转让的程序设计、优先购买权与定价;本 skill 管转让/继承/增资**完成之后**的资格证据与登记落地(名册、出资证明书换发、30日登记)。
- 与 `resolution-validity-procedure` 的区别: 那是决议本身的程序瑕疵与效力之争;本 skill 默认决议有效,处理决议之后的登记与证照执行。
- 与 `paper-validity-traps` 的区别: 那是合同上签字盖章的效力分层(代签/盗盖/私盖);本 skill 是公章**被侵占**这一物权/控制权问题及登记公示效力。
- 与 `legal-rep-compliance-contracts` 的区别: 那是法定代表人的人选规则、挂名风险与责任边界;本 skill 聚焦法代**变更登记的效力分界**与公章证照控制。

## E — 可执行步骤 (Execution)

1. **第一步:五类证据链盘点**
   - 逐项核对:章程是否载名→股东名册有无记载→出资证明文件(协议/银行凭证)→出资证明书(取得/换发)→工商登记。每项标注"有/无/可补"。
   - 完成标准:五项证据状态清单 + 对"资格是否成立"的初步结论(孤证弱、链证强)。
   - 判停条件:用户真实诉求是代持显名或代持风险安排 → 转 nominee-shareholding-risk;诉求是转让价格与优先购买权 → 转 equity-transfer-pricing。

2. **第二步:两层效力判断**
   - 分"对公司行权"与"对第三人对抗"两层下结论:对公司以名册记载为门(付款≠可对公司行权);对第三人以登记为准(未登记不得对抗善意第三人)。
   - 完成标准:用户的问题被拆成内部/外部两个答案,各自有明确依据。

3. **第三步:登记合规与时限检查**
   - 列出待登记事项(股东变更/法代变更/章程修正),标注 30 日时限、逾期后果(责令限期+罚款)与"登记机关仅形式审查、须自保"的警示;法代原任拒签的,由新任凭股东会决议签署申请书办理。
   - 完成标准:一张"变更事项→办理动作→时限→责任人"的登记清单。

4. **第四步:分场景补救动作**
   - 资格存疑:补五类证据,必要时确权之诉;出资瑕疵者按"催告→合理期限→股东会决议"处理,不得直接剥夺。
   - 继承:查章程→继承公证/判决→变更登记;此前分红与证照冻结,不向任何家属个别交付。
   - 公章证照被占:双线并行——公司诉请返还(法代代表公司即可)+报案登报持回执补领/重刻;明确告知登报不产生"作废/变更"效力。
   - 完成标准:每个场景给出动作顺序、所需文件与预期结果。

5. **第五步:预防清单**
   - 输出事前预防项:设立/转让/增资/继承/换法代五个节点各应同步完成的凭证与登记动作;提醒"登报了≠生效了"与"付款了≠成股东了"两句检查口诀。
   - 完成标准:清单可直接并入公司章程/内部制度,每条可追溯到前面某步。

## B — 边界 (Boundary) ★

### 法律时效性警示(必读)

- **本书为 2014 年版(2013《公司法》修正案语境)。** 2023 年《公司法》(2024-07 施行)与《市场主体登记管理条例》(2022 施行)已实质改写登记与资格规则:登记事项、变更时限与公示、实名核验按《市场主体登记管理条例》执行;2023《公司法》新增**股东失权制度**(第52条:董事会核查催缴+宽限期+书面失权通知,出资瑕疵除名程序更刚性,书中"催告→决议解除"路径被制度化)、删除对外转让"过半数同意"环节(第84条,保留书面通知+优先购买权)、延续并微调股权继承规则(第90条,章程除外)、法定代表人辞任与变更登记规则亦有更新。**引用任何具体时限、程序前必须对照现行法核实;本 skill 输出为方法论蒸馏,不构成法律意见,重大事项请咨询执业律师。**

### 不要在以下情况使用此 skill

- 用户需要的是代持架构设计、转让定价谈判、决议效力翻盘、合同上盖章效力认定——分别转四个相邻 skill(见 A2)。
- 股份公司/上市公司场景(本书视角为有限公司;股份公司记名背书、证券登记托管体系不同)。

### 作者在书中警告的失败模式

- **"登报崇拜"**:以为登报声明能让公章作废、法代变更或减资生效——本书用朱某公章案正面否掉(声明"毫无意义"),登报的真实功能只是报案补领的凭证环节与法定公告程序(如减资)中的一环。
- **付款=取得股权**的幻觉:转让款付清只对出让方生效,对公司行权以名册记载为门,未完成"名册+章程+登记"三步前权利悬空。
- 凭证不留痕:设立/转让/增资/继承各节点不收凭证(出资证明书、公证书、决议),纠纷时五类证据链断裂。
- 公司向个别"家属"径行交付死亡股东分红——侵犯其他继承人的低级错误。

### 作者的盲点 / 时代局限

- 张力点:问题54说报案+登报+重刻是公章被占的快速通道,问题86又说登报"毫无意义"——并不矛盾,区别在**公章真实灭失/被盗**(登报支撑补领)与**内部职务之争**(登报改变不了登记与占有状态),使用时须先分流场景。
- 全书基于上海园区语境,登记实践各地有差异;书中案例均化名且经律师转述,无法核对原始事实。
- 税务维度几乎缺失(仅提及继承"也许将来会征收遗产税"),股权转让所得税、继承税费成本须另行评估。

### 容易混淆的邻近方法论

- 把隐名投资确权标准("半数其他股东知晓+实际行权痕迹")直接套用到一般股东资格纠纷——两套框架的对象不同,先问有无代持关系。
- 把"对内决议有效、对外登记对抗"的双层效力混同于"登报作废"——前者是效力分界规则,后者是无效的民间替代手段。
- 把"出资瑕疵不丧失资格"(存续状态)与"可依法解除资格"(程序结果)混为一谈——前者是不灭资格的定性,后者是有门槛的程序出口。
