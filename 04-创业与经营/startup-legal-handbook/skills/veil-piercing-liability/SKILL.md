# 有限责任边界与刺破面纱

## R — 原文 (Reading)

> "只要股东向公司实际缴纳了其认缴的全部出资，并且没有抽逃出资，股东就不需要再对公司经营过程中形成的债务承担责任。"
>
> — 杨春宝、王成兵,《创业投资法律手册》第一章 问题2

> "公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任。"
>
> — 同书第二章 问题57(引《公司法》第20条第3款)

> "一人有限责任公司的股东不能证明公司财产独立于股东自己财产的，应当对公司债务承担连带责任。"
>
> — 同书第一章 问题11、第二章 问题57(引《公司法》第63条)

> "如果是让客户将所欠公司的货款汇入其个人账户，有涉嫌侵占公司财产罪的风险，千万不可为。"
>
> — 同书第二章 问题49

> "一是在诉讼中将虚假出资的股东直接作为被告，二是在执行程序中要求其股东承担连带清偿责任。"
>
> — 同书第二章 问题46

> "若董某已缴足其认缴的注册资本，且不存在抽逃出资或个人账目与公司账目混同的情形"
>
> — 同书第十章 问题224(外商独资企业责任)

---

## I — 方法论骨架 (Interpretation)

作者的核心主张:有限责任不是绝对护身符,它有两个前提——**出资到位**且**财产独立**。前提都守住,公司债务与股东个人财产之间有一道防火墙;前提被打破,面纱就会被刺破,股东对公司债务承担连带责任。整套方法论按四层展开:

1. **有限责任的前提条件**:股东实缴全部认缴出资、未抽逃出资时,公司债务止于公司财产(第一章问题2)。反之,出资瑕疵(虚假出资、抽逃)或滥用行为本身就是刺破的入口——有限责任的"有限"是挣来的,不是默认的。
2. **刺破面纱的两种情形**:①**滥用人格独立与有限责任**——利用公司形式逃避债务、严重损害债权人(如空壳运营、虚假出资后无资产);②**财产混同**——公司账目混乱致公私财产无法区分、两套账、公司资金支付个人开销。两者都指向《公司法》第20条第3款,后果是股东对公司债务**连带**清偿(第二章问题57)。个人债务与公司债务不得混同是双向的:公司资金付个人开销是混同,个人财产与公司债务的隔离也依赖这条边界。
3. **一人公司的举证责任倒置**(最锋利的一条):普通公司由债权人举证混同,一人公司则**由股东自证清白**——不能证明公司财产独立于个人财产,即对公司全部债务连带(第一章问题10/11、第二章问题57)。因此严格分账不是良好习惯而是法定避险动作:独立账户、规范账册、账物相符、经得起审计(第一章问题11)。外商独资企业虽依外资法设立,同样适用一人公司规则(第十章问题224)。
4. **债权人追加股东的两条通道与两条红线**:通道上,要求股东连带清偿可**诉讼中直接列为被告**(已掌握证据时,并可申请财产保全),或在**执行程序中追加**(证据常在执行阶段才取得)——选择依据是证据取得的时点(第二章问题46)。红线上,股东让客户把公司货款汇入个人账户,不止是混同证据,还**涉嫌侵占公司财产罪**(第二章问题49)。

## A1 — 书中的应用 (Past Application)

### 案例 1(主案例): 华先生一人公司账目混乱,公司债务烧到个人房产(第二章 问题57)
- **情境**: 软件代理公司F(一人有限公司)老板华先生,公司账目与个人财产混同——买豪车豪宅、母亲病重时挤占公司经营资金;自主研发失败后拖欠供应商,被起诉。原告起初冻结公司账户一无所获,华先生自恃大量财产登记在个人名下。
- **律师意见**: 原告转而以"F公司财务账目混乱、公司财产与华先生个人财产无法区分"为由,要求华先生对公司债务承担连带清偿责任。律师解释:一人公司股东不能证明公司财产独立于个人财产的,应当对公司债务承担连带责任——华先生无法自证清白,法院支持了原告。
- **结论**: "有限责任"挡不住财产混同;避险动作是建立完善的公司财务制度,明晰区分公司财产和个人财产。这也是"举证责任倒置"的实战形态——举证不能即败。

### 案例 2: 供应公司虚假出资,债权人追加股东(第二章 问题46)
- **情境**: 采购方付40万预付款后对方不供货,起诉时发现供应公司没有资产、股东虚假出资。
- **律师意见**: 两条途径——诉讼中直接把股东列为被告(已掌握证据,可并申请财产保全),或执行程序中要求股东连带;虚假出资+无自有资产的公司不具备法人资格条件,由开办股东担责。
- **结论**: 债权人"追加股东"的通道选择取决于证据取得时点;诉讼阶段已有证据就列被告+保全。

### 案例 3: 外商独资企业资不抵债,董某的个人财产安全吗(第十章 问题224)
- **情境**: 美籍华人董某的外商独资企业濒临破产,清算若资不抵债,会不会动用个人财产。
- **律师意见**: 外资企业组织形式为有限责任公司,且仍须遵守《公司法》一人公司规则——若已缴足注册资本且不存在抽逃或账目混同,即使破产也不动用个人财产。
- **结论**: 外资身份不改变一人公司规则;缴足出资+账目独立=个人财产安全,与案例1互为正反两面。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一人公司/夫妻店/个体老板日常公私账户混用(个人微信收货款、公司卡付房贷),现在公司被起诉,担心个人房子存款被执行
2. 债权人打赢官司(或还没打)发现对方公司账上没钱,但老板住豪宅开豪车、公司两套账/虚假出资/空壳,想追股东个人财产
3. 创业者主动问"有限公司到底有不有限""怎么保证公司欠债不连累我和家人"——想事前建立隔离

### 语言信号 (用户的话里出现这些就应激活)

- "公司欠债会不会执行我个人的房子/老板要连带吗"
- "一人公司/我自己一个人的公司,责任是不是更大"
- "公司的钱和我的钱分不清/两套账/公私混同"
- "让客户把货款打到我个人卡上行不行"
- "追加股东为被告/执行阶段追加股东/刺破面纱/法人人格否认"
- "有限责任是不是绝对的/有限公司护身符"

### 与相邻 skill 的区分

- 与 `capital-contribution-compliance` 的区别: 那是出资义务本身(认缴、实缴、未缴的补充清偿);本 skill 处理出资到位之后财产层面的问题(混同、滥用、举证倒置)。债权人以"未实缴"追索走前者,以"混同/滥用"追索走本 skill
- 与 `nominee-shareholding-risk` 的区别: 那是代持双方之间的权利义务与显名风险;本 skill 处理股东与**公司债权人**之间的责任边界
- 与 `exit-dissolution-liquidation` 的区别: 那是清算注销程序与清算义务人责任;本 skill 处理公司存续乃至诉讼执行阶段的股东责任,清算中抽逃补回属于前者
- 与 `entity-choice-incorporation` 的区别: 那是设立时选什么形式(合伙/独资/公司);本 skill 假设已设公司,处理有限责任的边界与失守

## E — 可执行步骤 (Execution)

### 视角一: 自保视角——怎么避免被刺破(股东/老板侧)

1. **第一步: 混同风险自查**
   - 逐项检查: 公司与个人是否使用不同账户?有无个人卡收公司货款?公司资金有无支付个人/家庭开销?账册能否做到账物相符?是否有一套真实账?
   - 完成标准: 输出混同风险点清单,每项标注"已隔离/需整改"
   - 判停条件: 用户问的是"认缴的钱要不要缴、什么时候缴"——转 `capital-contribution-compliance`
2. **第二步: 一人公司举证倒置专项加固**
   - 若为一人公司(含外商独资): 建立独立对公账户、所有收支走公司账户、规范会计账册、年度审计留档、股东与公司资金往来一律签协议留凭证——目标是"随时能自证财产独立"
   - 完成标准: 五项动作(独立账户/规范账册/审计/凭证留痕/往来协议)全部有落地安排
   - 判停条件: 用户实际经营的是个人独资企业/个体工商户(本无面纱可刺,投资人本来就无限责任)——转 `entity-choice-incorporation` 并直接说明责任形式差异
3. **第三步: 红线行为立刻叫停**
   - 代收货款: 停止让客户把公司货款汇入个人账户(侵占罪风险,不只是混同证据);已发生的尽快归还入账并留痕
   - 完成标准: 每条红线行为有"停止动作+补救动作+留痕方式"三项
4. **第四步: 输出隔离制度清单**
   - 汇总为可执行的财务隔离制度(账户、审批、账册、审计、往来凭证),按"今日可改/本月可建/请会计师配合"分级
   - 完成标准: 清单可直接交给财务落地,且每条对应一个刺破风险点

### 视角二: 追偿视角——债权人怎么追加股东(债权人侧)

1. **第一步: 定性股东责任路径**
   - 分流: 股东未实缴/抽逃出资 → 补充清偿路径(详见 `capital-contribution-compliance`);财产混同/滥用人格独立(两套账、空壳、公私不分)→ 刺破面纱连带路径(本 skill)
   - 完成标准: 责任路径定性明确,援引的事由(出资瑕疵 vs 混同滥用)写清
2. **第二步: 收集证据**
   - 混同证据: 账目混乱线索、公司资金流向个人、空壳运营事实;一人公司案件重点收集"对方难以自证独立"的线索
   - 完成标准: 证据线索清单成形,注明每项的取证方式(法院调查令、审计、工商档案)
3. **第三步: 选择追加通道**
   - 诉讼中已掌握证据 → 直接列股东为共同被告+申请财产保全;证据在执行中才发现 → 执行程序中申请追加股东承担连带清偿责任
   - 完成标准: 通道选择与证据时点匹配,并给出保全/追加的程序动作
   - 判停条件: 用户目的只是"让公司还钱"且公司有财产——无需追加,回到普通债权执行
4. **第四步: 预判对方抗辩并输出行动方案**
   - 一人公司股东唯一活路是自证财产独立——评估其账册审计完备度,预判其能否举证;普通公司则需己方举证混同
   - 完成标准: 行动方案含"主张事由+证据+程序通道+对方抗辩预判"四要素

## B — 边界 (Boundary) ★

### 法律时效性警示(必读)

**本书为 2014 年版,处于 2013 年《公司法》修正案语境(当时引用的是旧《公司法》第20条第3款、第63条)。2023 年《公司法》(2024-07 施行)已实质改写本 skill 涉及的规则,适用前必须按现行法核实:**

- **法人人格否认条款重新编号并强化**: 现行《公司法》第23条整合了纵向刺破(原第20条第3款)与一人公司举证倒置(原第63条,现第23条第3款),并**新增横向人格否认**(第23条第2款:股东利用其控制的两个以上公司实施滥用行为,各公司对任一公司的债务连带)——横向刺破在本书成书时仅是司法实践,现已入法
- **股东责任与资本制度全面强化**: 注册资本 5 年实缴、认缴加速到期、股东失权制度(第52条)、董事会核查催缴义务、董事对第三人责任——"出资到位"这一前提的 enforcement 更硬,认缴滚大注册资本的风险显著上升
- 2014 年立法解释后,虚报/抽逃出资罪的刑事追诉仅适用于实缴登记制公司;现行法下本 skill 相关行为主要暴露于民事连带与行政责任,刑事表述引用前须按现行口径修正
- 《九民纪要》(2019)细化了人格否认的审判口径(财产混同、过度支配与控制、资本显著不足三类),个案认定比"混同即连带"的表述更精细

### 其他失败模式(书中警示)

- "豪宅豪宅登记在个人名下就安全"——华先生案的教训:财产登记在谁名下不重要,混同证据一动即被刺破
- 让客户把货款汇入个人账户"先缓一缓"——不止是混同,是刑事红线
- 以为外资/一人公司"结构特殊"有豁免——外资独资企业同样适用一人公司规则
- 把有限责任当绝对护身符,平时不做任何隔离动作,被诉时才想自证——举证不能即连带,事后无法补账

### 作者的盲点 / 时代局限

- **输出为方法论蒸馏,不构成法律意见**;具体案件(尤其已涉诉的)必须咨询执业律师
- 案例全部化名并经律师转述(华先生案无法核对原始事实与判决),证据细节以书中叙事为准
- 上海园区语境,各地司法对人格否认的认定尺度有差异;全书几乎无税务维度——公私资金往来的税务后果(个税、视同分红)未被覆盖,而实践中常与混同问题并发

### 容易混淆的邻近方法论

- **个人独资企业 ≠ 一人有限公司**: 个人独资企业投资人依法承担**无限责任**,根本不存在"面纱"可刺——用户说"个人独资企业欠债要连累家庭吗",答案是"本来就无限,无需刺破",这是本 skill 最易误判的邻近概念
- 合伙企业普通合伙人无限连带:同样是"无限",但机制是合伙人身份自带,与刺破面纱无关
- 出资瑕疵补充清偿(未实缴股东以未出资本息为限)与刺破面纱连带(对全部债务连带):责任范围不同,事由不同,不要混为一谈
