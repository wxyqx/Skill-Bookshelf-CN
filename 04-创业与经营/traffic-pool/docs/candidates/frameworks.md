id: f01
title: 流量池思维（获取—存储—运营—发掘）
type: framework
source_chapter: 自序
source_quote: |
  流量池思维和流量思维是两个概念。流量思维指获取流量然后变现流量，这显然已无法解决今天的企业流量困局。流量池思维则是要获取流量并通过存储、运营和发掘等手段，再获得更多的流量。
summary: |
  全书统摄性思考模型：把流量当作可反复运营的资产，而非一次性消耗品。
  流量思维是"获取→变现"即止；流量池思维强调获取之后继续做存储、运营、发掘，
  用一批老用户找到更多新用户，让流量产生复利。
  用法：诊断企业若只有流量采买、没有自有池子，就应转向"筑池"——品牌、微信、App、
  CRM 都是池子形态；一切获客手段的优劣，都看它能否把流量留在池内再发酵。
  全书的获取七法（品牌/裂变/微信/事件/数字广告/直播/BD）都是装进这个模型的子程序。
tags: [mental-model, marketing, traffic, strategy]

type: framework
source_chapter: 第1章 流量即市场
source_quote: |
  线上流量来源大致可以分为三种：企业自有流量（官网、App、微信、CRM等）、媒体内容流量（媒体、自媒体）和广告采购流量（各类型广告，如搜索竞价、信息流、视频贴片等）。
summary: |
  给企业盘点流量家底的分类框架：线上流量只有三种来源——自有流量、媒体内容流量、
  广告采购流量。
  用法：把企业现有流量按三类分桶，估算各桶体量、成本与增速，即可看清"付费依赖度"；
  流量贫乏企业的典型诊断结果是自有流量近于零、采购流量占比过高且单价飙升，
  由此推出行动方向：建自有池（品牌/微信/App），并优先发展低成本的自有与社交流量。
tags: [classification, marketing, traffic, diagnosis]

title: 流量之困三问诊断（少/贵/陷阱）
type: framework
source_chapter: 第1章 成也流量，败也流量
source_quote: |
  面对流量，初创企业普遍面临三个问题：第一，流量少；第二，流量贵；第三，流量陷阱。
summary: |
  初创企业流量处境的诊断框架，三问依次排查：流量少（自然流量枯竭、账号无关注、
  优质流量竞价买不到）；流量贵（获客成本从几元飙至几千元）；流量陷阱（刷量作弊、
  媒介不透明、投放黑箱）。
  用法：先判断自己卡在哪一问——少则靠品牌与裂变自造流量；贵则用低成本获取方式
  （裂变、搜索、BD 互换）替代采购；陷阱则靠全程数据监测与 KPI 下沉来自证效果。
  这个"少—贵—险"三问是全书方法论的出发点。
tags: [diagnostic, marketing, startup, traffic]

title: 品效合一"急功近利"营销总纲
type: framework
source_chapter: 第1章 用流量池实现"急功"和"近利"
source_quote: |
  "急功"，是要快速建立品牌，打响知名度，切入市场，获得流量。
  "近利"，是在获得流量的同时，快速转化成销量，带来实际的效果。
summary: |
  全书营销决策总纲：当前营销分品牌流与效果流两个流派，作者主张两者合一——品效合一，
  即品牌动作必须带销量转化，效果投放也要承载品牌声量。
  "急功近利"在此非贬义：急功=快速建品牌获流量；近利=流量到手立即变销量。
  用法：为每笔营销预算同时问两个问题——它带来声量吗？它带来可测的转化吗？
  凡答不出转化路径的纯品牌投入（对流量贫乏的企业）都应改造或砍掉。

source_quote: |
  品牌即流量。通过关注和"粉丝"，可以获得源源不断的流量。从短期看，可能做品牌付出的成本很高，但基于品牌的持续性记忆、"粉丝"的口口相传以及明星品牌的社会关注，品牌成本会边际递减，甚至归零。
summary: |

  粉丝带来主动消费与口碑"自来水"；短期成本高，长期边际递减甚至归零。
  品牌同时解决认知（记得住、分得开）、信任（放心优先选）、认购（导向购买）三层问题。
  用法：评估一个品牌的流量价值，就看它的关注量与粉丝活跃度这两口"井水"的深度。

type: framework
source_chapter: 第2章 品牌：流量之井
source_quote: |
  如何让品牌尽快获得关注与粉丝，如何用较低的成本迅速建立品牌流量池，完成最终的效果转化，我将主要从定位、符号和场景（见第三章）三部分内容予以阐述。

  用法：品牌无流量时按环排查——定位模糊回炉定位三法；记不住补符号；
  记得住但不购买补场景与接触点。缺任何一环都先补那一环。

  AARRR分别是指：获取用户（acquisition）、提高活跃度（activation）、提高留存率（retention）、收入获取变现（revenue）、自传播（refer）。

  自传播（refer）即裂变，是五环中唯一能压低整体获客成本的一环——本书裂变方法论的位置。

id: f16
title: 裂变营销双原则与成本公式
type: framework
source_chapter: 第4章 裂变营销：用1个老用户找来5个新用户
source_quote: |
  第一，强调分享。即必须通过老用户的分享行为带来新用户。这样成本最低、获客最广。

  ②后付奖励——把事前付给媒体的广告费拆成双边奖励，用户完成注册/行为后才兑现，
  降低投放风险，即"把广告费奖励给用户"。
  与传统营销的本质区别是"去广告化获客"+技术反复测试提高分享率，把获客的不确定性
  变成可迭代的概率游戏；裂变流量自带社交信任，转化率与留存率优于传统拉新渠道。
