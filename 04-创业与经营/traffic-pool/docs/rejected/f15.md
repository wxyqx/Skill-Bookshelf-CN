# rejected/f15 — AARRR 增长模型

- 候选来源：frameworks.md f15（第4章）
- 判定：**淘汰**（转引常识，不独立成 skill）
- 挂在：**V3 独特性**
- 原因：AARRR 是 Sean Ellis 一系增长黑客的标准模型，作者本人也只是转引（BOOK_OVERVIEW 证据层级第3类：二手方法论转引）。抹去作者名字，任何增长从业者都能完整说出五环——不构成作者的独特视角、反直觉见解或独特术语体系。
- V1/V2 复核：五环框架在书内仅第4章一处陈述性使用，无第二独立语境的独立运用；其预测力测试只能复述书内已知分工（第一批靠投放、自传播即裂变），无外推增量。
- 处置：书内真正的独特点——"自传播（refer）是唯一能压低整体获客成本的一环、裂变是第五环的技术化放大"以及"第一批种子只能靠投放"——已分别由 CL09（裂变双原则）与 CL11（存量找增量）的通过单元承载；AARRR 五环本身作为背景素材，不再单列。
