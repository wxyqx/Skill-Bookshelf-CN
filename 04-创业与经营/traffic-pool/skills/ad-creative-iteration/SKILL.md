# 广告素材迭代实测

## R — 原文 (Reading)

> "第三版最大的改变是强化了电话号码，放到了主广告语上方。请注意，这个小小的改变让电话呼入量增加了140%。"
>
> — 杨飞，《流量池》第3章"传统广告也要提供互动方式"（车闪贷四版迭代实录）

---

## I — 方法论骨架 (Interpretation)

1. 广告行业的默认生产方式是"创意一次成型的赌注": 好坏靠评审会、靠老板品味、靠代理商提案现场。本方法论把广告（包括传统硬广）重构为可实测、可快速迭代的增长实验。
2. 支柱一，指标前置: 投放前先定本轮的唯一成功指标（呼入量/留资量/点击率/成单），没有指标就没有"更好"可言。
3. 支柱二，单变量: 每一版只验证一个假设——只改一个元素（电话位置、卖点数量、代言人、二维码位置），其余全部保持不变，这样效果差异才能归因到那个改动。
4. 支柱三，版本阶梯: 逐版淘汰递进——有效的改动沉淀为模板规则继续加码，无效的改动回滚，进入下一轮单变量。
5. 裁决规则: 当"老板觉得"与"创意总监觉得"冲突时，把争议点做成两版对比、一个投放周期定胜负——把品味之争转换为实验设计问题。
6. 适用面比直觉广: 书中同一逻辑横跨传统媒体（分众四版）、落地页（改 8 遍）、信息流素材（视角对比）与非广告域（裂变机制"用技术反复测试提高分享率"）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 车闪贷分众广告四版阶梯
- **问题**: 车闪贷与台湾奥美做的第一版分众广告"汽车龙卷风"画面漂亮，但日呼入不足 100 个，CPS 高得离谱。
- **方法论的使用**: 定唯一指标为业务电话呼入量，逐版单变量迭代——第二版改用 3B 吸睛原则；第三版强化"车财神"符号、把电话号码上移至主广告语上方；第四版换王祖蓝真人 IP、卖点压缩为"2小时/50万/0.49%"三个 ICON、二维码升至右上角。每版只验证一个假设。
- **结论**: 吸睛只是及格线，信息位与卖点可见性才是转化变量；广告不是艺术品。
- **结果**: 呼入量第二版 +30%、第三版 +140%；第四版留资量再 +300%，扫码留资反超电话呼入。

### 案例 2: 车闪贷落地页 8 轮迭代
- **问题**: 点击进来的流量承接不住，来电转化低。
- **方法论的使用**: 把落地页当营销终端而非创意稿，从初版到定稿改 8 遍——每轮围绕一个高转化组件调整（品牌区直接告知"有车就能贷"、口碑线打消顾虑、GIF 拨打按钮占最重要视觉位、4 个核心卖点扁平化上首屏等）。
- **结果**: 第 8 版的电话咨询量比第一版增加 330%。

### 案例 3: 大众蔚领落地页三版测试（第三方佐证）
- **问题**: 落地页改动是否真的影响转化，需要可对照的数据。
- **方法论的使用**: 5 天投放测试三版优化页——优化一精简头图文案、放大优惠高亮（转化率 8.6%）；优化二调整后不升反降（3.5%）；优化三把"试驾"留资入口前置到导航位、视觉扁平大留白（13.5%）。
- **结论**: 头图、导航优先级、文案量、留白等单点改动对转化率影响巨大；无效改动（优化二）靠测试暴露并回滚。
- **结果**: 为"数据是落地页唯一考核标准"提供了书外第三方证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 多版本素材评审僵持不下（老板要美感、创意要表达、销售要卖点），需要裁决机制。
2. 投放效果不达标，想知道先改什么、怎么改才科学，而不是每次全推翻重做。
3. 想从一次次"这版比上版好"的对比中沉淀出可复用的素材模板与规则。
4. 代理公司交来一版"更好看"的创意，需要判断该不该换的依据。
5. 想把投放从一次性赌注变成团队可持续优化的实验机制。

### 语言信号 (用户的话里出现这些就应激活)

- "哪个版本好""听谁的""怎么说服老板"
- "A/B 测试""迭代""测试一下""单变量"
- "素材优化机制""效果上不去怎么改""下一版测什么"
- "creative testing""A/B test""iteration""which version wins"

### 与相邻 skill 的区分

- 与 `traditional-ad-conversion` 的区别: CL07 是"一条广告怎么设计才对"的静态规则库（4件套、媒介判据、一瞥钟情）；本 skill 是"怎么用实验验证任何改动是否有效"的程序。设计问 CL07，裁决问本 skill。
- 与 `landing-page-conversion` 的区别: 用户问"承接页怎么改"（六要素审查、留资极简）归 CL16；问的是任意投放素材的实验方法论、或"页面迭代本身怎么组织"归本 skill（CL16 的 8 轮迭代正是本方法在页面域的实例）。
- 与 `feed-native-creative` 的区别: 信息流素材的内容生产法则（用户视角七法则、原生感三式）归 CL17；生产出来的素材怎么测、怎么迭代归本 skill。
- 与 `ad-anti-fraud-channel` 的区别: 实验数据异常（点击暴涨但成单为零）要先怀疑作弊与口径，渠道/KPI/防作弊体系归 CL15。

## E — 可执行步骤 (Execution)

1. **定唯一成功指标**
   - 完成标准: 写出本轮投放的一个核心指标（呼入量/留资量/成单量/点击率）与当前基线值；多指标并存时选最靠近收入的那个，其余降为观测项。

2. **把争议或猜想转成单变量假设**
   - 完成标准: 假设句式成文——"改〈单一元素〉会提升〈指标〉，因为〈理由〉"；一轮只允许一个变量，其余元素全部冻结。
   - 判停条件: 若找不到可冻结的对照条件（媒体、时段、人群都在变），先解决投放结构问题再谈素材实验，否则结论不可归因。

3. **分版投放并观测**
   - 完成标准: 两版（或阶梯多版）在同一媒体、可比时段与人群下投放一个完整周期；记录各版指标值与差异；排查同期其他营销活动的干扰（书中数据未控制此类变量，执行时应补上这一纪律）。

4. **裁决与沉淀**
   - 完成标准: 胜出版保留，有效改动写成模板规则（如"电话号码放主广告语上方""二维码放右上角"）；败版回滚；输出下一轮候选假设，进入循环。
   - 判停条件: 若单周期后两版差异在噪音范围内（差距 <10% 或无统计意义），停止微调该元素——换一个更大的假设变量，或回 `traditional-ad-conversion` 重审设计规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 没有投放、不可测的纯品牌内容（发布会物料、公关声明）——没有可测指标，实验法不适用。
- 样本量太小的投放（单点位、极短周期）——数据噪音淹没结论，硬做实验是自欺。
- 用户问的是"文案怎么写/页面组件怎么设计"这类生产规范——归 `feed-native-creative` / `landing-page-conversion`。

### 作者在书中警告的失败模式

- 唯美=无效的默认（反例 x18）: 不做指标前置时，评审会自然滑向"画面漂亮"标准——车闪贷第一版即如此；广告不是艺术品。
- 迭代数据本身的方法论缺陷（作者盲点）: 书中 +140%/+300%/+330% 全是前后版本对比，未控制时段/人群/出价变量、未披露样本量——照搬执行时须补齐实验纪律，不要把书中百分比当作预期收益。

### 作者的盲点 / 时代局限

- 单方口径: 所有迭代数据来自神州系内部，无第三方审计、无对照组；"下订/留资"口径含水分，读案例时要打折扣。
- 迭代的前提是有量: 单变量实验需要足够曝光与转化样本；小预算玩家可能跑不出显著差异，应合并周期或换更大颗粒度的假设。
- **时效警示**: 本书为 2018 年快照。分众扫码、电话呼入等指标形态随媒介生态变化（当期以点击/留资/成单的线上归因为主）；"指标前置+单变量+阶梯沉淀"的判断逻辑层不变，指标定义与归因工具须按当期平台规则重查。

### 容易混淆的邻近方法论

- 增长黑客的全漏斗实验（AARRR）: 本 skill 只聚焦"素材/版本层"的单变量迭代，不覆盖定价、渠道结构、产品功能实验。
- `landing-page-conversion` 的页面优化: 落地页迭代是本方法在页面域的应用实例；页面组件规范与六要素审查本身归 CL16。
- `ad-anti-fraud-channel` 的数据审计: 实验"数据太好看"时先查作弊——防作弊是实验有效性的前置守护，不是迭代本身。
