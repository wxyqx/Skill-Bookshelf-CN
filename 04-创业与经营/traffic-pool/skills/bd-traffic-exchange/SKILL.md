# 跨界 BD 与流量互洗（BD Traffic Exchange）

## R — 原文 (Reading)

> "'流量互洗'是企业在多轮营销活动后，已经很难进行流量拓展和深度发掘的情况下，依照品牌实际需求，将双方企业自身流量互换，实现双方平台价值利用最大化。"
> "如果说品牌、广告、社交媒体是市场部队中的重骑兵，那么BD则是一支神出鬼没的特种兵，往往以较小的代价创造神奇的效果。"
>
> — 杨飞，《流量池》第12章 跨界营销的流量巧用

---

## I — 方法论骨架 (Interpretation)

当自有流量增长见顶，与其继续花钱买流量，不如和"门当户对"的品牌把彼此的自有流量打通互洗——这是 BD（商务拓展）在营销里的本质：用较小的代价换取新流量。它不是喝酒吃饭拉关系，而是一套可操作的拓展系统。

操作分四层：先"知彼"——用数据画像研究对方用户与我方的结合点、调性共性与对方 KPI；再"知己"——盘出自家可交换的流量位，按曝光类（App 广告位、开屏、车身）与购买转化类（会员短信、微信、push）分类，按本次战役目标匹配给对方；然后选对象策略——主动出击、选择接受、行业打通三种路径；最后按四阶段递进推进：联合创意→内容平台合作→产品技术合作→订单交易合作，每往前一级都以上一级建立的信任为前提，跳级容易翻车。对强势品牌，先用一个对方感兴趣的小创意小成本试水，用真实数据换信任。

BD 经理的四词守则：真诚（先弄清并满足对方 KPI）、务实、高调（合作要大声宣传）、捞过界（能为对方提供创意、设计等分外增值）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 神州×Michael Kors 小成本试水
- **问题**: 想与轻奢品牌 MK 合作，对方以"出行品牌与自身调性不符"婉拒。
- **方法论的使用**: 不放弃，改用"小创意撬动信任"——策划情人节"坐专车，赢取限量版 MK 手包"，只在微信小成本试水。
- **结论**: 强势品牌不缺资源，缺的是对我方执行力的信任；小创意+真实用户参与数据是最好的敲门砖。
- **结果**: 大量真实用户转发参与、效果超预期，MK 被打动，双方建立信任并成为持续合作品牌。

### 案例 2: 神州×华为 Mate 系列预装（订单交易级合作）
- **问题**: 预装合作对象怎么选、怎么谈。
- **方法论的使用**: 用后台数据知己知彼——70% 以上用户用 iPhone、12% 用华为，遂按机型数据定向谈判；并设计 300 元券包提高定制版 App 激活率，让华为侧的 KPI 也有交代。
- **结论**: 用消费行为数据找结合点，把合作做到订单交易层，双方各有可量化收益。
- **结果**: 拿下华为 Mate 系列中国区唯一预装出行软件，此后 P 系列与 Mate 系列均预装。

### 案例 3: 神州×途家／×国美流量互洗（同量级置换）
- **问题**: 双方都在百万级体量，如何不花钱互导流量。
- **方法论的使用**: 知己盘点后按曝光类/转化类匹配资源位——神州出 App banner、微信、微博；途家出官网首页 banner、高铁与电视节目广告；与国美则置换全国卖场万台 LED 与 32 万台在售电视屏幕。
- **结论**: "实体要线上流量省钱、互联网要线下曝光提品牌"，双向互补即可成交。
- **结果**: 与途家总曝光 963 万、神州促成订单超 700 万元、途家新增 10 万+ 注册用户；与国美为国美节省 115 万广告成本、神州获 2000 万+ 曝光。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 自有流量见顶或预算有限，想找互补品牌互相导流、置换资源。
2. 被意向品牌拒绝，想知道怎么撬动强势品牌。
3. 要盘点自家能拿出去换的流量位，或评估对方能给什么。
4. 合作谈到了创意层，想知道怎么往产品层、订单层推进。

### 语言信号 (用户的话里出现这些就应激活)

- "跨界/异业合作/联合活动/资源置换/互相导流/联名""BD 怎么谈""流量互换"
- "对方拒绝我们了怎么办""我们能拿什么出去换"
- "BD / co-marketing / partnership / traffic exchange"

### 与相邻 skill 的区分

- 与 `livestream-imbt` 的区别（互斥对）: CL18 管直播带货的项目操作；本 skill 管品牌间合作关系的寻找、谈判与分层推进。即使合作产出是一场联合直播，直播执行归 CL18，合作关系归本 skill。
- 与 `ad-anti-fraud-channel` 的区别: CL15 是花钱采买流量并防作弊；本 skill 是不花钱（或少花钱）用自有流量置换。
- 与 `scene-trigger-niche` 的区别: CL06 是自家营销的场景选择与补贴设计；"行业打通型 BD"（如神州头等舱计划绑定高端会议与酒店）虽与场景相关，但只要落点在**双方合作关系的建立与推进**，就归本 skill。
- 与 `traffic-pool-diagnosis` 的区别: CL01 判断要不要建池、先建哪个池；本 skill 是池子见顶后向外借流量的操作程序。

## E — 可执行步骤 (Execution)

1. **知己：盘点可交换流量位**
   - 列出自有流量位（微信/服务号、App 广告位与开屏、会员短信/push、产品包装、门店物料、线下屏幕、数据洞察），按曝光类与购买转化类归档并标注量级。
   - 完成标准: 一张两类分档、带量级数字的流量位清单。

2. **知彼：画像与 KPI 调研**
   - 用数据分析对方用户画像、与我方的场景结合点与调性共性，写出"我方能帮对方达成哪一项 KPI"。
   - 完成标准: 一页对方画像+我方价值主张。
   - 判停条件: 找不到数据支持的结合点，或调性明显冲突——放弃，或降级为单次低成本试水，不做长期绑定。

3. **选对象策略并设计敲门砖**
   - 按主动出击/选择接受/行业打通三策略定位；对强势品牌设计一个对方感兴趣的"小创意"小成本试水，用真实数据换信任（MK 手包逻辑）。
   - 完成标准: 明确策略类型与首个试水方案的预算、周期、衡量口径。

4. **四阶段递进，不跳级**
   - 沿联合创意→内容平台→产品技术→订单交易推进，每级以上一级的执行结果为信任凭证再谈下一级。
   - 完成标准: 当前合作所处阶段明确，下一阶段有书面触发条件。

5. **守则执行与高调宣传**
   - 真诚（先满足对方 KPI）、务实、高调、捞过界；合作落地必须有联合对外传播，防止品牌被合作方淹没。
   - 完成标准: 对方 KPI 达成情况有记录，且合作有联合宣传物料出街。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 想做直播带货或联合直播的执行——形式操作归 livestream-imbt，本 skill 只管合作关系。
- 用预算直接采买流量（信息流、DSP、SEM）——归 ad-anti-fraud-channel；BD 是置换逻辑，不是投放逻辑。
- 双方体量悬殊到我方毫无对等流量位、只能付坑位费——那已变成媒介采购，不属流量互洗。

### 作者在书中警告的失败模式

- IP 合作品牌成陪跑者（反例 x36）: 热门 IP 势头碾压品牌，"受众记住 IP 形象而忘记合作品牌"，花钱替 IP 做嫁衣——BD 必须"高调"宣传并设计把流量沉淀回自身品牌的承接（对照麦当劳×小黄人全线产品与主题餐厅）。
- 前期不调研、后期定位失误（反例 x37）: 凭感觉选合作方，"在营销进行的后期会因为定位失误，让合作收益大打折扣"——知彼画像是硬前提。

### 作者的盲点 / 时代局限（时效警示：2018 年快照）

- **本书为 2018 年快照，只保留判断逻辑层，参数层须按当期重查**: 书内案例均为神州系大品牌的置换（预装、联名卡、卖场屏幕），且全部为成功入选、无失败复盘；中小企业"同量级交换即可启动"的主张缺少书中实证，用其判断时须自行验证对方对流量的真实需求。
- 作者两条原则方向相反且未给权衡框架——"门当户对"（体量、受众、调性匹配）与"跨度越大，化学反应就越明显"（越大胆的跨界越好）：本 skill 只能提供画像与调性数据来个案权衡，不存在通用解。
- 数据共享与联合营销在个保法与平台生态下有合规约束（用户数据互换须双方合规评估），书内零讨论。

### 容易混淆的邻近方法论

- 渠道分销/招商: 渠道合作是卖货分佣关系，流量互洗是市场部之间的流量置换——目标与结算方式不同。
- 品牌联名产品（co-branding）: 联名是 BD 的一种产出物，但 BD 的本质是流量互换——只做联名产品而无流量位交换，不算完成一次流量互洗。
