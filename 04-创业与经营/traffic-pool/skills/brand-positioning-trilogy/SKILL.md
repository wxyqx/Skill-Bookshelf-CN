# 品牌定位三法选型

## R — 原文 (Reading)

> 对立型定位是强竞争性导向（非用户需求导向），是与对手显著差异化的定位，适合市场已经相对饱和、后发创业的品牌。
>
> — 杨飞，《流量池》第二章"最犀利有效的三种定位方法"

---

## I — 方法论骨架 (Interpretation)

定位理论不是本书原创（源自特劳特/里斯与里夫斯），作者的增量是把"定位怎么选"做成一套收敛的决策程序，专供资源有限的后发品牌：

1. 按竞争态势三选一——红海后发者走对立型定位（对标行业最强者，用"更、没有、不是……而是……"句式一破一立，让对手被间接联想为对立面）；有独家功能创新的走 USP（单点物理功效，"……就用……"场景句式）；真开创了新品类才走升维（"重新定义××"，让用户觉得这是更高维度的购买）。
2. 两个硬判据收口——凡是不能一句话或几个字说清楚的，不算品牌定位；创牌期禁情怀，梦想、主义、主张式定位是管理者的自娱自乐。
3. 一道前置检验——定位必须与产品设计同步：产品要能为定位作证（神州做孕妈专车为"安全"作证），作不了证就先改产品或降级定位；明知产品没有某种优势还强行造光环，只会破坏信任。

这三步把哲学化的定位论改造成了后发品牌能跑完的决策树。

## A1 — 书中的应用 (Past Application)

### 案例 1: 神州专车"更安全的专车"——红海后发的对立型定位（第2章）
- **问题**: 2015 年神州专车后发杀入出行市场，面对滴滴、优步、易到三座大山，打不起价格战、拼不过车辆数。
- **方法论的使用**: 走对立型路线：不碰 C2C 同质化战场，把用户最敏感的痛点定在"安全"上，以"更安全的专车"对标滴滴优步，让对手被间接联想为"不安全的专车"；B2C 自营模式为定位提供产品支撑。董事长陆正耀在内部决策会上顶住市场部与台湾奥美专家对安全定位的质疑，坚持不改。
- **结论**: 定位一句话说清，且产品模式能为其作证。
- **结果**: 两年多后拥有 4000 万用户、日均超 50 万单，主动减少补贴仍稳步增长、年均增长率 50% 以上；滴滴后来也开始跟随主打"安全专车"形象。

### 案例 2: 定位与产品同步的正反对照——支付宝"圈子"翻车 vs ofo 大眼车（第3章）
- **问题**: 大品牌也会"定位超前进度于产品"：支付宝 2016 年为强化社交定位强推"圈子"功能，产品机制撑不住，上线即涌入大尺度内容。
- **方法论的使用**: 用"产品作证"检验定位——产品为定位赋能则定位成立（ofo 与小黄人 IP 联手做"大眼车"，产品部门与市场部门联手，萌车一上街就被骑空）；产品撑不起定位，光环就变成反光。
- **结论**: 定位等同品牌战略，必须为产品设计指明方向、与产品部门同步协同；强行造光环只会破坏信任。
- **结果**: 蚂蚁金服董事长出面道歉，圈子功能迅速下线。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新品牌/新产品定名与口号评审：定位句怎么写、走哪条路线。
2. 品牌升级 repositioning：老定位失效，要不要换、换成什么。
3. 创业者找定位咨询前自检：先自己跑一遍决策树再花钱。
4. 定位与产品"两张皮"诊断：营销讲的与产品做的对不上。

### 语言信号 (用户的话里出现这些就应激活)

- "定位怎么选 / 差异化（differentiation）/ 对标竞品"
- "USP、独特卖点、单点突破 / 升维、重新定义、开创品类（category creation）"
- "这个定位一句话说不清 / 是不是太情怀了"
- "positioning route — against the leader or a new category?"

### 与相邻 skill 的区分

- 与 `brand-symbol-building` 的区别：定位之后"怎么被记住"（符号）归它；本 skill 只管"说什么、走哪条路线"。
- 与 `scene-trigger-niche` 的区别：定位之后"在哪里被触发"（场景切割与补贴投向）归它。
- 与 `brand-as-traffic-well` 的区别：要不要投品牌的预算辩护归它；本 skill 假定已决定做品牌，处理"品牌的核心主张是什么"。

## E — 可执行步骤 (Execution)

1. **竞争态势判定**
   - 完成标准: 回答三个问题并各留书面答案——我是否红海后发者？是否真有独家功能创新？是否真开创了新品类？

2. **路线三选一**
   - 完成标准: 按态势选定唯一路线并写出定位句——红海后发→对立型（对标最强者，"更/没有/不是……而是……"句式）；功能创新→USP（"……就用……"场景句式）；真开品类→升维（"重新定义××"）。
   - 判停条件: 选升维前若发现需求频次低、习惯弱（伪需求），停止定位工作——营销救不了伪需求，先回产品验证需求本身。

3. **双判据+产品作证收口**
   - 完成标准: 三项检查全部通过——①一句话测试：定位能一句话或几个字说清；②创牌期禁情怀：剔除梦想/主义/主张类表述（品类领导者可例外）；③产品作证：产品设计能为定位提供证据，作不了证则先改产品或降级定位。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已是品类领导者、想做情感沟通型定位——作者明说领导者玩情怀"无可厚非"，三分法是给创牌企业的犀利路线，不是给成熟品牌的唯一答案。
- 用户问的是定位之后怎么被记住、在哪里被触发——转 `brand-symbol-building` / `scene-trigger-niche`。
- 用户想论证品牌预算值不值——转 `brand-as-traffic-well`。

### 作者在书中警告的失败模式

- 情怀定位（第2章）：创牌期玩梦想/主义/主张，在有限流量曝光中无法形成认知，"基本是管理者的自娱自乐"；红牛把"困了累了喝红牛"换成"你的能量，超出你的想象"后定位表述反而模糊。
- 升维踩中伪需求（第2章）：上门美甲、上门洗车、上门按摩等概念"需求频次低、习惯弱"，定位再大市场也起不来——"市场状况不是营销能够解决的"。
- 强行品牌光环（第3章）：产品没有相关特征仍把"黑科技""无边框"加在定位上，被网友戏称为对黑科技的"侮辱"，破坏企业信任。

### 作者的盲点 / 时代局限

- 三分法与双判据转引特劳特/里斯/里夫斯，作者增量是选型程序而非原创理论；升维定位与蓝海战略的关系未做辨析。
- 对立型定位的攻击性传播是双刃剑：神州"拒绝黑专车"教育型广告效果一般，Beat U 争议事件才把定位打入人心——作者同时警告"没有明确的、对消费者有益的定位主张，尽量慎用"这类对比攻击。
- "情怀定位一律禁用"的一刀切，忽略了品类成熟期情感资产与品牌转型的正当需求。

### 容易混淆的邻近方法论

- 特劳特/里斯定位论（占领心智）：同源但更偏哲学，缺少本 skill 的三选一决策树与产品作证门槛。
- 里夫斯 USP 原论：本书将"对立型"也纳入 USP 光谱并重排了适用条件。
- 蓝海战略：与升维定位神似，作者未区分，使用时需自行补足价值创新验证。
- 华与华"超级符号"：那是符号层操作，归 `brand-symbol-building`。

### 时效警示（2018 年快照）

本书成书于 2018 年：书中的对标案例（滴滴优步大战、ofo）与传播形态已成历史。但"按竞争态势三选一 + 一句话测试 + 创牌禁情怀 + 产品作证"的选型逻辑不随平台过时；时效风险主要在案例层而非方法层——引用案例时注明年代，攻击性传播的具体打法另须按当期舆论与监管环境重估。
