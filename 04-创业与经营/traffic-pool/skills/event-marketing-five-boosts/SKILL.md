# 事件营销"轻快爆"与五爆点设计

## R — 原文 (Reading)

> "事件、热点来得快、去得快，所以事件营销一定要'轻快爆'地出创意，见效果。"
>
> — 杨飞，《流量池》第7章"事件营销：轻快爆的交通规则"

---

## I — 方法论骨架 (Interpretation)

1. 背景前提是新闻速朽：热点半衰期已从一周缩到 1-2 天甚至一个上午，事件营销因此必须"轻快爆"——内容轻、媒介选线上、发力速度超过大众预期；好广告可以打磨半年，事件不行，速度优先于完美。
2. 设计任何一场事件战役，先跑五爆点检查链，逐项过、缺项不过就放弃：
   - 热点：借势公众情绪，判断这个情绪是否可借、有没有踩道德线；
   - 爆点：5 字以内的双井号主题词+统一视觉符号，先占住表达位（如 #逃离北上广# #Beat U#）；
   - 卖点：事件全程锚定品牌核心卖点，防止流量外溢——"事件火了但没人知道品牌"是最大尴尬，宁可牺牲创意趣味；
   - 槽点：主动预埋可控槽点（如一个错别字），把吐槽方向引向设计好的位置，借段子手保热度再收割；
   - 节点：安排周二至周四出街，竞争型话题选周四，周末易遇冷。
3. 路线决策先行：借势（拼速度、投入小、成功率高）优于造势（无中生有、投入大、易沦为自嗨）；造势只适合准备充分、可控性强的权威大品牌。
4. 预算形态遵循"小活动，大传播"：线下投入不必大，把传播成本放在线上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 神州专车"Beat U"造势
- **问题**: 创牌期"安全"定位用教育型硬广告投放，效果一般、被用户认为小题大做。
- **方法论的使用**: 以安全定位为锚造势——多位当红明星公开质疑对手 C2C 模式不安全，当天登微博热门榜第一；遭大量围攻后舆论反转（"姿势也许不对，但观点很正"），当晚道歉+发券收尾，全程锚定"安全"卖点。
- **结论**: 事件必须绑定明确且对消费者有益的卖点，攻击型传播是双刃剑；转化承接（发券）要在事件内闭环。
- **结果**: 道歉文章 1 分钟破 10 万+、领券突破 60 万；App 总榜从第 150 位升至第 61 位，月下载量环比增长三倍。

### 案例 2: 闪送"我们是谁"48 小时借势
- **问题**: 闪送预算有限，要同时拿声量和 App 下载。
- **方法论的使用**: 走借势路线——趁《我们是谁？》漫画刷屏，24 小时内出真人版（海报实拍修片、文案接地气）；再用约一天让海报登陆写字楼电梯与户外广告牌，形成 48 小时两波操作，底部带下载承接。
- **结论**: 借势拼的是速度与执行密度，不是创意体量；品效可以合一。
- **结果**: 据企业内部统计，两天 App 下载超 3 万，活跃度与移动端下载量双暴增，获评多家媒体年度事件营销。

### 案例 3: 网易新闻×饿了么"丧茶"快闪店
- **问题**: 要做一场低成本高声量的品牌事件。
- **方法论的使用**: "小活动，大传播"——把网络吐槽段子落地为仅 4 天的快闪店：改造一家现成奶茶店（成本低）、黑白丧系命名与装修、6 款"你的人生就是个乌龙玛奇朵"式丧爆单品菜单（天然易晒单转发）、羊驼网红代言。
- **结论**: 线下投入小（超 2000 人已算大活动），传播引爆放在线上。
- **结果**: 半天出圈、刷屏 2017 年夏天，成为年度事件营销经典案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 有明确事件/节点要引爆：新品上市、周年庆、大促节点、热点事件跟进，要策划一场完整 campaign。
2. 跟进决策："竞品昨天爆了个大新闻/某热点刷屏了，我们要不要跟进？"——需要检查链与路线判断。
3. 事件方案评审：主题词长度、视觉符号统一、要不要埋槽点、出街日期怎么选。
4. 效果预期管理：老板担心"热闹一场没人记得是我们品牌干的"，要防流量外溢。

### 语言信号 (用户的话里出现这些就应激活)

- "事件营销""策划一场引爆/刷屏活动""campaign 怎么排期"
- "借势还是造势""要不要跟进这个热点""五爆点"
- "埋槽点""防杠""怕火了没人记得品牌""周二周四发布"
- "event marketing, campaign launch, hijack the trend, buzz"

### 与相邻 skill 的区分

- 与 `social-content-light-fast` 的区别: CL13 管日常社媒内容生产与轻量借势（发海报、发内容，无战役属性）；本 skill 管一次性事件战役的完整策划与排期（有明确事件/节点、多方资源、五爆点检查、预案）。日常发内容→CL13；策一场战役→本 skill。
- 与 `livestream-imbt` 的区别: 直播这一形式的完整项目执行（脚本、福利、技术保障）归 CL18；本 skill 是事件通用程序，直播只作为其媒介选项之一。
- 与 `traditional-ad-conversion` 的区别: 已投放的传统广告怎么配事件防"墙纸化"（广告公关化）归 CL07；本 skill 管事件本体的策划、排期与检查。

## E — 可执行步骤 (Execution)

1. **路线决策：借势还是造势**
   - 完成标准: 写明路线与理由——预算少/时效紧→借势；准备充分、可控性强、预算厚→才考虑造势。
   - 判停条件: 借势窗口已过（热点过了半衰期）→ 放弃或转日常内容（`social-content-light-fast`），不硬做。

2. **跑五爆点检查链（逐项过）**
   - 完成标准: 五项各有结论与证据——热点（公众情绪可借、不踩道德线）、爆点（5 字内主题词+统一视觉符号）、卖点（事件与品牌核心卖点强相关，无关即不跟）、槽点（预埋可控吐槽方向）、节点（周二至周四，竞争型话题选周四）。
   - 判停条件: 任何一项不过→放弃或回炉改造方案，不带病上会。

3. **排期与预案**
   - 完成标准: 倒排出街时间（速度>完美）；争议型事件必备道歉/回应预案；备好转化承接（下载、领券、搜索关键词），确保流量有出口。

4. **效果验收（双口径）**
   - 完成标准: 复盘报告同时含声量口径（阅读、话题量）与品牌/转化口径（品牌搜索指数、下载、领券、成单），并回答"流量有没有外溢"——热度是否真的导向了卖点与转化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 日常内容运营、无事件属性的轻量借势发图——归 `social-content-light-fast`，套用战役流程是杀鸡用牛刀。
- 没有明确卖点关联、只想"搞个大新闻"——检查链第③项（卖点）不过，本方法论自己会否掉这个方案。
- 借灾难、伤亡等道德敏感热点造势——检查链第①项直接否决。

### 作者在书中警告的失败模式

- 流量外溢（反例 x23）: 斯巴达勇士（品牌主甜心摇滚沙拉被忽略）、"逃离北上广"（舆论焦点指向创意方新世相，品牌主像在买单）、"心中有沙"（途牛被当成网友恶搞）——事件火了、流量爆了，但关注点聚焦事件本身或创意方。作者警告：必须始终紧跟核心卖点，"即使会牺牲一些创意的趣味性，也比事件火了但品牌没人知道带来的尴尬要好"。
- 造势自嗨（反例 x24）: 造势型事件投入大、风险大，"有多少事件营销最终都沦为一场广告主和代理商的自嗨"；追热点的大忌是犹豫。

### 作者的盲点 / 时代局限

- 舆论反转不可设计: Beat U 的成功依赖"围攻后理性反转"的偶然性，书中把偶然写成了可控流程；攻击型/争议型营销在当期舆论与平台治理环境下风险显著更高，须谨慎评估。
- 大预算底色: 神州造势背后是明星阵容+全国性媒介投放，"轻快爆"的"轻"在神州案例里并不轻，小盘团队不能直接对标其打法量级。
- 速度与阵地已变: 热点半衰期进一步缩至小时级，传播主阵地迁至短视频平台；"埋槽点"等公关手法在当期环境的容忍度更低。
- **时效警示（内嵌）**: 本书为 2018 年快照——热点节奏、平台话题机制、周二至周四的媒介节奏均已改变；"轻快爆+五爆点+卖点锚定"的检查逻辑层保留，渠道、话题玩法与节奏参数须按当期平台重查。

### 容易混淆的邻近方法论

- 泛"蹭热点技巧": 本书增量是可否决方案的检查链（五爆点任何一项不过即放弃），不是创意灵感集。
- 危机公关: 方向相反——埋槽点是主动制造可控吐槽，危机公关是被动应对负面；负面舆情处置不在本 skill。
- 广告公关化（CL07）: 为已投放广告配事件是"事件服务广告"；本 skill 是事件本体策划，两者常配合但归属不同。
