# 小米创业思考 · [`xiaomi-startup-thinking/`](./)

- **作者**：雷军 / 徐洁云（执笔）· 2022（中信出版集团；创始人方法论自述，含 IPO 公开信与四篇年度演讲附录）
- **主题**：创业方法论 / 效率模型 / 爆品模式 / 互联网七字诀
- **一句话**：小米 12 年只做了一件事——用互联网方法改造制造业、推动效率革命：把"感动人心、价格厚道"从口号变成可计算的模型（ROI=利润率×周转）、可执行的纪律（七字诀）和可制度化的承诺（硬件净利率红线），方法论的价值超过公司本身。
- **Skills**：17 个（全部通过跨域/预测力/独特性三重验证与独立盲测压力测试，102/102 用例通过）

## Skills 清单

**效率与定价算账**
- [`efficiency-accounting`](./skills/efficiency-accounting/SKILL.md) — 效率算账：ROI=（毛利率–费用率）×周转次数、定倍率诊断、定价五分项
- [`impossible-triangle-model`](./skills/impossible-triangle-model/SKILL.md) — 不可能三角复合模型：感动人心×价格厚道×合理盈利（铁人三项小费模式）
- [`new-retail-efficiency`](./skills/new-retail-efficiency/SKILL.md) — 新零售效率：货权归属判定、渠道 ROI 算账、试点养店纪律
- [`cost-performance-philosophy`](./skills/cost-performance-philosophy/SKILL.md) — 性价比哲学：产品战略而非定价手段；高价是结果不是手段

**爆品模式**
- [`hit-product-judgment`](./skills/hit-product-judgment/SKILL.md) — 爆品判定：单款、精品、海量、长周期四特征+三产生条件
- [`hit-product-system`](./skills/hit-product-system/SKILL.md) — 爆品打造体系：四要素流程+80/80 产品定义取舍

**七字诀决策纪律**
- [`one-core-business`](./skills/one-core-business/SKILL.md) — 一元核心律：核心业务一元化、业务三问、"+"改"×"
- [`optimal-solution-excellence`](./skills/optimal-solution-excellence/SKILL.md) — 最优解极致：每个技术世代做到能力极限+防自嗨三问
- [`speed-four-abilities`](./skills/speed-four-abilities/SKILL.md) — 快的四能力：洞察/响应/决策/改善，战略快不得战术慢不得
- [`sunk-cost-restart`](./skills/sunk-cost-restart/SKILL.md) — 方向性错误推倒重来：沉没成本当学费（红米一代 4000 万打水漂）

**用户与口碑**
- [`word-of-mouth-design`](./skills/word-of-mouth-design/SKILL.md) — 超预期口碑设计：全触点总和，只有超预期才有口碑
- [`word-of-mouth-verification`](./skills/word-of-mouth-verification/SKILL.md) — 口碑验证三原则：阈值律、失真识别、刻舟求剑防范

**战略与终局**
- [`endgame-reasoning`](./skills/endgame-reasoning/SKILL.md) — 终局思维三层推论：业务终局→行业终局→用户期待（造车决策）
- [`new-business-three-pits`](./skills/new-business-three-pits/SKILL.md) — 新业务三大坑自检：认知错位、惯性思维、偶像包袱
- [`downturn-remediation`](./skills/downturn-remediation/SKILL.md) — 低谷补课：先补能力再谈故事，交付/创新/质量三抓手

**治理与组织**
- [`values-into-governance`](./skills/values-into-governance/SKILL.md) — 价值观制度化：把承诺写进法律/治理文件（5% 净利润率决议）
- [`minority-stake-empowerment`](./skills/minority-stake-empowerment/SKILL.md) — 生态链赋能：投资不控股、帮忙不添乱、赋能清单
