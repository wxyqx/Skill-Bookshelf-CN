# GLOSSARY —《小米创业思考》候选术语（glossary-extractor 产出）

说明：type 均为 term；source_chapter 为作者正式阐述该词的章节；author_definition 取书中定义或紧贴原文的转写；key_distinction 采用"≠X / =Y"格式，标注作者用法与常识/字典用法的差异。

```yaml
- id: g01
  term: 七字诀
  type: term
  source_chapter: 第五章、第六章
  author_definition: 互联网思维的最高概括——专注、极致、口碑、快。曾有第一版"互联、全天候、快速"，后向本质淬炼为四字；其核心表达是效率，落脚点是信任。四字间有因果链：资源有限→专注→极致→打动用户形成口碑→快速响应改善。
  key_distinction: ≠"互联网公司才适用的行业口号" / =既有商业准则（边际成本递减、免费、注意力经济）在新技术条件下的极致放大，可操作化的决策规则集，适用于一切行业
  why_it_matters: 七字诀 skill 与几乎所有下游 skill 都以此为主轴；不澄清"观念非技术、四字有因果链"，各 skill 会把四字当成并列口号而失去推理结构。
  tags: [方法论主轴, 互联网思维, 全书骨架]

- id: g02
  term: 爆品
  type: term
  source_chapter: 第九章（另见第十二章生态链）
  author_definition: 产品力超群、一流口碑、海量长销。可观察特征为"单款、精品、海量、长周期"四项，且四项是"体检指标"（结果）而非原因；爆品靠完整模式和体系打造，不靠营销。产生三条件：高效工业化大生产、大众消费能力定价、体验导向创新。
  key_distinction: ≠出货量大、性价比高、技术领先、标王式营销热卖（四个认知误区） / =单款海量长周期+全面优秀外加至少一方面杰出的体系结果
  why_it_matters: 爆品判定 skill 的核心判据；下游效率模型、生态链、新零售 skill 均引用"四特征是结果非原因"这一澄清，否则会误把销量当目标反推打法。
  tags: [产品战略, 判定标准, 高频引用]

- id: g03
  term: 铁人三项
  type: term
  source_chapter: 第一章（起源）、第十章（模型化）
  author_definition: 硬件+新零售+互联网服务的复合商业模式。以用户为核心形成闭环飞轮：硬件贴近成本定价获客，互联网服务赚"小费"提供利润，本质是互联网效率对三个环节的贯通。创立时是对手全是纯硬件公司的颠覆空隙。
  key_distinction: ≠"三块业务并列经营" / =以用户为中心的交叉补贴闭环模型，硬件是获客载体、服务是利润来源，缺一环即不成立
  why_it_matters: 效率模型、定价、生态链、造车决策等多处 skill 引用；须澄清"飞轮闭环"属性，避免下游把小米误读为多元化集团。
  tags: [商业模式, 交叉补贴, 高频引用]

- id: g04
  term: 性价比
  type: term
  source_chapter: 第八章（开市客论证）、第十章、第十四章
  author_definition: 同等性能价格最低的比较优势，而非绝对低价；"便宜"须有理由。性价比不是定价策略而是产品战略与商业修养，必须有高效率的完整体系支撑才能成立（开市客一度濒临破产证明其难度）。
  key_distinction: ≠便宜、低价、性价比=偷工减料 / =比较优势（性能/价格比在同档显著领先），是能力与修养问题而非竞争手段
  why_it_matters: 澄清"小米=低价"是全书最高频误读；定价、高端化、爆品 skill 都依赖"比较优势+体系支撑"双重限定。
  tags: [定价, 高频误读, 核心概念]

- id: g05
  term: 效率革命
  type: term
  source_chapter: 前言、第十章、附录（2018年公开信）
  author_definition: 中国商业的普遍问题不是生产成本（仅约10%），而是运营/交易成本（约90%，定倍率高达5-20倍）；效率革命即砍中间环节与定倍率，而非压榨供应商。小米模式="创新+效率"的加强型性价比模型。
  key_distinction: ≠降本增效、压低成本 / =向90%的交易成本开刀的结构性改造，"好东西越做越便宜"是伟大公司的共性
  why_it_matters: 全书第一性原理（效率给最多人带来最大幸福）的载体；ROI 算账、新零售、行业诊断 skill 均以此为总纲，须区分"10% vs 90%"的诊断对象。
  tags: [第一性原理, 效率, 总纲]

- id: g06
  term: 口碑
  type: term
  source_chapter: 第六章（口碑篇）
  author_definition: 只有超过用户预期的产品/服务才产生口碑（预期是相对值，须对同业可比档位保持显著比较优势）；口碑是衡量产品与服务的终极标准，领先于销量和利润，是与业务形成正循环的第一要件；口碑=产品+服务+沟通全触点的总和（全栈口碑）。
  key_distinction: ≠好产品自动有口碑、≠营销出来的好评 / =超预期的结果，且是"第一指标"而非销量利润的滞后结果
  why_it_matters: 口碑与用户信任 skill 的核心；"超预期是唯一来源"与"全触点总和"两个澄清直接决定下游 skill 的诊断与设计规则。
  tags: [用户关系, 判定标准, 高频引用]

- id: g07
  term: 生态链模式
  type: term
  source_chapter: 第十二章
  author_definition: 用"投资+孵化"（占股不控股）把小米模式复制到100个行业：小米输出产品定义、设计、供应链、渠道赋能，创业者保持独立，"用别人的专注成就自己的生态"，是"兄弟公司舰队"而非控股帝国。
  key_distinction: ≠控股收购、财务投资、代工贴牌 / =占股不控股+全方位赋能的共生结构（竹林效应），双方各取所长
  why_it_matters: 生态链与赋能 skill 的基座；"占股不控股+赋能清单"是可迁移的治理设计，不澄清会被误读为普通战略投资。
  tags: [生态, 投资孵化, 组织设计]

- id: g08
  term: 终局思维
  type: term
  source_chapter: 第十四章（造车决策示范）
  author_definition: 大额新业务决策法，三层推论：①该业务对公司业务终局的影响；②行业终局形态的判断；③决策的根本检验依据是用户期待。造车即由此推论：手机存量竞争、汽车消费电子化终局前五名拿80%份额、用户期待"敢造必买"。
  key_distinction: ≠长期规划、≠"风口跟风" / =从终局形态倒推当下必答性（why now）的结构化决策程序，根本检验锚在用户期待
  why_it_matters: 大额新业务决策 skill 的核心框架；须强调"用户期待是根本检验依据"这一层，否则会退化为普通行业分析。
  tags: [决策方法, 新业务, 造车]

- id: g09
  term: 技术为本
  type: term
  source_chapter: 第七章（亦为三大铁律之一）
  author_definition: 小米第一属性是科技公司，安身立命之本必须是技术。"科技公司"与"高效率交付科技产品的公司"的本质区别：不是拿来主义拼贴供应商方案，而是吃透、主导关键技术环节；是否自产零组件并非关键，对关键技术环节的把控力才是关键。
  key_distinction: ≠自研一切、自产零组件 / =对技术方向、设计方案、关键细节的主导权与把控力（可联合定制、可借上游）
  why_it_matters: 技术投入路径 skill 与三大铁律推导链（技术为本→工程师文化→极致产品→爆品→性价比模型→用户信任）的起点；防止把"技术为本"误读为全栈自研。
  tags: [三大铁律, 技术战略, 澄清误读]

- id: g10
  term: 和用户交朋友
  type: term
  source_chapter: 第八章
  author_definition: 互联网时代的群众路线。用户天然不信任商家但信任朋友，故把商业关系重构为朋友关系：明码实价、只赚"小费"式合理利润、不坑人；检验标准是"敢不敢让用户知道你赚了多少钱"。不是粉丝经济，而是信任经营。
  key_distinction: ≠粉丝经济、流量经营、营销话术 / =群众路线式的信任经营，动作（社区、参与感）可复制，长期一致的诚意不可速成
  why_it_matters: 用户关系、口碑、新媒体运营类 skill 共用的价值基座；"朋友≠粉丝"的区分决定下游 skill 是做转化设计还是信任设计。
  tags: [用户关系, 价值观, 澄清误读]

- id: g11
  term: 定倍率
  type: term
  source_chapter: 第十章
  author_definition: 零售价/成本的倍数。行业参考值：服装10-20倍、鞋5-10倍、化妆品20-50倍。定倍率衡量一个行业的效率损耗空间，定倍率异常高的行业即是效率革命的机会区；多数企业在10%的生产成本里抠搜，却不对90%的交易成本开刀。
  key_distinction: ≠毛利率、≠加价率（财务口径） / =行业级效率诊断工具（零售价/成本），用于定位"中间环节损耗"
  why_it_matters: 行业诊断与 ROI 算账 skill 的入口工具；给出具体参考倍数，可作为下游 skill 的量化判据。
  tags: [效率工具, 定量指标, 行业诊断]

- id: g12
  term: 分摊成本
  type: term
  source_chapter: 第十章
  author_definition: 商品定价由五项分摊成本+利润构成，关键在"分摊"而非绝对值。爆品的单款海量长周期把固定成本分摊到极低，量大则边际成本近乎免费；研发分摊成本是效率指标而非投入指标。
  key_distinction: ≠绝对成本、≠研发投入总额 / =固定成本被销量摊薄后的单位成本，"量大则边际成本近乎免费"
  why_it_matters: 反驳"小米低价=没研发投入"的关键澄清；定价、爆品、创业后发制人（不被巨头投入规模吓倒）类 skill 都依赖此区分。
  tags: [效率工具, 定价, 澄清误读]

- id: g13
  term: 货权归属
  type: term
  source_chapter: 第十一章（新零售）
  author_definition: 看零售链条中货是谁的：货权在厂商手中，厂商与渠道商才是合作而非博弈关系，才能做到交易即数据、实时管理、高周转低容错；货权层层转移（压货模式）必然沦为博弈，以牺牲用户利益和累积系统风险为代价。2018年线下扩张失败主因之一即货权外放。
  key_distinction: ≠渠道管理技巧、加盟政策 / =判定厂商-渠道关系本质（合作 vs 博弈）的第一变量，是数据、周转、管控的制度前提
  why_it_matters: 新零售与渠道设计 skill 的核心判据；"先看货权"是一个可迁移的单一诊断动作，下游 skill 必引。
  tags: [新零售, 渠道, 诊断工具]

- id: g14
  term: 竹林效应
  type: term
  source_chapter: 第十二章
  author_definition: 生态链企业的生长类比竹林：以投资为纽带输出方法论+全方位赋能（产品定义、设计、供应链、渠道），让每个团队专注在一件事上，用并行的小团队而非单一大组织实现最快业务布局；单根竹子生命周期有限，竹林则生生不息、快速蔓延。
  key_distinction: ≠集团多元化、内部事业部 / =投资纽带+独立团队+方法论复制的生态生长方式，与"占股不控股"配套
  why_it_matters: 生态链 skill 解释"为何不自己做"的组织逻辑；与 g07 生态链模式配套，避免下游把生态链误读为品类扩张。
  tags: [生态, 组织设计, 类比概念]

- id: g15
  term: 小费模式
  type: term
  source_chapter: 第五章（Costco 类比）、第八章、第十章
  author_definition: 互联网商业是"厚予薄取"：像开市客以低毛利+会员费盈利一样，先建立服务信任，再赚取用户愿意支付的"小费"式合理利润；硬件贴成本获客、互联网服务提供利润即此逻辑。2017年讨论会员费而不推即此原则的应用。
  key_distinction: ≠免费模式、≠羊毛出在羊身上的隐形收费 / =先予后取、明示的合理利润，与"和用户交朋友"（敢让用户知道赚多少）互为表里
  why_it_matters: 商业模式与用户信任 skill 引用；澄清"小费=主动克制的利润"而非隐蔽收费，是信任叙事成立的前提。
  tags: [商业模式, 利润观, 用户信任]

- id: g16
  term: 参与感
  type: term
  source_chapter: 第一章（MIUI 冷启动）、第八章
  author_definition: 把用户变成"10万人规模的开发团队"：100个梦想赞助商、用户投票决定功能优先级、爆米花奖与猪头奖的即时奖惩、内测/开发/稳定三版分级；新媒体时代全员（合伙人到工程师）硬性规定直面用户，参与感带来归属感，先有倾听与参与才有"自来水"式口碑。
  key_distinction: ≠用户运营活动、社群营销 / =让用户进入产品创造过程的机制设计，是口碑与信任的杠杆源头
  why_it_matters: 冷启动、社区运营、口碑类 skill 的机制库；须澄清其"生产机制"属性而非"营销手段"，否则下游会做成活动策划。
  tags: [用户参与, 冷启动, 机制设计]

- id: g17
  term: 风口上的猪
  type: term
  source_chapter: 第一部分引言（第一章）
  author_definition: 被普遍误读的作者原话。本意是放低姿态、顺势而为、苦练基本功——风口只属于有准备且有能力的企业；猪的比喻重心在"把握时机需要积累的能力"，而非"运气+投机"。小米起落三阶段的复盘框架由此展开。
  key_distinction: ≠投机跟风、躺赢运气 / =顺势而为的前提是苦练基本功，"风来了猪能飞"是自嘲式的谦辞而非方法论
  why_it_matters: 全书最高频被断章取义的词；机会判断、顺势而为类 skill 必须先纠正本义，否则会输出与作者本意相反的投机建议。
  tags: [澄清误读, 顺势而为, 高频误读]

- id: g18
  term: 不可能三角
  type: term
  source_chapter: 第十章
  author_definition: 产品感动人心、价格极其厚道、公司有合理盈利——传统认为三者只能取二；小米模式的解是复合模型而非单点取舍，核心公式为投资回报率=（毛利率–费用率）×年周转次数，靠硬件+新零售+互联网交叉补贴打破。
  key_distinction: ≠"三选二"的死局 / =用复合商业模式+周转效率打破的伪三角，解在模式设计而非单点妥协
  why_it_matters: 效率公式与定价 skill 的理论支点；"ROI 公式是三角的解"这一联结是下游算账 skill 的推理核心。
  tags: [效率模型, 定价, 核心概念]

- id: g19
  term: 溢价模型 / 性价比模型
  type: term
  source_chapter: 后记、第十四章
  author_definition: 世界上只有两种公司模型。溢价模型依赖信息不透明与超额利润，高溢价必然导致高成本低效率，作者判定为"不归路"；性价比模型克制贪婪、艰难但一旦领先极具韧性和穿越周期能力（沃尔玛、开市客、优衣库、宜家）。小米是"创新+效率"的加强型性价比模型，性价比还是创新的加速器。
  key_distinction: ≠按行业/产品分类 / =按"利润来源"对公司做二分：靠信息不透明+超额利润 vs 靠效率+克制贪婪；高端化=不做高溢价但做高用户价值
  why_it_matters: 公司模型判断框架是下游多个 skill 的元框架；"高端化≠溢价"的区分直接支撑小米高端化战略 skill 的立论。
  tags: [公司模型, 二分框架, 高端化]

- id: g20
  term: 三大铁律
  type: term
  source_chapter: 第四章（确立）、第十四章（展开推导）
  author_definition: 2020年8月十周年半年大反思的产出：技术为本、性价比为纲、做最酷的产品。回答"企业靠什么活、走什么路、靠什么赢"三个根本问题，铁律"永不更改"；配套三大策略（重新创业、互联网+制造、行稳致远）则随势而变。推导链：技术为本→工程师文化→极致产品→爆品→性价比模型→用户信任。
  key_distinction: ≠价值观口号 / =从"企业生存之问"推导出的不变约束，与"随势而变的策略"构成两层制度设计
  why_it_matters: 价值观制度化 skill 的范本（铁律 vs 策略的分层）；推导链同时是 g01/g04/g09 术语的结构性索引。
```
