# 性价比哲学——性价比是产品战略，高价是结果不是手段

## R — 原文 (Reading)

> 没有技术的创新、设计的进步、体验的提升，就会陷入片面追求低价的低水平竞争，这是"制造业的低效内卷"，会消耗大量的资源，导致制造业和消费者都无法获得更大的收益。
>
> — 雷军/徐洁云，《小米创业思考》第九章 爆品模式

---

## I — 方法论骨架 (Interpretation)

性价比的正确定义是"比较优势"——同等性能价格最低、同等价格性能最好——而不是绝对低价。它不是一种定价技巧，而是一个产品战略：先检查是否拥有完整能力体系（爆品单款海量摊薄固定成本、高效营销与渠道的低费用率、高周转效率），体系不支撑的低价只是低效内卷，短期可做、长期必败。所以任何降价决策前先算"体系账"，不支撑就先补体系再谈价格。

同一哲学向高端化延伸：正确的问法不是"坚持性价比能不能做高端"，而是"在坚持性价比的同时怎么做高端"。答案是体验优先——从性能领先走向体验优先，用体验增量赢得高端。高价只能是用户价值提升的结果，永远不能当作手段：一个提价方案如果给不出对应的体验增量，手段就是错的；且高端化是集团品牌的整体战略（品牌、用户、产品三要素同步），不可能靠单一品类提价实现。

## A1 — 书中的应用 (Past Application)

### 案例 1: Redmi 98 英寸巨屏电视——19999 元是性价比还是"违背性价比"
- **问题**: 2020 年 Redmi 98 英寸电视定价 19999 元，同期同尺寸进口巨屏约 15 万元，被质疑"这么贵还谈什么性价比"。
- **方法论的使用**: 用比较优势定义回应——BOM 约 25000 元加配送安装约 2000 元，成本高于售价；靠爆品单款海量摊薄与高效率体系支撑定价，这是"同等性能价格最低"而非绝对低价，"便宜"须有理由，"贵"也可以有理由。
- **结论**: 性价比由体系账与比较基准决定，与绝对价格高低无关。
- **结果**: 全行业 98 英寸电视月销 78 台被放大到小米单品牌月销 5000 台，2022 年降到 16999 元，98 英寸成为行业竞争热点。

### 案例 2: 高端化的问法纠正——"坚持性价比的同时怎么做高端"
- **问题**: 内部与舆论反复追问"坚持性价比能做高端吗"，高端化方案屡屡滑向单纯提价。
- **方法论的使用**: 把问题改写为"在坚持性价比的同时怎么做高端"；确立高价是高端的必要感性认知之一、是结果而非手段；高端化必须集团整体推进（品牌、用户、产品统一战略），指导思路从性能领先走向体验优先。
- **结论**: 提价方案给不出体验增量即手段错误，应驳回。
- **结果**: 小米 10 系列定价突破 4000 元档以体验取胜，成为高端化首个立足点；"不做高溢价但做高用户价值"被确立为高端化总纲。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队争论要不要降价、打价格战、以五折低价抢市场，需要判断低价能否长期健康运转。
2. 用户/客户质疑"性价比品牌=低端=没技术"，需要校正性价比的定义与辩护逻辑。
3. 子品牌或单品类提出提价方案冲高端，需要检验"高价是结果还是手段"以及是否具备集团级推进条件。

### 语言信号 (用户的话里出现这些就应激活)

- "性价比是不是就是便宜""低价/价格战能不能长期打"（value for money / price war）
- "同等配置比谁家便宜多少"式的对标讨论、比较优势
- "提价 30% 冲高端、高端化、premiumization"且品牌立身之本是性价比

### 与相邻 skill 的区分

- 与 `efficiency-accounting` 的区别: 那是（毛利率–费用率）×周转的数值算账工具，回答"这单赚不赚钱"；本 skill 是战略立场与判定——性价比是什么、低价是否可持续、提价是否成立，算账只是其中一个输入。
- 与 `hit-product-judgment` 的区别: 那是用单款/精品/海量/长周期四特征做事后体检；本 skill 关注价格哲学与高端化因果，产品形态本身不是焦点。
- 与 `impossible-triangle-model` 的区别: 那是把互斥目标改写为复合结构设计的解题法；本 skill 是性价比的立场定义与高端化判定，不处理目标冲突结构。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **校准性价比定义**
   - 完成标准: 把讨论锚定为比较优势（同等性能价格最低/同等价格性能最好），明确对标物与同档比较基准；若讨论对象是绝对低价内卷，先指出再纠正。

2. **算体系账**
   - 完成标准: 对分摊成本结构（单款海量摊薄）、渠道与营销费用率、周转效率三项逐一给出数据或缺口结论；三项不支撑该价位长期健康运转时，结论必须是"先补体系再谈价格"，而非放弃低价或硬撑低价。
   - 判停条件: 若用户只是要做具体 ROI 数值测算，转交 efficiency-accounting 类工具后停止。

3. **高端化提价检验（如涉及提价/冲高端）**
   - 完成标准: 逐项检查——①体验增量是否存在且可描述（给不出即手段错误，驳回提价）；②是否单品类提价（是则指出必须集团品牌+用户+产品三要素同步）；③高价是否被表述为"结果"而非回款/调性手段。

4. **输出结论**
   - 完成标准: 给出"可做/不可做/先补什么"的明确判定，附体系缺口清单或体验增量要求。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯财务测算：给定毛利率、费用率、周转数据求 ROI 数值——那是算账工具的活，本 skill 只提供战略判定。
- 以信息不透明与品牌溢价为立身前提的行业（奢侈品、收藏品）——本书"溢价模型是不归路"是对性价比模式的立场宣示，不能强加于选择溢价模型的业务。
- 不涉及价格与价值关系的纯产品功能讨论。

### 作者在书中警告的失败模式

- 把性价比做成绝对低价：用减配、压榨供应链和营销噱头实现低价，没有创新支撑的低价既无口碑也无利润，陷入"制造业的低效内卷"（对标逻辑变成"别人卖多少我们便宜多少"，复购与推荐率持续低于均值）。
- 提价无体验支撑：把提价当高端化手段，单品价格上去了而体验增量缺位——手段错误，口碑反噬。

### 作者的盲点 / 时代局限

- 性价比立场的价值宣示色彩："性价比是商业修养""溢价模型是不归路"是价值判断而非被证明的命题，对"品牌溢价支撑创新投入"的严肃反例处理不足。
- 数据口径：效率与成本优势数据均出自小米自述，无第三方口径。
- 幸存者叙事：以小米与开市客等成功样本归纳，低价体系失败的公司未被纳入分析。
- 进行时假设：高端化"以体验取胜"的路径写于 2022，属进行时的未充分验证假设。

### 容易混淆的邻近方法论

- efficiency-accounting：算账工具 vs 战略立场，前者是本 skill 体系账的执行件。
- hit-product-judgment：四特征体检的是产品形态；本 skill 体检的是价格哲学。
- impossible-triangle-model：互斥目标的结构解法，常在本 skill 判定"体系不支撑"后接续使用。
