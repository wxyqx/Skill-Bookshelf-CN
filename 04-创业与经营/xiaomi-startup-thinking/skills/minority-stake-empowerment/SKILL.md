# 生态链赋能模式——投资不控股，帮忙不添乱

## R — 原文 (Reading)

> 我们的原则是"投资不控股，帮忙不添乱"。生态链公司不是小米的子公司，而是独立的实体，是我们的兄弟公司。我们是一支舰队，让每一艘船都能乘风破浪是我们的目标。
>
> — 雷军/徐洁云，《小米创业思考》第十二章 生态链模式

---

## I — 方法论骨架 (Interpretation)

用投资+孵化把自身模式复制到多个行业时，治理结构只占少数股权、不控股。核心逻辑有三层：①控制的代价是创业团队的主动性——创业者不独立发展才是生态最大的失败，所以要鼓励被投企业建立自有品牌、尝试独立发展；②赋能与投资必须双轨分离——产业投资团队管治理与资本关系，工程师团队管产品定义与能力输出，两套人马各管一段，避免投资逻辑绑架产品逻辑；③赋能要落在清单上：产品定义、设计、供应链、推广与销售渠道的全方位支持，同时主动帮被投企业拿第三方订单（包括友商的订单），化解"站队"顾虑、保持其市场独立性。

成功标准反常识：生态的成功不是母公司控制了多少公司，而是被投企业能否独立长大——"只有他们成功了，小米生态链才算成功"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 紫米移动电源——赋能清单的完整落地
- **问题**: 2013-2014 年孵化紫米做移动电源，需要在扶植创业团队的同时把小米的爆品方法论装进去。
- **方法论的使用**: 不控股、只占股；输出产品定义（放弃 99/69 双方案，集中奔向 69 元唯一最优解）、供应链（张峰走 30 个城市找型材厂、开近 200 套模具攻克弧形一体成型工艺）、渠道与定价体系；初期成本 77 元高于售价，宁可倒挂靠海量出货摊薄。
- **结论**: 赋能清单（定义/设计/供应链/渠道）+不控股结构可以同时成立，创业团队保持专注与主动性。
- **结果**: 首月售 60 万只、首年出货破 1000 万只，成为生态链第一款千万级爆品。

### 案例 2: 产业投资的"拿第三方订单"机制（含友商）
- **问题**: 被投企业担心只做小米生意会被绑死、失去其他客户，外部伙伴对"站队"有顾虑。
- **方法论的使用**: 产业投资团队反复强调"投资不控股，帮忙不添乱"原则，只要求少数股份，并积极帮助企业获得第三方订单——不少项目随后获得小米在手机界友商的跟投，成为它们的重要供应商。
- **结论**: 主动帮被投企业进竞品供应链，是把"投资不控股"从口号变成可信承诺的关键动作。
- **结果**: 智能制造与芯片等领域的被投企业实现多客户结构，生态信任与扩张同步推进。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 平台/母公司想孵化外部团队做新业务（智能家居配件、机器人、行业硬件），在设计股权与治理结构，内部争论"不控股怎么保证控制力"。
2. 用户已持少数股权，在思考向被投企业输出哪些能力（定义/供应链/渠道）、如何避免"赋能"变成"添乱"。
3. 被投企业提出建自有品牌、接竞品订单，母公司在纠结放行与否，或被投方抱怨"被生态绑死"。

### 语言信号 (用户的话里出现这些就应激活)

- "投资不控股、帮忙不添乱、占股不控制"（minority stake, no controlling interest）
- "孵化/赋能外部团队，输出供应链和渠道，portfolio empowerment"
- "被投企业想独立做品牌/接别的订单，要不要管"

### 与相邻 skill 的区分

- 与 `one-core-business` 的区别: 那是公司内部核心业务一元化的聚焦律；本 skill 是对外生态治理——恰恰靠"用别人的专注成就自己的生态"，把多元品类交给独立团队而非自己扩张。
- 与 `new-retail-efficiency` 的区别: 那是渠道层级与费用率的效率设计；本 skill 是股权与赋能关系设计，即使被投产品经由自营渠道销售，治理逻辑也独立成立。
- 与 `endgame-reasoning` 的区别: 那是决定"自己要不要下场做新业务"；本 skill 适用于已决定不下场、改用投资孵化复制的场景。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定适用性与赋能清单**
   - 完成标准: 确认这是"能力外输+多行业复制"场景而非纯财务投资；逐项列出可输出的能力（产品定义、设计、供应链、推广、销售渠道），写清每项的输出方式与责任人。

2. **设计少数股权结构**
   - 完成标准: 股比低于控股线，配套董事会席位、否决事项清单等治理条款草案；能回答"不控股靠什么保证质量底线"（靠赋能依赖与共同利益，而非股权）。

3. **投资与赋能双轨分离**
   - 完成标准: 产投团队与工程师/产品赋能团队的职责边界成文，明确投资逻辑（治理、资本运作）不得干预产品定义决策。

4. **写入独立性条款**
   - 完成标准: 允许被投企业建自有品牌、承接第三方订单（含竞品）的条款落实；配套主动帮拿订单的机制设计，把承诺做成可信动作。

5. **设定生态成功标准**
   - 完成标准: KPI 以"被投企业能否独立长大"（独立品牌、独立客户结构、自造血能力）为核心，而非母公司控制力或并表收入。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯财务回报投资：不输出能力、不参与经营的股权投资，套用赋能清单反而添乱。
- 需要强管控的渠道与货权体系：分销/零售网络的管控逻辑走新零售类 skill，两者不能混用。
- 核心技术必须保密自营、不外输的业务：无赋能清单可列，"不控股"会变成失控。

### 作者在书中警告的失败模式

- 无边界扩张反噬专注：生态链 1.0 后期 SKU 过冗、资源过于分散、效率降低，叠加"杂货铺"骂名，2.0 阶段被迫从两个维度重设边界、砍 SKU——赋能模式会自发膨胀品类，必须配套进入/退出边界。
- "去小米化"被误读为背叛：若母公司把被投企业独立发展视为失控，赋能信任即瓦解——作者强调从一开始就开放和鼓励自有品牌。
- 赋能变添乱：投资逻辑干预产品定义，等于用控股者心态做事，违背双轨分离。

### 作者的盲点 / 时代局限

- 幸存者叙事：紫米、华米等成功样本被整编为模式证明，生态链中失败与退出的公司讨论很少。
- "帮忙不添乱"的边界在实操中如何监督，书中缺乏机制化描述，更多依赖关系与自律。
- 进行时假设：生态链 2.0 的边界调整、竹林效应的跨周期有效性，截至 2022 年均属进行时、未经充分验证。

### 容易混淆的邻近方法论

- one-core-business：内部聚焦律 vs 外部生态治理，前者约束自己做什么，后者约束自己怎么与别人共生。
- new-retail-efficiency：渠道效率结构 vs 股权赋能结构。
- new-business-three-pits：自己下场做新业务前的自检；决定不下场改投资孵化时，才轮到本 skill。
