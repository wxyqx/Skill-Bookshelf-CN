- **身份三态**：first-in-mind（抢第一）↔ leader-defense（守第一）↔ challenger-follower（跟随找位）——先用 mental-ladder-diagnosis 判自己在心智阶梯的位置，再选对应 skill。
- **depends-on**：reposition-the-competitor ← mental-ladder-diagnosis（先摸对手心智位置）；own-one-word ← outside-in-perception-first（先认知地基后选词）。
- **contrasts-with**：naming-that-hooks ↔ brand-extension-rules（新名字 vs 老名字沿用）；positioning-six-question-process ↔ mental-ladder-diagnosis（全流程 vs 单点摸底）。
- **composes-with**：country-place + company-institution（目的地与受益企业）；personal-career + naming（个人改名）。

## 推荐阅读顺序

1. 地基：outside-in-perception-first → mental-ladder-diagnosis
2. 选打法：first-in-mind / challenger-follower / leader-defense（按身份三选一）→ reposition-the-competitor
