  type: framework
  source_chapter: 序一

  title: 一词占领心智
  type: framework
  source_chapter: 第1章
  source_quote: |
    "简化信息这个定位观念又进一步发展成我们'一词占领心智'的理论。例如，沃尔沃用的是'安全'一词，宝马用的是'驾驶'，联邦快递是'隔夜到达'，佳洁士是'防蛀'。"
  summary: |
    应对过度传播的核心操作框架：把品牌全部传播浓缩为一个词，长期独占，让品牌成为该词在心智中的代名词。

- id: f03
  title: 由外而内思维（vs 由内而外思维）
  type: framework
  source_chapter: 第1章、第12章
  source_quote: |
    "定位思想的本质在于，把认知当成现实来接受，然后重构这些认知，并在顾客心智中建立想要的'位置'。我们后来称这种方法为'由外而内'的思维。"
  summary: |
    定位的基本推理方法，也是全书贯穿始终的思维方向判据：
    由外而内——不从产品内部寻找解决之道，而到潜在顾客的心智中寻找。步骤：先接受心智中已存的认知（哪怕是偏见），再围绕这些认知重组信息、在心智中抢占或重构一个位置；做命名/延伸决策时，先问"这个名字在顾客心智中代表什么品类"，再看新产品放不放得进去。
    由内而外（反面）——从公司自身（产品、名望、渠道、逻辑）出发推理，如"我们的顾客信任我们，会买我们的延伸产品"，每个推理步骤在公司内部都"合情合理"，却完全违背心智规律，是搭便车、品牌延伸等决策的共同病根，也是营销失败的常见根源。

- id: f06
  title: 心智阶梯/产品阶梯模型
  type: framework
  source_chapter: 第4章
  source_quote: |
    "人们学会了在心智上给产品和品牌分级……想象心智中有一个个的梯子。在梯子的每一阶上是一个品牌名称，而每个梯子代表某一类产品。"
  summary: |
    描述心智存储结构的核心模型：每类产品在心智中是一个梯子，领导者在最高一层，第二名第二层，依次排列；常见三层，最多七层（对应米勒七定律）。
    心智只接受与现有状态相符的新信息，"你看到的是你想看到的""你尝到的就是你想尝到的"（新可乐灾难为证）。
    用法：先诊断目标品牌在心智阶梯上的实际位置和对手位置，再决定策略——向上排挤（通常行不通）、关联挂靠（安飞士）、挂靠替代品（非可乐）、另立新阶梯（新品类）。
    做广告不能"像在真空中"，无视阶梯位置必劳而无功；该模型是全书后续章节（领导者、跟随者、重新定位、品牌延伸、国家阶梯）的几何底图。

  type: framework
  source_chapter: 第4章
  source_quote: |
    "安飞士的广告……是参照市场领导者而建立的定位。'安飞士在租车行业只不过是第二，为什么还找我们？我们工作更努力。'"

- id: f08
  title: 非可乐定位法
  type: framework
  source_chapter: 第4章
  source_quote: |
    "'非可乐'定位法通过把产品与已经占据潜在客户心智的东西联系到一起，把'七喜'确定为可以替代可乐的一种饮料。"
  summary: |
    挂靠定位的变体：不与领导者硬碰，而是把产品定义为已占据心智的强势品类（可乐）的替代品，借对手的巨大心智份额为自己抬轿。
    七喜从年净销售额8770万美元增至1.9亿美元以上，成为世界第三大软饮料。前提是心智中已有强大的可关联对象；同一逻辑也用于电台（WLKW=非摇滚音乐台）。
    第21章复盘：七喜的问题不在柠檬类饮料品类内部，而在心智中可乐的绝对优势——把自己的产品同心智中已有认知相联系才能成功。
    反面警示：后因广告不一致、品牌延伸（金七喜）、只说"不是什么"没说"是什么"，最终在柠檬-青柠品类输给雪碧。

- id: f09
  title: 新品类参照老概念定位法（"不是什么"定位）
  type: framework
  source_chapter: 第4章
  source_quote: |
    "心智不会接受新的、不同的事物，除非其与旧的事物有所关联。……告诉潜在顾客该产品不是什么，往往要比告诉他们该产品是什么还管用。"
  summary: |
    推出全新品类时的方法：心智不接受孤立的新事物，必须用已有的旧概念作参照。
    典型做法是用否定式命名/描述："不用马拉的车"（汽车）、"无铅"汽油、"无内胎"轮胎、"场外"下注、"非可乐"。
    先告诉顾客它不是什么，借助旧阶梯理解新阶梯——这也解释了为什么否定式描述比正面描述更管用。
    与"非可乐定位法"同源但侧重不同：本条针对全新品类的导入，非可乐法针对已有产品对强势品类的替代。
  tags: [new-category, reference-frame, naming]
  origin: [scannerA-fa06]

- id: f10
  title: 无法由此及彼的位置判断
  type: framework
  source_chapter: 第5章
  source_quote: |
    "如果它恰好处在一个'无法由此及彼'的位置上，照样会一败涂地的，花再多的钱也无济于事。"
  summary: |
    战前可行性判断框架：先判断目标位置从当前位置是否可达，再谈投入和努力。
    判断依据：心智阶梯上的相对位置、时机早晚、竞争格局。55岁的副总裁等不到总裁位置，RCA攻不下IBM（1971年2.5亿美元灾难性亏损）——位置错了，执行再好也无效。
    结论：问题不在于"做什么"，而在于"何时做"；尽早建立领导地位才是关键，失败者总以为关键是更加努力（"我能行"精神的陷阱）。
    通用电气史密斯救不了计算机业务、琼斯建议退出反成其功，说明认清"无法由此及彼"并果断止损同样是正确的战略动作。

- id: f12
  title: 领导者保持领先战略体系
  type: framework
  source_chapter: 第6章
  source_quote: |
    "应该同时运用以下两个基本战略。这两个战略看上去自相矛盾，但实际上不是。"
  summary: |
    领导者维护地位的一整套操作：不喊"我们是第一"而宣传品类价值；用潜在顾客的标准（而非自己的标准）确立领导地位；强化最初概念、把品牌塑造成"正宗货"；抓住每一个机会、克制傲气，在新产品扎根心智之前迅速拦截；用多品牌拦截对手；必要时用更宽泛的名称实现业务转型。

    领导者应利用短期灵活性确保长期稳定的未来——成为第一是艰巨的，保持第一却容易很多。

- id: f13
  title: "正宗货"战略
  type: framework
  source_chapter: 第6章
  source_quote: |
    "建立领导地位的主要因素是抢先进入人们的心智。维护领导地位的主要因素则是强化最初的概念，这是评价一切跟随者的标准。"
  summary: |
    每个最先进入心智的产品都会被看做正宗货（IBM主机、亨氏番茄沙司、固特异轮胎、可口可乐）。一旦被看做正宗货，就等于把所有其他品牌重新定位成仿效品。
    "正宗货"是最有力的广告语：强调正统性而非销量第一，把对手的全部宣传降格为"仿冒品的吆喝"。
    应用规则：领导者要持续对新进入市场的消费者宣传领导地位，不可中断（喜力弃用"美国进口啤酒第一"而把地位拱手让给科罗娜的教训）。
  tags: [leadership, advertising, the-real-thing]
  origin: [scannerB-fb02]

- id: f14
  title: 拦截战略（迅速回应）
  type: framework
  source_chapter: 第6章
  source_quote: |
    "要想使拦截行动行之有效，时间是关键。你得在新产品还没有在潜在客户的心智里扎根之前就主动去拦截它。"
  summary: |
    领导者面对竞争对手的新颖概念时不能"等等看"，必须在其扎根心智之前主动拦截：或迅速跟进推出同类产品，或直接压制对手的进攻。如同帆船比赛的拦截战术——绝不让对手摆脱阻拦进入开阔水面。时间差决定拦截成败。
    典型案例：泰诺在Datril降价广告投放前立即跟进降价，击退对手；吉列推出"好消息"一次性双刃剃须刀拦截BIC；柯达与3M以成本逻辑拒绝购买卡尔森静电复印专利，坐失施乐崛起的机会——领导者抓住每一个机会的本质是花小钱防意外。
    与跟随者"跟风"的本质区别在时机和地位：领导者拦截能获利，跟随者跟风不能。
  tags: [leadership, interception, timing]
  origin: [scannerB-fb03]

- id: f15
  title: 多品牌拦截（实为单一定位战略）
  type: framework
  source_chapter: 第6章
  source_quote: |
    "宝洁公司经典的'多品牌'战略，称它为多品牌战略可能用词不当，实际上，它是一种单一定位战略。"
  summary: |

    风险：宝洁后来陷入品牌延伸（50多种佳洁士牙膏），把牙膏领导地位让给了高露洁。

  type: framework
  source_chapter: 第6章

- id: f17
  title: 空位搜索清单
  type: framework
  source_chapter: 第7章
  source_quote: |
    "找出空位，然后填补上去。这个说法与美国精神中根深蒂固的'更大、更好'的理念恰恰相反。"
