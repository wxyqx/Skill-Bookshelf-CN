# Scanner A（front+引言+第1-5章）候选

## 第一部分：章节 digest

### front（致中国读者 + 序一 + 序二）综述（约150字）
序言部分确立了定位理论的战略地位：先胜而后战，胜负在于潜在顾客心智而非市场。序一（邓德隆）将定位列为继泰勒"科学管理"（提升体力工作者生产力）、德鲁克"管理"（提升组织生产力）之后的"第三次生产力革命"，其新生产工具是品牌/心智资源；提出定位四步法（分析外部环境→确立优势位置→信任状→整合进运营）、二元法则、"心智资源是组织的首要资源"等论断。序二（张云）梳理定位理论四个发展阶段（70年代定位、80年代商战、90年代聚焦、新世纪开创新品类），以A模式（聚焦）与J模式（宽泛）的长期赢利对比，论证定位是中国制造转向中国品牌的关键。

### 引言 传播的新方法 / "定位"的定义
本章提出"沟通本身就是问题"：美国已成为第一个信息过度传播的社会，传播的信息逐年增加而被接受的信息逐年减少。作者在此正式给出"定位"的定义：定位从产品开始（商品、服务、公司、机构甚至个人），但不围绕产品进行，而围绕潜在顾客的心智进行——将产品定位于潜在顾客的心智中；最新定义是"如何让你在潜在客户的心智中与众不同"。改名、价格、包装等是装饰性改变而非产品本身改变，目的都是在心智中占领一个有价值的位置。定位始于1972年《广告时代》的"定位时代"系列文章，典型案例有山咖"第三的咖啡"、安飞士"第二但更努力"、霍尼韦尔"另一家电脑公司"、七喜"非可乐"。定位是应对过度传播的第一个思想体系，任何人（推销产品、候选人或自己）都能运用。

### 第1章 到底何为定位
核心论点：定位不是创造新的、不同的事物，而是操控心智中已经存在的认知，重组已存在的关联。因为市场上有太多产品、太多公司、太多营销噪音（中型超市已有四万个SKU），旧的策略不再有效。定位需要新方法的根本答案是"传播过度的社会"：美国人均年广告消费200美元，信息却大多被心智屏蔽；人的心智只接受与既有知识和经验相匹配的信息，"心智一旦形成，几乎不可能改变"。由此推出全书最重要的原则：不要试图改变人类的心智。应对之策是"过度简化的心智"——尽量简化信息，"削尖"信息切入心智，并进一步发展成"一词占领心智"理论（沃尔沃=安全、宝马=驾驶、联邦快递=隔夜到达、佳洁士=防蛀）。传播者的工作不是传播而是筛选，解决之道不在产品中而在潜在顾客的心智中；要接受"传播者是错的，接受方是对的"，把认知当成现实来接受并重构之，即"由外而内"思维。

### 第2章 心智备受骚扰
本章用大量数据论证信息流失的四个来源：传播渠道阻塞（美国人口占世界6%却消费57%的广告；一年新书需17年读完；《纽约时报》周日版50万字需28小时读完）、媒体爆炸（任何能移动的物体都带着广告信息）、产品爆炸（超市从一万种增至四万种商品、45万个有效注册商标、176种香烟品牌、10万种处方药）、广告爆炸（广告效果降低的同时广告投入反而增加，专业人士和机构也开始做广告）。关键结论：心智容量有限（不到一升的容器），早已超出限度；存在"感觉超载"现象——超过极限大脑一片空白。因此"在传播上，多则是少"，只有极小量信息能通过且未必是最重要的。杰里·布朗（人们只知四件事）、康纳利（1100万美元一张选票，"独断专行"的认知无法改变）、雪佛兰（十个易混淆车型名，跌落第二）说明：一旦给人留下第一印象就绝无机会更改。心智就是战场，广告战在仅10多厘米宽的心智灰质层里打响。

### 第3章 进入心智
核心论点：进入心智的捷径是"成为第一"。"当第一胜过做得更好"是迄今最有效的定位观念——柯达、IBM、施乐、赫兹、可口可乐都是同类中第一个进入心智者。这类似动物学的"印刻现象"：第一印象一旦形成难以磨灭；婚姻与商业一样建立在"第一"胜过"最好"之上。第二个进入心智则难得多——屈居第二和默默无闻没什么区别（第二位单人飞越大西洋者无人知晓）。若无法做第一，第二有效的原理是"在另一个领域成为第一"（阿米莉娅·埃尔哈特：第三个飞越大西洋但是第一个女性）。本章回顾广告史三阶段：产品时代（瑞夫斯的USP，被模仿产品毁灭）、形象时代（奥格威的品牌形象长期投资，被跟风公司毁灭）、定位时代（创意不再是关键，必须在潜在顾客心智中占有一个位置；IBM没有发明电脑但第一个建立了电脑定位）。案例：阿美利哥（定位为独立大陆并大量写作，美洲以他命名，哥伦布死于狱中）、米狮龙（第一个在心智中建立"高价国产啤酒"定位）、米勒莱特（开创淡啤品类但输在通用名称）、贝克啤酒（"在德国最流行的德国啤酒"对位卢云堡）。

### 第4章 心智中的小阶梯
核心框架：心智像电脑存储器，为应对产品爆炸，人们把产品和品牌分级——心智中有一个个"梯子"，每阶一个品牌名，每个梯子代表一个品类；常见三层，七层封顶（米勒七定律：普通人的心智不能同时处理七个以上的单位）。心智只接受与现有状态相符的新信息，"你看到的是你想看到的""你尝到的就是你想尝到的"（新可乐灾难：盲测3:1喜欢新配方，看到商标后4:1喜欢经典可乐）。要增加份额，要么排挤梯子上方的品牌（通常行不通），要么把自己的品牌与已有的位置关联起来。两种经典方法：①"关联"定位法——安飞士承认"只是第二，所以我们更努力"，把自身挂在赫兹之下的第二阶，转亏为盈；妙处在于读者自己补出"比赫兹"。②"非可乐"定位法——七喜悄悄爬上可乐阶梯，把自己确立为可乐的替代品，净销售额从8770万美元增至1.9亿以上。新品类要参照老概念定位（"不用马拉的车"）。最后提出FWMTS陷阱："忘记成功之道"——安飞士改口"要当第一"、七喜宣称"美国人人喝七喜"，都是在宣传愿望而非事实，都失败了。成功的定位需要始终如一，坚持数年如一日。

### 第5章 你不能由此及彼
核心论点：许多人、政客和产品恰好处在"无法由此及彼"的位置上，愿望不会成为现实，大量做广告也无济于事。美国"我能行"精神（越战为典型）相信只要足够努力任何事都能办到，但在抢占心智的战争中，位置不对则再努力、再多钱也一败涂地。1969年作者依据定位规则预测"任何公司向IBM业已占据的定位直接发起挑战都不可能获得成功"，1970年RCA全速进军计算机业，1971年即遭2.5亿美元灾难性亏损，通用电气同年放弃计算机业务。教训："不要用事实来挑战认知，赢的总是认知"；与IBM类对手抗衡之道是：①承认现实，②不要做IBM做的事，③利用自己在心智中已占据的位置挂钩计算机业新位置——RCA本应借通信业领先地位定位，NCR借现金出纳机地位做"计算机化现金出纳机"成功，DEC则发明小型机在新品类中做第一。通用电气史密斯（"我能行"式高管）救不了计算机业务，琼斯（现实派）建议退出反成其功。结论：问题不在"做什么"而在"何时做"；尽早建立领导地位弥足珍贵，失败者总以为关键是更加努力。
