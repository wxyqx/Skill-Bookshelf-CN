# Scanner B（第6-10章）候选

## 第一部分：章节 digest

### 第6章 领导者的定位
核心论点：历史上第一个进入心智的品牌，长期市场份额通常是第二名的2倍、第三名的4倍，"只有争得第一才是最有效的营销战略"；领导者地位短期内几乎坚不可摧，光凭惯性就能维持。本章提出领导者保持领先的战略体系：不喊"我们是第一"，而宣传品类价值；用潜在顾客的标准（而非自己的标准）确立领导地位；强化最初概念，把品牌塑造成"正宗货"，从而把其他品牌都重新定位成仿效品；克制傲气、抓住每一个机会，在新产品扎根心智之前迅速拦截；用多品牌拦截对手——它实际上是以不变应万变的单一定位战略；用更宽泛的名称完成业务转型。关键结论：企业的实力来自产品在潜在客户心智中的定位，而非企业规模；领导者不应把对手赶出市场，跟随者是品类的组成部分；两强并驾齐驱的局面本质不稳定，终将形成5:3或2:1的稳定格局（二元法则的雏形）；定位行动的最终目的是在某个品类取得领导地位——成为第一是艰巨的，保持第一却容易很多。

### 第7章 跟随者的定位
核心论点：对领导者有效的方法对跟随者未必有效；跟随者效仿领导者不是拦截而是跟风，是传播过度社会里的致命陷阱；跟随者的最佳战略是在潜在顾客心智中"寻找空位"（cherchez le creneau），这要求逆向思考——人人都朝东走，你要找到往西走的空位。本章给出系统的空位清单：尺寸空位（大众"往小里想"）、高价空位（米狮龙、皇家芝华士、奥维尔雷登巴赫爆米花）、低价空位（Qwip传真机）、性别空位（万宝路男性化、维珍妮女性化）、年龄空位（Aim儿童牙膏、Geritol老人营养液）、时段空位（Nyquil夜间感冒药）、分销空位（L'eggs超市蛋袜）、重度使用者空位（Schaefer啤酒）。关键结论：要找心智里的空位而非工厂里的空位（埃德塞尔、《全国观察家报》的教训）；高价定位必须第一个建立、在广告中而非商店里建立、用真正的差异化支撑；新产品宜低价空位，维修服务不佳的老产品宜高价空位；技术陷阱——心智中没有的空位，实验室成果再好也会失败（干白威士忌Frost 8/80）；公司犯的最大错误是试图满足所有人的需求，不做出取舍就无法取胜。

### 第8章 重新定位竞争对手
核心论点：如今每个品类都有成百上千种产品，空位少之又少，最基本的营销战略必须是"重新定位竞争对手"——要想让新理念或新产品进入心智，必须先把心智里原有的相关观念或产品排挤掉；一旦旧理念被推翻，人们往往会主动寻找新理念填补空白。操作要领：必须对竞争对手的产品有所评论，改变潜在客户对对手（而不是对你自己）产品的认知；绝不要害怕争执，冲突能让人一夜之间建立名声；有效的重新定位宣传具有"两面性"——既说自己又暗讽对手（汉堡王"想怎么吃就怎么吃"）。案例：泰诺重新定位阿司匹林、Scope用"药味"两个字打垮李施德林、皇家道尔顿揭穿雷那克斯的产地、红牌伏特加点破美国伏特加的产地、智慧薯片当众读成分标签打品客。关键结论：重新定位不等于对比性广告——"我们比对手强"存在心理漏洞（"既然你那么强，为什么还没发财？"）；重新定位要公平、合乎道德；人们喜欢看到神话破灭；心智中有一个写着"失败者"的惩罚箱，产品一旦入箱就永无出头之日。

### 第9章 名字的威力
核心论点：名字就像钩子，把品牌挂在潜在顾客心智中的产品阶梯上；在定位时代，你能做的唯一重要的营销决策就是给产品起什么名字——玫瑰如果叫别的名字就不再芬芳。本章提出系统的命名原则：起一个能启动定位程序、告诉潜在客户产品主要特点的名字（海飞丝、苗条、永久、Close Up）；名字要"近乎通用但又不十分通用"，过头就会失去商标专用权（莱特啤酒沦为"米勒淡啤"）；只有当产品全新、需求迫切且第一个进入心智时，才有资格起新创的无意义名字（可口可乐、柯达、施乐）；名字不应掩盖产品本源，克服负面含义的第一步是公开产品本质并改名（人造黄油应为"大豆黄油"、玉米糖浆应为"玉米糖"）；压头韵的名字更易记。关键结论：坏名字是负资产，名字不好情况只会更坏（东方航空、固特里奇）；名字会过时，聪明公司推出新品牌利用变化；改名要"忘记过去"而非"立足过去"（埃克森是最成功的改名）；低热量、低价产品的命名别过头，暗示太露骨会把潜在客户赶跑。

### 第10章 无名陷阱
核心论点：公司放弃全名、启用首字母缩写是一种自杀性行为。本章提出"发音缩写"原则：心智靠耳朵运转，只有当全名音节太多、缩写发音更省力时人们才会使用缩写（RCA、GE、GM），而两者音节相同时人们总是选词不选字母（纽约很少被叫NY）；"心智靠耳朵而不是靠眼睛来运转"是全书最有用的基本观点之一，名字、标题、口号都应从听觉上检验，即使只用在印刷品上。原则"成功无捷径"：只有广为人知之后缩写才有意义（IBM、FDR、JFK都是先出名后用缩写），把因果关系颠倒过来就不管用；因名称过时而改缩写的公司（USM、SCM、CPC）从此销声匿迹。关键结论：首字母缩写从长期看会削弱公司地位；改名若有合理理由，正确方法是"忘记过去"树立全新名字（优耐陆、伊顿、美孚），而不是"立足于过去"拼出USR、EY&T这类怪胎；选缩拼词要小心负面谐音（GAF听上去像gaffe"失态"）和电话簿检索问题。

- id: pb01
  title: 不要广告高呼"我们是第一"
  type: principle
  source_chapter: 第6章
  source_quote: |
    "只要公司拥有第一的位置，就再没有必要去做广告高呼：'我们是第一！'宣传品类的价值要好得多。"
  summary: |
    领导者自夸第一有心理反效果：潜在客户已知你是第一，会觉得你没必要说；不知道你是第一，则会追问为什么。更好的做法是像IBM那样宣传品类的价值（所有类型的计算机），并对新进入市场的消费者持续宣传领导地位（喜力弃用"美国进口啤酒第一"而丢掉地位的教训）。
  tags: [leadership, advertising, dont]

- id: pb02
  title: 用潜在顾客的标准确立领导地位
  type: principle
  source_chapter: 第6章
  source_quote: |
    "不能用自己的标准来建立领导地位，如：'密西西比东部最畅销的、价格低于1000美元的高保真音响。'必须用潜在顾客的标准来确立领导地位。"
  summary: |
    自设口径的"第一"（限定区域、限定价格、限定渠道的最畅销）在心智中无效。领导地位必须以潜在顾客认可的通用标准来确立，否则宣传等于无效。检验标准：普通消费者听到这句话是否承认这是"第一"。

  type: term
  source_chapter: 第6章
  source_quote: |

- id: tb05
