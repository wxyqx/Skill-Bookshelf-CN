  type: framework
  source_chapter: 第9章、第12章
  summary: |

  title: 发音缩写原则（先出名，后缩写）
  type: framework
  source_chapter: 第10章
  summary: |
    判断缩写能否成立的标准是发音省力而非视觉简洁：全名音节多（Radio Corporation of America 12个音节）而缩写少（RCA 3个音节）时，缩写自然流行；两者音节相同时人们总是选词不选字母（纽约很少被叫NY）。公司命名应发音导向，而非视觉导向。
    因果规则（吸收 p32）：只有广为人知之后缩写才有意义（IBM、FDR、JFK都是先因全名出名，看到缩写时人们脑中浮现全称），把因果关系颠倒过来就不管用；为逃避过时旧名而改缩写的公司（USM、SCM、CPC、GAF、TWA）从此销声匿迹或付出惨重代价——首字母缩写从长期看会削弱公司地位。
    个人应用：正在上升期的人需要的是完整名字而不是首字母缩写，只有在人人都认识你时缩写才有效；混淆不清是定位的大敌。

- id: f32
  title: 品牌延伸的心理机制（代名词摧毁）
  type: framework
  source_chapter: 第12章
  summary: |
    强定位品牌的本质是成为品类的代名词——顾客说"来一瓶可口可乐""拜耳放在哪儿"，名字就等于品类；名字像刀尖，能把产品特点挂进心智。品牌延伸打破了这种代名词关系：顾客发现拜耳"只是一种产品名"，于是想买阿司匹林时不再用它指代；延伸产品"是原有品牌名称的卫星"，爬不上自己的阶梯。
    搭便车前奏（吸收 f26）：用公司或知名品牌的现成名命名新产品，动机看似理性（名字已深入人心、省广告费），但名字在心智中已被既有定位占用，新产品借它建立不了自己的阶梯，反而侵蚀原品牌份额（复方Alka-Seltzer没抢到对手市场，反而吃掉自己的份额）。
    使用方法：命名或延伸前先问"这个名字在心智中已代表什么"，若已有定位则必须另起新名。流行根源是"由内而外思维"；判别与检验见购物单/酒保检验法（f35），适用边界见五条行事规则（p40）。

    检验一个名字是否在心智中独立指代某品类的两把快刀：
    购物单检验——把品牌名写上购物单（舒洁、佳洁士、拜耳、Dial），看家人能否准确买回；写"亨氏、Scott、卡夫"就说不清是泡菜还是番茄酱、卫生纸还是毛巾。凡是写在购物单上会产生歧义的名字，说明其延伸已模糊了品类定位。
    酒保检验（吸收 f36）——只报品牌名，看对方能否给出唯一明确的产品：加冰J＆B=苏格兰威士忌，Beefeater=杜松子酒；说"顺风"就分不清是顺风Sark还是顺风12年陈酿。
    统一判据：凡需要附加描述词才能指认的品牌，说明延伸稀释了名字的指代力。

- id: f38
  title: 公司定位路径（产品/运营/行业三领先）
  type: framework
  source_chapter: 第14章
  summary: |
    公司定位的核心是成为领先企业，而领导地位靠"第一个做某事"建立（IBM第一个做计算机、施乐第一个做普通纸复印机），而不是自称领先。
    孟山都案例给出三条可选路径并逐一评估：①产品领先——评估竞争格局，打不过杜邦就放弃；②运营领先（如倡导自由企业）——人人都在谈的风尚领域，放弃；③行业领先——为整个行业代言，无人占位，选定。
    使用方法：先列路径，再用"竞争格局+是否风尚+是否有人已占位"三重过滤；避开"以人为本"与"多元化"两类陈旧主题——定位与多元化南辕北辙，强大定位建立在重大成就而非宽泛产品线上。
    避开风尚（吸收 p42）：人人都在谈论的主题没有占位价值，因为心智里该位置已被议论填满且无人能区分；选公司定位主题前先盘点同行在说什么，专找无人认领的议题。
    公司定位直接关系到招人和股价：公司在三类"买家"（求职者、股民、顾客）心中各有定位。

- id: f39
  title: 行业代言人战略
  type: framework
  source_chapter: 第14章
  summary: |
    当整个行业面临公众误解或攻击、而同行都在沉默时，第一个站出来为全行业辩护的公司就被心智认定为领导者。孟山都以"没有化学物质，生命不可能存在"为化工正名（"生活中的化学常识"系列），公众对化工支持率从36%升到42%，杜邦拨400万美元跟随——跟随行为本身再次确认了孟山都的领导地位。
    回报量化（吸收 p44）："领导地位是可以在银行里兑换成现金的。"只要客户对你有好印象，你就永远比对手做得出色；把公司定位项目当作资产负债表上的无形资产来投资。

- id: f49
  title: 成功六步曲
  type: framework
  source_chapter: 第21章
  summary: |
    启动任何定位项目的六问流程：①你拥有怎样的定位——定位需要逆向思维，从潜在顾客心智而非自己开始，答案从市场中来而非营销经理处，必要时花钱调研（七喜的问题不在柠檬饮料而在可乐的优势）；②你想拥有怎样的定位——"拥有"是关键词（吸收 p53）：找长期可以"拥有"的定位，太宽泛的定位即使建立起来也无法防御更窄定位的攻击（Nyquil对日用感冒药）；个人同理：聚焦做独一无二的专家，不做什么都干的通才；③谁是你必须超越的——不正面攻击市场领导者，绕过障碍比穿过它好；④你有足够的钱吗——建立和保住定位都需要金钱支持，资金有限就一个市场接一个市场地推；⑤你能坚持到底吗——基本战略几乎永不改变，能改变的只是战术与短期行动，定位如同价值连城的不动产，放弃就拿不回来；⑥你符合自己的定位吗——创意一文不值，只有为定位目标服务的创意才有意义。
    六问表面简单实则很难，是对勇气和信念的考验；顺序不可颠倒，先看清处境再找解决之道。

- id: f50

  type: framework

  summary: |

    同时要明确局外人不能提供什么：奇迹。广告公司不能点草成金，若能纺稻草成金他们就不会做广告了。
    使用方法（吸收 p57）：雇得起外脑就借外脑的客观，雇不起就必须学会自己运用局外人式的客观见解；定位决策要排除自我意识，好想法只在相互切磋的气氛中完善。

- id: p06
  title: 由外而内：把认知当现实，从潜在顾客心智中找答案
  type: principle
  source_chapter: 第1章、第16章、第17章、第21章
  summary: |
    定位的基本推理方法与姿态原则：传播者是错的，接受方（潜在顾客）才是对的；重要的不是客观事实，而是心智中已存的认知——把认知当成现实来接受，再重构这些认知，在心智中建立想要的"位置"。定位问题的解决方法一般要从潜在客户的心智中而不是产品中找到：答案从市场中来而非营销经理处来，必要时花钱调研；过早聚焦产品本身，就会忽略那些显而易见的东西。与之相对的"由内而外"思维（迷信产品事实与自我视角）是营销失败的常见根源。
    操作推论（吸收 p47）：不管投入多少钱，要打入潜在客户的心智，必须把它同心智中已有的东西联系起来——心智不会为全新事物腾出空位，只会沿已有认知的阶梯挪动一格。一切定位工作的操作起点永远是回答："提到我的名字/公司/产品，普通人脑子里出现什么？"

- id: p16
  title: 付出额外努力的时机是局势不明时
  type: principle
  source_chapter: 第6章、第22章
  summary: |

    勇气维度（吸收 p61）：领导地位的建立靠的不只是运气和时机，更是趁别人驻足观望时奋力一搏的决心——"以最多的人马最先进入阵地"。领导者通常在形势未定时就投入营销资金；等回过神来认为定位强大无需广告时，往往已跌出前五。

- id: p17
  title: 企业实力来自心智定位，而非企业规模
  type: principle
  source_chapter: 第6章、第11章、第12章
  summary: |

    价值层（吸收 p01）：组织最有价值的资源不再是土地、资本乃至人力与知识，而是品牌所代表的心智资源；没有心智资源的牵引，其他所有资源都只是成本。这也解释了互联网企业不赢利仍能获得大笔投资——心智资源本身就是成果。
    失位代价（吸收 p35）：失去领先地位失去的不只是业务，还有渠道能力、利润与声誉（Scott被延伸产品稀释后，卫生纸第一让给宝洁Charmin，其他Scott产品也随时会垮）——心智份额比市场份额更根本。

- id: p39

- **跟随者打法 vs 攻击传播**："我该占哪个位置" → `challenger-follower-positioning`；"这条攻击广告怎么写/能不能发" → `reposition-the-competitor`。
- **第一 vs 防御**："我怎么抢第一" → `first-in-mind-beats-better`；"我已经是第一怎么守住" → `leader-defense-playbook`。
- **由外而内 vs 游戏规则**："用认知还是用事实做判断" → `outside-in-perception-first`；"定位实践者的心态与素质自检" → `positioning-game-rules`。
- **流程 vs 各专项**：完整项目启动/复盘/预算/节奏 → `positioning-six-question-process`；进入某一具体环节后由专项 skill 接管。
