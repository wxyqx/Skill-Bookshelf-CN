## I — 方法论骨架 (Interpretation)

绝大多数品牌不是领导者。跟随者的生存法则是：**不与领导者拼同一维度**，而是在心智阶梯上找到属于自己的梯级。方法分四层：

1. **认清跟风的危险**。跟风产品的死法高度一致：把资源押在"我的产品更好"上，用改进产品的时间、更少的广告费和公司现成的名字入场——而胜负手恰恰是速度、名字和抢先建立的认知。领导者还没站稳时是唯一窗口，窗口一关，"更好"毫无意义。
2. **先排除正面进攻，再选路径**。面对心智中地位稳固的领导者只有三条路：①承认现实，不打正面（对方占六成份额时正面挑战是烧钱买败）；②反其道而行，领导者怎么做你就反着做；③借自己已被认知的位置挂钩新业务，或干脆在品类之外做新品类的第一。迂回永远优于穿越。
3. **沿维度搜空位**。把心智当地图，逐维检查哪里没人占：**尺寸**（大众"往小里想"）、**高价**（第一个立高价者赢，须真实差异化支撑且在广告里而非店里建立）、**低价**（顾客抱着试错心理的新品类适用）、**性别**（全行业取女名时男名胜出）、**年龄**（儿童/老人）、**时段**（夜间感冒药）、**分销渠道**（超市蛋袜）、**重度使用者**（"喝了还想喝"）。搜索姿态是逆向：人人都朝东走时，机会在西边。判据有二：空位只属于**第一个占据者**（同样的创意第二做无效）；独特性必须配得上**较大的市场需求**——"行业里的劳斯莱斯"是定位成功、销售失败。
4. **两把挂靠钩子 + 一条铁律**。找不到空位时可以挂钩领导者：**关联定位法**——坦然承认排位（"我们是老二，所以更努力"），借公众对弱者的同情与可信度上位，广告不把话说尽，让顾客自己补出"比领导者"；**非可乐挂靠法**——把产品挂到强势品类上，告诉顾客"你不是什么"（七喜=可乐的替代品、汽车=不用马拉的车），用旧阶梯理解新阶梯。铁律（工厂空位 vs 心智空位）：空位只存在于顾客脑中，不存在于产能、产品线缺口或实验室里。填工厂空位的战略从内部看"完美"，从心智看无位可占——判断标准永远是"顾客心智里有没有这个空位"，而不是"我们手里有没有这个产品"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 安飞士——"我们是老二"
- **问题**: 租车业老二安飞士连续赔本13年，正面追赶赫兹毫无胜算。
- **方法论的使用**: 关联定位法。直面心智阶梯（赫兹第一、安飞士第二、全美第三），打出"安飞士只不过是第二，为什么还找我们？我们工作更努力"——承认赫兹的位置、放弃正面冲突、借公众对弱者的同情；标题不把话说尽，让读者自行补出"比赫兹更努力"。
- **结论**: 承认第二比假装第一可信；位置选对，小预算也能翻盘。
- **结果**: 承认第二后第一年赚120万美元，第二年260万，第三年500万；后被ITT收购改口"要当第一"，落入FWMTS陷阱，重蹈失败。

### 案例 2: 七喜——"非可乐"
- **问题**: 七喜是柠檬-青柠汽水，品类太弱，正面宣传自身无人关心。
- **方法论的使用**: 非可乐挂靠法。当时每三份软饮料中两份是可乐，七喜不描述柠檬-青柠品类，而是把自己挂到可乐这个最强势的心智阶梯上，定义为"可乐的替代品"——借可乐的巨大心智份额为自己抬轿。
- **结论**: 心智不接受孤立的新事物，挂靠强势品类比正面描述更管用；但必须持续说清"是什么"。
- **结果**: 净销售额从8770万美元增至1.9亿美元以上，成为世界第三大软饮料；后因广告不一致、品牌延伸（金七喜）、只说"不是什么"没说"是什么"，在柠檬-青柠品类输给雪碧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 老二老三或新进入者讨论"我们该占哪个位置"：正面打不过，问有没有别的维度、别的价格带、别的挂靠方式可切。
2. 决策要不要跟风：手上有款和领导者差不多（或略好）的产品，想确认靠"更好"能不能赢。
3. 评估一个"空位"的真假：内部看是缺口/闲置产能/技术首创，要检验它是不是顾客心智里的空位、够不够养活品牌。

### 语言信号 (用户的话里出现这些就应激活)

- "我们是老二/老三""打不过领导者""有没有别的维度切进去""找空位"
- "跟风做一款更好的行不行""价格上有没有空间""高端被占了能不能做低价"
- "这个细分没人做，算不算机会""闲置产能/产品线缺口正好补一个"

### 与相邻 skill 的区分

- 与 `reposition-the-competitor` 的区别：本 skill 回答"**选哪个位置**"（空位、关联、挂靠——不攻击对手）；位置已定、要设计揭对手短处的**攻击传播**时找后者。"我是老二所以更努力"是本 skill，"对手伤胃不能吃"是后者。
- 与 `first-in-mind-beats-better` 的区别：本 skill 处理"**已经是跟随者/在位**，怎么在现有格局里找位"；"能不能换赛道抢做心智第一、时机够不够早"的问题找后者。
- 与 `leader-defense-playbook` 的区别：用户是品类第一时的拦截、多品牌、正宗货防御找后者；本 skill 只服务非领导者。
- 与 `mental-ladder-diagnosis` 的区别：摸底"我们在阶梯第几层"的调研找后者；位置摸清后的选位与找空位是本 skill。

## E — 可执行步骤 (Execution)

1. **画出心智阶梯现状**
   - 写出目标品类前三名各占什么词、自己排在第几。
   - 完成标准：一句话说清"提到这个品类，顾客按什么顺序想起谁"。
2. **排除正面进攻，选定路径**
   - 对照三条路径（承认现实/反其道而行/挂靠或另立），排除与领导者对拼同一维度的方案。
   - 完成标准：方案里没有任何"在同一定位上做得比领导者更好"的成分；否则判停。
3. **按维度搜空位并验真心智**
   - 逐维检查（尺寸/高价/低价/性别/年龄/时段/分销/重度使用者），每个候选空位问两个问题：顾客脑中此处是否真空着（不是工厂缺口、不是技术首创）？第一个占据者是谁、还活着吗？
   - 完成标准：候选空位通过"心智空位"检验与"次序检验"（我们或无人占，或我们确是第一个）；找不到空位则转第4步挂靠。
4. **检验市场规模，锁定并演练表达**
   - 用"独特性 × 较大需求"双检验排除劳斯莱斯式孤高定位；高价空位须有真实差异化支撑。
   - 完成标准：一句话定位（关联定位须含坦然承认排位的表述），通过"顾客听了能自己补全"的留白测试，且与现有品牌名的含义不冲突。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要写/评一条攻击竞品的文案——那是 `reposition-the-competitor`，本 skill 的位置选择不以攻击对手为前提。
- 用户是品类领导者做防御决策——`leader-defense-playbook`。
- 核心问题是"上市太晚还能不能抢第一、要不要换赛道"——`first-in-mind-beats-better`。

### 作者在书中警告的失败模式（空位误判家族 F）

- **工厂空位 ≠ 心智空位**：道·琼斯为消化闲置印刷设备推《全国观察家报》，福特埃德塞尔从生产端看"完美"——读者与购车者心智里均无空位，皆败。
- **技术陷阱**：干白威士忌、透明米勒、水晶百事，"实验室第一"要求顾客推翻既有颜色/类别认知，必败；判断标准是心智第一而非瓶子第一。
- **空位只属于第一个占据者**：Luke男性香烟比万宝路晚约20年，名字包装俱佳仍失败；Eve 模仿维珍妮同样失败。
- **劳斯莱斯思维**：独一无二但需求狭小（年销几千辆对凯迪拉克近50万辆），孤高定位是自嗨。
- 旁证失败模式：正面进攻领导者（NCR 对 IBM 几乎一蹶不振）；满足所有人（Rheingold 四个民族版广告什么人也没吸引到，同城的 Schaefer 聚焦重度饮用者成功）；成功后弃位（安飞士改口"要当第一"、米狮龙丢掉"一流"）。

### 作者的盲点 / 时代局限

- 空位判断在书中依赖个案与直觉，作者批评他人调研不可靠，自己的找位方法同样缺少可复现的验证程序。
- 案例绑定美国1960-80年代广告环境；长尾市场与平台经济下"二元格局""维度穷尽"的适用性未验证。

### 容易混淆的邻近方法论

- 对比性广告：自夸式比较是本 skill 反面，关联定位靠可信的示弱而非压对手一头。
- 传统 STP 细分：细分切的是人群统计，空位切的是**心智认知维度**——空位以"顾客脑中是否空着"为准，不以人群规模为准。
- 差异化口号：找空位要的是第一个占据并守住一个词，不是一句更好听的广告语。
