# 公司/机构定位——形象、行业代言与使命重塑

## I — 方法论骨架 (Interpretation)

公司层面的定位回答的不是"某款产品占哪个词"，而是"提到这家公司的名字，求职者、股民、顾客三类买家脑子里出现什么"。定位客观存在：不存在"不定位"的公司，只存在自觉精准与不自觉错误之分——按错误定位配置资源，新投入不被接受还浪费资产。

**1. 买卖与多元化解决不了问题。** 公司陷入困境时最常见的两条"出路"——把公司卖掉、或多元化铺开新业务——都绕开了真正的病灶。企业实力来自心智定位而非规模：离开核心定位，营收和名望都转移不过去；"定位与多元化南辕北辙"，强大定位建立在重大成就而非宽泛产品线上。把多元化本身当公司主题同样失败，因为它给不出一个可占据的概念。

**2. 名字要意有所指。** 公司业务已变而名字没变时，正确的动作是换一个与业务相称的新名字，而不是砸钱教育市场"我们不止是……"。名字把公司牢牢拴在过去的声誉上，只要旧业务还在运营，改认知的广告就是昂贵的错误。方向判断归本 skill，具体起什么名字走 `naming-that-hooks`。

**3. 公司定位三条路径 + 三重过滤。** 领导地位靠"第一个做某事"建立，不是自称领先。候选路径有三：①产品领先（先看竞争格局，打不过就放弃）；②运营领先（如倡导自由企业之类）；③行业领先（为整个行业代言）。每条路径过三道过滤：竞争格局允许吗？是不是人人都在谈的风尚？这个位置有没有人已占？三关全过才选定。

**4. 孟山都之路：选无人认领的议题，为行业说话。** 当整个行业面临公众误解或攻击、同行都沉默时，第一个站出来为全行业辩护的公司就被心智认定为领导者。所选议题必须避开风尚（人人都在谈论的位置已被议论填满），并配一个"常识级"的戏剧化表达反复投放。回报可量化：公众好感上升、对手跟随（跟随行为本身再次确认你的领导地位）。领导地位可以在银行里兑换成现金——把公司定位项目当作资产负债表上的无形资产来投资。

**5. 机构使命重塑：回溯历史找基础业务。** 经历转型、传播杂乱的机构，路径是：①承认传播问题存在（缺中心主题与连续性）；②回答"本机构的作用是什么"，答案必须简单明确；③回溯历史直至基础业务——必要时回到机构的"创立文献"；④让培训、活动、传播全部围绕该定位构筑。定位战略一旦确定，就为组织的所有活动指明方向。最大障碍在内部：管理层崇尚复杂、不屑简单，显而易见的方案容易被否。

**6. "以人为本"类主题为何危险。** 心智认为一流公司的员工素质天然最高——员工素质是定位的结果而非原因。不是第一却自称"人才是我们最大的资源"，招来的是"如果你那么聪明，怎么没发财"式质疑；同理危险的还有多元化、值得信赖等没有排他性的陈旧主题。公司定位应落在成就与地位上，而不是落在"人"和"态度"上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 孟山都"生活中的化学常识"
- **问题**: 化工业被舆论围攻，公众支持率低迷；孟山都产品打不过杜邦，公司形象广告无主题。
- **方法论的使用**: 逐条评估三路径——产品领先（打不过杜邦，放弃）、运营领先（自由企业是人人在谈的风尚，放弃）、行业领先（为化工正名无人占位，选定）；自 1977 年起每年投入数百万美元，推出"生活中的化学常识"系列广告，主题"没有化学物质，生命不可能存在"，持续为行业代言。
- **结论**: 抢占了"化工行业代言人"的心智位置，行业议题成为公司资产。
- **结果**: 两年内公众对化工支持率从 36% 升到 42%（同期石油业从 37% 跌到 22%）；《商业周刊》认定其为行业形象运动首创者，杜邦拨 400 万美元跟随——跟随本身再次确认孟山都的领导地位。遗憾：公司后来把重点转向基因工程，偏离了立足化工业的定位。

### 案例 2: 天主教会"福音教师"方案
- **问题**: 梵二会议后教会偏离"律法教师"旧定位却没有新定位：传播杂乱、各说各话，弥撒参与率跌破 50%，修士修女减少 20%。
- **方法论的使用**: 回答"教会的作用是什么"——回溯两千年历史与《圣经》，从《马太福音》分离出"福音教师"这一显而易见的定位（让耶稣活在子子孙孙心中），以布道培训为核心、配入门电影等戏剧化手段，让所有活动围绕单一主题构筑。
- **结论**: 方案诊断完整、路径可行，但卡在组织采纳环节。
- **结果**: 主教们认为方案"过于显而易见"而全盘拒绝，毫无结果；许多教士反而推崇"教会要扮演六种角色"的复杂定义——多概念定义在心智中的传播力为零。机构推行定位的最大障碍是管理层崇尚复杂、不屑简单。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要做公司形象广告、雇主品牌或年报叙事，主题在"以人为本/值得信赖/多元化/创新"之间挑花眼，或已有主题拿不准能不能用。
2. 所在行业被媒体和公众妖魔化，同行沉默，公司考虑要不要站出来为行业说话、选什么议题。
3. 机构/协会/转型期公司传播杂乱、各说各话，要回答"我们到底是干什么的"并重塑使命。

### 语言信号 (用户的话里出现这些就应激活)

- "公司形象片/企业形象广告怎么定主题""雇主品牌想说什么""公司在顾客/求职者心里等于什么"
- "行业被抹黑，我们要不要发声""为行业代言""选个行业议题"
- "机构转型后没中心主题""我们的使命该怎么重新表述""回溯初心"
- "'以人为本'这个主题行不行""多元化算不算定位"

### 与相邻 skill 的区分

- 与 `own-one-word-in-mind` 的区别：那是指**产品/品牌**在品类阶梯上占哪个词（如"安全""驾驶"）；本 skill 管的是**公司/机构整体**的形象与地位（为行业说话、使命是什么）。用户问的是某款产品占什么词 → 前者；问的是公司整体该被理解成什么 → 本 skill。
- 与 `positioning-six-question-process` 的区别：那是启动/复盘**完整定位项目**的六问全流程（含预算、坚持、外脑决策）；本 skill 只处理"公司/机构层面占什么位置"这一个点的具体做法。用户要全流程和节奏 → 前者；只问公司形象与使命这一环 → 本 skill。
- 与 `naming-that-hooks` 的区别：名字与业务脱节时"要不要换名"的方向判断归本 skill，"换成什么名字"的字面决策走后者。
- 与 `country-place-positioning` 的区别：给国家/城市/目的地定位（用邻居认知、权威背书）走后者；本 skill 只管企业与机构。

## E — 可执行步骤 (Execution)

1. **诊断三类买家的心智现状**：分别写下求职者、股民、顾客"提到本公司名字时想到什么"
   - 完成标准：三类买家各得一句话；答案来自外部访谈/搜索印象，不来自内部自评。
2. **列出三条路径并做三重过滤**：产品领先、运营领先、行业领先逐条过"竞争格局/是否风尚/是否已被占位"
   - 完成标准：每条路径三个问题都有明确答案；判停条件——三条全被过滤，先回核心业务建成就，不做形象工程。
3. **排除死题**：检查候选主题是否属于"以人为本、多元化、值得信赖"类悖论主题，是否人人都在谈的风尚
   - 完成标准：主题能指认一个无人认领、与自身成就挂钩的位置；否则推倒重来。
4. **戏剧化表达 + 全活动对齐**：把定位转成一句常识级表达，培训、传播、活动全部围绕它构筑
   - 完成标准：一句话能通过"提到我们公司，别人会说什么"的测试；组织内无第二套说法。
5. **长期投入承诺**：把项目当无形资产做多年预算，并预先解决向最高管理层的推销
   - 完成标准：有跨年度预算与最高层书面认可；判停条件——最高层嫌方案"太简单"，先做向内推销再启动。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 具体产品/品牌的定位决策——那是产品线各 skill 的事，公司定位不能替代产品定位。
- 没有真实成就与地位支撑却想"代言全行业"——行业代言权来自地位，空手代言会被识破。
- 预算撑不起多年期形象运动的短期项目——公司定位是长期资产投资，按战役打法必烂尾。
- 给国家/城市/景区做定位——走 `country-place-positioning`。

### 作者在书中警告的失败模式

- "以人为本"悖论：不是第一却自称员工素质最高，心智把素质视为定位的结果而非原因，招致"如果你那么聪明，怎么没发财"的质疑。
- 把多元化当公司主题：给不出可占据的概念，追随风尚的议题（人人都在谈）没有占位价值。
- 管理层否决显而易见的方案：教会主教嫌"福音教师""过于显而易见"而拒绝，定位工作死于内部的不屑。
- 代言成功后的定位漂移：孟山都后续把重点移离化工业，放弃了刚建立起来的行业地位。

### 作者的盲点 / 时代局限

- 案例取自美国 1960-80 年代广告环境，形象运动的 ROI（如支持率 36%→42%）难以剥离品类与环境红利；机构样本单一（教会一例），对政府、NGO 等的适用性靠推论；社交媒体时代"为行业代言"的议题竞争机制未覆盖。

### 容易混淆的邻近方法论

- 公关危机应对：借的是一次负面事件，行业代言占的是长期结构性议题。
- 雇主品牌话术：HR 视角的"雇主价值主张"常直接落进"以人为本"陷阱，与本 skill 的成就导向相反。
- 企业社会责任（CSR）：按风尚议题清单行事，未必指向无人认领的心智位置。
