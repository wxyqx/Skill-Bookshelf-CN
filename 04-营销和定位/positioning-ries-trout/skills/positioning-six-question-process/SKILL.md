# 成功六步曲——定位项目的完整流程

## R — 原文 (Reading)

> "定位需要逆向思维，从潜在顾客心智而非自己开始。"
>
> — 里斯 & 特劳特，第21章

> "公司内部的人习惯内向思维，而局外人很自然地习惯外向思维。"
>
> — 里斯 & 特劳特，第21章

> "地域式推销是一种办法：使产品在一个市场里站住脚后，再推到下一个市场里去。"
>
> — 里斯 & 特劳特，第22章

## I — 方法论骨架 (Interpretation)

六步曲把定位从"一个好想法"变成"一个能跑完的项目"。它表面是六个问题，实际是一条**顺序不可颠倒的推进链**：先看清处境（①②③），再算清代价（④⑤），最后管住执行（⑥）。全书另有一版更凝练的"四步法"（分析外部环境→确立优势位置→配信任状→整合运营），两者是一体两面：四步法讲定位的战略内容，六步曲讲项目的推进纪律。

**六问逐问展开：**

1. **你拥有怎样的定位？** 答案不在营销经理的愿望里，在潜在顾客的心智里。起点是市场证据（调研、访谈、试销），不是会议室的自我评估。
2. **你想拥有怎样的定位？** 关键词是"**拥有**"：找长期可以独占的窄定位。太宽泛的位置即使建立了，也防御不住更窄定位的攻击——个人同理，做独一无二的专家，不做什么都干的通才。
3. **谁是你必须超越的？** 列出心智阶梯上挡在你前面的对手，然后**不正面攻击**——绕过障碍比穿过它好。
4. **你有足够的钱吗？** 建立定位要钱，保住定位同样要钱。资金有限就缩小地盘，一个市场接一个市场推进。
5. **你能坚持到底吗？** 基本战略几乎永不改变，能改变的只是战术与短期行动。定位如价值连城的不动产，放弃就拿不回来。
6. **你符合自己的定位吗？** 创意本身一文不值，只有为定位目标服务的创意才有意义——这是所有广告、文案、方案的准入检验。

**预算现实：** 普通人一年接触约二十万条广告信息，打穿噪声靠的是单位市场的投入密度，不是铺开面积。大钱做全国，小钱滚地域——在一个城市花足钱，胜过在多个城市捉襟见肘；第一战场选对，成功可以复制。分阶段滚动有四条路线可选：按地域（一个市场站住再推下一个）、按人群（先做窄群体的第一）、按年龄（先占年轻人随其长大）、按渠道（先走专业渠道再进大众）。

**坚持到底与耐心：** 成功的定位需要数年如一日。当"想换战略"的冲动出现时，先问一句：是战略错了，还是只是战术没起色、管理层没耐心？窍门是找新方法让既有战略受人瞩目，而不是换战略。

**局外人的角色：供客观，不供奇迹。** 内部人长期浸泡在内向思维里，看不见外部心智的现实；局外人（广告公司、顾问，或自己刻意模拟的外部视角）卖的是客观性。但要明确：局外人不能点草成金——若能纺稻草成金，他们就不会替你打工了。雇得起就借外脑的客观，雇不起就学会自己用局外人视角审自己。

**何时才该换战略：** 六步曲默认答案永远是"不变"，真正的例外只有两种：第②问发现目标位置根本无法由此及彼（对手心智地位不可撼动、时机已过），果断止损；或原有名字/概念这个容器已经报废，换容器重新出发。其余绝大多数"换战略"的呼声，本质是没耐心或想换战术。

## A1 — 书中的应用 (Past Application)

### 案例 1: 比利时航空"五个阿姆斯特丹"——六问全对，死于第⑤问
- **问题**: 比利时航空客运落后，宣传美食与服务毫无起色。真正的问题不在航空公司，而在"比利时"这个目的地在游客心智中没有位置。
- **方法论的使用**: 局外人从游客心智现状出发（第①问：提起比利时，游客想不起任何东西），确立"在美丽的比利时，有五个阿姆斯特丹"的目标位置（第②问：借《米奇林指南》六个三星级城市占其五的权威事实，挂靠游客心智中已有的"阿姆斯特丹"），放弃正面宣传自己的服务（第③问），创意完全服务定位概念（第⑥问）。
- **结论**: 定位正确、概念有力，广告引来大量游客咨询（连荷兰旅游部长都被激怒致电）。但项目败在第⑤问——电视片制作中途管理层更迭，新班子不热心，旅游局又出于政治原因塞进非三星级城市。
- **结果**: "美丽的比利时"项目半途搁浅，未能完全实施。定位项目死于组织的坚持，而非战略本身。

### 案例 2: 西部联盟邮递电报——用试销代替主观判断，用坚持收获八年增长
- **问题**: 美国最早的电子邮件业务，宣传卫星与主机技术无人听得懂，如何建立定位？
- **方法论的使用**: 局外人不讲技术，对接心智中已有的"老式电报"认知，提炼出"低价电报"与"快速信件"两个候选主题（第①②问）；事关公司未来不凭主管好恶拍板，在六个大型通信中心做 13 周试销，同时跟踪销量与认识度（第①问的调研纪律 + 第⑥问的服务定位检验），"低价电报"胜出后长期坚持该战略。
- **结论**: 认识度从 23% 升至 47%（快速信件的认识度反而下降——销量两者都涨，但只有前者建立的是可持续的新认知）；此后 8 年年营收从 300 万美元增至 8000 万美元。
- **结果**: 后任广告公司放弃该战略，业务量连续三年大减——从反面再次验证第⑤问：放弃既有定位的代价远比想象大。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要启动（或复盘）一个品牌/公司/产品的定位项目，需要一套从头到尾、不跳步的流程。
2. 钱不够全国铺开，要决定预算节奏：先打哪个市场、怎么滚动。
3. 项目进行到一半起争执：该坚持还是该换战略？创意方案漂不偏离定位？要不要请外部顾问？

### 语言信号 (用户的话里出现这些就应激活)

- "定位项目怎么启动""有没有完整流程""六步曲""从头梳理定位"
- "预算有限""先打哪个市场""全国还是先做区域""一个城市一个城市来"
- "要不要请广告公司/咨询公司帮忙定位""外部顾问靠不靠谱"
- "该坚持还是该换战略""一年了还没起色""创意方案跟定位有没有关系"

### 与相邻 skill 的区分

- 与 `mental-ladder-diagnosis` 的区别：只想单点摸底"我们在顾客心智第几层/现状如何"，找后者（一次性诊断）；要把摸底→目标→对手→预算→坚持→执行完整走一遍，用本 skill（完整流程）。摸底只是本 skill 的第①问。
- 与 `positioning-game-rules` 的区别：谈定位实践者的素质（理解文字、六要、他人导向），找后者（做人做事的素质）；谈一个项目怎么推进，用本 skill（流程纪律）。
- 与 `personal-career-positioning` 的区别：个人职业赛道的具体选择（找马骑、六匹马），找后者；给"个人"这个品牌走项目流程时可用本 skill 的六问，但内容素材归后者。
- 与 `outside-in-perception-first` 的区别：认知地基问题（为什么必须由外而内、认知即现实），找后者；本 skill 假定地基已立，讲的是流程。

## E — 可执行步骤 (Execution)

1. **第①问·摸清现状**：从潜在顾客心智而非内部出发，收集"提到你，普通人脑子里出现什么"的市场证据（调研/访谈/试销数据）
   - 完成标准：一句话写出"你在顾客脑中等于什么"，且有市场证据支撑，不是经理的愿望。判停条件：若同时想摸的只是单点现状，转 `mental-ladder-diagnosis`。
2. **第②问·定目标并收窄**：对候选定位做"拥有"检验——五年十年内可独占吗？被更窄定位攻击时守得住吗？
   - 完成标准：目标位置能用一个词/一句话说尽，排除了宽泛表述。若判断目标位置无法由此及彼，果断放弃并止损，此为更换战略的合法时机。
3. **第③④问·列对手、排预算**：写出必须超越者并明确不正面攻击；按预算定节奏——大钱全国、小钱选单一市场（地域/人群/年龄/渠道四选一）滚动
   - 完成标准：明确"第一战场"与滚动顺序，且单点预算密度足以打穿当地噪声。
4. **第⑤问·立坚持契约**：与决策层书面约定基本战略在可预期的年限内不变，换届/换代理/换季度不重启战略；"想换战略"的呼声一律先过"是战略错还是没耐心"的检验
   - 完成标准：有明确的战略守门人与变更门槛；局外人角色已落实（外脑或模拟外部视角的例会机制）。
5. **第⑥问·创意准入检验**：所有广告、文案、方案领入场券的资格只有一个——符合定位
   - 完成标准：每条传播都能回答"跟我们的定位相符吗"，答不上来的否决，哪怕它更有才气。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单点战术问题**：起名（→ naming-that-hooks）、选媒体（→ mind-runs-by-ear-media-rules）、写一条攻击文案（→ reposition-the-competitor）、领导者防御动作（→ leader-defense-playbook）——本 skill 是项目级流程，不解决单点。
- 用户只要一份心智现状摸底报告——那是第①问的一半，单独做时转 `mental-ladder-diagnosis`。
- 项目尚未决定"要不要做定位"，用户在问定位理论本身是否成立——先回 `outside-in-perception-first` 立地基。

### 作者在书中警告的失败模式

- **顺序颠倒**：还没看清处境就急着找解决之道——六问必须按序走完。
- **定位太宽泛**：即使建立起来也无法防御更窄定位的攻击。
- **死于组织**：管理层更迭、部门政治、内部审美压倒心智事实——比利时项目半途搁浅、奶球"大嘴"被董事长个人好恶取消都是项目期夭折。
- **创意毁战略**：谨慎完成战略后交给"创意大师"，战略在一团技术迷雾中消失。
- **半途弃位**：后任广告公司放弃既有战略后业务连年大减；放弃的定位如同放弃的不动产，拿不回来。

### 作者的盲点 / 时代局限

- 六问的判断（空位在哪、位置能否由此及彼）依赖直觉与个案，作者批评他人调研不可信，自己的判断同样主观。
- 案例取自美国 1960-80 年代广告环境；数字渠道下"钱不够就缩地盘"的滚动逻辑、试销周期与"坚持数年"的节奏都已变化，非心智因素（渠道、成本、供应链）的权重被系统性低估。

### 容易混淆的邻近方法论

- **定位四步法（序一）**：分析环境→确立定位→信任状→整合运营，与六步曲同一流程的两个表述——四步法讲战略内容，六步曲讲项目纪律，不要当成两套竞争方法。
- **"创意一文不值"**：不是反对创意，是反对脱离定位目标的创意；朴素但服务定位的方案胜过华丽但漂移的方案。
- **坚持与僵化**：不可变的是基本战略，可变的是战术与短期表达——用这个区分处理"该不该换"的争论。
