## 这本书在讲什么

埃亚尔要回答一个所有做产品的人都遇过的问题：为什么有的产品能进入用户的"习惯区间"成为日常默认动作，而大多数产品只能昙花一现？他的答案是一台四冲程引擎——**触发→行动→多变的酬赏→投入**（上瘾模型 / Hook Model）。外部触发把用户第一次拉进门；越简单的行动让使用真的发生；不可预测的酬赏点燃"想要更多"的渴望；而用户投入的时间、数据、内容会沉淀为资产、并自动生成下一次召回——第四环接回第一环，循环闭合。设计者的全部工作，就是让这台引擎转起来，直到用户的某种情绪一出现、产品就自动出现在脑海里，不再需要任何外部提醒。

这本书的独特处有两个。第一，它把"投入"而非"付费"设为模型的枢轴——作者明言"投入并不意味着让用户舍得花钱，而是指用户的行为能提升后续服务质量"（L214），这与"转化即成功"的行业直觉相反；第二，它不讲道理讲动作：每个环节都配了带判据的检查表（五问、三归因、三通道、五资产、5% 门槛、两问四象限），作者自我定位是"实践工具，而非理论范本"（L237）。

但也要先记住这本书的自带警告：全书机制是强力机制，第 6 章是作者刻意放在应用之前的道德闸门——"先问该不该，再问能不能"。他划的红线很清楚：习惯是无意识但至少无害的行为，成瘾是"长期且被动地依赖……最终使人走向自我毁灭"（L476），"生产让用户成瘾的产品是不负责任的表现，因为这等同于蓄意伤害"。本文按书的骨架组织——立论与机会评估、四阶段机制、道德闸门、测量与机会——每节说明方法论解决什么问题、核心逻辑、书中最有代表性的案例、什么时候失效，最后单列组合路径、陷阱、作者局限与产物地图。

## 一、立论：习惯是竞争优势，但先过两道闸（第 1 章）

用户的依赖性（而非规模）才是习惯养成类公司的经济护城河，它折算为四项收益：更高的用户终身价值、更大的价格灵活性、更快的增长速度、更深的竞争壁垒——巴菲特敢持续提价的 See's Candies、Evernote 的"微笑曲线"（重度用户的付费爬升）、病毒循环周期随使用频率的缩短，都是这条论证的素材。但在动手设计之前，作者立了两道前置闸。

### 习惯区间：频率是硬轴，用途是软轴

**它解决什么问题**：拿到一个新点子，怎么判断它值不值得按"习惯产品"来设计？

**核心逻辑**：行为要成为下意识习惯，取决于"发生频率 × 可感知用途"两轴，而两轴**不对称**——频率可脱离用途单独把行为拖进习惯区间（刷社交媒体的"用处"说不清，照样成习惯），用途再强也救不了频率不足的行为：曲线在数学上不会与横轴相交，"无论这种行为能为你带来多么丰富的用途，发生频率的不足都只会让它作为你有意识的举动而存在"（L435）。牙线研究佐证：新习惯出现的频率越高，稳定性越强（L401）。配套两个诚实注脚：习惯形成没有通用时间表，"频率多高才算高"也无定论。

**书中的用法**：亚马逊与 Progressive 走的是低频高用途的另类路线——把可感知用途做到极致（帮竞争对手打广告消除价格顾虑），占据"首选心智"；Google vs Bing 则说明频率先行的高频习惯建成后，"略胜一筹"的性能差异毫无意义。两条路线都通，但别把"首选心智"误当习惯路线。

**什么时候会失效**：人寿保险、婚庆这类低频一次性产品没有频率轴可言（作者自设边界 L310–314）；"提高频率"指用户主动行为的发生频率，不是运营发送的频率——为凑数给用户刷屏推送，既违反自主权也推高打开率的衰减。

### 维生素→止痛药：验收看"痒"，不看口碑

**它解决什么问题**：投资人永远在问"你这是维生素还是止痛药"，用户都说好用但看不到离不开的迹象——是没救了还是没到时候？

**核心逻辑**：作者反用这对隐喻。对习惯产品这不是二选一，而是同一产品在时间轴上的两种状态：入场时是维生素（可有可无），成习惯后是止痛药（不可或缺）。转变的判据只有一条，且只认行为证据——"如果你因为无法实施某种行为而感到痛苦，那说明习惯业已形成"（L468）。注意作者刻意降调：多数产品安抚的不是剧痛，是"痒"——潜伏的、平时不被觉察的轻微渴求。所以 NPS、不愿卸载、"用户说喜欢"统统不算证据；要查的是：特定不适出现时用户是否**自动想起**产品、中断一周后是否难受、产品坏了有没有自发的绕路行为。

**书中的用法**：Facebook/Twitter/Instagram/Pinterest 在融资时全是"维生素"——"没人会在半夜爬起来大呼小叫地更新自己的状态"（L466）。第 8 章作者用同一判据重估"新生行为"：许多突破性产品"一开始都被评论家们当作玩具或利基市场而嗤之以鼻"（L2246），维生素期恰恰是观察者最容易被骗、设计者最该耐心经营的时间窗。

**什么时候会失效**：判据未过时先回频率轴——低频行为的"痒"永远建立不起来，阶段论不是留存差的借口；支付、报税这类一开始就解决显性痛点的产品不必从维生素起步。

### 机会从哪来：四路扫描

**它解决什么问题**：想做习惯产品，但点子不是扫出来的——怎么系统地找？

**核心逻辑**：四条扫描路径各带判据。①**照镜子**——研究自己反复忍耐的烦恼，判据是格雷厄姆的反问："我希望别人为我解决什么问题"（L2211）；②**新生行为**——被主流当玩具的边缘行为可能越界成主流，所以问"谁在天天做这件'没用'的事"，而不是"这有没有用"（电话、飞机、互联网的看走眼史是配套反锚定）；③**促成性技术**——新技术让哪个行为骤然变容易，看行为成本曲线的拐点；④**界面更改**——人与技术交互方式的重大迁移（图形界面、相机+手机）会批量制造新习惯入口，配套心法是布赫海特的"生活在未来"（L2274）。

**书中的用法**：Buffer 源于创始人自己发推太烦（照镜子）；Facebook 复刻的是哈佛学生早已熟悉的线下"花名册"（新生行为长于熟悉行为）。

**什么时候会失效**：设计者≠目标人群，照镜子须配"还有谁与我同痛"的验证；多数"玩具"就是玩具，作者没给新生行为的证伪标准——扫描产出的是候选，不是结论，逐个过频率闸与伦理闸之后才算数。

## 二、触发：外部买注意力，内部买反射（第 2 章）

四阶段的第一环回答"用户为什么来"。本书把触发拆成两个层面：看得见的外部触发（信息中的行动召唤）与看不见的内部触发（情绪与产品的绑定）——而"从依赖外部触发转向利用内部触发"（L1847）是整个循环的方向。

### 外部触发四分类：拉新与留存的分工

**它解决什么问题**：冷启动预算该投广告还是做内容？为什么一停投放留存就腰斩？

**核心逻辑**：所有外部触发分四类——付费型（广告，快而贵）、回馈型（媒体与商店推介，免费但昙花一现）、人际型（熟人推荐，根基是信任）、自主型（用户许可后持续出现的图标与推送）。真正做设计的分界线是**分工**："付费型触发、回馈型触发以及人际型触发都是以争取新用户为主要目标，而自主型触发以驱动用户重复某种行为作为重点"（L628）。买来的注意力都是一次性的，只有用户许可的自主型触发能以足够高的频率反复出现。于是预算问题从"哪种渠道便宜"变成"哪类触发服务哪段旅程"——且必须尽早拿到自主型许可，否则拉来的新用户没有回访通道。

**书中的用法**：Instagram 的完整接力链——朋友分享（人际）→媒体与商店推荐（回馈）→手机首屏图标（自主）→数周后内部触发接管（L730–737）。反面是《圣经》应用的正例：通知、红徽章、邮件、社区鼓励构成自主型触发的多层冗余，层层兜住漏网用户（L2069–2073）。

**什么时候会失效**：停投即流失说明问题不在投放而在内部触发未建立——停止加码，转诊循环后段；人际型的红线是不做透支信任的黑暗模式（"代价却是失去用户的信任与期望"，L616）。

### 5 问法：从功能请求挖到情绪根源

**它解决什么问题**：用户嚷着要"更快的报表"，提速 30% 使用率却没涨——表层请求和真实动机是两回事，怎么下钻？

**核心逻辑**：对同一个行为连问五个"为什么"。这本是丰田大野耐一的根因分析工具（作者自注 L696），埃亚尔的关键改用在**终点判据**：不停在"根本原因"，停在"出现情绪词"——怕、焦虑、孤独、怕被抛弃。两条纪律：起点必须长在**实际行为**上而非口头愿景上（"言语不一定能反映出最真实的想法"，L684；霍尔语 L686）；起点选错，五层答案整条走偏（L722）。

**书中的用法**：虚构用户朱丽与"电子邮件"的五连问——收发信息→分享并即时获取→了解亲友的生活→知道自己是否被需要→**害怕被圈子抛弃**。"恐惧感是她身上最强大的内部触发，因此，我们在设计产品时，应该考虑使它能减轻用户的恐惧心理"（L720–722）。

**什么时候会失效**：对真人连问五次"为什么"是审讯不是访谈——作者配套的做法是基于情境与资料推演、配合移情图；挖到的情绪是设计原材料，不是营销弹药（放大恐惧再卖安抚是明确的越线）。

→ 深入: [`five-whys-emotional-root`](./five-whys-emotional-root/SKILL.md)

### 内部触发锚定：把情绪做成条件反射

**它解决什么问题**：功能没问题、评价尚可，但用户不想起我们、推送一停就不回来——缺的不是功能，是情绪锚点。怎么把"一感到 X 就打开"装进去？

**核心逻辑**：安装三步。①找**高频负面情绪**候选——无聊、孤独、压力、FOMO、不确定感；负面情绪是最强的安装点，因为"人们几乎在一瞬间就不自觉地想打压它"；②验证产品是该情绪的**即时药方**——抚慰必须比"忍着"更快，延迟的缓解不合格；③设计**喂养期**——外部触发（以自主型为主）在情绪最活跃的时机反复出现，数周到数月后，情绪与产品间的纽带（作者比作牡蛎中的珍珠质）才长成条件反射。

**书中的用法**：英自称"没想用它解决什么问题，只是看见好玩儿的东西就想拍下来"（L539–545）——真实锚点是 FOMO："每当她担心某个与众不同的时刻会一去不复返时，就会打开 Instagram"（L643–645）。密苏里科大 216 人追踪研究给出独立证据线：承受负面情绪的学生显著更高频地从科技中寻求安慰（L651–655）。

**什么时候会失效**：低频工具硬找情绪锚只会产出打扰式推送；"内部触发可以通过设计安装"是全书论证最少的断言（Instagram 是解释性案例而非证据）——把安装成功当待验证假设，用习惯测试验收；伦理上这是全书风险最高处：不得制造负面情绪再卖药方，不得对未成年人做情绪锚定。

→ 深入: [`internal-trigger-anchoring`](./internal-trigger-anchoring/SKILL.md)

## 三、行动：先补能力，再谈动机（第 3 章）

第二环回答"使用怎么真的发生"。三个单元构成一条诊断链：先归因（B=MAT），再按归因结果展开（能力查六要素、动机选杠杆）。

### B=MAT：行为是乘法，不是加法

**它解决什么问题**：点击率高、完成率低；调研都说要、上线没人用——该改文案还是改流程？

**核心逻辑**：福格行为模型——"动机、能力、触发这三样缺一不可，否则，人们将无法跨过'行动线'"（L813）。三要素是**相乘**关系，任何一项为零乘积为零。它的价值不在预测而在归因：把笼统的"用户不感兴趣"拆成三个可分别检查的假设——不想做（动机）、够不着（能力）、没注意到（触发）。埃亚尔加了两条增量：诊断顺序固定为触发→能力→动机；修复排序**先补能力**——"增强用户的使用动机往往耗时又费钱"（L1009），而简化流程是设计者完全可控、见效最快的变量。

**书中的用法**："手机响了为什么没接"的三归因示范——手机在包里够不着（能力）、以为是推销员（动机）、手机静音（触发），三种解释对应三种完全不同的修复动作。Twitter 主页 2009→2012 年的改版则是"先补能力"的行业范本：放弃堆满说服文字的动机路线，只留两个行动召唤，"与其推销，不如让用户直接体验"。

**什么时候会失效**：0→1 阶段先验证需求存在，行为公式不解释"要不要做"；纯触达量问题先回触发端；奢侈品等动机本位的产品，"先简化"可能稀释吸引力。

→ 深入: [`bmat-action-diagnosis`](./bmat-action-diagnosis/SKILL.md)

### 动机三分类：先选杠杆，再设计强度

**它解决什么问题**：文案有 N 个候选打动点（省钱/避麻烦/攀比），主打哪个？恐惧诉求到底能不能用？

**核心逻辑**：福格把一切动机压成三对趋避杠杆——追求快乐/逃避痛苦、追求希望/逃避恐惧、追求认同/逃避排斥。杠杆有正反两面，恐惧与排斥并非禁区（头盔广告用伤疤照片同样有效）；但"能够成为某些人行为动机的东西未必适用于另一些人"（L851）——性卖点对目标人群是兴奋点、对其他受众是反感点。所以操作顺序是先小样本测出"哪根杠杆对该人群摆幅最大"，再设计强度。

**书中的用法**：四则广告各对应一组杠杆——奥巴马海报打希望、内衣广告打体感、百威打社交凝聚力、头盔广告打恐惧（L841–859）。

**什么时候会失效**：动机杠杆放大既有欲望，不能无中生有创造需求；行为缺失时先走 B=MAT 归因——多数"不行动"卡在能力而非动机；动用负面杠杆后过操纵矩阵复核。

→ 深入: [`three-core-motivations`](./three-core-motivations/SKILL.md)

### 能力六要素：摩擦不只存在于界面里

**它解决什么问题**：老年用户不会用政务 App，界面已经大字版了还是不行——"不够简单"到底是哪一种不简单？

**核心逻辑**：完成任务的能力由六项摩擦源决定——时间、金钱、体力、脑力、**社会偏差**（怕被人指指点点）、**非常规性**（跟他一贯的做事方式拧着）。后两项是这份清单相对常见易用性维度最有辨识度的补充。核心规则不是六项平均用力，而是**补最短板**：同一流程对不同人群的卡点完全不同，"设计人员应该关注用户最缺乏什么"（L922）。

**书中的用法**：四个简化案例各补不同短板——Facebook 注册器删中间步骤（脑力）、Twitter 一键分享（脑力）、iPhone 锁屏直开相机（时间）、Pinterest 无限滚动（时间）。Facebook 注册器的异议同时是警示：对隐私敏感者它"催生出新的焦虑"——短板因人而异，"包治百病"方案不存在（L945）。

**什么时候会失效**：投入阶段（填资料、建内容）需要的是拆小步而非减摩擦——方向相反（见第五节）；用户根本不认为行为有价值时，简化救不了零转化。

→ 深入: [`six-simplicity-elements`](./six-simplicity-elements/SKILL.md)

## 四、多变的酬赏：值钱的不是满足，是渴望（第 4 章）

第三环回答"为什么再来"。核心命题：驱动重复使用的不是酬赏本身，而是渴望酬赏时的迫切需要，而可预测的奖励恰恰消灭渴望。

### 酬赏三分类与对齐规则

**它解决什么问题**：内部知识库没人贡献，加积分商城有用吗？游戏化三件套上不上？

**核心逻辑**：酬赏有三条机制不同的通道——**社交酬赏**（被部落接纳：点赞、威望值只是载体）、**猎物酬赏**（追逐过程本身：信息流与老虎机共享"猎手是为了追逐而追逐"的机制）、**自我酬赏**（任务闭合的终结感：清空邮箱、升到下一级）。两条规则让它区别于泛泛的"给奖励"：第一，**对齐规则**——酬赏必须回答"用户为什么来"，为解闷而来的用户发积分是错位给药，说不出内部触发就无从对齐；第二，**通道选择**——社交认同的引力通常远大于金钱，因为金钱会重新定义行为性质（从兴趣变成低薪打工），把真动机挤出。

**书中的用法**：Mahalo vs Quora 的同赛道对照——Mahalo 用现金悬赏答案，Quora 一分钱不奖励、靠投票建立社交反馈。"人们对于社交酬赏以及同伴认同的渴望要远远大于对经济利益的期待"（L1398）；结果 Mahalo 冲到月访问 1410 万后迅速冷却，Quora 反超成为主导者。Stack Overflow 则证明社交认同足以支撑重劳动：投票累积的威望值让程序员每天无偿提交 5000 条高质量回答。

**什么时候会失效**：产品核心价值不成立时，再多的积分徽章只会放大"任务毫无意义"的认知（游戏化警示）；赌博式变量机制（开箱、抽签）对易感人群构成成瘾设计——机制有效性必须先过伦理红线。

→ 深入: [`three-variable-rewards`](./three-variable-rewards/SKILL.md)

### 有限 vs 无穷的多变性：新鲜感的结构问题

**它解决什么问题**：付费专栏两周读完用户就走；游戏 DAU 连跌，是运营没做好还是产品结构性的？

**核心逻辑**：把"用户会不会腻"从焦虑变成可判定问题——**不可预测性由谁制造？**只由设计者上新维持的是**有限多变性**：内容被消费后即变得可预见，用户的热情随剧情揭晓而消退，冷却不是运营失误而是结构宿命，唯一的活法是好莱坞式的工作室模式（不停押中新品，并把不确定性计入成本结构）。由其他参与者——对手玩家的出招、其他用户的创作——制造的是**无穷多变性**：用户自己互相制造新鲜感，供给不依赖你的内容团队。

**书中的用法**：Zynga 小镇系列"其实是新瓶装老酒"，玩家的热情很快消失、股价跌去 80%（L1478–1484）；反面是魔兽世界（队友的表现不可预知）与 Dribbble（设计师社区随潮流生长）——两条独立证据线指向同一结论：无穷多变性的来源是"他人"。

**什么时候会失效**：工具型产品的价值就在可预测，"用完即走"是正当的；变量是酬赏的属性——先选通道再查变量，别把"类型"和"存续"答成一个问题。

→ 深入: [`finite-infinite-variability`](./finite-infinite-variability/SKILL.md)

## 五、投入：让用户自己说服自己（第 5 章）

第四环是全书最反直觉、也最常被漏掉的一环。投入≠付费，而是用户向产品付出的点滴行为——它有两重回报：改写用户自己的态度（心理侧），沉淀为带不走的资产（资产侧），最后自动生成下一次召回（闭环侧）。四个单元构成完整的投入设计链。

### 三机制：宜家效应、一致性、文饰作用

**它解决什么问题**：SaaS 免费试用期间该让用户"做点什么"才能提高付费转化？用户评价"还行凑合"却每天用还续费，这种矛盾怎么解释？

**核心逻辑**：三条被实验反复证实的心理趋势，各有各的设计杠杆。**宜家效应**——为自己动手造的东西赋予更高估值（自折纸鹤的估值是旁观者的 5 倍，L1583），杠杆是"让用户动手造"；**行为一致性**——过去的微小行为预知未来行为（先贴 3 英寸小标识的居民，76% 同意立起难看的大牌子，直接请求只有 17%，L1593–1604），杠杆是"先要一个小承诺"；**避免认知失调**——人会给已付出的成本找理由（狐狸把够不着的葡萄说成酸的），杠杆是"允许用户保留自我合理化的空间"。三者汇成的总效应叫文饰作用：投入让用户自己说服自己，比任何营销话术都便宜且牢固。

**书中的用法**：游戏设计师谢尔复述"黑手党战争"玩家的心理过程——先承认游戏简陋，但"我已经为此花费了时间"，于是 20 美元"肯定物有所值，因为只有白痴才会白掏 20 美元"（L1625–1633）。作者展示这个案例时并未掩饰其操纵性质——它同时是第 6 章伦理讨论的引子。

**什么时候会失效**：宜家效应是估值偏差，不是价值证明——用它掩盖产品缺陷是把心理效应当遮羞布；以榨取持续付费为目的的投入设计（不可逆投入阻止用户离开的恶意锁定）必须被操纵矩阵拦截。

→ 深入: [`investment-changes-attitude`](./investment-changes-attitude/SKILL.md)

### 储存价值五形式：五条迁移性不同的绳索

**它解决什么问题**：续约率一直在掉，用户"也没啥不满，就是懒得续"——他们到底在我们这里存了什么、缺什么？竞品更好用为什么撬不动人？

**核心逻辑**：投入沉淀为五类资产，每类都是一条独立的转换成本——**内容**（iTunes 曲库、写过的帖子）、**数据资料**（LinkedIn 简历、Mint 聚合的账户，输入越多服务越准）、**关注者**（改换服务等于社交资产清零）、**信誉**（评分决定待遇，重建成本极高）、**技能**（Photoshop 熟练度无法迁移）。可区分判据是**迁移性**：技能不可迁移、内容可导出、关注者几乎不可迁移、信誉需重积累——诊断时要分清用户究竟被哪条绳索拴住。合法性前提："改换产品=放弃自己的一部分"，而不是导出门被焊死。

**书中的用法**：App.net 之死——"创建公司所需的技术一天之内就能建成"，但 Twitter 用户的关注网络、历史推文与多年经营的社会资本都无法复制，"对自己辛辛苦苦建起并精心呵护维持的关注群，没有人舍得放弃"（L1694–1714）。LinkedIn 的"哪怕一点点信息"判据则给出资产冷启动的操作规则：点滴投入从第一笔就开始累积，输入信息越多的用户回访频率越高（L1689）。

**什么时候会失效**：储存价值必须与隐私权衡（健康、财务数据存得越多风险越大）；GDPR 与数据可携带权之后，"资产天然不可迁移"的前提部分变成了法律义务；区分"用户真心获益的留存"与"被迫锁定的留存"是本书批判视角下最重要的一条边界。

→ 深入: [`five-stored-values`](./five-stored-values/SKILL.md)

### 时机与粒度：酬赏之后才要投入，小步开始

**它解决什么问题**：注册后要不要立刻让用户填 20 项资料？设置向导太长总被放弃，但每一步配置以后都有用，怎么办？

**核心逻辑**：先分段——**行动阶段求即时满足，要把摩擦减到极致；投入阶段关乎未来回报，可以有摩擦**（动手付出本身制造价值感），"体验永远越顺滑越好"的教条只对了一半。分段之内两条硬规则：**时序**——投入要求必须排在酬赏之后，顺序颠倒会同时撞上逆反心理与信任赤字；**粒度**——拆成小块、先小后大、随循环逐级加深、能预填则预填，因为目标渐近效应说明"看见自己接近目标"本身就是动力（洗车卡实验：同样消费 8 次，"10 次卡已免费打 2 孔"的组完成人数高出 82%，L1105–1109）。若用户没做你想要的投入，默认诊断不是"用户懒"，而是设计者要求太多（L1740）。

**书中的用法**：《圣经》应用把整本读经切成"所有步骤都以每日阅读为核心"的小片段（L2063）；Any.do 在第一次使用时先给祝贺与掌握感（酬赏），随即引导一个一步可完成的小投入——连接日历。

**什么时候会失效**：给注销流程加摩擦、以沉没成本为目的的繁琐步骤是恶意锁定不是投入设计；"小步"的最佳粒度无跨行业推导；GDPR/ATT 之后，预填与默认授权在多个法域有合规边界。

→ 深入: [`investment-timing-granularity`](./investment-timing-granularity/SKILL.md)

### 加载下一个触发：闭环的合页

**它解决什么问题**：推送打开率越来越低还被投诉骚扰；产品用完即走，怎么让用户"第二天主动回来"？

**核心逻辑**：循环要重新开始，必须有一个新触发把第四环接回第一环。本书的判据很硬：**触发必须由用户自己的投入内生生成**——发消息，对方的回复就成了通知；定日程，会前那一刻就成了推送时机；滑动匹配，匹配成功本身就是提醒。其二，**时机对准内部触发最活跃的瞬间**。这两条使它与一切运营群发有结构区别：群发打扰所有人、不建立情绪绑定，被感知为骚扰；内生触发只在用户自己安排的时刻出现，被感知为服务。

**书中的用法**：Any.do 在"下一个定期会议结束之后"发送通知，提示用户回来记录后续任务——外部触发恰好落在"怕忘事"的焦虑最活跃的时刻（L1753–1763）；Tinder 的每次点击累积匹配概率并推送通知，Snapchat 的每条阅后即焚照片都隐含"要求回应"——投入→触发的闭环可以压缩到单次会话之内（L1765–1779）。

**什么时候会失效**：内部触发尚未定位就先排推送时机，属于空转；把群发伪装成"个性化触发"改善打开率是明确的操纵（内生性的判定标准是触发事件来自用户行为，而非文案个性化）；通知过载的消耗在书中缺位——落地时应同时为用户保留关闭权。

→ 深入: [`load-next-trigger`](./load-next-trigger/SKILL.md)

## 六、道德闸门：先问"该不该"，再问"能不能"（第 4、6 章）

第 6 章在结构上是对第 2–5 章全部技术的"反驳性配套"——作者自认"如果你读时有精神控制说明书的感觉，那就太好了"（L1870）。这一章不是一个 skill 在守门，而是一个闸门加三个配套原则。

### 操纵矩阵：两问四象限

**它解决什么问题**：一个能拉 DAU 但制造焦虑的方案摆上了桌；团队为"盲盒要不要上"吵起来；发现自己正在为某个设计找正当理由——有没有一个框架判断这种事？

**核心逻辑**：两个问题交叉出四个象限——"我自己会使用这个产品吗"×"该产品会帮助用户大大提高其生活质量吗"。会使用+能提升=**健康习惯推广者**（成功概率最高，因为最懂用户）；不会用+声称能提升=**兜售商**（"现实扭曲场"使关键自问失效，广告业重灾区）；会使用+不提升=**娱乐用户者**（合法象限，但须靠持续上新在"跑步机"上奔跑，且不得伪装成提升生活质量）；既不用+不提升=**经销商**（剥削利用，道德与商业双输）。两条配套判据：**羞愧判据**——"如果你因为自己的所作所为而感到羞愧……请立刻停手"（L1908），回答时需要辩护本身就是失败的证据；**成瘾红线**——习惯与成瘾之辨（g20），制造自我毁灭式的被动依赖等同蓄意伤害。顺序不可换：先问该不该，再问能不能。

**书中的用法**：对照组是两位开发者——前海军军官哈里曼为设计扶贫方案与肯尼亚农民同住同耕（推广者先成为用户）；博格斯特的讽刺游戏 Cow Clicker 除点击奶牛听"哞"声外一无所有，却真有人不可救药地沉迷，最终引发"奶牛危机"，博格斯特本人把致瘾产品比作烟草（L1914–1963）。

**什么时候会失效**：矩阵全依赖自报与主观羞愧感，对自欺几乎无防御力——必须配合外部反馈（用户访谈、投诉数据）；它是自愿自检，不替代法律合规；"过了矩阵"不是免死金牌，外部数据恶化（如使用时长整体暴涨）时必须重新审视第二问。

→ 深入: [`manipulation-matrix`](./manipulation-matrix/SKILL.md)

### 三个配套原则

**保障自主权（p09）**：人对"被剥夺选择"有一触即发的防御反应——逆反心理；而规避方式反直觉：在提出要求的同一句话里明示对方可以拒绝——综合 42 项研究、22000 名参与者的分析，"你有权接受，也有权拒绝"让顺从率**翻倍**（L1421–1427），因为它卸去了"听命于人"的防御。产品化推论有两条：凡要求（授权、公开、记录、升级）都应附带退出选项与"拒绝不影响核心功能"的保证；强迫感本身就是设计缺陷的信号——Quora 未经提醒强加"显示浏览者身份"功能，数周后在声讨中撤回；作者对 MyFitnessPal 的弃用宣言是"我要么臣服，要么放弃，最终我选择了放弃"（L1455）。法定强制场景（实名制等）不能伪装成可拒绝——套用话术反而是欺骗。→ [`preserve-user-autonomy`](./preserve-user-autonomy/SKILL.md)

**重度使用保护义务（p16）**：这条原则的独特处是推理结构——**义务不来自伤害已经发生，而来自识别能力已经出现**。"公司现已首次被允许用自身数据标记过度使用的用户"（L1928），从这一刻起"不知道"不再构成辩护；"只有约 1% 病理性上瘾"不能当豁免理由（极端个案的诉讼与报道足以定义产品形象），作者甚至预言它将法律化——部分已经应验。落地动作：使用报告、用户可自设的限速、成瘾求助入口；边界是识别数据不得反用于优化粘性，且其余用户的行为责任归用户本人（L1966）。→ [`protect-heavy-users`](./protect-heavy-users/SKILL.md)

**改良而非替代（p18）**：让用户改变习惯，最稳的路径不是发布"新方式"，而是把产品呈现为既有行为的更顺手版本——照旧写周报，只是自动归档可检索——然后让用户自己决定换不换。心理机制与逆反心理同源：被迫换习惯触发对抗；威廉姆斯的观察给出方向性注脚——"人们上网只是为了继续做他们熟悉的事情"（L682）。Facebook 复刻线下花名册长成十亿用户产品是正向证据。操作判据：检验一个习惯设计是否健康，看用户是否保有**退回旧行为的自由**；业务上必须强制替换时，诚实说明原因、给足过渡期与储存价值补偿，不伪装成"为你好"的改良。→ [`upgrade-not-replace`](./upgrade-not-replace/SKILL.md)

## 七、测量与机会：把玄学变成程序（第 7、8 章）

第 7 章用《圣经》应用做了一次纵向串联——桌面网站之败（可及性不足=触发密度不足）到移动版成功的完整四阶段走查（通知/徽章/邮件/社区的多层触发、每日小片段的行动设计、"链条不断"的酬赏、高亮书签的投入与次日触发），1 亿台设备下载是这套模型的综合 demo。第 8 章则给了两件横向工具，这里取其测量件。

### 习惯测试三步：5% 门槛与习惯路径

**它解决什么问题**：DAU 看着还行，但投资人问"你的铁杆用户是谁、他们有什么共同行为"，答不上来；留存曲线一直掉，报告却只有折线图没有动作。

**核心逻辑**：三个动作顺序固定。**确定**——先于看数据定义"忠实用户应该"的使用频率，且不许拿专业用户当标准（社交产品设想每天多次，电影推荐每周不超过两次）；**分析**——活跃用户中至少 5% 达到你定义的频率，这是一个二元归因的硬门槛：不达标只有两种解释，用户判断错了，或产品要重做（作者自述 5% 是经验值，L2183）；**改进**——只从已达标的忠实用户行为流里反推共同序列（习惯路径），"你要找到一条'习惯路径'，即你最忠实的用户共同具有的一系列相似行为"（L2187–2188），然后通过注册渠道更新、内容变更、功能增删，把新用户往该路径上导。

**书中的用法**：Twitter 的"关注 30 人"——按三步走，发现新用户关注满 30 人是留存可能性的临界点，随后针对性改进注册流程鼓励即刻关注（L2189–2198）。

**什么时候会失效**：5% 对低频高价产品（汽车、房产、保险类）明显失灵；冷启动无数据阶段先做五问自检；只测频率不测质量——频率达标也可能来自焦虑驱动（打卡清零式使用），达标后应并操纵矩阵检查这个习惯是否值得经营、并按保护义务检查对过度使用者的责任。

→ 深入: [`habit-test-three-steps`](./habit-test-three-steps/SKILL.md)

## 八、21 个 skill 怎么组合用：典型使用路径

21 个 skill 不是并列的格言集，而是一台引擎的说明书：**hook-model-four-stages** 是总坐标系，四个阶段的单环 skill 是零件，习惯区间与维生素判据是入场前的两道闸，习惯测试是出厂后的验车，操纵矩阵与三个伦理原则是贯穿始终的守门员。四个典型组合：

**场景 A｜新产品出厂五问（从零开始）**：`four-opportunity-sources` 四路扫描找方向 → `habit-zone-frequency-first` 过频率×用途闸（低频且低用直接放弃）→ `hook-model-four-stages` 走五问逐环自检 → 按最弱一环下钻单环 skill：触发走 `five-whys-emotional-root` → `internal-trigger-anchoring`（配 `external-triggers-four-types` 做喂养），行动走 `bmat-action-diagnosis` → `six-simplicity-elements`/`three-core-motivations`，酬赏走 `three-variable-rewards` → `finite-infinite-variability`，投入走 `investment-timing-granularity` → `investment-changes-attitude`/`five-stored-values` → `load-next-trigger` 闭环 → `manipulation-matrix` 过闸上线。

**场景 B｜现有产品习惯诊断（数据在手）**：`habit-test-three-steps` 先定义频率、过 5% 门槛、提取习惯路径 → `hook-model-four-stages` 定位循环断在哪一环 → 单环 skill 深挖修复 → 迭代后复测。留存诊断的双支柱分诊：用户是"腻了"（→ `finite-infinite-variability`）还是"没沉淀"（→ `five-stored-values`）；行为是"不想做"（→ `three-core-motivations`）还是"做不动"（→ `six-simplicity-elements`）。

**场景 C｜伦理危机与灰色方案**：`manipulation-matrix`（该不该：两问四象限+羞愧判据）→ 被质疑"致瘾"时 `protect-heavy-users`（义务执行：报告/限速/求助流程）→ 单次要求的措辞与退出权归 `preserve-user-autonomy`；用户抵触换新工具/改版抗议走 `upgrade-not-replace`。测出来的高频用户若呈失控迹象，从 `habit-test-three-steps` 的经营对象转为 `protect-heavy-users` 的保护对象。

**场景 D｜增长手段审查**：投放依赖（停投即流失）→ `external-triggers-four-types` 判停转 `internal-trigger-anchoring`；游戏化方案 → `three-variable-rewards` 对齐检查；推送召回 → `load-next-trigger` 验内生性；每一条的输出最终都过 `manipulation-matrix`。

一条总规则：**每个 skill 的"何时不调用"清单就是下一个 skill 的入口**——这正是阶段 3 给 21 个 skill 铺设 49 条显式链接的用意（引用图见 [INDEX.md](./INDEX.md)）。

## 陷阱与反例

来自全书反例池（22 条中杀伤力最大的 6 条）：

1. **爆品陷阱**：一夜爆红的产品往往触发、行动、社交酬赏三环俱全，但缺第四环投入——"爆品也会随着时间推移而丢掉你的注意力"（ce21）。预警信号：热度高但用户没存下任何东西（无收藏、无数据、无关系链），下一轮召回仍靠烧钱。
2. **金钱挤出真动机（Mahalo 之败）**：把经济利益当杠杆驱动内容社区，金钱重新定义行为性质——补贴一停贡献即停、用户公开计算时薪、社区氛围交易化（ce08）。预警信号：贡献者开始谈论"值不值这个钱"。
3. **Zynga 换皮破产**：复制机制外壳而不注入新的不可预测性，玩家可预见一切后续体验（ce11）。预警信号：新品与旧品只有皮肤差异、社区出现"换皮"共识、收入集中于单一 IP。
4. **强迫式记录触发逆反（MyFitnessPal 之败）**：把帮助设计成审计，漏记一天即前功尽弃——投入无酬赏支撑、粒度无阶梯、时序上全程索求，"要么臣服，要么放弃"（ce10）。预警信号：用户出现"欠债感"、断签清零、记录动作本身带惩罚。
5. **自检的自我欺骗**：用正当化说辞回答操纵矩阵两问（"用户应该会喜欢的""这算不上操纵"）——辩解行为本身即动机性推理的证据（ce18）。预警信号：给两问加例外条款、用商业成功论证道德。
6. **"略胜一筹"的产品幻觉**：创业者以为功能好 10%–20% 就能撬走用户，但切换意味着重学+放弃储存价值，微弱优势被切换成本吞没，新产品反而"感觉更差"（ce05）。预警信号：竞品分析与攻击方案里完全没有"用户的储存价值"这一栏。

## 作者的局限（读这本书要打的折扣）

1. **2014 年硅谷移动红利期语境**：案例集中于 Facebook/Instagram/Twitter/Pinterest 等消费 App，默认"App 图标占据手机首屏"是自主型触发的主战场；小程序、超级 App 内嵌生态、直播电商、订阅制均未覆盖。套用前先对今日产品重新映射四类触发与"一次使用"的计量方式。
2. **算法推荐把链条部分短路**：推荐流让用户**无须投入**即可获得个性化多变酬赏——本书"投入→储存价值→依赖"的路径在算法主导产品中被"可刷性"取代；"无穷的多变性"被工业化后，还出现了作者未推演的军备竞赛后果（所有产品都变量化，用户的渴望阈值整体抬高）。作者 2019 年在新版后记转向"专注力/戒断"话题，间接承认了这一变化。
3. **最核心的断言论证最少**："内部触发可以通过设计安装"依赖解释性案例而非证据，无法排除"本来就想拍照的人自己找到了工具"；"习惯=依赖=企业收益"的因果链由幸存者叙事支撑，书中无对照研究，且写作期正值心理学复制危机发酵而只字未提（转引的小样本实验——折纸、洗车卡——效应量未验证）。
4. **设计师本位，用户是被塑对象**：全书视角始终是"我们如何钩住他们"，即便第 6 章谈道德，落点仍是设计者的良心与商业成功；用户侧的赋能工具（屏幕时间、默认关闭、数据可携带）几乎不讨论。本批 skill 保留了机制的反向用法——作为用户识别自己被钩住机制的自查工具。
5. **"1% 上瘾"的框定淡化分布问题**：作者把病理性上瘾淡化为例外、把其余责任推给用户（L1966），回避了默认设置与产品形态管制的解法。此后的注意力经济批判（Tristan Harris 等）指出：问题不是 1% 的极端者，而是全体用户的使用分布整体左移——这条线书中没有，本批 skill 的保护义务单元已用"分布复查"步骤补上。
6. **框架包摄力极强、可证伪性弱**：产品成功可解释为"符合模型"，失败可解释为"某环没做好"。本批 skill 用习惯测试的二元归因与判停条件保持可证伪性，但用它做事后归因时仍要警惕"怎么解释都对"的陷阱。

## 关键术语速查

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 习惯（habit） | "在情境暗示下产生的无意识行为"（L136） | ≠爱好/依赖/忠诚；判据是无意识，≠成瘾 |
| 上瘾模型（Hook Model） | 触发→行动→多变的酬赏→投入的**闭环**；目标是习惯不是成瘾 | ≠成瘾机制；≠线性增长漏斗 |
| 触发（三个含义） | 外部（信息中的行动召唤）/ 内部（情绪锚点）/ 加载下一个触发（投入生成的召回） | ≠推送统称；三个"触发"不可混用 |
| B=MAT | 行为=动机×能力×触发的乘法诊断式 | ≠需求分析；任一为零乘积为零 |
| 多变的酬赏 | 效力来自不可预期性；社交/猎物/自我三通道 | ≠积分奖励；"多变"≠"多" |
| 投入（investment） | "提升后续服务质量"的点滴行为，非付费 | ≠付费≠行动；行动减摩擦、投入可加摩擦 |
| 储存价值 | 内容/数据/关注者/信誉/技能五类资产 | ≠锁定；分界线是退出权与真实价值 |
| 习惯区间 | 频率×可感知用途的过滤坐标系；频率是硬轴 | ≠爆品标准；"多高算高"无定论 |
| 痒（itch） | 潜伏的、低烈度的持续渴求；"无法实施即痛苦"=习惯已成 | ≠痛点；判据只认行为证据不认态度数据 |
| 逆反心理 | 自主权受威胁时的对抗反应；明示"可拒绝"反而顺从翻倍 | ≠用户任性；是可设计的设计变量 |
| 多变性（有限/无穷） | 不可预测性由谁制造的结构属性 | ≠更新频率；决定商业模式 |
| 操纵矩阵 | 两问四象限的**出厂自检**；先"该不该"后"能不能" | ≠合规清单；自检≠免死金牌 |
| 习惯测试 | 定义频率→5% 门槛→习惯路径→改产品 | ≠留存报表；产出物是习惯路径 |
| 成瘾（addiction） | 长期被动依赖并走向自我毁灭 | 与习惯的分界是全书伦理红线 |

完整 27 条词典见 [GLOSSARY.md](./GLOSSARY.md)。

## 如果只带走三句话

1. **四阶段是闭环，投入是枢轴**——评价对象是"圈速与圈数"而非单程转化率；用户投入的每一点东西（内容、数据、关注者、信誉、技能）都反过来让下一圈更容易，而"投入"指的是改善后续服务的行为，不是掏钱。
2. **先测量，再优化；先过闸，再施工**——习惯用 5% 门槛与习惯路径验证，不看留存曲线的玄学叙事；任何循环设计落地前先过操纵矩阵两问，"该不该"永远先于"能不能"。
3. **外部触发买注意力，内部触发买反射；酬赏值钱的是渴望，多变性会耗尽**——让情绪成为你的召回引擎，让"他人"替你制造不可预测性，然后诚实回答：这条反射弧是否真的提高了用户的生活质量。
