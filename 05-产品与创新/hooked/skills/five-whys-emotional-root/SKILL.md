# 五连问挖到"可锚定情绪"的内部触发

## R — 原文 (Reading)

> "要进入某种情绪状态，你可以尽可能多地问问自己'为什么'。通常当你问到第五个'为什么'时，你所期冀的情绪状态就会出现。这就是在丰田生产系统中被大野耐一称为'5问法'的著名方法。"
>
> — 第2章 安装触发（L696）

> "5. 她为什么会在意这一点？答案：因为她害怕被圈子所抛弃。现在我们有答案了！恐惧感是她身上最强大的内部触发，因此，我们在设计产品时，应该考虑使它能减轻用户的恐惧心理。"
>
> — 第2章 安装触发（L720–722）

> "只有当你的研究重心放在人们的实际行为（看关于猫的视频）而非内心愿景（拍摄具有影院效果的家庭录像）上时，你才会发现更多的可能性。"
>
> — 第2章 安装触发，艾丽卡·霍尔语，埃亚尔转引（L686）

---

## I — 方法论骨架 (Interpretation)

用户嘴里说出来的永远是功能请求（"我要更快的报表"），而驱动他日复一日回到产品的却是功能背后的情绪。五问法是一条从功能层下钻到情绪层的探针：对同一个行为连续问五次"为什么"，每一问都针对上一问的答案再问一层动机。

埃亚尔对丰田原版做了一个关键改用：**终点判据变了**。丰田问五个为什么是为了找到流程或系统的根本原因；这里问五个为什么，是为了到达一个**可锚定的情绪状态**——所以停问信号不是"找到根因了"，而是"答案里出现了情绪词"（怕、焦虑、孤独、兴奋、怕被抛弃）。

两条使用纪律：其一，起点决定终点——起点选错（比如从错误的功能假设出发），五层答案会整条走偏，作者明言"如果一开始我们选择的对象不是朱丽……得出的结论就可能完全不同"（L722）；其二，起点要长在**实际行为**上而不是用户的口头愿景上（霍尔语，L686），因为言语不总能反映真实想法（L684）。挖到的情绪不是终点，它是内部触发设计的原材料。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 朱丽与"电子邮件"——五连问完整链条
- **问题**: 假设即将推出一款新技术（电子邮件），如何确定目标用户朱丽（中层经理）使用它的真实内部触发，而不是照着功能清单设计？
- **方法论的使用**: 作者基于朱丽的用户资料逐层推演五问：为什么用电子邮件？→收发信息。为什么收发信息？→分享并即时获取信息。为什么想分享获取？→了解同事朋友家人的生活。为什么想了解他们？→知道自己是否被别人需要。为什么在意这一点？→害怕被圈子抛弃（L700–720）。
- **结论**: "恐惧感是她身上最强大的内部触发"——产品设计应对准减轻这种恐惧，而不是宣传"更快的邮件"；同时作者自警：起点不同，结论可能完全不同，唯有准确把握潜在需求才能获得有价值启发（L722）。
- **结果**: 该链条成为第 2 章的标准示范，并固化为章末练习的作业规范——"想出三个能够促使用户使用该产品的内部触发，可参照本章中介绍的'5问法'"（L774），供读者对自己的产品实际执行。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 功能请求与使用行为脱节：用户喊"要更快的报表/更好的搜索"，团队照做提速了，使用率却没涨——需要下钻到功能背后的情绪动机。
2. 访谈提纲设计：做用户研究时不知道往哪深挖，或访谈收上来一堆功能愿望清单，要找出"为什么是这个功能"的情绪层答案。
3. 文案与定位的输入缺失：写推送文案、落地页、产品定位时，知道要"对准情绪"但说不出对准哪个情绪。
4. 竞品复盘：同样的功能竞品没人用你的有人用（或反过来），要找行为差异背后的情绪根源。
5. 跨域自查（个人）：对自己的某个习惯行为连问五个为什么，找出"我到底在安抚什么情绪"——如"为什么总忍不住刷手机"，作为自我洞察工具。

### 语言信号 (用户的话里出现这些就应激活)

- "五连问 / 5 个为什么 / 五个为什么 / 5 whys / five whys"
- "表层需求背后的真动机 / 真正想要的是什么 / root cause / 挖到根源"（underlying motivation, dig deeper）
- "用户口是心非 / 说一套做一套 / 嘴上说想要 A 行为却是 B"（says one thing, does another）
- "用户的情绪触发点是什么 / 他们在害怕什么 / 安抚什么情绪"（emotional trigger, what are they afraid of）

### 与相邻 skill 的区分

- 与 `internal-trigger-anchoring` 的区别：f06 是发现工具（研究中挖出情绪根源），f05 是安装机制（设计上把情绪与产品绑成条件反射弧）。用户在问"怎么挖"时用 f06，问"挖到之后怎么绑、怎么喂养"时才用 f05。
- 与丰田原版 5 Whys 的区别：原版用于流水线故障的根因分析（机器停了→保险丝烧了→过载→……→采购流程缺陷），终点是**流程/系统根因**；本 skill 终点是**可锚定的情绪**，停问信号是情绪词。设备反复停机找根因不属于本 skill。
- 与 `three-core-motivations` 的区别：f08 是动机分类学（三组趋避杠杆，用于选文案方向），f06 是挖掘方法（找到具体情绪锚点）；顺序上先 f06 挖到情绪，再用 f08 归类杠杆方向。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **校验并固定起点**
   - 完成标准: 写下表层陈述（用户说要什么/实际做什么），并用两条纪律校验：起点基于**实际行为**而非口头愿景（L686）；起点具体可观察（"打开报表模块导出周报"，而非"提升工作效率"这种抽象愿望）。

2. **连问五次为什么**
   - 完成标准: 得到 5 层递进答案链，每层针对上层答案追问动机，不得跳层；真实访谈中对用户本人发问，案头推演时基于用户资料与情境（如朱丽案例的做法），不凭空代答。

3. **停问判据**
   - 完成标准: 答案中出现**情绪词**（怕/焦虑/压力/孤独/怕被抛弃/兴奋等）即停——不必机械凑满五问；若第五问仍无情绪词，判起点选错，回到步骤 1 换起点重来，**不得硬凑情绪答案**。

4. **交叉验证锚点**
   - 完成标准: 把挖到的情绪拿回独立证据验证：至少一条行为数据或多用户访谈支持该情绪在目标人群中高频出现（连接 `habit-zone-frequency-first` 的频率判据）；单一用户的单一链条不直接当普遍规律（作者警告：起点不同答案完全不同）。

5. **交接与落句**
   - 完成标准: 用绑定句式落成一句话输出——"每当用户感到 X（情绪），他就会 Y（行为/产品入口）"，移交 `internal-trigger-anchoring` 做绑定与喂养设计、`three-variable-rewards` 做酬赏对齐（酬赏设计第一规则：回答用户为什么来）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 机械/流程故障的根因分析：那是丰田原版 5 Whys 的领地，终点是流程改进而非情绪；混用会把工程问题心理化。
- 审问式访谈：对真人连问五个"为什么"容易触发防御、得到编造的合理化答案——作者配套的做法是基于情境与资料推演（多尔西的"编写用户情境体验"，L689–694）、配合移情图等工具，而非把五问当审讯脚本。
- 情绪不该被挖的场景：求职背调、医疗心理评估等敏感场景，本 skill 的产品研究纪律（最小必要、可验证）不构成专业授权。

### 作者在书中警告的失败模式

- 口是心非："通过言语交流来让用户透露他们的所思所想似乎并不现实……言语不一定能反映出最真实的想法"（L684）——直接问"你为什么用"得到的多半是功能说明书，五问必须下钻。
- 用内心愿景当起点（霍尔语，L686）：研究"用户想拍影院级家庭录像"而非"用户实际在看猫视频"，整条链会在第一层就失真。
- 起点偏差传导（L722）：起点不是朱丽（或行为选错），五层结论整条不同——作者以此自警，挖到"漂亮情绪"不等于挖对了。

### 作者的盲点 / 时代局限

- 出处披露：5 问法源自丰田生产系统的大野耐一（作者自注，L696），非埃亚尔独创；其可区分增量仅在把终点判据改为"可锚定的情绪状态"并用于内部触发挖掘——引用时不得把方法本身记在埃亚尔名下。
- 示例是推演而非实证：朱丽案例是作者虚构的推演（cases.md c05 明确记录），书中无真实用户五连问的纵向记录佐证链条有效性；跨文化情绪表达差异（何时愿意承认"怕被抛弃"）书中无着墨。
- 设计者本位：默认人类设计者洞察人类用户；生成式 AI 产品的"用户"与"访谈"形态都在变化（对话日志可替代部分访谈），书中无此讨论。

### 容易混淆的邻近方法论

- 丰田 5 Whys：同源不同判据（见 A2）；引用时区分"根因停"与"情绪词停"。
- 用户旅程图：旅程图描述行为路径与触点，不提供情绪下钻；两者可配合（旅程图定位环节、五问下钻动机）。
- 移情图（empathy map）：书中列出的配套工具（L694），产出情绪候选但不能替代五问的链条式下钻。
- `motivational interviewing` 等专业访谈流派：那是心理干预技术，本 skill 是产品研究工具，专业心理场景不适用。

### 伦理红线

五问挖到的是用户不愿明说的情绪弱点，红线：**挖到的情绪不用于操纵**——不放大恐惧再卖安抚（恐吓式营销）、不用挖到的焦虑做定向推送的弹药、不为转化率刻意刺激"怕被抛弃"类情绪；对未成年人不做情绪挖掘式设计；情绪信息按最小必要原则使用与存储。产出物的合法去向是让产品更准确地**缓解**真实不适（f05 的即时药方资格验证），落地前过操纵矩阵（`manipulation-matrix`）两问。
