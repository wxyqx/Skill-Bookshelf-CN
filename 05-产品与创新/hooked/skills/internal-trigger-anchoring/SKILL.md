# 内部触发锚定（情绪→产品条件反射）

## R — 原文 (Reading)

> "情绪，尤其是负面情绪，是一种威力强大的内部触发，能给我们的日常生活带来极大的影响。诸如厌倦、孤独、沮丧、困惑或者游移不定等情绪常常会让我们体验到轻微的痛苦或愤怒，并使我们几乎在一瞬间就不自觉地采取行动来打压这种情绪。"
>
> — 第2章 内部触发（L643）

> "内部触发与产品之间的纽带并不是一蹴而就的。有时候你需要频繁使用几个星期或几个月的时间，才能让内部触发发展为行动暗示。外部触发可以培养新习惯，而内部触发造就的情感纽带则可以让新用户变成你产品的铁杆粉丝。"
>
> — 第2章 内部触发（L667）

> "感到无聊时，许多人都会想方设法找乐子，会去浏览醒目的新闻头条。压力太大时，人们会更渴望平静，也许会在 Pinterest 这样的网站上找到寄托。形单影只时，Facebook 或者 Twitter 可以让我们立刻感受到他人的陪伴。"
>
> — 第2章 内部触发（L659）

## I — 方法论骨架 (Interpretation)

外部触发（推送、广告、朋友邀请）只能把用户拉进循环一次两次；习惯的终点是**内部触发接管**——某种情绪一出现，产品就自动出现在用户脑海中，无须任何外部刺激。这就是"从依赖外部触发转向利用内部触发"（L1847）。

这个机制有三个要点。第一，安装点是**情绪**，尤其是负面情绪：无聊、孤独、压力、怕错过、不确定感——它们制造轻微不适，人几乎在一瞬间就不自觉地想打压它。第二，产品的角色是这股情绪的**即时药方**：设计者的第一功课不是列功能清单，而是弄清用户在何种情绪下、何地、何时会需要你（L676），且产品的抚慰必须比"忍着"更快。第三，绑定靠**喂养**形成：外部触发在情绪最活跃的时机反复出现，数周到数月后，情绪与产品之间的纽带（作者比作牡蛎中的珍珠质）才长成条件反射。

它是全书机制的核心，也是伦理风险最高处——把"情绪-行为"反射弧当作可施工的对象，前提是这条弧对用户的生活真正有益。

## A1 — 书中的应用 (Past Application)

### 案例 1: 英与 Instagram——FOMO 的锚定
- **问题**: 英自称"我没想用它来解决什么问题，只是看见好玩儿的东西就想拍下来"（L539–545）——一个"没解决任何问题"的产品为什么能成为日常必需品？
- **方法论的使用**: 作者拆出她看不见的内部触发："每当她担心某个与众不同的时刻会一去不复返时，就会打开 Instagram"（L643–645）——FOMO（怕宝贵时刻一去不复返）才是锚点；Instagram 通过外部触发完美转换至内部触发，成为满足这份需求最直接的途径（L669）。
- **结论**: 用户报告的功能理由与真实锚定情绪是两回事；"怕美好时刻流逝"这种低烈度持续不适才是高频触点。
- **结果**: 用户达 1.5 亿、10 亿美元被收购（c03）；"英不再需要外部刺激来打开这款应用，因为内部触发已经自动开始工作了"（L669）。

### 案例 2: 《圣经》应用——情绪低落时的自动求助
- **问题**: 读经计划的日常打开靠推送，但推送之外用户还会在什么时候想起它？
- **方法论的使用**: 数据分析显示，已养成习惯的读者"不仅在看到自己手机上的通知时使用《圣经》应用程序，而且只要他们感到情绪低落、需要一种方式来振作精神的时候都会使用该程序"（L2093）——情绪锚定已建立，触发权从运营转移到了用户的情绪状态。
- **结论**: 内部触发接管的标志是：外部通知之外，情绪波动本身开始驱动使用。
- **结果**: 应用成为用户情绪管理的默认选项，读经习惯稳固形成（第 7 章综合案例结论）。

### 佐证: 密苏里科技大学 216 人追踪研究（L651–655）
一学年追踪显示，访问过抑郁症咨询页面的学生使用电子邮件、看电影、玩游戏、聊天的频率显著更高——承受负面情绪的人会更多地从科技中寻求安慰、调节心情。这是"负面情绪→科技使用"方向的独立行为学证据线。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "功能没问题但用户不惦记"：产品可用、评价尚可，但没有推送用户就不回来——缺的不是功能而是情绪锚点。
2. 工具型产品的日常化：番茄钟、记账、背单词类工具只在特定压力场景（deadline、报税、考试前）被想起，要让某个更高频的情绪成为默认入口。
3. 触发设计的交接：用 `five-whys-emotional-root` 或访谈挖出了情绪根源，下一步要把它落成"每当用户感到 X 就会 Y"的绑定设计并安排喂养期。
4. 跨域自查（用户视角）：识别自己"一无聊就刷、一焦虑就囤"的条件反射——机制反向使用，帮助觉察被钩住的状态、重建设计替代反应。
5. 跨域（个人习惯设计）：给自己或他人设计习惯时，把目标行为绑到一个真实高频的情绪/情境锚点上（如"一坐下就开番茄钟"绑"启动困难"感），而非依赖意志力。

### 语言信号 (用户的话里出现这些就应激活)

- "内部触发 / internal trigger / 情绪锚点 / 情绪-产品绑定"（emotional trigger, anchor）
- "一……就……：一无聊就刷、一焦虑就想打开 / 条件反射 / 自动联想"（whenever I feel..., I automatically open...; conditioned response）
- "不用推送也会来 / 自动想起 / 铁杆粉丝 / 不请自来"（come back without notifications, top of mind）
- "用户在什么情绪下会想起我们 / 我们的产品安抚什么情绪"（what emotion does our product soothe）

### 与相邻 skill 的区分

- 与 `five-whys-emotional-root` 的区别：f06 是发现工具（用户研究中把表层需求挖到情绪根源），f05 是安装机制（设计上把情绪与产品绑成反射弧）。f06 的产出（可锚定情绪）是 f05 的输入；访谈阶段用 f06，触发设计阶段用 f05。
- 与 `external-triggers-four-types` 的区别：f04 管外部信息中的行动召唤（拉新 + 喂养期的载体），f05 管情绪绑定的终局。方向性规则：外部触发的终局是被内部触发取代——喂养期一过，外部触发应可撤出。
- 与 `three-variable-rewards` 的区别：酬赏是循环第三阶段"痒被挠到"的满足物，f05 是第一阶段"痒被唤起时的自动联想"；锚定在触发层成立，酬赏决定每次挠痒是否到位，两者不能互相替代。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列情绪候选清单**
   - 完成标准: 用 `five-whys-emotional-root`、用户情境体验或行为数据，列出目标用户 3 个以上高频负面/正面情绪候选（参考书中清单：无聊、孤独、压力、FOMO、不确定感），每个情绪附真实情境描述（谁、何时何地、什么场合出现）。

2. **选锚点并验证"即时药方"资格**
   - 完成标准: 按出现频率选出最高频情绪，验证产品能**比"听之任之"更快地**缓解它；用一句话写出绑定句式："每当用户感到 X，他就会 Y（产品的核心动作）"。若缓解是延迟的、间接的（如报税工具缓解焦虑要一周后），该情绪不合格——回到清单换锚点或判停。

3. **设计喂养期**
   - 完成标准: 制定外部触发喂养计划，三要素齐全：频率（数周到数月的持续喂养，L667）、渠道（四类外部触发中成本可持续的自主型为主）、时机（对准该情绪最活跃的瞬间）。产品每次对该情绪的回应保持一致（同一入口解决同一不适）。

4. **判停条件**
   - 找不到"产品能即时缓解"的高频情绪 → 不硬装条件反射，诚实定位为工具型产品（靠 `habit-zone-frequency-first` 的用途轴或储存价值路线），硬绑会因无真实抚慰而失败。
   - 用户对情绪绑定设计表现出被操纵感（逆反信号）→ 停止加强喂养，转 `preserve-user-autonomy` 检查自主权设计。

5. **验收与移交**
   - 完成标准: 观察验收信号——用户开始在没有外部触发的情况下自动使用（内部触发接管，参照《圣经》应用 L2093 的"情绪低落时使用"）；把绑定句式移交 `three-variable-rewards` 做酬赏对齐（回答"用户为什么来"），移交 `load-next-trigger` 让用户投入接手后续触发。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 低频工具硬找情绪锚：报税、房贷、体检类产品没有高频情绪可绑，硬造锚点只会产出打扰式推送——先过频率判据。
- 把品牌好感当内部触发：品牌印象/心智份额是态度，内部触发特指情绪→产品的自动反射弧；"用户喜欢我们"不等于"情绪一出现就想起我们"。
- 一次性/低价值场景：为用一次就走的场景安装反射弧既无效也不道德，喂养成本收不回来。

### 作者在书中警告的失败模式

- 纽带建立需要时间，急于求成必败："并不是一蹴而就的。有时候你需要频繁使用几个星期或几个月的时间，才能让内部触发发展为行动暗示"（L667）——指望几周推送就把反射装好，是喂养期设计最常见的失败。
- 只靠付费型外部触发喂养（ce03）：喂养渠道若长期依赖广告，停投即流失——因为付费触发从不生成内部绑定。
- 习惯与成瘾之辨（L476）：锚定目标是习惯（无意识但有益或至少无害的行为），不是成瘾（"长期且被动地依赖……最终使人走向自我毁灭"）；设计者须能说出这条反射弧改善用户生活的具体方式。

### 作者的盲点 / 时代局限

- 归因跳跃（BOOK_OVERVIEW 未证假设 3）："内部触发可以通过设计安装"是全书最核心但论证最少的断言——Instagram 是解释性案例而非证据，无法排除"本来就想拍照的人自己找到了工具"。使用本 skill 时把安装成功当**待验证假设**，用 f20 习惯测试验收，而非设计即生效。
- 2014 年情绪清单的时代性：无聊/孤独/FOMO 的锚定案例全部来自消费社交 App；算法推荐时代，产品端工业化供给的多变酬赏（可刷性）部分替代了情绪锚定的角色，AI 陪伴类产品更直接以拟社会关系为酬赏——情绪锚定的深度与伦理风险都在升级，书中无此讨论。
- 设计师本位：全书视角是"我们如何绑定他们"，不讨论用户侧的觉察与退出工具；本 skill 保留反向用法（A2 情境 4 的自查），用机制帮用户识别被钩住的状态。

### 容易混淆的邻近方法论

- 品牌定位/心智份额（mind share）：定位是认知联想，锚定是情绪反射弧；前者可靠广告达成，后者只能靠反复的共同体验。
- 心理学"锚定效应"（anchoring effect）：那是数字判断偏差（启发法），与本 skill 的情绪锚定毫无关系——本批单元组内 f11（启发法）已淘汰，勿混引。
- `hooked` 之外的 CBT/习惯环路（cue-routine-reward）：结构同源，但本 skill 的判据（负面情绪优先、即时药方、外部触发喂养）来自本书；做心理干预设计时应回到专业来源。

### 伦理红线

本 skill 是全书机制核心、伦理风险最高处。红线：**不用于绕过用户自主权的设计**——不得刻意放大或制造负面情绪（人为制造焦虑、孤独感、FOMO 再卖药方）；不得对未成年人做情绪锚定设计；不得把"让用户离不开"本身当目标（L476：生产让用户成瘾的产品等同于蓄意伤害）；锚定的情绪必须是产品真能即时缓解的真实不适，且用户保有随时退出的畅通路径。任何落地动作先过操纵矩阵（`manipulation-matrix`）两问：我会用吗？能否大大提高用户生活质量？作为用户自查工具使用时，目标是帮助识别与重获控制，不是强化依赖。

## 相关 skills

本 skill 是全书机制的核心与伦理风险最高处：上游接发现工具，下游交酬赏与召回，出现逆反信号转自主权检查。
