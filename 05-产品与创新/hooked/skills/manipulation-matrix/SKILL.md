# 操纵矩阵：该不该 vs 能不能（出厂道德自检）

## R — 原文 (Reading)

> "该操纵模式并不打算回答诸如哪些企业讲道德或哪些企业会取得成功这样的问题……而是旨在帮助你回答问题'我应该去牢牢抓住我的用户吗'，而不是'我能牢牢抓住我的用户吗'。"
>
> — 第6章 上瘾模型与道德操控（L1894）

> "如果你发现自己在问自己这些问题的时候感到羞愧，或者回答问题的时候需要证明自己是正确的，或需要为自己寻找正当理由，那么请立刻停手！你已经失败了。"
>
> — 第6章 上瘾模型与道德操控（L1908）

> "'成瘾'指的是长期且被动地依赖某种行为或是某个东西。依照定义，'成瘾'最终会使人走向自我毁灭。因此，生产让用户成瘾的产品是不负责任的表现，因为这等同于蓄意伤害。"
>
> — 第1章 习惯的力量：如何让你的产品从维生素变成止痛药（L476）

---

## I — 方法论骨架 (Interpretation)

操纵矩阵把"道德"从口号变成一张出厂检查表，在一切习惯设计技巧启用之前先回答"该不该"。两个问题交叉出四个象限：会使用+能提升生活质量=健康习惯推广者（成功概率最高，因为最懂用户）；不会用+声称能提升=兜售商（脱离用户，成功率极低，广告业重灾区）；会使用+不提升生活质量=娱乐用户者（合法象限，但须靠持续上新在"跑步机"上奔跑，且不得伪装成提升生活质量）；既不用+不提升=经销商（剥削利用，道德与商业双输）。两条配套判据：羞愧判据——回答时需要辩护、寻找正当理由，本身就是失败的证据；成瘾红线——设计习惯正当，制造自我毁灭式的被动依赖等同蓄意伤害。顺序不可换：先问该不该，再问能不能。

## A1 — 书中的应用 (Past Application)

### 案例 1: 哈里曼的努鲁国际 vs Cow Clicker
- **问题**: 怎样判断自己（或一个产品）落在矩阵的哪个象限？
- **方法论的使用**: 对照组一——前海军军官哈里曼为设计扶贫方案与肯尼亚农民同住同耕："只有将自己变成那些农民中的一员，哈里曼才能设计出解决方案"；对照组二——博格斯特的讽刺游戏 Cow Clicker 除点击奶牛听"哞"声外一无所有，却真有人不可救药地沉迷。
- **结论**: 推广者先成为用户；剥削型钩子只能靠操纵漏洞运转。
- **结果**: 博格斯特本人关闭游戏，引发"奶牛危机"，并把致瘾产品比作烟草（第 6 章，L1914–1922、L1956–1963）。

### 案例 2: 兜售商的"现实扭曲场"
- **问题**: 为什么设计者不用自己的产品就做不出好东西？
- **方法论的使用**: 作者分析兜售商象限的心理机制——"现实扭曲场"使设计者无法提出关键问题"我真的认为这有用吗"。
- **结论**: 答案几乎总是"不"；兜售商对用户做不到感同身受，只能靠想象填补用户模型。
- **结果**: 成为第 6 章四象限分析中对广告业"重灾区"的诊断（L1936–1944）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 上线前/接需求前的伦理把关：一个能拉 DAU 但制造焦虑的方案摆上了桌。
2. 团队争论增长手段是否越线：开箱抽签、无限滚动、红色角标、假装限时、放大社交攀比。
3. 职业自检：在一家"我知道它在操纵用户"的公司工作，要不要继续。
4. 自我识别：发现自己正在为某个设计找正当理由——辩解本身是信号。

### 语言信号 (用户的话里出现这些就应激活)

- "这样会不会太操纵 / 良心不安 / 合乎道德吗"（is this manipulative, ethics of engagement, guilty conscience）
- "该不该做 / 越线了吗 / 黑暗模式 / dark pattern"（should we do this, crossing the line, dark pattern）
- "停不下来算不算问题 / 上瘾红线 / 我们在制造成瘾吗"（addiction, compulsive use, are we creating addiction）

### 与相邻 skill 的区分

- 与各机制 skill（f04–f17、p09/p18）的区别：机制 skill 回答"怎么做"，f18 是前置闸门——任何机制设计落地前先过两问；机制 skill 的 E 段伦理复核步骤都指向本 skill。
- 与 `p09-preserve-user-autonomy` 的区别：p09 是单一交互规则（要求怎么提、明示可拒绝），f18 是整产品的象限自检。Quora 案例两者都涉及：p09 解释它为何失败（逆反），f18 问它该不该上线。
- 与 `p16-protect-heavy-users` 的区别：f18 在做之前划"做不做"的界，p16 在做了之后管"对被识别的过度使用者怎么办"——同一伦理链条的上下游两站。
- 与 `p18-upgrade-not-replace` 的区别：p18 是采纳策略（怎么让用户换过来），不判断产品本身该不该做；判断性疑问归 f18。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诚实回答第一问**
   - 完成标准: 明确回答"我自己会（定期）使用这个产品吗"，附真实使用证据（今天/本周用过什么功能）；答"不会"即预判兜售商或经销商象限，进入第 2 步复核。

2. **具体回答第二问**
   - 完成标准: 说出产品如何"大大提高"用户生活质量的具体机制（不是"提供便利"式套话）；说不出即落入娱乐用户者或经销商象限。

3. **羞愧判据复核（判停条件）**
   - 完成标准: 检查自己是否在"组织辩护""给两问加例外条款""用商业成功论证道德"。
   - 判停条件: 任一出现，按作者判据"请立刻停手"——方案驳回或重构，不以"平衡讨论"的名义继续推进。

4. **成瘾红线检查**
   - 完成标准: 对照习惯/成瘾之辨（g20）逐项核查：使用是否挤占生活功能、用户是否主观失控、是否面向未成年人或心理易感人群放大冲动、收入是否与用户痛苦程度正相关；触及"蓄意伤害"级特征直接否决。

5. **象限定位与处置**
   - 完成标准: 给出四象限落点与对应动作——推广者：继续并保持第一人称使用；娱乐用户者：诚实标注娱乐属性、靠持续上新维持，不伪装成提升生活质量；兜售商：先成为用户或放弃该方向；经销商：停止。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 给别人的产品做道德审判或竞品攻击——矩阵是第一人称自检工具，作者明言它不回答"哪些企业讲道德"。
- 替代法律合规审查（隐私、未成年人保护、算法监管）——矩阵是合规之上的自省，不是合规本身。
- 纯机制咨询（"这条推送文案怎么写"）——先走机制 skill，出方案后回本 skill 复核。

### 作者在书中警告的失败模式

- 自检时的自我欺骗（ce18）：用正当化说辞回答两问（"用户应该会喜欢的""这算不上操纵"）——辩解行为本身即动机性推理的证据，继续推进只是给剥削披上外衣。
- 兜售商（ce16）：设计者不用自己的产品，靠想象填补用户模型，"现实扭曲场"使关键自问失效。
- 经销商与 Cow Clicker（ce17）：商业模式依赖放大冲动而非创造价值，收入与用户痛苦正相关——识破与监督到来时商业与道德同时崩塌。
- 轻慢 1%（ce19）："只有极少数人病理性上瘾，无关紧要"——作者明文拒绝这一推论，义务见 p16。

### 作者的盲点 / 时代局限

- 矩阵全依赖自报与主观羞愧感，对自欺几乎无防御力——作者自己也要靠"请立刻停手"条款兜底；使用时必须配合外部反馈（用户访谈、投诉数据、第三方评估），不可单独定案（阶段 0 批判节）。
- "1% 病理性上瘾"的框定淡化了分布问题：此后的注意力经济批评（Tristan Harris 等）指出，问题不是 1% 极端者而是全体用户的分布整体左移——这条线书中没有；且作者把其余责任推给用户（"其余用户应对自己的行为承担最终责任"，L1966），回避了默认设置与产品形态管制层面的解法。
- 时代悖论：本书总结的机制后来被大规模用于作者明确反对的用途（博格斯特"本世纪的烟草"之讥）——矩阵是自愿自检，无外部强制；用它自检不等于机制被道德约束。故本 skill 的输出是"自检记录"，不是"免死金牌"。

### 伦理红线（本 skill 即伦理单元）

- 成瘾红线：习惯（有益或中性的无意识行为）≠成瘾（长期被动依赖并走向自我毁灭）；面向未成年人、抑郁焦虑等易感人群的设计按最严标准执行，不适用"娱乐用户者"豁免。
- 本 skill 用于自检而非洗白：产出若是"我们过了矩阵所以可以继续"的背书，而两问未获得诚实回答，则自检本身构成 ce18 式失败；外部监督与用户侧权利（知情、退出、数据可携带）不因自检通过而免除。

### 容易混淆的邻近方法论

- 一般商业伦理 / 道德哲学：本书贡献是可操作的象限结构+羞愧判据+"该不该先于能不能"的顺序，不是伦理学体系，不用于理论辩论。
- 法务合规清单：合规是外部强制的底线，矩阵是底线之上的自我审查，二者不可互替也不可互相替代。
- `p16-protect-heavy-users`：见 A2 区分——闸门（f18）与义务（p16）接力，不重复。
