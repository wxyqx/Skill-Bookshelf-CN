# 动机三分类（三组趋避杠杆）

## R — 原文 (Reading)

> "能够驱使我们采取行动的核心动机不外乎三种。第一种，追求快乐，逃避痛苦；第二种，追求希望，逃避恐惧；第三种，追求认同，逃避排斥。……每一组中的两个要素就像是杠杆的两端，其上下摆动的幅度会导致人们做出某种举动的可能性相应地增加或者减少。"
>
> — 第3章 动机（L832–L838）

> "能够成为某些人行为动机的东西未必适用于另一些人，所以，你一定要知道自己的目标客户到底需要些什么。"
>
> — 第3章 蕴含在广告中的动机（L851）

> "像恐惧这一类的负面情绪也可以充当动机，而且效果甚佳。"
>
> — 第3章 蕴含在广告中的动机（L859）

---

## I — 方法论骨架 (Interpretation)

所有人类行为背后只有三根"杠杆"，每根两端各有一个方向——趋与避：一是体感层面的快乐/痛苦，二是预期层面的希望/恐惧，三是关系层面的认同/排斥。福格的化简在于：不必穷举需求清单，只需判断目标行为被哪根杠杆、哪个方向撬动，以及摆幅够不够大。

这套分类的操作价值有三点。第一，杠杆有正反两面——文案既可以写"得到什么"（趋面），也可以写"失去什么"（避面），恐惧与排斥并非禁区， Helmet 广告用伤疤照片同样有效。第二，**先选杠杆，再设计强度**：对不同人群，杠杆的敏感度差异极大，对一部分人是兴奋点的东西对另一部分人可能是反感点，所以设计前必须先确认"我的目标客户吃哪一套"。第三，它与行动公式（B=MAT）中的 M 一一对应，是动机环节的选型工具而非需求分析报告——输出的是"用哪根杠杆拉"，不是"用户缺什么"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 动机三分类的广告四例
- **问题**: 哪个行业把动机表达得最直白？如何验证三组杠杆在真实说服场景中的用法？
- **方法论的使用**: 作者逐一拆解四则广告：2008 年奥巴马竞选海报打"希望"（趋希望避恐惧）；内衣/域名/汉堡广告用性卖点（趋乐避苦）；百威用三个好友为国家队助威的画面打社交凝聚力（趋认同避排斥）；摩托车头盔广告用事故伤疤照片打恐惧（避恐惧）。
- **结论**: 负面情绪可以充当动机且效果甚佳；但同一杠杆因人群而异——性卖点只对敏感人群（如青春期男孩）有效，"其他人则不一定，没准还会非常反感"。
- **结果**: 四例成为第 3 章动机节的标准示范（L841–859），支撑"先确认目标人群的敏感杠杆再设计"的规则。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 文案与素材设计：为落地页、广告、推送、活动标题选"打动点"，在多个候选卖点间摇摆。
2. 动机缺失归因：B=MAT 判定问题出在"不想做"之后，需要为该人群找可用的拉力。
3. 分众实验设计：同一产品面对多类人群（如 B2B 团队 vs 个人用户、年轻人 vs 老年人），要测哪根杠杆对谁敏感。
4. 自我激励设计：为健身、学习、早起等个人目标选驱动力（用希望还是用恐惧还是用同伴监督）。

### 语言信号 (用户的话里出现这些就应激活)

- "用什么打动用户 / 文案打哪个痛点 / 卖点怎么提炼"（motivation, which lever, what moves our users）
- "恐惧诉求行不行 / 正面激励还是负面激励"（fear appeal vs aspiration, gain vs loss framing）
- "动机三分类 / 趋利避害 / 用户在乎什么 / 什么能激励他们"（core motivations, incentive）

### 与相邻 skill 的区分

- 与 `f07-bmat-action-diagnosis` 的区别：f07 是三要素总诊断，负责判定"问题是不是动机"；f08 只在归因到 M 之后才介入，负责选杠杆。
- 与 `f05-internal-trigger-anchoring` 的区别：f05 找的是用户在使用场景中的情绪锚点（什么情绪会想起你），是触发的安装；f08 定的是说服文案的杠杆方向（用什么拉他行动），是行动前的推力。一个向内找情绪，一个向外找卖点。
- 与 `f12-three-variable-rewards` 的区别：f08 是行动之前的动机拉力；f12 是行动之后给什么反馈。用户"为什么来"用 f08 描述，"为什么再来"对齐 f12。
- 与 `f18-manipulation-matrix` 的区别：f18 是动用负面杠杆（恐惧/焦虑）之后的道德自检闸门，不选杠杆本身。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定目标行为与目标人群**
   - 完成标准: 一句话写清"希望谁做什么"；人群特征（职业/年龄/处境）具体到能判断其敏感点。人群模糊则先澄清，不进入选杠杆。

2. **填三组杠杆的趋/避两面**
   - 完成标准: 对目标行为列出 3 组杠杆 × 2 个方向 = 6 个候选打动点，逐个写一句文案方向；不适用的格子显式标注"不适用"及原因（如工作场景对快乐杠杆钝感）。

3. **小样本验证敏感杠杆**
   - 完成标准: 用用户访谈、文案 A/B 或小额投放测出"哪根杠杆对该人群摆幅最大"；有明确胜出项或组合项。
   - 判停条件: 若三组杠杆全部钝感（没有任何打动点产生响应），说明问题可能不在动机而在能力/触发——退回 `f07-bmat-action-diagnosis` 重新归因。

4. **按最敏感杠杆设计并上线**
   - 完成标准: 文案/素材对准胜出杠杆（可用避面表述），与触发时机配合；上线后行为指标可对比。

5. **伦理复核**
   - 完成标准: 若使用了恐惧/排斥等负面杠杆，过一遍 `f18-manipulation-matrix` 两问（我自己会用吗、能否提升用户生活质量），确认没有制造焦虑来收割行为。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需求尚不存在时：动机杠杆放大既有欲望，不能无中生有地创造需求；先验证需求，再谈打动。
- 组织激励制度问题：员工不使用内部工具若源于考核与流程设计，文案层面的动机杠杆无效。
- 把三分类当需求清单用：它是行动召唤的选型工具，不是用户研究结论本身。

### 作者在书中警告的失败模式

- 动机错配（L851 原文警告）："能够成为某些人行为动机的东西未必适用于另一些人"——性卖点对目标人群是兴奋点、对其他受众是反感点；不测人群直接套"普适动机"会适得其反。
- 误判核心动机（ce08，Mahalo 之败）：把经济利益当杠杆驱动内容社区，金钱重新定义行为性质并挤出社交认同——选错杠杆比不选更糟（该反例在 f12 展开，根源同在动机误判）。

### 作者的盲点 / 时代局限

- 三分类源自福格（作者明引），属二手框架；其"所有行为可压成三组"的完备性未给出论证。
- 文化外部效度存疑：书中证据全部来自美国市场，"认同/排斥"的形态（公开点赞、匿名威望值、实名荣誉）高度依赖文化对面子与集体的规范（阶段 0 批判节）。
- 性别与视角局限：广告例中的性卖点多以女性身体为素材，作者复述时未做批判性处理；恐惧诉求的长期社会成本（焦虑营销的外部性）不在讨论范围。

### 容易混淆的邻近方法论

- 马斯洛需求层次等需求理论：需求层次描述"人缺什么"，三组杠杆是成对的趋避方向、带反向文案选项、面向行动设计，粒度与用途都不同。
- 损失厌恶（行为经济学）：只对应"避"面的一种表述策略；本 skill 先选杠杆领域（体感/预期/关系），再谈框架效应，顺序相反。
