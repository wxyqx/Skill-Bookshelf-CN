# 留汰律（留人靠挑战：换出巧克力、电梯演讲挽留、爱他就让他走）

## R — 原文 (Reading)

> "想要留住创意精英，最好的方法就是避免让他们太过安逸，而是不断用新的想法保持他们工作的趣味性。" / "如果你还想给出更好的待遇条件来试着挽留，那你出手一定要火速（间隔时间最好不要超过一个小时）。因为时间一长，这位员工在心中就越发倾向于那家新的公司了。"
>
> — 施密特、罗森伯格，第三章《换出巧克力，留下葡萄干》/《爱他，就让他走》

---

## I — 方法论骨架 (Interpretation)

这套方法论的默认前提是：顶尖人才离开的常见原因不是钱，而是安逸与视野受限——所以留人的主战场在"发展供给"，薪酬只是配套。

- **回报律**：薪酬起点放低、按影响付薪——最高报酬属于与卓越产品关系最密切的人，低职级的关键贡献者可以比高职级的平庸者挣得多，打破平均主义。
- **挑战律**：用新挑战对冲安逸——列席管理会议、轮值新角色、为其特设职位；轮岗的机制陷阱是管理者"把巧克力留给自己、把葡萄干换给别人"，所以规则必须反着定：**被轮出去的必须是团队里的佼佼者**，用制度对冲囤积动机。
- **出口律**：挽留从倾听开始；对想自立门户者主动听 30 秒"电梯演讲"，构想不成熟就劝其边工作边完善，有说服力就体面送行甚至投资；反报价窗口以小时计，拖延只会把人心推向对手。

配套的长期动作是接班人计划：盯"升职最快的高潜"而非资历最深的老人，防止高潜力者因停滞流向竞争对手。

## A1 — 书中的应用 (Past Application)

### 案例 1: 乔治斯·海力克列席管理会议
- **问题**: AdSense 创始团队成员、解决"糟糕广告"的工程师海力克提出想离开谷歌。
- **方法论的使用**: 埃里克没有加薪挽留，而是邀他列席管理会议、加入高管邮件组，让他接触企业运营知识——用新的挑战填补视野。
- **结论**: 顶尖员工流失常因安逸或视野受限；把他们当顶尖人才对待，给新挑战即可挽留。
- **结果**: 海力克被激发加入产品管理团队，为公司多贡献两年（c51）。

### 案例 2: 为萨拉尔·卡曼加特设 YouTube 主管
- **问题**: 萨拉尔参与创建 AdWords 后想承担更多职责，公司却没有适当的职位。
- **方法论的使用**: 公司为他特设"YouTube 主管"一职——让组织为人才自我调整，而非让人迁就编制。
- **结论**: 为了顶尖员工大展身手，公司情愿打破编制造职位（把巧克力换出去）。
- **结果**: 萨拉尔执掌 YouTube；"为人才造职位"成为谷歌的常规操作（c52）。

### 案例 3: 杰西卡·尤因想写作
- **问题**: 年轻有为、参与推出 iGoogle 的产品经理杰西卡想去写作。
- **方法论的使用**: 不阻拦也不利诱，帮她理清职业规划与机会成本（包括将要到手的股权），尊重其最终选择。
- **结论**: 离职若对个人发展确是正确选择，就放行——爱他，就让他走。
- **结果**: 杰西卡离开追求写作；作者送上祝福，并按里德·霍夫曼的建议欢迎其加入离职员工交流群，关系延续到围墙之外（c53）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 明星员工提出离职，或得知正被对手接触——要设计系统的挽留动作，而不只是反报价。
2. 设计或诊断内部轮岗/人才流动制度：各部门经理把骨干扣住不放，流动的全是边缘人。
3. 薪酬决策：要不要给顶格 offer、绩效奖励怎么拉开差距、"人人平等"的发薪惯性要不要打破。
4. 高潜人才停滞、继任者计划无人可写、核心骨干"三年后是否还在"没有答案。
5. 好员工想离职去创业/写作/深造，纠结拦还是放。

### 语言信号 (用户的话里出现这些就应激活)

- "明星员工要离职 / 被挖角了怎么留 / counter-offer"
- "留人除了加薪还有什么办法 / retention"
- "轮岗推不动 / 好员工被经理扣住 / 谁都不放人"
- "高潜看不到前途 / 接班人计划 / succession"
- "他想出去创业 / 电梯演讲 / elevator pitch / alumni 群"

### 与相邻 skill 的区分

- 与 `expel-villains-protect-stars` 的区别：那是"品行出口"——恶棍损公肥私要迅速清除，明星的狂妄要容忍；本 skill 是"成长出口"——明星因安逸或视野想走时要接住。判别口诀：人品问题走驱逐，发展问题走留汰；对明星的保护（容忍性格）在那边，对明星的挽留（供给挑战）在这边。
- 与 `hiring-quality-bar` / `hiring-ops` / `talent-portrait` 的区别：那三个管"进门"（门槛多高、流程怎么走、看什么画像），本 skill 管"进门之后"（怎么留、怎么轮、什么时候放）。人还没招进来时不要用本 skill。

## E — 可执行步骤 (Execution)

1. **诊断流失动因**
   - 完成标准：能说出该员工最近一次被真正挑战是什么时候、动因是安逸/视野/报酬/外部拉力中的哪一种。判停条件：若对方以"不加薪就离职"的最后通牒姿态出现——关系已切换为博弈型，跳到步骤 5（体面放行），不进入竞价。
2. **用发展而非薪酬对冲**
   - 完成标准：检查他是否被困在"巧克力式囤积"的原岗位；给出至少一个一周内可启动的新挑战方案——特设职位、列席管理会议、压上 10 倍量级的难题，而不是口头承诺。
3. **听完整版电梯演讲（想自立门户者）**
   - 完成标准：听其 30 秒构想（战略基础、文化设想、能否打动潜在投资者）；构想不成熟→建议边工作边完善；有说服力→进入步骤 4，并评估是否投资。
4. **反报价只在真想留、且以小时计**
   - 完成标准：若确要反报价，1 小时内出手（时间越长人心越偏向新东家）；给不出对等条件就干脆放行，不搞拖延战术。
5. **体面放行 + alumni + 接班自检**
   - 完成标准：祝贺并欢迎加入离职员工交流群，不做竞业刁难；同时更新接班人名单——自检"升职最快的高潜里有没有下一个他"，别让挽留失败才第一次盘点人才梯队。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **绩效差或品行不端的员工想走**——留汰律只对明星与高潜使用；对这类人的正确动作是放行甚至加速，别把挽留话术浪费在错误对象上。
- **拿离职做杠杆的反复要价者**——通牒一出口关系已变味，满足一次只会验证威胁有效（见失败模式 ce33）。
- **利润引擎撑不起"超出常规的回报"**——承诺兑现不了的超常规薪酬比不给更毁信用，回报律须按自己的盈利能力校准。

### 作者在书中警告的失败模式

- ce31 巧克力囤积：轮岗制度只考核"是否轮换"不规定"轮换谁"，博弈均衡必然是流动的全是葡萄干、骨干原地禁锢。
- ce33 最后通牒挽留：以离职要价者"对企业已不抱感情"，挽留成功也只是把决裂推迟一个周期。
- ce60 接班人锁定"资历最深的 100 人"：高潜因年轻被无视，停滞直至流向对手——留汰的长期代价在接班断层时才显现。

### 作者的盲点 / 时代局限

- "给超出常规的回报"以 AdWords 式印钞机为前提：在不具备谷歌式利润引擎的组织里照搬豪华留才组合，可能先于"赋能"而破产（幸存者偏差：同期采用相似策略的雅虎、AOL 并未复制成功）。
- 全书默认员工是创意精英：造职位、轮岗、列席会议等手段对劳动密集型、强流程岗位的可移植性书中未讨论。

### 容易混淆的邻近方法论

- 主流 counter-offer 挽留：默认动作用钱和 title；本书独特在以发展对冲为主、反报价只是以小时计的最后手段，且放行被定义为成功选项之一。
- Netflix 式 keeper test / 末位淘汰：那是"汰"的纪律；本书重心在"留"侧的机制设计（轮岗方向、电梯演讲、alumni），并明确警告别把解雇当招聘缺位的借口。
