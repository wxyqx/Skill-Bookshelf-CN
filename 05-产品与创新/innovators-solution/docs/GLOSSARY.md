# GLOSSARY —《创新者的解答》共享术语词典

本文是 15 个下游 skill 共享的术语锚点：只收录作者用法与常识/字典不同的词、全书反复使用的核心概念词。每条给出"本书语境定义 + 与常识用法的差异（≠ 常见误读 / = 作者本义）+ 为什么下游 skill 需要这个澄清"，供 skill 在推理时对齐语义，避免用日常语感误读关键判据。

---

### 不对称动机

- **本书语境定义**：在位者的资源分配流程为延续性创新而设计、目光总盯着高端市场，几乎从不考虑保卫新市场或低端阵营；这种利益结构差异使破坏者常能"不战而胜"。
- **与常识用法的差异**：≠ 双方资源/能力不对等，或某一方犯了错；= 面对同一创新，在位者与新入者的理性选择方向系统性相反（在位者"逃跑比迎战更理性"）。
- **为什么下游 skill 需要**：这是战场选择的第一道闸门。下游 skill 据此判断"这个破坏性机会是否对所有重要在位者都成立"，避免选中只会招致激烈反击的延续性战场，并预测在位者必然向高端迁移的行为。

### 破坏性创新

- **本书语境定义**：依创新发生的客观环境定义的相对概念——把更简单、更便利、更廉价的产品商业化，销售给新客户群或低端客户群。
- **与常识用法的差异**：≠ 激进/突破性/高科技/跳出传统框架的技术；= 相对某一在位者的成本结构与价值网络而言的低端或新市场定位（对甲是破坏、对乙可能是延续）。
- **为什么下游 skill 需要**：全书的核心分类轴。所有 skill 判定"这是不是破坏性机会"都以相对性（对谁而言）为准，而非技术难度；也是拒绝"破坏 = 颠覆性技术"这一常识误读的锚点。

### 延续性创新

- **本书语境定义**：定位于要求更高的高端客户，为其提供超越当前市场水平的更优秀性能，既包含年复一年的渐进改进，也包含突破性、压倒竞争对手的产品。
- **与常识用法的差异**：≠ 以技术改进幅度定义的"渐进式创新"；= 沿既有性能轨迹服务高端、高利润客户的创新（无论技术激进与否）。
- **为什么下游 skill 需要**：与破坏性创新构成对称二分。skill 用它识别"把破坏性创意包装成延续性计划"的死亡陷阱，并判定在位者会反击还是逃离。

### 新市场破坏

- **本书语境定义**：面向"零消费"人群的破坏——客户有任务要完成，但因缺资金/技术或没有简单便宜的方案而未消费；以"没有"为参照，性能要求低，简单易用的产品即可取悦，常形成新价值网络与新渠道。
- **与常识用法的差异**：≠ 从现有竞争对手手中抢夺客户；= 拉动从未消费的人群开始消费（竞争对手是"非消费状态"本身）。
- **为什么下游 skill 需要**：决定进入哪个市场、按什么性能标准设计产品。新市场破坏初期不惊动在位者（甚至使其利润更好），是成长确定性最高的起点，是客户选择与"无痛冲击"诊断的依据。

### 低端市场破坏

- **本书语境定义**：以更简单、更便宜但"刚好够用"的产品进攻被过度服务的低端客户；必须以低价仍能赢利的独立业务模式（低管理费用 + 高资产周转）为载体，实践中常与新市场破坏混合出现。
- **与常识用法的差异**：≠ 单纯的低成本制造或以低价进入市场；= 以"低价仍高利"的独立业务模式为核心的低端进攻。
- **为什么下游 skill 需要**：判断低端破坏可行性的关键——没有独立赢利模式，一旦在位者跟进即陷入同质价格战；独立成本结构同时决定了必须设立独立组织（呼应 RPV）。

### 零消费者 / 零消费市场

- **本书语境定义**：人们需要完成某项任务，但因现有产品太贵或太复杂而尚未找到满意方案（勉强用不便、昂贵或满意度低的方式完成）；区别于"根本没有相应任务要完成"的人群。
- **与常识用法的差异**：≠ 买不起或未购买的人群（消费能力/价格问题）；= 有任务却无满意方案的人群（任务问题）。
- **为什么下游 skill 需要**：新市场破坏的理想客户。skill 用"任务问题"甄别真零消费与伪机会（如低价上网终端、便宜电脑因无任务而失败），并据此确定性能要求与渠道。

### 雇用产品 / 任务理论

- **本书语境定义**：客户不是在购买产品，而是在"雇用"产品去完成某项特别的任务；任务的功能、情感、社会维度决定购买条件，真正的竞争对手是完成同一任务的其他方案（奶昔的对手是百吉饼、香蕉和无聊，不是其他奶昔）。
- **与常识用法的差异**：≠ 按产品属性、人口统计或消费心理细分市场；= 按客户在具体情境中要完成的任务（情境条件）细分市场。
- **为什么下游 skill 需要**：市场细分与产品改良的第一原理。skill 用它重定义竞争集合、筛选新功能（与任务无关者落选）、发现破坏性立足点，并否决"让客户改变任务"类提案。

### 威胁-机遇塑造（认知不对称）

- **本书语境定义**：吉尔伯特研究——在位者把破坏性技术感知为威胁时会"威胁—僵化"，全力保卫现有客户、把技术硬塞进主流市场；解法是在资源分配阶段把它塑造为威胁以争取资金，在实施阶段交给独立部门并塑造为机遇。
- **与常识用法的差异**：≠ 号召管理者"保持乐观"或简单的心态问题；= 同一创新在立项与实施两阶段刻意切换框架（威胁立项、机遇实施）。
- **为什么下游 skill 需要**：解释"明知破坏理论仍失败"的机制，并给出资源分配与组织结构的双重处方，是"威胁-机遇双重塑造"流程的依据（报刊网络版、独立事业部）。

### 互依性-模块化（交互式/模块化架构）

- **本书语境定义**：产品架构光谱两端——交互式（interdependent，优化性能与可靠性、受专利保护、工程自由度高）与模块化（modular，规格统一、优化灵活性与速度、牺牲部分性能）；产品"不够完善"时交互式+整合取胜，"好得过头"时模块化+分包取胜。
- **与常识用法的差异**：≠ 用"核心竞争力"判断自制还是外包；= 按性能缺口/过度服务的情境决定架构与整合范围。
- **为什么下游 skill 需要**：自制/外包决策的前置理论。skill 据此判断整合还是分包、预测行业走向集中还是分散、检验外包接口三条件（规格明确/可衡量/无不确定互依）。

### 货品化 / 反货品化

- **本书语境定义**：价值链上任何一处发生货品化，必有一处相互作用的反货品化力量兴起；差异化与高利润沿价值链随破坏浪潮可预测地迁移，定位在"不够完善"环节的企业才能赢利（货品化六步 vs 反货品化五步）。
- **与常识用法的差异**：≠ 货品化是不可逆的利润终结与宿命；= 货品化与反货品化成对出现，利润不消失、只是在价值链上迁移。
- **为什么下游 skill 需要**：预测财富流向与品牌价值迁移位置，是"当前环节定位""滑向未来财富增长点""品牌随利润迁移投资"等决策的理论基础。

### 高利润守恒定律

- **本书语境定义**：当模块化与货品化的共同作用使价值链某一阶段的高利润凭空消失时，与之相邻的阶段中往往会出现能聚集高利润的专利性产品（得名灵感来自能量守恒定律，Tensilica CEO 克里斯·罗恩提出）。
- **与常识用法的差异**：≠ 利润总额固定不变（那只是"能量守恒"的比喻）；= 高利润在价值链相邻环节间转移聚集的经验性规律（模块化与交互式架构相邻配对）。
- **为什么下游 skill 需要**：定位"下一个财富增长点"、判断子系统/渠道利润聚集处、识别"把子弹卖给交战双方"机会的核心工具。

### RPV（资源/流程/价值观）

- **本书语境定义**：定义组织胜任业务范围的三要素——资源（resources：人、设备、技术、现金、关系，可见可转移）、流程（processes：互动/协调/决策模式，为特定任务而生）、价值观（values：员工优先决策标准，受成本结构与规模驱动）；能力随时间从资源向流程、价值观、文化沉淀。
- **与常识用法的差异**：≠ 能力仅指人员素质或资源多少（"谁来做"）；= 资源+流程+价值观三层，其中价值观决定组织"不做"什么。
- **为什么下游 skill 需要**：组织能力审计与自治组织决策的骨架。所有"组织能否胜任破坏性新业务"的 skill 都以 RPV 为分类；"组织不能自我破坏"的原因也在于价值观与文化。

### 经验学校

- **本书语境定义**：判断管理者能否胜任新任务，应审查他在哪些"学校"（情境）里修过哪些"课程"（问题），而非看他头上的成功光环；潜力不由特征衡量，而由学习能力衡量，失败与反思往往是关键课程。
- **与常识用法的差异**：≠ 按履历光环、过往职位或特征排名选人；= 把新业务将遇的问题转译为"经验课程"，与候选人真实经历过的情境逐项比对。
- **为什么下游 skill 需要**：破坏性新业务的选人法。skill 采用"前瞻列问题清单→转译经验课程→比对真实经历"三步，也是解释"履历完美的高管搞砸新业务"的依据。

### 应急型战略 / 谋划型战略

- **本书语境定义**：每家企业始终并存两种战略流程——谋划型（deliberate：有意识、分析性、自上而下、有始有终）与应急型（emergent：中层管理者、工程师、销售财务人员日常决策的累积涌现）；未来不明时应急主导，取胜策略明朗后谋划主导并无情执行。实际战略是资源分配流程的输出。
- **与常识用法的差异**：≠ "好战略 vs 坏战略"或"有计划 vs 无计划"；= 两种并存流程按情境匹配主导权（该探索时探索、该执行时执行）。
- **为什么下游 skill 需要**：战略流程诊断与切换。是谋划型三条件检验、危机期模式切换测试、发现式规划（discovery-driven planning）的情境前置。

### 好钱 / 坏钱

- **本书语境定义**：资金的好坏取决于投资环境隐含的投资者期望结构；萌芽阶段最好的钱是"对成长有耐心、对赚钱没耐心"的资金，随企业成功与华尔街成长缺口压力，好钱逐级变质为"对成长急不可耐、对利润异常有耐心"的坏钱（坏钱既可来自风投，也可来自企业内部投资）。
- **与常识用法的差异**：≠ 按出资人身份分类（风投 vs 企业资本、公募 vs 私募）；= 按"对成长的耐心 × 对利润的耐心"二维期望结构分类。
- **为什么下游 skill 需要**：融资与投资节奏决策。是好钱/坏钱诊断、"早期急迫赢利是良药"判据、以及"接受资金即锁定期望"谈判提示的依据。

### 死亡螺旋 / 成长缺口

- **本书语境定义**：好钱变坏钱的五步机制——成功并聚焦核心→华尔街贴现造成结构性"成长缺口"→缺口扭曲价值观、只有能迅速做大的项目才能过审→为兑现承诺巨额投入并忍受长期亏损→亏损攀升后新管理层收缩回核心，循环回到第三步。
- **与常识用法的差异**：≠ 企业常规的经营/财务危机循环；= 资本市场成长预期驱动的价值观与资源分配扭曲循环。
- **为什么下游 skill 需要**：诊断破坏性业务被"绑架"的机制。skill 用成长缺口测算与五步自检判断组织实际能给破坏性项目留多大空间。

### 破坏性成长引擎

- **本书语境定义**：高管的长期任务——把辨认、塑造并成功实现成长的能力根植于流程，形成可反复启动破坏性业务的可预测、可重复流程；作者自承尚未发现任何企业建成，仅提出四步骤（按节奏启动新业务、委派有权打破流程的高管、企业级推动团队、全员识别培训）。
- **与常识用法的差异**：≠ 企业风险投资式的撒网投资、或依赖天才与运气；= 把破坏性创新能力制度化、流程化的组织机制。
- **为什么下游 skill 需要**：高管角色的长期目标与组织设计锚点。skill 讨论"破坏性成长能否被复制/流程化"以及"别人还没干过"的风险边界时引用。

### 性能过度供给（过度服务/不够完善）

- **本书语境定义**：技术进步速度恒快于客户吸收/利用能力的提升，定位于主流客户的产品终将"过度服务"、超过客户实际使用能力；判据是客户不再愿为性能改进付费、只按价格选择（"好得过头"与"不够完善"是同一轨迹的两端）。
- **与常识用法的差异**：≠ 产品质量差或经济学意义的供给过剩；= 产品性能超出客户实际利用能力（竞争基础即将转移的信号）。
- **为什么下游 skill 需要**：破坏时机与架构/整合选择的判定前提，是所有"过度服务信号识别""竞争基础迁移"判断的基础概念。

### 向高端市场迁移（逐级吞食、双头垄断式上攻）

- **本书语境定义**：在位者受利润与资源分配驱动必然向高端迁移、甩掉低端（"逃跑比迎战理性"）；破坏者独占低端后同质竞争压价（"狗咬狗的大集市"），被迫逐级上攻；供应商则"逐级吞食、一路向上"，在过度服务环节最好的策略是"把子弹卖给交战双方"。
- **与常识用法的差异**：≠ 个别企业的战略选择或偶然行为；= 被经济力量驱动、可预测的行业性运动（在位者上移与破坏者追赶同时发生）。
- **为什么下游 skill 需要**：预测竞争演化与财富迁移方向，是判断"上攻路线""供应商吞食路径""交战双方策略"以及不对称动机落地行为的基础。

### 资源分配流程

- **本书语境定义**：企业实际执行的战略是资源分配流程的输出而非输入；中层管理者按单位毛利率（成本结构）、规模阈值、2-3 年轮岗周期、销售激励、客户账单等标准筛选创意，系统性地把破坏性创意包装、磨平成延续性计划——磨平环节是增长失败的第一现场。
- **与常识用法的差异**：≠ 高层制定的战略或正式决策文件；= 组织日常资金与产能流向所体现的真实战略（看行动不看言论）。
- **为什么下游 skill 需要**：诊断"组织实际会执行什么战略"。skill 用资源分配过滤器审计识别真实战略、预测哪些破坏性创意会被磨平，并定位初始成本结构这一头号杠杆。
