- id: p01
  title: 只有对所有重要在位者都是破坏的构想才值得出手
  type: principle
  source_chapter: 第2章
  source_quote: 你需要找出一个能在目标市场对所有先入对手给予破坏性打击的机会，否则，连试都不要去试。
  summary: |
    何时用：评估任何新成长业务构想（或为新业务立项把关）时的第一道否决闸门。
    怎么用：逐一列出目标市场的主要在位者，判断该构想对每一家是破坏还是延续；只要对任一重要在位者属于延续性创新（它会反击而非逃离），就退回计划阶段重新设计定位，不要投入资源。
    原理：破坏是相对概念；对在位者是延续性挑战时，对方有充足动机和资源正面迎战，后来者胜算趋零。
    反向用法：在位者也可自检——哪些新入者对自己恰好是"破坏"，即为最危险的战场。
  tags: [破坏性创新, 战场选择, 在位者, 不对称动机, 否决规则]

- id: p02
  title: 不要让客户改变任务，帮他们更好地完成现有任务
  type: principle
  source_chapter: 第3章
  source_quote: 想要让客户优先完成过去并不关心的任务，胜算是极低的。客户不会因为有一个新产品出来了就"改变任务"。新产品只有致力于更好地帮助客户完成现有任务，才有可能获得成功。
  summary: |
    何时用：评估新产品/新功能的价值主张，尤其是"教育客户、培养新习惯"类提案时。
    怎么用：问"客户是否已经在做这件事、只是现有方案不够好"；若价值主张依赖客户去做他本来不做、优先级不高的事（如整理数码照片），判为低胜算，直接否决；把产品重新定位到帮客户更便宜、更便捷地完成他已在做的任务。
    判据：客户对产品改良功能的利用轨迹是平缓的——新产品改变不了任务本身，只能改变完成任务的方式。
  tags: [任务理论, 产品定位, 客户需求, 否决规则]

- id: p03
  title: 按"客户要完成的任务"细分市场，不按产品或客户属性细分
  type: principle
  source_chapter: 第3章
  source_quote: 客户想要做的事情，或者他们想要达成的结果就构成了以情境条件为基础的市场分类。
  summary: |
    何时用：市场细分、产品定位、竞争分析时替换常规的品类/人群/心态细分。
    怎么用：按"客户在什么情境下雇用产品完成什么任务"划分市场；观察购买时间、场景、同购品，追问"不买它时你用什么替代"，用替代品集合（而非同品类）界定竞争对手。
    配套禁令：不要把基于产品/客户属性的历史评估数据（IT 报表只有产品、客户、组织单位三个维度）用于新产品研发——把这些数据封存，改用按任务/情境设计的量化研究。
  tags: [任务理论, 市场细分, 竞争分析, 数据禁令]

- id: p04
  title: 一个产品只服务一个任务，不要向多重任务客户问改良方向
  type: principle
  source_chapter: 第3章
  source_quote: 向那些有"多重任务"的客户询问应该改进奶昔的哪些特性时，得到的却是一个"四不像"的答案，根本满足不了任何客户的需求。
  summary: |
    何时用：产品功能规划、客户调研问卷设计、竞品功能对标冲动出现时。
    怎么用：先把身兼多重任务的客户按情境拆开，再分别就单一任务问改良方向；一个产品主打一个任务，与任务无关的先进功能（哪怕竞品都有）一律落选。
    预警信号：团队开始逐条抄竞品最新功能、产品定位越说越"全能"时，就是在制造无人满意的四不像。
  tags: [任务理论, 产品设计, 客户调研, 功能取舍]

- id: p05
  title: 新市场破坏只投"有任务无方案"的零消费者，甄别"无任务"的零消费
  type: principle
  source_chapter: 第4章
  source_quote: 一个产品如果定位于帮助"零消费者"完成他们并不急于完成的工作，那么这个产品是不太可能取得成功的。
  summary: |
    何时用：评估瞄准"零消费/未消费人群"的新市场破坏机会时。
    怎么用：用"任务问题"甄别两种零消费——问"这些人是否有任务要完成、只是现有方案太贵或太复杂"；有任务无方案者是理想客户（以"没有产品"为参照系，极易取悦），根本无任务者（如买不起电脑的多数家庭）注定失败，不要投资。
    判别问句："他们是有活要干，还是单纯买不起/不会用？"而非"这个市场有多大"。
  tags: [新市场破坏, 零消费者, 机会甄别, 任务理论]

- id: p06
  title: 破坏性产品必须通过破坏性渠道推广，渠道要能借它向高端转移赚更多钱
  type: principle
  source_chapter: 第4章
  source_quote: 本田的业务是从电力设备和体育用品零售店发展起来的，因为它让这些零售商有机会引进利润更高的机动摩托车产品，向更高端的市场迈进。在我们研究的每一个成功的破坏性创新案例中，产品和渠道都具备类似的双赢关系。
  summary: |
    何时用：为破坏性产品设计分销/销售渠道，或现有渠道拒绝进货、推广不力时。
    怎么用：把渠道每个环节（零售商、分销商、销售员、终端厂商乃至医生）当客户审视——检查他们能否靠你的产品沿自身轨迹向高端市场转移、提高利润；能提供这种动力的渠道才是助力，否则必然边缘化你。
    禁令：不要把破坏性产品硬塞进按产品类别经营、只能从大订单赚佣金的主流渠道。
  tags: [渠道策略, 破坏性创新, 渠道动力, 分销]

- id: p07
  title: 破坏性创新要双重塑造：资源分配时当威胁，实施时当机遇
  type: principle
  source_chapter: 第4章
  source_quote: 在资源分配流程中，最好把破坏塑造成威胁，争取获得足够的资源。一旦投资确定，就必须将其视为创造新成长的大好机遇，否则就会陷入弹性不足或缺乏关注的危险之中。
  summary: |
    何时用：在位企业内部推动破坏性业务立项及后续运营时。
    怎么用：立项与争取预算阶段，把破坏定位为"威胁"以触发高层重视（人对威胁的反应强于机遇）；资金落实后，立即把实施责任移交独立部门，并以"机遇"框架运营，让团队瞄准新成长而非保卫现有业务。
    禁令：不要在主流组织内以"威胁"框架继续实施——那会把资源导向保卫现有客户，把破坏技术做成延续性产品。
  tags: [威胁机遇塑造, 资源分配, 立项策略, 在位企业]

- id: p08
  title: 破坏性业务计划按典型模式评审，不走量化ROI筛选流程
  type: principle
  source_chapter: 第4章
  source_quote: 主管资源分配的高管应该以典型模式而不是数字规则为标准来衡量新的计划，作出预算决定。
  summary: |
    何时用：为主管资源分配的高管设计破坏性创意的评审与预算流程时。
    怎么用：为潜在破坏性创意另设平行流程，进入的是未经打造的初始理念，管理者按新市场破坏典型模式的每个要素（零消费客户、低参照基准、简单易用、新价值网络、破坏性渠道）塑造并评审计划；符合模式的计划获得预算，不要求可靠的市场规模数据。
    禁令：不要用延续性投资的量化规则（市场规模数据、ROI 测算）筛选破坏性创意——那会逼团队把策略扭曲成延续性计划硬塞进现有市场。
  tags: [资源分配, 平行流程, 业务计划评审, 模式识别]

- id: p09
  title: 产品"不够好"就整合自制，"好得过头"才模块化外包
  type: principle
  source_chapter: 第5章
  source_quote: 对于在市面上"不够好"的产品，内部开发更有优势，而外包（或者说是专业、独立的生产方式）则适用于那些"好得过头"的产品。
  summary: |
    何时用：自制还是外包、要不要开放架构、何时采用行业标准等业务范围决策。
    怎么用：先判断目标市场当前产品性能是"不够好"（未满足主流需求）还是"好得过头"（过度服务）：不够好→交互式专利架构+垂直整合关键接口换性能；好得过头→模块化+分包+行业标准换速度与低成本。
    预警信号：销售人员抱怨"客户看不出我们产品好在哪里、把它当大路货"，即竞争基础正在改变、该考虑模块化。
    禁令：不要用"这是不是我们的核心竞争力"作为外包依据——今天是核心的可能明天被货品化，反之亦然。
  tags: [自制外包, 整合, 模块化, 业务范围, 情境匹配]

- id: p10
  title: 模块化外包的三条件缺一不可：专业性、可靠性、确定性
  type: principle
  source_chapter: 第5章
  source_quote: 只有具备这三个条件——专业性、可靠性、确定性，才能组成一个有效的模块化接口。
  summary: |
    何时用：决定能否把某环节外包/分包给供应商或合作伙伴之前。
    怎么用：逐条核对三条件——①双方明确哪些功能指标是系统必需的（专业性）；②供应商熟悉产品属性的衡量标准，能按规格交付（可靠性）；③接口处不存在不确定的相互依赖（确定性）。三者齐备才分包。
    禁令：接口尚未定义清楚（技术、计费、流程互依未定）时强行分包或结盟，跨组织协调成本会吞掉全部收益，注定失败。
  tags: [外包, 接口, 模块化, 供应商管理, 前置检验]

- id: p11
  title: 破坏性业务必须建在主流组织之外的自治组织
  type: principle
  source_chapter: 第7章
  source_quote: 对于破坏性创新举措，建立一个自治的组织，来发展投资项目并使之走向商业化，对成功来说是必不可少的。
  summary: |
    何时用：为破坏性业务选址（放主流部门还是独立单元）、决定其成本结构与汇报线时。
    怎么用：当新业务的流程与价值观都和主流组织不匹配（破坏性的定义性特征），就设立自治组织——关键是新流程的自由度和独立的成本结构，而非地理分离或法律形式。
    判别：若该业务必须靠主流组织让渡利润率/规模阈值才能活，就绝不能放在主流组织里孵化；反之，纯延续性机会不要浪费钱建独立组织。
  tags: [自治组织, 组织设计, RPV, 破坏性业务, 成本结构]

- id: p12
  title: 选新业务负责人用"经验学校"：看他修过什么课程，不看履历光环
  type: principle
  source_chapter: 第7章
  source_quote: 因此一个业务单位可以被看做一所学校，而管理人员面临的问题则构成学校提供的"课程"。管理人员拥有或是缺乏某项技能，很大程度上取决于他们在这些"学校"中是否选修过相应的"课程"。
  summary: |
    何时用：为破坏性/新成长业务选聘领导者，或评估"履历完美"的候选人时。
    怎么用：先前瞻列出新业务将遭遇的关键问题清单，把问题转译成候选人应修过的"经验课程"清单作为聘用规范，再逐项比对其真实经历过什么情境；核心业务中反复立功的人恰恰没修过新业务的课，不能任命。
    配套：无法在内部找到修齐课程者时，确保管理团队整体凑齐所需经验组合；失败与改错的经历比成功履历更有信息量。
  tags: [选人用人, 经验学校, 领导力配置, 破坏性业务]

- id: p13
  title: 新业务启动即把初始成本结构设计成理想客户的小订单也赢利
  type: principle
  source_chapter: 第8章
  source_quote: 慎重控制新成长业务的初始成本结构，因为这会迅速决定价值取向，影响业务中关键的资源分配决策。
  summary: |
    何时用：新成长业务启动期做预算、租办公室、建团队、定薪酬结构时——这是高管的头号行政杠杆。
    怎么用：按零消费/低端理想客户的小订单口径设计成本结构（低固定成本、低管理费用、高资产周转），使小订单在内部审批中"够格"；因为成本结构会迅速固化为价值观，决定组织此后认为哪类客户、渠道、订单有吸引力。
    禁令：不要按大额收入假设花启动资金——高固定成本会把破坏性战略漂移成别的业务（如从产品制造商漂移成合约研究机构）。
  tags: [成本结构, 新业务启动, 价值观, 资源分配]

- id: p14
  title: 制胜策略未明时用应急流程小额试错，明朗后果断切换谋划执行
  type: principle
  source_chapter: 第8章
  source_quote: 高管层的错误在于，在策略运用的可行性尚不明确之前，就采用了谋划型策略流程。
  summary: |
    何时用：决定对新业务是大笔投入执行既定计划，还是保留弹性边做边学时。
    怎么用：自问三问——成功关键细节是否已知？全员能否一致理解执行？外部不可控力量是否排除？任一为否即处于应急阶段：保持灵活性、禁止大额承诺、从试错中筛出可行策略；一旦模式清晰浮现，立即停止资助分散注意力的项目，切换到谋划型流程大胆执行。
    两类典型失败：该探索时砸钱执行（神童通信、苹果牛顿），该执行时继续摸索。
  tags: [战略流程, 应急型, 谋划型, 情境匹配, 模式切换]

- id: p15
  title: 用"以探索为导向的计划"：先摆出要求的财务数字，再列出并测试必须为真的假设
  type: principle
  source_chapter: 第8章
  source_quote: 所需的利润表和投资回报率应该作为每场演示的第一张标准幻灯片。第二步是真正工作的开始，是编制一个假设清单，它旨在回答一个问题，"我们都知道利润率需要有多高，然后要使这些数字成为现实，我们需要证明哪个假设是真实的？"
  summary: |
    何时用：破坏性/探索期业务的计划制订与审批，替代传统"假设→财务预测→审批"流程。
    怎么用：重排四步——①开诚布公摆出资助所要求的利润率与ROI；②编制"要使这些数字成立必须为真"的假设清单；③按重要性从高到低排序；④用成本最低的方式逐一测试假设，边学边改计划。
    禁令：不要通过反复修饰假设让财务预测变好看——那是把真实假设藏进数字里，放任错误策略长期执行。
  tags: [发现驱动计划, 假设测试, 探索式规划, 业务计划]

- id: p16
  title: 破坏性业务早期资金要"对成长有耐心、对利润没耐心"
  type: principle
  source_chapter: 第9章
  source_quote: 在一项业务的萌芽阶段，最好的投资，应该是"对成长有耐心，对赚钱没耐心"的资金。
  summary: |
    何时用：为新业务筹资、谈判投资条款、决定补贴政策时；接受投资前就要谈好期望结构，钱到手即锁定期望。
    怎么用：早期只接受不催促快速做大的钱，同时要求业务尽快赢利——急迫的赢利要求倒逼尽快测试客户是否真愿付钱、催生低成本结构，并在核心业务失血或衰退时保护新业务免遭裁撤。
    禁令：尽量不用原有业务利润补贴新业务亏损；"先赔几年钱抢占市场"的方案说明团队在把破坏性技术塞进现有市场打延续性战争。
  tags: [资金管理, 好钱坏钱, 早期赢利, 投资期望, 补贴]

- id: p17
  title: 趁核心业务健康时按既定节奏持续启动新成长业务，不等失速才动手
  type: principle
  source_chapter: 第9章
  source_quote: 他们必须在核心业务依然茁壮成长时，就频繁启动或收购新的成长业务，因为当成长速度放缓，随之而来的企业价值观的巨大变化会全面叫停成长业务。
  summary: |
    何时用：制定企业成长投资节奏与收购政策时。
    怎么用：建立政策，按预设节奏（如每年新业务数量，而非仅资金预算）在核心业务仍强劲时启动或收购新成长业务，并保持小规模分散的业务单元让更多管理者"够得着"小机会；建设五年后见效的业务必须现在就启动。
    原理：停滞后再启增长的历史成功率仅约4%；且成长放缓会抬升价值观门槛，把破坏性项目全面卡死——等油表见底再加油就来不及了。
  tags: [成长引擎, 投资节奏, 失速点, 业务单元, 先见之明]

- id: p18
  title: 破坏性创新的资源决策必须高管亲自跨界参与，延续性创新才可授权

  source_quote: 在破坏性创新的情况下，当权的高管必须亲自参与。在延续性创新的情况下，授权他人即可有效完成任务。
  summary: |
    何时用：决定高管是否亲自介入某项创新决策时；判断依据是情境而非资金规模或业务规模。
    怎么用：主流组织的流程和价值观能保证决策质量的（延续性创新），授权自下而上执行；破坏性业务的塑造标准与主流价值观冲突，只有最高层有权打破既有流程与决策规则，必须亲自权衡新旧业务的资源冲突、跨界管理两套体系。
    警示：不要建立企业风投式撒网投资来回避此责任——其前提是"成败不可知"，而可靠理论可以把成功率做进流程。
