# 渠道动力测试（渠道也是客户）

## R — 原文 (Reading)

> 如果一件产品不能保证让渠道中的实体企业更顺利地完成它的任务，也就是沿着它们自己的延续性发展轨迹向高端市场转移，建立利润率更高的业务，那么你就难以成功。……你的渠道团队同样也是你的客户，他们也有需要完成的工作，那就是成长、赢利。
>
> — 克里斯坦森 & 雷纳，第4章《我们的产品最适合哪些客户》

---

## I — 方法论骨架 (Interpretation)

"渠道"要广义理解：不仅是批发商和零售店，还包括一切帮你把产品送到客户手上、从中创造价值的实体企业——分销商、销售团队，甚至整机厂商（对英特尔/微软而言，IBM/康柏就是渠道）、医生（医疗产品的渠道）。关键命题：**渠道也是客户**。

渠道成员有自己的任务，那就是成长与赢利；它们的经济处境和小型钢铁厂一样——必须沿自身延续性轨迹向高端迁移，否则就会与同实力对手陷入苦战、利润微薄。因此审计价值链每一个环节时问同一个问题：你的产品能不能帮它向高端转移、赚更多钱？能，它就会投入全部精力帮你把新品做成；不能，它必然理性地把它冷落、边缘化。

推论：破坏性产品通常需要破坏性渠道。佣金制销售员会优先推赚钱的产品，大项目顾问会弃小单选大单，主流高成本渠道会雪藏低毛利新品。鉴别提问可以快速分辨语境：延续性技术场景下渠道问"它能让我看得更准/更便宜吗"；破坏性技术场景下渠道问"要培训吗？培训收费吗？"

## A1 — 书中的应用 (Past Application)

### 案例 1: Pandesic合资公司败于渠道动力错配
- **问题**: 英特尔与SAP合资成立Pandesic，向中型企业销售简化廉价版ERP（新市场破坏），为何失败？
- **方法论的使用**: 管理层把产品交给SAP原有渠道伙伴（埃森哲等IT安装顾问）推广。把渠道当客户审计：这些顾问靠大型企业数百万美元软件加1000万至20亿美元安装运营费获利，面临"花时间卖大额SAP项目还是推销低价Pandesic"的选择，理性选择必然是SAP。
- **结论**: Pandesic的破坏性产品完全没有能量带动这些渠道沿自身轨迹赚更多钱。
- **结果**: 公司8个月雇100人、网罗40家战略伙伴，累计亏损超1亿美元，2001年2月倒闭；验证"破坏性产品需要破坏性渠道"。

### 案例 2: 本田SuperCub与索尼——破坏性产品找到破坏性渠道
- **问题**: 破坏性产品在主流渠道遭拒时该怎么办？
- **方法论的使用**: 本田SuperCub进美国时，哈雷摩托车经销商不愿代销（推销哈雷的佣金更高）；把体育用品店当客户审计——它们引进机动摩托车能向更高端市场迈进、赚更多钱，因此有动力推。索尼的固态电子收音机/电视则与凯马特等折扣零售商互相依托：折扣商没有售后力量修真空管电器，破坏性产品正好成为它们向上突破的助推燃料。
- **结论**: 渠道拒绝不是坏事；找到能借你的产品向高端转移的渠道才是关键。
- **结果**: 本田开创美国越野摩托新市场，索尼与折扣商共同成长；作者称"在我们研究的每一个成功破坏性创新案例中，产品和渠道都具备类似的双赢关系"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 破坏性/低价新品准备沿用现有渠道或销售团队，担心渠道没有动力推。
2. 渠道反馈"这个不如XX项目划算，顾不上"、经销商或代理商消极对待新品。
3. 要判断该继续用现有渠道，还是新建一条破坏性渠道。
4. 需要向团队解释"渠道也是客户"，把渠道纳入客户审计。

### 语言信号 (用户的话里出现这些可能激活)

- "渠道不推我们的新品怎么办？"
- "经销商只愿意卖大单/高价产品。"
- "销售团队忙着卖老产品，顾不上这个。"
- "Will our partners actually push this?"
- "渠道也是客户" / "channel is a customer"

### 与相邻 skill 的区分

- 与 `hire-product-theory` 的区别: 对方处理终端客户要完成的任务；本 skill 把"渠道成员"也当作要完成成长/赢利任务的客户来审计，是任务理论在渠道上的专门应用。
- 与 `asymmetric-motivation-test` 的区别: 对方预测产品市场上所有在位者的反应；本 skill 的对象是价值链上帮你触达客户的渠道环节，问的是"它有没有动力推"。
- 与 `commoditization-positioning` 的区别: 对方判断利润沿价值链迁移到哪个环节、渠道品牌价值如何变化；本 skill 只问渠道对新品的推力是否足够。
- 与 `new-market-disruption-pattern` 的区别: 渠道动力是对方四要素中要素四（新价值网络/破坏性渠道）的展开工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画出完整价值链并标出所有渠道环节**
   - 完成标准: 列出产品从生产到终端客户之间每一个实体环节——批发、零售、分销、销售团队、整机厂商、专业服务者（如医生）等，不遗漏隐性渠道（如内部佣金制销售）。

2. **逐环节把渠道当客户审计其任务与激励**
   - 完成标准: 对每个环节写明它自己的任务（成长、赢利）与赚钱方式（佣金、毛利、项目费），判断你的产品在它的选择清单里排第几。

3. **执行渠道动力问句**
   - 完成标准: 对每个环节回答"你的产品能否帮它沿自身延续性轨迹向高端转移、赚更多钱"；给出能/不能及理由。
   - 判停条件: 若某关键环节答"不能" → 标记为动力不足，进入步骤 4。

4. **决定换渠道或建破坏性渠道**
   - 完成标准: 对动力不足的关键环节，给出具体方案——改用或新建能借你的产品向高端转移的渠道；若必须用现有渠道，说明需要怎样改造其激励（但须评估可行性，通常不成立）。

5. **用鉴别问句确认渠道语境**
   - 完成标准: 用"它能让我看得更准/更便宜吗"（延续性）vs"要培训吗？培训收费吗"（破坏性）的问句区分渠道对新品的真实态度，并记录渠道的实际回应证据。

6. **输出渠道策略结论**
   - 完成标准: 给出单一建议（沿用现有渠道/新建破坏性渠道/暂缓）及关键假设；若渠道动力不成立，明确提示这会否决整个破坏性项目。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 终端消费者是否存在需求这个前置问题还没解决——先用 `hire-product-theory` / `nonconsumer-screening`。
- 纯定价、产品功能或技术问题，与渠道激励无关。
- 已经确认渠道动力充足、障碍在别处（如产能、监管）。

### 作者在书中警告的失败模式

- **用不给力的渠道推广破坏性产品（渠道错配）**：把破坏性产品交给只从大项目高毛利中获益的现有渠道（大客户顾问、佣金制销售、主流零售），渠道理性地优先推更赚钱的延续性产品，破坏性产品被边缘化，项目失败（ce06，Pandesic 即例）。
- **渠道助推燃料会耗尽**：当渠道自身也陷入同质竞争、利润见底时，你的产品不再是它的助推燃料（如折扣商放弃电子产品），需持续寻找新的破坏性渠道。

### 作者的盲点 / 时代局限

- 案例集中于 2003 年前美国上市大企业与其传统分销体系，对平台/生态型渠道、线上直销、双边市场、非上市耐心资本的适用性未经验证。
- "产品和渠道都具备双赢关系"来自作者研究的成功案例，存在幸存者偏差；失败渠道案例（如 CLEC 依赖电话公司网络）提示该结论并非普遍规律。
- 渠道激励的真实数据（佣金结构、内部KPI）多为企业内部信息，外部人难以精确观测；对渠道"向上迁移"意愿的判断带有推测性。
- 多渠道/平台型商业模式的复杂性超出书的二分框架（零售商/分销商），需要补充新理论。

### 容易混淆的邻近方法论

- 与"渠道管理/渠道政策"：本 skill 不是谈返利、铺货或分销政策，而是先判断渠道作为客户的**根本动机**是否与你一致。
- 与"品牌合作/战略联盟"：本 skill 追问的是对方借你的产品能否向高端转移，而非合作协议条款。
