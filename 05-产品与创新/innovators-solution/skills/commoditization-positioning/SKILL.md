# 货品化-反货品化价值链定位：利润不会消失，只会迁移

## R — 原文 (Reading)

> 我们相信这也是戴尔公司在20世纪90年代晚期战胜康柏公司的重要原因之一。戴尔公司在一个非常重要的"不够完善"的接口上进行了整合，而康柏公司却坐失良机。
>
> — 克里斯坦森 & 雷纳, 第6章 如何避免货品化

---

## I — 方法论骨架 (Interpretation)

货品化不是行业宿命，而是价值链上的钟摆。当某一段被模块化、标准化，竞争基础就从性能转向价格，那一段的高利润"凭空消失"；但与之相邻的某个环节必因仍未"不够完善"而聚集起新的高利润——这就是高利润守恒定律。诊断与定位分三步：

1. **定位本行业走到货品化第几步**：专利架构 → 过度服务 → 竞争基础转变 → 模块化 → 分包化 → 同质价格竞争。
2. **问下游客户"现在哪个性能导向子系统还不够好"**：那里就是下一个利润聚集点，企业应把资源重新定位到该环节（可能是子系统、软件、客户接口或渠道）。
3. **拒绝按"行业"标签判断盈利性**：同一行业不同环节利润率天差地别；品牌投资也必须随利润迁移到仍"不够好"的子系统或渠道环节。

预警：当别人劝你外包某业务时，反问"这项工作也不是他的核心竞争力，他为什么要？"——识别供应商逐级向上吞食的不对称动机。

## A1 — 书中的应用 (Past Application)

### 案例 1: PC/磁盘驱动器——毛利从 60% 降至 15%
- **问题**: PC 行业组件高度标准化后，整机组装环节利润被挤压。
- **方法论的使用**: 用六步货品化进程对照，组装环节已从专利架构走到同质价格竞争。
- **结论**: 利润并未消失，而是迁移到仍未"不够好"的子系统（英特尔芯片、微软操作系统）与客户接口（戴尔直销）。
- **结果**: 3.5 英寸驱动器毛利从 60% 降至 15%；Wintel 与戴尔成为 PC 价值链利润聚集处。

### 案例 2: 戴尔整合客户接口而非组件，90 年代末击败康柏
- **问题**: 组装已货品化，整机厂靠什么赚钱？
- **方法论的使用**: 戴尔判断对客户而言直销/客户关系接口仍"不够完善"，遂在客户接口上整合，对已过度服务的组件模块放手外包。
- **结论**: 高利润聚集在"不够好"的客户接口，戴尔选址正确。
- **结果**: 戴尔靠客户接口获得的利润远超组装业务，康柏坐失良机。

### 案例 3: TCC 寓言——组件公司逐级吞食
- **问题**: 模块化装配商 TCC 在 ROA 压力下被供应商以"这不是你的核心竞争力"逐级劝退业务。
- **方法论的使用**: 作者用寓言演示货品化与反货品化成对推进：每剥离一轮，供应商就向上吞食一层（电路板→主板→组装→供应链→设计）。
- **结论**: 货品化与反货品化是同一枚硬币的两面，利润沿价值链上移。
- **结果**: TCC 只剩空心品牌躯壳，利润被组件公司摄取。

### 案例 4: 品牌随利润迁移
- **问题**: 强品牌能否永久抵御货品化？
- **方法论的使用**: 作者指出品牌溢价只存在于"不够好"的环节，竞争基础转变后品牌价值会迁移。
- **结论**: 品牌投资须跟随利润流向（终端产品 → 子系统品牌或渠道品牌）。
- **结果**: 服装业渠道品牌 Gap/Talbot's 崛起；马克卡车品牌价值向康明斯发动机迁移。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 行业同质化价格战加剧，利润率被上下游两头挤压，企业在问"下一个赚钱的环节在哪"。
2. 公司想预测某个产业链（光伏、新能源、消费电子）未来的利润聚集点，做战略资源重新配置。
3. 有人主张继续重金投品牌以抗同质化，需要判断品牌溢价是否还能守住。
4. 供应商主动上门承接某块业务，企业想评估其中隐藏的不对称动机与价值链地位风险。

### 语言信号 (用户的话里出现这些就应激活)

- "行业越来越卷，只能拼价格了，利润都去哪了？"
- "利润被上游/下游赚走了，我们该往哪块走？"
- "我们品牌很强，应该能扛住价格战吧？"
- "产业链下一个高利润环节会在哪里？"
- "commoditization / profit migration / 反货品化 / 高利润守恒"

### 与相邻 skill 的区分

- 与 `interdependence-modularity-match` 的区别: 本 skill 预测"利润迁移到哪个环节、企业该重新定位到哪"（价值链选址）；后者解决企业自身的整合/模块化架构选择。
- 与 `modular-outsourcing-conditions` 的区别: 后者检验某接口能否安全外包；本 skill 关注外包背后利润被谁摄取、企业该守住哪个环节。
- 与 `resource-allocation-audit` 的区别: 本 skill 是价值链定位的预测框架；后者审计组织内部的资源分配过滤器与真实战略。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位本行业处于货品化第几步**
   - 完成标准: 给出六步（专利架构→过度服务→竞争基础转变→模块化→分包化→同质价竞争）中的具体定位与证据。

2. **画出价值链各环节的利润率与"不够好"程度**
   - 完成标准: 列出从上游到下游的各环节，标注哪一环仍未被充分满足、哪一环已被过度服务且只能拼价格。

3. **定位下一个高利润聚集点**
   - 完成标准: 明确回答"下游客户现在哪个性能导向子系统还不够好"，并指出对应的利润聚集环节。

4. **给出重新定位建议（含品牌投入流向）**
   - 完成标准: 输出资源应转向哪个环节的具体动作，并说明品牌/差异化投入是否应随之迁移。

5. **扫描供应商不对称动机**
   - 完成标准: 对"别人劝你外包"的业务，反问并回答"这项工作也不是他的核心竞争力，他为什么要？"，标出逐级吞食风险。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只在纠结单个模块该自研还是采购，不涉及价值链利润迁移判断——应先用 interdependence-modularity-match。
- 用户问的是短期财报波动或成本控制，未涉及竞争基础与利润结构变化。
- 行业利润下滑源于需求总额萎缩/政策管制，而非货品化机制——本框架预测的是迁移而非总量。

### 作者在书中警告的失败模式

- **为提升 ROA 层层剥离资产，陷入死亡旋涡**（ce09）：以"非核心"为由逐级剥离（电路板→主板→组装→供应链→设计），短期 ROA 与股价改善，最终只剩空心品牌。
- **把品牌溢价当抗货品化护城河**（ce10）：产品已过度服务仍把品牌预算全压在终端产品上，溢价随竞争基础转移而萎缩。
- **用"核心竞争力"话术做外包/业务范围决策**（ce07）：把看似非核心、实则代表未来利润增长点的业务让给供应商。

### 作者的盲点 / 时代局限

- 高利润守恒定律由有限案例（PC/磁盘驱动器/服装）归纳，属经验性规律；在平台型、双边市场、强网络效应行业中，利润分布逻辑可能不同，适用性未验证。
- 六步货品化进程是事后归纳的分期，现实中各步可能重叠或跳跃，精确判定行业"第几步"并不容易。
- 案例集中于 2003 年前的美国大企业；对非上市企业、耐心资本、生态型组织的价值链定位结论需打折。
- "品牌会随利润迁移"的前瞻语义强于实证，部分推演未经时间检验。

### 容易混淆的邻近方法论

- 波特五力/价值链分析：静态的结构与环节分析；本 skill 加入"利润随性能缺口迁移"的动态预测。
- 破坏性创新理论：货品化-反货品化是其价值链侧的分支。
