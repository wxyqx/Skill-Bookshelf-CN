# 高管参与度的情境判断规则（按情境不按规模）

## R — 原文 (Reading)

> 主流流程和价值观就能保证一些决策的有效性（主要是针对延续性创新），对这些决策来说，基本无须高管干预。只有当高管们意识到，主流组织的流程和价值观已无法处理组织中的重要决定（通常是在面临破坏性创新的情况下）时，才需要高管的参与。……唯有最高层的管理者能够批准在适合的情况下使用企业流程，而在不适合的情况下，则有权打破这些流程和决策规则的限制。
>
> — 克里斯坦森 & 雷纳，第10章《高管角色》

---

## I — 方法论骨架 (Interpretation)

"大人物做大决定"是一种错觉。其错误在于：组织的信息从纵向看是不对称的——数据分散在每个具体部门，高管除了下级选择上报给他们的信息之外几乎一无所知；更糟的是，中层经历多次决策后学会了"什么数据能过审、什么信息不该报"，于是高管的"重大决策"实际是在被筛选过的信息上做的。

另一个错误是"规模论"：认为大业务需要高管多参与、小业务可以放手。事实上潜在的破坏性新业务通常很小，但策略不明确、必须尽快赚钱，决策常常"不入天堂则下地狱"，而其组织内部缺乏正确的决策流程，管理者水平直接决定存亡；相反，成熟的大业务有稳固客户和精湛流程，按流程执行即可，反而不需要大人物。

正确的判据是**情境**：看主流流程与价值观能否保证决策质量。若是延续性创新（服务现有客户、流程价值观适用），授权即可，过度介入反而诱发中层报喜不报忧。若是破坏性创新（流程与价值观无法处理、标准不同），必须由最高层亲自跨界管理——因为只有最高层有权在适合时用流程、在不适时打破流程与决策规则。

## A1 — 书中的应用 (Past Application)

### 案例 1: 耐普罗Novaplast——CEO预见对了，却输给了组织流程
- **问题**: 精密注塑企业耐普罗的CEO兰克顿预见竞争基础正从大批量高精密转向多品种小批量，开发出不到1分钟完成参数设定的Novaplast机器，为什么会失败？
- **方法论的使用**: 他把机器交给28家工厂自行租用试用——这是把破坏性机会交给了主流组织评估。按情境判断：Novaplast会重塑赢利模式（冲击现有为大批量高精度业务优化的流程与价值观），属破坏性决策，主流流程无法处理，本应由CEO跨界另建组织来管理。
- **结论**: 治理结构错误——用授权处理了本应亲自跨界管理的破坏性决策。
- **结果**: 6家租用中4家在4个月内退回，因为现有流程和价值观把它过滤成了延续性技术；只有留下并靠长期订单验证价值的2家证明其潜力。CEO预见正确但治理错误，成为"高管必须跨界管理"的教科书案例。

### 案例 2: 大型零售集团CEO该不该亲自挂帅即时零售子公司（作者式情境推演）
- **问题**: CEO该不该亲自管一个新成立的即时零售子公司？
- **方法论的使用**: 按情境而非规模判断。若这是流程与价值观都不同的破坏性业务（低客单价、快迭代、新成本结构），主流体系的决策规则会把资源导向保卫现有门店客户，主流流程无法保证决策质量——必须CEO亲自跨界管理、打破既有流程与规则；反之若只是围绕现有客户体验的延续性改良，授权给现有团队即可，过度介入反而促使中层过滤信息。
- **结论**: 判据是"主流流程/价值观能否处理"，不是子公司规模大小。
- **结果**: 该书据此主张高管需要一个基于情境的"参政指南"，逐案判断介入深度。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新破坏性业务负责人向CEO汇报，纠结"CEO该亲自管到什么程度、该不该放权"。
2. 组织惯例是"按业务规模/预算大小决定汇报层级"，需要一个按情境判断的替代标准。
3. 高管怀疑自己拿到的信息被中层过滤过，想判断哪些决策必须亲自越过流程。
4. 要判断某项创新该授权给现有团队还是由最高层跨界另建组织管理。

### 语言信号 (用户的话里出现这些可能激活)

- "CEO要不要亲自挂帅这个新业务？"
- "该不该给事业部负责人放权？"
- "大领导该管多细？"
- "When should top management get personally involved? Span of control?"
- "我们是不是拿到的是被筛过的信息？"

### 与相邻 skill 的区分

- 与 `rpv-capability-audit` 的区别: 对方回答"这个业务该放进哪个组织、要不要自治组织"（结构设计）；本 skill 回答"这个决策该由谁来做、高管要不要亲自介入"（决策层级），二者常配合使用。
- 与 `resource-allocation-audit` 的区别: 对方揭示资源分配流程这个黑箱与过滤器；本 skill 关注高管该在哪个环节、以多大深度介入，其"信息纵向不对称"预警沿用对方的机制。
- 与 `emergent-deliberate-strategy` 的区别: 对方判断该用应急型还是谋划型战略流程；本 skill 判断决策权该放在高管还是授权，二者都会涉及"情境匹配"但对象不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定创新性质：延续性还是破坏性**
   - 完成标准: 明确该业务是服务现有客户/沿用现有流程价值观（延续性），还是标准不同、需要新流程新成本结构（破坏性），给出判定依据。

2. **检验主流流程与价值观能否保证决策质量**
   - 完成标准: 逐条说明主流流程/价值观会如何处理该决策；若能把资源导向正确方向，则属可授权情境；若会系统性偏向保卫现有业务，则属必须介入情境。
   - 判停条件: 若判定为"延续性且流程适用" → 结论为授权，进入步骤 5。

3. **对破坏性情境确认高管亲自跨界管理**
   - 完成标准: 明确该决策必须由最高层亲自参与，并列出高管有权在适合时用流程、在不适合时打破流程与规则的具体动作。

4. **排查信息纵向不对称与"报喜不报忧"预警**
   - 完成标准: 检查是否存在"中层知道哪些信息不该上报"的迹象；若存在，指出高管当前的"重大决策"在多大程度上基于被筛选信息，并给出获取未被过滤信息的办法（如亲自下场、设独立汇报线）。

5. **输出介入/授权建议**
   - 完成标准: 给出单一结论（高管亲自跨界管理 / 授权现有团队）及理由；若授权，说明授权边界与需要高管保留的决策点，避免过度介入诱发信息过滤。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 要设计具体的组织结构、成本结构或自治安排——那是 RPV 审计（`rpv-capability-audit`）。
- 常规运营的授权与排期，不涉及"流程/价值观能否处理"的判断。
- 单纯讨论高管个人风格或时间管理。

### 作者在书中警告的失败模式

- **按"胜任者特征/履历光环"选新业务领导人**：用光环选人、最受信赖的核心业务成功者反而最不适合领导破坏性新业务（ce12，Pandesic 即例）。
- **在主流组织内孵化破坏性业务（被价值观同化）**：把破坏性业务放进主流流程与价值观中孵化，被主流毛利率和规模阈值同化，要么被抬价做延续性、要么被砍掉（ce11，Woolco 即例）——这正是需要高管跨界另建组织的原因。
- **信息纵向不对称的决策幻觉**：高管"自以为"作着重大决策，实则是在中层筛选过的信息上决策（书第10章原话）。

### 作者的盲点 / 时代局限

- 样本集中于 2003 年前美国上市大企业（尤其耐普罗等个案），"按情境而非规模"的规则对平台/生态型组织、非上市耐心资本、扁平小团队与创始人主导型公司的适用性未经验证。
- "组织不能自我破坏""只有最高层能打破规则"主要靠个案支撑，缺乏系统性证据；对现代分布式决策、OKR/授权型组织的适用性需打折。
- "高管亲自参与是破坏性业务成功最重要的资源之一"带有较强规范性，可能低估了高管个人精力有限与情境判断本身的主观性。
- 部分前瞻推演与管理建议未经时间检验；后续治理理论（如委托-代理、敏捷组织）可能提供替代解释。

### 容易混淆的邻近方法论

- 与"领导力风格/授权艺术"：本 skill 不是谈放手与否的性格问题，而是按情境（流程与价值观能否处理）判断决策权归属。
- 与"规模决定汇报层级"的常规治理惯例：本 skill 明确反对以规模为标准，主张以创新性质为标准。
