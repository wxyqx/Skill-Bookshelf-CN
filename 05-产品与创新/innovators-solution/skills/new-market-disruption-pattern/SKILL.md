# 新市场破坏四要素模式（含模式评审式预算）

## R — 原文 (Reading)

> 1.目标客户想要完成某项工作，但是缺乏资金或技术，在现有的市场上又找不到简单便宜的解决方案。2.客户会把破坏性产品和"没有产品可用"来做对比……这些新市场客户对于性能的要求很低。3.破坏者们把复杂的技术引入到简单易用的破坏性产品上……4.破坏性创新制造了一个全新的价值网络。
>
> — 克里斯坦森 & 雷纳，第4章《我们的产品最适合哪些客户》

---

## I — 方法论骨架 (Interpretation)

新市场破坏不是碰运气，它有一套可复用的经验模式（四要素）。要素一：目标客户有任务要完成，但缺资金或技术，市场上又找不到简单便宜的方案——这是"零消费者"。要素二：客户拿"没有产品可用"当对比基准，因此很容易被取悦，对性能要求很低。要素三：技术本身可能复杂，但破坏者把复杂技术封装进简单易用、不需培训就能上手的产品里，这就是新的成长来源。要素四：破坏创新会造出一个全新的价值网络——新客户在新渠道购买、在新地点使用。

四个要素合起来既是"塑造工具"（把萌芽创意塑造成符合历史模式的业务计划），也是"评审模板"（主管资源分配的高管以"符合典型模式与否"而非数字/ROI 规则来衡量新计划，为破坏性创意开辟一条平行预算流程）。

为什么必须另开平行流程？因为理性的主管天然倾向于投资回报率最高、最像过去成功案例的项目；而破坏性机会在萌芽期"看不清市场"，硬塞进常规筛选会被扭曲成延续性计划，拿去现有大市场里硬碰硬。

## A1 — 书中的应用 (Past Application)

### 案例 1: 从晶体管收音机、血管成形术、太阳能归纳出四要素
- **问题**: 三个不同行业的新市场破坏（消费电子/医疗/能源）有无共同模式可循？
- **方法论的使用**: 作者萃取三者：
  收音机/电视——目标客户是买不起真空管设备、以"没有"为基准的青少年与小户型居民，产品简单低端即取悦；血管成形术——面向过去得不到治疗的心脏病患者（有任务无方案），技术复杂但操作被简化到普通医生即可实施，创造出心脏专科医生这一新价值网络；太阳能——无电网地区以"没有电"为基准，便宜、免审批、可靠即取悦，形成新渠道与使用场景。
- **结论**: 三者都完整符合四要素，说明新市场破坏有可复制的模式。
- **结果**: 这套模式被作为"塑造模板+评审模板"，指导后来者按模式设计并申请预算，而非被常规ROI流程淘汰。

### 案例 2: 吉尔伯特研究——报刊企业把网络部门设为独立事业部
- **问题**: 在位报刊企业如何在资源分配中既拿到钱、又不让新业务被主流同化？
- **方法论的使用**: 按四要素把网络媒体塑造成新市场破坏后，在资源分配阶段把它塑造为"威胁"以争取资源；一旦投资确定，就把它放进自主运营、独立核算的事业部（新服务方式、新供应商、新广告商），并塑造为成长机遇。
- **结论**: 模式化塑造 + 平行/独立安排，能让破坏性项目既拿到资源又保持新价值网络。
- **结果**: 独立事业部的报刊企业全力投入并开辟新市场；继续在主流市场打保卫战的报刊企业则自相残杀。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 已判定一个构想是新市场破坏，要写出一份能过内部评审的业务计划，而不是被常规市场规模/ROI 规则刷掉。
2. 高管/投资人要评审一个"破坏性"创意，需要一个不靠滞后财务数据的判断模板。
3. 组织里破坏性创意总被扭曲成延续性计划，想为它开辟平行预算流程。
4. 要为一款新产品设计"简单易用、免培训"的形态与全新渠道/使用场景。

### 语言信号 (用户的话里出现这些可能激活)

- "怎么把这个破坏性创意做成能立项的业务计划？"
- "评审新业务要不要用ROI？"
- "我们的破坏性项目总被要求补市场规模数据，怎么办？"
- "How should we shape/budget a new-market disruption plan?"
- "用四要素看看这个方案齐不齐"

### 与相邻 skill 的区分

- 与 `three-stone-tests` 的区别: 对方判断"这个构想能不能成为破坏"（三关检验）；本 skill 在判定之后，负责"怎么把它塑造成可资助、可评审的新市场破坏计划"。
- 与 `nonconsumer-screening` 的区别: 对方的零消费者甄别是本 skill 要素一的前置输入；本 skill 把四要素作为一个整体来塑造与评审。
- 与 `channel-motivation-test` 的区别: 对方的渠道动力测试是本 skill 要素四（新价值网络/破坏性渠道）的展开；当你只需解决"渠道会不会帮你推"时用对方。
- 与 `resource-allocation-audit` 的区别: 对方审计组织**现有**过滤器会怎么磨平创意；本 skill 主动设计一条**平行**的模式评审流程来保护创意。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **核对要素一：目标客户有任务、缺资金技术、无简单便宜方案**
   - 完成标准: 明确指出目标客户要完成什么任务、为什么现有市场没有简单便宜的方案，且客户属零消费者（有任务无方案），而非"买不起但无任务"。

2. **核对要素二：以"没有产品"为参照基准、性能要求低**
   - 完成标准: 说明客户拿什么做对比，确认是"没有产品可用"而非主流高端产品，据此定出低性能门槛与"易被取悦"的证据。

3. **核对要素三：把复杂技术封装成免培训的简单产品**
   - 完成标准: 给出一条具体的产品形态设计原则（如何让不需培训的人也能用），并指出哪些复杂性被封装、由谁承担。

4. **核对要素四：形成新价值网络**
   - 完成标准: 明确列出新客户将在什么新渠道购买、在什么新地点使用；若渠道尚未成立，转 `channel-motivation-test` 检验渠道动力。
   - 判停条件: 若无法形成新渠道/新场景（仍依赖现有高成本渠道）→ 要素四不成立，回到步骤 1 重塑定位。

5. **作为评审模板：以模式而非数字做预算标准**
   - 完成标准: 高管/评审方按"是否符合四要素模式"给预算，明确不要求萌芽期提供可靠市场规模数据与ROI；为破坏性创意设立与延续性项目并行的评审流程。

6. **设定威胁/机遇双重框架**
   - 完成标准: 在资源分配阶段把该创新呈现为威胁以争取资源，在实施阶段交独立部门并呈现为机遇；写明两阶段各自的动作。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 低端市场破坏的业务计划——它的核心是"低价仍赢利的独立业务模式"（低管理费用+高资产周转），不是四要素模式。
- 组织该放哪里、要不要自治、如何设成本结构——那是 RPV/自治组织问题。
- 已经成熟、在现有大市场里作战的延续性业务预算——常规ROI流程对它恰好是对的。

### 作者在书中警告的失败模式

- **把破坏性创意包装成延续性计划（磨平机制）**：中层为过审按"类似过去成功案例"重新包装，把面向零消费/低端的破坏性构想改写成服务现有主流客户、塞满现有客户与渠道的延续性计划（ce01）。这正是需要平行流程的原因。
- **把破坏性技术硬塞进主流市场（威胁-僵化）**：在位者把破坏性技术定义为威胁后全力保卫现有客户，把新技术做成延续性产品塞进主流价值网络自相残杀（ce02）。
- **用不给力的渠道推广破坏性产品**：把破坏性产品交给只从大项目高毛利中获益的现有渠道，必然被边缘化（ce06）——要素四落空。

### 作者的盲点 / 时代局限

- 案例集中于 2003 年前美国上市大企业，对平台/生态型组织、非上市耐心资本、扁平小团队的适用性未经验证。
- "以典型模式而非数字做预算标准"违背常规财务流程，其在大型组织中的可行性主要来自个别案例，未获普遍验证；也可能被滥用为"不做财务纪律"的借口。
- 四要素是经验归纳，"几乎总是"类表述受案例选择影响；在需求难以观测时，"性能要求低/易被取悦"的判断带有主观性。
- 精益创业等后续方法已部分替代书中的发现式规划，四要素在快速迭代环境中可能需要重新校准。

### 容易混淆的邻近方法论

- 与"最小可行产品/精益创业"：两者都强调早期不确定性，但四要素是行业级模式匹配与预算规则，不是产品迭代节奏方法。
- 与"蓝海战略"：四要素要求"零消费/无方案"这一硬条件，而非泛泛的价值创新。
