## V3 判定理由

"写你所知 / 从打动过你的东西出发"是创作领域的常见建议（Stephen King、编剧手册均如此）；"体验的终点是记忆"与行为科学的峰终定律（peak-end rule, Kahneman）高度重合；情景记忆/语义记忆的筛选机制是认知科学教科书内容。抹掉作者名后，聪明人可以完整说出这个单元。本书的独特贡献是"用记忆分类学支撑三种设计"的统摄地位——这是全书的本质章，但作为独立方法论单元缺乏独家操作程序。
