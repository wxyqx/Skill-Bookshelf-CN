# 疲劳厌倦时机管理（心理饱和→插入意外）

## R — 原文 (Reading)

> "'想玩，但很困！'玩家经常会陷入这种奇怪的状态，明明还有继续玩下去的欲望，但疲劳和厌倦已经在身心中累积了。" / "让人疲劳和厌倦，这正是直觉设计的致命缺点。"
>
> — 玉树真一郎，第2章《为什么是惊喜刺激》

---

## I — 方法论骨架 (Interpretation)

任何由"投入→确认→再投入"构成的长体验（学习、冒险、项目、课程），每一步都夹着"不知道对不对"的不安；加上大脑对重复刺激的反应会衰减（心理饱和/心理适应），疲劳和厌倦**必然**累积——这不是设计失误，是结构必然。它制造出一种矛盾状态："想玩，但很困"：欲望还在，疲劳已超标。超过极限，人就走，且不会回头。

大脑的预测模型给出了插入点的判据：大脑为生存持续预测未来，学习就是提高预测精度；当预测持续命中，大脑判定"不需要再学习"，进入饱和。所以插入意外的正确时机不是随机穿插，而是在用户"已经能完全预测接下来"的段落制造预测失灵——危机感重新激活学习动力。

同一坐标上有三种动作可选：①插入意外（让 `surprise-design-two-beliefs` 执行）；②战略暂停（换任务类型、留白——DQ4 赌场是设计出来的"暂时停止冒险"）；③让体验停止（交给 `stop-design-graceful-endings`）。编排上还有一条工具：按信息量×主动/被动把段落排成波浪——信息多的被动段与信息少的主动段交替，没有波浪就疲劳厌倦。

## A1 — 书中的应用 (Past Application)

### 案例 1: DQ1-4 的"惊喜刺激"登场时机
- **问题**: 学指令、练级、闯迷宫的连续学习让玩家疲惫厌倦，怎么让他忍着困也玩下去？
- **方法论的使用**: 四代作品的"惊喜刺激"全部出现在疲劳顶点：学完全部指令后/首次迷宫通关后/第一次打败强敌后——先定位饱和点，再让"意料之外"登场。
- **结果**: "想玩，但很困"被化解，玩家沉浸到通宵。

### 案例 2: DQ4 赌场
- **问题**: 20-30 小时的史诗冒险，疲劳怎么排？
- **方法论的使用**: 引入赌场，故意剥夺"认真攒钱"的玩家的认真感，设计一段战略性暂停；赌场以不引起怀疑的程度让玩家赢，再用强装备把人自然送回冒险。
- **结果**: DQ4 成为社会现象级作品。

### 案例 3: 演示中的沉默
- **问题**: 演示进行到中段听众开始走神。
- **方法论的使用**: 定期插入禁忌主题与沉默——沉默推翻"演示者在说话"的前提，重新激活注意力。
- **结果**: 听众被拉回（第5章应用3 的操作）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 课程/训练营/连载的中段流失：数据上"第 N 章/第 N 周"断崖。
2. 用户调研里出现"挺好的，就是坚持不下去""玩着玩着就腻了"。
3. 长会议、长活动、长项目越到后段越冷场，想安排"爆点"却不知放哪。
4. 产品做签到、每日任务，参与率逐周衰减。
5. 直播、播客、社群运营的热度维持。

### 语言信号 (用户的话里出现这些就应激活)

- "坚持不下去 / 中途放弃 / 弃坑 / 虎头蛇尾"
- "完课率/留存/参与率中途下滑"
- "腻了 / 疲了 / 没新鲜感了"
- "什么时候插互动/惊喜/休息"
- "can't keep going / drop-off mid-way / fatigue / pacing / burnout"

### 与相邻 skill 的区分

- 与 `intuition-design-loop` 的区别：那个管"单个循环怎么让人行动"，是疲劳的**来源**（连续微循环必然饱和）；本 skill 管饱和之后的**节奏**。先有好循环，才谈得上管理疲劳。
- 与 `surprise-design-two-beliefs` 的区别：本 skill 回答"什么时候需要惊喜"（定位饱和点）；那个回答"惊喜怎么造"（误解→尝试→惊讶的施工）。诊断用它，施工用那个。
- 与 `stop-design-graceful-endings` 的区别：目标是延长体验→本 skill；目标是体面结束→那个。

## E — 可执行步骤 (Execution)

1. **画出投入序列**
   - 完成标准：把长体验拆成按时间排列的段落，标注每段的"学习/投入强度"和"可预测程度"（用户能否猜到下一段）。
2. **定位饱和点**
   - 完成标准：找出连续高投入、高可预测的段落，标出 1-3 个"疲劳顶点"候选（参照：刚学完一整套东西之后、连续重复第 N 次时）。判停条件：若流失点之前根本没有连续投入（每次都很短），疲劳不是病因——转做内容价值诊断，勿用本 skill。
3. **三选一安排动作**
   - 完成标准：每个饱和点配置一种动作——插入意外（调用 `surprise-design-two-beliefs`）/ 战略暂停（换类型、留白、支线）/ 提前收束（调用 `stop-design-graceful-endings`）；写明触发条件与回程设计（像赌场用强装备送人回冒险）。
4. **波浪复查**
   - 完成标准：全序列按"信息量高（被动吸收）↔低（主动操作）"交替排列，无连续三段同型；顺序保证紧张段在缓和段之前。
5. **用数据验证坐标**
   - 完成标准：改版后观察原流失点的留存/完课变化；若饱和点前移（改动本身引入新疲劳），回步骤 1 重新画。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单次短体验**——广告、短视频没有疲劳累积，直接用"惊喜前置密集"的短内容配置（u05），无需时机管理。
- **流失根因是价值不足**——内容不好玩/没用的流失，插惊喜是止痛药；先用"没价值→故事设计"（`story-design-user-growth`）分诊。
- **把疲劳当变现工具**——本书前提是"为用户消除疲劳"；体力值、断签焦虑式设计是在放大疲劳，与本 skill 方向相反。

### 作者在书中警告的失败模式

- 连续直觉设计不放任何对冲——疲劳超限后彻底停止且不回头（ce13）。
- 在疲劳点"堆更好的内容"——内容质量不是杠杆，时机才是（第2章对 DQ 的分析）。

### 作者的盲点 / 时代局限

- 案例来自玩家有强动机的买断制游戏；低动机产品（工具类）的"疲劳顶点"更早更浅，饱和点要提前估。
- 预测饱和判据偏定性，书中未给量化指标；落地时需用留存/完课数据校准，而非照搬"学完指令后"这类游戏时点。

### 容易混淆的邻近方法论

- 游戏化任务系统（每日签到/体力）：形似（都是节奏设计），神反（那些制造疲劳变现，本 skill 消除疲劳）。
- 心流理论（Csikszentmihalyi）：都讲难度与投入的匹配；本书增量是"疲劳的时间坐标"——不是调节当下难度，而是预测饱和时刻并提前布局。
