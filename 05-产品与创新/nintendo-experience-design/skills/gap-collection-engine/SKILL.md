# 空缺驱动：整体→空缺→收集重复→成长

## R — 原文 (Reading)

> "只要认识到空缺就可以了。人们发现空缺就想填，而且不由自主就填了。" / "如果没有事先认识到整体的范围和共同的性质，就无法将'空缺'作为'空缺'来认识。"
>
> — 玉树真一郎，第3章《成长的主题1：收集和重复》

---

## I — 方法论骨架 (Interpretation)

收集是最利于成长的体验设计，因为它的心理引擎是被精确编排的：**先有整体，才有空缺**。人必须先认识整体的范围和共同性质（先看到 1～8，或先拿到空白的 151 格图鉴），"缺的那块"才会被识别为空缺；而人一旦识别出空缺，就"不由自主"想填——几个空缺支撑多次重复，重复使脑细胞联系增强，成长自然发生。游戏化常见的病灶恰是顺序颠倒：先发积分徽章、不给整体图景，徽章只是贴标签。

空缺的形态不止一格图鉴：可以是字幕留下的 20 年时间空洞（《最后生还者》）、可以是完全看不懂的神秘文字（《风之旅人》把文字本身当收集要素）。**节奏**是它的时间形态——"节奏就是在时间箭头上均匀分布的空缺"：广播体操用配乐让人做满 66 次举臂（"举 66 次"的命令没人听）；俄罗斯方块则反其道而行——方块一放下立刻掉下一块，**不给**"问题已解决"的缓解间隙（蔡格尼克效应：未解决的问题保持紧张感），所以停不下来。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 《精灵宝可梦》图鉴
- **问题**: 怎么让 151 个宝可梦被全部记住（连父母都惊叹）？
- **方法论的使用**: 游戏开局先让玩家三选一并得到**空白图鉴**——整体框架与空缺同时被认识；抓宝可梦的过程反复填空。
- **结果**: "要是学习也能这样就好了"成为一代父母的叹息。

### 案例 2: 俄罗斯方块的节奏
- **问题**: 只是把掉下来的方块排整齐，为什么停不下来？
- **方法论的使用**: 方块落下无停顿（三选一里最反直觉的答案③），玩家得不到缓解紧张感的间隙，只能持续思考下一个放置点。
- **结果**: 开创休闲益智品类的鼻祖，水平在停不下来中自动进步。

### 案例 3: 广播体操的配乐
- **问题**: "举起手臂 66 次"这种明确的重复指令没人有劲头。
- **方法论的使用**: 把重复嵌进节奏——一首完整的体操曲让空缺（下一拍）一个接一个自动出现。
- **结果**: 不知不觉做满 66 次。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 知识库/文档库/图鉴式功能建了没人维护、没人集齐。
2. 想让重复性行为（背单词、锻炼、练习、整理）"停不下来"。
3. 设计收集要素、进度条、完成度、成就系统，或评估现有积分体系为什么失效。
4. 内容连载想让读者追更、产品想让用户回来补全。
5. 争论游戏化（积分/徽章/排行榜）要不要上、怎么上。

### 语言信号 (用户的话里出现这些就应激活)

- "收集 / 集齐 / 图鉴 / 填满 / 补全"
- "进度 / 完成度 / 打卡 / 坚持不下来 / 停不下来"
- "积分徽章没用 / 游戏化怎么做"
- "让人反复回来 / 追更"
- "collection / completionist / streak / progress bar / Zeigarnik"

### 与相邻 skill 的区分

- 与 `risk-reward-choice-feedback` 的区别：那个是"成长"的第二主题（选项与反馈）；本 skill 是第一主题（收集重复）。书中两者可组合——收集选项兼任难度调节器，但触发问题不同：粘性/重复→本 skill；选择与反馈设计→那个。
- 与 `foreshadow-payoff-homecoming` 的区别：同样利用"缺"，空缺驱动**过程**（让重复发生），伏笔制造**终点揭示**；别把中途的空缺感误当伏笔设计。
- 与通用游戏化（PBL）：方向相反——本 skill 要求先给整体图景再露空缺，反对无图景的徽章贴标签。

## E — 可执行步骤 (Execution)

1. **画出整体图景**
   - 完成标准：目标领域有一张用户一眼能认识的"图鉴"——整体范围+共同性质（151 格、8 大类、全地图）。判停条件：画不出整体（领域无限开放）→ 收集引擎不适用，改用其他动机设计。
2. **制造被识别的空缺**
   - 完成标准：整体上留出醒目的空位（未认领条目、缺章、空格），确保用户"看见缺口"而不是"看不见库存"；空缺数量与用户的重复承受力匹配（3-7 个并行）。
3. **给重复配节奏**
   - 完成标准：把填空动作嵌进固定节奏（每周同一时段、固定间隔），不使用"一共要做 N 次"的命令式计数；需要"停不下来"的强粘性场景则反向设计——不给缓解间隙（完成即出现下一个）。
4. **反馈闭环检查**
   - 完成标准：每次填空都有即时、以用户为主语的确认（"你补上了××"），可衔接 `risk-reward-choice-feedback`；收集内容兼任难度调节（易得+难求并存）。
5. **防厌倦巡检**
   - 完成标准：重复第 N 轮后安排空缺形态的变化（图鉴→时间线→未知物），避免心理饱和；必要时插入战略暂停（见 `fatigue-timing-management`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **先有徽章、没有整体感**——PBL 式游戏化是本 skill 点名的反面教材，先补整体图景，否则撤掉积分。
- **一次性任务**——没有重复就没有收集的意义。
- **把"停不下来"用在有害行为上**——不给缓解间隙的强粘性设计用于消费/赌博类场景即成瘾设计；本书善意前提（促成长）必须成立。

### 作者在书中警告的失败模式

- 没有整体就发空缺任务——用户"找不到 9 该放进去的空缺"，任务成了噪音（c30 的关键前提）。
- 每天重复却感觉不到任何效果——必然厌倦；重复需要可填的东西维持（ce37）。
- 给了"问题已解决"的间隙——紧张释放，用户离开（c32 的反面）。

### 作者的盲点 / 时代局限

- 书中案例的收集对象都有内在价值（宝可梦、故事碎片）；现实中"为凑齐而凑齐"的空洞收集是当代游戏化的真实风险，空缺内容的价值设计要自行补足。
- 强粘性设计（无间隙）在注意力经济中易被滥用成时间黑洞——与 `stop-design-graceful-endings` 联合使用以守住边界。

### 容易混淆的邻近方法论

- 蔡格尼克效应（心理学）：同源机制；本书增量是"先整体后空缺"的前置条件律与"节奏=时间轴上的空缺"定义，把效应变成可排序的施工步骤。
- 目标梯度效应（越接近终点越努力）：互补不冲突；本 skill 管"空缺如何被识别"，目标梯度管"后程加速"，可在同一系统里分层使用。
