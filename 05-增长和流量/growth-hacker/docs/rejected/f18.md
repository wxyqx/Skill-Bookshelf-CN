# rejected: f18 诱饵效应选项设计

- **候选**: f18（framework-extractor）
- **挂在哪项**: V3（独特性检验）不通过；V1 勉强、V2 通过但不足以翻盘
- **原因**: 诱饵效应（Decoy Effect）源自丹·艾瑞里《怪诞行为学》的公共行为经济学概念（《经济学人》定价实验是艾瑞里的经典实验，非本书原创），抹掉作者名字任何聪明人都能说出"加一个负面选项改变评估框架"。按任务约定，公共概念本身不算独特。此外该手法属 dark pattern，与后记职业道德章节立场直接冲突（t10 术语条目自身亦注明"引用时应降权"），2015 年参数（迅雷"残忍地拒绝"按钮等）无判断逻辑残留价值。
- **降级去向**: 作为"行为操纵警示"素材并入 U08 ab-testing-protocol 的转化优化上下文与 U21 growth-ethics-redlines 的反面参照；术语 t10 随 glossary 素材池保留。
