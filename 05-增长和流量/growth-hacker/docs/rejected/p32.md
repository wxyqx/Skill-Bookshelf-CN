# rejected: p32 每月优化 10%，一年 3 倍

- **候选**: p32（principle-extractor）
- **挂在哪项**: V3（独特性检验）不通过
- **原因**: 复利式微改进是通用常识格言（复利叙事 ubiquitous），抹掉作者名字任何聪明人都能说出"每月进步 10% 一年就是 3 倍"；V1 亦弱——仅第 1 章特质描述一处，无独立第二语境的方法论展开。且与 p17"别陷入微优化陷阱，留力气给突破性变化"存在方向张力，两相对照后其独立价值更低——张力本身反而以 U08 的"微优化 vs 跃进"边界判断呈现更有用。
- **降级去向**: 作为"微优化 vs 跃进式提升"的对照素材并入 U08 ab-testing-protocol 的适用边界判断（何时值得测 0.x%，何时该换方向）。
