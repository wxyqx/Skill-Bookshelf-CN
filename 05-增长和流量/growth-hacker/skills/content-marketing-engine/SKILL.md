# 内容营销引擎（持续输出而非赌爆款）

## R — 原文 (Reading)

> "试图通过偶尔一两次'核爆炸'级的热门内容来换取长久关注是不现实的。你应当打造一台内容引擎，持续稳定地输出高质量内容。""内容营销的作用主要分为三方面：吸引流量、培养潜在用户、劝诱转化。"
>
> — 范冰，《增长黑客》第3章（内容营销：打造持续输出的传播引擎）

---

## I — 方法论骨架 (Interpretation)

内容营销不是"写几篇文章碰运气"，而是给产品装一台可持续运转的获客机器。骨架有四层：

1. **先定位作用，再定指标**。内容在漏斗里只干三件事：吸引流量（带链接的内容换回流）、培养潜在用户（用户平均要被"刷脸"约 7 次才会转化）、劝诱转化（内容直接引导注册或购买）。一篇内容可以兼有多重作用，但排产时必须知道这篇主要为什么服务，否则永远无法评估内容值不值。
2. **赌爆款是错误心智**。单篇"核爆炸"不可复制也不可预期；正确目标是建立选题、生产、分发、复盘的固定循环，让爆款成为引擎的副产品而非目标。
3. **持续输出的六要领**：明确目标受众；建立固定选题机制；标题做多版本 A/B（耸动但不标题党）；保证足够的信息量（长文比短讯更易被传播）；鼓励互动并把活跃读者晋级为传播者；选对发布渠道。
4. **文案有可复用结构**：概述→话题事件→核心特色→主要功能→团队访谈→未来计划→有奖活动→转化引导；配合"滑梯理论"——标题负责让读者读第一句，第一句负责让他读第二句，逐句钩住。

一句话：把内容当产品来做——有定位、有排产、有测试、有迭代，而不是当作文案灵感来碰。

## A1 — 书中的应用 (Past Application)

### 案例 1: 聚美优品的马甲软文（c08）
- **问题**: 聚美优品前身业务不见起色、天使投资见底，转做女性化妆品电商后没钱请达人、砸广告，急需低成本获得第一批信任与客流。
- **方法论的使用**: 创始人戴雨森在人人网注册女性马甲，伪装成有多年 BB 霜使用经验的美妆达人，写的不是广告而是目标受众真正想读的科普软文（对应"明确受众+劝诱转化"两要领）；同时自建简易摄影棚把每件化妆品实拍精修，配合口语化描述营造品质感，持续产出而非一锤子买卖。
- **结论**: 内容只要对准受众的真实关注点，就能同时完成引流与转化两重作用，不需要预算。
- **结果**: 该软文获得几十万次阅读，文末推广链接导流贡献几十万销售额，为团队赢得最早的生存现金流。

书中另以 KISSmetrics（内容贡献 82% 流量）、OkCupid 的 OkTrends 博客（新用户流量首要来源）、知乎（整理站内优质回答做持续输出）作为"引擎型"内容的跨域印证。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要为产品/公司从零搭建内容营销体系：公众号、博客、知乎号、视频号，问"该输出什么内容、多久发一篇"。
2. 内容做了几个月没效果，想诊断是选题、标题、篇幅还是渠道出了问题。
3. 老板/客户提出"做一篇 10 万+爆款"，团队需要判断该拒绝还是该换思路。
4. 内容人力有限，需要排产机制（选题库、发布节奏、复用结构）而不是靠灵感。

### 语言信号 (用户的话里出现这些就应激活)

- "内容营销怎么规划 / content marketing strategy / 选题怎么排"
- "想做公众号/博客/自媒体持续引流，写点什么好"
- "要不要追求爆款 / 10万+ / viral post"
- "内容没流量、没转化，哪里出了问题"

### 与相邻 skill 的区分

- 与 `do-things-that-dont-scale` 的区别：后者是冷启动期"没内容没人"时的人肉补课（马甲软文、上门拍照），是一次性补短板；本 skill 管的是补课之后/并行的**持续渠道体系**怎么搭、怎么排产。
- 与 `moment-marketing` 的区别：借势营销是追热点的一次性时机运营；本 skill 管日常选题与稳定输出，热点只能算选题库中的一类。
- 与 `seed-user-selection` 的区别：筛选种子用户管"让谁进来"（准入门槛）；本 skill 管"用什么内容把人持续吸引来"（渠道执行）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位内容的三作用主目标**
   - 与用户确认当前最缺的是流量、潜在用户培育还是转化，据此定每类内容的北极星指标（回流 UV / 订阅留存 / 注册与订单贡献）。
   - 完成标准: 产出一句"我们内容主要解决____，衡量指标是____"的声明，且三类作用至少明确当前主攻一类。

2. **搭选题与排产机制**
   - 从目标受众的高频问题、产品卖点、行业数据、站内素材（如知乎式整理优质回答）建立选题库；按团队产能定固定发布频率。
   - 完成标准: 有未来 4 周的选题排期表，且每个选题标注了它服务三作用中的哪一作用。
   - 判停条件: 若团队连一期双周产能都排不出来，先收缩到"单渠道+低频+可复用结构（八段式模板）"，而不是承诺日更。

3. **单篇执行六要领**
   - 每篇至少 2 个标题版本做 A/B；保证信息量；文末有互动钩子与带统计参数的转化链接；列出发送渠道清单。
   - 完成标准: 每篇发布前可通过"标题≥2版、唯一核心卖点、互动钩子、转化链接、渠道清单"五项检查。

4. **数据复盘迭代**
   - 按选题类别/标题风格/渠道三个维度回流对比，淘汰无效组合，放大有效组合。
   - 完成标准: 每月一次复盘，能回答"哪类选题、哪个标题、哪个渠道带来的回流/转化最高"。
   - 判停条件: 若连续 4–6 周所有内容对三类指标均无贡献，先停下排查受众与渠道错配（写给了不存在的读者），而非加大产量。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单次热点事件的借势传播**：那是时机运营问题，去用 `moment-marketing`；硬把热点塞进内容排产只会两头落空。
- **产品未达 PMF 就加大内容投入**：内容引擎会放大产品的问题，先把"产品值得被推荐吗"搞清楚（参考 `pmf-gate` 逻辑），否则是给漏水的桶灌水。
- **纯一次性宣发需求**（一篇新闻稿、一个活动公告）：直接写就行，不需要引擎。

### 作者在书中警告的失败模式

- 依赖"偶尔一两次核爆炸级内容"换长久关注——不可持续，爆款应是引擎的副产品。
- 无受众定位、无标题测试、无渠道匹配的内容生产，本质是自嗨。

### 作者的盲点 / 时代局限

- **幸存者偏差**：KISSmetrics、OkCupid OkTrends 都是赢家案例，同等投入下没做起来的内容博客从未被统计；内容成本（人力×时间）在书中被系统性低估。
- **2015 年快照时效警示**：书中"保证文章长度 2000 词以上""SEO 权重优化""电子书/代发媒介渠道"等参数层是 2015 年分发生态的产物（PR 值已成历史名词、搜索与社媒权重已大改）——**只保留"三作用定位+持续引擎+测试迭代"的判断逻辑层，篇幅、渠道、SEO/ASO 参数一律按当期分发平台规则重查**。

### 容易混淆的邻近方法论

- 冷启动"最笨的事情"（人工补课）、借势营销（热点时机）、病毒活动策划（体外循环，见 `external-viral-loop`）都与"写内容"沾边，但分别解决首批用户、时机、单次传播三个不同问题；本 skill 只解决"持续输出什么、怎么排产"。
