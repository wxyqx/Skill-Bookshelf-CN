# 体外病毒循环与病毒活动策划

## R — 原文 (Reading)

> "追TA通过构建产品本身之外的另一套易于推动的增长体系，来间接达到推广应用产品的目的。……这种在主推产品之外另辟蹊径的'曲线救国'方式，就是构建产品的体外病毒循环。"
>
> — 范冰，《增长黑客》第7章 7.4 构建产品体外的病毒循环

---

## I — 方法论骨架 (Interpretation)

当主产品本身缺乏传播性时，可以在产品之外另建一套"易于传播、先圈人再筛选"的增长体系——H5 小游戏、心理测试、价格漏洞话题——把"大海捞针"变成"瓮中捉鳖"。动手前先过三大考验：

1. **创意来源**：开发成本低意味着被山寨的成本也低，创意能否一句话转述、能否持续领先；
2. **生命周期**：这类活动天然只有三五天到两周的寿命，有没有"换皮续命"的二三次传播方案；
3. **产品契合度**：引来的人群与主产品是否同一群人——垂直产品借大众爆款导流，转化通常惨不忍睹。

执行层面有六要点：一句话创意、参与步骤足够简单、在用户的"成就时刻"怂恿分享、留下可吐槽的槽点、必要时故意放开漏洞制造二次传播、预备后续传播方案。另有一条反直觉原则：让用户略微付出一点代价（点一下才领、答完题才看结果），获得的东西反而更显价值、更被珍惜——比"直接白给"更高段。清醒账：活动参与量 ≠ 产品用户量，且体外循环寄生于平台生态，规则说变就变。

## A1 — 书中的应用 (Past Application)

### 案例 1: 追TA 的朋友圈整蛊 H5（c16）
- **问题**: 交友应用"追TA"名不见经传，投应用市场、换量、付费激励收效甚微，需要在红海中突围。
- **方法论的使用**: 借"围住神经猫"H5 热潮，在主产品之外做"哈佛心理系情感分析测验"整蛊游戏——被整蛊者答完敏感问题才发现被整，答案回传给整蛊者，激发"报仇"式转发；用广告条和公众号沉淀导流到 App。
- **结论**: 一个月 700 万人参与、公众号粉丝 65 万、零预算日增下载 2500-3000——圈人能力惊人；但广告条下载转化率仅 1%，且玩法惊动微信、遭平台干预。
- **结果**: 教科书级的量 + 教科书级的教训：参与量与转化落差巨大，渠道命脉握在平台手里。

### 案例 2: 云诺网盘"世界末日"点击领空间（c17）
- **问题**: 云诺（类 Dropbox）在巨头环伺下知名度低、零推广预算。
- **方法论的使用**: 借"2012 世界末日"节点策划"免费送无限空间"——用微调控件一下一下点击，点多少领多少；点击声引来同事围观形成线下传播；故意不设防作弊、放任"漏洞"在技术社区传播制造二次话题。
- **结论**: 付出感设计比"直接免费领的 Bug"更高段——付出辛劳让奖励更显珍贵。
- **结果**: 日新增用户平均 +400%，百度指数 +200%、官网流量 +460%，零预算达成数十万元营销预算的效果。

### 案例 3: 百度云 1/1000 价格 Bug 营销（c15）
- **问题**: 云存储大战中各家送空间已让用户麻木，亟需把"来了就走"的用户沉淀为登录账户。
- **方法论的使用**: 疑似精心策划的"价格漏洞"——原价数百元的年费套餐只付几毛钱；话题简明可转述（"百度网盘出 Bug 了"），几十小时不修复留足传播窗口，边际成本可控。
- **结果**: 全网狂欢抢购，数日后官宣用户破 7000 万、日增 20 万；一周后迅雷复制此打法。
- **警示**: 涉价格欺诈与消费者权益，引用须锚定道德红线（见 B 段与 growth-ethics-redlines）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 主产品没有传播性，想做个小活动引流，问"值不值得做、怎么评估"。
2. 要策划 H5 小游戏、测试类、抽奖类刷屏活动，问关键成功要素。
3. 看到别人搞 Bug 营销/价格漏洞引爆，想效仿或想评估这种打法的风险。
4. 活动数据出来了：参与量很大、转化很差，问哪里出了问题。
5. 担心活动会被平台（微信等）封杀，问体外循环的合规与退路。

### 语言信号 (用户的话里出现这些就应激活)

- "体外病毒循环 / external viral loop"
- "做个 H5 小游戏 / 测试类活动 / 刷屏 / 裂变活动引流"
- "Bug 营销 / 价格漏洞 / 故意留个漏洞"
- "活动怎么策划才有人转发 / 参与的人多但没转化"

### 与相邻 skill 的区分

- 与 `viral-k-factor` 的区别：那是产品**内建**的传播机制设计与 K 值度量；主产品外另建活动体系才是本 skill。
- 与 `moment-marketing` 的区别：借势是搭现成热点的顺风车；本 skill 是自己制造话题（两者可叠加：热点节点上发布体外活动，如云诺借"世界末日"）。
- 与 `subsidy-ladder` 的区别：红包补贴的关系链传播属于补贴形态设计；价格漏洞式话题营销属于本 skill。
- 与 `content-marketing-engine` 的区别：内容营销是持续输出的常设引擎；体外循环是三五天到两周寿命的爆发活动。

## E — 可执行步骤 (Execution)

1. **三大考验自检**
   - 创意能否一句话转述且不易被山寨？生命周期三五天到两周，有无换皮续命方案？引来人群与主产品是否契合（垂直产品借大众爆款基本失败）？
   - 完成标准：三问各有明确判断与依据。
   - 判停条件：产品契合度差（目标人群与活动人群错位）→ 建议放弃或改用其他获客渠道，不要硬做。

2. **按六要点设计活动**
   - 一句话创意 / 简单参与 / 成就时刻怂恿分享 / 留槽点 / 评估是否放开漏洞造二次传播 / 预备二三次传播方案。
   - 完成标准：六要点逐项落地，或写明该项不适用的理由。

3. **付出感设计**
   - 让用户略微付出代价（点多少领多少、答完才看结果），而不是直接白给。
   - 完成标准：活动机制中含付出环节，或说明为何该场景不需要。

4. **预设双口径度量与退出机制**
   - 参与量与产品转化分开统计；先评估当期平台政策（诱导分享封杀规则）与最坏退出方案。
   - 完成标准：有参与/转化两个口径的埋点方案 + 平台风险评估结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 期望活动直接带来大量高质量用户：追TA 700 万参与只换来约 1% 下载转化，垂直产品尤其如此。
- 把体外循环当作可持续增长引擎：它是有寿命的爆发手段，且寄生于平台生态。

### 作者在书中警告的失败模式

- x17（追TA）：200 万参与的"虚假繁荣"——下载转化率仅 1%；游戏因问题尖酸露骨被举报、遭微信干预，被迫换服务器 IP 才重新上线；此后微信加强对同类病毒小游戏的封杀。
- Bug 营销游走在价格欺诈与消费者权益的边缘，"法无禁止即可为"的空间是暂时的。

### 作者的盲点 / 时代局限

- 追TA、云诺是作者亲历项目，自证色彩浓；平台干预被轻描淡写为"第二版再战"，低估了渠道被封杀的常态性。
- **时效警示：2015 年快照。** 微信对诱导分享、H5 测试页、朋友圈小游戏的封杀此后持续加码，Bug 营销在今天还叠加消保法与广告法风险——活动玩法、平台政策、法律参数**全部按当期重查**；本 skill 只保留判断逻辑层（三大考验 + 六要点 + 付出感设计）。任何 Bug/漏洞玩法上线前必须先过 `growth-ethics-redlines` 三道闸。
- 与 `growth-ethics-redlines` 的关系：本 skill 的"故意放开漏洞"要点与其"契约精神"闸存在张力，冲突时红线优先。
