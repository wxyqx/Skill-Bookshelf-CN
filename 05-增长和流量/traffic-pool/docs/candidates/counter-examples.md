```yaml
id: x01
title: 百雀羚长图转化争议——刷屏不等于销量
type: counter-example
source_chapter: 第2章 品牌是最稳定的流量池（开篇）
source_quote: |
  文中讲到一个数据，说某企业花费180万元进行头部自媒体KOL（关键意见领袖）投放，
  销售转化不足8000元；而百雀羚这次的创意，指向的是淘宝旗舰店促销活动，加上其他
  各方面，总投放预算估计在300万元左右，然而淘宝店的总销售额不到80万元。
summary: |
  场景：2017年百雀羚《时间的敌人》一镜到底长图刷屏，微信总阅读量号称3000万，创意指向淘宝旗舰店促销。
  做法：创意精彩，但长图结尾缺少让用户立即点击购买的按钮，只提醒用户去打开淘宝领券，让用户跳出当前页面、多步操作。
  失败：被"公关界的007"曝光转化率不足0.00008，约300万预算换来不到80万元销售额，引发全行业对"刷屏=无效"的质疑。
  作者警告：用户被优质创意打动后的消费冲动只有几秒钟，"凡是让用户增加购买难度、跳出当前页面……都是令人可惜的浪费"；做品牌不承诺效果就是"耍流氓"。
  边界：此反例限制一切以阅读量、10万+、声量为唯一考核的内容营销做法。
tags: [marketing, content-marketing, conversion, brand]
```

```yaml
id: x02
title: 百雀羚落地页兑换流程繁琐——五六步操作耗尽冲动
type: counter-example
source_chapter: 第10章 百雀羚的刷屏案例如何做落地页转化
source_quote: |
  行动指示的最终目的是为了兑换优惠券，但是在兑换之前至少要有五六步的操作，
  一般消费者看到这里自然就放弃了。
summary: |
  场景：用户花3~5分钟看完百雀羚长图广告后的引导购买环节。
  做法：第一步让用户回到广告中找"百雀香粉"广告牌，第二步截图、打开天猫、搜索旗舰店、找客服、兑换优惠券。
  失败：用户看完已知情节再返回找提示信息"不太可能"，五六步操作让多数消费者直接放弃，转化在最后一米断裂。
  作者警告："不要让用户去思考，只要按照明确指示完成简单的操作"是营销团队的底线意识；给用户制造太多关卡绝对损失大部分流量。
  正确姿势（作者对照）：结尾直接附二维码长按识别跳京东，或领券页付定金锁购买，一次完成承接。
tags: [marketing, landing-page, conversion]
```

```yaml
title: 微信公众号刷量造假——5万+真实阅读只有300
type: counter-example
source_chapter: 第1章 问题三：流量陷阱
source_quote: |
  2016年9月，微信公众号刷量工具瘫痪事件，就将众多“微信大号”打回原形，真实阅读量

summary: |
  场景：微信生态中"僵尸粉"与刷出来的点击量是"最常见且心照不宣的作弊举动"。
  做法：公众号买粉、刷阅读量制造数据繁荣，广告主按虚假数据投放。
  失败：2016年9月刷量工具瘫痪，5万+稿件真实阅读仅300多个；百度报告显示其推广过滤的无效点击中49%~65%为机器作弊，5%为人工作弊。
  作者警告：世界广告主联合会预计流量欺诈十年内将成为仅次于毒品的犯罪市场；美国23%的视频广告有曝光水分，2016年广告主损失72亿美元。
  边界：任何按曝光/点击结算的投放都必须假设数据有水分，用成单层验证。
```

```yaml
id: x05
title: 采购流量红利速朽——获客成本三个月从30元涨到50元
type: counter-example
source_chapter: 第1章 问题二：流量贵
source_quote: |
  刚开始投放的广告效果很好，流量质量高，转化率也高，获客成本能控制在30元以内。
  三个月之后，投放广告的企业越来越多，用户也对各种广告产生免疫和厌烦情绪，导致
  流量质量明显下降，流量性价比远远不如投放之初，获客成本上升到50元左右
summary: |
  场景：神州专车早期与某新闻App合作投放，趁平台广告尚少抢红利。
  做法：低价买入新平台的优质流量，把增长押在外部采购上。
  失败：三个月内获客成本从30元升到50元，"已经和其他平台没有太大多区别"。
  作者警告："每一个优质的流量平台，都会在商业放量之后迅速变得平庸或成本高企"——这是全书立论的反面起点：只买不储的流量思维必然被成本上升吞噬。
  边界：一切"趁某平台还便宜赶紧投"的策略都只是短期窗口，须同步建自有流量池。
tags: [marketing, paid-traffic, strategy]
```

```yaml
title: App下载获客浪费——七成下载无留存
type: counter-example
source_chapter: 第1章 问题二：流量贵（第3章 分众广告延伸）
source_quote: |
  通常来说，一个App用户的下载成本在40元左右，但是现在很多用户初次下载使用后就不
  会再打开，而且有七成以上的用户下载App之后都没有留存消费。就是说一款App如果10个
  人下载，那么就有300元左右被浪费，这是一个恐怖的数字。
summary: |
  场景：App推广普遍以下载量为 KPI，广告素材引导用户当场下载。
  失败：七成以上用户下载后不再打开、无留存消费，10个下载约浪费300元。
  作者补充警告（第3章）：分众电梯里信号很差，"让用户去扫描一个几十兆的App，成功率很低"——强推下载等于把转化门槛抬到最高。
  正确姿势（作者对照）：二维码扫开 WAP 或关注微信/小程序并给奖励，先轻交互后重转化。
  边界：以"下载量"考核渠道效果的投放方案都要先过这一反例。
tags: [marketing, app-promotion, conversion]
```
