# 数字广告防作弊与渠道判断

## R — 原文 (Reading)

> "营销的精准化更多的仍然是广告商和媒体过度包装的概念，在我看来，更为准确的表述应该是'高相关性营销'。"
>
> — 杨飞，《流量池》第8章"数字广告（上）"

---

## I — 方法论骨架 (Interpretation)

1. 先做认知校准：无论经验定向还是大数据标签，数字广告都没有绝对精准；你买到的其实是"高相关性"，不是"精准"。预算审计要从这个假设出发——凡按曝光、点击结算的数据都应默认可能有水分。
2. 作弊有梯度：越靠近链路源头越容易造假（展现、点击、留资），越靠近成交越难造假（潜客、订单、成交）。因此 KPI 必须压到成单层——把考核定在展现量/点击量，等于制度性地逼投放团队和代理商造假；很多广告主被蒙蔽的根本原因是制定了不现实的 KPI。
3. 防作弊的根本手段是三端六环打通：三端=媒体数据、网站流量数据、订单数据；六环=展现、点击、留资、潜客、订单、成交。第三方监测只能看到单一终端的表面数据，三端数据分属媒体、市场、销售不同部门，打通只能靠自己。
4. 有了成单成本基准，用倒金字塔从最终成交反推各环节转化率：落在正常区间的环节才可信，突然过高的点击/留资环节就是作弊嫌疑，据此算出被浪费的比例。
5. 渠道风险排序：SEM、信息流相对放心；投放明细不可见、报告无法拉通核验的渠道（书中点名第三方 DSP 拿平台剩余垃圾流量）按黑洞处理，降权或剔除。
6. 总判断次序：先问"我能不能看见全链路"，再谈投放优化——看不见的钱，优化无从谈起。

## A1 — 书中的应用 (Past Application)

### 案例 1: 神州"神庙系统"三端六环监测
- **问题**: 媒体端、网站端、订单端数据分属三方，投放效果无法自证、作弊无从查起。
- **方法论的使用**: 自建数据管理平台"神庙系统"，覆盖神州买买车、租车、专车、车闪贷四大品牌，聚合第一方数据、实现漏斗级全程监控；以成单成本为基准做倒金字塔追溯。
- **结论**: 自建监测把数据掌控权拿回自己手里，是防作弊的唯一解。
- **结果**: 某业务成单成本连续 5 个月下降、成单量逐月上涨，划分出高效媒体/关键词/创意，排除 40% 的无效广告费；并支撑 SEM/SEO 分工重构。

### 案例 2: luckin 朋友圈 LBS 定投
- **问题**: 新店开业引流的渠道选型与效果验证。
- **方法论的使用**: 按"排期广告七分品牌三分效果、LBS 定投三分品牌七分效果"的双模式逻辑选 LBS 竞价定投，定向门店周边 3-5 公里，用"新客户首杯免费"利益点做领券追踪，全程用领券-核销数据验证。
- **结论**: 效果型投放要选可追踪到转化动作的模式与素材。
- **结果**: 平均点击率 3.5%、领券率超 40%，同类广告中遥遥领先；经后续转化与 CRM 短信召回，一周后 CPS 降到比多数渠道更便宜、仅次于用户裂变。

### 案例 3: 某新闻 App 投放三个月衰减
- **问题**: 早期合作投放效果极好，获客成本控制在 30 元以内，看起来可以加大投入。
- **方法论的使用**: 按"每一个优质的流量平台都会在商业放量之后迅速变得平庸或成本高企"的判断，持续监测成本曲线而非迷信单期数据。
- **结论**: 低价红利是窗口不是常态，渠道价值必须动态复评。
- **结果**: 仅三个月后获客成本升至 50 元左右，与其他平台已无差别——为预算调配提供了依据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 续约审计："代理商上月报表点击率创新高，但订单没涨，续约还是换？"——需要成单层审计而非看报表。
2. KPI 制定："老板要求按曝光量和点击量考核投放团队"——需要判别源头 KPI 的作弊温床属性。
3. 数据存疑："点击很高但没转化/留资突然暴增，是不是有水分？"——需要倒金字塔追溯。
4. 渠道选型："有家第三方 DSP 报价便宜还说能精准定向，要不要投？"——需要渠道风险排序。
5. 浪费定量化："投放的钱到底浪费在哪、浪费了多少？"——需要三端打通后按环节归因。

### 与相邻 skill 的区分

- 与 `feed-native-creative` 的区别: CL17 管信息流素材与文案怎么写；本 skill 管钱、KPI 与渠道审计。素材效果差归 CL17/CL08，数据真假归本 skill。
- 与 `landing-page-conversion` 的区别: CL16 管点击进来后页面怎么承接转化；本 skill 管点击之前与之后的数据链路可信度。
- 与 `ad-creative-iteration` 的区别: CL08 管两版素材哪个好怎么用实验裁决；本 skill 管数据本身可不可信、渠道可不可投。
- 与 `traffic-pool-diagnosis` 的区别: CL01 管企业级"该不该买量、要不要建池"战略；本 skill 是投放执行层的钱怎么管。

## E — 可执行步骤 (Execution)

1. **校准认知与盘点 KPI**
   - 完成标准: 把"精准营销"改读为"高相关性营销"；列出当前所有渠道的 KPI 定义，并标注每一项处于六环（展现/点击/留资/潜客/订单/成交）的哪一环。

2. **KPI 下沉**
   - 完成标准: 把考核指标从展现/点击/留资层改压到潜客/订单/成单层，输出新 KPI 文档并各方签认。
   - 判停条件: 纯品牌曝光类战役确实无法压到成单层——单列该预算、降低其权重并改用中间口径（搜索指数增量、留资线索）考核，不强行套用本程序。

3. **建全链路监测**
   - 完成标准: 盘点三端数据归属（媒体/网站/订单），确定打通方案——自建平台或最小可行版（订单回传+链接层追踪+UTM 规范）；验收标准是能对任意一笔投放回答"它带来多少成单"。
   - 时效提醒: 跨屏追踪与设备 ID 体系已受隐私监管约束（苹果 ATT、《个人信息保护法》），打通方案须先过当期合规评估。

4. **审计与渠道排序**
   - 完成标准: 用成单成本做倒金字塔追溯，产出各环节转化率与"正常区间"判断；突然过高的环节标记作弊嫌疑；渠道按可见性排序，投放明细不可核验者降权或列入黑名单；输出浪费比例估计与渠道黑白名单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯品牌曝光战役且无成单诉求——成单层 KPI 不适用，见步骤 2 判停。
- 问题出在素材吸引力或页面承接（点击低/留资低但数据可信）——分别归 `feed-native-creative`/`ad-creative-iteration` 与 `landing-page-conversion`。
- 企业战略层"要不要自建 DMP/要不要建自有流量池"——前者时效衰减严重只作参考素材，后者归 `traffic-pool-diagnosis`。

### 作者在书中警告的失败模式

- 源头 KPI 即作弊温床（反例 x25）: 把投放部门 KPI 定在展现量、点击量、留资量——恰是作弊最容易的三个环节，等于逼代理商造假；"很多广告主被流量作弊行为蒙蔽的根本原因是只追求效果，制定了不现实的 KPI"。
- DSP 垃圾流量黑洞（反例 x26）: 第三方 DSP 拿到的多是各大平台的剩余垃圾流量，转化差、品牌环境恶劣，投放不可见即黑洞；"精准"是媒体过度包装的概念。
- 三端数据孤岛（反例 x27）: 没有任何第三方监测机构能承诺监测三端所有数据——媒体不够开放、代理商注水、广告主不肯给销量数据时，作弊就有空间；防作弊没有外包解，必须自建打通。
- 流量红利速朽（反例 x05/c41）: 优质流量平台放量后迅速平庸涨价，渠道价值须动态复评，不能吃老数据。

### 作者的盲点 / 时代局限

- 对 DSP 一刀切否定被部分证伪: 后来 PDB、品牌安全等程序化玩法成熟，渠道格局已重洗（字节系崛起），渠道风险排序需按当期生态重建，不可照搬 2018 年名单。
- 隐私合规零讨论: 跨屏追踪、Look-alike、设备 ID 体系已被苹果 ATT 与《个人信息保护法》重创，书中完全没有合规维度；当期重建监测必须先过合规。
- 数据单方口径: "排除 40% 无效广告费"等效果数字全部为甲方自报、无第三方审计，宜作参考基准而非绝对值。
- **时效警示（内嵌）**: 本书为 2018 年快照——朋友圈竞价门槛与价格机制、DSP 格局、跨屏追踪与 ID 体系均已随隐私监管与平台生态重写；三端六环、成单层 KPI、倒金字塔追溯与"可见性排序"的判断逻辑层保留，具体追踪参数、工具与渠道名单须按当期规则重查。

### 容易混淆的邻近方法论

- 第三方监测报告: 行业常识是"相信秒针/AdMaster 报告"，本方法论立场相反——第三方只能测单端表面数据，报告可作参考不作结论。
- 增长分析漏斗指标: 相邻，但本书强调数据主权（自建打通）与 KPI 源头设计（指标本身就是作弊温床），不止是看漏斗。
- DMP 自建决策: 书中有专节（费用/人才/耐心三前提、三大用途），但参数层时效衰减严重，在本 skill 中只作素材层参考。
