# 信息流素材与用户视角文案（Feed Native Creative）

## R — 原文 (Reading)

> "在用户视角的指导下，文案并不是直接给出产品卖点，而是要在梳理出产品卖点之后再进行用户需求分析，最终完成匹配卖点和用户需求的文案。"
> "很多人在准备文案素材的时候特别喜欢罗列卖点，觉得好不容易投一次广告，不多准备点内容不够实在。但这种做法是十分错误的，会给用户带去极大的信息干扰。"
>
> — 杨飞，《流量池》第10章 数字广告（下）

---

## I — 方法论骨架 (Interpretation)

信息流的机制是"信息找人"：广告插在新闻和社交动态之间，用户处在刷内容的状态，没有购买意图。这决定了素材不能从"客户视角"（我把卖点说全）出发，而要从"用户视角"出发：先梳理产品卖点，再分析目标用户的需求与场景，最后把两者匹配成一条看起来不像广告的内容。

七条生产细则：一条文案只打一个卖点（罗列三个等于零个）；说大白话，不用专业术语；善用地域、年龄、日期等与用户相关的信息；激发主观动机而非讲道理；平等交流，不端品牌腔；用兴趣点提升专注感；最反直觉的一条——先给一个吸引人的事实、不讲原因，把答案留在点击之后。

配图按三式选型：场景式（原生感强、感性诉求）、福利式（折扣红包、冲动刺激）、告知式（LOGO+好评销量截图、理性助攻），目标是"不像广告的广告"，让用户以为是新闻或朋友分享。

最后用两版实测定稿——客户视角与用户视角文案的点击率差距可达 273.98%，数据说了算。

## A1 — 书中的应用 (Past Application)

### 案例 1: 客户视角 vs 用户视角信息流实测（第10章家装案例）
- **问题**: 信息流广告点击率低，投放团队按"客户视角"把产品卖点写全写美。
- **方法论的使用**: 把同一产品的文案改成用户视角——从用户使用场景的痛点事实切入，留悬念不讲原因，一条只打一个卖点，不同人群推不同卖点。
- **结论**: 用户阅读状态是"信息找人"，自我陶醉的完美文案反而无人点击；用户视角是可实测出的巨大杠杆。
- **结果**: 用户视角文案点击率比客户视角高出 273.98%。

### 案例 2: luckin coffee 朋友圈 LBS 定投素材
- **问题**: 新店开业要在门店周边 3~5 公里引爆客流。
- **方法论的使用**: 素材简单美观、原生感强，不堆卖点；配"新客户首杯免费"的福利式利益点作为唯一钩子。
- **结论**: 原生感+单一福利钩子优于信息堆砌。
- **结果**: 平均点击率 3.5%、领券率超 40%，在同类广告中遥遥领先；一周后 CPS 降到仅次于用户裂变的水平。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要在抖音/今日头条/朋友圈等平台投信息流或原生广告，需要写标题与文案。
2. 信息流点击率低、素材被划走，怀疑"文案像广告"或"卖点没写够"。
3. 一条素材里塞了多个卖点，纠结该主推哪一个。
4. 配图选产品白底图还是生活场景图，怎么让广告"隐身"在信息流里。

### 语言信号 (用户的话里出现这些就应激活)

- "信息流/原生广告/朋友圈广告的文案怎么写""点击率低""标题怎么起""怎么让广告不像广告"
- "要不要多写几个卖点""素材广告腔太重"
- "feed ad / native ad / creative copy / CTR"

### 与相邻 skill 的区分

- 与 `traditional-ad-conversion` 的区别（互斥对）: CL07 管品牌向的电视/户外/分众等传统硬广的转化设计（用户"当时当刻不能行动"）；本 skill 只管**效果类付费信息流/原生广告**素材（用户正在刷信息流、可即时点击）。电梯海报怎么设计找 CL07，信息流文案找本 skill。
- 与 `landing-page-conversion` 的区别: CL16 管点击后的承接页；本 skill 管点击前的创意素材。
- 与 `ad-creative-iteration` 的区别: CL08 管两版素材怎么用单变量实验定胜负；本 skill 管素材本身怎么生产（视角、卖点数、配图三式）。
- 与 `social-content-light-fast` 的区别: CL13 是自有社媒账号的日常内容与借势；本 skill 是付费投放的素材。

## E — 可执行步骤 (Execution)

1. **卖点与人群匹配表（用户视角流程）**
   - 先列产品卖点清单，再对每个卖点问"哪类人群、在什么场景、有什么痛点需要它"，最后匹配成文。
   - 完成标准: 产出一张"卖点→人群→痛点场景"匹配表；禁止跳过匹配直接从卖点清单写文案。

2. **一条文案一个卖点**
   - 每条素材只保留一个卖点，不同人群推不同卖点；砍掉"小户型+定制家具+免费设计"式罗列。
   - 完成标准: 任意一条素材能指出唯一卖点与目标人群。
   - 判停条件: 若文案已把答案讲清（原因、结果全给出），点击动机归零——打回按"事实吸引、不讲原因"重写。

3. **七法则自检**
   - 大白话、地域/年龄/日期等用户相关信息、激发主观动机、平等交流、兴趣专注、事实吸引不讲原因——逐条核对并写明取舍理由。
   - 完成标准: 七条有逐项结论，不允许"都符合"式略过。

4. **配图三式选型与原生感处理**
   - 按本轮诉求选场景式/福利式/告知式之一，风格向所在信息流的内容看齐（"不像广告的广告"）。
   - 完成标准: 图片有明确三式归属，且对"与投放位上下文风格是否一致"有一句明确判断。

5. **两版实测定稿**
   - 客户视角版 vs 用户视角版同预算小规模投放，用点击率数据定稿，再交 ad-creative-iteration 做持续单变量迭代。
   - 完成标准: 有两版同口径点击率对比记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 品牌向电视/户外/分众硬广——那是 traditional-ad-conversion 的地盘，两边用户状态（可即时行动/当时不能行动）完全不同，写法互斥。
- 搜索关键词广告（SEM/电商标题）——那是"人找信息"，用户带着明确需求主动搜，写法逻辑相反。
- 自有公众号/官微的日常内容与借势海报——归 social-content-light-fast。
- 落地页本身的承接与转化问题——归 landing-page-conversion。

### 作者在书中警告的失败模式

- 客户视角与卖点罗列（反例 x33）: "好不容易投一次广告，不多准备点内容不够实在"的直觉是错的——罗列三个卖点等于零个卖点，给用户极大信息干扰。
- 直接给出答案（反例 x33）: "不穿便宜货，这里的大牌不贵"式文案把话说尽，点击欲归零——要"事实吸引，不讲原因"。
- 与阅读环境不搭（反例 x33）: 雅思广告插在 G20 新闻流里会被直接忽视——触达了也等于没触达；品牌腔开场（"高额度贷款，10分钟到账"）一眼即知是广告。

### 作者的盲点 / 时代局限（时效警示：2018 年快照）

- **本书为 2018 年快照，只保留判断逻辑层，参数层须按当期重查**: 图文信息流的"三式配图"在短视频算法分发时代已演化为竖屏视频素材，形态需重写；但用户视角、单一卖点、原生感、事实吸引不讲原因的判断逻辑跨平台跨形态有效，可迁移到视频脚本开头 3 秒。
- 作者"信息流欢迎标题党"的说法在当期广告审核与平台生态下不可照用——如今标题党会被平台限流与处罚，原生感必须在不违规的前提下实现。
- 273.98% 是单一品类（家装）前后对比，未控制其他变量，只作方向性证据。

### 容易混淆的邻近方法论

- 经典直复营销与 AIDA 文案法: 同样讲注意力与行动，本书增量是"信息找人 vs 人找信息"的机制区分与"原生感优先于精致感"的立场。
- 内容营销: 内容营销追求长期信任资产，信息流素材只为一次点击——两者的考核口径与写法不同，勿混用。
