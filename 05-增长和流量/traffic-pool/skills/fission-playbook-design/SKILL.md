# 裂变玩法谱系与三要素设计

## R — 原文 (Reading)

> "在裂变的营销逻辑中，有三个起始性关键因素需要重视：种子用户、裂变诱饵和分享趣味。掌握这三个因素，裂变效果才更有保证。"
>
> — 杨飞，《流量池》第5章"裂变的三个成功因素"

---

## I — 方法论骨架 (Interpretation)

1. 前提（由 `social-fission-principle` 的原理保证）: 已决定做裂变、奖励预算已有来源。本 skill 是选型与落地手册——把"做裂变"翻译成一个可上线的活动方案。
2. 玩法谱系: 13 种玩法按载体分三级——App 裂变六式（拉新奖励、裂变红包、IP 裂变、储值裂变、个体福利、团购）、微信裂变四式（分销、众筹、卡券、礼品卡）、线下裂变三法（包装裂变、O2O 红包/一物一码、产品社交化）。选型逻辑是"目标 × 载体 × 成本"三匹配，拉新奖励是见效最快的标配。
3. 上线前三要素检查: 种子用户（影响力高、活跃度高、调性吻合、质量绝对比数量重要、能反馈产品建议）→ 裂变诱饵（确定性排序: 福利补贴 > 创意内容 > 玩法，反对"创意万能"）→ 分享趣味（给用户"谈资"与"个人形象"两种社交心理，而不是利益砸脸）。
4. 系统等式: 流量裂变 = 平台 + 创意 + 福利 + 技术。技术（裂变系统: 前端创建、后台配置、福利核销、用户管理、数据管理、平台对接六大子系统）是社交流量体系里最重要的一部分——缺技术承接的裂变等于白刷屏。
5. 合规红线: 分销不超过二级（超了涉嫌传销）、页面不出现"分享有福利"字样（防被判诱导分享封号）、现金红包必须防刷。
6. **时效总闸**: 书内半数具体玩法在 2018 年后已被微信规则封杀或边缘化（砍价 H5、集卡、打卡返现、二级复利分销等）——本 skill 只保留选型逻辑与三要素，每个玩法上线前必须按当期平台规则重查生存性。

## A1 — 书中的应用 (Past Application)

### 案例 1: 好色派沙拉的种子用户运营
- **问题**: 主食沙拉客单百元、转化率行业均值仅 2%，获客成本高。
- **方法论的使用**: 种子用户不追量、追质——锁定"华南马甲线用户"（有减脂增肌诉求的健身人群），调性严密贴合产品；从亲朋好友"杀熟"内测起步，再办 15 人线下小型试吃会，单场收获 1×11 的传播效果，几场试吃会积累天使用户并组建社群持续运营。
- **结论**: 种子用户质量绝对比数量重要；调性吻合的种子自带可信分享。
- **结果**: 不到两年微信社交广告转化率从 2% 提升至 20%，均值百元的获客成本拉低 1/5。

### 案例 2: 神州专车影视 IP 裂变红包
- **问题**: 裂变红包已成 App 标配，同质化严重、用户分享意愿下滑。
- **方法论的使用**: 在谱系内做玩法升级——用 BD 换来的免费影视 IP 资源把红包分享页做成影视海报样式，降低"领补贴"的目的性。《寻龙诀》用舒淇形象做"摸金校尉送你专车券"；注册后用短信触发邀请提醒加速转化，即"技术+创意"的叠加。
- **结果**: 单次 IP 裂变收获近 40 万新增用户；《太阳的后裔》IP 裂变分享次数比日常高 40% 以上，高峰期每天超 7 万次分享、带来 2-3 万新增注册。

### 案例 3: 味全每日 C"拼字瓶"包装裂变
- **问题**: 快消产品在线上没有 App 也没有服务号运营基础，怎么加裂变属性。
- **方法论的使用**: 走线下三法中的包装裂变——7 种口味 × 6 款汉字共 42 款瓶身，用户把瓶子摆出句子、拍照上传社交媒体成为新时尚（同时满足谈资与个人形象的分享趣味）。
- **结论**: 没有线上载体时，产品包装本身就是免费裂变载体。
- **结果**: 2016 年每月销售额同比增长 40%，7-10 月保持国内纯果汁品类第一。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. "我们想做裂变活动，砍价、拼团还是分销海报？"——玩法选型。
2. 方案初稿已有，上线前要过一遍检查: 种子、诱饵、趣味、技术承接、合规。
3. 活动上线后没转起来，需要诊断缺了哪个要素。
4. 在微信生态做活动，担心被封号，要核对合规红线。
5. 线下产品（饮料/包装/门店）想加裂变属性，问线下裂变有哪几种做法。

### 语言信号 (用户的话里出现这些就应激活)

- "砍价/拼团/分销海报/裂变红包/储值/礼包卡，选哪个"
- "种子用户怎么选""诱饵给什么""分享机制怎么设计"
- "诱导分享""被封号""微信规则""分销层级"
- "裂变方案帮我过一遍""活动上线检查""fission mechanics""which mechanic""compliance"

### 与相邻 skill 的区分

- 与 `social-fission-principle` 的区别: CL09 回答"该不该做裂变、奖励成本结构怎么定"（原理/预算层）；本 skill 回答"选哪种玩法、三要素齐不齐、合规过不过"（方案/执行层）。用户问"为什么/要不要/给多少"→ CL09；问"怎么做/选哪种/怎么不违规"→ 本 skill。
- 与 `fission-cold-start-lowfreq` 的区别: "我们低频产品做不了裂变吧""第一批用户从哪来"归 CL11；本 skill 假设存量与可行性已确认。
- 与 `wechat-service-superapp` 的区别: 裂变要挂在微信上时，服务号/小程序载体本身怎么建、怎么运营归 CL12；本 skill 只管活动机制。
- 与 `social-content-light-fast` 的区别: 靠内容趣味自传播的 H5/一图流（无奖励机制）归 CL13；带奖励与关系链驱动的才是裂变。

## E — 可执行步骤 (Execution)

1. **定目标与盘点载体**
   - 完成标准: 写明本次裂变的单一主目标（拉新/促活/转化）与可用载体清单（App/服务号/社群/线下包装）；无任何载体时判停——先建载体（逻辑归 `wechat-service-superapp`），不要空转。

2. **谱系选型**
   - 完成标准: 从三级 13 式中选出 1-2 种候选，写明选择理由（目标匹配 + 载体匹配 + 成本匹配）；无创意资源时默认优先"拉新奖励"标配——书中明示见效最快的仍是它。
   - 判停条件: 若候选玩法在当期平台规则下已被限制或封杀（以最新平台规范为准重查，2018 年书中口径仅作历史参考），判停换玩法，不得带病上线。

3. **三要素检查**
   - 完成标准: 逐项回答——种子用户画像与规模（影响力/活跃度/调性，质量>数量）、诱饵及其确定性等级（福利 > 创意内容 > 玩法）、分享趣味的社交心理（谈资/个人形象）；任一项空白即返回修改方案，不进入上线流程。

4. **合规红线检查**
   - 完成标准: 输出合规清单——分销层级 ≤ 二级、页面话术无"分享有福利"类诱导表述、现金红包有防刷机制、储值类玩法评估预付资金风险；清单存档备查。

5. **技术承接与上线**
   - 完成标准: 裂变系统就绪（参与门槛低、分享路径短、奖励可核销、数据可追踪）；设定监测指标（分享率、单位新客成本）后上线，数据回流后按单变量实验持续调优（逻辑归 `ad-creative-iteration`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 还没想清楚"为什么做裂变、预算从哪来"——先走 `social-fission-principle` 的原理与成本公式。
- 需要冷启动第一批种子、或产品低频疑似做不了——归 `fission-cold-start-lowfreq`。
- 想做的是传播内容（H5 刷屏、一图流借势）而非带奖励机制的裂变——归 `social-content-light-fast` / `event-marketing-five-boosts`。

### 作者在书中警告的失败模式

- 分销违规封号（反例 x20）: 复利分销超二级被定性传销，腾讯封杀"小黑裙"；页面出现"分享有福利"描述即被判诱导分享；现金红包不做人控会被刷取。（对照正面操作: 神州 U+ 招募司机的裂变海报页面不体现福利描述、只在种子群传播。）
- 同质化审美疲劳（反例 x21）: 裂变红包成为标配后各家互相模仿、福利逐期缩水（团购券从几元降到几分），用户不愿分享、机制失灵——规则须按用户习惯与投入产出比持续升级；纯创意赌裂变不确定性大，福利才是确定性诱饵。

### 作者的盲点 / 时代局限

- 合规假设天真: "分销不超二级即安全"是 2018 年口径——此后微信规则持续收紧，砍价 H5、集卡、打卡返现相继被封；平台规则是移动靶，上线前必须按当期规范重查。
- 储值裂变的预付资金风险、补贴对社交信任的透支，书中均未展开；13 式全部配成功案例、无失败选型复盘，幸存者偏差明显。
- 玩法有效性高度依赖 2015-2017 微信生态红利窗口，跨生态（抖音/小红书/私域企微）不可直接平移。
- **时效警示**: 本书为 2018 年快照。13 式谱系只作"选型思维"保留——每一式的当下合规性、交互形态、资金监管要求，均须按当期平台与监管规则重查后才能进方案。

### 容易混淆的邻近方法论

- 社交裂变 vs 内容传播: 有奖励机制 + 关系链驱动的是裂变（考核新客成本）；靠内容趣味自传播的是社会化传播（考核播放/转发），归 CL13/CL14。
- 团购促销: 拼团裂变的本质是关系链拉新，不是降价促销；用户只想要促销机制时不在本 skill。
- 游戏化留存（PBL）: 点数/徽章/排行榜服务留存提频，不服务拉新，勿混入裂变方案。
