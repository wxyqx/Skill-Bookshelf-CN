# 落地页第一生产力（Landing Page Conversion）

## R — 原文 (Reading)

> "所以我经常说，落地页才是数字广告转化的第一生产力。"
> "神州车闪贷的落地页从开始投放到当前版本（见下页图），一共改动了8遍。第8遍时，用户进入这个页面后拨打电话咨询数量比第一版时增加了330%。"
>
> — 杨飞，《流量池》第10章 数字广告（下）

---

## I — 方法论骨架 (Interpretation)

数字广告展示免费、点击付费：用户每点进来一次都是真金白银买到的，如果承接页不能把点击变成留资或订单，这笔点击成本就是 100% 浪费。所以作者把落地页抬到"第一生产力"的位置——它不是创意物料，而是营销链路的终端；唯一考核标准是数据（真实留资量、成单量），审美评审让位于数据。

结构上有一张六要素清单：核心卖点与活动信息、品牌印象与产品口碑、消费者益处、权威认证与社会证言、用户留资组件、索取信息——最后一项只取手机号级别的最关键信息，因为索取越多，用户越怀疑企业的规范程度。

操作上只有一条铁律：不要让用户思考。页面所有组件要连成一条引导转化的线性路径，动作按钮占最大视觉位，步骤能砍则砍。让用户"看完长图再回广告里找广告牌、截图、开天猫、找客服"的五六个步骤，会把已被打动的消费冲动全部耗尽。

落地页还是迭代对象而非一次性交付：车闪贷改 8 遍、来电 +330%，说明每一版只验证一个假设、用数据定胜负。

## A1 — 书中的应用 (Past Application)

### 案例 1: 神州车闪贷落地页 8 轮迭代
- **问题**: 车闪贷投放有点击，但电话咨询量低，落地页不知道该怎么改。
- **方法论的使用**: 按六要素拆解重排页面——品牌展示区直接告知"有车就能贷"；"已成功帮助××人解决资金难题"的口碑线打消顾虑；跳动的 GIF"拨打咨询"按钮占据最重要视觉位置；"2小时/50万/0.49%"等核心卖点用扁平 ICON 放首屏；加上二次留资按钮与集团权威背书。每改一遍只验证一个改动，用数据裁决。
- **结论**: 落地页不是创意稿而是营销终端，组件的信息位与可见性比画面美感更决定转化。
- **结果**: 第 8 版的电话咨询量比第一版增加 330%。

### 案例 2: 大众进口蔚领旅行轿车落地页三版测试（作者转述的第三方案例）
- **问题**: 礼遇活动页转化率低，不知道改哪里。
- **方法论的使用**: 5 天投放测试三版优化页——优化一精简头图文案、去掉"专属礼遇"式空话并放大优惠高亮；优化二调整后不升反降；优化三把收集销售线索的"试驾"入口前置到导航位、文案精简、视觉扁平大留白突出车体。
- **结论**: 头图文案、导航优先级、文案量、留白这些"小细节"对转化率影响巨大；且改版可能降转化，所以必须版版同口径对比。
- **结果**: 优化一转化率 8.6%、优化三 13.5%（优化二 3.5% 反降被放弃），印证"数据是落地页唯一考核标准"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 投放点击率正常但留资/成单差，纠结"先加预算还是先改页"。
2. 要为一个投放活动从零搭承接页（H5/小程序/表单页），不知道放什么组件、表单收几个字段。
3. 评审代理公司或设计部交来的落地页稿，需要可判定的审查标准而非审美争论。
4. 复盘"有曝光有声量但没订单"的活动页（如刷屏长图结尾转化断裂）。

### 语言信号 (用户的话里出现这些就应激活)

- "落地页/承接页/活动页/表单怎么设计""留资率、转化率上不去""表单要填哪些信息"
- "landing page / conversion / form fields / drop-off"
- "先加预算还是先改页面""用户点进来就走了"

### 与相邻 skill 的区分

- 与 `feed-native-creative` 的区别: CL17 管用户点击**之前**看到的投放创意与文案（信息流原生素材）；本 skill 管用户点击**之后**落到的承接页设计与评审。素材点击率高但承接差，找本 skill。
- 与 `ad-creative-iteration` 的区别: CL08 是"怎么用单变量实验验证素材好坏"的通用迭代程序；本 skill 给出落地页的**具体设计规范**（六要素/留资极简/不让用户思考）。改版实验流程归 CL08，页面内容怎么摆归本 skill。
- 与 `traditional-ad-conversion` 的区别: CL07 处理电视/户外/分众等传统媒体上"当时当刻不能行动"的广告如何加互动组件；本 skill 处理本来就发生在线上的点击承接。
- 与 `pinxiao-heyi-marketing` 的区别: CL02 判断单笔营销预算的品效回报口径；本 skill 负责把"效"落到页面上。

## E — 可执行步骤 (Execution)

1. **定页面类型与唯一考核指标**
   - 先判断是点击型（按钮跳转电商/门店做流量分发）还是线索生成型（信息表收集用户资料），再写下本轮唯一成功指标（留资量、来电量或成单量）。
   - 完成标准: 一句话写清"这是____型页面，唯一考核指标是____"。

2. **跑六要素审查**
   - 按顺序核对：首屏是否三秒回答"我是谁、给什么价值、有何差异"→ 有无产品口碑与权威证言 → 消费者益处是否具体 → 留资组件是否醒目 → 索取的是否只是手机号级别的最关键信息。
   - 完成标准: 六要素逐项标注"有/无/弱"，弱项列出改造点。
   - 判停条件: 若用户从进入到完成转化的操作超过 2 步，或索取字段超出最关键信息——先砍步骤与字段，其余改造都排在其后。

3. **"不让用户思考"走查**
   - 模拟用户路径：每个组件的下一步动作是否唯一明确、动作按钮是否占最大视觉位、有无需要用户返回/截图/换 App 的断点。
   - 完成标准: 画出一条无分叉的线性转化路径，无"回广告找信息"式断点。

4. **数据验证与单变量迭代**
   - 每版只改一个假设，同一口径对比留资/成单；有效改动沉淀为模板，无效改动回滚（车闪贷 8 遍、蔚领三版的逻辑）。
   - 完成标准: 新版相对旧版在同一指标上有可引用的提升（或回滚）记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无投放承接诉求的纯品牌官网、企业形象站——它们的目标不是当下转化，硬套六要素会毁掉品牌叙事。
- 问题出在创意素材本身（点击率低、文案像广告）——那是 feed-native-creative 的事，改页面救不了没点进来的用户。
- 还没有任何点击与留资数据时就"凭感觉优化"——本 skill 的前提是效果可测。

### 作者在书中警告的失败模式

- 百雀羚式转化断裂（反例 x02）: 3000 万阅读的刷屏长图，结尾却让用户"回广告找广告牌→截图→开天猫→找客服→换券"，五六步操作耗尽几秒钟的消费冲动，约 300 万投放换不到 80 万销售额。
- 口腔医院式自嗨页（反例 x32）: 把落地页当官网首页——电话图标没有拨打触发、主视觉放企业内部新闻（对消费者是无效对话）、小屏上闪动骚扰浮窗；"1 元点击成本若不转化就是 100% 的支出"，"还不如做纯展示"。
- 索取越多信任越低: 信息索取越多，消费者对企业规范程度越怀疑——表单只留最关键字段。

### 作者的盲点 / 时代局限（时效警示：2018 年快照）

- **本书为 2018 年快照，只保留判断逻辑层，参数层须按当期重查**: 落地页形态已从 H5/WAP 扩展到小程序、App 内页、直播间与私域承接，六要素的载体形态需按当期生态重排；但"唯一考核标准是数据、不让用户思考、留资极简"的判断逻辑不变。
- "索取手机号"在《个人信息保护法》（2021）与各平台隐私规范语境下必须加明示授权与最小必要原则，书内无任何合规讨论。
- +330%、13.5% 等提升均为前后版本对比，未控制投放时段、人群、出价变量，归因是单一变量的简化；引用时视为方向性证据而非精确效应。
- "第一要义是尽可能收集有效用户信息"服务于后续运营，与当下隐私最小化趋势存在张力，须按当期合规折中。

### 容易混淆的邻近方法论

- CRO（转化率优化）/ UX 设计: 通用 A/B 测试与 UX 方法与本 skill 同构，本书增量是"营销终端而非创意稿"的定位与"六要素+留资极简"的中国投放语境清单。
- 增长黑客 AARRR 漏斗优化: 可组合使用，但本书强调先改承接再扩投放——点击已经付费，承接不住时加预算只是放大浪费。
