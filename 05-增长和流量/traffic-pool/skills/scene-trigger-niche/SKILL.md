# 场景扳机与利基场景切割

## R — 原文 (Reading)

> "我认为，场景营销就是让品牌这个玄而又玄的东西能够迅速接地气、带流量、出效果的关键。品牌如果是一把手枪，场景就是扣动品牌子弹的扳机。"
>
> — 杨飞，《流量池》第3章"场景：用品牌做流量的'扳机'"

---

## I — 方法论骨架 (Interpretation)

1. 定位回答"你是谁"，但定位本身不触发购买——用户只在具体的时间、地点、心情、状态里才掏钱。场景就是扣动品牌这颗子弹的扳机：在正确的地方说正确的话，转化才发生。
2. 场景不是拍脑袋挑的，优先从自有经营数据里挖"反常点"——某个时段、人群、路线的异常波动，往往是未被满足的真实需求浮出水面（神州从订单数据里看出晚 9-10 点女性加班用车的波动）。
3. 候选场景过四道过滤：中高频（值得反复投入）、刚需（不是伪需求）、契合品牌定位（场景体验要能为定位作证）、避开巨头主战场（不在对方火力最猛处硬拼）。
4. 补贴从"面"挪到"点"：定向人群、限定时段、限量限额、瞄准高客单场景，把补贴补在刀刃上，而不是跟着对手无差别撒钱。
5. 打法是"选窗口→集中兵力→打透 1-2 个利基场景建立根据地→借场景势能反攻主战场"。以弱胜强由此从口号变成一套可执行的窗口选择程序。

## A1 — 书中的应用 (Past Application)

### 案例 1: 神州专车"金色星期天"接送机总攻
- **问题**: 定位"安全"之后，滴滴、优步垄断早晚高峰主战场，正面补贴战打不起也打不赢。
- **方法论的使用**: 选"接送机"场景——中高频刚需、自带安全焦虑、竞品无暇顾及。两个月连打两轮：第一轮"金色星期天"连续 4 个周日 80 元以内免费接送机；第二轮新用户注册送 1000 元接送机券（20 张、限时限额），比无差别补贴更划算。
- **结论**: 补贴限定在单一高价值场景内，既是拉新也是品牌教育，单位成本低得多。
- **结果**: 首周订单 8 万、超 30 万用户体验；此后接送机日订单超 4 万、占专车接送服务 40% 以上，成为接送机第一品牌，半年获 1500 多万用户，站稳脚跟后反向杀入早晚高峰市场。

### 案例 2: "放心睡"第三高峰与孕妈专车
- **问题**: 晚 8-10 点本是专车低潮期，运力闲置；同时安全定位需要具体情境来教育。
- **方法论的使用**: 从订单数据挖出反常点——主打安全后有女性用户在此时段用车的波动。锁定高端女性白领，在高端写字楼电梯投"放心睡"广告（夜晚加班回家、在神州专车上安心打个盹），发放仅晚 9 点后可用的"加班限时券"；又从下车地点数据发现妇产医院占比不小，开发中国唯一孕妈专车叫车入口（司机照料、控速、音乐腰枕）。
- **结论**: 数据反常点是免费的需求情报；场景创新可以连产品一起改造，产品反过来为"安全"定位作证。
- **结果**: 晚 9-10 点形成早晚高峰之外的"第三高峰"；孕妈专车很快做到日均 5000 单以上，同时强化了品牌安全形象。

### 案例 3: "头等舱计划"高端会务场景
- **问题**: 高端商务与企业客户是优质订单来源，但竞品全部兵力压在 C 端主战场。
- **方法论的使用**: 以前期补贴做品牌教育，专攻高端会议指定用车这一利基窗口。
- **结果**: 一年拿下达沃斯、G20、乌镇互联网大会、"两会"等绝大部分高端会议指定用车，把"高端会议用车唯一可选专车"植入心智，成为优质订单来源并为竞品设立壁垒。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 弱势品牌/后发者面对巨头补贴大战，纠结"跟不跟、在哪打"。
2. 产品定位已定，但不知道从哪个具体消费情境切入获客（"我们该主打什么场景？"）。
3. 手里有订单/用户运营数据，想知道怎么用它找出新增长点。
4. 预算有限，要决定补贴撒向哪里（全场券还是定向限时券、补多少钱）。
5. 看着好几个场景都像机会，需要排序取舍、集中兵力。

### 语言信号 (用户的话里出现这些就应激活)

- "对手在补贴，我们跟不跟？""怎么跟巨头打？""打不过怎么办"
- "我们的产品适合什么场景？""切入点在哪？""从哪儿撕开市场？"
- "补贴预算不多，怎么花在刀刃上？""定向补贴怎么设计？"
- "以小博大""以弱胜强""错位竞争""niche""scene""battlefield"

### 与相邻 skill 的区分

- 与 `brand-positioning-trilogy` 的区别: 那里解决"定位说什么"（对立/USP/升维三选一）。本 skill 假设定位已定，解决"在哪里被触发、从哪个消费情境切入"。用户还在纠结定位路线时先走 CL04。
- 与 `brand-symbol-building` 的区别: CL05 管"怎么被记住"（符号、口号、视觉锤）；本 skill 管"什么时候被想起并下单"（场景扳机）。
- 与 `traditional-ad-conversion` 的区别: 本 skill 决定"打哪个场景、补贴投向哪"；CL07 决定"选中的场景在付费媒体上广告怎么设计才能带转化"（4件套、媒介判据）。
- 与 `pinxiao-heyi-marketing` 的区别: CL02 检验"单笔营销动作的品效回报"；本 skill 输出的是场景与补贴的具体投向决策。

## E — 可执行步骤 (Execution)

1. **挖数据反常点**
   - 完成标准: 从自有订单/用户数据中列出至少 3 个异常波动（时段、人群、地点、路线），每个附原始数据依据；没有自有数据时，改用用户访谈、竞品评论、客服工单定性收集候选场景并注明证据等级。

2. **场景四条件过滤**
   - 完成标准: 用"中高频、刚需、契合定位、避开巨头主战场"四条件给候选场景逐项打分，筛出 1-2 个总分最高且四项无一为零的场景；"契合定位"一票否决——场景体验无法为定位作证的直接淘汰。
   - 判停条件: 若没有任何场景同时满足四条件（尤其定位契合项），停止补贴设计，先回 `brand-positioning-trilogy` 重审定位或改产品，不要硬补贴。

3. **定向补贴设计**
   - 完成标准: 为入选场景写出补贴方案，四要素齐全——定向人群、限定时段、限量/限额、明确的客单价区间；并写明与"无差别全场券"的成本对比估算，确认补贴确实"补在刀刃上"。

4. **单场景打透，再复盘反攻**
   - 完成标准: 集中资源只打入选场景，设定一个场景内可测指标（场景订单占比/复购率/场景词搜索量），达到阶段目标后复盘是否借场景势能反攻主战场；未达标先调补贴结构而非扩场景数量。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 品牌尚无清晰定位就直接挑场景打——场景必须为定位作证，否则补贴教育的是品类而不是你。
- 用户问的只是"投放广告怎么写、组件怎么摆"——那是媒介执行问题，归 `traditional-ad-conversion`。
- 资金雄厚、已是品类第一的玩家做全场大促——利基切割是弱者战术，强者正面战场打法本书不覆盖。
- 纯线上产品连使用情境（时间/地点/心情/状态）都无法具体化时生搬硬套——先回需求验证。

### 作者在书中警告的失败模式

- 神州"拒绝黑专车"教育型广告（反例 x13）: 只靠分众+地铁单向呼吁"注意打车安全"，投放后效果一般，用户觉得小题大做。场景沟通若不落在用户此刻的真实处境上，就是自弹自唱；广告若不配合事件/公关引爆，也难逃墙纸命运。

### 作者的盲点 / 时代局限

- 大预算甲方视角: 千元券、"免费接送机"底层是上市公司资本，"低成本"实为把补贴从面挪到点的资本密集打法。小团队应学结构（定向/限时/限量），金额须按自身现金流重算。
- 案例全部成功入选，无场景选择失败的复盘；"数据反常点"依赖已有的订单数据规模，冷启动企业没有这个前提。
- **时效警示**: 本书为 2018 年快照。书中场景挖掘基于网约车订单数据与电梯媒体，当期应结合小程序/私域/短视频平台后台数据重做反常点分析；分众投放价格、优惠券核销链路等参数层须按当期平台规则重查，本 skill 只保留判断逻辑层。

### 容易混淆的邻近方法论

- STP 市场细分: 细分是长期人群划分；本方法论是"窗口选择+补贴投向"程序，粒度细到"时间×地点×状态"的具体扳机。
- 特劳特定位理论: 定位是心智占领，场景扳机是触发机制，是先后两个环节而非同一件事。
- 增长黑客 A/B 实验: 场景选择先于素材实验——场景选错，跑再多素材实验也是零。
