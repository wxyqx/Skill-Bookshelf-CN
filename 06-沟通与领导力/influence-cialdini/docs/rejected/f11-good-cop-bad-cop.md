## 验证结果

### V1 — 跨域验证: ❌ 不通过

**问题**: 这个单元在书中至少 2 个独立的语境下有佐证吗？

**分析**: 好警察/坏警察策略仅在第五章中作为一个**综合案例**出现。它被用来展示多个原理（认知对比、互惠、喜好）如何在单一场景中叠加。全书没有第二个独立语境使用这个策略：

- 第二章（承诺和一致）：不涉及
- 第二章（互惠）：单独讨论互惠，不涉及好/坏警察组合
- 第四章（社会认同）：不涉及
- 第六章（权威）：讨论权威服从，但不涉及好/坏警察组合
- 第七章（短缺）：不涉及

**结论**: 这是一个出色的**多原理综合案例**，但不是一个在多个独立语境中反复出现的稳定方法论。它更适合作为 commitment-consistency 或 liking skill 中的 A1（Past Application）素材，而非独立 skill。

### V2 — 预测力测试: ✅ 通过（但无独立价值）

**novel_question**: "谈判中对方派两人，一个强硬一个温和，我该如何应对？"

**derived_answer**: 可以分析这是好警察/坏警察策略——温和方因对比显得通情达理（contrast），温和方的善意制造互惠负债感（reciprocity），对温和方产生好感（liking）。防御：识别组合策略，不单独评估"温和方"的善意。

**问题**: 这个预测力完全依赖于 contrast-principle、reciprocity-defense、liking 三个独立 skill 的组合。一旦这三个 skill 存在，好警察/坏警察策略的解释力就被完全覆盖了。

### V3 — 独特性检验: ✅ 通过

"好警察/坏警察"作为特定术语确实有辨识度，且其多原理叠加的机制分析有价值。
