# 公司全景诊断七问（用年报数据做全局体检）

## R — 原文 (Reading)

> "现在，街头小贩与在公司工作的大多数人的差别就凸显出来了。看看你能不能为你的公司回答以下一些问题。我们将给出两家公司——福特汽车（该公司负责销售汽车和货车的子公司）以及捷威计算机公司的答案。"
>
> — 查兰，第3章（L6544）

> "如果你能为贵公司回答这些问题，就说明你正在使用商业的通用语言，正在得到有关你所在公司整体经营的全景图，正如一个店主所具有的那种思维。获得这种语言和全景图并不需要很多数字——只需要销售收入、利润率、总存货、资产量和现金量。"
>
> — 查兰，第3章（L6608）

> "概述公司的各个基本方面，不要让职务等级或者“竖井”（职能部门）影响你对公司业务核心内容的理解。然后，后退一步，从全局的角度观察公司的业务。"
>
> — 查兰，第9章（L7205）

## I — 方法论骨架 (Interpretation)

这是一个把"看懂公司"变成可操作清单的体检工具。它的信念是：全景图不需要很多数字、不需要高精确度——只需要五个数据（销售收入、利润率、总存货、资产量、现金量），全部可从年报中提取。

七个问题依次是：
1. **去年的销售收入是多少？**
2. **增长是上升、下降还是停滞？前景如何？**
3. **利润率是多少？在上升、下降还是持平？**
4. **与竞争对手相比如何？与其他行业的公司相比呢？**
5. **存货周转率与资产周转率是多少？**
6. **资产收益率是多少？**（已知道利润率和周转率就可用 R=M×V 计算）
7. **现金净流入是增长还是下降？为什么？**（这一问必须回答"为什么"，方向比数字重要）
外加**市场份额**：在竞争中扩大还是萎缩。

使用纪律：
- **不求精确**——目标是形成"店主式的全景图"和追问方向，再决定深挖哪一项。
- **防竖井**——不要让职务等级或职能部门视角切割对业务核心的理解；拿着这张图去和周围同事、管理层求证，看自己的评价是否和从高层听到的一样。
- **数据可得即用**——年报、IR 部门、公司网站；私营/初创公司改用可得替代指标并声明局限。
- **输出追问方向**——七问的终点不是一张表，而是 3~5 个"该向谁问什么"的具体问题。

## A1 — 书中的应用 (Past Application)

### 案例 1：福特 vs 捷威——两张"健康表"的对照诊断
- **问题**：如何用公开数据快速判断两家完全不同的公司的经营性质？
- **方法论的使用**：用七问逐项抓数据——福特汽车 1999 年销售收入 1370 亿美元（较 1998 年增长 15%，1998 年较 1997 年下跌 3%）、税后利润率 4.2%、资产周转率 1.3，由 R=M×V 得资产收益率约 5.5%；捷威销售收入 86 亿美元（1998~1999 年上升 15.7%）、税后利润率 4.9%、周转率远高于福特，资产收益率约 61.7%；再看市场份额与现金净流入。
- **结论**：同一张表看出两家公司的经营性质完全不同（福特低周转重资产、捷威高周转），因此应对重点也不同——福特需要提高生产率与顾客满意，捷威可以扩份额。
- **结果**：演示获得全景图"并不需要很多数字……并不需要非常高的精确度"即可形成判断与行动方向（第3章，L6544–L6608，案例 b3-c20）。

### 案例 2：EDS 迪克·布朗的六天诊断
- **问题**：临危受命接手年收入约 170 亿美元、遍布 46 个国家、12.5 万员工的 EDS，信息繁杂、时间紧迫。
- **方法论的使用**：上任前研读董事会提供的大批材料（现在与过去的财务报表、竞争对手数据、市场分析、预测、盈亏合同），到任后走访所有主管；六天内用六要素理顺形势——现金状况良好，问题在收入与利润增长（公司年增速 9%~10%，低于行业 15%）、资产收益率持续下降、股价与 P-E 疲弱。
- **结论**：诊断指向症结——20% 销售人员未开新业务、资源投向大而未必有收益的项目、重复冗余资源；随后形成四项优先事项并配套沟通机制。
- **结果**：到 1999 年年底实际削减 10 亿美元成本，简化运作、更以客户为本，公司日益壮大（第8章，L7120–L7156，案例 b3-c36→并入 b1-c04）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 第一次接触一家公司或一个事业部（入职、空降、尽调、投后管理），要在几天内上手看清全局。
2. 非财务背景的管理者想补商业常识，需要一张能反复使用的体检表。
3. 跨职能会议上各说各话（销售说增长、财务说没钱、运营说周转慢），需要一套共同数字对齐。
4. 要向老板/董事会提问，但不知道"该问哪些问题"才算问到点上。
5. 接到一家陌生公司（客户、供应商、竞争对手、收购对象）的资料，要快速形成判断并指出下一步深挖方向。

### 语言信号 (用户的话里出现这些就应激活)

- "快速了解这家公司" "第一次做尽调" "想快速上手"
- "财报看不懂" "各说各话没有共同语言"
- "该问老板什么问题" "这家公司经营得怎么样"
- 英文：due diligence / get up to speed / financial statements / where do I start / how healthy is this business / common language

### 与相邻 skill 的区分

- 与 `b3-f01` business-acumen-six-elements 的区别：六要素是概念框架（通用语言本身：现金、利润、周转、ROA、增长、顾客）；本 skill 把六要素落成七个可回答的问题与数据来源。先掌握六要素，再用七问体检。
- 与 `b3-f03` r-m-v-return-decomposition 的区别：`R=M×V` 是七问中第 5–6 问的计算工具；本 skill 是完整清单。需要拆解某个收益率数字用 f03，需要全局体检用本 skill。
- 与 `b3-f04` cash-net-inflow-everyones-business 的区别：现金净流入是第 7 问；`b3-f04` 把现金责任展开到岗位与流程层面。七问发现"现金有问题"后再转 f04 深化。
- 与 `b3-f06` complexity-to-priorities 的区别：七问是"当前全景"（静态体检）；`b3-f06` 是"面向变化推演"（动态决策路径）。体检完要定行动时转 f06/f07。
- 与 `b2-f03` performance-pipeline-interview-build 的区别：那是册2 的建队六步骤，定义各层级该交出的业绩（纵向业绩契约）；本 skill 是同一家公司的横向经营体检。对象不同：一个管人/goal 层级，一个管生意数字。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **取数：抓五个基本数字**
   - 完成标准：销售收入、利润率、总存货、资产量、现金量（及市场份额若有）齐备，且标注来源（年报/IR/网站）与年份；明确声明"不求精确"。

2. **逐问回答七个问题（第 7 问必须答"为什么"）**
   - 完成标准：七问每问有答案或"缺数据"标记；现金净流入一问必须写出变化原因；增长与利润率两问要写趋势方向（升/降/平）。
   - 判停条件：若关键数据完全不可得（私营、初创、内部资料缺失），改用可得替代指标（如现金流、应收账期、单位经济），并明确声明"这是替代视图"，不得假装完成体检。

3. **识别经营性质：低利润高周转型还是高利润低周转型**
   - 完成标准：用 R=M×V 算出资产收益率；能用一句话描述公司的生意性质与最弱环节（如"福特：周转太低"）。

4. **产出追问方向**
   - 完成标准：列出 3~5 个要向管理层、同事或资料求证的具体问题，每个问题指向确定的要素与数据点（如"过去三年周转率下滑，是存货积压还是产能扩张？"）。

5. **接入下一步动作**
   - 完成标准：写明"下一个动作"——定优先事项转 `b3-f07`、推演趋势转 `b3-f06`、解释估值转 `b3-f08`、深化现金转 `b3-f04`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要精确的财务结论（审计、税务、报表合并、估值建模）：七问是粗算体检，不能替代专业财务工作。
- 上市公司投资决策：不能替代完整尽调与估值流程；本 skill 只是快速形成问题清单。
- 组织内部问题（士气、协同、执行力）：七问覆盖不了，转 `b1-f04`/`b2-f11` 等。
- 用户要的是"预测未来"：七问只看现状与历史趋势，不承诺预测。

### 作者在书中警告的失败模式

- **b3-ce01 职能竖井思维（屁股决定脑袋）**："在现实中，各级经理人员往往是“竖井思维”，“屁股决定脑袋”，各自为政，难以产生有效的协同，创造最大的绩效。……一个对本部门最好的方案，未必对公司整体最有利"（L5944、L6174）。机制：多数人从职能部门起步并在本职能内晋升，缺乏对整体业务的认知框架（共同的商业语言），于是用本部门指标替代公司目标。预警信号：会议官僚化、只谈部门利益；不理解公司现金/利润率/周转率与自身工作的关系；跨部门协作靠会议堆叠而非共同语言。本 skill 正是对治工具——用同一套数字让各部门看到同一家公司。

### 作者的盲点 / 时代局限

- **财务化还原论**：七个比率跳过战略、技术、组织政治与创新；"好公司"有被简化为"账面指标好的公司"的风险（BOOK_OVERVIEW 最强反对意见 1）。
- **六要素的非普适性**：对平台型、软件型、研发驱动型业务（边际成本近零、网络效应、烧钱换市场）并不直接适用；未讨论非营利与公共部门（册3 批判节未证假设）。
- **数据环境过时**：书中说财务数据"从年报/网站上就能获得"、分析师给出 P-E 判断——对今天的非上市公司、初创企业与平台公司讨论不足（册3 批判节时代局限）。
- **样本与类比**：案例为福特/捷威/EDS 等美国大公司；"街头小贩类比"在教学中有效，在诊断中会误导（规模跃迁后因果结构不可观测）。

### 容易混淆的邻近方法论

- 财务报表分析（会计技术）：那是对报表本身的专业解读；本 skill 是给非财务人的经营体检，只取五个数。
- 平衡计分卡/杜邦分析：杜邦分析同用 R=M×V 思路但展开到更细科目；本 skill 刻意保持"店主式"的粗粒度。
- 尽职调查清单（法律/财务/商业全套）：本 skill 是商业侧的快速热身，不覆盖合规与法律尽调。
