# MEALER 六阶段过渡模型

## R — 原文 (Reading)

> "1.工作意义（meaning）。通过对新角色和新身份的绝对明晰，个人能够找到对企业和个人的意义。……新领导首先要有归属感，这是最基础的需求……如果这一点做得不好，个人会觉得自己是很独特和'很特别'（'我和他们是不一样的'）。"
>
> — 斯蒂芬·德罗特，第10章（fulltext L5474）

> "每一个步骤都围绕着前一个步骤，建立在前一个步骤之上，并且超越前一个步骤。……在所有的六个步骤中，工作意义这一步骤是最为关键的，但悲哀的是，这又是最容易出错的一个步骤。"
>
> — 斯蒂芬·德罗特，第10章（fulltext L5488）

> "常见的一个错误是只注重行动和学习两个步骤，而没有将工作意义和工作动力这两个步骤做好。这种实现层级过渡的活动是有缺陷的，会造成短期成功的假象，过渡过程很快就会无法继续进行——没有实现过渡的目标。"
>
> — 斯蒂芬·德罗特，第10章（fulltext L5490）

## I — 方法论骨架 (Interpretation)

层级过渡不是发个任命、开个欢迎会就完成的事。几乎每一位新任领导都要经历一次身份的重新建立，而这件事有六个必须按序处理的阶段——MEALER：

1. **Meaning 意义**：先明确定义新角色与新身份（我从"团队一员"变成"团队的领导、而且是众多团队领导者之一"），从中获得归属感。意义没建立，人会以"我很特别、我和他们不一样"来代偿，反而不适合新层级。
2. **Engagement 动力**：用新职位的知识与权力去激发他人的动力，而不是自己冲在前面；克服自我陶醉（一切都得围绕我）与跟下属竞争的倾向。做不好，就开始与自己的团队竞争。
3. **Action 行动**：把战略或运营计划翻译成以业绩为导向的行动，并让人听懂用意。跳过前两步直接行动，往往霸道苛刻、让团队筋疲力尽、冒过高风险。
4. **Learning 学习**：依据反馈自省、思考、调整；战胜对失败的恐惧；知道驱动执行的是业务原则与角色要求，不是政治手腕。做不好会变得多疑、藏信息、靠政治与上级关系。
5. **Embedding 根植**：发现并复制真正管用的成功方法（业务上的、团队培养上的），使之成为惯例，生产率与能力才会真正提高。做不好就是复制错误的方法，或团队只是在迎合领导的自尊心。
6. **Reinvigoration 重新振作**：完成一项目标后要面对更难的目标，防止自满；否则成为"没有进步的占位者"，活在过去成功里。

顺序是刚性的：意义为动力奠基，动力决定行动与学习，最后到根植。实践含义：给新任者的过渡计划若塞满"行动清单＋培训"，几乎注定失败；老板与HR应按序补齐前两步，并把过渡当业务问题而非HR事务来投入。本书同时提醒：模型背后的神经科学解释（理性/感性双系统、六个功能网络）属于通俗包装，无实证引用，使用时只保留上述操作步骤并声明科学基础薄弱。

## A1 — 书中的应用 (Past Application)

### 案例 1: 只做行动与学习的过渡（作者诊断的典型失败轨迹）
- **问题**: 许多新任领导的过渡计划里充满"行动"：迅速上手做事、参加培训；短期看似成功，随后卡住、无法持续。
- **方法论的使用**: 用 MEALER 的顺序检查——他是否建立了新角色的意义与归属感？是否在激发他人动力（而非自己冲）？行动是否是业绩导向的？
- **结论**: 只做行动与学习两个步骤、跳过意义与动力，是有缺陷的过渡，"会造成短期成功的假象，过渡过程很快就会无法继续进行"；尤其要警惕"充满行动的过渡计划"。
- **结果**: 该诊断成为第10章的核心判据，并与"层级过渡十问题诊断清单"配对使用（十问题与六步一一对应）。

### 案例 2: 软件公司第四栏写下"不正确的表现"（把过渡边界显性化）
- **问题**: 快速成长但尚未建立管理文化的公司，经理们需要组织额外的指导，尤其是不清楚"什么表现说明自己还没过渡到新层级"。
- **方法论的使用**: 在业绩标准第四栏（通常放技能/知识/经验）改列"影响过渡到下一层级的不正确的表现"——如"所有的上班时间都待在办公室，闭门不出""自己亲自解决所有的业务难题"。
- **结论**: 过渡不能只告诉人"该做什么"，还要告诉组织"哪些表现说明他还在旧层级"；这种设计对初创、快速成长或改变管理方式的企业特别有用。
- **结果**: 该公司软件工程部据此提前于人力资源部的计划投入使用标准。

### 案例 3: 老板的八步做法（把 MEALER 用于新人过渡）
- **问题**: 老板招来需要过渡的新领导者，往往给一堆信息、偶尔看看进展，实际上没有履行帮助过渡的职责。
- **方法论的使用**: 作者给出"经证实有用的八个步骤"，其中与 MEALER 直接挂钩的做法包括：从新员工入职的第一分钟就参与；与新员工一起重温 MEALER，让他们知道必须先理解工作的意义、激发动力，然后再去创造业绩；把过渡当业务问题（像对待重要客户一样），排除不必要的工作、明确角色职责、处理反对者、控制信息倾泻的欲望。
- **结论**: 过渡失败主要是老板（与HR）的责任；把它当成重大企业问题解决，而不是只靠个人辅导。
- **结果**: 该方法被写入第10章"给老板的建议"，成为上司帮助新人过渡的操作清单。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 朋友/同事刚升任总监或总经理，干了三个月就想推翻前任战略、宣布大改革，用户想判断该不该劝、怎么劝。
2. 新任领导本人感觉"融不进去、下属不买账、自己被以前同事疏远"，来问怎么办。
3. 公司要为新晋升者设计上任90天/导师/HR辅导方案，避免"新官上任三把火"式失败。
4. 已经看到某人过渡不顺的迹象：总回旧岗位工作、亲自解决一切技术问题、藏信息、只做表面行动。
5. 组织完成了各级业绩标准，但没人知道新任领导"什么时候算完成过渡"。

### 语言信号 (用户的话里出现这些就应激活)

- "刚升职三个月就想大改，该劝吗？" / "newly promoted, wants to overhaul everything"
- "MEALER 六步/过渡阶段" / "MEALER model, transition stages"
- "新官上任三把火" / "big changes too early, premature big idea"
- "融不进新团队、觉得自己很特别" / "don't feel part of the team"
- "上任计划/ onboarding 怎么做才不失败？"

### 与相邻 skill 的区分

- 与 `first-manager-three-transitions`（b5-f04）及 `manager-transition-tactics-three-steps`（b5-f07）的区别: 那些是册5 对初任经理的三项转型与上司三步战术，对象偏一线；本 skill 是六步顺序机制，适用于任何层级过渡，且自带失败学与十问题诊断。
- 与 `three-dimension-transition`（b5-f02）的区别: 后者按技能/时间/理念三维度分析转型内容；本 skill 按心理与行动六阶段排顺序，两者可互补（三维度答"转什么"，MEALER 答"按什么顺序转"）。
- 与 `performance-dialogue-evidence`（b2-f22）的区别: 后者是稳态期月度业绩讨论；本 skill 专管上任初的过渡期。
- 与 `environment-three-variables`（b2-f19）的区别: 后者改"土地"（组织环境）；本 skill 处理个人层面的过渡过程。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确认过渡情境**
   - 明确：从哪个层级到哪个层级、上任多久、是内部晋升还是外部空降。
   - 完成标准: 一句话界定过渡类型与时间窗口。

2. **逐阶段核查（按 MEALER 顺序，不跳步）**
   - 意义：他是否能说清新角色与新身份（"我现在是团队的领导，而不是团队一员"）？是否有归属感，还是以"我很特别"自居？
   - 动力：他是在激发他人还是在跟团队竞争/自己冲？是否以自我为中心？
   - 行动：他的动作是否指向业绩（把战略转成业绩导向的行动），还是热闹的活动？
   - 学习：他是否依据反馈自省调整、敢承认不会、战胜了对失败的恐惧，还是开始靠政治与上级关系？
   - 根植：成功方法是否被识别并复制成惯例，还是在迎合领导喜好？
   - 重新振作：实现第一套目标后，是否已面对更有挑战的目标，还是停在过去成功里当"占位者"？
   - 完成标准: 六步逐一标注"已建立/半建立/缺失"，每项至少一条行为证据。
   - 判停条件: 若"意义"缺失，停止评估后续步骤，先处理身份与归属问题——它是最关键也最容易出错的一步。

3. **配对十问题排查**
   - 用"层级过渡十问题"（选错人、文化障碍、组织设计、老板考虑不周、坏消息淹没、被动晋升、不重视新工作、自我陶醉、过早实施大创意、与员工竞争等）对照被检查者的具体表现，定位根因在企业、老板还是本人。
   - 完成标准: 每个显现的问题都能追到十问题中的一条或多条。

4. **开出按序动作**
   - 意义：与上司共同明确新角色定义与预期贡献；找出归属锚点（与谁对齐、被谁接纳）。
   - 动力：把"我能做什么"改成"我如何让团队做成"；停止与下属竞争的具体行为（如不再抢着拍板/抢功）。
   - 行动：把大创意延后，先清除妨碍业绩的小障碍、处理既有问题；形成本层级的业绩导向行动清单。
   - 学习：建立反馈渠道（上司、同事、团队），主动收集"我哪里做得不对"。
   - 根植：识别已被验证的成功做法并固定为流程/惯例。
   - 重新振作：第一套目标达成后立刻设定更具挑战的目标。
   - 完成标准: 每个缺失阶段配一项动作、责任人（本人/老板/HR）、时间点。

5. **对接老板与HR（可选）**
   - 若用户是老板/HR：按八步做法介入——从入职第一分钟参与、共同重温 MEALER、处理反对者、控制信息倾泻、把过渡当业务问题排入日程。
   - 完成标准: 形成一页"过渡支持计划"；明确过渡结束的标志（实现第一套目标且正在实现更有挑战的目标）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **不可当科学模型讲授**：MEALER 的神经科学包装（理性/感性双系统、六个功能网络与六步一一对应）"无实证引用、不可证伪"（BOOK_OVERVIEW 批判节原话），任何使用必须声明只保留操作步骤、科学基础薄弱。
- 不做心理治疗：新任者的焦虑、抑郁、家庭问题应转介专业支持，本模型只处理角色过渡。
- 不用于绩效考核与奖惩决策：它是发展工具；把六步完成度当考核项会诱发表演式过渡。
- 组织尚未明确新岗位的角色与业绩标准：先有标准（业绩梯队/职责澄清），否则"意义"无从建立。
- 已经过渡完成、进入稳态期的人：回到月度业绩讨论（b2-f22），不要长期停留在"过渡"叙事里。

### 作者在书中警告的失败模式

- **只做行动与学习（b2-ce22）**：过渡计划充满行动与培训，跳过意义与动力，"会造成短期成功的假象，过渡过程很快就会无法继续进行"；提醒警惕"充满行动的过渡计划"。
- **过早实施重大创意（b2-ce13）**：新领导高调宣布新战略/新计划，引发恐惧、愤怒、狂热或不确定；直接下属未理解与接受前不会投入，小事情被忽略、业绩受损——"精力的投入方向错了，而不是用于清除各种业绩障碍或者解决问题"。
- **自我陶醉（b2-ce12）**：上任即叫停一切直到"弄清楚情况"、反复审查项目与旧观点，把所有工作都变成"关于他们自己"的工作；本人意识不到自己给他人造成的痛苦。
- **与员工竞争（b2-ce14）**：管理者用信息与资源优势"赢"下属——这是不合理的作弊游戏；本模型第2步正是针对这一失败设计。
- **知晓者文化中的过渡（b2-ce03）**：新管理者不敢承认不会、不敢求助，学习通道关闭，"过渡只能是一个比较缓慢的过程，而且发展的也不完整"。
- **老板考虑不周（b2-ce08）/坏消息淹没（b2-ce09）**：老板只谈目标不谈"该放弃什么"与时间再分配；或上任第一天被坏消息狂轰滥炸、直接进入救火模式——都会阻断过渡。

### 作者的盲点 / 时代局限

- **神经科学包装薄弱**：作者与咨询师 Peter Burow 共同发明的这套工具，用流行神经科学（大脑进化、双系统）背书，"六阶段与大脑网络的一一对应无实证引用、不可证伪"（系列级批判）；其循环论证风险与不可检验性必须随 skill 携带。
- **顺序刚性可能被现实打乱**：书中未讨论紧急接手（turnaround）情境下"先救火再谈意义"的合理性；把六步绝对化会低估危机领导的现实约束。
- **责任个人化倾向**：作者把过渡失败主要归于个人与老板的作为，较少处理组织政治、前任遗留、资源约束等结构性因素。
- **样本与语境**：案例来自作者咨询经验（GE 式大公司、2010 年前后），无对照与失败样本；对远程/混合团队、跨文化情境，过渡的六步形态需要重新验证。
- **性别与传统叙事**：正文用"她可能需要……"的示例化表述掩盖了案例几乎全为男性高管的现实；跨文化管理中"归属感"的来源可能完全不同。

### 容易混淆的邻近方法论

- 与 `first-manager-three-transitions`（b5-f04）：对象与颗粒度不同（一线经理具体转型 vs 通用六阶段顺序）；初任经理场景优先 b5-f04，并把 MEALER 作为补充。
- 与 `three-dimension-transition`（b5-f02）：三维度答"转什么内容"，MEALER 答"按什么顺序"；配合使用而非互相替代。
- 与 `performance-dialogue-evidence`（b2-f22）：过渡期 vs 稳态期的分工；过渡完成后切换到月度证据讨论。
- 与 `environment-three-variables`（b2-f19）：如过渡失败是全组织现象，先看"土地"（文化、运营模式、组织设计），别只辅导个人。
