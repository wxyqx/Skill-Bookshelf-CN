# 潜能-绩效九格矩阵与每格行动

## R — 原文 (Reading)

> "第四步，用潜能-绩效组合矩阵评估继任候选人。……注：此矩阵不适用于在现任职位上任期未满6个月的人员。"
>
> — 查兰/诺埃尔/德罗特，第10章（L11987、L11995）

> "方格1，卓越/转型　具备这一优秀绩效和潜能组合的个人已经做好准备承担来自更高领导层级的任务。由于这种状态尚不稳定，应该立即采取措施；员工清楚他们已经熟练掌握现有职位的技能，也在期待职位上的升迁。在很多情况下，这些人都是其他公司招募的主要目标。"
>
> — 同上，第10章（L12011）

> "遗憾的是，当我们追问其判断根据时（即如何为特定的人选决定其所属方格），我们发现他们是靠自己的直觉来完成这个选择。他们并没有依靠绩效证据或潜能标准。……九格矩阵只是面粉而非蛋糕。"
>
> — 同上，第10章（L12091）

## I — 方法论骨架 (Interpretation)

九格矩阵 = 绩效（卓越 / 全面 / 非全面）× 潜能（转型 / 成长 / 熟练）。它与通用九宫格的关键差别有两处：轴上用的是本书自己的三类绩效与三类潜能定义；每个格子都有规定的动作，而不只是分类。

九格动作要点（作者逐格给出）：

- **1 卓越/转型**：立即行动——安排到下一层级的岗位或新的职能/业务，给陡峭学习曲线与相称回报，防止被猎走。
- **2 卓越/成长**：留在原层级但给延展任务：做上级的某项工作、跨职能项目，测试其能否在不掉绩效的前提下承担越级任务；失败也没有损失，反而避免大错。
- **3 全面/转型**：给更高目标（比同事做得更多、鼓励创新方案）；在绩效明显提高之前不要转换其领导职位；同时注意其环境是否让成功不具可能性，必要时改判到 5。
- **4 卓越/熟练**：留在现层但必须表彰；让其参与培训他人、进入新产品/新项目学习团队——他们是领导力开发的核心资源，不能视为理所当然。
- **5 全面/成长**：绩效提升是关键；达标后可给同层更重要工作，完成得好可能直接跳入第 2 格；警惕管理者因"不想得罪人"而把 7/8 格的人误归到 5 格。
- **6 非全面/转型**：新提拔者给时间、经验与训练；若绩效欠佳不是"刚升上来"造成的，说明存在严重缺点，需深入分析。
- **7 全面/熟练**：两条路——成为现职佼佼者，或滑向无关紧要；要给训练机会并坦诚说明自满的危险。
- **8 非全面/成长**：严格绩效管理；他们有能力却未发挥（时间分配、岗位适配、上司问题都可能），必要时请高两级的上司或资深 HR 介入。
- **9 非全面/熟练**：常在不合适的层级工作，应重新安排至低一级甚至解雇；但划掉名字之前必须先查管理与组织因素（任务界定、资源、氛围）并直接对话。

使用纪律由作者用一句话概括：**"九格矩阵只是面粉而非蛋糕。"** 先有本地化的绩效与潜能标准、先有绩效证据，才允许填格；填格靠直觉的公司只是"错误地相信这九个方格能提供分析结论"。另两条规则：任职未满 6 个月者不适用；潜能评价至少每半年复核，正负结论不得永远不变。

## A1 — 书中的应用 (Past Application)

### 案例 1: 万豪国际——LTDI 把评估变成可运行的程序
- **问题**: 公司有领导梯队模型，但要把"谁准备好了、谁该往哪发展"变成覆盖所有层级的常规工作，还需要一套评估工具与治理结构。
- **方法论的使用**: 万豪建立"领导才能开发细则（LTDI）"——"这个开发细则是一套程序，万豪可以使用这个程序来评估各领导层人才的实力，确定当前已经做好准备能够获得晋升的经理"，先在 250 名最高级经理中试用，再推广到所有领导层级；配套人力资本执行委员会、网络化人才信息、深度面谈与高管竞争力模型。
- **结论**: 矩阵类评估工具必须嵌入治理与流程（谁主持、用什么证据、结论如何被使用）才有生命力，这正是"面粉做成蛋糕"的过程。
- **结果**: 数年内建立起宏大的管理人才储备，管理质量成为万豪资本市场叙事的一部分。

### 案例 2: 矩阵的"快速审视"用法——发现整层无人可提
- **问题**: 高层想知道某领导层级的人才厚度，但一个个看档案效率太低。
- **方法论的使用**: 把某层级所有人一次性放入矩阵做群体分布观察。例如"公司可能发现其职能经理都集中在中等潜能-中等绩效方格内，这说明在这一层级上该公司没有太多可提拔的人选，公司最好改变这一现状"。
- **结论**: 矩阵的第一层价值是群体扫描——能迅速暴露"某一层级整体缺苗"这种结构性问题，从而触发培养动作。
- **结果**: 作者提醒，这种浏览方式虽然有用，但通用矩阵的绩效/潜能表达太笼统，"无助于得到具体的发展举措"，所以要用三类绩效×三类潜能的版本重新诠释，才能落到每格动作。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要组织人才盘点/继任评估会，需要一套分级工具与每格的处理规则，避免"评完就散会"。
2. 盘点会已经开了，但填格靠印象、结论无证据，用户想建立"先标准、后填格"的纪律。
3. 拿到了某人的格子归属（如"卓越/转型"或"非全面/熟练"），但不知道下一步该做什么动作。
4. 发现某个层级的人才分布整体偏低（都堆在中间格），想判断这意味着什么。
5. 有人刚被提拔不到半年就被要求评价，需要知道规则边界。

### 语言信号 (用户的话里出现这些就应激活)

- "九宫格/人才矩阵怎么用？/ 盘点会怎么开才有用？"
- "他应该放在哪一格？/ 这一格的人一般怎么处理？"
- "盘点会填完就完了，没人跟进"
- "nine-box" / "talent matrix" / "performance-potential grid" / "calibration" / "talent review grid"

### 与相邻 skill 的区分

- 与 `b5-f28 potential-three-types` 的区别: 潜能三分类负责把"潜能轴"判准（证据、时间窗、复核）；本 skill 负责把两轴组合后的九格含义与动作落地。判不准潜能时先回 f28。
- 与 `b5-f27 succession-five-steps` 的区别: 九格矩阵是继任五步骤中的第四步工具；本 skill 只管矩阵本身的标准、证据纪律与每格行动，不负责会议节奏与全制度设计。
- 与 `b1-f12 talent-review-meeting-mrr` 的区别: MRR 是人才评估会议的组织机制（看谁、怎么问、如何跟进）；本 skill 是会上使用的分级工具与动作规则。
- 与 `b4-p12 assessment-dual-track` 的区别: 评估双轨强调业绩考核与领导力评估分离；本 skill 的绩效轴与潜能轴正是这种分离在矩阵上的具体呈现。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先立标准，再碰矩阵**
   - 完成标准: 产出公司本地化的三类绩效定义与三类潜能定义（用公司自己的话语，并经公示讨论）；明确指出在标准缺位时不允许开填格会议。
   - 判停条件: 若标准尚不存在，先跳到建立标准（可用 b5-f27 第二、三步作为流程载体），不要用直觉开工。

2. **收集证据，逐人建档**
   - 完成标准: 每个被评估者有"业绩证据＋环境背景＋潜能类别＋理由"四要素；任职未满 6 个月者一律不评；无证据者标"数据不足"。
   - 完成标准 (反直觉检查): 抽取若干格子让填格人回答"你的判断根据是什么"，凡答不出证据的结论退回补证。

3. **开填格会议并校准**
   - 完成标准: 由集体讨论逐人过格，记录异议与依据；对管理者可能因人情把 7/8 格误归为 5 格的倾向做专门复核（作者点名的典型偏差）。

4. **逐格给出行动（本 skill 的产出核心）**
   - 完成标准: 九个格子逐一写出本公司版本的动作，至少覆盖：1 格立即安排升级/新业务并防被猎；2 格给越级任务或跨职能项目做测试；3 格提目标、暂不换岗；4 格表彰＋参与培养他人；5 格抓绩效提升；6 格先给时间，异常者深入分析；7 格两条路并坦诚沟通自满风险；8 格严格绩效管理并排查时间分配与岗位适配；9 格先查管理与组织因素，再决定重新安排或退出。
   - 判停条件: 对 9 格人员的任何处置动作，须先完成组织因素排查与直接对话，未完成不得进入人事流程。

5. **设复核与复核后的更新**
   - 完成标准: 至少每半年复核一次；明确"正负评价不得永远不变"；把矩阵结论接入年度继任会议与季度审核，并跟踪每格行动的执行状态。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单个人的绩效面谈或辅导对话——用绩效圆圈即可，矩阵是群体工具。
- 任职未满 6 个月者——作者明确豁免；对新任者填格会把"上任初期的正常缺口"误判为不合格。
- 被当作裁员名单或强制分布工具：这会把发展工具变成惩罚工具，摧毁后续所有评估的可信度。
- 组织没有统一的层级与绩效/潜能标准时硬填——"面粉"做不成"蛋糕"，只会制造虚假精确。

### 作者在书中警告的失败模式

- **九格矩阵靠直觉填格＋潜能评价永远不变**: "这一方法很容易抓住人们的眼球。他们很骄傲地向我们展示那九个方格，上面还配上了相应的名称。遗憾的是，当我们追问其判断根据时……我们发现他们是靠自己的直觉来完成这个选择。他们并没有依靠绩效证据或潜能标准。依赖直觉的公司只会错误地相信这九个方格能提供分析结论……九格矩阵只是面粉而非蛋糕。"（b5-ce28，第10章 L12091–L12095；并入 b5-p23 使用纪律）——伦理提示：潜能标签会实际影响晋升与薪酬，须防止标签固化造成事实上的歧视或"自我实现预言"，评价数据应按人事档案规范管理（b5-ce28 ethics_legal_note）。
- **把人一次定级后不再更新**: "最坏的情况是出现正负的评价永远不变。继任工作和潜能鉴定需要至少每半年进行核查，你应当乐于根据个人和工作的新情况改变评估。"（同上，L12095）
- **为不得罪人而误归格子**: 管理者倾向把应属 7/8 格的人归入 5 格（全面/成长），作者要求"重新检查你针对他们的表现以及他们正在开发的技能的评价"，并审视自己的动机（第10章 L12027 附近）。

### 作者的盲点 / 时代局限

- **九宫格是通用 HR 工具，滥用风险高**: 书中的版本虽用三类潜能×三类绩效重新诠释，但其预测效度仍无实证支持；在缺乏坦诚文化的组织里极易退化为合规动作（参 b4-ce09 官僚填表式人才流程）。
- **标签固化的公平风险**: 潜能与绩效标签会实际影响晋升与薪酬分配；作者只提醒"每半年复核"，未讨论被评估者的知情权、申诉机制与评估者群体偏差。
- **美国大公司人才文化预设**: 假设组织有足够资源为每格设计差异化动作；资源紧张或扁平化组织中，九格动作需要大幅裁剪。
- **组织政治对填格的影响未展开**: 谁与谁关系好、谁掌握话语权，都会系统性地影响格子归属，书中只提到"动机"问题，未给出防政治化的机制。

### 容易混淆的邻近方法论

- **强制排名/活力曲线（册1）**: 那是横向排序与淘汰逻辑；九格矩阵是按层级要求做纵向定位与发展配置，作者反对把它当作淘汰名单（本 skill B 段已声明）。
- **通用九宫格（GE 版 3×3）**: 轴的定义常是笼统的"潜力/业绩"；本书版本要求先把两轴换成本地化的三类标准，且必须有每格动作。
- **能力-意愿矩阵等二维诊断工具**: 用于任务分配与管理风格匹配；九格矩阵用于人才盘点与继任，时间窗与用途不同。
