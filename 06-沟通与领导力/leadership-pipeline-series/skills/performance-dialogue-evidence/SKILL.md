# 业绩讨论与证据法

## R — 原文 (Reading)

> "证据是由两个因素组成的，它们分别是已经实现的业绩和业绩实现时的环境背景。例如，'收入增加了10个百分点'就是证据，但是，'在低迷的市场环境中，收入增加了10个百分点'或者'市场增长了15个百分点，收入增加了10个百分点'就是更强有力的证据。"
>
> — 斯蒂芬·德罗特，第11章（fulltext L5629）

> "在业绩考核周期第一个月末讨论业绩实现情况，具有特别重要的价值，因为还有11个月可以用来解决问题。在第二个月末的时候，仍然还有10个月可以用来解决问题。……年终才开展这样的讨论已经没有任何意义。"
>
> — 斯蒂芬·德罗特，第11章（fulltext L5609）

> "如果还没有实现任何真正的结果或者成就，要避免关于活动的陈述，如'访问了10个区域、分析了各种流程、以新的理念开展工作'，这些都属于活动，关键要回答的问题是，'这样的活动带来的可见的结果是什么？提高的结果是什么'。"
>
> — 斯蒂芬·德罗特，第11章（fulltext L5645）

## I — 方法论骨架 (Interpretation)

业绩标准写完之后，真正决定它有没有用的是"怎么谈"。作者把业绩梯队当成激励工具而不是评价工具：一年一两次、主观指责式的评估只会让人消极（"他并不知道我现在遇到了什么问题"就是失败信号）。有效做法有四根支柱：

**一、每月一次深入讨论。** 与所有成员回顾预算与目标进度，再对每个员工个人重复一遍。第一个月末讨论最有价值——还有11个月可以解决问题；越晚谈，讨论越没有意义。全盘讨论而非只谈热点，为的是强调"完成整项工作"的价值。

**二、以证据代替意见。** 证据＝业绩＋环境背景。同一句"收入增10%"配上背景（低迷市场 vs 市场增15%）强弱完全不同；相对证据（"比去年好"）必须说明为什么好（如用了新的市场调研），否则只是主观观点。要把信息挖到能正确把握对方业绩所处环境为止。

**三、排除两类伪证据。** 活动陈述（"访问了10个区域、分析了各种流程"）——追问"这些活动带来的可见结果是什么"；含糊概括（"在流程设计中做出了个人贡献"）——说不清业绩与成就。业务没有真正成果时，尤其要拒绝活动充数。

**四、记录成实录，结论自然显现。** 把全面业绩标准放第一栏、事实证据陆续填后面，全年结束"业绩等级"显而易见，只需一次全面评估。年度结论用固定问题清单：证据说明了什么、还需要什么证据、员工实际在哪个层级工作、哪些条目要改进、整体是未实现全面业绩/全面业绩/卓越业绩。考虑每季度做一次总结，焦点始终在"衡量工作与业绩"，不在"评价人"。

讨论的重心是接下来要做的事：要做什么、怎么做、会遇到什么障碍与风险、需要什么帮助。事前深入研究而非事后评头论足，才能真的辅导与学习。跨层级了解真实状态时用轻松中立的提问（发展计划执行程度、真正骄傲的事、最大障碍是什么），不让员工尴尬、不让其评判自己的老板，且不给出方向只搜集信息；听到的情况要与中间管理者确认后再行动，避免电子沟通占据与下属面谈的时间。

## A1 — 书中的应用 (Past Application)

### 案例 1: 一线经理的梯队评估表（实录设计示例）
- **问题**: 年终评估本身无法让人改正问题，且一次性主观评判破坏激励。
- **方法论的使用**: 作者给出表11-1"一线经理的梯队评估"：第一栏放全面业绩标准，后面栏目填入月度讨论中收集的事实证据，全年逐月积累。
- **结论**: "现在你就有了一份实录，在一年结束的时候，'业绩等级'就是显而易见了，除了进行一次全面的评估工作之外，就不再需要任何新的努力了。"
- **结果**: 该格式成为第11章建议的标准做法，并要求与直接下属分享，让他们自己按表带证据来参会。

### 案例 2: E公司：把增长与人才写进标准，讨论才有内容可谈
- **问题**: 事业部总经理只被收入和营业量两项片面指标评价，增长与人才培养没人重视。
- **方法论的使用**: 先解决"标准里有没有"的问题——建立"增长业绩"这一特殊业绩类型，把收购、释放企业能量、培养选拔领导写进标准；再用月度讨论与证据记录跟踪。
- **结论**: 衡量什么就得到什么；讨论机制的效力取决于标准中是否包含真正重要的业绩项。
- **结果**: 标准与月度讨论配套后，增长与人才培养成为可被讨论、可被记录的对象（并用生产效率与成本管理平衡"牺牲利润盲目追求增长"的冲动）。

### 案例 3: 跨层级提问法（激发所有层级动力的三问）
- **问题**: 仅根据汇报信息判断各层级状态远远不够，高层与低层直接谈业绩又会引起中间管理者不满。
- **方法论的使用**: 用三个示范问题（发展计划执行到什么程度？过去3/6/9个月真正感到骄傲的事是什么？最大障碍是什么、如何解决？）以轻松中立口吻提问；明确"不会给出工作方向或者解决问题，只是搜集信息"。
- **结论**: 员工讲活动而不讲成果，说明业绩导向没到位；讲出上层看不到的障碍，说明提问发现了真问题。
- **结果**: 该方法写入第11章"激发所有层级的工作动力"，并要求把听到的情况与中间管理者确认后再采取补救措施。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 季度/月度复盘要来了，用户觉得"每次都变成念数据、走过场"，想改造成真正有用的对话。
2. 员工交上来的汇报全是"我做了什么"（活动清单），用户想知道该怎么追问出结果与背景。
3. 要给下属做年度评价，担心被质问"你凭什么这么评"，想建立有事实依据的评估方式。
4. 公司刚做完业绩标准/业绩梯队，问"标准有了，接下来每月该怎么用"。
5. 团队里有人业绩达标难度大（市场不好）却更值得肯定，或有人数字漂亮但含水分，用户想区分。
6. 电子沟通泛滥，领导没时间和直接下属深谈。

### 语言信号 (用户的话里出现这些就应激活)

- "季度复盘怎么写才不流于形式？" / "how to run a meaningful quarterly review?"
- "业绩讨论/一对一怎么谈？" / "performance dialogue, monthly one-on-one"
- "证据/事实依据是什么？" / "evidence, facts vs opinions"
- "他说的都是活动，不是结果" / "activity statements, no results"
- "怎么谈才能激励人，而不是审判人？" / "motivate, not judge"

### 与相邻 skill 的区分

- 与 `performance-pipeline-interview-build`（b2-f03）的区别: 后者建标准（访谈→名词→双栏→确认），本 skill 用标准（每月讨论＋证据记录）；没有标准的用户先补 b2-f03。
- 与 `mealer-transition-six-steps`（b2-f21）的区别: 后者管上任初过渡期；本 skill 管稳态期的月度业绩对话。
- 与 `talent-review-meeting-mrr`（b1-f12）的区别: 后者是评估人的会议机制（人才盘点）；本 skill 是逐人的业绩对话与证据记录。
- 与 `follow-through-discipline`（b1-p08）的区别: 后者是单一目标追问到底的纪律；本 skill 是多标准、多员工、按月循环的证据体系。
- 与 `coaching-two-tracks`（b3-f12）的区别: 后者是教练辅导双轨（技能与职业发展）；本 skill 的对话虽含辅导，但以业绩证据与标准为轴。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确认是否有可用的业绩标准**
   - 检查是否存在分层的全面业绩标准（含关键业绩指标与目标）。
   - 完成标准: 有标准则进入下一步；无标准则判停，先走 b2-f03 建标准，否则讨论无框架。

2. **建立月度节奏**
   - 与团队全员回顾预算与目标进度，再对每位成员个人重复一次；把第一个月末列为最关键的第一次讨论。
   - 完成标准: 日历上固定的月度讨论时间；第一次讨论安排在考核期第一个月末。

3. **现场收集证据（业绩＋环境背景）**
   - 对每条标准记录：实现了什么＋当时的背景（市场、竞争、资源、突发事件）；相对证据必须说明为什么更好；不足时必须挖掘到能正确把握环境为止。
   - 完成标准: 每条被讨论的业绩项都有"业绩＋背景"两要素；背景缺失的条目标注待补。

4. **筛掉两类伪证据**
   - 活动陈述 → 追问"这带来了什么可见结果/提高"；含糊概括 → 要求具体的业绩、成就或结果说明。
   - 完成标准: 讨论记录中不含未加追问的活动与概括；凡追问后仍无结果者，如实记为"暂无结果"。

5. **写入实录**
   - 按表格式把全面业绩标准放第一栏，证据填入对应栏目，逐月累积并与直接下属共享（让对方按表带证据参会）。
   - 完成标准: 每人在考核年度内有一份可持续更新的证据记录；共享机制已建立。

6. **把讨论重心放在接下来**
   - 多数时间用于提问与探讨：要做什么、怎么做、会遇到什么障碍与风险、需要什么帮助；事前研究而非事后评头论足。
   - 完成标准: 每次讨论产出"下一步动作＋障碍＋所需帮助"清单。

7. **年度结论与等级自然显现**
   - 用固定问题清单收口（证据说明什么、还缺什么证据、员工实际在哪个层级工作、哪些条目要改进、整体等级是未实现全面/全面/卓越）；可每季度做一次小结；讨论始终聚焦工作与业绩，不评价人。
   - 完成标准: 年终等级由全年实录直接得出，无需临时回忆或补证。

8. **（可选）跨层级抽查提问**
   - 用三问（发展计划、骄傲的事、最大障碍）以中立口吻抽查各层级真实状态；声明只搜集信息不给方向；听到的情况先与中间管理者确认再行动。
   - 完成标准: 抽查问题清单与信息确认流程明确；不因抽查破坏中间管理者的权责。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 没有业绩标准就开谈：讨论会退化成"最近怎么样"的寒暄，或变成领导的临时标准。
- 把它当审判工具：作者明确"要将业绩梯队作为一个激励员工的工具，而不是一个评价工具"；若用户的目的是找证据处罚人，本 skill 的纪律（不评价人、给帮助）与之冲突，不应调用。
- 用于薪酬谈判与升降职决定：那些是需要单独程序的决策；本框架只产出证据与对话，不作处置建议。
- 电子沟通替代面对面：作者明确警告电子工具会堵住业绩梯队；月度讨论必须是面对面（或等效的深度对话），不能用邮件/IM 循环代替。
- 涉及个人态度、心理健康的判断：超出本 skill（个人态度问题应辅导为主、避免以"态度"为名随意处理，见 b2-ce18 的伦理提示）。

### 作者在书中警告的失败模式

- **活动陈述与概括陈述充数（第11章原文）**：没有真正成果时用"访问了10个区域、分析了各种流程"之类活动填充，或用"在流程设计中做出了个人贡献"的概括蒙混——都是证据的伪品。
- **电子沟通滥用堵塞业绩梯队（b2-ce20）**："很明显的一个业绩代价就是领导没有时间与自己的直接下属会面沟通"；领导上班第一件事是阅回邮件，无暇到现场，冲突先在邮件里升级。
- **评估式谈话的消极反应（b2-p15）**：一味责备进展慢、将原因指向他人（"你自己没有努力"）、一年只做一两次全面回顾，都会让人消极——典型信号是员工想"他并不知道我现在遇到了什么问题"。
- **只看业绩数字的评估盲区（b2-c08）**：采购经理马戈个人业绩超标23%、新增5家供应商，却从不带下属参与谈判，团队无人能接替；她一走业务告急。她本人说"业绩好坏只被按采购业绩评价"——标准与讨论缺了"培养团队"这一项，数字越漂亮越危险。
- **盲目遵循预算（第11章原文）**："盲目遵循预算（即18个月之前所做出的最好猜测）是没有帮助的"；不看环境背景的达标/未达标都可能是误判（3/5达标者可能卓越，4/5达标者可能只是称职，取决于资源与环境）。
- **把"态度问题"混进业绩讨论（b2-ce18 的伦理提示，原样落位）**：个人贡献者三害（愤世嫉俗、抵制变革、自我陶醉）的处置要在管理权限与合法合规框架内进行（对个人态度问题应辅导为主，避免以"态度"为名随意处理）；书中明确"合理担忧可以表达，但要在决定前、以正当渠道提出"。

### 作者的盲点 / 时代局限

- **绩效评估的制度现实**：本书方法论假设组织有坦诚文化、上司有辅导意愿；作者自己在系列批判中被指出——模型最需要的前提（组织坦诚与自律）恰恰最难满足，绩效标准会被博弈（书中仅在证据与情景分析处轻描淡写）。
- **"环境背景"的争议性**：把环境因素纳入评价，可能被滥用为找借口，也可能在资源分配不公时固化偏差；书中未给客观化的校准机制。
- **缺乏统计验证**：月度讨论→激励→业绩提升的因果链没有对照证据，属咨询顾问的经验主张。
- **美国大公司语境（2010年前后）**：以面对面、层层汇报为前提；远程/异步组织中"每月面对面"需重设计，作者未处理；也未讨论多文化情境下"直接给反馈"的边界。
- **隐含的评估权力**：实录最终仍由上司掌握并决定等级，被评估者的申辩权、程序公正未讨论。

### 容易混淆的邻近方法论

- 与 `performance-pipeline-interview-build`（b2-f03）：建标准 vs 用标准，顺序不能颠倒；两者可串联（先建后谈）。
- 与 `talent-review-meeting-mrr`（b1-f12）：一个是逐人对话，一个是评人会议；先有证据记录，盘点会才有依据。
- 与 `coaching-two-tracks`（b3-f12）：教练双轨处理发展需求，本 skill 处理业绩证据与对话节奏；两者常在同一个一对一里交替出现，但轴心不同。
