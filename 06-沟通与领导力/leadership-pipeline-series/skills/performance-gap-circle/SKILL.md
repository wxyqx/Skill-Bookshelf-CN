# 绩效圆圈与绩效缺口：七项内容与培养四步循环

## R — 原文 (Reading)

> "圆圈内的内容是这项工作的承担者所应当完成的职责，圆圈外的内容则是他人的职责。为了进一步说明这个概念，圆圈内绘制了7条斜线，它们代表前面提到的七项绩效内容：运营绩效、客户绩效、领导绩效、管理绩效、关系拓展、社会责任和个人专业能力。"
>
> — 查兰/诺埃尔/德罗特，第9章（L11656–L11660）

> "当你将某人任命到一个新的领导岗位时，你就已经创造了一个绩效缺口。因为他们不可能拥有新层级上有效工作所需的领导技能、时间管理能力和工作理念。结果是他们不可能立即在七项关键绩效内容上都取得显著成就。"
>
> — 同上，第9章（L11672）

> "令人难以置信的是，75%的原因与上司有关。例如，上司可能在错误的领导层级上工作。他们可能管得太精细了或是与下属缺乏沟通。……如果你想要通过领导梯队提升全面绩效，那么应当从上司开始。"
>
> — 同上，第9章（L11722）

## I — 方法论骨架 (Interpretation)

"他绩效不好"这句话太粗，本方法把它拆成一个圆：圆内是本岗位应完成的职责，圆外是别人的职责；圆内画七条斜线，分别对应七项绩效内容——运营（收入/成本/利润）、客户、领导（定方向/沟通/育人/建标准）、管理（控制/质量/及时）、关系拓展、社会责任、个人专业能力（只限与工作相关的部分）。逐项标注"已达标/未达标/不合适"，就能看出这个人处在四种形态的哪一种：全面绩效（全部达标，培养目标）、非全面（缺几块，最常见）、不合适（做了别人圈里的事）、卓越（远超要求，往往坐不住、易被猎头盯上）。

核心机制是"绩效缺口"：只要把人放到新层级，缺口就必然出现——他不可能同时具备新层级的技能、时间结构与理念。缺口不是问责证据，而是发展起点，必须在就任之初就告知本人并开始弥补。

培养走四步循环：① 承认缺口、立即补缺（教练辅导、培训、行为学习法）；② 培养必须持续到全面绩效，渐进提升远远不够；③ 达到全面绩效后，测试超常规能力（让他做上级的部分工作）；④ 给更挑战的任务或晋升——一旦晋升，新缺口再生，回到第一步。作者特别警告：全面绩效者提升得太快、跨级太多，同样会把好苗子变成平庸者。

找缺口原因先从上司查起：作者的经验是 75% 的原因与上司有关（错层、管太细、不沟通、缺标准、偏袒），其次才是组织因素（结构重叠、工作设计不合理、流程割裂、责权不匹配、人员配备不当）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 玛丽——从"管得太细"到学会授权
- **问题**: 程序员玛丽升任研发小组经理后，在工作压力下忘记角色转变，命令式管理、总想亲自写程序，导致下属积极性被削弱、系统交付失败。
- **方法论的使用**: 上司持续对她做教练辅导，并引入 360 度评估帮她照出缺口——当听到合作良好的小组成员说她"管得太细、不善于分配工作"时，玛丽非常震惊。
- **结论**: 缺口在"领导绩效"这一项：她理智上认同精管，情感上需要接受改变；改变路径是补上授权与人员管理的技能与时间分配。
- **结果**: 她花了好几个月学会有效授权、放手让下属做重要工作，并从帮助下属成功中获得与做技术同样的满足感，转型成功。

### 案例 2: 耐克经理——"十岁的孩子都能明白"
- **问题**: 企业普遍用复杂表格与评分卡做绩效管理，领导没时间看、员工看不懂，绩效讨论变成单向考核。
- **方法论的使用**: 作者教领导者用圆圈度量绩效：员工自己画圆圈，再与领导的圆圈比较或叠加，差距当场显现；必要时用每月一次的绩效讨论复盘。
- **结论**: 工具的简洁本身就是有效性的来源——"当我们问，这种图形的含义是否清楚时，一位耐克的经理说道：'十岁的孩子都能明白！'"
- **结果**: 使用该图形的企业反馈其简洁清晰、领导几分钟就能理解；员工从"被动承受者"变成梯队模型的一个环节，参与度和讨论质量都提高。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 刚提拔一个下属（或自己刚升职），要制定上任初期的培养计划，却不知道从哪几项入手。
2. 一个人业务能力很强但"只会自己做，不会带人/不管客户/不做横向协调"，评价时说不清到底缺什么。
3. 想区分"他是不努力"还是"他是被放在缺口里"，避免把结构性问题当成态度问题。
4. 培养做了很久却始终没到位，要判断是不是"渐进提升"代替了"全面绩效"目标。
5. 要给团队做一次绩效结构体检，把只盯运营指标的评价体系扩展为七项。

### 语言信号 (用户的话里出现这些就应激活)

- "刚提拔上来，怎么给他定培养计划？/ 他到底缺哪块？"
- "他只会自己干活，不会带团队 / 只管销量，其他都不管"
- "怎么培养才能算到位？补课补到什么时候算完？"
- "performance gap" / "full performance" / "development plan for a new manager" / "what is he missing"

### 与相邻 skill 的区分

- 与 `b5-f21 role-clarity-gaps-overlaps` 的区别: 先做职责澄清（画清圈子），再做绩效圆圈与缺口；本 skill 是在职责边界已明确的前提下定义标准、找缺口。
- 与 `b3-f12 coaching-two-tracks` 的区别: 双轨教练讲"怎么辅导"（业务与人的两条轨道）；本 skill 讲"补什么"——用七项内容定位缺口、用四步循环规定培养节奏。
- 与 `b4-p12 assessment-dual-track` 的区别: 评估双轨强调绩效考核不能替代领导力评估；本 skill 给领导力评估提供了七项内容的具体清单与可视化工具。
- 与 `b5-f19 diagnosis-five-steps` 的区别: 诊断五步用于症状不明的排查；本 skill 是在人已到位、需要培养时使用的标准与工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画圆圈：把七项内容逐项标注**
   - 完成标准: 产出本人（和必要时其上级、下属）的圆圈图，七项内容各有明确标记：全面 / 非全面 / 不合适（做了别人圈里的事）。
   - 判停条件: 若发现"不合适"形态占主导（它做了上一层级或下一层级的工作），先回到职责澄清，再谈培养计划。

2. **确认缺口是结构性的，而不是态度性的**
   - 完成标准: 在结论中显式写出"晋升必然创造绩效缺口"，并把缺口逐项列成清单；同时向当事人告知这份清单，取得其参与意愿。

3. **先查上司，再查组织，最后才谈个人**
   - 完成标准: 逐条核对上司侧原因（是否错层工作、管太细、沟通少、未定标准、未修复已出现问题的能力、资源不足、偏袒）与组织侧原因（结构重叠、工作设计不合理、流程割裂、责权不匹配、配备不当）；输出"与上司有关的因素"清单，并让上司本人先反思自身要改变什么。

4. **制定补缺方案并选工具**
   - 完成标准: 针对每一项缺口指定培养手段——教练辅导、培训、行为学习法（同层团队＋挑战性真实任务＋教练反馈）等，写明责任人与复盘点；方案目标必须是"全面绩效"，不接受以"渐进提升"为终点。

5. **设节奏并进入四步循环**
   - 完成标准: 约定每月绩效讨论（每年第一个月月底那次最重要，因为还有时间纠正与跟进）；达标后执行"测试超常规能力→升级或给挑战任务"；一旦升职，立即重画圆圈、回到第一步。
   - 判停条件: 若当事人明确不愿放弃旧方法、不愿意接受新理念（行为证据持续不变），应停止按培养处理，转入角色调整讨论——不要用更长时间重复同一种补缺。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯 KPI 对账、考勤纪律、单点技术失误的复盘——不需要七项框架，用普通绩效沟通即可。
- 岗位职责尚未澄清时，先做 b5-f21 的职责三步法；否则圆圈画不准，七项标准会建在流沙上。
- 用于给个人贴"全面不全面"的终身标签：圆圈是某一时点的对话工具，不是人事档案结论。
- 小团队里没有明确层级差异时，七项内容的权重需要重新裁剪，不能照抄。

### 作者在书中警告的失败模式

- **无差别培训浪费**: 培训不从业务问题与个人需要出发，按名册全员上课，半数人白耗时日，组织能力却无提升（b1-ce18，册1 第3章 L1042）——正是"未定位缺口就先补课"的典型。
- **CEO 失败的首要原因：不能快速处理绩效提升问题**: "对于没有完成预期业绩目标或者工作方法不当的直接下属，即使是最强硬的首席执行官，在对付他们时也会遇到麻烦……问题越拖越糟"（b5-ce19，第7章 L11325）。
- **组织默认的晋升假设**: "如果一个人能够出色地完成某个岗位的工作，那么他也会同样出色地完成下一个岗位的工作"（b5-ce35，导论 L9637）——本方法要反驳的默认心智模型。
- **伦理与合规（作者未展开，使用须遵守）**: 涉及绩效改进计划、解雇等高敏感人事操作，须依当地劳动法与公司流程执行；本书仅为管理框架（b5-ce19 ethics_legal_note）。

### 作者的盲点 / 时代局限

- **七项清单缺乏效度证据**: 清单来自作者咨询经验，没有统计验证；"个人专业能力（仅仅与你应该做的工作相关的部分）"的边界在实践中极易争议（BOOK_OVERVIEW 批判节）。
- **对组织政治、薪酬制度、行业周期处理很薄**: 作者承认薪酬制度不匹配会影响诊断，但未展开如何在制度不改的情况下推行全面绩效。
- **工具依赖组织坦诚**: 圆圈要有效，前提是员工敢画自己的圈、领导敢承认自己的圈；缺少坦诚文化的组织中，它会退化为另一种表格（参 b5-ce26）。
- **科层制预设**: 前提是公司存在稳定的领导层级；扁平化/项目制组织中"七项内容"的相对权重需重新定义。

### 容易混淆的邻近方法论

- **平衡计分卡/雷达图/OKR**: 那些是目标设定与打分工具；圆圈是"对话与定位"工具，不产生分数，产生的是双方对差距的共同认知。
- **能力模型（competency model）**: 能力模型描述"具备什么素质"；七项内容描述"交付什么绩效"，本方法刻意从交付物出发。
- **强制排名/活力曲线**: 那是横向比较与排序；圆圈是纵向定位（对照本层级要求），两者的用途与风险完全不同。
