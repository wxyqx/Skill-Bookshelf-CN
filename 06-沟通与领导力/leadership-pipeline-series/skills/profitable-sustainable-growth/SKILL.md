# 赢利可持续增长原则（增长必须赢利、可持续，并伴随利润与周转率的提高）

## R — 原文 (Reading)

> "业务增长从其本身来讲并不一定有什么好处。增长必须要赢利和可持续，业务增长必须要伴随着利润和周转率的提高，现金净流入能力也需要保持同步。"
>
> — 查兰，第2章（L6449）

> "所以，请不要把公司的规模作为其是否成功的衡量指标。奋力争取更多的营业额并不一定是好的经营方式。你需要知道为什么以及怎样使业务增长。同时，还要考虑你的公司是否在一条可持续的轨道上发展壮大。"
>
> — 查兰，第2章（L6465）

> "看看你的现金发展状况，或许在销售收入增长的同时，你的现金状况变得更糟了。再退一步讲，你的业务增长是在产出现金还是在消耗现金？你的利润率是改善了还是变得更糟了？"
>
> — 查兰，第2章（L6467）

---

## I — 方法论骨架 (Interpretation)

"增长好"是商业世界最强的默认假设之一，但作者把它当作待检验命题：**增长本身不一定是好事**。他给出的是一套增长验收标准：

1. **赢利**：增长必须带来利润，而不是用低价、赊销、大额前置投入换收入。
2. **现金同步**：现金净流入能力要与增长保持同步——"你的业务增长是在产出现金还是在消耗现金？"
3. **质量同步**：业务增长必须伴随着利润率和周转率的提高（若增长让周转率下降，等于用更多资产做同样的生意）。
4. **可持续**：必须问"为什么以及怎样使业务增长"，检查是否在可持续的轨道上（外部依赖、客户结构、竞争反击、技术替代）。
5. **规模不是成功指标**：营收、门店数、销量都是规模，规模不回答"是否赚钱、是否可持续"；要主动把规模指标换成赢利质量指标。
6. **增长的心理效应不构成理由**：增长能激活组织、吸引人才、鼓舞士气——这是加分项，但不能作为"为增长而增长"的论证。
7. **三个失败机制要主动自查**：①借款扩张（现金覆盖不了利息）；②错误激励（按销售额奖励，接进"吞钱机器"）；③忽视外部变化（旧盈利源被替代而无人察觉）。

## A1 — 书中的应用 (Past Application)

### 案例 1：饮料装置公司的盲目扩张破产
- **问题**：某公司为餐馆提供饮料装置——每安装一个装置花费 2000 美元，每月从餐馆收到 100 美元原料费；表面是赚钱的商业模型。
- **方法论的使用**：拆开现金与利差：生产装置的钱是借的，而那 100 美元原料费的利润非常低，根本不足以支付借钱的利息——装置装得越多，亏得越深。
- **结论**：公司在"盲目扩张"中把亏损放大；增长越快、破产越近。
- **结果**："随着这个野心勃勃的年轻人不断地扩张他的业务，公司很快就入不敷出了，并且最终导致破产。贷方认为公司需要换一个新的CEO"（第2章，L6451–L6453，案例 b3-c10）。

### 案例 2：注模公司的错误激励
- **问题**：一家销售收入 1600 万美元的注模公司，以销售人员卖出去的塑料封装金额为依据奖励他们，而不论公司是否赢利。
- **方法论的使用**：当公司从两家大客户接到价值 400 万美元的新订单时，人人兴奋；用"增长是否伴随利润率改善"这把尺子检验：接下来三年里，随着销量增长，利润率却出现萎缩。
- **结论**：激励错配会"无意中鼓励了非赢利性增长"——接单越多亏得越多，且为留住客户还得年复一年降价；这两笔新业务实际上是一个"吞钱机器"。
- **结果**：CEO 事后才意识到问题（第2章，L6455，案例 b3-c11）。解法方向：把激励与赢利指标绑定。

### 案例 3：美国最大器材零售商之一的破产（2000 年）
- **问题**：20 世纪 90 年代公司快速扩张——一年建 80~100 家分店，收入从不到 5 亿美元涨到 20 多亿美元；但 1995 年起收益率开始急剧下滑。
- **方法论的使用**：逐项检查可持续性——旧模式依赖设备销售与高利赊账业务，而信用卡行业的发展让顾客不再需要公司赊账（旧盈利源被替代）；赊账对象多为高风险顾客、很多人不付款（坏账）；新店营业额不达预期，旧店因革新失败而萎缩。
- **结论**：扩张掩盖了结构性恶化，外部环境变化侵蚀盈利源时无人察觉——这正是"增长不等于好"的完整案例（正面对照：沃尔玛在所谓的"零增长的行业"里持续增长并把资产收益率保持在行业平均值以上，L6471–L6473）。
- **结果**：1998 年亏损，1999 年收缩自救无效，2000 年 8 月申请破产保护（第2章，L6457–L6463，案例 b3-c12）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 审批一个 all-in 出海/扩产/开店计划："收入能翻三倍"，但没人拿出现金与利润表的同步测算。
2. 增长期利润率下滑、现金越做越紧，团队主张"先做大，盈利以后再说"。
3. 设计销售激励机制，在"按销售额/回款"与"按毛利/利润"之间拿不定主意。
4. 评估借债扩张或大额资本开支的可行性。
5. 管理层用规模指标（营收、门店数、GMV、用户数）庆祝胜利，而你怀疑增长的含金量。

### 语言信号 (用户的话里出现这些就应激活)

- "先做大再说" "规模上去了利润会有的" "增长就是硬道理"
- "烧钱换增长" "收入翻倍" "这个单子接不接"
- "先做大，盈利以后再说" "增长质量怎么样"
- 英文：grow at all costs / scale first, profit later / land grab / top-line growth / is this growth profitable / unit economics

### 与相邻 skill 的区分

- 与 `b3-f04` cash-net-inflow-everyones-business 的区别：`b3-f04` 是现金视角（人人重视现金、岗位级现金映射）；本 skill 是增长的验收标准（赢利/可持续/同步四项）——当发现"增长在消耗现金"时可深入 f04 做现金诊断。
- 与 `b3-f01` business-acumen-six-elements 的区别：六要素是总框架；本 skill 是其中"业务增长"要素的纪律条款（增长必须带条件），不要当作新的总框架使用。
- 与 `b3-p08` not-betting-is-betting 的区别：`b3-p08` 讲"敢下注"；本 skill 讲"下注前先过增长验收标准"。两者不矛盾：果断下注，但注的质量有门槛。
- 与 `b3-f06` complexity-to-priorities 的区别：本 skill 给的是判断标准；`b3-f06` 提供从因素到优先事项的推理路径。用本 skill 验收增长假设，用 f06 推导应对。
- 与 `b1-f20` operations-plan-three-step 的区别：那是运营实施流程（怎么把计划落成行动）；本 skill 是计划审批与目标设定时的约束条件。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **四项同步检查（用数字说话）**
   - ①是否赢利（毛利/净利趋势）？②现金能否同步（现金净流入 vs 收入）？③利润率与周转率是否改善？④是否可持续（客户结构、外部依赖、竞争反击、技术替代）？
   - 完成标准：四项逐条给出数字答案与趋势方向。
   - 判停条件：若四项全否且无改善路径 → 建议停止或收缩，而不是加速；若处于危机生存状态 → 先保现金（`b3-f04`），本流程暂缓。

2. **检验激励设计**
   - 完成标准：能说出销售/业务激励指标与赢利目标的一致性；若激励只看金额/销量，给出修改方案（挂钩毛利、回款或利润贡献）。
   - 判停条件：发现激励错配且无法修改 → 该增长计划不应批准（激励会把理性员工变成亏损放大器）。

3. **三个失败机制自检**
   - 完成标准：对"借款扩张（现金能否覆盖利息）""错误激励（是否在奖励吞钱机器）""忽视外部变化（旧盈利源是否被替代）"各写一句"我们是否中招"及证据。

4. **把规模指标换成赢利质量指标**
   - 完成标准：管理看板上至少一个规模指标被替换（如用可比销售额、总边际利润、资产收益率替代收入总额）；为现金与利润改善定义验收线。

5. **若通过：转成优先事项并跟踪**
   - 完成标准：把增长机会转成 3~4 项优先事项（转 `b3-f07`），每项写明对现金/利润/周转的影响假设；把"增长的心理效应（激活组织）"标注为加分项而非理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 危机中的生存性收缩：此时不需要"增长验收"，先保现金与偿付能力（`b3-f04`）。
- 新兴行业的早期模式验证期（无收入或无利润的烧钱阶段）：本原则的用户是成熟经营体；对烧钱型商业模型直接套用会误判（BOOK_OVERVIEW：六要素对平台型/软件型/研发驱动型业务并不直接适用）。
- 非营利与使命型组织：目标函数不同，四项标准需要改写后再用。
- 用户要的是"如何讲好增长故事去融资"：本 skill 不提供叙事包装，只提供经营验收。

### 作者在书中警告的失败模式

- **b3-ce04 把规模当成功：为做大而扩张**："请不要把公司的规模作为其是否成功的衡量指标。奋力争取更多的营业额并不一定是好的经营方式"（L6457–L6466）。机制：增长会掩盖问题、带来心理激励，形成"增长=正确"的组织惯性；外部环境变化侵蚀旧盈利源时无人察觉。预警信号：增长计划与现金计划分离；新店/新业务不达预期仍继续铺开；董事会只问营收不问回报。
- **b3-ce05 错误激励制造非赢利性增长**（L6455）：激励只挂销售额 → 销售团队接进亏损订单并年年降价保客户 → 销量越大利润越薄。机制：人会对被测量的东西做功；激励指标与公司赢利目标脱钩时，员工理性地最大化个人收益并侵蚀公司收益。预警信号：销售激励只看金额/销量，不看毛利或回款；大单成交后利润率逐季下滑；客户议价年复一年压低价格而无成本改善。
- **b3-ce06 大额资本开支押注未验证的需求**（L6290）：米勒啤酒 4.6 亿美元新厂尚未投产，主要竞争对手安海斯布希就采取营销措施阻止其发展计划，公司现金净流入变成负数。机制：资本开支决策周期长、不可逆，依据常是"当前趋势外推"，而竞争者行为与需求波动不在模型内。预警信号：扩产计划基于份额将继续攀升的线性假设；没有竞争对手反击的预案；新项目未投产而市况已变。
- **b3-p04 并入原则**：不要把公司规模作为成功衡量指标（L6465–L6468）。

### 作者的盲点 / 时代局限

- **"顾客公平交易→忠诚→持续收入的自动链条"**：缺乏对定价权、竞争结构、技术替代的讨论（BOOK_OVERVIEW 未证假设 9）——增长的可持续性判断因此少了关键变量。
- **六要素的非普适性**：对平台型、软件型、研发驱动型业务（边际成本近零、网络效应、烧钱换市场）不直接适用；未讨论非营利与公共部门（册3 批判节）。
- **股东/CEO 顾问立场与幸存者偏差**：成功案例集中在作者有咨询关系的公司，失败案例只有寥寥几笔背景交代；"同样的标准为何在别的公司失败"没有控制比较（册3 批判节立场盲点）。
- **时代局限**：案例数据多为 1999–2000 年；今天的融资环境、订阅制、负边际成本模式与书中语境已有差异，四项标准需按模式改写。

### 容易混淆的邻近方法论

- "增长黑客"式增长工程：关注获客与转化实验，不设赢利门槛；本 skill 是它的上游约束。
- 精益创业的"经证实的认知→再规模化"：同样反对过早规模化，但判据是学习与验证；本 skill 的判据是现金/利润/周转/可持续——两者可组合使用。
- 战略增长矩阵（安索夫等）：回答"往哪个方向增长"；本 skill 回答"这个增长能不能要"。
- `b3-p03` 与 `b3-p04`/`b3-ce04`/`b3-ce05` 属同一家族：不要在组内互抢调用，统一由本 skill 承载。
