# R=M×V：资产收益率＝利润率×周转率

## R — 原文 (Reading)

> "资金周转得越快，收益率也就越高。事实上，资产收益率就是利润率乘以资产周转率。这是一个普遍的商业定理，可以简单表达如下：资产收益率=利润率×周转率，即R=M×V……这个公式的结果R以百分数的形式表达——比如8%、10%或者15%的收益率，是一个可以直接用来比较的简单数字。"
>
> — 拉姆·查兰，第2章（fulltext L6349–L6355）

> "资产收益率一定要高于你使用自己的钱或别人的钱（银行家或股东的钱）所付出的成本（所谓的资本成本率），这是商业运作的真理。如果资产收益率低于资本成本率（一般在10%或更高），就会引起投资方的强烈不满，因为管理层正在损害股东的利益，使股东的财富遭受损失。"
>
> — 拉姆·查兰，第2章（fulltext L6415）

> "20世纪80年代初杰克·韦尔奇在通用电气就使用了这项原则。他说，通用电气的任何一项业务，如果不能做到行业第一或第二，如果不能达到合适的股东投资收益率，就要被冻结或者卖掉。"
>
> — 拉姆·查兰，第2章（fulltext L6417）

---

## I — 方法论骨架 (Interpretation)

生意赚钱的效率可以用一个百分数衡量：**资产收益率 R ＝ 利润率 M × 周转率 V**。R 表示"用你的资产赚了多少钱"，可以跨公司、跨行业直接比较。ROA、ROI、ROE 在概念上完全一样，只是分母不同——资产、投入资本或股本；会算一个就会算三个。

这个拆解的价值在于"两条腿"：
- **M（利润率）**：赚钱的效率。高利润率模式（奢侈品、软件）靠定价与成本结构。
- **V（周转率）**：用资产的效率。低利润率行业（超市3%~4%、PC制造）靠高周转也能挣出高收益率——戴尔的存货只有6天、周转50次/年，利润率不高但收益率极高。

因此改进动作必须问"是提M还是提V"：提价降本改善利润率，清库存、改渠道、缩账期改善周转；两者乘出 R，只盯一条腿会漏掉另一半。作者强调"很多人都把注意力集中在利润率上，而忽视了周转率"。

使用纪律有三条：
1. **粗算比较**：好的CEO不追求精确性，用 R 与去年、前年、竞争对手和行业范围比，判断"是不是在它应该处于的范围内"。那些最好的公司税后资产收益率都大于10%。
2. **门槛判断**：R 必须高于资本成本率（一般10%或更高），否则是在损害股东财富；达不到的业务要么提高收益率（从 M、V 两方面入手），要么剥离——韦尔奇"数一数二"（行业地位＋股东投资收益率的双门槛）就是这条原则的组合管理版。
3. **不用怕不懂财务**：作者带MBA学生到马那瓜湖露天市场，一个利润率仅5%、以34%年息借钱的卖衣女商贩靠"每天把货卖掉"（高周转）生存——她用"在空气中画圈"的手势表达周转。R=M×V 是未经教育的实践者也在使用的心算模型。

## A1 — 书中的应用 (Past Application)

### 案例 1: 马那瓜湖露天市场的女商贩（高利贷下的高周转）
- **问题**: 作者要证明"资产收益率不需要MBA才能理解"。
- **方法论的使用**: 现场访谈一位推手推车卖衣服的妇女：她以每月2.5%的利率借钱进货（利滚利年利率约34%），而利润率只有5%左右——单看利润率必死。问她怎么办，她用左手托着右肘、对着空气画了几个圈：货物快速周转。
- **结论**: 她靠"每天把货卖掉"的高周转覆盖高息并生存；R=M×V 是实践者本能使用的心算模型，不是财务专家专利。
- **结果**: 成为全书解释"低利润率靠高周转生存"的核心案例。

### 案例 2: 戴尔：现金机器与低存货周转
- **问题**: 一家低利润率的PC公司，如何成为创造巨大财富的公司？
- **方法论的使用**: 用 R=M×V 拆解戴尔模式——顾客在订购时、收货前用信用卡付款；公司通常在收到配件30天后才支付供应商；只保持6天存货（按订单定制）；存货周转50次/年，内部使用的投入资本收益率高达243%（为上一年两倍）。
- **结论**: 迈克尔·戴尔不是靠高利润率，而是看到低利润率行业（超市3%~4%）靠周转也能有高收益率，从而发现了 R=M×V 的另一半；业务增长越大，产出现金越多。
- **结果**: 戴尔成为全书最主要的正面样板；多家公司（含联合技术等）前往参观学习。

### 案例 3: 福特 vs 捷威：同一年两张"健康表"
- **问题**: 两家公司都能赚钱，怎么比较质量、怎么推出行动重点？
- **方法论的使用**: 用公开数据算 R=M×V——福特：税后利润率4.2%、资产周转率1.3，R约5.5%；捷威：税后利润率4.9%、资产周转率12.6，R为61.7%。再对照增长、现金与市场份额。
- **结论**: 两家利润率几乎一样，收益率差出一个数量级——差别几乎全在周转；由此推出的行动重点完全不同（福特→提生产率与顾客满意；捷威→扩份额），且"不需要很多数字、不需要高精确度"即可获得全景图。
- **结果**: 成为第3章用数字驱动行动的示范案例（并自然衔接到公司全景诊断七问）。

## A2 — 触发场景 (Future Context) ★

### 用户会在什么情境下需要这个 skill?

1. 对比两家公司（或两个事业部/两条产品线）的收益率指标，想判断"同样15%，哪家质量更高、风险结构如何"。
2. 某项业务利润薄，老板想砍掉，但用户怀疑"是不是还能靠周转救"；或反过来，某业务利润率高但资金占用惊人。
3. 需要向非财务背景的团队解释"为什么要清库存、缩账期"，需要一把直观的尺子。
4. 做业务组合决策（保留/改善/剥离），需要一条比"赚不赚钱"更硬的判据。
5. 用户第一次接触 ROA/ROI/ROE 三个缩写，想知道它们的区别与共同本质。

### 语言信号 (用户的话里出现这些就应激活)

- "两家公司收益率一样，哪家更好？" / "same ROE, which is better?"
- "R=M×V / 资产收益率怎么拆" / "decompose ROA, margin × turnover"
- "该提利润率还是提周转率？" / "improve margin or turnover?"
- "资本成本率/门槛收益率" / "cost of capital, hurdle rate"
- "低利润率的生意为什么也能赚钱？" / "low margin business, still profitable?"

### 与相邻 skill 的区分

- 与 `business-acumen-six-elements`（b3-f01）的区别: 本 skill 是六要素中"资产收益率"一格的深入工具；用户要全景用 b3-f01，要拆收益率用本 skill。
- 与 `cash-net-inflow-everyones-business`（b3-f04）的区别: 本 skill 看"用资产赚钱的效率"（收益率口径）；b3-f04 看"现金流入流出"（生存口径）。利润高、收益率好也可能被现金拖死，两者互补但不可互换。
- 与 `profitable-sustainable-growth`（b3-p03）的区别: 后者是增长纪律（为什么增长、能否持续）；本 skill 是收益率结构与门槛判断。
- 与 `complexity-to-priorities`（b3-f06）的区别: 后者把分析结果转成3~4项优先事项；本 skill 产出的是"哪条腿有问题"的诊断。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **取三个数，粗算 R**
   - 需要：销售收入、税后利润（算 M＝税后利润/销售收入）、资产量（算 V＝销售收入/资产）；换成投入资本或股本即得 ROI/ROE。
   - 完成标准: 算出 M、V、R 三个数（保留整数百分比即可）；数据不全时明确列出缺口与获取渠道（年报、IR部门、公司网站）。
   - 判停条件: 若 R 远低于资本成本率且业务无改善空间，直接进入步骤5的剥离讨论。

2. **做横向与纵向比较**
   - 与去年/前年比（趋势）、与竞争对手比（位置）、与行业最好公司比（标杆）。
   - 完成标准: R 至少有一个对比值，并给出"变好还是变坏、在什么范围内"的判断。

3. **拆出结构：问题在 M 还是 V**
   - 检查毛利率变化在提示什么（竞争压价？成本上升？顾客结构变化？）；检查存货与资产使用效率（存货天数、资金占用、渠道与账期）。
   - 完成标准: 明确写出"主要短板在 M / 在 V / 两者都有"，并各配一条事实证据。

4. **设计两条腿的动作**
   - M 侧：提价能力、产品组合（如福特把部分小汽车产能转向更赚钱的SUV/轻型货车）、成本结构。
   - V 侧：清库存与过时风险、缩短生产与交付周期、渠道与账期（低存货反而能利用零部件降价扩大优势）。
   - 完成标准: 至少各一条具体动作，含责任人与衡量指标；不得只开一条腿。

5. **对门槛做去留判断**
   - 把 R 与资本成本率（一般10%或更高）比：高于则继续投入或加速；低于则二选一——限期提高收益率（从 M、V 入手）或剥离，把资本还给收益更高的用途。
   - 完成标准: 给出"保留并改善 / 限期改善否则剥离 / 立即剥离"的结论及依据；引用组合管理先例（韦尔奇"数一数二"）时说明其双门槛（行业地位＋股东投资收益率）。
   - 判停条件: 若剥离涉及裁员、资产处置、证券信息披露，转交法务/合规与公司程序处理，本 skill 不提供处置方案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 当作精确财务分析：作者明确"好的CEO并不是很关注精确性"，框架用于直觉判断与比较；正式估值、并购定价、审计口径须用专业财务方法。
- 拿 R 的高低直接否定行业：不同生意的 M、V 结构天然不同（奢侈品 vs 超市），跨行业只比结构不看绝对值。
- 用它替投资者做投资决策或替公司做资本市场叙事：涉及预期管理与信息披露的合规红线（系列级边界：不得建议任何形式的数字操纵；估值沟通须符合证券法规）。
- 忽略资本结构与杠杆：ROE 可被负债放大，虚高的 R 可能是杠杆或会计口径造成的，须回到资产与投入资本口径核对。
- 新经济/平台型业务直接套用：六要素体系对边际成本近零、烧钱换市场的模式不直接适用（BOOK_OVERVIEW 批判），需先补单位经济逻辑。

### 作者在书中警告的失败模式

- **只看利润率、忽视周转率（b3-ce03）**："很多人都把注意力集中在利润率上，而忽视了周转率"；只通过提价/降本改善利润率，收益率的另一半被浪费——低利润率行业尤甚（超市/PC制造本就靠周转），且会计利润不显示资金被占用的代价。
- **存货积压与产品过时的双重危险（b3-ce20）**："对于电脑公司，产品过时是一个巨大的危险，产品的价格会不断下滑。如果存货很少，那么由于产品过时而导致滞销的危险就很小"；高存货既锁定现金又面临跌价，两头受损，低存货反而能顺势利用零部件降价扩大优势。
- **把规模当成功（b3-ce04）**：为做大而扩张，回头发现现金、利润率与周转率全面恶化（器材零售商一年扩张80~100家店后破产）；增长会掩盖问题。
- **做不到行业第一或第二就该冻结或卖掉**：这是有前提的组合管理规则（行业地位＋收益率双门槛），不是简单的规模排名；误用会把尚在培育期但战略必要的业务过早砍掉。

### 作者的盲点 / 时代局限

- **杜邦分解并非作者原创**：R=M×V 是财务教科书的经典分解（杜邦分析）；本单元的独特性在于面向非财务读者的粗算用法、两条腿的行动逻辑与街头摊贩到跨国公司的同一把尺子——不能把它当查兰的原创发现。
- **门槛数字的时代印记**："税后资产收益率大于10%"与"资本成本率一般在10%或更高"是2001年前后美国市场的经验值；利率与资本成本环境变化后数字需重设。
- **GE 模范已被后来的历史反证**：书中把 GE 与韦尔奇"数一数二"当权威范例；GE 2018年跌出道指、2021年拆分，说明该原则在组合管理与创新投入之间的长期张力（系列级批判：成书窗口与美国大公司案例偏差）。
- **未处理无形资产的度量**：模型以资产/存货为核心，对研发、品牌、数据等无形投入的解释力弱；知识密集型企业需补充口径。
- **行为盲区**：作者只说"要比较"，未讨论管理层为达标而操纵口径（如"分类为一次性费用"）的激励扭曲。

### 容易混淆的邻近方法论

- 与 `business-acumen-six-elements`（b3-f01）：总框架 vs 单要素工具；用户没有六要素概念时先给地图，再拆 R。
- 与 `cash-net-inflow-everyones-business`（b3-f04）：收益率口径 vs 现金口径；"有利润没现金"的困境要靠 b3-f04 解决。
- 与 `profitable-sustainable-growth`（b3-p03）：本 skill 判断"效率够不够"，p03 判断"增长值不值得"；组合决策时两者并用。
- 与 `company-panorama-seven-questions`（b3-f10）：七问是逐要素数据化体检，其中 R=M×V 是必答项之一；本 skill 是把该项做深的工具。
