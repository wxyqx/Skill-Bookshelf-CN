# 表现不佳者分层处置流程

## R — 原文 (Reading)

> "评价一个人员选育流程的标准就在于它是否能够清楚地将这两类人区别开来，以及它是否能够帮助领导者们做出可能会给人们带来一些痛苦的决定。"
>
> — 博西迪/查兰/伯克，第6章（L1814）

> "这位CEO是一个非常聪明而正直的人，他很欣赏斯坦，但缺乏足够的勇气面对眼前出现的问题，他没有及时地解雇斯坦，从而最终葬送了整个公司。"
>
> — 同上，第5章（L1411）

> "让人们以一种体面的方式离开自己的工作岗位是强化公司执行文化的一个重要手段。"
>
> — 同上，第6章（L1830）

## I — 方法论骨架 (Interpretation)

处置表现不佳者不是"要不要狠心"的问题，而是一次分层判断加一套体面程序：

1. **先分层**：把两类人分开——岗位不匹配（能力在，但岗位要求与其特质不符）与确实不胜任（长期不能完成目标或领导力不达标）。评价一个人员选育流程的标准，正是它能否清楚地区分这两类人。
2. **判定要基于事实**：证据来自多份投诉、加班记录、结果与完成任务方式的分离（是不是靠牺牲长期利益换来短期数字）；而不是印象与好恶。
3. **处置要快速而公平**：快速——拖延本身就是最大成本（斯坦案中拖延的代价是公司被兼并；老副总裁案中 CEO 自己被架空后被迫离开）；公平——给足补偿、坦诚对待推荐请求、以体面方式让其退出。
4. **三条路径**（书中示范）：不匹配但有长项者调岗再试（鲍勃）；长项明确但不宜任更高职位者留任原岗、坦诚告知（希德）；确实不胜任者给予补偿并帮助其体面离开（多格）。
5. **诊断闭环**：用人失当通常有四个障碍——知识缺乏（凭印象选人）、勇气缺乏（明知不胜任不行动）、心理舒适（只用自己喜欢/顺从的人）、责任感缺乏（不跟进人才培养）。处置流程要与这四项自检配合使用。

## A1 — 书中的应用 (Past Application)

### 案例 1: 鲍勃、希德、多格——三种处置路径的示范
- **问题**: 三人表现均未达预期：鲍勃（优秀制造人员被任命为工厂经理后无法胜任）、希德（出色的推销员，但知道自己永远不可能被任命为总经理，且事实上不适合）、多格（从不尽全力工作，属于聘任错误）。
- **方法论的使用**: 按"人—岗匹配度＋长项"分层：鲍勃技术优良、人缘极佳，把他调换到一个完全不同的岗位，希望他能取得新的成功；希德坦诚沟通——长项在客户关系管理而不在战略或运营，他选择留在原岗兢兢业业；多格则是解雇，但采用建设性程序。
- **结论**: "有时在别无选择的情况下，你必须解雇某些人，但我建议你，一定要尽量使这个过程富有建设性。"
- **结果**: 多格获得一年薪水（承认聘任责任）、坦诚但不造谣的推荐、体面退出方式（对外称"希望改变一下工作"）；公司关系与声誉得到保护。

### 案例 2: 斯坦——拖延两年，公司被兼并
- **问题**: 精工元件制造公司从外部聘请两位 CEO 候选人，斯坦负责北美业务（公司 80% 利润来源），他演讲极富煽动性但第一年就没能完成目标，成本结构失去优势、边际利润与现金流下降。
- **方法论的使用**: 作者把它当作"勇气缺乏"这一障碍的标本：CEO 认为"斯坦还是新手，需要时间"，第二年仍不达标；董事会要求解雇时为时已晚，此时股价不到原来一半。
- **结论**: "这样的悲剧每天都在上演着，勇气的缺乏使得很多公司成为优柔寡断的牺牲品"；不能胜任者一旦进入高级领导层，"他很可能会毁掉整个组织"。
- **结果**: 收购行动六个月内完成，这家公司彻底被兼并。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一位老员工业绩下滑、资历深人缘好，用户犹豫直接解雇还是留下。
2. 一位下属能完成数字但行为恶劣（辱骂同事、逼员工加班），用户不断用"他还很能干"说服自己。
3. 用户已经拖延了几个月，反复准备谈话却总在临门退缩。
4. 用户想给某位不适合当前岗位的人找出口，但不知道怎么谈、怎么给补偿。
5. 用户做年度评估时发现某人连续多个考核周期不达标，需要决定处置路径。

### 语言信号 (用户的话里出现这些信号就应激活)

- "这人不能用了，但实在不好开口。"
- "业绩下滑的老员工，留着还是请他走？"
- "拖了很久不敢谈 / 我该不该解雇他？"
- "underperformer" / "let someone go" / "how do I handle a failing employee"

### 与相邻 skill 的区分

- 与 `b3-f12 coaching-two-tracks` 的区别: 教练双轨用于"人还有救、需要用辅导补齐能力"的情形；本 skill 用于"已经判断出人岗不匹配或不胜任、需要做处置决定"的情形。
- 与 `b5-f30 leadership-deficit-four-causes` 的区别: 后者诊断的是组织层面为什么会出现缺陷领导者（选错、留太久等四因）；本 skill 是面对具体个人时的分层与处置程序。
- 与 `b1-f12 talent-review-meeting-mrr` 的区别: MRR 是做出判断的会议机制；本 skill 是判断之后如何落地处置。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先分层：不匹配，还是不胜任？**
   - 完成标准: 写出岗位的 3–4 条基本要求与该人的实际表现对照表；判断属于"能力与岗位要求错配"还是"长期不能完成目标/领导力不达标"。

2. **排除组织因素再下结论**
   - 完成标准: 逐项检查薪酬是否到位、职责是否清晰、资源是否足够、上司是否称职；确认问题不在组织侧，才进入个人处置。

3. **用事实取证，而不是印象**
   - 完成标准: 收集具体证据：多份投诉、加班记录、业绩与完成任务方式的分离、连续几个周期未达标的事实；证据要能被当面陈述。

4. **透明沟通，给对方知情与选择**
   - 完成标准: 进行正式谈话，明确告知问题、给出改进要求与期限，或给出调岗/退出选项；谈话内容留下书面记录。
   - 判停条件: 若对方是"能完成任务但行为恶劣"型，先给二选一（改变行为或离开），并附行为证据（书中示范为十份投诉与加班记录）。

5. **选择处置路径并执行到位**
   - 完成标准: 三条路径之一——调岗再试（附观察期）、留任原岗（坦诚说明长项与天花板）、体面退出（补偿、坦诚推荐、尊重性对外说法）；每条路径都有时间表与责任人。

6. **合规检查与收尾**
   - 完成标准: 按当地劳动法与公司程序复核流程；提供转岗或改进机会；书面记录完整；避免在情绪化状态下做决定。
   - 判停条件: 涉及裁员/解雇时，本 skill 不构成人力资源法律意见，须由 HR 与法务复核（见 B 段）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只是短期情绪冲突、一次意外失手、或外部环境突变造成的未达标——先在正常绩效沟通中解决。
- 用户想处理的人其实掌握关键信息/刚经历重大变故：直接套用流程会造成不可逆伤害。
- 用户把本 skill 当作"如何逼人走"的手册：书中路径以体面与公平为前提，不得输出规避补偿、制造离职理由类建议。

### 作者在书中警告的失败模式

- **不敢让不胜任者离开（勇气缺乏）**: 明知不胜任却以"他还需要时间"为由拖延，代价是市场份额、毛利、现金流全面恶化，直至公司被兼并或 CEO 被解职（b1-ce09）。
- **情感脆弱导致的用人决策变形**: 无法解雇老副总裁（CEO 自己反被架空）、聘人只求忠诚不宜强、对"行为恶劣的能人"一忍再忍（b1-ce20）。
- **仅提拔忠诚者（心理舒适因素）**: 用绝对忠诚取代能力标准组队，把优秀但敢言者边缘化（b1-ce08）。
- **把顶尖个人贡献者提拔为管理者**: 以个人业绩作为晋升依据，销售冠军被提拔为销售经理后彻底失败——他可能既无意愿也无能力招聘与培养下属（b3-ce10，跨册反例）。
- **思维定式不改（"会上同意、会后照旧"）**: 要求习惯于旧做法的经理改变关键指标（如存货周转率 2 次→30 次），口头配合但行为不变；判定"能不能改"要核查思维定式，而非听表态（b3-ce11，跨册反例）。
- **把领导岗位当作奖励/成就巅峰**: 以晋升作为个人业绩的回报，而不考虑其是否具备领导他人的条件，结果是个人与组织双输（b4-ce03，跨册反例）。

### 作者的盲点 / 时代局限（含风险提示）

- **风险提示（来自 b3-ce09，伦理/法律边界）**: 处理方式必须尊重当事人、给出转岗/改进机会、遵守当地劳动法与公司程序；书中强调"使他在其他公司找到能施展的位置"的正向结果，但操作中解雇/调岗均有合规要求。下游 skill 不得输出"如何逼走员工"类建议。
- **风险提示（来自 b3-ce15，伦理边界）**: 作者强调"直面"不等于粗暴；必须给对方知情、解释与选择，并避免在情绪化状态下做决定。
- **表现为"不合格"的判定标准主观**: 书中把"没能阻止工会成立"等也算作表现不合格，说明标准由上司界定；须警惕把管理偏好包装成业绩问题。
- **法律与治理风险被轻描淡写**: 让"表现尚可但没有潜力"的现任让位、以年龄/剩余年限作选拔理由等操作，在劳动法与反歧视法规下风险很高；书中只提示"如何尊重地做"（BOOK_OVERVIEW 最强反对意见 6）。
- **美国大公司语境**: "一年薪水补偿""体面说法"等做法须按当地法律与惯例重新设计。

### 容易混淆的邻近方法论

- 与"绩效改进计划（PIP）"的区别: PIP 是单一路径；本 skill 强调先分层（调岗/留任/退出三选一），PIP 只是其中一条。
- 与"末位淘汰"的区别: 本 skill 不采用相对排名，处置依据是岗位要求与个人表现的匹配度。
