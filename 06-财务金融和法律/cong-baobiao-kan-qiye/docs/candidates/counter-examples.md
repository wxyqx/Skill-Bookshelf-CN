- id: e03
  type: counter_example
  title: 机械套用美国比率体系及其经验值（流动比率2:1等）会完全误判中国企业
  source_chapter: 第4章、第5章
  source_quote: |
    "该公司流动资产与流动负债的比率（流动比率）约为1.1∶1，远远小于一般美国教材中强调的2∶1这一比较安全的经验数值。"
  summary: |
    警告：把美国教材的经验数值（流动比率2:1、速动比率1:1、资产负债率70%警戒线）当安全标准直接套用于中国企业，会得出"偿债能力差、风险大"的完全错误结论——教学实验中七名学过报表分析的研究生对一家竞争优势极其明显的优质公司正是这样误判的（流动比率约1.1、速动比率约0.9、资产负债率约80%被读成高经营风险高财务风险）。更深层的原因有二：其一，美国主流比率分析基于美国资本市场以合并报表为主的披露特征、服务于投资者估值，从设计目的上就不回答"企业管理得好不好、竞争力在哪里、风险在何处"的问题，用错工具问错问题；其二，经验值没有考虑行业、经营周期、上下游占款能力等中国情境。孤立计算的流动比率、周转率、资产负债率等传统比率脱离企业实际、无法揭示战略，本章的经营资产/投资资产与资本引入框架即是对这一失败模式的替代方案。
  tags: [counter_example, ratio-analysis, experience-value, purpose-mismatch]

- id: e04
  type: counter_example
  title: 比率计算的口径陷阱：原值/净值、合并/母公司与中国披露模式障碍
  source_chapter: 第4章、第6章、第13章
  source_quote: |
    "有的不知道应该用合并报表的数据计算还是用母公司报表的数据计算（如存货周转率）；有的不知道是用原值计算还是用净值计算（如固定资产周转率）。"
  summary: |
    失败模式：传统比率分析只给公式不给口径，面对真实中国上市公司处处踩坑。①固定资产周转率必须用原值：净值随折旧递减会使周转率虚增，极端情况下净值为零但仍在使用时周转速度无穷大，明显不合逻辑，而许多教材故意不写明用原值还是净值；②面对集团公司不知道该用合并报表还是母公司报表数据（如存货周转率），母公司资产中大量货币资金与投资资产还会使总资产周转率、流动资产周转率彻底失去意义；③中国"集中披露"模式只在地主表给减值净额、明细在附注，直接用净额算周转率会错（应回到附注看减值前原值，不可得时宁可近似说明或不算，恒瑞案例中作者对失真大的应收账款周转率选择不计算）。警告：脱离口径教育的比率公式训练培养不出真实分析能力，硬算失真比率不如不算。

  source_chapter: 第4章
  source_quote: |
    "有的公司自己并不从事经营活动，而是从事投资管理活动。在这种情况下，企业利润表的利润支撑点肯定是投资收益，而总资产周转率、毛利率、销售净利率等均没有了计算的数据基础。"

  type: counter_example
  title: 控股股东/关联方占用资金：从大股东提款到内控全面失灵
  source_chapter: 第5章、第8章
  source_quote: |
    "如果该公司的这种状况继续发展，就会出现企业经营好→大股东提款→小股东受到实质伤害→企业财务负担加重的情况。"
  summary: |
    失败模式：控股股东利用控制财务部门的便利，以公司名义贷款转作自用，账面表现为贷款（负债）和其他应收款（不良资产）同时增加，利息还由公司承担；银行因只看程序和利息偿付而不设防。真实案例同样触目：ST新生在海航集团指令下被关联方长期占用巨额资金，年底以"资金转回—买理财—回流"的循环制造假象应付监管检查与关账并虚假披露；辅仁药业控股股东违规占用资金16.36亿、违规担保，债务逾期后2023年退市。教训：只要与控股股东和关联方有关的"业务"，企业所有内控制度都可能失灵——这不是财会人员的问题而是治理问题；上市公司资产属于全体股东，即便母子公司体制内也要警惕非经营性资金往来，此类占用直接摧毁企业的分红能力与战略执行力。识别信号：合并报表其他应收款异常、资产被关联方长期占用、股权结构与治理格局突变。

- id: e08
  type: counter_example
  title: 现金充裕仍过度债务融资与存贷双高："企业不是饿死的，而是撑死的"
  source_chapter: 第5章、第11章、第13章
  source_quote: |
    "现实中往往有这样的企业：明明现金存量和增量根本用不完，还在不断增加各种贷款。……企业长期超出正常需求所进行的债务融资，除了导致企业利息费用增加、总资产周转率下降、总资产报酬率下降等后果外，不会对企业的财务状况做出任何积极贡献。"
  summary: |
    失败模式：融资能力强的企业反而容易死于钱多——竞争优势明显、根本不需要借款的企业在金融机构放贷压力与诱惑下不断增加贷款，资金闲置拉低资产报酬率，管理层又有把钱花出去的冲动，用于不需要的固定资产投入或盲目并购，过度融资是过度投资的推手，很多企业"因为钱多而死"。识别信号（五项财务表现）：金融性负债长期居高且股东入资频繁；货币资金与在建工程、固定资产增长过快且固定资产原值增长显著快于营业收入；高商誉；财务费用长期居高；筹资流入在逻辑上支持投资流出。对"存贷双高"（货币资金充裕却仍有借款）要区分情形：可能是照顾银企关系的"面子借款"或低成本融资套利（恒瑞案例的温和解释），但若伴随高金融负债与高利息费用，则是过度融资甚至资金被占用的危险信号（乐视网、辅仁药业类企业）；识别关键是借款有无真实经营投资需求、利息与存款收益是否匹配。另注意与集团统一筹资模式的区别——母公司借款可能是为子公司，不能一概而论。
  tags: [counter_example, over-financing, over-investment, cash, debt, 存贷双高]

- id: e09
  type: counter_example
  title: 高经营性负债/流动资产小于流动负债的双向误读：既可能是"两头吃"优势，也可能是经营困难
  source_chapter: 第5章、第11章
  source_quote: |
    "一般来说，不能仅凭流动负债高于流动资产就认定企业有风险：如果企业在市场竞争中具有较强的上下游关系管理能力并能够持续发展，由于经营性负债高而导致流动资产不抵流动负债，这应该是企业的竞争优势而不是风险点。"
  summary: |
    同一报表特征背后可能是相反的企业状态，两个方向都会误读。方向一：流动比率小于1不等于风险——经营性负债主导（预收、应付为主）且企业具备持续"两头吃"能力时，恰是竞争优势（占用上下游资金、资源利用效率高）；只有流动负债以金融性负债为主并出现偿债压力时才是真风险（顾地科技案例需先看债务结构）。方向二：反过来也不能把经营性负债长期居高不下一律读成竞争优势——当企业经营活动缺乏市场竞争力、资金周转不灵难以为继时，同样会表现为经营性负债长期居高不下，那是被动拖欠的经营严重困难而非资本引入战略的结果。区分标准在于企业经营活动是否有竞争力、现金流转是否正常、优势是否"持续"而非一年临时状态。
  tags: [counter_example, misreading, liquidity, 经营性负债, 两头吃]
  origin: [B-eb06, D-xd08]

  title: 应收账款周转率公式的系统性错误
  source_chapter: 第6章
  source_quote: |
    "请读者注意：不要使用这个公式计算，因为无论怎样计算都是不正确的。"
  summary: |
    失败模式：用营业收入除以应收账款（或其平均余额）计算周转率。四重错误：应收票据、应收账款、应收款项融资、预收款项与合同负债五大结算项目共同推动收入；营业收入不含增值税而收款含；应收款项融资多由应收票据转来被遗漏；报表披露扣减坏账准备后的净值而周转的是原值（企业间坏账准备估计差异极大）。即便补上增值税税率也会遇到其他问题。应改为看各债权项目期末期初差额判断回款状况，或企业内部直接计算应收账款加权平均天数。

- id: e13
  type: counter_example
  title: 高商誉高评估增值并购的"纸面资产"陷阱与业绩反噬
  source_chapter: 第6章、第7章
  source_quote: |
    "如果收购方在收购过程中代价过大，产生了过高的商誉或者无形资产评估增值，则收购方未来的财务业绩压力将是巨大的：居高不下的商誉和无形资产评估增值的'纸面'价值对收购方持续高质量发展的财务业绩是一个巨大的威胁。"
  summary: |
    失败模式（蓝帆医疗案例的教训）：发股融资→高对价并购（约60.5亿控制性投资产生63.61亿商誉，被收购企业净资产23.31亿被评估为-0.52亿）→承诺期内业绩"看上去很美"→承诺期后业绩变脸→商誉减值集中爆发（2020年17.55亿+2021年16.98亿，减值总额远超被并购企业三年净利润之和），即便按10年摊销测算年摊销6亿以上就足以让企业由盈转亏。复星医药案例同样显示：并购形成的商誉与无形资产评估增值（某无形资产增值约98倍）只是扩大合并资产规模的"纸面资产"，不能推动被收购企业收入增长，导致"营业收入因并购而增长，经营资产报酬率却难以改善"，还会因摊销或突然减值拖累利润。警告：不能被并购当年的收入、净利润增长迷惑，要看核心业务盈利能力是否实质改善；商誉不摊销只做减值测试的制度安排，既维持承诺期内利润表象，也为用减值调节利润留下空间。
