# Scanner B（第5-6章）候选

## 第一部分：章节 digest

### 第5章 看战略

本章核心论点：资产负债表蕴含丰富的战略信息，但以"资产=负债+股东权益"等式建立的传统报表存在"战略缺失的先天不足"，必须跳出会计概念束缚才能读出战略。作者依次展开五个分析路径：(1) 表外资源——资本资源、市场资源（产品市场让企业"走"、证券市场让企业"飞"）、人力资源（人手/人才/人物）等不入账资源同样重要；(2) 资产结构战略——把母公司资产剔除货币资金后按对利润的贡献方式分为经营资产与投资资产，据此把企业分为经营主导型、投资主导型、经营与投资并重型，资产规模与结构就是资源配置战略的实施结果；(3) 控制性投资扩张效应——用"合并报表数小于母公司报表数"的差额识别控制性投资占用的"基本规模"（长期股权投资+其他应收款+预付款项等），用合并与母公司资产总额之差衡量撬动效应；(4) 资本引入战略——把负债和股东权益按来源分为经营性负债、金融性负债、股东入资、留存利润四类，对应经营驱动、债务融资驱动、股东驱动、利润驱动、并重驱动五种类型，并强调企业发展真正的动力机制在报表右边；(5) 立场与集团管理——站在全体股东还是控股股东立场会得出不同战略判断；通过母公司与合并报表的数据差异可识别集团的债务筹资、货币资金、业务关系、销售费用、管理费用、研发费用等管理模式。

### 第6章 看经营资产管理与竞争力

本章把经营资产的管理质量与企业的竞争力直接挂钩。第一，货币资金存量管理：企业现金用于资本性支出与日常周转两种支付，资本性支出取决于战略安排、绝不能靠经营活动现金流量支持而须另行融资；日常周转现金存量取决于核心利润的现金能力、融资环境和管理者特质，"保存多少现金存量是没有最佳答案的"。第二，以存货为核心的上下游关系管理，核心是"两头吃"能力：购货付款看存货与预付款项、应付票据、应付账款的对应关系；销售回款看商业债权与合同负债（视同预收款项）的动态，并论证了传统应收账款周转率公式不成立的四点理由，主张看期末期初债权差额。第三，固定资产利用：周转率计算必须用原值；建立"固定资产原值—存货—营业成本—核心利润—经营净现金流量"的分析链条，并给出经验值——经营性非流动资产不太重时，核心利润（加其他收益）产生的理想经营净现金流量是核心利润的1.2~1.5倍。第四，资源管理的综合效应用总资产报酬率和净资产收益率考察，强调自创无形资产游离于报表之外、须综合分析。第五，高商誉并购的三重含义（买方高预期、卖方高业绩对赌、买方高风险），并以蓝帆医疗收购CB Cardio为例展示巨额商誉减值对收购方持续业绩的巨大威胁。
