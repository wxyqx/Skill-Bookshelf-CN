# 业务如何逐笔进入三张报表（推演教学）

## R — 原文 (Reading)

> "把资产负债表概括为底子，即企业的家底；把利润表概括为面子……把现金流量表概括为日子。"
>
> — 张新民，第1章

> "强化一下对企业的三张报表项目之间以及三张报表和业务之间的内在联系的理解。"
>
> — 张新民，第2章

> "企业的利润必须带来相应的现金流量，否则利润就可能是虚的。"
>
> — 张新民，第2章

## I — 方法论骨架 (Interpretation)

这是全书的地基：先建立三张报表的心智模型，再用"逐笔业务过三表"的推演把模型焊牢。分四块。

### 1. 三表通俗定位：底子、面子、日子

- **资产负债表 = 底子 / 实力**：特定时点的家底存照——企业能用货币表现的资源有哪些、归谁（债主还是股东）。它是纲：利润表和现金流量表其实都是它的展开说明（利润表解释盈余公积与未分配利润从期初到期末的变化，现金流量表解释货币资金项目年度内的变化）。
- **利润表 = 面子 / 能力**：一段时期内资源运用赚不赚钱。企业家最在意脸面，所以**造假的主战场一定是利润表**——底子和日子更难粉饰。
- **现金流量表 = 日子 / 活力**：钱从哪来（经营/投资/筹资）、花到哪去，反映企业实际生存状态。有面子不代表日子过得下去。

由此得到阅读策略：三表互证，"有没有家底 → 能不能赚钱 → 日子过得活不活"递进判断。注意同一概念跨表口径不同（现金流量表的"现金"≠资产负债表的货币资金；两表中"投资"内涵也不同），不能跨表直接划等号。

### 2. 业务逐笔过三表的推演方法

从三张空白报表出发，按企业生命周期把业务一笔笔"落账"：**股东入资 → 银行借款 → 买地 → 买设备 → 购货 → 赊销**，再到**对外投资扩张**。每笔业务问三个问题：

1. 动没动**资产**（哪个科目、增还是减）？
2. 动没动**负债和股东权益**（钱从哪来、权益变没变）？
3. 动没动**利润和现金**（有没有对外交易产生损益、现金流量表记不记）？

两条底层规则：①单纯的资产形态变化（不涉及对外交易、无增值减值）不改变资产总量，更不动负债和股东权益——左边的变换不惊动右边；反之资产毁损消失并不消灭负债，这就是"资不抵债"的机理（资产亏光而负债仍在）。②凡与外部有货币往来必入现金流量表；凡是与钱有关的业务先看钱的流向。

### 3. 利润与现金为何背离：机理

利润表按**权责发生制**确认，现金流量表按**收付实现制**确认。赊销当期即可确认收入和毛利（面子立刻有），但现金分文未进（日子照样紧）。所以利润必须带来相应的现金流量才算数；有利润无现金时，利润通常藏在**应收款项或存货的增加**里，应沿这两个项目追查。利润高而经营现金流长期入不敷出，是赊销过度、市场能力不强甚至虚假销售的风险信号——这正说明"面子"最易粉饰，要用"日子"来检验。

### 4. 企业各阶段报表的变化

- **设立**：股东入资+借款 → 资产负债表两边同增，利润表空白，现金流量表只有筹资活动流入。
- **经营**：购货、生产、销售逐笔展开三表；赊销开始制造利润与现金的时间差。
- **扩张**：母公司对外投资，子公司吸纳少数股东入资、独立负债、自身盈利积累——母公司报表分毫未动，合并报表却庞大起来（"以小博大"的杠杆扩张）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 六项业务设立与经营的报表推演（第2章教学案例）
- **问题**: 一家新设企业从设立到经营，六笔业务如何落进三张报表？
- **方法论的使用**: 从三张空白表起逐笔推演：股东入资2000万、银行借款1000万（均只动资产负债两边）、400万购土地使用权、600万购设备房屋、200万购存货（资产形态变化）、账面100万存货作价150万赊销。
- **结论**: 入资与借款不影响利润表；赊销产生毛利50万但现金流入为零，收入与成本确认同时变动股东权益——直观证明"有利润不等于有现金流量"。
- **结果**: 学员建立起"每笔业务问三个问题"的思维模板，理解了利润与现金背离的账务根源。

### 案例 2: 800万元撬动1500万元资源的扩张推演（第3章教学案例）
- **问题**: 母公司投800万，为什么能支配1500万的资源？
- **方法论的使用**: 两步推演加母公司/子公司/合并三套报表对照——母公司800万入资占子公司80%（注册资本1000万），支配1000万资产；子公司再独自获500万贷款，支配资源增至1500万，母公司报表分毫未动。
- **结论**: 控制性投资通过吸纳少数股东入资与子公司独立负债，实现"以较小的资源投入实现更大规模经营"的杠杆式扩张。
- **结果**: 解释了母公司报表小而合并报表庞大的原因，为母公司/合并报表对照分析打下基础。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 财报初学者问"三张报表都是干嘛的、什么关系""底子/面子/日子是什么意思"，需要建立第一层认知。
2. 用户说"拿个虚构例子/拿我们公司开张的过程，帮我推一遍业务怎么变成报表数字"——想看逐笔落账过程。
3. 用户困惑"公司明明盈利为什么没钱发工资/为什么账上有利润却缺现金"——要的是**机理讲解**而非诊断结论。

### 语言信号 (用户的话里出现这些就应激活)

- "三张报表什么关系""底子/面子/日子""实力/能力/活力""小白入门""从头讲讲"
- "业务怎么进报表""推演一遍""拿个例子走一遍""这笔业务三张表怎么变"
- "为什么有利润却没现金""赊销怎么就确认利润了""权责发生制和收付实现制区别"

### 与相邻 skill 的区分

- 与 `eight-lens-statement-analysis` 的区别：本 skill 是**教学基础**——解决"报表是什么、数字怎么来的"的理解问题；后者是**系统分析**——对一家真实企业按"八看"体系输出完整诊断。用户要学走一遍用本 skill，要分析结论用后者。
- 与 `core-profit-cash-conversion` 的区别：本 skill 讲利润与现金背离的**机理**（权责发生制 vs 收付实现制、赊销如何造面子）；后者用**指标检验**（核心利润获现率 1.2~1.5 倍等）对真实企业诊断利润质量。问"为什么会这样"找本 skill，问"这家公司利润有没有水分"找后者。
- 与 `parent-vs-consolidated-statements` 的区别：本 skill 在扩张段只讲"以小博大"的教学推演；后者专门处理母公司/合并报表的口径差异与扩张效应测算。学概念用本 skill，算差额用后者。

## E — 可执行步骤 (Execution)

1. **先用底子/面子/日子定位三表**：一句话说清每张表讲什么、三表以资产负债表为纲的展开关系
   - 完成标准：用户能复述"三表各答一个问题"（有没有家底/能不能赚钱/日子活不活）；若用户明显已有基础，改推诊断类 skill。
2. **搭三张空白表，按生命周期列业务清单**（设立→借款→买资产→购货→赊销→扩张，可按用户场景增删）
   - 完成标准：业务清单覆盖至少一笔筹资、一笔资产形态变化、一笔产生损益的对外交易。
3. **逐笔过三表，每笔问三个问题**：动没动资产、动没动负债和权益、动没动利润和现金；遵守"形态变化不动权益总量、资产毁损不消灭负债"两条规则
   - 完成标准：每笔业务在三张表上均有明确落点（不动的表也要说明"为什么不动"）。
4. **在赊销这一笔停下，专门拆利润与现金的背离**：权责发生制确认收入毛利、现金流量表零流入，指出追查方向是应收款项与存货
   - 完成标准：用户能自己举一个"有利润没现金"的例子并说明机理。
5. **收束到阅读策略**：三表互证、造假主战场在利润表，指出下一步可深入的学习/分析路径
   - 完成标准：给出一句"为什么不能只看利润表"的结论 + 指向对应进阶 skill 的衔接建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已具备报表基础、只要分析结论或诊断——推演教学会显得绕远（诊断→ `core-profit-cash-conversion`，系统分析→ `eight-lens-statement-analysis`）。
- 用户问的是具体会计准则处理、分录怎么做的会计实务教学——本书提供的是分析视角而非准则教程。

### 作者在书中警告的失败模式

- **形而上学地割裂三表**：把三张表当三个孤立的数字集合，不看"利润表和现金流量表都是资产负债表的展开"这层一体关系。
- **跨表直接划等号**：同一概念在三表中口径不同（现金及现金等价物≠货币资金、"投资"内涵各异），混用会得出错误勾稽结论。
- 只认面子不看底子和日子：被利润表数字带走，忘了利润必须有现金流量支撑、必须查应收与存货。

### 作者的盲点 / 时代局限

- 推演案例是简化的教学模型（无税费、无折旧细节、无准则调整项），与真实复杂报表之间有距离，不能替代实务训练；背景是中国会计准则下的报表结构，对其他准则体系（如美股不披露母公司报表）适配性未展开。

### 容易混淆的邻近方法论

- 复式记账/会计分录教学：本 skill 不教借贷记账，只推业务对三表的**结果**，别滑进会计实务课。
- 比率分析（杜邦等）：那是拿到报表之后的加工步骤，本 skill 是看懂报表之前的认知地基，顺序不能颠倒。
