# 从资本来源看发展动力与分红政策

## R — 原文 (Reading)

> "企业负债和股东权益的主要部分可以分成四类，即经营性负债、金融性负债、股东入资和留存利润。"
>
> — 张新民，第5章

> "为了改善财务杠杆、降低负债率，企业就应该考虑少分现金股利。"
>
> — 张新民，第5章、第10章

> "盈利能力有保证的项目可以更多地考虑负债融资，没有盈利保障的项目通常都要靠自有资金。"
>
> — 张新民，第10章

---

## I — 方法论骨架 (Interpretation)

传统分析把负债与权益合起来算一个资产负债率，看不出企业靠什么发展。本书的改造是：**把报表右边按资本来源拆成四类**，看谁在给企业提供动力——

- **经营性负债**（应付票据/应付账款/预收款项/合同负债等）：商业信用，无息占用上下游，来自竞争地位。
- **金融性负债**（短期/长期借款、应付债券等有息负债）：向债权人借来的，需还本付息。
- **股东入资**（股本+资本公积）：股东直接投入，含增资扩张。
- **留存利润**（盈余公积+未分配利润）：实质是股东的再投资。

按四类占比给企业的**发展动力定型**：经营驱动型（经营性负债为主，竞争地位强、"两头吃"）、债务融资驱动型（金融负债为主，多见于快速扩张期）、股东驱动型（入资为主，多见于初级阶段）、利润驱动型（留存利润为主，自我造血）、并重驱动型（大多数企业的常态）。

配套判断三条：

1. **动力结构即诊断**：经营一段时期后仍停留在股东驱动型，可能意味着产品经营不赚钱、债务融资能力弱或管理层不作为；但经营性负债长期居高也可能是经营困难（拖欠货款）而非竞争优势，必须结合经营竞争力与现金流转定性。
2. **分红政策服务融资战略**：降杠杆只有两条路——股东入资、提高利润积累度；后者要求少分现金股利，与股东回报诉求天然矛盾。高负债、现金紧、投资支出大时应用股票股利或组合方式；负债率低、现金充裕时才可激进分红。分红不是财务技术问题，是战略支撑问题。
3. **负债必须与项目盈利能力对应**：全贷款推动的项目至少要盈亏平衡以上；盈利有保证的项目可多用负债，盈利无保障的项目应靠自有资金。检查资本结构质量时要追问他借的钱花在什么项目上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 迈瑞医疗——利润驱动的零债务融资样本
- **问题**: 迈瑞医疗的发展靠什么动力支撑？
- **方法论的使用**: 拆解母公司 429.68 亿元资源：负债 124.75 亿且各类贷款为零，股本+资本公积约 67.83 亿，盈余公积+未分配利润约 247.09 亿。
- **结论**: 动力排序为累积利润、经营性负债、股东入资——利润驱动为主、经营性负债为辅，不靠融资靠持续高质量经营，并抵御住了金融机构放贷的诱惑。
- **结果**: 确认"自我循环"型发展路径，其负债融资空间是后备实力而非现实依赖。

### 案例 2: 恒瑞医药——四大动力排序与降杠杆底气
- **问题**: 恒瑞 2022 年母公司 392 亿元资源由谁贡献？
- **方法论的使用**: 第 13 章综合分析中观察报表右边四大动力的贡献排序，并与资产方扩张效应测算联动。
- **结论**: 排序为利润积累、经营性负债、股东入资、金融性负债，金融负债占比极小；企业发展不依赖债务融资、可实现自我循环。
- **结果**: 负债融资空间大——动力结构直接回答了"还有多少牌可打"的前景问题。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一份资产负债表（或负债权益构成数据），问"这家公司靠什么发展""它的钱从哪来""发展动力健不健康"。
2. 讨论分红方案：公司高负债还该不该分现金股利、分红政策与降杠杆怎么平衡、为什么这家公司只发股票股利。
3. 评估融资安排：企业又借款了，借来的钱投向的项目能不能养活这笔债；想降杠杆有哪些路径。

### 语言信号 (用户的话里出现这些就应激活)

- "资本来源""四大动力""资本引入""钱从哪来""发展动力"
- "分红政策""现金股利""股票股利""留存利润""少分还是多分"
- "降杠杆""负债率怎么降""股东入资""融资安排""借钱上项目值不值"

### 与相邻 skill 的区分

- 与 `strategy-from-asset-structure` 的区别：本 skill 看报表**右边**——钱的**来源**（负债与权益结构→发展动力与分红政策）；它看报表**左边**——钱的**投向**（资产结构→战略类型）。用户问"钱从哪来、靠什么动力发展、分红合不合理"找本 skill；问"钱投到哪、什么战略类型"找它。两者合看才是完整的"看战略"。
- 与 `financial-risk-debt-quality` 的区别：本 skill 把负债当**动力来源**定性（谁在推动企业发展、分红与降杠杆的取舍）；后者把负债当**风险敞口**定量（资产负债率拆金融负债率、偿债压力、70% 界限）。同一组负债数据，问"动力结构"用本 skill，问"风险大小"用后者。
- 与 `two-end-eating-working-capital` 的区别：经营性负债规模只是本 skill 四来源之一；要追问"占款能力从哪来、应付预收与存货债权怎么对应"时找后者。本 skill 只在"经营性负债占比意味着什么动力类型"这一层使用它。

## E — 可执行步骤 (Execution)

1. **取资产负债表右边数据**，把负债与股东权益按四来源归类：经营性负债（应付票据/账款、预收款项/合同负债等）、金融性负债（各类借款与债券）、股东入资（股本+资本公积）、留存利润（盈余公积+未分配利润）
   - 完成标准：四类各有金额与占比，合计能对上负债与权益总额。
2. **按占比给发展动力定型**（经营驱动/债务融资驱动/股东驱动/利润驱动/并重驱动），写出动力排序
   - 完成标准：给出类型结论 + 动力排序；对"经营性负债居高"与"停留在股东驱动型"两种形态补充经营竞争力佐证，防止把拖欠当优势、把不作为当稳健。
3. **检查分红政策与融资战略是否匹配**：对照负债水平、现金存量、投资支出压力，判断现金股利、股票股利或组合方式的选择是否在服务降杠杆或扩张
   - 完成标准：对分红政策给出"服务/背离融资战略"的定性结论，并指出降杠杆的两条路（股东入资、提高利润积累度）中企业实际走的是哪条。
4. **核对负债与项目的对应关系**：追查金融负债（尤其新增借款）投向了什么项目，项目盈利能力能否覆盖还本付息
   - 完成标准：对每一笔主要负债能指出来源项目或用途，并给出"盈利保障充分/存疑"判断；若无法从报表与附注追到项目，明确声明此为待核实项。
5. **汇成一句话动力画像**（如"利润驱动为主、经营性负债为辅、零金融负债"），并提示它对前景判断的含义（融资后备空间）
   - 完成标准：画像包含四来源占比排序与一条战略含义；若用户问题转向资产方或风险量化，分别转 `strategy-from-asset-structure`、`financial-risk-debt-quality`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是资产质量、资产结构与战略类型——那是报表左边的问题（→ `strategy-from-asset-structure`）。
- 用户要的是偿债能力量化结论（流动比率、利息保障、金融负债率拆解）——那是风险度量问题（→ `financial-risk-debt-quality`）。
- 只有合并报表、无母公司/集团结构信息，且四来源归属需要母子拆分时，只能做提示性讨论（口径问题 → `parent-vs-consolidated-statements`）。

### 作者在书中警告的失败模式

- **只算融资成本不算融资收益**（e06）：有学者据此断言"中国企业家明明能债务融资却去搞股权融资"很不理性——这犯了常识性错误，只从数量上关心融资成本，没关注融资收益。证券市场融资带来的融资能力、声誉、联盟资源等收益难以计算却可能远超成本（作者朋友 3 亿净资产的企业上市一次募资 10 亿，还成了当地唯一健在的上市公司）。用本 skill 评价动力结构时，不要用纯账面成本逻辑否定股权融资与上市选择。
- 把经营性负债长期居高一律当竞争优势——也可能是经营困难下的拖欠，必须结合竞争力与现金流转定性。
- 把分红当纯利润分配技术问题——分红与降杠杆、保债务融资能力是联动的战略决策。

### 作者的盲点 / 时代局限

- 四来源占比的经验判断来自作者对中国 A 股（2015-2023）的观察，非上市、金融类与跨境企业适用性未系统检验；"健康动力结构"没有统计显著性证明的阈值。
- 框架立足外部报表读者视角，对集团内部资金计划、预算等管理会计工具着墨少；"负债与项目对应"的核查依赖附注与尽调信息，外部读者常拿不全。

### 容易混淆的邻近方法论

- 传统资产负债率/杜邦体系负债度分析：只给一个总杠杆数字，分不出动力来源；本 skill 恰是它的拆解与替代前提。
- 资本结构的 MM 权衡理论（税盾 vs 破产成本）：只算成本侧收益侧的抽象权衡，本 skill 把权衡落到四来源占比与项目盈利对应上。
