type: case
source_chapter: 第1章第3节
source_quote: |
  借助结构分析很容易看出各项目在总体中的相对重要性，结构分析有助于报表使用者找出重要项目和异动项目。……2019年营业收入较2017年增长了56.76%……最终导致2019年净利润较2017年增长了188.21%。
summary: |
  问题：拿到一张三年期利润表，如何快速锁定影响利润的主变量与噪声项目。
  方法：以北陆药业2018—2019年利润表同时做结构百分比（共同比）与趋势（环比+定基）两套对比。结构上营业成本占比由32.96%降至31.10%、毛利占比升至68.90%，销售费用占比升至33.27%（增速46.28%超收入增速）、研发费用增80.53%、所得税增217.68%；趋势上收入两年增56.76%而成本仅增39.82%，毛利增65.83%，净利润增188.21%。
  结论：结构分析揭示各项目相对重要性，趋势分析区分驱动利润的主变量与小体量噪声项目；两法配合即可圈定进一步分析方向（如销售费用为何大增）。
  细节：研发费用2018年前并入管理费用、2019年单列造成的口径断裂，表中以"不可比"标注加注处理。
