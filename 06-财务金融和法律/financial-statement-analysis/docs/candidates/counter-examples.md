title: 银行"三品"经验：纯财务分析的固有边界
type: counter-example
source_chapter: 第1章案例讨论与分析·案例二
source_quote: |
  某银行行长说：我们着重考察企业的"三品"：第一，人品，即我们着重考察企业领导人的人品；第二，产品，即我们着重考察企业贷款用于生产的产品的盈利能力；第三，抵押品，即我们还要考察企业对贷款的保障措施。（第1章案例讨论与分析·案例二）

  陷阱：以为只凭报表就能做出信贷（或投资）决策。银行行长的"三品"（人品、产品、抵押品）中两项半都是报表外信息——企业家品行、产品竞争力、担保保障都不能从报表直接获得。
  为什么人容易掉进去：报表数据易得、可计算、显得"客观"，容易让人把分析等同于算比率，忽略非财务信息。
  预警信号/对策：作者用它引出"财务分析在信贷中的作用与局限"——财务分析有固有局限，必须结合非财务信息交叉验证；当报表内证据与"人品、产品、抵押品"的表外判断冲突时，警惕后者。
tags: [银行信贷, 三品, 非财务信息, 财务分析局限, 反例]

title: 新《证券法》改"持续盈利"为"持续经营"：盈利指标标尺弱化
type: counter-example
source_chapter: 第2章第2节
source_quote: |
  在我国新《证券法》（于2020年3月1日实施）的第12条中，将公司首次公开发行股票的条件由原来的"具有持续盈利能力，财务状况良好"修订为"具有持续经营能力"……既然没有盈利的企业都可以上市，那么已经上市的公司只要具有持续经营能力，即便没有盈利能力，也可能不再成为退市的理由。（第2章第2节）
summary: |
  陷阱（制度反例）：把"盈利"当判断企业资格的万能标尺。2020年新《证券法》把IPO条件从"持续盈利能力"改为"持续经营能力"，作者指出其双重后果：为尚未盈利的新经济企业上市提供法律依据，同时改变退市规则——没有盈利能力不再当然构成退市理由。
  为什么会掉进去：沿用旧监管标尺看新制度环境，会误判"亏损企业=坏企业"。
  预警信号/对策：盈利类指标的监管标尺作用弱化，持续经营能力评估（会计与审计中的传统难题）在资本市场中的权重显著上升，报表分析的重心须相应调整——从"赚不赚钱"扩展到"能不能活下去"。

id: ce07
title: 在建工程"迟迟不竣工"的三重好处
type: counter-example
source_chapter: 第3章第3节
source_quote: |
  实务中有很多企业的在建工程早已投入使用，却迟迟不办理竣工决算而长期在在建工程项目中挂账。这样做有很多好处：一是可以将借款费用继续资本化，计入工程的建造成本，而不影响当期利润；二是可以推迟对工程项目计提折旧，从而粉饰当期业绩；三是有机会将本该属于当期费用的一些项目"鱼目混珠"计入在建工程的成本，从而虚增当期利润。（第3章第3节）
summary: |
  陷阱：工程已达预定可使用状态本应（估价）转固并计提折旧，长期滞留在建工程却三管齐下虚增利润——继续资本化利息、推迟计提折旧、把当期费用混入工程成本。与 ce06（凭空虚构在建工程）机制不同：这里工程是真的，操纵在"时点"上。
  为什么企业会掉进去：竣工即折旧即费用，拖延转固是成本最低的利润调节器，且以"决算流程慢"为借口极具迷惑性。
  预警信号：核查工期与实际投产状态是否匹配、利息资本化的起止时点、在建工程长期挂账不转固；同类手法还包括以试生产为由推迟转固、借款费用过度资本化。
