# 现金流量三性分析(三类活动质量框架)

## R — 原文 (Reading)

> "不能仅仅依据现金流量净额的正负符号直接得出结论,而是应该针对各类活动的现金流量变化过程分别展开分析。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第5章第3节

> "经营活动现金流量的充足性是指企业是否具有足够的经营活动现金流量来满足正常的运转和规模扩张的需要。"
>
> — 第5章第3节

> "稳定性是指企业各会计期间的经营活动现金流量规模是否存在剧烈波动状况,内部构成是否基本符合所处行业的特征。"
>
> — 第5章第3节

> "各期投资活动现金流入量和投资活动现金流出量之间并不存在直接的对应关系,考察两者的匹配性和协调性一般是没有意义的。"
>
> — 第5章第3节

> "融资行为的恰当性分析,是指考察企业是否存在超过实际需求的过度融资、是否存在企业资金被其他企业无效益占用。"
>
> — 第5章第3节

> "通常只有在企业的某些特殊发展阶段(如初创期或转型期)……才允许企业产生负的经营活动现金流量净额。"
>
> — 第5章第3节

> "此项附注将有助于分析利润的含金量,即净利润与经营活动现金流量之间在数量上出现差异的具体原因。"
>
> — 第5章第3节

## I — 方法论骨架 (Interpretation)

作者主张:现金流量分析的大忌是"符号化判断"——净额为正就好、为负就坏。净额只是一个差,必须进入变化过程,看结构、看成因、看对企业发展的作用。三类活动各有专属评价维度,不能混用。

1. **经营活动看"三性"**:①充足性——净额能否支撑正常运转与简单再生产,正常时净额应大于核心利润;②合理性——流入是否顺畅(对照营业收入与应收账款/应收票据/预收款项余额变化)、流出是否恰当(对照营业成本与应付账款/应付票据/存货变化,识别过度支付),流入应以"销售商品、提供劳务收到的现金"为主,若"收到其他与经营活动有关的现金"占比畸高,可能混入资金运作或关联往来;③稳定性——各年度规模与结构应平稳,剧变可能意味着人为操纵(交易所对季度现金流量剧变下发问询函正是此逻辑)。
2. **投资活动不做匹配性分析,看战略吻合性**:因投资回收有滞后性,各期流入流出本就不对应,"平衡性"没有分析意义。应看三线索:购建长期资产支付的现金 vs 处置长期资产收回的现金——大进大出=置换升级,购建远大于处置=对内扩张,反之=收缩主业或被动收缩(结合经营净额是否同步改善区分主动与被动);"投资支付的现金" vs "收回投资收到的现金"判断对外扩张或结构调整;对内对外大规模相互转移=盈利模式转变。效果最终用以后期间核心利润与经营现金流检验。
3. **筹资活动看多样性与融资行为恰当性**:渠道与方式应多样化以降低资本成本;排查过度融资、资金被其他企业无效益占用(筹资当期合并报表"其他应收款"大幅增长是作者点名的排查项);关键定性是主动扩张还是被迫输血——筹资应纳入发展规划,与经营、投资的现金周转相适应,经营投资产生大量现金时应还债分红而非闲置。
4. **负的经营净额有免责条件**:初创期、转型期或危机期(如金融危机)可以为负,属正常;其余时期持续为负即造血功能不强,长期靠筹资输血维持运转(乐视式续命)是危险信号。免责也要验证:转型方向的投资是否与战略吻合、以后期间核心利润是否兑现;持续超预期年限且靠短期借款输血,免责失效转警报。
5. **先归因再下结论**:现金流量剧变先过归因清单——经营(行业结算特点/发展阶段/营销策略/收付异常/关联交易/异常运作)、投资(扩张加剧/战线收缩与处置不良/取得投资收益)、筹资(融资环境/不当融资/理财能力)。归因区分正常的战略性变化与危险信号,之后才允许做质量结论。
6. **附注三件套收口**:①间接法调节表——解释净利润与经营现金流的差异成因,检验利润含金量;②非现金交易双向解读——以固定资产/存货抵债可能是现金流转困境(透支未来),以非现金资产对外投资可能是盘活资源(管理水平提高),同一笔交易两种相反结论,结合现金存量定方向;③现金及现金等价物净变动——比"货币资金"更能揭示实际支付能力变化。

## A1 — 书中的应用 (Past Application)

### 案例 1: 北陆药业 2019 年报现金流量质量示范(正面)
- **问题**: 一家医药上市公司的现金流量表,如何给出质量结论。
- **方法论的使用**: 经营活动每年净流入较大、造血功能强;核心利润获现率小于 1,但归因发现是销售费用等付现费用大增(开拓市场)所致,结合无利息负担、资本开支小,判定经营现金流量仍充裕;投资活动规模不大,与专业化战略定位吻合;筹资活动"冷清"但无过度融资、无资金被占用,股东增资 2650 万系股权激励。
- **结论**: 现金流量充裕、连续分红,财务状况与盈利能力较好,且公司对未来有信心。
- **结果**: 作者以"三性+吻合性+恰当性"逐项走完,示范不靠比率堆砌也能形成质量判断。

### 案例 2: 乐视网 2016—2018 现金流量表(反面)
- **问题**: 不用算任何比率,直接从现金流量表看出端倪。
- **方法论的使用**: 经营净额从 -10.68 亿恶化到 -54.65 亿,连续大额为负;靠巨额筹资流入(2017 年筹资净流入 95.9 亿级别)输血续命——三性全面缺失,筹资属现金流出失控后的被迫行为,且不是纳入发展规划的主动扩张。
- **结论**: 造血功能丧失+输血依赖,"乐视网缘何难以为继"在现金流量表上早有答案。
- **结果**: 成熟期企业持续负经营净额+大额筹资输血=高危组合的标本。

### 案例 3: 某上市公司季度现金流量剧变遭问询(制度印证)
- **问题**: 营收与净利大增,但各季度经营现金流量净额剧烈波动(三季度为负)。
- **方法论的使用**: 稳定性本身就是质量信息——其他因素稳定、购销业务少有巨幅波动时,经营活动现金流量应保持平稳;剧烈波动提示可能存在操纵或异常收付。
- **结论/结果**: 深交所下发问询函,印证"剧变即可疑"不是作者的猜测,而是监管实践认可的判据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 贴出(或描述)现金流量表或三类活动的数字,问"这现金流怎么样/质量如何/正不正常"
2. 看到"经营现金流为负"或"净额由负转正/由正转负"的新闻或数据,想知道怎么解读
3. 投资活动或筹资活动出现大额异动(大进大出、连续大额流入),想判断背后的战略含义或风险

### 语言信号 (用户的话里出现这些就应激活)

- "经营现金流是负的,这家公司是不是要完了/还行吗"
- "现金流由负转正了,是不是实质性改善"
- "投资活动支付了好多钱建厂房,同时又卖设备,这什么信号"
- "筹资一直净流入,公司是不是在输血"
- "现金流量质量/造血功能/三类活动怎么分析"

### 与相邻 skill 的区分

- 与 `cash-quality-funding-risk` 的区别: 那个聚焦货币资金科目本身(受限资金、真假充裕)与获现率等比率诊断;本 skill 是三类活动的整体质量框架,拿到整张现金流量表用它,单抠货币资金与获现率用那个。
- 与 `profit-quality-3d` 的区别: 那个从利润侧问"利润是不是真金白银"(含金量/持续性/战略吻合);本 skill 从现金侧正向拆解三类活动本身的质量,两者在"含金量"处衔接但入口不同。
- 与 `earnings-manipulation-tactics` 的区别: 那个是造假手法排查;本 skill 是中性质量评估,只在稳定性剧变、关联占用等信号处把线索递给对方。
- 与 `receivables-and-funneling` 的区别: 那个深挖应收科目与资金被占用的手法;本 skill 只在"流入结构偏离销售收现为主""其他应收款大增"时提示去那里查证。

## E — 可执行步骤 (Execution)

1. **第一步:定调——没收"符号"**
   - 明确告知:净额正负不构成结论;列出三类活动净额,只作为后续分析的坐标原点
   - 完成标准:分析框架中不出现"净额为正所以好/为负所以差"式表述
   - 判停条件:用户只有一张净额汇总数而无明细行,向用户索要明细或声明"只能做初步判断"

2. **第二步:经营活动三性检查**
   - 充足性:净额与核心利润(或净利润)比较,能否支撑简单再生产;合理性:流入是否以"销售商品、提供劳务收到的现金"为主,"收到其他与经营活动有关的现金"占比是否异常,流入对照应收/预收余额变化、流出对照应付/存货变化识别过度支付;稳定性:多期(至少 3 年,有季度数据更好)规模与结构有无剧变
   - 完成标准:三性各有一句话结论,且每句都引用了具体数据行
   - 判停条件:发现流入结构异常或关联占用线索→标注并移交 receivables-and-funneling 查证

3. **第三步:投资活动战略吻合性检查**
   - 对内:购建 vs 处置长期资产现金比较(大进大出=置换升级/远大=对内扩张/远小=收缩);对外:投资支付 vs 收回投资比较;对内对外大转移=盈利模式转变;收缩情形结合经营净额是否同步改善区分主动退出与失血
   - 完成标准:给出"扩张/置换/收缩/转型"四选一的定性,并注明需以后期间核心利润与经营现金流检验的问题

4. **第四步:筹资活动恰当性检查**
   - 多样性:渠道与方式是否单一;恰当性:有无过度融资、有无筹资当期合并报表"其他应收款"大幅增长(资金被无效益占用)、定性主动扩张还是被迫输血(对照经营净额与投资方向)、利息股利支付能力与到期债务偿还
   - 完成标准:给出"纳入发展规划的主动筹资 / 失控后的被迫筹资"二选一定性

5. **第五步:变化归因(有剧变时必做)**
   - 过一遍归因清单:经营(行业结算/发展阶段/营销策略/收付异常/关联交易/异常运作)、投资(扩张/收缩与处置不良/投资收益)、筹资(融资环境/不当融资/理财能力);区分正常战略性变化与危险信号
   - 完成标准:每处剧变至少给出两个候选归因及支持/排除的证据

6. **第六步:附注三件套收口**
   - 读间接法调节表归因"净利润-经营现金"差异;非现金交易逐笔做双向解读(困境信号 vs 盘活信号,结合现金存量定方向);用现金及现金等价物净变动校正对支付能力的判断
   - 完成标准:输出"三类活动质量结论+免责/警报判定+待验证问题"三段式收尾;负经营净额必须先过免责条件(初创/转型/危机期)再定性

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问货币资金科目真假充裕、获现率怎么算——用 `cash-quality-funding-risk`
- 用户已明确怀疑造假、要手法排查——用 `earnings-manipulation-tactics`
- 分析对象是金融企业(银行/保险):经营/投资/筹资的边界与一般企业完全不同,三性框架适用性存疑
- 只有单月或单季一个时点的数据:稳定性与归因判断需要多期数据

### 作者在书中警告的失败模式

- 符号化判断:经营净额由 -2 亿转 +9 亿被媒体称"实质性改善",若改善来自压缩采购付款或占用上游,则是透支未来而非真改善——净额转正≠质量改善
- 对投资活动搞匹配性/平衡性分析:流入流出时间错配,匹配性没有意义,会得出"投资现金流为负=不好"的荒谬结论(扩张期本应如此)
- 只看"能融到钱是本事":筹资净流入连续大额为正+经营为负+其他应收款大增,是被迫输血+资金被占用的组合,恰是"融到钱"最危险的形态

### 作者的盲点 / 时代局限

- 三性判断高度依赖行业语境(结算方式、议价能力、市场环境),本书未提供可复制的判别阈值——"流入以销售收现为主""占比畸高"到什么程度算异常,结论可辩护性依赖分析师经验
- "核心利润获现率至少大于 1"明言不考虑行业与发展阶段差异,而同章又承认房地产等行业现金分布与利润分布严重错期——同一标准难以两头兼顾;净额与核心利润口径并非完全一致,作者只说"需进行一些调整"却未给出统一调整程序
- 归因清单中"关联交易/异常运作"只给名单不给识别技术:如何从现金流量表本身发现关联操纵,主要还得靠附注和资产负债表佐证

### 容易混淆的邻近方法论

- 自由现金流(FCF)分析:FCF=经营净额-资本性支出,是单一数量的估值输入(贴现模型的原料),不问结构、不问战略、不问融资行为;本框架是质量诊断,可以算 FCF 但重心在"为什么"而非"折现它"
- 现金流量充裕率的单指标评价:一个比率替代不了三性+吻合性+恰当性的分维度检查
