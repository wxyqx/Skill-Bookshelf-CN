# 存货与毛利率质量分析

## R — 原文 (Reading)

> "对存货进行质量分析，应该结合该项目本身的物理属性和预期效用，从盈利性、周转性以及保值性等三个维度入手。"
>
> — 张新民、钱爱民，《财务报表分析(简明版)》第3章第3节

> "往往是企业试图通过人为调整存货余额和低转（或高转）成本……来操纵业绩的一个显性证据。"
>
> — 张新民、钱爱民，《财务报表分析(简明版)》第3章第3节

---

## I — 方法论骨架 (Interpretation)

作者主张：存货质量不能只看"库存多了压资金"，要按四个维度拆开读，且存货与毛利率必须联动考察——存货是毛利率的"藏污区"。

1. **构成与规模恰当性（译码器）**：附注里原材料/在产品/库存商品的占比变化各有管理含义——原材料占比上升=囤料应对涨价或扩产备货；原材料降+产成品升=滞销减产嫌疑或低转成本，用产销率与同行毛利率对照即可二选一。
2. **盈利性=毛利率**：水平看与行业均值、同行的偏离，走势看年度间波动。充分竞争行业毛利率趋于平均化。作者给出归因清单：**高五种**（垄断地位、核心竞争力强、行业周期暂时走高、产大于销存货积压摊薄固定成本、会计处理故意调高），**低三种**（产品进入衰退期、品牌质量成本价格缺乏竞争力、会计处理故意调低）。
3. **反直觉判据**：产大于销也能推高毛利（产量增加摊薄固定成本）——高毛利未必是竞争力。"波动即证据"：产品结构未显著调整而毛利率年度间巨幅波动，就是操纵的显性证据。机理：当期营业成本+期末存货=可供出售产品成本，两者此消彼长，产销稳定时相对规模应大体不变；低转成本虚增毛利与存货，还能放大抵押贷款筹码。
4. **周转性与战略取舍**：存货周转率并非越高越好，它与应收账款周转率此消彼长。盈利性与周转性的取舍对应两种竞争战略——**差异化战略靠毛利率**（茅台式高毛利稳定），**成本领先战略靠周转率**（薄利多销，毛利率低且波动大）。单项最优可能误导，综合度量看**营业周期**（平均收账期+存货周转天数），追求其缩短而非单项极值。
5. **保值性**：成本与可变现净值孰低；查跌价准备计提比例对照行业均值，防潜亏挂账（冷背呆滞商品、违规开支长期挂存货）与"巨额摊销"为来年扭亏埋伏笔；同时查存货有无担保抵押。

## A1 — 书中的应用 (Past Application)

### 案例 1: 北陆药业 2019 年报——四维全正面的示范
- **问题**: 一家医药上市公司存货质量如何判断？
- **方法论的使用**: 构成——存货结构合理；盈利性——毛利率68.9%且较上年提升；周转性——周转率2.35次、较上年加快；保值性——跌价准备仅计提约0.5%。四个维度全部过筛。
- **结论**: 存货质量高，流动资产质量整体高，是四维框架的正向标杆样本。
- **结果**: 作者以此示范：质量结论必须逐维给出证据，而不是一句"存货不多"带过。

### 案例 2: 蓝田、银广夏——低转成本的点名反例
- **问题**: 毛利率高得反常、存货居高不下，问题出在哪？
- **方法论的使用**: 用"当期营业成本+期末存货=可供出售产品成本"的相对规模检验：产销稳定时此消彼长应大体不变；两家公司通过低转成本把已售成本留在存货里，虚增毛利率粉饰业绩。
- **结论**: 毛利率与存货余额同时反常=操纵嫌疑，且虚增的存货还能增加抵押贷款筹码。
- **结果**: 两案成为"波动即证据"判据的经典印证，也是本 skill 内置的造假识别切入点。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 贴出（或描述）存货附注构成/周转率/跌价准备数据，问"这家公司存货有没有问题""产成品大增正常吗"
2. 毛利率异常：比同行高/低很多、连续波动、突然跳升跳降，问"毛利率这么高正常吗""说明了什么"
3. 存货与毛利信号同时出现（产成品积压但毛利率持平、存货增存货周转慢但毛利升），要求给质量判断

### 语言信号 (用户的话里出现这些就应激活)

- "存货构成/存货周转率/存货周转慢/跌价准备/存货减值/潜亏"
- "毛利率过高/过低/波动/突然下降/比同行高/偏离行业"
- "产成品积压但毛利率没降""毛利和存货对不上"

### 与相邻 skill 的区分

- 与 `earnings-manipulation-tactics` 的区别: 那是怀疑造假后的十种手法系统排查；本 skill 是常规科目质量分析，内含"低转成本"这一个识别切入点——发现嫌疑后移交十法排查
- 与 `profit-quality-3d` 的区别: 那是对利润整体做含金量/持续性/战略吻合性三维评价；本 skill 只下沉到存货与毛利率这一个科目层面
- 与 `receivables-and-funneling` 的区别: 那是应收账款专项（虚构收入挂账）；本 skill 与其联动考察（周转率此消彼长、营业周期），但科目不同
- 与 `long-term-asset-quality` 的区别: 那是固定资产/在建工程/商誉等长期资产；本 skill 只管流动资产中的存货

## E — 可执行步骤 (Execution)

1. **第一步:拆存货构成与规模**
   - 从附注取原材料/在产品/库存商品/发出商品余额，算各期占比与变化；对照营业收入与产能变化
   - 完成标准:每项占比变化都有管理含义归因（囤料/扩产/滞销/低转成本嫌疑四选一）
   - 判停条件:无附注构成数据→明确标注"构成质量无法评价"，仅做比率层面判断

2. **第二步:毛利率归因清单**
   - 算毛利率，与行业平均、对标同行、自身三年走势对照；跑"高五种/低三种"清单逐项排除
   - 完成标准:排除法后给出剩余解释（含"产大于销摊薄"与"会计调高"两个反直觉选项），并核对营业成本与期末存货相对规模是否稳定
   - 判停条件:缺同行数据→向用户索要，或降级为"仅自身走势判断"

3. **第三步:周转性与战略取舍**
   - 算存货周转率（用减值前原值口径），与应收账款周转率联动，算营业周期
   - 完成标准:判定企业属差异化（高毛利）还是成本领先（高周转）模式，并指出当前组合是否与战略自洽

4. **第四步:保值性核查**
   - 查跌价准备计提比例（对照行业均值）、计提政策有无突变、有无冷背呆滞与担保抵押披露
   - 完成标准:给出"计提恰当/不足/洗大澡嫌疑"三档结论

5. **第五步:四维汇总输出**
   - 汇总构成-盈利性-周转性-保值性结论，输出"质量判断+嫌疑点+后续核查动作"
   - 完成标准:若"波动即证据"判据命中（结构未变而毛利巨幅波动），明确建议转入 earnings-manipulation-tactics 做系统排查

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 金融企业（银行/保险）与无实物存货的纯服务/平台企业：没有存货与毛利率概念，四维框架无落点
- 用户只想问一个公式（"毛利率怎么算"）：直接回答，无需启动质量分析
- 用户要的是利润表整体评价：用 profit-quality-3d

### 作者在书中警告的失败模式

- 见"高毛利"就当竞争力：产大于销积压同样推高毛利率（摊薄固定成本），必须先跑归因清单再下结论
- 孤立看周转率：存货周转率与应收账款周转率此消彼长，收紧信用可推高周转却牺牲市场；单项最优可能误导
- 季节性企业用年初年末平均数算周转率会失真（隐含匀速假设）；用减值后净值计算会得出"计提越多周转越快"的悖谬
- 把囤原材料一概当坏信号：战略性囤料会提升未来含金量，判据在付款性质而非金额

### 作者的盲点 / 时代局限

- 保值性评价依赖跌价准备数据，而减值计提恰恰是被操纵的环节——用可能被操纵的数据评价质量存在循环论证风险
- 框架高度依赖附注披露（构成、计提比例、担保抵押），但附注同样出自管理层之手；披露不足时落地能力未被讨论
- 蓝田、银广夏等反面案例均为事后追溯，"波动即证据"的事前预警能力未被独立检验
- "高五种/低三种"清单为经验归纳，无统计依据，跨行业照搬有风险

### 容易混淆的邻近方法论

- 杜邦分析透视竞争战略（差异化高毛利稳定/成本领先靠周转）：只是本 skill 战略取舍判读的一个视角，不含构成译码与操纵配对
- 传统营运能力比率分析：只算周转快慢，不含质量维度、战略归因与"低转成本"识别
- 存货监盘/审计程序：验证存货实物存在性；本 skill 是报表使用者的质量分析，不替代审计
