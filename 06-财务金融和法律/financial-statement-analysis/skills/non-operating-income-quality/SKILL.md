# 非经营性损益判读:含金量与可持续性

## R — 原文 (Reading)

> "投资收益是由企业拥有或控制的投资性资产所带来的收益,主要包括三个部分。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第4节

> "在判断某项损益是否为非经常性损益时……更重要的是考虑该项损益的性质、金额或发生频率的大小。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第4节

> "在我国,非经常性损益是一个资本市场的监管概念,会计准则和相关会计法规并未提出严格的非经常性损益概念和专门的披露要求。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第4节

> "仅仅是一种持有收益……即一种未实现的收益……也就是我们平时所说的浮盈(或浮亏),不会给企业带来真实的现金流量。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第3节

> "总结起来,对其他收益项目的质量分析,应注意以下要点:(1)企业业务与政府政策的关联度……(4)政府政策的阶段性。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第3节

> "一般情况下,政府补贴会给企业带来相应规模的现金增加,但并不总是如此。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第4节

## I — 方法论骨架 (Interpretation)

作者主张:净利润里凡与营业收入无直接关系的项目(投资收益、公允价值变动收益、其他收益、资产处置收益等),不能与"经营赚钱能力"混在一起看,必须逐项问两个问题——**是真金白银吗(含金量)?明年还有吗(可持续性)?**

1. **投资收益三分法**:投资收益由持有收益、处置收益、类别转换收益三部分构成,含金量截然不同。持有收益(权益法)取决于被投资企业的分红政策,不全分红就有"水分";处置收益含金量取决于售价,且是一次性的;类别转换收益(如权益法转公允价值计量)是纯账务处理,**零现金流**。
2. **投资收益现金回款公式**:现金回款=现金流量表"取得投资收益收到的现金"+应收股利/应收利息期末数−期初数。用回款除以账面投资收益,即得含金量;处置收益与类别转换收益全部作为一次性项目剔除。
3. **非经常性损益是监管概念而非会计概念**:会计准则没有这个口径,它是证监会为规范"扣非"披露而设的。识别不能只对着监管清单打勾,要**按活动分类**(经营/投资/筹资/其他)逐项过,再做实质性判断——看该项损益与生产经营的联系,以及性质、金额、发生频率。
4. **公允价值变动收益是监管盲区**:它是未实现的浮盈,零现金、可能随市价消失;但按监管口径"通常不列入非经常性损益"——所以扣非净利润也可能把它留在"真实业绩"里。占比过大时要额外警惕,这正是"花样扭亏"的惯用通道。
5. **政府补助四要点**:①业务与政策的关联度;②企业对政策的研究能力;③主营业务的市场竞争力;④政策的阶段性。补贴是双刃剑——光伏与新能源汽车的行业教训是,不当补贴导致产能盲目扩张、企业丧失自主创新动力。作者的判据:**完全靠政府持续补贴生存的企业不会有持续的竞争力。**
6. **"补贴挂账"含金量例外**:政府补助一般带来现金,但确认与收款可能长期脱节(新能源补贴挂账数年)。须核对其他应收款中补贴款的规模与账龄,与利润表其他收益对照——"有补贴收入、无补贴现金"是含金量的重大减分项。

## A1 — 书中的应用 (Past Application)

### 案例 1: 北陆药业 2019 年报——投资收益与浮盈的标准示范
- **问题**: 净利润里"投资收益+公允价值变动收益"占比很大,这些利润成色如何?
- **方法论的使用**: 投资收益三分法拆解——世和基因核算类别转换带来收益1398万元,一次性且不带来任何现金;权益法确认收益882万元,按现金回款公式算得实际回款仅537万元,含金量0.61;另有世和基因股价带来的公允价值变动收益1.73亿元浮盈,未实现、波动大。再按非经常性损益清单识别:全年非经常性损益占净利润51.36%,"真实"业绩约1.67亿元。
- **结论**: 账面高利润相当部分是零现金的账务收益与浮盈,销售净利率41.81%被公允价值变动收益撑大;核心利润1.85亿元才是经营基本盘。
- **结果**: 该案例成为三分法+浮盈判读的正面标准示范——识别之后,利润评价从"净利率极高"修正为"主业优秀但利润表被浮盈装饰"。

### 案例 2: 长安汽车 2018 年报——补贴挂账的含金量例外
- **问题**: 其他收益(政府补贴)28.73亿元,当年营业利润为−2.01亿元、净利润7.23亿元——补贴的真实价值几何?
- **方法论的使用**: 四要点判断政策关联度与阶段性之外,关键做含金量核对:其他应收款显示新能源补贴27.28亿元尚未收回,最长账龄近4年——"有补贴收入、无补贴现金"。
- **结论**: 剔除补贴后净利润即为负;补贴不仅不可作为持续盈利基础(政策阶段性),而且大额已确认部分还停在应收款里,含金量打折。
- **结果**: 作者以此示范"完全靠政府持续补贴生存的企业不会有持续的竞争力"的判据,并警示补贴依赖型盈利的整体质量。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 利润表里投资收益、政府补助、公允价值变动收益、资产处置收益金额大或占比高,想知道"这些利润是真的吗、明年还有吗"
2. 公司扭亏/保壳/业绩暴增来自卖资产、股票浮盈、补贴到账,想判断成色与来年风险
3. 想核对"利润—现金"缺口是否出在非经营项目上(补贴挂账、权益法不分红、账务转换收益)

### 语言信号 (用户的话里出现这些就应激活)

- "投资收益/政府补助/公允价值变动/资产处置收益的水分/含金量/可持续性"
- "净利润大增但扣非后很少""浮盈""卖房卖子公司保壳""补贴没收到现金"
- "非经常性损益占比过高,真实盈利是多少"

### 与相邻 skill 的区分

- 与 `profit-quality-3d` 的区别: 那个定义利润口径(核心利润)与三维质量(含金量/持续性/战略吻合性),是整体评价框架;本 skill 深挖具体非经营项目,是它的下钻工具
- 与 `profit-deterioration-sweep` 的区别: 那个是 12 种恶化信号的全面扫雷清单;本 skill 只聚焦非经营性损益这一族项目的深度检验
- 与 `revenue-quality-three-questions` 的区别: 那个管营业收入(卖什么/卖给谁/靠什么);本 skill 管收入之外的非经营项目
- 与 `cash-quality-funding-risk` 的区别: 那个管现金流与偿债资金链;本 skill 在利润表端识别"有利润无现金"的项目成因,再交由它验证现金面

## E — 可执行步骤 (Execution)

1. **第一步:拆口径、列清单**
   - 从利润表摘出投资收益、公允价值变动收益、其他收益、资产处置收益、营业外收支的金额,计算各占利润总额/净利润的比重;从附注取明细
   - 完成标准:一张"非经营项目一览表",每项有金额、占比、对应附注出处
   - 判停条件:占比均不足5%且无扭亏/异动背景→输出"非经营项目不构成主要质量风险"并终止

2. **第二步:投资收益三分法+现金回款公式**
   - 把投资收益拆为持有(权益法/成本法)、处置、类别转换三类;按公式计算现金回款=取得投资收益收到的现金+应收股利/应收利息期末数−期初数,得出含金量系数
   - 完成标准:三类各有金额与含金量;处置收益与类别转换收益已标注"一次性,剔除"

3. **第三步:非经常性损益按活动识别+实质性判断**
   - 按经营(关联购销、处置置换、盘盈亏、补贴)、投资(处置与类别转换全算,正常持有收益不算)、筹资(财务费用附注)、其他(捐赠、债务重组、罚款、政策追溯调整)四类过清单,再用性质/金额/频率做实质性判断
   - 完成标准:输出非经常项目清单与扣非口径利润;**公允价值变动收益单独标注为"监管盲区项目"**,不因"通常不列入非经常性损益"而放行
   - 判停条件:发现扭亏完全依赖非经营项目→直接给出"数量翻转≠质量翻转"结论

4. **第四步:政府补助四要点+补贴挂账核对**
   - 逐条评估:业务与政策关联度、政策研究能力、主业竞争力、政策阶段性;核对其应收款中补贴款的规模与账龄,与利润表其他收益对照
   - 完成标准:四要点逐条有结论;给出补贴的含金量判断(现金已到账/挂账中)与可持续性判断

5. **第五步:合成"真实"业绩与风险提示**
   - 剔除一次性项目与浮盈后给出调整口径利润,回答"如果明年没有这些项目,利润还剩多少"
   - 完成标准:输出"账面利润→调整后利润→各项目风险提示(浮盈消失/补贴退坡/无现金)"三段式结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是利润整体质量的系统评估(含金量/持续性/战略吻合性三维)——用 `profit-quality-3d` 定调,本 skill 只作下钻
- 怀疑的是收入本身(关联购销定价、客户集中、行政手段贡献)——用 `revenue-quality-three-questions`
- 分析对象是金融企业:投资收益/公允价值变动是其主营的一部分,"非经营"定性不成立,框架适用性存疑(作者仅以脚注承认新商业模式挑战)

### 作者在书中警告的失败模式

- **类别转换收益**:纯账务处理、零现金流、一次性——北陆药业1398万元就是标本,混在投资收益里极易被当成"投资眼光好"
- **浮盈消失**:公允价值变动收益未实现、可能随市价消失,且不在扣非口径内——把浮盈当真实业绩,市价回落当年即"业绩变脸"
- **补贴依赖**:"完全靠政府持续补贴生存的企业不会有持续的竞争力";不当补贴更导致产能盲目扩张、丧失自主创新动力(光伏/新能源汽车教训)
- **救命稻草效应**:靠资产处置收益改善营业利润的企业,可能主营业务正在经历困难时期(ST公司卖学区房保壳是极端样本)

### 作者的盲点 / 时代局限

- 高度依赖附注披露充分且可信(补助明细、公允价值计量层级、被投资企业分红政策)——附注同样出自管理层之手
- 以证监会非经常性损益口径为可靠前提,而该口径"通常不列入"公允价值变动收益,监管口径本身可能滞后于操纵手法
- 案例集中于2019年前后的A股制造业/医药企业,对金融、互联网平台的损益结构适用性未验证

### 容易混淆的邻近方法论

- **扣非净利润**:它是证监会口径的现成指标,直接取披露数;本 skill 是实质性判断——扣非不覆盖公允价值变动浮盈等盲区,也不能回答"持有收益的含金量多少""补贴挂账多久"。正确关系:以扣非为起点,再做分项检验修正
- **监管非经常性损益清单**:清单只是候选集,作者强调必须按"与生产经营的联系+性质、金额、频率"做实质性判断,不能打勾了事
