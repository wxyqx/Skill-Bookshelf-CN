# 商业债权质量与资金占用识别

## R — 原文 (Reading)

> "如果用常理解释不了，就要警惕该企业是否存在虚构交易，通过将虚假的收入在应收账款中挂账，达到粉饰当期业绩的目的。"
>
> — 张新民、钱爱民，《财务报表分析(简明版)》第3章第3节

> "其他应收款既为'其他'，就应该不属于企业主要的债权项目，数额及所占比例不应过大。"
>
> — 张新民、钱爱民，《财务报表分析(简明版)》第3章第3节

---

## I — 方法论骨架 (Interpretation)

作者主张：商业债权不是一个科目，而是一个"科目族"——应收票据、应收账款、预付款项、其他应收款。每个科目的功能不同，被滥用的方式也不同，必须分科设防。

1. **应收账款三步检验**：①真实性——把应收账款相对规模（占总资产、占收入的比例）与同行、行业均值、自身前期对比，急剧上升而经营性解释（行业竞争加剧、竞争地位下降、客户财务困境）讲不通，即虚构收入挂账警报；②周转性——账龄结构（注意账龄可被人为"洗短"）、债务人构成、商业债权周转率与平均收账期（须并入应收票据、用减值前原值计算，并与存货周转率联动考察）；③保值性——坏账准备计提比例与政策，对照行业均值，警惕计提政策突变背后的利润安排。另注意两个新科目：合同资产承担履约风险（比应收账款的纯信用风险更重），应收款项融资有追索权、实质是质押。
2. **债务人六维分析**：行业构成、区域构成（经济与法制环境决定偿还心态）、所有权性质、与债务人的关联状况（重点盯防）、稳定程度（稳定债务人过多反而说明经营无起色）、集中度（双刃剑，见下）。
3. **客户集中度双刃剑**：集中于优质老客户回款稳定、销售费用低；但集中度过高使大客户议价力强，降价、延付、"敲竹杠"风险反而推高坏账与盈利风险——同一维度同时给债权质量与收入质量打分。
4. **预付款项排查**：正常预付随业务量与信用状况规律变化并转化为存货；巨幅异动时先排除行业付款惯例与自身信用弱势，再查收款方与实控人的实质关联——对关联方打预付款这种令人费解的做法往往潜藏利益输送。
5. **其他应收款占用识别与集权例外**："既为其他，不应过大"；过高即不正常，借附注查金额大、时间长、来自关联方的款项，重点盯防大股东占用。但有一条关键例外：集团集权式资金管理下，母公司对子公司的大额其他应收款属正常资金输送，"越合并越小"的差额正是母子公司资金关系的信号——其质量取决于子公司盈利能力，合并层面仍超常的部分才指向占用或不良资产。
6. **后果模型**：虚假应收挂不长——来年往往以销售退回撤销或以坏账核销消化，业绩跳水。这使债权分析可以前瞻预判，而不只是事后确认。

## A1 — 书中的应用 (Past Application)

### 案例 1: 秋林集团——其他应收款的极端样本
- **问题**: 2019 年报显示其他应收款账面余额近 40 亿元、99% 以上已计提信用减值，这个数字背后是什么？
- **方法论的使用**: "既为其他，不应过大"判据报警→借附注查金额大、时间长、来自关联方的款项→欠款方集中于珠宝公司且"全军覆没"；作者连环追问：为何集体不还钱？9 人欠 2000 万也 100% 计提？两年内账龄为何迅速认定无法收回？
- **结论**: 表面是会计处理随意，深层是管理混乱、内控缺失、治理失效，不排除大股东掏空——关键证据（控制人行为）根本不在报表里。
- **结果**: 近 40 亿债权几乎全额减值，印证为不良资产；成为"其他应收款过高即不正常"的极端反面教材。

### 案例 2: 北陆药业——应收账款质量的正面示范
- **问题**: 一份正常年报里，如何有证据链地判断应收账款质量高？
- **方法论的使用**: 三步框架逐项走——相对规模与收入、资产对比未见异动；周转性看账龄（97% 在 1 年以内）；保值性看计提（整体计提 4.31%，与账龄结构匹配、对照行业水平温和）。
- **结论**: 账龄短、计提恰当，债权质量高。
- **结果**: 作者示范"质量高"是三步证据链的产物，而非"周转率不低"的单指标直觉——与秋林形成正反对照。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看报表发现应收账款/应收票据激增、账龄结构异常或坏账计提政策突变，想知道是不是虚增收入或回款恶化
2. 怀疑大股东或关联方占用、输送资金：预付款项异常放大、其他应收款畸高、媒体曝出"掏空"传闻后想用报表验证
3. 拿到附注中债务人/预付/其他应收款明细，想知道怎么从中读出资金占用的痕迹

### 语言信号 (用户的话里出现这些就应激活)

- "应收账款翻倍/增速远超收入""账龄会不会被洗短""坏账计提怎么突然变了"
- "大股东占用资金""其他应收款巨大/暴雷""预付给关联方""掏空"
- "这笔钱到底是不是被占用了/能不能收回来"

### 与相邻 skill 的区分

- 与 `earnings-manipulation-tactics` 的区别: 那是覆盖收入、成本、存货、在建工程等的系统性造假"十法"排查；本 skill 只聚焦商业债权与占款这一个科目族
- 与 `strategic-analysis-path` 的区别: 那是拿到年报的全程四步路径；本 skill 是对单一科目族的定点深挖
- 与 `revenue-quality-three-questions` 的区别: 客户集中度是两者的共同维度，但那个从收入端问"卖给谁、靠什么"，本 skill 从债权端问"钱收不收得回来"
- 与 `differential-analysis` / `consolidation-pitfalls` 的区别: 那两个提供合并与母公司报表的差额工具；本 skill 在"集权例外"分诊时调用其差额判据，但不承担集团结构分析

## E — 可执行步骤 (Execution)

1. **锁定科目族与规模基线**
   - 拉取应收票据、应收账款、预付款项、其他应收款的余额、增速与占比，与营业收入、总资产增速及同行均值对比
   - 完成标准: 每个科目给出"相对规模正常/异动"的标注
   - 判停条件: 用户只有比率没有科目余额→向用户索要报表数据或明确标注"只能做定性讨论"

2. **应收账款三步检验**
   - ①相对规模异动先找经营性解释（行业竞争加剧、竞争地位下降、客户财务困境），讲不通再报警；②账龄结构+商业债权周转率（并入应收票据、用减值前原值、与存货周转率联动）；③坏账计提政策与比例对照行业均值、查当期是否突变
   - 完成标准: 三步各有一个明确结论，账龄与计提互相印证（如 97% 一年以内对应整体计提约 4% 才算自洽）
   - 判停条件: 附注无账龄表或债务人明细→结论降级为"证据受限"，不得给出质量终判

3. **债务人六维分析**
   - 对前五大债务人按行业、区域、所有权性质、关联状况、稳定程度、集中度逐维打点
   - 完成标准: 关联方集中、区域法制环境差、集中度快速提高三者任一出现即红色标注
   - 判停条件: 附注仅披露"前五名合计占比"无明细→只做集中度单维判断并说明局限

4. **预付款项输送排查**
   - 巨幅异动时按顺序: 排除行业付款惯例→排除自身信用弱势（议价力弱被迫预付）→查收款方与实控人的实质关联（名义非关联也要查）
   - 完成标准: 每笔异动归因为"经营性/行业惯例/输送嫌疑"三类之一

5. **其他应收款分诊（含集权例外防误杀）**
   - 合并层面过高→借附注查"金额大、时间长、来自关联方"，锁定占用嫌疑；母公司大而合并小（"越合并越小"）→定性为对子公司的资金输送/控制性投资藏身处，改查子公司盈利能力定质量，不得按占用报警
   - 完成标准: 输出"占用嫌疑/集权输送/正常"三档分诊结论
   - 判停条件: 无母公司报表→集权例外无法执行，全部按合并层判据处理并声明

6. **后果模型与前瞻结论**
   - 若判定虚构收入挂账，前瞻预判来年销售退回或坏账核销致业绩跳水；汇总输出科目族质量分级+风险清单+后续跟踪点（退货公告、坏账核销、问询函）
   - 完成标准: 每条结论可追溯到前面某一步的证据；若关键信息在报表外（如控制人行为），明确声明"需报表外尽调，报表分析不能下终局结论"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 金融企业（银行/保险）: 其债权主体是贷款与垫款，本框架的科目口径不适用
- 用户要的是全报表造假排查或整体质地评估→用 earnings-manipulation-tactics / strategic-analysis-path
- 用户问的是收入本身的质量（客户集中度重叠但焦点在收入端）→用 revenue-quality-three-questions
- 只有合并报表、无母公司报表与附注: 集权例外分诊与账龄/债务人分析均无法落地

### 作者在书中警告的失败模式

- 虚构收入挂应收账款→虚假应收挂不长，来年以销售退回撤销或以核销坏账消化，业绩跳水（后果模型）
- 账龄可被人为"洗短"——向债务方提供资金让其还款再赊出，账龄表好看不等于质量好
- 万福生科式"安全科目"选择: 预付账款与在建工程审计难度大、叙事天然正面，恰是造假者偏爱的藏身处
- 银广夏事件后造假者"爱上了"其他应收款——户数多、金额小、难查证；大股东占用是中国资本市场"最大的毒瘤"

### 作者的盲点 / 时代局限

- 框架高度依赖附注披露充分且可信，而附注同样出自管理层之手；账龄、债务人明细披露不足时落地能力未被讨论
- 秋林等反面案例均为事后追溯（减值发生了才看出），框架的事前预警能力未被独立检验
- 保值性依赖坏账计提数据，而计提恰是被操纵的环节——用可能被操纵的数据评价质量，存在循环论证风险

### 容易混淆的邻近方法论

- **集权例外防误杀（最易误判处）**: 母公司"三高"（借款高、利息高、其他应收款高而合并数远低）是集权资金管理体制的正常形态，母公司大额对子公司其他应收款属正常资金输送，质量取决于子公司盈利能力——同一科目两种性质，见到"其他应收款大"就报掏空会误杀正常集团；区分点在合并/母公司差额结构，不在绝对规模
- 传统应收账款周转率: 单一净值口径指标会得出"计提越多周转越快"的悖谬，不能替代三步检验
- 信用评级式的单一"回收率"打分: 无债务人构成与后果模型维度，输出形态不同
