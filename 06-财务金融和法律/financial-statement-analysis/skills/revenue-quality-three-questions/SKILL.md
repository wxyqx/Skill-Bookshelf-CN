# 收入质量三问 — 卖什么 / 卖给谁 / 靠什么

## R — 原文 (Reading)

> "一般地,在对企业的营业收入进行分析时,应着重从卖什么、卖给谁和靠什么等方面入手。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第3节

> "信息使用者必须关注关联方交易形成的营业收入在交易价格、交易实现时间等方面是否存在非市场化因素。"
>
> — 张新民、钱爱民,《财务报表分析(简明版)》第4章第3节

---

## I — 方法论骨架 (Interpretation)

作者主张:营业收入是利润的源头,评价利润质量要先拆收入的质量。拆法是三个问题,展开为五个维度——

1. **卖什么(品种构成)**:收入靠哪些产品/业务撑起来。看点是品种集中度——主导产品单一化意味着抗风险能力系于单一品种,但也可能是专业化战略的体现;判断不能脱离企业战略表述,要在"专业化深耕"与"主导产品下的多元化"之间做权衡,而不是机械认为越分散越好。
2. **卖给谁之一(地区构成)**:收入在哪些区域实现。看点是区域强弱分布与增长态势——优势区域说明竞争地位,薄弱区域说明扩张空间或竞争短板;区域结构还是判断国际化程度的基础。
3. **卖给谁之二(客户构成)**:收入靠哪些客户实现。客户集中度是双刃剑——集中度高则议价能力弱,大客户可能"敲竹杠",坏账与盈利风险升高;集中度低且分布均匀则回款与议价更安全。
4. **靠什么之一(关联方交易)**:收入中有多少来自关联方。必须检验交易价格、交易实现时间是否存在非市场化因素;即便价格公允,交易能否在市场化时间持续实现仍存疑,且持续性依赖关联方自身存续——关联贡献大说明市场化能力不足。
5. **靠什么之二(行政手段)**:收入中有多少靠部门或地区的行政扶持维持。靠行政手段维持的业绩在政策改变后前途未卜;只有靠市场获得持续发展的企业才有核心竞争力。

整体逻辑:三问合起来回答一个元问题——这些收入是"市场挣来的"还是"关系/政策给的"。再配合合并报表与母公司报表收入构成的对比,还能看出集团的多元化与国际化程度。这一框架是利润质量分析(利润质量三维)的地基:收入构成不可持续,后面的含金量与持续性都无从谈起。

## A1 — 书中的应用 (Past Application)

### 案例 1: 北陆药业 2019 年报三问演练(主案例)
- **问题**: 一家医药上市公司的营业收入质量如何,不能只看总额 8 亿+的规模和 68.90% 的毛利率,要看构成。
- **方法论的使用**: ①卖什么——附注品种构成显示对比剂占 80.98%,作者判为"主导产品单一化",建议向"主导产品下的多元化"转型;②卖给谁(地区)——华北、华东、华中强且增长快,华南、东北薄弱,竞争地位与扩张空间同时可见;③卖给谁(客户)——前五大客户合计仅 17.84%,分布均匀、信用良好,集中度风险低。
- **结论**: 收入质量总体扎实——专业化战略下品种集中是主动选择而非被动依赖,区域有强点、客户不绑死;但品种单一化是未来需要用多元化对冲的结构性风险。
- **结果**: 这一结论成为第 7 章综合分析中"经营主导、专业化程度高"总体评价的收入侧证据。

### 案例 2: 关联与行政贡献的可持续性判据
- **问题**: 收入里有相当部分来自关联方购销或行政扶持的企业,业绩是不是真本事?
- **方法论的使用**: 对关联贡献,检验交易价格与交易实现时间两个市场化维度;对行政贡献,用"政策改变会怎样"做压力测试。
- **结论**: 关联交易即便价格公允,持续性仍存疑;靠行政手段维持的业绩在政策改变后前途未卜——两者都指向市场化能力不足。
- **结果**: 作者以此确立标尺:只有靠市场获得持续发展的企业才有核心竞争力;这一判据在书中与政府补助"双刃剑"的警告(完全靠补贴生存的企业不会有持续竞争力)互相呼应。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上有年报附注(或分产品/分地区/前五大客户数据),问"这家公司收入构成健康吗""产品是不是太单一""客户集中度有没有风险"
2. 尽调或选股时怀疑收入"含关系量":大额关联交易、靠政府/集团扶持、靠行政资源拿单,想知道这钱能不能持续
3. 问"这家公司的收入以后还能不能增长/持续""区域结构说明了什么"

### 语言信号 (用户的话里出现这些就应激活)

- "收入构成/产品结构/品种单一/主营业务集中度"
- "前五大客户占比/客户集中/大客户依赖/区域收入分布"
- "关联交易贡献的收入/靠政府扶持/行政手段/收入可持续吗"

### 与相邻 skill 的区分

- 与 `receivables-and-funneling` 的区别: 那个从应收账款等债权科目反推客户质量与资金被占用;本 skill 从收入本身看构成与来源——同样面对"客户集中",它查账期与坏账,本 skill 查品种、区域与市场化能力
- 与 `profit-quality-3d` 的区别: 那个管利润整体的含金量、持续性、战略吻合性;本 skill 只管收入的构成质量,是它的上游地基
- 与 `non-operating-income-quality` 的区别: 政府补助等非营业收入项目不在"营业收入"口径内,归那个 skill;本 skill 的"行政手段"维度专指混在营业收入里的行政依赖

## E — 可执行步骤 (Execution)

1. **第一步:取数与判停**
   - 从年报附注取营业收入三类明细:分产品/品种、分地区、前五大客户;另取关联交易附注与"经营情况讨论与分析"中的政策依赖线索
   - 完成标准:三张构成表齐备(品种、地区、客户),关联交易金额与定价方式摘出
   - 判停条件:附注未披露客户或地区明细→明确标注"披露不足,该维度无法落地",改用品种构成与定性信息,不得虚构明细

2. **第二步:问"卖什么"——品种构成**
   - 计算前几大品种收入占比,对照企业战略表述判断:单一化是专业化深耕还是被动依赖
   - 完成标准:列出品种占比排序+一句话定性(集中是战略选择还是风险敞口)

3. **第三步:问"卖给谁"——地区与客户构成**
   - 地区:列强弱区域分布与增长差异;客户:算前五大客户合计占比,评估集中度双刃剑(议价、坏账、盈利稳定)
   - 完成标准:给出区域强弱格局结论+客户集中度高/中/低三档判断及理由

4. **第四步:问"靠什么"——关联与行政贡献**
   - 关联交易:单列占收入比重,分别检验交易价格与交易实现时间的市场化;行政手段:识别订单、定价、补贴中行政扶持的成分,做"政策改变"压力测试
   - 完成标准:收入来源三分类占比(市场/关联/行政),每类附可持续性判断;关联部分即便价格公允也要给出持续性存疑的结论

5. **第五步:综合与升维**
   - 对比合并报表与母公司报表的收入构成(有集团结构时),考察多元化与国际化程度;输出"收入质量总评+可持续性风险+建议关注点"三段式结论
   - 完成标准:每条结论能追溯到第 2-4 步的具体证据;结论交付前自查是否混淆了本 skill 与债权、利润维度的分析边界

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是应收账款、其他应收款等债权科目的质量和客户欠款风险——那是债权维度,用 receivables-and-funneling
- 用户问的是利润整体的含金量、持续性、战略吻合性——用 profit-quality-3d,本 skill 只是其收入侧输入
- 用户只有利润表上的营业收入总额、没有任何附注明细——五维里四个维度无法落地,只能提示需要补充数据
- 分析对象是金融企业或平台型新业态(交叉补贴、免费+增值):品种/客户构成的教科书判据适用性存疑,作者仅以脚注承认新商业模式挑战

### 作者在书中警告的失败模式

- 客户集中度过高时大客户"敲竹杠":议价能力强,利润被侵蚀,坏账与盈利风险反而升高——只看收入增长不看客户结构会漏掉
- 靠行政手段(尤其央企、地方扶持)维持的业绩,政策一变即"前途未卜"——把政策性收入当市场化能力是致命误判
- 关联交易粉饰利润、转移资产:只核价格公允性而不问交易实现时间与持续性,仍会被"公允但不可持续"的关联收入骗过

### 作者的盲点 / 时代局限

- 框架高度依赖附注披露客户与地区明细——但附注同样出自管理层之手,披露不足或选择性披露时,五维中"卖给谁""靠什么"难以落地,作者未讨论替代程序
- 案例单一且同源:全书收入构成细案例几乎只有北陆药业一家(2019 年报),推广到互联网平台、金融企业时未经验证
- "只有靠市场获得持续发展的企业才有核心竞争力"是经验断言,对处在政策红利期的行业(作者自己也举光伏、新能源车),行政与市场边界本身模糊

### 容易混淆的邻近方法论

- 营业收入增长率/生命周期判据(>10% 成长、<5% 衰退):只度量数量的成长性,不问收入从哪来;本 skill 回答"构成与来源",两者互补不可互替
- 杜邦分析中的销售净利率拆解:拆的是利润率成因,不拆收入构成
- 行业景气度/赛道分析:用外部行业数据判断前景;本 skill 只用报表附注内的企业自身构成数据,结论粒度是"这家公司"而非"这个行业"
