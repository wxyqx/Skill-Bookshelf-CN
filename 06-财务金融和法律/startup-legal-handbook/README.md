# 创业投资法律手册：那些你在创业时应该知道的公司法知识

由杨春宝、王成兵（执业律师）《创业投资法律手册：那些你在创业时应该知道的公司法知识》（中国法制出版社，2014 年版）蒸馏出的一组**可被 AI Agent 调用的技能**（Skills）。

> 创业公司的法律灾难绝大多数不是来自"违法"，而是来自"想当然"：本书用 235 个真实咨询问答把每一个想当然逐一纠正，教创业者按"法定程序 + 章程自治"安排股权、治理、交易与退出。16 个技能覆盖企业形式与出资、章程治理、股东资格与救济、代持风险、股权流转与激励、增资改制、退出清算、法代合规与文件陷阱、涉外投资等全生命周期决策。

## 16 个技能

**起点与形式选择**
- [`entity-choice-incorporation`](skills/entity-choice-incorporation/SKILL.md) — **企业形式选择与设立**：按"责任敞口→税负交换→上市预留→过渡方案"选择企业形式，配套设立流程清单与"设立协议条款搬进章程"

**出资与财产边界**
- [`capital-contribution-compliance`](skills/capital-contribution-compliance/SKILL.md) — **出资合规判断**：按"两要件→禁止清单→财产判定→瑕疵与抽逃责任→债权人追责路径"判断什么能出资、认缴与抽逃的责任
- [`veil-piercing-liability`](skills/veil-piercing-liability/SKILL.md) — **刺破面纱与股东责任**：判断公司债务是否会烧到股东个人财产（公私混用、两套账、一人公司举证倒置），输出避险与追偿方案

**治理与章程**
- [`charter-governance-design`](skills/charter-governance-design/SKILL.md) — **章程与治理设计**：按"表决权数学→授权清单→僵局条款→控制权可行性检查"输出章程层设计建议（五五开、一票否决、董事职权）
- [`equity-rights-design`](skills/equity-rights-design/SKILL.md) — **股东权益安排**：为技术/不出资方安排表决/分红权脱钩、技术贡献者三路径选型与章程落点（同股不同权、超额分红）
- [`resolution-validity-procedure`](skills/resolution-validity-procedure/SKILL.md) — **决议效力判断**：按"无效/可撤销/决议不成立"分流定性，核对召集顺序、通知送达、表决基数与 60 日除斥期间

**股东权利与救济**
- [`shareholder-qualification-registration`](skills/shareholder-qualification-registration/SKILL.md) — **股东资格认定**：用五类证据链判断"谁是股东"——名册生效、登记对抗、30 日时限与分场景补救（含公章证照被抢）
- [`minority-shareholder-remedies`](skills/minority-shareholder-remedies/SKILL.md) — **小股东救济工具箱**：知情权三步 + 派生诉讼四步，先固定证据再诉讼，赔偿归公司不归个人
- [`nominee-shareholding-risk`](skills/nominee-shareholding-risk/SKILL.md) — **股权代持风险**：按"效力→不抗第三人→显名化→协议六项清单→名义股东风险"输出代持/隐名投资的防控与救济

**股权流转与激励**
- [`equity-transfer-pricing`](skills/equity-transfer-pricing/SKILL.md) — **股权转让全流程**：按"四步程序→两级救济→定价三锚点→瑕疵出资与付款红线"输出方案（优先购买权、公司代付转让款红线）
- [`capital-change-restructuring`](skills/capital-change-restructuring/SKILL.md) — **增资与改制**：按"增资四要件→稀释处理→改制路径→分立连带"输出程序与效力判断（入股协议打款、分家后债务）
- [`employee-equity-incentive`](skills/employee-equity-incentive/SKILL.md) — **员工股权激励**：干股 vs 真股权 vs 未上市期权五种变通的分水岭判断，配套离职退出与股份收回机制

**退出与清算**
- [`exit-dissolution-liquidation`](skills/exit-dissolution-liquidation/SKILL.md) — **退出全路径**：四级退出阶梯→50/50 僵局破局→司法解散三要件→清算注销程序→破产转换→"置之不理"的连环后果

**合规与陷阱**
- [`legal-rep-compliance-contracts`](skills/legal-rep-compliance-contracts/SKILL.md) — **法代责任与经营合规**：法代身份体检→登记程序→合同三步清单（代签/冒签/意向书/公章）→资金红线（闲钱拆借、挪用）
- [`paper-validity-traps`](skills/paper-validity-traps/SKILL.md) — **文件效力陷阱**：识别"以为生效其实失效"——登报声明公章作废、伪造签名决议、工商范本章程、多数决直接除名，并给程序替代通道

**涉外（强时效警示）**
- [`cross-border-foreign-investment`](skills/cross-border-foreign-investment/SKILL.md) — **涉外投资方法论**：按"身份认定→准入穿透→结构变通→形式选择→程序效力→管辖"定性涉外问题（2014 年语境，须按《外商投资法》及负面清单重核）
