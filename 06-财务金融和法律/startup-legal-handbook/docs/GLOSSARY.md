# 术语词典 — 《创业投资法律手册:那些你在创业时应该知道的公司法知识》(杨春宝、王成兵,2014 年版)

本词典收录书中律师有特殊实务用法、或用于纠正创业者常见误解的法律概念,共 55 条。定义以**律师在书中的实务用法为准**,不是字典义——每条同时给出"律师怎么用"与"和常识/误解差在哪"。**时效声明**:本书成于 2014 年(基于 2013 年《公司法》修正案),所引《合同法》《中外合资经营企业法》等已被《民法典》(2021)与《外商投资法》(2020)取代;2023 年《公司法》大修(2024-07 施行)更已改写认缴制、决议撤销、派生诉讼等多项规则。术语的现行法状态一律以官方文本为准,书中用法仅反映 2014 年语境。

## 一、核心概念(17 条)

| 术语 | 律师的用法 | 与常识/误解的差异 |
|---|---|---|
| 认缴制 | 只取消设立门槛(无最低资本、无验资、无首期比例),缴纳义务、违约责任、补充清偿责任全部保留;注册资本应按经营需要理性认缴 | 误读为"认缴=不用缴""注册资本可以随便写大"(2023 年《公司法》已改五年实缴+加速到期) |
| 有限责任 | 有前提的护身符:出资到位+不抽逃出资+不混同,三者缺一即失效;股权转让后原股东不再对公司债务负责 | 要么当绝对护身符,要么被追债时不知道边界在哪 |
| 资合与人合 | 解释有限公司全部特殊规则的底层框架:人合性→优先购买权、分红表决可另约;资合性→股份公司增资无优先认购 | 常识以为"谁投资多就听谁的",忽略有限公司并不完全按股权比例定事 |
| 公司章程 | "公司的宪法性文件":增资门槛、分红比例、表决安排、僵局条款、退出机制都授权章程自治;用工商范本=全部放弃自治 | 当成注册手续的一张纸,纠纷时才发现"无章可循" |
| 法人≠法定代表人 | "法人"是组织(公司本身),法定代表人才是自然人;法定代表人由董事长/执行董事/经理担任,与持股比例无关 | 口语把法定代表人简称"法人",又把法定代表人当独立职位或"虚职" |
| 法定代表人变更登记 | 股东会免职决议只对内生效,30 日内须办工商变更,否则对第三人原代表签的合同、提的诉讼公司都得认 | 以为开了免职决议就万事大吉 |
| 挂名法定代表人 | 民事上不担责(亏损、出资不实归股东),行政/刑事上只罚"直接负责的主管人员";"权力下放了,责任却无法下放" | 以为挂名无风险——风险在印章被实际控制人利用、被调查牵连、"是否知情"举证模糊 |
| 非货币出资两要件 | 统一标尺:(1)可用货币估价;(2)可依法转让;且须评估(不得协商定价)+办财产权转移手续 | 把"有价值"等同于"可出资"——劳务、信用、商誉、已抵押财产一律不得出资 |
| 技术股 | 严格两分:个人技术能力作股=劳务出资,违法;真正的技术出资须载体化、可转移、转移后能独立创造价值并评估过户 | 合伙人说"我以技术入股"时,十有八九指的是违法的那种 |
| 干股 | 分红权等权能的协议让渡,非法律意义股权:不能登记、不参与清算剩余分配、不能据此当选董事 | 当成"送的股份" |
| 一人公司财产独立举证 | 举证责任倒置:股东自证公司财产独立,做不到即对公司全部债务连带;普通公司财产混同同样可能被刺破 | 以为一人公司只是"股东只有一个人",不知道自证清白的义务 |
| 子公司不得向母公司出资 | 母子相互持股导致资本重复计算、虚增(实缴 1000 万反向注资 500 万变"1500 万"),工商直接不予受理 | 不知道这条"股权乱伦"禁令,误以为交叉注资是常规操作 |
| 分公司的缔约与责任 | 分公司非法人但可独立缔约、可做被告;最终责任归总公司,实务中可列分公司与总公司为共同被告 | 两个极端都错:"和分公司签的合同无效"、"分公司欠债与总公司无关" |
| 隐名投资(代持) | 协议原则上有效,但只约束隐名/显名双方,不能对抗善意第三人;显名确权须其他股东过半数知晓;规避准入的代持直接无效 | 以为签了代持协议就安全——名义股东处分股权,隐名方只能索赔不能追回 |
| 优先购买权 | 法定权利,优先于受让人的约定权利;对外转让须书面通知,30 日不答复视为同意,跳过通知可诉请转让无效 | 不知道程序时限,以为章程写了就算数 |
| 资本维持原则 | 出资后不得抽回、公司不得随意回购自己股权;股东退股只有转让或减资两条路;离职退股改由控股股东受让以避开红线 | 以为公司"收购股份"条款想写就写,以为退股协议一签就生效 |
| 空壳公司收购 | 实为受让全部股权:隐性债务、违法记录、欠薪欠税一并承接;认缴制后注册很快,买壳价值大减 | 以为"买壳省事" |

## 二、程序性概念(18 条)

| 术语 | 律师的用法 | 与常识/误解的差异 |
|---|---|---|
| 增资决议程序 | 特别决议须代表 2/3 以上表决权通过,董事会无权代作;程序五步(决议→改章程→缴资→出资证明/名册→变更登记)齐全才完整生效 | 只看到大股东 2/3 可合法稀释小股东,不知道程序缺一步效力悬置 |
| 决议无效与可撤销 | 三分法:内容违法→无效(任何人可诉);程序/内容违反章程→60 日内可撤销,逾期失权 | 混淆无效与可撤销;误读表决门槛(有限公司按全体表决权过半数,非出席过半数) |
| 股东会召集程序 | 法定顺序不可绕过:1/10 表决权股东书面提议→董事长→监事→才可自行召集;跳序开会的决议可撤销 | 以为有 10% 表决权就能直接自己开会 |
| 董事会一人一票 | 强制性规定,"董事会按出资比例表决"的章程条款无效;董事可以不是股东 | 想当然把股东会逻辑搬进董事会 |
| 章程僵局条款 | 章程必设条款:股东会 1/2 对 1/2、董事会平票、股东失联都会令决议瘫痪;设计阶梯程序+兜底董事长一票决定权 | 僵局没来时觉得多余——这是"章程自治"最典型的被浪费项 |
| 股东知情权 | 查账簿须书面请求+说明目的,公司 15 日内书面答复;未出资股东同样享有;是收集大股东侵占证据的先手工具 | 以为出资瑕疵就丧失知情权 |
| 股东派生诉讼 | 股东代公司起诉:书面请求监事会/董事会→拒绝或 30 日不起诉→紧急情况→以自己名义起诉;索赔额是公司损失全额 | 以为股东可直接告侵害人、按持股比例索赔 |
| 股东名册 | 对内主张股东权利的依据;证据阶梯=章程+名册+出资证明文件+出资证明书+工商登记 | 只认工商登记,不知道名册才是对内确权核心 |
| 工商登记对抗主义 | 股权变动在协议生效时已生效,登记非生效要件;未登记只是不能对抗第三人,对第三人登记在册者被推定担责 | 以为没登记=没成为股东=能要回出资 |
| 股权转让程序与定价三法 | 四步:签协议→通知其他股东(同意/放弃优先购买)→改名册章程→30 日工商变更;定价参考实缴出资/净资产/评估值;转让款归股东个人 | 以为"公司"能当转让方、转让后还能就未分配利润主张分红 |
| 减资程序 | 退股的唯一合法化路径之一:决议+编资产负债表及财产清单+10 日通知债权人+30 日公告+清偿或担保+变更登记 | 以为股东间一纸退股协议就有效 |
| 组织形式不能直接互变 | 责任形式决定程序:分公司↔子公司、合伙→公司、独资→有限一律"先注销再新设";有限公司→股份公司是唯一可变更路径 | 以为公司像改名字一样能"变更"组织形式;以为合伙变公司能甩掉原无限责任 |
| 股权继承 | 章程无相反规定则继承人自动取得资格,无须其他股东同意;董事长职位不可继承;建议生前以章程排除或安排 | 以为继承股权要其他股东点头,或以为"股权和职位一起传" |
| 公司分立后的债务连带 | 分立前债务由分立后各公司连带承担,"债务由某一家承担"的内部分工未经债权人书面同意对外无效 | 以为内部分工能约束外部债权人 |
| 外资并购审批生效主义 | 外国人受让境内公司股权即属外资并购,协议经审批后方生效;未报批=效力悬置(外商投资法后已改报告制度,本书用法属 2014 语境) | 以为"签了就算数" |
| 外商投资企业境内再投资 | 外资身份看投资主体国籍而非资金来源:外资企业再投资设的公司不算外资、不享优惠,且不能借道绕开产业目录 | 以为"有外资的钱就是外资企业" |
| 港澳台投资比照外资 | 港/澳/台投资者一律比照外商投资管理,不能注册为内资企业(特例与变通另论) | "香港人可以开内资公司"的想当然 |
| 外资准入与产业目录 | 四分法:鼓励/允许类直接登记;限制类须审批且常有股比上限;禁止类任何形式不得投;外资身份看国籍与出资货币无关 | 以为"用人民币出资就不是外资"、以为换个行业形态能绕开禁止类 |

## 三、责任类概念(13 条)

| 术语 | 律师的用法 | 与常识/误解的差异 |
|---|---|---|
| 抽逃出资 | 出资财产即属公司法人财产;隐蔽手法含公司代付股权转让款、验资后抽回、虚开发票提现;民事+行政+刑事三重责任 | 只想到"把钱转走"这种显性情形,不知道代付股款等日常操作也可能构成 |
| 补充赔偿责任 | 公司资不抵债时,未足额出资股东在未出资本息范围内对"公司不能清偿部分"兜底;可被追加为被告或被执行人 | 认缴制"泼冷水"条款——以为不实缴就没任何责任 |
| 瑕疵股权受让人的连带责任 | 分界线=善意:不知道且不应知道瑕疵的受让人不担责;知道或应当知道的与原股东连带;隐瞒瑕疵构成欺诈可撤销合同 | 以为受让股权就全盘接下出资义务(非善意才连带) |
| 出资瑕疵股东的权利限制 | 与出资对应的权利(分红、优先认缴、表决)可按实缴比例限制,但股东资格不因此丧失,知情权不能剥夺 | 两个相反的误解:"不出资就不是股东"与"不出资照样分红" |
| 董监高忠实义务与归入权 | 竞业禁止、篡夺商业机会、自我交易只约束董事/高管,不约束普通股东;违反者所得收入收归公司 | 以为"股东另开同类公司"违法——不违法;以为义务人人平等 |
| 竞业限制(劳动法) | 两层区分:劳动法上约束离职高管/技术人员,最长两年;股东身份的同业投资限制属合同约定,不受两年限 | 把"永远不能从事本行业"当有效条款;把两层义务混为一谈 |
| 缔约过失责任 | 合同无效或被撤销时赔"信赖利益":缔约费用、履约准备费用、丧失缔约机会,而非合同全部履行利益 | 以为被撤销的合同能按原合同索赔全部损失 |
| 承包经营内外债务 | "债务全归承包人"只对内有效:债权人直接找发包公司,公司赔完再向承包人追偿;应对之策=要求承包人提供担保 | 以为一纸承包合同能把债务真正推出公司 |
| 对外担保的决议机构 | 章程未规定时归股东会(九民纪要后越权担保改按相对人善意判断,本书结论已部分过时);债权人索取股东会决议仍是实务标配 | 以为董事会或章里没说就能随便盖公章担保 |
| 企业间借贷 | 成书时企业间直接借贷无效,自然人↔企业借贷有效,利率上限为银行同类贷款利率 4 倍(2015 年后已有限放开、改为 LPR 四倍) | 不知道这条边界,误以为公司间拆借只是"内部往来" |
| 股权出资 | 权属清楚、权能完整、依法可转让方可;须评估,子公司股东变更登记完成才算缴足;已设质权、章程禁转的不得用 | 把"把股权拿来当钱"想得太随意,忽略过户登记才算缴足 |
| 债转股 | 须符合法定情形(已履约的债权/生效裁判确认/重整和解);债权消灭、股权产生,权利性质根本改变;"先增资再取回"=抽逃出资 | 以为债转股只是"换张纸",不知道须法定条件且不认可对第三方出资 |
| 股东身份≠董监高身份 | 出资是股东唯一义务,参与经营是权利而非义务;能辞退的是经理/董事身份,辞不掉股东身份,也无权强迫退股 | "他不干活还占股份"是情绪不是法律问题;大股东也收不回小股东股权 |

## 四、涉外概念(4 条)

| 术语 | 律师的用法 | 与常识/误解的差异 |
|---|---|---|
| 离岸公司 | 在 BVI、开曼等离岸法域注册、不在注册地经营的公司;香港公司≠典型离岸公司(香港系实地征税法域);CRS 与经济实质法已改变其合规成本 | 把香港公司当离岸公司、把离岸架构当无成本工具 |
| 投资总额 | 外资特有:注册资本之外的总投资盘子,差额以股东借款/外债形式存在(债权、须偿还);比例表决定境外借款额度(外商投资法后比例表已无普遍适用意义) | 把"投资总额"当注册资本的同义词 |
| 外国企业常驻代表机构(代表处) | 只能做联络/调研/咨询等非营利活动,不得签业务合同;但在华仍须税务登记并纳税 | 以为代表处=便宜的分公司,既想让它接单又以为不用报税 |
| 外资并购 25% 线 | 外商注资无论比例多少,企业性质都变为外商投资企业,25% 只是待遇分水岭(不享优惠);想保内资身份只有隐名投资一条路 | "收购 28% 还算不算合资"——比例不改变性质,只改变待遇 |

## 五、常见误读纠正(3 条)

| 术语 | 律师的用法 | 与常识/误解的差异 |
|---|---|---|
| 意向书≠合同 | 效力判断阶梯:明示不具约束力→无约束力;具备合同基本条款+未排除约束力+一方已履行且对方接受→已转化为合同;取消意向虽非违约,仍可能担缔约过失责任 | 把意向书当"什么都不是";另纠正:"协议"与"合同"无效力差别 |
| 股权管理办法≠公司章程 | 公司单方制定的股权管理办法、员工持股规定未经章程吸纳或股东决议确认,对股东无约束力;离职退股"按注册资本原值返还"因显失公平无效,应按净资产/评估值 | 以为公司发个文件就能规定员工的股权命运 |
| 职工持股会 | 未经登记、非民事主体,不是公司股东;会员对公司不享有股东权(无原告资格),登记在理事长名下的股权实为信托式代持,权利只能内部主张 | 改制企业幻觉:以为拿了持股会出资证明书就是股东 |
