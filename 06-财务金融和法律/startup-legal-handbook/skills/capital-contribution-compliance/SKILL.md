# 出资合规与瑕疵责任

## R — 原文 (Reading)

> "股东可以用货币出资，也可以用实物、知识产权、土地使用权等可以用货币估价并可以依法转让的非货币财产作价出资。"
>
> — 杨春宝、王成兵,《创业投资法律手册》第一章 问题22(引《公司法》第27条)

> "它实际上是一种“劳务出资”，而不是我国公司法意义上的技术出资，并不符合可以用货币估价并可以依法转让这一前提条件。"
>
> — 同书第一章 问题23

> "股东或者发起人不得以劳务、信用、自然人姓名、商誉、特许经营权或者设定担保的财产等作价出资。"
>
> — 同书第一章 问题23(引《公司注册资本登记管理规定》第5条)

> "债权人有权诉请法院判令钱先生对公司债务不能清偿的部分承担补充赔偿责任。"
>
> — 同书第二章 问题39

> "股东在公司成立后，不得抽逃已投入到公司的出资。""抽逃出资可能面临民事、行政甚至刑事责任。"
>
> — 同书第二章 问题41

> "受让人对此知道或者应当知道，公司请求该股东履行出资义务、受让人对此承担连带责任的，人民法院应予支持。"
>
> — 同书第二章 问题44(引《公司法司法解释三》第18条)

> "出资存在瑕疵的股东，在其未丧失公司股东身份之前仍可按照公司法或者公司章程的规定行使相应的股东权。"
>
> — 同书第二章 问题45

> "在建工程属于可以评估作价并且可以依法转让的非货币财产。"
>
> — 同书第一章 问题22

> "债权作为一种可以用货币估价并可以依法转让的非货币财产，可以作为出资的一种形式。"
>

## I — 方法论骨架 (Interpretation)

作者的核心主张:出资是股东对公司唯一的法定义务,有限责任的保护以"出资到位且不抽回"为前提。判断与责任按四层展开:

1. **非货币出资两要件**:任一非货币财产入股,必须同时满足"可以用货币估价"+"可以依法转让"。两要件之外还有一份法定禁止清单——**劳务、信用、自然人姓名、商誉、特许经营权、设定担保的财产**不得作价出资。创业者常把"技术能力""客户资源""拉来的关系"折成股份,这些本质是劳务或信用,落入禁止清单,直接违法。
2. **"技术股"的法律含义**:法律意义的技术出资须载体化(记载于载体)、可转移控制、转移后能独立为受让人创造价值;光是"我懂技术、我来干活"是劳务出资,不能作价入股。合法替代路径:股东无偿转让股权、章程约定超额分红权、干股(仅分红权)。另有一条程序铁律:**约定占股比例不能替代评估程序**——非货币出资必须经有资质的评估机构评估作价。
3. **认缴≠不缴**:2013 年修法取消最低资本与验资,但缴纳义务、违约责任、补充清偿责任全保留——未足额出资股东对守约股东担违约责任,并在**未出资本息范围内**对公司债务不能清偿部分向债权人承担补充赔偿责任;出资瑕疵也不因此否定股东资格(知情权一般仍在),但分红、优先认缴、表决等与出资对应的权利按**实缴比例**受限,经催告仍不缴可决议解除资格。资本维持原则下,存续中股东不得抽回出资,退股只能走转让或法定减资。
4. **抽逃出资三重责任与债权人路径**:出资一旦投入即成法人财产,抽逃面临民事(返还+赔偿)、行政(抽逃额 5%–15% 罚款)、刑事三重责任(书内追诉标准:有限公司 30 万且占实缴 60% 以上等)。易踩场景:公司成立后立即"过桥"转出注册资本、用公司资金代付股东个人股权转让款、假借购料名义转款还个人债。债权人追责有两条路径:诉讼阶段直接列股东为被告,或执行程序中申请追加——取决于证据取得时点;受让瑕疵股权时**知情即连带**,资本充实责任不随转让链条消失。

各财产类型逐项判定:专利/商标(注册商标可;申请中未获注册的商标不宜出资)→须评估+办理转让登记,只交付不登记=出资义务未完全履行;股权→权属清楚、权能完整、可转让(已质押、章程禁转、应批准未批准的不得),出资后原股东不再持有该股权;在建工程→可出资,须办转让登记,竣工后由公司直接办房产证;债权→可债转股,但须符合法定情形且工商只认可对债务人本身的债权;借款给公司→合法,但那是债权不是出资,定性凭协议与凭证,定性不明则追偿无门。

## A1 — 书中的应用 (Past Application)

### 案例 1: 高博士想以"技术"多占 10% 股(第一章 问题23-24、26)
- **问题**: 高博士技术过硬,负责公司技术与业务经营,要求以技术出资多占 10% 达到 60% 股权;后来一位技术合作人姜先生以 2 项发明专利+1 项实用新型约定入股 30%,主张"已约定占股比例,无需再评估"。
- **方法论的使用**: 律师指出高博士的"技术特长"实为劳务出资,为法律禁止——合法路径是其他股东无偿转让股权、章程约定 60% 分红权或干股(仅分红权);而姜先生的专利虽属合格出资物,约定占股 30% 不能替代评估程序,必须先评估再按评估结果通过协议安排实现占股。
- **结论**: "技术能力"折股违法,载体化知识产权折股可行但评估程序不可省——两要件+评估程序是判断的唯一标尺。

### 案例 2: 吕先生借高利贷出资后抽逃(第二章 问题41)
- **问题**: 吕先生借高利贷筹措出资,公司起色后伪造银行对账单与购货发票,假借购买原料名义从公司账户转出 200 余万元偿还个人高利贷,公司随之陷入困顿。
- **方法论的使用**: 律师认定出资一旦投入即属法人财产,股东不得抽回;吕先生伪造凭证转款还个人债务构成抽逃出资且数额巨大,除民事返还赔偿、行政罚款外,已构成抽逃出资罪。
- **结论**: 借钱出资合法,但必须严格区分个人债务与公司债务、以合法方式偿还——"转出来还上再说"是三重责任的入口。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 注册公司或引入合伙人时商量出资结构:"我这技术/资源/设备/专利能不能折股""认缴 1000 万写 2050 年缴足行不行"
2. 股东已出现出资问题:有人没缴齐、想把注册资本转走"周转"、退出时想直接拿回出资、追加投入没签任何协议
3. 对外视角:公司欠我的钱,发现它股东出资没到位/抽逃过,能不能追股东个人;受让股权前要不要查实缴凭证

### 语言信号 (用户的话里出现这些就应激活)

- "以技术/劳务/资源/客户入股行不行""技术股怎么算"
- "认缴制是不是不用实际缴钱""注册资本写多大合适""认缴期限写长一点"
- "把钱转出来用一下再还回去""抽逃出资有什么后果"
- "他没出资/出资没到位,能限制他的股东权利吗""能追加股东为被执行人吗"

### 与相邻 skill 的区分

- 与 `entity-choice-incorporation` 的区别: 那是选合伙还是公司、设立程序;本 skill 假定公司形式已定,聚焦"拿什么出资、出资不到位怎么办"
- 与 `equity-rights-design` 的区别: 那是表决权/分红权的权益结构安排;本 skill 处理出资形式合法性、缴纳义务与瑕疵责任——"技术股怎么合法实现"两边都沾,以出资形式合法性为主时归本 skill
- 与 `veil-piercing-liability` 的区别: 那是财产混同等滥用情形下的人格否认;抽逃出资只是其触发情形之一,本 skill 覆盖出资全流程的合规与责任
- 与 `capital-change-restructuring` 的区别: 那是增资减资的程序要件;本 skill 只在"以减资掩盖退股/抽回出资"的定性处与其衔接
- 与 `nominee-shareholding-risk` 的区别: 那是代持安排;本 skill 处理名义股东被登记后须承担补足出资责任的对外一面

## E — 可执行步骤 (Execution)

1. **第一步:出资物两要件判定**
   - 逐项过:拟出资物能否用货币估价?能否依法转让?再对照禁止清单(劳务/信用/姓名/商誉/特许经营权/已设担保财产)一票否决
   - 完成标准:每个出资物给出"合格/不合格+理由",不合格的给出替代路径(现金出资+协议补偿/无偿转让股权/章程约定分红权)
   - 判停条件:用户问的其实是企业形式选择(合伙 vs 公司)时,转 entity-choice-incorporation

2. **第二步:非货币出资程序合规检查**
   - 有资质评估机构评估作价(约定占股比例不能替代)→办理财产权转移手续(知识产权过户登记/不动产过户/股权过户)→只交付不登记=出资未完全履行
   - 完成标准:列出"评估→转移登记→出资证明"三步各自的办理要点与缺口

3. **第三步:认缴义务与期限风险评估**
   - 核对各股东认缴额、章程约定期限与实缴现状;区分"未届期"与"逾期未缴";评估公司资不抵债时股东补充清偿敞口
   - 完成标准:给出每位股东的出资状态表(认缴/实缴/差额/责任性质)
   - 判停条件:用户诉求是增资或减资程序设计时,转 capital-change-restructuring

4. **第四步:瑕疵与抽逃定性及责任路径**
   - 区分三种情形:未足额出资(补充赔偿+权利按实缴受限)、抽逃出资(民事+行政+刑事三重风险)、追加投入定性不明(凭协议与凭证定股权还是债权);债权人视角给出"诉讼列被告 vs 执行追加"的选择;受让方尽调必须核查实缴凭证
   - 完成标准:对每一情形输出责任主体、责任范围、可走的追责/补救程序清单

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是"开合伙还是开公司""注册流程"——企业形式与设立程序归 entity-choice-incorporation
- 用户需要的是表决权/分红权/激励股权的结构设计——归 equity-rights-design 或 employee-equity-incentive,本 skill 只回答其中"出资形式合法性"的一半
- 上市公司、金融等实缴制特殊行业的资本规则(本书视角是认缴制下的一般有限公司)

### 作者在书中警告的失败模式

- 把"技术能力/客户资源"当技术股折价入股 → 劳务出资违法,出资瑕疵埋雷
- "认缴=不缴" → 补充清偿责任与违约责任全保留,认缴额即责任上限
- 注册资本"过桥"转出、公司资金付股东个人受让款 → 抽逃出资三重责任
- 追加投入不留凭证、不签协议 → 股权还是债权定性不明,清算时追偿无门
- 只签"退股协议"拿回出资、不走减资 → 协议只能解释为未履行的股权转让,用公司资金支付还侵犯法人财产

### 作者的盲点 / 时代局限

- **法律时效性警示(必须读)**:本书为 2014 年版(2013《公司法》修正案语境)。2023 年《公司法》(2024-07 施行)已实质改写本 skill 的多个落点:①**认缴期限改为 5 年实缴**并设存量公司过渡期,书内"期限自治、写多长都合法"的结论已被推翻,超长期限条款从合法设计变成必须整改的瑕疵,且新增加速到期、股东失权、董事会核查催缴义务;②**虚报/抽逃刑责口径有变化**——2014 年全国人大常委会立法解释后两罪仅适用实缴登记制公司,书内 30 万/60% 追诉标准不能直接套用,2023 年修法后行政罚款幅度亦已提高,引用刑事与数字表述前必须按现行法核实;③书内"禁止非金融企业间相互借贷"的背景(第一章 问题32)在 2015 年民间借贷司法解释后已变,企业间偶发借贷有效、利率上限改为 LPR 4 倍;④瑕疵股权转让责任(书内引《公司法司法解释三》第18条)在 2023 年《公司法》第88条及后续立法解释下另有规则排序。凡涉具体数字、程序、罪名,一律以现行法为准。
- 本 skill 输出为**方法论蒸馏,不构成法律意见**;出资结构、抽逃定性等重大事项请咨询执业律师。
- 作者为园区顾问,答案倾向"可以变通安排",全书几乎无税务维度——非货币出资评估作价、股权出资、债转股均有税负后果,书中未覆盖,设计时须另行补足。
- 案例全部化名并经律师转述,事实细节无法核对原案;结论基于上海登记实践,各地工商口径有差异。

### 容易混淆的邻近方法论

- "技术股"在本书有两个身份:法律意义的**技术出资**(载体化+评估+转让)与**干股/超额分红权**安排(无需出资)——混用会同时踩出资违法与权益结构两个坑,后者归 equity-rights-design
- 股东借款给公司 vs 增资:同一笔钱两种定性,凭证决定命运;债转股则须符合法定情形——与 nominee-shareholding-risk 的"隐名出资定性"问题相邻但不同
- 抽逃出资 vs 财产混同:前者是"拿回出资",后者是"公私不分",责任路径不同(三重责任 vs 人格否认连带),勿在分析中互换
