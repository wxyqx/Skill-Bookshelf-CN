# 章程定制与治理权力分配

## R — 原文 (Reading)

> "股东会会议、董事会会议无法召开或者无法形成有效决议的情况确实比较常见,我们称之为'僵局'。"
>
> — 杨春宝、王成兵,《创业投资法律手册》第三章 问题92

---

## I — 方法论骨架 (Interpretation)

作者的核心主张:公司法把大量治理事项授权章程约定,而绝大多数创业者直接用工商局格式文本,等于把这份自治权整个扔掉——纠纷发生时"无章可循",很多公司因此僵死。章程设计按四层展开:

1. **表决权数学(事前算账)**:修改章程、增减资本、合并分立解散等七类重大事项须代表 **2/3 以上表决权**的股东通过——注意基数是"全体股东所持表决权"而非出席者(有限公司);任何一方持股超过 1/3 即可否决一切重大决议;任何一方恰好 50% 则普通决议永远通不过。三人各 33.3% 是经典的僵局结构。
2. **董事会与股东会的边界**:董事会表决实行一人一票,是强制性规定——章程改"按出资比例表决"无效;合法的弹性在别处:全体股东书面一致同意可不召开股东会直接决定;董事提名权尽量贴近股权比例;重大事项决定权上收股东会。
3. **授权清单(约束经营者)**:对执行董事/总经理逐项写明权限——日常开支限额、合同签署限额、资产交易限额、担保限额、能否从事金融与房地产投资、制度制定权、人事规模与薪资;或反向界定:列明股东会保留权利,其余才归经营者。授权不明确,越权交易连追责的请求权基础都没有(相对方无恶意时交易还撤不掉)。
4. **僵局条款与控制权可行性**:僵局条款先约定程序化破解步骤(调停、冷静期、事项拆分),程序穷尽后才赋予董事长一票决定权——不要一上来就给终裁权。评估控制权争夺可行性时逐项过牌:股权转让降比、增资稀释、董事会改选,多数手段都以对方配合为前提——根本出路是把设计做在章程里。

## A1 — 书中的应用 (Past Application)

### 案例 1: 三人平股公司怎么搭治理结构(第三章 问题97-98)
- **问题**: 三名创始人各持股 1/3,问职位怎么分才平衡。
- **方法论的使用**: 律师指出职位分配不是核心,章程对职务权力范围的界定才是;配套清晰财务制度与监督机制;表决权上避免任何人恰好 1/2——可约定表决权 51% 以上或由一人出资过半。
- **结论**: 用章程权限界定+表决权微调替代"职位平衡"的直觉方案,从结构上消除僵局。

### 案例 2: 执行董事擅自设子公司并转让资产(第三章 问题85)
- **问题**: 执行董事越权设立子公司并转走资产,小股东想撤销交易。
- **方法论的使用**: 交易相对方无恶意即不可撤销(表见代表),只能依章程和法律追究执行董事个人赔偿;而追责的前提是章程有明确的授权边界——本案章程没有。
- **结论**: "授权不明确则连追责的机会都没有"——由此给出七个维度的授权清单与反向界定技术。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 注册公司前(或增资/引入新股东时)要起草或修订章程,问"章程该写什么"
2. 多位创始人讨论股权与表决结构("五五分""三人平分""一票否决给不给")
3. 想限制某个股东/经营者(执行董事、职业经理人)的权力,或评估夺回控制权有哪些牌

### 语言信号 (用户的话里出现这些就应激活)

- "章程怎么写/要不要用工商范本"
- "我们五五开/平分股权,会不会出问题"
- "怎么防止他一个人说了算/怎么限制执行董事"
- "股东会决议通不过怎么办/僵局条款"

### 与相邻 skill 的区分

- 与 `resolution-validity-procedure` 的区别: 那是决议已经出了问题(程序瑕疵、效力之争);本 skill 是事前设计,让问题不发生
- 与 `paper-validity-traps` 的区别: 那是识别"以为生效其实失效"的文件陷阱;本 skill 主动给出设计工具
- 与 `equity-rights-design` 的区别: 那是表决权/分红权/技术股的权益结构安排;本 skill 覆盖治理机构、授权与僵局的完整章程设计

## E — 可执行步骤 (Execution)

1. **第一步:表决权结构体检**
   - 列出各股东持股与表决权,检查三条线:是否有人≥2/3(可独断重大事项)、>1/3(可否决重大事项)、恰好 50%(普通决议死穴)
   - 完成标准:给出表决权分布表与三条线的判定结论
   - 判停条件:用户只有纯分红安排、无公司治理诉求时,转 equity-rights-design

2. **第二步:权力清单分配**
   - 按"股东会保留权利清单→董事会/执行董事授权清单(七个维度)→经理职权"三层分配;重大事项(七类 2/3 事项)必须留在股东会
   - 完成标准:每项权力有明确归属与限额,无"其余由董事长决定"式的兜底授权

3. **第三步:僵局预防写入章程**
   - 表决权结构避开 50% 死穴;写明僵局的程序化破解步骤(协商→调停→事项拆分),最后才考虑董事长终裁权;约定临时会议召集与送达留痕规则
   - 完成标准:僵局条款可执行(谁能启动、什么顺序、最终由谁决定)

4. **第四步:输出章程条欛建议清单**
   - 汇总为"建议写入章程的条款清单",逐条注明设计理由;提示哪些约定需与工商登记文件一致
   - 完成标准:清单可直接交给律师起草,且每条能追溯到前面某步的分析

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 股份公司/上市公司治理(本书视角是有限公司;股份公司按出席表决权计基数、治理规则不同)
- 用户需要现成章程范本文本——本书反复强调"不要用范本",但全书也未提供条款示范文本,本 skill 输出的是设计要点清单,正式文本仍需律师起草
- 合伙企业、个人独资企业的内部治理(规则体系不同)

### 作者在书中警告的失败模式

- 用工商格式章程 → 纠纷时无章可循,是全书重复率最高的失败根源
- 章程把董事会表决改成"按资表决" → 违反强制性规定,决议无效
- 恰好 50%:50 表决权 + 无僵局条款 → 公司决策瘫痪(50/50 与三人各 1/3 都是高危结构)

### 作者的盲点 / 时代局限

- **时效性警示**:本书为 2014 年版(2013《公司法》修正案语境)。2023 年《公司法》(2024-07 施行)对法定代表人制度、董事责任、决议撤销规则等有实质修改,引用具体条文前必须对照现行法核实;本 skill 输出为方法论蒸馏,不构成法律意见,重大事项请咨询执业律师
- 全书基于上海园区语境,登记实践各地有差异
- 书中只讲"要定制章程",未提供章程条款示范文本;税务维度(股权安排的税负)几乎未覆盖

### 容易混淆的邻近方法论

- 股权代持下的治理安排:代持场景的表决权行使另受隐名投资规则约束(见 nominee-shareholding-risk)
- "一致行动协议"等现代投资条款工具:本书未覆盖,设计时勿混入
