# ============ 第1章 撒旦的糖果：创业 ============

- id: p01

  type: principle
  source_chapter: 第1章、第4章
  source_quote: |
    "那数百万美元的投资最好是在你已经验证了你的商业模式后再到你的账上，而不是在这之前，因为过早地获得融资可能会置你于死地。"
  summary: |

- id: p08
  title: 为顶尖人才慷慨支付：股权与薪酬都不要小家子气
  type: principle
  source_chapter: 第1章、第6章
  source_quote: |
    "一个出色的员工的价值要远超十位平庸的员工的价值。如果这个人真的非常适合你的公司，你就应该支付远高于平均水平的薪酬，而不是小气地精打细算。"
  summary: |
    薪酬与股权的慷慨原则：一个出色员工的价值远超十位平庸者，对真正合适的人应支付远高于平均水平的薪酬，并用长期职业目标、工作环境、价值观等多重因素争取（优秀应聘者永远抢手，招聘是双向选择）。股权同理：早期给不到5%只是雇员，5%以上才是共同创始人（作者自己的公司由共同创始人平分股权），早期员工与顾问都应获得股权（顾问0.25%~1%），可用书面期望绑定＋分期兑现控制风险；完成后应支付高于行业均值的工资。理由：创业是孤注一掷的游戏，股权与薪酬都是用来吸引最出色人才的，员工跳槽的代价远高于工资差额。注意中美文化差异（中国投资人常要求CEO绝对控股）。

- id: p11
  title: 绝不保密你的创意
  type: principle
  source_chapter: 第1章
  source_quote: |
    "某个你认识的人剽窃了你的创意这种事情，在现实中发生的概率也许要低于千分之一，但如果你没有在早期将你的想法与合适的人进行沟通……最终失败的概率很可能会超过80%。"

- id: p14
  title: 需求为王，不能凭空创造需求
  type: principle
  source_chapter: 第1章
  source_quote: |
    "没有人能够凭空创造需求，这根本就是神话。需求总是独立于产品而存在的。……你唯一的职责就是寻找到一种没有被满足的需求，并且创造出能填补这一需求的产品。"
  summary: |

- id: p15
  title: "好东西"是死亡之吻，产品必须是必需品
  type: principle
  source_chapter: 第1章
  source_quote: |
    "在'必需品'和'好东西'这两类产品之间存在着巨大的鸿沟。如果你销售的是'好东西'，没有人——哪怕是你最好的朋友——会长期使用它。……对于创业公司来讲'好东西'实际上是死亡之吻。"
  summary: |
    产品分类原则：产品必须是"必需品"（解决关键问题或提供无处可获得的价值）而非"好东西"（可有可无的不错产品）。价值必须大于生活惯性，否则没人愿意改变。发现产品沦为"好东西"时唯一出路是重新开始。验证手段：软件做MVP加贝塔测试，观察用户是否回头、使用频率、是否推荐。

# ============ 第2章 获得风险投资 ============

- id: p16
  title: 三年5000万美元营收：接触风投的资格线
  type: principle
  source_chapter: 第2章
  source_quote: |
    "除非一家创业公司能够证明它可以在接下来的三年时间里实现指数级增长，即到第三年的时候，它每年至少有5 000万美元的营业收入，否则根本没有必要去接触风险投资。"
  summary: |
    操作性自检标准：只有能证明三年内指数级增长、第三年年营收至少5000万美元的公司才应接触风投；否则要么转向（pivot），要么调整预期去用其他融资方式。商业模式不适合风投时，一厢情愿和抱怨都无济于事。这是"什么时候不该融资"的第一判据。
  tags: [fundraising-fit, venture-capital, timing]
  origin: [pb01(B/第2章)]

- id: p17
  title: 准备好之前避开大牌风投（负面信号风险）
  type: principle
  source_chapter: 第2章
  source_quote: |
    "这就是为什么我会告诉那些创业公司，在它们准备好以前，最好还是避开大型风险投资公司，毕竟负面信号所蕴含的风险是不可控的。"
  summary: |
    早期引进红杉、Accel级别的风投后，若它们在后续几轮不再跟进，等于向其他投资人宣告"这家公司出了问题"，会吓跑整个市场。天使和种子投资人不跟进是常态，但大牌风投的缺席是强负面信号。原则：在证明上升势头之前不要为名气而拿大牌的钱。
  tags: [signal-risk, timing, venture-capital]
  origin: [pb02(B/第2章)]

- id: p18
  title: 绝不拿竞争对手企业的钱
  type: principle
  source_chapter: 第2章
  source_quote: |
    "在这里我有一条规则：当你面对企业投资人的时候，如果这家企业是你其他客户的竞争对手，就绝对不要拿它的钱。"
  summary: |
    企业投资人出于战略而非财务回报投资，其目标与你的最大利益可能冲突：与其结盟后你可能很难再和它的竞争对手做生意，业务受到严重限制。判断规则一句话：这家企业是你客户的对手，钱再多也不要。天使和风投的钱没有这个缺点。
  tags: [corporate-vc, conflict-of-interest, rule]
  origin: [pb03(B/第2章)]

- id: p19
  title: 融资前先询价校准估值
  type: principle
  source_chapter: 第2章
  source_quote: |
    "在进行融资之前，每一位创业者应该尽可能多的与风险投资公司的内部人员进行沟通，但不要向他们提出你的融资要求，而是要求他们对你的公司的价值进行快速地评估。"
  summary: |
    你的公司真正价值只等于市场愿意支付的金额。融资前尽可能多地收集数据：请风投内部人员不谈投资、只做快速估值评估；询问其他创业者市场行情；查Crunchbase、AngelList等网站的融资和估值排名。数据越多越好，用它们校准预期，避免坚持幻想估值而浪费一年。
  tags: [valuation, market-feedback, preparation]
  origin: [pb04(B/第2章)]

- id: p20
  title: 好律师给直截了当的商业建议
  type: principle
  source_chapter: 第2章
