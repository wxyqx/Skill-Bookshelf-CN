# Scanner A（front+第1章）候选

## 第一部分：章节 digest

### front（版权页+推荐序×2+前言）

本书是硅谷顶级创业孵化器"创始人空间"（Founders Space）CEO 史蒂文·霍夫曼（人称"霍夫曼船长"）继《让大象飞》之后的创业方法论新作，周海云译，中信出版集团2020年版。全书定位为"创业者在逆境中的生存指南"，核心议题覆盖是否该创业、融资途径与风险、增长策略与领导力。推荐序一（毛大庆）把"十条不要创业的理由"归纳为暴富、逃避、跟风三种心态，并强调"融资弹药需要回报"；推荐序二（蔡剑）提出从失误中学、从失败中悟、从失去中得的阅读视角。前言"船长日志"自述作者曾全自有资金创立两家公司、风投支持下创立三家公司，本书旨在帮创业者穿越寒冬、拥抱不确定性。

### 第一章 撒旦的糖果：创业

本章回答创业者出发前的根本抉择。核心论点：创业只适合极少数人，且出发理由必须正确——霍夫曼先给出"是否该跨出那一步"的自我拷问清单，再列出10个不该创业的理由（成为自己的老板、快速成名致富、逃避无聊工作、解决情感问题、取悦他人、跟风、怕错过机会、寻求刺激、寻找意义、笼统的改变世界），指出唯一正确的创业理由是"解决某个特定问题的强烈冲动"并辅以积蓄、支持系统等现实条件。

在资源与风险上，作者强调现金是企业的燃料，核心策略是"用最少的钱和时间证明设想"；把向亲朋好友借钱称为"撒旦的糖果"，原则上绝对禁止（父母赠与除外），并用 Gust 2.5% 融资率、天使投资4年后仅17%表现良好、超过90%初创企业失败等数据支撑风险认知。Halo Top 冰激凌案例则说明：当证据确凿时，可以打破一切规则孤注一掷。

在团队上，人才重于创意：独角兽统计显示2-3位创始人最理想；原则包括只收全身心投入的人、只聘用卓越人才、寻找"放大型"人才、组建互补团队、用股权而非现金支付且不要小家气。在验证上，提出"创新循环"8步框架（创意→分解假设→设计证伪实验→收集分析数据→迭代或重构），主张使命不是证明创意可行而是证伪它、绝不保密创意、尽早获得客户反馈、"需求为王"不能凭空创造需求、产品必须是"必需品"而非"好东西"（死亡之吻），并以 CB Insights 20种失败原因收尾，最后主张通过"重新制定规则"（反其道而行之）获得不公平优势。
