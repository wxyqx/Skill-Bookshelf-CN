# 跑通融资流程：把融资本身当作一条销售管道来管

## R — 原文 (Reading)

## I — 方法论骨架 (Interpretation)

融资不是一场演讲，而是一条可以逐格追踪的销售管道。本书把它拆成六个可执行的子系统：

1. **估值先问市场，再报价（房产类比估值法）**：想确切知道一套房子的价值，唯一方法是看同一社区最近的成交价。私营公司同理——查同阶段、同领域公司的融资数据（Crunchbase、AngelList），投资人脑中也是这个模型。融资前主动"询价校准"：请多家风投内部人员不谈投资、只做快速估值评估，再问其他创业者行情。你的公司真正价值只等于市场愿意支付的金额；估值还随市场波动（风投资金供应多的地区高、供应少的地区低）。
2. **定价取钟形曲线的中位数**：把多渠道收到的估值数据点画成钟形曲线——定价太低自己吃亏，太高只会减慢融资进度，取曲线中部。唯一例外：公司非常热门、有多个竞标者时，让几家同时竞标，既能抬升估值和条款，又能大幅缩短融资时间。
3. **融资十步销售路径**：见面→递交并陈述商业计划→讨论答疑→巩固关系→签投资意向书（TS）→协议谈判→尽职调查→签最终协议→钱到账→完成。最困难的是第五步签 TS。核心纪律：钱到账之前一切都只是一厢情愿——写下每一步，逐格追踪。
4. **渠道法则：常备 10 个投资人 + 三振出局**：渠道中始终保有约 10 个潜在投资人——少了，唯一的买家可以放慢节奏、在每项条款上锱铢必较；多了，精力分散管不过来。跟进节奏：路演次日发跟进邮件、等一周；无回复发第二封、再等一周；第三封后仍沉默即出局。第二次会面要设定成交目标、邀请能拍板的人到场，并提前问清对方决策流程（是否需全体合伙人会议）。
5. **竞争张力：隔离、双承诺、截止日期**：目标永远是让至少两家投资人差不多同时承诺，同时谈判争取最好条款。投资人会反复打听你还在和谁谈——克制冲动，无法 100% 确信其真实承诺前绝不透露竞争信息；被施压时用"若对方也感兴趣就介绍"激起其竞争天性：让他们竞争，而不是让他们串通。同时人为设定截止日期并真的执行——口头承诺只有到决策时刻才能验证，截止日会揭示谁是真投资人。
6. **背书：先锁领投人，再攀意见领袖**：强有力的领投人会带动其他投资人跟投，所以先集中火力锁定领投。社会资本——有影响力的重要人士的背书——作用远超一千个不知名投资人。做法：列出本垂直领域最有影响力的思想领袖名单，尽一切努力请他们加入；找出对方真正需要的东西并提供价值，抓住第一条大鱼后第二条容易得多。前提是真诚，否则会被识破。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1500 万美元估值的创始人
- **问题**: 一位创始人手里只有创意（连产品都没有），坚持交易前估值 1500 万美元，一年融不到资。
- **方法论的使用**: 作者介绍投资人让他感受市场、做询价校准——投资人喜欢项目但拒绝按幻想价格报价；市场数据明确显示只愿支付远低于此的金额。
- **结论**: 公司真正价值只等于市场愿意支付的金额；坚持幻想估值唯一的效果是拖慢融资。
- **结果**: 他在外漂泊一年后回到最初报价，两年后以该估值成交——但此时该领域融资已比一年前困难得多。早一个月校准，胜过晚一年坚持。

### 案例 2: 迪士尼拖延与圣诞截止日
- **问题**: 作者第三家创业公司融资时，迪士尼旗下思伟投资的朋友六次会面每次都说"真的很感兴趣、会投资"，却始终按兵不动。
- **方法论的使用**: 渠道管理 + 人为截止日期：宣布转投他人并真的约到世界最大对冲基金之一，同时维持另一家传媒巨头兴趣的朦胧感，无视"圣诞前无法成交"的行业惯性，要求圣诞前完成。
- **结论**: 口头承诺只有在实际决策时刻才能验证；截止日期揭示谁是真投资人——对朋友也一样要设截止期限。
- **结果**: 融资在圣诞前几天达成；拖延数月的"热诚朋友"当场现形。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 已开始见投资人，要给本轮定价：估值定多少、会不会稀释太多、市场行情如何。
2. 同时在谈多家机构，管不过来或被一家拖住：跟进节奏怎么排、沉默的还要不要追、怎么防止被压价。
3. 要制造竞争、设截止日期或找领投与背书：怎么让几家抢起来、领投怎么锁定、找行业大佬站台有没有用。

### 语言信号 (用户的话里出现这些就应激活)

- "估值定多少""可比公司怎么查""稀释太多怎么办""行情是多少"
- "同时在谈五家怎么排""这家一直拖着不回复""要不要再等等他"
- "怎么让他们互相竞争""截止日期该不该设""找谁当领投""找个大 V 背书有用吗""TS 签了下一步做什么"

### 与相邻 skill 的区分

- 与 `pitch-materials-that-land` 的区别：那个管"给投资人看什么"——11 页路演 PPT、冷邮件、视频、融资故事怎么写；本 skill 管"流程怎么跑"——估值、渠道、跟进、成交。用户在改材料/写邮件→那边；在定价格、管节奏、推进度→本 skill。
- 与 `win-the-pitch-room` 的区别：那个管"会面现场和谈判桌上怎么说话"——开场、主动提问、扑克脸、心理施压；本 skill 管"流程结构与时间表"。截止日期的重叠处：作为话术在房间里制造紧迫感→那边；作为管道设计让两家同时承诺并验证承诺真伪→这边。
- 与 `vc-dynamics-demystified` 的区别：那个理解对手的赚钱机制与轮次匹配，本 skill 执行流程本身。
- 与 `vet-investors-and-advisors` 的区别：那个筛人背调（真伪、冲突、律师），本 skill 在人已入渠道后跑流程。

## E — 可执行步骤 (Execution)

1. **校准估值（对应十步之前置）**：查同阶段同领域可比融资数据；请 3-5 家风投内部人员做非正式估值评估，再问其他创业者行情；把数据画成钟形曲线，取中位数定价（热门多竞标者除外，改为组织同时竞标）
   - 完成标准：能说出至少 3 个可比交易，写出一个有数据依据的估值区间和最终选定数字。
2. **建满渠道（步骤 1-2）**：列出并持续维持约 10 个活跃投资人，含来源、联系人与阶段标签；领投候选单独标注
   - 完成标准：渠道表 ≥10 行且每周更新，无"唯一希望"。
3. **批量推进、三振出局（步骤 2-4）**：每次路演次日发跟进邮件，一周无回复发第二封，再一周发第三封，仍沉默即出局并转移精力；第二次会面设定成交目标、邀请拍板人到场、问清决策流程
   - 完成标准：每个投资人有明确阶段标签，没有任何人"悬而未决"超过三周。
4. **制造双承诺与截止日期（步骤 5 前后）**：保持投资人相互隔离直到至少两家同时准备成交；绝不暴露绝望与急迫；宣布人为截止日期并真的执行
   - 完成标准：至少两家同时进入 TS 谈判；截止日期已宣布且观察到它真实改变了某家投资人的行动。
5. **锁领投、签 TS、追到账（步骤 5-10）**：先锁定强领投带动其他投资人；TS 签署前披露所有实质性信息；尽调与最终协议按十步清单逐项推进，全部协议集中存于云文件夹；钱到账前不宣布成功
   - 完成标准：钱到账，追踪表上十步各有日期记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还在决定要不要融资、这笔钱该不该拿——转 `choose-your-funding-path`。
- 用户要做路演 PPT、电梯路演、冷邮件、融资视频——转 `pitch-materials-that-land`。
- 用户问的是会面现场的表达、提问与谈判话术——转 `win-the-pitch-room`。
- 用户在筛选/背调投资人、选律师——转 `vet-investors-and-advisors`。
- 清算优先权等条款的法律分析——转专业律师（书中亦强调复杂交易必须请最好的律师）。

### 作者在书中警告的失败模式

- **暴露绝望**：作者第一次风险融资时让投资人知道自己多急缺现金，估值立刻被砍半；更重的后果是被趁急逼签强制性融资、股权大规模稀释直至控制权旁落——哪怕在破产边缘也要表现出随时可以离开。
- **串通报价**：应投资人要求把他们互相介绍＝他们会串通最后的报价压低条件；正确做法是保持隔离，让他们竞争而不是串通。
- **摇摆投资人**：把犹豫不决者和未承诺者放进同一投资组合，会在他们之间埋下怀疑的种子并毁掉整笔交易——100% 确认真实承诺前绝不引入。
- **口头承诺**：作者的朋友六次会面说"会投"却按兵不动；不到决策时刻连投资人自己都不知道会不会真投。
- **TS 无约束力**：投资人借意向书锁定交易、排除竞争者后拖延甚至临时改条款，一家公司白付 4 万美元律师费还蒙上"被领投放弃"的阴影。
- **文件散落**：协议分散存放（不少在一台旧笔记本里），补材料数周期间原本感兴趣的投资人已转向别处。
- **隐瞒实质信息**：有 CEO 把核心 IP 登记在个人名下且隐瞒，尽调中暴露后被断绝的不止这笔交易，而是声誉与全部融资渠道。

### 作者的盲点 / 时代局限

- 节奏经验（两个月完成 A 轮等）基于 2012-2019 美国低利率风投周期，寒潮期渠道容量与跟进节奏需相应放缓。
- 风投中心视角：对 bootstrapped 与利润优先路线着墨少；作者兼孵化器操盘者，对路演培训的价值判断难言中立。

### 容易混淆的邻近方法论

- 估值定价（可比交易+中位数）≠ 退出规模算术：前者定本轮价格（本 skill），后者判断你配不配进这家基金的门（`vc-dynamics-demystified`）。
- 流程性截止日期（本 skill）≠ 现场心理施压（`win-the-pitch-room`）。
- 找意见领袖背书（f23）不是营销带货：目的是给投资人信任信号，不是获客（获客归营销类 skill）。
