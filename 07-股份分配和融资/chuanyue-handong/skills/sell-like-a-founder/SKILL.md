# 像创始人一样销售

## R — 原文 (Reading)

> "你只需要询问你的客户他们排在前五的优先事项是什么。如果你的产品无法帮助他们达成其中的某一个目标，你的产品马上就会被他们拒绝……如果你的产品能够被他们排在前三的优先位置，你就肯定能够和他们建立起业务往来。"
>
> — 史蒂文·霍夫曼，第1章（f08 单元：客户前五优先事项测试）

> "（1）你为什么需要这款产品？（2）为什么贵公司需要这款产品？（3）购买这款产品需要获得谁的批准？（4）你的企业有哪些利益相关者？（5）在从1到10的衡量范围里，你会如何标注这款产品对于你们的重要程度？……（8）你是否愿意现在就下订单？"
>
> — 史蒂文·霍夫曼，第5章（f45 单元：客户访谈八问）

> "（1）为你的客户建立一个360度模型，这样你就能非常确切地知道谁才是你的目标客户……（22）把你90%的精力集中在少数几笔具有决定性意义的交易上。"
>
> — 史蒂文·霍夫曼，第6章（f59 单元：销售22条军规）

> "只需要少数几笔交易就能给你带来绝大部分的销售额。对于大型的战略性的销售，情况更是如此。把你90%的精力集中在少数几笔具有决定性意义的交易上。"
>
> — 史蒂文·霍夫曼，第6章（p71 单元：90%精力聚焦少数决定性交易，已并入 f59）

> "拒绝也是销售过程的一部分……如果你想要对这种打击产生免疫力，唯一的方式就是去拥抱它，而不是回避它，把这一过程当成一次学习的机会。"
>
> — 史蒂文·霍夫曼，第6章（p70 单元：拥抱拒绝，把拒绝变成信息）

## I — 方法论骨架 (Interpretation)

本书把 B2B 销售当成创始人不可外包的第一线工作：CEO 必须是金牌销售。给出一条从"判断值不值得卖"到"被拒绝怎么办"的完整操作链：

1. **客户前五优先事项测试（卖之前先判必需品）**。直接问客户排在前五的优先事项是什么：产品帮不上其中任何一个目标，马上就会被拒绝——满足第六、七、八位优先事项毫无价值；能进入前三优先级，业务关系即可建立。To C 版本换成小范围广告＋登录页，看有多少人点击购买按钮。这是销售动作的前提测试，不是成交后的总结。
2. **客户访谈八问（深挖需求与决策链）**。八问覆盖：为什么需要这款产品、为什么贵公司需要、购买需获得谁的批准、有哪些利益相关者、1-10 分重要度标注、竞争对比、替代品、是否愿意现在就下订单。要点有二：访谈要录音，积极的记录可作为市场需求真实存在的早期证据展示给投资人；最后一问"是否愿意现在就下单"把口头兴趣逼成行动验证。
3. **销售22条军规（创始人操盘全流程）**。核心动作：为客户建立 360 度模型锁定目标客户；吃透产品技术细节；识别谈判桌上对方想要什么；尽早找到真正决策者；寻找内线（销售英雄）；多听少说；以客户最大利益为核心建立信任——顶尖销售帮客户做正确决定，产品不合适时主动劝停，没有比信任更强大的关系基础；迭代销售话术；用数据支撑主张；设定底线；果断放弃僵局交易；建立销售渠道排序。
4. **90% 精力聚焦少数决定性大单（资源分配律）**。少数几笔交易贡献绝大部分销售额，大型战略性销售尤其如此。按成交概率与总体影响力给渠道中所有交易排序，影响力是其他交易之和两倍的单子拿走远超比例的投入，绝不平均分配时间。
5. **渠道纪律：预设底线＋僵局即弃**。预设底线（什么可接受、什么完全不能接受）谈成前就写下来；谈判无法推进就移出日程表——僵局交易里再投入时间也不产生回报，继续维持只是让"谈成"的期待消耗脑力与资源。
6. **拥抱拒绝，把拒绝变成信息**。被拒是销售常态，回避只会积累压力、焦虑与抑郁；每次被拒都要求对方解释不愿继续谈的原因，把每次拒绝转化为有价值的信息来源，以此对打击免疫。同一原则适用于销售、融资与商务合作。

## A1 — 书中的应用 (Past Application)

### 案例 1: Salesforce 早期拒绝数百万美元订单
- **问题**: 创业早期送上门的史上最大订单——大型电信公司的数百万美元定制方案——接不接？
- **方法论的使用**: 用"90% 精力聚焦少数决定性交易"的销售资源分配律反推：这笔定制订单会带走构建最好 CRM 平台的焦点，与目标客户的 360 度模型不符；同时做太多事情比几乎不做任何事情还危险。
- **结论**: 销售聚焦不只是"多追哪些客户"，也包括"拒绝哪些订单"；偏离核心产品的大单是陷阱不是胜利。
- **结果**: Salesforce 拒单后专注构建最好的 CRM 平台，成为书中"缺失业务发展的焦点会致命、而聚焦大单才出销售额"的正面样本。

### 案例 2: Slack 巴特菲尔德——逐层扩大贝塔测试，把客户反馈做成销售前哨
- **问题**: 企业即时通信产品还没做完，怎么确认企业客户真的需要、并铺开销售通路？
- **方法论的使用**: 在产品完成前就送到客户手中，7 个月做出阿尔法版；先让 6-10 家公司试用，逐层扩大贝塔测试规模，每加一家学到新东西并做关键调整，常发现"这个主意并不如想象中的那么好"；"我们祈求并哄骗那些在其他公司的朋友试一试我们的产品并给予我们反馈"。
- **结论**: 尽早让客户互动是发现必需品属性的唯一途径；逐层扩大反馈量既是产品迭代也是 B2B 销售管道的预热。
- **结果**: Slack 靠这一反馈循环长成企业通信巨头，成为书中"客户互动前置"的标杆案例。

### 案例 3: Boxed 黄杰——从自己的痛点锁定目标客户的 360 度模型
- **问题**: 怎么确切知道谁才是目标客户、他们真正要解决什么问题？
- **方法论的使用**: 黄杰搬进城放弃开车后，好市多大包小包难运回公寓成为自己的痛点，于是做手机下单、门到门送货的 Boxed——"我实际上只是想解决我自己的问题"，以自身处境为样本建立对目标客户（没车、依赖手机下单的千禧一代）的 360 度理解。
- **结论**: 对客户的 360 度模型可以从创始人自己就是典型客户的场景中生长出来；自己经历过的痛点天然匹配大量同类客户。
- **结果**: 3 年内从车库里销售额 4 万美元做到营收超 1 亿美元，并获 1.6 亿美元风投。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断必需品："客户说产品不错但就是不买/这单还有戏吗/我的产品对客户到底多重要"——先用前五优先事项测试。
2. 设计客户访谈："去拜访大客户该问什么/怎么问出真实的决策链/怎么避免对方客气敷衍"。
3. 建销售流程："第一个销售该招还是我自己跑/怎么找到能拍板的人/谈判怎么设底线"。
4. 大单取舍："这个大客户消耗了我全部时间还悬着/几笔单子先追哪个"。
5. 应对拒绝："又被拒绝了十次，还要继续吗/怎么从拒绝里学到东西"。

### 语言信号 (用户的话里出现这些就应激活)

- "拜访客户/跑客户/大客户/采购总监/对方说再考虑考虑""客户说需要但不下单""是不是必需品/客户优先级"
- "客户访谈问什么/访谈录音/决策链/谁拍板/利益相关者/重要度打分"
- "销售话术/谈判底线/砍价/僵局/内线/找到决策者""CEO 要不要亲自做销售"
- "大单/决定性交易/先追哪个客户/这单要不要放弃"
- "被客户拒绝/又被拒了/怎么面对拒绝"

### 与相邻 skill 的区分

- 与 `validate-before-you-build` 的区别：后者是**上游**——判断需求真伪、要不要做这个产品；本 skill 假设产品已在卖，回答"怎么卖进去、卖给谁、怎么谈"。用户还在问"这需求是真是假"先转后者；访谈八问里的下单追问是两者交界的闸门。
- 与 `market-and-grow-on-a-shoestring` 的区别：本 skill 管**一对一的战略销售**（创始人亲跑、单笔大单、谈判决策链）；后者管**一对多的规模化获客**（游击营销、公关、内容、漏斗）。"拿下这家大企业"找本 skill；"怎么让更多客户知道我"转后者。
- 与 `pitch-materials-that-land` / `run-the-fundraising-process` / `win-the-pitch-room` 的区别：融资也是"销售"，但对象是投资人，方法论（路演文档、估值、投资人渠道）自成体系——用户说"卖"而对象是投资人时，转那三个 skill。
- 与 `build-your-team-right` 的区别：招销售团队、给销售定薪酬是人的进出问题，转后者；本 skill 管创始人亲自操盘的销售打法本身（CEO 必须是金牌销售）。

## E — 可执行步骤 (Execution)

1. **对每个目标客户跑前五优先事项测试**：当面问对方"你们排在前五的优先事项是什么"，对照产品能否帮其达成其中之一
   - 完成标准：每个目标客户有书面的前五优先清单；产品对不上前五的，停止投入销售资源（满足第六位以后毫无价值）；能进前三的标记为 A 类优先攻。
2. **按八问清单做深度访谈并录音**：覆盖为什么需要/为什么贵公司需要/购买需谁批准/有哪些利益相关者/1-10 重要度/竞争对比/替代品/是否愿意现在就下单
   - 完成标准：每场访谈有录音和八问逐项回答记录；拿到"购买需获得谁的批准"的明确答案（决策者已识别）；最后一问得到行动式回应（下单/试用/意向书）而非口头赞美——只有客套话视为零反馈。
3. **建立 22 条军规的销售流程并找齐关键人**：建 360 度客户模型、吃透产品细节、识别对方想要什么、尽早接触真正决策者、发展内线、多听少说、以客户利益为核心建立信任
   - 完成标准：每笔在谈交易有一页客户 360 度模型（目标客户画像、决策者是谁、内线是谁、对方想要什么）；对话中自己说话占比不超过一半；每笔交易至少一条内线信息来源。
4. **用排序和底线管理交易组合**：按成交概率×影响力给渠道所有交易排序，90% 精力投向少数决定性大单；每笔交易预设底线（可接受/完全不能接受），谈判推进不动即移出日程
   - 完成标准：有书面的交易排序表；头号交易的时间投入可追溯为其他交易的两倍以上；每笔交易成文写明底线；本季度至少有一笔僵局交易被主动放弃并把资源转移的记录。
5. **建立拒绝处理机制**：每次被拒都要求对方解释拒绝原因，逐条记录并归因，回灌进话术与目标客户筛选
   - 完成标准：有拒绝原因台账（每条拒绝对应一条原因记录）；每月复盘一次并至少改写一版销售话术；至少一条产品/定位改进可追溯到某次拒绝反馈。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对象是投资人的"销售"——做路演材料、定估值、跟进投资人、会面博弈，转 `pitch-materials-that-land` / `run-the-fundraising-process` / `win-the-pitch-room`；本 skill 只管对付费客户的一线销售。
- 问题是一对多的获客与增长——游击营销、媒体公关、标题 A/B、渠道 LTV-CAC 算术，转 `market-and-grow-on-a-shoestring`。
- 还没到销售阶段——需求真伪、该不该做这个产品，先转 `validate-before-you-build`。
- 招销售团队、给销售定薪酬激励等"人的进出"问题，转 `build-your-team-right`。

### 作者在书中警告的失败模式（销售反例）

- **忽视销售的工程师团队（e01）**：一群工程师初创企业坚信"做出更好的产品客户自然会上门"，认为业务拓展、市场营销只是底层员工的工作，只顾加功能、优化服务器，最终没有任何客户上门而失败。"产品好就自然有客户"是最危险的自我假设之一——CEO 必须亲自成为金牌销售。
- **礼貌性反馈假阳性（e05）**：一位创业者走访潜在客户，90% 以上表示喜欢产品并让他产品完成后再来一次，作者断定这恰恰证明产品不是客户想要的——人们不愿当面说难听的话，没有主动问价、要求预订等行动式反馈就等于没有反馈。对治：访谈八问最后一问"是否愿意现在就下单"，用行动承诺而非口头赞美验证。
- **"蜘蛛舞"：培育市场的死亡之吻（e06）**：作者的第一家公司做互动电视，不得不一字一句地向好莱坞解释什么是互动电视来获得订单，市场崩溃后客户砍掉全部预算，公司随之陷入困境。不能指望市场追赶你——需求必须先于产品存在；产品对不上客户前五优先事项就别硬卖。
- **僵局交易的沉没成本陷阱（e48）**：为挽回已投入数月的谈判而继续维持僵局，让"谈成"的期待欺骗自己，实际持续消耗脑力、精力与资源。对治：预设底线，谈不成即果断放手，把资源转向有成交可能的客户。

### 作者的盲点 / 时代局限

- 军规以大型战略性 B2B 销售为原型（90% 精力押少数大单）；对客单价低、交易高频的中小 B2B 或 To C 场景，聚焦律会变成把鸡蛋押在极少数客户上的集中度风险，作者未给出小客单价场景的分配标尺。
- 22 条军规默认创始人有直接接触大企业决策者的通道；在层级更深、靠渠道与集成商成交的市场（如中国政企采购），"尽早找到真正决策者"的可执行性大打折扣，作者未讨论渠道型销售。
- 书成于硅谷语境（Salesforce、Slack 样本），"以客户利益为核心、产品不合适主动劝停"的信任打法在买方信任度低、关系型销售占主导的市场中见效更慢，需配本地信任建立机制，作者未展开。
- 客户访谈八问假设客户愿意如实回答且能准确预测自己的购买行为，未处理受访者系统性高估意愿的偏差——这一坑要靠 e05 的"行动式反馈"判据补齐。

### 容易混淆的邻近方法论

- **前五优先事项测试（f08）≠ 客户满意度调查**：测的是"产品在客户优先级里的位置"（卖不卖得动的闸门），不是对已购产品的评价工具；顺序是先测优先级、再谈成交。
- **访谈八问（f45）≠ 市场调研问卷**：八问是小样本深度访谈（覆盖决策链与下单意愿、要录音），不是发几百份的统计问卷；它是创始人亲自做的，不是外包给调研公司的。
- **90% 聚焦大单（p71）≠ 只服务大客户**：聚焦的对象是"决定性交易"，判断依据是成交概率×影响力排序，不是客户规模本身；小客户组合里影响力最大的那笔同样是决定性交易。
- **以客户利益劝停（p72）≠ 放弃成交**：劝停的触发条件是产品确实不合适，目的是用信任换取长期关系与转介绍；对合适的产品，多听少说不等于不推动成交。
- **拥抱拒绝（p70）≠ 盲目坚持**：拥抱的前提是把每次拒绝转译为原因信息并据此调整目标与话术；重复犯同样的错不叫免疫，叫不听反馈。
