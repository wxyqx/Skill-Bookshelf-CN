# 看懂风投：从对手的算术反推自己的路

## R — 原文 (Reading)

> "只需要有一家这样的创业公司就能够赚回整个基金在所有其他方向上的投入。"
>
> — 史蒂文·霍夫曼，第2章

---

## I — 方法论骨架 (Interpretation)

融资谈判的第一步不是打磨话术，而是算清**坐在你对面的人怎么赚钱**。本书把风投拆成一台可以被理解的机器：

1. **钱从哪来**：风投从 LP（出资人）处募资，赚 2% 管理费 + 20% 利润分成（2/20 结构）。数十亿美元基金光管理费每年就近 2000 万美元——这激励他们不断募更大的基金。
2. **钱怎么赚**：幂律回报——绝大多数投资归零，一到两个"贡献者"项目赚回整只基金。所以"能稳定盈利的中小企业"对风投毫无意义。
3. **由此推出门槛**：基金越大，要求的退出规模越大——大型基金只找退出时能达 5 亿美元以上估值的标的。你的公司按现实估算撑不起这个数，谈得再好也不会成交。
4. **由此推出行为**：必须在前三年把钱投出去、必须追极大退出、必然集体决策（全体合伙人听最后一场路演后投票，常一票否决——没人想显得蠢）。
5. **反推自己的路**：用融资阶梯对号入座——天使（几千到数十万美元）→ 种子（数十万到数百万）→ A 轮前（50 万到数百万）→ A 轮（数百万到数千万）；退出体量撑不起对方基金时，转投天使、种子或小额基金，别浪费一年。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1500 万估值的创始人
- **问题**: 一位创始人卡在"我要 1500 万美元估值"上，一年融不到资。
- **方法论的使用**: 用询价校准与市场数据对照：市场只愿支付远低于幻想的金额。
- **结论**: 你的公司真正价值只等于市场愿意支付的金额；坚持幻想估值浪费一年。
- **结果**: 作者给出校准路径——请多家风投内部人员做非正式估值评估、问其他创业者行情。

### 案例 2: 假天使 / 错配资金
- **问题**: 创业者拿到"天使"的钱却签了风投式条款，或向大基金推销小退出机会。
- **方法论的使用**: 用退出算术与轮次阶梯判断该找哪类资金、对方有无诚意。
- **结论**: 体量不匹配的投资人本质是假买家；错配的资金链条越早看清越好。
- **结果**: 转向匹配阶段的资金来源，避免时间与股权双重损失。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 被投资人拒绝后想知道"他们到底怎么想的"，或准备见投资人前想预判其行为。
2. 估摸自己公司未来退出体量，判断该找天使/种子还是 A 轮基金。
3. 纠结"我要不要走风投这条路"，想先算算自己适不适合这场游戏。

### 语言信号 (用户的话里出现这些就应激活)

- "风投怎么赚钱""2/20""LP""退出规模""5 亿美元""幂律"
- "天使轮/种子轮/A 轮该找谁""为什么总被拒""一票否决"
- "融资是不是唯一出路"

### 与相邻 skill 的区分

- 与 `choose-your-funding-path` 的区别：本 skill 讲"风投这台机器怎么运转"，后者讲"我自己该不该融资、钱该不该拿"（资金红线与替代路径）。先想自己，再看对手；但一句话若在问"为什么投资人拒绝我"用本 skill。
- 与 `run-the-fundraising-process` 的区别：理解机制 vs 执行流程（定估值、建渠道、找领投）。
- 与 `win-the-pitch-room` 的区别：理解对手 vs 现场成交技巧。

## E — 可执行步骤 (Execution)

1. **算对手的账**：确认对方基金规模与阶段，按 2/20 与幂律推出其最小可接受退出规模
   - 完成标准：一句话说出"这只基金必须靠什么样的退出赚钱"。
2. **算自己的账**：用可比公司估算自己的现实退出体量区间
   - 完成标准：给出有依据的数量级区间；判停条件——若两者差一个数量级以上，直接转投匹配阶段的资金（天使/种子/小额基金），结束谈判。
3. **对号入座融资阶梯**：按所处阶段匹配资金来源与合理金额
   - 完成标准：列出本阶段 2-3 类合适资金来源。
4. **预判行为**：据"三年投完/一票否决/只追极大退出"预判对方的时间表与决策链，弄清如何见到决策者
   - 完成标准：明确对方决策流程与关键人。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经决定融资、要写路演材料或推进流程——转 `pitch-materials-that-land` / `run-the-fundraising-process`。
- 用户做的是股权结构、条款细节的法律分析——转专业律师（书中 f25 亦强调律师边界）。

### 作者在书中警告的失败模式

- 把融到资等同于成功——融资获得的钱是要还的（股权与义务），弹药与战场弹药不同。
- 向大基金推销撑不起其账本的机会，浪费时间一年。
- 不知道对方一票否决机制，把宝押在某一位"喜欢你"的投资人身上。

### 作者的盲点 / 时代局限

- 案例与算术基于 2012-2019 美国风投周期与低利率环境；Bootstrapped/利润优先路线被系统性弱化（见 BOOK_OVERVIEW 批判节）。

### 容易混淆的邻近方法论

- 估值定价方法（可比交易/询价校准）：属流程执行，归 `run-the-fundraising-process`。
- 天使投资人个人动机：与机构 2/20 逻辑不同，不可混用。
