# 赢得路演现场：从被审视者到让对方按你的节奏成交

## R — 原文 (Reading)

> "无论在什么时候，都千万不要表现出你的绝望，风险投资公司喜欢的企业是那些并不需要他们钱的企业。"（第2章）

> "一旦你想办法让投资人说了'不'，你就给了他一个获得控制权的机会，并促使他反思自己想要的究竟是什么。"（第2章）

> "你在心中需要坚信，你的时间要比投资人的资金更加珍贵。"（第2章）

---

## I — 方法论骨架 (Interpretation)

现场成交的核心不是把话讲漂亮，而是**扭转会面的权力结构**：让投资人从审视者变成参与者，让他们按你的时间表行动，且永远猜不透你的底牌。全法可拆成七件事：

1. **开场：开门见山，不闲聊**。会面只有15分钟到1小时，寒暄两句即进入正题，用一段综述开场；听过路演的用2分钟唤起记忆，没听过的最多5分钟回顾。投资人打断你提问是好消息——提问说明愿意深入，要顺着他的语境讲下去，绝不用一句话敷衍了事。
2. **主动提问 + 顾问心态：听语调，不做推销员**。多数创始人以为路演就是不停叙述，其实更该主动提问——提出后续问题的人更受欢迎。心态上把自己换成"顾问"：你的工作是帮投资人全面理解企业，双方合适自然成交。一旦让对方闻到推销味，他们就会提高警惕；而倾听对方的语调和反馈、接纳建议，会让对方在贡献想法的过程中逐渐说服自己。
3. **扑克脸：绝不暴露绝望**。哪怕账上快没钱、员工准备离职，也要表现得随时可以走——风投只喜欢不需要他们的钱的企业。暴露脆弱的代价是真金白银的：对方一旦嗅到你的急切，估值应声被砍。
4. **隔离投资人与竞争张力**。投资人会反复打听"你还在和谁谈"，克制住炫耀的冲动：无法确信对方已做出真实承诺前，绝不透露竞争信息，更不要应要求把投资人互相介绍——那只会让他们串通报价。被施压时用"若对方也感兴趣我可以介绍"激起其竞争天性。让他们竞争，而不是让他们串通。
5. **人为截止日期：没有期限就没有决定**。投资人不做决定是因为没有理由做决定。自己制造紧迫感——明确宣布你的时间表（"圣诞前必须完成"），连你自己都要相信这个日期，并做好要么大获全胜、要么彻底崩溃的两种准备。一个想象中的截止日期就能筛出谁是真投资人。
6. **让对方说"不"的成交心理**。不要逼对方说"是"，而要用设计好的问题让他说"不"并暴露真实顾虑（估值太高？市场太小？没有领投？）。问题清单：您为何对这笔交易感兴趣？达成交易有哪些必经步骤？还有什么在阻碍推进？您希望在意向书里看到什么？先摸清感受再利用信息成交——最有效的成交是让对方自己构建出他愿意相信的故事。
7. **动机工程与心态基线**。投资人观望是因为恐惧（怕亏钱、怕丢声誉），克服恐惧的杠杆是贪婪：让他们相信错过的是独角兽级机会——只有大交易能上头条。姿态底座则始终是：你在经营公司，投资人的工作是找好项目，你把项目摆到他们面前是在帮他们的忙——礼貌但坚定，绝不傲慢，也不乞求。

**诚实红线**：以上全部技巧都踩在一条线上——永远不对投资人说谎。被问"能否准时交付"，答"绝对没有问题"是自信；编造不存在的数字是说谎。内心警报一响就撤回来。

## A1 — 书中的应用 (Past Application)

### 案例 1: Warby Parker——用连环提问让投资人自我说服
- **问题**: 在线眼镜商 Warby Parker 面对的是一道反直觉命题：让投资人相信人们愿意在网上花几百美元买眼镜。若靠单方面宣讲，很容易被当作又一个"电商卖眼镜"的故事。
- **方法论的使用**: 创始人放弃灌输，改用连环提问引导投资人自己验证核心假设："您愿意花400美元买一副眼镜吗？""能用半价买到呢？""我们先寄几件样品给您试一试呢？""能做到免费退货呢？"每个问题都让投资人脱口而出"对啊"。
- **结论**: 没有什么比让人说服自己更有效——当投资人亲口认可了你业务的核心设想，他就自己得出了"这就是我想要的"的结论，无需任何推销。
- **结果**: 这套提问式打法成为本书"让对方说不"成交法的经典范例；投资人先在问答中成为共谋者，再成为出资人。

### 案例 2: 作者第三家创业公司——圣诞截止日逼出真投资人
- **问题**: 迪士尼旗下思伟投资的一位朋友六次会面，每次都说"真的很感兴趣，我会投资"，却始终按兵不动；融资被拖入无限期观望。
- **方法论的使用**: 作者当场宣布转投他人并真的约到世界最大的对冲基金之一；刻意维持另一家传媒巨头（维亚康姆、福克斯或时代华纳之一）仍感兴趣的朦胧感制造竞争张力；同时无视"圣诞前无法成交"的行业惯例，人为设定圣诞前完成的截止日期。
- **结论**: 口头热诚不等于承诺，不到决策时刻连投资人自己都不知道会不会投；截止日期是唯一能区分真投资人与观望者的筛子——对朋友也一样要设期限。
- **结果**: 那家对冲基金抓住了机会，整轮融资在圣诞前几天达成；被晾在原地的口头承诺者就此出局。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 明天/下周就要与投资人会面，想知道开场怎么讲、如何应对打断与刁钻提问、以什么姿态坐在那里。
2. 融资拖了很久，投资人总是"很有兴趣但再看看"，想制造紧迫感、设定截止日期、激起投资人之间的竞争来推动成交。
3. 手头现金紧张或同时被多家机构压价，担心在谈判桌上流露急切被压估值，需要保持谈判杠杆的现场策略。

### 语言信号 (用户的话里出现这些就应激活)

- "明天要见投资人""开场怎么讲""只有15分钟""会不会被打断"
- "扑克脸""不能让他们看出我急""还在跟谁谈要不要说""让他们竞争"
- "怎么让他们尽快做决定""截止日期""圣诞前成交""让他说不"
- "像推销员还是像顾问""该怎么提问""听不出投资人什么意思"

### 与相邻 skill 的区分

- 与 `pitch-materials-that-land` 的区别：那个管**上台前**——PPT怎么写、故事怎么编、冷邮件怎么发；本 skill 管**会面进行中**——开场、问答、语调、姿态与临场成交。材料没做完先去那边；材料齐了坐在会议室里，用这个。
- 与 `run-the-fundraising-process` 的区别：那个管**流程执行**——估值定价、渠道里保持10个投资人、三振出局跟进、找领投；本 skill 管**单场会面内的心理与成交动作**。区分试金石：问题发生在"两次会面之间的节奏"归流程，发生在"一张会议桌上的心理博弈"归本 skill。
- 与 `vet-investors-and-advisors` 的区别：筛选与背调投资人、风投内部政治归那边；本 skill 默认对面已经值得谈。
- 与 `vc-dynamics-demystified` 的区别：理解风投怎么赚钱、为什么拒绝你归那边；本 skill 解决"这轮见面怎么拿下"。

## E — 可执行步骤 (Execution)

1. **会面前定姿态基线**：写下"我的时间比投资人的资金更珍贵"三遍，列出你手头其他在谈的机构（渠道不足10家先回融资流程补渠道）
   - 完成标准：能一句话说出"我为什么不需要这一次会面非成不可"；若答不出，先补渠道再赴会。
2. **开场即入题 + 预埋问题**：寒暄不超两句，用一段综述开场（老听众2分钟、新听众5分钟）；预写3个向投资人抛出的问题（您为何感兴趣/决策必经步骤/什么在阻碍推进）
   - 完成标准：开场讲稿背熟；3个问题写在会面笔记首页，会面中至少抛出2个并记下对方语调与顾虑。
3. **全程扑克脸管理**：会面前删掉一切可能暴露急切的口头禅和肢体信号；投资人打听竞争信息时统一用"若对方也感兴趣我可以介绍"回应，绝不主动报名单、绝不撮合投资人互认
   - 完成标准：演练一遍被问"你们账上还有几个月"的应答，答案里没有真实现金流细节。
4. **设截止日期并公开宣布**：给自己定一个连自己都相信的完成期限，告知所有在谈投资人"我在X日前完成本轮"
   - 完成标准：期限已写进跟进邮件；同时做好两种心理预案——期限内成交，或期限一到对观望者全部出局。
5. **收尾逼出真话**：用问题清单让对方说"不"并暴露真实顾虑，把顾虑记入跟进清单逐条消化；对方口头说"有兴趣"时追问"达成交易还有哪些必经步骤"
   - 完成标准：每场会面后拿到至少一条明确顾虑或明确承诺动作（而非"很有兴趣"）；判断停条件——三轮问题后仍只有口头热诚、无决策步骤，按流程出局转下一家。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还在做路演PPT、编融资故事或写冷邮件——转 `pitch-materials-that-land`。
- 用户问的是估值怎么定、渠道怎么管、跟进邮件怎么发——转 `run-the-fundraising-process`。
- 用户纠结"这个投资人该不该拿他的钱"、要背调或鉴别假天使——转 `vet-investors-and-advisors`。
- 用户做的是对客户的B2B销售谈判而非融资——转 `sell-like-a-founder`。

### 作者在书中警告的失败模式（融资谈判家族反例）

- **暴露绝望**：作者第一次风险融资时让投资人知道自己多急切要现金，估值立刻被砍掉一半；更重的后果是——当投资人发现公司有价值但快断粮时，会用强制性融资条款大规模稀释股权、接管公司（e16）。
- **让风投拖着走**：作者花几个月与某风投合伙人培养感情，最后全体合伙人会议上一票否决，数月努力归零——不要把宝押在单一投资人身上，要按自己的节奏推进（e17）。
- **投资人互相识=串通报价**：应投资人要求互相介绍，他们会串通压低条件且帮不了你成交；兴趣弱的一方还可能搞砸整笔交易（e19）。
- **把摇摆者引入组合**：把犹豫的投资人和未承诺的投资人放在一起，会埋下怀疑的种子，最后一笔交易整体失败（e18）。
- **信口头承诺**：作者的朋友六次会面次次说"会投"却按兵不动——不到决策时刻连投资人自己都不知道会不会投（e20）。

### 作者的盲点 / 时代局限

- 案例来自2012-2019美国风投周期的低利率环境，"制造稀缺、互相竞价"的打法在资金面收紧时可能直接遇冷；作者身处孵化器行业，对路演博弈技巧的价值判断难言中立。
- 全套杠杆假设创业者有可替代选项（多家在谈、随时能走）；对只有一家机构愿意谈的冷启动创业者，"扑克脸"的底气需要先靠补渠道建立，否则是空架子。

### 容易混淆的邻近方法论

- 通用销售谈判技巧（如锚定报价）：本书的成交心理针对风投特有的决策链（全体合伙人投票）与恐惧-贪婪动机结构，不可直接照搬到客户谈判。
- "永远诚实"不等于全裸奔：披露实质性信息是尽调阶段（签TS前）的义务，属于融资流程纪律；路演现场的自信表达（"绝对没有问题"）与隐瞒尽调信息是两码事，别混用。
- 对董事会示弱、主动暴露错误（领导力章节）与对投资人亮底牌：对象不同，前者换取信任，后者损失估值，场景不可互换。
