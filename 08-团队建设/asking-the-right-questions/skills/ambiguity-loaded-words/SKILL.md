## I — 方法论骨架 (Interpretation)

论证的语言层审查：说服力常常藏在词义的缝隙里。一个多义词在论证里取哪一义，直接决定理由撑不撑得住结论——不先把含义钉死，后面所有评价都建立在流沙上。

操作上有四道工序。第一，**锁定候选词**：只在论题、结论、理由里找关键词，其余词汇扔出淘金盘；词越抽象越可疑，想象不出具体画面的词（"不当着装""见效""重大违约"）是头号嫌疑。第二，**换义替换测验**：把该词的不同含义逐一替换进论证——换一种理解，理由对结论的支撑度就变了，即为重要歧义；不变则不是，立刻放手。第三，**感情色彩词检查**：内涵意义（情感联想）会劫持外延意义（实际所指），问"这个词想让我产生什么感情？它有没有蒙蔽我，让我看不到指称对象的某些重要特征？"再换成中性同义词复述，看论证是否当场变样。第四，**责任归属**：重要歧义未消除前拒绝表态——问"你这样说是什么意思"，而不是"我就知道你是这个意思"。

对写作者镜像适用：别以为自己的意思对读者显而易见；关键术语要么自己下定义，要么在语境里锁死含义，否则不同读者会复述出不同版本。

## A1 — 书中的应用 (Past Application)

### 案例 1: "大家牌"催眠药与旅游业短文（第4章开篇）
- **问题**: 广告词"30 分钟见效"里"见效"可指昏昏欲睡、也可指一觉到天亮；旅游业短文说要"采取更多措施控制旅游业"，却不说明是限游客数量还是规范行为，评论者无处下嘴。
- **方法论的使用**: 对歧义词做替换测验——把不同含义代入论证，看购买（或支持）意愿是否随之翻转；翻转即重要歧义。
- **结论**: 广告商往往故意把最有吸引力的含义安在歧义词上；不排查就会做出事后追悔的决定。
- **结果**: 确立"影响理由支撑结论效度的歧义才算重要"的判停标准。

### 案例 2: 学校着装规定——反串找出"不当着装"的歧义（第4章练习）
- **问题**: 一篇主张学校应有着装规定的文章，关键词"不当着装"没有定义、没有判定标准。
- **方法论的使用**: 作者先推测结论与理由，再排查关键词；接着站到反对立场（反串），发现学生穿反战、支持候选人的 T 恤也属于政治表达，会被"不当着装"一并扫进来。
- **结论**: 默认含义只是自己的假设；歧义消除前拒绝决断。
- **结果**: 示范"你这样说是什么意思"而非"我就知道你是这个意思"的提问习惯。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 审合同、条款、政策文件：有词说不清权利义务（"重大违约""合理期限"），每字都认识却不知到底指什么。
2. 审广告与宣传语（"见效""纯天然""无脂""头号"）：句句属实却不知道自己会买到什么。
3. 开会/辩论发现双方吵了半天，原来对同一个词各持一个定义。
4. 读到让自己瞬间愤怒或同情的词，想检查是不是被措辞操纵（"死亡税" vs "遗产税"）。
5. 自己要发需求文档、写公告，想自查关键词会不会被读者各自解读。

### 语言信号 (用户的话里出现这些就应激活)

- ""X"到底指什么 / 怎么定义""这词太模糊了 / 有歧义"
- "我们是不是在鸡同鸭讲 / 各说各话"
- "他们是不是在玩文字游戏 / 换个说法感受完全不同"（loaded words / emotionally charged terms）

### 与相邻 skill 的区分

- 与 `locate-issue-conclusion` / `identify-reasons`：歧义排查发生在结论与理由定位**之后**——连结论在哪都不知道，谈不上查关键词。
- 与 `descriptive-assumption-mining`：想当然认定多义术语取某一义，是定义性假设，归假设挖掘管；本 skill 只管"含义不明"这一层。
- 与 `fallacy-three-questions`：发现"词义不清"是本 skill；论证靠关键词中途换义滑行来支撑结论（偷换概念），那是理由层的花招，归谬误判别。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定候选词**
   - 操作: 只在论题、结论、理由内挑关键词（其余扔出淘金盘）；对每个词做画面测试——能否想象出具体画面
   - 完成标准: 列出 1–5 个候选词，各标注"能/不能想象画面"；判停：全部能想象且语境已锁定含义 → 排查结束
2. **换义替换测验**
   - 操作: 为每个候选词写出至少两种含义，逐一替换进论证
   - 完成标准: 给出"重要歧义/不是"判定——替换后理由对结论的支撑度改变 = 重要歧义；判停：支撑度不变 → 该词出局，不再纠缠
3. **感情色彩检查 + 反串**（遇到情绪词时执行）
   - 操作: 问"这个词想让我产生什么感情？有没有蒙蔽我看不到某些重要特征？"换成中性同义词复述论证；再站到反对视角重新推演——反方会把这个歧义词默认成哪个含义？
   - 完成标准: 标注哪些词在"用情绪替代理由"，并写明反方默认义
4. **澄清与收尾**
   - 操作: 重要歧义未消除前不下结论，向说服方索要定义（谁说服谁澄清）；写作侧则自查给自己的关键词下定义
   - 完成标准: 要么拿到澄清后转入后续审查，要么明确表达"澄清前拒绝表态"；不自动脑补作者含义

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 日常闲聊、无关紧要的措辞分歧——对每个词较真是抬杠不是审查；只在论题、结论、理由内查
- 词典义已经够用的词——判定标准是"影响推理效度"，不是"一词多义就算"
- 纯翻译/查词义请求——那是词典任务，与论证审查无关

### 作者在书中警告的失败模式

- 广告商故意把最有吸引力的含义安在歧义词上（"见效""超强止痛"）——不排查就事后追悔
- 感情色彩词让思维短路：情绪线路绕过描述义（"死亡税" vs "遗产税"；军方用委婉说法回避"自杀"）——被词激起情绪却找不到对应的具体事实
- 写作端的知识诅咒：以为意思对读者显而易见，关键术语不定义，不同读者复述出不同版本

### 作者的盲点 / 时代局限

- 本书默认说服走论证通道且对方愿意澄清；社交媒体上的说服（情绪标签、梗、身份符号）常常根本不给"要求澄清"留受理窗口
- 案例高度美国中心（"死亡税"等政治语言），跨文化使用需先本地化同类的感情色彩词对

### 容易混淆的邻近方法论

- 抠字眼/杠精：歧义排查有判停条件（换义后支撑度不变即出局），杠精没有
- 查字典：字典消除不了歧义，语境（作者背景 + 习惯用法 + 前后文）才是解药
