# 批判性思考者价值观自检

## R — 原文 (Reading)

> "批判性思维最为常见的一大障碍，就是相信凡与自己意见相左的人都是立场褊狭，而自己则立场公允。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

> "我们常见的做法是只愿听那些价值观取向和我们相似的人的观点，党同而伐异。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

---

## I — 方法论骨架 (Interpretation)

书中给批判性思维配了一张价值观底座，四条缺一不可：**自主性**——结论必须是自己提问问出来的，不能是借来的；**好奇心**——对"别人为什么会那样想"真心感兴趣，先弄懂对立阵营最好的理由再下判断；**谦恭有礼**——承认自己也可能错，与最聪明、最友善的批评者对话；**以理服人者逢之必敬**——只认论证质量，不认身份、立场、名气，讲理的对手值得最高敬意。

四条合起来指向同一个敌人：党同伐异加偏见盲点。人天然只听和自己价值观相似的人，还默认褊狭的是对方、公允的是自己——这个盲点最狡猾之处，是让"需要兼听"的信号本身失效。所以自检不能靠自我感觉（人人都觉得自己挺开放），要靠可核查的动作：数一数信息源构成、复述一遍最强反对论证、找出一个与你相左且讲理的人并让他认可你的复述。

"以理服人者逢之必敬"还有一个技术出口：它最终落进证据审查程序——看一条专家意见时问"持不同观点、利益的专家是否同意"，把尊重异见从姿态变成检查项。

## A1 — 书中的应用 (Past Application)

### 案例 1: "党同伐异"专段的现场画像（第1章）
- **问题**: 只在价值观相似的人群里搜罗观点、检验结论（书中举例：民主党人只听民主党人），会错过本可挑中的重要决定与选择，且当事人毫无察觉。
- **方法论的使用**: 作者把"与党同伐异的倾向作斗争"写成价值观清单的落地动作，并点名最常见障碍——相信凡相左者皆褊狭、唯独自己公允。
- **结论**: 开放不能靠自我感觉，要靠行为证据：信息源构成、是否完整听过最强反方。
- **结果**: 四条价值观从抽象名词变成可自查清单，并在第7章的证据审查里获得对应问句。

### 案例 2: "不同立场的专家是否同意"落进证据审查（第7章）
- **问题**: 面对一条专家背书，听还是不听？按身份选边的本能会直接替你给答案。
- **方法论的使用**: 审查程序把价值观问题转为工序问题：除专长是否对口之外，专问一句"持不同观点、利益的专家是否同意"。
- **结论**: 兼听不是美德口号，而是给证据称重前的规定动作。
- **结果**: 价值观自检获得可执行出口（后续由专家意见类审查 skill 承接）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 做重要决定（换工作/买房/选学校），发现咨询对象全是同温层。
2. 看到反对意见的第一反应是"这人立场有问题"，想改掉这个习惯。
3. 长期只看某一派的内容源，想自查自己的"信息饮食"。
4. 需要决定"该给谁的意见多大分量"——按身份站队还是按论证质量。

### 语言信号 (用户的话里出现这些就应激活)

- "我是不是在信息茧房里 / 同温层"（echo chamber, filter bubble）
- "凡是反对我的都偏激 / 他就是有立场"（everyone who disagrees is biased）
- "怎么保证我两边最好的理由都听到了"（hear the best arguments on both sides）
- "该听谁的 / 谁的话有分量"（whose opinion should count, open-mindedness）

### 与相邻 skill 的区分

- 与 `strong-sense-self-audit` 的区别：s02 审某个具体结论与理由；本 skill 审更上游的"我的信息源构成与待人姿态"。
- 与 `pan-for-gold-reading` 的区别：s01 是读的姿态；本 skill 决定"读谁的、把谁的当回事"。
- 与 `keep-dialogue-alive` 的区别：s03 是价值观层（跟谁对话、以何种敬意）；s04 是对话进行中的具体动作与话术。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **自主性检查：结论是谁问出来的**
   - 动作: 追溯当前判断的来源——自己提问得出，还是从某个阵营借来
   - 完成标准: 列出本次判断依据的 2–3 个信息源，且至少一个不属于自己常看的阵营
   - 判停: 若只是低利害琐事，跑第 1、4 两步即可
2. **好奇心检查：对立阵营的最好理由**
   - 动作: 尝试说出对方立场最强的那条理由
   - 完成标准: 能一句话复述到"对方会点头"的程度；做不到就先去补课，而不是先下结论
3. **谦恭检查：盲点盲点**
   - 动作: 自问是否默认"对方褊狭、我公允"；找出一位与自己相左且讲理的人
   - 完成标准: 完整复述该批评者的观点并获其认可，或明确承认"我还没听过最强反方"
4. **以理服人者逢之必敬：按论证质量给分量**
   - 动作: 给本次采信的每个主张标注理由质量，而非来源身份
   - 完成标准: 每个被采信的主张都能说出"因为它理由扎实"，而不是"因为是我这边的"

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 审某个具体结论的理由是否成立——那是 `strong-sense-self-audit`；本 skill 审"听谁说、以什么姿态听"
- 人生观/价值观咨询（"我该成为什么样的人"）——本 skill 的"价值观"特指支撑批判性思考的四种态度，不是人生价值排序
- 拿去诊断别人的信息源（"你就是茧房"）——它是自检工具，用来审判别人只会变成新的傲慢

### 作者在书中警告的失败模式（注：案例池无直接绑定条目，取内容最贴合的 ce05/ce02）

- 党同伐异与偏见盲点（ce05）：信息来源高度同质，反对声音只能从转述里听到；用"对方有立场"一句话打发异见，却不检查自己立场的来源；从未完整复述过最强反对论证
- 防御式听异见（ce02）：把相左意见当人身攻击——价值观层的谦恭缺席，在对话层表现为结构性听不见
- 反向失败：把谦恭做成没有立场——四条价值观里没有"和稀泥"；以理服人者逢之必敬同时意味着对烂论证不必敬

### 作者的盲点 / 时代局限

- 书中默认对话双方都在讲理；对身份政治、群体认同驱动的说服，价值观自检作用有限（BOOK_OVERVIEW·立场盲点）
- "研究证据 > 直觉"的默认序未给专业直觉（急救、消防类）留位置——好奇心检查在专业领域需调整
- 四条价值观作为道德主张提出，未配行为设计；双过程研究提醒：价值观自检同样会被快思考跳过

### 容易混淆的邻近方法论

- "包容多元"：谦恭不等于承认所有立场等价；判断标准始终是论证质量
- 信息健康管理/数字排毒：那些管"看多少、看多久"，本 skill 管"以什么价值观看、听谁的"
