## I — 方法论骨架 (Interpretation)

数字不会说谎，但说数字的人会挑数字。第10章对付的不是假数据，而是**真数字的误导性用法**——数字是真的，宣称失真了。工序六查：

1. **查来历**: 这个数字是怎么得来的？越难统计的东西（抑郁率、逃税、婚前性行为）越容易被报成斩钉截铁的精确数字——同一指标的独立估计可以相差几倍，先问估计方法。
2. **平均值三算**: "平均"有三种——平均数、中位数、众数。收入、房价这类右偏分布里，少数极端值拉高平均数却几乎不动中位数，选哪种平均的权力在陈述者手里。此外还要问**全距和分布**：只有中位数照样不够（存活中位数十个月，可能有人活过 80 岁）。
3. **数据-结论错位**: 最常见的骗局是用证明了 A 的数据包装成结论 B。两个检测策略：①先遮住数据，问"什么数据才能证明这个结论"，再与给出的数据对比；②先认真读数据，自己独立推出结论，再与作者的结论比对——自己推出的那个通常弱得多。
4. **缺失比较与互换验证**: 只有百分比没有绝对数（"增长 75%"其实是 4 家到 7 家）、只有绝对数没有基数（"54000 人患病"不除以 3 亿）都会误导。把百分比换算成绝对数、绝对数换算成百分比，双向各算一遍，再补"和什么比"的基线。
5. **风险表述转换**: 同一疗效可以是"风险降低 33%"（相对）、"降低 3%"（绝对）、"无复发率 94% 对 91%"——三种说法完全等价，观感天差地别。健康与理财数字要问一句"换成每百人里有几人，还剩多少"。医药广告偏爱相对风险，因为相对数字最能制造行为改变意愿。
6. **写作镜像**: 自己引用数据时主动给全——绝对数+基数+平均值类型+比较基线，别让读者猜。

## A1 — 书中的应用 (Past Application)

### 案例 1: NFL 球星"平均工资 180 万美元"
- **问题**: "国家橄榄球联盟球员 2010 年度平均工资 180 万美元"——听起来人人都是百万富翁。
- **方法论的使用**: 问用的是哪种平均：四分卫等巨星的天价薪酬急剧拉高**平均数**，而**中位数**只有 77 万美元——想让工资"显得高"就选平均数。癌症医嘱"存活中位数十个月"则是反例：不知全距就下绝望结论同样出错，分布里有人可能活到 80 岁。
- **结论**: 同一份数据换一种平均值，结论观感完全不同；分布信息缺失时任何"平均值"都不可单独使用。
- **结果**: 确立问句："是平均数、中位数还是众数？换一种平均值结论会怎样？"

### 案例 2: "肥脂畏 94% 有效"——证明了安全性，卖的是疗效
- **问题**: 减肥药广告宣称"94% 的人服用肥脂畏之后有了显著的积极效果"；另一篇报道称"约半数的美国人欺骗了自己的另一半"。
- **方法论的使用**: 双策略检验：遮住结论问"什么数据才能证明疗效"——给出的其实是"100 例中仅 6 例报告副作用"（安全性数据冒充疗效）；后者的数据其实是"75 名购物中心受访者中 36 人说**有朋友**承认欺骗过约会对象"（朋友的转述冒充本人行为，样本也错位）。
- **结论**: 数据句与结论句的关键词对不上（副作用 vs 疗效；朋友 vs 本人）——加倍的注意要放在两组措辞是否指同一件事。
- **结果**: 双策略成为可执行的错位检测工序。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 招聘与薪酬："平均月薪 2 万""年薪中位数"——接 Offer 前拆数字。
2. 健康与医药信息："94% 有效""风险降低 33%"——决定吃不吃、要不要转给家人。
3. 商业报道与 PR："用户增长 75%""销量翻番""满意度 90%"。
4. 理财产品："年化收益 8%""历史回报率"——决定投不投。
5. 写作与汇报自查：自己要用数据说服别人，提前做互换验证防误导。

### 语言信号 (用户的话里出现这些就应激活)

- "这个平均怎么算的 / 中位数是多少 / 百分比还是绝对数 / 口径是什么"
- "涨了 75% 很厉害吗 / 跟什么比 / 基数是多少"
- "相对风险还是绝对风险 / 每 100 人里有几个"
- 英文信号: average、median、percentage、relative risk、absolute risk、statistics can lie

### 与相邻 skill 的区分

- 与 `rival-causes-audit` 的分界（钦定）：s19 审**因果解释**（"留存涨 5% 是功能的功劳吗"）；本 skill 审**数字表述**（"'平均薪资 2 万'真假"）。
- 与 `research-survey-audit` 的区别：数字怎么**采集**（谁被问、怎么抽样）是 s17；数字已到手、怀疑"被怎么用"是本 skill。先 s17 后 s20 是正常顺序。
- 与 `omitted-info-probe` 的区别：摆出来的数字**怎么说**=本 skill；整个维度的信息**没出现**=s21。只缺一个参照数走本 skill 的互换验证，缺整个代价/反方维度走 s21。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列数字、查来历**
   - 列出材料中所有承重数字；对每个问"怎么得来的、谁统计的"
   - 完成标准: 查不到来历的标记为"不可验证的精确"；**判停条件**: 材料只有一句广告语、无任何上下文可查时，跳过溯源，直接进入 2–4 的表述检查并声明来历不明
2. **平均值三查**
   - 问用的是哪种平均；换另外两种重算观感变化；追问全距/分布是否给出
   - 完成标准: 三种平均的观感差异被明确陈述；缺分布信息时声明"典型值不可判断"
3. **错位双策略**
   - ①遮住数据写出"什么数据才能证明该结论"，与实际数据对比；②从数据独立推出自己的结论，再与作者结论比对
   - 完成标准: 任一发现关键词错位即标记"证明了 A、卖的是 B"；无错位则明确说"数据与结论同指"
4. **互换与转换**
   - 百分比↔绝对数双向换算；补齐"和什么比"的基线；健康类数字做相对↔绝对风险转换
   - 完成标准: 输出"每百人"式褪色表述；每个数字都有比较参照或声明"无基线不可比"
5. **判定收尾**
   - 完成标准: 三选一明确输出——数字真实但宣称失真 / 数字本身可疑 / 数字表述站得住；若用户在创作，附写作侧自查（绝对数+基数+平均值类型+基线是否给全）

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只想查某个统计数字本身（纯信息查询）
- 用户怀疑的是数据采集过程（抽样、问卷设计）→ `research-survey-audit`
- 用户问的是数字背后的因果解释 → `rival-causes-audit`

### 作者在书中警告的失败模式

- **不知来历的数据**: "40% 的大学生饱受抑郁症折磨"——数字的表面精确被误读为测量的精确，越难统计的东西报得越斩钉截铁
- **平均值偷换**: 右偏分布引用平均数冒充典型值；只给中位数不给全距同样是套路
- **数据与结论错位**: 副作用率冒充疗效、"朋友的行为"冒充"本人的行为"——可信度被从有数据的命题偷偷转移给想卖的命题
- **相对风险包装**: 同一疗法"降 33%"与"降 3%"并排出现，多数人选听起来最动人的那个——三者完全等价

### 作者的盲点 / 时代局限

- 本章停留在百分比/平均值/图表的表述层面，未覆盖大数据时代的 p-hacking、发表偏倚、指标定义博弈（"活跃用户""治愈"的定义本身就是战场）——现代数据审查需补充这些工具
- 隐含读者能拿到数字背后的方法说明；现实中多数数字只有 headline，本 skill 的判停规则据此设计
- 图表误导（截断 y 轴等）书中仅一笔带过，本 skill 未展开

### 容易混淆的邻近方法论

- **数学验算**: 本 skill 不是查算错——数字都对，毛病在"选哪个、怎么说、和什么比"
- **调查措辞偏见**: "怎么问出来的"是 s17 的地盘；"怎么算出来、怎么呈现的"才是本 skill
- **缺失数据**: "增长 75%"不给绝对数是数据问题（互换验证即可揭穿）；整个反方维度缺席才是省略信息问题
