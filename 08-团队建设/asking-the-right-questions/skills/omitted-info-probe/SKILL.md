## I — 方法论骨架 (Interpretation)

两条前提先立住：**所有论证必然不完整**（时空限制、注意力有限、知识不全、蓄意欺骗、价值观不同），且说服者天然把立场放在最强光线下——只报好的、藏坏的。因此只对摆在面上的信息做反应，等于只对别人替你选好的画面做反应。

但"重要"有判定标准，不是所有省略都值得追：**能影响你该不该被说服的省略才是重要省略**——批判性注意力是要配置的资源。

排查工具是九类清单：①常见反例/反面论证 ②关键词的定义 ③遗漏的价值观偏向与视角 ④事实的来源 ⑤产生效果的具体程序细节 ⑥获得同样好处的其他途径 ⑦刻意隐瞒或缺失的数据 ⑧被提倡行动的正反两面效果 ⑨预测失败的原因与预言的落空记录。

第一优先是**负面效果**——被提倡的行动几乎从不会被主动展示代价：谁蒙受损失？对权力分配、健康、人际关系、环境有何影响？长期的负面效果是什么？这些问题能让你在追随浪潮前停下来想一想。

收尾是**反瘫痪程序**：排查的目的不是宣布"信息不全所以无法判断"——那会阻止你形成任何观点。三选项：尽力索要缺失信息；表达不快并继续搜寻；或基于现有信息谨慎形成**暂定判断**（声明修正条件）。

## A1 — 书中的应用 (Past Application)

### 案例 1: "欢乐时光"头号特效药与祛痘灵 95%
- **问题**: 广告说"试试欢乐时光，它是医嘱治疗抑郁症的头号特效药"；祛痘灵宣称"祛除 95% 的深层污垢"。
- **方法论的使用**: 逐项追问没说的东西：头号广告不提药厂给治疗师的折扣与免费试用——这恰是选药的关键；祛痘灵至少六项缺失：其他品牌成绩（可能祛 99%）、单用香皂的效果、负面成分（皮肤干燥）、斑点的其他来源、剩余 5% 是否足以致斑、气味与价格。
- **结论**: 广告词可能句句属实却整体误导——"头号""五个医生中四个同意""纯天然"都靠省略说话。
- **结果**: 确立对广告的默认动作："他们没告诉我什么？"

### 案例 2: 新建大学与克隆技术——被略去的负面效果
- **问题**: 克隆论证通篇报喜（培育器官、战胜糖尿病帕金森）；新建一所大学校的正面叙事看起来只有好处。
- **方法论的使用**: 负面效果五问：克隆的副作用、器官稳定性、滥用风险全部缺席，且美国从未做过一例人体克隆实验——全部优点纯属假设；大学城藏着砍伐森林、抽走师资经费、抬高不动产税、影响周边房价。
- **结论**: 谁受损、长期效果、对权力分配与健康的影响——这些问题能在追随行动浪潮前踩一脚刹车。
- **结果**: 负面效果被确立为最常被忽视的省略类型，专节强调。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 广告与营销文案：理财、保健品、课程——"只说好话"的典型现场。
2. 重大决策前：买房、签合同、接 Offer、投资——主动补全卖方不会说的。
3. 方案与汇报评审：商业计划书、可行性报告、项目汇报只报喜不报忧。
4. 新闻报道：单方信源、缺席的另一方的声音、没有代价核算。
5. 写作自查：自己写方案前预演"对方会追问什么我没说的"。

### 语言信号 (用户的话里出现这些就应激活)

- "他没说什么 / 省略了什么 / 有没有反面 / 只报喜不报忧"
- "谁会受损 / 长期呢 / 代价是什么 / 只字不提"
- 英文信号: what's missing、what's left out、one-sided、omitted information、hidden cost

### 与相邻 skill 的区分

- 与 `deceptive-data-check` 的区别：摆出来的数字**怎么说**（s20）vs 整个维度的信息**没出现**（本 skill）。缺失比较对象是交叉地带：缺一个参照数走 s20 的互换验证；缺整个代价/反方维度走本 skill。
- 与 `alternative-conclusions` 的分界（钦定）：本 skill 找**被隐藏的**（补全输入）；s22 造**还可能的**（扩展输出）。
- 与 `rival-causes-audit` 的区别：s19 生成竞争解释（针对因果断言）；本 skill 找被隐藏的信息（针对论证完整性）——"被省略的替代解释"只是九类之一。
- 与 `scrutiny-worthiness-filter` 的区别：先问"关我什么事"决定是否启动；利害甚微的论题不启动九类清单。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **前提校准**
   - 先复用 `locate-issue-conclusion` 拿到结论与理由——没有参照系就谈不上"省略"
   - 完成标准: 能一句话说出"这份材料由谁选择展示什么"；**判停条件**: 论题对用户无利害影响时降级为一句话提醒，不启动九类清单（注意力过滤）
2. **九类清单逐项过**
   - 完成标准: 九类每类标注"已给/缺失/不适用"，缺失项逐条记录
3. **负面效果五问**
   - 完成标准: 对被提倡的行动答出——谁蒙受损失？长期负面效果是什么？对权力分配/健康/人际关系/环境有何影响？材料的正面叙事是否对代价只字未提
4. **重要性过滤**
   - 完成标准: 对每个缺失项问"补上它会改变我的立场吗"——会=重要省略，不会=记为次要；防止用小瑕疵堆砌替代真判断
5. **反瘫痪收尾**
   - 完成标准: 三选一输出——①列去向谁索要哪些信息 ②表达不快并继续搜寻 ③形成暂定判断并声明"若 X 出现则修正"；**判停红线**: 严禁以"信息不全无法判断"作为终点输出

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 娱乐性阅读、用户只求情绪共鸣——分析省略是答非所问
- 用户已通读完整研究报告且它确实交代了方法与反方（省略空间本来就小）
- 怀疑的是数字表述而非整类信息缺失 → `deceptive-data-check`

### 作者在书中警告的失败模式

- **只看摆在面上的信息**: 广告词句句属实却整体误导（"头号特效药"不提回扣、"纯天然"不提刺激性）——说服者从不会主动展示负面因素
- **信息缺失就拒绝下结论**: 以"信息不全"为由永久悬置判断，批判性思维从筛选工具变成行动瘫痪——正确姿势是形成可修正的暂定判断
- **把不重要瑕疵当重大发现**: 没有重要性过滤的排查会退化为完美主义挑剔

### 作者的盲点 / 时代局限

- 默认读者有渠道索要到缺失信息（问作者、查来源）；现实中信息不对称常由商业模式造成——卖方没有义务回应追问，"表达不快"在权力不对等关系（上级/客户/平台）中的作用书中未讨论
- 省略原因五种里"价值观不同"最难自查：读者自己缺的视角（如从未经历贫困）自己往往意识不到——清单无法列出"你不知道自己不知道的东西"
- 未覆盖算法信息环境：推荐系统本身就是一层"选择展示什么"的省略机器，且用户看不到过滤器的存在

### 容易混淆的邻近方法论

- **阴谋论式怀疑**: 本 skill 的前提是温和的（论证必然不完整），不是"有人在瞒我"——九类过完没有重要缺失，就正常接受结论
- **完美主义挑剔**: 判定标准始终是"能否改变立场"，不是"还有没有没说的"
- **决策拖延**: 排查是决策的输入环节，不是推迟决定的仪式
