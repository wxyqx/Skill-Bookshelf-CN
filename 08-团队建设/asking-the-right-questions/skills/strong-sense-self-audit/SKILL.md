# 强势批判自审（把关键问题对准自己）

## R — 原文 (Reading)

> "强势批判性思维是利用批判性思维来评估所有断言和看法，尤其是自己的看法。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

> "宁可在理由充分时反复无常。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

---

## I — 方法论骨架 (Interpretation)

批判性思维最大的滥用，是用全套提问技能只审别人、不审自己——作者称之为弱势用法：技能越娴熟，护短越高效，离真理越远。强势批判性思维要求把同一张清单对准一切断言，尤其是自己的。

落地为三个可自测的动作。其一，对称审查：你拿来挑别人毛病的问题（理由是什么？假设牢靠吗？证据够不够？），逐条问过自己的结论吗？其二，最强反方测试：能否完整复述对方阵营最好的那条理由，好到对方点头说"就是这个意思"？做不到，说明你打倒的只是自己想象的对方。其三，更新规则：作者的标准是"宁可在理由充分时反复无常"——被更好的理由说服而改立场不是失败，护住结论才是。要注意：强势审查不必然推翻初始看法，审过之后可能更加笃信；区别在于结论从此有了"被审过的来历"。

自审的时机信号：情绪先于理由升温、发现自己只在收集支持证据、结论被挑战之后才开始找理由（马后炮式理由）。任一出现，先停下对外的进攻，转向对内。

## A1 — 书中的应用 (Past Application)

### 案例 1: 取消终身教职论证中的强势批判检查项（第8章）
- **问题**: 一篇主张取消教师终身教职的文章引用全国电话调查为据，样本、措辞、动机等各项审查逐一进行，但还差一项。
- **方法论的使用**: 作者的审查十问中专门设有一项：论证者有没有显示出强势批判性思维的迹象——他有没有用同一套问题审过自己的立场？
- **结论**: 该文通篇只见对外开火、不见对己反审，这一项不过关本身就是减分证据。
- **结果**: "有没有自我审查的迹象"从道德号召变成一张可勾选的检查项，嵌进了证据审查工序。

### 案例 2: 被打败时的姿态规则（第1章）
- **问题**: 自审最难的一步是审输之后怎么办——多数人把改口当作丢脸，于是死守原判。
- **方法论的使用**: 作者给出姿态规则：宁可在理由充分时反复无常，也不在理由已尽时硬撑；并预告强势审查的另一端结果——自己的看法被审后可能更加笃信。
- **结论**: 改立场与坚持立场在程序上平等：谁的理由扎实信谁。
- **结果**: 自审从"认输仪式"变成可执行的立场更新程序。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队决策中自己是唯一反对者/少数派，想确认反对理由不是护短。
2. 写作或备稿时发现自己先定了结论、再回头找支持材料。
3. 被人反驳后第一反应是防御、想赢，根本没听进对方的理由。
4. 复盘一个坚持多年的立场，想让它过一遍与别人结论相同的审查。

### 语言信号 (用户的话里出现这些就应激活)

- "我是不是太主观了 / 我是不是在护短"（am I just defending my position）
- "帮我审审我自己的观点 / 把我的结论也过一遍清单"（audit my own conclusion）
- "我好像只在收集支持自己的证据"（confirmation bias about myself）
- "我有没有可能是错的"（could I be wrong, steelman the other side）

### 与相邻 skill 的区分

- 与 `pan-for-gold-reading` 的区别：同一张清单，对准别人的材料是 s01；对准自己的结论才是本 skill。
- 与 `critical-thinker-values` 的区别：本 skill 审"我这次结论怎么来的"；s03 审更上游的"我平时听谁说话、以什么价值观听"。
- 与 `keep-dialogue-alive` 的区别：发现自己防御时若已在对话中，语气与策略转 s04；本 skill 只管对内的审查程序。
- 与 `wishful-feeling-check` 的区别：愿望驱动（希望它是真的）归 s06；本 skill 处理的是立场捍卫（已经信了、不愿改）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别防御信号**
   - 动作: 确认触发点——情绪升温、只收集支持证据、理由晚于结论出现，三者命中其一即可
   - 完成标准: 能向用户指出具体命中了哪个信号、出现在哪句话/哪个动作上
2. **对称审查：清单对准自己**
   - 动作: 用与审别人相同的问题逐条过自己的结论——我的理由是什么？依赖什么假设？证据是什么级别？有没有替代解释？
   - 完成标准: 写出"我的结论 + 至少一条反审发现（薄弱理由/可疑假设/弱证据）"
3. **最强反方测试**
   - 动作: 完整复述对方阵营最强的那条理由，不歪曲、不打折
   - 完成标准: 复述达到"对方听了会点头"的程度；做不到则先去补课，而不是继续捍卫
4. **执行更新规则**
   - 动作: 按理由强弱决定去留——对方更强则明确改立场并说出依据；自己更稳则说明为什么
   - 完成标准: 给出"我现在相信 X，因为 Y"的表述，而非"我还是觉得我对"
   - 判停: 若情绪尚未平复或正处对抗现场，先暂停，约定再谈（转 `keep-dialogue-alive`）

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 对象是别人的材料/论证——那是 `pan-for-gold-reading` 及下游审查类 skill 的地盘
- 用户处于情绪峰值、要的是安抚——先共情，此刻上清单只会火上浇油
- 纯技艺水平的自我提升（"我代码写得怎么样"）——本 skill 审"结论与理由"，不审手艺

### 作者在书中警告的失败模式

- 弱势批判性思维（ce04）：只对别人的结论提问、从不把自己的结论放进同一张清单；理由出现在结论被挑战之后；以让对方认输为胜利标准——技能越强，离真理越远
- 感情先行（ce02）：把相反结论当成针对自己的人身攻击，观点之争体验为自我之争，结构性听不见对方本来足以说服自己的正当理由
- 逆向逻辑的自查面（ce39）：动笔前已有结论，研究只为找支持材料；同一结论的理由在不同场合版本不同；从不写下"什么证据会让我改变结论"

### 作者的盲点 / 时代局限

- 作者假设读者"愿意并能够"对自己珍视的立场做强势审查；但当身份认同与证据冲突时，书中没有给出程序性出路（BOOK_OVERVIEW·未被证明的假设）
- 双过程研究的反对意见：自我辩护是认知默认设置，靠意愿召唤自审极不可靠——本 skill 用防御信号做触发器只是部分弥补
- "强势"易被误读为对自己更狠；作者的本意是程序对称（同一张清单），不是自我攻击

### 容易混淆的邻近方法论

- 自我批评/自责：情绪性的自我否定不产生新信息；本 skill 是程序性的对称审查
- 事后复盘：复盘总结得失；自审发生在结论还热着、立场还没定死的当下
