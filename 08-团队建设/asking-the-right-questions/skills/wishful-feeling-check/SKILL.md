## I — 方法论骨架 (Interpretation)

这是对准自己情绪的两道自检，合并成一个场景：**发现自己强烈希望或拼命捍卫某个结论的那一刻**。

第一种机制是**感情先行**：观点经年累月内化成自我的一部分，遇到相反结论就体验为"他在攻击我"，于是只听得进支持自己的理由——对方立场上本来足以说服你的正当理由，被结构性过滤掉了。第二种机制是**一厢情愿**：把"我希望它是真的"直接当"它是真的"的证据，让事实迁就愿望而不是用愿望接受事实检验；它的变体是**奇迹式思考**——在科学解释缺位、或对境遇无能为力时，用奇迹和吉兆填补因果解释的空白。后者有个关键触发条件：无力感越强，机制越强，越盼越要查。

作者给的解法不是消灭感情（他明说批判性思考者不是机器），而是给感情**排序**：先完成分析推理，仍然笃信的结论才允许加大感情投入，投入之后感情仍随时受理智调节。操作抓手就是那句可脱口而出的自检问句——支撑"它是真的"的是我的愿望还是证据？答不出证据，愿望不构成证据，结论降级为"待证据"。

## A1 — 书中的应用 (Past Application)

### 案例: "似是而非"的三面示靶（第1章）
- **问题**: 人们偏爱希望为真的概念、回避已证明为真的概念：科尔伯特 2005 年嘲讽"我可不是事实的粉丝"（truthiness）；《哈利·波特与混血王子》里哈利指控马尔福，被问"你有什么证据"只答得出"我就是知道"；《辛普森一家》的巴特戳穿圣诞老人神话，反衬人们靠奇迹填补科学解释的空白。
- **方法论的使用**: 作者对每个靶子追问同一句话——这是因为我希望它是真的，还是有确凿证据？并指出奇迹式思维恰恰在无力改变境遇时最强（战争何时结束、产品标签是否名实相副），所以必须主动调用问题对抗，而不能等情绪自己退潮。
- **结论**: 自检句把"愿望"与"证据"切成两栏；愿望可以保留，但不能冒充证据，说不清证据的结论一律降级为待证据。
- **结果**: 第1章据此确立全书态度底线——感情投入放在推理之后；这也是后续各章"轮到你自己写时"自查的情绪闸门。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 自己正准备按一个"特别希望成真"的结论行动：体检结果、投资、招聘决定、感情判断。
2. 听到反驳的第一反应是火气或被冒犯，想回击而不是先听理由。
3. 面对没有科学解释或无力改变的事（疾病、运势、战局），开始转向偏方、吉兆、"信则灵"。
4. 阅读或研究中发现自己只强化支持材料，对坏消息选择性失明。

### 语言信号 (用户的话里出现这些就应激活)

- "我特别希望它是真的 / 我就盼着这个结果"（I really want this to be true）
- "我就是知道 / 说不出为什么，但肯定没事"（I just know）
- "他是不是针对我 / 我一听就来气"（feels like a personal attack）
- "万一有奇迹呢 / 信则灵"（magical thinking）
- "帮我看看我是不是一厢情愿"（wishful thinking, truthiness）

### 与相邻 skill 的区分

- 与 `strong-sense-self-audit` 的区别：它管确认护短**之后**的程序性对称审查（steelman、复述最强理由、理由充分时改立场）；本 skill 是更前置的情绪点检——先分清"愿望在说话还是证据在说话"，程序性审查才有干净的对象。
- 与 `pan-for-gold-reading` 的区别：淘金式是驱动整张清单的阅读姿态；本 skill 是阅读途中撞上"盼着它是真的"时的定点自检。
- 与 `keep-dialogue-alive` 的区别：它管对外的语气与谈话策略；本 skill 只管自己内心情绪的归位，不涉及怎么表达。
- 与 `fallacy-three-questions` 的区别：审查**对方**论证里的一厢情愿（混淆"是什么"与"该是什么"）是谬误 skill 的事；本 skill 只对准自己的愿望。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **命中自检场景**
   - 动作: 找"强烈希望/捍卫某结论"的信号——想到"可能不是真的"时的不适或抗拒、追问理由只会说"我就是知道"、情绪升温先于理由交换
   - 完成标准: 能判断此刻支撑结论的是愿望还是证据（二选一）
   - 判停: 若证据确实充分且说得出来 → 本 skill 到此结束，转入正常论证审查
2. **用自检句分离愿望与证据**
   - 动作: 逐条过"我希望的证据"——能独立核验的留下，只是愿望的降级为"待证据"
   - 完成标准: 结论落在三档之一：有证据支撑 / 待证据 / 纯愿望
3. **感情归位排序**
   - 动作: 不压制感情，把它挪到推理之后——列出"我先查什么，查完仍成立才允许自己投入感情"
   - 完成标准: 用户能说出具体的"先查清单"，而不是"以后冷静点"
4. **奇迹式思考预警**（无力感场景专用）
   - 动作: 在无力改变或科学缺位的事项上，主动要求找到至少一个替代解释或可核验来源，"奇迹"才允许入场
   - 完成标准: 给出至少一条可核验的替代解释；给不出则明确标注"此判断目前只有愿望支撑"

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只是倾诉情绪、求安慰——先接住情绪，此刻上自检句是拿工具扎人
- 纯信息查询或审美欣赏——没有"结论要不要信"的判断可检
- 文学创作中的许愿式想象——虚构不需要证据门槛

### 作者在书中警告的失败模式

- 一厢情愿（ce01）：结论先于证据出现，追问理由只能给"我就是知道"；对坏消息选择性失明，只强化升平世界的幻想；极端形式即奇迹式思考——愿望越强，机制越强
- 感情先行（ce02）：把相反结论当成人身攻击；反驳前没有复述过对方的论据；情绪升温先于理由交换——对论题感情投入的最大危险，就是考虑不到其他立场潜在的正当理由

### 作者的盲点 / 时代局限

- 作者假设读者"愿意"对自己珍视的立场做强势审查，但没给身份认同与证据冲突时的程序性出路（BOOK_OVERVIEW 批判段·未证假设）
- 心理学双过程研究的最强反对意见：直觉判断快而懒，靠一句自检句在情绪当口拦截，缺乏行为设计支撑——教会话术不等于用得出来
- 时代局限：社交媒体的情绪传播（短视频、算法推荐）成书前未出现——信息流里"先推理后投入"没有天然时机，自检需要外部触发器

### 容易混淆的邻近方法论

- 乐观主义/积极心态：作者反对的不是希望本身，是让事实迁就愿望；乐观可以保留，只是不充当证据
- 压抑情绪：本 skill 是给感情排序，不是消灭感情——"批判性思考的人毕竟不是机器"
- 怀疑一切：愿望降级为"待证据"，不是直接判假；降级后仍可被后续证据升级
