# 《掌控习惯》术语词典（GLOSSARY）

> 全书 16 个 skill 的共享术语词典，术语解释以本词典为准。
> **术语定义反映克利尔 2019 年用法；与杜希格《习惯的力量》三步模型的术语边界已在相应词条注明。**
> 词典只做定义，不展开操作步骤——操作见对应 skill。

| 术语 | 克利尔的定义（一句话） | 首次出现 | 被哪些 skill 引用 |
|---|---|---|---|
| **原子习惯（微习惯）** | 本身微不足道、简单易行的规律性举动，同时是复合增长体系的基本单元——"小习惯不会简单相加，它们会复合"；配套的 1% 法则（1.01^365≈37.8）是修辞化比喻，现实收益边际递减，只作动机叙事、不作收益承诺。 | 第1章 | 全局世界观术语，任一 skill 的定义段可引用（`identity-based-habits`、`habit-loop-four-laws` 开场；`tracking-and-accountability` 坚持期话术） |
| **基于身份的习惯（三层行为改变 · 投票模型）** | 行为改变三层（结果/过程/身份）中最内核的一层；每个行动都是投给"想成为的那种人"的一票，且不需要全体一致投票、只需多数即可——一次破戒不构成身份否决。 | 第2章 | `identity-based-habits`（主）；`start-new-habit`（记分卡身份判据）、`reward-design`（奖励-身份一致性）、`tracking-and-accountability`（恢复协议的理论依据）、`identity-flexibility`（同一机制的反向锁定） |
| **习惯回路（四步）** | 习惯循"提示→渴求→反应→奖励"四步运转，你渴求的是状态变化而非行为本身，任一环节缺失行为就不会固化。**术语边界**：杜希格《习惯的力量》为三步"诱因-惯常-奖励"，以外部刺激为主；克利尔的增量在"渴求"步（纳入思想、感情、信仰等内在状态），引用时 craving（渴求）不可写作 routine（惯常）。 | 第3章 | `habit-loop-four-laws`（主）；四定律技术群 `start-new-habit` 至 `tracking-and-accountability` 共用回路语言 |
| **行为转变四大定律** | 由习惯回路直接演化的操作规则——让它显而易见/有吸引力/简便易行/令人愉悦，各自对准回路一环；反向使用（脱离视线/缺乏吸引力/难以施行/令人厌恶）即戒除坏习惯，"好习惯推左、坏习惯推右"。 | 第3章 | `habit-loop-four-laws`（主）；`start-new-habit`、`environment-design`、`quit-bad-habit`、`temptation-bundling`、`join-the-culture`、`craving-reframing`、`two-minute-start`、`commitment-devices`、`reward-design`、`tracking-and-accountability` 各对应一条定律 |
| **习惯记分卡（含指差确认）** | 列出一天惯常行为、逐项标"+"（好）"−"（坏）"="（中性）且只观察不评判的觉察练习，好坏判据是"是否有助于我成为我希望成为的那种人"而非道德；配指差确认——大声说出行动与预期结果（源自日本铁路，错误减少约85%）。 | 第4章 | `start-new-habit`（觉察前置与锚点素材库） |
| **执行意图** | "我将于[时间]和[地点]做[事]"——用两种最稳定的提示把模糊意图转写为具体计划；克利尔的重新诊断是"人们缺的不是动力而是明确的计划"（执行意图组91% vs 动力组35-38%，全书最强证据）。 | 第5章 | `start-new-habit` |
| **习惯叠加** | "继[当前习惯]之后，我将[新习惯]"——执行意图的特殊形式，借每天必然发生的既有行为尾部当提示，须校验三条：提示具体可立即执行、频率一致、匹配动线。 | 第5章 | `start-new-habit`；`temptation-bundling`（两段式公式的第一段） |
| **环境设计（一空间一用途）** | 行为是人与环境的函数 B=f(P,E)——让好习惯的提示占据最显眼位置、每个空间（含数字设备）只分配一种用途，"背景就是提示"；其操作原则是最省力法则（第12章）：为好习惯减阻、为坏习惯增阻，"因减而加"。 | 第6章 | `environment-design`（主）；`quit-bad-habit`（增阻侧共用同一机制）；`two-minute-start`（启动减阻的物理配套逻辑） |
| **让它脱离视线（自律悖论）** | 第一定律的反用——"看似自律的人其实是较少暴露于诱惑的人"，自我控制只是权宜之计而非长远良策；习惯一旦编码几乎无法遗忘，破除坏习惯只能从源头移除提示。 | 第7章 | `quit-bad-habit` |
| **诱惑捆绑（绑定喜好）** | 用普雷马克原理（高频行为强化低频行为）把"需要做的"与"想要做的"做成同时性绑定而非事后奖励——多巴胺在期待时而非体验时激增，故让需要的习惯成为通往渴望的入口。**术语提示**：本条说的"渴求"（craving）是克利尔四步模型用语，不是杜希格的"惯常"。 | 第8章 | `temptation-bundling`（多巴胺期待机制并入本条，原 t14） |
| **模仿三群体与加入文化** | 我们尤其模仿三类对象——亲近的人、群体中的多数人、有权势的人；改变习惯最快的社会路径是加入一种文化，且须同时满足双条件：目标行为在其中是常态、你与成员已有共同点。 | 第9章 | `join-the-culture` |
| **"得→想"重构（激励仪式）** | 同一事实的负担版与机遇版说法都真，选机遇视角即改写预测、改写预测即改写渴望；激励仪式须把"喜欢的事×简短例行动作"反复配对、建立条件关联后才可随时调用。 | 第10章 | `craving-reframing` |
| **两分钟规则（门户习惯 · 决定性时刻）** | 当你开始培养一种新习惯时，它所用时间不应超过两分钟——先标准化再优化，"你不能改善一个不存在的习惯"；依据是习惯基于频率而非时长形成（第11章），门户习惯为后续行为定基调，每天几个两分钟级选择是决定性时刻。 | 第13章 | `two-minute-start`（酝酿/行动与频率命题并入本条，原 t17） |
| **承诺机制（一次性决策 · 自动化）** | 当下的抉择锁定未来的行为（奥德修斯合约）——"在成为诱惑的受害者之前，先让良好的意愿发挥作用"；一次性决策单次动作长期回报，频率低到无法成习惯的重要行为直接交给自动化。 | 第14章 | `commitment-devices` |
| **增强法（颠倒记账法）** | 给长期有利的行为添加即时快乐；颠倒记账法让"没做什么"也可见可奖励（每抵制一次诱惑就存入等额钱）；约束是奖励不得与身份冲突——"奖励启动习惯，身份维持习惯"。 | 第15章 | `reward-design` |
| **习惯追踪（绝不错过两次）** | 日历打叉等视觉量度一箭三雕——让行为同时变得显而易见、有吸引力和令人愉悦；"错过一次是意外，错过两次是新习惯的开始"；数字只是反馈而非目标（古德哈特定律），泄气时改看其他可测信号。 | 第16章 | `tracking-and-accountability` |
| **习惯契约（问责伙伴）** | 书面承诺声明 + 违约罚则 + 一两名问责伙伴共同签字——后果越局部、有形、具体、直接越有效，惩罚强度必须压过行为本身的吸引力。 | 第17章 | `tracking-and-accountability` |
| **基因适配（四问）** | 基因决定机会领域而非命运——乐趣的标志不是"喜欢"而是"能比多数人更容易承受其痛苦"；新活动先撒网探索后专注利用，找不到现成优势就叠加两三项"前25%"技能自创交叉领域。 | 第18章 | `domain-selection` |
| **金发女孩准则（4% 难度区）** | 人在处理难度约高出当前能力 4% 的事务时积极性最高（作者自认是方向而非可精确测量的刻度）——成功的最大威胁不是失败而是倦怠；"专业人士按计划行事，业余爱好者随心情而为"。 | 第19章 | `goldilocks-difficulty` |
| **精通公式（反思和审视 · 特质型身份）** | 习惯动作 + 刻意练习 = 精通；自动化的代价是对反馈的敏感度下降（"你只是在强化，而不是在改善"），解药是反思和审视体系（年终三问/决策日志/诚信报告），并以特质型身份改写防止身份固化。 | 第20章 | `mastery-reflection`（主）；`identity-flexibility`（特质型身份改写部分） |
