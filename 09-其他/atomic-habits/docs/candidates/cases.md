summary: |
  问题：人们期望努力立刻见效，在突破来临前看不到变化便放弃。
  叙事：房间温度从25华氏度一路升到31华氏度，桌上冰块始终纹丝不动；升到32华氏度时只多1度，冰却开始融化——
  突破时刻是此前一系列行动蓄积潜能的结果，"温度仅仅上升了1华氏度……但它引发了巨大的变化"。
  作者用同一类比串联：癌细胞增生80%的时间里检测不到；竹子生长头五年几乎看不到，因其在六周内猛蹿90英尺前

title: 作者的社交媒体密码托管
type: case
source_chapter: 第14章 怎样让好习惯不可避免，坏习惯难以养成
source_quote: |
  每周一，我的助手会重置我所有社交媒体账号的密码，此举使我无法在我的任何设备上登录。整整一周我都在工作，没有分心。星期五，她会把新密码发给我。
summary: |
  问题：作者写书那年总在工作之余忍不住浏览社交媒体（一般人每天在社交媒体上平均耗费两个多小时，
  相当于每年约600小时），持续的"再过一分钟"妨碍他做任何重要的事。
