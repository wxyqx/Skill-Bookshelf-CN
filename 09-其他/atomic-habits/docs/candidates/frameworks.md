id: f01
title: 目标 vs 体系（体系重于目标）
type: framework
source_chapter: 第1章 微习惯的惊人力量
source_quote: |
  目标是关于你想要达到的结果，而体系是涉及导致这些结果的过程。
  不求拔高你的目标，但求落实你的体系。
summary: |
  把"结果导向"换成"系统导向"的元框架：赢家和输家心怀相同的目标，所以目标不能解释成败；
  实现一个目标只是短暂改变，不修体系必然反弹（大扫除后房间复乱）。
  使用方法：为任何愿望写下"目标"，然后回答"每天/每周例行的是什么过程在产生这个结果"，把精力全部押在过程上。
  判据：如果只围绕结果动脑筋而没改输入端，就是治标不治本；修正输入端，输出端自行修正。
  附带收益：爱上过程而非结果，就不必把快乐延迟到"实现目标那一刻"。
tags: [habits, mental-model, goals-vs-systems]

id: f02
title: 滞后指标（看轨迹不看当下）
type: framework
source_chapter: 第1章 微习惯的惊人力量
source_quote: |
  你得到的结果是衡量你习惯的滞后指标。你的净资产是衡量你财务习惯的滞后指标。你的体重是衡量你饮食习惯的滞后指标。你的知识是衡量你学习习惯的滞后指标。
summary: |
  思维模型：你得到的一切结果（净资产、体重、知识、房间杂乱度）都是对应习惯的滞后读数。
  用法一：看轨迹不看当下——百万富翁月月超支与低收入者月月储蓄，未来走向完全相反。
  用法二：用结果反推习惯质量，而不是用愿望评判自己；想预测人生终点，就描画日常小选择的复合曲线。
  与1%复利公式搭配：单日选择无意义，十年曲线才显影；判断标准是"当前习惯是否让我走在正确的曲线上"。
tags: [habits, mental-model, feedback]

id: f03
title: 潜能蓄积期 / 失望谷地
type: framework
source_chapter: 第1章 微习惯的惊人力量
source_quote: |
  在培养习惯的过程中，有相当长时间是感受不到它的影响的，直到某一天，你突破了临界点，跨入新境界。
  你所做的努力并没有白费：它刚刚被蓄积起来。
summary: |
  解释"努力却看不到效果"的期望管理模型：复利进程最有力的结果总是姗姗来迟，突破前存在"失望谷地"。
  意象：冰块25→31华氏度纹丝不动，32度才融化；竹子前五年几乎不见，六周猛蹿90英尺。
  用法：感觉白费力气时，先问"我是没进步，还是没度过蓄积期"——努力被蓄积而非浪费。
  功能是把"没有可见回报"重新解读为"尚未到临界点"，防止在31度放弃，这是习惯能否坚持到突破的核心变量。
tags: [habits, mental-model, patience]

id: f04
title: 三层行为改变模型（结果/过程/身份）
type: framework
source_chapter: 第2章 你的习惯如何塑造你的身份（反之亦然）
source_quote: |
  第一层是改变你的结果。……第二层是改变你的过程。……第三也是最深入的层次是改变你的身份。这个层次是有关改变你的信仰
summary: |
  决策框架：任何改变都分三层——结果层（得到什么）、过程层（做什么）、身份层（相信什么）。
  多数人从外向内改（盯结果），注定失败；正确方向是由内向外，先定"想成为谁"，再让过程和结果随之对齐。
  使用方法：把"我要减20斤"（结果）改写为"我是那种把锻炼当日常的人"（身份），再设计支撑该身份的习惯。
  检验话术：拒绝烟酒时说"我不抽了"（身份转变）而非"我正在戒烟"（仍自认烟民）。
  与身份不符的行为不会持久，改变行为背后的信念才是长期坚持的唯一原因。
tags: [habits, identity, mental-model]

id: f05
title: 身份两步进程 + 投票模型
type: framework
source_chapter: 第2章 你的习惯如何塑造你的身份（反之亦然）
source_quote: |
  （1）决定你想成为哪类人。（2）用小赢证明给自己看。
  你采取的每一个行动都是投票给了你想成为的那个人。……你不需要全体一致投票才能赢得选举；你只需要多数即可。
summary: |
  操作流程：第一步决定"想成为哪类人"（可从想要的结果倒推：什么人能减40磅？什么人能著书立说？）；
  第二步用小赢证明给自己看，让每个行动成为投给新身份的一票。
  支撑模型是投票制：一两次行为不改信念，证据累积到多数即完成身份切换——这解释了微习惯为何能带来重大改变。
  关键豁免：不要求全票一致，偶尔投错票没关系，目标只是"赢得大多数时间"——对完美主义的结构化解药。
  两问变体："我想成为哪类人？这类人会做什么？"
tags: [habits, identity, decision]

id: f06
title: 习惯回路四步模型
type: framework
source_chapter: 第3章 培养良好习惯的四步法
source_quote: |
  养成习惯的过程可以分为四个简单的步骤：提示、渴求、反应和奖励。
  提示触发渴求，渴求激发反应，而反应则提供满足渴求的奖励，并最终与提示相关联。
summary: |
  全书的技术母体：一切习惯循"提示→渴求→反应→奖励"四步回路，前两步是问题阶段，后两步是解决阶段。
  提示是预测回报的线索；渴求提供动力——你渴求的是状态变化而非行为本身；反应取决于动力与能力；奖励满足渴求并教会大脑哪些行为值得复用。
  任一环节缺失行为就不会固化：消除提示则循环不启动，降低渴求则没有动力，行动太难则无法实施，奖励不满足渴求则没有下次。
  用法：诊断任何顽固行为时先定位它卡在哪一环，该环对应的正是四大定律之一。
tags: [habits, mental-model, habit-loop]

id: f07
title: 四大定律四问自查
type: framework
source_chapter: 第3章 培养良好习惯的四步法
source_quote: |
  1.我怎样才能让它变得明显？2.我怎样才能让它有吸引力？3.我怎样才能让它变得容易？4.我怎样才能让它令人愉悦？
summary: |
  由习惯回路直接演化的决策框架：想养成任何行为时依次自问四问，每问对应一个可操作的"杠杆"。
  正向使用养成好习惯；反向使用（让它脱离视线/缺乏吸引力/难以施行/令人厌恶）即可拆解坏习惯。
  使用方法：卡壳时逐条过一遍四问，找到当前最薄弱的杠杆先动它，而不是四管齐下。
  定位：作者宣称这是"改变人类任何行为"的近完备框架，适用于从体育到管理的所有领域。
tags: [habits, framework, four-laws]

id: f08
title: 习惯记分卡
type: framework
source_chapter: 第4章 看着不对劲儿的那个人
source_quote: |
  要创建自己的记分卡，就要先列出你的日常习惯。……如果是好习惯，就在旁边标注"+"号。如果是个坏习惯，就标注"-"。如果是中性习惯，标注"="。
  这种行为是否有助于我成为我希望成为的那种人？
summary: |
  觉察流程：列出一天的惯常行为清单→逐项标注"+"（好）"−"（坏）"="（中性）→只观察不评判，练习的第一步不改变任何行为。
  好坏判据不是道德而是身份："这种行为是否有助于我成为我希望成为的那种人？"同一样行为因目标不同可好可坏。
  用途：自动化程度越高越容易无意识滑行，记分卡把下意识行为提升到意识水平——行为转变总是始于自觉。
  附加价值：这份清单同时是习惯叠加的锚点素材库。
tags: [habits, awareness, tool]

id: f09
title: 指差确认
type: framework
source_chapter: 第4章 看着不对劲儿的那个人
source_quote: |
  大声说出你想采取的行动和你预期的结果。
  指差确认减少的错误高达85%，并让事故发生率降低了30%。
summary: |
  借自日本铁路系统的觉察技术：眼、手、嘴并用，把行动与预期结果大声说出来，把下意识习惯提升到警觉水平。
  两个用法：(1) 提醒正事——"明天午饭后，我要去邮局"，说出即提高执行概率；
  (2) 拦截坏习惯——拿起饼干时说"我要吃这块饼干，但我并不需要它。吃掉它会导致我体重增加，损害我的健康"，出声让后果变得触手可及。
  原理：自动化程度越高越不会质疑自己在做什么，出声即时增加行动的心理阻力，防止不知不觉滑入旧模式。
tags: [habits, awareness, tool]

id: f10
title: 执行意图
type: framework
source_chapter: 第5章 培养新习惯的最佳方式
source_quote: |
  我将在[时间]和[地点]做[事]。
  但是第三组中91%的人每周至少锻炼一次——比正常频率高一倍以上。
summary: |
  决策框架：把模糊意愿（"我要吃得健康"）转写为"我将于[时间]在[地点][行为]"的具体计划；最常见的两种提示就是时间和地点。
  证据强度全书最高：健身实验中执行意图组91% vs 动力组35-38%，动力陈述几乎无效——人们缺的不是动力而是明确的计划。
  附加收益：计划具体化后更容易对无关请求说不；行动时刻到来时无需再做决定，按预定计划执行即可。
  技巧：时点可选新年、月初等"新起点"，人们在此类时点满怀期望、更可能开始行动。
tags: [habits, planning, tool]

id: f11
title: 习惯叠加
type: framework
source_chapter: 第5章 培养新习惯的最佳方式
source_quote: |
  "继[当前习惯]之后，我将[新习惯]。"
  你的提示出现的频率也应该和你想要培养的习惯一样频繁。
summary: |
  执行意图的特殊形式：把新行为锚定在每天必然发生的旧习惯上，让旧习惯充当现成提示，无需另找时间地点。
  三条校验：提示具体且可立即执行（"合上笔记本电脑准备吃午饭"优于模糊的"午休时"）；提示频率与新习惯一致（每日习惯不能叠在每周习惯上）；位置匹配生活动线，忙乱时段不强加新习惯。
  可串联成链：倒完咖啡→冥想60秒→写待办清单→立即做第一件事；也可反向利用"一进一出"等通用规则。
  找锚点的方法：用习惯记分卡，或做两列清单（每天必做的行为 × 每天必然发生的事）。
tags: [habits, planning, tool]

id: f12
title: 环境设计 / 一空间一用途
type: framework
source_chapter: 第6章 原动力被高估，环境往往更重要
source_quote: |
  行为是环境中人的函数，或者B（行为）=f（函数）[P（人），E（环境）]。
  常言道："一个空间，一种用途。"
summary: |
  思维模型：行为=人的函数×环境的函数，"背景就是提示"，人们选择产品常因为它在哪里而非它是什么（餐厅加放矿泉水，苏打水销量降11.4%）。
  操作：让好习惯的提示占据最显眼位置——苹果放台面大碗、吉他架放客厅中央、药瓶放水龙头旁；最佳选项配最鲜明提示。
  进阶"一空间一用途"：每个空间（含数字设备）分配单一用途（电脑只写作、平板只阅读），空间不够就划活动区。
  延伸：在全新环境中建立新习惯更容易，因为与旧习惯绑定的提示被物理隔离。
tags: [habits, environment, design]

id: f13
title: 让它脱离视线（自律悖论）
type: framework
source_chapter: 第7章 自我控制的秘密
source_quote: |
  消除坏习惯的最实用的方法之一是避免接触引起它的提示。
  自我控制只是权宜之计，而非长远良策。
summary: |
  第一定律的反用，也是"自律悖论"：自控力强的人与深陷泥潭的人并无不同，只是他们很少置身于充满诱惑的环境——逃避诱惑比抗拒诱惑容易。
  操作：为坏习惯做提示源排查，逐项移除或远离——手机放另一个房间、电视移出卧室、取关引发嫉妒的社交媒体账号、游戏手柄玩完放进壁橱。
  理论依据：习惯一旦编码进大脑就无法删除只能绕开（提示诱发欲求快至33毫秒，快过意识）；抵制诱惑耗能巨大且终会失败。
  结论：与其每靠一次意志力，不如把精力花在优化环境上——去除一条提示，整个习惯往往就此消失。
tags: [habits, environment, inversion]

id: f14
title: 诱惑捆绑（绑定喜好）两段式
type: framework
source_chapter: 第8章 怎样使习惯不可抗拒
source_quote: |
  1.继[当前习惯]之后，我将[我需要的习惯]。
  2.继[我需要的习惯]之后，我将[我想要的习惯]。
summary: |
  技术模板：把"需要做的"与"想要做的"绑在一起（普雷马克原理：高频行为强化低频行为），使低频的必要行为获得高频喜好的拉力。
  两段式公式 = 习惯叠加 + 绑定喜好：例——午休回来后打三个销售电话（需要）→打完后上ESPN看比赛近况（喜好）；掏出手机后做十个立卧撑（需要）→做完后查看脸书（喜好）。
  原理：多巴胺在期待时激增，动力来自对奖励的期待而非奖励本身；让"做需要的事"变成通往喜好的入口。
  应用面：健身时才允许读八卦新闻、处理完过期邮件才做足疗。
tags: [habits, motivation, tool]

id: f15
title: 加入文化双条件筛选
type: framework
source_chapter: 第9章 在习惯形成中亲友所起的作用
source_quote: |
  加入一种文化，其间（1）你喜好的行为是正常行为；（2）你已经和这个群体有一些共同之处。
summary: |
  决策框架：改变习惯最有效的路径之一是换群体。人天生模仿三类人——亲近的人、群体中的多数、有权势的人。
  筛选双条件：①你想要的行为在该文化中被认定为正常（身边都是健身的人，坚持锻炼就显得不难）；
  ②你与成员已有共同点（书呆子健身社群里的游戏迷），归属感让改变更有吸引力。
  效果：集体身份强化个人身份（"我们是读者/我们是骑友"），把个体追求变成群体追求，这是维持长期动力的最强形式之一。
  警示：部落规范往往压倒个人偏好，逆主流文化需要额外付出。

id: f16
title: "得→想"重构 + 激励仪式
type: framework
source_chapter: 第10章 如何找到并消除你坏习惯的根源
source_quote: |
  仅仅换个词：你不是"得"而是"想"做那些事。
  关键是上述两种说法都是对的。你得做这些事，你也想做这些事。
summary: |
  认知重构技术：把"我得早起"改说为"我想早起"——两种说法都真，选机遇视角即改写预测，改写预测即改写渴望（习惯的原因是先于它的预测）。
  应用例：跑步=增强耐力的机会；省钱=提高下个月购买力；冥想分心=练习呼吸的机会；赛前紧张=兴奋，肾上腺素帮助集中注意。
  进阶"激励仪式"：把喜欢的事（摸狗、泡泡浴）与简短例行动作（三次深呼吸+微笑）反复配对，确立后可随时调用该提示切换情绪状态，如进入"竞技模式"。
  反用（第二定律颠倒）：像《简易戒烟法》一样逐条重写坏习惯的关联——"你以为在减压，其实在破坏神经"，使其失去吸引力。
tags: [habits, reframing, cognitive]

id: f17
title: 酝酿 vs 行动自检
type: framework
source_chapter: 第11章 慢步前行，但决不后退
source_quote: |
  酝酿意味着你在计划、策划和学习。这些都是好东西，但是它们不会产生结果。
  酝酿让你感觉自己正在做事。但实际上，你只是在准备做事。
summary: |
  自检框架：区分酝酿（计划、学习、罗列想法——不产生结果）与行动（产生结果的行为）。列20个选题是酝酿，坐下写出第一段才是行动。
  深层动机识别：酝酿让你感觉在进展而不必承担失败风险，本质是推迟可能的失败、回避被公开评判。
  判据一句话："这个动作直接产生结果吗？"和私人教练谈多少次都不会让身体更健康，只有开始锻炼才会。
  对策：不求完美先求重复——摄影课"数量组"包揽全部佳作，"质量组"只剩理论和一张平庸照片；关注次数而非最优方案。

id: f18
title: 最省力法则 / 因减而加
type: framework
source_chapter: 第12章 最省力法则
source_quote: |
  当在两种相似的选项之间做决定时，人们自然会倾向于需要最小工作量的那一个。
  我喜欢把这个策略称为因减而加。

  期望管理思维模型：满足感取决于所得与所期的差距——期望10美元得100美元是惊喜，期望100美元得10美元是失望；期望与结果匹配则满意。
  两条推论：期望过高注定痛苦（失败的痛苦与期望高度正相关，"我不想抱有太大的希望"有其智慧）；
  幸福是"已满足的欲望与酝酿中的欲望之间的空当"，想要远超所得则永不满意（塞涅卡：贫穷并不是太少，而是想要更多）。
  用法：提高长期坚持概率的两条路——降低对该习惯即时回报的预期，或设计超预期的即时奖励；这与第四定律的奖励设计直接衔接。
