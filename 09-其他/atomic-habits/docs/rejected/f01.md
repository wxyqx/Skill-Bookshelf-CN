# 淘汰：目标 vs 体系（体系重于目标）

- **候选 id**: f01, p01（framework-extractor 与 principle-extractor 双池重复提取，合并验证）
- **出处**: 第1章 微习惯的惊人力量
- **挂在哪项**: V3 独特性检验
- **原因**: "别只盯着目标，要建立体系/流程"已是流行心理学与商业管理的高度常识（概念源自斯科特·亚当斯，被无数生产力内容转述）。按任务 V3 口径，"目标 vs 体系"属于点名淘汰的"凡人皆知"型：抹掉作者名字，任何对本书毫无了解的聪明人都能说出"赢家和输家目标差不多，区别在做法"。V1 虽可通过（书中多处出现），但 V3 一票否决。
- **降级去向**: 作为 S01（identity-based-habits）/ S03（habit-loop-four-laws）的开场对照叙事素材；配套反例 x01（目标陷阱）、x02（溜溜球效应）随行引用。
