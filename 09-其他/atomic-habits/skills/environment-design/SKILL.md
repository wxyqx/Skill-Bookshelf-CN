# 环境设计（提示显性化 + 一空间一用途 + 减阻）

## R — 原文 (Reading)

> "行为是环境中人的函数，或者B（行为）=f（函数）[P（人），E（环境）]。……环境是塑造人类行为的无形之手。……常言道：'一个空间，一种用途。'"
>
> — 詹姆斯·克利尔，第6章《原动力被高估，环境往往更重要》

---

## I — 方法论骨架 (Interpretation)

想让好行为自动发生，先别升级动机，去改造空间。理论基座是卢因方程 B=f(P,E)：行为主要由环境而非"原动力"决定。两个杠杆：

一是提示的可见性。视觉是人类最强感官，谁占据视线谁赢得行为——把好习惯的提示（水果、吉他、书）放到动线最显眼处；"人们选择产品不是因为它们是什么，而是因为它们在哪"。

二是用途的单一性。"一个空间，一种用途"：床只睡觉、书桌只工作；手机能做几乎任何事，就成了"各种提示的大杂烩"，要按用途分屏分身份。背景本身就是提示，混合用途的空间里，更容易的那个行为（往往是坏习惯）总会胜出。

再配一道减阻工序：为明天的好习惯提前备好环境（前一晚摆好健身装、用完即归位），把启动所需的决策清到零。这是一次性动作换长期回报的工程，不靠每天的自我说服。

## A1 — 书中的应用 (Past Application)

> 注：本单元聚类表 A1 案例栏为"—"，以下用阶段 1.5 验证单元（v07）内的书中证据。

### 案例 1: 医院餐厅的矿泉水（第6章）
- **问题**: 如何在不劝说任何人的情况下改变众人的饮品选择。
- **方法论的使用**: 研究者只在每张餐桌和冷藏柜加放瓶装水，让水的提示更显眼——不贴海报、不办讲座，只调环境。
- **结论**: 提示可见性是行为的自变量。
- **结果**: 苏打水销量下降11.4%，瓶装水消费上升25.8%。

### 案例 2: 前一晚摆好健身装（第12章 减阻预备）
- **问题**: 早晨锻炼的启动阻力大。
- **方法论的使用**: 把健身装备提前摆在必经之处，把"决定+寻找+准备"压缩为零——与日本精益生产"因减而加"同一逻辑：清除流程中的阻力点即增加产出。
- **结果**: 启动概率显著高于依赖当天临场意志力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "在家总学不进去/工作走神"——空间混杂或提示不当。
2. "一拿起手机就放不下"（目的是让专注更容易而非戒手机——戒手机转 quit-bad-habit）。
3. "没有独立书房，工作生活搅在一起"——一空间一用途的空间不足变体。
4. "明天又要开始健身了，怎么让自己真的去"——减阻预备。
5. 搬家/换新环境期——建立新习惯的窗口期（新环境比老地方更易立新习惯）。

### 语言信号 (用户的话里出现这些就应激活)

- "环境/布置""放在哪/摆哪里""看得见/眼皮底下""一空间一用途""减少干扰"
- 英文: environment design / set up my space / one space one purpose / visible cues / reduce friction / desk setup

### 与相邻 skill 的区分

- 与 `quit-bad-habit`: 同是环境工程，方向相反——本 skill 让好行为更容易（提示显性化+减阻），S06 让坏行为更难（提示清除+增阻）。用户主诉是"戒X"时转 S06。
- 与 `start-new-habit`: S04 写"何时何地做"的计划；本 skill 是其物理配套。问"什么时间做"留 S04，问"放哪/怎么布置"到本 skill。
- 与 `commitment-devices`: S11 用承诺机制与自动化锁定未来行为（密码托管、自动转账），力度强于空间布置；需要"锁死"而非"顺手"时转 S11。
- 与 `two-minute-start`: "启动太难"若源于步骤太大而非环境，转 S10。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **画空间-用途映射表**
   - 列出主要空间与设备（床、书桌、沙发、手机各屏、平板），标注当前实际用途与期望用途，找出"一物多用"的冲突项。
   - 完成标准: 映射表完成，每个冲突项附一句"混用触发了什么行为"。

2. **提示显性化 + 分区**
   - 把好习惯提示移入每日必经视线（1 米内）；冲突用途物理分区或物体重定向（同一张桌子用朝向、物品区分工作/生活模式；手机只留一屏必要 App，其余移出首屏）。
   - 完成标准: 至少 1 个好习惯提示进入每日动线视线；每个空间/设备写下一句主用途。

3. **减阻预备**
   - 为明天的好习惯备好环境（衣物、工具、文件预先就位）；定一条"重启居室"规则（用完一处即复位，方便下一件事）。
   - 完成标准: 明早启动该习惯所需决策数为零（伸手即得）；重启规则成文。
   - 判停: 执行中若发现用户主诉其实是"戒掉某行为"，立即转 quit-bad-habit 的提示排查流程。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 戒除坏习惯——方向相反，转 quit-bad-habit。
- 用户没有起码的私人空间与稳定居所——书中的补救（"划分活动区"）对受限环境过于轻描淡写，应诚实告知适用边界并给最小替代（床头收纳、图书馆锚空间）。
- 把整理术当目的——本 skill 的目的是行为改变，不是美观收纳。

### 作者在书中警告的失败模式

- x08 一屋多用：作者创业期在沙发与餐桌上工作，"到了晚上，我还是放不下手头的工作"——混合情境时更容易的习惯总会胜出；手机是"各种提示的大杂烩"。

### 作者的盲点 / 时代局限

- 方案预设用户有可支配的私人空间与购置自由：合租者、照护者、轮班者适用性差，书中对受限人群着墨甚少。
- 第6章环境决定行为与第2章身份驱动行为在书中各自成立、边界未划——两者常需配合使用，本 skill 不覆盖身份层。
- 本书 2019 年出版，行为科学证据仍在更新，重要健康/心理决策应结合专业意见；克利尔为商业作者，科学细节有简化。

### 容易混淆的邻近方法论

- 断舍离/收纳术：目标是整洁而非行为，无"提示-行为"机制。
- S06（同框架反向）：见 A2 区分，勿混用两套动作。
