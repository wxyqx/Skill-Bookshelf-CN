# 习惯回路四步与四大定律（元诊断）

## R — 原文 (Reading)

> "行为转变的四大定律是一套我们可以用来培养好习惯的简单规则。它们是：（1）让它显而易见；（2）让它有吸引力；（3）让它简便易行；（4）让它令人愉悦。……我们可以反其道而行之，借以改掉坏习惯。"
>
> — 詹姆斯·克利尔，第3章《行为转变的四大定律》

---

## I — 方法论骨架 (Interpretation)

习惯是大脑省力用的心理捷径，循四步回路运转：提示（触发线索）→渴求（想要的不是行为本身，而是它带来的状态变化）→反应（实际去做，取决于动力与能力）→奖励（满足渴求，并教会大脑"这值得重复"）。四步缺任何一环，行为就不会固化成习惯。

由此直接演化出四条定律，各自对准一环：养成好习惯正向推（显而易见/有吸引力/简便易行/令人愉悦），戒除坏习惯反向推（脱离视线/缺乏吸引力/难以施行/令人厌恶）。

本 skill 的用法是元诊断：像电工查断点一样，先判断回路断在哪一环，再选对应定律的技术——而不是四条一起上。结论章给出按卡点定位的循环表：记不住→第一定律；不想开始→第二定律；太难→第三定律；不想坚持→第四定律；好习惯推左、坏习惯推右，一圈排查完再排下一个瓶颈。

## A1 — 书中的应用 (Past Application)

> 注：本单元聚类表 A1 案例栏为"—"，以下用阶段 1.5 验证单元（v03）内证据。

### 证据 1: 结论章——作者把四定律重构为循环诊断工具箱
- **问题**: 读者学了一堆技术，却不知道何时该用哪条。
- **方法论的使用**: 作者亲自把全书技术收束为一张"按卡点选定律"的诊断表（记不住→一；不想开始→二；太难→三；不想坚持→四），并要求"一圈又一圈排查下一个瓶颈"。
- **结论**: 四定律的正确用法是顺序排查的循环诊断，不是并行背口诀。
- **结果**: 这一重构就是本 skill 执行路径的来源。

### 证据 2（推演示例，非书中案例）: 背单词 App 三个月仍一见英语就烦
- **问题**: 提示（固定提醒）与反应（打卡动作）都在且已固化，为何仍厌学。
- **诊断**: 卡在奖励——即时奖励是"不断链"而非状态变化，不满足渴求。
- **处方**: 动第四定律（诱惑捆绑/增强法给背词接上渴望的尾巴），而不是换 App 或加打卡天数。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "什么都试过了"：打卡 App、闹钟、朋友监督全部失败，问"我到底哪里出了问题"。
2. 用户描述的失败模式可归入四类之一：忘了做 / 不想开始 / 太难做 / 坚持不了。
3. 用户拿着某个具体技术来问"这方法对我有用吗"——先定位回路再回答。
4. 用户想戒某习惯，但不知道该移除提示、重构渴望还是加阻力。

### 语言信号 (用户的话里出现这些就应激活)

- "为什么我的习惯总是养不成""卡在哪了""试过很多方法都没用""帮我分析一下"
- "习惯回路""提示渴求反应奖励""怎么诊断"
- 英文: habit loop / cue / craving / response / reward / diagnose my habit / why doesn't it stick

### 与相邻 skill 的区分

- 与 S04-S13 全部技术 skill: 本 skill 只回答"断在哪一环"，不产出具体技术方案；诊断完立即转介对应定律 skill，避免抢调用。
- 与 `start-new-habit`: 用户还不知道卡点时先来本 skill；已明确"就是要开始"则直接 S04。
- 与 `quit-bad-habit`: "想戒但不知从哪下手"可先经诊断；定位在提示环节即转 S06。若用户目标明确只求戒法，直接 S06。
- 与杜希格三步模型: 术语不可混用——杜希格"诱因-惯常-奖励"没有"渴求"步；克利尔的渴求=对状态变化的欲求，不是杜希格的惯常（routine）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **把行为装进回路**
   - 依次问：线索是什么？预期的状态变化是什么？实际做了什么？得到了什么即时结果？
   - 完成标准: 四个空格各有一句具体答案，能连成"每当[提示]，我就[渴求]，于是[反应]，换来[奖励]"的一句话。

2. **定位断点**
   - 按四问排查：注意不到→第一定律；不想做→第二定律；做不动→第三定律；做完没满足感→第四定律。
   - 完成标准: 唯一主断点被点名（最多并列两环，且排出先后次序）。
   - 判停: 好习惯按上表正向定位；坏习惯反向定位（提示太显眼→一反；诱惑太大→二反；太容易做→三反；事后无恶果→四反）。

3. **转介处方**
   - 输出一句处方："断点在X环，用第Y定律，移交 <skill-slug>"。
   - 完成标准: 处方点名具体 skill（S04-S13 之一）并给出一句理由；不做技术展开。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已明确卡点、直接要技术——转对应定律 skill，不要再走一遍诊断。
- 一次性任务，不需要习惯化——没有回路可查。
- 用户要的是解释"习惯为什么存在"——那是杜希格式的解释性问题，本书立场是工程性改造。

### 作者在书中警告的失败模式

- 不要四条定律齐头并进——结论章明示"一圈又一圈排查下一个瓶颈"，一次只动一个环节，否则诊断退化为泛泛建议清单。

### 作者的盲点 / 时代局限

- 本书 2019 年出版，行为科学证据仍在更新；回路模型是多巴胺等机制的口号式压缩（预测误差学习等核心功能被略去），克利尔为商业作者，科学细节有简化。回路诊断是启发式透镜，不构成因果保证。重要健康/心理决策应结合专业意见。
- 模型假设行为可分解为清晰四步，情绪性、冲动性强的行为（暴食、强迫倾向）定位常不干净，此时应考虑专业评估。

### 容易混淆的邻近方法论

- 杜希格《习惯的力量》三步"诱因-惯常-奖励": 缺"渴求"步，立场偏解释；引用时"渴望"在克利尔语境=渴求（craving），绝不能写成杜希格的惯常（routine）。
- "21天/66天养成习惯"式流行说法：只谈天数、无环节可查，不属于本框架。
