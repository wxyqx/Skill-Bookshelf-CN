# 戒除坏习惯（脱离视线 + 提示源排查 + 增阻梯度）

## R — 原文 (Reading)

> "自我控制能力强的人通常最不需要使用它。……研究人员称这种现象为'提示诱发的欲望'：某个外部触发因素激起的、需要重复坏习惯的强迫性的欲求。……自我控制只是权宜之计，而非长远良策。"
>
> — 詹姆斯·克利尔，第7章《自我控制的秘密》

---

## I — 方法论骨架 (Interpretation)

戒坏习惯的第一定律反用：不是练出更强的自控，而是减少暴露。习惯一旦编码就几乎无法遗忘——提示一出现（可快至意识来不及介入），渴望自动升起。所谓自律者与深陷者并无天赋差异，他们只是更少把自己放进诱惑环境："自我控制只是权宜之计，而非长远良策。"

因此工作重心从"忍住不做"换成"清除暴露"，三步走：先盘点提示源（地点、时间、物品、人、App、情绪状态）；再逐项移除或隔离；最后对移不掉的通道按增阻梯度逐级加障碍——退出登录、删快捷方式、拔插头、取电池、搬到别的房间——让冲动在触发前自然衰减。

成功的标准不是"今天忍住了"，而是"今天没看见、够不着"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 越战老兵的海洛因瘾（第7章）
- **问题**: 海洛因成瘾当时被视为不可逆，为何大批越战老兵回国后自行戒断？
- **方法论的使用**: 研究员李·罗宾斯追踪发现，驻越时士兵被提示包围（毒品触手可及、战争压力、战友同吸、身处异乡）；回国后这批触发因素整体消失——改变的是暴露环境而非意志强度。
- **结论**: 戒除坏习惯最实用的办法是从源头移除提示，让它脱离视线。
- **结果**: 老兵回家仅5%一年内复瘾、12%三年内复发；对照典型戒毒者约90%复吸——数据完全相反。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. "卸载了游戏每周又重装""删了 App 又装回来"——只移除了行动阻力，没移除提示源。
2. "一刷就停不下来"——短视频/社交媒体/网购类数字习惯。
3. "看到零食就想吃，管不住嘴"——零食触手可及的暴露问题。
4. "我意志力太差，每次都忍不住"——把问题错误归因于人而非环境。
5. "戒烟/戒糖，家里还囤着"——提示未清除。

### 语言信号 (用户的话里出现这些就应激活)

- "戒掉/戒除""忍不住/管不住""上瘾/成瘾""刷""诱惑""自控/意志力""重装"
- 英文: quit / can't stop / addiction / temptation / willpower / keep reinstalling / relapse

### 与相邻 skill 的区分

- 与 `environment-design`: 同为环境工程、方向相反——本 skill 移除坏习惯提示并增阻，S05 显性化好习惯提示并减阻。"帮好习惯"转 S05。
- 与 `craving-reframing`: 提示无法移除时（工作应酬的烟、办公室零食、必须用的社交软件），用认知重构让习惯失去吸引力，转 S09；本 skill 的先手始终是物理清除。
- 与 `commitment-devices`: 增阻不够、需要"锁死未来"（罚款契约、密码托管、定时断网）时转 S11——S11 是更强的结构锁定。
- 与 `identity-based-habits`: 用户满口"我正在戒"的旧身份叙事时，S01 的身份改写是配套前置，但清除提示仍是主手术。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **提示源盘点**
   - 围绕目标坏习惯列提示清单：地点/时间/物品/人/App 与入口/情绪状态，逐项写实。
   - 完成标准: 不少于 5 条具体提示源；每条能回答"它怎么触发我"。

2. **移除与隔离**
   - 能移除的移除（清空囤货、下架 App、退群、取关），不能移除的隔离（换位置、藏起来、搬出卧室/书房）。
   - 完成标准: 每条高频提示源标注"已移除/已隔离/不可移除"三态之一；不可移除项移交第 3 步或转介 craving-reframing。

3. **增阻梯度**
   - 对残留通道逐级加阻力：退出登录+改复杂密码→删除快捷方式→设备搬家→网站拦截器/定时断网；目标是冲动与行动之间隔至少 3 道障碍。
   - 完成标准: 写出当前梯度层数并完成至少两级；用户能自测"下次冲动时要跨几步"。
   - 判停: 若涉及物质依赖（酒精、药物）或已影响健康与工作，本 skill 只作辅助，明确建议专业戒治。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 养成好习惯——转 environment-design（同框架反向）。
- 提示已清除仍强烈复发、纯认知层面的渴望——转 craving-reframing 或 commitment-devices。
- 用"考验自己/硬扛诱惑"为荣的场景——这恰是本 skill 要拆除的思路，不是它的用法。

### 作者在书中警告的失败模式

- x09 孤勇式自控：把意志力当方案，零食放手边、手机放枕边正面硬扛——提示诱发欲望快至33毫秒，意识来不及对抗；"我还从未见过有人长期置身于消极环境中而能坚守积极的习惯"。成功依赖"忍住了"而非"看不到"即是警示信号。

### 作者的盲点 / 时代局限

- 平台有成建制的增长团队对抗个体的环境设计——密码托管对抗不了奈飞自动连播背后的整个增长团队，本 skill 是个体化补丁而非系统解。
- 成瘾有临床机制（神经适应、戒断反应），退伍军人案例为单一研究转述且属极端情境证据，不可直接外推到重症成瘾；物质依赖与戒断风险应寻求专业戒治。
- 本书 2019 年出版，行为科学证据仍在更新，重要健康/心理决策应结合专业意见；克利尔为商业作者，科学细节有简化。

### 容易混淆的邻近方法论

- environment-design（S05）: 同框架反向，见 A2。
- commitment-devices（S11）: 增阻是"多走几步"，承诺机制是"提前锁死"，力度与代价都更高。
- "21天戒断"类流行说法：无提示排查与梯度设计，不属于本框架。
