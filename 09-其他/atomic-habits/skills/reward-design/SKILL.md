# 奖励设计（增强法 + 颠倒记账法 + 身份一致性）

## R — 原文 (Reading)

> "The cardinal rule of behavior change: What is immediately rewarded gets repeated. What is immediately punished is avoided. ... Rewards can start a habit. Identity sustains a habit."
>
> 自译：行为转变的基本准则：即时得到奖励的行为会重复，即时受到惩罚的行为会避免。……奖励可以启动一种习惯，身份则可以维持一种习惯。
>
> — James Clear, Atomic Habits, 第15章

---

## I — 方法论骨架 (Interpretation)

1. 大脑进化于即时回报环境，而现代好习惯的回报全是延迟的：健身的果实三个月后到账，刷手机的快感三秒钟到账——在决定性的一刻，即时满足几乎总是胜出。
2. 基本准则因此是"重复有即时回报的行为，避免受即时惩罚的动作"；对好习惯要做的是增强法：给长期有利的行为添加即时快乐。
3. 抑制型行为（戒糖、省钱、戒刷手机）有个结构性难题：你"没做什么"，没有可庆祝的对象——颠倒记账法解决它：每抵制一次诱惑，就把等额钱转入目标账户，让"不做什么"变得可见、可奖励。
4. 硬约束是身份一致性校验：健身后冰激凌是拆台（投给旧身份的票），全身按摩才吻合；奖励必须与你想成为的人一致。
5. 交接机制：外部奖励只负责维持形成期的兴奋点，等行为本身的内在回报与身份证据接管后，应逐步撤除——"奖励启动习惯，身份维持习惯"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 卡拉奇的香皂 (c13)
- **问题**: 卡拉奇贫民窟几乎人人"知道"洗手重要，却极少执行——问题不在意识，在没有坚持的理由。
- **方法论的使用**: 公共卫生团队提供易起泡、满手泡沫、散发香气的舒肤佳香皂，把洗手从苦差变成愉悦体验（对照：缺乏感官愉悦的牙线始终难以普及）。
- **结论**: 让行为本身带来即时愉悦，重复才会发生，习惯才能留存。
- **结果**: 几个月内儿童腹泻率降 52%、肺炎减少 48%；六年后回访，超 95% 受助家庭仍保留洗手处——习惯不仅养成而且长期留存。

### 案例 2 (书中读者做法，随 v14 单元证据): 颠倒记账法
- **问题**: 想省钱/戒冲动购物，但"克制"这个动作本身没有任何即时反馈可庆祝。
- **方法论的使用**: 每放弃一次购买，就把等额钱转入"欧洲之旅"账户，让"没做什么"变成看得见的即时奖励。
- **结论**: 抑制型行为必须有专门的奖励形态，否则它天然输给即时满足。
- **结果**: 抵制行为获得正反馈，储蓄目标与冲动管控同步推进。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户开始了一个长期习惯（健身/学习/存钱），感到"看不到回报撑不下去"，想给它配即时奖励。
2. 用户纠结"奖励什么才不会破坏习惯"（戒糖第 10 天想奖励一块蛋糕？）。
3. 用户想奖励"忍住了/没做"这类抑制行为，发现没有自然的庆祝对象。
4. 用户依赖外部奖励后开始担心"没有奖励就不想做"，需要交接方案。

### 语言信号 (用户的话里出现这些就应激活)

- "奖励自己什么/做完怎么犒劳/即时反馈"
- "忍住了怎么奖励/颠倒记账"
- "奖励会不会毁掉习惯/是不是要一直奖励下去"
- 英文: instant reward / reinforcement / make it satisfying / treat myself

### 与相邻 skill 的区分

- 与 `temptation-bundling` 的区别：S07 是同时性绑定（踩单车时才能看剧），奖励嵌在行为之中、免掉一次"事后兑现"的决策；S12 是行为完成后的追加奖励。绑定能成立时优先 S07。
- 与 `craving-reframing` 的区别：S09 改变行为前的感受与预测（零奖励物、纯认知）；S12 引入真实的外部奖励物。用户"讨厌做"先试 S09，"不讨厌只是无聊/无反馈"用 S12。
- 与 `tracking-and-accountability` 的区别：S13 的契约给违约加即时痛苦（惩罚端）；S12 给坚持加即时快乐（奖励端）。问"罚多少合适"走 S13，问"奖什么合适"走 S12；追踪带来的"可见进步"本身也可充当 S12 的奖励。
- 与 `commitment-devices` 的区别：S11 锁定未来选项、消除临场选择；S12 润滑当下行为的体验。二者与 S12 分别对应第三定律的锁定面与第四定律的愉悦面。
- 与 `identity-based-habits` 的区别：S01 回答"投给哪个身份"的方向问题；S12 是在方向已定后，用身份一致性当奖励的筛选判据。

## E — 可执行步骤 (Execution)

1. **身份一致性校验**
   - 完成标准: 列出 3 个候选奖励，逐一问"这与我想成为的人一致吗"；剔除拆台式奖励（健身后冰激凌、戒糖者奖励蛋糕）。
2. **选增强形态并定额度**
   - 完成标准: 完成型行为配"行为完成后立即兑现"的小额奖励（延迟 ≤1 小时）；抑制型行为必须配颠倒记账（每抵制一次 → 等额转入目标账户），写明金额与触发条件。
3. **写明交接点**
   - 完成标准: 写下"外部奖励退役"的判据（如：连续 X 周不靠奖励也想做/身份证据已积累），并设置撤除节奏；期间若发现"只为奖励而做"，回到步骤 1 重新校验身份一致性。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想要的是"把想要的事和需要的事绑在一起同时进行"——temptation-bundling 更对口。
- 用户想给他人（孩子/下属）设计奖励——先过身份投票检验：按本数给读书奖励，会把行动的投票对象变成"拿奖励的人"而非"读者"；外部奖励可能侵蚀内在动机，教育场景尤需谨慎。
- 依赖性/成瘾行为的风险奖励（戒酒成功喝一杯庆祝）——无论多"应景"都在身份冲突名单上，此类情境应寻求专业支持。
- 用户真正缺的是启动设计或追踪结构——奖励救不了不存在的习惯。

### 作者在书中警告的失败模式

- x11 即时奖励脱节：坏习惯的奖励即时、后果延迟；"习惯的第一个果实越甜，以后的果实就越苦"——反向警示是给好习惯加即时快乐、给坏习惯加即时代价，是同一准则的两面。
- 身份拆台（第 15 章术语用法）：奖励与身份冲突时直接抵消习惯积累。

### 作者的盲点 / 时代局限

- 本书写于 2019 年：书中未处理过度理由效应（外部奖励消失后内在动机被侵蚀）与第 16 章外部追踪之间的张力——"外部奖励何时安全"本书没有完整判据；延迟满足相关研究（棉花糖传统）因社会经济地位混杂已受重创，克利尔的引述接近旧传统。克利尔为商业作者，科学细节有简化；行为科学证据仍在更新，涉及儿童教育与心理健康决策应结合专业意见。

### 容易混淆的邻近方法论

- 民间"给自己点奖励"无校验、无交接、无抑制型方案；本 skill 独有的是身份一致性校验、颠倒记账（奖励"不做什么"）与"奖励启动、身份维持"的交接机制。
- 游戏化积分体系是工业化的增强法，但积分本身可能变成古德哈特指标（x13 的警告同样适用）。
