# 追踪与问责（习惯追踪 + 绝不错过两次 + 习惯契约）

## R — 原文 (Reading)

> "A habit tracker is a simple way to measure whether you did a habit. The most basic format is to get a calendar and cross off each day you stick with your routine. ... Missing once is an accident. Missing twice is the start of a new habit."
>
> 自译：习惯追踪是衡量你是否做了某个习惯的简单方法，最基本的形式是拿一份日历，划掉你坚持例行的每一天。……错过一次是意外，错过两次是一种新习惯的开始。
>
> — James Clear, Atomic Habits, 第16章

---

## I — 方法论骨架 (Interpretation)

1. 追踪的价值不止"记录"：日历打叉这类视觉量度一箭三雕——让行为显而易见（视觉提示）、有吸引力（最有效的激励是可知的进步）、令人愉悦（记录本身即满足）。
2. 但追踪必须低成本，否则追踪本身先死：减负三原则——能自动化就自动化；只追踪最重要的一个习惯；行为一结束立即记录。
3. 断链是必然事件，协议比情绪重要："绝不错过两次"——错过一次是意外，第二次缺席才开始塑造新的坏习惯；糟糕日做两分钟最小版，保住"我是不错过的人"的身份投票，不做双倍补偿。
4. 防走偏：数字只是反馈不是目标（古德哈特陷阱）；单一指标泄气时改用其他可测信号（睡眠、体能、情绪）——无秤胜利法。
5. 自我追踪不足时，升级为社会约束：习惯契约 = 书面承诺 + 违约罚则 + 一两名问责伙伴签字；后果越局部、有形、具体、直接越有效，惩罚强度必须压过行为本身的吸引力。
6. 层次边界：S13 的记录回答"做没做"（频次可见），不管"做得怎样"（质量反思）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 曲别针策略 (c14)
- **问题**: 1993 年，23 岁的新人股票经纪人迪尔施米德被分到没人看好的偏远支行，如何快速做出业绩？
- **方法论的使用**: 桌上放两个罐子，一个装满 120 个曲别针；每拨通一个推销电话就把一个曲别针移到空罐，直到全部转移——"今天打了多少电话"变成肉眼可见的量度。
- **结论**: 视觉量度让进步可知，而可知的进步是最有效的激励。
- **结果**: 18 个月为公司带来 500 万美元收益，24 岁年薪达 7.5 万美元。

### 案例 2: 哈里斯的习惯契约 (c15)
- **问题**: 儿子出生后不久，企业家哈里斯意识到自己需要减肥，需要一种比自觉更强的约束。
- **方法论的使用**: 与妻子和私人教练签订书面契约：目标、季度路线图、每日习惯（记录饮食 + 称重）与违约罚则（忘记录饮食付教练 200 美元、忘称体重付妻子 500 美元、忘做冲刺跑穿死敌球队帽子上班），三人共同签字。
- **结论**: 契约三要件（书面 + 罚则 + 签字）把人情监督变成条款监督；签字仪式本身防止"紧接着开始偷懒"。
- **结果**: 三个月达成首季目标并上调下一季目标，体重随之下降。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户已经开始一个习惯，但打卡/日历断了，纠结"要不要双倍补"或"从头再来"。
2. 用户觉得追踪太累：记录成本高、App 太多、表格复杂，坚持记录本身成了负担。
3. 用户盯着某个数字（体重/步数/连续天数）越来越焦虑，数字停滞就想弃疗。
4. 用户自知自控不足，想找监督人、签契约、设罚则，但怕伤害关系。

### 语言信号 (用户的话里出现这些就应激活)

- "打卡/断链/连续中断/要不要补/从头再来"
- "追踪/记录/日志/监督/问责/罚则/契约"
- "坚持不下去（但已经开始了）"
- 英文: habit tracker / never miss twice / accountability partner / streak / broke my streak

### 与相邻 skill 的区分

- 与 `start-new-habit` / `two-minute-start` 的区别：S13 触发于"已经开始但持续不住"；S04/S10 触发于"还没开始/启动不了"。断链恢复、追踪工具选择、问责设计都在 S13。
- 与 `reward-design` 的区别：S13 的契约是惩罚端（让违约即刻痛苦）；S12 是奖励端（让坚持即刻愉悦）。追踪的可见进步与 S12 的增强法可以互相充当。
- 与 `commitment-devices` 的区别：S13 依赖社会成本与自觉记录，行为仍可行；S11 用结构直接使行为不可行。前者适合高频日常行为，后者适合脆弱时刻的强约束。
- 与 `mastery-reflection` 的区别：S13 的记录是"做没做"的频次可见；S16 的日志是"做得怎样、为何这样决定"的质量反思——层次不同，不互相替代。
- 与 `goldilocks-difficulty` 的区别：断链与追踪问题在 S13；无聊与难度校准在 S15。

## E — 可执行步骤 (Execution)

1. **选一个主习惯并选载体**
   - 完成标准: 只追踪一个最重要的习惯；载体满足减负三原则（能自动化就自动化/行为结束立即记录/手工成本 ≤10 秒）。
2. **定义最小阈值与打叉标准**
   - 完成标准: 写下糟糕日的两分钟最小版；"今天算完成"的判据不随状态浮动——哪怕最小版也算打叉。
3. **安装恢复协议**
   - 完成标准: 写下"绝不错过两次"预案——错过一次，当晚或次日立即做最小版回轨，不做双倍补偿，不重启叙事。
   - 判停条件: 若追踪本身引发焦虑或"为数字而活"（x13 信号），降频或换无秤胜利法（换其他可测信号），不必硬追。
4. **（可选）升级契约**
   - 完成标准: 当自我追踪连续失效时，按后果四性（局部/有形/具体/直接）设计罚则并找一两名问责伙伴签字；惩罚强度必须压过行为的吸引力；怕伤感情则把"执法"改成转账条款、伙伴只做见证人。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还没开始习惯——启动设计在 start-new-habit / two-minute-start。
- 用户想戒除坏习惯——正向追踪不适用，走 quit-bad-habit。
- 用户的问题是习惯内容太难而厌倦——goldilocks-difficulty。
- 用户处于强烈自责情绪中——先处理情绪与"错过一次是意外"的认知，暂不谈工具与罚则。

### 作者在书中警告的失败模式

- x12 全有全无怪圈："反正已经毁了"的自我对话 + 双倍补偿，第二次缺席才是真转折；糟糕日的损失远大于好日的收益（先涨 50% 只需跌 33% 回原点），中断正在蚕食复利。
- x13 古德哈特陷阱：为数字牺牲本意，数字一差全盘放弃——度量只是系统的一条反馈，不能因为它不可测就认定它不重要。

### 作者的盲点 / 时代局限

- 本书写于 2019 年："习惯跨过习惯线后自动维持"没有长期证据，书中核心实验多为两周至六个月；Streak 打卡机制已被 App 游戏化设计过度消费，用户可能带着"连续天数焦虑"进来——本书的减负三原则是对症的部分，但平台设计的诱导本书没有处理。克利尔为商业作者，科学细节有简化；行为科学证据仍在更新，涉及重要健康/心理决策应结合专业意见。

### 容易混淆的邻近方法论

- 与 OKR/KPI 管理不同：习惯追踪盯"做没做"的频次，且内置防走偏条款（古德哈特警告）；把业绩指标管理逻辑直接搬来会违背减负三原则。
- 与"21 天打卡挑战"不同：本书的判据是次数与身份证据，不是天数魔术数字。
- 与"找人盯着"的朴素监督不同：本 skill 有后果四性判据（局部/有形/具体/直接）与惩罚强度压过吸引力的定量要求。
