# 两分钟启动（两分钟规则 + 门户习惯 + 决定性时刻）

## R — 原文 (Reading)

> "When you start a new habit, it should take less than two minutes to do. ... You can't improve a habit that doesn't exist. ... Habits are the entrance ramp, not the final destination."
>
> 自译：当你开始培养一种新习惯时，它所用的时间不应超过两分钟。……你不能改善一个不存在的习惯。……习惯是切入点，而不是终点。
>
> — James Clear, Atomic Habits, 第13章

---

## I — 方法论骨架 (Interpretation)

1. 问题往往不是"坚持不下来"，而是"每次启动的成本太大"：目标写成"每天跑 5 公里"时，大脑面对的是一整场战役。
2. 规则：任何新习惯都压缩成两分钟内能物理完成的版本——"每晚睡前阅读"→"读一页"，"跑 5 公里"→"穿上跑鞋出门"。
3. 起步动作是"门户习惯"：它不是缩小版目标本身，而是把后续行为引上正轨的入口仪式；每天几个两分钟级的小选择是"决定性时刻"，为之后数小时定基调。
4. 次序判据是"先标准化再优化"：先让行为每天出现（问次数不问天数），再谈质量与时长——习惯基于频率而非时长形成，你不能改善一个不存在的习惯。
5. 反直觉强化版：状态好、想继续的日子，也在两分钟处强制停下——防止大日子抬高明天的启动门槛。
6. 时间轴定位：本 skill 只管从 0 到 1 的启动最小化；稳定后的加码、停滞后的反思是另外两件事。

## A1 — 书中的应用 (Past Application)

### 案例 1: 特怀拉·萨普的出租车仪式 (c10)
- **问题**: 编舞家萨普如何让每天两小时的晨练自动发生？
- **方法论的使用**: 她每天 5:30 醒来穿上练功服走出家门叫出租车；把"仪式"定义在叫出租车这个瞬间——一个每天以同样方式重复、封死偷懒变通空间的微动作。
- **结论**: 门户习惯 = 入口仪式，不是缩小版的健身目标；抓住"叫出租车"的决定性时刻，两小时晨练无需临场决断。
- **结果**: 晨练自动发生，她把职业生涯的成功归功于这个简单习惯。

### 案例 2: 摄影课的数量组 (c09)
- **问题**: 追求"最佳方案"与"立即行动"哪个产出更高？
- **方法论的使用**: 教授把学生分成数量组（按交片量评分）与质量组（整学期只做一张完美照片）；数量组整个学期忙于拍照、试错、改进。
- **结论**: 全部优秀作品出自数量组——先上次数、先标准化再优化；"酝酿让你感觉自己正在做事，但实际上你只是在准备做事"。
- **结果**: 质量组只剩一张平庸照片和一堆未经证实的理论；作者据此主张问"多少次"而非"多少天"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户宣布了新目标（健身/写作/学英语/冥想）但迟迟没有第一天，或已失败重启多次。
2. 用户的计划写得很大（每天 1 小时、每周 5 次），执行一两次后弃坑。
3. 用户在"酝酿"：买课、研究最佳方案、列计划、集思广益，就是不产出第一次真实行动。
4. 用户问"从哪里开始/第一步是什么/怎么才能开始"。

### 语言信号 (用户的话里出现这些就应激活)

- "启动不了/开始不了/坚持不了第一天""计划总是太大"
- "完美主义/一直在准备/等状态好再开始"
- "第一步该做什么/怎么才能开始"
- 英文: just get started / two-minute rule / gateway habit / start small / procrastinating on starting

### 与相邻 skill 的区分

- 与 `start-new-habit` 的区别：S04 回答"何时何地做什么"（执行意图、习惯叠加、记分卡觉察），管计划的精确性；S10 管"第一步小到不会失败"。两者常组合：先定时间地点，再把第一步压到两分钟。
- 与 `goldilocks-difficulty` 的区别：S15 管习惯已稳定运行后的难度校准；S10 只管从 0 到 1 的启动，不碰已运行习惯的强度——时间轴上正交，别把"加不动了"误当"启动不了"。
- 与 `tracking-and-accountability` 的区别：S13 处理"已经开始但断链"；S10 处理"还没开始"。若用户已在打卡只是断了，走 S13。
- 与 `mastery-reflection` 的区别：S16 管自动化后的钝化与年度复盘，属长期维护；S10 属起步期工具。

## E — 可执行步骤 (Execution)

1. **把目标回溯成两分钟版**
   - 完成标准: 写出完整习惯与两分钟版各一句；两分钟版能在 120 秒内物理完成（"穿上跑鞋出门"，而不是"跑 500 米"）。
   - 判停条件: 若用户已连续 ≥30 天完成两分钟版且想加量，本 skill 判停，转 goldilocks-difficulty 做难度校准。
2. **装上门户习惯与决定性时刻**
   - 完成标准: 说出每天为该习惯定基调的那个岔路口（几点、什么场景、选什么），并把两分钟版绑定其上——可与 start-new-habit 的执行意图句式合并成一句。
3. **先标准化再优化（含强制停止版）**
   - 完成标准: 约定观察窗（建议 ≥7 天），达标 = 每天出现两分钟版；状态好想继续时也在两分钟处停下。
   - 判停条件: 若两分钟版连续 3 天未做，回退进一步缩小（"只穿鞋/只打开琴盖"），直到不可再分再重启观察窗。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户的问题是断链恢复而不是启动——走 tracking-and-accountability 的"绝不错过两次"。
- 用户的问题是习惯本身太难而厌倦——先看 goldilocks-difficulty 或 habit-loop-four-laws 诊断。
- 用户想优化一个已稳定运行的习惯——两分钟版服务于"先标准化"；已标准化者应进阶而非继续压小。
- 纯信息查询（"什么是两分钟规则"）不构成调用。

### 作者在书中警告的失败模式

- x10 酝酿伪装成行动：准备时长远超行动时长、以"还没准备好/在等最佳方案"解释零产出，深层动机是推迟可能的失败——两分钟规则正是其解药。但注意：把"列计划/买课"本身当作两分钟版是自欺，两分钟版必须是习惯本身的动作。

### 作者的盲点 / 时代局限

- 本书写于 2019 年：两分钟规则是操作格言而非实验定律；书中核心实验多为两周至六个月的短周期（如执行意图实验仅两周），"习惯跨过习惯线后自动维持"无长期证据。克利尔为商业作者，科学细节有简化；"两分钟版 = 重申身份"的说法在书中是合理推断而非实证结论。涉及健康场景（如受伤后恢复运动）时，起始强度应遵专业意见。

### 容易混淆的邻近方法论

- 民间"从小目标开始/循序渐进"没有上限与停止规则；本 skill 的独有点是硬上限（≤2 分钟）+ 想继续时强制停 + "先标准化再优化"的次序判据。
- BJ Fogg 的微习惯方法与本书同源（习惯叠加即源自福格）；强制停止变体是克利尔的加强设计，用于防止"好状态"污染启动阈值。
