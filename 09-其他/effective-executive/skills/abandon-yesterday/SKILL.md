# 摆脱昨天（该不该开始之问与推陈出新）

## R — 原文 (Reading)

> "有效的管理者必须经常检讨他们和同事的工作计划，他们会问：'如果我们还没有进行这项工作，现在我们该不该开始这项工作？'如果不是非办不可，他们就会放弃这项工作，或者会将它搁置起来。"
>
> — 彼得·德鲁克，第5章·摆脱昨天（L1298）

> "过去的成功和活动，往往演变成'经营管理上的自我主义的资产'，并且是神圣不可侵犯的。但是，这些过去的成功和活动最需要无情的检讨，否则组织的血液都流失到这种自我之中了。"
>
> — 彼得·德鲁克，第5章·摆脱昨天（L1304）

> "有效的管理者打算做一项新的业务，一定先删除一项原有的业务。……要'出新'，必从'推陈'着手。"
>
> — 彼得·德鲁克，第5章·摆脱昨天（L1318、L1326）

---

## I — 方法论骨架 (Interpretation)

专注的第一原则不是"做什么"，而是清除"已经不再有价值的过去"。管理者必须对抗一个结构性倾向：今天的资源被昨天的决策与成功占满。

核心问句是"如果还没做这件事，现在该不该开始"——判据从"能不能做得更好"换成"该不该做"。答否的，放弃或至少搁置，并把最稀缺的精锐人力立刻抽出来投到未来。

最难清的恰恰是昨天的成功，以及"本应产生良好效果却没能产生效果"的活动。失败会促使人检讨，成功却使人免于检讨，于是沉淀为"经营管理上的自我主义的资产"：神圣不可侵犯、占用最能干的人，还被认为是值得的。

配套两条机制。其一，计划要预设退出：对政府式的常设计划，应视为"临时性质"、到期自动失效或经客观复审后重新立法延长；观念从"无法证明其无效就继续"扭转为"无法证明其有效及需要就放弃"。其二，推陈出新是硬规则：新业务开始前先删一项旧业务，否则没有"最有才干的人"可用；新工作必须交给已被验证有能力的人（新人用在成规明确、风险较低的职位，不用在风险最大处）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 杜邦公司——在产品尚未走下坡路之前就放弃
- **问题**: 大部分公司抱着"只要我们努力，我们总会有市场""我们靠这项产品起家，有责任维持下去"的想法，结果把有限的人力和资金用来保卫昨天。
- **方法论的使用**: 杜邦的做法相反：某一产品或流程在"尚未"开始走下坡路之前，就毅然放弃。德鲁克点明这条机制："杜邦公司从来不将其有限的人力和资金，用来保卫昨天。"
- **结论**: 要"出新"必从"推陈"着手。
- **结果**: 那些常派管理者参加创造力研讨会却拿不出新产品的公司，对照杜邦"天天忙于生产和推出新的产品"。

### 案例 2: 计划报废原则与约翰逊政府的计划检讨
- **问题**: 政府机构的计划和措施"过一段时间就会跟不上形势变化的需要"，却不但被认为是永恒的原则，还演变成法令规章与既得利益，"谁也动他不得"；美国联邦机构半数以上仍拘泥于早已无意义的规章。
- **方法论的使用**: 德鲁克提出原则：政府的每一项法案、机构、计划都应视为"临时性质"，经一定年限后自动失效；否则必须客观研究其存在价值、成果和贡献，再重新立法延长有效期。约翰逊总统 1965–1966 年仿效麦克纳马拉的"计划检讨"制度，对政府各机构及计划做研究，删除过时与无效的计划。
- **结论**: 观念必须从"无法证明无效就继续存在"改为"无法证明有效及需要，便该立即放弃"。
- **结果**: 德鲁克警告若仍抱旧观念，"这项研究恐怕仍难产生结果"——即以自动失效与定期复审为机制，把'昨天'按期清出组织。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司/团队要开新业务线、接新项目，说会加人，但现有骨干个个已满负荷。
2. 旧产品、旧渠道、旧流程多年微利或看不到前途，却因"我们靠它起家"一直保留。
3. 用户（个人层面）手里堆着若干有投入与产出的旧项目、旧承诺、旧关系维护（注意：不是行为习惯），新目标迟迟无法启动。
4. 组织要推"创新/转型/第二曲线"，但仍把最能干的人按在昨天的摊子上。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要砍掉（关停/放弃）这个产品、项目 / should we kill, sunset, discontinue"
- "人手不够，怎么再加新业务 / no bandwidth for the new thing"
- "这是我们起家的业务 / 老客户都靠它 / we've always done it this way"
- "新业务加人就行了吗 / can we just add headcount"

### 与相邻 skill 的区分

- 与 `priority-and-posterior`（f15）的区别：f15 在"都还值得做"的事之间排次序、定优后；本 skill 处理"根本不值得再做的事"的放弃与先删后开规则。用户问"这事还要不要做"→ 本 skill；问"几件事先做哪个"→ f15。
- 与 `one-thing-at-a-time`（f13）的区别：f13 是并行度纪律（一次只做一件）；本 skill 是存量清理（腾出人和资源）。先减存量，串行才有资源可言。
- 与 `decide-and-act-fully`（f24）的区别：f24 的"是否需要决策"判断"这问题该不该动用一次决策"；本 skill 判断"这项既有活动该不该继续存在"。前者针对新问题，后者针对既有承诺。
- 与 `time-diagnosis-questions`（f03）的区别：f03 的三问面对时间记录里的活动（不做会怎样/能否别人代做）；本 skill 面对整个业务或长期事业，且给出"先删后开"的配比规则。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出候选放弃清单**
   - 把所有的产品/项目/计划/活动摆上台面（不是只列"表现差的"，要把"昨天成功"的那几项也放进去）。
   - 完成标准: 清单覆盖存量全部主要项目，含至少一项"历史功臣"。
2. **过"该不该开始"之问**
   - 对每一项问："如果我们还没有进行这项工作，现在我们该不该开始这项工作？"
   - 完成标准: 每项有"该/不该"的判断与一句理由；答"该"的进入 f15 排序。
3. **清"自我主义资产"**
   - 对答"不该"但舍不得的项目，逐条查保留理由是否与今天的成果有关（历史、感情、面子、"我们靠它起家"）。
   - 判停条件: 若保留理由全属历史情感 → 进入第 4 步；若能证明其"确属有效及需要"（有成果证据）→ 允许进入 f15 参与排序。
4. **定放弃方式与节奏**
   - 区分"果断放弃"与"搁置"；写明资源回收计划（尤其是精锐人力）、对客户/员工的过渡安排与合规程序。
   - 完成标准: 每项有去向（放弃/搁置/保留+理由）+ 至少一项资源回收动作；涉及关停与人员调整的，注明须依当地劳动法规与组织程序。
5. **执行"先删后开"配比**
   - 对任何新业务/新任务：先指定被删除或大幅缩减的旧业务，再把新人选定位——由已被验证有能力的人主持，新人放在成规明确、风险较低的职位。
   - 判停条件: 若无法删掉任何旧事项 → 明确告知"加人但不减事"是赌上加赌，要求先定放弃项再启动新业务。
   - 完成标准: 新业务对应的"被删项"与主持人选都已落定。
6. **建立定期复审机制**
   - 给常设计划设"临时性质 + 到期复审"（自动失效或复审延期），把"无法证明有效即放弃"设为默认。
   - 完成标准: 有复审周期、责任人与失效条款。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 个人行为习惯的戒断与自律问题（戒烟、戒刷手机、拖延等）：那是行为设计/环境设计范畴；"摆脱昨天"的对象是占用资源或长期承诺的事业性活动，用在这里是把方法用错层次。
- 涉及员工安置、客户合约、监管义务的关停：放弃决策必须叠加法律与合规流程（承接 verified.md 对 ce18/ce19 的强制边界：人事调整须依当地劳动法规与组织程序），本 skill 只负责"该不该"的判断，不提供执行合法性。
- 用户需要的是在若干有价值的选项中排序：用 f15。
- 主业暂时亏损但属于战略必需（如基础设施、监管牌照、临床期项目）：德鲁克的判据是"确属有效及需要"，能被证明者不适用放弃。

### 作者在书中警告的失败模式

- **舍不得昨天的成功（ce21）**：昨天成功的产品/计划/制度因"我们靠它起家"而不能放弃；"本应产生良好效果但没产生效果"的活动尤其危险。预警信号：保留理由与它今天的成果无关（历史、感情、面子）；无法证明某活动确实有效及需要，但仍继续。
- **新工作交给新聘的人（ce22）**：新工作本身就是一场赌博，再另聘新人来做是"赌上加赌"；新人不宜用于风险最大之处（高层或开创性职位），应放在"比高层略低"、成规明确的职位。
- **"加人但不减事"**：不先删旧业务，最有才干的人永远腾不出来，新业务会自生自灭。

### 作者的盲点 / 时代局限

- 案例集中于 1900–1960 年代美国大企业（杜邦）与政府机构，日本终身雇用段落只作历史语境引用（BOOK_OVERVIEW 批判节）。
- 高管视角：方法默认组织有多个业务可放弃、有人员调度空间；对单产品小组织与个人，需降级为"放弃其中的活动/习惯"。
- "计划自动失效"是德鲁克对公共部门的规范主张，非已实现制度，本书无对照实证；证据等级声明：本书证据以作者顾问观察与轶事为主。
- 德鲁克对"放弃"的乐观（"只要能推陈出新，即使是最暮气沉沉的机构，也能获得生机"）忽略执行中的政治阻力与安置成本。

### 容易混淆的邻近方法论

- 精益中的"停止投资/杀掉项目"（kill criteria）：机制相近但语境是投资组合；德鲁克的特有增量是"新业务开始前先删旧业务"的配比规则与"自我主义资产"的病理命名。
- 与"定期清理待办"流行做法：德鲁克针对的是被神圣化的既有事业，不是任务的日常整理。
