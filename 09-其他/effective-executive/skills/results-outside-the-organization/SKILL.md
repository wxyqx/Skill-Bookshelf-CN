# 成果在组织之外（内/外定向）

## R — 原文 (Reading)

> "具体地说，在组织的内部，不会有成果出现，一切成果都存在于组织之外。举例来说，企业机构的成果，是通过顾客产生的，企业付出的成本和努力，必须通过顾客购买其产品或服务，才能转变为收入和利润。"
>
> — 彼得·德鲁克，第1章“卓有成效是可以学会的”（L364）

> "在组织内部所发生的，只有人工和成本。我们说企业内部的“利润中心”，其实是客气的称呼而已，实质上应该是“人工中心”。"
>
> — 同上，第1章（L368）

> "除非他能付出特殊的努力，使自己与外界保持直接的联系，否则他必将日益局促于组织内部。他在组织中的地位越高，他的注意力就越容易为内部的问题和挑战所困，而不能看到外部的情况。"
>
> — 同上，第1章（L370）

---

## I — 方法论骨架 (Interpretation)

这不是一句“以客户为中心”的口号，而是一条**结构定律**加一个**必然倾向**：

1. **定律**：组织是社会的器官，其成果只能由外部产生——企业的成果通过顾客、医院的成果体现在病人身上、大学的“顾客”是学生；组织内部发生的只有人工和成本；内部的“利润中心”实质是“人工中心”。一个组织产生既定成果所需的工作量越少，成绩越好；人数越少、内部工作越轻，组织越接近完美。
2. **倾向**：管理者被四类现实推向内部——时间属于别人、被日常运作牵着走、只在他人使用其产出时才有效、身处组织内部。且“他在组织中的地位越高，他的注意力就越容易为内部的问题和挑战所困”。所以内向不是态度问题，是结构性的默认状态；必须“付出特殊的努力”才能保持与外界直接联系。
3. **信息陷阱**：报告都经过组织过滤（“像戴上了一副变形的眼镜”）；只有内部资料是可量化的，外部情况往往是质的、滞后的——福特 Edsel 搜集了一切可得数据仍失败，因为消费者发生了质的转变（“收入决定购买”→“兴趣决定购买”）；而美国公共卫生医师因早察觉一种质变（轻微皮肤刺痛感），在沙立度胺广泛使用前敲响警钟。**“对于外部的情况，真正重要的不是趋势，而是趋势的转变。”**

用法是拿这三条做定向体检：你的时间与信息流有多少比例真正接触外部？你正在用哪类内部数字代替外部成果？你观察到的是趋势，还是趋势的转变？

## A1 — 书中的应用 (Past Application)

### 案例 1: 加州大学伯克利分校学潮（内部行政与“顾客”疏远）
- **问题**: 美国的大学校长有一种通病——过于重视内部的行政管理和筹措经费之类的事务；“以大学来说，学生就是学校的‘顾客’，但是大学校长以及其他行政主管们，几乎从来没跟他们的顾客建立过关系。”
- **方法论的使用**: 德鲁克用 1965 年伯克利学潮说明“成果在组织之外”对大学同样适用：行政当局平时与学生疏远，注意力都在内部事务。
- **结论**: 主要原因是学校行政当局平时跟学生比较疏远——成果的外部性被内部行政遮蔽。
- **结果**: 书中作为“过于重视内部事务”的代价案例（学生的“不满与不安”以学潮形式表现出来）。

### 案例 2: 麦克纳马拉出任国防部长后亲自经营国会关系（职位越高，对外需求越大）
- **问题**: 麦克纳马拉原在福特公司，是地道的“内向型”人；出任国防部长初期完全不懂政治，常将国防部与国会之间的联系工作交给部下去处理。
- **方法论的使用**: 几星期后他明白“国防部的业务少不了国会的了解和支持”，于是亲自处理这类他感觉既痛苦又乏味的事：改善与国会的关系、结识国防委员会中有影响力的议员、了解协调国会的艺术。
- **结论**: 一位管理者的职位越高，他在对外方面所需的贡献也越大——“在一个组织里，通常只有职位最高的管理者，才能在对外方面自由活动”。
- **结果**: 德鲁克评：“比起任何一位前任部长来，他做得毫不逊色。”

### 案例 3: 福特 Edsel 与沙立度胺（质变先于数据，外部不可只靠内部数字认识）
- **问题**: 福特推出 Edsel 前搜集了一切能够得到的（内部）数据，证明新车必能畅销；沙立度胺在欧洲造成大量畸形婴儿的悲剧。
- **方法论的使用**: 德鲁克指出，美国的汽车消费者已发生质的变化（从“收入决定购买”到“兴趣决定购买”），这种质变“无法用统计数字来显示”，等它能被充分数据说明时为时已晚；医药上，欧洲医生面对充分统计数字才发现异常、意识到严重性已太晚，而一位美国公共卫生医师因早察觉药物的质变信号（轻微皮肤刺痛感），在广泛使用前发出警告。
- **结论**: “事件本身并非事实”——外部情况是质的性质、难以量化；等到可以量化时，损害往往已经发生。
- **结果**: Edsel 失败；沙立度胺在美国幸得避免损害。此二例成为“观察趋势的转变而非趋势”的标准判例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 内部指标（KPI、报表、满意度分数）越来越好，但客户投诉/流失/退货却增多，找不到解释。
2. 组织变大或职位变高后，整天开会、审批、处理内部关系，几乎没时间接触客户/用户/病人。
3. 用户想判断所在行业是否正在发生“质变”（旧经验/旧数据还能不能用）。
4. 团队讨论全是内部流程、汇报关系、部门协调，没人能说出“最终是谁的什么问题被解决了”。
5. 公共/非营利组织想知道自己的成果究竟产生在谁身上（学校、医院、政府机构）。

### 语言信号 (用户的话里出现这些就应激活)

- “内部指标都好看，客户却不满意，为什么？”
- “我们是不是太内向了？多久没见客户了？”
- “行业是不是发生了质变，旧数据还作数吗？”
- “we're too internal” / “inside-out” / “customers keep complaining” / “are we losing touch with the market”

### 与相邻 skill 的区分

- 与 `contribution-question` 的区别: 后者是可操作的自觉问句（“我能贡献什么”），把个人注意力转向成果；本 skill 是结构定律与诊断（为什么必然内向、为什么成果只能在外部），为前者提供理论底色。
- 与 `feedback-and-inspect` 的区别: 后者在决策环节操作（决策前反馈、亲自视察、前提审计）；本 skill 做全局定向体检，判断注意力与信息流是否偏内。
- 与 `make-output-usable` 的区别: 后者让专业产出为他人（使用者）可用，是交付设计；本 skill 判断成果的外部来源，不解决交付形式。
- 与 `time-waste-institution-scan` 的区别: 后者诊断内部制度病灶（重复危机、会议 1/4 判据等）以省时间；本 skill 诊断注意力的内外方向，两者可先后使用。
- 与 `priority-and-posterior` 的区别: 后者在事项间取舍（重将来/重机会）；本 skill 在方向上校位（内 vs 外），可视为其“重机会”原则的外部定向基础。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定“外部”是谁**
   - 完成标准: 明确写出组织的成果由谁产生——企业写顾客、医院写病人、学校写学生（并按机构逻辑处理多重外部：纳税人/监管者/家长）；每个“外部”要具体到可接触的对象。
   - 判停条件: 若“外部”界定存在争议（典型如公共组织多重委托方），先与用户确认口径或升级处理；不要带着模糊的外部定义进入下一步。

2. **做注意力与信息流的内部占比体检**
   - 完成标准: 统计（或估算）用户/团队的时间与信息输入中“内部事务 vs 外部直接接触”的比例；标出最近一次亲自接触外部的时点。
   - 完成标准附加: 检查内部数字是否被当作成果本身（“利润中心”其实是人工中心；内部指标改善≠成果改善）。

3. **追问“外部发生了什么质变”**
   - 完成标准: 列出 2–3 个来自直接接触（而非报表）的外部信号，并区分“趋势”与“趋势的转变”：某一现象是量的延续，还是购买逻辑/需求性质变了（Edsel 判据）。
   - 判停条件: 若所有外部信息都来自报表，先安排一次直接接触（走访、使用者对谈、现场观察），再回来完成本步。

4. **自查四类现实中的内向引力**
   - 完成标准: 逐条核对——时间是否只属于别人、是否被日常运作牵着走、是否只在他人使用产出时才有效、是否身处内部看外部（对照 L340–370）；标注哪一条正在加强内向。

5. **设计“特殊的努力”（结构性安排，不是决心）**
   - 完成标准: 给出 1–3 个可执行的制度化动作：固定的对外接触时间（职位越高越需要，麦克纳马拉判据）、把外部信号引入决策的固定议程、指定专人对“质变”信号负责；并说明这是对抗结构性倾向的持续动作，而非一次性活动。

6. **关联到决策与事项安排**
   - 完成标准: 把外部定向体检的结论对接到具体决策（是否需要重做/抛弃）或优先次序（是否把资源从内部问题转向外部机会）；需要时移交 `feedback-and-inspect` 或 `priority-and-posterior`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把内部工作一概斥为浪费：内部的人工与成本是组织存在的必要条件，本定律的用途是防止把内部数字当成果，不是取消内部职能。
- “外部”界定不清的公共/非营利组织直接套用：学校、医院、政府的外部（学生？家长？纳税人？）远比企业复杂，德鲁克只举了医院与大学的例子、未给可操作判据（BOOK_OVERVIEW 未证明的假设）；必须先与用户界定口径。
- 变成“客户永远是对的”立场：本 skill 要求保持对外接触与察觉，不要求对任何外部声音照单全收（德鲁克同时主张顾问与专业人士有责任引导，而非迎合）。
- 纯内部职能岗位的日常优化任务：不涉及定向诊断时，用内部流程类工具即可。

### 作者在书中警告的失败模式

- **内部数字冒充成果**：内部的“利润中心”实为“人工中心”；组织越大、越成功，内部事务越多，越占据管理者的兴趣、精神和能力。
- **电脑与量化资料的强化作用**（ce36 的定向维度）：只有内部资料可量化，外部情况是质的；大量电脑信息反而使管理者与外界的实际隔离（“迷恋电脑的危险”）。**时代语境声明**：该书相关段落含 1966 年大型机时代的技术判断，不可作为当代技术结论；本 skill 仅保留“可量化信息天然偏内”与“察觉不可外包”的判据。
- **报告过滤现实**：管理者看外部“像戴上了一副变形的眼镜”，报告内容事先经过组织过滤，是“已经经过主观加工的、高度抽象的外部世界”。
- **Edsel 式失败**：在质变发生时继续用内部数据与统计确认旧结论，等到数据显现，损失已经发生。

### 作者的盲点 / 时代局限

- **“成果全部在组织之外”的适用范围未解决**（BOOK_OVERVIEW 未证明的假设）：对公共组织而言，“外部”界定与成果归属远比企业复杂；德鲁克未给出可操作判据，实际使用中需自行界定并对多重委托方排优先级。
- **高管视角**：本定律以高层管理者为叙述对象（总统、CEO、校长）；对一线知识工作者，“与外界保持直接联系”的含义不同（他们常已经天天面对外部，问题在相反方向——如何把外部信号变成决策输入）。
- **技术判断的时代性**：1966 年“电脑只能处理可量化资料”“外部世界的重要情况不能转化为电脑资料”的断言，在当代可计算域扩展后已被部分推翻；保留的洞见是“趋势的转变先于数据”，不是“外部不可量化”。
- **与“机会 vs 问题”的衔接未展开**：第8章“转移视线：由专注于问题转而重视机会”与本定律同向，但书中未把“外部定向”与“机会筛选”整合成一套程序；本 skill 与 `priority-and-posterior` 配合使用时需自行衔接。
- **证据声明**：本书证据以作者顾问观察与轶事为主，无对照实证；本方法应按经验判据使用（BOOK_OVERVIEW 批判节）。

### 容易混淆的邻近方法论

- 与“以客户为中心/客户旅程”类方法论的区别: 后者提供客户研究方法与流程设计；本 skill 是一条组织定向定律与体检，回答“为什么你会看不见客户”。
- 与“KPI/仪表盘治理”的区别: 仪表盘优化的是内部可量化信息；本 skill 指出可量化信息天然偏内，须以直接接触与质变察觉补位。
- 与 `contribution-question` 的区别: 见上，一个问句、一个定律，常配套使用。
