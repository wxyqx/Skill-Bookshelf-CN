id: p01
title: 投资与投机的操作性定义（三判据）
type: principle
source_chapter: 第1章 聪明的投资者将获得什么
source_quote: |
  投资操作是基于全面的分析，确保本金的安全和满意的投资回报。不符合这些要求的操作是投机性的。
summary: |
  全书的第一道闸门：一笔操作是不是"投资"，不看买的是什么证券、也不看持有期长短，
  只看三个判据是否同时满足——(1)基于全面的分析；(2)确保本金安全；(3)取得满意回报。
  缺任何一条即为投机。由此推出：不付息的股票、拖欠的债券也可以是投资（只要价值终将高于成本），
  而保证金操作、买热门股则是投机。
tags: [investing, definition, principle]

id: p02
title: 投机三非理性与专款隔离规则
type: principle
source_chapter: 第1章 投资和投机的区别
source_quote: |
  但在许多情况下，投机是非理性的，尤其是以下三种情况：（1）意识不到自己的投机行为；
  （2）缺乏足够的知识和技巧，严重投机；（3）动用比你能承受的损失更多的资金。
summary: |
  格雷厄姆不禁止投机，只禁止"非理性投机"：不自知、无能力、超承受力。
  配套的执行规则是：想投机就划出专款，比例越小越好，且在操作和思想上都与投资资金严格隔离。
  这给了普通人一个诚实的出口——承认投机欲望的存在，同时把它关进笼子。

id: p04
title: 股债 25–75 比例带
type: principle
source_chapter: 第1章 第一次世界大战前的投资和当今投资之比较
source_quote: |
  在任何情况下都应投资一定比例的资金于普通股，这个建议是不可改变的。我在这本书接受这个建议，
  并仅建议投资者考虑这个比例在最低限为25%而最高限为75%以内。
summary: |
  无论通胀担忧还是市场恐惧，都不走极端：普通股最低 25%、最高 75%。
  下限防的是通货紧缩/错过复利，上限防的是高位全仓暴露。这是防御型组合的地基规则，
  后续所有比例调整都在这条带内进行。
tags: [investing, portfolio, rule]

id: p07
title: 三条幸存准则（与人性相联系的准则长存）
type: principle
source_chapter: 卷首 投资策略
source_quote: |
  主要与证券类型相联系的准则没用了。而那些与人性和人的行为相联系的准则生存了下来。
  后者类似于陈腐格言，但是相当有用。以其中的三个为例：
  1. 如果投机，最终你将(可能)失去钱。
  2. 当大多数人(包括专家)悲观时，买;而当他们相当乐观时，卖。
  3. 调查，然后投资。
summary: |
  区分准则寿命的元规则：与证券类型挂钩的准则不断过时（"债券比股票安全"等），与人的行为挂钩的准则长存。
  三条幸存准则——投机终失钱、悲观买乐观卖、先调查后投资——都关乎人性而非证券。
  因此投资中最重要的部分与投资者的气质和态度相联系，而不太受时代变化影响。
tags: [investing, principle, meta-rule]

id: p08
title: 市场先生：价格波动对投资者的唯一意义
type: principle
source_chapter: 第2章 企业估值和股市估值
source_quote: |
  从根本上讲，价格波动对真正的投资者只有一个重要的意义：当价格大幅下跌后，提供给投资者购买机会；
  当价格大幅上涨后，提供给投资者出售机会。而其他时候，他如果忘记股票市场而把注意力放在股息收入和公司运作状况上，将会做得更好。
summary: |
  市场先生寓言的操作化结论：报价只在两种情况下有用——大跌给买入机会、大涨给卖出机会，
  其余时间应按企业运营状况形成自己的判断。把报价当价值向导的人，是把仆人当成了主人。
  这是全书心理基础的核心断言。
tags: [investing, principle, psychology, market-mr]

id: p09
title: 浮盈不可兑现律
type: principle
source_chapter: 第2章 价格波动是投资效益的指示计
source_quote: |
  在一个持续的规划中，不会实现市场利润，除非后来的重新投资确实发生，交易收益的真正度量是前面卖出价格与新买入价格之间的差。
summary: |
  账面利润不算数：只有当你卖出后不再以更高价格买回（或干脆决定不再买股票）时，利润才是真的。
  真正的度量是卖出价与新买入价之差。这条规则直接击碎"高抛低吸后总能买回"的自我安慰，
  也是对牛市中"兑现者"幻觉的解毒剂。
tags: [investing, rule, psychology]

id: p10
title: 时机之路终成投机者
type: principle
source_chapter: 第2章 市场波动是投资决策的向导
source_quote: |
  我同样确信，如果他在预测的基础上，把重点放在时机上，他最后会成为一个投机者，从而得到投机者的结果。
summary: |
  从波动中获利只有两条路：时机（预测市场）与价格（低于合理价买、高于合理价卖）。
  走时机之路的人最终会变成投机者并得到投机者的结果——对投资者而言，时间没有价值，除非它让他能以低得多的价格再次买入。
  配套证据：道氏理论 1938 年后 7 次再购买全部买贵；准则被普遍接受之时即失效之时。

id: p11
title: 股票剧涨后莫买，股票暴跌后莫卖
type: principle
source_chapter: 第2章 小结
source_quote: |
  他不应该因某一股票上涨了就购入，或是因某一股票下跌了就抛出。如果他记住这样一句格言他就不会犯大的错误：

summary: |
  对治追涨杀跌的一句可随身携带的格言：涨本身不构成买入理由，跌本身不构成卖出理由。

id: p12
title: 跌幅超过 1/3 或企业地位恶化才需在意
type: principle
source_chapter: 第2章 价格波动是投资效益的指示计
source_quote: |
  除非价格跌幅较大，比如，大于1/3,或是反映了该企业地位下降，否则价格下跌对真正的投资者没有太大的影响。
summary: |
  面对下跌的分级处理规则：先复核自己的计算（大西洋和太平洋茶叶公司 36 美元案例），
  若计算无误，则只有两种情况需要认真对待——跌幅大于约 1/3，或下跌反映了企业地位的实际恶化；
  否则有权把下跌当作"暂时的反复无常"加以忽视，甚至利用它廉价加仓。

id: p15
title: 牛市五特征
type: principle
source_chapter: 第2章 低价买进高价卖出的方法
source_quote: |
  几乎所有的牛市都具有这样几个典型的特征：（1）历史性的高价位；（2）高价格收益比；

  用于判断市场是否处于"抛出水平"。但配警告：1949 年后的牛市未按此模式收场，
  该清单用于警觉而非机械清仓。

id: p16
title: 高市况谨慎三准则
type: principle
source_chapter: 第3章 走什么路
source_quote: |
  投资的原理应遵循以下准则（以其重要性为序）：
  1. 不要借贷资金用来购买或持有证券
  2. 不要增加投入普通股的资金比例。
  3. 减少普通股股份的持有，当需要时，将其降低到占总投资组合的最多50%。
summary: |
  当投资者不能确定市场是否危险时的生存规则（按重要性排序）：不加杠杆、不追加股票、必要时降到最多 50%。
  配套：正在执行美元成本平均计划的可继续或暂停，但"危险水平"不新开计划。
tags: [investing, rule, risk-control]

title: 策略应注重不确定性而非确定性
type: principle
source_chapter: 第3章 小结
source_quote: |
  投资的策略应注重不确定性，而非确定性。因此，在这一转变和多变的时代，投资者的投资目标一定要准备应付各种情况。

id: p18
title: 过度成熟牛市六条件（打分清单）
type: principle
source_chapter: 第3章 从股市周期看1964年的价格水平
source_quote: |
  "过度成熟牛市模式"具有以下条件：
  1. 领头股的高价格，和过去市场水平相关；
  2. 同样，和过去的平均收入相联系；
  3. 当前股息回报率低于或不高于高质量债券；
  4. 经纪人贷款剧增，表明投资活动广泛存在；
  5. 劣质股价格大涨
  6. 许多新股上市，其中大多具有高度投机性且价格过高。
summary: |
  牛市顶部识别清单的扩展版（牛市五特征的 1964 年化）：逐条核对打分，而非依赖单一信号。
  格雷厄姆强调各条件要分别检验——1964 年前三条存在但后三条不显著，故"引起警惕，但并非股市接近尾声的信号"。
tags: [investing, checklist, market-cycle]

id: p19
title: 股息率低于债息是危险水平线索（附失效警告）
type: principle
source_chapter: 第3章 股票收益与债券收益
source_quote: |
  历时多年，这一现象为股份危险的高水平的出现提供了一个极其可靠的线索。确实，它不能用来预测几周或几月内牛市的结束，
  从而被投资者和股票交易商所注意

  "一个信号，如果要用7年甚至更长时间才能证明其准确性，那么这一信号就不能作为实际投资的指南。"

source_chapter: 第4章 投资者和投资顾问

id: p23
title: 回报与明智努力相称，而非与风险成正比
type: principle
source_chapter: 第5章 通用组合策略：防御型投资者
source_quote: |
  投资者所追求的回报率依赖于投资者愿意和能够完成任务的明智的努力程度。被动的投资者只能得到小的回报，
  因为他既想安全又不想过多地烦心；而机警的和进取的投资者则能得到最大的回报，因为他运用了最大的智力和技巧。
summary: |
  直接否定"风险越大收益越高"：预期回报取决于知识、经验、气质构成的明智努力程度，
  不取决于所冒风险。"购买一种有可能获得较大收益的廉价证券的风险，比购买收益大约4.5％的常规债券的风险要小得多。"
  这是全书身份二分（防御/进攻）的理论基础。
tags: [investing, principle, risk]

title: 风险重定义：风险是价值损失，不是价格波动
type: principle
source_chapter: 第5章 何谓“风险”
source_quote: |
  如果我们将风险的概念仅用于价值的损失，这个损失或者是通过实际出售所造成，或者由公司地位的急剧恶化而引起，

summary: |

  周期性的、暂时的价格下跌且持有者不必卖出——不是真正的风险。诚实投资者的判断标准是几年总回报，而非某一时点的报价。

  反面警告（1964 年现实）：收益率仅 6.25%、10 年超额仅约 1/5 时，边际不足，知名普通股也有真正的风险。

type: principle

source_quote: |

  轮盘赌演示：负边际（31:1）时多样化越多样越亏，正边际（35:1）时越多样越赚——

id: p72
title: 四大商业原理
type: principle
source_chapter: 第16章 最后的话
source_quote: |
  第一个也是明显的商业原理是："知道你正在做什么——知道你的商业。"对投资者而言，这意味着：
  不要试图从证券中取得"商业收益"，即超出正常权益和红利收入的收益，除非你了解证券的价值就像了解你打算制造或经营的商业的价值一样。
summary: |
  把证券买卖当商业经营的四条原理：(1) 知道你在做什么——不懂证券价值就不要谋求超额收益；
  (2) 不让任何人经营你的业务，除非你能理解并谨慎控制他、或完全信任其忠诚与能力；
  (3) 没有可靠计算表明能产生相当好的收益就不要操作——"远离有很少收益和很大损失的冒险"，操作应基于算术而非信心；
  (4) 利用你的知识、经验和勇气——"由于你的数据和推理是正确的，因而你是正确的"，即使公众怀疑。
