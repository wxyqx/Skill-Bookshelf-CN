# 投资建议使用纪律（Investment Advice Discipline）

## R — 原文 (Reading)

> "过去，华尔街的兴盛主要建立在投机的基础上，但股市投机者整体来说最后几乎注定是要赔钱的。因此对于经纪事务所来说，从纯职业的基础上进行操作，在逻辑上几乎是不可能的。"
>
> — 本杰明·格雷厄姆，第4章"来自经纪行的劝告"

---

## I — 方法论骨架 (Interpretation)

外部建议的价值不取决于建议者的名气与热情，而取决于两件事：他的**利益结构**和你的**提问质量**。格雷厄姆把建议来源分成四类逐一审视：投资银行与经纪行是卖方，佣金来自你的交易频度，而投机者整体注定赔钱，所以经纪行"在逻辑上几乎不可能"劝阻投机——大多数事务所只能提供客户想要的投机性暗示；金融服务机构奉行"前景好就买、不管价格"的肤浅原则；投资银行的建议"必须以怀疑的眼光经过仔细的审视"；向亲友求建议"和自己独立选择合适的证券一样困难"。

使用规则是**双条件**：要么把行动严格限制在标准保守的投资形式上（此时建议只是参数，误差有限）；要么对顾问的正直与能力有被完全证明的深度了解（此时才可不经理解地按建议行事）。两条都不满足时，任何建议只用来增长知识、形成独立见解。

配套纪律是**提问重构**：只问安全性、吸引力、内在价值——"为什么是这只证券、为什么是这个价格"；不问"下几个月涨不涨"；并且一开始就声明自己对"小费"毫无兴趣。问题质量决定建议质量。

## A1 — 书中的应用 (Past Application)

### 案例 1: 第4章四类建议对象的结构性审视（u51 主证据）
- **问题**: 业余投资者能否从经纪人、投资银行、金融服务机构、亲友处获得"怎样赚钱"的建议？
- **方法论的使用**: 对四类来源逐一解剖利益结构：经纪行兴盛建立在投机上、佣金随交易频度增长；投资银行与买方是卖方与买主关系；金融服务机构预测"根本就没有真正的意义，只不过满足了人们的一些心理需要"；亲友建议的可信度不比自己独立选择更高。
- **结论**: 建议的可用性由双条件决定，而非由来源的名气决定——对所有人持谨慎态度，无论对方对投机收入和利润作出什么允诺。
- **结果**: 形成可执行的使用纪律：限定行动空间，或深度了解顾问；否则只作知识素材。

### 案例 2: 新证券推销术——卖方偏见的极端形态（第6章；素材 c22，与 C6/C9 共用）
- **问题**: 卖方建议在最热处的形态是什么样？
- **方法论的使用**: 埃特纳·缅特纳斯 1961 年 11 月以 9 美元发行（发行前每股净资产约 1.20 美元、1956 年每股收益仅 0.01 美元），很快炒到 15 美元——新证券背后有特别的推销术，且总在"有利于销售者而结果对购买者不利"的市场条件下发行。
- **结论**: 卖方偏见与牛市推销叠加时，建议的"专业包装"与内在价值可以完全脱钩。
- **结果**: 1962 年跌到 2.375 美元，1964 年最低 0.875 美元，期间从未分红——"按这种方式动作的每一美元，如果结束时仅亏损两美元，你将是幸运的"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户拿着一份具体建议问"该怎么用"：大 V 荐股、智能投顾推荐、客户经理推销、付费研报、朋友消息（u51 V2 问题）；
2. 用户纠结"跟不跟单/要不要按推荐操作"——需要先审来源再审内容；
3. 用户想改进与顾问的交互方式："该问什么问题才有用""怎么判断这个顾问靠不靠谱"；
4. 用户收到推销性质的"机会"（新股、限时额度、内部消息），需要免疫程序。

### 语言信号 (用户的话里出现这些就应激活)

- "该不该信 / 能不能信他 / 怎么用这份研报 / broker advice"
- "大V荐股 / 智能投顾 / 跟单 / copy trading / 客户经理推荐"
- "朋友给了我一个消息 / 小道消息 / tips / 内幕消息"
- "付费投顾值不值 / 这个顾问靠谱吗"
- "我该问他什么问题 / 怎么跟顾问谈"
- "推销电话/直播间推荐的投资机会"

### 与相邻 skill 的区分

- 与 `protection-over-forecast` 的区别：C16 管"自己的分析该走定量保护还是定性预言"（方法认识论），本 skill 管"别人给的建议该不该信、怎么用"（人际信任结构）——审查完来源后对建议内容的检验转 C16；
- 与 `rule-reliability-trend-skepticism` 的区别：C2 管"某条方法/因子/策略能否依赖"（规则寿命），本 skill 管人际建议来源的信任结构；
- 与 `invest-vs-speculation-filter` 的区别：C1 判操作本身是不是投机（三判据），本 skill 判建议来源与使用方式（跟单前的来源审查通过后，操作性质仍要过 C1）；
- 与 `shareholder-governance` 的区别：顾问关系（你买他的服务）vs 所有者-管理层关系（你拥有公司的一部分）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **来源归类与利益结构**：把建议来源归入四类（卖方经纪行/投行、金融服务机构、亲友非专业、独立付费顾问），写清谁付钱、佣金或利益在哪。
   - 完成标准：利益结构用一句话说清（"他的收入随什么增长"）。

2. **双条件检验**：满足其一才可"不经理解地按建议行动"——(a) 行动严格限于标准保守的投资形式；(b) 顾问的正直与能力被完全证明且关系足够深。
   - 完成标准：明确落在哪一条，或两条都不满足。
   - 判停条件：两条都不满足 → 该建议降级为"知识素材"，跳到步骤 4。

3. **提问重构**：把"下几个月涨不涨"改写为"为什么是这只证券、在这个价格上安全性和吸引力由什么构成、内在价值几何"；开场声明对"小费"毫无兴趣。
   - 完成标准：问题清单重写完毕，且不含任何时机类问题。

4. **输出使用方案**：建议 → 独立验证（转 protection-over-forecast 的保护法检验、earnings-power-valuation 的估值）→ 决策自担。
   - 完成标准：给出"这份建议怎么用"的完整路径（用/不用/仅作素材）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 判断"这只股票本身好不好/值不值"——归 C14/C17；本 skill 不分析标的，只分析建议的来源与用法；
- "道氏理论/某因子/某条老规则还能依赖吗"——归 C2（规则可靠性）；
- "我自己做分析时该信前景还是信数字"——归 C16（方法认识论）。

### 作者在书中警告的失败模式

- **华尔街劝告的结构性失灵（x10）**：经纪行"在逻辑上几乎不可能"劝阻投机，大多数事务所只能提供客户想要的投机性暗示；金融服务机构奉行"前景好就买、不管价格"的肤浅原则；投资者应对所有人持谨慎态度，无论对方作出什么允诺；
- **卖方偏见在牛市顶点最烈（联动第6章，c22）**：新证券推销术在"有利于销售者"的市场条件下发行——埃特纳从 9 美元发行价跌到 0.875 美元；
- **"按允诺行动"的依赖结构（x14 作旁证）**：从华尔街得到的越多，越应对预测和时机持怀疑态度。

### 作者的盲点 / 时代局限

- 双条件框架未给"低成本指数化+规则化再平衡"这类第三路径留位置——他观察到基金跑输指数，却只能建议买封闭型基金折扣（今天用最低成本指数化即可执行其结论）；
- "亲友建议和自己独立选择一样困难"是经验断言，无数据支撑；
- 对"独立付费顾问"的利益冲突（管理费与规模挂钩）着墨不足。

### 时效警示

**1964 年快照，报表还原技术在当代会计准则下部分手法过时，学问题结构；估值参数按当期重查。** 具体：1964 年经纪行业结构（固定佣金、无折扣券商、无网络平台）已根本改变；金融服务机构已演化为投研平台、自媒体、直播荐股与智能投顾——四类对象的清单须按当期重写，但"利益结构决定建议倾向＋问题质量决定建议质量"的双柱结构不变；引用具体数字前回查英文原版。

### 容易混淆的邻近方法论

- C16（保护法）：自己分析的方法 vs 别人建议的使用；
- C2（规则可靠性）：规则寿命 vs 来源信任；
- C1（投机过筛）：跟单决定前先审来源（本 skill），来源通过后操作仍过三判据（C1）。
