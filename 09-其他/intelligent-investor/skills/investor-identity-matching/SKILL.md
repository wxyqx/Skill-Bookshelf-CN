# 投资者身份匹配（Investor Identity Matching）

## R — 原文 (Reading)

> "我们已把防御型投资者定义为那些主要感兴趣于投资的安全性和不愿烦恼的投资者。"（第1章）……"有进取心的投资者理性行为的第一条原则是他决不会购买没有经过自己研究的或根据自己的经验觉得不满意的证券。"（第1章）
>
> — 本杰明·格雷厄姆，第1章（身份二分详述见第5、7章）

---

## I — 方法论骨架 (Interpretation)

只有两种自洽的身份。防御型：首要目标是避免严重错误和损失、免除烦恼，取得相当（非惊人）的回报；方法＝严守简单原理——高等级债券与多样化主要普通股的组合、比例带、选股四原则、定投；不碰成长股与一切"不规则证券"。进攻型：愿意投入大量研究精力、追求超越平均回报；第一条原则——决不购买未经自己研究的证券；超额收益只能来自与大众不同且有分析依据的策略。

决定身份的是"与知识、经验、气质相联系的金融技能"，不是资金量，更不是智力。回报与明智努力相称，而非与承担的风险相称——"风险越大收益越高"在此被正面否定。

没有第三种身份：在防御与进攻之间徘徊、折衷，最可能产生失望。决策顺序因此固定：先定努力预算，再定收益预期——目标与投入矛盾时，要么降预期走防御，要么升级投入走进攻（进攻型须先经"大量的自我检验"）。

## A1 — 书中的应用 (Past Application)

> 注：聚类总表 Cluster 5 的 A1 素材列标注为"—"（cases.md 无对应 id），以下按 verified.md u13 的 V1 证据采用第5章原书三例。

### 案例 1: 寡妇型投资者与青年储蓄者（第5章）
- **问题**: 无投资经验、依赖本金生活的寡妇如何投资？刚开始积累的年轻人又如何？
- **方法论的使用**: 按身份匹配落地——寡妇的首要任务是安全与省心，从资本中有纪律地取用优于以投机方式"获得一些额外收入"（那是贪婪驱动的冒险）；青年储蓄者虽处积累期，同样按防御型简单原理执行。
- **结论**: 同一身份判据在不同处境下落地方式不同，但"策略必须与处境匹配"的判据一致。
- **结果**: 三例（寡妇/富裕医生/青年储蓄者）成为第5章论证"策略取决于人而非钱"的示范组。

### 案例 2: 富裕医生的能力圈陷阱（第5章；反例 x29 佐证）
- **问题**: 成功专业人士凭本行业的自信做证券，为何"很不成功"？
- **方法论的使用**: 用回报与明智努力相称律检验——他既未投入"充分注意"，也缺乏证券评价的专业方法。
- **结论**: 障碍不是智力，而是把其他领域的成功误当作投资能力，"太过于相信自己的才智"。
- **结果**: 判定：无充分注意与专业方法者应安于防御型角色，而非以资金实力冒充进攻型。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户报出收益目标（如年化 8–15%）＋投入意愿（每天 10 分钟/愿意系统研究），两者可能矛盾。
2. 用户自认"稳健型"却羡慕进攻收益，或反之，纠结要不要折衷。
3. 用户问"我适合学个股研究吗 / 我该照搬别人的策略吗"。
4. 用户有大额资金但无时间精力（继承/大额到手），问角色定位。
5. 用户在防御与进攻之间反复摇摆，需要一个判定框架。

### 语言信号 (用户的话里出现这些就应激活)

- "防御型还是进攻型 / defensive or aggressive"
- "我想年化 X%，但只有 Y 时间"
- "想跑赢平均 / 超越市场，但没时间研究"
- "有没有折衷方案 / 平衡一下"
- "我适合什么投资策略 / my risk profile"

### 与相邻 skill 的区分

- 与 `invest-vs-speculation-filter` 的区别: C1 判"这笔操作是什么性质"（单笔过筛）；C5 定"你是谁、该用哪类策略"（身份定位）。先 C5 定身份，单笔操作再用 C1 过筛。
- 与 `excess-return-path-selection` 的区别: 确认走进攻型之后，超额收益从哪条路来（五路排除、三域选择）→ C10；C5 不选路径。
- 与 `mechanical-allocation-dca` / `defensive-stock-selection` 的区别: 身份定了之后的执行——比例与定投 → C4，选股 → C7。C5 只输出身份与投入匹配结论。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点投入预算**
   - 完成标准: 三项成文（可半量化）——每周可投入的研究时间、已有知识/经验、气质（对波动与逆境的忍耐）。

2. **相称性检验**
   - 完成标准: 按"回报与明智努力相称律"判定目标收益与投入是否相称；相称 → 定防御或进攻；矛盾 → 二选一：降预期走防御，或升级投入走进攻（并提醒进攻型须"大量的自我检验"）。
   - 判停条件: 用户坚持"既要防御的省心又要进攻的收益" → 明示第7章警告（不会有中间的立场，折衷最可能产生失望），停止输出具体策略，回到身份谈判。

3. **输出身份对应策略骨架**
   - 完成标准: 防御型 → 简单原理骨架（比例带＋四原则＋DCA，衔接 mechanical-allocation-dca / defensive-stock-selection）；进攻型 → 第一原则（决不买未经研究的证券）＋自我检验＋负面清单（衔接 aggressive-negative-list / excess-return-path-selection）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 身份已明确、只问执行细节（→ C4/C7/C10）。
- 单笔操作的定性判断（→ invest-vs-speculation-filter）。
- "我该买哪只票"——C5 不回答选股问题。

### 作者在书中警告的失败模式

- x29 专业人士的能力圈陷阱：富裕医生把本行业自信迁移到证券上，"太过于相信自己的才智"，同时缺乏时间投入与专业评价方法。
- 寡妇以投机方式赚"额外收入"：靠贪婪驱动的冒险不如从资本中有纪律地取用。
- t04 的总警告："把大量精力、研究和天生的能力带入华尔街，结果不是赢利而是损失是常有的事"——选择进攻型身份前需要大量的自我检验。

### 作者的盲点 / 时代局限

- 二分过于刚性——巴菲特一脉"以合理价格买成长"正是对"无中间立场"的历史修正，说明中间地带并非绝对不存在。
- 对成长股全盘排斥的身份色彩过重；"气质"判断缺乏操作化量表，实践中难以自评。

### 容易混淆的邻近方法论

- 超额收益路径选择（C10）常被误当作身份问题：身份回答"你是谁"，路径回答"走哪条路"；未定身份先谈路径是倒置。

### 时效警示（全集群通用，必须内嵌）

**1964 年快照，估值锚/绝对门槛/税收论证须按当期重查，无指数基金时代约束。**
- 防御型"相当回报"的锚（1964 年债息 4.42%/股息率 2.92%）与进攻型三领域的可行性均按当期重查；
- 无指数基金时代约束——今日防御型的默认实现是低成本指数化，防御身份的执行成本结构已根本改变（1964 年只能全取样或买基金）；
