# 机械配置与定投（Mechanical Allocation & DCA）

## R — 原文 (Reading)

> "投资者不应将少于25％或多于75％的资金投资于普通股，而应相反将75％～25％的资金投资于债券。这说明在两个主要的投资媒价之间，标准的划分应该是相等的，或50％对50％。"……（DCA）"因为它防止了参与者在错误时间集中购买。"
>
> — 本杰明·格雷厄姆，第5章"债券：股票分配中的基本问题"（立规于第1章；"媒价"系老译本原文）

---

## I — 方法论骨架 (Interpretation)

两台不依赖预测的机械装置。装置一：股债比例带。普通股最低 25%、最高 75%，标准对半（50:50）；股票升到 55% 卖出 1/11 转入债券，降到 45% 用债券资金的 1/11 买回——把"涨卖跌买"的格言变成可执行程序。它不是预测工具，而是"投资的策略应注重不确定性，而非确定性"的姿态：承认无法判断市场去向，只保证高位不追加、低位有筹码。极值（75/25）只在有"廉价/危险"依据时动用；无把握者守住 50:50 即可。

装置二：美元成本平均（DCA）。每月/每季以等额资金买入，机理是防止在错误时间集中购买——低价时买进更多股份。这是格雷厄姆唯一保留的公式类方法，前提是持续现金流与长期耐心。状态管理：存量计划在下跌中不停（低价买到更多股份正是威力所在）；"危险水平"只约束新开或重启的计划。

默认动作：有钱即可按当前比例投入。等待的隐性成本（股息＋机会）归你，而"等到"的收益不可依赖——择时的举证责任在等待方，唯一暂停条件是市场远超公认价值标准。

## A1 — 书中的应用 (Past Application)

### 案例 1: 耶鲁大学放弃 35% 股票公式（c16）
- **问题**: 机构化的机械股债分配公式在长牛中能否坚持？
- **方法论的使用**: 对照耶鲁 1937 年起围绕 35%"正常持有量"再平衡的实践——这是与 50:50 几乎相似的公式化操作。
- **结论**: 50 年代的大牛市把这一曾负盛名的公式冲垮：耶鲁放弃了它，1963 年股票占组合 61.5%（同期 65 个大学基金平均 55.8%）。因此格雷厄姆主张防御型采用最简单的 50:50——牛市中它至少限制你越涨越买，并给持有者"做出了某些行动"的心理支撑。
- **结果**: 说明大的市场上涨对机械纪律的致命诱惑；50:50 的价值正在于简单到可以坚持。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 组合股债比例漂移：股票涨到 55% 以上或跌到 45% 以下，问要不要调、调多少。
2. 定投计划遇到连跌或大涨，问停不停、要不要重启。
3. 拿到年终奖/一笔闲钱，纠结"现在买入还是等回调"。
4. 想给自己定一套"不依赖预测"的配置规则。
5. 高市况想加仓股票（对应 75/25 极值使用的举证）。

### 语言信号 (用户的话里出现这些就应激活)

- "股债比例 / 股票占比 X% / allocation"
- "再平衡 / rebalance / 止盈再平衡"
- "定投 / 停扣 / DCA / dollar cost average"
- "现在入场还是等等 / 这笔钱怎么投"
- "帮我定一套不用盯盘的规则"

### 与相邻 skill 的区分

- 与 `market-mr-volatility-discipline` 的区别: C3 是对波动的态度与判断（含浮盈度量）；C4 是事先约定的机械程序。用户已有规则问执行 → C4；用户没有规则、被情绪冲击 → C3。
- 与 `defensive-stock-selection` 的区别: C4 只管"比例"，不管"买什么"；比例定了之后选什么 → C7。
- 与 `overheated-market-defense` 的区别: 问"市场过热该降到多少档"→ C6 的打分与谨慎三准则；C4 只在既有比例带内执行。"危险水平"的判断需要 C6 打分支撑。
- 与 `investor-identity-matching` 的区别: 定身份在先（C5）；防御型身份定了之后的机械配置执行 → C4。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认基准与带宽**
   - 完成标准: 写下目标比例（默认 50:50）与硬边界（普通股 25–75%）。

2. **偏离检查与再平衡**
   - 完成标准: 股票 ≥55% → 卖出 1/11 转入债券；≤45% → 以债券资金的 1/11 买回；给出具体金额。
   - 判停条件: 用户要求动用 75/25 极值 → 要求出示"廉价/危险"判断依据；无依据则回到 50:50，不给激进方案。

3. **DCA 状态管理**
   - 完成标准: 区分"存量计划坚持"与"增量计划择时"两个决策并分别给结论——存量计划（连跌/大涨）不停扣；新开/重启计划检查是否处于"危险水平"（判断可衔接 overheated-market-defense 打分）。

4. **新资金处置**
   - 完成标准: 默认按目标比例投入；等待方须举证"市场远超公认价值标准"；输出投入方案（金额/比例/是否分批）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- "买哪只股票/基金"（→ defensive-stock-selection）。
- 波动情绪安抚与买卖判断（→ market-mr-volatility-discipline）。
- "预测顶底来定比例"——这恰是本 skill 要消除的冲动，不为其提供伪装。

### 作者在书中警告的失败模式

- x07 公式型计划失效：把 50:50 当预测或跑赢工具会失望——它不承诺跑赢市场，只提供纪律与心理保护，故不在被证伪之列（t11 明示区分）。
- x08 "买低卖高"准则整体失灵：1949 年后不能把策略建立在等待可证明的熊市上——格雷厄姆的修正正是"根据价值标准衡量的吸引力在 25%–75% 区间调整股债比例"，比例带即那次修正的产物。
- c16 耶鲁放弃公式的反面警示：长牛对机械纪律有致命冲垮力，无机械程序者会被牛市拖着越涨越买。

### 作者的盲点 / 时代局限

- 股债两分框架在滞胀环境中两头受损（1965–1982 恰是其薄弱带）；对通胀对冲资产的讨论停留在 1964 年认识。
- "对半"本身是武断参数，缺乏按估值状态动态调整的机制。

### 容易混淆的邻近方法论

- 与"公式型投资计划"（t11）的区别是本 skill 的命门：公式计划本质是涨多了就卖、赌回归；50:50 不预测、只约束行为——混淆二者会导致错误地放弃或错误地信任。

### 时效警示（全集群通用，必须内嵌）

**1964 年快照，估值锚/绝对门槛/税收论证须按当期重查，无指数基金时代约束。**
- 25–75 带、±5%/1/11 参数、DCA 频率按当期利率与波动环境重校；
- 无指数基金时代约束——今日比例带两端可用低成本指数工具实现（1964 年"全取样"只能以道指 30 或封闭基金实现）；
- "危险水平"判断所需的估值标准（股息率 vs 债息等）按当期重查，禁止照抄 1964 年数字。
