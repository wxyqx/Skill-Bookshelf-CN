# 股东治理质询（Shareholder Governance）

## R — 原文 (Reading)

> "在投资上处于根本地位的是分红和市场价。它们是外部股东收回他们投资的唯一具体的方式，诚然，收益、经济强大及资产增加这些因素对他们也很重要，但这些只有在立即或最终影响他们的分红和市场价时显得那么重要。"
>
> — 本杰明·格雷厄姆，第14章"一般股东的合理待遇"

---

## I — 方法论骨架 (Interpretation)

格雷厄姆把投资者定义为所有者而非交易商：投资者整体是企业的主人，收益来自企业本身，而不是从同伴口袋里赚差价。由此推出两个结构性判断：

1. **内外股东利益背离**：分红与市价是外部股东收回投资的唯一具体方式，内部人却不依赖这两样——想变现时可出售控股、可重估、可低价回购；管理层天然想从股东手中获取尽可能多的资本。经营效率（低成本产出最高利润）不等于金融效率（股东资产按其最大利益运作）。
2. **治理判断必须量化**：管理好不好不看营收故事，看三个相对数——繁荣期股东回报不满意、销售利润率低于同业、EPS 增长低于工业平均——外加"不充分的市场价格"双重判据（市价远低于账面值，或市价/账面比率远低于行业平均）。

问责工具箱：股东大会质询、股利政策举证二分（要么支付正常股利约 2/3，要么证明低分配没有压低市价）、公平回购（公平价高于市价时必须竞争性招标）、支持高于市价的接管报价。"不喜欢管理就卖掉"被斥为愚昧有害——卖掉只改变所有权归属，丝毫不改善经营。

## A1 — 书中的应用 (Past Application)

### 案例 1: 菲利浦·莫里斯 1948 年报——三信号核查（c56）
- **问题**: 如何用可比数据认定管理效率的下降？
- **方法论的使用**: 年报只强调销售增长 170%；格雷厄姆与 4 家竞争者做 10 年对照：净资产净收入从 24.6%（竞争者 13.4%）降到 8.6%（竞争者 13.3%），净销售净收入从 20.6% 降到 7.1%。
- **结论**: 销售指标被薪金结构等扭曲，相对效率滑落被规模叙事掩盖——"管理好不好"从印象变成相对数的比较。
- **结果**: 讽刺的是股东大会上无人质疑，管理层以销售规模自我表功——此例成为"三信号"与"金融效率"概念的原始素材。

### 案例 2: Mission 持股公司——内外股东背离的标本（c57）
- **问题**: 持股公司的结构性折扣如何损害外部股东？
- **方法论的使用**: Mission 1937–1947 年平均以资产价值 35% 的折扣交易；1947 年与 Sunray 的合并将终结该结构，却被刚辞职的前总裁（兼 Skelly 总裁）以"不公平"为由诉讼阻止。
- **结论**: 内部人可通过撇除折扣随时变现，外部股东只能面对持续的折扣——不要指望管理层主动终止对自己有利的结构。
- **结果**: 合并泡汤，折扣依旧；直到 1963 年底因 Skelly 盈利与股价提升才收窄。

### 案例 3: FWO 董事会阻击 55 美元要约——接管正当性（c58）
- **问题**: 当管理层本身是低价的根源时，外部股东还有什么救济？
- **方法论的使用**: FWO 市价 36 美元，董事会自认"保守地讲每股也将超过 80 美元"，却以"捍卫交易所价格"为由阻击 Lazard Freres 的 55 美元收购要约（高于市价 50%）。
- **结论**: 高于市价的报价是外部股东从董事会不公正待遇中解脱的唯一方法——"抢掠者"的骂名安错了地方。
- **结果**: 低于 55 美元的股票按 55 成交，不低于报价者涨到 70 甚至 110 美元——董事会反而坐实了政策压价。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问"公司大量现金趴账不分红不回购/零分红的成长公司合理吗，小股东能做什么"——所有者路径与股利举证；
2. 用户问"管理层好不好怎么客观判断——营收创新高该满意吗"——三信号相对数核查；
3. 用户遇到"公司以低于公平价向关联方/内部人回购"——公平回购判据；
4. 用户讨论"敌意收购是不是掠夺/董事会拒绝要约对股东好吗"——接管正当性。

### 语言信号 (用户的话里出现这些就应激活)

- "股东能做什么 / shareholder rights / 小股东维权"
- "管理层干得好不好怎么判断 / management efficiency / 管理低效"
- "不分红合理吗 / 股利政策 / dividend policy / 该不该派息"
- "回购价格不公 / 向大股东定向回购 / buyback fairness"
- "敌意收购 / 要约收购 / takeover / 董事会拒绝收购对不对"
- "不喜欢管理就卖掉行不行"（反场景警报：恰是本 skill 要纠正的共识）

### 与相邻 skill 的区分

- 与 `investment-advice-discipline` 的区别：C20 管"该不该信/怎么用顾问与研报建议"（人际建议的使用纪律），本 skill 管作为所有者对公司管理层的质询与权利主张；
- 与 `stock-diagnosis-techniques` 的区别：C17 用报表还原找出"相对效率滑落"的证据（技术层），本 skill 拿证据问责、主张股利/回购/接管公正（权利层）；
- 与 `market-mr-volatility-discipline` 的区别：最终"卖不卖"的头寸动作与情绪纪律归 C3；但"卖掉≠治理答案"的判断本身在本 skill；
- 与 `margin-of-safety-core` 的区别："不充分的市场价格"作为治理问责证据使用时归本 skill，作为买入判据使用时归 C18。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **立场设定**：把问题改写为"作为所有者我能主张什么"，拒绝"不喜欢就卖"的默认反应。
   - 完成标准：诉求从情绪表达变为可陈述的权利主张。

2. **三信号＋市价判据核查**：算繁荣期股东回报、销售利润率对同业、EPS 增长对工业平均三个相对数，加市价/账面值与市价/账面对行业平均两个比值。
   - 完成标准：四个指数有当期数值与同业对照基准。
   - 判停条件：全部指标正常 → 治理质询不成立，退出本流程（诉求若属估值转 C14/C18，若属报表疑点转 C17）。

3. **权利工具匹配**：股利问题 → 举证二分（正常派息约 2/3，或证明低分配未压低市价）；回购问题 → 公平价/竞争性招标判据；接管问题 → 高于市价报价的正当性支持。
   - 完成标准：形成含数字的可质询主张，而非道德抱怨。

4. **现实性输出**：区分"可执行（质询函/股东提案/代理投票）"与"需制度条件"，并标注当期治理制度与 1964 年环境的差异。
   - 完成标准：行动清单分两栏＋时效标注。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- "怎么从报表里算出管理低效"——归 C17（还原技术）；本 skill 从证据开始做主张；
- "治理差是不是买入的便宜理由"——归 C18/C12（价格-价值判定）；
- "顾问推荐的组合该不该照做"——归 C20（建议使用）。

### 作者在书中警告的失败模式

- **"不喜欢管理就卖掉"的愚昧共识（x28）**：这一反应不能改善管理，只能降低股价并使所有权转换——作为总体的投资者因此从未推动过任何管理改进，股东在治理上"近乎一个失败者"、对管理层提议如绵羊般迟缓；
- **吝啬股利政策压低股价（x19）**：1 美元股利对市价的拉动约为 1 美元未分配利润的 4 倍；"管理者最知情"不是免检理由——相对不繁荣的公司借扩张之名扣股利尤其不合逻辑；
- **内部人让修正泡汤（x17，Mission）**：对折价持股公司，不要指望管理层主动终止对自己有利的结构。

### 作者的盲点 / 时代局限

- 接管正当性结论绑定 1964 年制度环境（阶段 1.5 已标 V3 borderline：为敌意收购正名是罕见的历史立场）；
- 对股东"如绵羊般迟缓"的判断基于 1960 年代股东大会文化；代理投票、独立董事、机构投资者与激进投资者生态是其未见的演化；
- "金融效率"框架假设管理层与外部股东的利益冲突无法通过激励设计缓解——现代代理理论部分回应了这一点。

### 时效警示

**1964 年快照，报表还原技术在当代会计准则下部分手法过时，学问题结构；估值参数按当期重查。** 具体：三信号的会计口径（EPS、销售利润率）随准则演变须重算口径；"正常派息约 2/3"是 1964 年市场常态参数，按当期重查；"现金红利+优先认股权"的税收论证与股票红利替代方案随税制一变即失效；治理制度（独立董事、披露规则、代理权争夺、激进投资者）已根本改变——学"利益背离诊断＋举证责任分配"的结构，制度工具按当期重写。

### 容易混淆的邻近方法论

- C17（诊断技术）：找证据 vs 用证据问责；
- C20（建议使用）：所有者-管理层关系 vs 投资者-顾问关系；
- C18（安全边际）：同一"低市价"现象，问"管理层为何允许它"归本 skill，问"它够不够便宜"归 C18。
