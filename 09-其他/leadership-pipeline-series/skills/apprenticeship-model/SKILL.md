# 轮岗培养模式总框架

## R — 原文 (Reading)

> ""轮岗培养模式"指的是通过岗位轮换，帮助有领导潜质的人才"从干中学"和快速成长，通过岗位锻炼、领导反馈、自我修正和重复实践来提升其领导力。这种模式为每一位有领导潜质的人才提供量身定制的培养路径，明确每个岗位给他带来的价值，并且确保他掌握必备的领导技能之后，才让他迈向下一个新的领导岗位。"
>
> — 查兰，前言（L7545）

> "要理解这个理念，你首先得接受一个颇受争议的看法：领导力只能在工作实践中培养。我们可以从书本中或课堂上学到有关领导力的概念、方法和工具。……但是，有领导潜质的人才必须通过工作实践来历练自己的领导能力，把书本经验转变为实践经验，并形成自己的应用技能和判断能力。"
>
> — 同上，第2章（L7795）

> "采用轮岗模式培养高层领导的公司会精心规划这些培养对象的工作安排，以强化他们的既有能力，并考验并培养他们新的潜力。公司会给他们实时的指导……公司至少每年对这些培养对象进行一次评估，考察他们取得了哪些进步……"
>
> — 同上，第2章（L7801）

---

## I — 方法论骨架 (Interpretation)

轮岗培养模式回答的是"高潜人才怎么养成"这个问题，它的立场很硬：领导力主要在工作岗位上长出来，课堂只是加速器。

模式的四根柱子缺一不可：
1. **尽早识别**——从入职早期就开始观察，用行为证据而不是资历、学历、聪明程度筛人；
2. **量身定制的轮岗**——为每个人设计挑战递增的岗位序列（见同心圆学习），每个岗位既发挥其现有特长、又考验新能力，且"掌握必备技能后才换下一岗"；
3. **上级领导当导师**——直接上级给实时、具体、聚焦一两项的反馈，而不是 HR 代办；
4. **制度化评估**——至少每年一次的集体评估与人才库更新，配合风险管理：对最有潜质者安排极具挑战、需要超出其显现专长的岗位，同时评估失败的后果。

与传统做法的三个切割：不是"按年头和空缺走的资历晋升"，而是成长状况决定下一步；不是"HR 主导的项目"，而是融入日常经营、各级领导共同承担；不是"轮岗数量越多越好"，而是挑战递增＋反馈闭环。

一句提醒：这套东西不会立竿见影，书中给出的量级是"新体系需要两三年才见效"，而一个人从新人到高层平均要走过约 25 年、五个岗位。

## A1 — 书中的应用 (Past Application)

### 案例 1: 加里——四段岗位串成的培养链（第1章）
- **问题**: 一个有领导潜质的年轻人，没有现成路径，怎么被识别、历练并推到高层？如果他中途觉得"这活我干过"而拒绝调动怎么办？
- **方法论的使用**: 导师鲍勃按四要件推进：先把加里等五六个二十多岁的年轻人调到总部贴身观察（尽早识别）；两年后派他去巴西做营销（挑战递增第一站）；在有更资深候选人的情况下，凭对加里能力的一手了解力荐他做巴西业务一把手（破格提拔＋风险评估）；加里已是一把手后，又说服他去日本合资企业管营销——表面"降级"，理由是新环境的跨文化、公司治理与处世方式本身就是学习价值（以退为进的平行调动）。
- **结论**: 每一次岗位变动都由"成长状况"而非空缺与资历决定；导师在转折点审慎关注业绩与个人成长，"指引加里前进，但从不命令加里做什么"；同时加里本人对成长负最终责任（b4-c01–c04）。
- **结果**: 加里在日本发现部门割裂、会议沉默，用母语分组讨论打开局面，六个月改变高管团队行为，两年扭亏，后续扩份额、进亚洲、降负债，并建立本地领导人才培养体系、培养出接班人；他后来负责公司最大最重要的部门。

### 案例 2: 高露洁——把四要件装进经营节奏（第6章）
- **问题**: 36000 名员工的全球公司，如何确保每个层级都有接班人选，而不是临时抱佛脚？
- **方法论的使用**: 培养流程分层咬合——国家分公司年度人才评估会（个人一页档案含"接下来两个锻炼职务"）→ 区域会议跨部门交叉评估 → 全球职能部门与高管团队双月评估会（看整体人才状况、认识关键人、业绩＋潜力、形成培养共识、确定接班人）→ 向董事会报告并安排候选人见面；用统一的"成功者特征"（达成目标／展现领导才能／以人为本）做共同语言；配套全球调动决策会、"领导力开发"课程（前5年）与"20/20"行动学习（10年后）、留住 90% 高潜的考核指标与 24 小时辞职上报。
- **结论**: 培养不是 HR 的独立项目，而是嵌进经营节律的制度；课程只在前段作加速器，主引擎始终是岗位实践。
- **结果**: 作者称其为"已经掌握这套流程并取得巨大成功"的完整样板；2006 年 CEO 马克向内部培养的库克交接顺畅（b4-c07）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司招了一批校招生或刚提拔一批年轻骨干，用户要为他们设计长期培养路径（轮什么岗、谁来带、怎么评）。
2. 关键岗位（部门负责人、子公司一把手、高管）出现空缺时总是找不到内部人选，用户想搭一套"自己造血的"体系。
3. 用户看到 GE、高露洁、德事隆的做法，想借鉴或复制到自己的公司，但不确定要抄哪些要件。
4. 用户所在公司的培训投入不小（课程、教练、行动学习都上了），但关键岗位依旧缺人，想弄清培养体系缺哪根柱子。
5. 用户要向上级或董事会汇报"领导人才培养方案"，需要一个有内在逻辑的框架而不是课程清单。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么培养后备干部 / 校招生培养路径怎么设计？"
- "轮岗怎么设计才有用？我们轮了但没效果。"
- "培养体系怎么搭？HR 该做什么、业务领导该做什么？"
- "talent development path" / "apprenticeship model" / "rotation program" / "build a leadership pipeline" / "how do we grow our own leaders"

### 与相邻 skill 的区分

- 与 `b5-f01 leadership-pipeline-six-passages` 的区别: 六阶段模型回答"每个层级要什么、交什么"，是本框架的上游定义；本 skill 回答"怎么把人培养到那些层级"。
- 与 `b5-f27 succession-five-steps` 的区别: 继任五步处理的是"某个关键岗位的接班人名单与准备度"；本框架是常年运行的培养引擎，为所有层级供货。
- 与 `b5-f36 dual-track-management-technical` 的区别: 双轨发展回答"个人走管理还是技术路线"；本框架默认目标是培养领导者，不负责路线分流。
- 与 `b1-f12 talent-review-meeting-mrr` 的区别: 那是评估会议怎么开；本框架是整套培养系统的设计与安装。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **盘清现状：识别（选人）与培养（岗位）两条线各自怎么运行的**
   - 完成标准: 列出公司目前的高潜名单来源、评估方式、岗位调动规则、导师安排、评估节律，并逐项标注"有／无／形式化"。

2. **建立或校正识人标准与取证方式**
   - 完成标准: 给出书面的潜质标准（至少含驭人／经商两轴的观察项），并明确证据来源是行为与决策；高潜名单要能说出每个人的两三项优势与待发展项。
   - 判停条件: 若公司连基础岗位标准与坦诚评估的文化都不具备，先说明"任何培养流程都会退化为填表"（见 B 段），再决定是否继续。

3. **为名单上的每个人设计挑战递增的岗位序列**
   - 完成标准: 每人写出"现岗已证明什么 → 下一岗要考验什么 → 再下一岗方向"，并校验每一站的广度或难度确实递增；确认每个岗位有明确的学习目标与考察标准（详见 `concentric-learning-job-design`）。

4. **指定导师并约定反馈节律**
   - 完成标准: 每名培养对象的直接上级被明确为导师，约定观察频率与反馈方式（聚焦一两项关键项、及时具体）、并把反馈落到可检验的下一步（详见 `deliberate-practice-feedback-loop`）。

5. **把评估制度化：年度领导力评估会＋人才库更新**
   - 完成标准: 会议已排进年度日历、有固定输入（一页评估表、成长路径图、行为证据）、有输出（名单增删、下一步岗位、发展重点），且与绩效考核分设两轨（详见 `assessment-dual-track`）。

6. **让高层先动，并管理预期**
   - 完成标准: CEO 与高管团队亲自参与评审与调动决策、把"育人"纳入对各级领导的考核与奖惩（详见 `developing-talent-is-every-leaders-job`）；同时向组织说明新体系需要两三年才见效果。

7. **记录并迭代**
   - 完成标准: 每年复盘一次——新增了多少合格接班人、哪些岗位安排失效、失败案例的归因是什么，并据此修改标准与路径。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 组织只有几十人、岗位屈指可数，"挑战递增的岗位序列"没有物质基础——此时重点是让创始人之外的少数人获得全面负责的机会，而不是搭大体系。
- 用户要的其实是一次培训采购或课程设计——本框架会明确告知课堂只作加速器，直接照此采购会答非所问。
- 公司处于生死存亡的危机期、无稳定经营节律：轮岗与评估的运转依赖经营正常化，先谈生存。
- 只想解决某个具体人的胜任问题（那是绩效与岗位匹配问题，不是培养体系问题）。

### 作者在书中警告的失败模式

- **"一刀切"式轮岗**：传统轮岗太快、重复、过于简单——人才还没做出成绩或融入环境就被调走，公司无法考察其真实能力，人才因无聊而流失（b4-ce01）。
- **只重书本知识、不重实践锻炼**：培养方案以课程为中心，"学员评价'收获很大'但行为无变化"，关键岗位仍无合格人选（b4-ce04）。
- **官僚填表式人才流程**：照搬 GE 的表格与会议形式而不学其严谨与专业判断，"流程完成、人才依旧"，还制造"我们已经在做"的错觉（b4-ce09）。
- **培养资源过度分散**：把高管时间与历练机会平摊给所有人，"只能寄希望于优秀者自己崭露头角"，关键岗位空缺时无人可用（b4-ce06）。
- **为培养一个人而增设组织层级**：破坏组织架构、拉长汇报线，两年内关键人员流失、运营困难（b4-ce15）。
- **培养人才不能听天由命**：把"偶然遇见伯乐"当常态（韦尔奇都差点流失）——不建体系就等于把公司命运交给运气（b4-c10、b4-p09）。

### 作者的盲点 / 时代局限

- **25 年培养周期的稳态预设**：本框架以 2008 年金融危机前后的美国大公司节律为背景（从入职到高层约 25 年、五个岗位、45～50 岁任 CEO）；在技术迭代加速、职业流动性高的今天，这个时间表与"留得住人"的假设都需重估（BOOK_OVERVIEW 批判节）。
- **美国大公司案例偏差与单因论**：成功样板（GE、高露洁、德事隆、诺华）多由作者参与背书，缺少失败企业与对照组；把复杂的人才困境压缩为"潜质识别与培养"，对组织政治、股权结构、行业周期等结构变量处理很薄。
- **科层制预设**：挑战递增的"岗位序列"依赖可预期的层级结构；对扁平化、平台型、项目制组织，框架中的"下一岗"可能根本不存在。
- **责任归属个人化**："个人对自己的成长负最终责任"在制度失败时存在把系统性风险转嫁给个体的倾向。

### 容易混淆的邻近方法论

- 与 Ericsson 的"刻意练习"研究：本书把该结论外推到领导力与判断力，跨域类推未经验证；只保留操作步骤（聚焦一两项、及时反馈、自我修正），不要引用其神经科学解释。
- 与"九格矩阵／人才盘点"：那是分类工具，本框架是培养流程；盘点不产生成长，岗位与反馈才产生成长。
- 与"继任计划"：继任是岗位视角的应急与交接安排，本框架是常年的人才生产系统。
