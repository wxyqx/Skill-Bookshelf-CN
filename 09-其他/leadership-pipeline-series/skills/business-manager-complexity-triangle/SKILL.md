# 事业部总经理：协同三角形与整合团队

## R — 原文 (Reading)

> "图5-1所示的三角形分析工具，对于理解复杂性非常有效。……该三角形展示了事业部总经理的主要工作职责、所需要的知识以及各方面的相互关系。"
>
> — 第5章「自我提升的方法：自学、历练、反省」（fulltext L10812–L10820）

> "例如，如果市场份额下降，或者业务没有获得应该的市场份额，事业部总经理通过这个三角形考察相关影响因素，提出合理的问题，问题的答案就可以成为事业部总经理决策的重要依据。这种方法有助于避免为了获得市场份额而采用降价之类的单一行动。"
>
> — 第5章（fulltext L10822）

> "问题的复杂性远远超出事业部总经理个人能够处理的范畴。……单打独斗就要遭受和卡特琳娜一样的失败。事业部总经理需要把部门经理整合成团队，而不是各行其是。"
>
> — 第5章（fulltext L10705）

## I — 方法论骨架 (Interpretation)

从职能主管升到事业部总经理，是六次转型中作者认为**最大的挑战**：第一次对成本与收入全面负责、在众目睽睽之下工作，而且从"把事做好"变成"决定该做什么"。它给出一件核心工具与两条硬要求：

1. **协同三角形（三角检查法）**：把总经理的工作拆成三个相互支撑的角——**战略方向、组织能力、人员能力**（可本地化替换为具体技能、流程、客户）。遇到问题（如市场份额下降）时，逐角检查影响因素并提问，用答案做决策。其价值有三：
   - 避免单一动作误治（"降价之类的单一行动"往往把三角压得更歪）；
   - 作为"是否承担了全部职责"的诊断——作者说"最经常显现出来的缺陷是组织胜任力的提升（右下角）"，即**组织能力角最容易被漏掉**；
   - 组织的缺点会直接拉低个人效率——"一个糟糕的企业一定会摧毁一个优秀的员工"。
2. **整合团队，不做超人**：问题的复杂性远超个人能处理的范畴，单打独斗就会重演卡特琳娜式失败；总经理必须把各部门经理整合成团队并领导它，"让每一位成员都高效工作"。作者另给两条派生命题：创建业务导向团队是其主要工作之一（要一对一教练直接下属，不能放任各自为政）；**战略规划不可完全授权**，总经理必须清楚市场在哪、未来竞争需要什么，短期与长期统筹兼顾。
3. **里程碑理念转变**：从职能层的"我们能不能做"到总经理的"我们该不该做"——前者是可行性问题，后者是取舍与优先级问题（卡特琳娜把过时产品"运营得更有效率"，而不是放弃它们，就是没越过这道线）。
4. **上手路径**：自我提升主要靠自己（自学、历练、反省），上司帮助是辅助；具体做法是逐角检查并提正确问题、与下属和客户请教、不怕暴露"无知"，然后用工具要求下属也协同使用（作者说用过的高管都认为有效，并建议要求下属采用同类工具）。
5. **失败信号**：转型困难的六类信号——缺乏激励的沟通、没有能力组建强大的团队、没有掌握业务赚钱的技巧、时间管理问题（走马观花、缺少与核心人员深谈）、忽视"软环境"（文化与价值观）、把战略完全交给战略规划部门；另一类是忽视支持性部门（人力资源、财务、法务等），而它们本是最了解全局的早期预警系统。

## A1 — 书中的应用 (Past Application)

### 案例 1: 卡特琳娜——从"把事情做得更好"到"我们应该做这件事情吗"
- **问题**: 卡特琳娜是优秀的事业部副总经理，曾把信用卡业务做出引人注目的业绩，随后被派去领导一家亏损的南美银行（支行太多、缺明确系统的战略、监管不力）。她沿用操作层面的打法：优化流程、把每项工作都做得更有效率——"她考虑的是'把事情做得更好'，而不是'我们应该做这件事情吗'"。该行产品组合里有些产品已经过时，"她应该放弃这些产品而不是更有效率地运营这些产品"。
- **方法论的使用**: 按三角逐角看——战略方向角（该放弃哪些产品与支行、该走什么路线）被跳过；组织能力角与文化角（她过细管理触及潜规则，"人们不再主动参与"）未处理；人员能力角未建团队。她只用了自己最擅长的一角（运营能力），把复杂题当成了流程题。作者点出深层机制："即使她知道在新的领导职位上这样做是不对的，但她还是又回到过去的思维模式中"。
- **结论**: "现在，这种'超人'般的努力却失败了"——单打独斗在事业部总经理层级必然失败，必须整合团队；同时她"不愿向上司求助"也切断了外部支持。
- **结果**: "卡特琳娜最终离开了这家银行，也离开了那家金融服务公司"——个人与公司双输（b5-c08；L10667–L10673）。

### 案例 2: 加里——用三角形评估后，主动废弃前任的成功战略
- **问题**: 加里接任商品交易部门总经理时业绩优异（收入 5 亿美元、利润率 23.8%），本可维持现状；他的晋升由老上司（提拔他的人）促成，而这个战略正是老上司的成功战略。
- **方法论的使用**: "他运用三角形评估工具分析业务战略方向、组织能力和人员能力。他也乐意向下属和客户请教，不怕暴露自己的'无知'。"三角检查发现：行业需求饱和、欧元区将减少产品需求，"目前的业务模式不适合当前的现实和客户需求"；随后他推动业务从产品交易转向专业咨询，并重组人员与客户流程。
- **结论**: 难点不是发现问题，而是**改变老上司的成功战略**——他靠团队协作、充分准备与勇气完成；这也印证"战略规划不可完全授权、直接下属必须教练"的可用性（他把团队与客户拉进分析与共识）。
- **结果**: "新战略巨大成功，抓住新的赢利机会并降低业务风险"（b5-c09；L10858–L10870）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户**刚接手一个事业部/业务单元**（或即将接手），面对一堆问题不知从哪下手，想防"一刀切"。
2. 用户面对**利润下滑/份额下降**，本能想降价、砍人、压成本，需要把诊断做全再动手。
3. 用户观察到某总经理**忙到飞起、个人英雄主义**（救火、通宵、什么问题都自己上），团队却各自为政。
4. 用户要**评估一位事业部总经理候选人/新任者**是否完成"该不该做"的里程碑转变。
5. 用户需要**给总经理层写角色要求或教练计划**：整合团队、教练直接下属、战略不可全授权这几条如何落地。

### 语言信号 (用户的话里出现这些就应激活)

- "我刚接手一个事业部/业务单元 / 新官上任 / 先砍哪里"
- "利润在下滑 / 市场份额掉了 / 要不要降价 / 降本也救不活"
- "协同三角形 / triangle / 战略方向、组织能力、人员能力"
- "他什么都自己干 / 不做超人 / 团队各行其是 / 整合不了团队"
- "该不该做 / 值不值得做 / 我们能不能做"

### 与相邻 skill 的区分

- 与 `functional-manager-maturity`（本册）：那条是"为业务建竞争优势"的职能主管（第三阶段）；本条是全面负责盈亏、决定业务取舍的总经理（第四阶段）。
- 与 `group-executive-indirect-success`（本册）：那条处理多业务组合与间接成功（第六阶段）；本条仍聚焦单个业务内部的三角与团队整合。
- 与 `functional-vp-four-results`（册2）：事业部副总业绩契约 ≠ 总经理协同工具。
- 与 `r-m-v-return-decomposition`（册3）与 `cash-net-inflow-everyones-business`（册3）：商业语言工具（盈利与现金视角）是总经理理解的底层语言；本条是治理复杂性的职责-知识关联图，两者互补不替代。
- 与 `question-to-reality`（册1）：追问到现实是通用的求实纪律；本条的三角是业务职责检查表。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定三角的三条边（先本地化）**
   - 与当事人一起把三角写清：战略方向（价值主张、目标客户、该放弃什么）、组织能力（结构、流程、系统、跨部门协同机制）、人员能力（关键岗位的人、团队组合与教练安排）。
   - 完成标准: 三角各有 1 页以内的现状描述；每条边都能指出"谁负责、证据是什么"。

2. **针对具体问题逐角检查并提问**
   - 以市场份额下降/利润下滑为例，三角各问："价值主张是否失效？"（对照戴比尔斯式从"不得不来找我们"到"想来找我们"的价值主张重建）"流程与结构是否支撑战略？""团队里是否有合适的人？"
   - 完成标准: 每个角至少 2 个问题的答案与证据；能量化则量化。
   - 判停条件: 若三角中两角以上均有问题，进入第 3 步组合方案；若仅一角问题，直接进入第 4 步，但注意别把"组织能力角"漏掉（它是最常缺失的一角）。

3. **形成组合方案，而非单一动作**
   - 把各角的问题配对成动作组（如：战略收缩产品线＋重构客户流程＋补关键人才），并明确每一步的里程碑；避免"降价/裁员"式单点动作。
   - 完成标准: 方案至少覆盖两角且相互支撑；每条动作有负责人、时间点、验证指标。

4. **落地两条硬要求**
   - ①整合团队：把部门经理变成一支团队（建立共同目标、协作机制、一对一的教练节奏），不要个人英雄主义；
   - ②战略不可完全授权：总经理亲自参与战略思考，把战略规划部门当支持而非替代；确保与直接下属一对一教练到位，让他们理解并接受业务战略。
   - 完成标准: 团队的议事与教练节奏书面化；战略会议中总经理本人有实质输入记录。

5. **做"该不该做"的里程碑自查与信息补全**
   - 自查：最近三次重大决策中，有多少是"能不能做"（可行性）型、有多少是"该不该做"（取舍）型；并检查支持性部门（HR、财务、法务等）是否被排除在关键会议之外——它们是最了解全局的早期预警系统。
   - 完成标准: 给出下一次决策的改进点与支持部门的接入安排；必要时把三角工具要求下属也使用以相互协同。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用它替代职能/集团层级的工具**：三角是事业部总经理的职责-知识关联图；职能主管用成熟度框架，集团高管用组合决策与间接成功标准。
- **把它当通用诊断模型**：它不是 SWOT/平衡计分卡的替代品，而是"职责完整性"的检查工具；逐角检查的价值在于暴露被漏掉的一角（通常是组织能力）。
- **只把三角当三栏清单**：三条边必须相互追问与印证；拆成互不相关的三个待办清单就丢掉了"相互关系"。
- **用于日常运营优化**：三角服务于复杂局面下的取舍与整合；常规执行的改进不需要它。
- **据此做人事处置**：诊断结论只作发展对话输入；调岗/解除须依当地劳动法与公司程序（系列级伦理边界）。

### 作者在书中警告的失败模式

- **事业部总经理转型困难的六类信号（b5-ce12）**：缺乏激励的沟通（无法用跨部门语言激励团队）；没有能力组建强大的团队（"独行侠"心态、通过产品和技术而不是人员运营业务）；没有掌握业务赚钱的技巧（抓不住核心流程与价值链、低估销售部门作用）；时间管理问题（走马观花、缺乏与核心人员讨论）；忽视"软环境"（企业文化与价值观长期被搁置）；把战略完全交给战略规划部门。
- **忽视支持性部门（b5-ce13）**：只偏爱自己出身的部门，"如果事业部总经理不理解或者不重视支持部门的贡献时，这些部门的员工就不会尽职尽责……甚至玩起公司政治"；支持部门本是"公司承担业务的早期预警系统"。
- **战略全授权（b5-p11 并入）**："事业部总经理不应该把战略规划工作完全授权给战略规划部门"；不建业务导向团队、不与直接下属一对一教练是"一个严重的错误"（L10904–L10906）。
- **团队崩塌与沟通失效（b5-c14）**：汤姆升任事业部总经理后回避下属关于成本整合的反馈（"别担心，你能解决这个问题。我们过去一直都能解决这一问题"），成本冲突升级、质量下滑、错过交货期，15 个月被解雇——本层级的关键要求正是"整合职能部门"。

### 作者的盲点 / 时代局限

- **工具来源与效度**：图 5-1 标注"资料来源：Drotter Human Resource, Inc."，作者以"用过该模型的事业部总经理都说很有效"为证——属于客户见证，无对照或效度检验。
- **"整合团队"缺少冲突与政治的处理**：把部门经理整合成团队假设各方目标可对齐；对事业部内既有的资源竞争、历史恩怨、矩阵汇报关系未展开。
- **组织能力角为何最常缺失**：作者给出经验判断但未解释机制，也未讨论权力约束（有些总经理无权改结构/流程）。
- **2000 年代初美国大公司语境**：案例以金融服务、商品交易、制造业为主；对平台型/软件型业务（边际成本近零、网络效应、烧钱换市场）的取舍逻辑未覆盖，"份额下降就查三角"的处方在这些行业可能失真。
- **对"该不该做"的判断标准留白**：书中只给方向（赢利与长远发展），未给取舍优先级工具（这需借助册3 的六要素与增长原则）。

### 容易混淆的邻近方法论

- 与 `functional-manager-maturity`（本册）：第三阶段 vs 第四阶段。
- 与 `group-executive-indirect-success`（本册）：单业务整合 vs 多业务组合。
- 与 `r-m-v-return-decomposition`（册3）：指标分解工具 ≠ 职责三角。
- 与 `profitable-sustainable-growth`（册3）：增长纪律 ≠ 事业部内三角检查。
- 与 `functional-vp-four-results`（册2）：职能副总业绩 ≠ 总经理职责。
