# 教练辅导双轨框架（业务轨＋行为轨）

## R — 原文 (Reading)

> "教练辅导下属并不是业绩回顾，也不是讨论去年做了什么，亦不与薪酬相关。它是一种针对个人的、非常个性化的指导。领导人要使员工猛然惊醒，帮助他自我觉察，面对自己的认知盲点，从而学会把事情做得更好。这种反馈是真诚和直接的，无须含含糊糊。"
>
> — 查兰，第6章（L6934）

> "当领导人教练辅导他人的时候，他们往往关注对方的行为改变。但请不要忘记了业务领域的教练辅导。这个人能否理清复杂的问题？这个人能否列出工作中的优先事项？他是否把工作分解实施，落到实处？他能否完成任务？"
>
> — 查兰，第6章（L6955）

> "教练辅导的机会无处不在，而且越及时越好。……这个缺点第一次被提出来，但已经太晚了。如果在10年前就给出这样的反馈，对他的成长将会有益得多，而且他也有足够的时间去修正。"
>
> — 查兰，第6章（L6936、L6938）

## I — 方法论骨架 (Interpretation)

"带人"最常见的两个错误：一是把教练辅导做成一年一度的考核谈话（结算数字、挂钩奖金），二是只盯行为不作业务辅导。这个方法给出一个双轨结构：

1. **先划清性质**：教练辅导是针对个人的、个性化的指导——不是业绩回顾，不是讨论去年做了什么，不与薪酬相关。它要帮对方自我觉察、面对认知盲点。
2. **业务轨**（常被忽略的一轨）：这个人能否理清复杂的问题？能否列出优先事项？能否把工作分解落实？能否完成任务？——考察的是他对**外部现实的评估能力**与对**基本商业要素**的把握（波比给汤姆的信是范本）。
3. **行为轨**：针对具体行为弱点（如"太富有同情心而接受了一些事实上并不合理的计划或者业绩表现"、"他的能力不足以抵消他的过失"——害怕承认错误、在亏损业务上动作迟缓、不能面对自己提拔的人不胜任），给出可操作的改进项，并让对方知道公司会支持。
4. **方法要点**：只挑少数重点（波比第二封信只列 4 项，行为信只列 2 项）、具体到行为与事例、不用空词（"战略"）、必要时写下来。
5. **时机纪律**：机会无处不在、越及时越好；负面场景（投影仪故障）也可以变成教学；攒到评估会才揭晓致命短板，修正窗口已经关闭。
6. **越界提示**：若辅导后确认是"人岗不匹配"，转人岗处置流程（`b1-f15`），并按法律与伦理边界执行（见 B 段 risk_note）——不要用"再辅导"无限期拖延。

## A1 — 书中的应用 (Past Application)

### 案例 1：波比给汤姆的两封信（业务轨范本）
- **问题**：40 亿美元公司的部门主管汤姆上报预算，仍按过去经验分配资源，忽略了公司正处在"根本性转型"（不是循环往复的变化）之中——销量与价格都将走低、欧洲成本沉重、区域诸侯割据。
- **方法论的使用**：CEO 波比看过预算后写信：要求计划应对更低销量与更低价格、提高欧洲资源投入、打破地区割据整合全公司业务；并预告"1998年将是你最艰难的一年"。半年后第二封信：肯定进步，只列 4 项 1999 年重点（全球市场成本结构、高附加值产品、供应商创新、印度和中国市场），建议准备备用方案，并明确"我能帮助你们什么呢？"
- **结论**：业务教练要具体、只挑少数重点、不用"战略"空词、必要时书面留痕；信中焦点是业务判断，不是业绩评价。
- **结果**：汤姆是公司最出色的管理人员之一（4000 万美元的资产回报率达 40%）；这两封信被作者当作业务教练的标准范本（第6章，L6957–L7017，案例 b3-c31）。

### 案例 2：大型技术公司 CEO 的反馈信（行为轨）
- **问题**：一位来自业界之外的下属"太富有同情心而接受了一些事实上并不合理的计划或者业绩表现"，影响目标达成。
- **方法论的使用**：CEO 用两页篇幅先充分确认优点，再列两项具体改进：①必须深入了解业务运作的细节，要求管理人员严格对业务指标负责（并承诺"我会帮助你"）；②坚持高标准、严要求，不为同情而接受不合理计划。
- **结论**：行为反馈可以点名但要保持尊重，改进项要具体；同时点明"他的能力不足以抵消他的过失"的警示（害怕承认错误、在亏损业务上动作迟缓、不能面对自己提拔的人不胜任）。
- **结果**：这位管理人员明确知道需改进之处，也知道在处理人事方面会得到上司支持——作者称之为"一种执行的优势"（第6章，L7030–L7042，案例 b3-c32）。

### 案例 3：韦尔奇的两个教练时刻
- **问题**：下属缺少主动学习与客户视角；一次汇报会中投影设备突然故障，年轻经理面对苛刻的 CEO 与 10 名同事。
- **方法论的使用**：①多年前的韦尔奇每周日早晨给直接下属打电话讨论《纽约时报》读到的内容——五周后每个下属都自发阅读并讨论；②投影故障时他不训斥，而是说"如果这种情况发生在我们的客户面前，客户会怎么想？让我们讨论一下你们在这种情况下将如何应对"，把尴尬变成教学讨论。
- **结论**：教练机会无处不在、靠问题引导而非责备；以身示范能带动学习。
- **结果**：作者用作"大师级教练"的行为示范（第6章，L6930、L6940–L6942，案例 b3-c29）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 下属刚被提拔或换岗，业绩数字还行但团队怨声载道，不知道该辅导业务还是行为。
2. 想给下属反馈，但公司里只有年度评估这一个正式场合，怕谈了伤感情、又怕不谈误事。
3. 有个聪明但"总需要别人告诉他应该做什么"或"太富有同情心而接受不合理计划"的人，想纠偏又怕打击。
4. 自己做了很多业务指导，但同样的行为问题（回避冲突、怕承认错误）反复出现；或反之，只谈态度不谈业务。
5. 关键人才的问题第一次暴露在评估会/晋升关头，需要建立日常辅导节奏防止重演。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么带这个人" "绩效面谈之外怎么谈"
- "他总需要别人告诉他应该做什么" "他太善良了"
- "说了没用过几天又犯" "反馈该怎么说"
- 英文：coaching / how do I develop this person / feedback / behavioral issues / too nice to hold people accountable / first-time manager struggles

### 与相邻 skill 的区分

- 与 `b4-f03` deliberate-practice-feedback-loop 的区别：那是册4 的培养体系机制（轮岗中的反复练习＋导师反馈闭环，面向高潜的长期生产）；本 skill 是日常上级对下属的**双轨谈话结构**，任何层级、任何一次辅导都可用。
- 与 `b5-f33`（并入本单元的教练三问题框架）的区别：三问题（现在在梯队哪一层？该层要求具备/缺什么？到达下一层要放弃什么？）是**谈话里定位用的提问结构**，本 skill 的 E 段在识别"层级/角色问题"时可调用它。
- 与 `b5-f23` performance-gap-circle 的区别：绩效圆圈是"岗位要求的完整业绩清单"（定义缺口用）；本 skill 是谈话的双轨内容（业务＋行为）。先用绩效圆圈定义缺口，再用双轨展开辅导。
- 与 `b1-f15` underperformer-tiered-handling 的区别：那个是表现不佳者的**分层处置**（含改进期与退出路径）；本 skill 是发展性辅导、不输出处置程序。若辅导后确认人岗不匹配，转 `b1-f15`，并遵守 B 段法律边界。
- 与 `b2-f22` performance-dialogue-evidence 的区别：那个用证据做业绩讨论（业绩达成与否）；本 skill 的辅导独立于业绩评价与薪酬，不混用。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先声明性质：这是发展辅导，不挂钩薪酬与考核**
   - 完成标准：谈话开场即说明性质（成长导向、独立于评估日程）；与年度评估/调薪会议分开安排。
   - 判停条件：若用户真实目的是绩效处理或辞退 → 转 `b1-f15`，本 skill 不输出"如何逼走员工"类建议。

2. **选轨：业务轨还是行为轨（或双轨并行）**
   - 完成标准：写下 1–3 个待辅导点，每点标注类别；业务轨点须落到"理清复杂问题/列优先事项/分解落实/完成任务"四问之一；行为轨点须附具体事例（时间、场合、行为、造成的影响）。

3. **给少数可操作改进项，并说明支持**
   - 完成标准：只挑最关键的 1–3 项（参照波比第二封信 4 项、行为信 2 项的做法）；每项具体到行为或判断标准，不用"战略"等空词；写明"公司/上司会如何支持"。
   - 判停条件：若对方当前岗位尚未达标，先聚焦当前岗位，不跳谈下一职位（教练三纪律之一）。

4. **及时谈，用问题引导自我觉察**
   - 完成标准：反馈在观察到行为后短期内完成（不攒到评估会）；谈话中至少用一个提问引导对方自己看见问题（如"如果这种情况发生在客户面前会怎么样"）；对方能复述改进项。

5. **跟踪与复核，必要时转轨**
   - 完成标准：约定下一次谈话时点并完成至少一次跟踪；观察行为/业务变化；若确认属人岗不匹配（拖延、抱怨、反复无效、消耗他人），转入岗处置流程并给出知情、解释、转岗/改进机会，遵守当地劳动法与公司程序（b3-ce09/ce15 risk_note）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 年度绩效评估与薪酬谈话：不与本 skill 混用（混用会破坏两类对话的功能，见 b3-ce13）。
- 处分、解雇、降职程序：转 `b1-f15` 与公司合规流程；本 skill 不提供"劝退话术"。
- 纯技能培训（软件操作、财务知识课程）：培训与教练分工不同；教练针对判断力与行为。
- 你无法观察对方的实际业务行为（未共事、远程且无工作接触）：外部教练的局限同样适用（b4-ce11）——先安排能观察的场景，或换由直接上级来谈。

### 作者在书中警告的失败模式

- **b3-ce13 用年度绩效评估代替成长辅导**："很多时候，这些年度评估只是一种用于调整薪酬的例行沟通，并不是帮助人们成长和发展的渠道"（L6932–L6934）。机制：评估的制度目的是薪酬与合规，而非学习；频率过低、内容回溯、缺乏个性化指导。预警信号：全年除考核外没有任何具体发展反馈；下属说不出自己正在改进的两项能力；考核对话只讨论数字与奖金。
- **b3-ce12 反馈太晚：到评估时刻才揭晓致命短板**："这个缺点第一次被提出来，但已经太晚了。如果在10年前就给出这样的反馈，对他的成长将会有益得多，而且他也有足够的时间去修正"（L6938）。机制：年度评估关注成绩与薪酬，不关注行为模式与潜质。预警信号：关键反馈在评估会/晋升关头首次出现；多年评价只有表扬没有具体改进项；当事人对结果感到震惊。
- **b3-ce09 让不合适的人在同一岗位"待得太久"**（risk_note 原文落位）：管理者因心理承诺、幻想其适应、避免冲突而拖延处理人岗不匹配；当事人不踏实、抱怨、消耗他人能量，团队协作与决策质量受损。**风险边界：处理方式必须尊重当事人、给出转岗/改进机会、遵守当地劳动法与公司程序；本 skill 不得输出"如何逼走员工"类建议。**
- **b3-ce15 为回避冲突而容忍不匹配**（risk_note 原文落位）："我看到了很多次人们如何反复准备着去谈话，可到了要解决问题的那一天，他们却退缩了"（L6903）；"避免冲突却伤害了公司，这对本人和周围的人造成更大的痛苦"（L6905）。**伦理边界：作者强调"直面"不等于粗暴；必须给对方知情、解释与选择，并避免在情绪化状态下做决定。**
- **跨册并入证据**：b4-ce11 外部管理教练的局限（看不到真实工作场景、不懂业务，只能谈通用技巧）；b5-ce32 教练辅导五种失效模式（只用威胁/承诺引起表面调整、教练无资质、把教练当万能药、职责外包等）。

### 作者的盲点 / 时代局限

- **"直觉常常正确"缺乏证据**：作者说"我们的直觉常常是正确的"，无任何验证；对反馈者自身偏见的机制未讨论（BOOK_OVERVIEW 未证假设）。
- **依赖"坦诚文化"这一最难满足的前提**：有效辅导要求上司放弃控制、坦诚反馈，而作者自己承认错位已是一种"沾沾自喜的文化"（BOOK_OVERVIEW 反对意见 4）。
- **可扩展性未讨论**：个性化辅导依赖上级时间与意愿，对大规模组织的覆盖机制未展开。
- **美国大公司语境**：对跨文化反馈接受度差异（如面子、等级敏感）未展开；案例几乎全为美国白人男性高管（BOOK_OVERVIEW 立场盲点）。

### 容易混淆的邻近方法论

- 绩效改进计划（PIP）：是流程与法律工具（限期、标准、后果），不是发展辅导；两者目的不同、留痕要求不同。
- 导师制（Mentoring）：通常是跨层级/非直属的长期关系；本 skill 是直接上级的日常辅导，两者可并存。
- 教练三问题/三纪律（册5，并入本单元）：是本框架的下位工具与纪律，用于谈话定位与责任归属；不要当作独立方法另起炉灶。
