# 个体与组织诊断五步/四步法

## R — 原文 (Reading)

> "（1）通过对个体的观察和谈话识别个体的行为和工作成效。看看他的日程表以判定他如何使用时间。……（2）了解他对其他人的影响——过去和现在的直线下属，以及其他部门的人。……（4）判定某人实际所处的领导层级是否与他应该达到的层级相匹配。……（5）建立一个以理念为中心的培训计划。"
>
> — 第8章「个体视角」（fulltext L11448–L11456）

> "（4）假如你在查看整个领导梯队，则要分析每个层级的强项和弱项。例如，是否事业部总经理层级情况较好……而业务经理层级较差呢？换句话说，领导梯队在哪里发生阻滞了？"
>
> — 第8章「团队视角」（fulltext L11475）

> "答：最佳的诊断方式是在看人之前先看他的工作。查明已经完成的工作以及那些被忽视或没有做好的关键工作。……确定那些下属得到晋升的领导以及下属很少晋升的领导。有了这些信息，你就可以将没有完成的工作和领导梯队联系起来，从而发现问题所在。"
>
> — 第8章 常见问题（fulltext L11511）

## I — 方法论骨架 (Interpretation)

这条方法论把"团队不行"这种模糊抱怨变成可执行的排查程序。它分两级，共享一个纪律。

**个体诊断五步（查一个人）**：
1. 观察与谈话，识别行为与工作成效；**看他的日程表**判断时间如何使用——"他每天做的第一件事"和"会见的第一个人"通常反映其真实优先级；
2. 了解他对其他人的影响——过去与现在的直线下属、其他部门的人：他是否按下属所处层级有效开发他们？是否频繁融洽地跨部门交流？
3. 把信息对应到领导梯队模型——按该层级的领导技能/时间管理/工作理念逐维比对一致或不一致；
4. 判定实际层级与应有层级的匹配度，确定两者之间的**差距**（可能只是缺某几项技能，或时间管理仅部分符合）；
5. 建立**以理念为中心**的培训计划——理念对了，时间管理与技能通常会跟着调整。

**组织/团队诊断四步（查一层或全公司）**：
1. 对被评估团队中的领导者做个人评价（可直接用上面五步）；
2. 持续检测其三维度是否符合所处层级要求；
3. 找出不符合的**具体构成**——不是"这人不行"，而是"这个层级上的大多数领导者更关注技术工作而不是培训他人"这类可归纳的差距形态；
4. 汇总各层级强项弱项，定位**"领导梯队在哪里发生阻滞"**，指出实际领导能力与要求不相称的层级。

**两条纪律（决定诊断质量）**：
- **先看工作，再看人**：先查明已完成的工作与那些被忽视或没做好的关键工作、已实现与未实现的目标，还要看"哪些领导的下属得到晋升、哪些的下属很少晋升"；有这些信息后再回到人。
- **先查组织，再下个人结论**：组织因素（薪酬制度是否奖励了错误行为、职责是否清晰、资源与上司是否到位）会影响诊断——"当公司的文化与制度出了问题时，最重要的是不要过早对个人下结论"。作者在绩效圆圈的工作中统计到约 75% 的绩效缺口原因与上司有关（第9章 L11722），因此提升全面绩效应当"从上司开始"。

诊断的产出不是"抓出责任人"，而是**系统阻塞点 + 发展计划**；危机时刻做这种诊断最有效，因为三类缺点最容易暴露。

## A1 — 书中的应用 (Past Application)

### 案例 1: 玛丽和查理——先查组织，再谈个人
- **问题**: 招聘经理玛丽被上司（部门总监查理）要求"亲自参与"招聘，查理则接手玛丽本该做的资源重配工作；任务完成、两人都拿奖金，查理还推荐玛丽做自己的继任者——但玛丽实际没有为更高层级做任何准备。
- **方法论的使用**: 走个体诊断五步，会发现两人都不在应有层级工作（玛丽的时间全在专业招聘上、查理在替下属做一线任务）；但继续追下去就会碰到组织要素——**薪酬制度**："查理和玛丽从错误的人那里以错误的方式取得了正确的结果，并由此获得了奖金。因此，薪酬制度不符合领导力发展的需要。"
- **结论**: "当公司的文化与制度出了问题时，最重要的是不要过早对个人下结论"（L11435）——若只做个人测评，会得出"两人表现优秀"的荒谬结论；正确诊断必须把制度因素纳入。
- **结果**: 该案例被用作诊断教学的元案例，说明产出多不等于做对事、错位会被制度化为"完成任务的方式"（b5-c15）。

### 案例 2: 千人高管教练项目——跳级明星的集体短板
- **问题**: 一次覆盖 1000 多人的高管教练辅导项目（含 360 度反馈）想把"有潜力但被阻滞"的人找出来。
- **方法论的使用**: 团队视角诊断——把接受教练的职能主管分成两类并对照六层级：第一类经历了全部领导阶段（培训+实践结合），有资格担任任何领导职位；第二类更快升上来，多为顶尖 MBA，入职时是职员、与咨询团队一起做项目，**跳过了第一个管理层级**；360 度反馈显示"他们在绩效管理领域却几乎一样糟糕"——目标设定、教练辅导、选人、处理纷争。
- **结论**: "六个层级诊断方法在加强领导梯队方面最重要的贡献之一，就是给那些跳过一个或者更多领导阶段的人员贴上标签"（L11484）；缺失不会自行补上，只会被天赋与专业成绩掩盖到暴露那天。
- **结果**: 跳级明星的短板被系统暴露，成为反对快速提拔、主张补课的经验证据（b5-c28；L11481–L11492）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户感觉**团队执行力差**、结果总不达标，想找出问题出在谁/哪一层，但不想凭印象抓人。
2. 用户要做**年度人才盘点或绩效诊断**，需要一个"逐人评价再按层汇总"的标准流程。
3. 用户怀疑公司出现**梯队阻滞**（"每个层级都在做下一级的事"），想知道卡点在哪个层级。
4. 用户要做**教练辅导或培训计划**，需要先弄清差距在哪（技能/时间/理念），再决定培训内容。
5. 用户面对**高管或高潜的失败**，想区分"个人不行"与"组织因素"（薪酬、职责、资源、上司）。

### 语言信号 (用户的话里出现这些就应激活)

- "诊断 / diagnosis / 帮我查一下 / 找找原因"
- "团队执行力差 / 结果老是不达标 / 找责任人 / 是谁的问题"
- "哪一层堵住了 / 梯队阻滞 / 每个层级都在做下一级的事"
- "他到底卡在哪 / 先看什么 / 怎么开始查"
- "到底是人的问题还是制度的问题 / 薪酬是不是奖励了错误行为"

### 与相邻 skill 的区分

- 与 `three-dimension-transition`（本册）：那条是三维度取证量表（尺子）；本条是完成整套诊断的流程（含组织因素与汇总），是本册诊断能力的操作骨架。
- 与 `leadership-pipeline-six-passages`（本册）：六阶段负责"定位层级语言"；本条负责"诊断流程"，含"先看工作再看人"的纪律。
- 与 `performance-gap-circle`（本册）：那条用绩效圆圈画七项绩效内容的缺口（75% 归因上司的数据出自其第9章工作）；本条是通用诊断五步/四步，二者相邻可组合。
- 与 `leadership-deficit-four-causes`（本册 b5-f30）：那是失败原因分类（选错人、留太久等）；本条是诊断的操作方法。
- 与 `question-to-reality`（册1）：追问到现实是通用求实纪律；本条的"先看工作再看人"是其在人才诊断上的具体化。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先看工作（不先看人）**
   - 列出：哪些目标没实现、哪些关键工作被忽视或没做好、哪些领导的下属得到晋升而哪些的下属很少晋升。
   - 完成标准: 一份"工作与结果"清单，含证据来源；未完成这一步不得进入对人的判断。
   - 判停条件: 若发现目标/职责定义本身不清、或薪酬制度明显奖励了错误行为，先记录为组织因素并跳到第 5 步汇总，避免得出个人结论。

2. **对个体做五步（逐个走，不跳步）**
   - ①观察+谈话＋看日程表（每天第一件事、会见第一个人）；②查他对下属与跨部门的影响；③把信息对应到层级维度（技能/时间/理念）；④判定实际层级与应有层级的差距；⑤写以理念为中心的培训计划。
   - 完成标准: 每人一张诊断卡：三维度各 1~2 条证据 + 差距描述 + 1 个发展动作。

3. **把结果向上汇总为组织诊断四步**
   - ①逐人评价完成；②检测各层三维度符合度；③归纳差距的**具体构成**（如"这个层级的大多数领导者更关注技术工作而不是培训他人"）；④汇总各层强弱项，指出阻滞层。
   - 完成标准: 一份按层级排列的汇总表；明确指出"梯队在哪里发生阻滞"及其构成。

4. **区分组织因素与个人因素（防误判）**
   - 逐条排查：薪酬是否奖励了错误行为、职责是否重叠或断裂、资源与上司是否到位、是否存在"人在错层"的上司影响下属。
   - 完成标准: 每个被诊断对象标注"个人因素/组织因素/混合"及依据；只有当组织因素排除后，个人结论才成立。

5. **转化为发展动作（不做人事处置）**
   - 依差距类型出动作：理念缺口→层级差别讲解与教练；技能缺口→培训+实践+反馈；时间缺口→日程重排；组织缺口→修制度/清职责。
   - 完成标准: 每项动作有责任人、时间点、验收方式；诊断结论仅作发展对话输入，涉及调岗/解除须依当地劳动法与公司程序。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **据此给个人贴"错层"标签或单方处置**："诊断结论仅作为发展对话的输入；不得据此单方面给员工贴错层标签，处置前应排除组织因素（第8章 L11435）"（b5-ce01 ethics_legal_note）；涉及调岗/解雇须依当地劳动法与公司程序，并提供转岗/改进机会与尊重程序。
- **只做个人诊断就下组织结论**：组织问题（薪酬、职责、流程、上司）不查清，个人结论会系统性失准——作者明确"不要过早对个人下结论"。
- **在危机之外频繁使用**：作者提示"危机时刻做这种诊断最有效"，因为三类缺点最容易暴露；常态下需更长的观察窗口与更多证据。
- **把诊断当问责工具**：目的是找系统阻塞点与发展动作，不是抓责任人；用错会破坏信任，使后续取证失效。
- **把它当心理测评或绩效评级**：它是管理框架，不是测评工具；书中的判断标准无预测效度证据（系列级批判）。

### 作者在书中警告的失败模式

- **跳级明星的集体短板（b5-ce20）**："在进行了360度反馈之后，与其领导层级所要求的相比，这些正在冉冉上升的新星在工作理念和领导技能方面的不足就明显暴露出来了"——单兵作战、把下属当"工蜂"、不重视培养他人。
- **用旧阶段的方式干新阶段的事（b5-ce01）**：日程表被旧层级事务占满；提拔后一年仍未完成新层级关键动作——正是个体五步第①②步要捕捉的信号。
- **组织默认的晋升假设（b5-ce35）**：把"本岗位高绩效"等同于"下一岗位胜任力"，使诊断中最常见的误判发生（只看现任业绩就下结论）。
- **CEO 失败的首要原因（b5-ce19）**：不能快速处理绩效提升问题——诊断出了差距却不处理，等于没诊断。

### 作者的盲点 / 时代局限

- **"75% 与上司有关"是作者自己培训项目中的统计**：未给出样本、方法或对照，不能当作普遍规律；引用时须声明其来源局限。
- **诊断依赖访谈者经验**："先看工作"要求"为了准确诊断，你必须要了解业务的细节"，这在小公司外行诊断者身上难以满足；书中未讨论诊断者自身的偏差与利益冲突。
- **2000 年代初美国大公司语境**：日程表、360 度、直线层级假设以线下科层组织为背景；对远程/混合、矩阵/项目制团队中"看日程表"与"看下属晋升"的替代证据未更新。
- **无心理测量与效度证据**：三维度判定与潜能分类都缺少预测效度检验，存在被用作标签化管理的风险（系列级批判明确要求防标签固化造成的歧视）。
- **组织因素的清单不完整**：只强调了薪酬与文化，对权力结构、历史包袱、市场周期等未展开；把复杂问题收敛为"层级/三维度"也是单因论倾向的一部分。

### 容易混淆的邻近方法论

- 与 `three-dimension-transition`（本册）：尺子 vs 流程。
- 与 `performance-gap-circle`（本册）：七项绩效内容缺口图 vs 通用诊断五步/四步。
- 与 `leadership-deficit-four-causes`（本册）：失败归因分类 vs 诊断操作。
- 与 `leadership-pipeline-six-passages`（本册）：层级语言 vs 诊断流程。
- 与 `talent-review-meeting-mrr`（册1）：评估会议机制（集体讨论） vs 个体/组织诊断方法。
