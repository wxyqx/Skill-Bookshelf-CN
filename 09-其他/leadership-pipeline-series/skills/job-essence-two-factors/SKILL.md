# 工作本质双因素判定：决策权＋障碍

## R — 原文 (Reading)

> "一项工作的真正本质是由以下两个因素决定的：任职者对该工作所做的决策和在该职位上所需要克服的阻碍。"
>
> — 斯蒂芬·德罗特，第1章（fulltext L3457）

> "你可以将自己的工作描述为'负责企业战略'，但是如果你不是那个最终决定企业该采取什么样的经营发展战略的人，那么你就只是企业的战略分析师、战略建议者或者战略研究者，而不是真正的企业战略家。真正的企业战略家要决定企业采取什么经营战略，并对该战略实施的后果负责。"
>
> — 斯蒂芬·德罗特，第1章（fulltext L3459）

> "一家规模较小、无人知晓、产品分销受限的企业，与一家拥有强大品牌和良好分销系统的企业，在投放新产品方面所面临的困难是完全不同的。这两家企业虽然都是向市场投放新产品，但是代表着两种全然不同的工作。"
>
> — 斯蒂芬·德罗特，第1章（fulltext L3461）

## I — 方法论骨架 (Interpretation)

岗位评估的常见做法是看头衔、看人数、看职责描述，作者说这些都不可靠。判断一份工作"真正是什么工作"，只看两个因素：

**因素一：决策权。** 最终由谁拍板、并对后果负责？负责战略的人如果不是决定战略的人，他就不是战略家，而是战略分析师。头衔里写着"负责X"，不等于"拥有X的决策权"。

**因素二：障碍。** 完成这项工作要克服什么阻碍？同样"向市场投放新产品"，有品牌和分销支持的企业是执行问题，白手起家的小企业是生存问题——两种工作的难度、所需能力、风险完全不同。

用法有三层：
1. **岗位对标**：两个都叫"区域总监"的岗位，若决策权与障碍不同，就不是同一种工作，薪酬差异有依据；反之，头衔不同而双因素相同，也可能是同一种工作。
2. **访谈追问**：用标准问题3A/3B/4问受访者"你做什么决策、要克服什么障碍"，并观察支持是"已建立"还是"还需要建立"。
3. **层级判定**：跨章节用同一判据区分七层级的"同名不同工"——例如真正的总经理与只负责成本或收入者，集团高管与事业部总经理。

判定的关键是"最终"与"后果"两个词：建议权不是决策权；过程困难不等于障碍不同。若双因素都相同，别被职级名头迷惑，那就是同一种工作。

## A1 — 书中的应用 (Past Application)

### 案例 1: "负责战略"的两种人（作者的判定示范）
- **问题**: 如何判断一个人是不是"真正的企业战略家"？很多人的工作描述里都写着"负责企业战略"。
- **方法论的使用**: 用决策权因素追问——他是不是那个最终决定企业采取什么经营战略的人，并对战略实施的后果负责？
- **结论**: 若不是最终拍板者，他只是战略分析师/建议者/研究者，而不是战略家；其建议虽重要，却不能决定企业发展方向。
- **结果**: 这一判定示范成为全书访谈提纲中问题3A/3B/4的设计依据（用于从访谈回答中识别真实工作）。

### 案例 2: 投放新品的两种企业（障碍因素示范）
- **问题**: 两家企业都"向市场投放新产品"，能否用同一标准判断这两份工作？
- **方法论的使用**: 用障碍因素对比——一家规模小、无人知晓、分销受限，必须自己克服主要困难（自建或购买支持体系）；另一家有强大品牌与良好分销系统，支持有迹可循。
- **结论**: 同一项任务的字面描述，代表两种全然不同的工作；观测要点是"哪些方面已经得到支持、哪些还没有；哪些方法已建立、哪些还需要建立"。
- **结果**: 该判据被固定进访谈工具（问题3A、3B、4），成为跨层级岗位分析的标准入口。

### 案例 3: 大型生活消费品公司访谈（决策与障碍答案反推岗位现实）
- **问题**: 公司刚完成大并购、正要推文化变革，想用访谈了解各层领导的真实工作。
- **方法论的使用**: 抽样访谈50位全球领导（每层7~10人），汇总"决策""障碍""需要更多权力"的回答。
- **结论**: 访谈发现出乎意料——无人提及文化变革是其工作（业绩、任务、决策、障碍）的一部分，无人提及做过创新；说明领导层实际的决策与障碍结构并未包含公司宣称的战略重点。
- **结果**: 公司把首要目的从"求得发展"改为"业绩实现"，把文化变革设为全球每位领导必须实现的可考核业务结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 两个头衔相同的岗位薪酬差一倍，员工来质疑公平性，需要给出有依据的解释。
2. 做职级体系/岗位价值评估，发现岗位名称五花八门，不知道如何归并对标。
3. 面试或岗位访谈中，候选人/任职者大谈"负责什么"，需要追问出"实际能决定什么、要克服什么"。
4. 讨论某人该不该提拔或平调：两个岗位看起来一样，实则需要的能力与风险不同。
5. 团队里有人名义上是负责人，实际无决策权、又背着与其它岗位相同的考核，用户想厘清这是不是"同一种工作"。

### 语言信号 (用户的话里出现这些就应激活)

- "这两个岗位都叫XX，能算同一级吗？" / "are these the same job?"
- "岗位本质是什么？" / "what is the essence of this job?"
- "决策权/拍板权在谁手里" / "decision rights / who decides?"
- "他要克服什么障碍、有多少支持？" / "obstacles, barriers, support"
- "职级对标、岗位价值评估" / "job leveling, job evaluation"

### 与相邻 skill 的区分

- 与 `performance-pipeline-interview-build` 的区别: 本 skill 是那套建队访谈里的一个判据（问题3A/3B/4 的分析工具）；若用户要搭建整套各层级标准，用建队流程，本判据作为其步骤3的输入。
- 与 `leadership-pipeline-six-passages`（b5-f01）及三维度转型（b5-f02）的区别: 那些回答"人在哪个发展阶段的转型"，本 skill 回答"这份工作本身是什么"，对象是岗位不是人。
- 与 `role-clarity-gaps-overlaps`（b5-f21）的区别: 后者找职责的空当与重叠（组织设计问题）；本 skill 判岗位本质是否相同（工作定义问题）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **写出两个岗位的"字面描述"**
   - 各用一两句话写出头衔、职责描述、汇报关系、团队规模。
   - 完成标准: 两份描述并列可见；若描述完全相同，直接进入步骤4比对。

2. **判定决策权**
   - 逐项追问：最终拍板的是什么决策？对后果负责吗？是建议、分析、执行还是决定？列出其"拥有"的决策清单。
   - 完成标准: 每个岗位得到一份决策清单（含"无最终决策权"的明确标注）。
   - 判停条件: 若决策清单完全相同且风险一致，跳到步骤4；若发现名义负责人无决策权，标记为"同名不同工"候选。

3. **判定障碍**
   - 逐项追问：要克服哪些阻碍（资源、品牌、渠道、人才、审批、竞争）？哪些支持已建立、哪些还需自建？障碍的难度与不可控性如何？
   - 完成标准: 每个岗位得到一份障碍清单，并区分"已有支持"与"需自己建立"。

4. **比对与结论**
   - 因素齐备则同一工作；任一因素不同则不是同一工作。给出结论与依据（引用决策清单与障碍清单的具体条目），并可据此解释薪酬/职级差异。
   - 完成标准: 一句话结论＋两条依据；若不同工，进一步给出合理的差异幅度逻辑（不替客户定具体薪酬数字）。

5. **形式化到工具**
   - 若用于访谈/招聘，把决策与障碍转成标准追问（问题3A/3B/4式）；若用于岗位分析，把两个清单写入岗位档案。
   - 完成标准: 追问清单或岗位档案片段产出，可被他人复用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用它替代正式的薪酬与职级制度：双因素只回答"是否同一种工作"，不给出具体薪酬数字，也不处理市场对标与预算约束。
- 只凭一次谈话就下判定：决策权与障碍需要多来源证据（任职者、上司、同事、下属），单一来源常高估或低估。
- 用它给个人贴标签（"这人格局只配当前岗位"）：本判据的对象是岗位，不是人。
- 组织正在改组、决策权尚未划定：此时双因素会随组织图变动，先等结构稳定。
- 涉及劳动关系争议的岗位调整：须依当地劳动法与公司程序，本 skill 不构成法律意见。

### 作者在书中警告的失败模式

- **层级错位（b2-ce01）**：升了职、待遇提高，但没做新的工作——"他们也会交付结果，但是他们所交付的结果却不是他们应该交付的"。凡是"头衔升级而决策权与障碍未变"的岗位，都是错位的温床。
- **选错人（b2-ce02）**：按资历、忠诚或政治权宜选人，而非按工作能力与岗位要求匹配；这与不辨岗位本质同源——岗位没定义清楚，选人就只能凭感觉。
- **组织设计不佳（b2-ce07）**：岗位角色定义不清、授权不足时，领导者会退向微观管理与委员会化；此时必须先修组织设计，再谈双因素判定。

### 作者的盲点 / 时代局限

- **岗位价值的政治现实**：作者把双因素说得像技术判断，但实际职级与薪酬决定往往牵涉谈判、历史遗留与组织政治；书中未处理利益相关方博弈。
- **未给量化规则**：两个因素不同到什么程度才该差多少薪酬，书中只有原则与案例，没有可审计的评分表；实践中需结合公司职级制度。
- **美国大公司原型**：判据源自GE式多层级公司；在扁平化平台组织里，"决策权"可能分散在团队与算法系统中，双因素需重新解释。
- **未验证的效度**：作为咨询工具的判定一致性没有对照研究；两名评估者可能得出不同结论（书中未讨论评估者信度）。

### 容易混淆的邻近方法论

- 与 `performance-pipeline-interview-build`（b2-f03）：那是母流程，本 skill 是其中一步的分析判据；别把子工具当完整方案交付。
- 与 `role-clarity-gaps-overlaps`（b5-f21）：空当/重叠是组织设计问题，不是岗位本质问题；两者可先后使用。
- 与 `talent-review-meeting-mrr`（b1-f12）：那是评人会议机制；本 skill 是评岗位。
