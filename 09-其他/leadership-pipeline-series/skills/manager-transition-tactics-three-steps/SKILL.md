# 疏通梯队三步战术：准备 — 监督 — 干预

## R — 原文 (Reading)

> "方法一，准备：让初任经理清楚地知道新岗位的要求，包括领导技能、时间管理能力和工作理念，并为他们实现转型提供必要的培训。"
>
> "方法二，监督：确认初任经理在转型中是否遇到了困难，困难是什么。" "方法三，干预：定期提供反馈和教练辅导，帮助初任经理实现转型。"
>
> — 第2章「疏通梯队战术」（fulltext L10087、L10103、L10113）

> "工作调整　一些初任经理还没有为新岗位做好准备，他们需要重返员工岗位继续锻炼和准备。另外一些从本质上不具备领导潜质，不适合担任领导工作，应该被安排在能够发挥他们才能的专业岗位上（如从销售员到超级销售员）。"
>
> — 第2章 方法三·干预（fulltext L10123）

> "·至少每年调整一次一线经理的队伍，这是继任计划的必需要求。……在一线经理岗位上工作6~12个月仍然不能胜任者，必须做出调整，目标是精干高效，一部分经理将在未来获得提拔，另一部分经理将在这个层级有效地工作很长一段时间。"
>
> — 第2章 一线观察（fulltext L10188）

---

## I — 方法论骨架 (Interpretation)

这条方法论回答一个常见的管理不作为："新人没转过来，等他自己悟还是我出手？"作者的立场非常明确——**转型的第一责任人是上司**，而不是人力资源部的培训项目；上司必须把这当成一套有步骤的战术来执行：

1. **准备（上任前/上任初）**：让初任经理清楚知道新岗位的要求**具体**是什么——不是泛泛的"要多沟通"，而是按领导技能、时间管理、工作理念三个维度讲清；配套培训、树立学习榜样、上司亲自答疑。这一步"比较容易，也经常被忽略"。
2. **监督（上任后持续）**：用三种方法核实转型状态——①观察与旁听（听他主持会议、看他的日程）；②360 度评估/抽样调查（横向纵向收集反馈）；③差距分析（把他的自我认知与外部观察、抽样结果做比较，让他自己看到差距）。监督的对象是**证据**，不是态度。
3. **干预（发现困难时）**：一对一教练辅导与反馈（不可替代，且要把能力提升写进绩效考核）；向同事学习、增强合作；会议、读书和旅行（与上司出差以获得办公室外的宽松沟通）；**工作调整**——这是最容易被忽视的选项：还没准备好的可以重返员工岗继续锻炼，本质上不适合领导工作的转入专业轨道（如从销售员到"超级销售员"）。
4. **两条配套纪律**：①提拔前评估意愿——先看此人是否愿意放弃部分专业技术工作、是否愿意为别人的成功负责（可先用组长/项目经理岗位考察）；②一线经理队伍至少每年盘点一次，6~12 个月仍不能胜任者必须调整，目标是"精干高效"——有人会被提拔，有人会长期在这个层级有效工作。
5. **顺序提示**：作者强调技能先行的现实路径——初任经理先实践并完善领导技能，才会愿意重新分配时间、才会认识到理念转变的重要性；因此干预通常从技能训练与反馈入手，但理念转变才是最终关。

## A1 — 书中的应用 (Past Application)

### 案例 1: 玛丽——干预成功的标杆（360 度反馈 + 持续教练）
- **问题**: 程序员玛丽升任研发小组经理后，在压力下命令式管理、想亲自写程序，削弱了下属积极性，系统交付失败、漏洞百出——正是"监督"应当发现的转型困难。
- **方法论的使用**: 公司**准备**在前（为新任经理办培训，教会她设计和分配工作、招聘面试）；随后**监督**介入——上司持续教练辅导并引入 360 度评估；当听到"管得太细、不善于分配工作"的反馈时，玛丽非常震惊；**干预**继续数月，帮她把授权练出来。
- **结论**: 转型"并非易事但可以做到"；她最终从帮助下属成功中获得与做技术同样的满足感。
- **结果**: 玛丽学会有效授权，成为书中第一阶段成功转型的示范（b5-c17；L10072–L10076）。

### 案例 2: 巴里——干预缺位，两年后流失
- **问题**: 巴里升任八人销售团队经理后不适应大量观察、招聘、培训、写报告的工作，失去签单的心理满足感，"当他们渴望得到指导时，巴里并没有给予他们有力的支持"。
- **方法论的使用**: 作者复盘时指出这套战术**全部缺位**——公司"没有合适的评估机制来确定巴里的工作理念是什么"（监督缺位），也没有及时的教练辅导（干预缺位）；若做了正确评估，"巴里就可能步入'超级销售员'的发展轨道，或者专门为他设计一个培养方案"（工作调整这一选项未被使用）。
- **结论**: 在巴里的管理层级上遇到的领导力问题"是可以防止和解决的"——他的失败不是缺潜力，而是缺机制。
- **结果**: 巴里在销售经理岗位苦苦挣扎两年，其下属也一起挣扎，最终他辞去管理职务、到另一家公司担任销售代表（b5-c16；L10066–L10070）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户**刚提拔了一个一线经理**，想知道除了发任命通知之外自己还该做什么（准备期）；或正在考虑"先给个组长/项目经理岗位试试"。
2. 用户观察到新经理**上手三四个月仍在做原来的业务**，在"等他自己悟"和"出手干预"之间犹豫。
3. 用户在做**新经理的 360 度反馈/季度复盘**，需要一个核实转型状态的取证方法（观察旁听、抽样、差距分析）。
4. 用户面对一个**明显不适合管理岗的人**，想知道除了解雇还有什么选项（重返员工岗、转专家/超级销售员轨道）。
5. 用户在设计**一线经理队伍的年度盘点与继任流程**，需要"至少每年盘点、6~12 个月不合格必须调整"的节奏依据。

### 语言信号 (用户的话里出现这些就应激活)

- "新提拔的经理 / 上任三个月 / 新人带教 / onboarding / 我该等他自己悟还是出手"
- "360 度反馈 / 观察旁听 / 抽样 / 差距分析 / 怎么核实他转没转"
- "要不要把他调回去 / 他是不是不适合做管理 / 能不能转专家岗 / 超级销售员"
- "一线经理盘点 / 每年盘一次 / 6~12 个月 / 该不该换人"
- "他看起来准备得很充分 / 但好像哪里不对"

### 与相邻 skill 的区分

- 与 `first-manager-three-transitions`（本册）：那条是**新任经理自己**对照的三项工作（界定工作/提高胜任/建关系），本条是**上司**执行的准备—监督—干预流程；一体两面，可组合但不要互相替代。
- 与 `three-dimension-transition`（本册）：本条的"准备"讲三维度要求、"监督"以三维度为核查清单；缺的是完整流程骨架与上司责任划分。
- 与 `coaching-two-tracks`（册3）/ `deliberate-practice-feedback-loop`（册4）：那两条是更细的教练/反馈技术；本条的"干预"是流程中的一环。
- 与 `assessment-dual-track`（册4）：评估双轨用于区分管理与技术路径；本条的工作调整（重返员工岗/专家轨道）是同一逻辑在初任经理层的落地。
- 与 `talent-review-meeting-mrr`（册1）：那条是评估会议机制；本条的年度盘点指一线经理队伍，粒度更小。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先做"准备"：把要求具体化并讲清**
   - 与新任经理逐条对齐该岗位在领导技能/时间管理/工作理念上的**具体**要求；配必要的培训（招聘、授权、团队建设、工作设计）；指定学习榜样与答疑安排。
   - 完成标准: 有一份书面的三维度要求清单，且当事人能复述自己需要放弃什么、新的成功标准是什么。
   - 判停条件: 若此人尚未任命，先做提拔前意愿评估（是否愿意放弃部分专业工作、是否愿为他人成功负责）——这一步没过，不要靠任命后再补。

2. **建立"监督"：三种取证方法固定下来**
   - 固定节奏：观察与旁听（会议、一对一）；360 度/抽样调查（下属、同级、相关部门）；差距分析（把本人自评与外部证据对照，并把差距当面反馈给他）。
   - 完成标准: 三项证据在任命后 6~12 个月内至少各完成一轮；每轮形成"已达成/未达成"的书面记录。

3. **判停：区分程度，选对干预层级**
   - 判停条件: 若差距集中在技能与时间（愿意学、行为在改善），走第 4 步的常规干预；若理念始终未动、且 6~12 个月仍不能胜任，跳到第 5 步的工作调整。
   - 完成标准: 给出"常规干预 or 工作调整"的判断及依据。

4. **常规"干预"：四类方法组合使用**
   - ①上司一对一教练辅导与反馈（不可替代），并把能力提升写入绩效考核；②向同事学习、增强合作，向标杆学习；③会议（谈上任以来学到什么）、读书、与上司一起出差；④按需做技能强化（先练技能，让时间与理念随之调整）。
   - 完成标准: 每项干预有责任人与时间表；下一轮监督中能看到行为变化。

5. **工作调整：为不合适的人保留体面的出口**
   - 未准备好的 → 重返员工岗继续锻炼；本质不适合领导工作的 → 转入专业轨道（如超级销售员）；同时更新一线经理队伍年度盘点结论（提拔/留任/调整）。
   - 完成标准: 调整方案有依据（监督记录）、有过渡安排；涉及调岗/职级/薪酬变更须依当地劳动法与公司程序，提供尊重程序与合理过渡期。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **把"干预"当成淘汰工具**：四类干预里前三类（教练、同事学习、会议读书出差）是主路径，工作调整只针对"未准备好"与"本质不适合"，且需以监督记录为依据；涉及调岗/解除须依当地劳动法与公司程序，并提供改进机会与尊重程序（系列级伦理边界）。
- **跳过准备直接监督/干预**：作者说准备"比较容易，也经常被忽略"；没有讲清要求就去考核转型，是制造不公。
- **只批评不配套**：干预不是谈话，要含教练、资源、时间与管理权限的调整；只讲"你要转变"无效。
- **用于其他层级**：准备—监督—干预是初任经理层的战术；更高层级的转型需要各自的岗位标准与教练方式（参见部门总监、职能主管各条）。
- **等待"自然成熟"**：作者立场是转型第一责任人是上司；"等他自己悟"等于放弃职责。

### 作者在书中警告的失败模式

- **放任自流式放权（b1-ce03）**：把"不做微观管理"错用成"不参与"；项目启动后领导者再不出现，只有年度评估没有阶段检查，出问题归咎于"下属不行"。
- **一线经理的三个显著失败迹象（b5-ce03）**：把下属提出的问题看成障碍；补救下属失误而非教会他正确做法；拒绝分享成功。这三条正是监督应捕捉的信号。
- **头衔化（b5-ce05）**：管理职务被当作"对高绩效个人贡献者的回报"，"如果管理职务代表的是地位而不是一系列的管理工作要求，公司的管理就变得'形同儿戏'"。
- **对部门总监要求不够（b5-ce08）**：公司用低于岗位标准的任务"喂养"下级层级，会导致其管理深度不足、下一层继任出现鸿沟——同一机制也适用于一线经理层。

### 作者的盲点 / 时代局限

- **依赖上司的意愿与能力**："第一责任人是上司"在管理幅度过大、上司自身也在错位的组织里难以落地；书中未讨论当上司缺位时 HR 与更上级该如何补位。
- **"6~12 个月必须调整"过于刚性**：未区分行业学习曲线、岗位复杂度与个体起点差异；也可能与劳动法关于试用期与解雇的程序要求冲突（须本地化）。
- **2000 年代初美国大公司语境**：360 度、观察旁听等方法以线下同地办公为前提；远程/异步组织的取证方式未更新。
- **缺少对照组**：玛丽与巴里的对比是作者自选案例，"干预有效"缺乏失败干预的样本。
- **工作调整的公平性与尊严问题**：作者强调"重返员工岗或转专家轨道"，但对当事人的职业预期、薪酬身份落差与心理影响未充分讨论。

### 容易混淆的邻近方法论

- 与 `first-manager-three-transitions`（本册）：上司流程 vs 经理自查清单。
- 与 `three-dimension-transition`（本册）：流程骨架 vs 三维度取证量表。
- 与 `coaching-two-tracks`（册3）/ `deliberate-practice-feedback-loop`（册4）：干预中的教练技术细节。
- 与 `assessment-dual-track`（册4）/ `dual-track-management-technical`（本册）：工作调整/双轨的机制面。
- 与 `talent-review-meeting-mrr`（册1）：人才评估会议 vs 单个新任经理的带教流程。
