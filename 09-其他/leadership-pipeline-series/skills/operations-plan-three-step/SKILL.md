# 运营实施流程三步法与预算从属

## R — 原文 (Reading)

> "这项工作共分三步，第一步就是确定目标。第二步是制定行动计划，其中包括在短期任务和长期目标之间把握好平衡。我们还要确定出那些人们能够制定出应急方案的领域。第三步我们将和所有的与会人员一起就会议讨论结果达成共识，并建立详细的跟进措施以确保每个人都能完成自己的任务。"
>
> — 博西迪/查兰/伯克，第9章（L2642）

> "这些运营计划通常是建立在一个事先已经准备好的预算方案上的，但真正理想的方式应该是反向的：具体的预算应该根据企业的运营计划来确定，而不是反之。"
>
> — 同上，第9章（L2498）

> "所谓"由外到内"是指，这些数字必须反映公司所面临的经济和竞争环境，它们所传达的信息必须使投资者相信：购买这家公司的股票是值得的。所谓"从上到下"是指，在确定目标的时候应该采取先整体后局部的顺序"
>
> — 同上，第9章（L2644）

## I — 方法论骨架 (Interpretation)

运营流程是把战略与人员接起来的最后一环，它的核心是"顺序"与"参与"：

1. **诊断：传统预算的三大缺点**——不针对计划的前提条件公开讨论；围绕高层希望得到的结果，却不讨论实现结果所需的执行方案；领导者没有机会做指导、无法建立协作。结果是预算变成数字练习：目标高于能力就压、低于能力就藏，季度末靠压货凑数。
2. **顺序反转**：预算由运营计划推导，而不是计划建立在预算上；先把前提、目标、行动计划谈清，数字自然得出。
3. **三步法**：①定目标（收入、现金流、生产力、市场份额等，用一页纸按"由外到内、由上到下"总结）；②制定行动计划（平衡短期任务与长期目标，确定需要应急方案的领域）；③与所有与会者达成共识，并建立详细的跟进措施，确保人人完成任务。
4. **同步协调**：所有变动环节对外部环境持有相同假设（"左手知道右手在干些什么"）；三天同步预算的做法是——同场对话、把信息输入统一表格、四轮修改定案。
5. **两条硬纪律**：执行者参与目标制定并与回报挂钩；"如果没有精力对某个项目进行彻底跟进，千万不要批准这个项目"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 通用汽车——"9·11"后快速重排运营计划抢占份额
- **问题**: "9·11"后美国汽车需求骤降，但几天内影响就开始消退；美联储降息至 40 年最低点，消费者手中现金增加，需求从 1600 万辆飙升到 2100 万辆。
- **方法论的使用**: 负责北美业务的副总裁唐·扎里拉意识到财务将受重大影响，据此调整需求预测；随后公司制定新的运营计划，对资源重新分配并协调各环节：生产多少辆什么车、在哪些工厂生产、哪些地区需要什么产品结构、广告投入多少、投向哪里。
- **结论**: 各环节必须共享同一假设并同步调整——若生产与广告部门没有协调一致，就会在销量下降的同时抬高生产成本。
- **结果**: 在其他制造商仓促联合时，通用汽车凭快速反应重新占领巨大份额；成本削减提高了生产力，重振了市场份额——这是"非临时性应急，而是抓住机遇一举扭转 30 年份额下滑"的判断。

### 案例 2: 100 亿美元公司——只看收入、忽略毛利的计划修正
- **问题**: 一家 100 亿美元公司的 CEO 依据财务预测（2002 年收入将下降 10 亿美元）制定运营计划，却忽略了毛利。
- **方法论的使用**: 一位好友指出：由于行业价格压力，公司毛利率将从 25 个百分点下降到 20 个百分点——毛利下降幅度甚至大于收入下降幅度；建议重做计划，考虑成本生产力改进、把总部人员削减为原来一半、把管理团队削减一层。
- **结论**: "太多的领导者在谋求增加收入的同时没有注意到提高或保护自己公司的毛利，而毛利实际上正是公司所有开支的基础。"
- **结果**: CEO 接受建议，一周之内修改了计划。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要主持明年的预算会，担心又变成"分数字、谈条件"。
2. 用户发现战略与预算两张皮：战略会讲方向，预算会分资源，没人把它们接起来。
3. 用户需要把年度目标分解成可执行的行动计划，并让执行者真正承诺。
4. 用户在复盘"计划定了但没人执行"，想建立共识与跟进机制。
5. 组织遭遇外部变化（汇率、需求、政策），需要重新排运营计划并协调各环节。

### 语言信号 (用户的话里出现这些信号就应激活)

- "预算会怎么开才有用？"
- "预算就是分钱 / 计划跟预算两张皮。"
- "年度计划定了没人执行。"
- "budget season" / "annual operating plan" / "how do I make the budget meaningful"

### 与相邻 skill 的区分

- 与 `b1-f22 assumptions-and-contingency` 的区别: 后者专门处理前提假设的显性化与应急方案；本 skill 是运营计划的整体三步流程，其中第一步即调用前提讨论。
- 与 `b3-f07 priority-focus-three-to-four` 的区别: 优先事项聚焦讲"目标不超过三四个、反复强调"；本 skill 讲"计划如何生成、预算如何从属、共识与跟进如何建立"。
- 与 `b2-f22 performance-dialogue-evidence` 的区别: 后者是业绩结果的月度检验对话；本 skill 是计划制定阶段的流程与顺序。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先谈前提，不谈数字**
   - 完成标准: 公开列出影响计划的前提（不超过六个），逐条取证并达成共识——数字在此之前不进入讨论。
   - 判停条件: 若无人能说明关键前提，转 `b1-f22` 专门处理。

2. **确定目标（由外到内、由上到下）**
   - 完成标准: 收入、现金流、生产力、市场份额等目标用一页纸总结；数字反映外部经济与竞争环境（由外到内），先整体后局部（由上到下），且执行者参与制定。
   - 判停条件: 若目标由上层单方下达、执行者不认同，停止推进——"不切实际的目标，或者是没有征得实施者认同的目标，却只会把公司引向更糟糕的局面"。

3. **制定行动计划并做平衡检查**
   - 完成标准: 每项目标都有对应行动方案与阶段里程碑；显式检查短期任务与长期目标的平衡（书中示范：先亏三年的"曲棍球棒"计划被退回，团队随后找出"出售非核心部门降本 10%＋四五项措施"的新方案）；标出需要应急方案的领域。

4. **关注毛利与成本结构，而不只是收入**
   - 完成标准: 单独列出毛利变化及其驱动因素（价格压力、成本结构），并给出保护毛利的措施。

5. **达成共识并建立跟进**
   - 完成标准: 与会者当场确认目标与行动方案；每项任务写明六要素——目标、责任人、时限、完成方式、所需资源、下次检查的时间与方式。
   - 判停条件: 若没有精力彻底跟进某个项目，不批准该项目。

6. **预算从运营计划推导**
   - 完成标准: 预算数字逐项对得上运营计划的行动与前提；如使用同步预算方式，召集相关部门同场对话并把信息输入统一表格，多轮（约四轮）修改后当场定案。

7. **季度评估与"现在就行动"**
   - 完成标准: 每季度核对计划执行；遇到"希望下季度会好转"的说法，要求以现实为基础立即行动（参见 `b1-p08`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 现金流告急的应急周：此时先做止血决策，之后再按本流程重排计划。
- 人数很少、没有正式预算体系的团队：可直接用"前提—目标—行动—跟进"的轻量版，不必强推三天同步预算。
- 把本流程当作财务部门的作业：作者强调任何流程的实践者都包括执行者本人，财务不能替代。

### 作者在书中警告的失败模式

- **预算数字游戏与"从未来借债"**: 预算成为讨价还价的数字练习，季度末把库存推入销售渠道换取当期数字，损失留给下个季度；警告信号包括季度末异常促销、应收账款增速远超收入、预算会上只谈数字不谈方案（b1-ce16）。
- **风险提示（来自 b1-ce16，伦理/法律红线）**: 朗讯案中"如果产品卖不出去，我们可以收回所有积压库存"的承诺已接近渠道压货欺诈，与证券信息披露违规只有一步之遥；任何"以回购承诺换取销售收入"的做法都应视为红线。本 skill 不得提供任何形式的数字操纵建议。
- **目标不现实或未获实施者认同**: 上层单方下达高目标、靠电话追责数字，最终计划全面落空（b1-ce13）。
- **目标脱离执行能力（未做组织能力评估）**: 制定计划时假设自己拥有其实不具备的人才、流程与文化，进入执行阶段才发现处处缺人缺能力（b1-ce17）。

### 作者的盲点 / 时代局限

- **季度资本主义底色**: 本书写作于"以季度为单位评价执行业绩"最盛的时期，部分案例（如高露洁的季度增长记录）把季度节奏当作正面实务；在长周期研发与平台型业务中，这种节奏可能扭曲资源配置（BOOK_OVERVIEW 批判节）。
- **三天同步预算依赖成熟条件**: 需要高度坦诚的对话文化、实时的数据系统与在场的决策权；在信息不透明或矩阵复杂的组织里，压缩到三天可能只带来表面共识。
- **"预算服从计划"需要治理层支持**: 若董事会与资本市场仍以预算数字考核，流程反转在单个部门内很难坚持。

### 容易混淆的邻近方法论

- 与"零基预算"的区别: 零基预算解决"每笔支出是否必要"；本 skill 解决"计划与预算谁主导、谁来参与、如何跟进"。
- 与"滚动预测"的区别: 滚动预测是数字更新机制；本 skill 要求先有共享假设与行动计划，预测才有意义。
