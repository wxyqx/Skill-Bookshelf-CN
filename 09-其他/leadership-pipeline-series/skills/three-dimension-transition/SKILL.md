# 阶段转型三维度：技能 / 时间 / 理念

## R — 原文 (Reading)

> "每个阶段都要求领导者习得一种新的管理和领导方法，同时抛弃原有的方法。这主要表现在以下三个方面：◆ 领导技能——胜任新职务所需要的新能力。◆ 时间管理——新的时间分配结构，决定如何工作。◆ 工作理念——信念和价值观非常重要，让工作聚焦。"
>
> — 导论「领导梯队的各个阶段」（fulltext L9675–L9681）

> "许多经理都在错误的领导层级上工作，例如，他们在第二阶段（管理他人）工作，但还保留着第一阶段（管理自我）的工作理念，或是并不具备目前领导层级所需的领导技能或时间管理能力。这不仅导致身为领导者的他们绩效不高（或者干脆就是毫无绩效），同时他们所管理的员工也会受到负面影响。"
>
> — 导论（fulltext L9683）

> "要记住如果人们树立了正确的工作理念，他们自然就会有正确的时间管理能力和领导技能。"
>
> — 第8章 领导梯队诊断（fulltext L11456）

---

## I — 方法论骨架 (Interpretation)

这条方法论解决的是"升职了，但人没换"的测量问题。它把"一个新层级到底要求什么"拆成三件必须同步改变的东西，然后逐件取证：

1. **领导技能**：新岗位需要的新能力（如一线经理的工作设计、授权、教练；集团高管的资金调拨评估）。它不是通用素质清单，而是**该层级特有的**新能力——脱离层级谈领导技能就会退回作者反对的"一刀切"。
2. **时间管理**：不是效率技巧，而是**角色定义本身**。你实际把时间给了什么，你就是什么层级的领导者；日程表是最硬的证据——看他每天做的第一件事、会见的第一个人。集团高管基准：≥50% 育人、≥25% 战略与组合、10%–20% 公司事务——时间结构即角色。
3. **工作理念**：关于"什么工作最重要、什么值得投入、什么该放弃"的信念（岗位是经理、思维却是业务员，就是理念滞后）。它最难评估，却是另外两项能否持久的前提；反过来，理念一变，时间和技能通常会随之调整。
4. **三者必须同步**：任何一项滞后 = 在错误的层级工作，会同时拖累本人绩效与其下属。
5. **理念的证据通道（不可信口头宣布）**：①他是否从教训中学习、是否接受并采纳他人的意见（教训讨论）；②日程表（时间流向哪里）；③他如何评价下属（是否按下属层级要求评价发展他们）；④他站在某种理念立场提交的计划——计划中最详细、最占篇幅的部分就是理念线索。风格上的短暂调整不等于理念转变。
6. **用法**：拿它当"转型体检表"，先分开量三件事，再决定干预点（几乎总是从理念开始），而不是一上来就送培训。

## A1 — 书中的应用 (Past Application)

### 案例 1: 蒂娜——技能已具备，问题在理念
- **问题**: 蒂娜从销售职能主管升任中等规模业务的事业部总经理后，仍用销售职能的战术思维：贸然上项目、不问"该不该做"、不在赢利与长期议题上发言。表面看是"做事方式不对"，且她并不缺技能。
- **方法论的使用**: 上司不指出她"错了什么"，而是讲解**职能主管与事业部总经理的工作理念差别**及其他层级差异，让三把尺子分开摆——她的领导技能大多已具备，缺的是与岗位相配的工作理念。
- **结论**: "蒂娜就意识到，自己虽然具备了事业部总经理所需要的许多领导技能，但却缺乏适当的工作理念。一旦她意识到她的问题来自于自己的职能性理念，她就会愿意根据自己的新职务重新去评价那些工作理念。"
- **结果**: 她有意识地按新层级理念改变工作方式——成为"理念是转型枢纽"的示范案例（b5-c21）。

### 案例 2: 玛丽和查理——用三维度看，两人都没在履行本位职责
- **问题**: 招聘经理玛丽在危机中被上司（部门总监查理）要求"亲自参与"招聘；查理则接手玛丽本该做的资源重配工作。任务完成、两人都拿了业绩奖金，查理还推荐玛丽做自己的继任者。
- **方法论的使用**: 逐人过三维度——玛丽（应为一线经理层级）把时间全部收回专业工作、放弃了管理性工作；查理（应为部门总监层级）替下属做了一线任务。产出多不等于做对事，两人的时间与职责都错位。
- **结论**: 错位会被"完成任务的方式"制度化；当薪酬制度奖励了错误行为时，**不要过早对个人下结论**——乔治（作者）指出"薪酬制度不符合领导力发展的需要"（L11435），诊断应先于奖惩判断。
- **结果**: 作者用这个元案例说明：只有把技能/时间/理念三把尺子分开量，才能看清"奖金发对了、梯队却堵住了"的真相（b5-c15）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户看到一个**新晋升者仍大量从事旧工作**（技术大牛继续写代码、销售冠军继续签单），想弄清"卡在哪一环"。
2. 用户要**判断培训为什么无效**："技能课也上了、时间也给了，为什么行为没变"——需要先分清是技能问题、时间结构问题还是理念问题。
3. 用户要为**某个层级写转型说明/培养计划**，需要一份可观察、可取证的要求清单。
4. 用户在做**述职/一对一反馈**，想对下属说清"你现在这个位置要求什么变了"，而不是泛泛谈态度。
5. 用户怀疑**某人的理念没转**（口头接受新角色、行为照旧），需要取证方法而不是直觉。

### 语言信号 (用户的话里出现这些就应激活)

- "三维度 / 三个转型 / three dimensions / the passage"
- "他升职了还在做原来的活 / 还在写代码 / 还在签单 / still doing the old job"
- "日程表 / 时间都花在哪 / 每天第一件事是什么 / time application"
- "观念没转过来 / 理念没变 / work values / 心态还是业务员"
- "培训也上了但没效果 / 道理他都懂，就是不做"

### 与相邻 skill 的区分

- 与 `leadership-pipeline-six-passages`（本册）：先定位层级（哪一层），再用本 skill 体检三维度（缺什么）；两条常前后连用。
- 与 `diagnosis-five-steps`（本册）：本 skill 是"尺子"，那条是"流程"（观察→谈话→日程表→对应层级→判差距→以理念为中心的培训计划）；要做完整诊断时用对方。
- 与 `mealer-transition-six-steps`（册2）：那条处理转型的**过程与顺序**（意义→动力→行动→学习→根植→再振作），本 skill 处理转型的**内容与证据**。
- 与 `coaching-two-tracks`（册3）/ `deliberate-practice-feedback-loop`（册4）：那两条是干预/培养手段；本 skill 是诊断工具。
- 与 `performance-gap-circle`（本册）：那条画"七项绩效内容"的缺口图，本 skill 查"三维度"的转型状态，两者互补但不可互换。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写下新层级的三件要求**
   - 用一句话分别写清：新岗位需要的**新技能**、新的**时间分配结构**、要放弃什么与新的成功标准（理念）。
   - 完成标准: 三行俱全且具体到该层级（不是"多沟通"这类通稿）。

2. **先取证时间（最硬的一手证据）**
   - 让其列出典型一周日程或拿出日历：每天第一件事、会见的第一批人、时间占比最高的三类活动。
   - 完成标准: 能算出"管理性/新层级核心活动"的时间占比；与目标岗位基准对比。
   - 判停条件: 若时间结构已达标但行为仍旧，跳到第 4 步（查理念），不要停在"时间管理"。

3. **再取证技能（可测）**
   - 对照该层级技能清单逐项核验（如一线经理：工作设计、授权、反馈、教练、绩效评估），指出会/不会、熟练/生疏。
   - 完成标准: 每项技能有明显证据（做过什么、结果如何），不以自评代替。

4. **用四条通道取证理念（最难、最关键）**
   - ①最近一次教训/反对意见如何回应；②日程表；③如何评价与发展下属；④其提交的计划——最详细部分与立场。
   - 完成标准: 至少两条通道出具一致证据；口头宣布不计分。

5. **排优先级并出干预动作**
   - 理念缺口 → 用层级差别讲解+教练对话（参照蒂娜案例），而非技能课；技能缺口 → 培训+实践+反馈；时间缺口 → 用日程重排并设边界。
   - 完成标准: 每个缺口配 1 个动作、时间点、验收方式；结论仅作为发展对话输入，不直接用于人事处置。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **据此给个人贴"错层"标签或直接处置**："诊断结论仅作为发展对话的输入；不得据此单方面给员工贴错层标签，处置前应排除组织因素"（b5-ce01 ethics_legal_note）；涉及调岗/解雇须依当地劳动法与公司程序。
- **把时间管理当效率问题**：日程表在这里是**角色证据**，不是时间管理技巧；开"提高效率"的处方会漏掉真正的角色错位。
- **只查个人、不查组织**：薪酬、职责、资源、上司是否到位会系统性影响三维度表现（玛丽与查理案例）。
- **缺证据就下结论**：理念评估"要困难得多"，"有些人表现出好像正在按新岗位要求做出调整，但实际上仍然固守着其作为个人贡献者时的工作理念"——证据不足时应延长观察。
- **把"理念"变成口号合格性检查**：它看的是行为与时间，不是表忠心的表态。

### 作者在书中警告的失败模式

- **用旧阶段的方式干新阶段的事（b5-ce01）**：日程表被旧层级事务占满（技术工作、救火、签单）；反复讲"我们过去一直都能解决这一问题"；提拔后一年仍未完成新层级的关键动作（如没做过一次像样的教练对话）。
- **不重视新工作、固守旧成功的奖励记忆（b2-ce11）**：日程表仍以亲自交付为主、辅导反馈被排到最后、对处理低绩效者一拖再拖。
- **组织默认的晋升假设（b5-ce35）**：把"本岗位高绩效"等同于"下一岗位胜任力"，忽略三层级要求不同（技能/时间/理念）——这正是本 skill 要反制的心智模型。
- **头衔化（b5-ce05）**：经理越来越多、直接下属越来越少，管理"形同儿戏"——头衔与真实职责脱钩时，三维度无从谈起。

### 作者的盲点 / 时代局限

- **"理念可以被训练"未获心理测量支持**：作者反复主张理念转变是最关键的第一步，但除四条行为证据外缺少可操作的心理测量，其因果方向也可能倒置（失败后回退到熟悉行为，被误读为"未转型导致失败"）。
- **"理念先于技能"是断言而非验证**：书中未给出反例（技能先行带动理念转变）的讨论。
- **2000 年代初美国大公司语境**：三维度以科层制、终身雇佣式的层级历练为背景；对知识工作者、远程/混合办公下"时间分配"的可观察性（日程表是否还能作为硬证据）未作更新。
- **"时间管理=新时间分配结构"对扁平/矩阵组织适用性未讨论**：在项目制组织中，同一人可能同时横跨多层角色。

### 容易混淆的邻近方法论

- 与 `leadership-pipeline-six-passages`（本册）：定位 vs 体检。
- 与 `diagnosis-five-steps`（本册）：内容清单 vs 操作流程。
- 与 `performance-gap-circle`（本册）：七项绩效缺口 vs 三维度转型缺口。
- 与 `mealer-transition-six-steps`（册2）：转型的顺序过程 vs 转型的内容与证据。
- 与 `deliberate-practice-feedback-loop`（册4）：练习与反馈机制 ≠ 转型诊断。
