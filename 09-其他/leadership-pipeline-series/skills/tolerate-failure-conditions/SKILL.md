# 宽容失败三条件（给人才自由，把失败当信号）

## R — 原文 (Reading)

> "无论你的人才培养计划多么严密，都必须让领导人才有机会自由发挥，以获得成功（当然也可能失败）。如果一位领导人才从未失败，那么他的学习经历是不完整的，这样的考验也不够有效。应该把领导人才置身于符合以下三项条件的环境之中。"
>
> — 查兰，第4章（L8289）

> "给予他们为实现远大目标而重新定义工作内容的自由。……让他们自由选择，用最适合的方式领导团队。独立做出人事决策，激励团队达成目标。……给予他们平衡业务的短期发展与长期发展的自由。"
>
> — 同上，第4章（L8291–L8295，节引）

> "你应该把那些失败看成是改善人才识别和培养方式的机会，并总结失败的教训：是领导者和培养机会的搭配上出了错吗？也许是这位领导者表现出了推动业务增长的能力，但是却被调任到一个负责控制成本的岗位……"
>
> — 同上，第4章（L8297）

## I — 方法论骨架 (Interpretation)

这套方法把"允许失败"从一句口号变成一份可设计、可归因的安排。

**三条件，即给人才的三项自由**：
1. **重新定义工作内容的自由**——他可以不接受现状，重新制定工作计划、设定个人与业务目标；上级要了解并接受这一点，但也不能毫无节制，双方要一起分析双赢方案。
2. **带团队的自由**——用他认为最合适的方式领导团队、独立做人事决策、激励团队达成目标；前提是不破坏和中断有连续性的工作。
3. **平衡短期与长期的自由**——被允许为长远投资而不被当期指标追杀；指标是协商制定的，即使大势与预期不同（如经济萎缩），他仍能在应对变化中获得历练。

**两项配套动作**：
- **失败预算**：给未经验证的人自由，前提是事前做过严谨评估——评估其潜质、周密考察其在新职务上可能的表现，并判断"万一失败公司能否承受"（弗兰克案例就是反面：错误时间＋错误岗位＋错误人选）。给"自由发挥"的地方，必须是不至于失守的位置。
- **失败归因三分类**：把失败当成改善识别与培养方式的机会，追问是——①人与机会搭配错误（如增长型人才被派去管成本控制）？②文化适应问题（他不喜欢外国文化却被期望去适应）？③进展太激进而失败（他表现出强烈的欲望和干劲，公司就让调动幅度过大）？同时要辨别：他的干劲是为了职务升迁，还是为了学习与成长。

**结论是"失败不是终点"**：在某个岗位上失败但被调任到更适合其才能的岗位上却很成功的案例很多；轮岗培养模式正是利用每一次岗位表现提供的信息去调整发展路径、决定下一站，必要时给出更适合的岗位重新证明。注意"人的个性几乎不可能改变"——若失败来自根深蒂固的缺点，就要考虑把他从领导人才名单中删除。

## A1 — 书中的应用 (Past Application)

### 案例 1: 加里执掌日本（成功侧，第1章）
- **问题**: 日本业务需要全面负责人，而加里此前只做过营销与国家一把手，面对的是部门割裂、会议沉默、管理层士气低落的局面。
- **方法论的使用**: 让他拥有三条件的空间——先在董事会上准确诊断（员工无目标、产能陈旧过剩、产品无差异、管理层士气低落）并做出"根本问题在管理团队"的判断，获得全面授权后自主设计动作：把企业整体财务状况讲给高管团队，再把他们三四个人分成一组讨论整体状况与解决方案，"如果他们愿意，用日语讨论也可以"——用分组母语讨论化解日本文化中不敢提问的障碍；再据此重塑团队。
- **结论**: 给足自由＋允许他在不熟悉的文化中用不同方法带团队，才可能逼出真正的学习与判断；六个月改变高管团队行为是"给自由"的成果。
- **结果**: 两年扭亏，随后扩份额、进亚洲、降负债，并建立本地领导人才培养体系、培养出接班人实现交接（b4-c04）。

### 案例 2: 弗兰克（失败侧，边界，第4章）
- **问题**: 首席战略官聪明、精通业务但只在职能部门、最多管过 100 人，被放去负责困难重重、对公司至关重要的北美业务。
- **方法论的使用**: 用失败预算反读——事前没有认真评估"万一失败公司能否承受"：北美业务必须扭亏为盈、正是不能失守的位置；岗位要求的能力（选人育人、树立威信、大批量业务决策）与他此前的经验完全不匹配，调动幅度超出其准备度。
- **结论**: 该案例的失败同时命中三条件的反面与失败预算的缺失；作者定性为"在错误的时间、用错误的岗位、对错误的人进行的一次错误的考验"——不是"不该允许失败"，而是"不该在这里赌"。
- **结果**: 两年内北美市场份额由 20% 跌至 15%，现金入不敷出、债券沦为垃圾级；弗兰克被撤职、CEO 被迫离职，公司多年深陷泥潭（b4-c13）。

### 案例 3: 乔恩（不可克服的个人约束，第4章）
- **问题**: 呼声最高的 CEO 候选人乔恩拒绝为竞选 CEO 去北美，他厌恶政治，且全家人都在欧洲扎根；而他现任的欧洲岗位正是其他候选人的关键历练。
- **方法论的使用**: 作者的处理是把"个人意愿与家庭约束"视为培养设计的硬约束，而不是劝服问题——公司必须处理两难：他占着一个对别人重要的历练岗位，却不参与竞争。
- **结论**: 培养设计不能只从组织需要出发；有些障碍无法克服，组织需要预案，也需要尊重个人的选择。
- **结果**: 乔恩离开公司去另一家欧洲公司任 CEO；公司让另一位候选人接掌欧洲，获得历练机会——双方各自达成更合适的安排（b4-c17）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户想派一个高潜去接手困难业务（烂摊子、下行市场、转型岗位），但担心"他搞砸了怎么办"。
2. 一个被寄予厚望的人在新岗位上失败了，用户在问"这是不是说明他不行""还能不能给他机会"。
3. 用户在纠结培养性岗位的授权边界：要不要让他自行定目标、自己换人、自己决定长期投入。
4. 公司的新业务／试点需要有人负责，但季度考核压力与长期投入互相冲突，用户想设计"允许试错"的空间。
5. 高潜本人拒绝一次关键调动（家庭、地域、业务风险），用户想知道该怎么判断与处理。

### 语言信号 (用户的话里出现这些就应激活)

- "想派他去接手那个烂摊子，但怕他搞砸。"
- "他这次失败，还该不该继续培养？"
- "这个岗位该给他多大授权？目标要不要公司定？"
- "他要换掉现有团队，我该不该让他动手？"
- "stretch assignment risk" / "learning from failure" / "how much freedom should I give him" / "is this failure fatal"

### 与相邻 skill 的区分

- 与 `concentric-learning-job-design` 的区别: 那决定"给什么岗位"（挑战递增与风险评估）；本 skill 决定"在这个岗位上给多大自由、失败后怎么归因与调整"。
- 与 `b1-f15 underperformer-tiered-handling` 的区别: 分层处置处理的是持续不胜任者的责任与出路；本 skill 处理的是成长性挫折的归因与再安排，两者的前提与结论都不同。
- 与 `b3-f12 coaching-two-tracks` 的区别: 双轨教练是对话机制（业绩／能力两条轨道分开）；本 skill 是环境设计与失败处理机制。
- 与 `b5-f23 performance-gap-circle` 的区别: 绩效圆圈界定"期望与现实的缺口"；本 skill 解释缺口出现后如何把它当成培养系统的信息。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **确认这是"培养性挑战"而不是责任岗位**
   - 完成标准: 明确该岗位的性质（历练位还是必须守住的岗位）、失败的业务后果量级、公司是否有承受能力。
   - 判停条件: 若业务不可失守且无兜底方案（如弗兰克式处境），停止并把安排改为低风险载体（任务小组、单业务单元、区域试点），或先补足其经验。

2. **逐条检查三项自由会落到实处**
   - 完成标准: 就三问给出明确答案——①他能否重新定义工作内容与目标（而不是被旧目标与旧考核绑死）？②他能否自主组建团队、独立做人事决策？③他能否被允许为长期发展投资而不被季度数字追杀？任何一项做不到，都要说明原因并约定例外管理方式。

3. **事前评估失败的可能性与代价（失败预算）**
   - 完成标准: 写下最可能失败的三个场景、每个场景的业务代价与止损方案；并获得上级或董事会层面的知悉与认可。

4. **约定观察机制，而不是遥控指挥**
   - 完成标准: 设定检查节律（如每季度一次深度复盘）、约定要观察的具体行为与指标、明确"什么情况会触发干预"；反馈要及时、坦诚、直接且注意方式方法。
   - 判停条件: 若上级发现自己无法放手（要求事事汇报），先解决授权问题——半放权比不放权更容易造成失败。

5. **失败后按三分类归因**
   - 完成标准: 明确写出属于哪一类——①人与机会搭配错误（增长型人才被派去控成本）；②文化／环境适应问题；③进展过激进（因干劲被过度提拔，或调动幅度过大）；并检查是否辨别了他追求的是升迁还是成长。

6. **据此调整路径，而不是终止培养**
   - 完成标准: 给出下一步安排（更适合的岗位、补短板后再战、缩小职责范围），并说明为什么这更可能成功；若失败源于根深蒂固的个性与行为缺点，则做出"从名单中移除"的判断并记录理由。

7. **把教训回灌到识别与培养机制**
   - 完成标准: 把本次失败的归因写入人才识别标准或岗位设计规则的修订记录（"把那些失败看成是改善人才识别和培养方式的机会"）。

8. **处理不可克服的个人约束**
   - 完成标准: 对拒绝调动或家庭约束的情形，评估是否可通过替换地点、平行调动、调整时间表解决；无法解决时尊重其选择并准备组织预案，不以"奉献"名义强推（详见 B 段 risk_note）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 涉及合规、安全、诚信红线的失败：那不是"学习和成长"的范畴，必须按制度处理（参见 `leadership-is-work-not-honor` 的伦理红线）。
- 常规绩效不达标、能力与岗位长期不匹配：走绩效管理与岗位调整流程，不要用"宽容失败"延长痛苦。
- 公司没有失败承受力（关键业务、现金紧张、客户不可失守）时：不适用试错设计。
- 用户想要的是"给某人免责"的依据：本 skill 要求事前评估与事后归因，不是免责工具。

### 作者在书中警告的失败模式

- **拔苗助长／错误的破格提拔**：错误的时间＋错误的岗位＋错误的人选；不看领导经验与岗位复杂度跨度、不评估失败后果与承受力，结果业务与个人双输，甚至波及 CEO 与公司多年（b4-ce02）。
- **只重书本不重实践**：没有真实压力与失败空间，学习经历就是不完整的——"如果一位领导人才从未失败，那么他的学习经历是不完整的，这样的考验也不够有效"（b4-ce04 的反面）。
- **家庭与流动性约束被忽视**：培养设计默认"可全球流动"，配偶职业、子女教育、社会关系等约束未被纳入，人才被迫退出；某地点反复无人愿意去，可能不是人的问题而是"那个地点的事业本身有问题"（b4-ce23）。
  > risk_note（b4-ce23 保留）：涉及家庭与照护责任的安排不能以"奉献"名义强制；调动涉及劳动合同变更与异地用工合规；公司应提供弹性与替代路径，不得构成对特定群体的间接歧视。
- **把干劲当准备度**：作者提醒要辨别"领导者表现出的强烈欲望与干劲，是为了谋求职务升迁，还是获得学习、锻炼与成长"——用升迁欲望驱动过度调动，正是失败来源之一（L8297）。
- **无阶段性考核与退出方案的培养性任命**：b4-ce02 的警示信号明确列出"目标岗位当前处于危机且不可失守""无阶段性考核与退出方案"两条。

### 作者的盲点 / 时代局限

- **"允许失败"与股东/组织耐心的张力**：本书建议给人才留失败空间，但对上市公司季度压力、董事会容忍度、股东沟通成本几乎没有讨论；实践中"允许失败"往往败在时间表与资本市场的节奏上。
- **失败代价的外部化**：作者用弗兰克案例承认代价巨大，但这是员工、客户与股东承担的；框架中没有补偿或问责机制的设计。
- **精英视角**：三条件的"自由"默认接受者是已被选中的少数高潜；普通员工在同一组织里是否有试错空间，作者未讨论。
- **个体化归因倾向**：把失败主要归类为个人与机会的搭配问题，对制度性原因（资源、政治、指标设计）着墨少。

### 容易混淆的邻近方法论

- 与"授权（delegation）"：授权关注任务与权责的转移；本 skill 关注成长性的自由设计与失败归因。
- 与"心理安全（psychological safety）"：心理安全是团队层面的氛围条件；本 skill 是个人培养路径上的失败预算与归因机制，可相互补充但不互相替代。
- 与"复盘（AAR）"：复盘面向事件与流程改进，本 skill 面向人才发展路径的调整。
