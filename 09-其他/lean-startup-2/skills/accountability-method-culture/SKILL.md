# 责任制→方法→文化三层因果模型（文化是残留不是海报）

## R — 原文 (Reading)

> "'精益创业2.0'的基础同样由这4种要素构成，首先是责任制，驱动员工行为，并配套相关的奖励和激励措施。……方法源自责任制，因为每个公司的责任制会限制方法的选择。"
>
> — 埃里克·莱斯，第 5 章（行 1667-1669）

> "文化是整个组织的肌肉记忆，不是看企业希望怎么运作，而是看企业过去都做过什么。光靠贴海报提倡员工'不断革新！''打破常规！'改变不了文化。……文化是随着时间沉淀形成的，是公司过去选择的各种方法和责任制的残留。"
>
> — 埃里克·莱斯，第 5 章（行 1671）

---

## I — 方法论骨架 (Interpretation)

这是全书职能改造案例共用的底层因果模型。它主张变革有一个固定方向，逆着来就会失败：

- **责任制是输入端**：薪酬、晋升、表彰、辞退依据什么？考核什么、惩罚什么？它决定员工行为的"重力方向"。
- **方法是中间层**：团队日常使用的工具与流程。责任制一改，"只要没有伤害性的激励措施"，大多数团队会围绕新工具自组织——方法不需要被强制推行，它跟随激励迁移。
- **文化是输出端（残留）**：日久沉淀成的"在我们这里就是这么做的"共识。它是过去选择的记录，不是愿望的声明。
- **诊断规则**：凡"口号说 A、行为是 B"，必能在责任制里找到奖励 B 或惩罚 A 的条款；找不到就改不了。想改文化，唯一的入口是责任制和方法——海报、团建、价值观宣讲都在输出端做功，白费。
- **文化重建的正路**：新文化源自对新方法的成功实践——先让团队赢几次，再用证据与语言把已发生的行为重述成价值观（信念制定式），而不是反过来先发布愿景。

## A1 — 书中的应用 (Past Application)

### 案例 1：白板工作法——从问责传导入手改一个部门
- **问题**：第一批受训员工回到原部门"格格不入"（ce18）：个人方法更新了，但主管不问新问题、考核原封不动，热情三个月内被组织重力耗尽。
- **方法论的使用**：一位部门总裁不办新培训，而是用一块白板强制每位主管写下本季度谁在带精益项目，并公告季度末将逐一约谈——约谈只问一句"你的主管在审核项目时问了你们什么问题？"。这一手把问责点从个人方法层移到管理层行为层。
- **结论**：主管被考核"问什么问题"之后，其行为（即部门的方法环境）才真正改变；问责传导比方法灌输快得多。
- **结果**：该部门成为 GE 最早完成转型的部门之一（第 7 章，行 2478-2488，案例 c11）。

### 案例 2："通用电气信念"的制定——文化当产品来做
- **问题**：转型进行到深处，旧价值清单已与现实脱节，需要一份能指导行为的新"北极星"。
- **方法论的使用**：森佩尔团队把 MVP 方法用于价值观本身：列出 12 个特征→向前 200 位中层与 4000 名员工验证"哪些我们已强、哪些最欠缺"→针对弱点起草→2014 年发布五条信念（唯客户定成败、求精益拼速度等）。
- **结论**：文化表述必须来自行为证据（已验证的强项与缺口），而不是高管愿景的独白——这正是"文化是残留"的正面操作。
- **结果**：五条信念发布，为后续 PD@GE 等深层变革提供了合法性（第 6 章，行 2356-2387，案例 c30）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队墙上贴满价值观海报、口号天天喊，但没人当真——想弄清为什么宣贯无效。
2. 培训做了、热情有了，员工回部门却"格格不入"，三个月后实验数为零。
3. 考核矩阵在直接惩罚目标行为（如惩罚返工量导致团队拒绝更优的并行开发方案）。
4. 想推动文化转型，正在犹豫是先做宣导团建，还是先动考核薪酬。

### 语言信号 (用户的话里出现这些就应激活)

- "企业文化" "价值观落地" "贴海报" "氛围不行" "两张皮"
- "培训完没变化" "回部门就没人理了" "考核不改什么都没用" "激励不对"
- 英文：culture change / values are just posters / incentives / muscle memory / training didn't stick

### 与相邻 skill 的区分

- 与 `behavior-before-tools`（技术只是手段：先改行为与文化，再上工具）的区别：`behavior-before-tools` 讲工具与行为的先后顺序（技术至多是放大器）；`accountability-method-culture` 讲文化从哪里来（责任制→方法→文化）。同一"上线没人用"的症状，若存在明确惩罚新行为的考核条款，归 `accountability-method-culture`；若只是工具先于行为实验上线，归 `behavior-before-tools`。
- 与 `gatekeeper-to-enabler`（把关部门→赋能部门改造路径）的区别：`gatekeeper-to-enabler` 是把模型应用于职能部门的具体操作路径（预批、红黄绿、样机进现场）；`accountability-method-culture` 是其底层因果逻辑。部门改造若不动该部门内部"考核什么"，会停在流程表面——先 `accountability-method-culture` 诊断再 `gatekeeper-to-enabler` 施工。
- 与 `internal-change-owner`（变革必须内部专人专责）的区别：`internal-change-owner` 回答"变革由谁负责"（治理规则），`accountability-method-culture` 回答"变革按什么顺序改什么"（因果模型）。
- 与 `leap-of-faith-assumption-audit`（信仰飞跃假设审计）的区别：`leap-of-faith-assumption-audit` 审的是商业假设，`accountability-method-culture` 审的是组织因果假设（"改了文化宣贯行为就会变"也是一个待证伪假设）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **诊断因果方向**
   - 完成标准：写出目标组织当前"考核什么、奖励什么、惩罚什么、晋升什么样的人"的清单（不含愿景与口号）；能指出至少一条"考核 A 却期望行为 B"的矛盾条款（如考核返工量却希望并行开发）。
   - 判停条件：若找不到任何激励与目标行为的冲突，问题多半不是文化而是技能或资源——停止本流程，转培训或资源方案。

2. **改责任制（输入端）**
   - 完成标准：至少一条考核/奖惩条款被实际修改或豁免（如取消返工量惩罚、把"做了几个验证实验"纳入主管评价）；变更以书面制度或当众承诺形式固定。

3. **让方法自组织，不强行推行**
   - 完成标准：观察期内（通常一个考核周期）出现团队自发采用新工具/流程的行为证据；不组织强制推广（那是 `behavior-before-tools`/`bingo-card-diagnostic` 反例的做法）。

4. **用证据重述文化（信念制定式）**
   - 完成标准：面向真实员工验证"哪些已强、哪些欠缺"，新的文化表述覆盖已发生的行为证据，而非高管愿景独白。

5. **复查残留（3-6 个月）**
   - 完成标准：新方法被默认执行而不再需要解释（肌肉记忆置换的可观察判据：新人入职即被告知"我们这里就是这么做的"且内容已是新说法）。
   - 判停条件：若复查发现行为回退，回到步骤 1——通常是责任制改了但晋升案例未跟上，或只改了方法未动考核。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 新组建的团队/公司：没有历史残留，直接设计责任制即可，不需要"改造"叙事。
- 纯技能缺失：员工想做不会做，培训与教练（`coach-assume-they-are-right`/`coach-not-leader-not-spy`）是解法，动考核只会惩罚无辜。
- 用户要的是"文化活动策划"（团建、宣讲、内刊）——那是宣导产物，恰是本 skill 认定无效的那类动作。
- 你无权触碰任何考核与奖惩条款，也没有攒政治资本的路径——此时先转 `three-stage-transformation` 三阶段路线图做边缘试点。

### 作者在书中警告的失败模式

- ce09 激励矩阵杀死更优方案：GE 员工管理系统惩罚返工量，工程师明知方案更优也异口同声拒绝——"员工管理系统"甚至成为拒绝变革的通用借口；责任制不改，任何方法培训都会在考评面前失效。
- ce10 工具先行、文化缺位：绩效 app 上线两周零反馈——"测试失败不是因为工具不好，而是还不具备有效使用工具的环境"。
- ce18 只培训个人不改文化：受训者回部门格格不入，个人热情被组织重力耗尽——培训改变方法层，环境仍由旧责任制支撑。

### 作者的盲点 / 时代局限

- "员工会自愿拥抱实验文化"是书中未被证明的假设：对 3 万自愿报名者着墨多，对被旧文化塑形的多数沉默员工如何转化，机制着墨不足。
- 创新核算的 NPV 层在 HR/文化类项目上未被书中案例真正走通（PD@GE 最终依赖的是领先性指标）——"文化改变也能量化对账"部分依赖主观建模，容易退化为新的表演性指标。
- 模型提炼自作者深度参与的 GE 等公司（存在利益关联与幸存者偏差）；GE 其后的绩效制度回摆也削弱了"责任制一改文化即换"的线性叙事。

### 容易混淆的邻近方法论

- 科特式变革管理（八步法）：从营造紧迫感与愿景沟通开始；本模型从考核与奖惩开始——因果方向相反，是本 skill 与主流变革管理最易混淆也最需分辨的一点。
- 《精益创业》正传：几乎不涉及组织文化机制；"文化是残留不是宣言"与反向因果链是本书 2.0 的组织层核心增量。
- "数字化转型=换工具"论：对应 ce10 的失败形态——技术只是手段，先改行为与文化环境再上工具（与 `behavior-before-tools` 互为表里）。
