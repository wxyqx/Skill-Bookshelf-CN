  type: framework

- id: f05
  title: 生活情境 vs 生命
  type: framework
  source_chapter: 第三章（另见第四、十章）
  source_quote: |
    "你的生活情境存在于时间之中。你的生命则是在当下。你的生活情境是思维创造出来的。

  summary: |
    把"我的生活"切成两层：生活情境（过去未来的产物，可改善、可抱怨、充满问题）

    先问"此刻我的生命怎么样"。
  tags: [distinction, reframing]

  type: framework

  source_quote: |
    "问题"的意思是，你在心理上不断地琢磨某种情况，而没有真正地在当下采取行动，

  summary: |

    要么接受（说"好的"），两者都不产生"问题"；只有心理反刍才把情境变成问题。
    若真有此刻能做的事，把"未来一百件事的重担"换成"此刻能做的一件事"。

- id: f09

  type: framework
  source_chapter: 第四章（另见第三章"本体的喜悦"）
  source_quote: |
    "外在目的是达到你的目标……内在目的与你去的地方或你正在做的事没有任何关系，
    但是它与你如何做事有着密切的关系。……你外在的旅程可能包含着上百万个步伐；

  summary: |

    自检问句："我现在正在做的事情是否让我感觉喜悦、自在和轻松？"若否，先改做事方式
    而非改事情；注意力放在行动本身而非结果上（作者引《薄伽梵歌》业力瑜伽）。
  tags: [goals, meaning, action]

    配套话术："我没有在等待，我仅仅是站在这里自得其乐。"

  type: framework
  source_chapter: 第六章
  source_quote: |
    "首先将注意力轮流集中在你身体的不同部位——双手、双脚、手臂、大腿、腹部、胸部、

    作者称可加强身体与"精神"免疫系统、消除负面情绪，并强调它不能替代日常的进驻练习。

  type: framework
  source_chapter: 第六章
  source_quote: |
    "当倾听别人说话时，不要仅用大脑去聆听，还要用整个身体去聆听。……大部分人不知道

  summary: |

    片刻、注意力落在体内，"习惯性地徘徊于思考和对内心的倾听之间"，重新思考时思维
    更新鲜有创造性。
  tags: [listening, creativity, body]

- id: f14
  title: 寂静与空间：注意力从"有"转向"无"
  type: framework
  source_chapter: 第七章（另见第五章"沉默"节）
  source_quote: |
    "将你的注意力更多地集中在寂静上而不是声音上。……即使表面上看起来坚固的东西，

  summary: |

    寂静；对话时注意词与词之间的间隔；②看物体"之间"的空间——房间里的家具不是房间，
    "那里没有的东西比那里有的东西更为重要"。注意力从事物移向空间，会自动从思维移开
    （思维"物体"=观点情绪；空间对应物=意识）。不可思考空间，只能觉知空间。
  tags: [attention, meditation, perception]

- id: f15
  title: 两次臣服机会
  type: framework
  source_chapter: 第十章（另见第二、四、九章）
  source_quote: |
    "你的第一个机会是向当下的现实臣服。承认现实不能改变……如果你不能接受外在的状况，
    那么请你接受内心状况。这就是说，不要去抗拒痛苦，允许它的存在。"
  summary: |
    厄运当头的两级程序：第一级——承认"已经发生的不能改变"，做必须做的事，不产生第二支
    箭；第二级——若情绪大到无法接受事件，就转向接受感受本身：不压（压进无意识会污染

    就是全面的接受，就是臣服"。臣服≠切断感受（古希腊哲学家"我早知道他不是不朽的"
    被明确排除）。

  source_quote: |

    反应；不抗拒≠不行动（东方武术：因势利导，以柔克刚）。

  tags: [death, compassion, meditation]
