```yaml
- id: g01
  term: 信誉（credibility）
  type: term
  source_chapter: 第二章/第八章（沃尔克建立、伯恩斯反例、耶伦"资本资产"论述）
  author_definition: >-
    由行动和结果而非口头承诺建立的、使通胀预期保持锚定的资产。重建代价高昂（沃尔克的1981-82衰退、
    失业率10.8%是"信誉的买价"），但换来数十年预期锚定红利；它是需要持续维护的"资本资产"，会贬值。
  key_distinction: ≠口头承诺或表态（言辞无行动支撑反而损耗信誉）；≠个人声誉；=一种可存取、会折旧的预期资本，靠言行一致与结果兑现来维护。
  why_it_matters: 信誉/预期管理类 skill 的核心变量；不澄清"信誉=行动×预期一致性"，先发制人、承诺设计、沟通工程等 skill 会退化成空洞的"要守信"说教。
  tags: [信誉, 预期锚定, 资本资产, 言行一致]

- id: g02
  term: 先发制人（preemptive strike）
  type: term
  source_chapter: 第一章/第三章（马丁"收走酒杯"、格林斯潘1994-96软着陆）
  author_definition: >-
    因货币政策对通胀有一年以上时滞，在通胀仅有苗头、指标尚温和时就采取的打击策略；等实际通胀恶化再行动，
    所需紧缩力度更大、对扩张伤害更重。格林斯潘1994年在通胀仍低、失业仍高时加息即教科书级范例。
  key_distinction: ≠事后响应式调控（"等确凿证据再动手"）；≠刺破泡沫；=以温和的提前行动代价换取免于日后的激烈矫枉，是长时滞下唯一负责任的策略。
  why_it_matters: 与"风险管理/买保险"（g10）是全书两大决策模式，且 2021 年"暂时论"被作者定性为放弃先发制人的代价；下游对比类 skill 需要这个精确边界。
  tags: [时滞, 提前干预, 软着陆, 代价比较]

- id: g03
  term: 时断时续（stop-go）政策
  type: term
  source_chapter: 第二章（伯恩斯）
  author_definition: >-
    通胀飙升时紧缩、失业一升立即放松的摇摆模式。作者判定它比不紧缩更糟：同时失去两个目标，
    使通胀与通胀预期螺旋上升、预期脱锚——伯恩斯 70 年代的失败被归因于此模式叠加成本推动论教条。
  key_distinction: ≠渐进式微调；≠"灵活应对"；=以"上一次的痛"为节奏的逆风摇摆，是信誉的反面操作（每次转向都被市场定价为不可持续）。
  why_it_matters: 是"信誉建立与维护" skill 的核心反面教材；不澄清此词，容易把"相机抉择的灵活性"与"系统性摇摆"混为一谈。
  tags: [反面教材, 预期脱锚, 政策摇摆]

- id: g04
  term: 中性利率（R*，R-star）
  type: term
  source_chapter: 第四章/第八章/第十二章（定义、逐级下修、政策空间核算）
  author_definition: >-
    原文定义："当经济处于充分就业且通胀稳定时的利率"——既不刺激也不抑制经济的利率。由人口、生产率、
    储蓄偏好等结构性因素决定，不可直接观测；数十年结构性下降（实际值从超3.5%降至不到0.5%）压缩了传统降息空间。
  key_distinction: ≠当前政策利率（联邦基金利率）；≠市场利率；=估计值会漂移的不可观测锚，70年代对自然失业率/R*的过度自信正是大通胀的认知根源。
  why_it_matters: "政策空间核算"与"凭星导航（参数谦逊）"两类 skill 的支点变量；所有"弹药还剩多少"的讨论都以 R* 为分母。
  tags: [不可观测参数, 结构性变化, 政策空间, 估计谦逊]

- id: g05
  term: 有效下限（ELB, effective lower bound）
  type: term
  source_chapter: 第四章/第五、六、十一至十三章
  author_definition: >-
    政策利率不能显著跌破零（或略低）的约束；原文"有效下限被假定为零，或者略高于零"。它是全书工具创新的
    触发器：QE、前瞻性指引、FAIT、负利率与收益率曲线控制的讨论全部由 ELB 逼出。
  key_distinction: ≠零下限的绝对数学约束（美国估计约-0.35%，负利率技术上可行）；≠流动性陷阱的经济学假说；=政治与技术共同决定的软约束，且衍生"日本陷阱"式自我强化循环。
  why_it_matters: 工具选择类 skill 的状态开关：德尔菲/奥德赛指引、TPLT/FAIT 的适用条件都绑定"是否触及 ELB"。
  tags: [约束条件, 工具创新触发器, 名义利率]

- id: g06
  term: 量化宽松（QE）与信贷宽松（credit easing）
  type: term
  source_chapter: 第六章/第十一章（机制与证据）
  author_definition: >-
    大规模购买长期证券，通过减少市场上长期证券的净供应（投资组合平衡渠道）与传递"低利率更久"的信号
    （信号渠道）压低长期利率。美联储刻意区别于日银以准备金为中心的做法，自称"信贷宽松"——强调降低家庭
    和企业面临的长期利率。"存量观点"（累计持有+预期）比"流量观点"更符合证据。
  key_distinction: ≠印钞/准备金扩张（"推绳子"，M2 未必增加）；≠市场稳定性的"最后买家"购债（2020年3月那种，目标不同）；≠财政赤字货币化；效果靠"预期外成分"计量。
  why_it_matters: QE 是全书被批评与自辩最集中的工具；归因纪律 skill（区分已定价部分与意外成分）直接建立在此定义上。
  tags: [非常规工具, 双渠道, 存量观点, 预期外成分]

- id: g07
  term: 前瞻性指引（德尔菲式 vs 奥德赛式）
  type: term
  source_chapter: 第四章/第七章/第十一章
  author_definition: >-
    央行通过管理市场对未来政策路径的预期来移动长期利率的工具。第十一章引埃文斯等区分：德尔菲式
    （Delphic，预测性沟通，告知央行对经济的预期）与奥德赛式（Odyssean，承诺性指引，约束央行自身未来行为）。
    后者有效的前提是可核验措辞+机构声誉+共识性框架+独立性。
  key_distinction: ≠单纯的信息发布（奥德赛式是承诺，兑现失败即信誉损失）；≠"靠嘴刺激经济"的空谈；=宣布本身即政策（GSS 2005：3/4 以上长端收益率变动来自指引而非利率意外）。
  why_it_matters: "承诺设计" skill 的分类学；两类指引适用条件不同（奥德赛式主要在 ELB 附近有增量价值），混用会导致承诺过度。
  tags: [沟通即政策, 承诺, 预期管理, 可信度四支柱]

- id: g08
  term: 状态依赖性承诺（vs 时间依赖性承诺）
  type: term
  source_chapter: 第七章（2012年12月失业率6.5%/通胀2.5%门槛）
  author_definition: >-
    把政策绑定于经济状态（失业率/通胀门槛）而非日历日期的承诺形式；可随经济自我校准、更能激发信心，
    但触发条件说不清、有被误解风险。时间依赖承诺（"至少至2013年中"）简单直接，适合需要戏剧性扭转预期的场合。
  key_distinction: 关键区分：门槛（threshold）≠触发（trigger）——"失业率降到6.5%之前不考虑加息"只排除过早紧缩，不承诺到点必加；状态型≠自动按钮。
  why_it_matters: "承诺设计" skill 的核心选择维度（时间型/状态型/免责条款的组合）；门槛-触发混淆正是缩减恐慌的诱因之一。
  tags: [承诺设计, 门槛, 自我校准, 指引形式]

- id: g09
  term: 有限制的自由裁量权（constrained discretion）
  type: term
  source_chapter: 第七章（伯南克-米什金概念；2012年1月框架落地）
  author_definition: >-
    规则派与相机抉择派之间的妥协方案：相机决策+承诺跨期实现目标（2%通胀目标）+公开解释决定，
    由通胀目标、《经济预测摘要》（SEP）、点阵图、季度发布会构成制度框架；透明度同时支撑市场传导与独立性。
  key_distinction: ≠机械规则（泰勒规则式绑定）；≠完全相机抉择；=给自由裁量装上"可解释的目标+参照系"——耶伦时期进一步演化为"规则做参照系而非枷锁"。
  why_it_matters: "沟通工程/框架设计" skill 的总纲；几乎每个沟通类案例（发布会、点阵图、声明措辞）都是它的实例化。
  tags: [规则vs相机抉择, 通胀目标制, 制度框架, 透明度]

- id: g10
  term: 风险管理框架 / 保险性降息（insurance cut）
  type: term
  source_chapter: 第三章/第九章（格林斯潘1998、鲍威尔2019三次降息）
  author_definition: >-
    把决策从"押注单一最优预测"改为对一组可能情境定价：为低概率高后果的尾部风险支付适度保费
    （降息幅度略超基准预测的合理幅度），风险消退后收回保费。1998年格林斯潘降息是真保险（事后逆转加息175bp）；
    2019年鲍威尔三次降息事后被证实风险本不会兑现（无保费、不逆转）。
  key_distinction: ≠放弃通胀目标的机会主义宽松；≠政策转向；=有明确退出条件的条件性保险——且行动后须区分"风险未兑现因为保险"与"风险本来就不会兑现"。
  why_it_matters: "风险管理式决策" skill 的命名概念；与先发制人（g02）构成风险不对称下的两种模式切换，退出条件缺失即信誉受损。
  tags: [尾部风险, 保险, 可逆性, 风险不对称]

- id: g11
  term: FAIT（灵活平均通胀目标制，flexible average inflation targeting）
  type: term
  source_chapter: 第十章/第十三章（2020年8月杰克逊霍尔公布）
  author_definition: >-
    2020年新框架：寻求通胀"适度高于2%一段时间"以补偿此前的不足（平均意义上回到2%），且不对低失业
    先发制人加息；实质是"临时价格水平目标制（TPLT）+非对称补偿"的混合体，专为低R*、低通胀世界设计。
  key_distinction: ≠对称补偿的价格水平目标制（超标不反向补偿）；≠放弃2%目标；=分状态激活的条件性框架（强承诺只在 ELB 处生效）——2021-22 通胀考验暴露其超标时可能反应迟钝，作者自己在第十三章承认。
  why_it_matters: 是全书批判（B字段）的最大靶点之一："为低通胀世界设计的框架遇上高通胀世界"；下游对照类与批判类 skill 都需精确定义。
  tags: [框架演进, 非对称补偿, ELB, 2021通胀考验]

- id: g12
  term: 点阵图（dot plot）
  type: term
  source_chapter: 第七章（2012年1月随SEP首次发布）
  author_definition: >-
    《经济预测摘要》中各 FOMC 参与者对联邦基金利率路径的个体预测散点；2012年起按季发布。
    它展示的是"各参与者观点"而非委员会承诺或一致预测——点阵图与实际政策屡有偏差（2015-16年预测加息次数远多于实际）。
  key_distinction: ≠委员会承诺（不是前瞻性指引本身）；≠一致意见（FOMC"太大太分散"，只是个体预测汇总）；≠机械规则，是有限制的自由裁量权的沟通组件。
  why_it_matters: 沟通工程 skill 的高频案例：点阵图引发的市场误读是"沟通口径脱节"的典型素材，须先澄清其法律与逻辑地位。
  tags: [SEP, 沟通工具, 预测≠承诺]

- id: g13
  term: 缩减恐慌（taper tantrum）
  type: term
  source_chapter: 第七章（2013年5-6月）
  author_definition: >-
    2013年5月22日伯南克国会证词暗示"接下来某次会议可能放慢购债"，至9月10年期收益率上升整整1个百分点、
    新兴市场"脆弱五国"遭溢出冲击。作者归因于沟通口径的内部脱节：开放式QE3需要"不惜一切代价"的承诺心态，
    而委员会犹豫外泄被市场定价——言行一致性比信息精确性更根本。
  key_distinction: ≠缩减（taper）本身——减速购债≠加息预告，两者信息应解耦；≠纯粹的数据意外或市场过度反应；=内部分歧泄漏+市场情报失真（一级交易商调查盲区）的复合沟通事故。
  why_it_matters: "言行一致性检查"与"退出设计"两个 skill 的核心案例；教训（标准一开始就精确、分歧会被定价）是可迁移的沟通纪律。
  tags: [沟通失败, 退出设计, 溢出效应, 言行一致]

- id: g14
  term: 大稳健（Great Moderation，中译亦作"大缓和"）
  type: term
  source_chapter: 第二章/第八章/第十四章（沃尔克的遗产与伯南克的归因）
  author_definition: >-
    1980年代中期至2007年间通胀低而稳、产出波动收窄的时期。作者把它归因于沃尔克-格林斯潘重建的信誉
    （冲击不再螺旋化为工资-物价循环）+结构变化，而非单纯的运气——它是"信誉红利"的宏观证据。
  key_distinction: ≠运气或结构红利单因论（作者持信誉+结构多因论）；≠货币政策万能的证明；=中译本存在"大稳健/大缓和"两译，正文两处用"大稳健"、导读用"大缓和"，skill 引用需统一。
  why_it_matters: 信誉红利 skill 的关键证据节点；同时也是全书批判线索的靶子（2008年证明金融不稳定可在物价稳定之下积累）。
  tags: [信誉红利, 时代背景, 译名统一]

- id: g15
  term: 最后贷款人（lender of last resort, LOLR）
  type: term
  source_chapter: 前言/第五章/第十章（白芝浩原则及其现代扩展）
  author_definition: >-
    白芝浩经典原则：尽早、自由地以惩罚性利率向"有良好抵押品的有偿付能力机构"放贷。现代扩展：污名可用
    拍卖机制化解（TAF）、危机超出信贷冻结时央行须充当"非金融借款人的最后贷款人"（CPFF、TALF）；但央行
    "有借贷权力而不是支出权力"，资本重组须靠财政（TARP）。
  key_distinction: ≠救助资不抵债机构（偿付能力是放贷门槛：AIG可救、雷曼不可救）；≠支出权力；≠无条件纾困（须计道德风险，配套私人代价）。
  why_it_matters: "工具边界判断" skill 的第一分界线（流动性vs偿付性、借贷权vs支出权）；2020年预置工具箱案例也挂靠此概念。
  tags: [白芝浩, 流动性vs偿付性, 危机工具, 道德风险]

- id: g16
  term: 宏观审慎（macroprudential）
  type: term
  source_chapter: 第十四章（与货币政策的工具分工）
  author_definition: >-
    针对金融体系整体脆弱性的定向监管工具（资本/流动性要求管韧性，压力测试/逆周期缓冲管时变风险）。
    作者的核心判断：利率是钝器——宽松确有"风险承担渠道"，但识别泡沫难、传导不明、代价高，金融稳定
    应主要由宏观审慎处理，货币政策只在定向工具不足时谨慎补充。
  key_distinction: ≠用利率"戳泡沫"（"斯特朗打屁股原则"：不能因为一个孩子坏就打所有孩子）；≠微观审慎（单个机构稳健≠系统稳健，影子银行套利即反例）；前提是"同等业务同等监管"。
  why_it_matters: "工具边界判断" skill 的第二分界线（钝器vs手术刀）；第十四章的"工具适配三问"（能否识别、传导是否可理解、是否精准）依赖此概念。
  tags: [金融稳定, 工具适配, 风险承担渠道, 监管]

- id: g17
  term: 全球储蓄过剩（global saving glut）
  type: term
  source_chapter: 第四章（伯南克2005年演讲提出；与长期停滞互补）
  author_definition: >-
    解释实际利率长期下降的供给侧假说：新兴市场（尤其亚洲）危机后积累巨额储蓄、涌入美国安全资产，
    压低全球实际利率。作者用它与需求侧的"长期停滞"假说互补归因 R* 下降——两者兼容时结论更稳健。
  key_distinction: ≠美国宽松货币政策的同义词（作者以此反驳"美联储制造泡沫"论）；≠纯粹的国内现象；=资本输入国的结构性资金供给变化，与经常账户失衡绑定。
  why_it_matters: 归因纪律 skill 的示范案例：作者本人是该假说提出者，存在自辩色彩（BOOK_OVERVIEW 批判第3条），下游引用时须标注利益冲突。
  tags: [R*下行, 供给侧假说, 作者自辩点]

- id: g18
  term: 长期停滞（secular stagnation）
  type: term
```
