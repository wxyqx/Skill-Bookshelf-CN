# 宣布即干预：承诺本身就是政策

## R — 原文 (Reading)

> 在我们发布新闻稿后的几分钟内，这个指标显著下跌了0.65个百分点。30年期抵押贷款利率在12月又下降了约1个百分点。
>
> — 本·伯南克，《21世纪货币政策》第六章

---

## I — 方法论骨架 (Interpretation)

常规直觉的设计次序是"先备钱、再表态"——钱没到位就别说话。本书把这个次序反转了：在恐慌导致市场失灵的场景里，**可信的宣布本身就是干预**。

机制：恐慌的自我实现依赖"人人认为别人会跑"的预期结构。一个条件明确、额度（近乎）无限、声称"随时准备行动"的公开承诺，直接改写这个预期结构——交易者知道卖压有人接，于是不再需要跑，市场功能恢复，实际动用量反而很小。承诺的干预力来自三个要素：

1. **条件明确**：什么情况、什么价格、什么资产，没有解释空间，恐惧无法在模糊处繁殖。
2. **额度可信**：授权口径上"无限量"或明显大于最坏情形所需，堵死"撑不住"的投机逻辑。
3. **兑现路径清晰**：法律授权、资金来源、执行时间表完整——可信度是全部前提，缺了这一条的宣布不是政策是赌博。

由此得出两个反直觉推论：设计干预时先问"承诺够不够可信、够不够简单"，再算"要花多少钱"；评估干预时，"实际用量远小于授权、市场靠宣布就稳住"是成功的标志而非注水的证据。

## A1 — 书中的应用 (Past Application)

### 案例 1: QE1 的宣布效应（2008）
- **问题**: 危机深处，MBS 市场冻结，购买计划从决策到实际操作需要时间，而市场等不了。
- **方法论的使用**: 2008年11月25日先宣布购买5000亿美元MBS+1000亿美元GSE债券的承诺——操作尚未开始，承诺先行。宣布数分钟内GSE-MBS与长期国债利差下跌0.65个百分点，12月30年期抵押贷款利率再降约1个百分点。
- **结论**: 信号渠道先于资金渠道生效：承诺的可信度本身就是干预，后续实际购买是在巩固已被宣布改变的预期。
- **结果**: QE1总承诺最终达1.75万亿美元、资产负债表近乎翻倍；宣布效应成为"沟通即政策"的关键证据。

### 案例 2: 2020年疫情工具箱（第十章）
- **问题**: 疫情引爆"现金挤兑"，企业与市政债市场一周内冻结，而按程序发放贷款需要数周。
- **方法论的使用**: 两周内复用2008年剧本一键公布13条3款工具箱：3月23日宣布"无限量"购债；CARES法案4540亿美元财政部拨款作为损失吸收股本，支撑美联储估计至少2.3万亿美元的放贷能力。企业与市政债市场在大部分工具尚未投出一分钱时就接近恢复正常——与德拉吉2012年"不惜一切代价"同构。
- **结论**: 市场对"准备好"的信任就是稳定器；工具实际用量远小于授权恰是设计成功的证据。
- **结果**: 史上最短衰退（两个月），宣布即干预的范式完成第二次大规模验证。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 挤兑/恐慌正在发生（用户提现、商家挤兑、赎回潮、挤爆服务器），而资金、授权或执行团队到位需要时间。
2. 设计担保、兜底、流动性支持类方案，正在纠结"承诺额度定多大、会不会真被全额兑付"。
3. 干预已宣布、实际动用远小于授权，需要向内部解释"没怎么花钱就稳住了"为什么算成功而非白忙。
4. 危机预案设计：把"宣布脚本"当作与资金同等重要的预置弹药来编制。

### 语言信号 (用户的话里出现这些就应激活)

- "钱还没到位，能不能先发个声明稳住"
- "无限量承诺 / 兜底声明靠不靠谱"
- "实际没怎么用市场就恢复了，这算成功吗"
- "先表态还是先备钱 / announce / verbal intervention"

### 与相邻 skill 的区分

- 与 `signal-engineering` 的区别: 那是宣布的形式工程——按预期缺口大小选戏剧性还是铺陈，管"怎么说不被误读"；本 skill 管宣布的实质地位——可信承诺本身构成干预，管"设计次序（先可信度后金额）与用量逻辑"。
- 与 `panic-contagion-template` 的区别: 那是诊断工具——定位恐慌处于链条哪一环；本 skill 是处方工具——诊断完成后设计"以承诺止慌"的干预。两者是接续关系。
- 与 `guidance-credibility-design` 的区别: 那是常规环境下前瞻性指引的类型学（德尔菲/奥德赛）与四支柱；本 skill 是危机环境下的紧急承诺设计，且核心是宣布与实际用量的分离。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认适用条件**
   - 核对两点：市场失灵源于预期结构（挤兑/自我实现恐慌）而非纯基本面破产；承诺主体具备法律授权与兑现路径。
   - 完成标准: 两点均有明确依据；若承诺无法兑现，终止本流程并明示"空头表态会使危机加速"。

2. **设计承诺三要素（先于金额测算）**
   - 按"条件明确→额度可信→兑现路径清晰"的次序起草承诺文本，额度口径取"明显大于最坏情形所需"或直接无限量。
   - 完成标准: 承诺文本无模糊解释空间；最坏情形所需的量级估算存在且额度覆盖之。
   - 判停条件: 若最坏情形所需远超一切可得授权且无止损结构，转常规救助设计（该停就停，不硬发承诺）。

3. **先发布，后操作**
   - 宣布与实际投放解耦：承诺先行，执行跟进；同步公布执行时间表与授权依据以增可信度。
   - 完成标准: 宣布文本、授权文件、执行计划三者口径一致（口径脱节是本书最大的沟通教训）。

4. **以市场功能恢复为成功标准**
   - 监测利差、成交量、赎回/挤兑流等"功能指标"而非实际动用金额；用量远小于授权视为成功并如实公布。
   - 完成标准: 有明确的功能恢复指标集及宣布前基线；向内部/外部的解释材料采用同一标准。

5. **兑现少量以巩固信任**
   - 即使承诺已生效，仍完成小额实际操作以证明"说到做到"，防止宣布可信度随时间衰减。
   - 完成标准: 至少一笔象征性/常规量级的实际执行落地并被公开记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 预期未脱锚的常规环境——市场运转正常时口头承诺没有增量价值，此时过度表态反而引入噪声（对应"奥德赛式承诺只在需要拉回脱锚预期时才有价值"的选型判据）。
- 承诺无法兑现却想"先稳住再说"——空头表态被识破时不是中性失效而是加速器：市场会按"承诺即谎言"重定价此后一切表态。
- 对象是偿付性破产的机构或基本面已死的资产——承诺改变的是预期结构，改变不了价值本身，此时应用救助分类程序。

### 作者在书中警告的失败模式

- 无授权支撑的安抚性表态（ce08）: 2007年"次贷问题很可能得到控制"既是预言也是希望，无证据的安抚语在事后成为信誉负债——宣布的力量与"希望混入评估"的诱惑是一枚硬币两面。
- 口径脱节毁掉承诺（ce11）: 缩减恐慌中开放式QE本需"不离不弃"的承诺心态，内部分歧外泄使一句含糊证词重定价一个百分点——宣布效应的前提是宣布体系内部一致。
- 宣布可信度的存量属性: 每一次未兑现或含糊的宣布都在消耗下一次宣布的干预力（信誉资本逻辑），承诺不是免费的弹药。

### 作者的盲点 / 时代局限

- 归因分离未经判决性检验: "宣布即有效"的效应可能混杂同期财政救助预期（BOOK_OVERVIEW 明确列为未证假设），书中未做拆分——本 skill 的成功标准应保留这一归因保留项。
- 2020年复盘的对称性不足: 作者对宣布效应浓墨重彩，对同期同样宣布即生效的财政刺激各自贡献几何着墨很少；自辩色彩使其倾向高估央行沟通的独立贡献。
- 时代局限: 宣布效应依赖受众对机构的既有信誉存量；对信誉存量本就为负的机构（书中 QE2 支持率跌至末位的教训），"先宣布"未必优于"先兑现"，这一条件依赖书中未系统讨论。

### 容易混淆的邻近方法论

- 安抚性公关话术: 公关追求情绪平复，本 skill 追求预期结构的机械改写——差在"条件明确+额度可信+可兑现"三要素，缺了就是话术不是政策。
- 期权做市商的"gamma 承诺"（隐含波动率 pin）: 同为"承诺改变行为、实际成交很小"，但机制是套利定价而非预期管理，迁移时注意受众理性程度不同。
