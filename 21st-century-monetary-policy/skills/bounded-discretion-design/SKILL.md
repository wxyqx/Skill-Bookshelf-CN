# 有限制的自由裁量权设计——规则与相机抉择之间

## R — 原文 (Reading)

> 2012年1月批准了货币政策的一份原则性声明，这在美联储历史上是首次。在这份报告中，我们宣布了一个正式的通胀目标——每年2%，由个人消费支出价格指数衡量。
>
> — 本·伯南克，第七章《货币政策的演化：QE3和缩减恐慌》

---

## I — 方法论骨架 (Interpretation)

在"机械规则"（泰勒规则式绑定）与"完全相机抉择"（人治）之间取第三条路：保留相机决策的灵活性，但用三件套约束它——**承诺跨期实现明确的数值目标**、**公开解释每一次偏离的理由**、**把某条简单规则当对外可比的参照系**（是参照系而非枷锁：定期比较实际决策与规则所暗示的路径，偏离时说明为什么）。

核心定价机制：自由度不是免检的，每一单位自由裁量都要用"可解释性"购买。你想保留多少临场判断的权力，就要公开多少决策依据与偏离原因。这样做的双重回报：市场能理解你，就更能预测你、更少误读；公众能理解你，制度独立性就更稳固——被理解的机构更可能被支持。

制度化载体在书中是：正式2%通胀目标 + 《经济预测摘要》（SEP）+ 点阵图 + 季度发布会。迁移到任何组织时，对应物是公开数值目标、定期预测/预测披露、以及"偏离须逐次说明"的纪律。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2012 年 1 月框架制度化
- **问题**: 美联储长期只有模糊的"双重使命"表述，格林斯潘不愿正式定目标；零利率下需要更强的预期锚。
- **方法论的使用**: 伯南克完成制度化——正式2%通胀目标（PCE口径）+"平衡方式"对待双重使命，同日SEP首次发布点阵图；数值选择本身是工具（"低到足以稳物价、高到足以给有效下限留降息空间"）；政治时机先以SEP长期预测作迂回、再说服国会放行。
- **结论**: 目标+预测摘要+发布会构成有限制的自由裁量权的完整制度。
- **结果**: 框架沿用至今（2020年升级为FAIT）；但点阵图与实际路径不一致的沟通缺陷随后反复暴露。

### 案例 2: 耶伦以"规则作参照系而非枷锁"化解立法施压
- **问题**: 国会立法强制美联储执行泰勒规则，否则接受审计——机械规则的一次政治进攻。
- **方法论的使用**: 论证简单规则的价值在于可比较、可问责，但绑定执行会在经济结构变化时锁死政策——规则做参照系，偏离公开说明即可。
- **结论**: 同一框架在政治防御中的第二次应用。
- **结果**: 施压被化解，"有限制的自由裁量权"获得政治层面的确认。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 组织制度设计：决策层想立机械风控线/硬性KPI，又怕错过规则外的好机会；或反之，纯人治被质疑"凭什么信你"。
2. 对外建立可信度：机构需要向客户/市场/上级证明决策不是任意拍脑袋，想设计目标声明+定期披露+偏离解释的制度。
3. 直接问书中场景：2%通胀目标怎么来的、点阵图是什么、"有限制的自由裁量权"（constrained discretion）如何平衡规则派与相机派。

### 语言信号 (用户的话里出现这些就应激活)

- "立规矩还是给自由 / 机械规则 / 泰勒规则 / Taylor rule / constrained discretion"
- "制度设计 / 决策流程该不该写死 / 有没有中间路线"
- "通胀目标 / 点阵图 / dot plot / 预测摘要 / 参照系"

### 与相邻 skill 的区分

- 与 `commitment-spectrum-design` 的区别: 本 skill 是**整个决策制度**的规则-相机平衡（目标+参照系+解释纪律）；承诺光谱是**单次承诺**的结构参数（日期 vs 状态、门槛 vs 触发）。前者是宪法，后者是具体条款。
- 与 `policy-evaluation-discipline` 的区别: 本 skill 事前设计决策制度；后者事中/事后评估政策效果（意外成分校正、反事实基准）。一个是立法，一个是司法。
- 与 `credibility-capital-management` 的区别: 制度化是信誉的主要存入方式之一，但本 skill 管制度结构本身，不管账户核算。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **设定公开数值目标（锚）**
   - 完成标准: 目标是跨期的、可核验的、数值化的（如最大回撤上限、通胀2%式锚），并说明数值的取舍逻辑（如"给有效下限留降息空间"式的双边界论证）。无跨期问责结构则停用本框架并告知用户。

2. **选一条简单规则作公开参照系**
   - 完成标准: 选定一条可对外复算的简单规则（泰勒规则式/波动率目标式），明确其地位是"参照系而非枷锁"，并设计定期比较的格式。

3. **设计披露机制**
   - 完成标准: 制度含定期预测/决策依据发布（点阵图式或等效物）与偏离解释的固定环节；同时评估披露工具自身的误读风险（点阵图是个体预测聚合而非集体承诺，见 B）。

4. **执行"可解释性购买自由度"纪律**
   - 完成标准: 每次偏离常规参数/规则路径都有逐次书面解释；连续无解释的偏离出现时，框架判定为信誉支取并告警。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无跨期问责结构的组织（纯一次性项目、临时团队）：无法兑现"跨期目标"承诺，制度化只是仪式。
- 问题实质是单次承诺怎么写（日期还是条件）：转 commitment-spectrum-design。
- 问题实质是"这个政策过去效果如何"：转 policy-evaluation-discipline。

### 作者在书中警告的失败模式

- **点阵图与实际指引不一致**（第七章、ce13）：匿名个体预测被市场当作官方路径，2015-16年预测加息次数远多于实际，制度化工具越精确、错位代价越高——设计披露机制时必须预防"预测冒充承诺"。
- **机械规则的枷锁化风险**（第八章）：把参照系当硬约束，会在结构变化时锁死政策——70年代对u*点估计的过度自信即前车之鉴。

### 作者的盲点 / 时代局限

- FAIT 是有限制的自由裁量权的下一代实例，但其非对称设计（只补低不压高）在通胀超标侧缺乏自动刹车，2021-22受通胀考验后作者仅承认问题、未提出修正方案（第十三章）。
- "用可解释性购买自由度"的成本被低估：点阵图式披露本身制造了持续的"沟通债务"（每次脱节都是事故），书中对此的解决方案停留在"主席多澄清"。
- 自辩色彩：框架设计的政治经营（说服国会）着墨详尽，对框架在2021年恰好为推迟加息提供依据的角色复盘不足。

### 容易混淆的邻近方法论

- `commitment-spectrum-design`：制度宪法 vs 单次条款，见 A2。
- `policy-evaluation-discipline`：立法 vs 司法，见 A2。
- `guidance-credibility-design`：披露机制的信誉前提（四支柱）由后者补充。
