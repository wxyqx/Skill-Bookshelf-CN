# 信誉资本资产管理——靠行动建立、需持续维护

## R — 原文 (Reading)

> 这种"时断时续"的模式——在通胀飙升时收紧政策，但在失业率开始上升时又立即放松，结果被证明是无效的，并导致通胀和通胀预期逐步上升。
>
> — 本·伯南克，第二章《伯恩斯与沃尔克》

---

## I — 方法论骨架 (Interpretation)

把信誉当作有形资产入账管理，而不是当作品德口号。它的三个会计属性决定了全部操作：第一，**只能靠行动和结果建立**，口头承诺没有存入效应，言辞无行动支撑反而构成支取；第二，**会贬值**，如所有资本资产一样需要日常维护（言行一致、兑现既有承诺、不搞时断时续的摇摆）；第三，**重建成本远高于维护成本**——沃尔克用1981-82年失业率10.8%的衰退才换回反通胀信誉，这笔"信誉的买价"远贵于平时的每一笔小额维护。

由此得到两套操作规程。日常维护：前任的承诺也是你账户上的负债，"新官不理旧账"等于直接支取信誉资产；要么兑现，要么在早期公开重新议价——后者的支取额远小于默默违约。决策审批：每一项重大决策前先问"此举对信誉账户是存入还是支取"，支取必须换回等值的东西（沃尔克的支取换来了数十年预期锚定），换不回来就不批。

伯恩斯"时断时续"的失败揭示贬值机制：公众从政策的历史模式而非当期宣言推断未来，摇摆一旦被识别，所有承诺都会按"必将被放弃"定价。

## A1 — 书中的应用 (Past Application)

### 案例 1: 沃尔克以衰退重建信誉资产
- **问题**: 1979年接手时通胀预期已脱锚（约10%），口头紧缩已无人相信。
- **方法论的使用**: 以戏剧性行动宣示"现状不可接受"（1979年10月转向），随后顶住拖拉机围堵、木板邮寄、弹劾威胁与1984年政治施压"坚持到底"，把1981-82年衰退当作信誉的买价支付。
- **结论**: 重建靠行动与结果，代价事先认账。
- **结果**: 1982年通胀降至约4%，预期此后数十年锚定，"大稳健"成为信誉红利的宏观证据。

### 案例 2: 伯恩斯"时断时续"使信誉破产（反面）
- **问题**: 70年代通胀抬头就紧缩、失业一升立即放松。
- **方法论的使用**: 每一次半途而废都同时消耗紧缩的真实效果、并向公众证明紧缩不可持续——账户被反复支取而从未存入。
- **结论**: 摇摆比不行动更糟：双目标尽失且预期脱锚。
- **结果**: 通胀螺旋升至1979年的13%，最终需要沃尔克级别的重建。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 接任者纠结"要不要兑现前任许下的承诺"（对客户、董事会、市场的承诺），或想悄悄违约。
2. 组织对外承诺（排期、SLA、服务标准）时紧时松，客户/员工已开始按最坏假设定价，需要重建一致性。
3. 重大决策前的信誉影响评估："这次破例/违约/改口，账户上是存是取？"
4. 直接问书中场景：沃尔克为什么值得、信誉为什么是"资本资产"、大通胀怎么毁掉信誉。

### 语言信号 (用户的话里出现这些就应激活)

- "信誉 / 信用 / 信任崩了 / credibility / trust capital / 预期锚"
- "前任的承诺 / 新官上任 / 要不要兑现旧账 / 继任者该认吗"
- "一会儿这样一会儿那样 / 反复改口 / 言行一致 / 承诺没法信了"

### 与相邻 skill 的区分

- 与 `announcement-as-policy` 的区别: 本 skill 管信誉资产的**长期账户**（建立、维护、折旧、重建）；宣布即干预管**单次危机宣布**的可信度设计。前者是资产负债表，后者是一次交易。
- 与 `stop-go-discipline` 的区别: stop-go 是信誉破产的**具体失败模式**（摇摆节奏），本 skill 是**资产核算视角**——止损摇摆只是维护动作之一，账户还包括前任承诺继承、支取审批等。
- 与 `guidance-credibility-design` 的区别: 后者管单次前瞻指引发布时的可信度四支柱（措辞、声誉、共识、独立性）；本 skill 管声誉这项资产本身的跨期经营。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **建账：盘点信誉资产现状**
   - 完成标准: 评估当前预期锚状态——对方（客户/市场/员工）按什么假设为你定价？历史言行一致吗？判断账户是盈余、损耗还是已透支。判断依据用行动史与结果，不用口头表态。

2. **逐笔核算：存入/支取标注**
   - 完成标准: 对当前争议决策明确标注"存入还是支取"，前任承诺按负债继承处理；若是支取，列出它换回的东西并评估是否等值。
   - 判停条件: 若是支取且换不回等值物，跳到步骤 3 直接给出"不批"建议。

3. **给出处置方案**
   - 完成标准: 三选一并说明——兑现、公开重新议价（早期进行，比默默违约支取小）、违约（仅当换回物等值）。禁止"拖着不表态"的隐性选项。

4. **设定维护机制**
   - 完成标准: 给出防摇摆的日常规则（承诺先于发布做可兑现性审查、公开承诺与内部资源对齐、不因短期痛苦反向），并约定贬值预警信号（对方开始按最坏假设定价）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性危机公关与个人形象修复：目标是单次舆论事件，不涉及跨期预期锚，套用"资本资产"框架会把公关问题复杂化。
- 对方是纯一次性交易关系（无重复博弈）：没有预期定价机制，信誉投资无回报结构。
- 把 skill 当道德劝说用：用户要的是"我要不要守信"的价值判断时，应转回其真实问题——通常是某笔具体的存取核算。

### 作者在书中警告的失败模式

- **时断时续的紧缩**（第二章、ce01）：摇摆比不紧缩更糟，每次转向都被市场定价为不可持续，双目标尽失。
- **"人人知道是临时的"承诺必然失效**（第一章、ce05）：1968年10%临时附加税被储蓄平滑吸收——被理解为临时的承诺近乎无效，宣布"临时"这个词本身可能自废武功。

### 作者的盲点 / 时代局限

- "信誉红利"与大稳健之间的归因（信誉+结构 vs 运气）在书中是主张而非判决性检验。
- 2021年通胀对信誉资产的消耗测试在书成时尚未完结（第十三章承认FAIT受考），作者未能复盘"锚定的预期既是红利也是预警失灵之源"这一机制的全部后果。
- 自辩色彩：伯南克对自己任内承诺（如缩减时点）造成的信誉损耗着墨少于对前任失败的剖析。

### 容易混淆的邻近方法论

- `announcement-as-policy`：单次交易 vs 跨期账户，见 A2。
- `guidance-credibility-design`：单次发布的可信度 vs 声誉资产的跨期经营。
- `stop-go-discipline`：失败模式之一 vs 资产核算总框架。
