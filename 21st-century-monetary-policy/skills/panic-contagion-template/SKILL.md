# 恐慌模板与传染优先——挤兑-贱卖-螺旋的诊断框架

## R — 原文 (Reading)

> 向金融机构提供短期资金的人最容易被挤兑，他们可以很容易地撤回资金，而且这样做几乎没有什么损失。
>
> — 本·伯南克，第五章 全球金融危机

---

## I — 方法论骨架 (Interpretation)

恐慌有一个跨越 century 稳定复现的通用链条：先是信贷繁荣——用短期债务融资去持有投机性或非流动的头寸；然后某个事件（真假消息皆可）逆转信心；短期资金提供者最先夺门而出，因为他们跑得最快、损失最小；被挤兑者为筹现金被迫贱卖长期非流动资产；价格暴跌引发更多破产，新信贷随之断绝，螺旋自我强化。这个模板的作用是给任何危机做定位：说出它此刻卡在第几环、下一环是什么。

评估冲击的破坏力，不看初始损失的绝对值，而看它是否击中了信心与融资结构的传导机制——次贷损失本身并不大，却点燃了整个体系，小损失可以引发大恐慌。据此有两个实务工具：监测仪表盘盯融资条款的边际变化（回购估值折扣从1%抬升到30-40%这类信号），它比"断流/未断流"的二元状态早几周报警；扫描体系时专找"功能上等同银行但不受银行监管"的期限错配伪装者，脆弱性总在监管地图的空白处重建。

## A1 — 书中的应用 (Past Application)

### 案例 1: 影子银行的挤兑——老恐慌的新包装（第五章）
- **问题**: 2007-08年次贷损失本身规模有限，为何演成系统性崩溃？
- **方法论的使用**: 伯南克用恐慌模板逐环定位：影子银行（SIV、回购融资的投资银行、货币基金）以批发融资持有长期非流动资产，正是"用短期债务融资的投机头寸"；次贷亏损逆转信心后，回购对手与货币基金最先挤兑，强制贱卖MBS，估值折扣飙升，螺旋成型。
- **结论**: 这不是新物种危机，而是"挤兑-贱卖-螺旋"经典序列在监管空白处的重演——脆弱性从受保的存款体系转移到了不受保的批发融资体系。
- **结果**: 诊断直接决定处方：对被挤兑的市场逐个充当"最后买家"（TAF、CPFF、TALF），恢复各环节的融资功能。

### 案例 2: 2020年3月的"现金挤兑"（第十章、第十四章）
- **问题**: 这次没有银行倒闭，为什么市场仍然冻结？
- **方法论的使用**: 模板再次定位：共同基金、ETF、做市商等非银行主体用日内融资持有公司债与市政债，疫情冲击下投资者争先赎回，结构上复制了批发挤兑——"dash-for-cash"。
- **结论**: 恐慌模板在新结构下重演，证明监管缺口仍在——凡有期限错配处，凡有"功能等同银行但不受银行监管"的伪装者，恐慌就有宿主。
- **结果**: 美联储两周内对每个被挤兑的市场部署工具，且这次有2008年预置剧本，响应速度从一年多压缩到两周。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某稳定币/理财基金/会员制平台出现小额脱锚或赎回上升，用户问"才3%，要不要紧张"——需要按传导机制而非损失规模做判断。
2. 用户所在行业出现危机苗头（房企、教培、加密、某类供应链金融），想定位"现在处于哪一环、下一步会怎样、会不会传染到自家"。
3. 用户要为组织设计风险预警仪表盘，想知道该盯哪些"早于断流"的边际指标而非二元状态。
4. 用户想扫描自己业务里"功能上等同银行但不受银行监管"的期限错配伪装者（预收款、账期、保证金池）。

### 语言信号 (用户的话里出现这些就应激活)

- "挤兑""run""传染""contagion""会不会蔓延"
- "贱卖""fire sale""抛售螺旋""死亡螺旋"
- "脱锚了要不要紧张""处于哪个阶段""期限错配""影子银行"

### 与相邻 skill 的区分

- 与 `bailout-three-step-program` 的区别: f10 解决"救谁、怎么救、开什么条件"的逐案决策；本 skill 解决"危机处于哪一环、破坏力多大"的系统诊断。先诊断后决策：定位找本 skill，出手找 f10。
- 与 `bagehot-stigma-design` 的区别: f11 处理"工具已就位但该用的人不敢用"的机制摩擦；本 skill 处理恐慌本身的演化。工具失灵找 f11，恐慌定位找本 skill。
- 与 `announcement-as-policy` 的区别: p09 是止住恐慌的手段（可信承诺本身即干预）；本 skill 是判断与监测。止住它找 p09，看清它找本 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画出恐慌链条**
   - 完成标准: 六环各填入具体对象——信贷繁荣（谁用短期债务持有什么头寸）、信心触发器、短期资金提供者是谁、被迫卖什么资产、价格如何反噬、新信贷从哪断。

2. **定位当前环节**
   - 完成标准: 明确输出"处于第N环"及支撑证据（融资条款、赎回数据、价格行为），不是泛泛的"市场很恐慌"。

3. **按传导机制而非损失规模评估破坏力**
   - 完成标准: 给出红色/黄色/绿色分级判断，理由指向"是否击中信心与融资结构"——小损失击中融资结构即为红色，大损失不涉融资结构可为黄色。

4. **建立边际指标仪表盘**
   - 完成标准: 选出2-3个融资条款边际指标（赎回费、估值折扣、保证金比例、展期期限），每个有阈值和观察频率——不使用"断流/未断流"二元指标。

5. **扫描伪装者**
   - 完成标准: 列出体系内"功能等同银行但不受同等监管"的清单（预收款、做市商、金罐平台），标注各自的期限错配程度。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单一机构的偿付性评估与救助决策——先问"该不该救"是 f10 的分诊程序，恐慌模板回答不了这个问题。
- 用户要的是"工具没人用怎么办"——那是机制设计问题（f11），与恐慌阶段无关。
- 纯粹的价格波动讨论：若冲击完全未触及融资结构（如无杠杆资产的账面浮亏），恐慌模板会高估破坏力。

### 作者在书中警告的失败模式

- 把小概率灾难按基准情景对待：2007年3月作者本人向国会称次贷问题"很可能得到控制"，"这既是一种预言，也是一种希望"——安抚语混入评估，概率语言被乐观污染。
- 恐慌动力学是指数型的：晚几个月行动，所需干预规模非线性放大（"不够早、不够大"）；预测模型未纳入"信贷市场全面崩溃"情景时，模型不输出的情景被无意识赋予近零概率。

### 作者的盲点 / 时代局限

- "可控"论出自作者本人，书中以"在当时似乎是一个合理的评估"带过，未正面回答：对外的安抚表述本身会被市场当作信息定价，央行沟通纪律与危机诊断存在张力——自辩色彩。
- 模板在2020年重演证明监管修补是猫鼠游戏，但作者把补漏责任归于监管者，未处理"长期低利率政策本身催生期限错配"的行动主义批评（全书最强反对意见书中未正面处理）。
- 书中建立了"盯边际指标而非二元状态"的预警纪律，却对2021年通胀积累期间未对通胀预警指标做同样处理缺乏自省——"暂时论"复盘不足。

### 容易混淆的邻近方法论

- `bailout-three-step-program`：诊断与决策的分界。链条定位（本 skill）是 f10 第一步"系统性如何"判断的输入，但不替代分类与结构设计。
- `risk-management-insurance`：为低概率恐慌预付保费属 f02；本 skill 只负责"狼来了没、到哪了"。
