# 政策效果评估纪律

## R — 原文 (Reading)

> （交易商预计）88%的可能性会采取该计划……交易商们预计该计划的规模一般都会超过美联储最终选择的规模。因此，在宣布这一消息的当天，市场反应不大也就不足为奇了。
>
> — 本·伯南克，《21世纪货币政策》第十一章

---

## I — 方法论骨架 (Interpretation)

评估一项持续实施的干预，门外汉看"行动之后指标动没动"，本书给出三条更严格的纪律：

1. **意外成分校正**：事件研究只计"实际计划与市场预期的差"。一项早已预告的操作，效果在预期形成时就已经计入价格，宣布日"没反应"恰恰说明它已生效，而非无效。
2. **反事实基准**：不问"干预后复苏快不快"，问"与不采取该行动的假想情景相比是否更好"，并控制政策之外的因素。没有反事实基准的评估会把经济自身的反弹记到政策头上，或把"没有变得更糟"误读为"没起作用"。
3. **保守估计**：建模时刻意排除有利渠道，让结论成为效果的下界。下界仍然显著，结论才站得住。

附带一条防御性反问：面对"效果只是暂时的"这类质疑，用套利检验回敬——若市场真认为效果会反转，为何没有投资者押注反转？持续存在的价格效应本身就是市场对"非暂时"的投票。

## A1 — 书中的应用 (Past Application)

### 案例 1: QE2"无效"之谜（2010）
- **问题**: 2010年11月宣布6000亿美元国债购买计划后，事件日10年期收益率仅降0.18个百分点，批评者引为"QE无效"的铁证。
- **方法论的使用**: 伯南克做归因纠错：事前一级交易商调查已有88%预期该计划，且多数预计规模更大——效果早已计入价格。事件研究必须只计"计划与预期的差"；真正的意外是期限分配中10-30年期券仅占6%。
- **结论**: 校正意外成分后，QE2与QE1同样有效；评估单位应从"流量"转为"存量"（累计持有+预期）。
- **结果**: 事后期限结构模型估计QE1-3累积压低10年期收益率超1.2个百分点，折算约相当于额外降息3-4个百分点。

### 案例 2: FRB/US 保守建模取下界（第十二章）
- **问题**: 要回答"利率降到零之后，非常规工具还剩多少火力"，模型折算依赖大量假设，容易被质疑高估。
- **方法论的使用**: 用FRB/US做数百次模拟，刻意排除有利渠道，使"QE+指引≈额外3个百分点降息"成为效果下界而非最优估计；同时用"与利率降到零后无所作为相比"的反事实评估贡献。
- **结论**: 即使按保守口径，新工具也足以应对典型衰退——尽管作者承认该数字不确定区间大、不可外推。
- **结果**: 这一保守下界成为后危机时代工具箱正当性论证的核心证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 干预实施后数据"没反应"，有人据此主张撤掉它——需要判断是"无效"还是"已被预期/尚未传导"。
2. 需要向决策层或公众证明"是政策起了作用，不是经济自己好转"——要搭一个可信的因果归因框架。
3. 政策被批评"效果只是暂时的、治标不治本"，需要结构性回应而非情绪辩护。
4. 多项措施同时出台，说不清哪个起效、各占多少——需要归因纪律拆分。

### 语言信号 (用户的话里出现这些就应激活)

- "好像没什么效果，是不是该停了"
- "有人说效果只是暂时的，怎么反驳"
- "怎么证明是它的功劳而不是市场自己反弹"
- "反事实 / counterfactual / 事件研究 / 归因"

### 与相邻 skill 的区分

- 与 `signal-engineering` 的区别: 那是事前设计"如何让宣布不被误读"（形式工程）；本 skill 是事后评估"干预到底起没起作用"（效果归因）。
- 与 `policy-firepower-accounting` 的区别: 那是事前量化"还剩多少政策空间"（弹药盘点）；本 skill 是事后验证"已打出的弹药命中了多少"（战果核算）。QE 的"3个百分点"是两者的接口但用途相反。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **校正意外成分**
   - 找出行动前市场/相关方的预期基准（调查、定价、预告内容），只把"实际计划与预期的差"计为待评估的干预量。
   - 完成标准: 能明确说出"预期是什么、实际是什么、差在哪里"；找不到预期数据时显式声明该纪律不可用并降级结论置信度。

2. **建立反事实基准**
   - 构造"不采取该行动"的假想情景，控制政策外因素（季节性、外生冲击、其他并行干预）。
   - 完成标准: 产出至少一个可陈述的反事实情景及其依据，评估结论以"相对反事实的改善"表述，不以绝对结果表述。
   - 判停条件: 若干预本身可随机化/可对照（存在天然对照组），直接用对照实验替代假想情景，跳到步骤3。

3. **做保守估计**
   - 刻意排除有利渠道与乐观假设，重新计算效果，使结论成为下界。
   - 完成标准: 给出"即使排除X渠道，效果仍为Y"形式的双层结论，并标注下界的假设清单。

4. **用套利检验回应"暂时论"**
   - 检查是否存在与"效果会反转"对赌的市场行为（押注反转的头寸、竞品的反向操作、长期合约定价）。
   - 完成标准: 结论中能回答"若真暂时，为何没人押注反转"，或承认无人对赌时该论证的局限。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性、可逆、低成本的小决策复盘——三条纪律的成本超过决策价值，直接看结果即可。
- 纯相关观察且无法获得任何预期数据或对照的场合——此时应先说"无法评估"，而不是硬套框架产出伪精确结论。
- 事前决策场景（要不要做、还有多少空间）——那是火力核算与先发制人的领地，本 skill 只做事后评估。

### 作者在书中警告的失败模式

- 单一模型折算的脆弱性（ce18）: "3个百分点"经验法则依赖FRB/US的隐含假设，环境变化会使折算系数本身漂移——保守下界也可能霉变，须定期重估假设清单。
- 市场情报失真导致虚假确认（ce11）: 预期调查的覆盖面窄于实际参与者结构（一级交易商遗漏"无限QE"持有人），会造成"预期已对齐"的错误判断——意外成分校正的前提是预期测得准。
- 把"复苏快于预期"直接记为政策战果: 疫情后复苏的证据被封锁型衰退的独特性质污染，归因不干净。

### 作者的盲点 / 时代局限

- 自辩色彩: 作者对 QE 收益侧做了严格的保守估计，对成本侧（不平等、资产泡沫、退出困难）仅以"可控"带过、缺乏对称的量化——本 skill 若只学其收益评估，会继承"只对有利结论严格"的不对称。
- "宣布即有效"的归因分离未经判决性检验: 宣布效应可能混杂财政救助预期，书中未拆分。
- 对 2021 年"暂时论"的复盘不足: 作者本人曾受益于类似归因纠错逻辑，但对通胀侧"暂时性"判断的评估纪律失误着墨很少。

### 容易混淆的邻近方法论

- 通用因果推断（双重差分、断点回归）: 工具同源，但本 skill 特有的是"意外成分校正"这一预期计价视角与"套利反问"，处理的是"干预已被预期"这类传统方法盲区。
- A/B 测试: 是反事实基准的实验化特例；当无法随机化时，本 skill 的假想情景+保守估计才登场。
