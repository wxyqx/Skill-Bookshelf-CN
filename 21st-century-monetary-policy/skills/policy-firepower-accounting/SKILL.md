# 政策火力核算——弹药盘点与空间管理

## R — 原文 (Reading)

> 量化宽松辅之以政策制定者承诺采取更低利率政策的前瞻性指引，可以提供相当于额外约3个百分点的政策空间。换句话说，如果中性利率为2.5%……接近美联储在有效下限成为问题之前对典型经济衰退做出的正常反应。
>
> — 本·伯南克，第十二章 美联储的工具箱足够了吗

---

## I — 方法论骨架 (Interpretation)

把应对下行的资源当成弹药库来管理，核心动作是把异质武器折算成同一单位。基准单位是降息幅度：传统火力≈政策利率能降多少，由中性利率 R* 决定；非常规火力则按"压低10年期收益率1个百分点≈降息3个百分点"的经验系数，把 QE、前瞻指引等折算成"等效降息"。两者加总得到总火力，再对照压力情景的需求（应对典型衰退大约需要降息5-6个百分点），得出够或不够的结论。

这个核算体系有两个反直觉推论。其一，"运行指标越漂亮，危机弹药越少"——平时把利率维持在与景气匹配的中性水平而不留余地，等于把弹药提前打光，所以好年景可能要刻意保持偏高的利率来储备空间。其二，"实现目标本身就是储备弹药"——通胀持续不达标会拉低 R*、侵蚀未来的传统降息空间，达成目标不是消耗弹药而是在补充它。

## A1 — 书中的应用 (Past Application)

### 案例 1: 第十二章的 FRB/US 模拟火力盘点
- **问题**: 2008年后利率长期贴着有效下限，公众与学界都在问：再来一场衰退，美联储还有弹药吗？
- **方法论的使用**: 伯南克用美联储 FRB/US 模型做数百次模拟，把 QE 与前瞻指引的效果折算成等效降息——经验法则是10年期收益率每降1个百分点≈联邦基金利率降3个百分点，危机后 QE+指引累积压低10年期收益率超1.2个百分点，折合约额外3个百分点的降息空间。
- **结论**: 总火力≈R*（可降息幅度）+3个百分点；若 R* 为2.5%，总火力约5.5个百分点，接近危机前对典型衰退的正常反应幅度。
- **结果**: 作者同时自认不确定区间大：新工具创造的空间"有可能不到3个百分点"，且随经济与市场状况变化，不能外推到他国——核算结论是带误差棒的下界。

### 案例 2: R* 结构性下行为核算提供分母（第四章、第十三章）
- **问题**: 数十年间 R* 从实际值超3.5%降到不足0.5%，传统降息空间被结构性压缩。
- **方法论的使用**: 核算框架先量化传统空间的收缩，再倒逼非常规工具的折算入库；通胀持续不达标进一步拉低 R*，于是"把通胀拉回目标"本身被计入储备资产。
- **结论**: 弹药不足不是宿命——第十三章据此主张研究外国央行的负利率、收益率曲线控制等新工具，把工具扩展本身当作补给线。
- **结果**: 核算框架成为"要不要为下一场危机提前立法授权新工具"这类制度讨论的共同底座。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 财务负责人在景气年份纠结"该把现金/授信/预算用到多满"——需要一套"典型下行要耗多少、现在存了多少"的量化盘点。
2. 团队已用尽常规手段（降价、加投放），想知道非常规手段（渠道创新、跨界合作）能折算成多少常规当量，总火力够不够覆盖最坏情景。
3. 用户发现"当期目标达成"与"未来弹药"冲突（如低价冲量侵蚀未来定价空间、低利率环境侵蚀未来降息空间），需要判断要不要为储备而放弃当期最优。
4. 制定组织的"弹药储备规则"：好年景留多少冗余、哪些非常规工具入库折算、谁的消耗要计入分母。

### 语言信号 (用户的话里出现这些就应激活)

- "政策空间""弹药""firepower""dry powder""还剩多少子弹"
- "等效降息""折算成多少""R*""中性利率"
- "下一场衰退/危机还够不够用""要不要留余地""好年景储备"

### 与相邻 skill 的区分

- 与 `risk-management-insurance` 的区别: f02 解决"怎么花弹药"（为尾部风险付保费、事后回收）；本 skill 解决"弹药还剩多少、要不要储备"。花钱找 f02，盘点找本 skill。
- 与 `policy-evaluation-discipline` 的区别: f13 是事后评估某次干预有没有效（意外成分校正、反事实基准）；本 skill 是事前核算空间存量。评估效果找 f13，盘点空间找本 skill。
- 与 `preemptive-strike-policy` 的区别: f01 决定行动时点（等不等）；本 skill 决定行动的资源前提（够不够）。时点问题找 f01。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定义基准工具与核算单位**
   - 完成标准: 明确"基准弹药"是什么（降息、现金、核心产能）、折算单位是什么（等效降息/等效现金），后续所有数字共用该单位。

2. **盘点传统空间**
   - 完成标准: 给出传统火力数字及其依据（对央行是 R* 估计带区间；对企业是现金+授信+可压缩成本），不可观测参数必须以区间表达。

3. **折算非常规工具入库**
   - 完成标准: 每项非常规工具有折算系数、系数的证据来源和不确定性区间；书中警告——系数可能小于经验值且随环境漂移，需标记为下界。
   - 判停条件: 若某工具完全无历史证据支撑折算系数，不强行入库，单独转入"工具扩展"讨论。

4. **对照压力情景需求**
   - 完成标准: 写出最坏/典型情景的弹药需求（如典型衰退需5-6个百分点），输出"缺口/盈余"结论。

5. **输出储备规则**
   - 完成标准: 产出可执行的储备策略——好年景保留多少冗余、把"目标达成本身"计入储备资产（如维持通胀目标以守住 R*）、下次复盘的时间点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单次战术决策的资源分配（一次投放、一笔支出）——不需要全套弹药核算，套用是大炮打蚊子。
- 无法定义共同折算单位的多维资源盘点——硬折算会制造虚假精度。
- 用户问的是"这次干预效果如何"——那是政策效果评估纪律（f13）。

### 作者在书中警告的失败模式

- 单一模型折算的脆弱性：FRB/US 把多渠道效应压缩成一个线性系数，"新工具创造的政策空间有可能不到3个百分点"，且会因经济或金融市场状况而不同；支撑证据部分来自疫情衰退这一非常态环境（封锁型需求萎缩与利率无关），归因不干净。
- 把等效空间当不会霉变的库存弹药——环境变化会使折算系数本身漂移，弹药会"过期"。

### 作者的盲点 / 时代局限

- "3个百分点"结论出自 QE 推行者本人，自辩色彩明显：核算只算了收益侧弹药，QE 成本侧（不平等、资产泡沫、退出困难）仅以"可控"带过、无量化。
- 框架默认弹药只被衰退消耗，未纳入2021-22年加息周期"双向消耗空间"的情形——FAIT 时代通胀重来时，紧缩同样需要空间，这层核算在书中缺失。
- 与"救雷曼也无法阻止恐慌"的反事实一样，等效3个百分点缺乏判决性检验，作者承认不可外推却仍以点估计口径参与公共讨论。

### 容易混淆的邻近方法论

- `stop-go-discipline`：那是节奏纪律（摇摆比不行动更糟）；本 skill 是存量核算。但两者可在"为储备弹药而放弃时断时续式微调"处衔接。
- `policy-evaluation-discipline`：f13 的保守估计（刻意排除有利渠道取下界）正是本 skill 折算系数应当继承的方法论。
