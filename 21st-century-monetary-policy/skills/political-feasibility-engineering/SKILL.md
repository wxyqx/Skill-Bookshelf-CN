# 政治可行性工程

## R — 原文 (Reading)

> 正如一些鹰派人士警告的那样，新一轮的量化宽松政策确实引发了政治反弹。令我特别不安的是，11月17日，也就是QE2宣布两周后，国会中的四名共和党人士破天荒给我写了一封信。
>
> — 本·伯南克，《21世纪货币政策》第六章

---

## I — 方法论骨架 (Interpretation)

正确的决定不自动拥有政治生存权。本书把"如何让不受欢迎的正确决策活下来"当作一门工程，包含五个可单独部署的部件：

1. **威胁测绘**：先回答谁会攻击、攻击什么措辞、通过什么渠道（信件、听证、泄露、民粹叙事），再选对策。
2. **替罪羊对冲**：独立机构的宿命是被期待做脏活——紧缩、叫停、问责都由你来出。对策不是回避，而是绕过中间人直接向公众解释，用大白话重建正当性。
3. **政治掩护**：把决定装进技术框架（规则、程序、模型输出），让"利率/处罚是副产品而非我们的选择"，把火力从立场之争转移到参数之争。
4. **任命经济学**：关键岗位选名声与任务匹配的人——要收紧就派可信的鹰派，人选本身先行压制"选择性执法/立场偏袒"的质疑。
5. **叙事先发**：明知会面内容会被泄露，就在会后立即发布己方版本，抢占框架；配合日常的"先例经营"（每次都是先例，惯例比条文管用）。

贯穿纪律：只谈数据不谈政治、不回应人身攻击、不评论管辖外事务——用程序正当性代替立场辩论。

## A1 — 书中的应用 (Past Application)

### 案例 1: QE2 政治反弹与沟通转向（2010）
- **问题**: 纯技术性的购债决策被读作"印钞救市/美元贬值"，两周内收到四位共和党议员的破天荒公开信，随后出现"叛国"级人身攻击，盖洛普支持率跌至联邦机构末位。
- **方法论的使用**: 伯南克诊断失败机理——政策的可见成本（账面扩表）集中而显性，收益（未发生的更深衰退）分散而反事实，技术共识无法自动兑换政治合法性——于是改为替罪羊对冲：主席直接上电视媒体、开启季度新闻发布会，绕过国会转译层向公众直连解释。
- **结论**: 独立性靠"被理解"维系，沟通是政治经营的延伸。
- **结果**: 反弹未撤销 QE2，但重建了公众沟通通道，"上媒体+季度发布会"成为常设制度。

### 案例 2: 鲍威尔对特朗普的组合拳（2019）
- **问题**: 总统持续推文施压并放风"解雇鲍威尔"，任何回应都会被放大成机构对抗白宫。
- **方法论的使用**: 防御组合完整执行——每次会后都开发布会以杜绝"私下妥协"猜测；对贸易政策等管辖外议题一律不评论；被总统在晚宴上当面质问后立即发新闻稿自定叙事（叙事先发）；以"磨破地毯"式的国会日常经营换取制度缓冲。
- **结论**: 对施压的回应是程序化的稳定输出，而非立场交锋。
- **结果**: 独立性未受损，2019年政策转向被市场解读为数据驱动而非政治屈从。

### 案例 3: 沃尔克的沉默离场（1984）
- **问题**: 财政部长贝克当面警告大选前不要加息。
- **方法论的使用**: 不辩解、不承诺、一言不发离场，然后用继续加息的行动划界。
- **结论**: 当语言必然被解读为立场博弈时，行动是唯一不被污染的信号。
- **结果**: 加息照做，通胀预期未脱锚。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 独立机构/职业经理人要出台收紧、叫停、问责类决定，预期会遭到公开政治攻击。
2. 决定已出台且遭遇反弹（公开信、听证传唤、舆论围攻），需要止损与正当性重建。
3. 一次敏感会面注定被对方或在场者泄露，需要管理事后叙事。
4. 关键岗位人选本身就是信号——需要设计"谁去署名、谁去谈判、谁去作证"。
5. 被上级要求做边界外的事（评论管辖外议题、回应人身攻击），需要拒绝的纪律话术。

### 语言信号 (用户的话里出现这些就应激活)

- "上面/国会/股东施压怎么办"
- "这个决定肯定会被骂，怎么顶住"
- "会面内容一定会被泄露"
- "让谁去出面/署名合适" / "under political pressure"

### 与相邻 skill 的区分

- 与 `credibility-capital-management` 的区别: 那是长期信誉资产的建立与折旧管理（跨年度的存取核算）；本 skill 是针对具体政治攻击的即期战术集，一次会面、一封信、一个人选的工程。
- 与 `signal-engineering` 的区别: 那是设计政策宣布本身的形式（戏剧性 vs 铺陈）；本 skill 处理宣布之后政治系统的反应面——攻击、泄露、问责的攻防。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **威胁测绘**
   - 列出攻击者（谁）、攻击点（"越权/偏袒/冷血/实验"哪类叙事）、渠道（信件、听证、泄露、社媒）与时机。
   - 完成标准: 产出威胁清单，每条攻击点对应至少一个可预防或可回应的接口。

2. **选配防御组合**
   - 逐项部署：只谈数据不谈政治、不回应人身批评、不评论管辖外事务、以程序正当性代替立场辩论；明确每条的拒绝话术。
   - 完成标准: 形成一页"回应纪律"，任何外部质询都能映射到四条之一。

3. **部署人选与程序掩护**
   - 检查署名人/出面人的名声与任务是否匹配（任命经济学）；把决定装进规则、授权条款或模型输出等程序容器。
   - 完成标准: 能回答"为什么是他出面"与"决定为什么是程序的产物而非个人的偏好"。
   - 判停条件: 若决定完全无法装入任何程序框架（纯个人裁量），回到威胁测绘重估可行性，而非硬推。

4. **叙事先发与先例经营**
   - 对高泄露风险会面预设会后己方版本并第一时间发布；把本次行动的边界处理登记为今后可援引的先例。
   - 完成标准: 会后纪要/新闻稿先于或同步于任何对方版本出现；先例登记入档。

5. **复盘可见成本与反事实收益的呈现**
   - 主动把"未发生的更坏情景"翻译成公众可感知的对照（替罪羊对冲的实质）。
   - 完成标准: 对外材料中至少有一处"与不行动相比"的显性对照表述。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯内部技术分歧（团队两派争论方案优劣）——没有政治攻击面，套用攻防战术只会把技术问题政治化。
- 可以通过利益交换或方案修改化解的普通谈判——先谈内容，政治工程是内容谈不动时的第二阶段。
- 无需公开辩护的低层级日常决策——战术成本（发布会、纪要、先例登记）超过其价值。

### 作者在书中警告的失败模式

- 技术共识无法自动兑换政治合法性（ce14）: 政策可见成本集中、收益反事实分散，在政治市场上天然失分——指望"科学正确"自动获得支持是结构性错误。
- 沟通脱节引爆政治危机（ce15）: 2018年12月多点紧缩信号叠加，市场与政治同时反噬，一个月内被迫全盘转向——政治可行性是政策设计的输入而非事后公关。
- 沉默与拖延的代价: 伯南克自承2007-08年行动"不够早、不够大"，部分原因正是"怕被视为反应过度"的政治顾虑压过了损失分布判断。

### 作者的盲点 / 时代局限

- 自辩色彩: 作者把独立性受损主要归因于沟通不足，但对"QE救助加剧财富不平等"这一政治反弹的真实根源（分配后果）书中未正面处理——战术再好，若分配后果真实存在，对冲只是推迟清算。
- 对 2021 年通胀引发的政治问责复盘不足: FAIT 框架受通胀考验后独立性遭到的侵蚀，超出其"沟通可以解决"框架的解释力。
- 时代局限: 书中战术以美国两党制、成熟媒体环境为背景；在机构间权责更模糊的环境里，"程序正当性"能否充当掩护未经验证。

### 容易混淆的邻近方法论

- 公关/危机公关: 通用公关管品牌形象，本 skill 只服务"让正确决定活下来"这一个目标，且拒绝形象化的安抚话术（那会损耗信誉资本）。
- 科层政治学（upward management）: 向上管理是影响上级决策，本 skill 是决策已定后的外部攻防，两者可衔接但对象不同。
