# 先发制人打击——长时滞下等通胀出现再动手就太迟

## R — 原文 (Reading)

> 货币政策对通胀的影响有着明显的滞后效应……如果美联储要等到实际通胀恶化后才采取对策，那就太久了。在这一点上，适度的纠正措施将不再足够……相反需要采取更严厉的措施，即使这会对短期的经济活动产生不可避免的负面影响。
>
> — 本·伯南克，第三章《格林斯潘和繁荣的20世纪90年代》

---

## I — 方法论骨架 (Interpretation)

适用前提有两条，缺一不可：你的工具产生效果有明显时滞（货币政策对通胀的时滞在一年以上），且问题恶化后再纠偏，所需力度非线性放大。两条都成立时，"等确凿证据再行动"不是一个谨慎选项，而是一个必然迟到的选项——因为行动生效时你面对的已经是过去的经济。

操作上：不等问题在数据里"坐实"，在苗头期（指标尚温和、尚可作多种解释）就小步行动，用温和、可控的误伤代价，换一张"免于日后激烈矫枉"的期权。先发制人买的不是确定结果，而是避免最坏路径的可能。

配套一条核算纪律，用来对冲"再等一个季度"的直觉：每次想等待时，先显式估算两个数——等待的期望成本（问题恶化概率 × 恶化后纠偏的额外代价）与提前行动的误伤成本（行动错了损失什么）。两者孰高，决定动不动。门外汉的默认直觉恰是"等证据确凿"，本方法论的全部价值就在于把这个直觉倒过来并给出核算程序。

## A1 — 书中的应用 (Past Application)

### 案例 1: 格林斯潘 1994-96 年教科书级软着陆
- **问题**: 1994年初通胀仍低、失业仍高，经济刚复苏，要不要加息？
- **方法论的使用**: 格林斯潘依据"政策时滞一年以上、等通胀出现再动手就太迟"的逻辑，在通胀尚未抬头时启动五年来首次加息（25基点），一年内把联邦基金利率从3%提到6%，并预先把"债市大屠杀"的副作用纳入管理。
- **结论**: 先发制人的紧缩可以在通胀成形之前扼住压力累积。
- **结果**: 通胀未起、扩张延续至2001年，成为软着陆的经典范本。

### 案例 2: 2021 年"暂时论"——先发制人的反面
- **问题**: 2021年通胀飙升，FOMC押注"暂时性"（供给瓶颈可缓解、预期锚定），选择等"切实证据"再行动。
- **方法论的使用**: 行动标准被设为"观察到通胀证据"，而观察指标本身滞后于压力积累——正是"等通胀出现再动手"的时滞陷阱在FAIT框架下的重演。
- **结论**: 放弃先发制人 = 把温和纠偏的期权白白作废。
- **结果**: 通胀持续超预期（书成时CPI已超6%），最终被迫以几十年最陡的紧缩收拾，代价远超提前小步行动。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 运营指标缓慢恶化（响应时长、错误率、流失苗头），修复手段周期长（招人、培训、重构），团队倾向"等下季度数据确认"。
2. 监管/合规/技术债问题尚无事故，但一旦爆发整改代价巨大，决策层在"现在小步投入"与"出事再大修"之间摇摆。
3. 直接问书中场景：美联储为什么要在通胀还没起来时加息、2021年为什么没早点动手、软着陆怎么实现。
4. 政策/制度设计者讨论"行动触发标准应该设在苗头期还是确认期"。

### 语言信号 (用户的话里出现这些就应激活)

- "等更多数据确认 / 再观察一个季度 / 现在动手是不是反应过度"
- "苗头 / 趁早 / 提前行动 / preemptive / act early / nip it in the bud"
- "等出了事再修就来不及了 / 时滞 / 滞后效应"

### 与相邻 skill 的区分

- 与 `risk-management-insurance` 的区别: 先发制人应对的是**基准情景正在缓慢恶化**的问题（苗头已现、方向明确）；保险式决策应对的是**低概率高破坏的尾部风险**（基准情景本来没事）。前者问"现在动不动"，后者问"要为小概率付多少保费"。
- 与 `stop-go-discipline` 的区别: 先发制人管**启动时点**（什么时候该出手）；stop-go-discipline 管**启动后的坚持性**（已经开始收紧/改革后能不能不摇摆）。2021年问题是前者，伯恩斯问题是后者。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认适用前提：时滞 + 非线性**
   - 完成标准: 明确说出该决策中工具的生效时滞大约多长、问题恶化后纠偏成本如何上升。若时滞短且可随时回滚，则本框架不适用，直接告知用户。

2. **期望成本核算**
   - 完成标准: 给出两个数——等待的期望成本（恶化概率 × 恶化后纠偏的额外代价）与提前行动的误伤成本（行动错了损失什么），并比较孰高。禁止只列定性理由。
   - 判停条件: 若等待成本明显低于误伤成本，得出"可以再等"的结论并说明监测指标，跳到步骤 4。

3. **设计小步行动序列**
   - 完成标准: 行动方案为"苗头期小步 + 可加码"的序列而非一次性重手，并说明每步的升级触发条件；同时管理已知副作用（如1994年预先纳入"债市大屠杀"）。

4. **预设复盘锚点**
   - 完成标准: 约定何时回看"等待成本核算"是否成立，防止等待决策在无核算的情况下被无限顺延（2021年教训）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 短时滞、可逆性高的日常决策：随时可回滚的事情不需要买"避免激烈矫枉"的期权，先发制人反而是过度反应。
- 低概率尾部风险的定价：基准情景本来没事、只是怕万一——那是要不要买保险的问题（risk-management-insurance），硬套先发制人会导致对一切小概率风险过度出手。

### 作者在书中警告的失败模式

- **等通胀出现再动手的时滞陷阱**（第三章）：等待本身制造了本想避免的代价——温和措施窗口关闭后只剩激烈紧缩。
- **对不可观测锚过度自信导致的苗头误判**（第一章、ce04）：60年代政策制定者把自然失业率u*当硬约束，通胀已升也不修正，宽松维持过久——先发制人要求判断"苗头"，而判断所依赖的关键参数往往不可观测。
- **2021年"暂时论"**（第十章、第十三章）："这次是暂时/供给侧的"成为延迟行动的主要论据，"预期仍锚定"被用作不动手的充分条件。

### 作者的盲点 / 时代局限

- 对2021年"暂时论"的复盘不足：作者承认FAIT"为低通胀世界设计"、在通胀超标时可能反应迟钝，但未清算"等证据"标准与自身先发制人主张之间的矛盾。
- 时代局限：FAIT框架在2021-22通胀考验中的表现、菲利普斯曲线趋平后"苗头"是否还可识别、R*走势，均未经判决性检验。
- 自辩色彩：对QE成本侧仅以"可控"带过；先发制人的"误伤成本核算"在书中停留在叙事层面，未给出可操作的核算表。

### 容易混淆的邻近方法论

- `risk-management-insurance`：苗头型恶化 vs 尾部型风险，见 A2 区分。
- `stop-go-discipline`：出手时点 vs 出手后的坚持。
- `policy-firepower-accounting`：本 skill 管"何时用弹药"，后者管"还剩多少弹药"。
