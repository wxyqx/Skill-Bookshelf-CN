# GLOSSARY — 《当音乐停止之后》共享术语词典

> 布林德的特定用法。与书架其他卷术语体系不同。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **七祸源** | 两个泡沫+杠杆+监管松懈+次贷+无监管衍生品+评级+薪酬——叠加共振的清单 | ≠ 单因论（贪婪银行家/低利率任选）；是清单化归因 |
| **威利狼模型** | 泡沫破灭时点不可预测——走到悬崖外才"往下看" | ≠ 泡沫可预测论；事前识别近乎不可能 |
| **影子银行** | 非银放贷+两房+投行+SIV+货币基金及其市场构成的监管外体系 | ≠ 模糊修辞；机构+市场的清单式定义 |
| **牵连太多而不能倒** | 救贝尔斯登的理由：主经纪商+衍生品对手+回购市场+风险同质（资产仅 3950 亿、16 家更大） | ≠ "大而不倒"规模论；是网络关联论 |
| **规则手册机制** | 市场可承受任何清晰规则，不可承受规则突变——"不一致性是心魔" | ≠ 救助万能论/破产万能论；一致性优先 |
| **白芝浩三和音** | 最后贷款人：自由借贷、优质抵押物、惩罚性利率 | 19 世纪原则的现代工具化变体（TAF/TSLF） |
| **利差之战** | 危机战场从利率转向利差：国债利率跌掩盖利差飙升 | ≠ 利率政策；利差才是传导变量 |
| **QE 2×2 矩阵** | 非常规操作：结构/规模×国债/私人债券 | ≠ 笼统的"印钱"；是工具谱系分类 |
| **大而不乱** | "大而不倒"的正解：不求拆分，只求有序清算决议机制 | ≠ 规模管制；是处置机制建设 |
| **三位一体障碍** | 止赎政策失败：巨额资金（贷非花）+产权阻力+救助失败者污名 | ≠ 执行力问题；是结构性政治障碍 |
| **政策的悖论** | 干预成功→善意流失→政治反弹→干预能力自毁 | ≠ 一般的民意波动；是干预型政策的内生反弹 |
| **金融十诫** | 记住人们所忘记的、不靠自我监管、少用杠杆、保持简单、衍生品场内化、调薪酬等 | ≠ 立法条文；是行业行为层的方向性戒律 |
