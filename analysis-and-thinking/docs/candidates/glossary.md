# candidates/glossary.md — 《分析与思考》共享术语

```yaml
- id: g01
  term: 问题—结构—对策
  source_chapter: 后记
  author_definition: |
    作者自述核心研究范式："先研究问题、分析问题，找到问题结构性的、体制性的、机制性的、
    制度性的短板，通过改变问题的联系方式、边界条件，使得问题朝着理想的方向和预期的目标转化。"
  key_distinction: |
    ≠ 总量调控（油门）；= 改造结构（气缸）。书架已有 five-step-structural-analysis 是其操作化
    展开，本词典正式挂接作者的官方命名。
  why_it_matters: 全部 skill 的元框架；引用时用作者自己的名字以保真。
  tags: [term, meta]

- id: g02
  term: 汇兑本位制
  source_chapter: 第4讲
  author_definition: 作者对人民币现行发行制度的诊断命名：外汇占款主导基础货币投放（峰值 83%），
    实质间接锚定美元。
  key_distinction: ≠ 联系汇率制（钉住）；≠ 主权信用制（锚本国）；是介于两者之间的过渡态标签。
  why_it_matters: 货币制度类 skill 的核心判别词。
  tags: [term, currency]

- id: g03
  term: 金融本质三句话
  source_chapter: 第1讲、附录
  author_definition: 为有钱人理财为缺钱人融资；信用—杠杆—风险三环节把握度；一切金融活动为实体经济服务。
  key_distinction: 不是行业定义，是异化检验的三重标准。
  why_it_matters: 金融类 skill 的价值基准。
  tags: [term, finance]

- id: g04
  term: 六种杠杆黏结工具
  source_chapter: 第1讲
  author_definition: 高息揽储、刚性兑付、资金池、错配、通道、嵌套——"纵横交错叠加在一起……就是十八般武器"。
  key_distinction: ≠ 单个违规行为；是可组合的底层部件，乱象=组合。
  why_it_matters: 乱象识别类 skill 的部件清单。
  tags: [term, risk]

- id: g05
  term: GDP 1:1 标尺
  source_chapter: 第13讲
  author_definition: M2、政府债务、股市总市值、房地产总市值与 GDP 之比正常不超 1:1，达 1.5:1 为严重泡沫。
  key_distinction: 经验标尺非定理；美国 M2/GDP 天然低于 1（储备货币国），须分国校准。
  why_it_matters: 泡沫诊断类 skill 的阈值体系。
  tags: [term, valuation]

- id: g06
  term: 三零
  source_chapter: 第10讲
  author_definition: 零关税、零壁垒、零补贴——中间品贸易 70% 时代 FTA 的规则方向；"三零不等于统统归零"。
  key_distinction: ≠ WTO 现行规则；是趋势方向与谈判筹码。
  why_it_matters: 贸易类 skill 的规则坐标。
  tags: [term, trade]

- id: g07
  term: 危机后移
  source_chapter: 第13讲
  author_definition: 用吹大另一个泡沫对冲当前危机：股市→房地产→政府债务——"把现在的危机推向未来"。
  key_distinction: ≠ 危机解除；是风险的空间/时间转移。
  why_it_matters: 宏观预测类 skill 的传导逻辑。
  tags: [term, crisis]

- id: g08
  term: 六分之一理论
  source_chapter: 第8讲
  author_definition: 房租≤月收入 1/6；一生买房支出≤工作年限收入 1/6；房地产投资≤固投 25%、≤GDP 1/6——重庆治理实践归纳的经验系数。
  key_distinction: 经验逻辑而非国际统计口径；用于快速判断可负担性。
  why_it_matters: 住房类 skill 的量化标尺。
  tags: [term, housing]

- id: g09
  term: 五个蓄水池
  source_chapter: 第14讲
  author_definition: 人民币国际化五条水道：跨境贸易结算、本币互换、离岸人民币、
    "一带一路"人民币使用、大宗物资人民币计价。
  key_distinction: ≠ 单一清算渠道建设；是多市场分层蓄水。
  why_it_matters: 人民币类 skill 的路径地图。
  tags: [term, rmb]

- id: g10
  term: 三链
  source_chapter: 第10讲
  author_definition: 产业链集群、供应链纽带、价值链枢纽（结算点）；"控制了交易所就掌控了产业链附加值的枢纽、供应链的纽带、产业链集群的核心"。
  key_distinction: 与姊妹卷 chain-power-analysis 同源；本书补充"结算枢纽即财富中心"（1.8 万亿结算在境外）。
  why_it_matters: 跨书术语，与已有 skill 词典挂接。
  tags: [term, value-chain]
```
