  type: decision-framework
  source_chapter: 第1章
  source_quote: |

- id: f10
  title: 先有理由再有结论（理由是模具）
  type: mental-model
  source_chapter: 第3章
  source_quote: |
    "要竭力避免'逆向逻辑'或'反向推理'，这样做的理由不过是追加的一记马后炮而已，它们会随着你的结论而变化。理想的做法是，理由是模具，结论据此得以成型和修改。"（第3章）
  summary: |
    防止"结论先行"的思维模型：先充分探究、掂量各种可能的理由及其分量，让结论从理由中"成型"，而不是先攥住结论再倒推理由（逆向逻辑）。识别信号：被问及理由时一脸茫然、恼羞成怒，或理由随结论当场变化——弱势批判性思维的警报。用法：写作/表态前先做理由探究，随着理由充分思考，让初始结论"屹立不倒或轰然倒塌"。

  type: decision-framework

  source_chapter: 第5章
  source_quote: |
    "这样，判定价值取向的一个重要方法就是问一下这个问题：'为什么作者用做理由的特定后果或结果对他而言显得那样可取？'"（第5章）

  type: decision-framework
  source_chapter: 第5章
  source_quote: |
    "（1）不断思考理由和结论之间的鸿沟。（2）寻找支持理由的那些想法。（3）把自己放到对立的反对立场。（4）意识到还有其他潜在的方法可以获得理由中提到的种种好处。（5）对论题进一步学习了解。"（第5章）

- id: f15
  title: 谬误三问判别法（不背名称识破花招）
  type: decision-framework
  source_chapter: 第6章
  source_quote: |
    "（1）提供的推理需要明显错误的或者让人不能接受的假设才能成立……（2）把那些明明和结论无关的信息弄得好像和结论有关，以此来分散我们的注意力；（3）看似为结论找证据，而证据算数的前提则取决于结论本身已经成立。"（第6章）
  summary: |

- id: f16
  title: 事实断言三问与证据类型分级审查
  type: decision-framework
  source_chapter: 第7章
  source_quote: |
    "对于事实断言你要问的第一个问题就是：'我为什么要相信它？'……证据的质量主要取决于证据的类型。因此，要评价证据，我们首先要问：'这是什么类型的证据？'"（第7章）
  summary: |
    证据审查的总入口。对任何事实断言（结论、理由或假设中的"事实"）依次问：①我为什么要相信它？②需不需要证据？需要却没有=孤立论断，认真怀疑；③证据效力怎么样？然后按证据类型切换问题集：直觉（私密、无法判可靠性，查有无其他证据支撑）、个人经历（样本无代表性，防以偏概全）、典型案例（生动但问：有代表性吗？有无相反例子？提及方式有无偏见？）。没有一样证据能一锤定音，别一根筋找完美证据。
  tags: [decision-framework, evidence, triage]

  type: reasoning-method
  source_chapter: 第12章
  source_quote: |
    "我们需要谨慎地使用条件句（if-clauses）来创造多种结论。在条件句中，我们陈述一个假设的条件，目的是帮助我们得出某个特定的结论。"（第12章）
  summary: |

- id: f30
  title: 二分式思维破除三问
  type: reasoning-method
  source_chapter: 第12章
  source_quote: |
    "这种限定的过程需要你对任意一个结论提出以下问题：（1）结论在什么时候是精确的？（2）结论在什么地方是精确的？（3）结论为什么或为了什么目的才是精确的？"（第12章）
  summary: |
    全书收尾的大敌与解法。二分式思维把存在多种答案的问题压成是/否两面：限制选择的范围、过度简化复杂情境、让人容不得异议。破除法：给任意结论加语境限定——它什么时候精确？在什么地方精确？为什么/为了什么目的精确？答案是"这取决于……"而非斩钉截铁的是/否；用"是的，但是……"的限定回答既避开假确定，又仍形成可行动的立场。收益：更多可能的结论=更多可能的自由选择。
