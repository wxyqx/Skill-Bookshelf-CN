## I — 方法论骨架 (Interpretation)

这本书的全部内容就是一张清单：11 个关键问题，对应第 2–12 章各章——论题和结论是什么、理由是什么、哪些词语意思不明确、什么是价值观假设和描述性假设、推理中有没有谬误、证据效力如何（直觉/案例/证词/专家，及个人观察/研究/类比两章）、有没有替代原因、数据有没有欺骗性、有什么重要信息被省略、能得出哪些合理的结论。

**顺序不是排列偏好，而是依赖关系**：不定位结论就无处找理由，不清理歧义就无法判断假设，假设挖不出就看不穿谬误，谬误排除之后才轮到证据分级与因果审查，最后由省略信息与备选结论把"信不信"还原为"在哪些条件下选哪个"。所以走清单的正确方式是按序推进、逐问留产出，而不是跳着挑喜欢的问。

本 skill 是清单的**元层**：它管立项分流（这份材料值不值得走全流程）、顺序编排、每问的产出物与判停，以及在每一问上把深耕工作路由给对应的单点 skill。清单也有态度底座——启动前有权衡利害的过滤，全程有"同一张清单也要对准自己"的镜像要求。它不是仪式：低利害材料只走前两问加省略速查即可收工，判停是流程的一部分。

## A1 — 书中的应用 (Past Application)

### 案例 1: 禁枪论证的连珠五问（第1章旗舰示范）
- **问题**: 一篇反枪支管制的文章条理清晰、证据齐全（惯犯作案史、政要持枪名单、执法不力），海绵式读者读完只会照单全收。
- **方法论的使用**: 作者按清单顺序发问：先定位"他要我信什么"（结论），再问"凭什么"（理由），然后逐问核查——"绝大多数"何指（歧义词）、样本是否充分、有没有相反研究被略过（证据与省略）。每个问题都钉在前一问的产出上。
- **结论**: 五问之后论证漏洞显形；恰当的连珠发问不需要读者是枪支专家。
- **结果**: 示范了清单的价值在"按序 + 依赖"：换一个顺序、少问几问，缺口就漏过去。

### 案例 2: 禁播酒类广告论证的中段接力（第6章）
- **问题**: 一篇主张不禁酒类广告的社论给两条理由，读者不知道从哪下手审。
- **方法论的使用**: 作者先走清单前两问（整理出结论与理由），再启用假设挖掘，最后落在谬误判别——滑坡谬误与追求完美方案谬误都是从"理由到结论的隐含假设"里长出来的。
- **结论**: 中段问题（假设→谬误）只能踩着前两问的产出进行，印证清单的依赖结构。
- **结果**: 第6章成为"清单前半段产出喂给后半段"的现场演示，作者并在章中回放了整张清单。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一份利害攸关的材料（新制度公告、商业计划、研究报告、爆款长文），需要从头到尾系统评估而不是挑单点看。
2. 用户说"全面拆一下 / 整体评估 / 该问的问题都问一遍"，或者不清楚该用哪个单点 skill——先走总纲再路由。
3. 自己要做重大决定，想把支持某个选项的论证完整过一遍（买房、跳槽、大额投入）。
4. 写完论证文章，发布或提交前想按全套标准自查。

### 语言信号 (用户的话里出现这些就应激活)

- "帮我全面分析/系统拆解这个论证"（full breakdown, systematic review）
- "从头到尾过一遍，别只挑一点"（walk through the whole checklist）
- "这个论证整体靠不靠谱，做个体检"（overall assessment, audit the argument）
- "我想审它，但不知道从哪开始"（where do I start）

### 与相邻 skill 的区分

- 与单点审查 skill（`locate-issue-conclusion`、`identify-reasons`、`ambiguity-loaded-words`、`fallacy-three-questions`、`evidence-grade-triage` 等）的区别：总纲管"从哪开始、按什么顺序、每步产出什么、何时路由"；单点问题被命中后由对应 skill 接管该步的深耕。
- 与 `pan-for-gold-reading` 的区别：淘金式是驱动清单的阅读姿态（怎么边读边问）；总纲是清单本体的流程编排（问什么、按什么序）。
- 与 `scrutiny-worthiness-filter` 的区别：它先决定要不要投入注意力；总纲是决定投入之后的全流程。
- 与 `strong-sense-self-audit` 的区别：清单对准别人的材料时由本 skill 编排；对准自己的结论时由它接管。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **立项分流**
   - 动作: 快速估利害与用户意图，定档"全审 / 抽查 / 不审"；抽查档只走问 1–2 加省略速查
   - 完成标准: 档位与起点明确；低利害材料交回 `scrutiny-worthiness-filter` 或按抽查档走
   - 判停: 用户只要单点答案时，直接路由对应 skill，不强行展开全清单
2. **结构与暗层问（问 1–4）**
   - 动作: 定位结论与理由（路由 `locate-issue-conclusion`、`identify-reasons`），再查歧义词与假设（路由 `ambiguity-loaded-words`、假设挖掘 skill——slug 阶段3确认）
   - 完成标准: 产出"作者要我相信 X，因为 Y"一句话 + 会影响支撑效度的关键词清单 + 理由到结论的隐含前提
3. **质量问（问 5–9）**
   - 动作: 逐条理由查谬误、证据效力、替代原因、数据（路由 `fallacy-three-questions`、`evidence-grade-triage` 等）
   - 完成标准: 每条主要理由标注"成立 / 有疑 / 作废"，并注明是哪一问打掉的
4. **收尾问（问 10–11）与立场输出**
   - 动作: 排查省略信息、生成备选结论（路由省略信息、备选结论 skill——slug 阶段3确认），最后形成自己的暂定立场
   - 完成标准: 输出可辩护的暂定立场，注明"基于现有信息，直到新证据出现"；提醒清单镜像（同一套问对准自己的立场过一遍）

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 低利害的吃瓜材料——先过 `scrutiny-worthiness-filter`，别为热搜启动 11 问
- 用户只需单点深查且该点已明确——直接路由，全流程是浪费
- 对话中的即时回应——来不及走清单，先用 `keep-dialogue-alive` 维持通道
- 叙事、抒情等非论证文本——没有可审的推理结构

### 作者在书中警告的失败模式

- 清单变成免检抬杠（ce45）：看到谬误标签就跳过证据审查，用"有人反对"一句话拉平论证——模式匹配替代了逐问审查
- 弱势用法（ce04）：清单只对准别人、从不把自己的结论放进去——技能越强，离真理越远
- 只摆清单不下判断：11 问走完仍说"都存疑"，把审查做成了拒绝判断的仪式（对照 ce46 的行动瘫痪）

### 作者的盲点 / 时代局限

- BOOK_OVERVIEW 批判段：作者警惕了二分式思维，却未讨论"清单式批判"本身可能变成条件反射式的抬杠——清单有沦为新教条的风险
- 最强反对意见（Kahneman 双过程研究）：慢思考天性懒惰，一张 11 问的清单在实践中极少被完整执行——教会清单不等于养成习惯，本书对"勤于练习"的回应停留在意愿层面
- 时代局限：清单针对"文章、演讲、研究报告"式论证载体；信息流里"结论 + 情绪"的输入常没有完整论证，走不全清单，需要先降级处理

### 容易混淆的邻近方法论

- 图尔敏模型等论证形式分析：本书清单以"提问"组织、按依赖顺序推进，不求形式完备，求"哪一问最能动摇这个结论"
- SOP 式审计清单：总纲的价值在依赖关系与路由，不是逐项打勾的仪式；跳序和漏问都是走样
