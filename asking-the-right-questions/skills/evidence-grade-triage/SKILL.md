# 证据效力分级（弱证据四类分诊）

## R — 原文 (Reading)

> "没有一样证据可以像灌篮那样一锤定音、一劳永逸。"（第7章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第7章

> "单一的个人经历，甚至是个人经历的总和，根本不足以构成一个有代表性的经历样本。"（第7章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第7章

> "你的结论或是理由争议性越大，你花在提供证据上的时间就应该越多。"（第7章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第7章

## I — 方法论骨架 (Interpretation)

证据审查的最小单元是**事实断言**——论证中"希望被当事实接受"的看法，它可能藏在结论、理由或假设三个位置。审查的第一问永远是"我为什么要相信它"；第二问是"这种断言需要证据吗"——越是无可争议的常识越不需要，越有争议的断言需要的证据越多。

作者的核心洞见是：**证据的质量主要取决于证据的类型**。知道了类型，就等于知道了该问什么问题。四类"弱证据"各有各的结构性毛病：

1. **直觉**：私密性是它最大的问题——别人无法判断其可靠性，两个直觉冲突时也没有裁决基础；它多是无意识加工的产物，容易忽略证据、放大偏见。
2. **个人经历**："我认识一个人""以我的经验"——鲜活易得，但单一经历（甚至经历的总和）构不成有代表性的样本，直接外推就是以偏概全。
3. **典型案例**：有名字、有细节、动之以情的故事。它生动得让人不再追问三件事：有没有代表性？有没有强有力的相反例子？被提及的方式有没有偏见？
4. **当事人证词**：推荐语、代言、现身说法。四个怀疑点：证人是精心挑选的（选择性）、作证人可从中获利（个人利益）、判断标准被省略、期望值会过滤经历（相信什么就看得见什么）。

对应的正确动作不是全盘拒斥，而是**降级**：这四类证据至多"展示可能性"，不能证明普遍结论。要动真结论，需要升级到系统化证据——那就进入研究与专家意见的审查分支。

校准预期同样重要：没有一样证据能一锤定音，追求完美证据只会让人泄气。

## A1 — 书中的应用 (Past Application)

### 案例 1: 校长的哈佛毕业生故事（典型案例）
- **问题**: 一位大学校长用一名进入哈佛法学院深造的前 5% 毕业生做论据，证明"我们的学生当然能在一流大学取得成就"——故事具体、动情、给人留下深刻印象。
- **方法论的使用**: 对这个典型案例执行三问：这个例子有代表性吗（前 5% 能代表全体毕业生吗）？有没有强有力的相反例子（多少学生连普通工作都没找到）？提及方式有没有偏见（为什么偏偏选他）？
- **结论**: 典型案例可以展现"可能性"、给抽象数据一张面孔，但绝不能充当代表性证据。
- **结果**: 作者用同一套三问对照了死刑犯人伦悲剧的报道——一个骇人的具体故事恰好遮住了"30 年间 119 名死刑犯被证明无辜"这一罕见基率。

### 案例 2: 篮球明星为"前进头箍"作证（当事人证词）
- **问题**: 练习文章中多位运动员声称戴上某种头箍后投篮命中率大涨，证词激情四射。
- **方法论的使用**: 逐项追问：证人是精心挑选的还是随机使用者？命中率提高是否纯属偶然或另有原因？作证者是否"耳根子软"、期望值先行？
- **结论**: 在拿到系统研究数据之前，这些证词不能证明头箍有效——它提供的只是"某人的满意"，不是效度证据。
- **结果**: 确立了对一切证词的处理姿势：暂缓采信，直到查到背后的专门知识、利益与偏见。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 朋友/家人用"我姑妈喝了治好了""我认识一个人"来支持健康、理财、教育类主张，用户想知道该怎么权衡。
2. 广告、带货直播、软文里出现消费者见证、名人代言、逆袭故事，用户决定买不买/信不信。
3. 用户自己写文章或做汇报，手里只有一个身边例子，问"这样够不够格当证据"。
4. 读到新闻或热帖里一个具体人物的遭遇，想判断它能否代表普遍现象。
5. 群聊讨论中有人用"我感觉""直觉告诉我"反驳数据，用户想回应该给直觉多大分量。

### 语言信号 (用户的话里出现这些就应激活)

- "他说他亲身经历过的 / 我认识一个人就是这样 / 有个典型案例"
- "这个见证可信吗 / 算不算证据 / 个例能说明问题吗"
- "我就是知道 / 直觉告诉我 / gut feeling"（"works for me"、"trust me"）
- 英文信号: testimonial、anecdote、case in point、vivid story、personal experience

### 与相邻 skill 的区分

- 与 `expert-opinion-audit` 的区别：证据提供者是**专家/权威/名人/机构**身份（靠专门知识发言）→ 交给他；普通人的日常经历与见证（靠亲历发言）→ 留在本 skill。
- 与 `research-survey-audit` 的区别：出现"研究表明/调查显示/样本"等系统化证据 → 交给他；本 skill 只处理前系统化的四类。
- 与 `analogy-evaluation` 的区别："就像/好比/公司是船"式的比较论证 → 交给他。
- 与 `deceptive-data-check` 的区别：数字已经给出、审的是表述与结论的错位 → 交给他；本 skill 在数字出现之前先给证据类型定级。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **切出事实断言并定位**
   - 列出论证中的关键事实断言，并标注每个断言所处的位置（结论/理由/假设）
   - 完成标准: 能用一句话复述"他希望我未经检验就接受什么"；若发现断言被期望值过滤的迹象（相信什么就看见什么）一并记录
2. **识别证据类型并分流**
   - 对每条断言标注证据类型：直觉 / 个人经历 / 典型案例 / 当事人证词 / 专家意见 / 研究调查 / 类比 / 个人观察
   - 完成标准: 每条断言都有类型标签；类型为专家意见、研究调查、类比的，分别转交 `expert-opinion-audit`、`research-survey-audit`、`analogy-evaluation`，本 skill 只继续处理四类弱证据与个人观察
3. **对弱证据做对应审查并降级**
   - 直觉: 问"说得出直觉背后的具体经历或数据吗？两个直觉冲突时听谁的？"——答不出即降级
   - 个人经历: 问"样本量多少？覆盖面？这些经历是不是恰恰因为罕见才被记住？"
   - 典型案例: 三问（代表性？强反例？提及方式偏见？）
   - 当事人证词: 四查（证人选择？个人利益？判断标准是否省略？期望值效应？）
   - 完成标准: 每条弱证据都被改写成"它至多展示了 X 的可能性"级别的降级表述；**判停条件**: 若全部证据都是弱类型而断言争议性高，直接输出"证据不足，该结论应保持待证状态"，不再往下审
4. **按争议度校准证据投入并给出走向**
   - 完成标准: 向用户说明"争议越大需要的证据越多"，并给出下一步建议——要动真结论需要系统化证据（转研究审查）、要查省略信息（转 omitted-info-probe）、要查因果断言（转 rival-causes-audit）

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 无争议的日常事实陈述（"下周二放假"）——审查成本高于收益
- 用户只是分享自己的经历、求共情而非立论——此时盘问样本代表性是答非所问
- 纯信息查询、闲聊——没有事实断言需要分诊

### 作者在书中警告的失败模式

- **以偏概全**: 从"我朋友通宵复习考得不错"推出"今晚不用睡觉"——概括范围远超样本保证的范围
- **被生动细节带走**: 一个有名字有情节的故事挤占了证据评估的带宽，让人忘了问"它多罕见"
- **"眼见为实"的反转**: 相信什么就看得见什么——期望值先过滤了经历，证词只是信念的回音
- **直觉当证据**: "我就是知道"无法被他人检验；两个直觉打架时没有任何裁决基础

### 作者的盲点 / 时代局限

- 本书以"研究证据 > 直觉"为默认排序，未区分直觉在专业领域（急救、消防等 Gary Klein 研究的高经验情境）中作为模式识别的可靠性——对新手直觉从严、对老手直觉打折处理才是更完整的版本
- 双过程认知研究（Kahneman 系统 1/系统 2）表明清单式审查实践中很少被完整执行，本 skill 的降级动作需要练习到成为默认反应
- 成书于短视频与算法推荐兴起前夜：如今"见证式证据"（探店视频、买家秀、好物分享）以远超书稿年代的速度和规模传播，且常常伪装成"素人经历"

### 容易混淆的邻近方法论

- 诉诸公众谬误：那审的是"用流行度冒充理由"的推理花招（→ fallacy-three-questions）；本 skill 审的是证据类型本身的效力，对象不同
- 撒谎检测：本 skill 评估证据效力，不评判陈述者诚实与否——诚实的人也会被糟糕证据说服
