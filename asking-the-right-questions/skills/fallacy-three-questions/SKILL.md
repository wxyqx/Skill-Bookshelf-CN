# 谬误三问判别法

## R — 原文 (Reading)

## I — 方法论骨架 (Interpretation)

谬误审查的对象是**理由本身**——不是理由与结论之间的缺口（那是假设，属合法未言明部件），而是理由内部的花招：推理靠错误的垫脚石、声东击西或原地打转来冒充支撑。

作者的差异化设计：**不背几十个谬误名称，用统一三问判别一切花招**。一问，这条理由是否依赖明显错误的假设才能成立——滑坡把"可能连锁"偷换成"必然连锁且不可中止"；追求完美方案以"不能归零"否决局部改善。二问，是否用与论题无关的信息转移注意力——人身攻击审查送信人代替审查信息，稻草人歪曲对方立场再击倒，诉诸公众用"人多"冒充"为什么可信"，诉诸感情让情绪直接连通结论按钮，转移话题换了赛道还宣布获胜。三问，结论是否伪装成理由——"传统教科书好，因为教材形式有利于学习"，把结论换词重述一遍冒充依据。

三个辅助落点：警告词"不是……就是……"常是虚假两难的信号；乱扣帽子（"他就是个混球""中年危机"）是用命名冒充解释；名称（滑坡、稻草人……）只在判断**之后**用作与人交流的标签，不充当判断工具本身。

两条防滥用制衡与三问同等重要：**找到谬误只作废该条理由**，其余理由仍要公平考虑；**不要自动驳斥诉诸权威**——权威不被自动采信，但其证据仍要认真审查。

## A1 — 书中的应用 (Past Application)

### 案例 1: 攻击斯彭道参议员的致编辑信（第6章）
- **问题**: 读者来信反对增税提案，却只援引对方"自由派民主党人"的名声，不提任何反对增税的具体理由。
- **方法论的使用**: 三问命中两处——依赖"自由派必提增税所以其主张必错"的荒诞假设才能连接结论；攻击的是送信人而非送来的信息（注意力花招）。定性：人身攻击谬误。
- **结论**: 一句话即可识破，无需记名称。
- **结果**: 日常版同型示范："反正你就是个输不起的人"——同样绕开了理由本身。

### 案例 2: 禁播酒类广告——滑坡与追求完美方案（第6章）
- **问题**: 结论"不该禁酒类广告"，两条理由：今天禁了酒类广告，明年就要禁糖果牛奶鸡蛋；反正禁了也没人戒酒。
- **方法论的使用**: 先整理结论与理由，再逐条查假设——理由一依赖"一旦行动就无法阻止类似行动"的错误假设（滑坡）；理由二依赖"禁令目标是完全消除饮酒"的错误假设（追求完美方案：部分改善也值得要）。
- **结论**: 第 5 章挖假设的技能直接转化为判谬能力。
- **结果**: 建立标准流程：整理结论理由 → 查假设 → 定性花招。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 群聊、评论区、家长群看到一段雄辩但感觉被绕进去了，想拆招而不是吵架。
2. 辩论、评审、审稿中要判断某条理由是否成立——先查花招，再查证据。
3. 媒体/演讲里出现"不是……就是……""大家都这么认为""你这样的人"等信号。
4. 自己写完一段反驳，想自查是不是不小心用了滑坡、稻草人。

### 语言信号 (用户的话里出现这些就应激活)

- "他是不是在诡辩 / 耍花招 / 绕开重点"
- "人身攻击 / 滑坡 / 稻草人 / 循环论证 / 诉诸公众"（用户自己报名称请求验证）
- "这段推理有毛病 / 哪里不对劲"（fallacy / straw man / slippery slope）

### 与相邻 skill 的区分

- 与 `value-assumption-mining` / `descriptive-assumption-mining`：假设是理由与结论之间的合法缺口（挖出来补桥评估）；谬误是理由自身的毛病（查出来作废）。
- 与 `ambiguity-loaded-words`：发现"关键词含义不清"是歧义排查；论证靠词义中途滑动支撑结论（偷换概念）是本 skill 的花招。
- 与 `evidence-grade-triage`：花招是推理结构的毛病，证据弱是支撑物的毛病（个人经历、典型案例）——先过三问，再进证据分级。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **逐条过三问**
   - 操作: 对理由清单上每条理由依次问：依赖明显错误的假设吗？用无关信息转移注意力吗？结论换装重述（循环）吗？
   - 完成标准: 每条理由获得三问的明确答案（命中/未命中 + 一句话依据）
2. **记录花招与落点**
   - 操作: 命中者记录花招类型与触发句（如"不是……就是……"=虚假两难信号）；名称只在此时贴，用作交流标签
   - 完成标准: 每处命中附原文短引用与失效原因
3. **防滥用制衡**（与判谬同时执行，不可省略）
   - 操作: (a) 作废仅限命中理由本身，对未命中的理由重新公平评估——不能一条中招全盘驳回；(b) 遇"专家/权威说"不自动贴"诉诸权威"标签，转查权威实际掌握的证据与立场
   - 完成标准: 输出"作废理由 + 仍待公平评估的理由"两张清单
4. **汇总与移交**
   - 操作: 三问均未命中但理由仍可疑 → 判停，移交证据效力审查或替代原因审查；承重理由全部作废 → 结论暂不可信；部分作废 → 按剩余理由强度暂定立场
   - 完成标准: 给出"该论证是否还有立足理由"的明确判断

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户想找"理由与结论之间缺什么"——那是假设挖掘；缺口是合法未言明前提，不是花招
- 用户嫌证据弱（个人经历、个案故事）——证据分级审查的事，三问解决不了样本问题
- 用户想给对方贴谬误标签赢辩论——本书明确这是把批判技能当武器（弱势用法）

### 作者在书中警告的失败模式

- 把谬误名称当免检武器，模式匹配替代三问审查——看到"专家说"就驳是廉价驳回：多数医生坚持慢跑这类权威共识照样是重要信息
- 用"许多专家不同意你这个观点"一句话拉平论证——分歧的存在被冒充分歧的分量，不再比较双方理由质量
- 找到一处谬误就宣布对方全盘皆输——正确动作：只作废该理由，其余理由公平过一遍

### 作者的盲点 / 时代局限

- 作者警惕了二分式思维，却未讨论"清单式批判"可能变成条件反射式的抬杠——三问技能同样可被弱势用法征用，本书未给出行为设计层面的防线
- 心理学双过程研究视角：人在情绪激活时极少完整执行三问；作者对"勤于练习"的回应停留在意愿层面，社交中被解读为敌意的风险未处理

### 容易混淆的邻近方法论

- 谬误名称背诵清单（市面常见教法）——本书立场：名称是事后标签不是判断工具，判断靠三问
- 形式逻辑（前提-有效性符号化检验）——本书处理自然语言说服场景，不做符号化
