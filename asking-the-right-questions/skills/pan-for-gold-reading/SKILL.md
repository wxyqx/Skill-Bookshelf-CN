# 淘金式阅读姿态

## R — 原文 (Reading)

> "淘金式思维要求读者问自己一系列既定的问题，旨在找出最佳判断或最合理的看法。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

> "你的淘金盘里首先得有点东西供你掂量才行。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

---

## I — 方法论骨架 (Interpretation)

淘金式阅读 = 读书读人时主动出题，而不是等着被灌输。它由三部分组成：一套随身携带的关键问题清单（从"结论是什么"直到"有什么重要信息被省略"）；与材料互动的动作（页边批注、把疑问当场写下来、随时准备与作者辩驳）；一个明确的目标设定——不是为了驳倒作者，而是为了找出最佳判断。

两点最常被误读，必须先立正。第一，淘金式不是海绵式的对立面，而是它的接力棒：海绵式吸收是必要基础，"淘金盘里得先有东西"；它唯一的结构缺陷是回答不了"该信什么、忽略什么"。所以正确姿势是先通读吸收，再带清单回来掂量，两者互补而非二选一。第二，淘金式不等于抬杠：挑刺只是副产品，终点是形成一个自己能辩护的判断——如果读完只留下"处处是漏洞"的快感而没有立场，那是把工具用反了。

操作上，姿态落在"一遍读、一遍问、一遍记"：对每一段写下针对它的提问，而不是只画线摘抄；每问之后标注"信/不信/待证据"，让吸收和评价各归各位。

## A1 — 书中的应用 (Past Application)

### 案例 1: 禁枪论证的淘金式拆解（第1章旗舰示范）
- **问题**: 一篇反对枪支管制的文章写得头头是道：杀人犯多是惯犯、政要普遍持枪、现行法律没被执行。海绵式读者读完只记得"禁枪理由大多是臆造的"。
- **方法论的使用**: 作者对同一篇文章连发追问："绝大多数"指多少？"枪支持有者"怎么界定？那项研究的样本够不够？有没有相反研究没被提？每年死于本可管制枪支的人有多少？
- **结论**: 五问之后论证的缺口显形；恰当的连珠发问不需要读者是枪支专家就能切中要害。
- **结果**: 海绵式与淘金式在同一篇文章上的行为差异被看得一清二楚，读者拿到可模仿的动作模板。

### 案例 2: 影迷的选片困境（第1章开篇）
- **问题**: 影评家们对同一部电影意见从不一致，全信不可能，一部部亲测又看不过来。
- **方法论的使用**: 两位作者的解法不是"多读"，而是带着问题甄别哪些影评可信，只认真处理经过筛选的输入。
- **结论**: 权威彼此矛盾时，出路是掌握评判工具，不是寻找更权威的权威。
- **结果**: 这个日常场景成为全书出发点——通往合理结论的道路从问题开始。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读完一篇长文/一份研报/一本书，只能说"写得挺好"，说不出自己信什么、不信什么。
2. 准备精读一本重要著作或一门课程，想建立边读边问的批注式阅读习惯。
3. 发现自己的观点总随最近读到的东西漂移——谁写得有说服力就信谁。
4. 有人转来一篇"雄文"，你想认真对待它，但不想照单全收。

### 语言信号 (用户的话里出现这些就应激活)

- "我不想全盘接受 / 不想被作者带节奏"（don't want to take it at face value）
- "怎么边读边提问 / 带着批判的眼光读"（read critically, question while reading）
- "我读完就信 / 观点老跟着最近看的文章变"（sponge reading, whatever I read last）
- "帮我列一套读的时候该问的问题"（pan for gold）

### 与相邻 skill 的区分

- 与 `scrutiny-worthiness-filter` 的区别：先由它判断这份材料值不值得投入注意力；本 skill 管"决定投入之后怎么读"。
- 与 `strong-sense-self-audit` 的区别：本 skill 的清单指向材料与作者；把同一张清单对准自己的结论，是 s02 的事。
- 与 `locate-issue-conclusion` 的区别：后者是清单上的第一问（结构定位的专门工序），本 skill 是驱动整张清单的阅读姿态。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先海绵后淘金：第一遍通读吸收**
   - 动作: 通读材料，记住结论与主要理由，不做评价——先把"淘金盘里的东西"备齐
   - 完成标准: 能用自己的话复述作者的核心主张和主要理由
2. **带清单重读互动**
   - 动作: 调出关键问题清单逐问互动（结论是什么？理由？有无歧义词？假设？证据效力？省略了什么？），对每个相关段落写下拉针对于该段的提问
   - 完成标准: 至少 3 个提问是钉在具体段落上的，而非泛泛感想
   - 判停: 若材料已被 scrutiny-worthiness-filter 判为低利害，可停在"只记结论"档，不展开
3. **批注产出取舍决定**
   - 动作: 在每个问题旁标注"信 / 不信 / 待证据"，把吸收与评价分开
   - 完成标准: 读完能说出"我信什么、不信什么、为什么"，而不是"作者说了什么"
4. **防抬杠自检**
   - 动作: 检查自己是否只挑刺——至少找出材料中一条站得住的理由并明确承认
   - 完成标准: 对站得住的理由有交代；需要深查的点转 `locate-issue-conclusion` 等下游工序

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 已判定低利害、决定放下的材料——先走 `scrutiny-worthiness-filter`，别为吃瓜启动全套清单
- 用户要的是纯信息提取或速读——没有审查意图时，批注式提问纯属负担
- 小说、诗歌等叙事抒情文本的主线阅读——审查清单对非论证文本作用有限

### 作者在书中警告的失败模式

- 海绵式依赖（ce03）：读完只记得作者说了什么、说不出哪里可疑；观点随最近一次阅读对象漂移；笔记里全是结论，没有一条质疑
- 一厢情愿渗入阅读（ce01）：对材料里"希望它是真的"的部分跳过审查，追问理由时只能给出"我就是知道"
- 偏听偏信式淘金（ce05）：只对异见材料开火，对同温层材料免检——淘金只淘了一半

### 作者的盲点 / 时代局限

- 本书成书于社交媒体与算法推荐兴起前夜：信息流里的说服常是"结论 + 情绪"，根本没有论证段，清单对这类输入作用有限（BOOK_OVERVIEW 批判段·时代局限）
- 心理学双过程研究的反对意见：慢思考天性懒惰，一张十余项的清单极少被完整执行——教会清单不等于养成习惯，本书未提供行为设计
- 案例高度美国中心（禁枪、大选季），迁移到其他语境需先做本地化转译

### 容易混淆的邻近方法论

- 速读/精读技巧：它们优化吸收效率，本 skill 优化判断质量——目标不同
- 全盘怀疑：淘金式的目的是找出最佳判断，不是见什么驳什么；"盘里得先有东西"决定了它以吸收为前提
