# 研究报告与调查审查

## R — 原文 (Reading)

> "研究结果并不能证明结论。充其量它只能支撑结论。"（第8章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第8章

## I — 方法论骨架 (Interpretation)

研究证据是八类证据中较强的——可公开验证、程序可控、语言精确。但"较强"不等于"免检"，本书给的是一条中间路线，既不走"研究表明"崇拜，也不走"研究都是编的"虚无：

1. **改写原则**：遇到"研究结果表明……"，先在脑中改写成"研究人员**解释**他们的研究结果是表明了……"。科学发现总能找到不止一种解释，研究人员的结论不该被当成证明了的真理。
2. **单一研究脱离研究群**：一项研究什么都说明不了。要问：有没有重复验证？有没有相反研究？资助方是谁（食糖研究所资助的糖研究很难发现糖的危害）？转述版本是不是比原始报告的限定更强（"麻疹疫苗引起孤独症"这类曾被当"研究事实"的说法后来被推翻）？
3. **样本三查**：从样本概括整体，取决于三件事——**数量**够不够大、**覆盖率**够不够广（类型多样吗）、**随机性**好不好（每个人被抽中的机会均等吗）。自愿参加的调查往往混进同一类人：在线约会研究里是春风得意者，招聘文案里的"90% 满意度"只有在职者能投票，离职者缺席。三查任一不过关，就是**过度概括**——宣称的范围远超研究能保证的范围。
4. **调查两偏见**：调查测量的是"口头汇报"而非态度本身。**措辞偏见**——"你对于总统误入歧途地强制推行某某医改有什么看法"这种问题自带答案；**语境偏见**——同一问题排在"选举权该不该给 18 岁孩子"之后答案就变，问卷太长后段的回答开始敷衍；再加**自我报告失真**——酗酒频率这类敏感问题，受访者给的是"应该给的答案"。
5. **反方向警告**：审出瑕疵不等于结论作废。因为样本有限、未重复验证就抛弃方向一致、多次重复的证据（吸烟致癌），犯的是强求确定性谬误——对人类行为的研究只能给概率支撑，以"百分之百确定"为门槛会让一切结论都进不了门。

## A1 — 书中的应用 (Past Application)

### 案例 1: 取消终身教职——十连问的整合示范
- **问题**: 一篇主张取消公立学校教师终身教职的文章，引用一项 1000 人全国电话调查：28% 支持现行终身制，56% 认为终身教职让教师失去工作动力。
- **方法论的使用**: 作者把散落各节的审查问题逐一套上：电话自选参与本就有偏差，未说明是否覆盖手机用户，随机性与覆盖率无从判断；"铁饭碗"的措辞暴露问题本身暗含反对倾向；看不到问卷原文、题序与长度；无重复验证，不知论证者的获利动机，也看不到持不同观点者的意见。
- **结论**: 先别接受这个概括性断言——不是判定为假，而是证据地位不足以支撑宣称的力度。
- **结果**: 本章以此作为"把十连问整合成一次完整评价"的样板。

### 案例 2: 在线约会 94% 与戒酒会 451 人——过度概括与测量偏差
- **问题**: 一项 229 人、单一网站的自选调查宣称"94% 的人第一次见过网络伴侣后会再次约会"，被解读为"参加在线约会的人极有可能找到佳偶"；另一项戒酒会研究称 77% 的会员父母至少一人酗酒（对照组 23%）。
- **方法论的使用**: 前者查样本：只覆盖一个网站、自愿参加者很可能尽是成功找到对象的得意者，随机性无从得知——概括被强行推广到"所有"在线约会者；后者查测量："酗酒"的定义与评判标准缺失，对照组靠自我评定"不酗酒"（社会认可的答案），戒酒会成员自愿报名。
- **结论**: 两组数据的毛病不同——前者坏在样本代表不了宣称的整体，后者坏在测量工具测不准要测的东西。
- **结果**: 确立核心问句："他们抽样的事件或人群有多少，覆盖率多大，随机性怎么样？"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 招聘文案/公司宣传出现"90% 员工满意度""用户调研显示"，用户在决定入职或合作。
2. 健康类新闻"最新研究表明吃 X 导致 Y"，用户想知道这项研究能不能信、能不能转给家人。
3. 用户自己要做问卷/用户调研/满意度调查，想在设计与解读阶段避开偏差。
4. 产品评审、竞品分析中各方都拿数据说话，用户要判断哪份数据更站得住。
5. 看到两份结论相反的研究，用户想知道为什么"科学"也会打架。

### 语言信号 (用户的话里出现这些就应激活)

- "研究表明 / 调查显示 / 有数据说 / 科学证明 / 民调结果"
- "这个样本靠谱吗 / 谁被调查了 / 怎么抽样的 / 问卷怎么设计的"
- "两份研究结论相反 / 这个 90% 怎么来的"
- 英文信号: research shows、survey、poll、sample、study found、according to data

### 与相邻 skill 的区分

- 与 `evidence-grade-triage` 的区别：s15 是证据类型总入口；一旦证据是"研究/调查/实验"形态就离开 s15 进入本 skill。
- 与 `expert-opinion-audit` 的区别：专家**转述**研究时先查人再查研究；本 skill 审的是研究本身的质量，不管专家身份。
- 与 `deceptive-data-check` 的分界（最易混淆）：本 skill 审"**研究与调查的质量**"——数据怎么采集、样本能否概括宣称的整体；s20 审"**数字表述与结论的错位**"——数据是真的，但平均值类型、相对风险包装、用证明了 A 的数据冒充结论 B。拿到的是"调查来的数字"走 s17；数字已给定、怀疑"被怎么用"走 s20。
- 与 `rival-causes-audit` 的区别：研究得出"X 导致 Y"后，追问还有什么原因能解释这组数据——那是 s19 的因果审查；本 skill 的组间比较只查到"分组方式是否公平"为止。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **改写还原**
   - 把"研究结果表明 X"改写为"研究人员解释其数据为 X"，并对照转述版本与原始主张：限定语有没有被摘掉？"所有/极有可能"这类全称词是自己加的吗？
   - 完成标准: 一句话写出该研究的实际主张（而非转述版主张）
2. **研究群检查**
   - 问四件事：有无重复验证？有无相反研究？资助方与结论方向有无利益关系？这是孤证还是方向一致的研究群之一？
   - 完成标准: 列出支持/削弱该结论的研究群证据；**判停条件**: 只拿得到孤证且查不到任何验证信息时，输出"单一研究，证据地位=待验证"并停止深挖，不假装能查到原文
3. **样本三查**
   - 数量多大？覆盖了哪些类型、漏了哪些类型（离职者/流失用户/没时间接电话的人）？抽取方式随机吗（自愿报名=先打一个大问号）？
   - 完成标准: 明确说出"这个样本能概括的上限"与"宣称范围"之间的落差
4. **调查偏见检查**（仅当证据来自问卷/民调）
   - 能拿到问题原文吗？措辞有没有情绪词或诱导结构？题序与问卷长度会不会产生语境偏见？敏感话题的自我报告有没有当真？
   - 完成标准: 对每个拿不到的信息记为"不可判断"，并在结论中如实声明
5. **双向校准收尾**
   - 汇总输出：该研究"支撑"到什么程度、哪些环节不可判断、需要什么信息才能升级；同时自查用户是否正在犯强求确定性谬误——若研究有重复验证且方向一致，不能因单个瑕疵全盘抛弃
   - 完成标准: 给出"谨慎接受/保持待证/降低分量"三选一的明确立场及条件

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户怀疑的是数字的表述方式（平均值类型、相对风险、数据与结论错位）→ `deceptive-data-check`
- 用户纠结的是"X 导致 Y 还是 Y 导致 X"→ `rival-causes-audit`
- 证据是专家身份而非研究程序 → `expert-opinion-audit`
- 用户只是想找某个统计数字的出处（纯信息查询）

### 作者在书中警告的失败模式

- **过早拥抱研究结论**: 见"科学研究"四字就免检放行——研究质量有高有低、结果常互相矛盾，作者引述复检发现大量医学干预断言错误或被夸大
- **强求确定性谬误**: 因样本有限、未重复验证这类不完美就抛弃方向一致的重复证据（吸烟致癌）——审查的目的是校准分量，不是追求不可能的百分之百
- **措辞与语境偏见当真**: 引导性问题和题序操纵让"数据"偏离它号称测量的东西；问卷不给原文时尤甚
- **自我报告失真**: 酗酒频率、社会敏感行为等自我评定被直接当客观数据使用

### 作者的盲点 / 时代局限

- 书中审查停留在传统抽样与问卷层面，未覆盖大数据时代的 p-hacking、发表偏倚、可重复性危机的机制细节与算法偏差——现代研究审查还需补充这些工具
- 隐含读者能获取原始研究文本；现实中多数人只见二手转述（新闻稿、公众号），本 skill 的判停规则据此设计，但"转述链损失"在书中着墨很少
- "研究证据 > 直觉"的默认排序在专业直觉（Klein 式经验判断）领域需要打折，与 s15 的盲点是同一条

### 容易混淆的邻近方法论

- 数据欺骗性检查（第10章）：那一章的前提是"数字本身已到手"，审表述；本章审"数字从哪来、能不能概括"——先 s17 后 s20 是正常顺序
- 统计学专业审查：本 skill 是普通读者的追问清单（谁/多少/怎么抽/怎么问），不是替代统计方法审查
