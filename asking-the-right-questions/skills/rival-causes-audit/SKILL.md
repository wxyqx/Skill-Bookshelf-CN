## I — 方法论骨架 (Interpretation)

因果断言是说服力最强的一类断言，也最难自己证明自己：一旦你接受了"X 导致 Y"，行为就跟着变（买、投、采用、责怪）。第9章给的不是一句口头禅，而是一套工序：

1. **相关四解释框架**：看到"甲和乙相联"，至少有四种解释——甲导致乙、乙导致甲、第三种因素共同导致甲乙、甲乙互相影响。四格全部过一遍，才有资格谈"甲导致乙"。
2. **侦探式生成**：把自己当侦探而非法官——"我能不能找到其他方法解读这个证据？还有什么别的可能引发它？"比较组之间也要问：两组除了被强调的因素还有哪里不同（培训班学生得分更高，可能只是背景和动力不同）。
3. **事后归因检查**：时间先后只是因果的必要条件。"在这之后"不等于"因为这个"——找不到先后之外的其他过硬证据，因果断言就不成立。这是迷信的直接来源，也是政客与商人最爱（上台后的好事全揽自己头上）。
4. **基本归因错误自查**：解释他人行为时，人普遍高估"他是什么样的人"、低估"他处在什么处境"。发现解释落在人格标签上，强制补一轮环境因素（压力、激励、处境）。
5. **按数量校准信心**：找出的言之成理的替代原因越多，原断言的确定性越低。多数事件是多因联合，"唯一原因"叙事要默认打折。

## A1 — 书中的应用 (Past Application)

### 案例 1: 胡德堡枪击案——三种解释都说得通
- **问题**: 2009 年胡德堡军事基地枪击案后，专家各执一词：心理压力过载（即将被派驻阿富汗）、工作申诉被上司无视、政治立场倾向恐怖主义——每个解释都言之成理。
- **方法论的使用**: 不在几个解释里挑一个顺眼的，而是把它们并列为竞争假说；作者点破：任何单一原因都极可能只是"原因之一"，专家也不会主动替你提供替代原因。
- **结论**: 事件由多因共同造就，单一归因（无论哪个方向）都过度简化。
- **结果**: 确立侦探四问："我能不能找到其他方法解读这个证据？还有什么别的可能引发它？"

### 案例 2: 《体育画报》封面魔咒——事后归因现场
- **问题**: 四分卫卡特勒登上封面后随即受伤、球队输球，"封面魔咒"再度应验？
- **方法论的使用**: 问"除了一件事紧随另一件之后，还有没有其他过硬的证据"——对手防守强度等替代解释都说得通；同类的还有"幸运硬币"（考 A 其实靠埋头苦读）。
- **结论**: 唯一依据是时间顺序的因果断言不成立；断言恰好对政客和商人有利时更要加倍警惕。
- **结果**: 迷信被识别为事后归因谬误的日常产物。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 产品/增长分析："新功能上线后留存涨了 5%，是功能的功劳吗？""转化率提升是因为这次改版吗？"
2. 健康/科普信息："研究发现吃 X 的人更长寿，我该不该跟着吃？"
3. 归因他人/团队："核心员工离职是因为钱吗？""他老迟到，是不是态度有问题？"
4. 巧合与迷信："穿这双鞋就连赢三场，真有玄学吗？"
5. 写作自查：复盘报告、归因分析动笔前，检查自己是否只给了一个原因。

### 语言信号 (用户的话里出现这些就应激活)

- "是不是因为它 / 是功劳吗 / 还有什么别的原因 / 正好在那之后发生"
- "相关能说明因果吗 / 为什么会这样 / 都怪 / 都是因为"
- 英文信号: rival causes、alternative explanation、correlation vs causation、post hoc、is it because of

### 与相邻 skill 的区分

- 与 `deceptive-data-check` 的分界（钦定）：本 skill 审**因果解释**（为什么会发生——解释层）；s20 审**数字表述**（数字怎么算、怎么呈现——表述层）。"留存涨了 5% 是功能功劳吗"是本 skill；"'平均薪资 2 万'真假"是 s20。
- 与 `research-survey-audit` 的区别：先查数据采集质量（样本、问卷），数据过关后若结论是因果断言，接力进入本 skill。
- 与 `fallacy-three-questions` 的区别：相关当因果、事后归因会被贴上谬误标签，但贴标签不产出替代解释——生成竞争解释是本 skill 的活。
- 与 `descriptive-assumption-mining` 的区别：描述性假设是理由到结论的逻辑缺口；替代原因是针对同一因果断言的竞争解释。组间差异是两章的交叉点。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **切出因果断言**
   - 用一句话写出"据称 X 导致 Y"；区分相关陈述（"甲乙同步变化"）与因果宣称（"因为甲所以乙"）
   - 完成标准: 能明确指出材料中的因果断言（或确认没有）；**判停条件**: 材料只有相关报告、无人做因果宣称时，本 skill 降级为一句预防提醒（"此相关尚不能支撑因果解读"），不强行生成
2. **相关四解释过一遍**
   - 逐格检查：甲→乙？乙→甲？第三因素？互相影响？每格给出"说得通/说不通"及一句理由
   - 完成标准: 四格全部有判定；组间比较时额外列出两组的其他差异点
3. **侦探式生成替代原因**
   - 问：还有什么别的方法解读这个证据？还有什么别的可能引发它？事后归因检查：唯一依据是不是时间先后？基本归因错误自查：解释落在人格标签上时，强制补环境因素
   - 完成标准: 列出至少 2 个言之成理的替代解释（若确实存在）；每个解释注明"要排除它需要什么信息或设计"
4. **按数量校准信心并输出**
   - 完成标准: 输出原因果断言的信心评级（高/中/低）及依据；说明多因联合是默认假设；**判停条件**: 用户已在做随机化实验（A/B 测试）时，转检查实验设计是否真随机、分组是否可比，而不是空喊"还有别的解释"；同时自查反向滥用——不能因"存在替代解释"就把方向一致的重复证据（如吸烟致癌）一概打倒

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 材料里没有因果断言，用户只是想查事实（纯信息查询）
- 数字本身的表述可疑（平均值/相对风险）→ `deceptive-data-check`
- 用户想审的是样本与问卷质量 → `research-survey-audit`
- 用户单纯发泄情绪、求安慰——先接情绪，归因分析等对方要

### 作者在书中警告的失败模式

- **把相关当因果**: 冰激凌销量与犯罪率同升的真凶是夏天气温；四解释从未被排查（因果混淆、忽略共同原因）
- **事后归因**: 幸运硬币、封面魔咒——大量迷信的直接来源；断言对政客和商人有利时更要警惕
- **过度简化因果**: 为复杂事件（抑郁率上升、组织事故）寻找"唯一原因"，实际是多因联合创造整体环境
- **基本归因错误**: "他就是个混球"式人格归因替代处境分析；事后总能找到"童年原因"的性格标签是危险信号

### 作者的盲点 / 时代局限

- 成书于算法推荐兴起前夜：信息流里的因果暗示（精心挑选的相关图、"研究表明"标题党）常不走完整论证通道，清单对这类碎片输入的抓力有限
- 隐含读者有闲暇与能力排查替代原因；现实中因果归因已高度专业化（A/B 测试、归因模型），本 skill 是普通人的追问清单，不能替代实验设计知识
- 最强反对意见（双过程研究）：快直觉是判断默认，11 项清单极少被完整执行——本 skill 因此把工序压到四步，但习惯养成书中未给行为设计

### 容易混淆的邻近方法论

- **乱扣帽子谬误**: "他中年危机所以酗酒"——命名伪装成因果解释，是本 skill 生成分的第一道排查对象：把标签展开后若不含机制，不算解释
- **描述性假设挖掘**: 第5章找"理由到结论的缺口"，第9章找"同一果的其他因"——问法不同（"还需什么成立" vs "还有什么能解释"）
- **"相关≠因果"当万能驳回词**: 作者立场是校准信心而非一票否决——方向一致的重复证据仍应有分量，滥用替代原因就是清单式抬杠
