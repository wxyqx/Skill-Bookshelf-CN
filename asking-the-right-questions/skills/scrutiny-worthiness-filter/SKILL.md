# 审查价值过滤（"关我什么事"）

## R — 原文 (Reading)

> "最好先问一问关我什么事。"（第1章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第1章

> "能影响你该不该被说服的信息，才是重要的省略信息。"（第11章）
>
> — 布朗 & 基利，《学会提问（原书第10版）》第11章

---

## I — 方法论骨架 (Interpretation)

批判性审查是昂贵的活动：一张完整清单走下来，一篇材料要花掉实打实的注意力。本书对此的诚实处理是给出一个入口过滤器：在决定认真评估一个论题之前，先问一句——这件事关我什么事？论争结果对自己和自己在乎的人影响甚微，就不启动全套审查；影响重大（钱、健康、关键选择、他人权益），才值得投入。

"重要性"的判定标准在第11章被明确化：能影响你该不该被说服、会影响你推理过程的信息才算重要信息——同一把尺子反过来用，也能衡量一个论题值不值得你花推理。过滤之后是档位分配：**全审**（高利害，走完整清单）、**抽查**（中等利害，只查最致命一两问）、**不审并明确放下**（低利害）。

两个防走偏的护栏：其一，放下不等于禁止围观——可以吃瓜、可以看热闹，只是不为它动用审查资源；其二，低利害的判断要复查间接影响，物业费、体检建议这类"小事"常常是利害伪装的。

## A1 — 书中的应用 (Past Application)

### 案例 1: 影评不必篇篇通吃（第1章开篇的诚实交代）
- **问题**: 每部电影都有海量影评，若对每一条都做完整审查，人会被审查本身吞没。
- **方法论的使用**: 两位作者坦白自己的做法：不来者不拒地通吃，而是先借助少数可信渠道完成粗筛，只把完整的批判性处理留给真正要做的决定（看哪部片）。
- **结论**: 注意力有预算，批判性思维的第一问是配置问题，不是技术问题。
- **结果**: 全书在教审查技术之前，先安放了"值不值得审"的入口。

### 案例 2: "重要"的尺子（第11章）
- **问题**: 排查一篇论证缺了什么，缺的东西无穷无尽，追哪些才算数？
- **方法论的使用**: 以祛痘灵广告类靶子为例，作者逐项追问缺失项——其他产品的效果、负面成分、价格——每一项的追问资格都由同一标准决定：它会不会改变"该不该买"的判断。
- **结论**: 能影响你该不该被说服的信息才是重要省略；这把尺子同时是注意力过滤器。
- **结果**: 过滤器与省略信息排查首尾相接，形成"筛选 → 深查"的闭环。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 热搜八卦、明星骂战、网络争论推到面前，纠结要不要认真查。
2. 信息过载：待读文章、待核消息堆积，需要决定审哪些、放下哪些。
3. 有人要你对一条无关痛痒的传言"深挖/辟谣"，你想先判断值不值。
4. 时间只够深审一两件事，需要挑出利害最大的那个。

### 语言信号 (用户的话里出现这些就应激活)

- "关我什么事 / 谁在乎啊"（does this affect me）
- "值不值得较真 / 要不要认真查"（worth my attention）
- "信息太多了审不过来 / 帮我排个优先级"（what deserves scrutiny）
- "这个跟我有关系吗"（is it relevant to my stakes）

### 与相邻 skill 的区分

- 与 `pan-for-gold-reading` 的区别：先过滤（本 skill）后深读（s01）；本 skill 判"值得"，s01 才开始"怎么读"。
- 与 `critical-question-master-list` 的区别：全清单是重装备；本 skill 决定要不要把它掏出来。
- 与 `strong-sense-self-audit` / `keep-dialogue-alive` 的区别：它们是"怎么审自己/怎么对话"；本 skill 是"要不要把注意力给这件事"，位于一切审查类 skill 的上游。
- 批内五件套中唯一不做任何审查动作的 skill——只做投入决策。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **利害初筛**
   - 动作: 问"这个论争的结果对我 / 我在乎的人有实际影响吗"，覆盖钱、健康、选择、他人权益四类
   - 完成标准: 明确归入"高利害 / 低利害"，并说出一句话理由
2. **高利害 → 排程深审**
   - 动作: 给材料标定审查档位（全审 / 抽查），并指出从哪个下游 skill 接入（`pan-for-gold-reading` 或 `critical-question-master-list`）
   - 完成标准: 产出"审什么、用哪套工序、何时做"的安排
3. **低利害 → 明确放下**
   - 动作: 一句话说明"为什么不管它"，不启动任何审查清单，注意力转回高利害事项
   - 完成标准: 没有为低利害话题展开任何后续审查动作
4. **复查误判**
   - 动作: 检查"低利害"判定是否漏了间接影响（看似无关的科普可能关联健康与钱包）
   - 完成标准: 若发现任何间接利害，升级档位并回到步骤 2
   - 判停: 影响确实甚微则止步，不因"话题有趣"升级

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 已经决定深审的材料——过滤器的使命已完成，转 `pan-for-gold-reading` 等下游工序
- 涉及切身利害的事（健康、钱、权益）——不许用"低利害"判定逃避该做的功课
- 评价别人的关注选择（"你居然关心这个"）——过滤器是自用工具，不是审美裁判

### 作者在书中警告的失败模式（注：反例池无直接绑定条目，取两端最近的失败模式素材）

- 全盘吸收端（ce03，海绵式依赖）：没有过滤机制时，信什么取决于最后读到的是谁——本 skill 要防的另一端是"不选就审，什么都过一遍清单"
- 机械审查端（ce45，清单滥用）：看什么都模式匹配地挑谬误、见标签就驳回——"凡事都要批判性思考"的代价是把技能变成条件反射式抬杠
- 作者自身的处境（BOOK_OVERVIEW·立场盲点）：对"什么值得审"全书仅一句带过，注意力经济着墨极少——本 skill 恰好补在最薄弱处，也因此最缺书中细化程序

### 作者的盲点 / 时代局限

- 算法推荐时代，"送上门的论题"已被供给侧筛选过；过滤器的输入不再是作者设想的"你主动遇到的文章"（BOOK_OVERVIEW·时代局限）
- 利害判断本身可能出错：短期无关的议题可能长期要命；步骤 4 的复查只是补丁
- 影响甚微不等于假：放下的判断是对注意力的诚实安排，不构成对该论题真伪的表态

### 容易混淆的邻近方法论

- 时间管理四象限：那边管任务的紧急与重要，这里只问一个尺度——论争结果与我的利害；两套别混用
- 犬儒式"关我什么事"：过滤是配置注意力，不是放弃一切关注；高利害论题恰恰必须审
