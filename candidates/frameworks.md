# 思维模型/决策框架候选集

- id: f01
  title: "相互依赖理论（社会交换理论）"
  type: framework
  source_chapter: "第6章 相互依赖"
  source_quote: |
    "社会交换的三个重要因素是人们关系的结果、比较水平（CL）和替代的比较水平（CLalt）。结果=奖赏-代价；结果-CL=满意度；结果-CLalt=依赖度。"
  summary: |
    用经济学视角看待亲密关系：人们追求以最小代价获取最大奖赏的交往。满意度取决于结果与期望（CL）的差距，而关系稳定性取决于结果与替代选择（CLalt）的差距。满意度和依赖度是相对独立的两个维度。
  tags: [社会交换, 关系评估, 满意度, 依赖度]

- id: f02
  title: "人际关系四种类型矩阵"
  type: framework
  source_chapter: "第6章 相互依赖"
  source_quote: |
    "同时考虑CL、CLalt和关系结果三个因素的高低变化时，产生四种关系类型：幸福稳定型（结果>CL且>CLalt）、不幸福稳定型（CL>结果>CLalt）、幸福不稳定型（CLalt>结果>CL）、不幸福不稳定型（结果<CL且<CLalt）。"
  summary: |
    将满意度（结果vs CL）和依赖度（结果vs CLalt）两个维度交叉，形成四种关系类型。帮助判断关系所处的状态：既幸福又稳定、痛苦但离不开、满意但有更好选择、既痛苦又不稳定。
  tags: [关系分类, 满意度, 稳定性, 决策框架]

- id: f03
  title: "接近-回避动机双独立框架"
  type: framework
  source_chapter: "第6章 相互依赖"
  source_quote: |
    "接近动机驱使我们追求快乐，回避动机驱使我们逃避痛苦，它们并不是一块硬币的正反面。愉悦和痛苦各自独立地起作用，涉及不同的脑机制，引起不同的情感和行为。"
  summary: |
    亲密关系中存在两种独立的动机系统：追求奖赏的接近动机和回避代价的回避动机。两者并非此消彼长，而是可以共存或同时缺失。只有两种动机都满足时才有十足的幸福感；只满足回避目标的关系可能安全但沉闷。
  tags: [动机, 情绪, 关系质量, 双系统]

- id: f04
  title: "关系紊乱模型"
  type: framework
  source_chapter: "第6章 相互依赖"
  source_quote: |
    "随着新伴侣开始习惯于他们日益增加的相互依赖，应该预期到一段混乱和调整的时期。当伴侣决定更严肃地投入时，动荡到达顶峰，随后随着彼此适应新的相互依赖方式而减少。"
  summary: |
    亲密关系从随意约会过渡到严肃投入时，会经历一段动荡期：生活常规被打断、朋友阻力增加、不确定性上升。成功度过这一阶段后关系会安定下来，满意度重新缓慢增长。这是关系发展的正常过程而非失败信号。
  tags: [关系发展, 过渡期, 适应, 满意度变化]

- id: f05
  title: "自我延伸模型"
  type: framework
  source_chapter: "第6章 相互依赖 / 第8章 爱情"
  source_quote: |
    "自我延伸模型认为，能扩展我们的兴趣、技能和经验的伴侣关系就能吸引我们。保持快乐的关键是创造性地发现持续你个人成长的方法，从而消除关系的沉闷。"
  summary: |
    人们天生寻求自我扩展，新建立的亲密关系因带来新知识、新角色、新体验而令人兴奋。当伴侣变得熟悉后，自我延伸速度减慢，关系容易变得沉闷。维持快乐的关键是持续创造新奇和成长的机会。
  tags: [自我成长, 关系维持, 新鲜感, 动机]

- id: f06
  title: "爱情三角理论"
  type: framework
  source_chapter: "第8章 爱情"
  source_quote: |
    "斯腾伯格认为各种不同的爱情都能由三个构成成分组合而成：亲密（热情、理解、沟通、支持和分享）、激情（性的唤醒和欲望）、承诺（投身于爱情和努力维护爱情的决心）。"
  summary: |
    爱情由亲密、激情、承诺三个独立成分组成三角形，不同强度组合形成不同类型的爱：喜欢（高亲密）、迷恋（高激情）、空爱（高承诺）、浪漫之爱（亲密+激情）、相伴之爱（亲密+承诺）、愚昧之爱（激情+承诺）、完美之爱（三者皆高）。
  tags: [爱情类型, 三维度, 分类框架, 斯腾伯格]

- id: f07
  title: "浪漫爱情双因素理论"
  type: framework
  source_chapter: "第8章 爱情"
  source_quote: |
    "激情洋溢的吸引力根源于两个因素：（1）生理唤醒，如心跳加快，并伴随（2）相信另一个人是引起你唤醒的原因。根据这一双因素观点，当情感唤醒是由于出现了另一个有吸引力的人时，浪漫的爱情就会产生。"
  summary: |
    浪漫爱情 = 生理唤醒 + 对唤醒的浪漫归因。任何形式的高唤醒（恐惧、兴奋、运动等）都可以增强对有吸引力之人的爱恋感受，因为人们容易将唤醒的原因错误归因于对方的魅力。
  tags: [情绪唤醒, 归因, 浪漫, 吊桥效应]

- id: f08
  title: "首因效应+验证性偏差认知模型"
  type: framework
  source_chapter: "第4章 社会认知"
  source_quote: |
    "首因效应使最先获得的信息印象深刻。验证性偏差使人们常常寻找那些能够证明自己正确的信息，而不是那些证明自己错误的证据。第一印象会影响后来的思维，且很难改变。"
  summary: |
    对他人的认知受两个系统性偏差驱动：第一印象（首因效应）设定了初始框架，随后人们倾向于寻找证实该框架的信息（验证性偏差），忽略反面证据。这导致人们对伴侣的判断常常过度自信但实际不准确。
  tags: [认知偏差, 第一印象, 判断, 社会认知]

- id: f09
  title: "归因三维度与关系归因模式"
  type: framework
  source_chapter: "第4章 社会认知"
  source_quote: |
    "幸福的配偶对彼此的积极行为都通常给以内部的、稳定的、普遍的归因，倾向于淡化彼此的过失，认为它们是偶然的、特殊的和局部的。痛苦不满的伴侣反其道而行之。"
  summary: |
    伴侣对行为的归因方式（内部/外部、稳定/不稳定、普遍/特定）深刻影响关系满意度。幸福伴侣采用"改善关系的归因"（放大好事、缩小坏事），痛苦伴侣采用"维持苦恼的归因"（放大坏事、缩小好事）。
  tags: [归因, 关系满意度, 认知模式, 自我服务偏差]

- id: f10
  title: "宿命信念vs成长信念"
  type: framework
  source_chapter: "第4章 社会认知"
  source_quote: |
    "宿命信念认为伴侣要么天造地设，要么冤家聚头。成长信念假定幸福的亲密关系乃是辛勤维护的结果，只要努力付出，几乎任何亲密关系都能取得成功。"
  summary: |
    两种根本不同的关系信念体系。宿命信念者认为爱情天注定、争吵就是不爱、伴侣无法改变，遇到问题倾向于逃避或结束关系。成长信念者认为关系需要经营、努力可以改善，遇到问题积极寻求解决方法。
  tags: [关系信念, 思维模式, 成长型思维, 固定型思维]

- id: f11
  title: "自我实现的预言"
  type: framework
  source_chapter: "第4章 社会认知"
  source_quote: |
    "自我实现的预言指错误的期望最终变为现实，因为它会诱导被期望人的行为，从而使错误的期望得到实现。知觉者往往从目标身上引出他们所期望的行为，却很少意识到自己在其中所起的作用。"
  summary: |
    四步过程：知觉者形成期望→以与期望一致的方式行动→目标以类似方式回应→知觉者将目标行为归因于其性格而非自己的推动。积极期望带来积极结果，消极期望（如对被拒绝的担忧）会制造出自己恐惧的现实。
  tags: [期望, 行为塑造, 认知, 循环效应]

- id: f12
  title: "社会渗透理论"
  type: framework
  source_chapter: "第5章 沟通"
  source_quote: |
    "社会渗透理论认为人际关系通过人际沟通的系统性变化而得以发展。自我表露体现在两个方面：沟通的广度（所讨论话题的多样性）和沟通的深度（所讨论话题对于双方的个人意义）。"
  summary: |
    人际关系从肤浅的信息交流开始，通过自我表露的广度和深度的逐渐增加而发展。早期交往存在相互性（匹配彼此的开放程度）。一次说太多太快是危险的，最好的策略是循序渐进，让亲密感逐步增加。
  tags: [自我表露, 关系发展, 沟通, 亲密感]

- id: f13
  title: "人际亲密过程模型"
  type: framework
  source_chapter: "第5章 沟通"
  source_quote: |
    "两个人要变得亲近必须满足三个条件：必须进行有意义的自我表露；必须对彼此的个人信息有兴趣和同理心；双方必须都认识到另一方具有应答性。感知到的伴侣应答性是亲密关系发展的关键要素。"
  summary: |
    真正的亲密感建立需要三个条件：自我表露（敞开心扉）、对方的应答性（兴趣、同情、尊重）、以及感知到对方的应答。只有表露而没有回应不会产生亲密，只有回应但没有感知到同样不行。
  tags: [亲密感, 自我表露, 应答性, 关系建立]

- id: f14
  title: "冲突辩证张力模型"
  type: framework
  source_chapter: "第11章 冲突"
  source_quote: |
    "亲密关系中总交织着一定的张力，它们迟早会引起一些紧张。四个辩证法式的矛盾——自主性对联系性、开放对封闭、稳定对变化和聚合对分离——能解释已婚夫妻最近发生的三分之一以上的打斗和争吵。"
  summary: |
    冲突不可避免的根本原因在于亲密关系中存在四对永远无法完全满足的对立动机：自主vs联系、开放vs封闭、稳定vs变化、聚合vs分离。这些张力持续存在，人们在不同时间被牵引到不同方向，因此冲突是常态而非异常。
  tags: [冲突, 辩证, 动机张力, 关系矛盾]

- id: f15
  title: "Rusbult 不满反应四象限模型"
  type: framework
  source_chapter: "第11章 冲突"
  source_quote: |
    "应对冲突的四种类型在主动或被动维度和建设性或破坏性维度上存在差异：讨论（主动、建设性）、忠诚（被动、建设性）、离开（主动、破坏性）、忽视（被动、破坏性）。"
  summary: |
    当亲密关系出现不满时，人们有四种典型反应方式，沿"主动-被动"和"建设性-破坏性"两个维度分布。越满意、越投入的关系越可能采用建设性方式（讨论或忠诚）。讨论比忠诚更有效，因为忠诚常被忽视。
  tags: [冲突应对, 关系满意度, 分类模型, Rusbult]

- id: f16
  title: "Gottman 夫妻冲突风格分类"
  type: framework
  source_chapter: "第11章 冲突"
  source_quote: |
    "处理冲突有三种不同方法可以导致稳定而牢固的婚姻：多变型（频繁激烈争论但能用智慧和真情缓和）、确认型（更镇定，像合作者，通过同理心确认对方）、逃避型（很少争吵，回避正面对抗）。"
  summary: |
    约翰·戈特曼识别出三种能维持稳定婚姻的冲突风格和一种危险风格。关键不在于争吵多少，而在于奖赏-代价比率是否维持在5:1以上。敌对型夫妻无法维持这个比率，冲突充满批评、蔑视、防卫和退避，最可能离婚。
  tags: [冲突风格, 婚姻稳定, Gottman, 关系分类]

- id: f17
  title: "要求/退避模式"
  type: framework
  source_chapter: "第11章 冲突"
  source_quote: |
    "要求/退避模式表现为一方（要求者）批评、不断唠叨、向另一方提出要求，而伴侣（退避者）逃避正面接触、退避、采取守势。这种模式能自行延续，受到退避影响要求者更加坚持，而增加的压力使退避者更加抵触。"
  summary: |
    亲密关系中常见的功能失调的互动模式：一方想要讨论和改变（要求者），另一方逃避和退缩（退避者）。这是一个自我强化的恶性循环。多数情况下女性是要求者、男性是退避者，既与性认同差异有关，也与权力不平衡有关。
  tags: [冲突模式, 沟通障碍, 恶性循环, 性别差异]

- id: f18
  title: "关系维持机制框架（认知+行为）"
  type: framework
  source_chapter: "第14章 亲密关系的维持和修复"
  source_quote: |
    "忠诚的伴侣在认知上表现为：认知上的相互依赖（更多用'我们'）、积极错觉（理想化伴侣）、感知到的优越感（认为自己的关系更好）、对替代选择的无视、贬低诱人的替代选择。"
  summary: |
    关系维持分为认知和行为两大类机制。认知机制包括：认知相互依赖、积极错觉、感知优越感、忽视替代选择、贬低替代选择。行为机制包括：牺牲意愿、米开朗基罗现象、顺应、自我控制、共同玩乐、宽恕。
  tags: [关系维持, 承诺, 认知偏差, 行为策略]

- id: f19
  title: "米开朗基罗现象"
  type: framework
  source_chapter: "第14章 亲密关系的维持和修复"
  source_quote: |
    "当伴侣的行为表明他们鼓励我们成为我们想要成为的人时，亲密关系也可能变得更加亲密。当伴侣关注和回应他们的需要和愿望，帮助他们成为他们想要成为的人，他们就会对亲密关系更为忠诚。"
  summary: |
    好的伴侣关系像雕塑家雕琢大理石一样，帮助对方成为其理想中的样子。伴侣通过支持学习技能、赞同新角色、促进自我成长，潜移默化地塑造对方。这种现象能同时提升亲密关系质量和个人幸福感。
  tags: [自我成长, 伴侣支持, 关系提升, 理想化自我]
