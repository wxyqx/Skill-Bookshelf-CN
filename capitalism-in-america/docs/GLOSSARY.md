# GLOSSARY — 《繁荣与衰退》共享术语词典

> 格林斯潘 & 伍德里奇的特定用法。与书架其他卷术语体系不同。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **创造性破坏** | 熊彼特比喻的操作化：五机制通道（机器/流程/投入成本/要素利用/地理）+三大社会问题 | ≠ 泛泛的"创新"；是替换性（有输家）的结构变化 |
| **多要素生产率（MFP）** | 资本与劳动无法解释的 GDP 增量（索洛-阿布拉莫维茨残差），"终极指标" | 核算残差被赋予实质含义——循环论证风险须自觉 |
| **通用目的技术（GPT）** | 改进空间大、用途多样、渗透广、强互补的技术；效应滞后数十年 | ≠ 即期见效；索洛悖论=还在重组中 |
| **大压缩** | 1940-1970 不平等罕见、充分就业、蓝领中产的历史特例（戈尔丁-马戈） | ≠ 市场经济自然状态；战争与政策的特例 |
| **管理型资本主义** | 寡头+股权分散被动+经理自主+终身雇佣+企业办福利 | 被股东积极主义终结的历史形态 |
| **权益挤出机制** | 权益支出占 GDP↑≈国内储蓄等额↓→资本存量→生产率 | 统计稳定性惊人但因果性存疑（恒等式嫌疑） |
| **铁笼 vs 沼泽** | 美国困境是政策可逆的自制铁笼，非结构性宿命沼泽 | ≠ 衰落宿命论；可逆性判断 |
| **繁荣-萧条天花板** | 金本位下的周期机制：扩张→黄金约束→利率上行→调整；1913 美联储以主权信用替代 | ≠ 现代央行周期；金属货币约束的历史机制 |
| **大压缩**（戈尔丁-马戈） | 见上 | |
| **受迫劳动连续谱** | 鞭子驱动→分成雇农制（债务锁定）→罪犯租赁——旧体制改头换面存续 | ≠ 废除即自由；强迫劳动的形式演化 |
| **马匹悖论** | 新技术初期反使旧技术繁荣（铁路时代马匹增 6 倍） | ≠ 替代立即发生；互补期常被忽视 |
| **铁笼** | 见"铁笼 vs 沼泽" | |
