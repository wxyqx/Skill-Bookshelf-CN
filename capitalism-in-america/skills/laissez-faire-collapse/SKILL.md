# 自由放任的瓦解条件

## R — 原文 (Reading)

> 自由放任只适用于小商贩＋无主土地的社会；当企业跨州雇用数千人时，市场与政治的边界必然重划——1875-1900 年物价年均跌 1.9%，1881-1905 年美国发生 3.7 万次罢工。
>
> — 格林斯潘、伍德里奇，《繁荣与衰退》第五章（要点组织）

---

## I — 方法论骨架 (Interpretation)

自由放任不是永恒真理，其运转依赖隐含前提；分析框架：

1. **前提检验**：自由放任预设市场主体是小商贩、土地无主、企业规模小到劳资冲突可在社区内化解——巨型企业（跨州雇用数千人、铁路跨国界）摧毁了这些前提，市场与政治的边界必然重划；
2. **通缩-冲突传导链**：长期通缩同时冲击四类人群——生产者（农产品价格暴跌）、借贷者（名义债务实际加重）、雇主（名义工资黏性下被迫压成本）、雇员（工资不降但失业）——交叉引爆民粹（布赖恩）与工运（3.7 万次罢工、霍姆斯特德血案）；
3. **意识形态的掩护机制**：金本位痛苦被解读为"它正在起作用"——制度选择被伪装成自然律（批评者需先破解这层修辞）；
4. **转折的完成**：反托拉斯公诉、《赫伯恩法》、第十六修正案（个税）、美联储——守夜人政府转为管制国家；一战总动员为新政预演（罗考夫命题：新政每项措施几乎都能在一战找到先例）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 波洛克案与谢尔曼法虚置（第五章）
- **问题**: 为什么反托拉斯立法后垄断反而更强？
- **方法论的使用**: 法律与宪法解释的博弈——1895 波洛克案五票否决个税、E.C.奈特案以"制造不等于贸易"实际废除谢尔曼法——司法把守夜人立场制度化。
- **结论**: 自由放任的终结需要同时改变立法、司法与观念三道闸。

### 案例 2: 美联储取代摩根（第五章）
- **问题**: 私人金融秩序为什么被公共机构取代？
- **方法论的使用**: 摩根在 112 家公司握 341 个董事席位——"私人央行"以个人信用承担公共职能，普若听证会暴露其不可持续。
- **结论**: 体系性风险需要公共最后贷款人，私人秩序撑不起现代体量。

## E — 可执行步骤 (Execution)

1. **验前提**：对照"小商贩+无主土地+社区化解劳资"三前提检查现状
   - 完成标准: 每个前提有"存续/破坏"判定
2. **测传导链**：通缩/通胀的分配冲击是否正在四类人群中交叉积聚
   - 完成标准: 四类人群的受损度量与抗议指标同步追踪
3. **识别转折信号**：观念革命（知识分子转向）、司法转向、立法突破、央行/管制机构设立
   - 完成标准: 转折信号清单逐项核对
   - 判停条件: 三前提存续且无传导链积聚 → 判定自由放任仍可持续，终止
4. **给边界设计**：新边界的落点（反垄断、社保、央行、劳工保护）与配套次序
   - 完成标准: 边界设计与传导链的痛点对应

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把管制国家的兴起当单向进程——两党钟摆使管制有紧有松（里根时代回摆），框架描述结构转向而非单行道
- 用于解释一切政府扩张——战争、危机、观念各有独立的扩张机制，本框架针对规模经济与通缩传导

### 作者在书中警告的失败模式

- 把"市场规律"当自然律的意识形态包装（金本位修辞）——任何制度选择都有分配后果
- 对进步时代的浪漫化——革新主义者的中产精英立场与优生学污点（作者亦予揭示）

### 作者的盲点 / 时代局限

- 把进步时代写成观念驱动的态度革命，弱化农民与工人的物质利益诉求（物质数据与观念叙事的权重失衡）
- "美国例外论"式的收尾（宪法与文化使美国免于欧式反建制思潮）论据单薄

### 容易混淆的邻近方法论

- 与波兰尼"大转型"（双向运动）：波兰尼讲市场扩张引发社会保护的反向运动——与本框架的传导链高度同构，可互证
