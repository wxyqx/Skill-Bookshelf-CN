# 活力衰退诊断（权益挤出）

## R — 原文 (Reading)

> 州际移民率较 1948-71 均值降 51%；新企业占比 14.6%（1978）→8.3%（2011）；上市公司 6797 家（1997）→3485 家（2013）；权益支出占 GDP 从 4.6% 升至 14.6%——美国"大篷车"社会正在变成"堡垒"社会。
>
> — 格林斯潘、伍德里奇，《繁荣与衰退》第十二章（要点组织）

---

## I — 方法论骨架 (Interpretation)

诊断一个经济体是否患上"活力衰退症"的完整程序：

1. **六症状普查**：①地域流动率（州际/跨县迁移，降 51%）②创业率（新企业占比 14.6%→8.3%）③IPO 与上市公司数（6797→3485 家）④包容失败程度（破产文化、重启频率）⑤基建投资（贝永大桥 47 项审批 4 年）⑥企业集中度与前沿公司技术扩散（900 余行业中 2/3 更集中；OECD"前沿公司"与追赶者差距拉大）；
2. **主因假说——权益挤出**：权益（福利）支出占 GDP 4.6%→14.6%，与国内储蓄下降等额对应→资本存量与生产率受损；"权益悖论"：领受者相信"拿回自己的钱"，改革不可行的政治机制；
3. **次因——监管爆炸**：《联邦公报》年增 7.3 万页、30% 工作需许可证、小企业合规成本高于大企业；
4. **三排除**：教育领先丧失说、IT 革命失望论（戈登）、劳动力萎缩论——各有反驳但反驳力度不均（自校）；
5. **药方**：瑞典福利改革范本（固定缴费制+退休年龄挂钩预期寿命+物价指数化；公共支出 67%→49%、债务 70%→37%）+银行 25-30% 资本充足率替代细则监管；"铁笼 vs 沼泽"——困境可逆。

## A1 — 书中的应用 (Past Application)

### 案例 1: 美国的六症状全景（第十二章）
- **问题**: 美国创新活力为什么下降？
- **方法论的使用**: 六症状普查——切蒂研究"30 岁收入超父母概率 86%→51%"、Hsieh-Moretti 迁移成本使 GDP 损失 9.5%、900 行业 2/3 集中度上升。
- **结论**: 多症状同步指向系统性衰退而非周期。

### 案例 2: 瑞典钥匙（大结局）
- **问题**: 福利国家能自救吗？
- **方法论的使用**: 瑞典 1990 年代改革对照——固定缴费制自动平衡、退休年龄 65→挂钩预期寿命；公共支出 67%→49%。
- **结论**: "铁笼有钥匙"的实证——但规模限制与共识条件须自觉。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 诊断某经济体（国家/区域）创新活力与企业家精神的衰退
2. 分析福利制度与增长/储蓄的宏观关系
3. 评估"日本化""欧洲化"（低增长低利率低活力）风险
4. 政策辩论中检验"活力衰退"的归因是否成立

- "活力下降""创业率暴跌""经济僵化""日本化"
- "福利拖累经济""企业家精神""vitality" / "僵尸经济"

- 与 `creative-destruction-framework` 的区别：创造性破坏是活力的动力机制，活力诊断是动力衰减的症状普查——机制与症状。

## E — 可执行步骤 (Execution)

1. **六症状普查**：逐项采集流动率、创业率、IPO 数、破产文化、基建、集中度数据
   - 完成标准: 六症状各有趋势数据
2. **筛查非病因**：排除周期性因素与统计口径变化
   - 完成标准: 周期因素剔除后症状仍存在才成立
3. **检验主因假说**：权益支出与储蓄/投资的挤出关系（注意恒等式嫌疑，补对照组）
   - 完成标准: 主因假说有因果检验或标注为假说
   - 判停条件: 六症状多数不成立 → 判定"活力衰退"不成立，转查其他病因
4. **配药方**：按确诊症状对照瑞典范本与监管简化清单
   - 完成标准: 药方与确诊症状对应，政治可行性单列

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把权益挤出的"统计稳定性"当因果证明——恒等式嫌疑（ce04），须补对照组与外部融资渠道分析
- 用于周期性衰退或单一企业活力问题——框架针对经济体的结构性活力

### 作者在书中警告的失败模式

- "权益悖论"：福利领受者的自我支付幻觉使改革在政治上不可行——技术方案与政治可行分开
- 监管爆炸对小企业的歧视性成本——合规成本固定，规模越小分摊越重

### 作者的盲点 / 时代局限

- 六症状中"包容失败"等软指标难以量化，诊断的客观性打折
- 三个排除解释的反驳力度不均（作者自认"深层原因依然不明"）——主因假说应作假说使用
- 对不平等扩大与活力衰退的共生关系未纳入框架

### 容易混淆的邻近方法论

- 与 Secular Stagnation（长期停滞）理论：萨默斯讲需求侧长期不足，本框架讲供给侧活力被挤出——需求侧与供给侧两说并存
