  type: framework
  source_chapter: 第1章（另见第13章试验主义）
  source_quote: "在接踵而来的第二次大战的破坏下，各国政府开始接受新观点，而且，实际上它们可以在一张白纸上写下蓝图。"
  summary: |
    判断重大改革/制度重建是否可行，先问：旧体系是否已实际失灵甚至停摆？狭隘利益是否被压制？
    只有在"白纸期"（旧规则失效、利益格局被外生冲击打乱、无既有受益者阻击）才可能达成彻底重建；
    平静议程中的宏大改革蓝图大概率流产（C-20 改革纲要即反例）。
    用法：推动变革前先评估窗口是否打开；窗口未开时只做应急准备与方案储备，等待危机开启窗口；
    若现状可论证地瓦解而无确定性收益方案，可用探索性试验替代等待完美方案（"若不尝试，将无从知晓"）。
  tags: [改革时机, 危机驱动, 制度变迁, 机会窗口]

- id: f02
  title: "私器公用"两难诊断（特里芬模板）
  type: framework
  source_chapter: 第2章
  source_quote: "这种分析被称之为特里芬困境，它很难脱离自己无法改变的逻辑。"
  summary: |
    凡一种主权私器被用作公共品（储备货币、平台规则、枢纽企业标准），其私利目标与公共职责必然冲突：
    公共品供给要求私器方持续输出/让利，而持续输出侵蚀其自身信用与可持续性。
    诊断任何此类安排时三问：流动性/公共品靠什么输出？信心/私器信用靠什么支撑？两者是否兼容？
    若不兼容，则内置崩溃时间表，只能靠替代供给（SDR式）或转嫁负担延缓，无法根除。
  tags: [结构性两难, 储备货币, 制度诊断, 特里芬]

  type: framework
  source_chapter: 第1章、第4章、第11章
  source_quote: "完全消除债务人方面的道德风险，如果这是可行的话，将只会起到给债权人带来道德风险的作用，反之亦然。"
  summary: |
    评估任何制度/规则设计做三检：①对称检验——只约束弱方（逆差国/债务人/员工）而不约束强方

    完全消除一方的风险后果只会把它转嫁给另一方，设计目标是找平衡点而非消灭；③风险归属检验——
    政府担保介入会模糊私人风险与公众风险，必须把风险归属和政府角色透明化。

- id: f10
  title: 强承诺干预框架——"宏大、综合、一致"+时机=压垮预期
  type: framework
  source_chapter: 第5、8章
  source_quote: "这次一揽子计划成功的另一个原因，在于该计划是宏大、综合而且一致的。在1978年，美国财政部也采取了许多措施以保卫美元，但这些措施都是零零散散地出台的，而且半心半意，因而未能成功地影响市场心理。"
  summary: |
    市场只对强承诺作出反应。有效干预/救市的有效性条件：①规模宏大且一揽子综合（多项措施互相印证），
    零散措施反而加速信心丧失；②与基本面政策方向一致（脱离货币政策的干预很可能无效）；
    ③多国协调以放大信号；④时机在市场接近拐点时充当"致命一击"，顺势而非逆势（只熨平反向尖峰）；
    ⑤象征性动作与实际资金同等重要——打破惯例、宣布未必全额可提取的授信本身就是信用信号；
    ⑥体制前提——先查决策权限结构，"相互否决制"下最终决策权归于最不情愿干预的机构，
    协同干预需财政部-央行-白宫一致。反面工具：当干预被市场当作低价筹码时，
    "当你赌博时，最好的战略就是完全、突然地改变战略"——釜底抽薪、抽走对手盘。
  tags: [干预, 市场预期, 协调行动, 一揽子计划, 时机]

- id: f11
  title: 软承诺与模糊工程——公开模糊、内部锚定，防投机攻击
  type: framework
  source_chapter: 第8、9章（另见第1章）
  source_quote: "所有人都同意对汇率作出一个过于具体的公开承诺会给投机者提供一个过于诱人的目标。"
  summary: |
    对市场敏感的承诺要刻意模糊：目标范围不公开、不书面确认、有限制/暂时/未被承认；
    精确数字只放在不公开的副手报告中（公开立场模糊+内部锚定精确）；超范围先协商修改而非机械保卫，
    波幅调整幅度远小于波幅宽度使交易员无法做"单向打赌"。模糊的代价是约束力弱——
    软目标区既躲开了投机靶子也失去了真承诺。另注意公报期望值管理：没有真正重要的事就不发公报，
    仪式化重复承诺会推高市场期望并透支可信度。关键概念的模糊也可换取协议达成（"根本性不平衡"
    无法定义——"只有你见到一个，才能认出一个"），代价是日后争议。
  tags: [模糊承诺, 目标区, 投机, 公报工程]

  title: 多边协调的成熟度评估与组织设计
  type: framework
  source_chapter: 第9章（另见第2、4、5章）
  source_quote: "成功的政策协调，需要四个必要条件。第一个是参与国之间紧密而相互依赖的关系。第二个条件是对某些宏观经济政策的协调将带来的既定成果要有共同的理解。"
  summary: |

    合作框架分层递进——信息交流→减少意外→危机互助→真协调，先做低层次不越级承诺；
    协调目标停留方向性、相互启发层面，避免精确数量目标（1.2亿人的经济无法精确调控）；
    内嵌快速调整机制或缩小承诺范围，因为"计划、谈判总要花去几个月一年"，时滞会吞掉协调价值。
  tags: [政策协调, 多边机制, 四条件, 组织设计]

- id: f15
  title: 危机管理序列——止血→争取时间→结构改革→自愿减债（逐案+时间窗口）
  type: framework
  source_chapter: 第7、11章
  source_quote: "危机初期所谓逐案解决，或者说一个国家一个国家的解决方法是一个关键性决定，它沿用至今。其替代方案是所谓全球解决方案，它有一个缺陷：没有针对各个国家的不同需要，这正是债务国不支持该方案的原因。"
  summary: |
