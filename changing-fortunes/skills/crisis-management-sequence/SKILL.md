# 危机管理序列——止血 → 争取时间 → 改革 → 减债

## R — 原文 (Reading)

> 墨西哥提供本金由美国财政部"零息债券"作为抵押担保的20年期新债券，以交换打折扣的旧债务。……对一个债务大国来说，这是第一次组织广泛的、市场化的、自愿削减债务交易，它被证明是一个真正的转折点。
>
> — 保罗·沃尔克，第7章/附录1（1989-90年墨西哥布雷迪减债交易）

---

## I — 方法论骨架 (Interpretation)

危机管理有两个目标，顺序不可颠倒：先制止系统性崩溃（保住支付体系与金融网络），再解决单个债务人的可持续性。围绕这两个目标，工具按序列展开——这个序列不是事先设计，而是多次危机中被动演进出来的：

1. **止血**：应急流动性结清支付体系，"一匙一匙地喂入"以防抽逃；官方资金只做桥梁，不替私人债权人买单。
2. **争取时间**：以"偿付停顿"（standstill）而非"债务拖欠"的措辞稳住法律与市场预期；逐案处理——不给统一救助框架以防道德风险、保留各国重返市场的资格，代价是拖延。
3. **结构改革**：续贷与改革条件互锁（条件性），融资太多调整太少无助于债务人，反之无助于债权人。
4. **自愿减债**：最后才动债务存量——市场化、自愿、有担保的打折换新债，且减债与新增融资互补而非互替，减免必须与可信改革互为条件。

配套操作：为众多债权人设立代理谈判结构（按敞口+地域组成咨询委员会）降低谈判成本；时间窗口管理——政权/管理层空窗期用临时安排稳住局面，但需继任者担保，否则只是粉饰门面。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1982年8月墨西哥危机——止血与争取时间
- **问题**: 墨西哥宣布无力偿债，全球银行体系面临连锁违约风险，几十家债权银行需协调行动。
- **方法论的使用**: 三层顺序——先止血（央行联合过渡贷款18.5亿结清支付体系，一匙一匙喂入）；再稳预期（"偿付停顿"措辞避开交叉违约法律后果，财长把银行的沉默解释为"默许"造成既成事实）；再锁集体行动（德·拉罗西埃以IMF批准计划为杠杆，要求商业银行先承诺新融资总额90%的"关键主体"，关掉小银行免费搭车的退路）。
- **结论**: 先保系统、再逐案，条件性同时加于债务人与债权人两侧。
- **结果**: 危机未演变为全球金融崩溃，模式复制到多国；但逐案+只融资不减债的代价是债务国十年"失败的十年"。

### 案例 2: 贝克计划到布雷迪计划——序列的后半段
- **问题**: 融资换时间的策略维持三年后走到尽头，债务存量问题无法再回避。
- **方法论的使用**: 贝克计划（1985，增长导向新贷款）失败暴露了序列缺了最后一段；1987年底墨西哥在J.P.摩根协助下以70-80美分换1美元面值发行零息债券抵押的20年期新债，1989年布雷迪计划把市场化自愿减债升为官方战略，1990年2月一揽子减债35%（约50%银行选降息、40%选减本金）。
- **结论**: 减债是新融资的互补品而非替代品，且必须与可信改革互为条件——格瑞亚公式："没有什么能替代良好的经济政策，但没有债务缓解就启动不了良性循环。"
- **结果**: 市场信心回归，墨西哥重新获得银行新贷款与债券市场准入。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一个行业/生态多家主体同时爆发兑付危机，用户（监管方、行业协会、平台方、母集团）要排处置顺序：先保什么、谁先谁后、要不要统一救助。
2. 用户在组织众多债权人/投资人谈判，纠结怎么搭谈判结构、防止个别方抽逃搭便车。
3. 用户处于管理层/政权交接窗口期，需要用临时安排稳住局面，并在评估临时安排的风险。

### 语言信号 (用户的话里出现这些就应激活)

- "同时爆雷这么多家，先救谁？要不要出统一纾困方案？"
- "债权人有四十多家，怎么谈？怎么防止小股东/小债权人先跑？"
- "现在是先稳住还是先动手术？减债/重组什么时候提上桌？"
- "新班子还没到位，先用临时安排撑两个月行不行？"
- 英文: crisis sequencing / standstill / creditor committee / when to restructure / systemic stability first

### 与相邻 skill 的区分

- 与 `crisis-diagnosis-first` 的区别: 那个回答"这是什么病"（流动性vs偿付能力），本 skill 回答"病定了之后治疗顺序是什么"；诊断结论（偏偿付能力）会直接决定本序列要走到最后一段（减债）。
- 与 `unilateral-default-trap` 的区别: 那个评估威胁性限付/单方面违约的自我失败；本序列坚持自愿重组与债权人权利框架，两者在"怎么对待债权人"上立场相反。
- 与 `incentive-symmetry-check` 的区别: 那个检验救助设计中的道德风险双向平衡（条件性也加于债权人）；本 skill 是完整时间序列，道德风险只是其中逐案处理环节的理由。

## E — 可执行步骤 (Execution)

1. **划定系统性威胁边界**
   - 明确"若什么都不做，72小时内/短期内什么会连锁倒塌"（支付通道、供应链、上下游担保链）。
   - 完成标准: 一份系统性关键节点清单，区分"倒塌会传染"与"倒塌可隔离"的主体。

2. **止血——应急流动性**
   - 对系统性关键节点提供应急资金，分批喂入；每一笔标注偿还来源，绝不直接替私人债权人承担损失。
   - 完成标准: 支付/提现/交付通道恢复运转，且资金台账可区分"桥梁"与"置换"。

3. **争取时间——standstill 与逐案**
   - 用非违约措辞（偿付停顿、展期安排）稳住法律后果；对非系统性主体逐案处理，不给统一救助框架；同步搭建债权人代理结构（按敞口+地域组成咨询委员会）。
   - 完成标准: 无交叉违约触发；代理委员会获得多数敞口授权；明确记录"逐案的拖延代价"被接受。
   - 判停条件: 若诊断结论为偏偿付能力且时间已被前几轮续贷耗尽，压缩本步、直接进入第5步。

4. **条件性改革**
   - 续贷/展期与可验证的整改计划互锁（融资太多调整太少无助于债务人，反之无助于债权人）。
   - 完成标准: 整改里程碑与资金释放节点一一对应，且整改可由第三方验证。

5. **市场化自愿减债**
   - 仅当净转移确认不可持续时启动：打折换担保新债、自愿参与、与新融资互补；临时安排须有继任者担保。
   - 完成标准: 减值方案附担保/增信结构，参与率与覆盖率可统计，减债额度与改革里程碑挂钩。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题性质未定性（还不知道是流动性还是偿付能力）：先走 `crisis-diagnosis-first`，否则整个序列可能建在误诊上（拉美十年误诊的教训）。
- 用户在权衡单方面限付/威胁违约：那是 `unilateral-default-trap`，本序列明确排除对抗性违约路径。
- 单一主体、债权人结构简单的小额违约：完整序列的组织成本超过收益，直接谈判即可。

### 作者在书中警告的失败模式

- **序列缺最后一段的十年拖延**（第7章，ce01）: 1982年后只做止血+争取时间、拒绝减债，"借小钱还全额利息"拖成"失败的十年"——序列不完整本身就是失败模式。
- **对抗性违约的自我失败**（第7章，ce13）: 秘鲁限付、巴西暂停付息都跳过序列直接摊牌，"前门省下的钱从后门流出"，均以经济崩溃收场；对照墨西哥维持债权人权利的谈判路径反而最先重返市场。
- **临时安排变粉饰门面**（第7章）: 政权空窗期的隔夜互换"粉饰"储备只能买时间，没有继任者担保的临时安排在交接时放大崩盘风险。

### 作者的盲点 / 时代局限

- **序列是被动演进而非设计**: 作者承认每一步（standstill、关键主体、布雷迪）都是问题暴露后的补救，本 skill 把它整理为前瞻序列，但应记住其有效性依赖于"下一次危机与上次相似"——1992年后主权债务进入国内法债与集体行动条款（CAC）强制化时代，"自愿"重组的形态已变。
- **对发展中国家代价的轻描淡写**: 双作者视角下"危机未演变为全球金融崩溃"是成功标准，债务国十年紧缩的民众代价与银行家自辩色彩被弱化。
- **未涉及中国等新兴债权国**: 序列默认债权人是以欧美银行为主的私人银行，对新兴债权国官方贷款占主导的重组（后来的非洲、斯里兰卡情形）无覆盖。

### 容易混淆的邻近方法论

- `crisis-diagnosis-first`: 诊断门 vs 治疗序列，必须先后衔接。
- `unilateral-default-trap`: 序列内自愿重组 vs 序列外对抗摊牌，互为反面参照。
- `incentive-symmetry-check`: 序列中第3-5步的道德风险权衡工具。
