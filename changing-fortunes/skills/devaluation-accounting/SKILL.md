# 贬值/价格调整效果三重核算

## R — 原文 (Reading)

> "广场会议后的两年，美元兑日元的名义汇率下降了约41%。但把美国在世界各地的外贸量进行加权平均，得知美元实际的汇率仅下降了32%，约为名义下降值的3/4，这是因为许多发展中国家实行钉住美元的汇率制度。"
>
> — 行天丰雄，第9章

---

## I — 方法论骨架 (Interpretation)

这是一套给"价格已经调过了"的政策做效果核算的纪律，防止把名义变动直接读成结果。

1. 第一道修正是时滞：价格变化总是先于数量反应——贬值初期出口量没跟上、进口账单先变贵，收支往往先恶化再改善（J曲线）。所以初期变差不构成"政策失败"的证据。
2. 第二道修正是稳定期：数量反应需要价格在足够长的时间里保持稳定才会显现；如果价格每个月都在动，J曲线就不断被重新加深，任何价位上都没有稳定期让账目反应出来。
3. 第三道修正是权重：名义变动幅度不等于有效变动幅度——对手方跟随降价、第三方钉住你的定价基准，都会稀释你实际获得的价格优势，必须按贸易量/品类/渠道加权重算"有效变动"。
4. 还要留一笔滞后账：强价格扰动造成的结构性变化（供应关系转移、产能迁移）有滞后效应且不可逆，即使价格回调，旧格局也回不来。
5. 三关全过，改善才能归因于调价；任何一关不过，"调价换平衡"就是幻觉，结论必须是"仍需基本面（成本/产品/储蓄-投资结构）调整"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 广场协议后两年的贬值效果核算
- **问题**: 广场协议后美元对日元名义贬值约 41%，但美国贸易逆差两年内并未改善，舆论开始质疑"贬值无效"。
- **方法论的使用**: 作者过三道修正核算：①J曲线——价格变了、进出口量未反应，初期赤字反而扩大；②稳定期——1986-87 年汇率每月都在变，美元在任何价位都没稳定足够长时间，J曲线不断加深；③权重——按贸易量加权后有效贬值仅约 32%，因许多发展中国家钉住美元稀释了权重；另叠加滞后效应——80 年代初强美元造成的进口模式变化不会很快逆转。
- **结论**: 逆差未改善不能证明贬值无效，但即便贬值完全传导，也不解决储蓄-投资失衡这个基本面。
- **结果**: 此核算支撑了全书核心命题：汇率政策永远不能替代基本面政策。

### 案例 2: 1971年史密森协议的有效汇率核算
- **问题**: 史密森谈判中各国对"对美元升值多少"僵持不下，小国抵制双边升值。
- **方法论的使用**: 沃尔克发明贸易加权的"有效汇率变动"算法——对 OECD 整体约 8%、不含加拿大则为 12%，把议题从"对美元双边升值"重构为"整体有效重估"，并给小国算出"维持现平价即实际小幅贬值"的台阶。
- **结论**: 名义双边变动与加权有效变动之差本身就是谈判与评估资源。
- **结果**: 协议达成（日元+16.9%、马克+13.57%）；但因幅度不足且无承诺支撑，六个月后英镑浮动——核算口径正确不能替代幅度足够。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司全线降价/大幅促销后一两个季度，数据起色或未起色，用户想宣布"降价战略成功/失败"并决定下一步。
2. 货币贬值/汇率调整后贸易数据迟迟不改善，用户问"贬值到底有没有用、要不要再贬"。
3. 用户想区分"名义调了 30%"与"实际有效调了多少"（对手跟随降价、部分品类没降）。
4. 评估历史上一轮调价（提价、补贴、定价重构）的真实效果，为复盘或对标提供结论。

### 语言信号 (用户的话里出现这些就应激活)

- "降价都半年了怎么市场份额还没起来，是不是得再降一轮？"
- "名义上降了三成，感觉实际效果没那么多，怎么算有效降幅？"
- "货币贬了这么多，出口顺差怎么反而还在恶化？"
- "现在能宣布调价成功了吗？会不会太快下结论？"

### 与相邻 skill 的区分

- 与 `strong-commitment-intervention` 的区别：强承诺干预是"如何通过干预把汇率/价格打下来或稳住"的行动设计；本 skill 是行动之后的评估纪律——核算真实效果，两者一个在事前、一个在事后。
- 与 `crisis-diagnosis-first` 的区别：诊断先行判断问题性质（流动性/偿付能力），决定处置路径；本 skill 判断"已实施的价格调整政策有没有产生真实效果"，决定的是归因与下一步（再调 vs 基本面调整）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **固定评估口径**
   - 完成标准: 明确评估对象（收支/份额/销量）、起算时点、计量单位与加权口径，并确认数据可按此口径取得；若用户尚未实施调价，判停并转定价方案设计建议。
2. **过时滞关**
   - 完成标准: 判断当前数据处于"价格已变、数量未反应"的哪一段，明确"初期恶化不构成失败证据"，并给出预期时滞区间的估算依据。
3. **过稳定期关**
   - 完成标准: 检查调价后价格是否稳定了足够长时间；若存在频繁再调价，指出J曲线被反复加深的事实，改善未显现不得轻率归因为政策失败。
4. **过权重关**
   - 完成标准: 算出加权后的"有效变动幅度"（对手跟随、第三方钉住/跟随、未调品类稀释），并明示名义与有效之差。
5. **结论分级**
   - 完成标准: 三关全过才允许把改善归因于调价；任一关不过，结论写明"调价效果待显或被稀释，仍需基本面调整"；并单列滞后效应中不可逆的结构变化，防止高估回调后的恢复能力。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 调价尚未实施、用户要的是"该不该降价/定多少"——那是定价策略设计问题，没有效果可核算。
- 一次性促销的短期营销 ROI 核算——促销核算看即时转化，不涉及 J 曲线时滞与价格结构平衡。
- 纯成本或利润率核算——与"调价换平衡"的效果归因无关。

### 作者在书中警告的失败模式

- **贬值幻觉（第10章）**: 1971 年以来美元对日元、马克分别贬值 60% 和 53%，美国逆差却持续扩大——贬值被用作回避财政纪律与储蓄-投资调整的替代品；政策辩论聚焦"再贬多少"而非"赤字为何存在"即是警讯。
- **频频变动下的归因错误（第9章）**: 汇率每月都在变，J曲线不断加深，任何价位上都没有稳定期让账目反应改善——此时宣布"无效"或"有效"都是幻觉。

### 作者的盲点 / 时代局限

- 作者自承滞后效应"还没有足够的经验式证据"，三重核算中第三道的参数化程度有限。
- 写于 1991-92：对欧洲货币联盟/ERM 的汇率稳定前景乐观，未预料其内部调整同样受时滞与稳定期约束并被危机证伪；全书未涉及中国等新兴经济体在全球贸易权重中的动态。
- 双作者为美日决策精英，核算框架以大宗贸易数据为基础，对服务贸易与数字经济的权重结构无法覆盖。

### 容易混淆的邻近方法论

- `strong-commitment-intervention`（事前干预设计）与 `crisis-diagnosis-first`（问题定性）——见 A2 区分；另与 `soft-commitment-ambiguity` 易混：后者讨论目标参数该不该公开模糊，本 skill 讨论效果如何核算，与公开与否无关。
