# 激励对称设计检验

## R — 原文 (Reading)

> "完全消除债务人方面的道德风险，如果这是可行的话，将只会起到给债权人带来道德风险的作用，反之亦然。……坚定地把私人风险从公众风险中分离出去——或者广义地说，政府作用的透明度——是防止道德风险的关键。"
>
> — 沃尔克 & 行天丰雄，第11章（桂田）

---

## I — 方法论骨架 (Interpretation)

评估任何制度或规则设计，过三道检查。第一检，对称检验：把规则的全部义务列出来，看落在谁头上——只约束弱方（逆差国、债务人、被监管的小机构）而不约束强方（顺差国、债权人、系统核心）的条款，强方永远有动力也有能力不执行，必成一纸空文；可持续的规则必须让盈亏两侧都面对真实的调整压力。第二检，道德风险双向守恒：把某一方的风险后果压到零，风险不会消失，只会转嫁给另一方——债务人风险清零则债权人乱放贷，债权人风险清零则债务人乱举债；因此设计目标是找平衡点（限额、共同承担、双方各留敞口），而不是"彻底消灭道德风险"这个不可能的目标。第三检，风险归属透明：政府担保一旦介入，私人损失与公众（纳税人）损失的边界就开始模糊，道德风险正是从这个入口涌入的——必须公开写明哪些损失由私人股东与管理层承担、哪些动用公共资金，把政府角色透明化。"规则要公平"是常识，"道德风险守恒、只能平衡不能消灭"是反直觉的独特判断。

## A1 — 书中的应用 (Past Application)

### 案例 1: 稀缺货币条款成一纸空文（第1章）
- **问题**: 凯恩斯方案要求惩罚长期顺差国（"短缺货币"条款），允许逆差国限制购买顺差国出口。
- **方法论的使用**: 对称检验——该条款只威胁顺差方，而美国作为潜在顺差对象从一开始就反对一切将其付诸实行的建议。
- **结论**: 没有强方同意的自我约束条款只是装饰。
- **结果**: 条款从未被启用，"成了一纸空文"；30 年后德日巨额顺差时美国自己陷入同一困境，问题仍未解决。

### 案例 2: 指标方案——把对称义务制度化（第4章）
- **问题**: 70 年代美国逆差累积而顺差国（德日）无调整义务，体系压力全在美国一侧。
- **方法论的使用**: 沃尔克的"客观指标"方案把对称检验制度化——顺差国若不主动调整，将逐步丧失储备兑换权；调整义务从单向变为双向。
- **结论**: 规则要对顺差国也产生真实约束，才谈得上体系修复。
- **结果**: 因顺差国政治抵制而失败，但成为"对称义务"设计的标准参照（作者视为凯恩斯方案的第二次尝试）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计存款保险、投资者保护基金、平台兜底担保等风险分担机制，纠结"全额担保还是限额担保"。
2. 起草多方合作协议/联盟规则/行业标准时，需要检查义务分配是否只落在一方头上。
3. 评估 IMF 式条件性、平台处罚规则、监管限额等是否在现实中可执行（会不会被强方架空）。
4. 救助方案辩论中有人主张"必须严惩道德风险/必须彻底担保"，需要双向权衡框架。

### 语言信号 (用户的话里出现这些就应激活)

- "道德风险 / moral hazard"、"这样担保会不会鼓励冒险"
- "为什么只有我们/弱者被约束，他们（强者/债权人/大平台）完全不用守规则？"
- "风险最后算谁的？纳税人/公众会不会买单？"

### 与相邻 skill 的区分

- 与 `triffin-dilemma-diagnosis` 的区别: 那是结构层诊断（私器公用是否内生崩溃）；本 skill 是制度层检查表（义务分配与风险归属是否对称），两者可先后使用但层次不同。
- 与 `crisis-diagnosis-first` 的区别: 那判断单个债务人"不能还是不愿"并排序处置；本 skill 在设计事前的规则，不处理已发作危机的处置顺序。
- 与 `unilateral-default-trap` 的区别: 那是债务人谈判策略的边界（威胁违约自我失败）；本 skill 站在设计者角度让双方激励平衡，恰好是避免把债务人逼向对抗性违约的制度手段。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列义务清单**
   - 把规则/担保/协议的全部义务、惩罚、出资责任逐条列出并标注归属方。
   - 完成标准: 一张"义务—归属方"对照表，无遗漏条款。

2. **对称检验**
   - 检查每条义务：是否只约束弱方？强方（顺差侧/债权人/核心玩家）是否有等效义务与等效惩罚？强方违反时有无可执行的手段（历史上稀缺货币条款式的空文）？
   - 完成标准: 对每条单向义务给出对称化修改建议，或明确论证为何单向成立（如强方已提供对价）。

3. **道德风险双向检验**
   - 对每一方分别问：若把这一方的风险后果压到零，风险转移到了谁身上？找到平衡点工具（限额担保、共同承担、股东先亏、双向条件性）。
   - 完成标准: 明确写出"哪一方承担多少、另一方保留什么敞口"，并指出'彻底消灭'式方案为何不可行。
   - 判停条件: 若设计本身不含任何风险后果转移（如纯信息规则），跳过本步。

4. **风险归属透明化**
   - 划清私人损失与公共资金的边界，写入条款：谁先亏、亏到哪里触发公共介入、政府角色是否公开。
   - 完成标准: 方案文本中可指出具体的归属条款；若存在"个案裁量"式豁免口子，予以标记（书中警告这类口子会被市场工程化规避）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单纯的商业合同对价谈判（一对一、无公共品与担保介入）：普通谈判工具即可，套三检属过度工程。
- 已发作危机的定性（先诊断流动性/偿付能力）与处置排序：属于 crisis-diagnosis-first 与危机管理序列的领地。
- 用户只是抱怨"感觉不公平"而无具体规则文本可检：先请其给出义务分配事实，否则三检无对象。

### 作者在书中警告的失败模式

- 监管被既得利益架空（第7章，"所罗门式决定"）：银行贷款逼近 10% 法定限额时，监管者以"借款实体有独立财源"豁免，银行立即通过分散借款主体绕开限制，限额形同虚设——可被法律技术拆解的规则都会被工程化规避。
- 规则精细到无人可执行（第7章，多色分类系统）：预警规则精细超过一线检查员的分辨能力时，所有人默认放行灰色地带——复杂度反而制造系统性盲区。
- 债权人侧道德风险被无视（第7章，警告者困境与过度放贷）：只盯债务人纪律而放任银行顺周期放贷，利差收窄恰是过度承担风险的证据而非安全证明。

### 作者的盲点 / 时代局限

- 双作者为美日决策精英，债务危机一章有银行家自辩色彩：对债权人侧激励的反省主要转引 IMF 官员（桂田）视角，对发展中国家承受的紧缩代价缺乏内生分析。
- 写于 1991-92，未预见其"对称义务"思路在欧元区（顺差国同样不受约束）将重演第1章教训；未涉及中国等新兴顺差大国的角色。
- 书中"价格稳定→长期繁荣"的单向因果作者自承难以验证，制度设计检验不能替代对其经验基础薄弱的警觉。

### 容易混淆的邻近方法论

- `triffin-dilemma-diagnosis`：结构悖论诊断，不是规则检查表；别用三问去审合同。
- `crisis-management-sequence`：危机中的处置排序与道德风险（逐案处理防道德风险）相关，但那是事后流程，本 skill 是事前设计。
- `unilateral-default-trap`：同属激励问题但视角相反——设计者平衡激励 vs 债务人策略边界。
