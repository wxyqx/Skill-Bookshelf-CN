# 范式失效识别与坚持纪律

## R — 原文 (Reading)

> "其中最重要的是约束我们自己。一旦联邦储备委员会更加注重货币供应量……我们会发现，即使我们的决定导致了令人痛苦的高利率，我们也将很难再有退路。"
>
> — 保罗·沃尔克，第6章

---

## I — 方法论骨架 (Interpretation)

这套方法论处理的是一个特殊时刻：旧工具在框架内已经失灵，但表面上看"再多用一点总该有效"。

1. 先识别"负反馈失效"：你的纠偏工具（加码、施压、收紧）本身也是被通胀式的环境消解的——工具剂量涨得比问题快，且所有同行都在用同一招，说明失效的是范式而非火候。
2. 此时真正的选项有三个，不是两个：加码（无效）、放弃（崩溃）、换操作范式（改变工具作用的结构，而非继续调参数）。
3. 换范式的同时要"预登记最大错误"：事先写下"我现在可能犯的更大错误是什么"，用它作为动摇时的对照基准——通常是"坚持不住、半途而废"，而不是"再苦一阵"。
4. 退出加码必须等硬条件同时成立：目标性指标已受控、且另一端出现体系性告急，而不是增长压力、下属抱怨或政治噪音本身。
5. 对微调保持怀疑：在范式替换期，逐月相机微调只会反复重新制造犹豫信号；表达上要么给数字、要么给日期，千万别两者都给。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1979年10月6日联储操作框架转变
- **问题**: 1979年的美国通胀居高不下，联储旧模式（盯住联邦基金利率+小步微调）持续加码——利率一路上调——却始终"涨不过通胀"，市场只把每次加息读作"联储在通胀曲线后面"的新证据；9月18日贴现率 4:3 的分裂投票更被市场解读为犹豫。
- **方法论的使用**: 沃尔克判定负反馈已经失效：问题不在加息幅度不够，而在操作范式本身不断强化"联储不会动真格"的预期。他选择换框架而非继续加码——把操作目标从货币价格转向银行准备金/货币量，同日贴现率+1个百分点、辅以特别准备金，多项措施互相印证同一信息，并用制度性转变断掉自己的退路。
- **结论**: 换范式、断退路，并预先登记"更大的错误是坚持不住"。
- **结果**: 利率破 20%、两次衰退、失业逾 11%，但通胀预期被扭转，为 80 年代扩张打下价格稳定基础。

### 案例 2: 1982年7月转向宽松的两个硬条件
- **问题**: 紧缩最困难的时刻——失业逾 10%、国会施压、拉美债务压力逼近——每天都有"再不放松经济就完了"的诉求。
- **方法论的使用**: 沃尔克坚持不因增长压力或债务国请求放松，把"可能犯的更大的错误是不能坚持紧缩政策"预登记在案；转向只在两个硬条件同时成立时执行：货币供应量已受控 + 国内金融体系告急（宾州广场银行破产、伊利诺斯大陆银行受创）。
- **结论**: 退出条件是客观状态而非痛苦程度。
- **结果**: 转向后 1983 年经济复苏、通胀未反弹，反通胀战役收官。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 增长/获客/控本等指标持续不达标，团队已多轮加码（预算、人手、频次）且成本增速超过效果增速，用户问"还该不该继续投入"。
2. 组织处在紧缩/转型/攻坚期，每次月度数据一波动就有人提议松一松，用户问"怎么判断是真该停了还是我们坚持不住"。
3. 用户隐约意识到"这套方法本身可能失灵了"，想区分"火候不够"与"范式失效"。
4. 用户已决定换范式，想知道怎么防止自己在半途被逐月数据和内部压力拖回去。

### 语言信号 (用户的话里出现这些就应激活)

- "已经加了三轮预算了，越投越贵还是不行，是不是该放弃了？"
- "每次数据一难看就有人喊松一松，怎么才能不半途而废？"
- "我感觉不是力度不够，是这套打法本身失灵了。"
- "凭什么这回还要坚持？什么时候才能停？"

### 与相邻 skill 的区分

- 与 `commitment-device-design` 的区别：承诺装置回答"如何让一个承诺可信"（断退路、信号打包），是设计动作；本 skill 回答"何时判定旧范式整体失效、换轨后如何坚持"，是诊断与纪律。两者在 1979.10.6 案例上会先后使用，但入口问题不同。
- 与 `crisis-diagnosis-first` 的区别：诊断先行给危机定性（流动性 vs 偿付能力、不能 vs 不愿）；本 skill 给"工具失效"定性（负反馈失效 vs 火候不足），对象是政策/策略框架而非债务危机。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定负反馈是否失效**
   - 完成标准: 列出投入/代价曲线与产出曲线的历史数据点，明确给出"旧框架内加码已边际无效"的证据清单或反证；若加码仍边际有效，判停并回到常规优化建议。
2. **生成第三选项（换范式）**
   - 完成标准: 至少给出 2 个改变操作结构（而非调参数）的备选方案，与"继续加码""骤停放弃"并列成三选项对比表，说明各自代价。
3. **预登记最大错误**
   - 完成标准: 与用户共同写下"当下可能犯的更大错误是什么"的排序，确认后作为后续每次动摇时的对照基准。
4. **设定退出硬条件**
   - 完成标准: 退出条件写成可观测的客观指标组合（目标性指标已受控 + 出现体系性告急类信号），明确排除"增长压力/政治压力本身"；表达纪律为"要么给数字要么给日期，不可两者都给"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 反馈边际仍然有效的一般优化迭代——那是常规管理问题，"换范式"会过度反应。
- 尚未开始实施的方案设计——本 skill 处理"实施后失灵"的判断，不处理"该不该启动"。
- 纯工具/框架选型对比（选哪个项目管理方法）——选型不涉及"旧范式失效"的历史证据。

### 作者在书中警告的失败模式

- **过早放松（第6章，1980）**: 信贷控制导致货币骤降，联储立即大幅放松，三个月内基金利率 20%→8%，经济迅速反弹、通胀预期未被击溃，只能以更深的衰退重新紧缩。教训：以单一统计骤降为放松依据是错误的，骤降可能是措施的机械结果而非趋势。
- **拖延换轨的代价（第13章，1978 干预）**: 关键节点行动太晚，通胀预期已根深蒂固，最终代价远大于早行动。

### 作者的盲点 / 时代局限

- 写于 1991-92：书中未预见"广场协议→日元升值→日本超低利率→资产泡沫"的链条——恰说明"坚持纪律"的时点判断本身可能孕育新失衡；对欧洲货币联盟的乐观亦被其后 ERM 危机部分证伪。
- 全书未涉及中国等新兴经济体的宏观治理经验，"规则优于微调"的断言基于 1992 年前的美欧日证据。
- 双作者均为决策精英，对"坚持的代价由谁承担"（失业者、小企业）着墨极少。

### 容易混淆的邻近方法论

- `commitment-device-design`（设计可信承诺）与 `crisis-diagnosis-first`（危机定性诊断）——见 A2 区分；另与 `strong-commitment-intervention`（强承诺干预）易混：后者是"信心已动摇时如何一揽子扭转预期"，本 skill 是"工具已失效时如何换轨并坚持"。
