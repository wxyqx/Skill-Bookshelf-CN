# "私器公用"两难诊断（特里芬模板）

## R — 原文 (Reading)

> "布雷顿森林体系对美元的依赖性有一种内在的、致命缺陷。……将来的黄金产量不足以满足这种需求，因而在布雷顿森林体系内部加速增长的必要国际清偿手段的来源，将只能是美元。把那些美元放入世界其它国家手中的唯一途径，就是美国的国际收支逆差。"
>
> — 沃尔克 & 行天丰雄，第2章

---

## I — 方法论骨架 (Interpretation)

凡一种主权私器被当作公共品使用——一国货币充当全球储备、一家公司的产品充当行业结算层、一个平台的规则充当市场基础设施——就会出现同一种结构性死结：公共品职责要求私器方持续输出（供给流动性、让利、扩张服务），而持续输出本身又不断消耗私器方自身的信用支撑。

诊断只需三问：第一问，流动性/公共品靠什么输出？（谁在持续供给、以什么为代价）第二问，信心/私器信用靠什么支撑？（凭什么大家继续信它）第三问，前两个答案是否兼容？——若输出越多则信用支撑越薄，两者结构性不兼容。

若三问判定不兼容，结论不是"修补参数"，而是：该结构内置崩溃时间表。出路只有两条——外部替代供给（如 SDR 式的替代资产）或把负担转嫁给担保方，二者都只能延缓而非根除。门外汉会说"印多了就贬值"；本模板的独特处在于"公共品供给义务与私器信用支撑结构性不兼容"的三问结构与崩溃时间表推断。

## A1 — 书中的应用 (Past Application)

### 案例 1: 特里芬诊断布雷顿森林体系（第2章）
- **问题**: 战后贸易持续扩张，世界需要更多国际清偿手段；黄金产量不足，供给只能靠美国逆差输出美元。
- **方法论的使用**: 三问拆解——流动性靠美国逆差输出美元；信心靠"美元和黄金一样好"的兑换承诺支撑；逆差越积累兑换承诺越不可信。输出机制与信心支柱指向同一个变量且方向相反，判定不兼容。
- **结论**: 体系不是"设计得好不好"的问题，而是内置崩溃时间表，只能延缓。
- **结果**: 1968 黄金总库破裂、1971 关闭黄金窗口、1973 普遍浮动，预测如期兑现；SDR 于 1970 年创设即为替代供给方案，但始终未成主要储备资产——特里芬难题实际未被解决。

### 案例 2: C-20 改革与替换账户的两次替代尝试（第4、10章）
- **问题**: 如何以替代供给（SDR 本位、替换账户）根除两难。
- **方法论的使用**: 沃尔克诊断任何替代方案同样要过三问——替代资产的信用靠什么支撑？最终都绕回大国承诺，而调整负担不对称（顺差国无约束）使政治死结无解。
- **结论**: 改良不等于解决；"无体系"是崩溃后唯一现实选择。
- **结果**: C-20 改革失败，替换账户搁置，浮动汇率接盘。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估某私人发行的稳定币/结算资产被行业广泛用作储备与计价单位，问"长期会怎样、会不会暴雷"。
2. 一家公司/基金会为整个生态提供公共基础设施（支付通道、开源核心件、云服务底座），讨论其商业模式与可持续性是否自洽。
3. 讨论一国货币国际化、或某枢纽（城市/港口/中介机构）吃扩张与信用两头失衡的长期前景。
4. 设计或评估替代供给方案（新储备资产、行业共治基金、替代性标准）能否真正根除依赖。

### 语言信号 (用户的话里出现这些就应激活)

- "既要它输出流动性/服务，又要大家信它，这不矛盾吗？"
- "特里芬难题/Triffin"、"私器公用"、"储备货币的死结"
- "这个体系是不是从设计上就注定要崩？能不能靠修补参数救？"

### 与相邻 skill 的区分

- 与 `confidence-fragility-check` 的区别: 那是短期脆弱性管理（信心是唯一可瞬间逆转的快变量，怎么守住）；本 skill 是长期结构诊断（输出义务与信用支撑是否兼容、内置崩溃时间表），不处理当下波动。
- 与 `crisis-diagnosis-first` 的区别: 那是单主体危机的定性诊断（流动性 vs 偿付能力）与处置排序；本 skill 处理的是尚未发作的体系性悖论，产出的是结构判断而非处置序列。
- 与 `multilateral-coordination-assessment` 的区别: 那评估多方协调机制能否运转；本 skill 诊断单一私器承载公共品的内生矛盾，两者常先后使用（先诊断死结，再评估协调能否解）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别私器与公共品**
   - 列出：谁是供给方（私器方）、公共品是什么、受益方是谁。
   - 完成标准: 能用一句话说清"X 的私器被当成了 Y 的公共品"，且供给方与受益方分离。

2. **三问诊断**
   - 问一：流动性/公共品靠什么输出？问二：信心/私器信用靠什么支撑？问三：两个机制是否兼容（输出是否侵蚀支撑）？
   - 完成标准: 每问有具体机制答案；第三问给出明确的"兼容/不兼容"判定及因果链。
   - 判停条件: 若第三问判定兼容（如供给方有独立于输出的信用来源），则停止，改做普通可持续性分析。

3. **推断崩溃时间表**
   - 若不兼容：列出侵蚀速度的观察指标、可能的触发事件（信心 testing 点）、历史上同类结构的崩点形态。
   - 完成标准: 给出"什么信号出现说明时间表在走"的可观察清单，而非只说"迟早崩"。

4. **评估出路**
   - 逐一评估三条路：替代供给（外部资产/共治结构）、转嫁负担（担保方兜底）、参数修补——按模板明确指出参数修补不能根除。
   - 完成标准: 对每条路给出书中式判断（谁买单、政治上是否可行），并说明这是延缓还是根除。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 普通商业两难（增长 vs 利润、扩张 vs 品控）：无"公共品供给义务"这层结构，用常规权衡即可。
- 单主体已发作的危机（还不上钱、挤兑进行中）：先用 crisis-diagnosis-first 做定性诊断，本 skill 的长周期结构判断救不了火。
- 纯技术选型问题（哪个标准更好用）：不涉及信用与供给的冲突时是工程问题，不是特里芬结构。

### 作者在书中警告的失败模式

- 信心支柱的国内纪律崩塌（第2章，越战拒税）：特里芬难题的信心支柱靠核心国支付国内纪律成本，约翰逊拒绝为越战加税一环失守引爆全局——"这不是个能力问题，而是意愿问题"。
- 善意忽略式拖延（第5章）：明知死结存在却放任逆差累积，等待的每一天都在积累需要更大冲击才能扭转的预期。
- 改良幻觉（第2、10章）：SDR 创设、替换账户等"外围修补"从未触及不对称的调整负担，作者明确记录特里芬难题实际未被解决——把改良当解决是最常见的误判。

### 作者的盲点 / 时代局限

- 写于 1991-92 年，对欧洲货币联盟乐观，未预见 ERM 危机与欧元区债务危机同样呈现"私器公用"式死结（成员国财政主权 vs 统一货币）。
- 未预见"广场协议→日元升值→超低利率→日本资产泡沫"的传导链条，即本模板的延缓手段（转嫁/协调）自身可催生新泡沫。
- 未涉及中国等新兴经济体崛起对储备货币格局的改变；分析以美国财政部与联储为中心，发展中国家承受的代价着墨极少。

### 容易混淆的邻近方法论

- `confidence-fragility-check`：同一枚硬币的短期面（快变量管理），别用三问诊断去回答"下周信心会不会崩"。
- `crisis-diagnosis-first`：单主体定性诊断工具，别把体系悖论当流动性问题开药方。
- `incentive-symmetry-check`：规则层面谁被约束的检查表；特里芬诊断在结构层，激励检查在制度层，可组合但不可互替。
