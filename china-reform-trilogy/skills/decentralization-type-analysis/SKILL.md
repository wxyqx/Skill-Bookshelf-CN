# 行政性分权 vs 经济性分权

## R — 原文 (Reading)

> 行政性分权仍是行政协调，经济性分权使企业独立——1958、1970 年两次"体制下放"皆以混乱和再集中告终，"放—乱—收—死"。
>
> — 吴敬琏，《中国改革三部曲》Ⅱ第二章（要点组织）

---

## I — 方法论骨架 (Interpretation)

"放权"不必然是改革——分权的性质比程度更重要：

1. **类型区分**（鲍恩斯坦框架）：行政性分权=中央向地方政府层层放权，微观决策仍在行政系统内（只是换了发号施令者）；经济性分权=把微观决策权还给面向市场的企业，行政机构只管宏观总量并经市场间接调节；
2. **行政性分权的宿命循环**："放—乱—收—死"——放权后地方割据、重复建设、经济混乱→被迫再集中→"一统就死"→再放。1958（88% 中央企业下放、统配物资 530 种减至 132 种）与 1970 年两次循环验证；
3. **病灶机制**：命令经济需要集中才能运转（"命令经济需要秦始皇"）；行政性分权只是把一个集中改成多个集中——地方"诸侯经济"、市场割据（厘金、法国包税制的历史镜像）、"连裆裤"政企关系；
4. **经济性分权的落地三前提**：①建立在统一市场基础上（州际贸易条款式约束）；②财政、金融、外汇三大总量调节权归中央（南斯拉夫教训：谁发货币谁得利）；③财政收入与企业隶属关系脱钩（1994 分税制为此设计：事权划分+增值税分享+国地税分设）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1958/1970 两次下放（Ⅱ第二章）
- **问题**: 向地方放权为什么总以"一放就乱、一收就死"告终？
- **方法论的使用**: 类型判定——两次下放都是行政性分权（企业从中央的婆婆换成地方的婆婆）；混乱源于协调方式未变。
- **结论**: 不改变协调方式的放权必然循环。

### 案例 2: 分税制（Ⅱ第七章）
- **问题**: 1994 年分税制为什么是分权改革的转折？
- **方法论的使用**: 三前提对照——统一市场方向、总量权收归中央、财政收入与隶属脱钩（增值税共享+国地税分设）。
- **结论**: 从行政性分权转向经济性分权框架的关键一步（后遗症：事权财权错配，作者已警示）。

1. **定性分权**：列出权力下放的具体清单，判定是"换婆婆"还是"还给企业"

2. **验三前提**：统一市场、总量权集中、财政与隶属脱钩逐项检查
   - 完成标准: 三前提各有结论

3. **查循环位置**：若在"放-乱-收-死"循环中，定位当前处于哪一环
   - 完成标准: 循环环节判定与下一环预测完成
4. **给方案**：按三前提设计经济性分权的落地清单（分税/事权/隶属脱钩）
   - 完成标准: 方案与三前提一一对应

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 否定一切地方分权——框架反对的是行政性分权；经济性分权下的规范化政府间分权是正解
- 忽视 M 型结构论等反方观点（许成钢-钱颖一、张五常县际竞争）——作者对其否定偏快，使用时保留竞争性分权的正面证据

### 作者在书中警告的失败模式

- "为分权而分权"：收买中间层次的地方利益集团"尾大不掉"
- 南斯拉夫"多中心国家主义"：谁发货币谁得利，破坏统一市场
- 财政大包干：基数谈判、鞭打快牛、地方封锁（1988 年地方新增收入中央仅分得 3.3%）

### 作者的盲点 / 时代局限

- 分税制的后遗症（事权财权错配、土地财政依赖）受写作时点所限未展开——后续诊断须补充
- 对地方竞争正面效应（县际竞争论）的回应不足

### 容易混淆的邻近方法论

- 与财政联邦主义（Oates）：理论给出最优配置原则，本框架给出转轨经济中区分分权性质的诊断工具与失败循环
