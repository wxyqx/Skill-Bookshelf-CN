  type: framework
  source_chapter: 第一章
  source_quote: |
    "全球化分为早期的殖民主义全球化，中期的产业资本全球化，现代的金融资本全球化。资本主义在不同阶段的转变与它内生性矛盾所造成的危机直接相关"。
  summary: |
    判定国际竞争形态的坐标：三阶段各有核心竞争要素——殖民主义阶段（贸易与白银：欧中逆差→白银危机→航海大发现）、产业资本阶段（原材料产地+商品市场："在国化"竞争→两次大战）、金融资本阶段（货币体系+话语权：金融法西斯式剥夺）。分析任何国际冲突先问：竞争处于哪个阶段、争夺的核心要素是什么、冲突的形态（战争/冷战/金融战）由什么决定。
  tags: [core-theory, globalization, history]

- id: f02
  title: 在国化与战争的必然性
  type: framework
  source_chapter: 第一章
  source_quote: |
    "产业资本一定是在国化的，它一定受到这个国家本身幅员的局限……越是小国，越是受幅员局限，生产过剩就越严重"——生产过剩必向外转嫁，海权陆权竞争催生热战。
  summary: |
    战争的政治经济学解释链：产业资本在国化→受幅员局限生产过剩→向外转嫁（夺原料产地与市场）→后起工业国与老牌海权国战略对抗（陆权 vs 海权）→热战。日本案例：岛国无资源，30 年代战争首发于亚洲。推论：低端产业转移使发达国家间生产过剩对抗消失→热战条件消失；竞争转入金融阶段。
  tags: [war, political-economy]

- id: f03
  title: 金融排斥机制（金融法西斯主义）
  type: framework
  source_chapter: 第一章、第四章
  source_quote: |
    "金融不参与任何生产销售流程，不参与任何技术研发过程，却占有大部分生产和技术带来的收益，这是一种超强剥夺"——最终演化出金融法西斯。
  summary: |
    美元循环的剥夺机制：布雷顿森林（黄金 60%、发行 70%）→各国"需要而非强迫"用美元（两个需要：工业化需要产业转移、贸易需要结算体系）→美元锚定石油（军事控制）与粮食（美占 40% 出口）→金融+军工复合体。排斥性：金融不参与生产却占数十倍收益，吸引产业资本虚拟化（荷兰病：一个行业的暴利挤死另一个行业）。识别指标：金融业占比攀升、实体萎缩、QE 流动性进不了实体。
  tags: [dollar, financialization, core-theory]

- id: f04
  title: 产业转移的双向命运
  type: framework
  source_chapter: 第一章
  source_quote: |
    "只有当劳资矛盾有效抑制，劳动密集型产业所产生的收益才能被原转出国的跨国公司所获取"——转出国成债权国，以金融方式占有收益；承接国以债务形式接受并深陷债务危机。
  summary: |
    产业转移不是双赢叙事：①转出逻辑——劳资矛盾最尖锐的劳动密集型产业必须转移到"有控制能力"的承接方（集权国家：拉美军政府、朴正熙韩国）；②承接代价——无对等交换物只能负债接受，连带接受西方制度、教育、文化（软实力入侵）；③转出后果——产业空心化（英国金融化）或装备升级（德国）。中国特殊性：只接受弥补性改造，非照搬。配套姊妹卷 foreign-capital-dependency-risk（承接国的中辍风险面）。
  tags: [industrial-transfer, development]

- id: f05
  title: 货币化主权（货币赋权与政治主权）
  type: framework
  source_chapter: 第二章、第三章
  source_quote: |
    "货币是一张纸，货币的价值来源于'纸信用'……国家主权的独立性，国家权力的强大与否，是决定本币币值的"——苏联解体前 1 卢布兑 3 美元，解体后 1 美元兑 4000 多卢布。
  summary: |
    货币信用的赋权主体是政治主权。苏东教训双面：①非货币化（计划调拨、货币不作交易媒介）使其无法参与金融竞争，币值虽高但投资能力受限，GDP 计量切换后"显得"落后；②政治主权解体→货币失去赋权主体→金融体系同步崩溃。中国对照：92 年放弃票证（货币元年）、渐进货币化、增发货币替代撤离外资——主权完整则货币可自主赋权。评估任何国家货币风险先看政治主权完整性再看经济指标。
  tags: [currency, sovereignty, core-theory]

- id: f06
  title: 危机收割机制（割韭菜与鲸落）
  type: framework
  source_chapter: 第三章
  source_quote: |
    "实体资产货币化加资源性资产货币化，形成巨大的货币化收益，也叫定价收益"——苏东的陨落犹如"鲸落"，使90年代的西方国家陡然进入高增长时期。
  summary: |
    危机收割四步：①资产无定价（非货币化或金融体系崩溃）；②休克疗法强行入市（交易主体无定价经验）；③硬通货低价收购（美元纸币换实体与资源资产；私有化券被买办收购）；④定价收益回流（推高西方资本市场与新经济——IT 技术解密民用+不付研发成本的机会收益+为金融交易提速）。反收割三条件（中国案例）：不开放资本市场、基本品自给、自主货币赋权。
  tags: [crisis, harvesting]

- id: f07
  title: 货币集团竞争
  type: framework
  source_chapter: 第三章
  source_quote: |
    "在金融资本阶段能够与美元竞争的只有欧元"——科索沃战争 80% 军力从美国本土调运，军费由北约盟国支付，德国财政赤字陡然突破5%。
  summary: |
    金融资本阶段的竞争形态：话语权支持制度权、制度权决定获利方式。美元集团 vs 欧元集团：欧元问世（币值高于美元、区内贸易为本）→美国以战争推高欧洲财政赤字（科索沃）、以难民潮冲击欧元信用→顺差国改用欧元结算被政权更迭（伊拉克）。亚元讨论（东北亚美元湖）随南海、钓鱼岛、萨德被打断。分析地区冲突先问：哪家的货币集团利益受威胁。
  tags: [currency-war, geopolitics]

- id: f08
  title: 三驾马车驾辕分析
  type: framework
  source_chapter: 第五章
  source_quote: |
    "经济增长三驾马车，应该是内需驾辕，外需和投资拉套"——80年代内需驾辕（乡镇企业）→90年代外需驾辕（三来一补）→新世纪投资驾辕（国债基建）。
  summary: |
    判断一个经济体增长结构的主从分析：三驾马车不是并列的，必有"驾辕"的主引擎。中国的切换史：80 年代内需驾辕（乡镇企业换汇）→90 年代外需驾辕（外资撤离后靠低端出口）→1998 起投资驾辕（国债基建）。应对生产过剩的基本方法=把外需转化为内需（五通进村是家电下乡的基础），再以投资引导产业升级、收入提升、内需扩大的国内良性循环。
  tags: [demand-structure, macro]

- id: f09
  title: 国家资本与资产货币化
  type: framework
  source_chapter: 第五章
  source_quote: |
    "形成了1300万亿设施性资产，与这些实体资产相比，100万亿的负债规模和300万亿的金融资产就显得不值一提"——中国债务对应可变现实体资产，美国是消费型债务。
  summary: |
    国家资本模式的机制：①财政金融一体（举国体制：1997 剥离不良+注资、香港护盘、光伏维持性贷款+扶贫一举四得）；②国债投资的双重作用（逆周期调节+区域再平衡：西部开发/东北振兴/中部崛起、新农村→乡村振兴）；③资产货币化（以金融杠杆把资源性资产转化为可交易实体资产，债务对应优质资产故不冲击币值）；④生态资本化（绿水青山就是金山银山：人民币改锚国内可控资源型资产，摆脱外汇占款式增发）。对照美国：消费型债务无法变现，由虚向虚。
  tags: [state-capital, monetization]
