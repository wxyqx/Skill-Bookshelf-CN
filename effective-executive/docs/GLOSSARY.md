# GLOSSARY.md — 《卓有成效的管理者》共享术语词典

> 由 `candidates/glossary.md`（28 条，阶段 1.5 全部通过"作者特定用法"校验）提升而来的共享词典，
> 对所有 25 个 skill 生效：任何 SKILL.md 中出现的术语，以此处的"作者本人的用法"为准。
> 本书术语多为"看起来是常用词、作者用法与常识不同"（有效性、贡献、长处、管理者、边界条件……），
> 本词典的价值恰在锁定德鲁克本人的用法，防止 skill 沿用字典义失真。
> 出处按 fulltext.txt 中文部分行号标注；定义尽量用书中原文。
> 标 **▲** 的 8 条（g01、g03、g04、g12、g14、g17、g19、g20）为 verified.md 认定的"最易被常识义污染"的术语，相关 skill 必须先对齐再使用。

| # | 术语 | 作者本人的用法（书内定义） | 与常识的差异 | 关联 skill |
|---|---|---|---|---|
| g01 ▲ | 管理者（executive） | "如果一位知识工作者能够凭借其职位和知识，对该组织负有贡献的责任，因而能实质地影响该组织的经营能力及达成的成果，那么他就是一位管理者"（L291） | ≠有下属的主管（领班/监工"确实是主管人员，但……不是管理者"）；≠高层头衔；判据是"对组织成果的贡献责任" | effectiveness-five-habits、results-outside-the-organization（定义适用对象） |
| g02 | 知识工作者（knowledge worker） | 生产"知识、创意和信息"而非实物；其产品必须被另一位知识工作者当作投入才具有实际意义（L276） | ≠白领泛称；强调其无法被严密督导、必须自我管理，其生产力=有效性 | effectiveness-five-habits、make-output-usable |
| g03 ▲ | 有效性 / 卓有成效（effectiveness） | "做对的事情"的能力；"使能力和知识资源能够产生更多更好成果的一种手段"（L282、L425） | ≠效率、≠聪明/努力/职位、≠"成效不错"的结果形容词；是把资源转化为成果的习惯组合 | effectiveness-five-habits（全部 skill 的背景词） |
| g04 ▲ | 效率 vs 有效性（to do things right / to get the right things done） | "所谓效率，可以说是'把事情做对'的能力，而不是'做对的事情'的能力"（L250） | 效率是体力工作的衡量维度，有效性是知识工作的维度；用效率方法管知识工作等于"精美的蓝图"配错误的产品 | effectiveness-five-habits、results-outside-the-organization |
| g05 | 组织的囚徒 | "如果我们从工作的情形来替管理者下一个定义，我们简直可以说他是组织的囚徒"——时间随时被别人占用（L340） | ≠抱怨修辞；是四类结构性现实之一（时间只属于别人），需系统方法而非意志解决 | know-thy-time、consolidate-free-time |
| g06 | 可自由运用的时间 / 整块时间 | "高级主管真能自由运用的时间，大概只有1/4。……时间分割成许多段，等于没有时间"（L745–L749） | ≠空闲/业余/碎片时间的总和；判定看下限门槛（写报告 6–8 小时、实验 5–12 小时、影响他人 ≥1 小时） | consolidate-free-time、one-thing-at-a-time、know-thy-time |
| g07 | 时间记录（time log） | "必须在处理某一工作的'当时'立即加以记录，而不能事后凭记忆补记……以连续三四个星期为一个时段，一年内记录两三个时段"（L607–L609） | ≠日程表/计划表/待办清单，≠事后回忆日志；是被分析的原始耗用数据 | know-thy-time、time-diagnosis-questions、consolidate-free-time |
| g08 | 例行作业（routine） | "将本来要靠专家才能处理的事，设计成无须研究判断，人人均可处理的作业……是专家们从过去的危机中，学会的一套有系统和有步骤的处理方式"（L672） | ≠日常琐事；是把重复危机制度化的产物，是"管理好"的标志（"管理好的工厂，总是单调无味"） | time-waste-institution-scan、problem-classification |
| g09 | 贡献（contribution） | "对我服务的机构，在绩效和成果上，我能有什么贡献？"他强调的是责任（L782）；三领域：直接成果、价值观、人才（L813） | ≠勤奋/辛苦/职权；是使注意力转向外部成果的自我要求；"重视贡献，就是重视有效性" | contribution-question、three-domains-of-contribution、make-output-usable、manage-your-boss |
| g10 | 成效三领域（直接成果 / 价值观 / 人才） | "如果在成效中缺少这三方面中的任何一个方面，那么机构就会衰败甚至垮台"（L813） | ≠只等于"业绩"；是三条并列、互不替代的存续线（食物＋维生素矿物质＋明天的接班） | three-domains-of-contribution |
| g11 | 旁系人士 | "对管理者的有效性而言，最重要的人物，往往并不是管理者直接控制的下属，而是其他部门的人"（L356） | ≠同事的客套称呼；结构性概念：有效性取决于"你无法指挥的人"是否使用你的产出 | make-output-usable、contribution-question |
| g12 ▲ | 因事用人 / 因人设事 | "职位应该是根据客观需要而设定的，应由任务而定，而不应因人而定"（L1022）；因人设事"必将产生恩怨派系" | 常识常把"因人设事"当灵活用人的美德；德鲁克视之为组织陷阱（仅凯特林/霍普金斯级特例例外） | strengths-based-staffing |
| g13 | 长处（strength） | "才干越高的人，其缺点也往往越多。有高峰必有深谷"（L996）；"只会说某人在完成某项任务方面是个'能人'"（L1126） | ≠优点/优势的泛称；必须绑定具体任务与成果，只能"具体到能不能完成任务"来说 | strengths-based-staffing、use-your-own-strengths、appraisal-four-questions、manage-your-boss |
| g14 ▲ | 要事优先（first things first） | "把重要的事情放在前面先做，而且一次只做好一件事"（L1257）；被归入"领导力"——"人人皆可达成的专心、决心和目标"（L1912） | ≠时间管理技巧；其实现路径是"摆脱昨天 + 优后决策 + 集中"，不是把事情排得更好 | one-thing-at-a-time、priority-and-posterior、abandon-yesterday |
| g15 | 优后（可缓办之事） | "主要困难在于他们确定不了哪些事情可以缓一缓"（L1349）；"所谓'暂行缓办'，实际就是'永远不办'"（L1351） | ≠优先级列表的下半部分；是需勇气并须坚持的独立决定，且被搁置往往等于被取消（有时机代价） | priority-and-posterior |
| g16 | 摆脱昨天 / 推陈出新 | "如果我们还没有进行这项工作，现在我们该不该开始这项工作？"（L1298）；"要'出新'，必从'推陈'着手"（L1326） | ≠定期清理待办；针对"经营管理上的自我主义的资产"（昨天的成功、被神圣化的既有活动），新业务开始前先删一项旧的 | abandon-yesterday、one-thing-at-a-time |
| g17 ▲ | 边界条件（boundary conditions） | "决策的目标是什么？换言之，最低限度应该达成什么目的？应该满足什么条件？"（L1558） | ≠约束条件/预算上限；是判定决策有效与否的检验器，也是判定"何时应该抛弃该决策"的依据 | boundary-conditions、correct-before-compromise、decide-and-act-fully、decision-five-elements |
| g18 | 经常性问题 / 偶发问题（问题四分类） | 四类：真正经常性；特殊情况下的经常性；真正偶发；"经常事件"的首次出现。除第三类外均需"经常性的解决方法"（L1496–L1516） | ≠按大小/急缓分类；按"是否重复出现"分类，且默认假设是"先假定该问题为经常性质"（L1544） | problem-classification、time-waste-institution-scan |
| g19 ▲ | 见解（opinions） | "所谓见解，乃是'尚待证实的假设'"（L1673）；"决策的过程……先从其本人的见解开始" | ≠主观意见（贬义）；是决策的正当起点——"事件本身并非事实"，没有衡量标准就找不到事实 | opinions-first、feedback-and-inspect |
| g20 ▲ | 反面意见（dissent） | "除非有不同的见解，否则就不可能有决策。这是决策的第一条原则"（L1721）；三重功能：防俘虏、提供"另一方案"、激发想象（L1740–L1762） | ≠民主程序/征求意见的姿态；被主动"制造"并当作决策资源；处理纪律是"假定出于至诚、先理解再判是非" | dissent-as-resource、manage-your-boss |
| g21 | 反馈 / 决策前的反馈 / 亲自视察 | "这里的所谓反馈，是决策前的反馈"（L1701）；"最可靠的反馈，却在于亲自视察"（L1642） | ≠执行后的检查/复盘；两层：①决策前反馈检验衡量方法本身；②亲自视察对抗组织过滤的报告与抽象数字 | feedback-and-inspect |
| g22 | 机会 vs 问题 | "有效性的每一面，都是'机会的开发，问题的消失'"（L1236）；"化机会为成果，肯定比解决旧问题更有生产性"（L1377） | ≠乐观态度；是资源配置的方向判据：解决问题只恢复昨天，抓机会才产生明天 | priority-and-posterior、results-outside-the-organization、use-your-own-strengths |
| g23 | 成果在组织之外（内部 vs 外部） | "在组织的内部，不会有成果出现，一切成果都存在于组织之外……在组织内部所发生的，只有人工和成本"（L364–L368）；"真正重要的不是趋势，而是趋势的转变" | ≠走市场/跑客户的口号；是结构定律＋必然倾向（组织越大越高层越被内部吸引），须付出"特殊努力"保持外部接触 | results-outside-the-organization、contribution-question |
| g24 | 有效的个性 | "世上并无所谓的'有效的个性'"（L442）；有效者"共同点：人人都具有做好该做的事情的能力" | ≠领导力特质的集合；被明确否定的虚构物——有效性不带人格门槛，唯一共性是"实践中经历同样的训练" | effectiveness-five-habits |
| g25 | 正直（integrity） | "一个人如果缺乏正直和诚实，则足以败事……有这种缺点的人，没有资格做管理者"（L1118） | ≠道德加分项；是**唯一的资格否决项**：不参与"长处/短处"的换算（不是"限制"而是"资格"） | appraisal-four-questions、strengths-based-staffing |
| g26 | 读者型 / 听者型 | "人大致可以分为两种类型：'读者型'和'听者型'。……面对'读者型'的人侃侃而谈，那是徒费口舌"（L1195） | ≠学习风格标签；是沟通设计的自变量（"如何提出这一建议"、给谁一页纸/全文），"无所谓好，也无所谓坏" | manage-your-boss、use-your-own-strengths、make-output-usable |
| g27 | 疏离感（知识工作者的） | "知识工作者常会厌烦、失意、消沉。……会产生所谓的'疏离感'"（L1940）；只有在成为有效的管理者之后才能获得机会、成就、实现与价值（L1948） | ≠心理问题/情绪管理；是结构性处境（知识权威须服从组织目标），德鲁克把"有效性"提为其唯一可行解法；低引用优先级（第8章社会层面概念） | effectiveness-five-habits（仅作背景） |
| g28 | 通才（与专家） | "所谓'通才'，应该也是一位专家，是一位能将其所专的一个小领域与其他广大知识领域联系的专家"（L890） | ≠样样都懂的人；是能把自己的专精领域与整体需要连接起来、使别人能用其成果的专家 | make-output-usable、effectiveness-five-habits |

## 使用约定

1. **先对齐再使用**：skill 产出文本涉及上表术语时，按本词典的"作者用法"书写；标 ▲ 的 8 条最易被常识义污染，相关 skill 的 I 段与 B 段已内置防误读表述。
2. **易混三组重点区分**：①有效性 vs 效率（g03/g04）；②要事优先 vs 时间管理技巧（g14/g15）；③边界条件 vs 约束条件（g17）。
3. **敏感条目**：g27（疏离感）只作第 8 章世界观背景引用，不构成对当代职场人的心理诊断；g25（正直）的否决权使用时须以具体行为事实为依据（appraisal-four-questions B 段已设防滥用声明）。
4. **不可操作边界**：本词典是理解工具；所有可执行步骤以各 SKILL.md 的 E 段为准。
