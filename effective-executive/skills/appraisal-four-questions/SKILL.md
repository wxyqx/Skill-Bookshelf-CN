# 绩效考评四问（含正直否决项）

## R — 原文 (Reading)

> "今天大多数组织制定的考评办法，其实是脱胎于一般医生对病人的评估。医生的目的在于治病，医生重视的是病人的毛病，而不是病人的优点。……我们所能评估的，只有绩效。我们所应该评估的，也只有绩效。"
>
> — 彼得·德鲁克，第4章·要用人所长（L1086、L1098）

> "（1）哪方面的工作他确实做得很好？（2）因此，哪方面的工作他可能会做得更好？（3）为了充分发挥他的长处，他还应该再学习或获得哪些知识？（4）如果我有个儿子或女儿，我愿意让我的子女在他的指导下工作吗？"
>
> — 彼得·德鲁克，第4章·要用人所长（L1102–1108）

> "正直的品格本身并不一定能成就什么，但是一个人如果缺乏正直和诚实，则足以败事。所以人在这方面的缺点，不能仅视为绩效的限制。有这种缺点的人，没有资格做管理者。"
>
> — 彼得·德鲁克，第4章·要用人所长（L1118）

---

## I — 方法论骨架 (Interpretation)

德鲁克把考评从"找毛病"改成"找长处"，理由是：传统考评照搬医患模型（医生只对病人毛病感兴趣），用在主管与下属之间破坏团结，最终被束之高阁；而"潜能"不可评估，能评估的只有已经发生的绩效。

正确的考评流程分两步准备、四问收口。准备：先列出对某人在其职务上"期望的贡献"，再用实际绩效记录与之对照。注意这里的参照系是"组织希望他做出的具体成绩"，不是通用的能力项。

四问中前三问只谈长处与绩效：他哪方面确实做得好；因此哪方面可能做得更好；为发挥长处还需学什么。缺点只作为"发挥长处与成就有效性的限制"附带记录，不作为主线。

第四问是唯一的资格门槛，也是唯一以品格为主的一问：愿不愿让自己的子女在他的指导下工作。愿意/不愿意都要写出理由——因为下属（尤其年轻有为者）会以上司为楷模塑造自己，缺乏正直与诚实的人"成事不足、败事有余"。

关键换算是非对称的：长处/短处可以权衡、可以容忍，可以靠组织手段让短处不产生作用；正直不行——它不参与换算，是任职资格的一票否决。

## A1 — 书中的应用 (Past Application)

### 案例 1: 日本管理界的对话——"我们没有考评制度"
- **问题**: 德鲁克在日本主持管理发展研讨会，发现日本大企业根本没有考评制度，感到万分奇怪。
- **方法论的使用**: 他问日本高层为什么。对方回答：你们的考评只用来发现一个人的错误和弱点；我们不能因缺点开除或降级人，所以自然对"找毛病"的考评不感兴趣——我们想知道的是他有什么优点、能做些什么。德鲁克由此反推出考评的取向错误，并对照自己观察到的现象：西方的考评表年年归档，真要做人事决策时"谁也不会专门为此去翻阅档案"。
- **结论**: 考评应以长处为重心；德鲁克不完全同意日本终身雇用（认为大多数人都将成为公司的负担），但主张学习其"见人之所长和用人之所长"的精神。
- **结果**: 这段对话成为"考评四问"的由来，四问法被定位为"以当事人的长处为重心，以当事人能做些什么开始"。

### 案例 2: 马歇尔的人事实践——提拔无名将官与不称职即调职
- **问题**: 1930 年代中期美国陆军几乎找不到堪用的年轻将官；同时，对不称职的军官，旧习是"找不到继任人选"就拖着不动。
- **方法论的使用**: 马歇尔以"此人能做什么"为标准，从未经考验的无名军官中提拔艾森豪威尔等人；对不称职者立即调职——"某人不称职只是不称'此'职，选派他到这一职务是我的错误，我应负责再给他找到适合的工作"；为巴顿辩护时也不因"缺少做幕僚的气质"这类短处抹杀长处。
- **结论**: 评价与任用都只问"能做什么"；对不到标准的人，处理的责任在任命者，而不是让其在原位煎熬。
- **结果**: 经他提拔的将领"几乎无人失败，而且他们都是第一流的人才"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 管理者要写年终考评、准备绩效面谈，面对旧表格只会"挑毛病"、面谈开不了口。
2. 纠结对某下属的处置：能力有短板但产出很高，要不要留用、要不要提拔。
3. 要设计或改造公司的考评表、晋升评审标准、高潜人才盘点流程。
4. 被要求"评估某人的发展潜力"，或听到同事说"这人没什么缺点，就是不突出"（求全式评价）。

### 语言信号 (用户的话里出现这些就应激活)

- "年终考评怎么写 / 怎么写绩效评语 / annual review, performance appraisal"
- "他有什么不足 / 怎么谈他的缺点 / areas for improvement, weaknesses"
- "高潜人才盘点 / 他有没有潜力 / high-potential, potential assessment"
- "该不该开掉他 / 要不要留用（提拔）这个人 / should I let him go, should I promote"

### 与相邻 skill 的区分

- 与 `strengths-based-staffing`（f09）的区别：f09 管事前择人——职位设计、因事用人、容忍短处；本 skill 管对在岗者的周期考评与面谈输出，且多一道正直资格判决。用户在做招聘、岗位设计时用 f09。
- 与 `use-your-own-strengths`（f12）的区别：评估对象是别人 → 本 skill；评估对象是自己 → f12。
- 与 `dissent-as-resource`（f23）的区别：在考评结论与晋升讨论中有人提出反对意见时，处理异议用 f23；本 skill 负责产出作为讨论对象的评价本身。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **准备"期望贡献"清单**
   - 列出组织对这个人在其职务上期望的贡献（成果、责任、期限），不是泛泛的职责描述。
   - 完成标准: 书面写出 ≥3 条期望贡献，每条是"成果"而不是"动作"。
2. **对照实际绩效**
   - 把每个期望与已知的实际结果并排放（事实、数字、他人反馈）。
   - 完成标准: 每条期望旁边有具体结果；缺口处注明"无记录"而不是主观印象。
3. **走前三问（只谈长处与绩效）**
   - 逐条回答：哪方面确实做得好 → 因此哪方面可能做得更好 → 为发挥长处还应学什么。
   - 完成标准: 三问各有具体答案；此过程中的缺点仅以"限制"字样附带记录，不进入主线。
4. **走第四问（正直资格）**
   - 问自己："我愿不愿意让自己的子女在他指导下工作？"愿意/不愿意都写出理由。
   - 判停条件: 若答案是否、且理由指向正直与诚实（欺骗、推责、侵害他人）→ 资格否决，不进入"容忍短处/绩效换算"路线；若理由只是脾气、风格、能力 → 回到第 5 步作为发展措施处理。
5. **产出发展行动**
   - 为发挥其长处给出至少一项安排：学什么、给什么机会、谁负责。
   - 完成标准: 有一项具体到时间与形式的行动，并且与第 3 步的答案对应。
6. **复核"不评潜能"纪律**
   - 通读记录，删除/改写所有"他将来可能……""有希望……"式表述。
   - 完成标准: 全部评价文字只含已发生的绩效与事实。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 招聘选拔场景：还没有绩效可评，应按 `strengths-based-staffing` 做职位设计与择人。
- 违纪处分、解雇的法律程序：本 skill 不是合规工具，人事调整须依当地劳动法规与组织程序执行（承接 verified.md 对 ce18/ce19 的强制边界）。
- 强制分布、公开排名场景：四问是主管的私人判断工具，用于面谈与发展；德鲁克明言这套方式"显然与通常的做法不同"，把它改造成打分排序机器就违背了设计意图。

### 作者在书中警告的失败模式

- **用考评找毛病、评估"潜能"（ce17）**：医患模型使缺点成为焦点，主管抗拒面谈考评，制度被束之高阁；用"潜能"评估等于用"有希望"预测未来，无法验证。
- **求全式评价（ce14 的机制）**：以"无重大缺点"为标准必然选出平庸者；在考评语境中的表现就是"他没什么毛病"式结论。
- 配套警戒（ce18"少不了某人"、ce19 留着不称职者）：把"我少不了他"当美德、或为情面拖延不称职者的调整，都会让下属失去发展机会；处置须依合规程序进行。

### 作者的盲点 / 时代局限

- 人事决策类单元须声明其高管视角（BOOK_OVERVIEW 批判节）：全书管理者均为男性、"子女测验"是 1966 年的措辞；案例以美国大企业高管为主，对基层与非营利组织的考评现实着墨少。
- 日本终身雇用案例只作历史语境引用，不作规范主张（日本雇用制度 1990 年代后已大变）。
- "只能评估绩效、潜能不可评估"是作者断言，本书无对照实证；与今日人才测评实践直接冲突，本 skill 采其"以长处为重心"的取向，不替其否定一切潜力评估工具。
- 正直否决不设防滥用机制：德鲁克把它交给主管的良知，实践中可能被用来排除异己；使用时须以具体行为事实为依据。
- 证据等级声明：本书证据以作者顾问观察与轶事为主，无对照实证、无失败者对照（BOOK_OVERVIEW 批判节）。

### 容易混淆的邻近方法论

- "360 度评估""胜任力模型"式做法：它们把"潜能/素质"合法化为评估对象，方向与本 skill 相反。
- 医学式缺陷诊断（PIP 谈话技巧类）：只处理缺点清单，同样不回答"他能做什么、该给什么机会"。
