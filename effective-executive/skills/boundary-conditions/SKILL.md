# 边界条件：决策必须满足的最低规范

## R — 原文 (Reading)

> "决策的第二个要素，在于确实了解决策应遵循的规范。决策的目标是什么？换言之，最低限度应该达成什么目的？应该满足什么条件？用科学的术语来说，这就是所谓“边界条件”。一项有效的决策必须符合边界条件，必须足以达成目的。"
>
> — 彼得·德鲁克，第6章“决策的要素·决策的五个要素”（L1558）

> "社会生活及政治生活中最显著的一项事实是：暂时性的事物往往具有永久性。……他会问自己：“如果这个临时办法被长期执行下去，我会愿意吗？”如果他的回答是否定的，他就会从更基本的、更理性的及更广泛的观念上去另谋解决之道。"
>
> — 同上，第6章（L1550）

> "在各种不同的可能决策中要识别出哪项决策最危险（所谓最危险的决策，就是勉强可行的决策，唯有在一切顺利的情况下，才可能达成的决策），也必须了解边界条件。"
>
> — 同上，第6章（L1582）

## I — 方法论骨架 (Interpretation)

边界条件不是“不能突破的框框”（预算上限、约束清单），而是**这项决策最低必须达成什么才配叫解决**。它有三个用途，缺一个这方法就只用了一半：

1. **定标准**：探求方法是追问“解决这一问题应有什么最低需要”。斯隆 1922 年的反问是范本——“如果解除各独立部门的自主权，能满足本公司的需要吗？”答案“不能”直接改写了问题性质（组织结构问题，而非人事协调问题）。
2. **判生死**：不符合边界条件的方案，不论看起来多漂亮，都是无效决策，不予采纳；还要识别“最危险的决策”——只有一切顺利才可能成立的“勉强可行”方案。
3. **定抛弃时机**：边界条件写清楚，才知道这项决策什么时候该被抛弃。舒利芬计划的教训是边界条件早就不成立、却无人敢弃；罗斯福 1933 年则是边界条件一变就断然换掉整个计划（“复兴”改“改造”）。

配套判据是**临时措施永久化测试**：任何权宜之计出台前，先问“如果这个临时办法被长期执行下去，我会愿意吗？”答“不愿意”就不能靠它拖着，而要从基本原则另谋方案。边界条件往往不易找全，且不同人看到的边界条件不同（《纽约时报》总编辑心中的边界条件是“不得有任何文法错误”，不是当日发行量），所以必须把清单写出来、摆到桌面上对齐。

## A1 — 书中的应用 (Past Application)

### 案例 1: 斯隆与通用汽车分权制度（边界条件改写了问题性质）
- **问题**: 1922 年通用汽车由几家企业合并而成，各部门主管像独立部落的酋长，不听“王命”，公司濒于关门。当时人人都认为这是人事问题，只能靠权力斗争出一个胜利者。
- **方法论的使用**: 斯隆检讨边界条件——“如果解除各独立部门的自主权，能满足本公司的需要吗？”答案是不能：各经营部门必须具备经营能力并负起经营责任，同时还需要一个统一的中央管制。
- **结论**: 依据边界条件的了解，问题是公司**组织结构**的问题，不是人事协调的问题。
- **结果**: 斯隆据此构想出分权制度（既保证分公司经营自主权，又体现总公司方向与政策指导），成为大企业组织典范。反证法：通用唯一没有采用分权制度的领域（对美国政治与政府政策的预测）恰是其最差劲的一步。

### 案例 2: 舒利芬计划（边界条件变了却无人敢弃）
- **问题**: 一战德军两线作战计划：先以小部兵力牵制俄军、全力闪电击败法军、再回师对俄。1914 年 8 月俄军侵入德境速度过快，东普鲁士告急，原计划的边界条件（东线只需牵制）已不成立。
- **方法论的使用**: 按理应完全抛弃该计划或立即以新计划取代（罗斯福式的反应），但继任将领只擅长作战而拙于决策，固守原计划细节。
- **结论**: 他们竟抛弃了计划中最基本的原则——“德国的军力应集中而不应分散”，遂使原定目标不可能达成。
- **结果**: 西线兵力被调走、胜利无法贯彻，东线兵力不足以对抗俄军，落入计划本欲竭力避免的“僵持战局”，从此德军作战完全走样。

### 案例 3: 罗斯福 1933（边界条件一变就换掉整个计划）
- **问题**: 罗斯福竞选时以“经济复兴”为纲，计划建立在财政保守与预算平衡之上；就任前四个月，美国经济几乎整个要垮了。
- **方法论的使用**: 他看清边界条件已变——原经济目标在政治上难以搞下去，于是立即另提政治目标，以“改造”取代“复兴”，政策由保守转为革新。
- **结论**: 不是修补原计划，而是断然放弃原定计划，以保证施政有效。
- **结果**: 德鲁克评：“边界条件变了，罗斯福总统真是反应敏锐，不愧是一位伟大的决策者。”

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 立项、评审或写决策文件时需要界定“最低必须达成什么”，各方对“这方案行不行”的标准不统一。
2. 老板或团队提出“先上线再迭代”“先临时顶一下”的权宜方案，需要判断能否接受、以后会不会永久化。
3. 决策执行了一段时间，想判断“当初的决策什么时候该抛弃/重做”。
4. 跨部门对同一件事的底线理解不同，方案反复推倒（各人看到的边界条件不同）。
5. 面对一个“看起来都能成、但细看每项条件都有冲突”的方案，需要识别它是不是“勉强可行”的危险决策。

### 语言信号 (用户的话里出现这些就应激活)

- “这项决策的最低要求是什么？”“做到什么程度才算数？”
- “先临时这样，以后再改。”“这方案能满足要求吗？”
- “当初的前提是不是已经变了？这个决策还作数吗？”
- “boundary conditions” / “minimum must-haves” / “will this plan qualify” / “when should we drop this decision”

### 与相邻 skill 的区分

- 与 `decision-five-elements` 的区别: 后者是把五要素（问题性质/边界条件/正确方案/行动/反馈）走一遍的全程审计；本 skill 只深挖要素二，并把“何时抛弃”做成可写进决策档案的动作。
- 与 `problem-classification` 的区别: 先辨问题性质（经常还是偶发）才谈得上边界条件——性质判错，边界条件一定写不准；前者负责分类，本 skill 负责定规范。
- 与 `correct-before-compromise` 的区别: 边界条件是辨别两类折中的**标尺**；本 skill 负责把标尺造出来，后者负责拿标尺去谈判。
- 与 `decide-and-act-fully` 的区别: 后者判定“要不要做这项决策”“做就要做全”；“只做一半”之所以是错，判据正来自本 skill——半截行动不符合边界条件。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出决策目的与“最低需要”**
   - 完成标准: 把决策要解决的问题写成一句可检验的目标句；追问“解决它应有什么最低需要”，得到 2–5 条候选边界条件，每条都能回答“缺少它，决策还算不算达成目的”。
   - 判停条件: 若连“最低需要”都写不出，说明问题性质尚未辨明，退回 `problem-classification` / `decision-five-elements` 重做要素一。

2. **逐条做必要性检验并查冲突**
   - 完成标准: 对每条问“去掉它，目的还能达成吗”——能去掉的不是边界条件、只是愿望，予以剔除；清单压缩到“缺一不可”的最小集，并显式记录互相冲突的规范（冲突意味着“勉强可行”，必须重设方案或承认很可能失败）。

3. **对临时措施做永久化测试**
   - 完成标准: 方案中每个“先临时”项都有一句判语：如果它长期执行下去，我是否愿意？答否的项改为从基本原则另谋方案；保留的临时项写明到期复审条件。

4. **做“一切顺利才行吗”测试**
   - 完成标准: 逐条检查方案是否只在所有条件都如愿时才成立；给出“最危险成分”判断——若成功需寄望奇迹，方案退回重设，不予采纳。

5. **写下抛弃触发器**
   - 完成标准: 决策记录中有一行“抛弃条件”：当哪条（或哪几条）边界条件不再成立时，该决策应被抛弃或重做。
   - 判停条件: 若边界条件**此刻已经变了**（罗斯福 1933 的情形），直接进入重做决策，不要修补原计划。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 还没确定“要不要做这项决策”：先用 `decide-and-act-fully` 过门槛；边界条件是为已决心要做的决策服务的。
- 日常琐碎、可逆、后果极小的选择：为它写边界条件是过度工程（“行政长官不宜考虑鸡毛蒜皮之类的事情”）。
- 紧急止损现场：先执行预案，边界条件与抛弃条件事后补写。
- 把边界条件当“约束条件/预算上限”使用：那是误读。德鲁克的用法是“决策必须满足的最低规范”，用来判定决策有效与否、何时该弃，不是“在框框内尽量做”。

### 作者在书中警告的失败模式

- **临时措施永久化**（ce27）：以“先临时顶一下”创设的措施、机构、制度，几十年后依然存在并变成不可触碰的既得利益（英国旅馆登记制、法国房租管制、美国“临时建筑”）。没有到期复审机制，只有创设动力没有退出机制。
- **勉强可行的决策**：各项边界条件互相冲突、唯有在一切顺利时才可能达成；“若成功需寄望于奇迹，则问题不是奇迹出现的机会太小，而是我们不能依赖奇迹”（L1582）。
- **边界条件含糊不清**：舒利芬的继任者守着一份边界条件已失效的计划走向灾难；德鲁克给出的对照是罗斯福 1933——边界条件变了就换掉整个计划（L1572–1580）。

### 作者的盲点 / 时代局限

- **边界条件是“充满风险的判断”，但书里没给裁决程序**：德鲁克自己承认“要确定边界条件和提出规范，光靠‘事实’是不够的……这是一种充满风险的判断”（L1584）；当各方看到的边界条件不同且规范冲突时，除了“别依赖奇迹”之外没有可操作的裁决方法——实际使用中需要自行补充对齐机制（书面清单、责任人裁定）。
- **公共组织的边界条件尤其难定**：书中把英国国营航空公司“三种直接成果混淆”当作管理糊涂，但公共组织往往存在政治性的目标冲突（谁的价值观、为谁服务），这不是把边界条件写清楚就能消解的（BOOK_OVERVIEW 立场盲点）。
- **案例集中于 1900–1960 年代的美欧大企业与军事**：舒利芬计划、《纽约时报》分节、罗斯福新政的语境与当代商业环境差异大，判据可迁移，案例细节只作类比素材。
- **证据声明**：本书证据以作者 45 年顾问观察与轶事为主（《纽约时报》分节故事他本人“就不大相信”），无对照实证；本方法应按“经验判据”而非“科学结论”使用（BOOK_OVERVIEW 批判节）。

### 容易混淆的邻近方法论

- 与“约束理论/范围管理”的区别: 后者管“不能超出的限制”；本 skill 管“必须达到的最低规范”。
- 与“风险清单/敏感度分析”的区别: 后者评估变量波动的影响；本 skill 先把“有效性门槛”定下来，再谈风险。
- 与 `decision-five-elements` 的边界条件条目重合是刻意的：本 skill 是其展开版，完整流程请走后者。
