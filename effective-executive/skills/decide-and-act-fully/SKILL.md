# 是否需要决策与做全：不做也是决策，做就做全

## R — 原文 (Reading)

> "最后，有效的管理者还得再问一个问题：“我们是不是真需要一项决策？”为什么要问这个问题呢？是因为有时候不做任何新决策，可能正是最好的决策。"
>
> — 彼得·德鲁克，第7章“有效的决策”（L1786）

> "·如果利益远大于成本及风险，就该行动。……·行动或不行动；切忌只做一半或折中。……只采取一半行动才是不折不扣的错误，是一项绝对不符合最起码的要求，和不符合边界条件的错误。"
>
> — 同上，第7章（L1804–1808）

> "到了这一步，有效的管理者绝不会说：“让我们再研究研究！”那只证明这位管理者缺乏胆识。……卓有成效的管理者会问：“是不是再做一次研究就能讨论出新方案来？即使研究出新的方案，它是不是一定比现有的方案好？”"
>
> — 同上，第7章（L1814）

---

## I — 方法论骨架 (Interpretation)

德鲁克在决策的两端各补了一个常被忽视的环节：

**前端——判定“是否需要决策”。** 做决策像动外科手术：任何新决策都不免影响既有制度、多少得冒风险，不到非动不可的时候不轻言开刀。判定方法是问一句“**保持现状，会有什么后果？**”——若答案是“不会有变化”，就不必横生枝节；即使问题恼人但不重要，也没有改变的必要。需要决策只有两种时机：继续墨守成规情况就会恶化；或出现至关重要、稍纵即逝的新机会。反面是小动作大做——财务主管为控制成本向两三位临退休老职员开刀，细节用力而成果微不足道，还落下“公报私仇”的名声（罗马律法：“行政长官不宜考虑鸡毛蒜皮之类的事情”）。

**后端——做就做全。** 到了“一切条件具备、只等决策”的一步，剩下的不是分析而是勇气。两条收尾原则：利益远大于成本及风险，就该行动；行动或不行动，切忌只做一半——切除阑尾只切一半同样是冒险，半截决策“绝对不符合最起码的要求，也不符合边界条件”。同时给“再研究研究”设判据：再做一次研究能否产出新方案？新方案是否一定更好？否定则不再研究。但勇气不是说完全不要犹豫——德鲁克保留“守护神”式的略事犹豫（“我通常总得停下来，多想一下”），并明确其量级：一两天，最多一两个星期。

## A1 — 书中的应用 (Past Application)

### 案例 1: 费尔认定必须做“根本的决策”（是否需要决策的正例）
- **问题**: 费尔任贝尔公司总裁期间，许多人都看到该公司有被政府接管的可能，大家都在力图挽救——但挽救方法只是就事论事：反对这项或那项政府法案，反对这位议员、拉拢那位议员。
- **方法论的使用**: 只有费尔了解这类办法肯定仍不能挽救公司的颓败——“即使是打赢了每一仗，也不能打赢整个战争”；他认定必须采取根本的办法来创造新局面，看清了应建立“公众管制”才是有效对策。
- **结论**: 现状不会自行好转（继续墨守成规将恶化），因此需要一项新决策，而且必须是根本性的决策、不是修补。
- **结果**: 他做出“把实现公众管制作为贝尔公司目标”的大决策，成为贝尔四项战略决策之一。

### 案例 2: 财务主管削减成本（不需要决策 / 小题大做的反例）
- **问题**: 一位财务主管感到财务危机重重，大声疾呼要求降低成本，连细枝末节也不放过；他发现最难控制成本的地方在推销与运输部门，又发现某部门“多”用了两三位临近退休的老职员，于是不顾别人印象大声叫嚷裁员。
- **方法论的使用**: 德鲁克用它说明两点——“从小处来降低成本，即使有成果，其成果也微不足道”；且此事本属不必做的决策（不做也不会有严重后果），决策规模与后果严重不对称。
- **结论**: “行政长官不宜考虑鸡毛蒜皮之类的事情”；只做一半的行动与小题大做都是错误。
- **结果**: 成本问题依旧，主管声誉受损——“公司同仁谁也不记得他当初挽救了公司，大家只记得他公报私仇”。

### 案例 3: 割盲肠与“守护神”（做就做全 + 勇气的量级）
- **问题**: 决策到最后一步，往往让人“恍然大悟”：原来决策那么难受、那么不受欢迎、那么不容易——于是有人要求“再研究研究”。
- **方法论的使用**: 德鲁克以手术设喻——切除扁桃体或阑尾固然是冒险，但只切除一半同样是一大冒险，手术不成功不但治不了病，反而引起更严重后果；所以“开刀或不开刀，不能只开一半”。对“再研究”的呼声，他给出两问（能否出新方案、新方案是否一定更好）与苏格拉底“守护神”式的略事犹豫（一两天，最多一两个星期）。
- **结论**: 决策的最后一步需要勇气；没有胆识的人可能失败一千次，有胆识的人则只失败一次。
- **结果**: 成为“行动或不行动、绝不只做一半”的标准解说与拍板时限判据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 摆出一堆流程小毛病/小改进点，问“要不要启动一次大改造”，需要先过“是否值得决策”的门槛。
2. 条件、方案、得失都已清楚，但用户或团队“就是下不了决心”，反复要求再研究。
3. 有人提出“先做一半试试”“折中一下稳妥”，需要判断这算不算半截决策。
4. 领导把资源投在鸡毛蒜皮的小事上大动干戈，用户想给出说理依据（罗马律法判据）。
5. 面对“至关重要、稍纵即逝”的新机会，需要判断该不该立刻做新决策。

### 语言信号 (用户的话里出现这些就应激活)

- “要不要启动这次大改造？”“这件事值不值得动一次决策？”
- “再研究研究吧。”“条件都够了，我还是不敢拍。”
- “先做一半试试，稳一点。”“折中一下总没坏处吧？”
- “do we really need a decision” / “let's study it more” / “just do half and see” / “go big or not at all”

### 与相邻 skill 的区分

- 与 `decision-to-action` 的区别: 本 skill 管决策的两端（要不要做、做就做全）；后者管中间——已定决策的行动承诺四问与激励同步。
- 与 `boundary-conditions` 的区别: 后者定义“必须达成什么”（半截行动之所以错的判据来源）；本 skill 用该判据收尾并处理勇气与拖延。
- 与 `dissent-as-resource` 的区别: 本 skill 在异议穷尽之后接棒（“到这里只剩拍板”）；后者负责在决策前制造并消化异议。
- 与 `priority-and-posterior` 的区别: 后者处理多个事项之间的取舍与“不做什么”；本 skill 处理单个决策的启动门槛与收尾完整性。
- 与 `one-thing-at-a-time` 的区别: 后者管注意力的集中（一次只做一件事）；本 skill 管一项决策自身是否完整（做全或不做）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **过“是否需要决策”门槛**
   - 完成标准: 对每个候选议题问“保持现状，会有什么后果？”——答“不会有变化/后果很小”者，明确建议不做（不做也是决策），并说明理由。
   - 判停条件: 若出现两种需要决策的时机之一（继续守成将恶化；有至关重要、稍纵即逝的机会），进入步骤 2；其余一律停在“不做”。

2. **滤掉鸡毛蒜皮与小动作大做**
   - 完成标准: 对拟启动的决策做规模—后果比对，剔除投入与后果严重不对称的项（财务主管式反例）；保留者必须能说出其“根本性”。
   - 判停条件: 若议题只剩小事，回到步骤 1 收尾为“不决策”，不为其制造决策工程。

3. **按两项原则做收尾判断**
   - 完成标准: 对确定要做的决策给出明确判断——利益是否远大于成本及风险；若不满足，明确不做而非降规模硬做。
   - 完成标准附加: 检查方案是否意图“只做一半”（把关键部分留待以后），如有则改为做全，或退回不做。

4. **给“再研究研究”设上限与判据**
   - 完成标准: 用两问检验每一次“再研究”要求——能否产出新方案？新方案是否一定更好？否定则该要求不成立；为决策设定拍板时限（参考“守护神”量级：一两天，最多一两个星期）。
   - 判停条件: 若确实存在未了解清楚之处（非情绪性犹豫），允许“略事犹豫”，但必须在时限内带新判据回来；否则按现有最优方案拍板。

5. **拍板并确认不是半截行动**
   - 完成标准: 明确宣布行动或不行动；行动方案在关键部分上没有缺口（对照边界条件逐条检查），并移交 `decision-to-action` 补行动承诺与激励同步。
   - 判停条件: 若方案在关键部分仍需悬置（因能力、资源或时机），视为“只做一半”，须重设为完整方案或明确不做。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 拿“不做也是决策”当拖延或卸责的挡箭牌：德鲁克的判据是“保持现状会有什么后果”，不是“我懒得动”；若后果是情况恶化，不做就是错。
- 危机现场：先止损，两端判据事后补做。
- 已定决策的行动设计与落地：改用 `decision-to-action`；本 skill 不负责四问与激励同步。
- 缺少决策权限的场合：本 skill 假定使用者能拍板；若无权限，其可执行部分是把两端判据写成建议提交决策者。

### 作者在书中警告的失败模式

- **“再研究研究”：以拖延代替决策**（ce34）：一切条件具备后仍不断要求再研究，实质是逃避拍板；拖延把成本转嫁给组织（时间、时机、下属信心），且往往并无新信息增量；反面判据就是德鲁克的两问。
- **只做一半 / 小题大做**（ce35）：以“半截行动”装作稳妥（割盲肠只切一半）；或在鸡毛蒜皮上大动干戈（财务主管向临退休老职员开刀），既无效又摧毁组织的公正感。
- **不做无足轻重的决策**（p32 的展开）：不做决策也是一种决策；避免“为决策而决策”与小题大做——“行政长官不宜考虑鸡毛蒜皮之类的事情”。

### 作者的盲点 / 时代局限

- **“是否需要决策”的判定依赖对未来后果的估计**：德鲁克的判据（保持现状会有什么后果）本身建立在判断之上，书中没有给“后果严重性”的衡量方法；在高度不确定环境中，该门槛可能两端都判错——过松会小题大做，过紧会错失时机。
- **勇气个人化的后果未讨论**：把最后一步归为勇气（“没有胆识的人可能失败一千次”）在实践上容易滑向对人品的评判，无助于诊断真实的阻碍（信息不足、授权不清、政治风险）；书中以“守护神”兜底，落到执行层太薄（BOOK_OVERVIEW 最强反对意见 4 的同一逻辑）。
- **高管视角**：费尔、罗斯福式拍板都以最高决策权为前提；对无拍板权者，本 skill 的“做全”可能表现为以卵击石，需要先解决授权问题。
- **案例与证据**：案例集中于 1900–1960 年代美国企业（贝尔、通用）与 2000 年前的罗马律法引语；证据以顾问观察与轶事为主，无对照实证（BOOK_OVERVIEW 批判节）。

### 容易混淆的邻近方法论

- 与“机会成本/净现值门槛”的区别: 财务门槛算的是同一决策的收益与成本；本 skill 前问“要不要做决策”、后问“做是否做全”，是两个非财务判据。
- 与“MVP/先做一半试试”的区别: 适度的最小可行方案是设计完整的实验；本 skill 反对的是把关键部分故意悬置的“半截决策”，二者可区分——实验边界完整即是做全。
- 与 `decision-to-action` 的区别: 见上，两端 vs 中间。
