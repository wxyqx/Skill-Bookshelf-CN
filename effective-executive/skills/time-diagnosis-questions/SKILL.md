# 时间诊断三问（取消 / 授权 / 问下属）

## R — 原文 (Reading)

> "将时间记录拿出来，逐项逐项地问：'这件事如果不做，会有什么后果？'如果认为'不会有任何影响'，那么这件事便该立刻取消。"
>
> — 第2章，L613

> "第二个该问的问题是：'时间记录上的哪些活动可以由别人代为参加而又不影响效果？'"
>
> — 第2章，L619

> "有效的管理者懂得有系统及诚恳地问他的下属：'请你想想看，我常做哪些浪费你的时间而又不产生效果的事情？'问这样的问题，而且问得对方敢说真心话，才是有效管理者的特色。"
>
> — 第2章，L635

---

## I — 方法论骨架 (Interpretation)

时间记录只是原料，真正的管理动作是把记录拿出来逐项过三问。三问各管一个方向，不能互相替代：

第一问是**取消**：拿每一件事问"如果不做，会有什么后果？"——答案是"不会有任何影响"就立刻删。它针对的是讲演、宴会、委员、列席指导一类"难以割舍"的活动；判据是后果，不是兴趣、体面或人情。常见的是：主人只是礼貌，真希望回执上写"敬谢"。

第二问是**授权**：哪些活动可以由别人代为参加而不影响效果？这里要先纠正"授权"的词义——它不是"把我的工作推给别人"（那既不道德也不成立），也不是"越闲的经理越好"，而是把**可由别人做的事**交出去，好腾出手做真正非自己不可的事。旅行、参加会议、写新闻稿都在可交之列。

第三问是**修己**：我是否在浪费别人的时间？这一问不靠自查，靠直接问下属（或合作者、服务对象）——"我常做哪些浪费你的时间而又不产生效果的事情？"难点不在于问，而在于问得对方敢说真话。

三问之后还有一个总判断：大胆删减的风险被严重高估了——"一位管理者大刀阔斧减少不必要的工作，绝不会有太大的风险"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 天天有应酬的总经理——1/3 不必参加、1/3 可由高管代去

- **问题**: 一家大公司的总经理两年间除两个节日外每晚都有应酬（送退休员工、宴请政府官员）；他自己知道这些饭局对发展无益，本人也无兴趣，但觉得非参加不可。
- **方法论的使用**: 用第一问检讨"不参加会有什么后果"，第二问检讨"能否由别人代去"。
- **结论**: 至少 1/3 的宴请根本不必参加；另有 1/3 只要有公司高管到场即可。他还发现主人往往并不真心希望他出席，只是礼貌性发帖。
- **结果**: 砍掉三分之一、转出三分之一；"主人倒真希望他在请帖回执上写个'敬谢'"。

### 案例 2: 财务经理的会议改革——12 人一下午变成 4 人一小时

- **问题**: 某大企业财务经理深感会议浪费时间：不管讨论什么，他都要通知财务部全体主管出席，人人为了表示关切都要发言，会议越拖越长；他又担心少请人会让未被邀请者觉得被忽视。
- **方法论的使用**: 他诚恳地问了下属（第三问），发现大家都认为会议太浪费时间。随后改用会前分发通知：指定 4 人讨论 + 欢迎需要了解者自愿出席 + 会后立即送纪要供不便出席者提供意见。
- **结论**: "少请人"与"不被忽视"可以两全——关键是把信息通道补上。
- **结果**: 过去 12 人耗整个下午的会议，现在 4 人一小时结束，"并且没有一个人有被忽视的感觉"。

### 案例 3: 霍普金斯——被迫删到只剩重要工作，有效性丝毫无损

- **问题**: 罗斯福总统的机要顾问霍普金斯二战期间体衰力竭，每隔一天才能办公几个小时。
- **方法论的使用**: 他不能不把一切事务都撇开，只处理真正重要的工作——等于执行了最极端的"取消"。
- **结论**: 大幅删减非生产性工作并不会损害有效性；对"删减会不会出问题"的顾虑是多余的。
- **结果**: 丘吉尔赞其为"盖世奇才"，他完成的任务"当年美国政府无人能出其右"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户被拉进一堆会/群/委员会/应酬，要逐项决定退出哪些、保留哪些。
2. 用户想交出部分职责，但分不清"授权"与"推卸"，担心交出去出事。
3. 用户怀疑自己开的会、发的通知、要求的汇报在批量占用别人的时间。
4. 用户已经做完时间记录，手上的活动清单需要逐个裁决。

### 语言信号 (用户的话里出现这些就应激活)

- "这件事该不该继续做 / 我该退出哪个会"/"should I drop this committee"
- "如果我不去会怎么样"/"what happens if I just don't do it"
- "怎么授权才不是甩锅"/"how to delegate properly"
- "我是不是在浪费团队的时间"/"am I wasting my team's time"
- "我都难以割舍，但又觉得没意义"（应酬/讲演式两难）

### 与相邻 skill 的区分

- 与 `know-thy-time` 的区别: 本 skill 的前提是记录已经到手；若用户还没有样本，先让它去采集。
- 与 `time-waste-institution-scan` 的区别: 本 skill 处理"个人选择做不做这件事"；重复危机、会议占 1/4、人员过多这类**制度病灶**由它处理。
- 与 `consolidate-free-time` 的区别: 本 skill 负责把活动删掉/转出；删完剩下的时间怎么并成整块并防守，是那个 skill。
- 与 `manage-your-boss` 的区别: 若"该不该参加"的答案取决于上司的接受方式，则属沟通设计问题，不属本三问。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **备料：把活动清单摆出来**
   - 完成标准: 有可逐项操作的清单（来自时间记录最佳；至少包含活动、频次、时长、是否必须本人）。
   - 判停条件: 若清单只是凭记忆，先回到 `know-thy-time`，不要基于印象裁决。

2. **第一问：后果测试（取消）**
   - 动作: 逐项问"如果不做，会有什么后果？"，写下后果的具体内容（对组织、对我、对对方）；答案是"不会有任何影响"就列入取消清单。
   - 完成标准: 每一项都有明确后果判断；取消清单有依据而不是好恶。
   - 判停条件: 若"不做后果严重但本人不必到场"，不走取消，进入第 3 步。

3. **第二问：可代做测试（授权）**
   - 动作: 对保留项问"能否由别人代为参加/处理而不影响效果？"；同时检查授权语义——交出去的是"可由别人做的事"，不是"我的工作"，也不是以"闲"为目标。
   - 完成标准: 每一项要么给出可代做的人与交接方式，要么有"非我不可"的理由。

4. **第三问：问相关人（修己）**
   - 动作: 向直接下属/合作者诚恳提问"我常做哪些浪费你的时间而又不产生效果的事情？"，并创造敢说真话的条件（先说明意图、承诺不追责、事后有可见的改动）。
   - 完成标准: 收回至少若干条具体反馈，并逐条给出"改/不改（理由）"的回应；至少落实一处可核查的改动。

5. **落地与风险复核**
   - 动作: 把取消与转交写进行程/制度（如取消通知、指定代理人），并复核删减风险——按书中判断，大胆删减的风险远低于直觉。
   - 完成标准: 有书面或日历层面的落实，且设一个 1–3 个月后的复看点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要在权力不对等的组织里用第一问随手取消合规、安全、法定义务类事项——这三问的前提是"对成果无影响的非生产性活动"，不是"不想做的事"。
- 用户需要的是"怎么执行拒绝"（写信、话术）而不是"要不要拒绝"——先判据后执行。
- 用户还没有任何时间记录（凭印象裁决会系统性地漏掉真正的浪费）。

### 作者在书中警告的失败模式

- **对无贡献的邀请不敢谢绝**（ce04）: 把"被邀请"当地位象征全部接受；总有一种倾向高估自己的重要性，认为许多事非躬亲不可。
- **误解授权**（ce05）: 把授权当甩包袱（"我的工作让别人做"），或以"最闲的经理最好"为目标，两头落空。
- **在浪费别人的时间而不自知**（ce06）: 只审计自己的时间，不审计自己对他人时间的消耗；会议人数只增不减、怕漏请人被觉得忽视。

### 作者的盲点 / 时代局限

- **有下属可问的假设**: 第三问默认管理者有下属可问（1966 年语境）。无下属者应把提问对象改为合作方、服务对象或上游——但书中未给这种转写的操作细则，须自行谨慎处理。
- **"问得对方敢说真心话"并非总能成立**: 在缺乏心理安全、考核压力大的组织里，第三问可能只得到客气话；德鲁克未讨论权力不对等对答案可靠性的影响。
- **无时间自主权岗位的替代动作（强制声明）**: 对时间被制度性占满的岗位，三问的可操作部分只有"识别并削减非生产性叠加项"（如重复汇报、格式性会议），不能把法定/必需工作当"浪费"删掉。
- **时代语境案例**: 应酬、宴会、委员会等 1960 年代高管生活形态今已变形；性别角色化石（秘书、宴会女主人式场景）使部分例子只能作历史语境引用。
- **证据等级**: 全部为顾问观察与轶事（如总经理、财务经理案例），无对照实证。

### 容易混淆的邻近方法论

- 通用"学会说不"/边界管理: 只教拒绝姿态；本三问给出的是逐项判据（后果、可代做、他人视角），且强调删减风险极低。
- 会议管理技巧（议程、时长控制）: 关注如何把会开好；本 skill 关注"这个活动是否该存在"。
- 精力管理/深度工作类方法: 讨论注意力与生物节律，不处理"哪项活动在消耗时间而不产生成果"。

## 相关 skills

**depends-on**（使用前提）:

- `know-thy-time` — 三问的操作对象来自它的时间记录；还没有记录先回它采集，不要凭印象裁决。

**contrasts-with**（同境况二选一）:

- `time-waste-institution-scan` — 同样是"时间被浪费"，若来源是个人选择（这件活动该不该继续）用本 skill 三问；若是制度病灶（重复危机、会议占 1/4、人员 1/10）转那边修制度。

**composes-with**（配合使用/先后接力）:

- `consolidate-free-time` — 删掉/转出活动之后，由它把剩下的自由时间并成整块并持续防守。
