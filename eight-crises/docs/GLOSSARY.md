# GLOSSARY — 《八次危机》共享术语词典

> 温铁军的特定用法。这些术语与书架既有词典（黄奇帆两卷）语义体系不同，跨书引用时注意区分。

| 术语 | 作者的用法 | ≠ 常识/字典义 |
|---|---|---|
| **成本转嫁论** | 危机代价沿权力与制度通道向弱势端转移（对外向殖民地/发展中国家，对内向三农）；核心问句"代价谁承担" | 不是阴谋论，是制度通道分析；与"增长多少"并列为双账本 |
| **软着陆/硬着陆** | 判据是代价能否向三农转嫁：能转嫁=软着陆（体制维持），不能=硬着陆（制度变革） | ≠ 宏观调控的 CPI/GDP 平滑度；"软着陆"可能代价更大 |
| **发展陷阱** | 后发国家复制宗主国模式→亲外资制度干犯主权→外资中辍→危机转嫁无门→灾难 | ≠ 贫困陷阱/中等收入陷阱；要件是外资依赖+无转嫁渠道 |
| **去依附** | 外资中辍后摆脱对宗主国资本、技术、制度体系依附的能力（L 替代 K） | ≠ 闭关自守；是依附中断时的生存延续能力 |
| **政府公司主义** | 土地、劳力、资金三要素政府所有制＋政府直接从事资本积累 | ≠ 国企；特指政府作为积累主体的整体体制 |
| **政府退出/政府进入** | 危机应对两模式：退出=甩包袱（收益留微观成本社会化）；进入=国家信用逆周期投资 | ≠ 国进民退口号；是代价分配方式的选择 |
| **农户理性/村社理性** | 土地均分+村社组织使小农内部化处置外部性风险——真实"比较优势"来源 | ≠ 小农保守落后；是风险内部化的制度能力 |
| **三池调节** | 农村劳动力"蓄水池"+第一资产池（沿海基建）+县域"第二资产池" | ≠ 财政缓冲；是实体承接载体的分层 |
| **以地套现** | 廉价征地—土地抵押融资—城市扩张—税费增收的政府闭环 | ≠ 土地财政泛称；强调对农民增值收益的制度性占取 |
| **双重过剩** | 劳动力过剩与产能过剩互相压缩、只能靠外需释放；+金融资本过剩为三大过剩 | ≠ 行业产能过剩；是结构锁定机制 |
| **图钉型社会** | 塔基海量小有产者+中间约 3 亿中产+顶端富裕层；中产"刚形成即衰落" | ≠ 橄榄型社会；中产规模≠政治权重 |
| **再依附** | 金融化时代对霸权国的三重新依附：金融赋权、资源通道、对冲增发 | ≠ 一般贸易依赖；是依附的金融资本形态 |
