```yaml
- id: f01
  title: 上瘾模型（Hook Model）四阶段总框架
  type: framework
  source_chapter: 前言（L182–216）；第6章（L1845–1859）；第8章（L2146–2148）
  source_quote: |
    "上瘾模型包括四个阶段：触发，行动，多变的酬赏，投入。……通过用户的'投入'，就可能
    产生下一次'触发'，从而开始一个正向循环。"
  summary: |
    把"让用户养成使用习惯"拆成一个可循环的四阶段引擎：①触发（外部唤起/内部情绪）让用户
    使用；②行动（动机×能力×触发）让使用发生；③多变的酬赏满足需求并激发渴望；④投入储存
    价值并加载下一个触发，回到①。模型的意义在闭环：每一圈都让下一圈更易发生（触发更灵敏、
    行动更省力、酬赏更诱人）。作者强调它衔接"用户面临的问题"与"企业的应对策略"，是过滤
    点子、定位缺陷、组织迭代的总坐标系。
  tags: [mental-model, core, habit, loop]
```

```yaml
- id: f02
  title: 习惯区间（频率 × 可感知用途）
  type: framework
  source_chapter: 第1章（L429–443）
  source_quote: |
    "若某种行为发生的频率足够高，被感知到的用途足够多，就会进入我们的'习惯区间'，进而
    演变为一种默认的行为方式。这两个因素缺一不可。"
  summary: |
    判断一个行为能否成为用户习惯的二维坐标系：横轴是可感知用途，纵轴是发生频率。关键的不
    对称性：频率轴上，即使用途不明显，够高频也会成习惯（如刷社交媒体）；用途轴上，频率
    不足的行为无论多有价值都永远停留在有意识举动，成不了下意识反应（曲线永不相交横轴）。
    图中刻度刻意留白——没有通用时间表，习惯形成从几周到 5 个月以上不等，行为复杂度和
    重要性会改变速度。用途：新点子可行性过滤的第一道闸。
  tags: [habit, diagnostic, product-strategy]
```

```yaml
  type: framework
  source_chapter: 第1章（L449–474）
  source_quote: |
    "如果你因为无法实施某种行为而感到痛苦，那说明习惯业已形成。……科技公司在初期更像
    是锦上添花的维生素，可一旦它成为用户日常生活的一部分，那就会像止痛药一样抚平人们
    内心的'痒'。"
  summary: |
    反用投资人"维生素还是止痛药"的老问题：习惯养成类产品的正当路径不是以止痛药姿态入场，
    而是先做维生素（满足情感需求、可有可无），通过习惯养成变成止痛药（不用就难受）。
    判断转变是否发生有一个行为学判据——"无法实施就感到痛苦"。配套概念是"痒"：不是剧痛，
    而是潜伏于内心的渴求，得不到满足时产生不适感，产品的作用是更快地"挠痒"。
  tags: [product-strategy, habit, diagnostic]
```

```yaml
- id: f04
  title: 外部触发四分类（付费/回馈/人际/自主）
  type: framework
  source_chapter: 第2章（L594–628）
  source_quote: |
    "付费型触发、回馈型触发以及人际型触发都是以争取新用户为主要目标，而自主型触发以
    驱动用户重复某种行为作为重点，目的是让用户逐渐形成习惯。"
  summary: |
    所有藏在信息中、明确告知下一步行动的外部触发分四类，各有成本结构与生命周期：
    付费型（广告/推广，拉新快但代价不菲，不能长期依赖）；回馈型（媒体报道、应用商店推介，
    免费但要持续经营且昙花一现）；人际型（熟人推荐，可病毒式增长，也可能被黑暗模式滥用）；
    自主型（用户同意后持续出现的应用图标/简报/通知，唯一以驱动重复为重点）。前三类管拉新，
    第四类管留存——拉新与留存的触发必须分开设计。
  tags: [trigger, acquisition, retention, taxonomy]
```

```yaml
  type: framework

    不定等情绪常常会让我们体验到轻微的痛苦或愤怒，并使我们几乎在一瞬间就不自觉地采取

    直至条件反射建立（外部触发培养新习惯，内部触发造就铁杆粉丝）。正面情绪也可触发
    （分享好事=维系关系）。这是消费者技术成功的关键，也是全书机制的核心。
```

```yaml
    唯有准确把握潜在需求才能获得有价值启发。配套工具：用户情境体验、移情图、客户发展计划。
```

```yaml
- id: f07
  title: B=MAT 福格行为模型（行为三要素诊断）
  type: framework
  source_chapter: 第3章（L809–823）
  source_quote: |
    "要使人们行动起来，三个要素必不可少。第一，充分的动机；第二，完成这一行为的能力；
    第三，促使人们付诸行动的触发。……动机、能力、触发这三样缺一不可。"
  summary: |
    行为 = 动机 × 能力 × 触发（B=MAT），任一为零则行为为零，用户跨不过"行动线"。用途
    不在预测而在诊断：行为未发生时按三要素逐项归因——手机响了没接，要么够不着（能力），
    要么以为推销员（动机），要么静音（触发）。三要素分别对应上瘾模型的前三个阶段的
    门槛条件，是第 2 章（触发）与第 3 章（动机/能力）之间的总开关。
  tags: [behavior, diagnostic, fom, core]
```

```yaml
- id: f08
  title: 动机三分类（三组趋避杠杆）
  type: framework
  source_chapter: 第3章（L830–834、L1138）
  source_quote: |
    "能够驱使我们采取行动的核心动机不外乎三种。第一种，追求快乐，逃避痛苦；第二种，
    追求希望，逃避恐惧；第三种，追求认同，逃避排斥。"
  summary: |
    福格对动机的化简：所有人类行为受三组核心动机驱动，每组是一根杠杆的两端（趋/避），
    上下摆动幅度决定行为可能性。三组分别对应愉悦体感、预期情绪、社会关系三大领域。
    广告业是动机表达最直白的行业（希望海报、性卖点、社交凝聚力、恐惧诉求），但作者提醒
    "能够成为某些人行为动机的东西未必适用于另一些人"——动机设计必须先确认目标人群的
    敏感点。用途：给任何行动召唤找动机抓手，或诊断"用户为什么不想要"。
  tags: [motivation, taxonomy, core]
```

```yaml
- id: f10
  title: 简化三步法（减法创新）
  type: framework
  source_chapter: 第3章（L874–876；豪普特利《创新轻松三步法》）
  source_quote: |
    "第一步，了解人们使用某个产品或服务的原因。接下来，列举出用户使用该产品时的必经
    环节。最后一步，在明确整个过程的所有环节之后，开始做减法，把无关环节全部删除，
    直至将使用过程简化到极致。"
  summary: |
    创新的另一条路径：不是加功能，而是减环节。①弄清用户使用的根本原因；②列出完成该
    行为的必经环节全清单；③逐一做减法直至简化到极致。作者用网络史佐证：拨号上网→
    宽带、建站写博客→注册即发的博客平台→140 字符的 Twitter→一键拍摄的 Pinterest/
    Instagram，每一次发布门槛的骤降都带来内容供给的爆发。判断标准是"凡能让用户以最
    简便方式享用的产品或服务，一定是用户使用率最高的"。
  tags: [simplification, innovation, process, ability]
```

```yaml
  type: framework
```

```yaml
- id: f17
  title: 行动阶段与投入阶段的对称区分（减摩擦 vs 加摩擦）
  type: framework
  source_chapter: 第5章（L1642–1658）
  source_quote: |
    "行动阶段使用户即时获得满足，而投入阶段主要与用户对未来酬赏的期待有关。……投入
    阶段会增加摩擦。这无疑打破了产品设计界的传统思维，即一切用户体验都应该越'轻松
    简单'越好。"
  summary: |
    上瘾模型里一组精巧的对称：行动阶段要即时满足、要减摩擦（越简单越好）；投入阶段
    关乎长期期待、可以有摩擦（填写资料、关注他人、设置日程），因为摩擦本身产生价值感。
    关键在时机——必须在用户享受过酬赏之后再提出投入要求，否则变成强加的负担。这是
    对"用户体验永远越顺滑越好"这一行业教条的精确修正：不是全流程顺滑，而是分段处理。
  tags: [action, investment, friction, timing, core]
```
