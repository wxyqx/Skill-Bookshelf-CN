```yaml
  type: principle
```

```yaml
  type: principle
  source_chapter: 第2章（L632–667）
  source_quote: |

    等于持续为漏水的桶注水。判断产品健康度的隐含指标：外部触发依赖度是否在下降。
```

```yaml
- id: p04
  title: 研究用户的实际行为，而非内心愿景
  type: principle
  source_chapter: 第2章（L684–694；引艾丽卡·霍尔）

    而非他们声称想要什么。行为与言辞的矛盾或冲突恰恰代表机会。配套工具：用户情境体验、
    移情图、客户发展计划。
  tags: [principle, user-research, behavior]
```

```yaml
- id: p09
  title: 保障用户自主权——"你有权拒绝"
  type: principle
  source_chapter: 第4章（L1408–1433）
  source_quote: |
    "仅凭一句'你有权'，人们就会更容易被说服，因为这句话进一步肯定了人们的选择权。
    ……当对方提出要求的同时用熨帖的话语肯定你的自主权时，'逆反心理'就会不翼而飞。"
  summary: |
    涉及说服与要求时的规则：自主权受威胁会触发逆反心理（对抗性抗拒），而明确肯定对方
    的选择权（"你有权接受，也有权拒绝"）反而让顺从翻倍（42 项研究 22000 人）。产品化
    用法：让用户感到是在"既有方式与更便捷方式之间做选择"，任何强制感都是设计缺陷
    （Quora 可视功能教训）。既是提升转化的技巧，更是伦理护栏。
  tags: [principle, autonomy, reactance, ethics]
```

```yaml
- id: p22
  title: 习惯不等于成瘾——生产致瘾产品等同蓄意伤害
  type: principle
  source_chapter: 第1章（L476–478）
  source_quote: |
    "'成瘾'指的是长期且被动地依赖某种行为或是某个东西。依照定义，'成瘾'最终会使人
    走向自我毁灭。因此，生产让用户成瘾的产品是不负责任的表现，因为这等同于蓄意伤害。"
  summary: |
```
