# 淘汰记录 — f10 简化三步法（减法创新）

- **候选**: candidates/frameworks.md f10（出处：第3章 L874–876，转述丹尼斯·豪普特利《创新轻松三步法》）
- **判定**: 不通过 —— **V3 独特性**
- **理由**:
  1. 该方法系作者对豪普特利的直接转述（"了解使用原因→列举必经环节→做减法直至简化到极致"），抹掉书名后即为当代产品圈的"减法创新/MVP"常识；"删步骤提转化"在精益创业、极简设计话语中已高度普及。
  2. 埃亚尔在本节的真正增量是**证据链**（博客→Twitter→Instagram 的发布门槛史）而非方法本身；该证据链已在 f09（能力六要素）与 f07（先补能力）的 V1 证据中承担论证功能。
  3. 其操作内核"把行为简化到极致"没有独立于 f09 六要素之外的判据（六要素已给出"简化什么"的排查清单，三步法只给出"怎么删"的顺序）。
- **处置**: 降级为 f09/f07 的论证素材（简化史案例 c14、c16 已绑定）；不独立成 skill。
- **可捞回条件**: 若用户认为"先列全环节清单再逐一减法"的程序化约束足以构成差异（区别于凭感觉做减法），可在阶段 2 前捞回，并入 f09 的 A2 段（而非独立 skill）。
