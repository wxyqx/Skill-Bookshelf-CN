# 上瘾模型四阶段与出厂五问自检

## R — 原文 (Reading)

> "触发就是指促使你做出某种举动的诱因——就像是发动机里的火花塞。触发分外部触发和内部触发。让你产生习惯性依赖的那些产品往往是外部触发最先发挥作用。"
>
> — 前言 上瘾模式（L186）

> "话说回来，投入并不意味着让用户舍得花钱，而是指用户的行为能提升后续服务质量。……这些投入会对上瘾模型的前三个阶段产生影响，触发会更易形成，行动会更易发生，而酬赏也会更加诱人。"
>
> — 前言 上瘾模式（L214）

> "现在你可以利用上瘾模型询问自己关于如何让用户上瘾的五个基本问题：1.用户真正需要什么？你的产品可以缓解什么样的痛苦？（内部触发）……5.用户对你的产品做出了哪些'点滴投入'？这些投入是否有助于加载下一个触发并储存价值……？（投入）"
>
> — 第6章 上瘾模型与道德操控（L1849–1859）

---

## I — 方法论骨架 (Interpretation)

把"让用户反复使用、最终不假思索"这件事拆成一台四冲程引擎：①触发负责唤起（外部暗示或内部情绪把用户带到产品门口）；②行动负责让使用真的发生（越省力越好）；③多变的酬赏负责点燃渴望（可预期的结果不产生渴望）；④投入负责让下一圈更容易（用户存的每一点东西都反过来强化前三环）。

两个关键结构判断使它区别于普通的增长漏斗：第一，它是**闭环**——第四阶段的产出会回连第一阶段（用户投入生成下一次触发），所以评价对象是"圈速与圈数"，不是单程转化率；第二，**投入是枢轴**——它不是商业意义上的付费，而是用户付出时间、数据、内容来改善后续体验的行为，这是模型里最反直觉也最常被漏掉的一环。

五问把模型变成出厂检查表：内部触发、外部触发、最简行动、酬赏渴望、投入加载——每问带判据，逐环过一遍即可定位习惯潜能弱在哪。作者还给它配了一个前置检查：先确认产品类型适合经营习惯（用户主动参与、可高频发生），再动用模型。

## A1 — 书中的应用 (Past Application)

### 案例 1: 芭芭拉与 Pinterest——前言演示
- **问题**: 如何向读者完整展示模型四阶段如何在真实使用中循环起来。
- **方法论的使用**: 作者虚构用户芭芭拉逐环走一遍：Facebook 图片是外部触发→点击进入 Pinterest 是行动→视觉惊喜让她滑屏 45 分钟是多变的酬赏→收藏与关注是投入。
- **结论**: "这份投入反过来又会强化她与网站之间的联系，促使她在下一次打开电子设备时优先登录这些网站"——闭环成立，每一圈都让下一圈更易发生。
- **结果**: 芭芭拉从偶然访客变成"逐渐将 Facebook/ Pinterest 看成社交生活方式"的习惯用户；作者用它引出全书（L186–216）。

### 案例 2: 《圣经》应用程序——第 7 章纵向走完四阶段
- **问题**: 一个桌面时代几乎失败的产品，如何在移动端让用户每日读经。
- **方法论的使用**: 作者以自己第一人称体验逐环对照：通知/红徽章/邮件/社区邮件构成多层触发（L2069–2073）；读经计划切分小片段降低行动门槛（L2054–2056）；次日经句的神秘感与"链条不断"提供酬赏；高亮/书签/评论沉淀为"卷了边的书"式投入。
- **结论**: 四阶段每一环都可被产品化，且投入端（书签、高亮、连续打卡）直接加载了次日触发。
- **结果**: 1 亿台设备下载，《圣经》类目应用商店居首（L2000–2121）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新产品/新功能评审：判断"这个东西有没有习惯潜能"，需要一张出厂检查表逐环过。
2. 留存诊断：数据说用户不回来了，但说不清断在哪一环——需要先把问题归到四阶段之一。
3. 增长手段整理：手里一堆推送、签到、勋章、收藏夹等零散方案，要组织成完整循环而不是点状功能。
4. 向上汇报/方案叙述：需要用"闭环"语言向团队解释增长策略为什么这样排。
5. 跨域：个人习惯系统设计（学习、健身）也可以按四阶段搭自己的循环。

### 语言信号 (用户的话里出现这些就应激活)

- "上瘾模型 / hook model / 四阶段 / 习惯回路"（hook model, four stages, habit loop）
- "有没有习惯养成潜能 / 为什么用户不回来 / 留存断在哪"（habit-forming potential, why users don't return）
- "把增长手段串起来 / 完整循环 / 五问自检"（close the loop, five questions checklist）

### 与相邻 skill 的区分

- 与 `f02-habit-zone-frequency-first` 的区别：f02 是入场前的可行性过滤（这个行为值不值得做习惯设计），f01 是入场后的全流程设计框架。先过 f02 的闸，再进 f01 的循环。
- 与 `f07/f12/f16` 等单环 skill 的区别：它们各管一环（行动诊断、酬赏设计、加载下一触发）；f01 是总坐标系与出厂自检，定位出弱环后应转交对应单环 skill 深入。
- 与 `f20-habit-test-three-steps` 的区别：f01 是上线前的设计与自检，f20 是上线后用数据验证习惯是否真的形成。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **适用性前置检查**
   - 完成标准: 明确回答"该产品是否用户主动参与、行为可高频发生"。强制消费型（人寿保险等低频一次性购买）或纯被动工具，判定模型不适用并说明理由。
   - 判停条件: 若产品核心价值尚未成立（用户用一次就不想再用），判停——先解决价值问题，习惯设计不救烂产品。

2. **五问逐环自检**
   - 完成标准: 对五个问题各写出一句话答案并附证据：内部触发是什么情绪/焦虑；外部触发靠什么唤起；3 分钟内能否完成最简行动；酬赏是否让人想要更多；有哪些点滴投入在加载下一触发、储存价值。

3. **定位最弱一环**
   - 完成标准: 五问中证据最薄弱的一环被显式点名（"潜在弱点"用法，L2146–2148），并说明它如何拖住整个循环。

4. **转交单环 skill 或给出改进动作**
   - 完成标准: 每个弱环给出改进方向，并注明应深入的单环 skill（行动→bmat-action-diagnosis；酬赏→three-variable-rewards；投入与召回→investment 类 skill；触发→trigger 类 skill）。

5. **闭环完整性复查与伦理自检**
   - 完成标准: 检查第四阶段产出是否真的回连第一阶段（断在投入处的"爆品"最常见）；最后过操纵矩阵两问（我自己会用吗/能否提升用户生活质量），确认没有为循环指标牺牲用户自主权。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性工具与强制消费型产品：计算器、年检代办、人寿保险——作者自设边界（L310–314），"本书所构建的理论框架和实践指导并不是包治百病的灵丹妙药"，这类产品没有循环可言。
- 产品价值不成立时把模型当救命稻草：四阶段能放大好产品，不能替代好产品。
- 把模型当线性漏斗使用：只优化单程转化（看到→点→付费）而不管投入回连，等于只建了半个引擎。

### 作者在书中警告的失败模式

- 爆品陷阱（ce21）：一夜爆红的产品往往触发、行动、社交酬赏三环俱全，但缺第四环投入，"爆品也会随着时间推移而丢掉你的注意力"——判断产品不能只看前三环的热闹。
- 触发成功但循环断裂（ce22）：就算触发生效、动机强烈，能力不足行为仍为零；把"曝光"误当"行动"是常见归因错误。
- 可预见反馈回路无效（ce06，冰箱门）：上瘾模型与普通反馈回路的区别就在"多变"——结果可预料，用户就不会"没完没了地重复"。

### 作者的盲点 / 时代局限

- 成书于 2014 年硅谷移动红利期：案例集中于 Facebook/Instagram/Twitter/Pinterest 等消费 App，默认"App 图标占据首屏"是触发主战场；小程序、超级 App、短视频算法流等后继形态未覆盖。
- 框架包摄力极强、可证伪性弱：产品成功可解释为"符合模型"，失败可解释为"某环没做好"，书中无失败预测记录——用它做归因时要警惕事后诸葛。
- 证据以幸存者案例与二手心理学实验为主，无对照研究；"习惯=依赖=收益"的因果链是相关叙事而非实验证明。

### 容易混淆的邻近方法论

- AARRR/增长漏斗：漏斗是线性、以转化为终点；上瘾模型是闭环、以重复为终点。混用会把投入阶段误做成付费引导。
- 福格 B=MAT（f07）：那是行动环节内部的诊断工具，不覆盖全循环。
- 普通习惯回路暗示—惯常行为—奖赏（杜希格）：缺少"投入改变下一圈"这一枢轴，解释力止步于既有习惯。

### 伦理红线

本书主题是"让用户养成使用习惯"，四阶段是强力机制，红线必须写明：**不用于绕过用户自主权的设计**。作者划出的分界："成瘾"指长期被动依赖并最终损害使用者，"生产让用户成瘾的产品是不负责任的表现，因为这等同于蓄意伤害"（L476）——模型目标是习惯（有益的无意识行为），不是成瘾。落地任何循环设计前过操纵矩阵（f18）两问；对未成年人等易感人群不做强迫性循环设计。

## 相关 skills

本 skill 是全书的总坐标系：四阶段闭环给每个单环 skill 提供定位，出厂五问是进入任何单环深挖前的总检查表。

**depends-on**（使用前提）: 无 — 总纲不依赖其他单元；反向地，多数单环单元都以理解四阶段闭环为背景。

**contrasts-with**（同境况二选一）: 无 — 与各单环 skill 是"全景 vs 局部"的分工，不是备选方案。

**composes-with**（配合使用/先后接力）:

- `habit-zone-frequency-first` — 入场前先过习惯区间闸（该不该做习惯设计），再进本 skill 的循环设计；频率不达标时本 skill 的适用性检查直接判停。
- `bmat-action-diagnosis` — 五问定位出"行动"是弱环后，转交它做 B=MAT 乘法归因与"先补能力"排序（E 段步骤 4）。
- `three-variable-rewards` — 五问定位出"酬赏"是弱环后，转交它做三通道选择与动机对齐（E 段步骤 4）。
- `load-next-trigger` — 投入环节的闭环合页：检查第四阶段产出是否回连第一阶段，由它给出内生召回设计（E 段步骤 4）。
- `habit-test-three-steps` — 上线前用本 skill 设计与自检，上线后用习惯测试验证习惯是否真的形成（5% 基准 + 习惯路径）。
- `manipulation-matrix` — E 段步骤 5 的伦理自检闸门：任何循环设计落地前先过两问（"我自己会用吗/能否提升用户生活质量"）。
