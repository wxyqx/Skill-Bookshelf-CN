# 驱逐恶棍，保护明星

## R — 原文 (Reading)

> "恶棍把私利置于集体利益之上，而明星虽然自我感觉良好，但对个人利益和集体利益同等重视。恶棍一经发现，就需要及时处理；明星对企业的贡献足以支撑其狂妄，你就需要对他们多加容忍，甚至悉心保护。"
>
> — 施密特、罗森伯格，第一章《驱逐恶棍，保护明星》

---

## I — 方法论骨架 (Interpretation)

团队里"难相处的人"其实是两类完全不同的人，处理方向必须相反。

**判别标准只有一条：他的行为把私利还是集体利益放在前面。** 恶棍的恶行是人品不端的产物（嫉妒、抢功、把脏活甩给别人）；明星的"难搞"是出类拔萃的结果——他自我感觉良好，但对个人利益和集体利益同等重视。用"难不难相处"当尺子，必然两边都判错。

**处理规则不对称。** 对恶棍：一经发现迅速处理——先减少职责、让正派的"骑士"接手剩下的工作，极端恶行立即铲除，"一日为恶，终身为恶"。对明星：刻意容忍、甚至悉心保护——企业文化的条条框框常常在扫恶棍时把不循常规的明星一并扫掉。

**为什么必须快：恶棍比例有临界点。** 这个数字比直觉小得多——比例一过，正派员工认为自己必须迎合恶棍才有出路，开始模仿恶行，文化崩坏不可逆。所以监控的是趋势而不只是个案。

**入口拦截是配套防线**：品行问题最好在录用前拦住——看应聘者对无权势者（助理、服务生）的态度，这就是博兹沃茨法则。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: "这是作恶"——价值观红线的即时执法
- **问题**: 一项可能带来丰厚利润的广告体制改动被摆上会议桌面。
- **方法论的使用**: 一位工程负责人拍桌反驳"这是在作恶，这事我们不能做"，全场停下共同评估——如丰田安灯绳，人人可拉绳中止流水线。
- **结论**: "不作恶"不是口号而是授权：品行与价值观问题在职内即时生效，不等季度复盘。
- **结果**: 提案被否决；价值观成为管理方式与产品计划的北极星（c29）。

### 案例 2: 博兹沃茨法则——把品行检测前置到录用入口
- **问题**: 如何在正式面试之外考察应聘者的人品。
- **方法论的使用**: 一位资历外貌俱佳、被认为十拿九稳的候选人，因"对秘书态度非常恶劣"被拒；谷歌随后把征询助理意见制度化。
- **结论**: 对无权势者的态度是品行最可靠的证据。
- **结果**: "博兹沃茨法则"进入谷歌招聘惯例，人品不端者在入口被拦截（c44）。

### 案例 3: 反面——恶棍临界点
- **问题**: 恶棍留到什么时候处理才算晚？
- **方法论的使用**: 作者给出非线性机制：比例过临界点（数字比想象的小），骑士不再举报而转向模仿。
- **结论**: 缓处理即失守；管理层以"他是明星"为由拖延是最常见的错误。
- **结果**: 恶行从个案变成组织的生存策略，文化崩坏不可逆（ce16）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队里业绩最好的人抢功、甩锅、打压同事，管理者在"忍他还是动他"之间摇摆。
2. 准备立规矩、整顿文化，担心把不循常规的怪才明星一起清掉。
3. 招聘/面试时想提前识别品行风险，而不只看履历与面试表现。
4. 发现团队里开始有人模仿某个"能人"的恶劣做派，或员工打听"他那样的行为公司管不管"。
5. 有人以价值观/道德为由要求叫停一项决策，不确定该不该接。

### 语言信号 (用户的话里出现这些就应激活)

- "技术最强但人品差 / 混蛋但绩效高 / brilliant jerk / toxic"
- "抢功劳 / 甩锅 / 把私利置于团队之上 / 害群之马"
- "天才都难相处，要不要忍 / 保护怪才 / 别误伤能人"
- "他对助理、服务生态度特别恶劣"
- "大家开始学他的坏做派 / 恶棍 villain / 明星 star"

### 与相邻 skill 的区分

- 与 `hiring-quality-bar` 的区别：那是招聘的质量标准（宁缺毋滥、A 撑 A），管"门槛多高"；本 skill 管"在岗人员的品行处置"。博兹沃茨法则是两者的接口——入口拦截。
- 与 `retention-playbook` 的区别：留汰律处理绩效与成长不匹配，对明星有以小时计的挽留窗口；本 skill 对恶棍没有挽留流程——品行问题不谈条件。
- 与 `hippo-resistance` 的区别：河马可能是好人，只是职位权重扭曲了讨论，用会议机制解决；恶棍是品行问题，用人的去留解决。别用整人的方式修会议结构。

## E — 可执行步骤 (Execution)

1. **判别：私利还是业绩**
   - 完成标准：列出此人行为的具体事实，逐条按"把私利还是集体利益放在前面"归类；明确不用"难相处"作判据。
   - 判停条件：若他重视集体利益、只是不循常规或不好相处 → 转步骤 3（明星保护路径），不启动驱逐。
2. **处置恶棍：先削权，再清除**
   - 完成标准：明确削权方案与"骑士"接手名单；极端恶行（价值观红线）立即执行，一般恶行也以天计而非以季度计；不给第二次机会。
3. **保护明星：给非常规开豁免**
   - 完成标准：把他违反的"文化条条框框"逐条过一遍，为其中不损害集体利益的部分开豁免并向团队说明理由；同时明确对私利行为同样零容忍——保护的是狂妄，不是特权。
4. **监控恶棍比例的临界点**
   - 完成标准：检查三个预警信号——员工打听"他那样的行为管不管"、举报者被孤立、恶棍的盟友在增加；任一出现即升级处置速度。
5. **把入口拦截制度化**
   - 完成标准：招聘流程中正式征询助理/服务生等无权势接触者的意见（博兹沃茨法则），并留档；发现品行红灯一票否决。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **绩效不达标但品行端正的人**——那不是恶棍，走 `retention-playbook` 的汰换流程，别给人品定罪。
- **内向、直率、说话冲等性格特质**——判据是利益指向不是相处舒适度；先查有没有损公肥私的事实。
- **会上高薪者压制讨论**——话语权问题是 `hippo-resistance`，用会议机制解决；给同事贴"恶棍"标签只会激化冲突。

### 作者在书中警告的失败模式

- 两向搞混：把不循常规但贡献卓著的明星当恶棍清洗，或把业绩显赫的恶棍当明星容忍——绩效与品行混在同一张考核表里打总分，是最常见的机制性错误（ce15）。
- 恶棍临界点：比例过线后骑士模仿恶行、举报者被孤立，文化崩坏不可逆；"他是明星"式的拖延处理是最大推手（ce16）。

### 作者的盲点 / 时代局限

- 判定权问题书中未讨论：说谁"把私利置于集体之上"由管理者单方认定，没有程序正义设计（谁判定、如何申诉）；判定权本身可能被滥用为清除异己的工具（BOOK_OVERVIEW 批判节：当事人叙事、原则间张力）。
- 书中案例来自高利润引擎支撑的谷歌；在职业安全感低的组织里，"迅速清除"若无透明标准，会放大人人自危。

### 容易混淆的邻近方法论

- Netflix 的"brilliant jerks"：只讲了别容忍混蛋这一侧；本书独特在对偶另一侧——明星的狂妄要悉心保护，且给出"私利 vs 集体利益"的可操作判据。
- 绩效管理（performance management）：绩效差是能力/匹配问题，品行差是利益指向问题；两套流程、两个出口，混用必然误伤。
