# 人才画像（学习型动物 / 机场测试 / 加大光圈）

## R — 原文 (Reading)

> "我们理想的应聘者，都是那些勇于乘坐过山车且学习不辍的人。这些'学习型动物'不仅有处变不惊的智慧，也有乐于享受变化的心态。" / "想象一下，你要与一位同事一起在机场里因飞机延误而待上整整6个小时。你能与他开心聊天打发时间吗？"
>
> — 施密特、罗森伯格，第三章《雇用学习型动物》/《机场测试》

---

## I — 方法论骨架 (Interpretation)

画像的总原则：**看潜力，不看存量**。在指数级变化的行业里，已掌握的知识会过期，学习的速度才是资产——理想的候选人是"勇于坐过山车且学习不辍"的学习型动物：不怕问蠢问题，不怕得到错答案。

三个可操作的测量：①**学习力**——让候选人剖析自己错失的机遇与犯过的具体错误，这类问题无法用套话预演，看的是如何从错误中走向成熟，而非先见之明。②**共事质量与品行**——机场测试（延误 6 小时愿不愿真聊）被制度化为第四评分板块"谷歌范儿"，与一般认知能力、职务知识、领导经验并列；博兹沃茨法则看他对服务生、助理等无权势者的态度；真热情在细节密度里，不在自我标榜里。③**光圈**——一般招聘者的光圈太小，只装得下"有头衔、能立刻胜任"的人；把光圈调大，以职业上升趋势为判据，纳入跨领域、无经验但高潜力的被排除者，愿意为高出标准的人破例。

地基是创意精英四基座：专业知识、商业头脑、创造力、实践经验，缺一不可。承认偏见无法自除，所以全程用统一的事实评分。

## A1 — 书中的应用 (Past Application)

### 案例 1: 谢尔盖面试乔纳森——从经济学白板到求爱秘籍
- **问题**: 2000 年乔纳森面试产品负责人职位，白板讲解经济学定律令谢尔盖把玩溜冰鞋看向窗外。
- **方法论的使用**: 面试目标是发现思维模式而非验证资历复述——乔纳森立即换话题，用"如何赢得太太的第一次约会"讲清沟通策略。
- **结论**: 测的是把复杂问题讲明白的能力与真实思维，不是学历与套话。
- **结果**: 乔纳森拿到工作，后成为谷歌产品负责人（c41）。

### 案例 2: "1996 年你错失了哪些机遇"——学习型动物探测器
- **问题**: 怎么在面试中识别学习型动物，而不是"相关知识储备最多"的人？
- **方法论的使用**: 让应聘者剖析过去错失的浪潮与具体错误——先说当时的预见，再联系实际观察，实实在在承认失误。
- **结论**: 该问题不检验先见之明，检验从错误中总结与成熟的能力，且无法用"我的弱点是完美主义"式套话应付。
- **结果**: 成为乔纳森的标准面试武器；能给出让人眼前一亮的答案者，多半就是学习型动物（c43）。

### 案例 3: 肖娜·布朗——"毫无相关经验"执掌运营
- **问题**: 2003 年为高速扩张的谷歌寻找人力资源主管，约 50 名传统候选人无一胜任。
- **方法论的使用**: 勿被"相关经验"绑架，把业务运营交给毫无相关经验的麦肯锡合伙人——看能力与上升轨迹，不看履历对口。
- **结论**: 高层选人的最大陷阱是按经验划线；聪明的通才没有专家偏见。
- **结果**: 肖娜·布朗入职成功；2008 年 CFO 人选皮切特按同一逻辑选出（c47）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 为一个新岗位（或两年前不存在的岗位）写 JD / 定画像，纠结"要求几年经验、什么背景"。
2. 设计面试题，想测学习力、潜力、品行，而不是让候选人复述简历。
3. 一位候选人简历"不对口"（转行/自学/无学位）但作品与思路出色，要不要给面试机会。
4. 团队画像争论：要资深专家还是聪明的通才、要证书还是要好奇心。
5. 评估高管/资深候选人时，被"有没有做过一模一样的事"绑架。

### 语言信号 (用户的话里出现这些就应激活)

- "学习型动物 / learning animal / 成长型思维 / growth mindset / 怎么看潜力"
- "机场测试 / airport test / 谷歌范儿 / Googleyness / 文化契合怎么问"
- "面试题怎么设计 / 怎么识别学习能力 / 问什么能测出真本事"
- "要不要给没有经验的人机会 / JD 该写几年经验 / 简历不对口"
- "要专家还是要通才 / 错失了哪些机遇"

### 与相邻 skill 的区分

- 与 `hiring-quality-bar` 的区别：本 skill 管"看什么维度、用什么题测"（画像与测量）；那个管"门槛多高、拿不准怎么办"（质量律）。用本 skill 选维度，用那个守底线。
- 与 `hiring-ops` 的区别：本管面试的内容设计（问什么、看什么信号）；那个管流程参数与决策权（时长、轮数、谁拍板、依据什么）。
- 与 `expel-villains-protect-stars` 的区别：博兹沃茨法则在**入口**测品行，防恶棍进门；已入职者的品行执法与恶棍清除是那个 skill 的事。
- 与 `retention-playbook` 的区别：招进来之后"让学习型动物继续学习"是留才话题的入口，但留汰机制本身在那本书。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写画像：潜力优先于存量**
   - 完成标准：JD 第一条不是"N 年经验"；列出创意精英四基座（专业知识、商业头脑、创造力、实践经验）各需要什么证据；行业变化越快，经验权重越低。
2. **设计学习力探测器**
   - 完成标准：至少一题要求候选人剖析具体错误（"上一波浪潮你错过了什么、做错了什么、怎么发现的"变体）；能区分套话与真实剖析——剖析错误的质量无法排练。
3. **设计品行与共事测试**
   - 完成标准：机场测试进入评分表（共事质量与认知能力、职务知识、领导力并列为四大板块）；正式征询助理/行政对接人的意见（博兹沃茨法则）；记录面试前后的行为观察；对把"激情"挂嘴边的自述降权。
4. **加大光圈**
   - 完成标准：漏斗中纳入跨领域/非典型背景人选；以职业上升趋势为判据；对高出标准但不符合条文的人，记录破例理由、让规则为判断让路（Instagram 的教训）。
   - 判停条件：若岗位是强资质合规岗（执照/法规硬门槛），光圈不得越过法规，本步只放宽"经验年限"类软门槛。
5. **用统一事实评分，进门抛偏见**
   - 完成标准：全部候选人走同一套维度与事实记录；每条结论附具体观察，禁止印象词；承认偏见无法自除，用结构化流程对冲。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **强资质合规岗（医生、飞行员、注册会计师等）**——执照与法定门槛是硬约束，"光圈"不能放大到绕开法规。
- **无具体候选人的通用面试话术求助**——先问清岗位与场景，否则只是知识问答，套用画像没有对象。
- **已入职员工的评价与处置**——画像管入口；在职绩效、轮岗与淘汰转 `retention-playbook` / `expel-villains-protect-stars`。

### 作者在书中警告的失败模式

- 把"激情"挂嘴边的应聘者：品质一旦成为评分项就变成表演对象（古德哈特定律的面试版），真信号在具体追求的细节密度里（ce24）。
- 模式匹配招聘："5-10 年微件经验"招来的是专家偏见，行业一变，昨日专家成为变革阻力（ce25）。
- 拒绝凯文·希斯特罗姆：硬性门槛沦为免除判断责任的挡箭牌，组织精确地按条文筛掉天才（ce26）。
- 智力谜题被应试化：题库上网后，谜题测的只是演技，最终被作者亲手剔除（ce27）。

### 作者的盲点 / 时代局限

- 画像本身曾是"非工程师不招"（工程师中心），对非技术职能的可移植性书中未讨论。
- "机场测试/谷歌范儿"与"千篇一律是失败的温床"（书中同时主张观点多样性）之间存在未经调和的张力：面试官容易把"和我投缘"当"范儿达标"。
- "毫无相关经验"的高管成功案例（肖娜·布朗）背后有谷歌的品牌吸力与利润引擎兜底（幸存者偏差）；普通公司复制时容错空间更小。

### 容易混淆的邻近方法论

- 泛化的 culture fit 面试：本书的"谷歌范儿"只是四维之一，且有机场测试的操作定义；"聊得来"不等于"范儿"。
- STAR 行为面试：本书的错失机遇之问方向相反——不问成功案例问错失，套话难以预演。
