- id: f01
  title: "卡嗒，哗"自动反应模型
  type: framework
  source_chapter: 第一章 · 影响的武器
  source_quote: |
    "卡嗒，特定的磁带被启动了；哗，一系列标准的行为放了出来。"
    "在我们这个社会中存在着一种非常令人不安的盲目服从专家的倾向。"
  summary: |
    人类拥有类似磁带播放的固定行为模式：特定启动特征（trigger feature）触发一整套
    机械反应。启动特征往往只是事物的一个微小方面（如价格、头衔、"因为"一词），
    但足以绕过理性分析。信息过载越严重，人们对这种捷径的依赖越深。
    防御关键：识别启动特征 → 暂停自动反应 → 启动"有控制的反应"。
  tags: [framework, automatic-response, mental-model, click-whirr]

- id: f02
  title: 认知对比原理
  type: framework
  source_chapter: 第一章 · 影响的武器
  source_quote: |
    "如果两件东西很不一样，我们会趋向于认为它们之间的差别比实际的更大。"
  summary: |
    先后接触的两件事物会被感知为差异更大。先看贵的再看便宜的，后者显得更便宜；
    先提大请求再提小请求，后者显得更无足轻重。这是拒绝—退让策略等
    多种依从技巧的基础增强机制。原理本身是中性的，关键在于识别
    "前一件东西"是否被刻意安排。
  tags: [framework, perception, contrast, enhancement-mechanism]

- id: f03
  title: 柔道策略（利用自然之力）
  type: framework
  source_chapter: 第一章 · 影响的武器
  source_quote: |
    "一个精通柔道的妇女在与对手搏斗时很少用到自己本身的力量，而是尽可能地利用
    蕴藏在自然原理中的力。那些利用自动影响武器的人也正是这样。"
  summary: |
    依从从业者不直接施压，而是启动对方体内的心理学"磁带"，让对方自己按预设
    方式行动。柔道策略的核心是：不创造力量，而是引导已有力量。理解这一模型
    后，防御者可将同样的柔道原理反向运用——把对方释放的心理力量转化为
    防御动力（如把短缺引起的冲动当作警告信号而非购买驱动）。
  tags: [framework, judo, leverage, meta-strategy]

- id: f04
  title: 重新定义防御法
  type: framework
  source_chapter: 第二章 · 互惠
  source_quote: |
    "你需要在脑子里把事情重新定义一下。不要把你从检查员处收到的东西定义为礼物，
    而是把它们定义为推销手段，这样你便可以任意拒绝（或接受）他的购买要求。"
  summary: |
    当识别到对方的"恩惠"实为依从策略时，在认知层面对其重新定义：
    "礼物"→"促销手段"、"让步"→"依从策略"。一旦完成重新定义，
    互惠原理的约束力即被消解，因为"诡计不必用恩惠来回报"。
    适用于互惠、承诺、社会认同等原理的防御。
  tags: [framework, defense, reframe, cognitive-redefinition]

- id: f05
  title: 情绪信号防御法（肠胃/心灵信号）
  type: framework
  source_chapter: 第三章 · 承诺和一致
  source_quote: |
    "来自肠胃的信号……当我们意识到自己落入了某种圈套时，我们的肠胃会做出反应。"
    "来自心灵深处的信息应该是一种很纯粹很基本的感觉。"
  summary: |
    两层信号系统：(1) 肠胃信号——当明显被算计时胃部痉挛，用于识别明确的
    依从圈套；(2) 心灵信号——当不确定是否被操纵时，问自己"如果时间倒流，
    知道现在知道的一切，我还会做同样的选择吗？"然后捕捉第一闪念的直觉反应。
    理性认知系统会在原始直觉之后才启动，因此第一闪念更接近真实判断。
  tags: [framework, defense, body-signal, intuition, commitment-consistency]

- id: f06
  title: 分离防御法（人 vs 请求）
  type: framework
  source_chapter: 第五章 · 喜好
  source_quote: |
    "把精力集中在这一笔生意……我们选择了丹要卖给我们的车，将要在车里开走的是我们，
    而不是丹。"
  summary: |
    当发现自己对提出请求的人产生了超出正常程度的好感时，主动将"提出请求的人"
    与"请求本身"在认知上切割。评估请求本身的优劣，而非基于对人的好感做决定。
    适用于所有涉及人际好感的依从场景（销售、募捐、社交请求）。
  tags: [framework, defense, separation, liking, decision-making]

- id: f07
  title: 拒绝—退让策略
  type: framework
  source_chapter: 第二章 · 互惠
  source_quote: |
    "先提出一个比较大的、我极可能会拒绝的请求。然后，在我拒绝了这个请求之后，
    你再提出那个小一些的、你真正感兴趣的请求。"
  summary: |
    先提大请求（预期被拒），再提小请求（真实目标）。被拒后的退让被对方
    感知为"让步"，触发互惠原理使其也做出让步（答应小请求）。
    同时认知对比原理使小请求显得更无足轻重。
    两个甜蜜副产品：受害者对协议更有责任感（"是我促成的"）和更高满意度
    （"对方终于让步了"），因此更可能履行承诺并继续合作。
    边界：最初请求不能太极端否则被视为无诚意。
  tags: [framework, compliance-tactic, reciprocity, contrast, door-in-face]

- id: f08
  title: 入门策略（Foot-in-the-door）
  type: framework
  source_chapter: 第三章 · 承诺和一致
  source_quote: |
    "从小事做起，循序渐进，慢慢积累。"
    "一旦他同意了一个请求，他的态度就变了。在他自己的眼里，他变成了会去做这些事情的那种人。"
  summary: |
    从小请求开始（几乎不可能被拒绝），引发对方做出承诺并改变自我形象，
    使其随后更愿意答应更大的相关甚至不相关请求。
    机制：小承诺 → 自我形象改变（"我是会做这种事的人"）→ 一致性压力
    驱动后续依从。有效承诺需满足：主动、公开、费力、自由选择。
  tags: [framework, compliance-tactic, commitment, self-image, foot-in-door]

- id: f09
  title: 抛低球策略
  type: framework
  source_chapter: 第三章 · 承诺和一致
  source_quote: |
    "首先出一个很有诱惑力的价钱，使顾客做出买车的决定；然后，当这个决定已经做出
    但还没有最后成交时，那个最先给出的诱惑却被巧妙地拿走了。"
  summary: |
    给出诱人条件诱使对方做出承诺，待承诺做出后（此时承诺已"长出自己的腿"——
    新的理由已经生成），再拿走最初的诱人部分。即使条件变差，对方仍会
    履行承诺，因为新长出的支持理由已足够支撑决定。
    防御：问自己"如果时间倒流，知道了真正的条件，我还会做同样的选择吗？"
  tags: [framework, compliance-tactic, commitment, low-ball, sunk-cost]

- id: f10
  title: 多元无知分析框架
  type: framework
  source_chapter: 第四章 · 社会认同
  source_quote: |
    "每个人都认为既然大家都无所谓，就说明一切都很正常。而与此同时，事情却变得越来越危险。"
  summary: |
    紧急事件中，每个旁观者都在观察他人反应以判断事件是否紧急。
    由于所有人都试图不动声色地寻找线索，结果人人都显得若无其事，
    整个群体据此"确认"事件非紧急。人越多、彼此越陌生，多元无知越严重。
    破解：明确指向一个人，给出明确指令（"你，穿蓝夹克的，叫救护车"），
    消除不确定性和责任分散。
  tags: [framework, social-proof, bystander-effect, pluralistic-ignorance, emergency]

- id: f11
  title: 好警察/坏警察策略
  type: framework
  source_chapter: 第五章 · 喜好
  source_quote: |
    "好警察/坏警察的方法之所以总能奏效有好几个原因：对长期监禁的恐惧被坏警察挑起；
    认知对比原理保证好警察显得通情达理；互惠原理使嫌疑犯觉得应该还好警察一个人情。"
  summary: |
    两个合作者交替施压：坏警察制造恐惧和敌意，好警察表现友善和同理心。
    通过认知对比（坏→好）放大好警察的吸引力，通过互惠（好警察帮忙说话/买咖啡）
    制造负债感，最终形成"我们站在一边"的喜好感。是多原理组合运用的典型。
  tags: [framework, compliance-tactic, multi-principle, liking, contrast, reciprocity]

- id: f12
  title: 短缺情绪两步防御法
  type: framework
  source_chapter: 第七章 · 短缺
  source_quote: |
    "一旦我们感觉到短缺引起的情绪冲动，我们应该利用这种冲动作为使其立即停下来的信号。
    一个明智的依从决定中是没有恐慌和狂热的位置的。我们应该冷静下来，重新恢复理智。
    做到这一点以后，我们就可以进行第二步了，也就是问一问自己，我们为什么想要这样东西。"
  summary: |
    第一步：将短缺引起的情绪冲动（焦虑、兴奋、竞争感）本身作为警告信号，
    立即暂停决策。第二步：冷静后问"我为什么想要它？"——如果是为了拥有
    （社会/经济/心理优势），短缺程度可作为价格指标；如果是为了使用
    （吃、喝、驾驶），则短缺不改变功能，"短缺的小甜饼吃起来并不会味道更好"。
  tags: [framework, defense, scarcity, emotion-signal, two-step]
