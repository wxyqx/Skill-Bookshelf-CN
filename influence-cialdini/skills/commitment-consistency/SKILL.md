# 承诺和一致：识别与逃脱陷阱

## R — 原文 (Reading)

> "一旦我们做出了一个决定，或选择了一种立场，就会有发自内心以及来自外部的压力来迫使我们与此保持一致。有时候，不是思考过程的艰辛，而是思考的严峻后果，让我们避之惟恐不及。机械地保持一致可以为我们提供一个躲避烦恼现实的安全所在。"
>
> "在知道了所有这一切之后，如果时间能够倒流，我还会做出同样的选择吗？"
>
> — Cialdini, 第三章 · 承诺和一致

---

## I — 方法论骨架 (Interpretation)

做出决定后，内外压力驱使我们保持与决定一致——即使决定已不合理。一致性之所以强大，因为它有两个诱惑：逃避思考的艰辛（捷径）和逃避思考的严峻后果（安全港）。两者结合使机械一致成为"愚昧的城堡"，理性攻击无法穿透。

承诺越主动、越公开、越费力、越自由选择，锁定力越强。入门策略从小承诺开始改变自我形象（"我是会做这种事的人"），抛低球用诱人条件诱使承诺再拿走（承诺已"长出自己的腿"）。

两层防御信号系统：(1) 肠胃信号——当明显被算计时胃部痉挛，立即暂停；(2) 心灵信号——不确定时问"如果时间倒流，知道现在的一切，我还会做同样选择吗？"然后捕捉第一闪念，而非后续理性化的理由。

## A1 — 书中的应用 (Past Application)

### 案例 1: 中国战俘营改造 (c09)

- **问题**: 如何让战俘主动与 captor 合作？
- **方法论的使用**: 渐进策略——从写"美国并不完美"开始→列举例子→签名→小组讨论→文章→广播。每步都是自愿、公开、书面的承诺，逐步改变自我形象。征文比赛用小奖品（非大奖励）确保内在归因
- **结论**: 小承诺→自我形象改变→一致性压力驱动后续依从。公开+书面+自愿的承诺固化效果最强
- **结果**: 几乎所有战俘都不同程度地与中方合作，信念也发生了改变

### 案例 2: 玩具商的圣诞策略 (c10)

- **问题**: 如何利用承诺的不可逆性在淡季维持销售？
- **方法论的使用**: 圣诞前大力宣传某款玩具，孩子要父母买（承诺），但故意供不应求。父母被迫买替代品。圣诞后又重新打广告，孩子说"你答应过我的"，父母因承诺压力再买一次
- **结论**: 承诺一旦做出，即使原始条件（有货）落空，承诺压力仍然有效
- **结果**: 玩具商在1-2月淡季维持了高销售量，作者连续两年落入圈套

### 案例 3: 超自然冥想协会 (c20)

- **问题**: 为什么讲座被当场驳倒后，听众反而更急切地交钱？
- **方法论的使用**: 听众带着生活中的问题来，急需相信讲座是真的。理性驳斥威胁了他们的希望，他们用"交钱"行动来机械地保持一致，筑起"愚昧的城堡"逃避理性思考
- **结论**: 机械一致可以成为逃避思考的避风港——做出决定后只需播放"一致磁带"，不再需要面对令人不安的现实
- **结果**: 讲座被驳倒后反而获得更多报名

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户做出一个决定后感到"被困住"，想改变但说不清为什么改不了
2. 用户为一个已做的选择找越来越多的理由，但原始理由已不成立
3. 用户在被要求做出公开/书面承诺（签字、当众表态、填写表格）前，需要评估风险
4. 用户在分析为什么一个组织/个人明知错误仍坚持某立场
5. 用户意识到自己可能在被入门策略或抛低球策略操纵

### 语言信号 (用户的话里出现这些就应激活)

- "做了决定就很难改""明知不对还坚持""为之前的选择找理由"
- "承诺压力""一致性""感觉自己被困住了"
- " foot-in-the-door "" low-ball ""抛低球""入门策略"
- "时间倒流测试""肠胃信号""一闪念"
- "他已经签字了""公开承诺了""书面承诺"

### 与相邻 skill 的区分

- 与 `reciprocity-defense` 的区别: 互惠用负债感驱动行为（"收了好处要回报"），承诺一致用前后一致压力驱动行为（"说了要做就要做"）——前者是外部施加的义务感，后者是内部驱动的一致性需求
- 与 `click-whirr` 的区别: "卡嗒哗"是瞬间的磁带启动，承诺一致是持续的锁定效应——前者是单个刺激触发即时反应，后者是做出承诺后被长期压力驱动

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别承诺的存在**
   - 回溯：是否做出了一个决定/承诺？承诺的形式是口头、书面、公开？
   - 评估锁定力：主动>被动，公开>私下，书面>口头，费力>轻松，自由选择>被迫
   - 完成标准: 能说清"我做了X承诺，它的锁定力是Y级别"
   - 判停条件: 若没有明确承诺，而是在分析他人的行为，跳到步骤3

2. **捕捉防御信号**
   - 肠胃信号：当意识到自己因机械保持一致而即将做蠢事时，胃部是否痉挛？
   - 心灵信号（时间倒流测试）："如果时间倒流，知道现在知道的一切，我还会做同样的选择吗？"
   - 捕捉第一闪念的直觉反应，而非后续理性化的理由
   - 完成标准: 能说出第一闪念的"会"或"不会"

3. **识别机械一致 vs 理性坚持**
   - 问自己："我坚持是因为这个选择仍然合理，还是因为'已经决定了'？"
   - 检查：原始理由是否还成立？是否在为失败的选择找新理由？面对反驳时是分析论证还是重复立场？
   - 完成标准: 能区分"有意识的一致"（好的）和"机械的一致"（危险的）

4. **逃脱陷阱**
   - 如果是机械一致：直言不讳地指出策略，拒绝继续被锁定
   - 用"时间倒流"的答案作为行动依据：如果第一闪念是"不会"，则改变决定
   - 完成标准: 做出基于当前最佳判断的决定，而非基于过去的承诺

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 理性坚持——如果坚持基于持续的评估和证据更新，不是机械一致，不需要防御
- 意志力/自律分析——坚持好习惯是意志力，不是被一致性压力锁定
- 习惯养成——有意识重复形成的行为是习惯，不是承诺锁定

### 作者在书中警告的失败模式

- **机械一致作为逃避思考的避风港 (ce02)**: 当深入思考的结论令人不安时，人们用机械保持一致来逃避。做出决定后只需播放"一致磁带"，不再面对令人不安的现实。导致在错误决定上越陷越深。警告信号: 面对反驳时不是分析论证而是重复立场、急于做出决定以"结束不确定性"、做出决定后拒绝接收新信息
- **承诺"长出自己的腿" (ce03)**: 莎拉选择蒂姆后，即使导致选择的条件全部落空（蒂姆没戒酒、没结婚），她反而更忠诚——因为承诺创造了新理由。原始理由消失后新理由支撑继续承诺
- **外部压力削弱内在承诺 (ce07)**: 过强的威胁或过大的奖励给行为提供了"外在解释"，阻止内在归因。行为只在监督下发生，外部压力消失后行为也消失

### 作者的盲点 / 时代局限

- 一致原理在社交媒体时代更加放大——公开承诺（发帖、表态）的固化效果远超书中描述的签字
- 沉没成本效应与承诺一致性高度重叠，但作者未建立与行为经济学文献的关联
- 对"改变立场是智慧而非软弱"的文化差异讨论不足

### 容易混淆的邻近方法论

- **入门策略 (foot-in-the-door)**: 利用承诺一致的策略——从小承诺开始改变自我形象。本 skill 包含但不止于此
- **抛低球 (low-ball)**: 利用承诺一致的策略——给好条件诱使承诺再拿走。本 skill 包含防御方法
