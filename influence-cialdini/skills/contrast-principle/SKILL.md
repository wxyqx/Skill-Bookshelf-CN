# 认知对比原理

## R — 原文 (Reading)

> "如果两件东西很不一样，我们会趋向于认为它们之间的差别比实际的更大。"
>
> — Cialdini, 第一章 · 影响的武器

---

## I — 方法论骨架 (Interpretation)

先后接触的两件事物会被感知为差异比实际更大。这不是简单的"有比较才有差异"——主观感知的差异被系统性放大了：先看贵的再看便宜的，后者显得更便宜；先提大请求再提小请求，后者显得更无足轻重。

这个原理本身是中性的感知机制，但关键在于：接触顺序可以被刻意安排。依从从业者通过控制你"先看到什么"来操纵你对"后看到的东西"的判断。先呈现的东西是"锚"，它不改变后者的客观属性，但改变了你对后者的主观感知。

防御的关键不是"不做比较"（不可能），而是识别"前一件东西"是否被刻意安排——如果是，就需要脱离锚定物独立评估。

## A1 — 书中的应用 (Past Application)

### 案例 1: 童子军巧克力推销 (c07)

- **问题**: 作者为什么会买下自己完全不喜欢、不需要的巧克力？
- **方法论的使用**: 童子军先推销5元门票被拒（大请求/锚），退到1元巧克力（小请求/目标）。对比原理使巧克力显得"不过一元钱而已"
- **结论**: 对比原理使小请求在对比下显得更无足轻重，叠加互惠原理（对方"让步"了）共同驱动了购买
- **结果**: 作者购买了毫无兴趣的巧克力

### 案例 2: 水门事件决策 (c08)

- **问题**: 为什么米切尔和马格拉德会批准一个荒唐的闯入计划？
- **方法论的使用**: 利迪先后提出100万、50万、25万三个计划。前两个被否决后，25万在对比下显得"可以接受"。唯一未参加前两次会议的拉如反对——他未被锚定
- **结论**: 对比原理在重大政治决策中同样有效。未被锚定的人（拉如）能看清计划的荒谬，被锚定的人则因对比而接受
- **结果**: 导致了尼克松总统下台的政治灾难

### 案例 3: 好警察/坏警察 (f11引用)

- **问题**: 为什么好警察的策略有效？
- **方法论的使用**: 坏警察制造恐惧和敌意（锚），好警察随后表现友善。对比原理保证好警察显得通情达理
- **结论**: 坏→好的对比放大了好警察的吸引力，叠加互惠原理（好警察帮忙说话/买咖啡）形成负债感
- **结果**: 多原理叠加使嫌疑犯更可能与好警察合作

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在购物/投资后发现"当时觉得很划算，现在想想没那么好"，怀疑被对比操纵
2. 用户面临一个决策，之前刚接触了另一个极端选项，需要判断当前选择是否被锚定
3. 用户在谈判/销售场景中，对方先展示了一个极端方案再"让步"
4. 用户在分析为什么一个商品在特定陈列方式下销量异常

### 语言信号 (用户的话里出现这些就应激活)

- "先看了X再看Y就觉得Y特别好/便宜"
- "对比之下觉得划算""先贵后便宜""锚定效应"
- "他先报了个高价再打折""先提大要求再退让"
- " contrast effect ""认知对比""感知差异被放大"

### 与相邻 skill 的区分

- 与 `rejection-retreat` 的区别: 拒绝退让是利用对比原理的具体策略（先大后小），本 skill 解释底层感知机制——对比原理是引擎，拒绝退让是装了引擎的车
- 与 `click-whirr` 的区别: "卡嗒哗"是所有自动反应的元框架，认知对比是具体的增强机制——对比原理本身有自己的触发条件和防御策略

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别锚定物**
   - 回溯：在做当前判断之前，刚接触了什么？
   - 完成标准: 能说出"我之前看了/听了X，它可能是锚"

2. **评估放大效应**
   - 问自己："如果不是先接触了X，我对Y的评价会一样吗？"
   - 尝试脱离锚定物独立评估Y的客观属性（价格、质量、合理性）
   - 完成标准: 能说出至少一个不依赖与X对比的独立评价理由
   - 判停条件: 若脱离锚定物后评价不变，说明锚未生效，无需继续

3. **重置参照系**
   - 用自己的基准（而非对方安排的锚）重新评估
   - 如果是价格：查市场均价；如果是请求：问"如果没有人先提过大请求，这个请求合理吗？"
   - 完成标准: 形成一个基于独立参照系的判断

4. **记录锚定模式**
   - 记录对方使用了什么锚（极端价格、极端请求、极端案例）
   - 完成标准: 形成"当出现X类锚时，脱离对比独立评估"的规则

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯价格比较（如比较两个商品的性价比）——这是理性比较，不是感知被放大
- 无参照物场景——对比原理需要"先后两件事物"，如果只有一个事物不存在对比
- 个体偏好差异（如有人天生喜欢甜的）——这是稳定偏好，不是情境触发的感知放大

### 作者在书中警告的失败模式

- **对比原理是多种依从策略的增强引擎**: 拒绝退让、好警察坏警察、先展示贵品再展示目标品等策略都依赖对比原理。如果只看到表面策略而未识别底层的对比机制，会防不胜防
- **"昂贵=优质"公式的误判 (ce10)**: 价格作为启动特征触发自动反应，认知对比使"先贵的→后便宜的"显得更便宜——两者叠加使操纵效果倍增

### 作者的盲点 / 时代局限

- 对比原理的效应量因人而异（经验丰富的消费者更难被锚定），书中未充分讨论个体差异
- 与行为经济学的锚定效应（anchoring effect, Tversky & Kahneman）高度相关，但作者未建立与认知科学文献的关联

### 容易混淆的邻近方法论

- **锚定效应 (行为经济学)**: 高度相关但有区别——锚定效应是数字估计中的偏差，认知对比是感知差异的放大。在实践层面可合并理解
- **拒绝退让策略**: 是对比原理的具体应用，不是独立感知机制
