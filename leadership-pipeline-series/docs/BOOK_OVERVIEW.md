## 1. 结构 (Structural)

### 类型
**"诊断—处方"型管理方法论的丛书合集**，五个分册分别占据同一问题的五个侧面：为什么目标落空（册1）、每层该交什么（册2）、用什么语言谈生意（册3）、人才从哪来（册4）、领导者为什么在升职后失败（册5）。文体均为**咨询顾问知识**的典型体裁：以客户案例与一致经验（"我们发现……"）代替统计证据，没有文献综述、没有对照组研究。五册共享高度一致的世界观（大型分权公司、逐级历练、内部培养），作者群高度重叠（查兰出现于全部五册；德罗特出现于册2、册5；两册是明确的姊妹篇）。

### 一句话主旨（系列级）
公司的成败很大程度上取决于它能否**成批量、可预见地从内部培养出各层级领导者**——为此需要：把"每个层级该做什么"（六阶段×三维度，册5）与"每层该交出什么业绩"（业绩梯队，册2）定义清楚，让选拔、培养、评价、继任全部对齐到同一套层级标准；用轮岗实践而非课堂来生产人才（册4）；用一门通用的商业语言让全员看懂公司如何赚钱（册3）；并由领导者亲自把人员、战略、运营三条流程咬合成一套执行系统（册1）。

### 五册各自的一句话主旨
1. **册1《执行》**：执行不是战术细节，而是"目标与结果之间的桥梁"——一套把人员、战略、运营三大流程紧密结合、由领导者亲自实践的系统学问；不掌握执行的领导层不完整，不建立执行文化的企业必然出现战略与结果之间的鸿沟。
2. **册2《业绩梯队》**：组织必须为**每一个领导层级**定义"独特的存在目的＋可衡量的业绩标准＋向下级传递的关键结果"，让每层领导在自己的层级交付正确的结果（而不是回到上一层级的工作），企业才能在不确定环境中持续实现业绩。
3. **册3《CEO说》**：一切生意（从街头小贩到《财富》500 强）都遵循同一套通用商业语言——现金净流入、利润、周转率、资产收益率、业务增长、顾客，加上知人善任与沟通机制；任何人掌握这套语言就能看清公司如何真正赚钱，并像 CEO 一样思考和行动。
4. **册4《高管路径》**：领导力只能在实践中培养：尽早识别少数真正具有领导潜质的人（驭人之道×经商之道的双螺旋），为他们量身定制"广度与难度递增"的岗位轮换路径（同心圆学习），由上级领导充当导师给予精心反馈，并以制度化流程替代听天由命的运气式晋升。
5. **册5《领导梯队》**：从员工到 CEO 要穿越**六个领导力发展阶段**，每次晋升都不是头衔变化而是**领导技能、时间管理、工作理念三个维度的整体转型**；任何维度滞后都会造成"在错误层级工作"并沿梯队向下挤压，阻塞整条管道——公司可以通过明确各层要求、按层级设立绩效标准、系统化继任与教练辅导，把领导人才培养变成可预见、可管理的流程。

### 骨架（系列级论点及其关系）

1. **层级差异论（总纲，册5）**：领导力是分阶段的；相邻层级要求"总体相近、具体差别重大"；六个阶段＝管理自我→管理他人→管理经理人员→管理职能部门→管理事业部→管理业务群组→管理全集团；每次转型必须在技能/时间/理念三维度同步完成，理念是枢纽。（册5 导论、第1–7章）
2. **业绩/能力双契约（册2 与册5 合并主线）**：同一套七层级，两种语言——册5 回答"每层需要什么能力（转型）"，册2 回答"每层交付什么结果（业绩）"；两书互为姊妹篇（德罗特为共同作者）。层间以"向下传递的关键结果"相连，无漏接、无重叠。（册2 导论–第9章 + 册5 第9–10章）
3. **执行系统论（册1）**：执行 = 三基石（领导者行为、文化、知人善任）支撑三流程（人员、战略、运营）；三流程必须由领导者亲自运营并在彼此间建立联系；执行能力是战略的前提。（册1 第1–9章）
4. **商业语言论（册3）**：跨行业存在六要素通用语言（R=M×V 为核心工具）；化繁为简的路径＝内外部因素→关系趋势→公司基本行为→3~4 项优先事项；商业智慧必须与人员判断相乘（执行＝商业智慧×人员判断）。（册3 第1–9章）
5. **人才生产论（册4）**：领导力只能在工作实践中培养；人才能被"生产"而非等运气——识别（双螺旋）→量身定制路径（同心圆/以人定岗）→导师反馈（持续强化练习）→制度化评估与选拔（集体讨论/8 阶段 CEO 选拔）。（册4 第1–8章及附录）
6. **制度化论（册2/册5 共同）**：把上述各论变成与财务体系同等严谨的机制——绩效标准、继任审核、九格矩阵、年度评估会、董事会参与、60~90 天行动计划。（册2 第10–11章 + 册5 第8–14章）
7. **边界论（五册共同但深浅不一）**：模型必须按组织规模、层级数、术语定制，严禁机械照搬（册5 p28；册2 f03 六步含"留灵活性"；册4"以人定岗"处理个体差异）。（各册末章/附录）

**论点之间的关系**：册5 立总纲（层级差异＋三维度转型），册2 从业绩侧补齐同一体系的另一半；册4 解决"人从哪来"（供给侧的方法）；册3 提供全员沟通的底层语言；册1 把一切拉回"结果"（执行系统）。整体是"总纲—双契约—生产—语言—执行"的**立体互补**结构，而非单线递进。

### 作者要解决的核心问题
**为什么企业投入大量资源（招聘、培训、继任、战略、预算）却持续缺人才、缺业绩、缺执行？** 五册各给出一个侧面答案：缺的是把"每个层级的角色要求"定义清楚并对齐所有系统的方法（册5/册2）；缺的是把领导力生产当成系统工程而非运气（册4）；缺的是全员共享的商业语言（册3）；缺的是领导者亲自驱动的执行系统（册1）。合起来是一个判断：**问题不在个别领导者的能力，而在组织没有建立起"领导力驱动的操作系统"**。

## 2. 解释 (Interpretive)

### 关键术语（系列合并版 · 精选 24 条，完整词典见 candidates/glossary.md）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 领导梯队模型（leadership pipeline） | 六个发展阶段 × 各层级三维度（技能/时间/理念）要求构成的组织框架，同时用于选拔、培养、评价、诊断与继任（册5） | ≠ 人才梯队名单/储备库；重点在"每层角色要求不同"而非"有多少后备" |
| 领导技能 / 时间管理 / 工作理念 | 新职务所需的新能力 / 新的时间分配结构（决定如何工作）/ "什么重要、什么该放弃"的信念（册5） | 常识把"时间管理"当效率技巧；作者用它定义角色（日程表是最硬的角色证据），且主张理念先于技能 |
| 管理自我→管理全集团（六阶段） | 六个职业转折点：个人贡献者→一线经理→部门总监→事业部副总经理/职能主管→事业部总经理→集团高管→CEO（册5） | ≠ 头衔变化；"不可能通过读一本书或几天培训学会"；阶段数可按公司规模调整为 5 或 7 |
| 业绩梯队（performance pipeline） | 纵向的"业绩契约"：每层独特目的＋特定业绩＋向下传递的关键结果（册2） | ≠ 领导梯队（能力转型）≠ KPI 体系（横向分解）；是纵向层间的业绩定义 |
| 全面业绩 vs 卓越业绩 | 全面＝在该层级充分履职（称职线）；卓越＝远超期望＋同事标杆＋（可能）部分相关的完全创新（册2） | ≠ 超额完成即卓越、排名第一即卓越；并非每项业绩都需要卓越线 |
| 工作价值观（册2）/ 工作理念（册5） | 该层级"把时间与注意力投向哪里、以什么为交付物"的取向；升职不转价值观即错位 | ≠ 企业价值观（诚信、客户尊重）；是层级特异的工作取向 |
| 绩效缺口 / 全面绩效 | 晋升必然造成七项绩效内容的缺口，须在就任初开始弥补，培养持续到全面绩效为止（册5） | ≠ 能力不足的贬义标签；是**结构性必然** |
| 继任计划（新定义） | "在领导梯队中培养各级高绩效人员，以保证每个领导层级现在和将来都有足够的高绩效者"（册5） | ≠ 给某岗位找接班人，≠ 人才库；覆盖到入职级别，90% 时间用于内部选拔 |
| 潜能三分类（转型/成长/熟练） | 潜能＝将来能完成的工作：3–5 年能承担下一层级/同层更重要工作/在现职持续增强（册5） | ≠ "高潜/非高潜"二分；反对把潜能等同于表现；需至少每半年复核 |
| 九格矩阵 / 领导培训矩阵 | 绩效（卓越/全面/非全面）×潜能（转型/成长/熟练）九格，每格规定行动（册5） | 常识把它当盘点工具；作者警告"只是面粉而非蛋糕"——没有标准与证据就是直觉冒充分析 |
| 轮岗培养模式（apprenticeship model） | 通过岗位轮换"从干中学"：岗位锻炼＋领导反馈＋自我修正＋重复实践，为每人量身定制路径（册4） | ≠ 传统轮岗（换岗本身）；强调挑战递增、反馈闭环、掌握必备技能后才换岗 |
| 同心圆学习（concentric learning） | 圆心＝个人禀赋，外圈＝广度/难度递增的岗位序列；在现岗脱颖而出才进入下一圈（册4） | ≠ 职业阶梯（按资历升级）；是"能力—岗位"匹配式进阶 |
| 持续强化练习（deliberate practice） | 反复实践＋高人及时反馈＋自我修正；改变大脑处理信息方式，把思考固化为直觉（册4，借自 Ericsson） | ≠ 单纯重复；核心是"反馈＋改进"闭环（作者对领导力的跨域外推未经验证） |
| 双螺旋领导潜质 | 驭人之道（激励团结、知人善任、果断指导、处理害群之马、建立人脉）× 经商之道（懂赚钱与财务稳健、直觉与果断），两者缺一不可（册4） | ≠ 最聪明/业绩最好者；明确反对"看起来像领导"的选拔标准；20 多岁显现、极难后天补足 |
| 以人定岗 | 先考察人才的成长需要与能力缺口，再选择/创造适合的岗位（册4） | 与"职位空缺→选人"相反；岗位可以为培养而调整（须做风险评估，防弗兰克式失败） |
| 商业智慧（business acumen） | 把公司看作整体、用六要素判断赚钱逻辑并用通用语言表达的能力（册3） | ≠ 学历/智商/MBA；"街头小贩=CEO"的普适化主张 |
| 现金净流入 | 一段时间内现金流入与流出之差；"公司的氧气"（册3） | ≠ 利润/收入（赊销造成时间差）；且"人人都要重视现金"而非只是财务部门 |
| R=M×V（资产收益率＝利润率×周转率） | 用你的资产赚钱的效率比率，两条腿乘出收益率；ROA/ROI/ROE 只是分母不同（册3） | ≠ "赚了多少钱"的绝对额；可跨公司比较（好公司税后>10% 且高于资本成本率），且只需粗算 |
| 优先事项（重点工作） | 特定时间段最重要的行动：3~4 项（≤5）、不频繁变化、须反复强调并与盈利目标挂钩（册3） | ≠ 愿景口号；要求"聚焦到 5 万英尺以下"、可衡量、可协同 |
| 社会化沟通执行机制 | 为交换信息、协同行动而设计的信息节奏：即时同步、非正式、零过滤、高频、无边界（册3） | ≠ 例会制度；是被"设计"的、由领导人亲自主持的机制（"不是人力资源部的任务"） |
| 执行（Execution） | 一整套行为和技术＋三大流程的整合系统，"目标与结果之间的桥梁"（册1） | ≠ 战术、≠ 关注细节、≠ 一次性运动；必须渗透进回报系统与行为准则 |
| 社会软件（Social Software） | 价值观、信念、行为规范等"使硬件系统得以运营"的组织软件（册1） | ≠ IT 系统/社交工具；与组织结构、薪酬、报表（硬件）相对 |
| 情感强度（Emotional Fortitude） | 真诚、自我觉察、自我控制、谦虚四特质；"敢不敢做艰难决策"的底座（册1） | ≠ 脾气强硬/冷酷无情（书中以邓洛普为反例） |
| 知人善任 | 岗位标准定义→面试核验→基于事实的评估→梯队培养→处理不胜任者的系统（册1） | ≠ 招到好人（一次性动作）；是领导者亲力亲为、必须喜爱的工作 |
| MEALER 模型 | 层级过渡的顺序敏感机制：意义→动力→行动→学习→根植→重新振作（册2） | ≠ 培训课程表；后步依赖前步（神经科学包装薄弱，使用需声明） |

### 核心命题（系列合并版，用自己的话）

1. 领导力是分阶段的；不同管理层级需要不同的能力组合，不存在一把通用的"领导力尺子"。（册5）
2. 晋升的默认假设——"干得好就会干得更好"——是错的；相邻层级要求总体相近、具体差别重大。（册5）
3. 几乎所有组织都存在"把人员配置在错误层级"的问题，且高频发生在一线经理、事业部总经理、集团高管三层。（册5）
4. 工作理念（什么重要、什么该放弃）是转型枢纽：理念不转，技能与时间只会被用来服务旧角色。（册5）
5. 领导者在错误层级工作会造成向下挤压的连锁反应，把整个梯队逐级阻塞。（册5）
6. 每个层级的存在目的与应有业绩必须被显式定义，否则领导力发展会被用在错误的工作上。（册2）
7. 领导者最大的普世错误是越俎代庖：做下级该做的事，导致业绩沿层级下推、无人谋划未来。（册2）
8. 层级过渡是重大业务问题而非 HR 事务；应像服务重要客户一样设计过渡（MEALER 顺序不可跳步）。（册2）
9. 领导力只能在实践中培养；课堂与阅读只能加速，不能替代历练。（册4）
10. 真正的领导潜质是驭人之道×经商之道的双螺旋，属于少数人；培养资源应集中而不撒胡椒面。（册4）
11. 成长速度取决于反馈质量：上级导师的及时、直接、具体反馈是最强的加速器；培养人才是每位现任领导的职责并须考核。（册4）
12. 一切生意共享一门通用商业语言（六要素）；跨职能、跨层级沟通失败多因缺共同语言，而非人坏。（册3）
13. 不产出现金的利润是脆弱的；增长必须赢利、可持续，并伴随利润率与周转率的改善。（册3）
14. 化繁为简是领导者的核心智力工作：把复杂性压缩为 3~4 项优先事项，并反复向下对齐。（册3）
15. 执行是领导者的主要工作，不能外包；执行能力是战略的前提而非结果。（册1）
16. 人员、战略、运营三条流程必须由领导者亲自运营并在彼此间建立联系，任何一环脱节都形成鸿沟。（册1）
17. 奖励必须与业绩（含行为方式）透明挂钩；"完成任务的方式"与"是否完成"同等重要。（册1）
18. 文化变革的杠杆是行为与结果（目标→条件→奖励→教练/处置），不是标语和问卷。（册1）
19. 人才问题的代价可被制度化管理：继任覆盖全员层级、90% 内部选拔、绩效准入、持续流动。（册2+册5 合并命题）
20. 所有模型必须按组织实际定制（层级数、术语、标准本地化），机械照搬会把框架变成教条。（册2/册5）

### 论证链（系列合并版）

五册的论证同构，均为"**现象→归因→框架→案例验证→操作化**"，且共享同一批证据源与世界观：

1. **现象起点**（各册第1章）：公司无法兑现承诺/业绩不达标且人才断档/职能竖井各说各话/接班人危机/高管失败频发。
2. **归因**：册1→"执行"从未被当作学问；册2→各层业绩未被定义＋纵向架构问题；册3→缺共同商业语言；册4→培养靠运气；册5→"能做好当前岗位就能做好下一个"的错误假设（彼得原理的组织版本）。
3. **框架**：三基石三流程（册1）｜七层业绩契约（册2）｜六要素＋两基础（册3）｜轮岗培养四要件（册4）｜六阶段×三维度（册5）。
4. **案例验证**：以作者咨询过的公司为主——联信/EDS/霍尼韦尔/施乐/朗讯/AT&T（册1）；戴比尔斯/运输公司/C公司等（册2）；福特/捷威/戴尔/沃尔玛/可口可乐（册3）；高露洁/德事隆/GE/诺华（册4）；万豪/花旗/GE/约30 个高管故事（册5）。
5. **操作化**：评估会议、预算程序、诊断五步、绩效圆圈、继任五步、九格矩阵、8 阶段 CEO 选拔、60~90 天行动计划等工具集。
6. **一般化与边界**：模型可按规模调层级、按行业调术语（各册末章"常见问题/一线观察"主动声明边界）。

**证据类型与质量**：全部五册以**作者亲历咨询案例 ＋ 一致经验（"我们发现……"）** 为主，辅以少量外部引用（Ericsson 刻意练习研究、科尔尼调查、德鲁克/韦尔奇引语、《财富》统计），**没有任何统计对照、失败样本系统分析或预测效度检验**。这是"咨询顾问知识"的典型体裁——可操作性强、可证伪性弱（见批判节）。

## 3. 批判 (Critical) ★

### 系列级时代局限（跨册共同盲点之一）
- **成书窗口 2001–2011，美元大公司语境**：册1 写于安然/世通丑闻后、季度资本主义最盛期（"以季度为单位评价执行业绩""管理 P-E 值、满足每股收益预期"被当作正面实务）；册3 把 GE 当"赚钱机器"模范（GE 2018 年跌出道指、2021 年拆分即后来反证）；册5 把电子商务当作最大变量（对数字化/AI 对管理幅度、远程领导、算法管理、知识工作者自组织的根本改变没有预见）；册2/册4 则以 2008 年金融危机与"25 年培养周期、5 个岗位、45~50 岁任 CEO"的稳态大公司节律为背景，与技术迭代加速、职业流动性高的今天存在张力。
- **科层制预设**：册5 明言六阶段是"大型的、分权管理的公司"的"天然工作层级"，以 GE 为原型；册2 的服务对象是 GE 式大型多层级公司。对扁平化、平台型、项目制/矩阵制组织，六阶段是否还存在、以什么形态存在，作者只在"柔性模型"一节给出 5 层微调讨论，**没有正面处理"中层消失"与敏捷/自治团队的挑战**。此后十年扁平化、敏捷化、平台化与 OKR 实践构成对"强化层级清晰"的反向证据流。
- **强制排名类工具的时代争议**：册1 引用韦尔奇式活力曲线（A/B/C 分级）与相对排名；GE 自身在 2015 年后放弃强制排名，"评选公正"的限定条件在真实组织极难满足。此类内容在 skill 化时必须携带负向 Boundary。
- **多元与全球化视角缺失**：案例几乎全为美国白人男性高管；册5 全书只在万豪案例提到一次女性领导会议；册4 对"全球流动"以"能搬迁的人"为默认培养对象；对日本论资排辈等非西方实践只作"需要克服的文化障碍"处理；中国/新兴市场仅在再版序被提及（中文版推荐序对国资委语境的对接与书中"公开评估、让不胜任者离开、按业绩排名"等做法存在未解决的本地化张力）。

### 系列级立场盲点（跨册共同盲点之二：美国大公司案例偏差）
- **咨询顾问的样本与利益**：五册作者均为模型的设计者、培训者与销售者（Drotter Human Resources 以业绩梯队为核心产品；查兰以 CEO 顾问身份贯穿全系列）；所有"我们发现""我们观察到"无法核验，成功案例（万豪、GE、高露洁、德事隆）由他们自己参与背书，**缺少实施失败的企业与对照组**，存在系统的选择偏差。
- **幸存者偏差与因果倒置**：样本是"人才培养得好且商业成功"的公司，无法区分"体系带来成功"与"成功公司有资源投资体系"；失败者"输在三维度未转型"没有对照（无法排除战略误判、市场恶化等解释）；册1 的成功样板（联信、EDS、戴尔）在后续十年各有起伏甚至困境。
- **单因论倾向**：册1 把复杂组织失败压缩为"没执行"、册5 压缩为"层级错位"、册4 压缩为"潜质识别与培养"，都便于推销自家框架；对**组织政治、股权结构、董事会约束、行业周期、运气**等结构性变量处理很薄（册5 提到薪酬制度不匹配但未展开；册1 的"领导者有勇气就能解决"忽略了治理制约）。
- **权力与人的复杂性被简化**：册5 最后一句话提醒"不要机械运用……时刻提醒自己人的复杂性"，但正文用极简三维度给每层下定义，实操极易退化为贴标签（作者自己警告九格矩阵被直觉化滥用，说明风险真实）；册4 的精英二分法（"只有少部分人真有潜质"）对被排除的大多数的士气与公平路径几乎未作讨论；各册对"人的多样性"（性别、文化、家庭约束）系统性缺席。
- **责任归属的个人化**：册2 的"个人管理七动作"、册4 的"个人对自己的成长负最终责任"、册5 的"领导者要主动界定自己的工作"，在制度失败时存在把系统性风险转嫁给个体的倾向。

### 未被证明的假设（跨册共同盲点之三：模型的经验主义基础）
1. **"六个阶段是天然的"**（册5）：这是修辞而非发现；亚马逊式扁平化、华为式矩阵、平台型公司并不按此分层。
2. **领导力可完全由岗位层级解释**：模型假设失败主因是"人在错层"，忽略个人天赋、行业周期、市场突变等不可控因素；对"哪些阶段可以跳"的唯一判据是"是否在更高层失败"——事后归因，不可证伪。
3. **工作理念可以被训练**：反复主张"理念转变是最关键的第一步"，但除四条行为证据（教训讨论/日程表/如何评价下属/计划立场）外，缺少可操作的心理测量支持。
4. **潜能三分类＋三年绩效的判断标准**（册5）没有任何效度证据；**"领导潜质 20 多岁基本成形、极难培养"**（册4）是全书枢纽断言但缺乏可检验定义与预测效度证据，且存在循环论证风险（判据本身可能就是"已在岗位上表现出色"）。
5. **同心圆学习＋持续强化练习的机制解释**：把 Ericsson 关于专业技能的结论外推到"领导力与判断力"，跨域类推未经验证；MEALER 的神经科学包装（理性/感性双系统＋六个功能网络）属于流行通俗神经科学，六阶段与大脑网络的一一对应无实证引用、不可证伪。
6. **"定义业绩/定义职责"是万能钥匙**：业绩标准写得清楚并不自动带来业绩；标准在复杂环境中会被博弈（书中只在"证据与情景分析"处轻描淡写）。
7. **"内部培养优于外部引进"**：对空降兵的批评与对内部体系的推崇不对称；什么条件下必须外部寻找只给案例（扭亏/重塑形象/文化变革/战略转型）未给判据体系；90% 内部选拔准则的例外只有一条。
8. **"集体讨论能消除偏见"**（册4）：把"背后议论公开化"视为优点，但未讨论被评估者的知情权、程序公正与评估者群体偏差（同质化、政治联盟）。
9. **"顾客公平交易→忠诚→持续收入"的自动链条**（册3）：缺乏对定价权、竞争结构、技术替代的讨论；六要素对平台型/软件型/研发驱动型业务（边际成本近零、网络效应、烧钱换市场）并不直接适用。
10. **文化可以被会议日历＋奖惩机制"设计"出来**（册1）：社会工程式假设，未讨论自组织与涌现；"结构化会议文化＋强 KPI"在知识密集型/创意型组织中可能适得其反（2010 年代敏捷与心理安全研究提供了相反证据）。

### 最强反对意见（若要反驳整个系列）
1. **不可证伪的整体**："执行不力""层级错位""理念未转型"可以解释一切失败却不冒被推翻的风险；"凡是失败都是 X"的诊断在逻辑上不可反驳，等于把所有组织问题收进一个不可检验的筐。
2. **层级本身可能是问题**：信息衰减、决策变慢、责任稀释——与其把每层业绩写得更好，不如减少层数、让团队自治；领导梯队可能把过时的科层结构"合法化"并延长寿命。若团队自组织成为主流，"管理经理人员""管理职能部门"两个层级可能根本不存在，模型退化为"任何层级都有其独特要求"的空泛主张。
3. **筛选主义的人力代价**：把资源向少数"高潜"集中，会自我实现地制造"胜者—陪跑者"结构；误判（漏掉大器晚成者、押错早慧者）的代价被系统性低估；知识工作者越专业越不接受"通过他人完成任务"作为唯一成功定义（书中"超级销售员/技术轨迹"只是补丁，未进入模型内核）。
4. **可执行性依赖组织政治**：绩效标准、继任审核、教练辅导都要求上司放弃控制、坦诚反馈，而作者自己承认"错位已经成为一种沾沾自喜的文化"——模型最需要的前提（组织的坦诚与自律）恰恰最难满足。
5. **因果方向可疑**：观察到"失败者带着上一层级的做事方式"就断定"未转型导致失败"；也可能是"失败导致其退回熟悉的行为"。模型无法区分。
6. **治理与伦理边界被轻描淡写**：让表现尚可但"没有潜力"的现任让位、落选者留给新 CEO 处理、为培养增设岗位层级、以"年龄/还有几年退休"作选拔理由——这些操作的劳动法、程序公正、年龄歧视与治理合规风险，书中均只提示"如何尊重地做"而未讨论可申诉机制与合规底线（本系列相关反例已带 ethics_legal_note/risk_note，见 candidates/counter-examples.md，供阶段 2 的 B 段使用）。中文语境下另有国企干部管理、劳动关系与"公开评估/按业绩排名"的本地化落差。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**：①凡涉及层级判断的 skill 必须声明"不能据此对个人做标签化评判，须先排除组织因素（薪酬、职责、资源、上司）"；②凡涉及解雇/降职/让位/落选者处理的 skill 必须声明"不构成人力资源法律意见，须依当地劳动法与公司程序执行，并提供转岗/改进机会与尊重程序"；③凡涉及 P-E 值/预期管理的 skill 必须声明"不得建议任何形式的数字操纵，估值沟通须符合证券法规与信息披露规则"；④凡涉及 MEALER/持续强化练习的 skill 必须声明"神经科学包装无实证支撑，只保留操作步骤"；⑤凡涉及潜质/潜能评估的 skill 必须声明"判断标准缺乏预测效度证据，且须防标签固化造成事实上的歧视"；⑥涉及中国/非美国语境的用户，须先提示模型的美国大公司科层语境。

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容
经阶段 1.5 三重验证，**59 个 skill 单元**进入阶段 2（框架 51 + 原则 8；完整名单与逐条判定见 `verified.md`）。按主题归并：

- **体系总纲类（册5）**：六阶段模型、三维度转型、初任经理三项转型、部门总监四项技能、职能成熟度、事业部总经理协同三角形、集团高管间接成功、CEO 五项挑战、个体/组织诊断、明确职责三步、绩效圆圈、继任五步、潜能三分类、九格矩阵、双轨发展、定制化原则。
- **业绩维度类（册2）**：建队六步骤、工作本质双因素、控制三时点、事业部副总四项业绩、大环境三变量、MEALER、业绩讨论证据法。
- **执行系统类（册1）**：执行架构、追问到现实、深入一线、文化绩效联结、MRR 评估会、分层处置、基石式战略、战略评估问题框架、运营三步、前提假设、跟进纪律。
- **商业语言类（册3）**：六要素、R=M×V、现金视角、顾客直接接触、化繁为简、优先事项、P-E 机制、全景七问、教练双轨、社会化沟通、增长纪律、不下注即赌博。
- **人才生产类（册4）**：轮岗培养模式、同心圆/以人定岗、持续强化练习、双螺旋、CEO 选拔治理、宽容失败、育人职责、评估双轨、领导是工作而非荣誉。

### 不适合 skill 化的内容
- 具体公司案例的细节与数据（作为 example/A1 素材保留，操作细节无法脱离语境复用）；
- "管理 P-E 值/满足季度预期"的资本市场操作（时代局限＋合规风险，只作 Boundary 素材）；
- 涉及具体人事处置的话题（解雇、降职、让位、落选者处理）——只进 Boundary 警示，不做成自动建议流程；
- 2000 年代语境的"电子商务挑战"清单、1999–2000 年公司数据、美国式绩效排名体系——历史语境引用；
- MEALER 的神经科学论证部分（只保留操作步骤，须标注"科学基础薄弱"）；
