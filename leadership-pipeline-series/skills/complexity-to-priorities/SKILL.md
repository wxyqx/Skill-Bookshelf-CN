# 化繁为简的决策路径（因素→关系→基本行为→优先事项）

## R — 原文 (Reading)

> "企业家可以运用自己的商业智慧将商业挑战看成是一道智力难题。首先，要考虑那些随时变化的内部因素和外部因素。……要从总体上考虑这些因素是怎样联系在一起的，然后考虑公司的基本行为。对于既定的模式和趋势，要思考这些与赢利相关的公司的基本行为是怎样运作的……从而将公司变成一个赚钱机器。"
>
> — 查兰，第4章（L6687）

> "不能仅仅凭借臆想来预测一个新市场的开发或者新需求的产生。毕竟，未来是从已有的世界中产生的。"
>
> — 查兰，第4章（L6660）

> "列出的外部影响因素越多，情况也就越复杂。……需要先搞清楚其中哪些因素是重要的。其中是否有一些是相互关联的？是否存在某种趋势？不要以为这很容易。你需要练习才能突破这种复杂性，而且你可能得不到所需的一切信息，因此还需要去调查。"
>
> — 查兰，第9章（L7228）

---

## I — 方法论骨架 (Interpretation)

商业现实天生复杂，作者的处理方式不是回避复杂，而是给出一条固定的压缩程序——"把商业挑战当成一道智力难题"：

1. **第一步：把因素摊开**。列出所有影响赢利的内部与外部因素（利率、汇率、市场趋势、政府法规、产能、行业整合、价格竞争、新对手、电商……），每个因素都写现状与对未来的预测。先求全，不求精。
2. **第二步：找关系、辨趋势**。因素不是孤立清单，要标出哪些相互关联、哪些形成趋势、哪些不重要可以丢掉。产出是少数几条"重要模式/趋势"，而不是一堆并列条目。
3. **第三步：落到公司的基本行为**。在既定趋势下问：六要素（现金净流入、利润、周转率、资产收益率、业务增长、顾客）会怎么被影响？哪个业务/产品线受损、哪个受益？这一步把外部现实翻译成自家生意的因果。
4. **第四步：定优先事项**。据此前推 3~4 项优先事项（并可交给 `b3-f07` 做数量与稳定性纪律），同时写明"必须停止做什么"。
5. **两条硬约束**：①未来从已有世界产生——不能用臆想预测全新市场（苹果案例的教训是种子早已播下）；②单一动作（如"直接涨价"）多半是绕过分析的选择，四步顺序不能跳。

## A1 — 书中的应用 (Past Application)

### 案例 1：韦尔奇出售 GE 航空业务
- **问题**：1989 年前后外部环境剧变——冷战结束、苏联解体、柏林墙倒塌，各国国防预算大减、国防工业萧条；GE 的航空业务何去何从？
- **方法论的使用**：先识别外部变化（国防需求萎缩、行业将整合），再用公司基本行为检验：业务增长、资产收益率和现金净流入不能满足投资者的需要；据此判断最好的选择是将航空业务出售，并选择可能成为行业垄断者的马丁·玛丽埃塔作为买家。
- **结论**：不满足收益率与增长要求的业务就退出，且把资产卖给行业整合者（与"数一数二"原则同源）。
- **结果**：GE 以现金加股份的形式出售航空业务；马丁·玛丽埃塔后发展为洛克希德·马丁，GE 在其股价高攀时出售股份获利颇丰（第4章，L6691–L6693，案例 b3-c21）。

### 案例 2：纳塞尔判断"汽车价格将持续下降"
- **问题**：1997 年掌管福特汽车集团的纳塞尔通过分析得出结论：汽车价格将持续下降，普遍的价格上涨不会持续。
- **方法论的使用**：从价格趋势（外部因素）推到基本行为——毛利、业务增长、现金；再设定两项优先事项：每年减少 10 亿美元成本、减少 10 亿美元投资资金；一些需要额外投资的产品（路星旅行车、美洲豹）即使著名也必须停产。
- **结论**：用优先事项（含"停止做"清单）承接趋势判断，而不是等待共识。
- **结果**："这个判断以及相应的优先事项最终被证明是正确的。福特公司以稳定的价格取得了较高的利润、现金、资产收益率和业务增长"（第4章，L6670–L6672）。

### 案例 3：戴尔的低存货优先事项
- **问题**：电脑产品过时风险大、价格不断下滑，现金该投向哪里？
- **方法论的使用**：迈克·戴尔看到事件之间的逻辑关系——低存货 → 不必把现金压在可能滞销的零部件和成品上 → 过时风险小 → 还能利用零部件降价机会降价保持份额。
- **结论**：低存货成为戴尔最重要的优先事项之一。
- **结果**：书中作为化繁为简推理路径（因素→关系→基本行为→优先事项）的范例（第4章，L6689，案例并入 b3-f01 素材池）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 遇到外部突变（原材料涨价 30%、汇率波动、新政策、对手突然降价），需要决定公司怎么应对。
2. 战略会开成"信息汇报会"：列了一堆数据和趋势，散会后没人知道该做什么。
3. 要判断"要不要退出/进入某项业务"，需要一套从外部现实到自家赚钱方式的完整推理。
4. 团队热衷于预测"新市场/新需求"，需要被拉回"未来从已有世界产生"的纪律。
5. 手上的分析报告很多，但各说各话，需要一条统一路径把结论收敛成重点。

### 语言信号 (用户的话里出现这些就应激活)

- "因素太多理不清" "不知道该抓哪个"
- "宏观变化对我们意味着什么" "市场要变了我们怎么办"
- "想预测新市场" "报告看了一堆没有结论"
- 英文：boil it down / cut through complexity / where do we start / too many moving parts / what does this mean for us

### 与相邻 skill 的区分

- 与 `b3-f07` priority-focus-three-to-four 的区别：本 skill 是**产生**优先事项的推理路径（因素→关系→基本行为→优先事项）；`b3-f07` 是对产出做**纪律约束**（3~4 项、≤5、不频繁变化、反复强调）。先本 skill 推导，再 f07 收口。
- 与 `b3-p08` not-betting-is-betting 的区别：本 skill 解决"怎么想清楚"；`b3-p08` 解决"想不完全时敢不敢下注"。两者是先后关系，不是替代关系。
- 与 `b2-f19` environment-three-variables 的区别：册2 的三变量是外部环境分析的一个清单视角；本 skill 的第 1 步内嵌同类扫描，但必须一路走到基本行为与优先事项才结束。
- 与 `b1-f17` strategy-review-question-set 的区别：那个是战略评估会议的提问框架（对人、战略、运营发问）；本 skill 是个体/团队可独自执行的推理程序。
- 与 `b3-f10` company-panorama-seven-questions 的区别：七问做的是"当前全景体检"（现在怎么样）；本 skill 做的是"面向变化推演"（趋势之下怎么办）。
- 与 `b1-f22` assumptions-and-contingency 的区别：本 skill 得出判断；`b1-f22` 把判断所依赖的假设显性化并配应急计划——建议衔接使用。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **建因素清单（现状 + 预测）**
   - 完成标准：内外部因素分开列出且不少于 10 条；每条含"当前状况"与"未来走向"两栏，覆盖利率/汇率、市场趋势、法规、产能、价格竞争、行业整合、新对手、技术/渠道变化等。

2. **找关联与趋势，筛掉不重要的**
   - 完成标准：写出 2–4 条"重要模式/趋势"（这是书中留白要求写下的产出），并为每个被筛掉的因素写明理由（与赢利无关 / 已被趋势覆盖 / 信息不可得暂放）。
   - 判停条件：若关键信息缺失且无法在合理时间内补齐，记录为"关键未知"转 `b3-p08` 处理，不在此无限分析。

3. **分析基本行为：趋势如何影响六要素**
   - 完成标准：每条趋势至少对应一条要素影响的因果说明（现金净流入、利润、周转率、资产收益率、业务增长、顾客）；能指出哪些业务/产品线受损或受益。
   - 判停条件：若团队说不出六要素的语言，先补 `b3-f01` business-acumen-six-elements，否则本步空转。

4. **形成优先事项，并写明"必须停止做什么"**
   - 完成标准：产出 3~4 项（不超过 5）优先事项，每项与现金净流入或赢利目标挂钩；"停止做"清单非空。
   - 判停条件：把清单交给 `b3-f07` 做数量/稳定性复核；若环境支持快速试验，转小步验证而非一次性豪赌。

5. **写下假设与复查条件**
   - 完成标准：至少 1 条可证伪假设与对应监测指标；写明"若 X 发生则回到第 1 步重做"的触发条件（可与 `b1-f22` 衔接）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已有明确单一动作的日常决策：四步流程的成本高于收益，直接执行。
- 纯财务技术问题（估值建模、税务、报表合并）：用 `b3-f08`/`b3-f10` 或专业财务，不套四步。
- 团队没有共同商业语言时：第 3 步会变成术语表演——先补 `b3-f01`。
- 用户实际想要的是"预测一个全新市场"：本方法明确不承诺这个（未来从已有世界产生），应改为情景假设 + 小步验证。

### 作者在书中警告的失败模式

- **b3-ce06 大额资本开支押注未验证的需求（米勒啤酒）**："就在新工厂还没有建成和投入运营的时候，它们的主要竞争对手安海斯布希公司采取了一系列雄心勃勃的营销措施，阻止了米勒公司的发展计划……公司的现金净流入变成了负数"（L6290）。机制：资本开支决策周期长、不可逆，决策依据常是"当前趋势外推"，而竞争者行为与需求波动不在模型内。预警信号：扩产计划基于份额将持续攀升的线性假设；没有竞争对手反击的预案；新项目未投产而市况已变。
- **b3-ce07 "交易商"式 CEO：会做交易，不会经营**（L6707–L6709）。靠并购与资本市场叙事获得声望，但缺少六要素经营能力与优先事项设定：并购后重复职能未整合、协同不落地，投资者期望的利润与增长成空，董事会最终要求其辞职。预警信号：公司故事围绕交易与估值而非顾客与现金；并购后整合计划缺失；董事会只听过路演没看过经营细节。
- **b3-ce18 领导者不设优先事项，公司失去活力**："如果领导人不能设定优先事项，持续改变自己的思维模式，或者不能清晰有效地沟通，整个公司就将失去活力"（L6703–L6705）——本 skill 的终点（优先事项）若缺位，四步分析全部作废。

### 作者的盲点 / 时代局限

- **财务化还原论**：把经营浓缩成六个会计/财务比率，跳过战略质量、技术、组织政治与创新；"好公司"有被简化为"账面指标好的公司"的风险（BOOK_OVERVIEW 最强反对意见 1）。
- **六要素的非普适性**：对平台型、软件型、研发驱动型业务（边际成本近零、网络效应、烧钱换市场）并不直接适用；未讨论非营利与公共部门（册3 批判节未证假设）。
- **"街头小贩类比"的规模断言**：小贩的全部决策变量可在头脑中完成，大公司面对的是不可观测的因果结构；类比在教学中有效，在诊断中会误导（册3 批判节）。
- **样本与立场**：案例是作者咨询过的美国大公司（GE、福特、EDS 等），存在幸存者偏差；"练成本能"回避了从知识到判断力的断层。

### 容易混淆的邻近方法论

- SWOT / PEST / 五力等环境扫描工具：通常止步于"列因素、找机会威胁"（相当于本 skill 第 1–2 步）；本 skill 的独特处是强制推到基本行为与优先事项，并带"停止做"清单。
- 战略规划流程（正式规划部门主导）：本 skill 是领导者个人的思维程序，可在会前/会中执行，不依赖规划部门。
- `b3-p08` not-betting-is-betting：不要用"再分析一下"逃避下注——四步做完就必须选择。
