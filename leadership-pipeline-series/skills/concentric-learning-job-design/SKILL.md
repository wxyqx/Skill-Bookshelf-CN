# 同心圆学习与以人定岗（岗位路径设计）

## R — 原文 (Reading)

> "我们可以把有领导潜质的人才的职业发展看成是一系列同心圆：圆心代表该领导人才的禀赋及才能，同心圆代表工作岗位，从内到外的一系列同心圆代表入职后的第一个岗位到之后广度及难度不断递增的多个工作岗位。如果领导人才能战胜挑战，在现有岗位上脱颖而出，说明他已经做好准备，迎接下一个广度及难度更大的工作挑战。"
>
> — 查兰，第2章（L7911）

> "很多公司遵循传统方式，以岗选人。而轮岗培养模式恰恰相反，会为领导人才量身安排工作岗位，为他们选择最适合的岗位，必要时调整现有的岗位，甚至是打造新的岗位。岗位的职责设计尤为重要，因为这决定了他们是快速成长，还是停滞不前。"
>
> — 同上，第4章（L8227）

> "最佳的职务调动不一定是升迁，也可能是平行调动到一个新的业务领域甚至是调往级别稍低的职务。……平行调动的主要目的，不是让领导者学习另一个部门（如制造部门）的专业性知识……而是学习如何把这个新部门和他原来的专业结合起来，使他更加善于从整体来看待业务。……领导者不应该被一个新的部门完全同化……"
>
> — 同上，第4章（L8243–L8245）

---

## I — 方法论骨架 (Interpretation)

这套方法把"给某人安排什么岗位"从填空变成设计。

**同心圆讲的是判据和方向**：圆心是这个人的禀赋与才能，一圈圈岗位围绕它外扩；每往外一圈，岗位的广度与难度都必须明显上升。进入下一圈的通行证不是年头、不是空缺、不是"他想要"，而是"在现岗战胜挑战、脱颖而出"。从基层到 CEO，管理的复杂程度要跨越四五个数量级，所以必须由易到难逐级加码，一步登天就是揠苗助长。

**以人定岗讲的是决策方向的反转**：传统是"岗位缺人了，找一个合适的人填"；这里先问"这个人下一步需要什么历练"，再去挑、去改、甚至去造岗位——但创造的载体不一定是正式职位，也可以是任务小组、跨部门项目、某品牌或产品线的全面负责。前提是先把"高层需要什么能力"和"此人现有能力与缺口"弄清楚。

**平行调动与破格提拔是两个配套工具**：平行调动（平级甚至略降）的价值在于视角整合——把原来的专业与新领域结合，而不是被新部门同化；破格提拔则是在成长速度远超常规时果断加码，但必须做风险评估：时间、岗位、人选三者是不是匹配，万一失败的后果公司能否承受（弗兰克案例就是反例）。同时有两个硬边界：不能为培养一个人而增设组织层级；岗位节奏要给 3～5 年让贡献显现，一两年内就暴露负担过重，说明挑战失配。

## A1 — 书中的应用 (Past Application)

### 案例 1: 韦恩 vs 伊莲——同一岗位、两条路径（第4章）
- **问题**: 公司两位全球品牌经理业绩同样出色，要不要都按"去某个国家全面负责"的惯例往上推？
- **方法论的使用**: 先评估各自的禀赋与缺口：韦恩虽只负责营销，但已展现业务主管潜质（视野全面、与各地业务经理关系良好）——派他去规模较小、经营简单的国家全面负责，再调德国（业务规模巨大、市场与客户复杂、还需改变当地根深蒂固的文化），若再次证明自己则考虑整个欧洲；伊莲营销能力出众、也能与研发良好协作，但思维模式完全从营销角度出发、在工作中造成不必要的摩擦，是否具备商业头脑与全面管理能力还是未知数——于是不派她去管国家业务，"为她在营销领域安排了更具挑战性的工作"。
- **结论**: 不搞"一刀切"轮岗：路径必须因人而异；证据不足时不拿关键岗位做赌博；"以人定岗"意味着同岗两人的下一步可以完全不同。
- **结果**: 两人各得其所——韦恩沿总经理序列获得更大空间，伊莲的营销路线延续（b4-c14）。

### 案例 2: 加里"以退为进"——平行调动的完整演示（第1章）
- **问题**: 加里已经是巴西业务一把手，总部却让他去日本合资企业管营销，职位与级别看起来"倒退"，他心想"这不是我早就干过的事嘛"。
- **方法论的使用**: 导师的说服逻辑是学习价值而不是头衔："你应该去东京，别管职务和级别。日本和巴西是完全不一样的……这是一个挑战，你绝不会感到无聊，并且还可以学到很多东西。"新环境包含跨文化、不同公司治理、不同处世方式——这正是同心圆外扩时最稀缺的挑战维度；加里到任后主动了解业务全貌，用其人际能力推动部门之间表达与交流。
- **结论**: 判断一次调动好坏的标准是"是否接受了更大挑战"，而不是级别升降；平行调动要整合视角、不被新部门同化。
- **结果**: 加里融入日本并积累全面了解，为接掌日本业务铺垫，随后全面负责并实现扭亏（b4-c03、b4-c04）。

### 案例 3（边界反例）: 弗兰克——错误的破格提拔（第4章）
- **问题**: 首席战略官聪明、精通业务、被视作 CEO 接班人，但一直在职能部门工作、最多管过 100 人；董事会把他放去负责困难重重、对公司至关重要的北美业务。
- **方法论的使用**: 反读风险评估三要素——时间（业务正处危机、不可失守）、岗位（需要选拔培养人才、树立威信、大批量决策，与其经验完全不匹配）、人选（无独立业务与带团队经验）：三者全部错配。
- **结论**: "这的确是一次旨在人才培养的破格提拔，但这是在错误的时间、用错误的岗位、对错误的人进行的一次错误的考验"——破格可以做，但必须先算失败后果。
- **结果**: 两年内北美市场份额由 20% 跌至 15%，现金入不敷出、债券沦为垃圾级；弗兰克被撤职，CEO 也被迫离职，公司多年深陷泥潭（b4-c13）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 部门里有个技术骨干，用户考虑让他走管理线或去业务线，问"下一步放哪"。
2. 公司要调一个高潜去另一个地区／部门，对方觉得是"降级"或"重复劳动"，用户需要判断这次调动到底有没有培养价值、以及怎么解释。
3. 岗位空缺出现时，用户纠结"填最合适的人"还是"给某个有潜质的人历练机会"；或在问"要不要为他专门设一个岗位"。
4. 用户想提拔一个表现突出的年轻人，但不确定是否"早了"，担心拔苗助长。
5. 用户在做某个高潜的成长路径图，需要逐站检查"每一站是不是都比上一站更难"。

### 语言信号 (用户的话里出现这些就应激活)

- "他的下一步该放哪里？"
- "平调是不是倒退？他本人觉得这是降级。"
- "要不要给他设个新岗位？还是再等等？"
- "他在现岗还没做出成绩，能升吗？"
- "stretch assignment" / "lateral move" / "job rotation" / "is he ready for the next role" / "should we create a role for him"

### 与相邻 skill 的区分

- 与 `apprenticeship-model` 的区别: 那是制度层（四要件、体系怎么搭）；本 skill 是操作层（某个人下一步的具体岗位安排与判据）。
- 与 `b5-f27 succession-five-steps` 的区别: 继任五步面向关键岗位的接班名单与准备度；本 skill 面向个人的成长路径，可以不绑定任何空缺。
- 与 `b3-f12 coaching-two-tracks` 的区别: 教练辅导双轨是岗位之上的对话机制（业绩与能力两条轨道）；本 skill 决定"换不换岗、换去哪里"。
- 与 `b4-f18 tolerate-failure-conditions` 的区别: 本 skill 决定给什么挑战；tolerate-failure-conditions 决定给多大自由、失败后如何归因与调整。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **弄清目标方向：此人要培养成什么层级的领导者**
   - 完成标准: 写出未来目标岗位（或目标层级）所需的关键能力清单，并得到当事人与其上级的确认。
   - 判停条件: 若此人并不想做领导者（目标是个人贡献者／专家路线），跳到 B 段提示并转入双轨发展讨论（b5-f36），不要硬设计领导岗位。

2. **评估现有能力与缺口，并检查现岗表现**
   - 完成标准: 用行为与决策证据写出"已证明／待证明／未知"三栏；确认其在现岗是否"战胜挑战、脱颖而出"——未脱颖而出则先在本岗补课，不启动外扩。

3. **设计下一站：挑战递增检查**
   - 完成标准: 下一站至少满足以下一项增量——更复杂（多业务／多地区／多利益相关方）、更不确定（新市场、危机、转型）、更全面（从职能到全面负责、从单业务到多业务）、更快（增长或整合速度）；并写明"这一站要考验什么、学习目标是什么"。
   - 判停条件: 若下一站与现岗复杂度相似或只是同质平调（如到另一个单位继续做成本控制），判定为无培养价值，删除该选项。

4. **选择或创造载体**
   - 完成标准: 从正式岗位、平行调动（可平级或略降，但必须接受更大挑战）、任务小组／跨部门项目、某品牌或产品线全责中选定一种，并说明为什么它比"等空缺"更快有效。
   - 判停条件: 若方案依赖"新设一个管理层级"，停止——这已被明确列为失败模式（b4-ce15、b4-c28），改用不改变组织架构的载体。

5. **做风险评估（时间／岗位／人选三要素）**
   - 完成标准: 逐项回答——这个时间点业务能否承受失误？岗位要求与他的经验差距是否超过一个数量级？万一失败，公司的损失可控吗？并写下退路（临时支援、阶段性考核点、退出方案）。

6. **沟通与节奏设定**
   - 完成标准: 向当事人如实说明调动的原因、挑战与风险（可参考道格对阿曼达：坦承"这样做对我们两个人都风险很大"，让对方调研后再决定）；约定 3～5 年的贡献窗口，以及每半年一次的复盘点；一两年内出现明显负担过重信号即调整而非硬撑。

7. **记录成长路径并回填人才库**
   - 完成标准: 把历任岗位与复杂性变化画成成长路径图，并在每次评估会或职务变动后更新。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 组织处于稳定期、岗位序列清晰但用户其实想做的是"批量轮岗"：那是制度问题（apprenticeship-model），逐人设计反而变成负担。
- 当事人明确不愿走领导路线：不要用"以人定岗"的名义强迫其接受管理岗位，应转双轨发展讨论。
- 岗位调整涉及跨地区劳动关系变更、劳动合同条款、异地用工合规时：本 skill 只处理培养逻辑，不构成人力资源法律意见。
- 关键业务正处于危机且不可失守、公司无失败承受力时：不要用"历练"名义安排试验，先解决业务存续。

### 作者在书中警告的失败模式

- **拔苗助长**：错误时间＋错误岗位＋错误人选——只看"聪明／懂业务"，未评估领导经验、岗位复杂度跨度、失败后果与公司承受力，业务与个人双输，甚至波及 CEO 与公司多年（b4-ce02）。
- **为培养一个人而增设组织层级**：新岗位与既有岗位职责重叠、汇报线拉长，两年内关键人员流失、运营困难（b4-ce15；案例 b4-c28）。
- **遥控管理代替海外亲历**：把"全球化历练"做成总部遥控＋短期出差——"身在纽约，却遥控中国大陆的业务，和亲身到中国大陆经营业务是全然不同的经历"（b4-ce24，L8239）。
- **把同一部门内的同级调动当培养**：在不同单位做完全相同的专业工作（如成本控制）"无法拓展领导者的个人能力"（b4-g11）；作者举出反例：一位领导者靠着提价增收、从不在一个职务上待久等结果显现，升任高层后旧决策的后果爆发，职业发展就此终止（L8243）。
- **家庭与流动性约束被忽视**：培养设计默认"可全球流动"，配偶职业、子女教育、社会关系等约束未被纳入，人才被迫退出；若某地点反复无人愿意去，问题可能不在人而在"那个地点的事业本身"（b4-ce23）。
- **为育才而让现任让位必须小心处理**：把干得好但缺乏发展潜力的现任调离岗位、为有潜力者腾位置，是"没有比和他们面对面地讨论职务调动更困难的局面"；书中强调"每一位领导者都应该得到重视和尊重"，缓解方式之一是说明新职务对其发展同样有益（多数人能在新职务上重新焕发活力），但作者也承认当事人仍可能愤愤不平——操作须依当地劳动法与公司人事程序，提供转岗与改进机会（L8266）。

> risk_note（b4-ce23 保留）：涉及家庭与照护责任的安排不能以"奉献"名义强制；调动涉及劳动合同变更与异地用工合规；公司应提供弹性与替代路径，不得构成对特定群体的间接歧视。

### 作者的盲点 / 时代局限

- **"以人定岗"与组织设计的张力**：本章同时要求"必要时打造新的岗位"，而组织设计的成本（层级、公平感、汇报关系）在其中着墨很少，只靠个别反例提醒。
- **精英二分法的公平成本**：路径设计把资源向少数高潜集中，"未被选中者"的发展与士气作者未讨论；"以人定岗"若不透明，很容易被读成"为某人特设"（b4-ce15 的 warning_signs 已提示这种解读风险）。
- **能力形成期的强假设**：同心圆外扩依赖"能力可以通过岗位序列逐步养成"；在岗位流动性高、跨行业跳槽普遍的今天，五站式序列的前提并不普遍成立。
- **非美国语境落差**：书中默认可搬迁、可全球调动的培养对象，对双职工家庭、照护责任与本地劳动制度考虑不足（BOOK_OVERVIEW 批判节）。

### 容易混淆的邻近方法论

- 与"人岗匹配"（岗位优先、寻找最合适的人）：本 skill 的方向相反（人的成长优先），两者需要按场景选择：成熟业务的关键岗位用前者，培养场景用后者。
- 与"轮岗＝多岗位经验"：本 skill 的核心判据是挑战递增＋学习目标，而非岗位数量。
- 与"晋升谈判"：本 skill 不负责级别与薪酬的谈判逻辑，只负责学习价值。
