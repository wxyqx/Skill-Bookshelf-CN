# 文化变革的绩效联结框架

## R — 原文 (Reading)

> "只有当你的目标是完成任务的时候，文化变革才可能真正实现。……首先你应该清楚地告诉人们公司的目标是什么，然后你会与大家一起讨论实现这些目标所应当具备的条件"
>
> — 博西迪/查兰/伯克，第4章（L1116）

> "一段时间之后，你应当对那些做出贡献的人进行奖励；如果他们没有实现预定目标的话，你应该对他们进行更多的教练辅导，取消奖励，调换工作岗位，或者是让他们离开。"
>
> — 同上，第4章（L1116）

> "当人们，特别是企业的高级主管，违反了公司某些基本价值观的时候，领导者就会公开地对这些违反者进行惩罚，否则就说明领导者本人缺乏必要的情感强度。"
>
> — 同上，第4章（L1145）

## I — 方法论骨架 (Interpretation)

文化变革失败的通病是"文化与实际业绩不挂钩"。本框架把文化还原为可操作的循环，而不是问卷与标语：

1. **前提**：只有当目标是完成任务时，文化变革才可能真正实现——文化是结果，不是项目。
2. **四步循环**：告诉人们目标是什么 → 与大家一起讨论实现目标所应具备的条件 → 对做出贡献的人奖励 → 对未达标者教练辅导、取消奖励、调岗或让其离开。
3. **顺序追问法**（书中示范的问法）：以"变革文化"为目标，先问"首先要解决什么问题"；把答案逼到"从什么状态到什么状态"；再问"从哪里开始"——答案必须是"我们自己"；最后问"改完自己之后接着做什么"（逐级向下传导）。
4. **信念对照**：需要改变的是影响行为的信念（可用"旧信念清单 vs 新信念清单"的方式公开讨论），而基本价值观（诚信、尊重客户）更多需要强化与对违规者的公开处理，而非改变。
5. **底线**：领导者容忍什么，文化就是什么；对违反价值观者（尤其是高级主管）不处理，等于宣布价值观作废。

## A1 — 书中的应用 (Past Application)

### 案例 1: EDS 三年重建——用信念对照＋奖励挂钩改文化
- **问题**: EDS 转型前普遍存在"我们是商品公司""无法扩大市场份额""每位领导都拥有所有的资源——关键是控制""同事就是竞争对手""人们普遍缺乏责任感"等旧信念，责任感缺乏是痼疾，业绩不佳不会带来任何不良结果。
- **方法论的使用**: 迪克·布朗在高级领导层会议上要求各小组总结过去五年占主导地位的旧信念与今后五年需要建立的新信念（新清单包括"协作是成功的关键""每个人都应当确立明确的责任意识""我们要更加重视客户的意见"等），第二张列表随即成为全体成员态度改进的日程表；同时把奖金与业绩挂钩，把所有主管按相对业绩排名并据此奖励。
- **结论**: 行为改变的基础是把业绩与奖励挂钩并使联系透明；信念一旦转为行动就表现为行为，行为带来结果。
- **结果**: 布朗花三个月巡视全球分公司、办 150 名主管两天会议、替换 20% 零业绩销售人员；股价上升 65%，运营边际收益与每股收益连续 11 个季度两位数增长，91% 客户评价服务良好或优秀。

### 案例 2: 铁路公司副总裁琼斯——对破坏者长期容忍的代价
- **问题**: 铁路公司执行副总裁琼斯在电话会议上辱骂下属、公开顶撞 CEO，行为违反公司"尊重个人"的价值观；因他掌控 80% 的预算与员工，CEO 长期容忍。
- **方法论的使用**: 直到琼斯当众拒绝执行部门调整指令，CEO 才停止容忍、一个月后将其解雇——这正是"领导者对违规者的处理力度决定价值观是否成立"的现场检验。
- **结论**: 容忍即默许，领导者的容忍会被组织解读为"这类行为可接受"，直接抵消价值观宣示。
- **结果**: 琼斯被解雇后"整个公司都松了一口气"；其下属接任后重新调整成本结构，公司股价四年之内翻了一番。

### 案例 3: 联信公司——博西迪重建执行文化
- **问题**: 博西迪回到联信时，公司运营管理团队存在很大不足，流程与实际业绩长期脱钩（他后来离任不到两年，霍尼韦尔的执行文化即流失、股价下跌，2001 年被迫再次出山，说明文化不是一次性资产）。
- **方法论的使用**: 他组织新团队全身心投入日常运营，按目标—条件—奖励—处置的循环重建文化，并把人员评估、战略与运营流程咬合起来运行。
- **结论**: 文化变革的成果可以量化，但必须持续维护；同一套机制停转后文化会流失（b1-c07）。
- **结果**: 到 1999 年与霍尼韦尔合并时，公司营业毛利增长两倍、接近 15%，股本回报率从 10% 上升到 28%，股东实际回报几乎是以前的九倍。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司推"客户第一""奋斗者文化"等，宣讲、海报、培训都做了，行为却没有变化。
2. 用户要设计一次文化变革，想弄清先改什么、从哪里开始。
3. 用户发现"高绩效但行为恶劣"的人被容忍，团队开始模仿其行为。
4. 用户要做一次"旧信念 vs 新信念"的讨论会或文化诊断（对比问卷式诊断）。
5. 用户想检查奖励系统是否真的在传递文化信号（优秀者与平庸者待遇无差别）。

### 语言信号 (用户的话里出现这些信号就应激活)

- "文化推不动 / 宣讲半年没人变。"
- "价值观都挂在墙上了，行为还是老样子。"
- "怎么才能让员工真的改变行为？"
- "rewards don't match the culture" / "values on the wall" / "how do I change behavior, not slogans"

### 与相邻 skill 的区分

- 与 `b3-f13 social-operating-mechanism` 的区别: 后者设计承载对话的会议节律（机制层）；本 skill 处理目标、条件、奖励、处置四步的行为工程（激励层），两者互补但不可互相替代。
- 与 `b2-f19 environment-three-variables` 的区别: 后者考察企业外部大环境（土地/环境）对业绩的影响；本 skill 处理组织内部信念与行为的改变。
- 与 `b1-f01 execution-system-architecture` 的区别: 本 skill 是执行架构第二块基石的具体操作，不负责整体诊断。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **把模糊诉求逼成具体状态**
   - 完成标准: 产出一句"从 X 状态到 Y 状态"的描述，必须是可观察的行为（如"从互相推责到每个问题有明确责任人"），而不是"从非执行文化到执行文化"这类空话。

2. **定位起点：从管理层自己开始**
   - 完成标准: 让管理团队回答"从哪里开始"，答案落在"我们自己"；并给出管理层自身要做到的 2–3 项具体行为改变。
   - 判停条件: 若管理层不愿先改自己，终止流程并说明：文化变革在源头就不可能成立。

3. **检查条件的具备度**
   - 完成标准: 逐项确认实现新行为所需的流程、授权、资源、培训是否就位；缺什么补什么，写明负责人。

4. **检查奖励与行为的挂钩**
   - 完成标准: 拿出薪酬/晋升/表彰的实际数据，验证优秀者与平庸者是否被区分；把协作、客户导向等期望行为纳入评选因素并使联系透明。
   - 判停条件: 若奖励无法区分优劣，先修奖励系统，不要继续宣导。

5. **处理违规者与未达标者**
   - 完成标准: 对违反基本价值观者公开处理（尤其高级主管）；对未达标者执行教练辅导→取消奖励→调岗/离开的路径。
   - 判停条件: 涉及解雇/降职时，须按当地劳动法与公司程序执行，并提供转岗或改进机会（见 B 段风险提示）。

6. **做一次信念对照并向下传导**
   - 完成标准: 组织两人/小组形式讨论，产出"旧信念清单"与"新信念清单"，并把新信念转为可执行的行为规范；随后按 300 名经理→3000 名主管→员工的层级逐步传导。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想要一次团建/文化建设活动（如文化节、价值观征文）：本框架属于行为与激励工程，不是活动策划。
- 用户没有管理层授权、只想在下属层面"改文化"：与"从哪里开始（我们自己）"的前提直接冲突。
- 用户的问题其实是战略不清或人员不胜任：先解决那个问题，文化议题会随之简化。

### 作者在书中警告的失败模式

- **无原则奖励**: 领导者希望被爱戴，缺乏情感强度做客观诚实的评价，甚至为业绩不佳者创造新岗位，"结果，整个组织陷入一片混乱，大家被领导者的奖励政策弄得晕头转向"（b1-ce05）。
- **对违规者不罚 / 对价值观破坏者长期容忍**: 价值观宣传与处理违规的力度不一致，默认"这类行为可接受"（b1-ce21）。
- **流程空转型官僚主义**: 文化变革若只留下问卷、材料和会议外壳，没有与实际业绩挂钩，就与书中批评的"六英寸厚材料"同类（b1-ce11）。
- **沉默的谎言与无言的反对**: 追求"一团和气"会扼杀批判性思维，让决策成为一纸空谈——文化变革必须建立在"真相高于和气"之上（b1-ce04）。

### 作者的盲点 / 时代局限

- **"文化可以被会议日历＋奖惩机制设计出来"是典型的社会工程式假设**，未讨论自组织与涌现；在知识密集型/创意型组织中，"结构化会议文化＋强 KPI"可能适得其反，2010 年代敏捷与心理安全研究提供了相反证据（BOOK_OVERVIEW 未证假设 10）。
- **强制排名类工具的时代争议**: 书中引用的韦尔奇式活力曲线（A/B/C 分级）在真实组织中极难满足"评选公正"的限定条件，GE 自身在 2015 年后放弃强制排名；若引用该工具，必须同时带上书中三个约束——客观标准、对低等级者的解释反馈、把评选当作教练机会（BOOK_OVERVIEW 批判节）。
- **单因论与美国大公司语境**: 案例几乎全为美国大型公司，对文化变革失败的政治、治理与资源约束讨论很薄。

### 容易混淆的邻近方法论

- 与"变革曲线/科特八步"的区别: 那些描述变革的阶段与情绪；本框架只回答"用什么杠杆让人改变行为"。
- 与"雇主品牌/价值观提炼"的区别: 那是话语层；本框架要求落到奖励与处置的硬约束。
