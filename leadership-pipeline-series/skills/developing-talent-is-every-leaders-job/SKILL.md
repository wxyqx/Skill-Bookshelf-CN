# 培养人才是每位现任领导的职责，必须考核与奖惩

## R — 原文 (Reading)

> "“轮岗培养模式”赋予基层领导者巨大的责任，他们的重要职责之一就是发现和培养未来的领导者，这和他们负责的战略、财务、营销等工作一样重要。"
>
> — 查兰，前言（L7549）

> "没能让现任领导人认识到，识别及培养有领导潜质的人才也是自己的重要职责。他们既不知道如何识别及培养领导人才，也不会因为在人才培养方面的努力得到任何奖励。绝大多数公司只用财务业绩来考核他们，并不关心他们是否有能力培养领导人才。"
>
> — 同上，第1章·错误理念清单（L7721）

> "每位上级领导应该投入20%~25%的时间观察有领导潜质的人才，及时提供准确的反馈意见与指导，敏锐的识别领导人才需要发展的一两项事项（不要超过两项）……"
>
> — 同上，附录·公司基石之二（L9180）

---

## I — 方法论骨架 (Interpretation)

这条原则要把"育人"从道德号召变成岗位责任与考核项。

**三个动作**：
1. **职责化**——识别与培养领导人才被写进每位现任领导的岗位职责，与战略、财务、营销同等重要（推荐序中的自评表把它列成第一条："在我的公司，培养领导人才是现任领导的重要职责之一"）。配套的量化要求是：直接上级投入 20%～25% 的时间观察有领导潜质的人才、给反馈。
2. **考核与奖惩**——公司对育人的投入程度进行评估，做得好给予认可和奖励，做得不够有惩罚措施；薪酬激励制度相应修改；"对于那些没有能力或者没有意愿培养领导人才的领导……之后他们仍然不愿改变自己，他们就必须离开现在的领导岗位"。同时把"为其他单位输送了多少人才"纳入评价，并用公开的职务空缺公告制度削弱部门本位。
3. **上行下效**——体系必须从公司高层开始，CEO 以身作则：作者举韦尔奇（20 年给 15 位下属逐一写信）与德事隆的坎贝尔（以自己做评估样本、亲自取得六西格玛绿带）为例；反过来，"CEO 和人力资源部门主管必须制定一套基本的制度及方法"是启动条件。并且要管理预期：新体系往往需要两三年才见成效。

**两个防误读的限定**：①高潜人才与一般人才不同、值得投入大量时间精力，"这些高潜质的领导人才并不能因此就觉得自己在公司里高人一等"；②育人不是 HR 的独角戏——HR 的职责是推动、督促与专业支持（"没有他们的推动及督促，轮岗培养模式很难成功"），但主力军始终是各级业务领导。

## A1 — 书中的应用 (Past Application)

### 案例 1: 韦尔奇——20 年给 15 位下属逐一写信（第2章）
- **问题**: 一家巨型公司的 CEO 如何把"育人"变成可长期坚持的日常动作，而不是项目式的口号？
- **方法论的使用**: 韦尔奇把季度业务分析会、预算会、半年战略会与 15 位直接下属的定期谈心都变成育人场景；每次会议结束亲自动笔给每一位下属写信，总结讨论的主要议题及行动计划——"每次会后给15位下属逐一写信，这么大的工作量韦尔奇整整坚持了20年"。他还创造非正式途径（提前散会带团队去酒吧谈到深夜）考察与培养人，做到"面对业绩极为出色的领导者也不盲信盲从"。
- **结论**: 育人之所以能持续，是因为被当成责任与习惯，而不是"额外的时间"；作者的评价是这种持续练习才是他成为领导大师的原因。
- **结果**: 韦尔奇被作者视为"我们这个时代企业领导大师及楷模"；GE 建立起持续产出的领导人才培养机制（b4-c11）。

### 案例 2: 德事隆——把育人写成考核指标（第8章）
- **问题**: 一家多元化集团，1999 年时高级管理人员主要靠外部招聘，如何转向内部造血？
- **方法论的使用**: 由最高层推动并亲自示范：CEO 坎贝尔要求领导们用同一套标准评估年轻新秀，并用自己做评估样本——"我在某些方面获得好评，但也有人建议我在某些方面需要改进。以我自己为例来进行分析，我们的讨论就变得具体而不空洞"；他自己努力达到六西格玛绿带水准以表明重视；HR 提出框架但必须让业务单位人力资源主管认可"这些工具和流程是他们单位真正需要的"；把"培养下属"作为各级领导的主要考核指标；配套统一薪酬与退休方案、全员职务空缺公告、六西格玛黑带跨单位流动以促成人才流动。
- **结论**: 育人不进入考核就无法对抗业务压力；高层的亲自示范是让中层相信"这是真要求"的唯一方式；同时要接受体系建设的渐进性——德事隆自评只完成 70%，剩余难点是"为高潜专门设计短期岗位"。
- **结果**: 7 年后集团近 3/4 的高级管理人员由内部提拔（2001 年为 1/10），170 位高级经理每人都有两名内部接班人选；目标 90% 内部培养（b4-c31）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 中层或高管抱怨"业务都忙不完，哪来时间带人"，用户需要给出制度性的回应而不是道德劝说。
2. 用户要设计或修改对管理者的评价与激励：把"培养人才"写进职责、考核与奖惩，问具体怎么写、怎么量化。
3. 公司老板问"人才培养到底该谁负责"——是 HR 的项目，还是业务领导的职责。
4. 公司里出现"部门不放大才""把高潜藏在自己手里"的现象，用户要找机制解（人才输送纳入考核、空缺公开）。
5. 培养体系刚启动但推不动，用户需要确认启动顺序（CEO 先动、上行下效）并管理好组织对见效时间的预期。

### 语言信号 (用户的话里出现这些就应激活)

- "没时间带人 / 业务都忙不完，谁还有空培养人？"
- "培养人才算谁的职责？"
- "怎么考核育人？写进 KPI 吗？"
- "部门不放人 / 领导不愿意教怎么办？"
- "talent development accountability" / "every manager owns talent" / "hold leaders accountable for developing people" / "20% time for people"

### 与相邻 skill 的区分

- 与 `apprenticeship-model` 的区别: 那是培养系统的整体设计（选择人、岗位、反馈、评估）；本 skill 解决"谁负责、凭什么投入"的激励与责任问题，是让整套系统能转起来的前提。
- 与 `b1-f12 talent-review-meeting-mrr` 的区别: 评估会议是育人的运行机制之一；本 skill 是它背后的责任与考核安排。
- 与 `b4-p12 assessment-dual-track` 的区别: 双轨讲"评估要看什么"；本 skill 讲"谁被考核、考核什么、奖惩如何"。
- 与 `b1-f15 underperformer-tiered-handling` 的区别: 后者处理不胜任的下属；本 skill 中"不愿育人的领导必须离开领导岗位"是对领导本人的要求，不是对下属的处置流程。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **把育人写进岗位职责文本**
   - 完成标准: 在管理者职责说明、绩效目标或干部标准里出现"识别与培养领导人才"，并明确它是与战略、财务、营销同等重要的职责，而不是附加项。
   - 判停条件: 若组织尚未确定高潜名单与培养路径，先做 `b4-f04`／`b4-f02`，否则考核无对象、只能空转。

2. **给出可操作的投入要求**
   - 完成标准: 明确直接上级的观察与反馈投入（书中量为 20%～25% 的时间）、每人聚焦不超过两项关键事项；并说明这不是"额外加时"而是调整接触的关注点。

3. **设计考核与奖惩**
   - 完成标准: 列出考核项（如为其他单位输送多少人才、下属成长证据、接班人准备度）、评价方式（结合领导力评估会，而非只看数字）、奖惩后果（认可与奖励；对无意愿者先帮助、仍不改变则离开领导岗位）。
   - 判停条件: 若公司不能接受"不育人即离岗"的后果，改设渐进路径（先公开排名与曝光、再影响奖金与晋升），但必须说明这会显著拉长见效时间。

4. **建立人才流动机制，削弱部门本位**
   - 完成标准: 推行全员职务空缺公告，明确"不得私藏人才"；将输送人才纳入部门评价。
   - 判停条件: 涉及个人知情权、调动合规与人事程序时，交由 HR 与法务按当地规则执行（见 B 段 risk_note）。

5. **CEO 与高层先行**
   - 完成标准: 列出高层以身作则的具体动作（亲自参与评估、亲自反馈、亲自担任导师、公开示范），并确认它们已排入日程。
   - 判停条件: 若高层只发文件不投入时间，停止推进并如实告知用户：体系会退化为填表（b4-ce09）。

6. **配套激励与制度同步修改**
   - 完成标准: 检查薪酬、奖金、晋升与接班人规则是否与"育人"要求一致；对"跟着领导走的高潜"要有制度化的调动支持。

7. **管理预期并公布时间表**
   - 完成标准: 明确告知组织新体系通常需要两三年才见成效，并设定检查点（名单质量、内部提拔比例、关键岗位接班人覆盖数）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 想把"育人"设计成个人绩效的硬指标但组织还没有评估能力时：无证据的考核会催生形式主义（打分好看、人才没长）。
- 用于处理个别管理者的态度问题：本 skill 是制度设计；个体态度问题走管理沟通与人事程序。
- 用户其实是要解决"某个高潜被压着不放"的具体人事纠纷：那需要 HR 介入与程序处理，本 skill 只提供机制建议。
- 小规模组织（团队几十人以内）尚无正式考核体系时：先把育人变成固定对话与赋能动作，不急着上考核。

### 作者在书中警告的失败模式

- **育人不在职责与考核里**：公司口头重视人才、制度上只考核财务，"领导把带人当额外负担，人才培养沦为 HR 独角戏，梯队持续空缺"（b4-ce08）。
- **私藏人才**："小金库"与"武大郎开店"心理——领导者隐藏人才、阻挠调动，人才因缺乏挑战而流失（b4-ce17）。
  > risk_note（b4-ce17 保留）：纠正需通过透明制度（空缺公告、跨部门评价、把"输送人才"纳入考核），而不是个人冲突或惩罚性调动；同时避免侵犯员工知情与选择权。
- **让基层主管负责识别人才**：把最难的任务交给最缺工具与动力的层级，导致标准走样、圈层化（b4-ce07）。
- **官僚填表式流程**：仅靠考核表与流程不产生人才，只会制造"我们已经在做"的错觉（b4-ce09）。
- **培养资源过度分散**：不聚焦少数真正有潜质者，只能寄望"优秀者自己崭露头角"（b4-ce06）。

### 作者的盲点 / 时代局限

- **责任归属的个人化**：本书把育人责任交给个人领导者与其上级，对制度性障碍（编制、薪酬总额、跨部门调动审批、政治格局）讨论很薄；在矩阵与事业部并存的组织里，"为其他单位输送人才"往往需要更高层级的强制与补偿机制。
- **"不育人就离岗"的现实约束**：这一要求在中国国企、机关式组织与强专业型团队中的落地难度与劳动法边界，作者未讨论，只提示"如何尊重地做"（BOOK_OVERVIEW 批判节）。
- **量化指标的副作用**：20%～25% 的时间配额在知识密集型组织中难以度量，容易退化为工时游戏。
- **样本偏差**：正面案例（韦尔奇、坎贝尔、高露洁）均由咨询顾问长期参与或背书，缺少推行失败的对照企业。

### 容易混淆的邻近方法论

- 与"OKR／KPI 设计"：那是目标管理工具；本 skill 解决"育人不被测量的制度空缺"，落地时可借用 OKR 形式但核心是责任与奖惩。
- 与"人才管理归属之争（HR vs 业务）"：本 skill 的立场是业务领导为主、HR 为推动与专业支持方，不是把责任推给 HR。
- 与"导师制项目"：导师制是育人的载体之一；本 skill 关注的是让导师制不靠自觉而靠制度运行。
