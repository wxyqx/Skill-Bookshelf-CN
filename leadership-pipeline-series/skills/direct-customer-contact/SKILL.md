# 顾客直接接触法（未经过滤的第一手观察）

## R — 原文 (Reading)

> "当你发现不能保持原价和维持原有毛利时，就应该去和消费者进行交流，直接地、不经过滤地观察他们，而不是通过分销商或其他中间人的眼睛。"
>
> — 查兰，第2章（L6512）

> "直接接触能够提供很多其他市场调研方法所不能提供的信息和见解。……当纳塞尔钻进汽车和这个年轻人一起驾驶的时候，他发现这辆车实际上还是装了很多新的附件，包括一个拖车挂钩……不过这个车主已经把这些东西都看做“这辆车的一部分”了，所以他根本没有想到它们。"
>
> — 查兰，第2章（L6496）

> "他们可能是也可能不是那些产品的最终使用者——消费者。同时理解这两者非常重要。当高露洁棕榄（Colgate-Palmolive）开发新产品的时候，它试图去了解消费者的需求和需要，但是它的很多环节，物流、折扣、订单的计划安排、上架和推销，都是面向沃尔玛这样的顾客的。"
>
> — 查兰，第2章（L6502）

---

## I — 方法论骨架 (Interpretation)

组织越大，关于顾客的信息越会被层层过滤：汇报会提炼、问卷会预设选项、渠道会转述自己的利益诉求。等到毛利守不住、份额悄悄流失时，领导者手里往往只剩被加工过的结论。这个方法给出的替代路径是：

1. **触发信号是数字恶化**，尤其在不能保持原价和维持原有毛利时——那是顾客价值主张出问题的先行指标。
2. **领导人亲自到现场**，直接观察购买与使用行为（巡店、跟车、看着用户使用），不通过分销商或调研公司的眼睛。
3. **严格区分两群人**：消费者＝最终使用者；顾客＝直接购买方/渠道（如沃尔玛）。渠道话术不等于用户需求，两者要分别理解、分别服务。
4. **把消费者"买什么"想简单**：他们买的可能不只是产品，还有可靠性、便利、服务与信赖——购买理由必须简单到一句话能说清。
5. **寻找"未满足的特定领域"**：直接接触的产出不是印象，而是具体的待改善点（排队、缺货、看不见的附件），并可回溯到利润率、周转率等数字。
6. **接触是持续纪律**：顾客信任优先于短期赢利；一旦停止接触（西尔斯），趋势判断就会失灵。

## A1 — 书中的应用 (Past Application)

### 案例 1：纳塞尔与西班牙裔年轻车主
- **问题**：市场调研问不出消费者对汽车附件的真实需求；福特豪华车市场份额出现萎缩，需要贴近决定潮流的人群。
- **方法论的使用**：纳塞尔到迈阿密拜访一群西班牙裔年轻人，并钻进一位年轻车主的车与他一起驾驶，直接观察车辆使用现场。
- **结论**：车主说自己没有给车另外添加任何附件，实际装了拖车挂钩、广角后视镜、橡皮垫和驾驶灯——他早已把它们视为这辆车的一部分，自己都意识不到。这是问卷问不出来的需求。
- **结果**：直接接触支持了福特把林肯水星分公司迁往加利福尼亚、近距离接触豪华车潮流决策者的决策（第2章，L6496–L6498，案例 b3-c16）。

### 案例 2：凯马特新 CEO 的突击巡店
- **问题**：凯马特增长速度减慢，利润率与周转率只有沃尔玛的一半，需要找出顾客体验上的问题。
- **方法论的使用**：2000 年 5 月，新任 CEO 查克·科纳韦与新任人力资源主管在预先不通知的情况下视察很多分店，直接与顾客和商店员工交谈。
- **结论**：顾客主动提供的、CEO 也亲眼确认的三大问题——等待付款的长队、杂乱的过道、货架缺货，正是"有待提高的特定领域"。
- **结果**：书中作为直接接触价值的例证（"与顾客直接的、未经过滤的接触和沟通有利于发现那些有待提高的特定领域"）；凯马特随后（2000 年 9 月）制定了包括加强物流在内的一系列优先事项（第2章，L6492，案例 b3-c15）。

### 案例 3：西尔斯女装重振与再度失守（正反两面）
- **问题**：西尔斯服装的式样和价格都不是中产阶级女性消费者所期望的，业务被百货商场与折扣店两头挤压。
- **方法论的使用**：1992 年加入管理营销部门的亚瑟·马丁内斯查明了女性消费者不喜欢西尔斯服装的真实原因，据此扩充并重新设计女装部。
- **结论**：贴近顾客可以发现趋势错位；但"接触"必须持续——90 年代末西尔斯在塔吉特、沃尔玛的竞争中再次失去立足点。
- **结果**：女装业务产生的利润一度约占西尔斯 2/3 的营业收入，销售收入 1994–1996 年从 290 亿升至 330 亿美元、营业利润率从 4.9% 升至 6.1%；随后再次失守（第2章，L6506–L6510，案例 b3-c17）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 毛利守不住、被迫频繁降价促销，想找原因，手里却只有渠道反馈、问卷与第三方报告。
2. B2B 公司客户满意度分数很高，但客户在流失、续约率下降，想弄清真实原因。
3. 要判断消费者偏好与流行趋势的变化，管理层各执一词，靠二手数据吵不出结论。
4. 产品要进入新市场/新人群，不确定"用户到底在买什么"，产品定义与渠道策略悬而未决。
5. 渠道商（分销商/零售商）与最终用户的要求相互矛盾，需要判断谁的需求优先、如何分别服务。

### 语言信号 (用户的话里出现这些就应激活)

- "客户满意度很高但客户在流失"
- "渠道反馈说……" "问卷/调研显示……" "不知道用户真正要什么"
- "毛利守不住" "我们在替用户制造麻烦" "到底该听谁的"
- 英文：voice of customer / customer visit / get close to customers / unfiltered feedback / distributor feedback / churn despite high scores

### 与相邻 skill 的区分

- 与 `b1-f04` field-visit-protocol（深入一线视察流程）的区别：那个走组织内侧（到现场了解员工、流程与执行真相）；本 skill 走市场侧（观察顾客与消费者的购买和使用行为）。同样是"下现场"，对象不同。
- 与 `b3-f10` company-panorama-seven-questions 的区别：那个用年报数字做全局体检（内部财务视角）；本 skill 用现场行为取证（外部顾客视角）——两者互补，一个回答"数字上哪里不对"，一个回答"顾客那里发生了什么"。
- 与 `b3-f01` business-acumen-six-elements 的区别：六要素提供"看什么"的通用语言（顾客是其中一要素）；本 skill 是获取"顾客"这一要素的原始数据的动作。
- 与 `b2-f19` environment-three-variables 的区别：那个分析大环境变量（宏观/行业/竞争），本 skill 聚焦终端用户；大环境变化只是触发进一步接触的背景。
- 与 `b3-f03`/`b3-f04`（R=M×V、现金视角）的区别：那两个是财务分解工具；本 skill 的发现最终要能解释这些数字，但取证手段是现场观察。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先判停：确认问题在"顾客侧"且存在可接触的现场**
   - 完成标准：能说出毛利/份额/流失等具体恶化数字，并指出可以观察的真实使用或购买现场。
   - 判停条件：若问题被证据指向纯成本结构或内部流程（与顾客行为无关），停止本流程，转 `b3-f03`/`b3-f04` 或 `b1-f04`。

2. **划清两群人：顾客（渠道/采购）与消费者（最终使用者）**
   - 完成标准：产出一张两栏对照——谁直接买、谁最终用、各自在意什么、各自向谁提要求；能指出对渠道承诺什么、对终端用户验证什么（高露洁式渠道—产品分工）。

3. **选择未经过滤的接触方式并到场**
   - 完成标准：完成至少 1 次现场接触（不打招呼巡店 / 跟车 / 使用现场观察 / 亲自接听客服来电等），记录原始事实（发生了什么、谁在做什么、卡在哪一步），而不是印象和评价。
   - 判停条件：若确实无法接触终端，改为设计替代证据链（渠道数据交叉 + 终端样本访谈），并明确声明"这是过滤信息"，不得假装等同于直接观察。

4. **提炼"未满足的特定领域"**
   - 完成标准：把观察转成 1–3 个具体待改进点，每点能定位到具体人群、场景与环节，并能回答"它解释了哪个数字"（利润率/周转率/流失率）。

5. **接入决策并建立固定接触节奏**
   - 完成标准：发现被列入优先事项清单（转 `b3-f07`）或诊断结论（转 `b3-f10`）；同时约定下一次接触的时间与形式，把"直接接触"变成纪律而非一次性调研。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要市场规模的定量估计、价格弹性研究、大规模统计调查：这些是调研方法的任务；本 skill 是补充（提供问卷问不出的信息），不是替代。
- 问题在组织内部（士气、协同、执行）：那是 `b1-f04` field-visit-protocol 的场景。
- 无法接触终端、也不做替代证据链设计时：不要硬套"巡店"叙事，输出的会是想象。
- 你观察的是自己的想象而非真实行为（如只看报表和二手总结）：这不叫直接接触，触发条件不成立。

### 作者在书中警告的失败模式

- **b3-ce16 与顾客失去接触：趋势判断失灵**。"西尔斯完全失去了对这个趋势的把握，它还是一如既往地保持与那些折扣商店相比丝毫不具竞争力的价格，从那些他们合作了很多年的供应商那里进货"（L6506–L6508）。机制：依赖中间渠道与历史经验，缺少直接、未经过滤的观察；顾客偏好的变化先在销售现场出现，组织却最后才知道。预警信号：市场份额持续小幅流失；管理层只通过分销商/调研报告看市场；顾客抱怨（排队/缺货/款式）长期不解决。
- **b3-ce19 被动降价的品牌代价**。"折扣降价和增加广告投入都会降低利润，而且这种促销手段本身也会导致品牌形象贬值。但是，公司必须承担这种负面效应，因为它们需要现金"（L6195）。现金压力下会被迫促销——这正是"接触失效"的时间差代价：用直接接触提前发现需求变化，而不是事后打折补救。
- **b3-p05 并入原则：不能以牺牲顾客利益为代价追求赢利**。"如果没有顾客的信任，其他一切都免谈"（L6500–L6504）。凡士通轮胎召回中福特停产三周优先换胎——短期利益受损，但顾客信任是其他一切的前提。

### 作者的盲点 / 时代局限

- **"顾客公平交易→忠诚→持续收入"的自动链条**（BOOK_OVERVIEW 未证假设 9）：本书缺乏对定价权、竞争结构、技术替代的讨论——直接接触能发现需求，但能否变现取决于这些未被讨论的变量。
- **"街头小贩类比"的规模断言**：作者承认大公司"复杂得多"，仍坚持商业本质一致；对跨国公司的技术颠覆、跨国政治、文化复杂度，直接观察能覆盖的范围有限（册3 批判节）。
- **样本与立场**：案例集中在作者有咨询关系的美国零售/汽车公司，存在幸存者偏差；对线上行为数据、平台型业务的"直接接触"形态没有预见（成书于 2001 年）。

### 容易混淆的邻近方法论

- 市场调研（问卷、焦点小组、净推荐值）：是过滤信息的主要来源之一，本 skill 恰恰提示不要把它的结论当作终审。
- "以客户为中心"的口号与企业文化宣传：不是动作；本 skill 要求可验证的现场事实。
- `b1-f04` field-visit-protocol：同为"下现场"，但对象是组织内部，不要互相抢调用。
