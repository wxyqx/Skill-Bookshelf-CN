# 大环境（土地）分析三变量

## R — 原文 (Reading)

> "对于大多数企业而言，大环境通常需要进行三种类型的改变：与战略计划不相匹配的文化因素和运营模式因素的改变；运营模式太小不能满足业务增长的需要或业务规模的需要；组织设计需要改变，包括在组织中权力没有足够下放的情况。"
>
> — 斯蒂芬·德罗特，第9章（fulltext L5191）

> "将企业所处的大环境想象成土地，在这片土地上，种植了企业的员工，因此，这片土地就会养育出各种类型的业绩成果……如果大环境是'土地'，员工是'种子'，被种植在这块土地上，这时领导的角色就变成了耕种的'农民'。"
>
> — 斯蒂芬·德罗特，第9章（fulltext L5163、L5165）

> "定期对'土地'进行检查。不要依靠顾问或者其他外部人士来告诉你'土地'出现了什么情况……要保证每个季度有10%的领导确实这么做了。"
>
> — 斯蒂芬·德罗特，第9章·耕地比喻的具体建议（fulltext L5325）

## I — 方法论骨架 (Interpretation)

员工是种子，领导是农民，大环境是土地——同样的种子，种在不同的土地上，长势完全不同。组织花力气育人、换人、写标准（改良种子），但若土地贫瘠（环境不善），新种子一样长不出来。作者把"土地"拆成三个可以分析的变量：

**变量一：文化要求。** 不是泛泛的"企业文化"，而是与战略匹配与否的具体取向：从"知晓者"到"学习者"（能不能承认不会、敢不敢求助、容不容错）；从家庭型（排他、依赖"父亲"、按资历与忠诚晋升）到团队型；从交易型到系统型；从只应对当下到高层做长期思考、基层做短期交付。文化不匹配战略，是换多少人都不解决问题的第一原因。

**变量二：运营模式。** 如何决策、用什么流程、标准是什么、工作在哪里做。核心问题：这套模式是不是太小了——创始人模式在十亿美元规模还撑得住吗？模式不随规模演进，就会出现"换总裁也改变不了"的局面，因为"真正的原因是公司的运营模式已经不适合目前的现实情况了"。

**变量三：组织设计。** 授权是否足够、直接下属数量是否合理（太少会造出"伪管理岗"）、官僚化程度（责任与权威是否被交给辅助/审计部门）、层级是否僵化（信息与想法上下流动的堵点在哪）。

诊断与改良的原则：先移除障碍物（岩石块、杂草——那些抑制种子生长的问题），再添加营养物（如业绩梯队）；检查不外包给顾问，领导者亲自做——每个季度保证有10%的领导实际执行"土地检查"，用"企业会如何反应"的自测问题（有新想法时是鼓励还是劝退？要快速决策时是授权还是层层上报？出错时是隐瞒还是如实上报？）访谈各层级，且"这是关于'土地'的问题，而不是关于'种子'的问题"，避免责备个人。

## A1 — 书中的应用 (Past Application)

### 案例 1: 载重运输公司转型物流：文化从"知晓者"到"学习者"
- **问题**: 公司通过并购快速成长后要从运输转向物流，但领导层的行为表现出他们是文化的"知晓者"而非"学习者"，招聘外部人才屡屡不匹配。
- **方法论的使用**: 用文化变量诊断：引入以团队为基础的衡量标准，把团队合作作为招聘标准与总裁会议的定期议题；保留家庭文化中的忠诚与关怀，但取消"表现不好也能通过考核"的惯例。
- **结论**: 文化要求必须与转型战略匹配：从"知晓者"与家庭文化转向"学习者"与团队文化，招聘失败正是文化不匹配的信号。
- **结果**: 转型后成为美国客户眼中第三方物流的首选公司。

### 案例 2: C公司：创始人模式撑不住十亿美元规模
- **问题**: 公司到了十亿美元规模，问题丛生，但更换总裁或主要领导者都不能改变局面。
- **方法论的使用**: 用运营模式变量判断——"这样的问题并不是人的问题，而是公司大环境的问题。真正的原因是公司的运营模式已经不适合目前的现实情况了。"
- **结论**: 需要对"土地"进行改良：总裁与董事会主席同意大改运营模式（见表9-1），调整产品质量流程、领导能力培养与战略规划，确保各地设施按统一标准提供同等质量服务。
- **结果**: 以可控步骤分步实施新运营模式，而非靠换人解决。

### 案例 3: 保守保险公司：把政策从"不能做什么"改为"要做什么才能成功"
- **问题**: 官僚化的控制体系让被收购公司的领导失去主人翁感，决策需要层层审批。
- **方法论的使用**: 改造组织设计变量——第一个主要决定是发布"要做什么才能取得成功"的行为政策，而非禁令清单；建立"预先评审"制度：董事会成员可提异议但不得单方否决。
- **结论**: 授权不足的根源常在控制设计（谁有否决权），把否决权改为异议权，主人翁感才能回来。
- **结果**: 被收购公司领导接受授权政策，工作效率更高、工作更投入。

### 案例 4: 服装零售商：被短期思维困住的行业
- **问题**: 服装零售商常到公司之外找CEO，因为没有从长期角度对培养和发展员工作出规划；过度扩张与只应对当下需求普遍存在。
- **方法论的使用**: 用文化变量中的时间取向诊断：品牌特色、采购、合作关系、人员、设备、信息技术与资金都需要长期思考，而行业内普遍被季度循环绑住（零售业的季度循环 vs 战略循环）。
- **结论**: 需要新的文化要求——高层长期思考、基层保持短期交付导向。
- **结果**: 该诊断成为第9章"长期思维"文化要求的支撑案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新CEO/总经理上任推行变革，团队成员能力不差但推不动，用户问"该先动人还是先改环境"。
2. 公司换了总裁、请了顾问、做了培训，问题依旧，用户怀疑"是不是人的问题"。
3. 要推一项需要全员学习/暴露问题的变革（数字化转型、质量改进、文化变革），员工却不敢承认不会、不敢求助。
4. 组织规模上了台阶（如从几亿到十亿），创始人/元老的工作方式成为瓶颈。
5. HR或OD负责人被要求做"组织诊断/文化诊断"，需要一套可访谈、可检查的分析框架。

### 语言信号 (用户的话里出现这些就应激活)

- "先动人还是先改环境？" / "change people or change the environment?"
- "换了几任领导还是老样子" / "new leaders, same problems"
- "员工不敢承认不会、不敢求助" / "knower culture, afraid to ask"
- "创始人模式/老办法撑不住了" / "founder mode no longer works at scale"
- "土地/种子/农民" / "environment assessment, culture audit"

### 与相邻 skill 的区分

- 与 `culture-performance-linkage`（b1-f05）的区别: 册1 把文化变革与绩效目标直接联结（目标→条件→奖励→教练）；本 skill 先诊断"土地"三个变量的缺失，再决定改什么。
- 与 `performance-pipeline-interview-build`（b2-f03）的区别: 建队流程解决"标准"，本书作者明确警告过度依赖业绩梯队——环境不支持，"营养物"加得再多也没用；两者是"种子"与"土地"的分工。
- 与 `leadership-deficit-four-causes`（b5-f30/f31）的区别: 册5 从组织缺陷看领导层缺失；本 skill 给出三个可改变变量的具体清单与土地检查法。
- 与 `assumptions-and-contingency`（b1-f22）的区别: 后者处理计划前提假设；本 skill 处理执行环境的载体（文化/模式/设计）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **明确战略与需要的改变**
   - 写清当前战略/变革要求"土地"支持什么（学习、协同、长期投入、授权……）。
   - 完成标准: 一句话说明"新的业绩要求是什么，因此环境需要支持什么"。

2. **文化变量诊断**
   - 对照清单：知晓者 vs 学习者（能否承认不会、能否求助、容错度）；家庭型 vs 团队型（晋升依据、外部人才能否进入）；短期 vs 长期（高层是否做长期规划）；互不往来 vs 信息自由流动。
   - 完成标准: 每个维度给出"现状证据＋与战略是否匹配"。

3. **运营模式诊断**
   - 对照问题：决策如何做、流程与标准是什么、工作在哪里完成；模式是否还适配当前规模（创始人模式还能撑住多大的盘子）？模式不动、只换人是否能解决？
   - 完成标准: 明确指出"适配/过小"及需要重构的模式要素。

4. **组织设计诊断**
   - 检查授权程度（是否有事实否决权、是否层层上报）、直接下属数量（是否出现"伪管理岗"）、官僚化（责任是否被移交给辅助/审计）、层级僵化（信息与想法在哪一层被堵）。
   - 完成标准: 三个子项各给出证据与结论。

5. **执行"土地检查"访谈（自测问题）**
   - 用"企业会如何反应"的自测问题访谈各层代表：有新想法时鼓励还是劝退？重大决策时授权还是层层上报？开销超预算时有人在乎还是只受罚？发现问题时鼓励如实上报还是希望"说得好听"或拖延？
   - 规则：不急于承诺、先多听多确认趋势、避免责备员工（"这是关于'土地'的问题，而不是关于'种子'的问题"）、反馈结论给员工后再行动。
   - 完成标准: 每季度10%的领导实际完成检查；产出问题清单（最常被提及者优先）。

6. **先移除障碍，再添加营养物**
   - 先移除"岩石块、杂草"（障碍物）——很多问题会随之消失；再添加营养物（如业绩梯队、衡量标准、培训）。按可控步骤分步实施。
   - 完成标准: 障碍清单与移除计划（含责任人与期限）；营养物添加计划排在障碍移除之后。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把它变成"责备文化"运动："土地检查"的纪律明确是不责备个人、不做人身评价；若用户意图是找人为问题背锅，不能调用。
- 组织尚未决定战略方向：文化要求"与战略计划相匹配"——没有战略，就没有匹配的对象。
- 只想做一次性的团建或文化宣传：本框架要求领导者亲自周期性检查与移除障碍，不是活动。
- 涉及解雇/降职等以"文化不匹配"为名的处置：须依当地劳动法与公司程序，并给出改进机会（系列级伦理边界）；本 skill 不提供人事处置方案。
- 小规模组织且无实际层级：三个变量可简化为"文化取向＋决策方式"，无需全套机制。

### 作者在书中警告的失败模式

- **知晓者文化（b2-ce03）**：不容错、不求助、知识垄断——"总裁是不能容忍管理者犯错误的……使得新的管理者不敢承认他们缺乏相关的管理知识或技能，也不敢去寻求帮助"，学习通道关闭，过渡缓慢且不完整。
- **家庭文化与资历/忠诚晋升（b2-ce04）**：排他、依赖"父亲"、按忠诚与资历晋升、表现差也能通过考核；外部人才察觉不匹配不愿加入，"公司所有的重大决策都要向上传递到总裁那里去"。
- **互不往来（b2-ce05）**：抑制信息自由流动的壁垒，跨部门缺乏对话，新领导的学习范围狭窄，"学到的是不与他人分享的文化"，自己也成为问题的一部分。
- **低效率文化（b2-ce06）**："足够好就已经足够了"：任务刚完成就行、刚好符合预算、把含事实性错误的报告呈给上级、容忍低绩效员工；标准太低，"实现完全的层级过渡、实现所有需要的业绩就成了不可能发生的事情"。
- **官僚主义（b2-ce19）**：把管理者的责任与权威交给职员、辅助人员、审计人员、会计；"领导者们会失去主人翁感……顺从和冷漠就会取代本该有的工作动力"。
- **组织随意增长（b2-ce21）**：直接下属只有2~4个的"伪管理岗"，管理时间填不满，管理者回去做技术性工作，人才培养断档。

### 作者的盲点 / 时代局限

- **科层制与美国大公司原型**：三变量以GE式稳态大公司为背景（每季度10%的领导做检查、层级清晰为前提）；对平台型/敏捷组织，"文化要求、运营模式、组织设计"的切分是否仍是最佳分解，书中未验证。
- **把文化当可控变量**：本书假定文化可以被领导者有意识地改写（"领导允许层级僵化，僵化才会存在"），未讨论自组织、亚文化与文化惯性的抵抗；社会工程式假设明显。
- **缺少改变的方法论**：诊断清单完备，但如何具体改变文化（尤其涉及权力、历史恩怨、利益格局）在书中着墨甚少。
- **"土地优先"被绝对化**：作者强调环境决定一切，个人能力与选拔的作用被弱化；实际是环境与人的互动（书中案例也无法区分因果）。
- **样本偏差**：案例均为作者咨询企业，缺乏失败对照；"观察到的改变"背后可能另有变量。

### 容易混淆的邻近方法论

- 与 `culture-performance-linkage`（b1-f05）：册1 偏"把文化与绩效目标、奖励、行为联结起来"；本 skill 偏"把文化、模式、设计当土地先诊断"，可先后串联。
- 与 `performance-pipeline-interview-build`（b2-f03）：先看用户要改的是"标准"还是"环境"；作者明确二者是营养物与土地的关系，不可互相替代。
- 与 `role-clarity-gaps-overlaps`（b5-f21）：职责澄清属于组织设计变量的具体一步；用户若只要澄清职责，不必动用土地检查。
