# 潜能三分类：转型/成长/熟练

## R — 原文 (Reading)

> "在讨论这些标准之前，我们强调个人的潜能判断必须要考虑前面章节里提到的绩效标准。一个人若能保持较高的绩效水平（至少三年），则很可能具备转型潜能。如果一个人的绩效水平不稳定，则可能具备成长潜能。也有些人能够做出成效但却在不适当的层级工作，如果能够在适当的层级工作，就可能开发出转型潜能。"
>
> — 查兰/诺埃尔/德罗特，第10章（L11956）

> "潜能是指一个人在将来能完成的工作。……转型潜能——在3~5年内能够承担下一层级的任务；成长潜能——在3~5年内能够承担相同层级上更重要的工作；熟练潜能——能够继续在现任或相似职位上增强能力。"
>
> — 同上，第10章（L12093）

> "在运用这些标准以及与他人讨论这些标准时不要轻视成长潜能或熟练潜能。……熟练潜能也铺设了通向卓越绩效的道路。"
>
> — 同上，第10章（L11964）

## I — 方法论骨架 (Interpretation)

把"高潜/非高潜"的二分换成三类可操作的定义。潜能不是一个人身上的固定属性，而是"他在将来能完成的工作"，按时间和幅度分三档：

- **转型潜能**：3–5 年内能够承担下一层级的任务——证据是持续的高绩效（至少三年）。
- **成长潜能**：3–5 年内能够承担同一层级上更重要的工作——证据是绩效水平不稳定，但能力尚可开发（常见于新手、跨职能转换者、被环境限制者）。
- **熟练潜能**：能够继续在现任或相似职位上增强能力——证据是在现职持续做得更好，但不指向更高层级。

判定有三条纪律。第一，先看绩效再谈潜能：绩效是入场券，且必须结合岗位层级一起看；"有些人能够做出成效但却在不适当的层级工作，如果能够在适当的层级工作，就可能开发出转型潜能"——错层的人要先归位再评。第二，绝不能把潜质等同于表现，也不能只看学历、名校、口才与仪表。第三，三类对公司都有价值：成长潜能适合业务扩张时的更大任务与全球化布局，熟练潜能是走向卓越绩效的通道；"不要轻视成长潜能或熟练潜能"。

潜能是动态的：客户需求、竞争、产品与技能要求都在变，"最坏的情况是出现正负的评价永远不变"，因此继任与潜能鉴定至少每半年复核一次，愿意根据个人与工作的新情况修改结论。

用途在于对话与配置：说清"你具备哪类潜能、证据是什么"，比笼统的"你是高潜"更能让人做出理性的发展选择（接不接艰巨任务、走哪条路）；同时它也是给管理者一个统一原则——关注"简是否具备转型、成长或熟练潜能"，而不是"简是否具备成为优秀领导者的潜能"。

## A1 — 书中的应用 (Past Application)

### 案例 1: "平步青云者"——用潜能分类拆掉精英心态
- **问题**: 管理者和 HR 对刚出校门的学生宣称他们"即将飞黄腾达"来吸引入职；被贴上这个标签的人害怕失败、失去优越地位，于是拒绝承担艰巨任务，反而错失了每个层级必需的转型与成长。
- **方法论的使用**: 在继任计划里公开使用三类潜能语言，并告诉每个人他在哪条"弯道"上（"领导梯队不是一根笔直的管道而是有六道90度拐弯的弯道"），让其知道下一步该做什么。
- **结论**: 一旦员工清楚自己被认定为具备转型、成长或熟练潜能，以及每层的要求，就能理性选择如何积极追求自身发展；潜能分类把"飞黄腾达"的许诺替换为可讨论的路径。
- **结果**: 高潜能员工从被动等待标签变成主动参与继任计划，因为他们清楚管理层对他们的期望以及需要做什么才能晋升。

### 案例 2: 通用电气——"C 阶段"评估层级变化准备度
- **问题**: 领导者面对职位与层级变化时，组织难以判断谁真的准备好了；临时凭印象选拔风险极大。
- **方法论的使用**: GE 用"C 阶段"程序专门评估领导者对职位/层级变化的准备情况，并据此配置业务知识、领导能力与文化技能的培训。
- **结论**: "准备好承担下一层级"就是转型潜能的制度化表达：把准备度作为可讨论、可培训的结论，而不是给个人一个含糊的高潜标签。
- **结果**: GE 几十年保持数名可随时接任 CEO 的候选人，9 位 CEO 全部内部产生，成为领导者的"黄埔军校"——潜能分类配合制度才能兑现。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队里有人绩效一般但稳定、从不出错，用户拿不准该评价为"没潜力"还是"熟练潜能"，担心伤了老员工。
2. 要做高潜人才名单/发展计划，需要一套比"高潜/非高潜"更细的分类与证据规则。
3. 员工问"我到底能不能升"，管理者说不出证据，只会说"再等等"。
4. 某人业绩不错但一直被评价"不稳定"，要判断这属于成长潜能还是需要归位后再评。
5. 上一次的人才评价结论放了很久没更新，需要一套复核纪律修正过期标签。

### 语言信号 (用户的话里出现这些就应激活)

- "他到底有没有潜力？/ 能不能进高潜名单？"
- "这个老员工绩效一般但从不出错，怎么评价他？/ 是不是该放弃了？"
- "他说想升职，我拿什么标准回答他？"
- "high potential" / "potential review" / "is he promotable" / "how far can this person go"

### 与相邻 skill 的区分

- 与 `b5-f29 nine-box-actions` 的区别: 本 skill 回答"潜能怎么判定、分哪三类、证据是什么"；九格矩阵回答"把绩效与潜能组合后放在哪一格、每格做什么"，前者是后者的输入。
- 与 `b4-f04 leadership-potential-double-helix` 的区别: 双螺旋是入口判据（谁值得培养，看驭人之道×经商之道）；本单元是出口判据（培养到什么程度、能到哪一层级）——一个看禀赋，一个看可承担的工作范围。
- 与 `b5-f27 succession-five-steps` 的区别: 继任五步骤是制度框架；本 skill 是第四步评估中使用的潜能语言，脱离制度单独使用时注意别变成贴标签。
- 与 `b4-p12 assessment-dual-track` 的区别: 评估双轨解决"业绩考核不等于领导力评估"；本 skill 在领导力评估内部进一步区分三类潜能。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先确认"潜能≠表现"，并锁定评估对象**
   - 完成标准: 明确写出评估对象在当前层级的工作年限与绩效记录情况；对任职时间过短（无连续绩效可查）者，标注"数据不足，暂不分类"。
   - 判停条件: 若此人当前层级明显错配（在做上层或下层的事），先做职责澄清/归位，再回到本流程——错层会污染潜能判断。

2. **收集绩效证据（至少三年视角）**
   - 完成标准: 至少列出近三年（或全部在职期）的分段绩效结论与关键事件，包括是否有持续性、是否跨情境（不同环境/任务）成功；区分"成果好"与"方法对"。

3. **按三类给出判定与理由**
   - 完成标准: 对每个人输出一句"潜能类别＋证据＋时间窗"的结论，例如"转型潜能：连续三年在本层全面绩效，具备在 3–5 年内承担下一层级任务的证据"；禁止只写"高潜"两个字。
   - 判停条件: 若证据只支持"能力强但绩效不稳定"，判为成长潜能并指明环境/动机等限制因素；若证据是"在现职持续增强"，判为熟练潜能，不得硬拔为转型。

4. **与本人做发展对话（透明使用分类）**
   - 完成标准: 向当事人说明分类、证据与下一步选项（更大任务、同层更重要工作、或深耕现职），并记录其发展意愿——三类潜能都要尊重，意愿是配置动作的必要输入。

5. **设置复核闹钟并维护动态性**
   - 完成标准: 至少每半年复核一次；复核内容包括客户/竞争/技能要求的变化以及个人新表现；明确"正负评价不得长期不变"，变更时留下修订记录。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 没有连续绩效记录、或此人任职不足一个完整周期时——此时分类就是拍脑袋。
- 用户真实目的是"找个理由淘汰人"：潜能分类不是处置工具，用它给裁员找依据会同时毁掉制度信用与合规性。
- 招聘筛选场景：本书的潜能判据以在岗绩效证据为基础，不适用于简历筛选。
- 把三类潜能当成绩效等级或薪酬依据：它描述"将来能做什么"，不是"过去值多少钱"。

### 作者在书中警告的失败模式

- **把潜质等同于表现**: "人才库的概念促成了一些继任计划，但从领导梯队的角度来看，这一概念存在缺陷。……问题在于人才库存将潜质等同于表现。我们发现具备高潜质的人并不一定能成为拥有高绩效的人。"（b5-ce27，第10章 L11900–L11904）
- **潜能评价永远不变＋靠直觉**: "最坏的情况是出现正负的评价永远不变。继任工作和潜能鉴定需要至少每半年进行核查。"（b5-ce28，第10章 L12095）——伦理提示：潜能标签会实际影响晋升与薪酬，须防止标签固化造成事实上的歧视或"自我实现预言"，评价数据应按人事档案规范管理（b5-ce28 ethics_legal_note）。
- **"平步青云"式承诺的反噬**: 用飞黄腾达的许诺招人留人，使人害怕失败、拒绝艰巨任务，错失每层级必需的转型（第10章 L11943）。

### 作者的盲点 / 时代局限

- **判据缺乏效度证据**: "三年持续高绩效→转型潜能"等规则来自咨询经验，没有预测效度检验，且存在循环论证风险（判据可能就是"已在岗位上表现出色"）（BOOK_OVERVIEW 批判节）。
- **精英筛选的人力代价**: 分类若管理不善，会自我实现地制造"胜者—陪跑者"结构，误判大器晚成者的代价被系统性低估；对"被判定为熟练潜能者"的士气与公平路径讨论不足。
- **美国大公司语境**: 以长周期、层级分明、内部培养为主的公司为背景；职业流动快、扁平化组织中的适用性需重新评估。
- **潜能可训练性的心理测量空白**: 作者对"潜能可开发"的机制解释缺乏可操作的心理测量支持。

### 容易混淆的邻近方法论

- **九宫格/人才矩阵**: 那是潜能与绩效的组合工具；本 skill 只管其中"潜能轴"怎么判定。
- **继任计划**: 那是制度；本 skill 是其评估环节的判据，不能代替制度。
- **能力素质模型（competency framework）**: 那描述静态素质项；本 skill 描述未来可承担的工作范围，必须以绩效证据与层级要求为锚。
