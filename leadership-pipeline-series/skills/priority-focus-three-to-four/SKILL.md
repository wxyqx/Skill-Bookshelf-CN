# 优先事项聚焦（少而稳定的 3~4 项）

## R — 原文 (Reading)

> "在实际情况中，商业智慧能够帮助CEO选择3项或者4项（不超过5项）既能够留住顾客，又能达到所有赢利目标的优先事项（重点工作）。……一项优先事项可以确定在某一特定时间段需要采取的最重要的行动。"
>
> — 查兰，第4章（L6666–L6668）

> "必须做出判断，什么事情是你的部门、分部或者公司一定要做的，什么又是必须停止做的；还必须决定哪些事情必须优先处理，同时要和公司的目标协同一致。这些焦点不应该太多，也不要经常变化，必须明确地反复强调它们。"
>
> — 查兰，第9章（L7247）

> "不要被宏伟的目标弄得云山雾罩。把你的愿景聚焦到5万英尺以下，这样你就能够用简单清晰的语言说明你要做什么，以及为什么这样做会使你赚钱。"
>
> — 查兰，第9章（L7249）

---

## I — 方法论骨架 (Interpretation)

组织失焦很少是因为没人努力，而是因为"重点"太多且彼此打架。这个方法把"聚焦"从口号变成一组硬约束：

1. **数量约束**：优先事项 3~4 项，不超过 5 项。超过这个量级，资源无法形成合力，"十个顺序清晰的目标"实际等于没有目标。
2. **方向约束**：每一项必须同时服务两件事——留住顾客、达到赢利目标；用运营语言（不是愿景口号），能讲清"你要做什么，以及为什么这样做会使你赚钱"。
3. **稳定性约束**：不频繁变化。焦点频繁更换会让组织疲惫、执行归零；换清单需要明确条件（环境突变），而不是新官上任或季度冲动。
4. **取舍约束**：必须回答"什么事情是你的部门、分部或者公司一定要做的，什么又是必须停止做的"。停止栏为空，说明还没做真正的选择。
5. **沟通约束**：自上而下反复强调，直到全组织对齐；用简单语言把愿景"聚焦到5万英尺以下"，让每个层级都能转译成自己的行动。
6. **闭环**：优先事项是化繁为简（`b3-f06`）的产出物，也是后续沟通机制（`b3-f13`）、教练辅导（`b3-f12`）与资源配置的输入。它把"公司怎么赚钱"从分析变成全组织可执行的语言。

## A1 — 书中的应用 (Past Application)

### 案例 1：福特提升 P-E 值的三大优先事项
- **问题**：福特的 P-E 值只有 8 倍，远低于标普 500 公司的 23 倍；汽车价格持续下降，公司需要让投资者相信自己能持续改善基本要素。
- **方法论的使用**：纳塞尔围绕六要素设定三项优先事项——提高顾客满意度（同时提升周转与利润率，维系老客更经济）、使用"用户推动的六西格玛"工具（如 3 次铃响接起电话、百万次 3 次失误）、把优秀品牌推向全世界（捷豹/林肯/沃尔沃/路虎）；并每周给 35 万员工写信反复沟通。
- **结论**：提升估值要靠从基本要素推导出的少数优先事项，而不是宏大叙事。
- **结果**：书中作为"管理层级联示范"；福特对顾客满意度的重视直接支撑了凡士通召回时的果断决策（第5章，L6812–L6829，案例 b3-c26）。

### 案例 2：EDS 迪克·布朗的四项优先事项
- **问题**：EDS 年增速仅 9%~10% 低于行业 15%、资产收益率持续下降、股价跌了一半；20% 的销售人员过去 9~12 个月没有开出新业务，激励资源投向大而未必有收益的项目，业务部门有重复冗余资源。
- **方法论的使用**：六天诊断（含读全部材料+走访所有主管）→集体讨论找症结→确立四项优先事项：通过其他供应商而不只是通用汽车实现收入增长并超过市场平均值；提高客户服务水平；降低 10 亿美元成本以提升利润率；2000 年年底实现两位数利润率。
- **结论**：先有清晰简单的优先事项清单，再谈人员潜能与协同机制（清单本身只是成功的一部分条件）。
- **结果**：到 1999 年年底实际削减 10 亿美元成本，简化运作、更以客户为本，"从此，电子数据系统公司变得日益壮大"（第8章，L7130–L7156，案例 b3-c36→并入 b1-c04）。

### 案例 3：零售连锁巨头的三级传导
- **问题**：新 CEO 面对目标不集中的问题，公司主张多建商店，他认为建造更多商店只会让问题更严重。
- **方法论的使用**：拒绝多建商店，聚焦"可比销售额"与"总边际利润"；然后把目标分三级传导：与 10 名直接下属讨论方案 → 100 名执行官两天研讨会并各定 90 天计划 → 再向几百名营销负责人与店长重复。
- **结论**：少数重点要在层级间反复讲、逐级转译，才能形成对齐。
- **结果**：截至 2001 年 12 月总边际利润大幅提高，股价上涨近一倍（册1，L969，案例 b1-c11，并入本单元）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队同时跑 20 个改进项目，资源与人手打架，要决定砍到什么程度。
2. 战略/年度目标写出来了，但里面有十条"重点"，向下讲不清楚、资源平均摊薄。
3. 优先事项每季度换一轮（或新官上任就换），组织疲惫、方向感丧失。
4. 上下对"什么最重要"的回答不一致，各层级自行解释目标。
5. 会议里每一件事都被称为"重要"，需要强制产出"必须停止做"的清单。

### 语言信号 (用户的话里出现这些就应激活)

- "十个重点等于没有重点" "项目太多做不完" "怎么砍"
- "老板的想法老变" "每件事都重要"
- "讲不清最重要的是什么" "资源都摊薄了"
- 英文：too many priorities / what to cut / stop doing list / top 3 priorities / everything is a priority

### 与相邻 skill 的区分

- 与 `b3-f06` complexity-to-priorities 的区别：`b3-f06` 负责**推导**优先事项（因素→关系→基本行为→优先事项）；本 skill 负责对这份清单做**纪律收口**（数量、稳定性、两栏取舍、反复强调）。清单未形成时先用 f06，清单已有一堆项要砍时用本 skill。
- 与 `b3-p08` not-betting-is-betting 的区别：`b3-p08` 处理"不敢选/总在等"；本 skill 处理"选太多/选完了守不住"。前者是决断纪律，后者是聚焦纪律。
- 与 `b1-p08` follow-through-discipline 的区别：那个管"决定之后持续跟进直至达成"；本 skill 管"先选对少数重点，并把它们反复讲下去"。
- 与 `b1-f16` bedrock-strategy-one-pager 的区别：那个是战略表达法（一页纸怎么写得让人记住）；本 skill 是取舍纪律（哪些进、哪些出）。表达法解决"写不清"，本 skill 解决"选太多"。
- 与 `b5-f02` three-dimension-transition 的区别：那是个人层级转型的三维度；当新经理把"事事亲自做"当优先事项时，先做本 skill 的取舍，再谈角色转型。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **收集现行全部重点（含隐性）**
   - 完成标准：把目标、项目、KPI、老板口头强调事项全部列出并标注推动人/资源占用；清单数量可见（例如 20 项）。

2. **用四把尺筛选**
   - 尺一：是否服务"留住顾客 + 赢利目标"（与现金/利润/周转挂钩）；
   - 尺二：总数压到 3~4 项（不超过 5）；
   - 尺三：能否稳定一段时间（不频繁变更）；
   - 尺四：能否用简单语言讲清"做什么 + 为什么这样做会赚钱"。
   - 完成标准：每项明确通过或出局，出局项写明理由；入选清单能一句话说清每项如何影响赚钱。

3. **两栏取舍："必须做" / "必须停止做"**
   - 完成标准："停止做"栏至少 1 项，并把停止决定通知受影响方（含资源释放方案与合规/合同例外标注）。
   - 判停条件：若某项因合同/合规无法停止，标注例外并写明代价，不硬性删除。

4. **向下反复强调，逐级转译**
   - 完成标准：设计重复沟通的节奏与载体（如纳塞尔每周给员工写信、三级传导会）；至少完成一轮向下传达，并抽检 2~3 个层级能否复述"最重要的几件事及理由"。

5. **设复核点并守住稳定性**
   - 完成标准：写下复核周期（建议季度而非每周）与"什么情况下才允许换清单"的条件；把清单交给 `b3-f06` 复核因果链条、交给 `b3-f13` 设计配套沟通机制。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 危机应对期：需要单点全组织动员（如现金流断裂救援），常态的 3~4 项清单不适用，先保生存（`b3-f04`）。
- 个人待办与时间管理：本 skill 的对象是经营优先事项，不是日程管理。
- 没有经营目标语境的场景（纯使命型、非营利）：尺一需要改写后再使用。
- 你无权调整资源与考核：此时清单只是愿望——先解决授权，或从小范围试点开始。

### 作者在书中警告的失败模式

- **b3-ce18 领导者不设优先事项，公司失去活力**："如果领导人不能设定优先事项，持续改变自己的思维模式，或者不能清晰有效地沟通，整个公司就将失去活力"（L6703–L6705）。机制：不设优先事项＝默认所有事项同等重要；缺乏清晰沟通使各层级自行解释目标。预警信号：优先事项超过 5 项且每季度变化；各层级对"最重要的是什么"回答不同；大量项目齐头并进、无一完成。
- **b1-ce13 目标不现实或未获实施者认同**（并入证据，L705）：上层单方下达高目标、无人解释如何实现，最终计划落空、季度连续下调预期。机制：目标制定与执行能力、资源、人员脱钩；实施者不认同便没有承诺。预警信号："目标已定你只需完成"；无人能回答"如何实现"。
- **b3-p06 并入原则**：领导者必须设定 3~4 项优先事项并反复强调；"不下注本身就是一种赌博"（等待一切明朗等于选择保持现状）。

### 作者的盲点 / 时代局限

- **数量阈值缺乏实证**：3~4 项（≤5）来自作者咨询经验，没有研究证据；不同复杂度与规模的组织可能需要调整——把它当纪律起点而非自然定律（BOOK_OVERVIEW 未证假设 6：业绩标准写清楚并不自动带来业绩）。
- **单因论与财务化还原**：把经营压缩为少数财务导向的重点，跳过战略质量、组织政治与治理约束（BOOK_OVERVIEW 立场盲点）。
- **"文化可被会议日历＋强 KPI 设计"的社会工程假设**：在知识密集型/创意型组织，强焦点＋强考核可能适得其反（2010 年代敏捷与心理安全研究提供了相反证据）。
- **美国大公司语境**：案例为福特、EDS、GE、零售连锁等，对扁平化团队、跨文化组织的适用需本地化调整。

### 容易混淆的邻近方法论

- OKR：目标管理框架，可同时承载多个目标（含学习型目标）；本 skill 是经营重点的取舍纪律，不反对用 OKR 作载体，但要求数量与稳定性受约束。
- 战略地图/平衡计分卡：多维度的上-下对齐体系；本 skill 是"先砍到少数"，不负责多维度展开。
- 待办清单与优先级排序（个人效率方法）：量级与对象不同，不要互相替代。
