# 选人不能只看一个绩效因素，要问"能否接受新理念"

## R — 原文 (Reading)

> "相邻两个层级的总体要求可能相近，但在具体的领导技能、时间管理能力和工作理念方面则显示出重大的差别……在做出选择决定时，应注重候选人能否在明显不同的环境中做出成绩。询问一个人能否顺利地接受新的理念。他是否已获得所需的技能，能否轻易地改变他分配时间的方式？"
>
> — 查兰/诺埃尔/德罗特，第11章（L12145–L12147）

> "有些候选人在整个职业生涯中惯于依赖同样的领导技能、时间管理能力和工作理念，如果你知道他们确有这样的问题，要意识到你将他们提拔至更高的领导层级就是在让他们走向失败。"
>
> — 同上，第11章（L12147）

> "他并没有任何大的过失，但问题是他没有遇到什么逆境，所以他很可能无法应付公司当前所面临的形势。"
>
> — 博西迪/查兰/伯克，册1《执行》第6章（L1748，跨册互证）

---

## I — 方法论骨架 (Interpretation)

晋升决策最常见的失误是"单因提拔"：候选人现任岗位成绩好，于是被认为能胜任更高层级。作者指出这是错的，因为相邻层级"总体要求相近、具体差别重大"——理念、时间结构与技能都要换一套。因此提拔前要做三项尽职调查（"三必问"）：

1. **能否在明显不同的环境中做出成绩**——他的成功是只能在熟悉领域复制，还是换过环境（不同市场、不同业务、不同职能、逆风期）也能成？顺境业绩不能证明抗压能力与迁移能力。
2. **能否接受新理念**——对与旧理念冲突的新要求，他的反应是什么？关键行为证据是：会上同意、会后照旧，就是红灯；领导层级越往上，理念（"什么重要、什么该放弃"）越是决定成败的枢纽。
3. **是否具备新技能且愿意改变时间分配**——不只是"会不会"，还要看"愿不愿意"：愿不愿意把时间从自己做转到他做，从运营转到规划、选人、整合。

作者给出的底线判据：如果候选人的整个职业生涯都依赖同一套技能、时间结构与理念，那么"你将他们提拔至更高的领导层级就是在让他们走向失败"——组织为此付出的代价远大于个人（书中以 18 个月损失 10 亿美元为量级的案例说明）。因此要么宁缺毋滥，要么先安排过渡性历练（跨环境任务、越级任务）再决断。

配套的逆镜检查（跨册证据）来自册1：履历漂亮、零过失但从未打过逆风仗的人，很可能在环境转恶时全盘被动；"没有遇到什么逆境"本身就应作为证据不足处理，而不是加分项。

## A1 — 书中的应用 (Past Application)

### 案例 1: 保罗 vs 罗杰——四人小组四小时推翻提拔倾向
- **问题**: 公司考虑把保罗提为部门总裁乃至 CEO 候选人。保罗无可指摘、业绩稳定，但从未经历过逆境。
- **方法论的使用**: 决策小组（四人）围绕"他能否在不同环境中做出成绩"激烈争论四个小时，逐条比对两位候选人的经历证据；结论是保罗"并没有任何大的过失，但问题是他没有遇到什么逆境，所以他很可能无法应付公司当前所面临的形势"。
- **结论**: 顺境中的优秀与危机中的胜任是两回事；同环境、同方法、无逆境的履历不构成晋升证据。
- **结果**: 保罗被排除在部门总裁与 CEO 候选人之外；该公司由此为领导管道建立了更严格的选拔标准。

### 案例 2: 杰瑞与蒂姆——只看一个绩效因素，18 个月损失 10 亿美元
- **问题**: CEO 杰瑞因蒂姆在事业部总经理任上营收与赢利俱佳而提拔他做公司高管。蒂姆沿用旧法，大举投资所有未开发市场；团队进入既不熟悉又无资源的领域，执行力崩溃。
- **方法论的使用**: 复盘时用层级要求逐项对比：职能部门理念问"我们能做到吗"、事业部总经理问"我们应该做吗"、公司高管问"哪个选择能在现在和将来带来最好结果"；蒂姆的理念比岗位低了两级——他从未被考察过"是否具备新技能、是否愿意改变时间分配、能否接受新理念"。
- **结论**: "在一个层级上做出成绩不应成为选择某人担任更高层级职务的主要原因"；应注重候选人能否在明显不同的环境中做出成绩。
- **结果**: 蒂姆在任 18 个月后被撤职，公司损失 10 亿美元；杰瑞在其职业生涯中因两个选人决定各损失 10 亿（另一例是文斯）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 候选人过去三年业绩全优，但要接的岗位要求完全不同，用户拿不准敢不敢提。
2. 团队讨论提拔时，唯一的依据是业绩数字或"他资历够了"，需要一套可操作的核查清单。
3. 老板已有人选倾向，需要独立地做一次"该不该用他"的尽调（尤其涉及老部下、旧交情时）。
4. 要为高潜者安排跨环境历练（轮岗、逆境任务），需要说清"为什么要先换环境再提拔"。
5. 复盘过去的提拔失败时，要检查当初漏掉了哪一问。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要提他？/ 他业绩全优，能升吗？"
- "敢不敢把这个人放到那个位置上？"
- "他在现在的岗位很成功，换个岗位还行吗？/ 他能接受新玩法吗？"
- "is he ready for promotion" / "promotion decision" / "due diligence on a candidate" / "can he handle a different role"

### 与相邻 skill 的区分

- 与 `b5-f30 leadership-deficit-four-causes` 的区别: 四因复盘是事后归因"失败从哪来"（选错人只是其中一因）；本 skill 是事前尽调——提拔决策前必须走完的核查清单。
- 与 `b4-p12 assessment-dual-track` 的区别: 评估双轨解决"绩效考核不能替代领导力评估"（两套体系）；本 skill 是单次提拔决策内的三项证据要求（不同环境成绩/新理念/新技能与时间）。
- 与 `b4-f04 leadership-potential-double-helix` 的区别: 双螺旋是潜质的入口判据（驭人之道×经商之道）；本 skill 是就某一次提拔做尽职调查，回答"这次该不该动"。
- 与 `b5-f28 potential-three-types` 的区别: 潜能三分类给某人一个 3–5 年时间窗内的类别；本 skill 针对具体岗位做证据核验，反例是"整个职业生涯依赖同一套模式"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出目标岗位的层级要求与新旧差别**
   - 完成标准: 一页纸列出该岗位在领导技能、时间管理、工作理念三方面的要求，并逐项标注与候选人现任岗位的"相同/不同"；不同项即本次尽调的重点。

2. **三问取证（每问必须有具体事例，不接受概括评价）**
   - 完成标准: ① 不同环境成绩——列出他在至少一个与本次岗位明显不同的环境/任务中做出成绩的证据（含跨职能、跨市场、逆风期）；② 新理念接受度——列出他面对与旧做法冲突的新要求时的具体反应，出现"会上同意、会后照旧"即记为红灯；③ 新技能与时间重排——列出他已具备的目标层级技能缺口清单，以及愿意把时间从哪转到哪的明确承诺。
   - 判停条件: 若三问中任何一问只有概括性评价而无事例，标为"证据不足"，不得进入步骤 3 的通过结论。

3. **做"同一套模式"逆镜检查**
   - 完成标准: 明确回答——他的整个职业生涯是否依赖同一套技能/时间/理念？若是，写出结论："提拔他就是在让他走向失败"，并给出替代路径（先过渡历练、留在现层承担更大任务、或选其他人）。

4. **形成决策建议并写明代价**
   - 完成标准: 输出三选一建议——提拔（附条件与就任初的培养安排）／先历练再议（写明历练岗位与检验标准）／不提（写明替代人选或空置安排）；同时写明错误提拔的代价量级（书中案例为 10 亿美元级损失）与宁缺毋滥的理由。

5. **若决定提拔，立即接续缺口管理**
   - 完成标准: 就任初即告知"晋升必然带来绩效缺口"并启动培养计划（转 b5-f23 的四步循环）；明确上司在这一过程中的教练责任。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 同级轮换、临时代理、行政性任职——不涉及层级转换，三必问会显得过度。
- 已经掌握充分证据、只差走流程的决策——本 skill 的价值在于补证据，不是拖延机制。
- 用来否定一切"没换过环境"的候选人：本 skill 要求的是补证据（可先历练），不是把没有跨环境经历的人永久排除。
- 把"能否接受新理念"变成服从性测试：它检验的是学习与调整能力，不是听不听话。

### 作者在书中警告的失败模式

- **选错人：把一个层级的成绩当作提拔的主要依据**: "相邻两个层级的总体要求可能相近，但在具体的领导技能、时间管理能力和工作理念方面则显示出重大的差别"；"在一个层级上做出成绩不应成为选择某人担任更高层级职务的主要原因"（b5-ce21，第11章 L12143–L12147）。
- **未经历逆境者被推到关键岗位**: 保罗履历全是升迁与成功、无危机处理记录，"没有遇到什么逆境"使他在环境转恶时全盘被动（b1-ce10，册1 第6章 L1748）。
- **组织默认的晋升假设**: "如果一个人能够出色地完成某个岗位的工作，那么他也会同样出色地完成下一个岗位的工作"——"正因为如此，几乎所有的组织都存在把人员配置在错误层级的问题"（b5-ce35，导论 L9637）。
- **友情与欠情扭曲评价**: 杰瑞对文斯"觉得自己欠文斯的"、反复指望其"重新焕发魔力"，最终公司缩成本几十亿美元、成千上万员工被解雇、CEO 被迫提前退休（b5-c13）——尽调必须独立于私交，必要时引入第三方视角。
- **伦理与合规提示（作者未展开，使用须遵守）**: 任何基于本尽调结论的人事动作（不予提拔、调岗、解雇）均须依当地劳动法与公司程序执行，并保留书面证据；本 skill 只做决策前的证据审查，不构成人力资源法律意见。

### 作者的盲点 / 时代局限

- **三必问缺乏预测效度检验**: "能否在不同环境做出成绩"没有操作化定义（多不同算不同？），判据可能退化为事后归因；"谋定而后动"的经验来自咨询案例，无对照研究（BOOK_OVERVIEW 批判节）。
- **信息来源依赖组织坦诚**: 三问所需的负面证据（会上同意会后照旧、拒斥反馈）通常由熟悉者提供；在缺乏坦诚的组织里，尽调会被漂亮话填满（参 b5-ce26）。
- **"宁缺毋滥"的执行成本被低估**: 岗位空置或引入外部人的代价、团队内部公平感，书中未展开。
- **美国大公司语境**: 以层级分明、内部晋升为主的公司为背景；快速成长或高流动组织中，"先历练再提拔"的窗口可能不存在，需要压缩版判据。

### 容易混淆的邻近方法论

- **面试评估/结构化面试**: 那是获取信息的工具；本 skill 规定"必须获取哪三类证据"以及如何据此决策，可与之组合使用。
- **九宫格/潜能评估**: 那是常规人才盘点的分级；本 skill 是就具体岗位与具体时点的单次尽调，输入可以来自盘点，但不能用格子归属代替证据核验。
- **试用期/考察期设计**: 那是决策后的风险控制手段；本 skill 主张在决策前补齐证据，避免用"先提了再说"代替尽调。
