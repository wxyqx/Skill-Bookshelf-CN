# 继任计划：新定义、四原则与五步骤

## R — 原文 (Reading)

> "继任计划是指在领导梯队中培养各级高绩效人员，以保证每个领导层级在现在和将来都拥有足够的高绩效者，从而确保公司基业长青。"
>
> — 查兰/诺埃尔/德罗特，第10章（L11908）

> "关注绩效　当前所显示出的优秀绩效是未来受到关注和发展的入场券。……现在，在所有领导层级实现全面绩效才是继任计划的目标。"
>
> — 同上，第10章（L11912）

> "第五步，经常认真审核整个领导梯队的继任计划和实施进展。别让继任计划成为你几年或一年才做一次的事情……理想的情况是，你的公司应至少每年举行一次围绕绩效-潜能评估的继任会议，你也要安排好季度审核和月度行动报告。"
>
> — 同上，第10章（L12055–L12059）

---

## I — 方法论骨架 (Interpretation)

作者先换定义：继任计划不是为某个岗位预选接班人，也不是把高潜质者存进"人才库"（那会把潜质等同于表现）；它是在整条领导梯队上持续培养各级高绩效人员，保证每一层现在和将来都有人可用。

四条原则是定义的操作面：① 绩效准入——当前绩效是入场券，没有在当前层级展现全面绩效的人不进继任视野；② 全层级持续流动——每个层级都做，自下而上层层有人，才能避免"越级提拔"；③ 先懂层级要求——清楚每层技能/时间/理念要求，才知道某人该放在哪一层；④ 短长期兼顾——只满足当下或只储备未来都不够。

五步骤把制度落地：① 把通用模型改成本公司的层级与职位语言（五层、六层、七层皆可）；② 用公司自己的话语阐释绩效与潜能标准；③ 在组织内公示并讨论这些标准（培训项目是主渠道，标准要随环境修订）；④ 用潜能-绩效九格矩阵逐人评估（先标准、后填格；证据先于结论；任职未满六个月者不适用）；⑤ 高频审核——至少年度继任会议＋季度审核＋月度行动报告，且每个层级主管要看比自己低至少两级的评级。

另外两条量化纪律：覆盖到"入职级别"（从招聘端就要有人愿意走领导路线）；为了降低风险，90% 的选拔时间应用于内部，例外只有一种——进入新业务/新市场且找不到合格内部人选时。判断继任计划是否合格，作者给了三个自检问题：能否看清从初级到 CEO 的流程？能否同时管住短长期绩效？是否迫使你持续工作而非一年一次？

## A1 — 书中的应用 (Past Application)

### 案例 1: 通用电气——"C 阶段"把继任变成程序
- **问题**: 高管离任时，外部候选人了解公司甚少、内部候选人可能尚未在新层级上准备好；临时挑选的 CEO 上任不久就悻悻离职的报道天天都有。
- **方法论的使用**: GE 用"C 阶段"继任计划程序评估领导者面对职位与层级变化时的准备情况，并配套学习业务知识、领导能力与文化技能的培训项目。
- **结论**: GE 的 9 位 CEO 全部出自"C 阶段"体系，几十年间始终保留数名可随时接任的候选人；作者据此强调 GE 的领导力优势不来自更聪明或更忠诚的员工，而来自"内部在领导人才成长方面的投入"以及对"层级不同、能力要求不同"的认知。
- **结果**: 通用电气成为领导者的"黄埔军校"，既满足自身继任，也向外部公司输送大量高管——这是五步骤中"用层级语言定义准备度＋持续审核"的样板。

### 案例 2: Baxter——"高层领导点名板"把填补周期从 16 周压到 7 天
- **问题**: 副总裁职位空缺袭来时找人慢、候选人质量参差，选人过程被动而冗长。
- **方法论的使用**: 把人员选育流程与战略关键岗位挂钩：每周语音邮件＋周一名单会持续滚动评价约 200–325 名副总裁，评判分"非常合适/有些牵强/不合适"三类，全部评判须在六个月内结束（册1 第6章，L1869）。
- **结论**: 继任不是换人时才启动的突击任务，而是覆盖关键高层的常态化持续评价与流动。
- **结果**: "在1999年开始实施该流程之前，我们寻找一个副总裁职位候选人的平均时间为16周。现在，我们把这一时限缩短到了七天，而且候选人的质量和数量也得到了大大提高。平均算来，我们每个职位都有五个候选人。"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司只有 CEO/老板一个人在操心接班人，继任变成"换人时的紧急事项"。
2. 想建立公司级人才梯队/人才库，担心名单变成"贴了高潜标签却没人准备好"的纸上工程。
3. 关键岗位频繁空降外部人，内部人却总说"还没准备好"，用户想搞清是标准缺失还是培养缺失。
4. 要做一次继任制度设计（含评估节奏、会议机制、覆盖范围），需要一套可落地的步骤。
5. 需要向管理层论证"为什么继任要覆盖到入职级别、为什么要给标准做公示"。

### 语言信号 (用户的话里出现这些就应激活)

- "接班人计划怎么做？/ 只有老板一个人在操心接班人"
- "人才库怎么建？/ 建了名单也没用，换人还是靠空降"
- "怎么知道自己有没有梯队？关键岗位能不能有人顶上？"
- "succession planning" / "talent pipeline" / "bench strength" / "who's ready to step up" / "candidate slate"

### 与相邻 skill 的区分

- 与 `b5-f28 potential-three-types` 的区别: 潜能三分类是第四步的输入——先能判定"哪一类潜能＋证据"，九格矩阵才填得下去；本 skill 管的是从定义到审核的整条制度链。
- 与 `b5-f29 nine-box-actions` 的区别: 九格矩阵是五步骤中的第四步工具（含每格动作）；本 skill 是它上一层——定义、标准、公示、评估、审核的制度框架。
- 与 `b4-f16 ceo-selection-process` 的区别: 后者聚焦治理层的 CEO 选拔流程（董事会视角）；本 skill 覆盖全层级，尤其强调"继任的起点在非高层职位"。
- 与 `b1-f12 talent-review-meeting-mrr` 的区别: MRR 是人才评估会议的运作机制（怎么开会、看什么人）；本 skill 是继任体系的设计与审核节奏，MRR 可作为第五步中"年度继任会议"的载体。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **第一步：把模型改成本公司版本**
   - 完成标准: 产出一张本公司实际的层级清单与职位名称（可用五、六或七层），并写出每层的技能/时间/理念要求要点；显式声明"未把通用模型硬塞进公司结构"。
   - 判停条件: 若公司尚无层级定义或规模过小，先与用户确认是否值得做；个体户/极小企业不获益（作者原话）。

2. **第二步：用本地话语写清绩效与潜能标准**
   - 完成标准: 标准文档全部使用公司自己的术语；绩效标准对接七项绩效内容或本公司业绩类别；潜能按转型/成长/熟练三类分别写出可观察证据。

3. **第三步：公示并讨论标准**
   - 完成标准: 通过培训项目让员工了解标准并有机会提问；说明标准的修订机制（商业环境变化→行为变化→标准更新），并留存讨论记录。
   - 判停条件: 若标准仍是 HR 内部文件、员工不知道"到什么程度算准备好"，不要进入第四步——匿名标准只会制造猜测与不信任。

4. **第四步：用潜能-绩效矩阵逐人评估**
   - 完成标准: 每个层级的关键岗位候选人都有一条"绩效证据＋潜能类别＋拟行动"的记录；不依赖直觉填格（详见 nine-box-actions）；任职未满六个月者不评。
   - 判停条件: 若某人的绩效证据不足或长期无更新，标注为"数据不足"，不强行给格子。

5. **第五步：建立审核节奏与跨度**
   - 完成标准: 落实"至少年度继任会议＋季度审核＋月度行动报告"；规定每个层级主管须查看比自己低至少两级的评级；覆盖范围下探到入职级别。
   - 完成标准 (量化纪律): 明确内部选拔的目标比例（作者基准：90% 时间用于内部选拔），并写明唯一例外（新业务/新市场且无合格内部人选）。

6. **输出继任健康度自检**
   - 完成标准: 用作者三问收尾——能否说明从初级职位到 CEO 的上升流程？是否同时兼顾短期与长期绩效？制度是否迫使组织持续工作而非一年一次？

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 临到换人前几周才想找替补——应急场景需要的是过渡方案与临时安排，不是本制度。
- 公司只有一层管理、尚无梯队可言时，硬做继任会制造大量空转文件。
- 把继任计划悄悄做成"淘汰名单/替换计划"：这会毁掉公示标准与坦诚评估所需的前提。
- 只做 CEO 层的继任：作者原话是"大多数继任计划都在关注领导梯队的另一端——首席执行官"，而这正是失败源头之一。

### 作者在书中警告的失败模式

- **把继任计划误当"接替计划"或"人才库"**: "传统观点认为，继任计划等同于接替计划。……人才库的概念促成了一些继任计划，但从领导梯队的角度来看，这一概念存在缺陷。它蕴涵着这样的假设，如果公司储备了一群优秀的人才，就有足够的候补来接替离任的领导者。但问题在于人才库存将潜质等同于表现。"（b5-ce27，第10章 L11900–L11904）
- **九格矩阵靠直觉填格＋潜能评价永远不变**: "当我们追问其判断根据时……我们发现他们是靠自己的直觉来完成这个选择。他们并没有依靠绩效证据或潜能标准。……九格矩阵只是面粉而非蛋糕。"（b5-ce28，第10章 L12091）——伦理提示：潜能标签会实际影响晋升与薪酬，须防止标签固化造成事实上的歧视或"自我实现预言"，评价数据应按人事档案规范管理（b5-ce28 ethics_legal_note）。
- **私藏人才（"武大郎开店"）**: 现任领导者把高潜下属藏为部门私产、阻挠调动，人才因缺乏挑战而流失（b4-ce17，册4 第4章 L8270–L8272）。纠正须通过透明制度（空缺公告、跨部门评价、把"输送人才"纳入考核），而不是个人冲突或惩罚性调动；避免侵犯员工知情与选择权（b4-ce17 risk_note）。
- **忽视家庭与流动性约束**: 培养设计默认"可全球流动"，双职工、配偶职业、子女教育等约束未被纳入，导致高潜人才退出（b4-ce23，册4 L7974–L7978、L8276–L8278）。不得以"奉献"名义强制调动；调动涉及劳动合同变更与异地用工合规，应提供弹性与替代路径，避免对特定群体的间接歧视（b4-ce23 risk_note）。

### 作者的盲点 / 时代局限

- **"内部培养优于外部引进"不对称**: 90% 内部选拔准则的例外只有一条（新业务/新市场），文献中空降失败的批评远多于内部体系失败的检视（BOOK_OVERVIEW 批判节）。
- **缺乏效度证据**: 潜能判断标准与"三年持续绩效"规则没有预测效度检验；"准备好"的判定可能陷入循环论证（已在岗位上表现好）。
- **对组织政治与治理制约处理薄**: 谁有权否决候选人、董事会与 CEO 的权责边界，书中只作原则性提示。
- **美国大公司语境**: 建立在长周期（20 年以上）、多层级、总部主导的稳态公司假设上；技术迭代快、职业流动性高的组织中，全层级滚动继任的成本与可行性需要重新评估。

### 容易混淆的邻近方法论

- **人才库/继任名单**: 那是"有哪些人"的静态清单；本 skill 是"培养与流动的制度"，清单只是其中一步的副产品。
- **接替计划（replacement planning）**: 为特定岗位预选一个或几个人；本 skill 明确反对这种静态做法，因为市场与结构变化会让"重要岗位"失去重要性。
- **人才盘点会（talent review）**: 那是一次会议；本 skill 要求年度会议＋季度审核＋月度行动报告的持续节奏，会议只是节奏中的节点。
