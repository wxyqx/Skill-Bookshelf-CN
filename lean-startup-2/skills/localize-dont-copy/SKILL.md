# 用本公司语言重述方法，不照搬复制

## R — 原文 (Reading)

> "学习使用这种新方法进行工作不是要你严格采用一系列做法，而是要找到办法，把别人的东西加以调整，运用到自己的公司。……'你无法复制。你们要自己做实验，把所有做法用到自己的流程中，然后你们会发现哪些做法在你们公司行得通。'"
>
> — 财捷 Design for Delight 负责人贝内特·布兰克，转引自第 6 章

> "我认为如果你用企业沟通的内容、企业使用的语言判断它的文化，你就会知道自己在改变。……请记住，丰田连'精益生产'都不说，他们叫'丰田生产方式'。"
>
> — 埃里克·莱斯引康贝丝语，第 6 章

---

## I — 方法论骨架 (Interpretation)

组织学习外部标杆时最常见的死法是"连名带骨一起搬"：挂上同一块牌子、用同一套术语、抄同一份流程。本书的判断更狠——复制不是"效果打折"，而是"不可能"：FastWorks 之于 GE、Design for Delight 之于财捷、USDS 之于联邦政府，每套做法都长在母组织的文化与性格上，抽出来就死了。连精益的原点企业丰田都不借用"精益生产"这个词。

替代程序是三步的本地化实验。第一步，挑机制而不是整套体系：从外部方法里拆出可分离的机制（如"审计对照过去""预批参数化"），逐个在本部门试运行，记录哪些行得通。第二步，换成本组织的语言与工具：每个机制起一个本公司员工听得懂、认得出的名字，配套本公司已有的工具载体。第三步，用本组织自己的案例重写教材，让"这套方法在这里可行"由内部证据而非外部光环来证明。

配套一条术语纪律：警惕同一词汇承载两种含义（GE 的 FastWorks 与 FastWorks Everyday 之别）——术语撞车会让两种工作互相冒名，最后哪种都做不实。

## A1 — 书中的应用 (Past Application)

### 案例 1: GE"通用电气信念"的制定
- **问题**: GE 想改变员工的工作方式，但旧价值清单承载的是老一套"增长价值"；直接抄任何公司的价值观都会水土不服。
- **方法论的使用**: 森佩尔团队明言"不想复制任何公司的理念"：把候选压缩为 12 个特征，向前 200 位中层与 4000 名员工做 MVP 式验证，确认 7 项已强、5 项需补，针对 GE 自己的弱点起草，并另起一个区别于旧价值的名字——"通用电气信念"。
- **结论**: 方法可以学习，表达必须自有——"取其精华，使其应用于通用电气，让它为我所用"。
- **结果**: 2014 年发布五条信念，成为后续 PD@GE 绩效重构等深层变革的合法性来源。

### 案例 2: 三家公司的教练体系各不相同
- **问题**: 同一套创业方法论，不同公司怎么落地教练体系？照抄哪一家？
- **方法论的使用**: 没有一家照抄——IBM 设"敏捷大夫坐诊"（30 位教练按次约谈 1-2 小时）；思科做"我的创新"（在线资源+教练，面向 7 万员工）；Techstars 立导师宣言"指导，不要控制"。三个体系同名不同骨，各配各的机制。
- **结论**: 各体系反映母组织的文化与性格——"你无法复制"的正面证据。
- **结果**: 三种体系都在各自组织运转，互为异构参照而非复制品。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 高管读完一本标杆书或参加对标参访后要求"把 GE/亚马逊/字节的做法搬过来"，有人负责落地。
2. 采购咨询公司的转型模板，团队怀疑"这模板在我们公司跑不通"，要决定怎么改造。
3. 组织正在引入新方法论（OKR、敏捷、精益），要给它起名、定术语、编内部教材。
4. 培训回来的员工抱怨"方法好是好，回到部门格格不入，同事听不懂我在说什么"。
5. 发现公司里同一个新词被两个部门用来指完全不同的两件事。

### 语言信号 (用户的话里出现这些就应激活)

- "我们能不能照搬/复制他们的做法"（copy / replicate / 照搬）
- "对标华为/GE/亚马逊，人家是怎么做的"（benchmark / 对标）
- "要不要直接买咨询公司的现成模板"（adopt template / 套模板）
- "这套东西怎么变成我们自己的"（make it our own / 本土化、本地化）

### 与相邻 skill 的区分

- 与同书 `internal-change-owner`（变革必须内部专人专责）的区别: `localize-dont-copy` 管"怎么学别人"（方法与语言的本地化程序），`internal-change-owner` 管"谁来负责"（内部专人与授权）。用户问"能不能抄"是本 skill，问"该派谁主导"是 `internal-change-owner`。
- 与同书 `accountability-method-culture`（责任制→方法→文化三层模型）的区别: `accountability-method-culture` 解释为什么贴海报式照搬无效（因果链在责任制端）；`localize-dont-copy` 给出照搬之外的替代程序（本地实验→自有语言→自有工具）。一个是诊断，一个是处方。
- 与同书 `innovate-in-the-open`（公开创新，不偷偷摸摸）的区别: `innovate-in-the-open` 管创新的政治姿态（地上 vs 地下），`localize-dont-copy` 管创新的移植姿态（自有 vs 照搬）。
- 跨批提示: 与 `organizational-experiment-loop`（精益实验循环五步法）的区别——`organizational-experiment-loop` 是被本地化的对象之一（方法本体）；本 skill 恰恰警告"连 `organizational-experiment-loop` 的术语也不可照搬"，两者是内容与元层的关系。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **禁用外来词汇清单**
   - 完成标准: 盘点候选方法论中的品牌词与机制名（如"增长委员会""PRFAQ"），逐个回答"用本公司语言它该叫什么"，产出一张"外来词→暂定名"对照表；连"精益"二字是否保留都要过一遍（丰田先例）。

2. **机制级本地实验**
   - 完成标准: 从外部方法中挑出 1-2 个可分离的机制（不是整套体系），在本部门试运行一个周期，留下"行得通/行不通"的实验记录；若领导坚持整套照搬，先援引"你无法复制"谈判降级为机制实验。

3. **用本公司案例重写教材**
   - 完成标准: 培训与宣讲材料中，本组织自己的试点案例数不少于外部案例数；"这套方法在本公司可行"由内部证据支撑。

4. **术语撞车检查**
   - 完成标准: 每个新术语有且仅有一个书面定义，并经主要使用部门确认不与现有词汇冲突（防 FastWorks / FastWorks Everyday 式双含义）；发现撞车立即改名或合并。

5. **判停**: 若组织既不肯做本地实验（只要现成模板）、又拒绝换自己的语言（必须用原品牌词），按本书判据该项目将以排异告终——此时不值得投入，先向决策层重述"复制不可能"的论证再动工。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- "本地化"不等于给旧做法换新名词：如果机制没变、只是包装变了个说法，那是 ce02 式的口号文化，重述的对象必须是机制而非修辞。
- 合规与会计硬约束不参与"语言重述"：法务红线、会计准则该走 `one-page-preapproval` 的预批参数化或保留原文，不是本地化修辞的对象。
- 组织尚无任何实验能力时，先跑 `organizational-experiment-loop` 建立方法本体——没有内部实验，"本地化"没有可供验证的载体。

### 作者在书中警告的失败模式

- ce18 只培训个人不改文化：培训回来的个人"格格不入"，方法未被组织语言承载，三个月内被组织重力耗尽——照搬培训而不重述的典型结局。
- 同一术语两种含义：作者自认当初反对区分 FastWorks 与 FastWorks Everyday 的意见有问题——术语撞车让"创业团队项目"与"人人皆创业"两种工作互相冒名。
- 抄来的合法性幻觉：书中明示各项目"反映了上级组织的文化和性格"，跨组织移植名字即移植了不属于你的性格。

### 作者的盲点 / 时代局限

- 本地化实验要求组织已有实验能力，这对没有 `organizational-experiment-loop` 基础的公司是"先有鸡还是先有蛋"——书中未讨论能力建设的第一步怎么走。
- 本书本身是最易被"照搬词汇"的源头：读者读完就挂"增长委员会"的牌子，恰是本 skill 的反面案例——调用本 skill 时应警惕这一自指风险。
- 案例集中于大型标杆组织（GE/财捷/丰田），对小组织"语料太少、造不出自有语言"的情形未讨论。

### 容易混淆的邻近方法论

- 与《精益创业》正传的区别: 正传是被本地化的对象之一；本书警告连正传的词汇也不可照搬（"精益创业"本身要改名试用）——调用时勿把本 skill 讲成"精益创业的本土化应用"，它的对象是一切外部标杆。
- 与"入乡随俗"式妥协的区别: 本地化的判据是机制在本组织行得通（有实验记录），不是措辞讨好各方；只改说法不改机制的是谄媚，只改机制不改说法的是照搬的另一半。
- 与 NEET 式 NIH（排斥一切外来的）的区别: 本 skill 不反对学习外部方法，反对的是复制这一种学习方式——"把别人的东西加以调整"仍是起点。
