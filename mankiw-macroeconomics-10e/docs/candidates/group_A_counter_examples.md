# A组候选·反例（counter-example，作者明确警告的误区/陷阱/衡量偏差）｜来源：序言、第1章、第2章

- id: Ak01
  title: 简化假设踩掉关键特征→结论失真
  type: counter-example
  source_chapter: 第1章 1.2节
  source_quote: |
    不过，如果模型的假设抛弃了对要处理的问题至关重要的经济特征，那么，它们可能误导我们得出在现实世界不成立的结论。因此，构建经济模型要求我们小心谨慎，同时还要了解常识。
  summary: |
    作者明确警告：简化是构建有用模型的必要组成（完全反映现实的模型复杂到无人能懂），但"简化"与"误导"一线之隔——被抛弃的特征若恰是问题关键，模型越简洁结论越错。
    判断标准要回到常识与研究目的，这是使用一切简化模型（包括本教材全部模型）的通用护栏。
    怎么用：接受模型结论前自查其假设清单里是否藏着对本题致命的省略。
  tags: [模型局限, 简化风险, 作者警告]

- id: Ak02
  title: 同一个模型换个问题就用错：比萨饼店数量的教训
  type: counter-example
  source_chapter: 第1章 1.2节
  source_quote: |
    但是，如果我们的目的是解释为什么有10个比萨饼店的城镇的比萨饼价格比只有2个比萨饼店的城镇低，那么，这个简单模型就不是那么有用了。
  summary: |
    作者用比萨饼模型自我示范误用：解释"奶酪价格如何影响比萨饼均价"时，"单一价格"假设无害；可一旦问题是"店多的城镇为何价格更低"，价格多样性本身就成了研究对象，简单模型失效。
    误区本质：不检查模型假设与研究目的是否匹配，把为甲问题设计的模型硬用到乙问题上。
    怎么用：问题的性质从"给定结构看价格"变成"结构本身为何如此"时，往往必须换模型。
  tags: [模型误用, 假设与目的匹配, 作者警告]

- id: Ak03
  title: 把市场出清模型用于短期波动
  type: counter-example
  source_chapter: 第1章 1.2节
  source_quote: |
    持续的市场出清的假设并不完全是现实的。……事实上，许多工资和价格调整缓慢。劳动合约常常设定了长达三年的工资。……对研究诸如实际GDP和失业的逐年波动这类短期问题而言，价格弹性的假设就不是那么合理了。
  summary: |
    作者明确警告：市场出清（弹性价格）模型"并没有描述每一时刻的经济"——劳动合约锁定三年工资、杂志零售价三四年不变，短期里许多价格是预先确定的。
    误区：用它分析逐月逐年的波动会得出误导性结论；它的正确领地是描述"经济所趋近的均衡"，即长期问题。
    怎么用：分析短期波动换黏性价格模型；用出清模型时明确声明"我看的是长期倾向"。
  tags: [市场出清, 时间范围错配, 作者警告]

- id: Ak04
  title: 期待宏观经济学给出精确预测
  type: counter-example
  source_chapter: 第1章 1.1节
  source_quote: |
    的确，宏观经济学是一门不完美的科学。宏观经济学家预测经济事件未来走向的能力并不比气象学家预测下一个月天气的能力强。但是……宏观经济学家对经济如何运行确实知之甚多。
  summary: |
    作者明确警告的期待错位：不要把宏观经济学当预测水晶球——预测能力并不比气象学家预测下月天气强；但它在"解释经济事件、制定经济政策"上的知识是真实存在的。
    误区本质：因预测不准而全盘否定学科，或因学科存在而迷信点状预测。
    怎么用：对任何"权威预测下年GDP/通胀"的数字降低置信；把宏观知识用于理解机制与权衡，区间表述比单点数字更诚实。
  tags: [预测局限, 学科定位, 作者警告]

- id: Ak05
  title: 名义GDP翻倍不等于经济能力翻倍
  type: counter-example
  source_chapter: 第2章 2.1节
  source_quote: |
    如果数量没有任何变化而价格翻倍了，那么，名义GDP也将翻倍。但是，如果我们说经济满足需求的能力翻倍了，那么，这将是一种误导，因为所生产的每一种产品的数量仍然是相同的。
  summary: |
    作者明确警告的读数误区：拿名义值当福利指标。价格翻倍、数量不变时名义GDP同步翻倍，但经济能满足的需求丝毫未增——"这种衡量指标没有确切反映出该经济可以在多大程度上满足需求"。
    怎么用：一切"创新高"的表述先换成实际（不变价）口径复核；这正是"名义=实际×平减指数"框架（Af10）要防的错误。
  tags: [名义与实际, 衡量误区, 作者警告]

- id: Ak06
  title: 用过时的基年价格估值
  type: counter-example
  source_chapter: 第2章 2.1节
  source_quote: |
    近年来电脑的价格大幅度下降，而大学每年的学费却上升了。当我们为电脑和教育的生产估值时，用10年或20年前的价格就会引起误导。
  summary: |
    作者明确警告：固定基年用久了，在相对价格剧烈变动的年代会让实际GDP失真——用20年前的高价给今天的廉价电脑估值会夸大产出。经济分析局1995年改用链式加权正是对此的修正。
    怎么用：长期比较选链式加权序列；自己做不变价估算时定期更新基期价格；警惕任何"永远用一组老价格"的估值。
  tags: [基年偏误, 实际GDP, 作者警告]

- id: Ak07
  title: CPI替代偏差：固定篮子看不到换购
  type: counter-example
  source_chapter: 第2章 2.2节
  source_quote: |
    由于CPI衡量固定的一篮子产品的价格，所以，它没有反映消费者用相对价格下降的产品进行替代的能力。因此，当相对价格变动时，真实生活成本的上升比CPI慢。
  summary: |
    作者明确警告的三大CPI偏差之一：CPI按固定篮子计价，相对价格变化时消费者会少买涨价的、多买降价的，而CPI不记录这种替代，于是高估生活成本上升（拉氏指数的固有偏差）。
    橘子霜冻的例子就是专门说明这一点的：CPI夸大了橘子涨价的影响，因为它忽略了消费者用苹果替代橘子的能力。
    怎么用：把CPI读数理解为"维持原篮子的成本变化"而非"生活成本的真实变化"；涉及工资、社保等指数化时记得这一系统性高估。
  tags: [CPI偏差, 替代效应, 作者警告]

- id: Ak08
  title: CPI新产品偏差：多出来的选择没被记功
  type: counter-example
  source_chapter: 第2章 2.2节
  source_quote: |
    当一种新产品进人市场时，消费者的境况变好了，因为消费者有了更多产品可供选择。实际上，新产品的出现提高了美元的实际价值。但这种美元购买力的提高并没有表现为CPI的下降。
  summary: |
    作者明确警告的三大CPI偏差之二：新产品让同样一美元能买到更多满足，等效于物价下降，但CPI只在新品进入篮子之后才计其价格变动，"福利增益"从不入账——于是通胀被系统性高估。
    怎么用：想到智能手机进入篮子的过程就能体会这一偏差；评估"实际收入停滞"之类的论断时留出这个误差余量。
  tags: [CPI偏差, 新产品, 作者警告]

- id: Ak09
  title: CPI无法衡量的质量变化
  type: counter-example
  source_chapter: 第2章 2.2节
  source_quote: |
    舒适或安全性等许多质量变化很难衡量。如果无法衡量的质量改进（而不是无法衡量的质量下降）是有代表性的，那么，我们衡量的CPI的上升就比应该上升的要快。
  summary: |
    作者明确警告的三大CPI偏差之三：价格变化里混着质量变化，劳工统计局尽力调整（如汽车加大马力后按质量调整价格），但舒适性、安全性等难以量化的改进测不到；若未测到的质量改进居多数，CPI涨幅被夸大。
    怎么用：比较跨期价格时先问"东西是不是也不一样了"；把名义价格差换算成"同质商品"价格差是所有价格指数的公共难题。
  tags: [CPI偏差, 质量调整, 作者警告]

- id: Ak10
  title: 帕氏指数（GDP平减指数）的反向偏差：低估
  type: counter-example
  source_chapter: 第2章 2.2节
  source_quote: |
    由于GDP平减指数是一个帕氏指数，所以它低估了橘子价格上升对消费者的影响：GDP平减指数显示价格没有上升，但是，毫无疑问，橘子价格提高恶化了消费者的境况。
  summary: |
    作者明确警告：偏差是成对的——拉氏（CPI）高估，帕氏（GDP平减指数）低估。橘子绝收、价格飞天时，GDP平减指数因橘子已退出篮子而显示"价格未变"，但消费者福利确凿恶化（因为帕氏"并没有反映出这种替代可能引起的消费者福利的减少"）。
    怎么用：别以为换用可变篮子指数就万事大吉；任何单一指数都有方向性偏差，结论要放在"高估—低估"区间里读。
  tags: [帕氏指数, 衡量偏差, 作者警告]

- id: Ak11
  title: 家庭调查与机构调查的口径陷阱
  type: counter-example
  source_chapter: 第2章 2.3节
  source_quote: |
    有人可能会预期这两个就业总数的衡量相同，但是情况并非如此。虽然这两种衡量正相关，但它们可能相互背离，特别是在短期内。
  summary: |
    作者明确警告：就业的两个官方测度会显著背离。原因包括口径差异（自雇者只在家庭调查中算就业；两份工作者在机构调查中被算两次）、机构调查对新开业企业的遗漏、家庭调查依赖的人口规模估计误差（移民率变化）。
    由此引出的普遍教训：所有经济统计数字都是不完美的，"对每一个经济统计数字的解释都应该适度谨慎"。
    怎么用：引用"新增就业"数据时先说明是哪个调查；两者背离期（如2001-03）避免武断断言就业增减。
  tags: [就业统计, 口径差异, 作者警告]

- id: Ak12
  title: 丧失信心的工人：失业率的分母魔法
  type: counter-example
  source_chapter: 第2章 2.3节
  source_quote: |
    注意，一个想工作但放弃寻找工作的人——丧失信心的工人（discouraged worker）——不被计人劳动力。
  summary: |
    作者明确提醒的分类边界：想工作但已放弃寻找的人不算失业者，也不算劳动力（"失业者"要求此前4周在力图寻找工作）。
    陷阱：长期萧条中一部分绝望者从统计上"消失"，失业率反而可能被压低——单看失业率会低估劳动市场的恶化。
    怎么用：解读失业率时同时看劳动力参与率；失业率下降可能是好消息（找到工作）也可能是坏消息（退出劳动力），必须追问分母发生了什么。
  tags: [失业统计, 丧失信心的工人, 作者警告]

- id: Ak13
  title: GDP的系统性遗漏：地下经济与家庭生产
  type: counter-example
  source_chapter: 第2章 2.1节
  source_quote: |
    人们在家准备饭菜时的增加值没有纳人GDP。……地下经济（underground economy）中销售的产品和服务的价值也没有作出估算。……据估计，美国的地下经济不到官方经济的10%，而在泰国、尼日利亚和玻利维亚等一些发展中国家则超过官方经济的一半。
  summary: |
    作者明确警告：GDP漏掉了没有市场价格的活动——自住房的估算租金计入了，但汽车、割草机等耐用品的服务和家中做饭不计入；地下经济（逃税与非法活动）完全不计入，且遗漏规模国别差异巨大（美国不足10%，部分发展中国家超过一半）。
    误区：拿GDP直接做跨国生活水平比较，忽略各国偏差不同。
    怎么用：跨国比较时记住较穷国家的真实产出相对其GDP被低估得更多；GDP的逐年比较因偏差稳定而仍可用（见Ap12）。
  tags: [GDP遗漏, 地下经济, 作者警告]

- id: Ak14
  title: 把季节性波动当成经济变化
  type: counter-example
  source_chapter: 第2章 2.1节
  source_quote: |
    当你观察到实际GDP或任何其他数据序列的上升或下降时，你必须寻找季节性周期以外的解释。
  summary: |
    作者明确警告的读数陷阱（"必须"句式）：收入数据有约8%的规律性季节摆动（Q4顶点、Q1回落）；官方数据已做季节性调整，因此调整后序列的升降只能由季节以外的因素解释。
    反面情形：若误用未调整数据或忘了季节调整的存在，就会把圣诞购物季效应读成经济繁荣、把Q1回落读成衰退。
    怎么用：看环比波动先问"这是季节吗"；对未调整的原始序列保持警惕。
  tags: [季节性, 数据误读, 作者警告]
