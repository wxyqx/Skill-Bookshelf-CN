- id: Af01
  title: 内生/外生变量——建模第一步
  type: framework
  source_chapter: 第1章 1.2节
  source_quote: |
    内生变量（endogenous variables）是一个模型要解释的变量。外生变量（exogenous variables）是一个模型视为给定的变量。模型的目的是说明外生变量如何影响内生变量。换言之，外生变量来自模型以外，是模型的投入，而内生变量则在模型之内决定，是模型的产出。
  summary: |
    解决什么问题：拿到一个经济问题无从下手，不知道模型该长什么样。
    核心逻辑：建模先把变量分两类——要解释的设为内生（模型的"产出"），暂时视为给定的设为外生（模型的"投入"）；模型本身就是把外生变量映射为内生变量的一台机器。
    怎么用：分析任何问题的第一步先问"这个问题里什么是我要解释的"，把它设为内生，其余设为外生（必要时留给别的模型解释）；模型给出的答案就是"外生变量变动→内生变量如何变"。
  tags: [模型方法论, 建模入门, 变量分类]

- id: Af02
  title: 供给—需求—均衡三件套市场模型
  type: framework
  source_chapter: 第1章 1.2节
  source_quote: |
    最后，该经济学家假设比萨饼的价格将进行调整，以使供给量与需求量达到平衡。……市场均衡是供给曲线和需求曲线的交点处的价格和数量。在均衡价格处，消费者选择购买的比萨饼量正好等于比萨饼店所选择的比萨饼生产量。
  summary: |
    解决什么问题：某种产品或服务的价格与数量由什么决定。
    核心逻辑：任何市场都可以写成三个方程——需求函数（数量取决于价格与总收入）、供给函数（数量取决于价格与原料成本）、均衡条件（价格调整到供需相等）；图形上是两条曲线的交点。这个"比萨饼市场"是全书一切市场模型的原型。
    怎么用：分析任何市场先写需求、供给、均衡三件套，再让外生变量移动曲线，读出价格与数量的变化方向。
  tags: [供需模型, 均衡分析, 建模入门]

- id: Af03
  title: 比较静态分析：让外生变量动起来
  type: framework
  source_chapter: 第1章 1.2节
  source_quote: |
    这个模型可以用来说明一个外生变量的变动如何影响两个内生变量。例如，如果总收人增加，那么，对比萨饼的需求增加……该模型表明，在这种情况下，比萨饼的均衡价格和均衡数量都上升。类似地，如果原料价格上升……比萨饼的均衡价格上升，而均衡数量减少。
  summary: |
    解决什么问题：预测"某事件发生后市场会怎么变"。
    核心逻辑：比较静态＝改变一个外生变量→曲线移动（需求右移或供给左移）→重新求出新均衡→与旧均衡比较。需求增加则价升量升，供给减少则价升量减；两个内生变量方向不一致时，模型立刻暴露出冲击的性质。
    怎么用：分析新闻事件（收入变化、成本冲击）时，先判断它动的是需求还是供给、朝哪个方向动，再读出价格与数量的变化方向；方向不明就老实说"模型无法确定"。
  tags: [比较静态, 供需模型, 政策分析]

- id: Af04
  title: 时间范围决定模型选择（弹性 vs 黏性价格）
  type: framework
  source_chapter: 第1章 1.2节 内容提要
  source_quote: |
    宏观经济模型的关键特征是：它假设价格是有弹性的还是黏性的。根据大多数宏观经济学家的看法，弹性价格模型描述了长期中的经济，而黏性价格模型对短期中的经济提供了更好的描述。
  summary: |
    解决什么问题：宏观模型这么多，到底该用哪一个。
    核心逻辑：模型按"价格调整速度"的假设分两大类——弹性价格（市场出清）模型适合长期（几年以上），黏性价格模型适合短期（逐月逐年）；同一个问题在两个时间范围里可能结论相反（例如货币的作用）。
    怎么用：面对任何宏观问题先问时间范围——问的是十年趋势还是明年波动？前者用古典/弹性价格模型，后者用凯恩斯/黏性价格模型。这是全书的元框架，也是作者明言"特别重要的一组假设"。
  tags: [元框架, 长期与短期, 价格黏性]

- id: Af05
  title: 模型工具箱：按问题选模型
  type: framework
  source_chapter: 第1章 1.2节
  source_quote: |
    正如木匠用不同的工具做不同的任务一样，经济学家用不同的模型来解释不同的经济现象。学习宏观经济学的学生必须谨记，不存在单一的、适用于每个经济问题的"正确"模型。相反，存在许多模型，每一个模型都有助于解释经济的某个特定方面。
  summary: |
    解决什么问题：试图寻找一个"放之四海而皆准"的经济总模型。
    核心逻辑：像木匠的工具箱，每个模型为特定问题定制、各有假设；结论"相反"的模型可以并存且都"对"，关键是假设是否匹配手头的问题。
    怎么用：分析问题时先列候选模型，选假设最贴合的那个；给出结论时同时交代"本模型假设了什么"，防止越界使用。
  tags: [模型方法论, 工具箱思维]

  title: 简化到什么程度，由研究目的说了算
  type: framework
  source_chapter: 第1章 1.2节
  source_quote: |
    问题的答案取决于我们的目的。如果我们的目的是解释奶酪的价格如何影响比萨饼的平均价格和销售量，那么，比萨饼价格的多样性大概就不重要了。简单的比萨饼市场模型可以很好地解决这个问题。
  summary: |

    核心逻辑：简化不是缺点而是模型的本质；一个假设是否可接受取决于要回答的问题——同一模型在甲问题里阐明了思考，在乙问题里就会误导（作者说这是"经济学的艺术"）。
    怎么用：被批评"模型太简单"时，先回到研究目的：被忽略的细节对这个问题重要吗？重要才加复杂度，否则保持简单。
  tags: [模型方法论, 简化判断]

- id: Af07
  title: 先长期后短期的分析次序（古典二分法）
  type: framework
  source_chapter: 序言（主题的安排）
  source_quote: |
    我讲授宏观经济学的策略是：首先考察弹性价格的长期，然后考察黏性价格的短期。这种做法有若干优点。第一，由于古典二分法允许实际与货币问题的分离，长期内容更易于被学生理解。第二，当学生开始学习短期波动时，他们懂得了经济波动所围绕的长期均衡。
  summary: |
    解决什么问题：一整套宏观理论应按什么顺序掌握、长期与短期是什么关系。
    核心逻辑：古典二分法把实际变量与名义变量分离，使弹性价格的长期理论可以独立掌握；短期波动是围绕长期均衡的偏离，先懂均衡再懂波动。
    怎么用：分析经济事件时分两层——先算长期锚（潜在产出、自然率），再看短期偏离及其回归路径；学习本书也按此路线（第2、3篇长期与超长期，第4篇短期）。
  tags: [古典二分法, 长期与短期, 学习路线]

- id: Af08
  title: 循环流：收入=支出的一体两面
  type: framework
  source_chapter: 第2章 2.1节
  source_quote: |
    GDP如何能既衡量一个经济的收人，又衡量在产出上的支出呢？原因是这两个量其实是相等的：对整个经济来说，收入必定等于支出。这个事实又是源于一个甚至更基本的事实：由于每笔交易都有一个买者和一个卖者，所以，买者支出的每1美元必然成为卖者的1美元收人。
  summary: |
    解决什么问题：GDP到底是什么，为什么一个数字能同时算总收入与总支出。
    核心逻辑：每笔交易买方的支出即卖方的收入，所以经济循环流的上半圈（收入）与下半圈（支出）必然相等；GDP就是这个循环中美元流量的度量。
    怎么用：从任一侧切入皆可——分析家庭境况看收入面，分析企业销售看支出面；判断"这笔交易算不算GDP"，用"支出与收入是否等量增加"来检验。
  tags: [循环流, GDP, 恒等关系]

- id: Af09
  title: 存量/流量二分法
  type: framework
  source_chapter: 第2章 2.1节 参考资料"存量与流量"
  source_quote: |
    存量（stock）衡量一个给定时点的数量，而流量（flow）衡量每一单位时间内的数量。……一个人的财富是存量；他的收人和支出是流量。……政府债务是存量；政府预算赤字是流量。
  summary: |
    解决什么问题：经济变量单位混乱，把"水池"当"水龙头"。
    核心逻辑：存量是某一时点的量（浴盆里的水），流量是每单位时间的量（水龙头流速）；流量是存量的变动，二者单位不同。GDP是最重要的流量变量。
    怎么用：读任何统计数字先问"这是存量还是流量"；分析问题时用"流量改变存量"把变量连成因果链（投资→资本、赤字→债务、失业人数为存量而失去工作人数为流量）。
  tags: [存量流量, 变量分类, 数据解读]

- id: Af10
  title: 名义=实际×平减指数的换算框架
  type: framework
  source_chapter: 第2章 2.1节
  source_quote: |
    名义GDP=实际GDP×GDP平减指数。……名义GDP衡量经济中产出的现期美元价值。实际GDP衡量按不变价格估值的产出。GDP平减指数衡量产出相对于其基年价格的价格。……它用于平减名义GDP（即从中剔除通货膨胀），以得到实际GDP。
  summary: |
    解决什么问题：价格上涨与真实增长混在一起，分不清"钱多了"还是"东西多了"。
    核心逻辑：任何名义值都可拆成"实际值×价格指数"三元组，知道其中两个可求第三个；平减指数就是"挤出通货膨胀"的那个除数。
    怎么用：看到名义增长先除以价格指数再下结论；同一框架适用于名义工资与实际工资、名义利率与实际利率，凡"名义/实际"成对的变量都照此换算。
  tags: [名义与实际, 换算方法, GDP平减指数]

- id: Af11
  title: 支出分解框架 Y=C+I+G+NX
  type: framework
  source_chapter: 第2章 2.1节
  source_quote: |
    Y=C+I+G+NX ……GDP是消费、投资、政府购买和净出口之和。GDP的每一美元都属于这四大类中的一类。这个等式是一个恒等式（identity）——由于变量定义的方式而必然成立的等式。这个等式被称为国民收人核算恒等式。
  summary: |
    解决什么问题：总量数字太大看不出结构，产出到底被谁买走了。
    核心逻辑：把GDP按买者分成四桶——消费、投资、政府购买、净出口，每一美元必落入且只落入一桶；等式因定义而恒成立，不是行为理论。
    怎么用：分析经济先做结构分解（哪块大、哪块在涨），政策讨论落到具体桶上（刺激消费、扩投资、政府购买、净出口）；第3章的可贷资金分析就建立在这个分解之上。
  tags: [国民收入核算, 恒等式, 结构分解]

- id: Af12
  title: 价格指数设计选择：拉氏 vs 帕氏
  type: framework
  source_chapter: 第2章 2.2节
  source_quote: |
    经济学家把用一篮子固定产品计算的价格指数称为拉氏指数（Laspeyres index，或称拉斯拜尔指数），而把用一篮子可变产品计算的价格指数称为帕氏指数（Paasche index）。
  summary: |
    解决什么问题：把千万种价格加总成一个"物价"时，篮子怎么选。
    核心逻辑：固定篮子（拉氏，如CPI）度量"维持原来那篮子要花多少钱"，可变篮子（帕氏，如GDP平减指数）度量"现在实际买的那篮子要花多少钱"；两者没有明显优劣，且各有系统性偏差——拉氏倾向高估、帕氏倾向低估。
    怎么用：使用任何价格指数先认清篮子类型，判断偏差方向；需要稳健结论时用多个指数（CPI、GDP平减指数、PCE）交叉验证。
  tags: [价格指数, 拉氏帕氏, 衡量方法]

- id: Af13
  title: 劳动力三分类统计框架
  type: framework
  source_chapter: 第2章 2.3节
  source_quote: |
    根据对调查问题的回答，每个成年人（16岁及以上）被归人三种类型之一：就业者……失业者……不属于劳动力者。……劳动力（labor force）是就业者与失业者之和，失业率（unemployment rate）是失业者在劳动力中所占的百分比。
  summary: |
    解决什么问题："多少人失业"看似显然，其实必须先分类才有数字。
    核心逻辑：每个成年人先切成三类（就业/失业/不属于劳动力），劳动力=就业+失业；失业率=失业÷劳动力，劳动力参与率=劳动力÷成年人口；失业者有严格定义（想工作且此前4周在找工作）。
    怎么用：读到失业率先想到分母是劳动力而非全部人口；"退出劳动力"与"失业"是两种不同命运，许多劳动市场故事藏在分类边界的变化里。
  tags: [失业统计, 劳动力市场, 统计口径]

- id: Af14
  title: 理论—观察—检验的侦探循环
  type: framework
  source_chapter: 第2章 章首
  source_quote: |
    他们建立理论以试图理解他们所看到的正在发生的事情。然后，他们转向更系统的观察，以便判断理论的正确性。只有在理论与事实一致时，他们才认为自己理解了事态。
  summary: |
    解决什么问题：如何有根据地认识经济世界，而不是空谈理论或只堆数据。
    核心逻辑：科学家、经济学家、侦探同款循环——先立理论解释所见，再用系统观察检验，理论与事实一致才算理解；宏观无法做受控实验，历史数据就是"案卷"（第1章明确此点）。
    怎么用：分析任何经济现象先明确自己的"理论"（预期是什么），再主动找数据检验；两者冲突时修改理论，而不是歪曲事实（章首福尔摩斯引言的警告）。
  tags: [方法论, 理论与数据, 实证精神]

- id: Af15
  title: 链式加权：让基准价格不过时
  type: framework
  source_chapter: 第2章 2.1节
  source_quote: |
    该局现在使用实际GDP的链式加权（chain-weighted，或称滚动加权、连锁加权）测度。……这种新的实际GDP的链式加权衡量方式比传统的衡量方式更好，因为它确保了用来计算实际GDP的价格永远不会过于陈旧。
  summary: |
    解决什么问题：固定基年用久了失真——电脑价格大跌、学费大涨的年代，还用一二十年前的价格估值会误导。
    核心逻辑：不设永久基年，用相邻两年的平均价格计算逐年实际增长，再把逐年增长率串成"链"，任意两个时期皆可比较。
    怎么用：做长期比较优先用链式加权序列；理解官方实际GDP为何定期"重述"；警惕用陈旧价格给新产品估值造成的偏差。
  tags: [链式加权, 实际GDP, 衡量方法]
