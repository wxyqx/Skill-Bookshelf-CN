- id: Dc01
  title: 作为生产率源泉的良好管理（布鲁姆-范雷南企业调查）
  type: case
  source_chapter: 第9章 9.2节 案例研究
  source_quote: |
    这项研究的要旨是，管理实践的差别有助于解释为什么一些国家比另一些国家有着更高的生产率从而有着更高的收人。这些管理上的差别又可能被追溯到竞争程度和历史传统上的差别。
  summary: |
    方法论主题：生产效率差异的微观根源诊断。
    布鲁姆与范雷南对法、德、英、美732家中型制造企业实地打分发现：管理质量在企业间、国家间高度异质（美国最优、英法垫底），且与企业绩效（销售、利润、市值、低破产率）显著相关；糟糕管理得以持续的两个原因是缺乏竞争与长子继承制（凭出生顺序继任CEO）。
    启示：解释"要素积累与生产效率正相关"时，管理/竞争等微观制度是一条通道；诊断一个经济体的效率短板要下钻到企业层面与历史传统。
  tags: [生产率, 管理, 竞争, 案例]

- id: Dc02
  title: 实践中的产业政策（汉密尔顿关税、阿帕网、通产省vs本田、Solyndra）
  type: case
  source_chapter: 第9章 9.3节 案例研究
  source_quote: |
    日本的通商产业省……曾经竭力阻止本田公司将其业务从摩托车扩展到汽车。……本田成为世界上最大的、利润最高的汽车公司之一。该公司的创始人本田宗一郎曾经说道："如果没有通商产业省，我很可能会更加成功。"
  summary: |
    方法论主题：政府挑选赢家的能力边界——评价产业政策必须同时看正反样本。
    正例：《1789年关税法案》扶持制造业（却伤害农民、埋下南北紧张）；阿帕网（互联网前身）证明政府能启动新兴技术。
    反例：通产省竭力阻止本田造车，幸而失败；Solyndra在获5.35亿美元联邦贷款担保两年后破产。
    结论句：对政府干预市场的最终评判"要求既要评估自由市场的效率，又要评估政府机构识别值得支持的技术的能力"。
  tags: [产业政策, 政府失灵, 案例]

- id: Dc03
  title: 朝鲜与韩国的制度对照实验
  type: case
  source_chapter: 第9章 9.3节（建立适当的制度）
  source_quote: |
    这两个国家曾经是统一的，有着共同的政府、传统、文化和经济。……朝鲜的人均GDP还不到韩国的1/10。……韩国灯火通明——电的广泛使用是经济发达的标志，而朝鲜则笼罩在黑暗之中。
  summary: |
    方法论主题：用"其他条件近乎相同、只有制度不同"的对照设计确立制度的因果地位。
    同一民族、共同历史文化，1945年后沿38度线分别建立苏联模式与美国模式制度，数十年后收入相差10倍以上，夜间卫星灯光图是最直观的展示。
    之所以"最清晰"，是因为它天然排除了文化、地理、民族能力等竞争性解释——变量只剩制度。
    启示：论证制度重要性时寻找这类自然实验；它也是作者从"资本积累vs生产效率"走向"制度作为共同第三变量"的关键证据。
  tags: [制度, 自然实验, 案例]

- id: Dc04
  title: 现代制度的殖民地渊源（阿西莫格鲁-约翰逊-罗宾逊）
  type: case
  source_chapter: 第9章 9.3节 案例研究
  source_quote: |
    在大量欧洲人移居的地区，殖民者建立了欧洲风格的制度，这些制度保护产权和限制政府的权力。与此相对，在赤道气候下，殖民权力机构常常建立"掠夺性"（extractive）制度……
  summary: |
    方法论主题：把可疑的相关（纬度—繁荣）拆解成机制链条，用历史变异识别制度的因果作用。
    四步因果链：17-19世纪赤道疾病（疟疾、黄热病）阻止欧洲人定居→定居者多的地区建立保护产权的欧洲式制度，攫取资源的热带殖民地建立"掠夺性"制度→早期制度延续至今（只是换了本土精英）→制度质量决定投资激励与增长，"今天观察到的生活水平的国际差别的大部分是历史长期作用的结果"。
    启示：地理本身不直接决定贫富，它通过制度起作用——因果链中间环节才是分析重点。
  tags: [制度, 历史, 因果识别, 案例]

- id: Dc05
  title: 自由贸易有利于经济增长吗（从相关到因果的三级证据）
  type: case
  source_chapter: 第9章 9.3节 案例研究
  source_quote: |
    由于这些地理特征与贸易相关，但是可以论证它们与经济繁荣的其他决定因素不相关，所以，它们能够用于确定贸易对收人的因果关系。（这种统计技术被称为工具变量……）
  summary: |
    方法论主题：确立因果关系需要识别策略（工具变量），相关不等于因果。
    三级证据递进：(1)萨克斯-沃纳横截面数据：开放国家增长更快（发达国家2.3%vs0.7%、发展中国家4.5%vs0.7%），但"相关并不能证明因果关系"；(2)开放事件前后增长上升（1850s日本、1960s韩国、1990s越南），仍非决定性；(3)弗兰克尔-罗默用地理禀赋（距主要市场远近、内陆与否）作工具变量——结论："贸易与GDP之比上升1个百分点使人均收人上升至少0.5个百分点"。
    启示：观察性证据层层加码，只有找到外生变异才能下因果结论。
  tags: [自由贸易, 工具变量, 因果识别, 案例]

- id: Dc06
  title: 生产率增长的减缓（1973年断点之谜）
  type: case
  source_chapter: 第9章 附录 案例研究
  source_quote: |
    1973年以前，全要素生产率每年增长1.9%；1973年以后，其增长率每年只有0.7%。……如果生产率增长率一直保持在原先的水平，2016年美国的实际收人将会比现实值高大约67%。
  summary: |
    方法论主题：对TFP（余量指标）的变化做多因诊断，逐一给出可检验推论并接受证伪。
    现象：1973年前后TFP年增长从1.9%骤降至0.7%，累积效应巨大。四个候选解释各有困难：衡量问题（质量改进难测，但须论证"衡量变得更糟"才成立）；石油价格（时序吻合，但被1986年油价大跌后未加速证伪）；工人素质（婴儿潮与女性入场拉低平均经验）；思想枯竭（战时压制的技术储备用尽）。
    结论：此谜至今未解（2016年前十年TFP仅增0.4%/年）。启示：承认未解也是方法论素养。
  tags: [全要素生产率, 增长减缓, 归因, 案例]

- id: Dc07
  title: 大衰退（2007-2009）：产出与失业联动的最新样本
  type: case
  source_chapter: 第10章 10.1节（开篇）
  source_quote: |
    从2007年第三季度到2008年第三季度，经济中产品和服务的生产差不多停滞了……2008年第四季度和2009年第一季度实际GDP陡然下降。失业率从2007年11月的4.7%上升到2009年10月的10.0%。
  summary: |
    方法论主题：奥肯定律的现实注脚——产出收缩如何翻译成失业飙升。
    大衰退事实链：2007Q3-2008Q3生产停滞→2008Q4-2009Q1 GDP陡降→失业率从4.7%升至10.0%→2009年6月衰退正式结束但复苏疲软，失业率直到2016年才回落到5%以下。
    两个教训：一是"产出下降与失业上升紧密相连"的规律再次验证；二是衰退后失业可以长期居高——"复苏疲软"本身是需要解释的现象，并成为第11章财政刺激辩论（奥巴马案例）的背景。
  tags: [大衰退, 奥肯定律, 经济周期, 案例]

- id: Dc08
  title: 如果你想知道为什么企业有黏性价格，询问它们（布林德调查）
  type: case
  source_chapter: 第10章 10.2节 案例研究
  source_quote: |
    黏性价格是常见的。经济中典型的企业一年调整价格一次或两次。……在这12种理论中，协调失灵排在首位。……价格黏性可能是一种不存在单一的微观经济解释的宏观经济现象。
  summary: |
    方法论主题：用直接调查检验理论的现实贴切度，接受"多理论并存"而不是押注单一解释。
    布林德调查企业定价行为：典型企业一年调价1-2次（约10%企业少于一年一次、约10%超过每周一次）；请经理对12种黏性理论逐一评判，每种都有人认同也有人拒绝——协调失灵（等别的企业先调价）以60.6%居首。
    政策推论（布林德）：若协调难以实现，"采用积极的货币政策来遏制衰退就有必要了"。
    补充：纳卡穆拉-斯泰因森用微观价格数据复核，剔除促销后调价频率与布林德结论大体一致。
  tags: [价格黏性, 调查研究, 协调失灵, 案例]

- id: Dc09
  title: 1724年法国的货币教训（价格黏性的历史自然实验）
  type: case
  source_chapter: 第10章 10.4节 案例研究
  source_quote: |
    确实，这正是1724年9月22日发生的事情。每个法国人醒来后都发现，他们的钱比前一天晚上少了20%。在该年的七个月时间里，货币存量的名义价值减少了大约45%。
  summary: |
    方法论主题：现代央行不会做大幅紧缩实验，历史事件可以充当自然实验，验证"短期价格黏性→货币非中性"。
    事件：法国政府一夜之间把货币价值削减20%，七个月内名义货币存量减少约45%。结果：价格与工资没有等幅、即时下降（耗时数月甚至数年），实际工资一度上升，纺织业萎缩约30%（"信贷紧缩"）；1726年5月名义货币增加20%后经济立即复苏。
    作者结论："对法国历史事件的这一描述与我们从现代宏观经济理论得到的启示吻合得很好"——货币在短期确实影响实际变量。
  tags: [货币紧缩, 价格黏性, 历史案例]

- id: Dc10
  title: 欧佩克石油冲击：70年代滞胀与80年代转机
  type: case
  source_chapter: 第10章 10.5节 案例研究
  source_quote: |
    1974年石油价格上升68%是大幅度的不利供给冲击。正如我们所预期的，它既引起了更高的通货膨胀率，又引起了更高的失业率。……在1986年，石油价格下降了将近一半。这种有利的供给冲击导致了美国的低通货膨胀以及失业率下降。
  summary: |
    方法论主题：用"通胀与失业同向还是反向"诊断冲击类型——供给冲击使两者同向恶化（滞胀），需求冲击使两者反向。
    数据链：1974年油价+68%（CPI 11.0%、失业5.6%）；1979-81年再度大涨（通胀两位数、失业7%+）；1986年油价−44.5%（通胀1.9%、失业下降）——有利供给冲击的镜像。
    结构性补充：此后美国单位实际GDP耗油量下降55%、经济转向服务业，对石油冲击的脆弱性大幅下降。
    启示：诊断波动先分清冲击种类，政策处方完全不同（见Df13）。
  tags: [石油冲击, 滞胀, 供给冲击, 案例]

- id: Dc11
  title: 大萧条与凯恩斯革命（模型失效触发范式更替）
  type: case
  source_chapter: 第11章 章首引言
  source_quote: |
    在最严重的年份1933年，美国有1/4的劳动力失业，实际GDP比1929年的水平低30%。……古典理论看起来不能解释大萧条。……许多经济学家认为，需要一个新模型来解释这种大的和突发性的经济衰退。
  summary: |
    方法论主题：理论被淘汰的方式是"关键事实解释不了"；新模型的价值在于既解释异常又给出政策处方。
    大萧条事实（1933年1/4劳动力失业、GDP比1929年低30%）与古典理论（收入由要素供给与技术决定）冲突——因为1929-1933年间要素与技术没有重大变动。凯恩斯1936年《通论》应运而生：总需求低迷才是衰退的罪魁。
    后续：2008-09大衰退使这些争论"再次成为经济政策争论的中心"。
    启示：范式更替的经验触发点是解释力的硬失败，而不是逻辑瑕疵。
  tags: [大萧条, 凯恩斯革命, 模型更替, 案例]

- id: Dc12
  title: 肯尼迪减税与布什减税（同一政策的双机制归因）
  type: case
  source_chapter: 第11章 11.1节 案例研究
  source_quote: |
    当一个记者问肯尼迪为什么主张减税时，肯尼迪回答："为了刺激经济。难道你不记得经济学101了吗？"……减税通过之后，经济繁荣接踵而至。1964年实际GDP增长了5.8%，1965年实际GDP增长了6.5%。
  summary: |
    方法论主题：同一政策可经两条机制起效（总需求vs供给激励），归因必须区分机制；政策辩护词会随形势切换。
    1964年大减税后繁荣（GDP增5.8%、6.5%，失业降至4.5%）——供给学派归因于劳动供给激励，凯恩斯主义者归因于可支配收入扩大总需求；作者判断"最有可能的是，这两种观点都有正确之处"。
    布什2001/2003减税：经济尚好时用供给逻辑（提高工作激励）辩护，经济减速后转用需求逻辑（刺激支出）——同一政策、两套话语。
    启示：听政策辩护时先识别用的是哪套机制。
  tags: [减税, 供给学派, 凯恩斯主义, 案例]

- id: Dc13
  title: 奥巴马刺激计划（乘数的政策应用与评估争议）
  type: case
  source_chapter: 第11章 11.1节 案例研究
  source_quote: |
    国会通过了奥巴马总统提议的刺激计划……总额达7870亿美元的法案。它有效果吗？经济从衰退中复苏了，但比奥巴马政府的经济学家起初预测的要慢。……这是一个持续争论的问题。
  summary: |
    方法论主题：模型给基准，实证与配置顾虑做修正；政策效果评估本身陷入归因困境。
    2009年刺激案（7870亿美元，约GDP的5%）：支持者按乘数逻辑主张支出优于减税（政府购买乘数1.57 vs 税收乘数0.99）；克鲁格曼批评规模太小（面对每月失去60万岗位的经济体，承诺创造350万岗位不够）；阿莱西纳-阿达格纳跨国研究发现减税型刺激更成功；贝克担心为救就业建的基础设施错配真实需求（萧条地区vs成长地区）。
    结果：复苏慢于官方预测——是刺激失败还是衰退比认识到的更严重？无法简单裁决（见Dk14）。
  tags: [财政刺激, 乘数, 政策评估, 案例]

- id: Dc14
  title: 用区域数据估计乘数（准实验识别及其外推边界）
  type: case
  source_chapter: 第11章 11.1节 案例研究
  source_quote: |
    利用美国所有50个州的数据，纳卡穆拉和斯泰因森得到政府购买乘数为1.5。也就是说，政府在一个州增加1美元的国防支出会使该州的GDP增加1.5美元。
  summary: |
    方法论主题：全国财政政策因果难分离（政策内生），改用区域数据获取准随机变异，再显式讨论外推边界。
    两个准实验：纳卡穆拉-斯泰因森利用国防产业州际暴露差异（联邦增购时加州国防支出增约3%州GDP、伊利诺伊仅0.5%）估出乘数≈1.5；阿孔恰等利用意大利反黑手党法（市议会解散→公共投资骤减）得≈1.5——与凯恩斯预测一致。
    但外推到全国有三个反向修正：区域支出由全国税收筹资、不引起货币政策反应（两者使全国乘数偏小），小区域进口漏损大（使其偏小——即全国乘数可能偏大）。
    启示：换测量层面做识别，结论外推前必须列出层面特有机制。
  tags: [乘数估计, 因果识别, 区域数据, 案例]
