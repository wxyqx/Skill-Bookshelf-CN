  title: 有技术进步的索洛模型（有效工人分析框架）
  type: framework
  source_chapter: 第9章 9.1节
  source_quote: |
    我们现在用k=K/(L×E)代表有效工人的人均资本……资本存量的变动△k等于投资sf（k）减去收支相抵的投资（δ+n+g）k。……nk是为新工人提供资本所需要的，gk是为技术进步所创造的新的"有效工人"提供资本所需要的。
  summary: |
    解决"人均产出的持续增长从哪里来"的问题。把技术进步建模为劳动效率E以速率g提高，分析单位从"人均"改成"有效工人人均"，资本积累方程变为 △k=sf(k)−(δ+n+g)k：投资要同时抵消折旧、人口增长和"有效工人"扩张三股摊薄力量。
    用法：给定s、n、g、δ即可解出稳态k*，再由表9-1推出各变量的稳态增长率——有效工人人均量不变、人均产出按g增长、总产出按n+g增长。
    这个框架是第8章人口增长分析向技术进步分析的"平移模板"，说明技术进步为何在增长理论中地位特殊：它接管了长期人均增长率的解释权。
  tags: [经济增长, 索洛模型, 技术进步, 稳态]

- id: Df02
  title: 黄金律检验（判断一国储蓄率是否合意）
  type: framework
  source_chapter: 第9章 9.3节
  source_quote: |
    为了确定美国经济处于、高于还是低于黄金律稳态，我们需要比较减去折旧后的资本的边际产量（MPK−δ）与总产出增长率（n+g）。正如我们在9.1节所证明的，在黄金律稳态，MPK−δ=n+g。
  summary: |
    解决"一国储蓄率是太高、太低还是合适"的评价问题。有技术进步时黄金律条件为：资本净边际产量等于总产出增长率（MPK−δ=n+g）。
    操作三步：用国民收入核算事实（资本存量≈2.5年GDP、折旧≈GDP的10%、资本收入≈GDP的30%）解出δ≈4%与MPK≈12%，得MPK−δ≈8%；再与n+g≈3%比较；若MPK−δ>n+g则资本低于黄金律、应提高储蓄，反之应降低。
    作者据此判断美国（及多数经济体）储蓄不足。用法：任何"该不该鼓励储蓄"的辩论，先做这道估算题再表态。
  tags: [黄金律, 储蓄率, 政策评价]

- id: Df03
  title: 增长核算（增长三大源泉的定量分解）
  type: framework
  source_chapter: 第9章 附录（经济增长源泉的核算）
  source_quote: |
    产出增长=资本的贡献+劳动的贡献+全要素生产率的增长。这是增长核算的关键方程。它确定了并且让我们可以衡量增长的三个源泉：资本量的变动、劳动量的变动和全要素生产率的变动。
  summary: |
    解决"一段增长中有多少来自投入、多少来自效率"的归因问题。方程为 △Y/Y=α△K/K+(1−α)△L/L+△A/A，权重取要素收入份额（美国α≈0.3，故资本增10%只带来产出增3%）。
    全要素生产率（TFP）不可直接观察，作为余量倒算出来（索洛余量），是"考虑了可直接衡量的增长决定因素后剩余的产出增长量"。
    用法：拿到产出、资本、劳动的增长数据与资本份额，即可分解增长来源（书中美国1948-2016：3.4%≈1.3%资本+1.0%劳动+1.1%TFP），再追问余量背后是知识、教育还是管制。
  tags: [增长核算, 全要素生产率, 索洛余量]

- id: Df04
  title: 内生增长基本模型（Y=AK）
  type: framework
  source_chapter: 第9章 9.4节
  source_quote: |
    如果sA>δ，那么，即使没有外生技术进步的假设，经济的收人也会永远增长下去。……在索洛模型中，储蓄暂时性地导致增长，但资本收益递减最终迫使经济达到稳态……相反，在这个内生增长模型中，储蓄和投资可以导致持续增长。
  summary: |
    解决"没有外生技术进步时储蓄能否带来永久增长"的问题。把生产函数设为Y=AK（资本收益不变），与资本积累方程△K=sY−δK联立得 △Y/Y=△K/K=sA−δ：只要sA>δ，收入永远增长。
    与索洛模型的唯一关键差别是资本收益是否递减；作者给出的辩护是把知识看作一种资本——知识收益递减并不自然。
    用法：遇到"储蓄/投资能否驱动长期增长"的问题，先问K里包含什么——若把知识计入资本，收益不变的内生增长模型就成立，储蓄率s直接进入增长率。
  tags: [内生增长, 经济增长, 知识资本]

- id: Df05
  title: 两部门内生增长模型（大学生产知识）
  type: framework
  source_chapter: 第9章 9.4节
  source_quote: |
    正如在索洛模型中一样，用于储蓄和投资的产出比例s决定了稳态的实物资本存量。此外，大学中劳动力的比例u决定了知识存量的增长。尽管只有u影响稳态的收人增长率，但s和u都影响收人水平。
  summary: |
    解决"技术进步率由什么社会决策决定"的问题。设两个部门：制造业企业生产产品 Y=F[K,(1−u)LE]，研究型大学生产知识 △E=g(u)E，资本积累照旧；把资本广义化（实物资本+知识）后整体收益不变，持续增长内生产生。
    关键结论：劳动力在大学的配置比例u决定稳态收入增长率，储蓄率s只影响收入水平——模型在"哪些社会决策决定技术变化速率"上迈出一步。
    用法：分析研发投入、教育资源配置对长期增长的影响，以及"提高u是否一定更好"（要权衡制造业产出损失）。
  tags: [内生增长, 两部门模型, 研发]

- id: Df06
  title: 富国穷国差距归因框架（要素积累 vs 生产效率）
  type: framework
  source_chapter: 第9章 9.2节
  source_quote: |
    人均收人的国际差别可以被归因于生产要素的差别，例如实物和人力资本数量的差别，或者各经济体使用其生产要素的效率的差别。……究竟是用（1）资本积累（包括人力资本）的差别还是（2）生产函数的差别？
  summary: |
    解决"如何解释国家间巨大收入差距"的诊断问题。把差距拆成两大候选原因：要素积累的差别（缺工具和技能）与生产效率的差别（有工具技能但没用好）。
    经验研究发现两者正相关，于是进一步用三种假说解释因果方向：效率促进积累、积累引致效率（外部性）、共同第三变量驱动（尤其是制度质量——"当政府把事情搞糟时，它们就彻底搞糟了"）。
    用法：分析任何穷国/落后地区案例时先做这道二选一诊断，再追问背后的共同根源（制度、政策、腐败）。
  tags: [发展差距, 生产效率, 制度]

- id: Df07
  title: 时间范围选择框架（用价格行为定长短）
  type: framework
  source_chapter: 第10章 10.2节
  source_quote: |
    大多数宏观经济学家认为，短期与长期之间的关键差别是价格行为。在长期，价格是有灵活性的，能对供给或需求的变动作出反应。在短期，许多价格是"黏性的"，固定在某个前定水平上。
  summary: |
    全书的元框架：面对任何宏观问题先问"分析的时间范围是什么"。判据只有一个——价格行为：长期价格有弹性，古典模型适用（货币中性、古典二分法成立，名义变量不影响实际变量）；短期价格黏性，古典二分法失效，需求决定产出。
    由于价格行为不同，"各种经济事件和政策在不同时间范围中有不同的影响"——同一项政策（如货币供给减少5%）长期只改价格、短期改变产出与就业。
    用法：选模型之前先定时间范围；读任何政策辩论先分辨双方谈的是哪个时间尺度。
  tags: [方法论, 时间范围, 价格黏性, 古典二分法]

- id: Df09
  title: 用货币数量方程推导总需求曲线
  type: framework
  source_chapter: 第10章 10.3节
  source_quote: |
    如果我们假设流通速度V是常数，货币供给M由中央银行固定，那么数量方程得出了价格水平P和产出Y之间的负相关关系。……这条向右下方倾斜的曲线被称为总需求曲线。
  summary: |
    给总需求曲线一个"简单但不完全"的第一推导：MV=PY中V固定、M由央行给定，则P越高Y必越低；M增加使AD右移、M减少使AD左移。
    经济学直觉有两条：价格水平上升→每次交易需要更多美元→交易次数（购买量）下降；或者价格上升→实际货币余额M/P下降→可支撑的交易量与需求量下降。
    用法：作为AD曲线的入门推导和"货币政策如何移动AD"的第一近似；作者同时预先警告它不完全——流通速度会变，完整理论要等IS-LM。

- id: Df10
  title: 奥肯定律（产出与失业的换算器）
  type: framework
  source_chapter: 第10章 10.1节
  source_quote: |
    通过散点画出的线告诉我们：实际GDP的百分比变动=3%−2×失业率的变动。……失业率每上升一个百分点，实际GDP增长通常下降2%。
  summary: |
    把产出波动翻译成失业波动的经验转换器：GDP增长%≈3%−2×失业率变动。3%是正常增长（来自劳动力增长、资本积累和技术进步）；2是失业变动对GDP的边际影响（美国数据相关系数−0.81）。
    例：失业率从5%升到7%→GDP增长=3%−2×2=−1%，即经济处于衰退。
    用法：给定失业数据快速估计产出缺口，或反向估计衰退的就业代价；同时用它区分两类问题——GDP的长期增长（与技术进步有关，与失业的长期趋势无关）与短期波动（与劳动力使用密切相关）。
  tags: [奥肯定律, 失业, 经验规律]

- id: Df12
  title: 冲击分类与稳定化政策框架
  type: framework
  source_chapter: 第10章 10.5节
  source_quote: |
    经济学家把使这些曲线移动的外生事件称为对经济的冲击（shock）。使总需求曲线移动的冲击称为需求冲击……使总供给曲线移动的冲击称为供给冲击……稳定化政策（stabilization policy）……指代旨在减少短期经济波动严重性的政策行动。
  summary: |
    波动归因与应对的总框架。第一步分类：让AD/AS移动的外生事件=冲击，分需求冲击（如信用卡普及提高货币流通速度）与供给冲击（又称价格冲击，如石油涨价）。
    第二步应对：稳定化政策的目标是使产出与就业尽可能贴近自然水平；因为货币政策能强力移动AD，它是主要工具。
    用法：诊断波动来源（需求冲击：通胀与失业反向；供给冲击：同向恶化）→判断政策能否抵消——需求冲击可对冲，供给冲击面临两难（见Df13）。
  tags: [冲击, 稳定化政策, 诊断框架]

- id: Df13
  title: 不利供给冲击的应对两难（适应 vs 硬扛）
  type: framework
  source_chapter: 第10章 10.5节
  source_quote: |
    面对不利的供给冲击，具有影响总需求能力的政策制定者，如美联储，会在两个选项之间作出困难的选择。……第二个选项是扩大总需求……我们说美联储适应（accommodate）了供给冲击。这个选项的缺点是，价格水平永久性地更高了。
  summary: |
    决策框架：不利供给冲击后SRAS上移（滞胀），政策制定者只有两个都不完美的选项——
    (1) 保持总需求不变：产出与就业低于自然水平，靠痛苦的价格缓慢下调恢复到A点，代价是"痛苦的衰退"；
    (2) 扩大总需求"适应"冲击：经济直接移到C点、更快回到自然产出，代价是价格水平永久性更高。
    核心结论：稳定产出与稳定价格不可兼得（见Dp14）。
    用法：观察央行面对油价/成本冲击时的表态，判断它选择了哪条路径及其代价。
  tags: [供给冲击, 滞胀, 政策权衡]

- id: Df14
  title: 凯恩斯交叉（收入决定基石模型）
  type: framework
  source_chapter: 第11章 11.1节
  source_quote: |
    在《通论》中，凯恩斯提出，在短期中经济的总收人主要由家庭、企业和政府的支出计划决定。……因此，凯恩斯相信，衰退和萧条期间的问题是支出不足。凯恩斯交叉模型化了这种见解。
  summary: |
    最简收入决定模型，IS曲线的基石。构件：计划支出PE=C(Y−T)+I+G（斜率=边际消费倾向MPC）、45°线、均衡条件Y=PE（实际支出=计划支出）。
    核心调整机制是计划外存货：生产>计划销售→存货被动累积→企业解雇工人、削减生产→GDP下降，反向亦然，经济自动回到均衡——"存货在调整过程中起着重要的作用"。
    用法：在I与财政政策给定时决定Y，再做财政政策比较静态（乘数，见Df15）；它把"支出不足导致衰退"这一凯恩斯诊断模型化（见Dp15）。
  tags: [凯恩斯交叉, 收入决定, 存货调整]

- id: Df15
  title: 财政乘数分析（政府购买乘数与税收乘数）
  type: framework
  source_chapter: 第11章 11.1节
  source_quote: |
    政府购买的增加引起收人甚至更大幅度的增加。也就是说，△Y大于△G。△Y/△G这一比率称为政府购买乘数……凯恩斯交叉的一个启示是：政府购买乘数大于1。
  summary: |
    解决"财政政策对收入的总效应有多大"。机制是消费-收入的循环反馈：△G先变成等额收入，再按MPC逐轮转化为消费（MPC×△G、MPC²×△G……），总效应是无穷等比数列求和。
    结果：政府购买乘数=1/(1−MPC)>1（MPC=0.6时为2.5）；税收乘数=−MPC/(1−MPC)（MPC=0.6时为−1.5），绝对值较小，因为减税第一轮只有MPC部分进入支出。
    用法：给MPC即可算两个乘数，比较不同刺激工具的力度；也是后来IS曲线移动幅度（△G/(1−MPC)）的计算基础。
  tags: [财政政策, 乘数, 凯恩斯交叉]

  title: IS曲线（产品市场均衡的r-Y轨迹）
  type: framework
  source_chapter: 第11章 11.1节
  source_quote: |
    IS曲线结合了投资函数所表示的r和I之间的相互作用以及凯恩斯交叉所表示的I和Y之间的相互作用。IS曲线上的每一点都代表产品市场的均衡，该曲线显示了均衡收人如何依赖于利率。
  summary: |
    把利率引入收入决定的组合拳：利率r上升→计划投资I(r)下降（利率是融资成本）→计划支出线下移→均衡收入下降（凯恩斯交叉）；把每一轮的(r,Y)组合描点，得到向右下方倾斜的IS曲线。
    IS曲线按给定的财政政策绘出：G增加或T减少使IS向外（右）移动，移动量为乘数放大的△G/(1−MPC)。
    用法：分析产品市场均衡如何随利率与财政政策变动；它是IS-LM框架的一半，与LM联立后决定短期均衡(r,Y)。

- id: Df17
  title: 流动性偏好理论（短期利率决定模型）
  type: framework
  source_chapter: 第11章 11.2节
  source_quote: |
    他的解释被称为流动性偏好理论，因为它假设利率调整使经济中最具流动性的资产——货币——的供给和需求平衡。正如凯恩斯交叉是IS曲线的基石一样，流动性偏好理论是LM曲线的基石。
  summary: |
    凯恩斯的短期利率理论：实际货币余额供给M/P（央行定M、P黏性，供给曲线垂直）与需求L(r)（利率是持币的机会成本，r越高需求越少）的交点决定利率。
    比较静态：货币供给减少→M/P左移→均衡利率上升；货币供给增加→利率下降。调整机制是资产组合调整——货币过多时人们买债券，压低利率。
    用法：解释央行在短期如何移动利率，是LM曲线的基石；注意其时间范围限定——长期名义利率由费雪效应主导（见Dp19）。

- id: Df18
  title: LM曲线（货币市场均衡的r-Y轨迹）
  type: framework
  source_chapter: 第11章 11.2节
  source_quote: |
    LM曲线上的每一点都代表货币市场的均衡，该曲线表示均衡利率如何依赖于收人。收人水平越高，实际货币余额的需求就越高，均衡利率也越高。由于这个原因，LM曲线向右上方倾斜。
  summary: |
    在流动性偏好理论中引入收入：货币需求改写为L(r,Y)，与利率负相关、与收入正相关（收入高→交易多→需要更多货币）。收入Y上升→货币需求右移→利率上升；描点得向右上方倾斜的LM曲线。
    LM按给定的实际货币余额供给M/P绘出：货币供给减少使LM向上移动，增加使LM向下移动。
    用法：与IS曲线联立，交点给出给定价格水平下同时满足两个市场均衡的(r,Y)；是分析货币政策第一步效应的工具。
