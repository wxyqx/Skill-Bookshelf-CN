- id: Ec01
  title: 2001年美国衰退——三重IS冲击与政策对冲
  type: case
  source_chapter: 第12章 12.1节（案例研究）
  source_quote: |
    三个值得注意的冲击解释了这一事件。第一个是股票市场的下跌。……第二个冲击是2001年9月11日恐怖分子对纽约和华盛顿的袭击。……第三个冲击是一些全国最著名公司……的一系列会计丑闻。
  summary: |
    方法论主题：用IS-LM对多冲击事件做逐项归因，并检验政策对冲效果。失业率从2000年9月的3.9%升至2003年6月的6.3%，归因于三个连续的IS左移：股市下跌25%压消费与投资、911袭击增加不确定性推迟支出、安然/世通丑闻抑制企业投资。
    政策面：减税+增支（IS右移）与扩张货币（LM右移）同时对冲，2003年下半年增长回升。教学价值：展示"冲击识别→曲线移动→政策逆向操作"的完整作业流程，不确定性本身作为需求冲击进入分析。
  tags: [案例研究, IS冲击, 政策对冲, 不确定性]

- id: Ec02
  title: 大萧条1929-1933——一个事件、三套竞争性解释
  type: case
  source_chapter: 第12章 12.3节
  source_quote: |
    20世纪30年代初的收入减少与利率下降是同时发生的。这个事实促使一些经济学家提出，收入减少的原因可能是IS曲线的紧缩性移动。这一观点有时被称为支出假说，因为它把萧条的罪魁祸首归结为在产品与服务上支出的外生下降。
  summary: |
    方法论主题：用单一模型框架组织对重大历史事件的多重解释与筛选。数据指纹：收入降+利率降→指向IS左移（支出假说：股市崩盘压消费、住房过度建设退潮、银行倒闭断信贷、1932年《岁入法》紧缩财政）；货币供给降25%→货币假说（弗里德曼-施瓦茨），但LM左移应抬高利率，与事实矛盾——需借助通货紧缩的不稳定渠道（债务-通缩、预期通缩）补救，把严重性归咎于美联储。
    教学价值：展示"让数据指纹裁决假说、允许多因并存"的归因工艺，而非非此即彼的站队。
  tags: [大萧条, 支出假说, 货币假说, 归因方法]

- id: Ec03
  title: 2008-2009金融危机与大衰退——危机传导链与政策强度的反事实比较
  type: case
  source_chapter: 第12章 12.3节（案例研究）
  source_quote: |
    不断下降的住房价格、不断增加的取消住房赎回权、金融不稳定性以及更高的波动性共同导致了第四个后果：消费者信心的下降。……作为所有这些事件的结果，经济经历了一次大的IS曲线收缩性移动。……由于政策制定者的积极应对，另一次大萧条被成功地避免了。
  summary: |
    方法论主题：把金融危机翻译成IS-LM语言，并用历史对照组评估政策。传导链：低利率+证券化催生房价泡沫→房价跌30%→资不抵债、止赎激增→抵押担保证券巨亏、银行互不信任→信贷冻结→信心崩塌、耐用品支出骤降→大的IS收缩性移动（失业率4.7%→10.0%）。
    对照组：工业生产大萧条跌超50%用7年恢复，大衰退仅跌17%用不到6年恢复——归因于政策强度（零利率、7000亿注资、财政刺激、QE）。教学价值：反事实比较（若不做会怎样）与跨事件标准化比较（峰值=1.0）的用法。
  tags: [金融危机, IS冲击, 反事实比较, 政策响应]

- id: Ec04
  title: 大萧条会重演吗——制度防线的清单化
  type: case
  source_chapter: 第12章 12.3节
  source_quote: |
    联邦存款保险体系使大面积的银行倒闭的可能性降低了。所得税制使税收在收入下降时自动减少，这起到了稳定经济的作用。最后，今天的经济学家比20世纪30年代的经济学家知道得更多。
  summary: |
    方法论主题：从历史错误中提炼可核查的制度防御清单。作者承认起因未定论、无法确切排除重演，但逐条列出已拆除的引信：①央行不会再放任货币供给减少四分之一、长期通缩不再可能；②大规模失业下坚持平衡预算的错误不再犯；③存款保险阻断银行挤兑传染；④所得税自动稳定器在收入下降时自动减税；⑤知识存量本身是防线。
    教学价值：示范"承认不确定性+列出已封堵的具体错误"的风险陈述方式，把"会不会重演"转化为"哪些机制已被制度性封堵"。
  tags: [大萧条, 制度设计, 自动稳定器, 风险评估]

- id: Ec05
  title: 国际金本位——用套利者的自利实现自动均衡
  type: case
  source_chapter: 第13章 13.3节（案例研究）
  source_quote: |
    套利者进行的黄金国际运输是调整货币供给和稳定汇率的自动机制。这种制度并没有完全固定汇率，因为横跨大西洋运送黄金是成本高昂的。但国际金本位确实把汇率保持在运输成本决定的范围内。
  summary: |
    方法论主题：机制设计——让个体的逐利行为自动执行宏观均衡，无需央行干预。美元与英镑各自钉住黄金后，汇率偏离即产生套利利润：市场汇率1美元兑2英镑时，买英镑-换黄金-运美-卖美元净赚，黄金流入自动扩张美国货币供给、收缩英国货币供给，把汇率拉回。运输成本只留下一个窄幅波动带。
    教学价值：与美联储主动干预的固定汇率（套利者把外汇卖给央行获利，效果相同）对照，理解"自动调节机制"的两种实现；也预埋了金本位在大萧条中变成紧缩枷锁的伏笔（见Ec06）。
  tags: [金本位, 套利, 机制设计, 自动稳定]

- id: Ec06
  title: 法定贬值与从大萧条中的复苏——汇率制度选择作为决定性杠杆
  type: case
  source_chapter: 第13章 13.3节（案例研究）
  source_quote: |
    那些实行法定贬值政策的国家迅速从大萧条中复苏。更低的通货价值增加了货币供给，刺激了出口，扩大了生产。与此相反，那些维持原有汇率的国家受经济活动水平低下之苦的时间更长。
  summary: |
    方法论主题：用蒙代尔-弗莱明的预测做历史分组检验。1930年代各国对金本位的态度天然分成两组：法国、德国、意大利、荷兰坚守原平价；丹麦、芬兰、挪威、瑞典、英国贬值约50%。结果与模型预测一致——贬值组快速复苏（货币扩张+出口刺激），坚守组萧条更久。美国是自然实验：胡佛守住金本位、罗斯福1933年6月弃金，恰在当月通缩结束、复苏开始，经济史学家视之为罗斯福最重要的反萧条行动。
    教学价值：识别"准实验"式的历史检验——制度选择差异充当了处理组/控制组的分界。
  tags: [大萧条, 法定贬值, 蒙代尔-弗莱明, 历史检验]

- id: Ec07
  title: 墨西哥1994-1995——风险贴水、储备耗尽与信任崩塌的危机链条
  type: case
  source_chapter: 第13章 13.4节（案例研究）
  source_quote: |
    感知的国家风险的变动——常常是由于政治不稳定所引起的——是小型开放经济中利率和汇率的一个重要决定因素。
  summary: |
    方法论主题：用r=r*+θ框架诊断货币危机的因果链。比索从30美分跌到16美分的机制：NAFTA后的乐观被恰帕斯起义与总统候选人遇刺逆转→θ飙升→固定汇率下央行被迫卖美元护盘、货币内生收缩→储备告罄→被迫法定贬值→食言摧毁信任→θ再升、比索再贬、股市暴跌、无法滚动还债→濒临破产→美国+IMF贷款担保恢复信心。
    教学价值：展示固定汇率的死亡螺旋（护盘→紧缩→储备耗尽→食言→更深的信任危机），以及"承诺可信性"如何进入经济变量；贷款担保通过压低θ起作用，是预期管理的政策工具样本。
  tags: [货币危机, 风险贴水, 固定汇率, 预期管理]

- id: Ec08
  title: 亚洲1997-1998——信心危机的六步恶性循环与通货错配放大器
  type: case
  source_chapter: 第13章 13.4节（案例研究）
  source_quote: |
    1.银行业系统的问题削弱了国际投资者对这些经济的信心。2.信心的丧失提高了风险贴水和利率。3.利率的上升与信心的丧失共同抑制了股票和其他资产的价格。4.资产价格的下降降低了用于银行贷款的抵押品的价值。5.抵押品价值的减少增加了银行贷款的拖欠率。6.越来越多的拖欠加剧了银行业系统的问题。
  summary: |
    方法论主题：把金融危机表述为可循环迭代的传导链条，并识别放大参数。起点是真实问题——"裙带资本主义"（银行按政治影响力而非盈利性放贷）暴露→信心崩塌；链条六步首尾相接自我强化（印尼：利率超50%、股市缩水90%、卢比贬80%、1998年GDP降13%）。放大器是通货与期限错配：银行外币借债（美元）、本币放贷，本币贬值直接恶化资产负债表。IMF的处方是短贷+改革承诺换信心，把恶性循环扭成良性循环。
    教学价值：两种解释的并存处理——"自我实现的预言"与"真实问题的循环放大"，作者裁定后者为主、前者为放大机制。
  tags: [亚洲金融危机, 恶性循环, 通货错配, 裙带资本主义]

- id: Ec09
  title: 关于欧元的争论——最优货币区条件的具体化
  type: case
  source_chapter: 第13章 13.5节（案例研究）
  source_quote: |
    美国与欧洲在两个重要的方面存在差别。第一，美国各州之间劳动力的流动性大于欧洲各国之间。……第二，美国有强大的中央政府，可以运用财政政策……在各地区之间重新分配资源。
  summary: |
    方法论主题：把"该不该加入货币联盟"还原为可检验的条件清单。货币联盟=固定汇率的极端形式（美国50州即一个联盟）。成本：放弃各国货币政策——2008-2013年南欧失业率（西班牙26.1%、希腊27.3%）无法用本币贬值促出口缓解，德国却降至5.3%。美国为何撑得住？两大调节器：①劳动力跨州流动吸收地区冲击；②联邦财政跨地区再分配。欧洲两者皆弱，故成本更大。
    教学价值：评价任何货币 union 时检查"要素流动性+财政转移"这两项替代性调节机制是否存在、是否够用。
  tags: [欧元, 货币联盟, 最优货币区, 劳动力流动]

- id: Ec10
  title: 人民币争论——用不可能三角形解读汇率政治
  type: case
  source_chapter: 第13章 13.5节（案例研究）
  source_quote: |
    1995-2005年中国的通货，人民币，以8.28元兑1美元的汇率与美元挂钩。……这一固定汇率的政策与限制资本国际流动的政策相结合。
  summary: |
    方法论主题：把国际汇率争端翻译成三角形占位问题。中国1995-2005年的组合是"选项3"：固定汇率+资本管制，换取独立货币政策；维持低估汇率靠央行发人民币买美元积累巨额储备。美国的抱怨（低估的人民币补贴出口）与中国的选择在三角框架下各有定位——美国选项1（浮动+自由资本流动），香港选项2（固定+自由流动）。结局：2005年7月改为一篮子有管理浮动，十年升值约25%，议题降温。
    教学价值：示范框架的第一用途——把情绪化的贸易政治争论去情绪化，先问"各方的制度组合是什么、放弃了哪个角"。
  tags: [不可能三角形, 人民币, 汇率争端, 资本管制]

- id: Ec11
  title: 总供给曲线的国际差别——卢卡斯的跨国检验
  type: case
  source_chapter: 第14章 14.1节（案例研究）
  source_quote: |
    根据他的模型，总供给曲线的斜率应该取决于总需求的波动。……卢卡斯利用产出和价格的国际数据检验了这一预测。他发现，在那些总需求和价格最稳定的国家里，总需求变动对产出的影响最大。
  summary: |
    方法论主题：让理论输出可证伪的跨国预测，用数据差异裁决。不完备信息模型预测：总需求波动大的国家，物价变动多为一般性上涨、供给者学会不反应→总供给陡（α小）；需求平稳的国家，价格变动多为相对价格信号→供给者强烈反应→总供给平（α大）。数据支持卢卡斯。黏性价格模型给出第二个可检验预测：平均通胀越高→企业调价越频繁→摩擦消失→总供给越陡，国际数据同样支持。
    教学价值：两个竞争理论在同一数据集上各自通过检验且互不排斥——理论评价的标准操作是"导出预测→找差异场景→检验"，而非寻找唯一胜者。
  tags: [卢卡斯, 总供给, 跨国检验, 可证伪性]

- id: Ec12
  title: 美国通胀与失业1960-2016——用三力量框架读半个世纪
  type: case
  source_chapter: 第14章 14.2节（案例研究）
  source_quote: |
    20世纪60年代和80年代的情况说明了需求拉动型通货膨胀的两面：在60年代，低失业拉高了通货膨胀；而在80年代，高失业拉低了通货膨胀。20世纪70年代的石油价格上涨显示了成本推动型通货膨胀的影响。
  summary: |
    方法论主题：以π=Eπ−β(u−u*)+v为解码器通读宏观史。60年代：减税+越战开支的需求扩张→失业破5%、需求拉动通胀；70年代：欧佩克两次提价→成本推动，尼克松的工资物价控制+温和紧缩失效；80年代：沃尔克紧缩→1982-83年失业达40年最高，把通胀从9%压到2%（需求拉动的反向运用）；2008-09：失业高企却未现通缩——预期锚定2%，可信性改变了曲线行为。
    教学价值：单一方程的三项分别对应三个年代的主导力量，展示"一个框架覆盖一组异质历史"的解析力，也暴露其边界（2008年的意外）。
  tags: [菲利普斯曲线, 需求拉动, 成本推动, 沃尔克]

- id: Ec13
  title: 实践中的牺牲率——沃尔克反通胀的历史核算
  type: case
  source_chapter: 第14章 14.2节（案例研究）
  source_quote: |
    我们知道GDP损失了20.0%，通货膨胀率下降了6.1%。因此，通货膨胀率每下降1%所损失的GDP为20.0/6.1=3.3个百分点。沃尔克反通货膨胀的这段时期的牺牲率估计值为3.3。
  summary: |
    方法论主题：把抽象参数变成可复核的历史核算。步骤：通胀从1981年峰值9.3%（GDP平减指数）降到1985年的3.2%，降幅6.1个百分点（1986年油价暴跌是有利供给冲击，故截断于1985年排除干扰）；以自然率6%逐年累计周期性失业10.0%；奥肯定律折算GDP损失20.0%；相除得牺牲率3.3——低于事前普遍预测，归因于沃尔克立场的可信性压低了部分预期。
    教学价值：完整示范参数估算全程（定窗口、控混杂、定基准、算比值），并引出65次反通胀的横截面发现：快比慢省、工资灵活者省。
  tags: [牺牲率, 沃尔克, 奥肯定律, 参数估算]
