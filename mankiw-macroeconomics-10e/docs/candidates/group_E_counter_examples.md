# 第12-14章 反例/陷阱（counter-example）候选 — group E
# 来源：《宏观经济学（第十版）》曼昆 第12章（总需求Ⅱ：应用IS-LM模型）、第13章（蒙代尔-弗莱明模型与汇率制度）、第14章（总供给与菲利普斯曲线）
# 均为作者明确警告的误区或失败教训

- id: Ek01
  title: 流动性陷阱——利率到零后常规货币政策失效
  type: counter-example
  source_chapter: 第12章 12.3节
  source_quote: |
    如果利率已经下降到几乎为零，那么也许货币政策就不再有效了。名义利率不可能下降到零以下：一个人与其以负的名义利率放贷，还不如就持有现金。
  summary: |
    作者明确警示的货币政策边界：扩张性货币政策靠降利率刺激投资起作用，但名义利率存在零下限（持有现金零收益优于负利率放贷），利率贴近零时进一步增加货币供给只让资产组合更"流动"而无任何效果，总需求可能被锁死在低水平。1930年代美国（利率长期低于1%）与2008年12月后（联邦基金利率0-0.25%维持至2016年）是两例。
    教学点：作者同时给出怀疑派回应（前瞻指引、量化宽松仍有空间）——陷阱是"常规工具失效"，不是"政策彻底失效"。
  tags: [流动性陷阱, 零下限, 货币政策边界]

- id: Ek02
  title: 大萧条时期的财政紧缩——高失业下的平衡预算执念
  type: counter-example
  source_chapter: 第12章 12.3节
  source_quote: |
    20世纪30年代的财政政策也造成了IS曲线的紧缩性移动。当时的政治家更关注平衡预算，而不太关心用财政政策将生产和就业维持在自然水平。……虽然当时出现了历史上最高的失业，政策制定者却在寻求增加税收和减少政府支出的方法。
  summary: |
    作者点名的政策错误样本：1932年《岁入法》对中低收入者加税，民主党纲领主张"立即并大幅度减少政府支出"——在失业率冲向25%的时刻做双重紧缩，使IS曲线进一步左移、萧条加深。作者在"大萧条会重演吗"中再次断言：现在很少有经济学家在面临大规模失业时还支持严格坚持平衡预算。
    教学点：财政政策的"审慎美德"（平衡预算）在需求崩溃时变成顺周期放大器——规范性美德与周期性需求可能正面冲突。
  tags: [大萧条, 财政紧缩, 顺周期错误]

- id: Ek03
  title: 货币假说的单一渠道误判——LM冲击解释不了1929-1931
  type: counter-example
  source_chapter: 第12章 12.3节
  source_quote: |
    因为货币供给的下降伴随着价格水平更大的下降，所以1929-1931年实际货币余额还略有上升。……如果LM曲线的紧缩性移动引起了大萧条，那么，我们应该观察到了更高的利率。然而，1929-1933年的名义利率在持续下降。
  summary: |
    作者演示的归因陷阱：货币供给确实暴跌25%，但据此断言"货币紧缩通过LM渠道造成萧条"会遇到两个数据硬伤——①实际货币余额M/P在1929-1931年不降反升（价格跌得比货币快），LM并未紧缩；②LM左移应推高利率，而名义利率持续下行。货币假说须经通货紧缩的间接渠道（债务-通缩、预期通缩抬实际利率）才能解释严重性，且解释不了最初的衰退。
    教学点：相关性（货币降、收入降）不等于通过你设想的机制起作用——必须核对模型预言的"指纹"（利率方向、实际余额）。
  tags: [货币假说, 归因陷阱, 大萧条]

- id: Ek04
  title: 预期通缩的隐形紧缩——名义利率下降掩盖实际利率上升
  type: counter-example
  source_chapter: 第12章 12.3节
  source_quote: |
    当企业预期通货紧缩时，它们不愿意借款购买投资品，因为它们相信以后不得不用更值钱的美元来偿还这些贷款。……名义利率的下降小于预期的通货紧缩，因此，实际利率上升了。
  summary: |
    作者警示的观察陷阱：只盯名义利率会误判货币环境。通缩预期使事前实际利率r=i−Eπ在Eπ<0时被抬高——名义利率从6%降到3%但预期物价每年跌4%，真实借款成本反而上升，投资被抑制、IS左移。1929-1933年"利率很低"的表象之下藏着紧缩性的真实利率。
    教学点：任何借贷决策与政策评估必须用实际利率；名义利率的历史低点可能恰恰对应最紧的货币环境。
  tags: [预期通缩, 实际利率, 名义幻觉]

- id: Ek05
  title: 投机性攻击——谣言可以自我实现的固定汇率之死
  type: counter-example
  source_chapter: 第13章 13.5节
  source_quote: |
    投机性攻击——使固定汇率无法维持的投资者认知的变化——的可能性。……这一挤兑将耗尽中央银行的储备，可能迫使中央银行放弃钉住美元。在这种情况下，结果证明谣言是自我实现的。
  summary: |
    作者明确警示的固定汇率内生脆弱性：央行外汇储备有限，只要市场"认为"钉住将放弃——哪怕毫无根据——挤兑就会把储备耗光、迫使贬值，让最初的谣言变成预言。这与墨西哥案例（Ec07）中"食言引发更深信任危机"互为表里。
    教学点：固定汇率的可持续性不仅取决于基本面，还取决于市场对"捍卫意愿与能力"的信念；防御手段是把承诺做实（货币局制度、美元化），即用制度消除猜疑空间。
  tags: [投机性攻击, 固定汇率, 自我实现预言]

- id: Ek06
  title: 固定汇率下货币扩张徒劳——LM*自动弹回原位
  type: counter-example
  source_chapter: 第13章 13.3节
  source_quote: |
    设想实行固定汇率的中央银行力图增加货币供给……套利者通过向中央银行出售本币对汇率下降作出反应，导致货币供给和LM*曲线回到它们的初始位置。因此，通常实施的货币政策在固定汇率下是无效的。
  summary: |
    作者明确警告的政策幻觉：在固定汇率下试图用购买债券扩大货币供给，只会压低汇率，触发套利者按承诺价把本币卖回央行，货币供给原路收回——扩张完全无效。央行的"印钞权"在固定汇率承诺面前自动失效。
    教学点：政策工具的有效性以制度前提为条件；固定汇率国家想要货币政策自主，只有三条路——放弃钉住、限制资本流动或改变钉住水平（法定贬值）。
  tags: [固定汇率, 货币政策无效性, 蒙代尔-弗莱明]

- id: Ek07
  title: 风险贴水模型的反直觉预测不成立——"θ升收入增"在现实中落空
  type: counter-example
  source_chapter: 第13章 13.4节
  source_quote: |
    这种分析的一个惊人的一—也许是不确切的一—预测是，用θ衡量的一国风险的增加会引起该国收入的增加。……但是，在实践中，由于三个原因，这种收人增加一般不会出现。
  summary: |
    作者亲手标记的模型失效点：标准蒙代尔-弗莱明加风险贴水后，θ上升→货币贬值→净出口大增→模型预测收入反而增加。作者立即标注这个预测"也许是不确切的"，并列出三条现实渠道使收入实际下降：央行怕贬值过度而收缩货币、进口涨价推高物价、居民把货币当最安全资产增持——三者都使LM*左移。
    教学点：模型结论反直觉时，先怀疑模型的辅助假设（此处是M、P、货币需求都不变），再用现实机制修正——不要把反直觉当作深刻。
  tags: [风险贴水, 模型失效, 货币危机]

- id: Ek08
  title: 把短期权衡当长期权衡——不存在永久的通胀-失业替代
  type: counter-example
  source_chapter: 第14章 章首引文（弗里德曼）
  source_quote: |
    通货膨胀和失业之间总是存在一种暂时的取舍；不存在永久的取舍。这种暂时的取舍并不是来自通货膨胀本身，而是来自未预期到的通货膨胀，这通常意味着通货膨胀率的上升。
  summary: |
    全章反复警告的核心误区：政策制定者若把短期菲利普斯曲线当作长期菜单，持续用需求扩张"购买"低失业，预期终将追上所选通胀率，曲线整体上移，最后 unemployment 回到自然率、只剩更高的通胀（60年代末的美国即样本）。替代关系只在预期未调整的窗口内有效。
    教学点：任何"通胀换就业"的承诺都隐含了预期不调整的假设；评估时必须区分一次性水平变化与持续性政策。
  tags: [菲利普斯曲线, 短期长期混淆, 预期调整]

- id: Ek09
  title: 尼克松工资-价格控制的失败——控制物价不等于治理通胀
  type: counter-example
  source_chapter: 第14章 14.2节（案例研究）
  source_quote: |
    尼克松总统对工资和价格实行了暂时的控制；美联储通过紧缩性货币政策制造了一次衰退，但通货膨胀率仅稍稍下降。……到1972年，失业率与10年前相同，而通货膨胀率高出了大约3个百分点。
  summary: |
    作者叙述的失败组合拳：面对60年代遗留的需求拉动通胀，用行政性工资物价控制（治标，控制取消后影响随即结束）配合力度不足的货币紧缩（衰退太小，抵消不了此前繁荣的膨胀影响）——结果是四年折腾后失业率原地踏步、通胀反而高出3个百分点。
    教学点：通胀的根源在总需求与预期，行政限价只压制表象；治理力度不足+手段错配的双重错误使代价白付。
  tags: [工资价格控制, 通胀治理, 政策失败]

- id: Ek10
  title: 适应性预期外推的误判——2008-09年的通缩预言落空
  type: counter-example
  source_chapter: 第14章 14.2节（案例研究）
  source_quote: |
    由于失业率持续维持在高位，一些经济学家担心经济会经历通货紧缩（通货膨胀率为负）。但是，这种情况并没有出现。一种可能的解释是，通货膨胀预期仍然稳定在2%左右，而没有像适应性预期假设所表明的那样变动。
  summary: |
    作者指出的理论应用风险：按适应性预期的菲利普斯曲线，2009年失业率飙升本应把通胀拉入负值区间，实际却没有发生——因为美联储多年积累的可信性把预期锚定在2%附近，预期并未随失业线性滑动。用"过去的通胀预测未来的通胀"的简单外推在这种情境下失效。
    教学点：预期形成机制本身是制度的函数（央行可信性）；不同时期适用不同预期假设，模型选择错配会导致方向性预测错误。
  tags: [适应性预期, 锚定预期, 预测失效]

- id: Ek11
  title: 公告不可信则无效——反通胀承诺必须"被广泛地相信"
  type: counter-example
  source_chapter: 第14章 14.2节（萨金特引文）
  source_quote: |
    现在和未来确定赤字所使用的一贯的政府政策或战略必须断然改变，这种政策改变必须具有充分的约束力从而被广泛地相信……用放弃的产出来衡量的这种变动的成本有多大以及这种变动需要多长时间才能起作用，将部分地取决于政府承诺的坚定和可信程度。
  summary: |
    萨金特（理性预期派）点出的条件缺失陷阱：反通胀宣传本身不降低通胀——只有当政策制度"断然改变"且改变"被广泛地相信"时，预期才会下移；约束力不足的公告等于没有公告，通胀的"内在动力"照样运转，代价按牺牲率全额支付。
    教学点：无痛苦反通胀的两个条件（先于预期形成+足够可信）缺一不可；口头承诺不构成可信性，需要财政货币规则的实质配合。
  tags: [可信性, 理性预期, 反通胀]

- id: Ek12
  title: "零是利率下限"的想当然——下限略低于零
  type: counter-example
  source_chapter: 第12章 12.3节（参考资料：负利率的奇妙原因）
  source_quote: |
    如果负得太多，那么，购买安全的金库存储现金就变得有吸引力了。因此，尽管利率下限并非恰好是零，但利率不能下降到低于零很多。
  summary: |
    作者修正的常识性假设：利率下限不是精确的零——大额持有人面临储存现金的安保成本（作者举《毒枭》中现金腐烂的桥段），宁愿支付小额费用（即接受略负的利率，如2017年瑞士的-0.73%）换取银行托管。下限由"买金库存现金的成本"决定，略低于零但不会深负。
    教学点：教科书的简化边界（零下限）在现实中会被持有成本软化一点点；评估负利率政策空间时用"储存成本"而非"零"作地板。
  tags: [负利率, 零下限, 常识修正]
