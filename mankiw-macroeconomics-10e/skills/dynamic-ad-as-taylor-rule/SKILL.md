# 动态 AD-AS 与泰勒规则

> 来源：曼昆《宏观经济学（第十版）》Ch15（15.1-15.4）；组件承接 Ch14 菲利普斯曲线，规则讨论衔接 Ch16

---

## R：原理（Rationale）

曼昆第 15 章把 IS-LM、费雪方程、菲利普斯曲线与货币政策规则熔成一个跨期模型：央行不再是被动的"移动曲线者"黑箱，而是一个**可写出、可估计的反应函数**。

- **五方程总框架**：需求方程、费雪方程、菲利普斯曲线、适应性预期、货币政策规则共同决定产出、通胀、实际利率、名义利率的时间路径；上期通胀是前定变量，把时期串成动态链。
  > 原文引用：「动态总需求和总供给模型融合了五种经济关系。」（Ch15）
- **货币政策规则**：i = π + ρ + θπ(π−π*) + θY·产出缺口。θπ、θY 两个政策参数刻画央行鹰鸽程度；央行设名义利率目标，货币供给被动配合。
  > 原文引用：「一个货币政策规则，中央银行根据这一规则将名义利率设定为通货膨胀和产出的函数。」（Ch15）
- **泰勒原理（稳定性判据）**：通胀升 1 点，名义利率必须加 >1 点，实际利率才升、需求才降温；反应不足则 DAD 向上倾斜，冲击滚成通胀螺旋。
  > 原文引用：「为了稳定通货膨胀，中央银行对通货膨胀的上升作出的应对必须是将名义利率提高更多。」（Ch15）
- **波动性权衡与长期锚**：θπ、θY 决定供给冲击的代价落在通胀方差还是产出方差上——这是"稳定哪个变量"的选择，不是通胀-产出水平之间的长期取舍。
  > 原文引用：「中央银行选择货币政策参数时面临着通货膨胀可变性和产出可变性之间的权衡。」（Ch15）
  > 原文引用：「动态AD一AS模型的长期均衡是古典的。」（Ch15）

**论点关系**：静态 AD-AS / IS-LM 只能回答"当期怎么动"；动态版加入"规则→预期→下期供给"的反馈环，才能回答"系统稳不稳、路径怎么走"。图形工具是纵轴为**通胀率**（非价格水平）的 DAS（上倾，由菲利普斯曲线代入适应性预期而来）与 DAD（下倾，由需求方程+费雪方程+规则消元而来，且"相对于给定的货币政策规则"绘出）。

## I：指令（Instruction）

面对央行行为与通胀动态问题，按五步执行：

### 第一步：写出并识别央行反应函数
- 把"央行在做什么"写成方程：i = π + ρ + θπ(π−π*) + θY·(Y−Yn)；泰勒规则实例——名义联邦基金利率＝通胀＋2.0＋0.5×(通胀−2.0)＋0.5×GDP缺口
- 核对稳定判据：名义利率对通胀的**总反应**是否超过 1:1（若规则写作 i = … + φπ·π，判据是 φπ > 1；曼昆把 1 拆出单列通胀项，判据等价于 θπ > 0）
- 记住工具属性：现代央行的政策工具是名义利率目标，货币供给被动调整以实现该目标

### 第二步：用泰勒原理判断系统稳定
- 判据：通胀升 1 个百分点，名义利率必须提高超过 1 个百分点 → 实际利率上升 → 需求收缩 → 通胀回落，形成自动刹车
- 若加幅不足（θπ≤0）：DAD 向上倾斜，链条变成「通胀↑→预期通胀↑→实际利率反降→需求更旺→通胀再升」，无自动刹车
- 判断松紧永远换算实际利率（r = i − Eπ），不看名义动作

### 第三步：冲击分析——一次只动一个外生变量，追踪逐期动态
- 四个外生变量：自然产出 Yn、需求冲击 ε、供给冲击 ν、目标通胀 π*
- SOP：从长期均衡出发 → 只让一个变量变动（其余不变）→ 定即时效应（哪条曲线动、移到哪点）→ 逐期追踪（实际通胀改变预期通胀 → DAS 逐期移动 → 缓慢回归）
- 用脉冲响应思维作答：不只问"升还是降"，还问"何时到峰值、多久回归、路径形状如何"

### 第四步：通胀-产出波动权衡定位
- θπ 大（对通胀强硬）→ DAD 平坦 → 供给冲击主要伤害产出，通胀稳
- θY 相对大（对产出照顾多）→ DAD 陡峭 → 产出稳，通胀波动大
- 明确这是方差之间的权衡：没有免费的稳定，央行真正选择的是"稳定哪个变量"

### 第五步：长期均衡校验（收尾纪律）
- 无冲击且通胀稳定时：Y=Yn、r=ρ、π=π*、i=ρ+π*；目标通胀 π* 只决定通胀、预期通胀与名义利率三个名义变量
- 任何结论分两段写：短期动态（货币非中性）+ 长期古典（中性）；长期增长是 DAS 与 DAD 同步右移，增长本身不制造通胀

## A1：应用场景一 — 书中案例：大通胀的 θπ 实证

**问题**：70 年代美国通胀失控，为什么？——克拉雷达、盖里、格特勒用利率、产出、通胀数据估计货币政策规则，一个参数给出答案：
- **沃尔克之前（1960-1978）**：θπ = −0.14，违反泰勒原理。面对需求冲击（越战支出）与供给冲击（欧佩克油价），美联储确实在加息，但幅度不足——名义利率升、实际利率降——通胀螺旋上升，看不到尽头
- **沃尔克-格林斯潘时代（1979 后）**：θπ = 0.72，接近泰勒建议的 0.5，满足泰勒原理，通胀重新被稳定在低位
- **结论模板**：一段宏观灾难可以定位到反应函数的一个系数；"制度学习"本身是宏观史的一部分
- **第二案例（规则撞上硬约束）**：2008-09 大衰退中通胀与产出双低，泰勒规则建议负名义利率，但现金零回报使负利率不可行——美联储最接近规则的做法只能是把利率压到约零。规则有失效域

## A2：应用场景二 — 未来触发

### 场景一：「央行对通胀 1% 的上升只加息 0.5%，会怎样？」
1. 识别反应函数：加幅 0.5 < 1 → 违反泰勒原理（落在 θπ<0 一侧）
2. 推演：实际利率下降 → 需求更旺 → 产出超自然水平 → 通胀再升 → 预期通胀抬升 → 螺旋自我强化
3. 结论：短期看似"温和应对"，实则系统失稳；一次性需求冲击也会滚成失控通胀
4. **与 is-lm-demand-management 的区分**：IS-LM 是静态一期模型——利率由货币市场决定、没有预期通胀反馈环，它能答"这一期需求怎么动"，答不了"加幅不足会不会螺旋"；凡问"规则参数如何决定系统稳定性"，必须升级到本框架

### 场景二：「70 年代美联储一直在加息，为什么通胀越加越糟？」
1. 加息了 ≠ 收紧了：费雪方程换算——预期通胀上行比名义利率快，实际利率反而下降，等于火上浇油
2. 病根在反应函数：θπ = −0.14，规则本身错了；通胀得到治理不是靠"加得更多"，而是 1979 年沃尔克改变了规则
3. **与 policy-rules-vs-discretion 的区分**：那个 skill 论证"该不该用规则约束央行"的元问题（时滞、时间不一致、卢卡斯批判）；本框架是**给定一条具体规则**后做定量分析——θπ 失守是"按坏规则行事"的机制解剖，而"为什么要承诺规则、规则如何才可信"交给那边

### 场景三：「油价暴涨，央行该稳通胀还是稳产出？」
1. 供给冲击 ν>0：DAS 上移，通胀与产出同时恶化，央行只能选代价落在哪个方差上
2. θπ 大 → 通胀稳、产出损失大（欧洲央行风格：2008 年仅从 3% 降到 2%）；对产出权重高 → 产出稳、通胀荡（美联储双重使命：从 4.25% 砍到 0-0.25%）
3. 没有免费的稳定——权重的选择本身是使命与制度问题

## E：边界与反例（Edge Cases）

### E1：加息了不等于收紧了
- 名义利率上行 + 预期通胀上行更快 = 实际宽松（70 年代的教训：美联储加了息，实际利率却下降）
- 任何"央行出手了"的新闻，先换算实际利率、再对照泰勒原理判据；名义动作不是松紧的尺子

### E2：违反泰勒原理的螺旋
- "跟着通胀加息"仍可能不够：θπ≤0 的经济中，一次性需求冲击即触发 A→B→C→D… 的失控螺旋（图 15-13 轨迹）
  > 原文引用：「通货膨胀螺旋式上升，失去了控制。」（Ch15）
- θπ>0 是系统稳定性的硬边界，不是鹰鸽风格偏好

### E3：反通胀公告不可信则代价更高
  > 原文引用：「向更低的通货膨胀过渡的路径会包含一段产出损失（指低于自然水平）的时期。」（Ch15）
- 公众若不信降通胀公告，适应性预期下只能靠实际压低通胀逐步说服——衰退成本正是不可信的代价；可信公告则 DAS 立即下移、经济即刻到达新均衡
- 评估反通胀先评可信性，不只看目标数字（牺牲率之争与 phillips-curve-analysis 衔接）

### E4：规则的失效域——零下限
- 通胀与产出双低时泰勒规则要求负名义利率，但人们宁持零回报的通货，负利率不可行（2008-09）
- 此时"按规则加息/减息"的加法失灵；约束失效时的补偿策略与参数漂移解读（平均化 vs 自然利率下调 vs 反应太慢）超出本框架的常规分析

## B：适用边界（Boundary）

### ✅ 适用场景
- 解读央行利率决策：加息够不够力、松紧判断、鹰鸽参数定位
- 诊断通胀失控风险：检验反应函数是否满足泰勒原理
- 推演冲击（油价、需求刺激、目标通胀调整）后的逐期动态与脉冲响应路径
- 比较央行制度/使命差异（双重使命 vs 价格稳定优先）对冲击反应的含义

### ⚠️ 谨慎使用
- 利率触及零下限时规则加法失效，本框架只能指出约束存在，非常规工具需另行分析
- θπ 是计量估计值，参数有不确定性（70 年代央行为何消极，作者明言尚无定论）；模拟结论的"形状稳健、数值随参数缩放"
- 开放经济与汇率维度未包含，需叠加蒙代尔-弗莱明后再下结论

### ❌ 不适用场景
- 静态一期需求管理与乘数计算 → is-lm-demand-management
- "要不要规则约束央行"的元论证（时滞、时间不一致、政治周期、卢卡斯批判）→ policy-rules-vs-discretion
- 牺牲率与反通胀代价细算、通胀惯性三力量分解 → phillips-curve-analysis
- 通胀的长期货币根源（数量论、铸币税、恶性通胀的财政病根）→ inflation-diagnosis
- 时间范围未定的宏观问题 → 先过 macro-timeframe-selection 定位
