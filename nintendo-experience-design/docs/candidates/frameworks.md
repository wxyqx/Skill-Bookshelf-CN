    "1. 假设 自发建立"要××吗？"的假设。*但是，玩家不知道假设是否正确。
    2. 尝试 自发决定"试试××"，然后行动起来。*但是，玩家不知道尝试是否正确。

    "高兴"来自不确定感的消除，因此假设必须简单容易到"不由自主就会去试"。

  title: 疲劳厌倦诊断（直觉设计的致命弱点）
  type: framework
  source_chapter: 第2章（为什么是惊喜刺激）
  source_quote: |
    ""想玩，但很困！"玩家经常会陷入这种奇怪的状态，明明还有继续玩下去的欲望，
    但疲劳和厌倦已经在身心中累积了。"
  summary: |
    连续的直觉设计会累积疲劳和厌倦：每一步都在"不知假设对不对"的不安与"确认对了"的高兴间摇摆，
    加上相同刺激重复会使反应变弱（心理饱和/心理适应）。
    于是出现"想玩，但很困"的矛盾状态——欲望还在，疲劳已在累积；超过极限，体验就停止。
    用法：诊断任何长体验（课程、会议、产品）坚持不下去的原因，先查是否连续学习、无惊喜、无间歇。
  tags: [diagnosis, mental-model, fatigue]

  type: framework
  source_chapter: 第2章（出乎玩家意料的体验设计）
  source_quote: |

    用法：判断插入惊喜的时机——不是随机穿插，而是在用户"已经可以完全预测"的段落制造预测失败。

- id: f13
  title: 两种"坚信"（惊讶的两个杠杆）
  type: framework
  source_chapter: 第2章（契机是两种"坚信"）
  source_quote: |
    "1. 对前提的坚信→"这个游戏是××" 2. 对日常的坚信→"应该不会出现禁忌"
    有意识地背叛这两种坚信，才是设计师应采取的战略。"
  summary: |
    制造"出乎意料"只有两个杠杆，因为惊讶=坚信被打破：
    ①对前提的坚信（"这件事是××"）——打破它惊讶最强，但需要长期铺垫"说谎"，成本高；
    ②对日常的坚信（"禁忌不会出现在日常里"）——让禁忌主题登场即可，成本低、惊讶稍弱。
    用法：设计惊喜前先盘点目标对象此刻坚信什么，再选打破哪一种。
  tags: [mental-model, surprise, leverage]

- id: f14
  title: 惊喜设计三步（误解→尝试→惊讶）
  type: framework
  source_chapter: 第2章（惊喜设计的结构）
  source_quote: |
    "1. 误解 自发做出"要做××吗？"的错误假设。2. 尝试 自发尝试"试一试××……"并行动起来。
    3. 惊讶 自发发现"××是错误的"，然后大吃一惊。"
  summary: |
    惊喜的结构化编排：让用户自发做出错误假设并坚信其正确→自发尝试→自发发现"错了"而大吃一惊。
    与直觉设计同构，只是第三步的高兴换成了惊讶。
    使用对象是疲劳厌倦中的用户，目的是重激活、延长体验。
    关键区别：必须让用户先"坚信"（而不是怀疑），坚信越深崩塌越惊人，且用户不会生气反而开心。
  tags: [experience-design, structure, surprise]

- id: f15
  title: 惊喜设计实施三步（掌握时机→构建误解→暴露误解）
  type: framework
  source_chapter: 第2章（惊喜设计的结构）
  source_quote: |
    "1. 掌握玩家疲劳和厌倦的时机……2. 事先构建让玩家产生误解的游戏主题
    ……3. 设计能"暴露"误解的游戏剧情"
  summary: |
    实施惊喜设计的操作顺序：
    ①掌握用户疲劳厌倦达到顶峰的时机（如学完全部指令之后）；
    ②事先花长时间构建让用户产生误解的主题（让其坚信"这是严肃冒险"）；
    ③设计能"暴露"误解的剧情，让两种坚信同时落空。
    难点在第二步——要让对方对前提误解，就必须持续铺垫，
    所以低成本替代方案是直接打破对日常的坚信（禁忌主题）。
  tags: [process, surprise, planning]

- id: f16
  title: 禁忌主题与四问检验
  type: framework
  source_chapter: 第2章（10种禁忌主题）
  source_quote: |
    ""这个体验，描绘的是人类本能的欲望吗？"……"这个体验，有人们想要回避的东西吗？"

  summary: |
    10种禁忌主题（食/得失/认可/性4种本能＋肮脏/暴力/混乱/死亡4种回避＋侥幸偶然＋个人隐私）
    是制造惊讶的原材料库。用四个问题检验一个体验能否带来惊讶：
    描绘了人类本能的欲望吗？有人们想回避的东西吗？让用户下注祈祷吗（侥幸/概率/会心一击）？能体现个性吗（隐私暴露）？
    用法：长体验疲劳时，从这十个方向找"日常里不该出现的东西"插入。
  tags: [checklist, surprise, raw-material]

- id: f20
  title: 节奏和对比（波浪结构）
  type: framework
  source_chapter: 第3章（片段式叙述、波浪式叙述、未来式叙述）
  source_quote: |
    "每个场景包含的信息量，以及主动性/被动性，这两个要素构成了波浪。
    ……并不仅限于游戏，所有故事内容都具有同样的结构，一般被称为"节奏和对比"。"
