# 先诊断，后开方（Diagnose Before You Prescribe）

## R — 原文 (Reading)

> "下一次你还会再去找这个医生吗？我想一定不会。一个不诊断就开药方的医生怎么能信任呢？但与人沟通时，我们常常这样不问青红皂白就妄下断言。"
>
> — 史蒂芬·柯维，第八章·先诊断，后开方（fulltext.txt L5591-5593）

> "如果你要让我用一句话总结人际关系中最重要的一个原则，那就是：知彼解己。这是进行有效人际沟通的关键。"
>
> — 史蒂芬·柯维，第八章·先诊断，后开方（fulltext.txt L5613，据原书义校订）

> "正确的沟通方式也就是移情聆听，至少包括四个阶段。第一阶段是复述语句……第二阶段加入解释……第三阶段掺入个人的感觉……第四阶段是既加以解释，又带有感情，左右脑并用。"
>
> — 史蒂芬·柯维，第八章·有效的沟通（fulltext.txt L5875-5891）

> "从某种意义上说，这很矛盾，因为在影响对方之前，你必须先被影响，即真正理解对方。"
>
> — 史蒂芬·柯维，第八章·移情聆听（fulltext.txt L5720 附近）

## I — 方法论骨架 (Interpretation)

沟通有一条次序律：**理解先于建议**，就像诊断先于处方。多数沟通失败的共同结构是跳过诊断：

1. **默认反应是自传式的**——大部分人聆听不是为了理解，而是为了回应；四种自传式回应（价值判断、追根究底、好为人师、自以为是）会立刻把对方的倾诉通道关上。
2. **诊断要分级进行**——移情聆听四阶段由浅入深：先只复述语句让人专心听；再用自己的话解释（逻辑层）；再掺入对方的感觉（情感层）；最后解释与感情并用。每深入一层，对方才多吐露一层。
3. **诊断完成的标志**是对方主动说出更深层的信息，甚至反过来问"你觉得呢"——那一刻才是开方（给建议）的合法时点。
4. **移情有风险也有前提**——先被影响意味着自己会脆弱，需要安全感与内在定力；而账户透支的关系里，任何聆听技巧都会被读成操纵。

## A1 — 书中的应用 (Past Application)

### 案例 1: 芝加哥房地产谈判当场拿单
- **问题**: 一位地产商孤注一掷要拿一个项目，前一次谈判已经搞砸，次日要面对挑剔的对方老板。
- **方法论的使用**: 他在谈判开场说"请先听听看我是不是真正理解您的立场"，然后如实复述对方的处境与顾虑，直到对方认可他确实听懂了——先诊断，完全不开方。
- **结论**: 诊断本身建立了信任，让对方确信此人理解自己。
- **结果**: 谈到一半，对方起身走到电话旁给太太拨电话，捂住话筒说："这个项目是你的了。"

### 案例 2: 父子对话——从"上学真无聊"到吐露真言
- **问题**: 儿子说"上学真是无聊透了"，父亲的第一反应（价值判断+好为人师）让儿子回应"算了，多说也没什么用"。
- **方法论的使用**: 父亲改走四阶段——复述"你已受不了了，觉得上学太无聊"→解释"你不想上学了"→掺入感觉"你觉得很有挫折感"→解释+感情"你对上学有很深的挫折感"；期间儿子出现情绪性反应（嫌补习贵）时立刻退回聆听。
- **结论**: 移情不仅了解对方，更帮对方认清自己；情绪性信号出现时不给建议。
- **结果**: 儿子终于说出真话——阅读能力测验只有小学程度、他才是担心这个。柯维点评："此时才是父亲发挥影响力，提供意见的时刻。"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 朋友/家人/同事向自己倒苦水，自己忍不住想直接给建议、改简历、出主意——想确认"该不该劝、什么时候劝"。
2. 孩子说出"上学真无聊""我不想学了"之类信号，自己第一反应是讲道理，然后孩子什么都不说了。
3. 销售、咨询、面试、谈判的开场：准备了一大堆方案，被提醒"别上来就讲"，想知道具体怎么听。
4. 下属或客户求助，自己习惯性打断说"我懂我懂"，对方话越来越少。

### 语言信号 (用户的话里出现这些就应激活)

- "他跟我倒苦水，我该不该直接给建议 / 该不该劝"
- "我一开口他就烦 / 孩子现在什么都不跟我说了"
- "怎么听 / 先听后说 / 别急着给方案 / empathic listening"
- "我是不是该忍住别说'我懂'"

### 与相邻 skill 的区分

- 与 `seek-first-to-understand`（p13）的区别: p13 是"先理解再被理解"的**原则**（次序律本身，含议程设计等结构性应用）；f14 是一对一沟通的**操作规程**（四阶段+四种自传式回应禁忌）。用户问"为什么该先听"用 p13，问"具体怎么听"用 f14。
- 与 `synergy-third-alternative`（f15）的区别: f15 处理诊断完成**之后**的分歧共创；只听不清不叫 f15。典型链条：先 f14 诊断，发现分歧再 f15 共创。
- 与 `emotional-bank-account`（f08）的区别: 开口即被当成操纵（"你到底想干什么"）时，先查账户余额做存款，再回来用聆听技巧——技巧在透支状态下无效是 f08 的管辖范围。

## E — 可执行步骤 (Execution)

1. **自检并暂停自传式回应**
   - 完成标准: 说出自己正要出口的话属于哪一类（价值判断/追根究底/好为人师/自以为是），并收回。
2. **阶段一：复述语句**
   - 完成标准: 对方听到自己的话被原样复述，谈话未中断。
3. **阶段二：加入解释**
   - 完成标准: 用自己的话概括对方的意思，对方未纠正或仅轻微修正。
4. **阶段三：掺入感觉**
   - 完成标准: 说出对方情绪（"你觉得很有挫折感"），对方确认"对，就是这种感觉"。
5. **阶段四：解释+感情，等待开方信号**
   - 完成标准: 既概括处境又点出情绪，直到对方主动吐露更深层信息或问"你觉得呢"。
   - 判停条件 1: 对方出现情绪性反应（抱怨代价、赌气话）→ 退回阶段三、四继续聆听，不进行建议。
   - 判停条件 2: 对方说"你到底想干什么""跟你说也没用"→ 账户可能透支，先转入情感账户的针对性存款，硬听无用。
6. **开方**
   - 完成标准: 建议明确绑定诊断结果（"你刚才说的是 X 担心，所以建议 Y"），而非通用建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方明确只要答案的纯技术问题（怎么写公式、几点开会）——直接回答就是最好的诊断。
- 紧急安全处置（事故、伤害在发生）——先行动，后沟通。
- 用"先诊断"拖延该给的明确答复（对方要的是 yes/no 却被反问三连）——诊断是为了理解，不是话术缓冲。

### 作者在书中警告的失败模式

- **四种自传式回应毁掉亲子沟通**: 价值判断令人不能畅所欲言，追根究底令人无法开诚布公；孩子从"想谈谈心事"退到"多说也没什么用"（ce15）。
- **不诊断就开方**: 眼科医生把自己戴了十年的眼镜直接送给病人——"我戴的时候很好啊"是所有好心建议的结构性盲区（ce16）。
- **透支账户讲技巧**: 余额为零时，同一段关心会被读作控制与胁迫（ce08）。

### 作者的盲点 / 时代局限

- 书中引用的"沟通 10% 语言/30% 语调/60% 肢体"是无法溯源的梅拉宾法则讹传版本，只能作修辞不能作科学依据。
- 柯维自认移情聆听是七个习惯中最难实践的；本书是自助框架，不是心理治疗手册——对创伤性倾诉（重大丧失、虐待）应优先建议专业支持。
- 案例均为柯维顾问经历的单源叙述（房地产拿单、父子对话），无第三方可验证性；原则中心论在书内不可证伪。

### 容易混淆的邻近方法论

- 罗杰斯式积极倾听 / 教练技术（GROW、动机式访谈）——操作层面高度相似；柯维的差异点在"先被影响的风险结构"与"品德先于技巧"的前提（技巧会被识破为操纵）。
- `品德第一感情第二理性第三`（本书第八章另一框架）——管的是**表达侧**的次序（说服别人时）；f14 管的是**接收侧**的次序（理解别人时），两者互补易混。
- 非暴力沟通（观察-感受-需要-请求）——句式相似，但 NVC 无"四阶段递进诊断"与自传式回应禁忌清单。
