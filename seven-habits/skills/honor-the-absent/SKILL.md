# 维护不在场的人

## R — 原文 (Reading)

> "而体现这种品格的最好方法就是避免背后攻击他人。如果能对不在场的人保持尊重，在场的人也会尊重你。当你维护不在场的人的时候，在场的人也会对你报以信任。"
>
> — 史蒂芬·柯维，第六章（人际关系的本质）·正直诚信

> "如果你刚想批评上司，我就表示同意，同时建议我们直接去找他，一起商量怎么改善，你就会明白，如果有人在我面前批评你，我也会这样处理。"
>
> — 史蒂芬·柯维，第六章（人际关系的本质）·正直诚信

> "作为一名教师和一个父亲，我发现在征服九十九个人之前，必须先征服一个人，特别是那个最能考验你的耐心和好脾气的人。那九十九个人会通过你对待这个人的方式来设想你会如何对待他们。"
>
> — 史蒂芬·柯维，第六章（人际关系的本质）·正直诚信

---

## I — 方法论骨架 (Interpretation)

背后议论是社交中最常见的"低成本拉近"：一句"跟你说个秘密"，立刻换来同盟感。柯维指出这笔交易的真实价格——听者会当场推理："他今天对我说别人，明天就会对别人说我。"你以为买到一个朋友，实际上向在场所有人证明了自己两面三刀。

这条原则把"正直"从抽象美德落成一个可观察的行为规则：

1. **行为规则**：人前不议人非。当有人开始批评不在场者，不附和、不传话，转向"我们一起去找他当面聊"。
2. **机制**：你的处理方式会被在场者当作"将来你如何对待我"的预演。维护不在场的人，等于当众演示自己值得信任；附和攻击，等于当众演示自己不可信任。
3. **排序**：正直高于忠诚。对个人或小圈子的效忠若要求你参与背后攻击，长期看反而摧毁所有关系——"最好的办法是让别人信任你，而不是喜欢你。信任和尊重终将产生爱。"

短期代价要如实告知：在人后闲言碎语是人的通病，拒绝同流合污起初"反而显得格格不入"；柯维的回答是"路遥知马力，日久见人心"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 儿子约书亚的问题（作者亲自经历）
- **问题**: 柯维发现自己偶尔对他人反应过激、不耐烦、不客气，儿子看在眼里。
- **方法论的使用**: 幼小的约书亚会一脸无辜地看着他的眼睛问："爸爸，你爱我吗？"——孩子想知道爸爸的这种一反常态会不会也落到自己身上。柯维把这当作自我省察的镜子：对最亲近、最能考验耐心的人的方式，就是其他所有人预期的模板。
- **结论**: "在征服九十九个人之前，必须先征服一个人。"
- **结果**: 成为其家庭与教学中关于"平等对待所有人"的标志性自省案例。

### 案例 2: 批评上司情境的标准处理（L4715，柯维设计的推演场景）
- **问题**: 同事在你面前批评上司，附和可以立刻建立好感。
- **方法论的使用**: 表示理解对方感受的同时，建议"我们直接去找他，一起商量怎么改善"；对以分享他人隐私讨好你的行为，明确指出听者内心的盘算："这家伙大概也会把我说过的什么话这样告诉别人吧。"
- **结论**: 用议论不在场的人换来的信任是假信任；三个月的"金蛋"以杀死友谊的"鹅"为代价。
- **结果**: 该三段式推演（当面批评/找上司同去/分享隐私）成为第六章正直诚信一节的行为范本。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 入职/融入压力：老同事拉你一起吐槽某领导或同事，纠结附和是不是最快的合群方式。
2. 饭局与群聊：有人讲第三者的隐私或糗事活跃气氛，不接话显得扫兴，接话就是入伙。
3. 办公室政治：想通过向领导反映"某某的问题"来换取信任或自保。
4. 事后修复：自己已经背后议论过伴侣/朋友/下属，话传回去了，想挽回。
5. 带团队：发现团队人前和谐、人后互撕，想立规矩。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要跟着一起吐槽""不附和是不是不合群"
- "跟你说个秘密/别告诉别人"（gossip / behind one's back）
- "背后说人坏话""打小报告""别人跟我抱怨第三个人怎么办"
- "他不在场，怎么处理这种场合"

### 与相邻 skill 的区分

- 与 `emotional-bank-account`（f08）的区别：诚信是情感账户的基础投资，但 f08 是余额诊断工具（存款提款记账）；本 skill 是诚信的**一条具体行为规则**及其社交压力应对。关系整体变冷 → f08；具体到"背后议论"场景 → 本 skill。
- 与 `make-and-keep-promises`（p04）的区别：诚信的两条腿——守约（p04：承诺-兑现）与表里如一（本 skill：人前人后一致）。失信问题 → p04；背后话问题 → 本 skill。
- 与 `influence-circle`（f01）的区别：背后议论他人属关注圈行为（他人品格非我能控），当面沟通是影响圈动作；本 skill 给出的是把抱怨从关注圈拉回影响圈的**具体话术**，f01 给出的是整体精力框架。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **判定场景性质**
   - 完成标准：区分三种情形——(a) 情绪倾诉（背后有真实委屈）、(b) 结盟攻击（以贬低不在场者换亲近）、(c) 举报事项（涉违纪违法/伤害）。(c) 走正式渠道，本 skill 只处理 (a)(b)。
   - 判停条件：若涉及骚扰、霸凌、违法，停止社交策略讨论，直接给举报与留证建议。

2. **拆解账目给用户看**
   - 完成标准：向用户复述柯维的推理链——在场者会推定"他也会背后说我"；把"短期同盟感 vs 长期信任归零"的交换明示出来，让用户基于机制而非道德说教做决定。

3. **给出替代话术**
   - 完成标准：为当前场景产出 1-2 句不附和也不说教的回应（参照"我理解你很憋屈——要不要一起去找他当面聊聊？"），保持关系温度的同时转向当面沟通。

4. **对最亲近的人先练**
   - 完成标准：按"先征服一个人"原则，让用户选定自己最容易背后议论（或最容易对其失态）的那一个人（常是伴侣或某位同事），把当面沟通的改进先落在他身上。

5. **修复已发生的议论**
   - 完成标准：若用户已经背后议论且话已传开，产出补救动作：向被议论者当面承认并致歉（"我错了，那不是我的本意"），向听过的在场者不再重复同样内容；完成标准是行动被用户确认执行。
   - 判停条件：若用户只想让用户方"更隐蔽地议论"，如实指出这是 ce09 的加速版并停止配合。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **正当举报**：违纪、违法、伤害行为必须走正式渠道；"维护不在场的人"绝不用于掩盖问题，柯维的排序是"正直>忠诚"，正直以原则为基准而非以人情为基准。
- **公开实名批评**：会议上对事不对人的当面批评不属此列；本 skill 只规范"不在场者无法自辩"的场景。
- **受害者求助**：被伤害者向信任的人陈述遭遇是正当倾诉，不是结盟攻击；机械地让对方"去找他当面谈"可能造成二次伤害。

### 作者在书中警告的失败模式

- 背后攻击换同盟（ce09）：以他人隐私讨好你，"我想你多半会在心里盘算：这家伙大概也会把我说过的什么话这样告诉别人吧"——短期得金蛋，杀死下金蛋的鹅。
- 警示信号：对话以"跟你说个秘密"开场；团队中人前和谐、人后互撕。
- 先求忠诚后求信任："如果试图反其道而行之，想要先获得忠诚，你就会发现自己损害或放弃了正直"（L7992）。

### 作者的盲点 / 时代局限

- **原则中心论不可证伪**："维护不在场者→获得信任"被设定为原则，反例（当面直言被报复、正直者被边缘化）在书中被"长远来看"吸收，命题不可检验（BOOK_OVERVIEW 批判节）。
- **"格格不入"的真实代价**：柯维承认不同流合污起初格格不入，但对举报文化缺失、派系政治强势的组织里此举的现实风险（被孤立、被打压）没有给出应对结构。
- **组织问题个体化**：团队互撕的根源可能在激励机制与领导示范（百慕大结构），只教个人正直行为而不查体系，是 BOOK_OVERVIEW 批判的"把制度问题个人化"的又一例。

### 容易混淆的邻近方法论

- 一般职场"情商话术"（圆滑、不说坏话但也不表态）：柯维要求的是**主动维护**（建议当面谈、为不在场者辩护），不只是沉默回避；被动沉默得不到"在场者会报以信任"的机制收益。
- 非暴力沟通中的" Behind-the-back 谈话"练习（Sura Hart 等后衍工具）：结构相似但源头独立，本 skill 以柯维的信任推演机制为核心，勿混引。
