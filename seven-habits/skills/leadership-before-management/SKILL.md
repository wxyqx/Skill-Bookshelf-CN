# 领导先于管理（做正确的事 vs 正确地做事）

## R — 原文 (Reading)

> "领导与管理就好比思想与行为。管理关注基层，思考的是'怎样才能有效地把事情做好'；领导关注高层，思考的是'我想成就的是什么事业'。用彼得·德鲁克和华伦·贝尼斯的话来说就是：'管理是正确地做事，领导则是做正确的事。'管理是有效地顺着成功的梯子往上爬，领导则判断这个梯子是否搭在了正确的墙上。"
>
> — 史蒂芬·柯维，第四章（习惯二）·领导与管理：两次创造

> "如果缺乏有效的领导，即使是高效率的管理，也只不过像在'泰坦尼克号沉没之前拉开躺椅'一样徒劳无功。再成功的管理也无法弥补领导的失败。"
>
> — 同上

## I — 方法论骨架 (Interpretation)

领导与管理是两个层次的活动，不是两个职位。领导回答"要砍的是不是这块丛林、梯子是否搭对了墙"（第一次创造），管理回答"爬得快不快"（第二次创造）。

次序不可颠倒：方向错误时，一切执行优化都是在高效地抵达错误地点；忙碌与成果会给人"在正轨"的错觉，直到成功之后空虚才暴露问题。

所以当有人问"该加人、换人还是改流程"，这个问题的前面还藏着一层："要砍的是不是这块丛林？"方向没验证之前，任何执行投资都可能是在给错误加速。

这个框架同样适用于个人：自我领导（方向）先于自我管理（日程）。德鲁克名言人人会引，柯维的增量是把它绑进两次创造，并给出个人生活版与"谁该爬上最高的树"的可操作定位。

## A1 — 书中的应用 (Past Application)

### 案例 1: 石油公司总裁放掉管理、专注领导
- **问题**: 公司发展到瓶颈，总裁每天被日常运营缠住，团队被动等指令。
- **方法论的使用**: 他检讨自己的角色，发现"我根本不曾领导，而是每天都忙着管理"——于是痛下决心把管理性工作下放，自己退出来把握方向，尽管紧急事务更能给他成就感，过程很痛苦。
- **结论**: "现在我做到了，整个公司也脱胎换骨"——领导的缺口无法用更好的管理弥补。
- **结果**: 公司营业额翻番，利润增长四倍。

### 案例 2: 为人父母的管理误区
- **问题**: 家长盯着作业、日程、习惯等管理层细节，与孩子冲突不断，却收效甚微。
- **方法论的使用**: 柯维指出家庭同样需要先领导后管理——人格、方向、内动力属于领导层，靠管理手段（监督、奖惩）处理领导层问题是误诊。
- **结论**: 家长要做的是确立家庭的方向感与孩子的人格基础，管理细节退居其次。
- **结果**: 该论述成为"自我管理之前先自我领导"在家庭域的应用依据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队执行力差，用户在纠结加人、换人还是改流程。
2. 个人或组织极忙但关键成果空虚：升职之后反而失落、规模增长利润不增。
3. 家庭教育中"盯作业盯到鸡飞狗跳"，孩子的品格与方向没人管。
4. 新官上任大改流程与制度，却说不清"我们要去哪"。

### 语言信号 (用户的话里出现这些就应激活)

- "执行力不行 / execution problem"
- "是不是该换个人/换个流程"
- "这么忙为什么没成果"
- "团队没有方向感"

### 与相邻 skill 的区分

- 与 `two-creations`（f03）的区别：f03 检查"蓝图存在与否"，本 skill 检查"蓝图（领导）与施工（管理）的层级次序"；两者同源，本 skill 带更多组织与人事判断。
- 与 `fourth-gen-time-management`（f07）的区别：f07 是自我管理工具（第二次创造内部）；用 f07 前应先过本 skill 的方向检查，否则是给爬错墙的人加速。
- 与 `stewardship-delegation`（f18）的区别：授权是管理层的杠杆技巧；先确认领导层没错，再谈授权。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先答领导层问题**
   - 写下"我们要砍的是不是这块丛林"——目标是什么、为什么是它
   - 完成标准: 一句话目标+两条理由
   - 判停条件: 答不出或理由互相矛盾 → 判定为方向存疑，暂停一切执行投资，先做方向验证（找证据/小成本试错）
2. **归因分诊**
   - 方向确认后，把"执行力差"拆解为四类：人不对/流程不对/资源不够/目标传达失真，逐类取证
   - 完成标准: 每一类有支持证据或明确排除
3. **对症处理**
   - 只在第 2 步认定的类别上投入（加人/换人/改流程/重述目标）
   - 完成标准: 措施与病因一一对应，无"全都上"的撒药式方案
4. **个人版校准**
   - 用使命宣言（f11）校准本周日程，区分"自我领导时间"（方向、复盘、学习）与"自我管理时间"（执行）
   - 完成标准: 周计划中存在至少一项纯方向性活动
5. **复查**
   - 一个月后对照：是否"更忙且更近目标"；若只更忙，回第 1 步
   - 完成标准: 能指出一项因方向修正而放弃或新增的事

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 方向由外部硬约束给定（法规、甲方合同、急救流程、值班规章）——领导层问题已被锁死，直接进管理优化
- 灾难/危机救援现场："先想方向"会贻误处置
- 用户处于纯情绪倾诉状态（如刚被否定的沮丧）——先共情，不诊断

### 作者在书中警告的失败模式

- 梯子搭错墙的忙碌（反例 ce07）：极忙但说不出"做正确的事"是什么；达成目标后感到空虚；"每一次行动无疑加快了失败的步伐"
- 把"领导"做成空谈方向、不落地管理——柯维的次序是先后不是取舍；放掉管理的石油总裁经历了痛苦适应期，因为紧急事务更能给成就感

### 作者的盲点 / 时代局限

- "管理是正确地做事"转引自德鲁克/贝尼斯，名言广为流传；柯维的增量是绑定两次创造并给出个人生活版与丛林寓言的可操作定位
- 石油总裁案例为单源叙述（营业额翻番、利润增四倍无第三方验证）；作者作为培训售卖方，对"改造失败"的组织保持沉默
- 方向判据最终诉诸"正确原则"，属原则中心论体系——在书内不可证伪；"哪堵墙是对的"在价值多元场景下书内未给出裁决程序
- 与邻近方法论混淆：与战略/执行二分（战略管理教科书）形似，柯维版的判词是丛林寓言——"谁该爬上最高的树喊'不是这块丛林'"，并强调个人生活同样存在此层级
