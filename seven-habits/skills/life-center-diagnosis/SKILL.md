# 生活中心诊断（十种中心+情境测试）

## R — 原文 (Reading)

> "现在假定你已经买好票，准备晚上与配偶一起去听音乐会，对方兴奋不已，满怀期待。可是下午四点钟，老板突然来电话要你晚上加班，理由是第二天上午九点钟有一个重要会议。"
>
> — 史蒂芬·柯维，第四章（习惯二）·加班/音乐会情境测试

> "一般说来，我们的生活中心是以上某几种中心的混合体，依环境不同而有所变化。……生活中心如此摇摆不定，情绪上难免起起落落，一会儿意气风发，一会儿颓唐沮丧……缺乏固定的人生方向，没有持久的智慧，也没有稳定的力量或自我评价。"
>
> — 同上·识别自己的生活中心

---

## I — 方法论骨架 (Interpretation)

每个人都有一个无意识的"生活中心"——配偶、家庭、金钱、工作、名利、享乐、朋友、敌人、宗教、自我等。它不是兴趣爱好，而是你的四个心理支柱的供给源：安全感（价值感从哪来）、人生方向（准绳是什么）、智慧（怎么理解事物）、力量（敢不敢行动）。

中心不同，同一个两难（加班还是音乐会）会推出完全不同、且各自"理直气壮"的选择——选择本身不重要，"为什么这样选"暴露了中心。

诊断法：拿一个真实两难回放自己的第一反应，对照十种中心反推归属。

多数人的中心不是单一的，而是随环境摇摆的混合体——这正是情绪起落、自我评价不稳的根源。替代方案是以恒常原则为中心：唯一稳定、能同时校准其他中心的支点。

## A1 — 书中的应用 (Past Application)

### 案例 1: 加班/音乐会情境测试（作者构造的诊断实验）
- **问题**: 读者难以回答"什么是你的生活中心"——直接自省往往无效。
- **方法论的使用**: 作者构造"买好音乐会门票、下午四点老板来电要求加班"的两难，逐一推演以家庭/金钱/工作/名利/朋友/宗教/自我等为中心者的第一反应，展示中心如何决定动机、决策与理解。
- **结论**: 中心会直接决定动机、日常决策、行为以及对事物的理解；用它回放即可反推中心（附录二提供自测）。
- **结果**: 该情境测试成为习惯二章节的核心自测工具，衔接"以原则为中心"的替代方案。

### 案例 2: 可敬父亲的加班电话
- **问题**: 一位父亲正准备带子女出游，公司来电要求加班。
- **方法论的使用**: 他的裁决路径没有经过金钱/名利的计算——"工作还会再来，童年却只有一次"。
- **结论**: 同一刺激下，中心决定回应；不以金钱为中心的父亲在此情境中毫无纠结。
- **结果**: "这一幕深深印在子女脑海里，一生难忘"——中心的选择同时塑造了下一代的记忆。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 情绪随外界评价大起大落：老板一句表扬/批评能影响一整周的状态。
2. 两难选择（加班还是家庭、赚钱还是兴趣）反复纠结，选什么都后悔。
3. 说不清"我到底要什么"，目标总随着身边的人变（伴侣想安定就安定，朋友跳槽就心动）。
4. 某个人（上司/敌人/前任）占据了过多心理空间，行为围绕对方反应组织。

### 语言信号 (用户的话里出现这些就应激活)

- "我最近情绪特别不稳定 / mood swings"
- "一会儿觉得自己行，一会儿觉得不行"
- "到底该顾工作还是顾家"
- "我好像活在别人的期待里 / 我的生活围着他转"

### 与相邻 skill 的区分

- 与 `personal-mission-statement`（f11）的区别：本 skill 是诊断（找出摇摆的中心），f11 是处方（书面宪法固定为原则中心）；诊断出"摇摆混合体"后转 f11。
- 与 `maturity-continuum`（f09）的区别：f09 定成长阶段（依赖/独立/互赖），本 skill 定价值供给源；情感依赖期的人常伴"以他人认可为中心"，两者可连用。
- 与 `funeral-exercise`（p06）的区别：p06 是终点视角的价值观探测（输入工序），本 skill 是对现有中心的诊断（现状工序）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **两难回放**
   - 选一个最近的真实两难，写下当时的选项、第一反应、情绪强度与事后评价
   - 完成标准: 还原出"当时哪个因素压倒了其他因素"
2. **中心归因**
   - 对照十种中心（配偶/家庭/金钱/工作/名利/享乐/朋友/敌人/宗教/自我）指出最像的 1-2 个
   - 完成标准: 能指着第一反应说出"这暴露了我在用 X 定价值"
3. **四要素审计**
   - 安全感/人生方向/智慧/力量——各自的现实供给源是谁、稳定度如何
   - 完成标准: 四要素各有一行"来源+稳定度"
   - 判停条件: 若情绪波动伴随持续两周以上的睡眠/食欲改变或快感缺失 → 建议专业评估，本 skill 不替代心理咨询
4. **替换实验**
   - 写出"如果以原则（诚信/贡献/成长）为中心，我会怎么选"，与原反应对比
   - 完成标准: 至少一条与原反应不同的选择及其理由
5. **复测**
   - 用第二个两难重复第 1-2 步，检验归因是否一致
   - 完成标准: 两次归因一致 → 中心确认；不一致 → 印证"摇摆混合体"，转 personal-mission-statement（f11）起草使命宣言

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 临床抑郁/焦虑、双相情绪障碍：情绪波动不是"中心"问题，诊断框架会让当事人错误自责；先医学评估
- 用作给他人贴标签（"他就是以敌人为中心"）——本 skill 只用于自测
- 用户已有明确使命宣言并稳定使用——直接用 f11 裁决，无需回炉诊断

### 作者在书中警告的失败模式

- "伪面具"（反例 ce23）：有自制力却无使命的人——不检验生活中心，只修自律与工具，"外在表现的也许内心并不认同"，终被诱惑拖回原中心
- 中心摇摆的代价（L3180）：情绪起落、方向不定、智慧受限、力量不稳——把摇摆当"性格敏感"会错过真正的干预层

### 作者的盲点 / 时代局限

- "以原则为中心"被断言为唯一稳定解，但原则清单是柯维的归纳，该论断在书内不可证伪（凡持久的都被算作原则，凡失败的都因违背原则）——使用时应作为"柯维的假设"呈现，而非已证事实
- 十种中心的清单带 80 年代美国中产文化印记（宗教中心的讨论方式、"以敌人为中心"的心理化命名）；当代新增的中心（粉丝社群、流量、算法）书内未覆盖，需类比迁移
- 情境测试为自评，存在自利偏差与事后归因；与价值观排序练习（card sort 等）的区别——柯维问的不是"什么重要"，而是"什么在供给你的安全感与力量"
