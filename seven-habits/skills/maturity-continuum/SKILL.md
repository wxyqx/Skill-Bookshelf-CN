# 成熟模式图（依赖→独立→互赖）

## R — 原文 (Reading)

> "依赖期的人靠别人来实现愿望；独立期的人单枪匹马打天下；互赖期的人，群策群力实现最高成就。"
>
> — 史蒂芬·柯维，第二章（概论）·成熟模式图

> "独立远比依赖要成熟，可谓人生的重大成就，但却不是最高成就。不过当前社会总是大力推崇人的独立性，许多个人和组织也堂而皇之地以此为目标。"
>
> — 同上

> "独立是互赖的基础。缺乏独立人格，却一味玩弄人际关系的技巧，纵使得逞于一时，也不过是运气罢了。"
>
> — 史蒂芬·柯维，第六章（人际关系的本质）

---

## I — 方法论骨架 (Interpretation)

人的成长有三个阶段，且要分维度计量：生理、智力、情感可以各自处于不同位置——事业上的强者，情感上可能仍靠他人评价供血。依赖期以"你"为核心（你照顾我），独立期以"我"为核心（我可以做到），互赖期以"我们"为核心（我们可以共创）。

两个反直觉点：第一，独立不是终点，社会对独立的推崇过头了，许多励志书把"不靠任何人"当最高成就，其实是把依赖矫枉过正；第二，互赖与依赖长得像但本质相反——只有独立的人才有资格"选择"互赖，未独立者的"合作"只是依赖的变体（借团队之名推责、索取或利用）。

七个习惯的次序就是沿这张图排的：习惯一至三立己（依赖到独立），习惯四至六成众（独立到互赖），习惯七更新全程。

## A1 — 书中的应用 (Past Application)

### 案例 1: 用阶段图裁决"先修关系还是先修自己"
- **问题**: 后记答读者问中，读者面临的困境是：人际关系挑战（沟通困难、丧失信任）明明发生在"关系"里，为什么柯维要人先回去修个人领域的成功？
- **方法论的使用**: 柯维用成熟模式图定干预次序——"只有先把外界挑战作为开端，然后再采取自内而外的方法，这种手段才最为奏效"，即先实现个人领域的成功（独立），再实现公众领域的成功（互赖）。
- **结论**: 关系技巧解决不了阶段错位；先立己，技巧才有承载者。
- **结果**: 该裁决构成全书"习惯一至三在前、四至六在后"的次序依据。

### 案例 2: "玩弄技巧"者的诊断
- **问题**: 许多人上沟通课、学关系技巧，想直接跳到互赖期的成果。
- **方法论的使用**: 柯维按阶段图检查其独立性——"缺乏独立人格，却一味玩弄人际关系的技巧，纵使得逞于一时，也不过是运气罢了"，逆境一到技巧即失效。
- **结论**: 互赖是独立者的选择，不是依赖者的捷径。
- **结果**: "相互依赖比独立还要难上 10 倍"——要先有极强的独立性与内在安全感，才谈得上真正的合作（后记第 6 条）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队里有人能力极强但总搞不好协作，用户在纠结该不该换人。
2. 用户以"我靠自己习惯了/我不想麻烦别人"为由拒绝协作，或反被团队孤立。
3. 伴侣/成年子女事事征求意见、无法自主决定，用户不确定这是亲密还是依赖。
4. 团队上了协作工具、搞了团建和培训，协作依旧互相拖累。

### 语言信号 (用户的话里出现这些就应激活)

- "他能力很强就是没法合作 / can't collaborate"
- "我一个人干更快 / 我靠我自己"
- "这么大人了还什么都要问别人"
- "为什么上了协作工具还是一盘散沙"

### 与相邻 skill 的区分

- 与 `emotional-bank-account`（f08）的区别：f08 诊断互赖关系的介质（账户余额），本 skill 诊断人处于哪个成长阶段；连"是否有资格谈互赖"都未确认时先用本 skill。
- 与 `synergy-third-alternative`（f15）的区别：统合综效是互赖期的产出能力；团队未到互赖期时先补阶段与账户，不硬上共创流程。
- 与 `habit-knowledge-skill-desire`（f21）的区别：f21 诊断单个习惯的三要素缺口；本 skill 诊断成长阶段与干预次序，两者可连用（先定阶段，再定要素）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **三维度定位**
   - 对当事人（或自己）分生理/智力/情感三个维度，各自判断处于依赖/独立/互赖
   - 完成标准: 三个维度各有定位与证据；情感维度的关键证据是"自我价值是否依赖他人评价"（L1905）
2. **识别假互赖**
   - 检查"合作失败"属于哪类：依赖变体（推责、索取、借团队掩护不独立）还是真互赖受阻（信任、机制问题）
   - 完成标准: 给出二选一判断
   - 判停条件: 若为依赖变体 → 禁止上协作技巧或团队重组（预测直接训诫协作会加深依赖），先做第 3 步
3. **先立己处方**
   - 给情感未独立者建自我价值支点：影响圈内的小事（f01）、承诺兑现循环（p04）、独立完成一个完整的任务周期
   - 完成标准: 当事人完成一件"自己负责到底"的事并获得客观反馈
4. **再选互赖**
   - 独立达标后重新引入协作，并配情感账户（f08）经营与明确的协作期望（p16）
   - 完成标准: 下一次协作冲突中，当事人能表达不同意见而不崩

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把互赖当集体主义/道德工具："为了团队你必须服从"可能是赢/输模式的变体，不是成熟
- 给他人贴阶段标签（"你就是依赖型人格"）——本 skill 用于定位干预次序，不是人格判决
- 用户要的是具体协作机制或工具选型——先完成阶段定位，再进入机制设计

### 作者在书中警告的失败模式

- 有条件的爱加深依赖（反例 ce10）：把爱与表现挂钩，孩子以"为反对而反对"维护自主权；对依赖期者施压"要合作"只会加深依赖
- 假借独立之名的逃避："那些宣称要'摆脱桎梏''我行我素'的人反而因此暴露了依赖心理"——任由他人伤害自己的情感，或把失控归罪于外

### 作者的盲点 / 时代局限

- 后记第 5 条作者自我松动："只有先把外界挑战作为开端……这就是我常常先讲习惯四、五、六的原因"——教学次序并非实践次序，"独立先于互赖"的严格次序书中未系统论证
- 全书案例中女性多以家庭角色出场；"个人领域成功先于公众领域成功"的断言依赖品德成功论前提，该前提（原则中心论）在书内不可证伪
- 与邻近方法论混淆：与发展心理学的依恋/社会化阶段论不同——成熟模式图是效能模型而非病理模型，且明确反对把独立当最高成就
