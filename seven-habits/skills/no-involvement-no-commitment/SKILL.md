# 唯有参与，才有认同

## R — 原文 (Reading)

> "所以在审视企业的使命宣言时，我一定会问员工：'这儿有多少人知道你们有使命宣言？有多少人知道其中的内容？有多少人参与了使命宣言的拟定？又有多少人真正认同并在决策中贯彻执行？'……唯有参与，才有认同，这个原则值得强调再强调。"
>
> — 史蒂芬·柯维，第四章（习惯二）·唯有参与 才有认同

> "很多公司都订有崇高的目标，却不见得能够实践。……同样是使命宣言，由所有成员共同拟定的和由少数高层决策者包办的真是有天壤之别。"
>
> — 史蒂芬·柯维，第四章（习惯二）·组织的使命宣言

> "一个真正反映每个成员的共同愿景和价值观的使命宣言，能调动他们的创造力和奉献精神，使他们不再需要旁人的指挥、监督和批评。"
>
> — 史蒂芬·柯维，第四章（习惯二）·唯有参与 才有认同

---

## I — 方法论骨架 (Interpretation)

被要求执行的目标，永远换不来被认同的目标。柯维观察到一个普遍断裂：组织（和家庭）的最根本问题不是没有目标，而是成员并不认同集体目标——墙上贴着崇高宣言，员工各走各路。

这条原则的操作结构是：

1. **认同不能灌输，只能生成**。孩子和新人可以暂时接受外加的观念，但一旦有了独立意志，就要求参与。没有参与过程，规则只是领导（或家长）的意志，执行靠监督，监督一停就松。
2. **参与有深浅四档**，用四个问题逐级检验：多少人**知道**它？多少人知道**内容**？多少人**参与拟定**？多少人**认同并在决策中贯彻**？真正的分界线在第三档——前三档都可以靠宣传完成，第四档只能靠参与完成。
3. **参与的回报是免除监督**：当成员"接受了不变的核心原则"，创造力和奉献精神被调动起来，不再需要旁人的指挥、监督和批评。

代价也要如实告知：让所有人参与拟定，比领导直接宣布慢得多、烦得多——柯维的原话是"不厌其烦地广泛征求意见"。这笔前期投入买的是后期免于推动。

## A1 — 书中的应用 (Past Application)

### 案例 1: 旅馆连锁的员工参与式使命宣言（cases.md c18，bound to p08/f11）
- **问题**: 柯维住进一家服务远超同行的旅馆：前台主动加餐、服务员一口揽下记号笔难题、无主管监督仍自动自发。为什么这家机构能彻底奉行顾客至上？
- **方法论的使用**: 柯维访问各阶层员工后追问经理"宣言是谁拟定的"，得到答案：全体员工——清洁工、女服务员、文员都包括在内，且每家分店再按自身需要拟定自己的版本。
- **结论**: "由所有成员共同拟定的和由少数高层决策者包办的真是有天壤之别。"
- **结果**: 营运成绩斐然；另一家分店的客房部经理甚至为服务员送饮料迟到 15 分钟主动致电致歉。

### 案例 2: 保险公司企划会改造（cases.md c23，bound to f15/p08）
- **问题**: 例行企划会照稿宣读、气氛沉闷，提案没有生命力。
- **方法论的使用**: 改为不记名书面报告汇编、会前通读、会上只聆听不陈述，把拟定的过程还给全体与会者，再进入共同讨论。
- **结论**: 参与(报告即共同拟定)加上聆听，使"意见分歧被重视和升华，新的共识开始成形"。
- **结果**: "人的创造力一旦得到释放，结果真是难以置信。兴奋取代了沉闷"；柯维观察到"一旦经历过真正的统合综效，人们就会脱胎换骨"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 管理者推行价值观、OKR、协作制度，宣贯做完员工点头散会，转头一切照旧。
2. 家长定的家规贴在墙上、说破了嘴，孩子就是不执行，考虑"贴得更显眼/罚得更重"。
3. 新官上任想推出团队章程、公约或使命宣言，纠结"我先写好再征求意见，还是一起写"。
4. 社群、班级、业委会等志愿组织章程无人遵守，想判断问题出在哪一层。

### 语言信号 (用户的话里出现这些就应激活)

- "没人认同/不买账/推不动"（no buy-in）
- "贴在墙上没人看""宣贯了还是老样子"
- "怎么让员工/孩子/成员参与进来""共同制定 rules"
- "使命宣言/价值观/家规 落地不了"

### 与相邻 skill 的区分

- 与 `personal-mission-statement`（f11）的区别：f11 处理**个人**宪法的内容与写法；本原则处理**共同**目标如何获得成员认同——是家庭版/组织版使命宣言的配套拟定原则。个人方向感缺失 → f11；群体不认同 → 本 skill。
- 与 `synergy-third-alternative`（f15）的区别：统合综效是"差异双方共创出优于各自方案的第三选择"，用于具体议题的创造性解决；本原则聚焦**规则与目标层面**的认同生成，产出的是共同文件与贯彻力，不是一次性的方案。
- 与 `win-win-five-dimensions`（f12）的区别：双赢五要领诊断"双赢推行不下去卡在哪一层"（品德/关系/协议/体系/过程）；本原则是其中"过程与体系"层里最常用的第一杠杆——若卡点在奖励机制（百慕大结构），应转 f12 先改体系。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **跑四问检验**
   - 完成标准：对现状逐档统计——多少人知道目标/知道内容/参与拟定/认同并贯彻；明确卡在哪一档。若卡在前两档 → 传播问题；卡在第三档 → 走第 2 步；卡在第四档 → 走第 3 步。

2. **设计真实的参与流程**
   - 完成标准：产出一份参与方案，含：谁参加（执行者全员，含"清洁工"级的基层）、用什么形式输入（不记名书面意见/工作坊/家庭会议）、决策如何汇总、多长时间修订一次（参照柯维家每年 6 月/9 月修订家规的节奏）。红线：决策权不可先内定，否则判定为走过场。

3. **补认同贯彻机制**
   - 完成标准：约定认同怎么落到日常决策——成员有权依据共同文件质询与纠偏（如旅馆服务员自行处理客诉），而不只是喊口号。

4. **检视执行环境的相容性**
   - 完成标准：检查薪酬/奖惩/家规约束是否与共同目标相容（柯维提醒"很多企业的薪酬制度与其所标榜的理想不相契合"）；发现相悖处列出修改清单。
   - 判停条件：若用户的情境是紧急危机（如事故处置、限时截标），暂停参与流程，先由有权者决断，事后补一次参与式复盘。

5. **设修订节奏**
   - 完成标准：确定下一次共同修订的日期与触发条件，防止文件僵化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **紧急决策**：参与流程需要时间，火灾现场不开会征求意见；柯维模型的适用域是规则、目标与方向层。
- **走过场的伪参与**：决策已内定，再组织"征求意见"，参与者会识别出来并永久折价未来的参与邀请——比不参与更糟。
- **执行者缺乏基本信息的领域**：让完全外行"共创"专业细节，产出的是平庸折中；参与应聚焦目标与标准，方法交给专业判断。

### 作者在书中警告的失败模式

- 高层包办："很多公司都订有崇高的目标，却不见得能够实践"——由少数高层决策者包办的宣言没有执行力。
- 薪酬与理想相悖：制度奖励与标榜的目标背道而驰时，参与产生的认同会被体系绞杀。
- 只宣传不参与：知道≠知道内容≠参与拟定≠认同贯彻，前三档的投入换不来第四档的结果。

### 作者的盲点 / 时代局限

- **原则中心论不可证伪**："唯有参与才有认同"被表述为值得强调再强调的原则，但书中未讨论参与失败的条件（参与了仍不认同怎么办），解释体系不可检验（BOOK_OVERVIEW 批判节）。
- **顾问立场与幸存者叙述**：柯维的职业是向组织售卖培训，案例多为改造成功的旅馆与保险公司，对参与式改造失败的组织没有统计。
- **权力不对等下的参与**：当管理者与员工、家长与孩子权力悬殊时，"参与"可能被强势方框定议程；书中对这种结构性约束讨论不足。

### 容易混淆的邻近方法论

- 一般民主表决/头脑风暴：参与≠投票或发散讨论；柯维的参与服务于"共同拟定有约束力的文件"，有四问作为验收。
- `stewardship-delegation`（f18）：授权是把一项**任务**连同责任交给个人（五要素共识）；本原则是把**共同目标**的拟定权开放给全员。一对一授权场景 → f18。
- `synergy-third-alternative`（f15）：见 A2 区分。
