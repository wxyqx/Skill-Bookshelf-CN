# 双赢思维五要领（Win-Win: Five Dimensions）

## R — 原文 (Reading)

> "双赢的原则是所有人际交往的基础，包括五个独立的方面：'双赢品德'是基础，接着建立起'双赢关系'，由此衍生出'双赢协议'，需要'双赢体系'作为培育环境，通过'双赢过程'来完成，因为我们不能用赢/输或输/赢的手段达到双赢的目的。"
>
> — 史蒂芬·柯维，第七章·双赢思维的五个要领（fulltext.txt L5142）

> "没有双赢品格和双赢关系作为后盾，书面协议就形同虚设。只有真诚的感情投资，才能有助于实现双赢。"
>
> — 史蒂芬·柯维，第七章·双赢关系（fulltext.txt L5232）

> "双赢只能存在于体系健全的组织机构中。如果提倡双赢，却奖励赢/输模式，结果注定失败。"
>
> — 史蒂芬·柯维，第七章·双赢体系（fulltext.txt L5332）

---

## I — 方法论骨架 (Interpretation)

双赢不是一句谈判口号，而是一个五层叠起来的结构，缺任何一层都会塌：

1. **品德层**：诚信（有一贯价值观）、成熟（在"敢作敢为"与"善解人意"之间取得平衡）、知足（富足心态，相信资源充足）。品德不够的人用双赢话术，会被识破为操纵。
2. **关系层**：双赢的载体是情感账户里的信用。余额不足时，连"协议"都会被读成陷阱。
3. **协议层**：用五要素把期望说清（预期结果/指导方针/可用资源/任务考核/奖惩），把纵向的上下级变成水平的合作关系，让对方自我评估、自我监督。
4. **体系层**：奖励机制必须奖励合作本身。制度只奖"唯一赢家"时，个人的双赢努力会被组织绞杀。
5. **过程层**：达成双赢的路径只能靠先理解对方、寻找第三选择——不可能用赢/输的手段抵达双赢。

核心推断是"跳层失败链"：没有品德与账户，书面协议形同虚设；没有体系支撑，个人的双赢姿态救不了系统。

## A1 — 书中的应用 (Past Application)

### 案例 1: 大型金融机构的管理培训（六个月压到五周）
- **问题**: 年预算 75 万美元的培训计划让毕业生在 12 个部门各实习两周，共六个月，注重方法而非结果，受训者被动熬资历。
- **方法论的使用**: 柯维把它改造成一份双赢协议：与业务部门逐项追问"究竟想让他们学到什么"，提炼出 39 个培训目标与评估标准（预期结果与任务考核），向受训者讲清可用资源，明确"达标即升助理经理"（奖惩），培训进度完全由受训者自己掌握（自我监督）。
- **结论**: 盯结果、给资源、放手方法，信任会释放创造力。
- **结果**: 三周半完成首轮目标；高层再加 8 个更严苛目标后，一周半又完成——六个月的计划压缩到五个星期，且受训者素质高于以往任何一届。

### 案例 2: 16 岁女儿的双赢用车协议
- **问题**: 青春期女儿用车，父母既想给自由又担心失控，命令式管理会摧毁关系。
- **方法论的使用**: 签订书面协议——女儿须遵守交规、清洁保养汽车、自觉完成分内事；父母提供汽车、汽油和保险；每周日碰面评估，达标可用车，不达标停用。
- **结论**: 协议从一开始就明确了双方对彼此的期望，女儿的诚信加上充足的账户储蓄使她能自我管理。
- **结果**: "协议让我们三个人都得到了解放"，父母不必再时刻监督。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 公司推协作工具、OKR、价值观培训，但各部门依旧各自为政、藏技能、抢资源——要定位卡点在五层中的哪一层。
2. 领导嘴上要求"互相补位"，考核与奖金却只发给个人/部门冠军（百慕大结构），要指出机制与口号相悖。
3. 想跟孩子、配偶或下属立一个"不是我说他听"的约定：用车、零花钱、绩效目标、合伙分工。
4. 谈判或合作前想设计"对方也赢"的结构，但不确定该先改人（心态）还是先改制度（激励）。

### 语言信号 (用户的话里出现这些就应激活)

- "为什么没人真协作 / 协作文化推不下去 / collaboration 不 work"
- "我们奖励 top sales，却要求团队合作 / 激励机制和协作矛盾"
- "怎么让对方也赢 / win-win 怎么落地 / 双赢是不是太理想化"
- "想立个规矩但不想变成命令 / 签个协议 / 绩效协议怎么定"

### 与相邻 skill 的区分

- 与 `six-interaction-modes` 的区别: 六模式用来**定性**一次具体交往或一个人的默认姿态（这是赢/输还是输/赢）；五要领用来**构建/修复**长期双赢结构（卡在哪一层）。先定性，再建结构。
- 与 `stewardship-delegation` 的区别: 授权五要素只覆盖"协议层"如何操作（一次授权怎么做）；五要领管全部五层，尤其品德与体系两个授权管不到的前提。
- 与 `win-win-or-no-deal`（p19）的区别: p19 是双赢不可得时的合法出口（好聚好散/无交易条款）；五要领是出口之前的主路。

## E — 可执行步骤 (Execution)

1. **品德层检查**
   - 完成标准: 对主导者（自己/上级）给出三个特征（诚信、敢作敢为×善解人意的成熟度、富足 vs 匮乏心态）各自的证据。
   - 判停条件: 若主导者把人生当零和游戏（匮乏心态明显），先处理心态（找双赢榜样/安全感建设）或更换谈判代表，**不要先改制度**——制度改了也会被人性绞杀。
2. **关系层检查（情感账户余额）**
   - 完成标准: 列出最近对关键方的存款与提款各 2 条以上，给出余额高/低判断。透支则先按情感账户 skill 做针对性存款。
3. **协议层检查**
   - 完成标准: 五要素（预期结果/指导方针/可用资源/任务考核/奖惩）逐项写出现状；缺项即卡点。
4. **体系层检查**
   - 完成标准: 写出制度里实际被奖励的行为，与双赢目标对照。判停条件: 若奖励机制在奖励唯一赢家，**改体系优先于培训个人**（百慕大教训）。
5. **过程层推进**
   - 完成标准: 用"先理解对方→寻找第三选择"的流程推进当前具体议题，产出双方认可的下一步动作清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性零和交易（一锤子买卖、竞技比赛、拍卖）——柯维承认竞争在生活中存在，只是占比小；强推双赢是教条。
- 对方明确只要赢/输、且双方不再有后续关系——此时独善其身或好聚好散更诚实。
- 对方处于权力绝对优势且无意履约——书面协议"形同虚设"的警告同样适用于弱势方。

### 作者在书中警告的失败模式

- **嘴上双赢、机制奖励竞争（百慕大之旅）**: 总裁每周训示合作，却以百慕大之旅奖励唯一赢家，员工理性选择内斗——体系层赢/输绞杀品德层双赢（ce14）。
- **把双赢让成输/赢**: 缺乏敢作敢为、只善解人意时，"双赢"滑向一味让步，压抑的怨恨终以两败俱伤收场（ce24）。
- **透支账户讲双赢**: 账户为零时，协议与技巧都会被读作操纵与"恶意服从"（ce08）。

### 作者的盲点 / 时代局限

- "双赢"在柯维自己的商业体系里同时也是培训产品的销售话术（顾问立场、幸存者叙述），案例多为改造成功的组织。
- "双赢是所有人际交往的基础"属原则中心论断言——本书对"原则"的验证方式（设想反其道而行的后果）是循环式的，原则中心论在书内**不可证伪**；双赢的普适性是柯维的归纳而非已证自然律。
- 对权力严重不对等的关系（劣迹雇主、体制性弱势），"追求双赢"可能变成劝弱势方继续留在牌桌上的话术；书中对制度性解决着墨极少。

### 容易混淆的邻近方法论

- 谈判学的 BATNA/利益谈判（focus on interests）——只在"过程层"与"协议层"有交集，无品德-体系五层结构。
- 非暴力沟通——请求而非命令的句式相似，但不处理激励机制与组织体系层。
- 彼得·德鲁克的目标管理与 OKR——形似于协议层，但通常缺"奖惩与资源的成对共识"与账户前提。
