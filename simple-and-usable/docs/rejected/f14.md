# rejected/f14 — 问题理解三阶段（简单→复杂→优雅）

## 候选原文

- **id**: f14
- **title**: 问题理解三阶段（简单→复杂→优雅）
- **type**: mental-model
- **source_chapter**: 第2章
- **内容摘要**: 乍一看问题很简单（没理解复杂性）；搞清楚后发现真的很复杂，于是拿出复杂方案；大多数人止步于此，真正伟大的人继续向前找到关键与深层原因，拿出优雅方案（乔布斯语）。作者佐证：任何项目的前 3 个方案大约都是"对真正重要问题的描述"。

## 不独立成 skill 的原因

**V1 不通过**：

1. 全书中它只在第2章"明确认识"出现一次（乔布斯引文+作者的前 3 个方案经验），没有第二个独立语境的佐证——按验证标准应降级。
2. V2（预测力）中等：它能解释"团队在第三版方案处想拍板"的现象，但推导结论（继续坚持）接近"要耐心"的常识，独特性主要在阶段标签而非可执行程序。
3. 它的合理调用场景（设计开始前的心态准备）与 s03（简单基准描述）完全同场：写基准正是"不要匆忙着手设计"的落地动作。

## 处置

- 并入 **s03 simplicity-baseline 的 B 段（边界与失败模式）**："复杂感上升≠跑偏，多数人止步于复杂方案阶段"——作为坚持写基准、不要过早动手的警示。
- 原候选保留在 candidates/frameworks.md 中备查。
