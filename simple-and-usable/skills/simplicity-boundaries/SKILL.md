# 简单的边界

## R — 原文 (Reading)

> "简单并不意味着最少化。朴素的设计仍然具有自身的特征和个性。"（第1章）
>
> "在翻阅手册的时候，用户非常放松，能够想象度假时的美好感觉。"（第8章）
>
> — Giles Colborne，《简约至上：交互式设计四策略》第1、8章

---

## I — 方法论骨架 (Interpretation)

这是全书的两条护栏，防止"简单"被执行成风格运动或数字游戏。

**下边界：简单 ≠ 极简主义。** 夏克椅与潘顿椅都把组件减到最少，却一个耐磨、一个方便堆叠——特征源自方法、产品与用户任务，用户能识别这种差异并赋予价值（就像人们分得清 Google 和 Bing）。极简风格砍掉的是特征，不是复杂性；被砍到"性冷淡"的设计失去的正是用户识别与记忆的抓手。特征不等于复杂：潘顿椅的可堆叠不给使用者添任何认知负担。

**上边界：留白。** 人像电脑——想记的太多会忘，要做的决定太多会停滞。把界面塞满一切"可能有用"的信息，用户就没有地方安放自己的生活。简单发生在用户的头脑中：旅行社的手册让用户放松地想象度假，功能更全的网站只让人疲于筛选。留白不是浪费空间，是让用户把当前任务变成生活的一部分。

两句收尾自检把两条边界缝在一起：**复杂性真的变少了吗？特征与留白还在吗？** 前者防以"简单"为名的乱砍，后者防以"充实"为名的乱塞。

## A1 — 书中的应用 (Past Application)

### 案例 1: 夏克椅 vs 潘顿椅
- **问题**: 有人把"简单"理解成"最少化"，要求产品砍到没有个性。
- **方法论的使用**: 两把椅子都把组件减到最少、都能用当时的技术轻易制造，但一个耐磨、一个方便堆叠——解决了不同的问题，特征与用途完全不同，人们却能识别并赋予价值。
- **结论**: 简单≠最少化/极简主义；朴素的设计仍可有特征和个性，个性应源自方法、产品与用户任务。
- **结果**: 作者以此论证"抛开极简主义，也能够成就简单"。

### 案例 2: 旅行社手册 vs 网站
- **问题**: 旅行社请作者公司对比在线查线路与翻手册的体验——网站信息更全、功能更强。
- **方法论的使用**: 观察结果相反：用户在网站里"披荆斩棘"、焦急烦躁；手册只有大幅照片、热门线路标识、完整报价表，用户翻阅时放松，能想象度假的美好感觉——简单的体验为用户留出了想象空间。
- **结论**: 不要让设计干扰用户思绪；用户会用生活填充留白，创造更丰富的体验。
- **结果**: 手册在放松度与想象空间上完胜网站，成为"简单发生在用户头脑中"的终章实证。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计被砍到"性冷淡"，用户或老板说冷冰冰、没个性、认不出品牌了。
2. 改版把品牌插画、俏皮文案、标志性元素都当"冗余"删了。
3. 界面塞满一切"可能有用"的信息，用户完成任务后疲惫而非满足。
4. 争论"留白是不是浪费空间""极简是不是就是高级"。
5. 简化推进中想确认"删到哪为止"的度。

### 语言信号 (用户的话里出现这些就应激活)

- "极简主义 / 性冷淡 / 冷冰冰 / 没个性 / 认不出来了 / 砍过头了"
- "留白 / 塞太满 / 信息太密 / 用户说累 / whitespace / minimalism"
- "简化是不是有个度 / over-simplified / 特征 / 个性 / 品牌感没了"

### 与相邻 skill 的区分

- 与 `remove-strategy` / `declutter` 的区别：它们管"删什么、怎么删"的执行；本 skill 定"删到哪为止"的边界，常在简化被过度执行时作纠偏。
- 与 `four-strategies` 的区别：总纲管简化路径；本 skill 不给路径，只画双边界。
- 与 `visual-organization` 的区别：网格空白是布局引导技巧（第5章手法）；本 skill 的留白是"为用户的生活留空间"（第8章哲学）。
- 与 `details-carry-simplicity` 的区别：留白不豁免关键细节——该有的一行字不能省。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点被砍的东西**
   - 列出简化中删掉/禁用的元素，标注哪些是"复杂性"（选项、步骤、干扰），哪些是"特征"（个性、标志性、源自任务的方法）
   - 完成标准: 两类清单分开，无混装
2. **检查下边界（特征保留）**
   - 逐个问：这个特征源自方法/产品/任务吗？删掉后用户还能认出"这是你的产品"吗？它给用户添认知负担吗？
   - 完成标准: 每个被删特征有明确理由，无"只是风格统一"的模糊理由
3. **检查上边界（留白）**
   - 走查界面有没有塞满"可能有用"的信息；任务完成后用户是疲惫还是放松/期待
   - 完成标准: 关键任务界面留有视觉与认知余量；无"塞满每个像素"的区域
4. **双问收尾并判停**（判停条件：若问题其实是功能/结构复杂，转 four-strategies；若纯属审美偏好分歧，不启动简化）
   - 完成标准: 简化方案同时通过"复杂性真的变少了吗"和"特征与留白还在吗"两问

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户没有抱怨，只是设计者个人不喜欢现在的风格——审美偏好不是边界问题
- 拿"个性"当挡箭牌保留制造复杂性的元素——每个特征也要过四策略检验
- 竞品都是极简风于是跟进——跟随风格不等于服务用户的感觉

### 作者在书中警告的失败模式

- **把简单当风格运动**：砍特征砍个性，用户说"冷冰冰"——极简是审美主张，简单是用户的感觉，两者不是一回事（夏克椅与潘顿椅的对照）
- **塞满一切可能有用（旅行社网站反例）**：朝着最大化方向努力、快出麻烦时戛然而止——功能闲置，用户在"披荆斩棘"后疲惫而非期待
- **把留白做成空旷**：留白是给用户的生活留空间，不是信息越少越好——地铁应用漏掉"方向"一行字就崩塌，该有的决定性细节不能省

### 作者的盲点 / 时代局限

- "特征与个性"给了原则与案例，但缺少"如何设计特征"的操作指引；且暗黑模式时代"极简的简单"可能被滥用于让用户不知不觉放弃控制权，设计伦理边界成书时不存在
- "放松、冷冰冰"这类判断依赖自我报告，与实际行为有系统差距，需用行为数据复核

### 容易混淆的邻近方法论

- 极简主义（minimalism）：一种风格流派；本书的简单是用户的感觉，可与之兼容但不同物
- `visual-organization`：空白网格是引导注意力的手法；留白是认知空间哲学，两个层次
- 品牌设计/视觉识别：表达体系不等于复杂性，不能整体豁免也不能整体砍除
