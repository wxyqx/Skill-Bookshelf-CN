- id: f01
  title: 黄奇帆五步分析法
  type: framework
  source_chapter: 全书通用（各章论证套路）
  source_quote: |
    "我们就当前房产商面临的困难并非短期的、周期性的，而是结构性、基础性的调整"（第六章）；各章均为"现象数据→边界条件→结构机制→量化推演→对策"结构。
  summary: |
    分析一个重大经济/行业问题的固定五步：①用官方数据描绘现象与规模；②列出边界条件（哪些约束变了）；③解释结构机制（为什么会这样）；④用量化推演或国际比较检验；⑤给出分级分步对策。
    适用于行业研究、政策解读、商业尽调等"复杂系统问题"的结构化分析。
  tags: [universal, analysis, policy]

- id: f02
  title: 边界条件分析法
  type: framework
  source_chapter: 第六章
  source_quote: |
    "我们就当前房产商面临的困难并非短期的、周期性的，而是结构性、基础性的调整"——"边界条件出现了变化"。
  summary: |
    判断一个行业处于结构性拐点还是周期性波动：列出该行业的长期边际约束集合（人口、城市化率、库存、杠杆率、政策空间等），逐项检查哪些已触顶或不可逆变化。
    若多数边界条件同时触顶→结构性拐点，须转向新平衡模式；若仅个别条件波动→周期性调整，可逆。来源于工程学思维。
  tags: [industry-analysis, turning-point, real-estate]

- id: f03
  title: 兵棋推演式对抗分析
  type: framework
  source_chapter: 第十二章
  source_quote: |
    "兵棋推演；并对'十大脱钩'按发生风险高低进行了分类：'高风险'有科技、互联网和国际清结算网络三个方面……"
  summary: |
    面对对抗性情景（贸易战、竞争、谈判）的结构化推演：①把对方威胁清单化逐项拆开；②每项推演"对我冲击—对对方反冲击—双方胜算"；③以"杀敌一千自损八百/三千"类的相对代价为判据；④按"对方能力、对方代价、操作便利度"三维度做高/中/低风险分级（分的是发生可能性而非危害度）。
    适用于地缘风险、商业竞争、反垄断/监管情景评估。
  tags: [geopolitics, risk, scenario-analysis]

- id: f04
  title: 增速倍率法（对美赶超推演）
  type: framework
  source_chapter: 第一章（问答）
  source_quote: |
    中国保持美国 2 倍增速则 2035 年左右超越，降至 1.5 倍以下则拖至 2070 年；"把 2030 定为努力目标、2035 定为底线目标"。
  summary: |
    追赶型目标的敏感性测算：不问"能不能超"，而问"在什么增速倍率下多少年超"。对关键变量（增速倍率）做区间推演，把单点预测改为"努力目标+底线目标"双轨。
    适用于增长预测、竞品追赶、目标管理的敏感性分析。
  tags: [forecasting, sensitivity, gdp]

- id: f05
  title: 先立后破节奏控制
  type: framework
  source_chapter: 第三章
  source_quote: |
    "'先立后破、爬行钉住加保留安全冗余'的原则推动清洁替代"。
  summary: |
    大系统转型（能源、技术栈、组织流程）的节奏控制框架：①新系统未立稳前不拆旧系统；②"爬行钉住"——按固定小步幅推进（如按 3∶1 每隔 3 年退 1/3 火电），每步校准；③全程保留安全冗余（调峰、备胎、储备）。
    适用于技术迁移、基础设施切换、组织变革等高代价不可逆转型。
  tags: [transition, energy, risk-control]

- id: f06
  title: 产地销/销地产二分法
  type: framework
  source_chapter: 第五章、第十二章
  source_quote: |
    "'产地销'和'销地产'……'水平分工和垂直整合''代工龙头和链主企业'……"——"产地销和销地产是跨国公司全球产业链集群选址布局的基本原则"。
  summary: |
    跨国/跨区域产业布局的基本盘只有两种：产地销（在产地生产、卖全球，需五条件：配套、基础设施、劳动力、开放、公共服务）与销地产（在销售地生产，四优势：避关税、降物流、贴近需求、税利留在当地）。
    配套判断工具：搬厂需 1-2 年、搬产业链需 3-5 年——用时间常数过滤产业转移传言。
  tags: [manufacturing, fdi, supply-chain]

- id: f07
  title: 产业链管控五类型与链头"三链"
  type: framework
  source_chapter: 第五章
  source_quote: |
    "'链头'企业，既不搞零部件、中间品制造，也不搞产成品的总装，而是抓住价值链上游的品牌建设、研发设计和下游的销售结算清算、售后服[务]"。
  summary: |
    产业链权力结构分五型：集中管控型（流程工业）、龙头带动型、巨头联合型、外包代工型、链头管控型（连总装也外包，如苹果）。链头靠"三链"获利：定产业链标准、控供应链纽带、管价值链枢纽（集中结算）。
    用于分析一家公司在产业链中的真实权力位置与利润分配，以及招商/选品的生态位选择。
  tags: [supply-chain, value-chain, business-model]

- id: f08
  title: 超大规模市场三效应
  type: framework
  source_chapter: 第五章
  source_quote: |
    全门类（41 大类、207 中类、666 小类）+超大规模+单一市场；规模摊薄六项成本（研发、固定资产、采购、人力、物流、市场开拓）影响总成本 30-40%；"引力场效应"。
  summary: |
    分析"规模优势"的具体机制：①全门类×超大规模×单一市场三位一体；②六项固定成本被规模摊薄（影响总成本 30-40%）；③引力场效应（需求虹吸产能）与大海效应（抗波动）。
    适用于判断一个市场/平台的护城河来源，或企业选址（靠近大市场还是低成本地）。
  tags: [economies-of-scale, market, competitiveness]

- id: f09
  title: 数据产权四权分层
  type: framework
  source_chapter: 第四章
  source_quote: |
    数据产权分层：管辖权、交易监管权归国家；原始个人数据所有权归消费者、平台只有使用权；脱敏后数据平台可拥有所有权并出售；转让后主体仅有使用权不得再转让。
  summary: |
    数据要素确权的四层设计：国家（管辖+监管）→个人（原始数据所有权+使用知情权）→平台（脱敏后所有权+收益权）→受让方（仅使用权、不得再转让）。
    用于数据业务合规设计、数据产品定价、数据治理制度讨论。
  tags: [data-economy, governance, property-rights]

- id: f10
  title: 数字化转型四步骤
  type: framework
  source_chapter: 第四章
  source_quote: |
    "数字化（万物发声）→网络化（万物万联）→智能化（人机对话）→智慧化（智慧网联）"，前一步是后一步的基础。
  summary: |
    组织数字化成熟的四级阶梯：数字化（数据被记录）→网络化（数据互联）→智能化（机器参与决策）→智慧化（系统自主协同）。每级是下级的必要前提，跳级必失败。
    用于诊断一个企业/城市数字化所处的真实阶段与下一步投资方向。
  tags: [digitalization, maturity-model]

- id: f11
  title: 滚雪球战略
  type: framework
  source_chapter: 第九章
  source_quote: |
    "'滚雪球'战略，充分发挥超大规模市场优势，逐步扩大'朋友圈'"。
  summary: |
    以既有同盟/协定为底座（雪核），按由易到难顺序逐层吸收新伙伴（中日韩→中英→CPTPP），每一步都以存量雪球为谈判筹码。核心是"以我为主"定义雪球滚动的方向与次序。
    适用于联盟建设、生态合作、标准推广等需要逐层扩大朋友圈的策略。
  tags: [strategy, alliance, trade]

- id: f12
  title: 制度基因分析法
  type: framework
  source_chapter: 第十一章
  source_quote: |
    "香港自由港制度体系、独特的税收制度和具有国际公信的法治体系构成了香港经济制度的基因；而其血脉则来自祖国的[发展]"。
  summary: |
    解释一个城市/组织的长期竞争力：找出一组"可遗传、难复制"的制度组合（如香港=六大自由+十大税制+三大法治），再验证它在历次环境冲击中是否持续起作用（基因），同时区分外部输血（血脉）的贡献。
    用于城市竞争力、组织文化、商业模式可持续性的归因分析。
  tags: [institutions, hong-kong, competitiveness]

- id: f13
  title: "三个三"未来定位框架
  type: framework
  source_chapter: 第十一章
  source_quote: |
    三个作用（引资平台、跨国公司高地、超级联系人）+三个功能（资本市场、离岸人民币、政策协调"都江堰"）+三个使命（中美转圜地、双循环枢纽、"一带一路"加速器）。
  summary: |
    给一个枢纽型主体（城市、机构、平台）做未来定位的结构：现有作用（它现在是什么）→核心功能（靠什么功能立足）→战略使命（被需要做什么）。三层各三点，强制收敛。
    适用于区域战略、机构定位、个人职业卡位。
  tags: [positioning, strategy, hong-kong]

- id: f14
  title: 源头治理思维
  type: framework
  source_chapter: 第七章（问答）
  source_quote: |
    "凡是广泛存在的问题、长期存在的问题一定要从制度、基础土壤的角度去分析、去求解、去采取措施"。
  summary: |

- id: f15
  title: 长周期"不会变"判断法
  type: framework
  source_chapter: 第十二章（问答）
  source_quote: |
    "五个不会变"：全球化多极化、亚洲占世界经济比重上升、第四次工业革命中国参与引领、中国改革开放、中国占世界增长 30% 份额——以结构性趋势过滤短期政策波动。
  summary: |
    对抗短期噪声的判断法：先列出一组以十年计的结构性趋势（人口、技术革命、经济重心、制度方向），凡短期波动与结构性趋势方向一致则放大权重，方向矛盾则视为噪声。
    适用于长期投资、职业选择、战略定力维护。
  tags: [long-term, judgment, geopolitics]

- id: f16
  title: 技术创新三环节
  type: framework
  source_chapter: 第八章
  source_quote: |
    "'0 到 1'原始创新→'1 到 100'转化（专利产权 1/3 归发明人＋1/3 归投资人＋1/3 归转化者；技术经理人）→'100 到 100 万'产业化"。
  summary: |
    创新链条三段诊断：0→1（基础研究，看投入占比）、1→100（转化，看产权分成设计与技术经理人）、100→100万（产业化，看资本与场景配套）。找创新体系短板时逐段检查断点在哪。
    适用于科研管理、科技成果转化、创新生态评估。
  tags: [innovation, r-and-d, commercialization]

- id: f17
  title: 改革三类型分类法
  type: framework
  source_chapter: 第八章
  source_quote: |
    改革三类型：行政性改革（政府花钱）、分配调整型改革（切蛋糕）、要素市场改革（做大蛋糕产生制度红利）。
  summary: |
    给改革/变革措施分类定价：行政性改革花财政的钱、分配型改革动既得利益、要素市场化改革不花钱但释放制度红利。优先推动第三类，用第三类的增量反哺前两类的成本。
    适用于政策评估、组织变革方案排序。
  tags: [reform, institutional-economics]

- id: f18
  title: 要素市场成熟度五功能评估
  type: framework
  source_chapter: 第八章
  source_quote: |
    要素市场五种功能：维护秩序、资源优化配置、集中竞价（定价权）、资金枢纽、大数据与人才集聚；集聚区域 80%+ 交易量、集聚会员中介品牌、物流通信枢纽。
  summary: |
    评估一个市场/交易所/平台是否"真市场化"的五功能清单：秩序、配置、定价权、资金枢纽、要素集聚；配合三个集聚观察指标（交易量占比、中介品牌、物流通信枢纽地位）。
    适用于交易所选址评估、平台经济分析、区域金融中心诊断。
  tags: [market-design, evaluation]

- id: f19
  title: 城市群齿轮啮合结构
  type: framework
  source_chapter: 第一章、第六章（问答）
  source_quote: |
    城市群"齿轮啮合"：大中小城市规模失配则辐射无法承接；超大城市人口天花板 1500 万，大中小城市按 1∶3 梯次递减，连绵带城市化率 70%+。
  summary: |
    城市群健康度的结构判断：首位城市与腹地城市人口规模需呈齿轮状梯次啮合（约 1∶3），缺齿（如京津冀缺七八百万级中等城市）则辐射断档。用人口梯次结构预测楼市与产业承接力。
    适用于城市选择、楼市分析、区域投资。
  tags: [urbanization, real-estate, city-cluster]
