# 边界条件分析法

## R — 原文 (Reading)

> "从这些边界条件的拐点进行分析，我们就知道当前房产商面临的困难并非短期的、周期性的，而是结构性、基础性的调整。"
>
> — 黄奇帆，《战略与路径》第六章

---

## I — 方法论骨架 (Interpretation)

 borrow 自工程学的思路：任何行业的长期走势由一组"边界条件"（慢变量约束）框定。分析分三步：

1. **列出该行业的边界条件清单**——人口结构、渗透率/保有量、库存与产能、杠杆水平、政策空间、替代技术等，通常 8-10 项；
2. **逐项判断状态**：未触顶（还有空间）/ 渐触顶（增速放缓）/ 已触顶或不可逆变化；
3. **合成判断**：多数条件同时触顶 → 结构性拐点，旧模式不可延续，必须换模式；仅个别条件波动 → 周期性调整，可逆，扛过低谷即可。

关键纪律：先查边界条件再谈周期。人们习惯用上一轮周期的经验外推（"熬过这轮就好了"），而这恰恰是结构性拐点中最致命的错误——周期可扛，结构不可扛。

## A1 — 书中的应用 (Past Application)

### 案例 1: 房地产十大拐点（第六章）
- **问题**: 房企困难是调控所致还是趋势逆转？
- **方法论的使用**: 列出人口增长、老龄化、城市化率、人均住房、库存、年开工量、旧改、基建、杠杆率、涨价预期十个边界条件，逐项论证已触顶。
- **结论**: 结构性拐点，须"五个重组、五个转变"软着陆，而非等待周期回升。
- **结果**: 为"软着陆"政策组合提供依据。

### 案例 2: 法拍房作为先行指标（第六章问答）
- **问题**: 如何量化判断某个城市房价的下行风险？
- **方法论的使用**: 用边界条件中的"交易活跃度"细分出法拍房占比指标——超交易量 5% 影响定价，超 20-30% 必螺旋下跌。
- **结论**: 判断城市风险看法拍房多少。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断某行业是否"见顶"（地产、教培、光伏、咖啡连锁、互联网……）
2. 决策"硬扛等回暖"还是"转型换赛道"
3. 评估某类资产（城市房产、某类商品）的长期持有逻辑
4. 分析某轮下行是"周期低谷"还是"永久性变化"

### 语言信号 (用户的话里出现这些就应激活)

- "这是周期还是拐点""是不是见顶了""还有没有回升可能"
- "行业天花板""渗透率到头了吗"
- "cyclical or structural" / "turning point" / "peak"

### 与相邻 skill 的区分

- 与 `long-cycle-constants-filter` 的区别：边界条件法判断"当前所处的阶段"，长周期法判断"该信什么趋势"——前者向后看约束，后者向前看方向。
- 与 `five-step-structural-analysis` 的区别：用户只要"拐点判断"这一个结论时用本法，不必跑完五步。

## E — 可执行步骤 (Execution)

1. **建清单**：为分析对象列出 8-10 个边界条件（人口/渗透率/库存/杠杆/政策/替代品等）
   - 完成标准: 清单覆盖"需求侧慢变量+供给侧慢变量+约束变量"三类
2. **定状态**：逐项标注"未触顶/渐触顶/已触顶"，每项给出依据
   - 完成标准: 每项有一个数据点或可核查事实，不允许"感觉还行"
   - 判停条件: 关键项找不到数据时，明确标注不确定性并给出双侧情景
3. **合成判断**：统计触顶项占比
   - 完成标准: 给出"结构性拐点 / 周期调整 / 混合"三选一结论及置信度
4. **给动作**：结构性拐点→换模式清单；周期调整→等待与抄底清单
   - 完成标准: 动作与判断类型严格对应（不给"周期调整"配"转型"建议，反之亦然）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 日内/短期价格预测——边界条件是十年级慢变量
- 尚处早期、边界条件从未稳定的全新行业（此时清单无从建立）

### 作者在书中警告的失败模式

- 把结构性拐点当周期性波动硬扛（ce01）——房企用"熬过这轮"思维加杠杆续命即此错误
- 法拍占比超 5% 还在等回暖——微观先行指标已经报警时不可再用宏观均值安慰自己

### 作者的盲点 / 时代局限

- 作者 2021 年判断房地产"软着陆、房价与 GDP 同步"，其后实际调整更深——边界条件清单本身也可能遗漏新变量（如人口负增长提前、信用收缩）；输出时保留误差区间

### 容易混淆的邻近方法论

- 与波特五力：五力看竞争强度（静态），边界条件看约束触顶（动态阶段）
