# 产业链权力分析

## R — 原文 (Reading)

> "'链头'企业，既不搞零部件、中间品制造，也不搞产成品的总装，而是抓住价值链上游的品牌建设、研发设计和下游的销售结算清算、售后服务。"
>
> — 黄奇帆，《战略与路径》第五章

---

## I — 方法论骨架 (Interpretation)

产业链中的权力不是按产能或营收分布的，而是按对三样东西的控制力分布的：

**五种管控类型**（从重到轻）：
1. 集中管控型——流程工业（钢铁/化工）一体化自持；
2. 龙头带动型——龙头自己做约 50% 核心环节，其余带动配套；
3. 巨头联合型——几家巨头合资共控关键产能；
4. 外包代工型——只做总装，80% 外包，权力在品牌方；
5. 链头管控型——连总装也外包，只握标准、研发与结算（苹果型）。

**链头的"三链"判据**：是否提供产业链标准、是否控制供应链纽带（物流/通关/集采）、是否管理价值链枢纽（集中清算结算）。三链占几条，决定利润分成的上限——苹果拿走手机链约 80% 利润的根源在三链俱全，而非制造环节。

用途：给任何企业定位（它在第几型、占几条链），并设计升级路径（代工→掌握核心环节→沉淀纽带→谋标准）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 苹果链头模式（第五章）
- **问题**: 为什么苹果不生产手机却能拿走产业链 80% 利润？
- **方法论的使用**: 用三链判据拆解——品牌研发（上游）+销售清算（下游）两头全握，制造全部外包。
- **结论**: 权力在三链不在产能；制造业的出路是向"链头/隐形冠军"生态位升级。

### 案例 2: 佛山铝深加工扩链（第八章问答）
- **问题**: 资源型环节如何提升价值？
- **方法论的使用**: 沿链条扩链——从卖铝锭（每吨 1.5 万）做深加工升至每吨 3-4 万。
- **结论**: 在链条中的位置每上移一段，单位价值翻倍。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分析某家公司/供应商的真实议价权与利润分配
2. 代工厂、配件商决策战略方向（做大产能还是做深环节）
3. 投资尽调中判断"链主概念"是真链头还是普通代工
4. 地方招商评估目标企业是"链主"还是"产能"

### 语言信号 (用户的话里出现这些就应激活)

- "产业链地位""谁说了算""利润都被谁赚走了""议价权"
- "链主""隐形冠军""代工""value chain" / "bargaining power"

### 与相邻 skill 的区分

- 与 `origin-sale-vs-local-production` 的区别：本法看链条内权力，彼法看产能地理布局；分析"要不要迁厂"用彼法，"要不要升级"用本法。
- 与 `manufacturing-share-diagnosis` 的区别：微观（一家企业）用本法，宏观（一个经济体制造业占比）用彼法。

## E — 可执行步骤 (Execution)

1. **画链**：列出该行业上中下游与关键环节
   - 完成标准: 链条图含标准/核心件/总装/分销/结算五段
2. **定位型**：对照五类型判断目标企业的管控型态
   - 完成标准: 五选一并给出证据（自持比例、外包结构）
3. **数三链**：逐条检查标准、纽带、枢纽的控制权归属
   - 完成标准: 每条链有"谁控制"的明确答案
4. **算分成**：用三链占有数解释/预测利润分配
   - 完成标准: 能回答"为什么它赚/不赚这个钱"
5. **给路径**：设计升级或防御动作
   - 完成标准: 动作指向具体环节（如"争取 define 某标准"）而非"提高竞争力"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 完全竞争的同质化商品市场（无明显链条权力结构）
- 把"营收大"当"链主"——链权与规模可以完全背离，须以三链判据为准

### 作者在书中警告的失败模式

- 把链头利润全归因于"霸权"而忽视其承担的创新风险与高失败率——模仿链头模式（全外包+轻资产）而不具备三链能力者会两头落空

### 作者的盲点 / 时代局限

- 作者的链头叙事偏向"权力垄断"，对链头企业自身的创新投入与失败率着墨少；对被链头挤压的代工生态的升级可行性偏乐观

### 容易混淆的邻近方法论

- 与微笑曲线：曲线只描述价值分布，本法给出权力类型与判据，可解释"为什么有的总装厂也有话语权"
