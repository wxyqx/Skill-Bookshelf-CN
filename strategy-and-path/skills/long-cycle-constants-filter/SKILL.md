# 长周期"不会变"判断法

## R — 原文 (Reading)

> 未来"五个不会变"：全球化多极化的趋势不会变、亚洲占世界经济比重上升不会变、第四次工业革命中国参与引领不会变、中国改革开放不会变、中国占世界经济增长 30% 份额不会变——以结构性趋势过滤短期波动。
>
> — 黄奇帆，《战略与路径》第十二章问答（要点组织）

---

## I — 方法论骨架 (Interpretation)

对抗噪声的判断程序：

1. **先列清单再判事**：在评估任何短期冲击之前，先写下 5 条左右以十年计的结构性趋势（技术革命方向、人口与经济重心、制度方向、需求结构……）。清单必须显式写出，不许"心里有数"。
2. **双向过滤规则**：短期利好与趋势同向 → 是趋势的确认，可加权；短期利空与趋势同向（趋势本身在推进）→ 别误读为利空；短期波动与趋势反向 → 默认是噪声，除非出现趋势本身逆转的证据。
3. **逆转判据**：什么才算"趋势逆转"？慢变量方向的持续变化（人口、技术成本曲线、制度走向），而不是政策口风或单一事件。
4. **输出**：把当前决策对照清单重估——多数"要不要慌"的问题会变成"是否符合趋势的节奏问题"。

配套纪律：对趋势清单上的每一条，也要诚实评估自己是否在"信念化"（作者的五条也有争议项），至少一条附上"什么证据会让我放弃这条"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 脱钩恐慌中的定力（第十二章问答）
- **问题**: 中美脱钩会不会逆转全球化收益、改变长期布局？
- **方法论的使用**: 列五个不会变（多极化、亚洲占比升、技术革命、改革开放、增长份额），把脱钩冲击对照清单评估。
- **结论**: 冲击改变节奏与形态，不改变方向——"熬得过"的持久战判断。

### 案例 2: 三大台阶的时间坐标（第一章）
- **问题**: 15 年的远景目标依据什么？
- **方法论的使用**: 以人均收入、城镇化、全要素生产率等慢变量推演三大台阶。
- **结论**: 长期判断建立在慢变量而非年度波动上。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 政策整顿、行业地震后决定"要不要继续做/继续投"
2. 舆论周期中（悲观/乐观交替）校准自己的长期计划
3. 把年度规划与十年方向对齐，避免被 KPI 噪声带偏
4. 评估某条爆炸新闻是"转折点"还是"噪声"

### 语言信号 (用户的话里出现这些就应激活)

- "这次是不是不一样了""还有没有长期前景""该不该转型/离场"
- "长期怎么看""十年后""secular" / "long-term trend" / "是不是拐点"

### 与相邻 skill 的区分

- 与 `boundary-condition-analysis` 的区别：边界条件判断"当前阶段的性质"（向后看约束），本法判断"该信什么方向"（向前看趋势）；同一问题两者可先后使用。
- 与 `relative-cost-judgment` 的区别：技术替代的可持续性用相对成本法（更硬的证据），本法处理更宏观的方向感。

## E — 可执行步骤 (Execution)

1. **列趋势清单**：为决策对象写下 5 条十年级结构趋势
   - 完成标准: 每条有慢变量证据（人口/成本曲线/制度文件），不是口号
2. **加证伪条款**：每条趋势附"什么证据出现我会放弃它"
   - 完成标准: 至少一条趋势有明确的证伪条件
3. **过滤当前事件**：把要评估的事件对照清单分类（确认/噪声/逆转信号）
   - 完成标准: 事件被归入三类之一并说明理由
   - 判停条件: 事件命中任一证伪条款 → 退出本框架，改用边界条件法重估
4. **重估决策**：按过滤结果调整决策的力度与节奏
   - 完成标准: 输出"方向不变/节奏调整/方向修正"三选一结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 短线交易与应急决策——时间尺度不匹配
- 趋势清单本身已过时或从未更新——清单须至少每年复核一次

### 作者在书中警告的失败模式

- 被短期波动带偏长期布局（作者的"保持定力"）；但定力不等于死扛——命中证伪条款必须修正

### 作者的盲点 / 时代局限

- 作者的五条"不会变"带有体制内信念色彩（如"改革开放不会变"更多是规范性期许）；使用者须把规范期许与实证趋势分开，避免把愿望当趋势（ce07、ce10 的通用教训）

### 容易混淆的邻近方法论

- 与"第一性原理"：第一性原理拆解问题结构，本法过滤时间噪声；两者解决不同的认知错误
