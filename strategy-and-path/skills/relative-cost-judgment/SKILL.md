# 相对成本判断政策转向

## R — 原文 (Reading)

> 判断新能源政策转向的方法：看度电成本与火电的相对关系，而非财政动机；中国光伏度电成本已低于火电，未来可降至 2 毛。
>
> — 黄奇帆，《战略与路径》第三章问答（要点组织）

---

## I — 方法论骨架 (Interpretation)

预测一项补贴驱动的技术/模式能不能活，盯补贴文件是读反了因果：

1. **找对成本对**：识别新方案与在位方案的"对决成本"（光伏 vs 火电的度电成本、电动车 vs 油车的全生命周期成本、云 vs 自建的总拥有成本）。
2. **画交叉点**：两条成本曲线的学习率决定交叉时点——交叉前，行业靠补贴输血，政策风险是最大风险；交叉后，市场自主驱动，补贴只是锦上添花。
3. **倒读政策信号**：补贴**加码**说明未过交叉点（要警惕）；补贴**退坡而行业加速**说明交叉点已过（确认信号）；交叉点远未到而补贴骤停＝出清开始。
4. **产能纪律**：交叉点附近最易发生"一拥而上"的产能过剩（光伏风电已有两轮前科）——判断行业时区分"技术已成熟"与"产能已过剩"这两件事。

## A1 — 书中的应用 (Past Application)

### 案例 1: 光伏补贴退出的解读（第三章）
- **问题**: 取消光伏补贴是行业利空吗？
- **方法论的使用**: 查度电成本——已低于火电，退坡是技术成熟的确认。
- **结论**: 政策退出不是财政困难而是胜利宣言；用成本关系预判政策走向。

### 案例 2: 数字人民币替代 SWIFT 的节奏（第四章）
- **问题**: 数字货币何时撼动美元清算？
- **方法论的使用**: 不看政治意愿看成本与网络效应——"将是一个比较漫长的历史过程"。
- **结论**: 跨境清算的替代由相对成本+网络外部性决定节奏。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 判断新能源细分赛道（钠电、氢能、储能）补贴退坡后的生死
2. 评估依赖补贴/流量扶持的商业模式的自主性
3. 政策发布后判断"这是打压还是确认成熟"
4. 投资中区分"技术成熟"与"产能过剩"两个变量

### 语言信号 (用户的话里出现这些就应激活)

- "补贴退了怎么办""什么时候不用补贴""成本什么时候打平"
- "grid parity" / "cost crossover" / "补贴依赖"

### 与相邻 skill 的区分

- 与 `first-build-then-demolish` 的区别：相对成本法定"是否到了替代拐点"（方向），先立后破定"拐点之后怎么走"（节奏）——先方向后节奏。
- 与 `long-cycle-constants-filter` 的区别：技术替代的硬证据是成本曲线，趋势过滤处理更宏观的方向感。

## E — 可执行步骤 (Execution)

1. **定对决成本**：明确新方案与在位方案各自的总成本口径
   - 完成标准: 口径一致（同单位、同边界），无"拿度电成本比购置成本"类错配
2. **取曲线**：收集双方成本的历史序列与学习率
   - 完成标准: 至少 3-5 年序列；无法取得时明确标注为估计
3. **判位置**：标定当前处于交叉前/交叉点/交叉后
   - 完成标准: 位置判断附误差区间
4. **倒读政策**：把补贴动向按位置解读（加码=未过、退坡而扩张=已过、骤停=出清）
   - 完成标准: 给出"这轮政策变化意味着什么"的结论
   - 判停条件: 数据不足以定位交叉点 → 输出双侧情景而非单点结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无成本学习曲线的领域（纯制度性变化、时尚消费品）
- 用它否定产业政策的一切——成本法判断的是"何时能自主"，不回答"该不该培育"

### 作者在书中警告的失败模式

- 把补贴驱动的繁荣当技术成熟而一拥而上（ce05）——交叉点前的大扩产是过剩制造机
- 把"财政退出"一律解读为利空——方向可能正相反

### 作者的盲点 / 时代局限

- 成本曲线假设在位方案不反击（火电价格受管制即为对照失真）；交叉点也可能被碳价、安全溢价等制度变量左右移动

### 容易混淆的邻近方法论

- 与学习曲线理论：学习曲线是本法的底层机制，本法把它变成"读政策信号"的实用规则
