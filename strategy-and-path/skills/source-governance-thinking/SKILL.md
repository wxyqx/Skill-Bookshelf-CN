# 源头治理思维

## R — 原文 (Reading)

> "凡是广泛存在的问题、长期存在的问题一定要从制度、基础土壤的角度去分析、去求解、去采取措施。"
>
> — 黄奇帆，《战略与路径》第七章问答

---

## I — 方法论骨架 (Interpretation)

对顽固问题的诊断分流器：

1. **先做两个判定**：这个问题广泛存在吗（多数人/多数场合都有）？长期存在吗（反复出现多年）？——两问都"是"才进入本方法；偶发或局部问题直接处理，不必兴师动众。
2. **判定为制度问题的含义**：广泛+长期说明不是人的问题而是土壤问题——规则、激励、信息结构或要素配置在系统性地生产这个问题。换人、加惩罚、发文件都属于症状层修补。
3. **上溯路径**（三选一或组合）：①规则层——考核、流程、产权界定是否在激励错误行为；②要素层——要素（人/钱/数据/土地）的流动与配置是否被堵死，把行为问题逼成了制度问题；③结构层——是否把本该源头分配的事压到了末端（该一次分配解决的压给慈善、该制度保障的压给道德）。
4. **在源头改规则**：重构判据是"让正确的行为成为最省力的行为"，而不是"让错误行为代价更高"（后者仍靠监督，监督必有漏洞）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 共同富裕从分配源头求解（第七章）
- **问题**: 收入差距是道德劝喻（三次分配）能解决的吗？
- **方法论的使用**: 三大差距的主要矛盾在生产力源头——先改一次分配结构（居民收入占比、劳动者持股、农村财产性收入），二次分配是关键，捐赠只是配套。
- **结论**: 把希望主要寄托在末端再分配是"事倍功半"。

### 案例 2: 城乡差距的土地根源（第七、八章）
- **问题**: 农民收入为何难提？
- **方法论的使用**: 上溯到要素土壤——农民财产性收入仅占 3%，根源是城乡二元架构限制要素流动；解法是土地三权分离+指标交易+落户改革，而非补贴。
- **结论**: 制度松绑一年可创造约 2 万亿的城乡财富转移通道。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队/组织里反复出现同一类问题，罚过、培训过、换过人都不管用
2. 个人屡改屡犯的习惯（拖延、超支）想找结构性解法
3. 评估一个"运动式治理"方案能不能治本
4. 行业性顽疾（拖欠、造假、内卷）的机制分析

### 语言信号 (用户的话里出现这些就应激活)

- "屡禁不止""反反复复""治标不治本""根子上"
- "recurring problem" / "root cause" / "怎么才能彻底解决"

### 与相邻 skill 的区分

- 与 `five-step-structural-analysis` 的区别：五步法是全问题分析流程，本法只做"根因分流+源头重构"一件事；五步法第 3 步（机制）深化时可调用本法的上溯路径。
- 与 `boundary-condition-analysis` 的区别：彼法判行业阶段，本法判问题性质（制度 vs 偶发）。

## E — 可执行步骤 (Execution)

1. **双问分流**：广泛存在吗？长期存在吗？
   - 完成标准: 两问都有明确答案；任一为"否"→ 改用直接处理，终止本流程
2. **排除人因**：检查是否换过人/罚过款仍复发
   - 完成标准: 有"处理过仍复发"的证据，或明确说明为何跳过
3. **上溯定位**：沿"规则层→要素层→结构层"找出生产问题的土壤
   - 完成标准: 定位到一条具体规则/一项要素配置（如"提成按签约不按回款"），不说"文化问题"
4. **源头重构**：改规则使正确行为成为最省力行为
   - 完成标准: 新规则能用一句话说清，且能推演"在新规则下旧问题为何不再被激励"
5. **设观察期**：定义复发信号与复查时点
   - 完成标准: 有量化的复发指标与复查日期

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 偶发事故与明确的外部冲击——过度制度化的成本大于收益
- 把一切问题都归因制度（另一个极端）——个体责任与制度土壤要分开核算

### 作者在书中警告的失败模式

- 对广泛长期的问题在症状层持续加码（运动式治理），成本高而复发（方法存在的意义即防止此模式）
- 制度方案"理想但不可操作"（作者对数据分成举证成本的自认）——源头方案必须过"可执行"检验

### 作者的盲点 / 时代局限

- 作者的"制度土壤"多指向经济制度，对权力结构与寻租土壤着墨少（阶段 0 批判）；组织内使用时，土壤排查也应包含权力与信息不对称

### 容易混淆的邻近方法论

- 与 5-Why 根因分析：5-Why 沿因果链追问（事件级），本法先做"广泛+长期"分流再上溯到制度层（系统级）
