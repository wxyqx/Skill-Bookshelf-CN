# 兵棋推演式对抗分析

## R — 原文 (Reading)

> "对'十大脱钩'逐个进行了态势分析、兵棋推演；并对'十大脱钩'按发生风险高低进行了分类：'高风险'有科技、互联网和国际清结算网络三个方面……'低风险'有金融机构、外汇市场、国际经贸规则三个方面。"
>
> — 黄奇帆，《战略与路径》第十二章

---

## I — 方法论骨架 (Interpretation)

把模糊的"对方可能打击我们"变成可管理的分析程序：

1. **清单化**：把对方的一切威胁拆成编号清单，逐项处理，不许打包说"完了"；
2. **双向推演**：每项算三笔账——对我冲击多大、对对方反冲击多大、双方胜算几何，判据是相对代价（"杀敌一千自损八百"还是"自损三千"）；
3. **三维度分级**：按对方能力（有没有非对称优势）、对方代价（动了会不会伤己）、操作便利度（政府一纸命令还是要千万市场主体配合）评出高/中/低风险——注意分的是**发生可能性**，不是危害度；
4. **区别应对**：高可能性项靠备胎先行（CIPS、自研），中可能性项靠利益捆绑（半脱钩），低可能性高危害项靠威慑与盾牌（资本管制）；
5. **心态纪律**：战略上藐视（多数威胁不会全面发生）、战术上重视（逐项备胎），"先为不可胜而后可胜"。

## A1 — 书中的应用 (Past Application)

### 案例 1: SWIFT 脱钩推演（第十二章）
- **问题**: 美国会不会把中国踢出 SWIFT？
- **方法论的使用**: 双向算账——中国短期痛（跨境结算受阻），但美方将丢掉占其结算量约 10% 的中国市场利润且加速 CIPS 替代；且冻结中国资产形同宣战。
- **结论**: 全面脱钩属低可能性高危害，但精准打击特定企业是现实威胁 → 推广 CIPS 备胎。
- **结果**: 其后 CIPS 持续扩容、备胎逻辑被广泛采纳。

### 案例 2: 芯片断供的"自杀式制裁"判断
- **问题**: 科技脱钩谁的损失大？
- **方法论的使用**: 中国年采购芯片约 3000 亿美元（全球 5000 亿）；断供后 2-3 年该市场将被欧日韩中覆盖，IC 业年折旧 20-30% 撑不住空窗。
- **结论**: "杀敌一千、自损三千"的自杀行为 → 高风险但对方也痛，反制是加快自主而非恐慌。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司被列入制裁清单/断供威胁/平台封禁风险评估
2. 谈判前推演对方可能的施压手段与己方反制
3. 分析地缘冲突对供应链、资产的影响
4. 竞争对手扬言"价格战到你退出"之类的对抗情景

### 语言信号 (用户的话里出现这些就应激活)

- "会不会被制裁/断供/封号""对方敢不敢真动手"
- "怎么反制""备胎""风险分级"
- "sanction risk" / "wargame" / "what if they cut us off"

### 与相邻 skill 的区分

- 与 `boundary-condition-analysis` 的区别：有明确对抗方、威胁来自对方意志时用本法；无对手的行业演进用边界条件法。
- 与 `self-reliance-boundary` 的区别：本法是评估程序，自给边界法是评估后的投入分配规则——先推演哪些环节会被打、再决定哪些环节值得自主化。

## E — 可执行步骤 (Execution)

1. **清单化威胁**：把对方威胁拆成编号清单
   - 完成标准: 每项是单一可执行的动作（如"断供 X 部件"），不是笼统的"打压"
2. **双向算账**：逐项推演"对我冲击/对对方反冲击/双方胜算"
   - 完成标准: 每项有量级估算（钱、时间、替代性），标注"杀敌一千自损 N"
3. **三维度分级**：按对方能力、对方代价、操作便利度评高/中/低
   - 完成标准: 明确写出分级对象是"发生可能性"而非"危害度"，两者分列
4. **配对应对**：高概率→备胎与替代；中概率→利益捆绑与预案；低概率高危害→威慑与盾牌
   - 完成标准: 每项威胁至少对应一条已启动的应对动作，不允许"观察"作为唯一结论

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 普通商业风险（需求下滑、汇率波动）——无对抗意志，用常规风险管理
- 对方决策完全非理性化/情绪化的场景——推演以理性为前提，此时需政治安全逻辑另行加权

### 作者在书中警告的失败模式

- 用"对方不理性"排除推演，或用"对方理性"排除极端情景（ce03）——低概率项一旦发生危害最大，备胎不可省
- 把低风险当成低危害——分级维度混用会导致该备胎的不备胎

### 作者的盲点 / 时代局限

- 作者的风险分级建立在经济理性假设上，其后芯片禁令扩围、投资限令的演进快于"半脱钩"预期——安全政治逻辑可能压倒成本收益，对"低可能性"结论保留怀疑
- "企业家听市场不听政客"被友岸外包、补贴改写了部分激励，推演时要把对方政府的产业政策算进去

### 容易混淆的邻近方法论

- 与常规情景规划（scenario planning）：情景规划穷举未来状态，本法聚焦"对方动作—己方反制"的双向博弈
