# GLOSSARY —《激荡四十年》共享术语词典

> 本词典收录吴晓波《激荡四十年》中**作者特定用法与常识/字典用法存在差异**、且被多个下游 skill 共享引用的关键概念。每个词条给出三样东西：本书语境定义、与常识用法的差异（≠X / =Y）、以及为什么下游 skill 需要这个澄清。引用书中概念时请以本词典口径为准，避免把作者的实证描述误读为规范性主张（或反之）。

---

### 水大鱼大

- **本书语境定义**：经济规模急速扩容（水）与公司体量巨大成长（鱼）互为因果、互相激荡——大水寻找疆域边界，被冲击者承受衍变压力，大鱼之间形成新的竞合格局（周其仁语，作者引为 2008-2018 十年之纲）。
- **与常识用法的差异**：≠单纯"经济总量变大"的规模描述；=规模与公司体量互为因果的**动态结构关系**——水（市场/总量）喂养鱼（企业），鱼的体量又反向改变水的流向与边界。
- **下游 skill 为何需要**：分析 2008-2018 任何企业案例（平台、地产、金融）的默认框架——判断一家企业是大水托起的鱼，还是鱼在重塑水域；混淆则会把周期红利误读为企业能力，污染 rent-based-model-audit 与 delusional-expansion-detection 的归因。

### 三大资本集团

- **本书语境定义**：中国企业史的本质是国营（国有）、跨国（外资）、民营三大资本集团的博弈、妥协与交融；四十年所有产权、政策、市场冲突都在这三方力量场中展开，其中贡献最大的民营资本命运最舛。
- **与常识用法的差异**：≠所有制教科书分类（全民/集体/私营/外资）；=作者的分析框架，强调三者是**动态博弈主体**而非静态类别——同一企业在不同年代会在集团间变换身份（红帽子、合资、混改）。
- **下游 skill 为何需要**：所有政商、产权、调控类 skill 的坐标系——判断任何企业事件前先定位其在三大集团博弈中的位置；脱离此框架谈"企业兴衰"会丢失所有制变量。

### 红帽子

- **本书语境定义**：私产挂靠集体/国有以换取合法性与政治身份的制度安排。交易结构：私产无偿捐给集体 → 换取安全、政治身份（劳模、人大代表）与信贷支持 → 环境逆转后回购股权恢复私产（蒋锡培 2002 年回购时资产已超 10 亿）。"产权的正式名分可以让渡，实际控制权往往留在创始家族。"
- **与常识用法的差异**：≠企业所有制分类意义上的"集体经济"；=作者明确定性为**恐慌定价的临时产权交易**（政治避打击、经济享优惠、运营获信任三重动机），是灰区生存术而非真实产权安排。
- **下游 skill 为何需要**：red-hat-structure-decision 的核心概念——理解"名分与控制权分离"的交易设计与制度环境逆转时的可赎回性；initial-identity-pricing 与 property-rights-timing 都以"是否戴过帽"为分岔前提。

### 改革从违规开始

- **本书语境定义**："很多时候，改革是从违规开始的"——制度约束下企业家/地方政府的决策逻辑：先灰色突破、后事后追认（自下而上推动、自上而下呈现）。制度空白既是风险也是套利空间，破坏既有秩序在早期具有天然道德性，越到后期破坏成本越高。
- **与常识用法的差异**：≠鼓励违法的立场宣示；=对改革生成机制的**实证描述**——民营经济的原始积累普遍走在立法之前，是"预料中的意外"；违规在追认前随时可能被清算。
- **下游 skill 为何需要**：制度套利与政策周期类 skill 的第一公理——解释为何政策风险先于政策红利落在民企头上，并设定 dormant-clause-interpretation、marginal-zone-entry 等灰区决策 skill 的风险前提。

### 放两年再看

- **本书语境定义**：对争议性新事物不做定性、不禁止也不提倡，用时间让事实说话——"既避免决策错误又为既成事实铺路"（年广久雇工案；邓小平"看一看"方针，直到 1987 年中央 5 号文件才放开）。
- **与常识用法的差异**：≠不作为/政策缺位；=一种**主动的拖延裁决术**（摸着石头过河的核心操作）：不做政策界定，让既成事实倒逼制度让步。窗口期即"观察期"。
- **下游 skill 为何需要**：policy-signal-capture 与 dormant-clause-interpretation 的关键暗号——"放两年再看"意味着制度默许窗口开启，先做出来再等名分；判断灰区行动的合法性时机时必引此概念。

### 边区效应

- **本书语境定义**："对旧体制的最初突破，往往发生在旧体制最疏于防范的地方"（张仁寿论，作者引用）。温州十大市场坐落交通不便之地，因"左"的思潮薄弱而存活——选址逻辑是政治安全性优先于商业便利性。
- **与常识用法的差异**：≠地理边远/经济洼地的自然现象；=**观念解放度（体制束缚强度）比工业基础、区位、政策扶持更具决定性**的改革区位规律。义乌"四个允许"即人造政策凹地。
- **下游 skill 为何需要**：marginal-zone-entry 的选址框架——寻找监管洼地与政策凹地；也解释了为何工业基础好的东北、上海反难萌发民资（变量是观念而非资源）。

### 祭旗者

- **本书语境定义**："跟历次宏观调控一样，总有一些人会成为倒霉的'祭旗者'"——宏观调控"只宣布开始、不通知结束"，紧缩期经济过热的出清代价按所有制"等级"再分配，民企充当祭旗。选择机制：违法性质相似的项目中，最典型、最显眼者被选中震慑全局——"项目越成功越可能成为标本"。
- **与常识用法的差异**：≠违法必究的一般执法；=带有**所有制选择性与震慑功能**的政治化出清（1989、1998、2004 三个崩溃之年同构）。年广久、温州八大王、郑乐芬、戴国芳同列此名单。
- **下游 skill 为何需要**：policy-cycle-positioning 的核心机制——判断调控阶段、评估自身成为祭旗者的暴露度（铁本 vs 建龙的对照），是民企逆周期生存的前提。

### 公司元年（1984）

- **本书语境定义**：以美国 1886 年"伟大公司年份"类比提出的"集束式诞生"命题：万科、海尔、联想、健力宝等在 1984 年集束出现。"这些公司的共同优势不是资源，而是'自由'——因新创或濒死而游离于计划体系关注之外，成为少数能掌握自己命运的企业。"
- **与常识用法的差异**：≠"这一年政策最优惠"；=恰恰因**游离于体制关注之外**（计划外/濒死试点）而获得自由。作者以此启动"1984 派"谱系（对应 92 派、互联网派等创业族群分期）。
- **下游 skill 为何需要**：企业家谱系与创业时机分析的时间锚点——"自由优于资源"是全书解释企业起源的标志性判断，1984 代际案例引用时须用此定义而非"政策红利"解释。

### 国进民退 / 国退民进

- **本书语境定义**：三大资本集团博弈中产业资本格局的钟摆表述。1997 金融风暴后"抓大"改弦为"国退民进"：国有资本退出 164 个竞争性行业、在上游强化垄断；2009 四万亿信贷后吴敬琏指认"国进民退"，2010 固化为民企的阶层性预期。
- **与常识用法的差异**：≠单向的意识形态路线变化；=**外生冲击的应激反应**（作者设问"如果金融风暴迟两年爆发会怎样"），是钟摆而非定格。作者并提醒"四万亿 95% 给国企"等定性数据不可考。
- **下游 skill 为何需要**：政策周期与产权类 skill 的宏观坐标——判断企业所在行业处于钟摆哪一段、上游垄断/下游竞争格局如何形成；引用时须连带"应激反应"解释与数据口径警示，防止当成确定性路线结论。

### 原罪

- **本书语境定义**："既是体制的突破者又是现行制度的违规者"——民营资本的双重身份遗产。"行为被认同之前失败随时降临，故民营企业家长期游离于合法/非法灰色地带，'原罪'是制度结构而非道德问题。"
- **与常识用法的差异**：≠道德/法律意义上的企业家个人罪行；=**制度结构产物**：改革从违规开始的结构性后果。2004 河北省委"原罪豁免"文件随宏观调控风向逆转而被抛弃，恰说明其政治属性。
- **下游 skill 为何需要**：business-government-distance 与产权类 skill 的前提概念——评估民企历史包袱的政治风险时，须把它当作结构性、可被政策周期激活/豁免的变量，而非恒定法律事实。

### 价格双轨制

- **本书语境定义**：为保护国营企业原材料采购优势而生，却直接滋养"倒爷经济"、瓦解指令性计划。计划内外价差 + 贷款利差 + 汇差构成巨额制度租金（1988 年约 3500 亿、占国民收入 30%、约 70% 流入私人），有政府背景者按计划价买、按市场价卖即可无风险套利。倒爷阶层是"压垮计划经济的最后一根稻草"。
- **与常识用法的差异**：≠物价改革的一般过渡措施；=一套**可精确测算租金规模的制度套利结构**。作者核心命题：价格管制是天下最事与愿违的政策——守计划的国营企业反成最大受害者。
- **下游 skill 为何需要**：rent-based-model-audit 的历史原型（租金测算 + 准入身份套利）；"制度租金型商业模式"体检与 dormant-clause-interpretation 的合法性身份分析都以此为参照系。

### 三角债

- **本书语境定义**：企业间资金循环拖欠，1989 年 3 月末全国拖欠总额 1085 亿元，全年清欠约 700 亿后债务链仍超 1000 亿。作者定性：深层是全社会信用体系的危机——银行中介式"对等清欠"只适用于小半径债务链，半径稍大即失效，技术性清欠无效，须等经济复苏自然解套。
- **与常识用法的差异**：≠单纯的资金链/流动性问题；=**信用体系塌陷的症状**。引出结构性结论："既要找市场，又要找市长"（徐有泮）——市场失灵时政府信用是最后的流动性来源。
- **下游 skill 为何需要**：调控周期与现金流风险分析用它区分"流动性危机"与"信用危机"两种不同对策；也是理解国企对体制双重依赖的入口。

### 抓大放小

- **本书语境定义**：国企改革思路从"放权让利"转向"抓大放小"——它终结了 1978 年以来以机制改革为主题的运动，转向所有权改革：中小企业"放掉"，产权清晰化试验从暗流转明流。政策信号与套利窗口：赵新先率先嗅出商机"下山摘桃子"，三九借势并购 140 家。
- **与常识用法的差异**：≠单纯的企业规模分类管理政策；=**机制改革 → 所有权改革的战略转折点**，同时是"制度变革窗口即套利窗口"的教科书案例——政策文件发布前后的时间差是最大的并购窗口。
- **下游 skill 为何需要**：policy-signal-capture 的标准案例（信号兑现）；产权类 skill 讲"放掉的部分成为民企/经营者接盘场"时也必引此转折。

### 产权清晰化

- **本书语境定义**：四十年企业命运的第一变量。三条路径并列（1988）：王文京一步到位领个体执照；柳传志曲线救国（香港联想做"利益变压器"，借子公司引进私人合资者）；鲁冠球"花钱买不管"——净资产评估、以基数定额上缴利润置换政府干预，"外部边界清晰、内部边界模糊，不争个人股份以绕开最敏感地带"。首届 20 位全国优秀企业家无一人完成产权清晰化改造。
- **与常识用法的差异**：≠"私有化"或登记变更的单一动作；=**政商博弈的角斗场**，路径选择（灰色 MBO vs 另起炉灶）决定生死（郑俊怀 vs 牛根生标本）。在产权未清的体制内企业，企业家命运不由经营业绩决定。
- **下游 skill 为何需要**：property-rights-timing 与 half-step-rights-reform 的总纲概念——三条路径 + 时机（声誉顶峰期）+ 边界设计技巧是全书产权决策方法论的核心，所有产权案例 skill 共用此定义。

### 野蛮人（门口的野蛮人）

- **本书语境定义**：悬在企业头上的资本劫掠者/治理冲突方。用法三层：①1994 君安事件——"股东与董事会的第一次直接对抗"；②制度真空期的资本掮客——"缺乏规则时，实业家被挡在门外，娴熟的'门外的野蛮人'（张海、顾雏军式资本运作方）反而轻易进场"；③宝能举牌万科，刘士余痛斥"野蛮人""妖精"，行政干预边界问题再落地。
- **与常识用法的差异**：≠单纯恶意收购者的中性金融术语；=作者用它指认"**资本运作能力与产业责任错位**"的进场者，且强调制度真空期野蛮人与实业家的进出场由规则缺失决定。
- **下游 skill 为何需要**：产权与资本风险分析共用——识别交易对手身份可预判改制/控制权走向；宝万之争的反转是"实体经济 vs 资本力量"博弈的标志性判决案例。

### 标王

- **本书语境定义**：央视广告招标冠军。谭希松的发明本质是"拍卖稀缺注意力"——全国性媒介稀缺期"知名度可被明码竞价"，凡稀缺资源被集中定价处，必有泡沫与豪赌。秦池 6666 万加冕、3.2 亿蝉联（报价为姬长孔的手机号码）后因"川酒勾兑"报道崩塌，是媒体造神周期律的顶点标本。
- **与常识用法的差异**：≠广告投放策略概念；=**注意力经济泡沫的计量单位 + 媒体造神流水线的加冕仪式**（步鑫生 → 马胜利 → 标王的造神系列）。
- **下游 skill 为何需要**：media-deification-cycle 与 delusional-expansion-detection 引用——标王现象证明"用知名度买时间"的商业模式在媒介格局分众化后整体失效，是营销狂飙派的墓志铭。

### 92派

- **本书语境定义**：南巡后 10 万党政干部下海形成的创业者族群（陈东升、毛振华、田源、冯仑等）。画像：从体制出来的"中国现代企业制度试水者"——有政府关系 + 知识基础 + 清晰股东意识，善于用"中国""国际"字头获取局级单位的全国经营身份；方法论："创新就是率先模仿"（陈东升录香港拍卖回国研究）。
- **与常识用法的差异**：≠一般"下海经商"泛称；=**特定年份、特定出身（体制内精英）、特定方法论（找全球标杆做模板 + 体制资源个人变现）的谱系标签**，是作者五阶段谱系（农村能人 → 1984 派 → 92 派 → 中国制造/地产系 → 互联网/VC）的一环。
- **下游 skill 为何需要**：latecomer-resource-borrowing 直接继承了"创新就是率先模仿"方法论；92 派证明"读懂政策信号并第一时间行动本身就是核心能力"（南巡兑现），是 policy-signal-capture 的谱系参照点。

### 法罪错位

- **本书语境定义**："中国企业史上独特的'法罪错位'现象"——全世界都知道管金生因 327 国债事件被捕，但指控罪名则是受贿 29.4 万和挪用公款 240 万。败因是规则解释权在管理层手中，罪与罚却落在别处。
- **与常识用法的差异**：≠"违法必受相应处罚"的法治常识；=**真实诱因/事件与司法罪名系统性错位**的结构性现象：在规则未立的市场上，罪名往往无法覆盖真实冲突，企业家的真实"罪"是触碰了体制利益（对应"限定条款休眠-激活"机制）。
- **下游 skill 为何需要**：dormant-clause-interpretation 与 business-government-distance 必备澄清——分析倒下的企业家时，须把"公开罪名"与"真实诱因"分开归因，否则会误读风险的真实来源。

### 容忍非均衡（灰度治理）

- **本书语境定义**：四十年增长四动力之一（制度创新、容忍非均衡、规模效应、技术破壁）：让一部分人先富起来、沿海优先、外资超国民待遇、长期容忍环境破坏与农民工利益剥夺、容忍民企对现行法律的突破——"以不均衡换速度是打破计划体制的秘诀，也是后续矛盾的伏笔"。
- **与常识用法的差异**：≠管理学术语"灰度管理"（任正非）；=**国家层面的治理策略**：以牺牲均衡换取速度的制度安排。配套判断标尺：制度创新可逆、技术破壁不可逆。
- **下游 skill 为何需要**：全书总体解释框架的支柱——任何"为什么中国式做法能成"的分析都回到四动力框架；灰度治理解释灰区套利为何长期被默许，也预示其债务（不均衡矛盾）由谁偿还。

### 宁与外客，不与家人

- **本书语境定义**：地方政府处置体制内企业时的避嫌逻辑：为避国资流失问责之嫌，"宁可将企业卖给陌生的外来资本，也不卖给创业团队"，客观上为张海、顾雏军式资本掮客敞开大门。配套教训：企业家发动舆论战（李经纬）只能把政府逼进墙角、加速翻脸，不能换来交易。
- **与常识用法的差异**：≠"崇洋/不信任内部"的态度问题；=**官员在无法规依据时的免责理性**（避问责 > 最优配置）。与红帽子、灰色 MBO 同属产权博弈的行为逻辑链。
- **下游 skill 为何需要**：property-rights-timing 与 business-government-distance 的关键机制——解释"宁与外客"类交易的成因与可预判性（识别交易对手身份），以及企业家在政府处置中的失效动作清单。
