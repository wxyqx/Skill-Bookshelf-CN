# 泡沫识别与退出纪律（行政出清论）

## R — 原文 (Reading)

> 有意思的是，就是这样的过程中，他们清醒地看到，"海南的好景长不了"。一年后，6人就撤离海南
>
> — 吴晓波，《激荡三十年》1992 年章（万通六兄弟撤离海南）

---

## I — 方法论骨架 (Interpretation)

在泡沫中掘金是可能的，前提是把识别、入场、退出设计成一个整体纪律，而不是边涨边找理由。

识别靠两组清单：三征兆——价格与基本面脱钩、垃圾资产被神话化（垃圾公司连板成妖）、专业投资者公开宣布"向市场投降"（"无脑买入"）；庞氏清单——无从业经历的创始人+看不懂的底层标的+广告轰炸式获客+显著高息+"大而不倒"迷信。凡多数吻合，定性即为庞氏而非估值分歧，出路只有离场。

纪律的核心是时序：入场的那一刻就写死撤离触发条件——万通六兄弟在海南狂欢中就判定"好景长不了"，一年后全撤；先有退出方案再有头寸，不许用上涨收益为继续持仓辩护。

终局认知是本方法论的中国特色：吹起泡沫的是投机预期，但刺破泡沫的最终是行政权力——君子兰泡沫靠禁止公款购买终结，2015 年股灾由清理场外配资引爆。因此逃顶信号不应盯成交量与估值，而应盯行政动向：监管表态升级、公款/信贷资金渠道被掐，就是顶。对隐形杠杆结构，治理者"无数据即无治理"，收紧永远是突发的。

## A1 — 书中的应用 (Past Application)

### 案例 1: 万通六兄弟撤离海南（1992-1993）
- **问题**: 在全民炒地的海南，如何既吃到泡沫红利又不陪葬？
- **方法论的使用**: 六兄弟在狂欢中保持清醒判定"海南的好景长不了"——入场同时预设退出时点，不因行情加速而修订纪律。
- **结论**: 泡沫中的胜负手不是选股选地，而是预先写定的撤离触发条件。
- **结果**: 一年后 6 人全部撤离；潘石屹回京创办红石（SOHO 中国前身），无人留在海南接盘。

### 案例 2: 君子兰泡沫的行政终结（1982）
- **问题**: 长春君子兰价格脱离一切基本面暴涨，如何判断顶在哪里？
- **方法论的使用**: 作者记录限价令反而给泡沫"浇油"——市场信号全部失灵；最终由禁止公款购买这一行政动作终结行情。
- **结论**: 刺破泡沫的变量是行政权力而非供求，逃顶必须盯文件不盯 K 线。
- **结果**: 行政出清后价格崩塌，持花者血本无归。

### 案例 3: 2015 年股灾——隐形杠杆遭行政强平（2015）
- **问题**: 场外配资规模无人说得清，牛市顶在哪？
- **方法论的使用**: 作者复盘灾因——证监会下文禁止券商为场外配资提供交易接口，"正是在这一天，上证指数在 5178.19 点上掉头下坠"；三征兆此前已齐（基本面脱钩、暴风科技 39 连板的垃圾神话化、"无脑买入"），行政清理即顶部。
- **结果**: 年底 A 股市值蒸发 25 万亿；泡沫的制造与刺破均出自同一只"政策方向盘"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某资产/行业/风口连续暴涨、媒体宣称"这次不一样"，用户问该不该进、进去的话怎么设退出。
2. 用户已重仓热点资产，情绪既贪婪又恐惧，需要一套写死的撤离触发条件而非临场感觉。
3. 用户怀疑某个高息理财/新型投资品是庞氏结构（e租宝式），需要清单化定性。
4. 公司主业 riding 泡沫（囤货、炒房、押注风口），需要把市场泡沫纪律落到企业头寸上。

### 语言信号 (用户的话里出现这些就应激活)

- "这是不是泡沫，什么时候破，该不该撤"
- "怎么逃顶/止盈，怕卖飞又怕站岗"（bubble top, exit discipline, "this time is different"）
- "年化那么高，会不会是庞氏骗局"

### 与相邻 skill 的区分

- 与 `delusional-expansion-detection` 的区别: 本 skill 面向资产价格与市场整体的群体狂热，输出头寸与退出纪律；delusional-expansion-detection 面向单个企业的扩张决策质量，输出内部刹车与体检。企业加杠杆追风口两者交汇时，先定性市场（本 skill）再诊断企业（后者）。
- 与 `policy-cycle-positioning` 的区别: 调控周期定位回答"现在处于放—乱—收的哪一段"（宏观坐标），本 skill 回答"手里这个头寸何时离场"（操作坐标）；两者共享"盯行政动向"的技术，但颗粒度与输出物不同。
- 与 `rent-based-model-audit` 的区别: 制度租金体检针对商业模式收入结构，本 skill 针对价格狂热中的头寸。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定性：泡沫还是价值重估**
   - 完成标准: 跑三征兆（价格与基本面脱钩/垃圾资产神话化/专业投资者投降）与庞氏五项清单，逐项标注证据；输出定性结论——健康牛市、估值泡沫或庞氏骗局。
   - 判停条件: 若三征兆与庞氏清单基本不吻合，判定非泡沫，转常规资产分析，不套用逃顶纪律。

2. **设计入场头寸与退出触发条件**
   - 完成标准: 若决定参与，明确可承受杠杆上限，并写出书面化撤离触发条件（行政信号优先：监管表态升级、公款/信贷渠道被掐；其次：三征兆出现第二项）。触发条件一经设定不得因浮盈修订。

3. **设置监测面板**
   - 完成标准: 列出需日常跟踪的行政动向源（监管文件、座谈会措辞、对公款/信贷/牌照的态度变化）与市场信号源（垃圾资产表现、投降式言论），并约定读数频率。

4. **输出离场剧本**
   - 完成标准: 写明触发后的分批离场路径（不追求卖在最高点、以确定性换价格），以及庞氏定性情形下的"立即全撤、不抄底"规则；给出复查时点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是某商品/股票的长期内在价值与基本面分析——无群体狂热情景，逃顶纪律无处安放。
- 单个公司该不该砍扩张业务——那是 delusional-expansion-detection 的企业层诊断。
- 调控处于哪一段、下一轮刺激何时来——宏观定位归 policy-cycle-positioning。

### 作者在书中警告的失败模式

- 温州抬会式庞氏雪崩：收益率在数学上要求指数级拉新（第十八个月需 20883 个会员），官员卷入使监管信号失灵，崩盘波及 30 万人。
- e租宝/泛亚式创新叙事庞氏：虚构底层资产+广告轰炸+年化 14%，"大而不倒"迷信实为放大刑责半径。
- 中科创业式庄家囚徒困境：收益依赖单边价格与合伙人默契，股价越高背叛收益越大，数学上必然崩盘。

### 作者的盲点 / 时代局限

- 数据口径: "监管估 4000-5000 亿、实际 3 万亿"等场外配资规模口径含糊，泡沫规模的测量不可靠，识别征兆的定量阈值因此缺乏校准基础。
- 幸存者偏差: 万通的"清醒撤退"是事后书写——同期撤退者与未撤者的命运未被对等呈现，"纪律有效"这一命题本身无法证伪。
- 时代边界: 写于 2018，平台经济、数字资产等新泡沫形态未纳入；"刺破泡沫的最终是行政权力"在中国市场被反复验证，但对跨境资产、去中心化资产的适用性未经作者检验。
- 当代人写当代史: 作者自认二次建构，对 2015 救市"内鬼"叙事的取舍含价值观支配，引用时应区分事实与判词。

### 容易混淆的邻近方法论

- delusional-expansion-detection：市场层头寸 vs 企业层决策。
- policy-cycle-positioning：宏观周期坐标 vs 操作性逃顶时点。
