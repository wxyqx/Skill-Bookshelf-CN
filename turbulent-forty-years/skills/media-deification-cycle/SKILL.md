# 媒体造神周期律与典型制造流水线

## R — 原文 (Reading)

> 这样的形象无疑是高大、勇敢和受人拥戴的，是那个时代所一再期待和呼唤的，至于它是不是步鑫生的真实面目则似乎是不重要的。
>
> — 吴晓波，《激荡三十年》1983 年章（步鑫生典型报道）

---

## I — 方法论骨架 (Interpretation)

中国的企业典型不是自然长出来的，是被一条自上而下的流水线生产的：内部参考→领导人批示→新华社通稿→全国转载→争议出现→调查组进驻→二次批示定调。被选中的对象未必是真实的经营强者，而是"体制亟需重启某种热情"时的叙事符号——所以光环的高度由政治需要决定，与企业实际能力无关，甚至系统性超出实际能力。

这个落差就是风险本身：政治期望替企业签下了它兑现不了的支票。公众与上级从此以"典型"标准要求它，任何经营失误都被放大为路线问题；而造神与毁神是同一台机器的两面——步鑫生被免职与马胜利集团成立同周见报，神坛的高度决定坠落的动能，被捧过的人再起成本远高于无名者。

因此名声要按负债记账：可推的荣誉尽量推，公开表述永远压在实际水平之下，趁热度还在把媒体注意力转化为组织能力与产品力，并提前准备第二曲线。标王式的注意力拍卖（知名度明码竞价）则是这条流水线的极端形态——凡稀缺资源被集中定价处，必有泡沫与豪赌。

判断要点是周期定位：媒体报告量与经营基本面脱钩、参观团增速超过订单增速、上级开始向你要"新经验"，说明已进入顶部区间。

## A1 — 书中的应用 (Past Application)

### 案例 1: 步鑫生——批量制造的典型（1983-1988）
- **问题**: 一位裁缝出身的厂长被胡耀邦批示+新华社通稿选中为改革典型，媒体一次发出 27 篇报道、3.4 万字。
- **方法论的使用**: 作者解剖生产链——形象是"时代所一再期待和呼唤的"，与真实面目无关；光环远超企业经营能力，期望值与能力倒挂。
- **结论**: 被树典型是风险事件而非利好；典型身份不能兑换经营失败的豁免。
- **结果**: 1988 年步鑫生被免职，坠落后比寻常人更难东山再起。

### 案例 2: 马胜利——新旧典型同周更代（1987-1989）
- **问题**: 承包石家庄造纸厂成名后，在承包制被捧上"一包就灵"神坛的 1987 年宣布承包百家造纸厂。
- **方法论的使用**: 作者记录"马胜利集团成立"与"步鑫生被免职"同周见报——造神与毁神同周期运行；48 小时签约贵阳厂被《贵州晚报》当决策美德头版歌颂，恰是决策质量最危险的时刻。
- **结论**: 光环加身者的局部失败会被解读为整体神话破产，退出成本远高于无名者。
- **结果**: 四个月后接连失利，1989 年初旗下企业 2/3 亏损，集团崩盘。

### 案例 3: 秦池标王——注意力的明码竞价（1996-1997）
- **问题**: 央视标王竞标让广告出价脱离任何回报测算，秦池以 3.2 亿元蝉联（报价即姬长孔的手机号码）。
- **方法论的使用**: 作者把标王定义为"拍卖稀缺注意力"的加冕仪式——知名度放大的是所有缺口；媒体造神的另一面是媒体毁神，"勾兑"报道后试图出钱收购报道，加速陨落。
- **结果**: 销售额从 9.5 亿跌至 3 亿，商标拍卖无人应价。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户的企业/客户/上级被官方媒体连续正面报道、树为行业标杆，问"这是好事还是风险，要不要配合宣传"。
2. 企业家获奖、上热搜、被评首富/劳模/人大代表，纠结荣誉接不接、表态说到什么程度。
3. 舆论已从捧转贬、出现质疑文章或调查传闻，需要判断自己处在造神-毁神周期的哪个位置。
4. 竞对或同行被捧为典型，需要预判其命运曲线以决定跟不跟风。

### 语言信号 (用户的话里出现这些就应激活)

- "被媒体捧上天/树为典型，是不是该小心"
- "企业家成名之后怎么自保，荣誉该不该推"（poster child / media hype risk）
- "负面报道开始出现，是不是要走下坡路了"

### 与相邻 skill 的区分

- 与 `delusional-expansion-detection` 的区别: 本 skill 管外部光环如何变成经营负债（媒体机器的机制与自保姿态）；delusional-expansion-detection 管企业内部扩张决策的失控识别。"48 小时签约被歌颂"是两者的交点——本 skill 的输出是压低公开姿态、推掉荣誉，后者的输出是刹车、做扩张体检。
- 与 `bubble-exit-discipline` 的区别: 造神周期是单个企业/企业家的名声曲线，泡沫是行业与资产价格的群体狂热；前者的逃法是姿态降级，后者的逃法是头寸纪律。
- 与 `business-government-distance` 的区别: 政商距离管长期公共姿态选位，本 skill 管典型周期内的动态应对。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位周期位置**
   - 完成标准: 按生产链（内参→批示→通稿→争议→调查→二次定调）判断对象当前处于哪一环；用三条顶部落带核查——报道量与基本面脱钩、参观团增速>订单增速、上级索要"新经验"而企业无新故事。

2. **执行自保三件套**
   - 完成标准: 给出可推荣誉清单（能推尽推）、公开表述校准（永远低于实际水平）、热度转化计划（把媒体注意力兑换为组织能力/产品力/渠道，设明确时限）。

3. **预演毁神情景**
   - 完成标准: 写出"争议→调查→二次定调"一旦启动的应对预案：绝不高调自证、绝不出钱买报道（秦池教训）、提前准备第二曲线与退路叙事。
   - 判停条件: 若对象尚未被任何官方渠道注意且无被选典型的迹象，判定周期未启动，转常规声誉管理建议。

4. **输出风险记分**
   - 完成标准: 以"名声负债"口径给出当前光环超出实际能力的差值评估（高/中/低），并给出下一季度复查点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要的是怎么打广告、怎么做品牌传播、怎么写通稿——那是营销策划，不是造神周期的风险判断。
- 单一产品质量危机的公关应对——没有"被树为典型"这一前提，光环负债逻辑不成立。
- 企业自身并购/开店速度失控的诊断——内部决策质量问题归 delusional-expansion-detection。

### 作者在书中警告的失败模式

- 步鑫生式光环反噬：期望与能力倒挂，免职后比无名者更难东山再起。
- 禹作敏式身份幻觉：把典型身份当护身符与豁免权，"局长算个球"式狂狷，身份不能兑换法律责任。
- 秦池式危机自毁：丑闻曝光后"花钱买报道"，把声誉事件升级为操守事件。

### 作者的盲点 / 时代局限

- 当代人写当代史: 作者自认其书写是"基于事实的二次建构"，且他本人长期身处财经媒体的造神-毁神现场——他对步鑫生、马胜利的叙述本身参与了这个循环，褒贬不可当中立史料。
- 幸存者偏差: "推荣誉自保"是全书反复给出的药方，但照做成功者几乎没有被记录——自保法是从失败案例反推的，无正面验证样本。
- 归因摇摆: 作者时而把典型坠落归于个人"忘乎所以"，时而归于体制造神机器，人物责任与结构责任的权重在章节间漂移。

### 容易混淆的邻近方法论

- delusional-expansion-detection：舆论反指是两者共享的信号，但一个管对外姿态、一个管对内刹车。
- business-government-distance：长期选位 vs 周期应对。
