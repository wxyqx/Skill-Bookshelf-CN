# 政策周期定位法——放-乱-收时钟

## R — 原文 (Reading)

> 在过去将近30年的改革历程中，宏观调控——在20世纪90年代之前被称为治理整顿——已成为一个具有鲜明中国特色的名词。它几乎每隔3～5年就会出现一次，而且从1981年开始，历次的宏观调控从来只宣布开始，而不通知结束。
>
> — 吴晓波，《激荡四十年》2006年章

---

## I — 方法论骨架 (Interpretation)

在做任何投资或扩张决策前，先给宏观政策"对表"，四个要点：

1. **节律定位**: 宏观调控约3-5年一轮，且"只宣布开始，不通知结束"——退出的时点官方永远不告诉你，必须自设预警信号（重大工程完工潮、银行上市潮、股市楼市双回暖这类历史上出现过的"方向盘突转"前兆）。
2. **四段论推演**: 强势产业政策遵循"刺激→层层加码→倍级扩容→失控"四段。判断当前在哪一段，就能推演下一段：失控之后必是出清。
3. **祭旗者机制**: 紧缩期的出清代价按所有制"等级"再分配——重资产、信贷依赖度高、被树为典型或最显眼的民企最先被选中震慑全局。出清顺序由身份而非经营质量决定，违法性质相近者中"项目越成功越可能成为标本"。
4. **资金纪律**: 不押信贷续期，以自有资金按"不知道会紧多久"的假设安排现金流——1989年治理整顿中个体户减少300万户、私企腰斩，存活者靠的是资金链长于冬天。

## A1 — 书中的应用 (Past Application)

### 案例 1: 铁本——周期急转弯中的祭旗者（2004）
- **问题**: 戴国芳的105.9亿元钢厂项目在景气扩张期大干快上，调控风向突转时如何自处？
- **方法论的使用**: 用周期坐标看：2004年春调控启动，紧缩期需要最典型、最显眼的民企项目做标本；铁本分22次越权拆分审批、违规征地，恰好同时满足"重资产+高信贷依赖+最显眼"三个祭旗者条件。
- **结论**: 成为"标志性案件"不是偶然，是祭旗者选择机制的必然。
- **结果**: 铁本死亡、戴国芳家产8万元被查封；同省同业的博思格钢铁7个工作日拿到17亿元项目执照——身份不同，审批与处置结果完全不同。

### 案例 2: 治理整顿的出清深度（1989-1991）
- **问题**: 紧缩会持续多久？民企如何做资金安排？
- **方法论的使用**: 按"只开始不结束"的规律，不做"很快放松"的假设，以自有资金假设最坏情景。
- **结论**: 冬天以年计，而非以月计。
- **结果**: 治理整顿期间个体户减少300万户、私企数量腰斩，靠信贷扩张维持的企业批量出清。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某新兴产业在补贴刺激下各路资本倍级涌入，用户想知道按四段论下一阶段会发生什么、自己该在哪个阶段前撤出或收缩。
2. 紧缩信号已现（信贷收缩、整顿文件），用户是重资产高杠杆民企，要评估自己成为"祭旗者"的暴露度。
3. 用户问"这轮紧缩/宽松会持续多久"，需要自设周期转折预警指标而非等待官方宣布。
4. 用户要决定扩张节奏：是趁"放"的早段抢跑，还是在"收"的下半场蛰伏。

### 语言信号 (用户的话里出现这些就应激活)

- "现在调控进行到哪一步了？"
- "我们会不会成为下一个铁本/被拿来开刀？"
- "紧缩还要多久？资金链能撑住吗？"
- "补贴一出各路资本都疯了，接下来是不是要一地鸡毛？"
- "policy cycle, tightening phase, where are we in the cycle, deleveraging"

### 与相邻 skill 的区分

- 与 `policy-signal-capture` 的区别: f01 处理单次开闸信号的进攻兑现（小时级决策）；f04 处理多年周期的位置定位与退出预警（季节级决策）。信号可以出现在周期任何阶段，先定位周期再决定信号的可信度。
- 与 `bubble-exit-discipline` 的区别: f13 管单一泡沫资产里的个体逃顶纪律（盯行政动向定逃顶）；f04 管宏观周期位置与企业在周期中的身份暴露度。前者是持仓纪律，后者是经营坐标。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **周期定位**
   - 完成标准: 按"刺激→层层加码→倍级扩容→失控"四段论给出当前阶段判断，并列出证据（信贷投放增速、重大工程完工潮、银行上市潮、股市楼市温度等自设信号），不得只凭体感。
   - 判停条件: 若定位在"放"的早段且用户无杠杆，输出观察建议即可，跳过步骤 3。

2. **祭旗者暴露度评估**
   - 完成标准: 按四个维度给用户企业打分——所有制身份（民企/国企/外资）、重资产程度、信贷依赖度、典型性/显眼度（规模排名、媒体曝光、树典型历史），输出暴露度结论与最脆弱环节。

3. **资金压力测试**
   - 完成标准: 以自有资金、假设"不知道会紧多久"重算现金流存活期，给出明确数字（能撑几个月的紧缩），并列出降杠杆的优先顺序。

4. **出清期预案**
   - 完成标准: 输出阶段预案——如何降低典型性/显眼度、哪些扩张暂停、什么信号出现时认为调控结束（自设，非官方），以及结束前的蛰伏期动作清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 官方已明确开闸、用户要决定怎么抢跑单次窗口——那是 policy-signal-capture。
- 用户问的是手中某个泡沫化资产何时卖出——那是 bubble-exit-discipline。
- 企业的问题与政策暴露无关（纯产品、竞争、组织问题）。

### 作者在书中警告的失败模式

- **踩线+最显眼=祭旗**（铁本，2004）: 把违规成本估算为"最多罚款"、用上一轮周期的经验给本轮定价，紧缩期恰恰最显眼者最先被清算；为"花钱消灾"提交的自查报告两年后成为检察院最有力的指控证据。
- **产融结构赌流动性永不收缩**（德隆，2004）: 靠护盘与质押融资维持的高台，宏观紧缩是天然死线——断血即崩，206.8亿市值数周蒸发160亿。
- 书中对照：同业博思格7天拿照——紧缩打击的是身份与信号功能，不是行业本身。

### 作者的盲点 / 时代局限

- **当代人写当代史的二次建构**: "3-5年一轮"的节律是作者对四十年史的归纳性叙事，样本有限且各轮成因迥异，作者本人也未将其当作可外推的规律。
- **幸存者偏差**: 祭旗者机制由铁本、德隆等失败样本反推；同期未被选中、同样踩线的项目（如以接受国企控股换"合法准生"的建龙）作为对照被轻描淡写。
- **数据口径问题**: 书中调控年份的投资、信贷数据多为转述；作者在其他处明确承认"四万亿95%给国企"等定性数据不可考。
- **重个人轻结构的归因摇摆**: 同一批案例，作者时而归因于企业家冒险踩线（个人责任），时而归因于周期与所有制结构（体制责任），铁本章与综述章的归因口径不一致。
- **2018年写作的时代边界**: 写作时点前调控以信贷与审批为主要工具；此后预期管理、精准定向工具使"只宣布开始不通知结束"的表现形式改变，自设预警信号清单需更新。

### 容易混淆的邻近方法论

- `policy-cycle-positioning` 与 `rent-based-model-audit`: 租金依赖型商业模式在周期转向时归零，是两个 skill 的交汇——但前者回答"周期在哪、我多危险"，后者回答"我的收入结构有多脆"。用户拿不准时先做周期定位，再进入模式体检。
