# 制度租金模式归零体检——靠审批/关系/公款消费的商业模式体检

## R — 原文 (Reading)

> "不要再抱任何幻想，不会再好起来了。"一位相熟的官员私下里对孟凯说，"八项规定"不是一阵风，而是体现了执政者的新决心。
>
> — 吴晓波，《激荡四十年》2013 年章（湘鄂情）

---

## I — 方法论骨架 (Interpretation)

有些生意的收入并不来自市场竞争力，而来自制度本身：公款消费撑起的高端餐饮、审批权派生的中介与代理、双轨价差滋养的倒卖、特定政策恩惠喂养的补贴业务。这类收入的本金是"制度租金"——它不是利息而是敞口：租金型模式等于在做空政策风险，风向掉头时没有任何市场缓冲，收入曲线不是下滑而是瞬间归零（八项规定后的官宴餐饮、管制方式改变后的倒爷经济）。

体检的操作是压测而非定性：把租金类收入（补贴、政府订单、审批派生收入、政商关系型客户）从总收入中剥离，测算"政策归零情景"下现金流能存活多久。归零存活期越短、租金占比越高，模式越脆弱。此时最危险的选项是"概念式转型"——换赛道讲新故事（改名大数据、宣布跨界），它救不了旧结构，只会用新故事融资给旧模式续命，转型叙事本身就是加速崩塌的信号。唯一有效动作是在景气期把技术性收入建起来：看技术性收入占比的变化率，而不是看转型新闻。

## A1 — 书中的应用 (Past Application)

### 案例 1: 湘鄂情的归零与"中科云网"式转型（2013-2014）
- **问题**: 湘鄂情以公务宴请为支柱的"京城第一大厨"模式，在八项规定出台后遭遇断崖，2013 年关闭 8 家门店、上市公司巨亏 5.64 亿元。
- **方法论的使用**: 官员的私下告知（"不要再抱任何幻想"）确认这是新政治周期而非一阵风——按归零体检，应立即测租金归零后的存活期；而孟凯的实际动作是概念式转型：投资环保、进军房地产影视、发力"新媒体大数据"、把公司改名"中科云网"并宣布与中科院合作募资数十亿元。
- **结论**: 租金归零无缓冲，概念式转型是用新故事给旧结构续命；诊断线索恰是转型公告本身。
- **结果**: 转型屡战屡败，公司戴上 ST 帽，创始人最终离场——"别和我谈餐饮，谈大数据"成为租金依赖症的墓志铭。

### 案例 2: 双轨租金的整体消亡（1985-1992）与万达"内贷外投"触礁（2017）
- **问题**: 80 年代倒爷经济完全寄生在双轨价差上（1988 年租金规模估算约 3500 亿）；2017 年万达以"内贷外投"模式扩张，负债端依赖国内信贷、资产端转移海外。
- **方法论的使用**: 两例同构：收入/扩张的本金来自制度安排（价差管制、信贷管制下的套利通道），制度本身一变（价格闯关并轨、对外投资强监管），模式整体消亡而非渐衰——不存在"用经营改善对冲"的选项。
- **结论**: 租金型模式的死亡方式是"归零"而非"亏损"；体检必须以"制度变量=0"为情景，而非以经营波动为情景。
- **结果**: 倒爷阶层随双轨制终结整体退出历史；万达被迫紧急出售资产、断臂求生。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一家公司收入的大头来自政府补贴、政府采购、政务订单或审批派生的中介费，要评估政策变动下的真实风险。
2. 高端餐饮、会所、礼品、政务信息化等依赖公款消费曲线的生意，遇到作风/廉政类政策转向。
3. 一家租金依赖型企业宣布"转型"（换赛道、改名、跨界合作），投资方或管理层要判断转型可信度。
4. 投资/尽调场景：标的公司报表漂亮，需要剥离制度租金、测算政策归零情景下的现金流存活期。
5. 企业自查：如何在景气期规划"去租金化"，把技术性收入建起来。

### 语言信号 (用户的话里出现这些就应激活)

- "这生意 basically 是靠政府补贴活的，能长久吗？"
- "政策一变天，他们收入会怎么样？"
- "公司说要转型做 XX，这转型靠谱吗？"
- "公款消费 / 官宴 / 政府订单占比太高"
- "制度租金 / 做空政策风险 / 政策归零"

### 与相邻 skill 的区分

- 与 `policy-cycle-positioning` 的区别: 那是判断调控周期位置与紧缩期生存对策（所有企业通用），本 skill 是对特定商业模式收入结构的归零体检；周期问题问"现在是冬天的哪一段"，本 skill 问"你的收入里有多少是制度发的糖"。
- 与 `business-government-distance` 的区别: 那是公开姿态与政商距离设计，本 skill 是收入结构的财务诊断；前者输出姿态纪律，后者输出压测数字。
- 与 `policy-thermometer-reading` 的区别: 那是观测风向的指标面板，本 skill 在风向确认后量化自身敞口；温度计是输入，归零压测是动作。

## E — 可执行步骤 (Execution)

1. **租金收入剥离**
   - 把收入按来源分类：市场性收入 vs 租金性收入（补贴、政府/国企订单、审批派生、政商关系型客户、公款消费曲线），逐项标注其依附的制度变量。
   - 完成标准: 一张收入结构表，租金类收入占比有明确数字或可靠估算区间。

2. **政策归零压测**
   - 设定"制度变量=0"情景（补贴取消、订单冻结、审批通道关闭、公款消费归零），测算现金流存活期与刚性支出的缺口。
   - 完成标准: 给出存活期月数与最脆弱环节；存活期长于转型所需周期则为及格线。
   - 判停条件: 若租金占比低于可忽略水平（如<10% 且无单一制度依赖），终止体检，告知模式非租金型。

3. **转型叙事可信度诊断**
   - 若企业已宣布转型：核对新业务的独立竞争力与真实投入，判断是"技术性收入替代"还是"用新故事融资给旧结构续命"。
   - 完成标准: 输出二选一结论——可信转型（看技术性收入占比变化率）或概念式转型（加速崩塌信号），并列出后续验证指标。

4. **去租金化路线图**
   - 为高租金依赖企业设计景气期的替代收入计划：优先建技术性/市场性收入线，设定租金占比的逐年下降目标与预警线。
   - 完成标准: 用户获得带时间表与预警线的去租金化清单；若已处于归零后阶段，输出止损与出清建议而非转型建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 企业的问题在扩张速度、多元化失控或资金链腾挪，收入结构本身健康——那是狂想式扩张诊断或产融风险分析的领地。
- 用户问的是"调控周期现在到哪一段、该不该收缩投资"——转 `policy-cycle-positioning`；本 skill 只针对租金型收入结构。
- 用户需要解读具体政策文件对某业务的影响（合规判断）——转 `dormant-clause-interpretation`。

### 作者在书中警告的失败模式

- 孟凯/湘鄂情（j10_2013）：租金归零后连续概念式转型（环保、地产、影视、大数据改名中科云网），每一步都在用新故事给旧结构续命——"转型公告是制度租金依赖症的诊断线索"。
- 双轨官倒（j30_1988）：价差租金使企业理性选择围绕寻租配置资源而非生产（南京千吨钢材原地炒卖 129 次），配额越紧倒卖越烈——租金经济会反向腐蚀主业能力。
- 联营空心化（j30_1993）：沈阳双喜品牌使用费超过自身产销利润后停止研发，坐吃品牌——租金收入超过主业利润之日即空心化开始之时。
- 万达内贷外投（j10_2017）：扩张本金依赖制度性信贷通道，强监管落地后只能紧急出售资产——租金型扩张没有软着陆。

### 作者的盲点 / 时代局限

- 数据口径问题：书中支撑"制度租金"叙事的关键数字（如双轨租金 3500 亿、"四万亿 95% 给国企"）多为转述、估算或匿名信源，未经独立核验——引用时须连带口径警示，压测应以企业自身报表为准。
- 作者自认当代人写当代史、价值观支配下的二次建构：对租金型企业的清算叙事带同情式书写（民企悲情滤镜），"瞬间归零"的戏剧化框架可能低估市场型收入同样会受政策影响的双向性。
- 幸存者偏差与归因摇摆：穿越周期者（褚时健、华为）被浓墨书写为"技术性收入"的正例，但其成功亦有周期与个人因素；作者在归因于企业家选择还是制度结构之间摇摆。
- 时代边界：成书于 2018 年，未纳入后来的平台经济治理、数据监管、地产"三道红线"等新租金变量的形态；公款消费场景的边界也与当下不同。

### 容易混淆的邻近方法论

- "客户集中度风险"常识：财务上讲"大客户依赖"，本 skill 的独特处在于把依赖对象锁定为"制度变量"（审批、补贴、公款消费），并以"政策归零"而非"客户流失"为压测情景，加上"概念式转型是诊断线索"的反直觉判断。
- `red-hat-structure-decision`：若"租金"来自借身份挂靠换来的准入优惠，身份交易账（含赎回）转彼 skill；本 skill 只管收入结构的体检。
