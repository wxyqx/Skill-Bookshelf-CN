- id: Af01
  title: 问题驱动的经济学方法（以问题为线索组织理论）
  type: framework
  source_chapter: 前言 §1；第1讲 开篇
  source_quote: |
    现有的教材更多在介绍“宏观经济理论是怎样的”，而这份讲义则更多在讲“宏观经济
    理论怎么用”，并在运用的过程中让读者逐步体会到“宏观经济理论为什么会是这样的”。
  summary: |
    解决的问题：学了理论却用不到现实、理论与现实“两个世界”的脱节。
    核心逻辑：不从理论体系的内在逻辑出发，而从中国经济现实提出的真实问题出发，
    以“回答问题的思路”为线索串起一个个模型；模型在回答问题的过程中组成自洽的
    逻辑体系。
    怎么用：面对任一经济议题，先把它提炼成一个清晰的关键问题，再挑选能回答该
    问题的分析工具，而不是先拿工具再找问题。每一讲的流程是“问题的提出—分析—
    回答—运用”。
  tags: [问题驱动, 方法论, 全书总纲]

- id: Af02
  title: “水与石头”框架：市场规律×约束条件
  type: framework
  source_chapter: 前言 §2
  source_quote: |
    所谓“水”，指的是市场经济的运行规律，而“石头”则是市场运行面临的约束条件。
    ……要真正弄懂中国这条河流为什么会是现在这个样子，必须把流体动力学的知识和
    水中石头分布的信息结合起来。
  summary: |
    解决的问题：为什么照搬西方教科书结论解释中国常常失灵。
    核心逻辑：市场经济规律如水，普适且灵活，但没有自己的形状；约束条件（计划
    经济残余、制度摩擦）如石头，决定了水呈现的形状。西方河流里石头早被冲走，只
    需流体动力学；中国河流里石头尚多，浪花和漩涡（中国特有现象）正是水冲石头
    的结果。
    怎么用：分析任何中国现象，先问“这里的普适规律是什么（水）”，再问“这里
    特有的约束条件是什么（石头）”，二者结合推演运行特性。
  tags: [中国视角, 约束条件, 元框架]

- id: Af03
  title: 供需图判别波动来源：价量同向=需求侧，价量反向=供给侧
  type: framework
  source_chapter: 第1讲 1.2.1节
  source_quote: |
    如果市场中的需求方发生波动……那么成交价格与成交数量会同向变化——价量同涨
    同落……反过来，如果是供给方变化引发的市场波动，则成交价格与成交数量会反向
    变化——价跌量涨或是价涨量跌。
  summary: |
    解决的问题：不知道某市场价格波动的根源在需求还是供给，政策就会开错药方。
    核心逻辑：需求曲线平移时价量同向变动；供给曲线平移时价量反向变动。因此只
    需观察现实中价格与数量的相关性符号，即可反推波动的来源侧。
    怎么用：拿到一个市场的价量数据→判断相关方向→确定波动来自哪一侧→再判断
    针对该侧的政策工具（如货币政策属需求管理）能否起作用。作者用此法一击回答
    房地产调控与猪价通胀两个重大现实问题，示范“简单工具的穿透力”。
  tags: [供需分析, 波动来源诊断, 价量判别]

  type: framework

  source_quote: |
    本书的目的便是回答这些关键问题，并用一个个问题的答案搭起理解中国经济的分析
    框架，让读者有分析中国经济现实问题的能力，从而可以参与到真实世界中激烈的
    政策辩论中去。
  summary: |
    解决的问题：中国经济问题千头万绪，需要一个分类坐标让分析不迷失。
    核心逻辑：把关键问题归为四类——经济增长（长期绩效）、经济波动（短期周期）、

    各讲分别对应回答其中某类问题。
    怎么用：遇到任何中国宏观议题，先归入四类之一，找到对应的模型工具与已有
    答案；也可用来检查自己的分析缺了哪个维度。
  tags: [问题地图, 宏观四分法, 全书导览]

- id: Af05
  title: 国民财富追问链：终极关切决定衡量方式
  type: framework
  source_chapter: 第2讲 2.1节
  source_quote: |
    对国民财富成因的探究可以拆分成一系列层层递进的追问：什么是国民财富？国民
    财富怎样衡量（如何统计）？国民财富从何而来？国民财富如何增加？……还有一个
    更为关键的问题：我们为什么关心国民财富？
  summary: |
    解决的问题：统计指标（如GDP）常被当成不言自明的出发点，导致对它的误读。
    核心逻辑：先追问“为什么关心”（终极关切=居民福利），再由终极关切倒推
    “用什么衡量”（可观测、与效用相关的指标→GDP），再谈如何增加。定义与度量
    是从目的推导出来的手段。
    怎么用：分析任何经济指标前，先沿“它为何存在→它服务什么目的→它如何被
    定义”的链条回溯，避免把手段当目的。
  tags: [终极关切, 追问链, GDP溯源]

- id: Af06
  title: 从居民福利出发为“现状好坏”找标尺
  type: framework
  source_chapter: 第2讲 2.4节
  source_quote: |
    我们需要从居民福利出发，以居民的效用最大化为起点，来论证恰当的消费占比应该
    是多少。我们还需要分析，这种恰当的比例是通过什么样的经济制度和机制在真实
    世界中实现的。
  summary: |
    解决的问题：说“中国消费占比低于国际平均”不构成规范判断——比较的标尺
    从哪来？
    核心逻辑：标尺只能来自经济学的终极关切（居民福利）：先由效用最大化论证
    恰当比例应是多少，再分析该比例赖以实现的经济制度与机制，找出中国现实中
    缺失的环节——缺失处即政策突破口。
    怎么用：三步走：①用模型/理论定出“应然”标尺；②对照现实找差距；③追问
    实现机制中哪一环缺失，定位改革抓手。反对停留在“就事论事”的国际比较。
  tags: [福利标尺, 规范判断, 消费转型]

- id: Af07
  title: 市场经济三环节循环与GDP三种统计方法
  type: framework
  source_chapter: 第2讲 2.3节
  source_quote: |
    市场经济是一个由产出、收入与需求三阶段组成的无尽循环过程……从产出到收入是
    收入分配的问题，从收入到需求是消费和投资行为的问题，从需求到产出是经济总
    供给与总需求的关系问题。
  summary: |
    解决的问题：GDP如何成为“深入经济内部的思路”而不只是一个总量数字。
    核心逻辑：市场经济是产出→收入→需求的循环；循环的每个环节对应一个观察
    视角，也对应一种GDP统计方法——生产法（产出侧，按产业增加值）、收入法
    （收入分配侧）、支出法（需求侧，三驾马车）。三个视角同时切，可得经济全貌。
    怎么用：分析中国用生产法GDP（官方主指标），看结构用产业构成，看分配用
    收入法构成，看波动来源用支出法“三驾马车”的拉动分解。
  tags: [GDP核算, 经济循环, 三视角]

- id: Af08
  title: 寓言式简化建模：抽象出简化世界再映射回现实
  type: framework
  source_chapter: 第2讲 2.1节
  source_quote: |
    直接分析错综复杂的真实世界是困难的。我们需要从真实世界中抽象出一个简化
    模型，再利用这个模型来思考。……将那些不重要的东西忽略，而只留下那些他们
    认为关键的因素。
  summary: |
    解决的问题：真实经济变量太多、因果纠缠，无法直接分析。
    核心逻辑：像伊索用龟兔赛跑讲道理一样，剥离次要因素，只保留关键因素，构造
    一个用数学描述的简化世界（如本讲的代表性消费者+苹果经济），在简化世界里
    得到逻辑线索，再拿回真实世界解释现象。
    怎么用：①明确要回答的问题；②选择最小要素集建模（一个消费者、一种商品
    即可）；③求解/推演；④把结论对照现实验证。模型的“不真实”不是缺点，只要
    关键机制被保留。
  tags: [建模方法, 简化抽象, 代表性消费者]

  type: framework
  source_chapter: 前言 §3
  source_quote: |
    这三条线索分别是中国经济的结构失衡、中国货币政策传导路径的阻塞以及绵延数
    百年至今的有关萨伊定律的思想论争。
  summary: |
    解决的问题：25讲内容如何不散架，读者如何在长程阅读中保持主线感。
    核心逻辑：线索一（实体失衡）：最大的一块“石头”是调节消费与投资的市场

    怎么用：读任何一讲时先定位它服务哪条线索；分析现实问题时也检查这三个
    维度（实体结构、货币传导、思想立场）是否都覆盖。

- id: Af10
  title: 双向翻译：自然语言与数学语言之间的往返转换
  type: framework
  source_chapter: 第1讲 1.2.2节、1.3节
  source_quote: |
    经济学家需要不断在自然语言和数学语言之间做双向翻译：既要把现实问题转换成
    数学语言，以便于分析；又要把用数学推理得到的逻辑和结论翻译成自然语言，让
    非经济专业的人士领悟。
  summary: |
    解决的问题：自然语言模糊引发伪悖论（苹果悖论），数学语言精确却难沟通、
    建模时还必须做简化取舍。
    核心逻辑：翻译是双向且持续的——现实→数学（建模，须警惕重要因素被简化掉）
    →推理→数学结论→自然语言（传播）。数学的价值在于让“思维中的模糊之处
    无所遁形”。
    怎么用：遇到似是而非的争论，先把各方的命题改写成明确的数学/图形表述，
    偷换概念会立刻现形；得出结论后必须能“用大白话讲出来让人信服”才算真正
    解决问题。
  tags: [数学化, 语言精确化, 经济学家素质]
