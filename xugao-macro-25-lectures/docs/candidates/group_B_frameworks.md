# 框架候选（第3-4讲）

- id: Bf01
  title: 增长研究的根本问题清单（卢卡斯之问）
  type: framework
  source_chapter: 第3讲 3.1节
  source_quote: |
    有没有印度政府能够采取的措施，可以将印度的经济增长提升到印度尼西亚或埃及的水平？
    如果有的话，是什么？如果没有，是印度的什么东西让它这样的？……一个人一旦开始思考它们，
    就很难再去想别的问题。
  summary: |
    解决"增长研究该问什么问题"的问题。卢卡斯在1988年经典文章中列出增长研究的核心问题
    清单：经济为什么增长？国家间、时期间增长为何不同？资本、劳动、技术、制度、文化各起
    多大作用？能否用政策提升增长率？这些问题对人类福利影响巨大，一旦开始思考就很难放下。
    用法：把任何增长议题先还原到这个清单上，明确自己问的是清单中的哪一问，避免问题错位。
  tags: [增长, 卢卡斯, 问题清单]

- id: Bf02
  title: 供给/需求双视角切入增长 + 价量相关性判定法
  type: framework
  source_chapter: 第3讲 3.2节
  source_quote: |
    可以用交易价格和数量之间的相关性来判定主导市场的因素在供给面还是在需求面——价量反向
    变化表明供给因素主导市场，价量同向变化表明需求面是主导因素。这一方法对宏观经济分析也
    是适用的。
  summary: |
    解决"增长约束在供给面还是需求面"的判别问题。交易量恒等于供给量也等于需求量，故无法
    直接从成交量分辨谁在主导；用价格与数量的相关性来做裁判：价量反向（滞胀组合）说明供
    给冲击主导，价量同向（高增长伴随高通胀或低增长伴随低通胀）说明需求主导。对一国GDP
    真实增速与通胀（GDP缩减指数）做10年滚动相关系数，即可给该国增长的主导因素定性。
    用法：先算价量相关性给经济体"定性"，再决定用供给面还是需求面框架去分析。
  tags: [供给与需求, 价量分析, 增长诊断]

- id: Bf03
  title: 生产函数框架：Y=F(K,L) 与规模报酬不变
  type: framework
  source_chapter: 第3讲 3.3节、3.3.1节
  source_quote: |
    从供给面来分析经济增长，核心问题是：经济中的产出为什么会越来越多？我们需要把那些与
    宏观经济相关的因素组织起来……这一框架就是生产函数（production function）——个把投入
    要素和产出联系起来，概括了经济中生产活动的函数。
  summary: |
    解决"如何组织供给面因素做数量分析"的问题。把资本K、劳动L两大要素投入与产出Y用函数
    联系起来；要求规模报酬不变（所有要素倍增则产出倍增，tY=F(tK,tL)，一次齐次）。在完全
    竞争下由欧拉定理推出产出被完全分割为要素回报：Y=rK+wL。这是增长计量与索洛模型的
    共同地基。用法：写下生产函数即等于对生产技术做出一组假设，分析前必须明确假设内容。
  tags: [生产函数, 规模报酬不变, 欧拉定理]

- id: Bf04
  title: 稻田条件：新古典生产函数的经典假设组
  type: framework
  source_chapter: 第3讲 3.3.2节
  source_quote: |
    即当资本投入量非常小时，增加一点资本带来的边际产出非常巨大。相反，当资本投入已经很多
    时，增加资本带来的边际产出微乎其微……便构成了新古典经济学对生产函数的经典假设，即所谓
    的稻田条件（Inada conditions）。
  summary: |
    给出新古典生产函数的标准假设：无投入无产出、边际产出为正且递减、要素投入趋于零时边际
    产出趋于无穷、趋于无穷大时边际产出趋于零。稻田条件保证索洛模型中稳态的存在与收敛。
    用法：它同时是一把"边界标尺"——这套假设排除了资本回报为零或为负的情形，从而排除了
    产能过剩问题的讨论空间；使用前先检查研究对象是否落在假设边界之外。
  tags: [稻田条件, 生产函数, 假设边界]

- id: Bf05
  title: 技术进入生产函数的三种方式
  type: framework
  source_chapter: 第3讲 3.3.3节
  source_quote: |
    最常见的是Y=AF(K,L)，在这种生产函数的设定下，A被称为全要素生产率（TFP）……资本增进型
    （capital-augmenting）技术进步：Y=F(AK,L)……劳动增进型（labor-augmenting）技术进步：
    Y=F(K,AL)。
  summary: |
    解决"技术这个非物质因素如何进入模型"的问题。三种设定：希克斯中性（Y=AF(K,L)，同时
    提升资本与劳动效率，A即TFP）、资本增进型Y=F(AK,L)、劳动增进型Y=F(K,AL)。在柯布-
    道格拉斯生产函数下三种形式完全等价，可合并为Y=AK^α L^(1-α)。注意A的内涵远不止狭义
    技术，一切影响产出的非物质因素都被囊括其中。用法：做增长计量时知道自己在哪种设定下
    解释A。
  tags: [技术进步, TFP, 生产函数设定]

- id: Bf06
  title: 柯布-道格拉斯生产函数与要素份额稳定性
  type: framework
  source_chapter: 第3讲 3.3.4节
  source_quote: |
    当α+β=1时，这一生产函数呈现出规模报酬不变的特性。此时，此生产函数可写为Y=K^α L^(1-α)。
    这便是在宏观经济学研究中最为常见的生产函数形式。
  summary: |
    解决"什么生产函数能与要素份额稳定的事实相符"的问题。道格拉斯从1899-1922年美国制造业
    数据发现资本与劳动在产出中的份额不变，请数学老师柯布构造出Y=K^α L^(1-α)。其中α是资本
    份额、1-α是劳动份额；份额稳定源于工资率变化对工资性收入与就业量两种相反效应相互抵消。
    α由生产技术决定：资本密集型行业（芯片）α高，劳动密集型行业（服装）α低。人均形式
    y=Ak^α 是最常用的工作形态。
  tags: [柯布-道格拉斯, 要素份额, 资本份额]

- id: Bf07
  title: 增长计量（增长核算）分解框架
  type: framework
  source_chapter: 第3讲 3.4节
  source_quote: |
    利用生产函数，我们可以将经济增长分解为来自资本、劳动力以及技术的贡献，从而对经济增长的
    生产面源泉有一个大致的认识。这就是增长计量（growth accounting）。
  summary: |
    解决"增长的源泉各占多少"的分解问题。对Y_t=A_t K_t^α L_t^(1-α)取对数差分，得
    ΔY/Y=ΔA/A+α·ΔK/K+(1-α)·ΔL/L。产出增速、资本增速、劳动增速都可观测，唯有gA不可直接
    观测：用增速数据回归估计α，gA作为残差被估计出来，即索洛剩余/TFP。用法：给增长表现做
    "来源体检"；更精细的做法是把索洛剩余黑箱继续拆分（如用教育水平衡量人力资本）。
  tags: [增长核算, 索洛剩余, 分解]

- id: Bf08
  title: 索洛增长模型：设定、关键方程与稳态
  type: framework
  source_chapter: 第3讲 3.5节
  source_quote: |
    索洛模型中的关键假设是经济中的储蓄率s（0<s<1）外生给定，并不随时间变化……这样，经济中
    的资本存量运动就可以用下面这个方程来描述：K_{t+1}=sAF(K,L)+(1-δ)K。这是索洛模型的关键
    方程。
  summary: |
    解决"增长从哪里来、走向何处"的机制问题。封闭经济、无政府，人口以速率n增长、技术以
    速率g增长，唯资本内生积累；储蓄率s外生给定，资本按折旧率δ损耗。人均形式
    k_{t+1}=[sf(k)+(1-δ)k]/(1+n)，配合稻田条件保证人均资本收敛到稳态k*，稳态满足
    sAf(k*)=(n+δ)k*。为什么关心稳态：长期福利水平由稳态人均资本存量决定。用法：把任何
    关于储蓄、投资、长期增长的争论放进这个动力学框架里讨论。
  tags: [索洛模型, 稳态, 资本积累]

- id: Bf09
  title: 黄金律储蓄率框架：以福利为目标评价储蓄率
  type: framework
  source_chapter: 第3讲 3.5.3节
  source_quote: |
    给定技术水平，有一个最大化稳态人均消费量的储蓄率，被称为储蓄的黄金律（golden rule）
    水平……由这一优化问题的一阶条件可以解出，s_Golden=α。所以，如果以居民福利为经济
    增长的目标，储蓄率就不是越高越好，投资也不是越多越好。
  summary: |
    解决"储蓄率多高算合适"的规范问题。目标函数不同答案不同：若追求稳态人均产出最大，储蓄
    率越高越好（极端到近乎全部储蓄）；若以居民福利（稳态人均消费）为目标，则存在黄金律储
    蓄率，柯布-道格拉斯下 s*=α。储蓄率上升有双重效应——提高人均产出、压低消费份额，黄金律
    平衡二者。用法：为讨论中国储蓄过剩、消费不足提供模型基点，判断现实储蓄率相对黄金律的
    位置。
  tags: [黄金律, 储蓄率, 居民福利]

- id: Bf10
  title: 总量生产函数分析的"一分为二"评价框架
  type: framework
  source_chapter: 第4讲 4.1节
  source_quote: |
    一方面，这是经济分析一步值得赞赏的跨越。借助生产函数的框架，我们直达了生产活动的本质
    ……另一方面，我们要看到这种总量生产函数分析框架的局限……它忽略了总量中的结构问题。
  summary: |
    解决"如何看待增长计量这类总量分析"的方法论定位问题。正面：直达生产本质，推出人口增长
    与资本积累都不是长期增长之源、唯一源头是索洛剩余，且中国改革前后数据支持这一点。负面：
    把增长源泉归结为"对我们未知的度量"的黑箱不算满意的研究；总量函数丢失了结构信息，而
    结构剧烈变化时会反过来影响总量。用法：把总量分析当作起点而非终点，下一步往黑箱里拆
    结构（本讲即引出新结构经济学思路）。
  tags: [总量分析, 结构, 方法论]

- id: Bf11
  title: 资本密集度（α）刻画生产技术的框架
  type: framework
  source_chapter: 第4讲 4.2节
  source_quote: |
    从以上推导可以看出，资本份额（α）与生产活动对应的资本和劳动力配比是正相关的。因此，
    可以把资本份额（α）看成是对生产技术本身资本密集度的刻画。
  summary: |
    解决"'技术'到底指什么"的辨析问题。柯布-道格拉斯中的α是资本总回报占产出的份额，与厂商
    最优资本/劳动配比正相关，故可视为生产技术本身的资本密集度：芯片制造α高、服装鞋帽α低。
    为清晰起见，本书把α称为"生产技术的资本密集度"，把A称为"索洛剩余"而避免叫它"技术"，
    因为A与α都是技术的表征但含义完全不同。用法：讨论"提升技术"时先说清是提升A还是选择
    不同α（产业选择）。
  tags: [资本密集度, 技术选择, 概念辨析]

- id: Bf12
  title: 资源禀赋→技术选择模型与多样化锥
  type: framework
  source_chapter: 第4讲 4.3.2节、4.3.3节
  source_quote: |
    经济对生产技术的选择与经济的人均资本存量k/l（也叫资本密集度）联系在一起。技术2的资本
    密集度较高，因而只有在全社会人均资本存量比较高的时候才会被采用……这个锥叫做多样化锥
    （diversification cone）。
  summary: |
    解决"给定资源禀赋该选什么资本密集度的技术"的问题。自由竞争下，厂商一阶条件要求两类
    技术资本回报率相等，可解出：人均资本存量低时只用劳动密集型技术，高时只用资本密集型
    技术，中间区间（多样化锥）内两技术并用且资本越丰富、资本密集型产出占比越高。把分段
    生产函数放入索洛模型做数值模拟，市场自由选择的路径产出始终不低于任何单一路径。用法：
    判断一个经济体当期的合意产业结构，就是看其人均资本存量落在哪个区域。
  tags: [技术选择, 多样化锥, 资源禀赋]

- id: Bf13
  title: 发展战略→经济绩效的传导框架（比较优势 vs 赶超）
  type: framework
  source_chapter: 第4讲 4.4.1节
  source_quote: |
    第一，如果让自由竞争的市场来选择技术，可以获得最高的经济绩效……第二，随着资源禀赋的
    变化，对经济最有利的生产技术（产业）会发生变化……第三，对一个资本密集度比较低的经济体，
    强行选择资本密集度高的生产技术会损害经济绩效。
  summary: |
    解决"发展战略如何决定经济绩效"的问题。三个结论：市场自由选择技术等价于福利经济学第一
    定理下的最优配置；随禀赋积累动态更换技术即林毅夫的比较优势发展战略；禀赋未到而强行
    赶超（优先资本密集型行业）适得其反。中国改革开放后从服装鞋帽做到家电、汽车、造船再到
    大飞机的"小步快走"是正面实践。用法：评价任何产业政策，先问它是否符合当期资源禀赋的
    比较优势。
  tags: [发展战略, 比较优势, 产业政策]

- id: Bf14
  title: 赶超战略→传统计划经济体制的内生制度逻辑链
  type: framework
  source_chapter: 第4讲 4.4.2节
  source_quote: |
    较低的人均资本存量和赶超战略是外生给定的，是逻辑线索的源头。为了调和二者之间的矛盾，
    扭曲的宏观环境、资源的计划配置制度以及对微观主体自主性的抑制相应而生。
  summary: |
    解决"传统计划体制从哪来"的制度起源问题。逻辑链：资本稀缺的小农经济 + 重工业优先赶超
    （二者矛盾）→ 人为压低利率、工资、生活必需品价格以让重工业有利润 → 压价导致稀缺流向
    失控，必须资源计划配置 → 防止私人资本流向高利润劳动密集型行业，收归国企、人民公社、
    统购统销 → 计划体制全面形成，宏观产业结构失衡+微观激励不足，绩效低下。制度安排内生于
    禀赋与战略，不是拍脑袋。用法：分析任何"政策与禀赋矛盾"（如去杠杆 vs 储蓄过剩）时，
    按同样的链条推扭曲的生成。
  tags: [赶超战略, 计划经济, 内生制度]

- id: Bf15
  title: 索洛剩余的再认识：从黑箱拆出发展战略
  type: framework
  source_chapter: 第4讲 4.5节
  source_quote: |
    如果我们不考虑产业结构的差异，而只是用一个总量生产函数去试图分解改革前后的经济增速，
    会得到什么样的结果？……这样，增长计量就会把产出的差异大部分归结于索洛剩余的变化。
    但这种索洛剩余的变化其实是经济发展战略的调整所导致的。
  summary: |
    解决"索洛剩余黑箱里到底装了什么"的问题。改革前后资本与劳动投入变化不大而产出剧变，总量
    增长计量会把差异几乎全记在索洛剩余头上；但第4讲表明这其实是发展战略（技术选择是否契合
    禀赋）的调整所致。由此得到索洛剩余的两种解读：狭义技术进步 vs 制度/战略/资源配置因素，
    二者不能混为一谈。用法：凡是用TFP解释增长差异的结论，先追问剩余里可能是战略与结构因素。
  tags: [索洛剩余, 再解读, 结构分析]
