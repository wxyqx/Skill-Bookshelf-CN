# 第5-6讲 框架候选（group C, frameworks）

- id: Cf01
  title: 持久收入假说：消费由预期的未来平均收入决定
  type: framework
  source_chapter: 第5讲 5.1.2
  source_quote: |
    消费者当期的消费并不完全决定于当期的收人，而是决定于他对自己未来平
    均收人的预期（将其定义为YP）。YP叫做持久收入（permanentincome）。
  summary: |
    解决的问题：为什么用真实数据估计不出稳定的凯恩斯消费函数。核心逻辑：把消费者
    建模为在预算约束下做跨期效用最大化（两期模型 u(C1)+u(C2)，s.t. 借贷自由转移
    资源），一阶条件推出每期消费等于持久收入 YP（预期未来平均收入）；收入可分解为
    Y=YT+YP，消费只对持久收入变化反应，不对暂时收入反应。用法：解释任何"当期收入
    变了但消费没变（或相反）"的现象时，先问当期收入变动是否改变了行为人对持久收入
    的预期；这也是判断消费刺激政策（一次性补贴 vs 永久性收入政策）效果的基础模型。
  tags: [消费函数, 预期, 跨期优化, 弗里德曼]

- id: Cf02
  title: 凯恩斯消费函数与乘数效应框架
  type: framework
  source_chapter: 第5讲 5.1.1
  source_quote: |
    政府增加1单位的开支，会通过乘数效应带来超过1单位的经济总产出之扩张。
  summary: |
    解决的问题：需求不足时产出由什么决定。核心逻辑：把凯恩斯消费函数 C=c0+c1Y 代入
    支出法 GDP 会计等式 Z=C+I+G+NX 并令 Z=Y，解出产出决定方程，自发性支出（c0+I+G+NX）
    每扩张 1 单位，产出扩张 1/(1-c1) 倍——乘数效应。用法：这是需求面分析的入门框架，
    也为政府用财政政策熨平波动提供理论依据；但按作者提醒，它建立在消费函数这一行为
    假设之上，后续会被持久收入假说与卢卡斯批判瓦解，只能作为方法论演进故事的第一环。
  tags: [乘数效应, 凯恩斯, 需求决定产出]

- id: Cf03
  title: 两个产出决定方程的适用范围框架（供给决定 vs 需求决定）
  type: framework
  source_chapter: 第5讲 5.1.1
  source_quote: |
    这两个方程分别代表了分析产出决定问题的两条不同的思路，适
    用范围不同。……只有在Y<Y时，（5.4）式才是成立的。这是凯恩斯理论的一个隐含假设。
  summary: |
    解决的问题：生产函数 Y=AF(K,L) 与需求决定方程 Y=(c0+I+G+NX)/(1-c1) 哪个对。
    核心逻辑：两者都"对"但适用域不同——用生产函数隐含假设需求不构成约束（萨伊定律），
    产出由供给决定；用需求方程的潜台词是需求不足（产出低于产出潜力），产出由需求决定。
    用法：分析任何产出问题时先判断经济处在"需求瓶颈"还是"供给瓶颈"状态，再选方程；
    这也是作者从供给面（第3-4讲）转入需求面（第5讲起）分析中国经济的转折依据。
  tags: [萨伊定律, 需求不足, 适用范围]

- id: Cf04
  title: 斯塔克伯格双寡头模型：解释统计规律为何因行为改变而失效
  type: framework
  source_chapter: 第5讲 5.3
  source_quote: |
    厂商二的行为受厂商一行为的影响。厂商一行为的改变将使以前观察
    到的厂商二的行为模式不再成立。
  summary: |
    解决的问题：菲利普斯曲线这类统计规律为什么会"用着用着就消失"。核心逻辑：厂商一
    固定产量观察厂商二，可估计出一条行为"规律"（反应方程）；但该规律只在厂商一产量
    维持不变时成立。厂商一据其求最优产量时，自身行为改变，厂商二（同为理性主体）的
    最优反应方程随之改变，旧回归方程失效。正确做法是把对方当作理性主体，代入对方的
    最优化问题求其最优反应，再做自己的决策。用法：凡是用"历史数据规律"预测"被政策
    改变了行为的经济主体"，都套用此框架检验——先问"我据此行动后，对方行为会不会变"。
  tags: [斯塔克伯格, 反应方程, 理性主体]

- id: Cf05
  title: 理性预期革命后的范式：宏观分析以人的理性为微观基础
  type: framework
  source_chapter: 第5讲 5.4
  source_quote: |
    宏观分析的基础需要构建在经济中最深层次的"不变"——也就是人的理性——之上。
    也就是说，宏观分析需要有微观基础（micro-foundation）。
  summary: |
    解决的问题：宏观变量间数量关系偶然而易变，宏观分析还能建在什么之上。核心逻辑：
    宏观经济变量间的数量关系都建立在人的行为之上、受预期影响，预期一变关系即失效；
    唯一深层的"不变"是人的理性，故宏观模型必须从微观个体的最优化问题出发构建，并在

    分析先写出各主体（居民、企业、政府）的优化问题与约束，而非直接假设总量指标间的
    关系；也是判断一个宏观论证是否"现代"的分水岭。
  tags: [理性预期革命, 微观基础, 范式]

- id: Cf06
  title: 卢卡斯批判框架：历史数据关系不能用于评估政策变化
  type: framework
  source_chapter: 第5讲 5.4
  source_quote: |
    论证说用观察到的历史数据之间的数量关系来评价经济政策调整的效果是无效的。
    如果历史数据用的是高度加总的宏观数据，则更是如此。
  summary: |
    解决的问题：为什么传统的计量政策评估（用历史回归关系推算政策效果）系统性失效。
    核心逻辑：历史数据中的统计关系内嵌于当时的政策体制与行为人预期；政策一旦改变，
    行为人预期与行为随之改变，原统计关系不再成立——高度加总的宏观数据尤其如此。因此
    政策评估必须先建立包含行为人优化与预期形成的结构性模型，再在模型内做反事实模拟。
    用法：评估任何政策（减税、刺激、调控）时，拒绝直接套用历史弹性/系数外推，先问
    "政策改变后，被影响者的预期和行为如何内生变化"。
  tags: [卢卡斯批判, 政策评估, 预期内生化]

- id: Cf07
  title: 理性人假设：把唯心问题转化为客观优化问题的方法论桥梁
  type: framework
  source_chapter: 第5讲 5.5.2
  source_quote: |
    经济学假定人都是理性的（rational），会在约束条件之内，做出对自己最有利的选择。
    这样，人的主观意识和行为这样唯心的课题，就变成了一个在客观约束条件之下的
    客观优化问题。
  summary: |
    解决的问题：人的主观意识无从捉摸，行为无法预料，经济学如何可能。核心逻辑：意识
    是黑箱，但在宽泛偏好假定（趋利避害、多多益善）下，给定客观约束条件，"什么行为
    最有利"可以用一个优化问题算出来；所有人均衡地实现最优即经济均衡。于是唯心课题
    被转化为可用唯物（自然科学）方法研究的客观问题。用法：遇到"人怎么想"不可观测的
    局面，改问"给定他的约束与偏好，什么选择对他最优"；这是全部均衡分析起点，同时
    需记住作者提醒——理性是假设与信念而非已被证明的真理。
  tags: [理性人假设, 优化问题, 均衡]

- id: Cf08
  title: 消费函数与生产函数的本质区分（卢卡斯批判的边界）
  type: framework
  source_chapter: 第5讲 5.4
  source_quote: |
    消费函数是对人的行为做出的假设。人的想法不一样，行为改
    变后，之前的假设就不再成立了。而生产函数是对不以人的主观意志为转移的生产活动
    潜力的描述。
  summary: |
    解决的问题：既然宏观统计关系都受卢卡斯批判攻击，为什么第3-4讲还敢用生产函数。
    核心逻辑：区分两类"函数"——描述人的行为的（消费函数，随预期改变而失效）与描述
    不以主观意志为转移的客观技术可能性的（生产函数描述产出潜力，与人的想法无关）。
    实际产出低于潜力时，不是生产函数失效，而是产出不由它决定。用法：对任何统计或
    结构关系先分类——"这描述的是人的行为还是自然/技术约束"；前者要加预期与微观基础，
    后者可直接作为模型约束使用。这也解释了为何供给面分析不必先讲方法论，需求面必须。
  tags: [生产函数, 行为假设, 卢卡斯批判]

- id: Cf09
  title: 单期宏观一般均衡模型（代表性居民+厂商+政府+市场出清）
  type: framework
  source_chapter: 第6讲 6.2
  source_quote: |
    均衡意味着两点——所有微观主体都达到其最优以及所有市场都出清。
  summary: |
    解决的问题：怎样把理性人假设落成可求解的宏观模型。核心逻辑：三部门设定——代表性
    消费者 max u(c,1-n^s)=log c+log(1-n^s) s.t. 预算约束（工资+利润-税收）；竞争性
    厂商 max z(n^d)^α-wn^d；政府平衡预算 t=g。均衡定义为三条件：消费者最优、厂商最优、
    市场出清（n^s=n^d 且 c=z(n^d)^α-g）。求解套路：先解各主体优化，把行为表示为价格
    w 的函数，再用出清条件解出 w 及所有内生变量。用法：这是全书一切宏观模型的母版，
    后续拉姆齐模型、货币模型都是它的跨期/引入货币扩展。
  tags: [一般均衡, 代表性主体, 市场出清]

  type: framework
  source_chapter: 第6讲 6.2.4
  source_quote: |
    宏观一般均衡模型分析一般包括三大块内容——模型设定、均衡定义以及模型求解。
  summary: |

- id: Cf11
  title: 均衡作为刻画现实的限定条件集
  type: framework
  source_chapter: 第6讲 6.3.1
  source_quote: |
    所谓均衡，就是所有人都达到了自己的最优，且所有人的最优化行为都和谐共存
    （不违反自然世界定律）的状态。……现实世界处在均衡之中。
  summary: |
    解决的问题：凭什么定义一个数学均衡就能帮我们认识现实。核心逻辑：现实世界的可能
    状态有无穷多，需要限定条件去排除——自利人组成的世界有两条件必成立：(1)所有人都
    达到最优（未达最优的状态不稳定、会被追求最优的行为改变）；(2)不违背自然规律
    （资源约束，不能无中生有）。两者合成即均衡定义；均衡是无人有动力偏离的状态，
    不均衡的现实转瞬即逝，故可观察的稳定状态必是均衡。用法：解释经济现实时，先写
    下"这个状态稳不稳定、有没有人想偏离、是否违反资源约束"，用均衡条件筛出唯一解。
  tags: [均衡概念, 刻画现实, 稳定性]

  type: framework
  source_chapter: 第6讲 6.3.2
  source_quote: |
    价格协调了不同微观主体的行为。……所以，斯密说的"看不见的手"其实就是价格机制。
  summary: |
    解决的问题：各自独立决策的微观主体如何达成协调、一般均衡求解有何现实含义。

- id: Cf13
  title: 福利经济学两大定理：均衡与帕累托最优的等价桥梁
  type: framework
  source_chapter: 第6讲 6.4.1
  source_quote: |
    福利经济学第一定理（firsttheoremofwelfareeconomics）：在完全竞争的竞争性
    市场中，均衡是帕累托最优。
  summary: |
    解决的问题：实证的"市场均衡是什么样"与规范的"应该是什么样"如何连接。核心逻辑：
    第一定理——完全竞争市场的均衡都是帕累托最优（给市场均衡提供规范支撑，反垄断、
    鼓励竞争的合理性暗含其中）；第二定理——在偏好与技术凸性下，任何帕累托最优配置
    都可通过调整禀赋分配后用竞争性均衡实现。前提是完全竞争。用法：评价一项配置或
    政策时先问"是否存在帕累托改进空间"；同时记住等价关系有条件——垄断、信息不对称
    等破坏完全竞争时两定理失效，均衡不再必然有效。
  tags: [福利定理, 帕累托最优, 规范分析]

- id: Cf14
  title: 中央计划者问题：求均衡的捷径（福利定理的应用）
  type: framework
  source_chapter: 第6讲 6.4.2
  source_quote: |
    在宏观分析中，我们经
    常会利用这种便捷性，通过求解中央计划者问题来间接求取均衡。
  summary: |
    解决的问题：逐个求解微观主体优化再联立出清条件的均衡求解太繁琐。核心逻辑：当

  type: framework
  source_chapter: 第6讲 6.5
  source_quote: |
    所谓校准，就是将模型中的参数设为符合现实世界的数值，然后观察模型产生的模拟

  summary: |
    解决的问题：卢卡斯批判之下，直接估计宏观变量间统计关系没太大意义，模型如何与

    系数等），而非逐个系数拟合；这也是 DSGE/RBC 传统的方法论基础。
