# 第5-6讲 原则候选（group C, principles）

- id: Cp01
  title: 评价政策必须内生化预期（预估民间对政策的最优反应）
  type: principle
  source_chapter: 第5讲 5.4
  source_quote: |
    而在思考宏观政策时，也会充分预估到民间对宏观政策的最优反
    应，并对这一反应在设计政策时就加以考虑。
  summary: |
    理性预期革命后的政策设计准则：政策对象是理性人，会对政策做出最优反应；政策效果
    必须把这一反应内生地纳入模型，而不是假设民间行为在政策改变后保持不变。凡是设计、
    评估政策（税收、刺激、调控），先问"被作用者会如何最优地调整自己的行为与预期"。
  tags: [政策设计, 预期, 理性反应]

- id: Cp02
  title: 宏观分析的结论不能建立在宏观变量间的数量关系之上
  type: principle
  source_chapter: 第5讲 5.4
  source_quote: |
    因此，宏观经济分析的结论不能构建在宏观变量间的数量关系之上，因
    为这些关系都是偶然而易变的。
  summary: |
    宏观变量间的统计关系（消费函数、菲利普斯曲线等）都内嵌于人的行为与预期，是偶然
    且易变的；可依赖的只有最深层的"不变"——人的理性。因此分析结论要构建在微观基础
    上：从主体的最优化问题出发推出结论，而非从回归关系出发。这条原则直接否定了
    "找到一条历史经验规律就外推"的分析方式。
  tags: [微观基础, 统计关系, 均衡方法论]

- id: Cp03
  title: 卢卡斯原则：历史数据关系不能用来评估政策调整的效果
  type: principle
  source_chapter: 第5讲 5.4
  source_quote: |
    论证说用观察到的历史数据之间的数量关系来评价经济政策调整的效果是无效的。
    如果历史数据用的是高度加总的宏观数据，则更是如此。
  summary: |
    用历史数据估计的宏观关系评估政策效果是无效的，因为政策改变会改变行为人的预期与
    行为，从而使原关系失效；数据越加总越如此。可操作的推论：政策评估必须基于结构
    模型做反事实模拟，任何"历史上政策 X 与结果 Y 相关，所以推出政策 X 会带来 Y"
    的论证都要先过这一关。
  tags: [卢卡斯批判, 政策评估]

- id: Cp04
  title: 不能把社会科学当自然科学研究（唯物/唯心鸿沟）
  type: principle
  source_chapter: 第5讲 5.5.1
  source_quote: |
    不认识到这一点，而试图将社会科学当成自然科学来加以研究的努力必然会失败。
    菲利普斯曲线的消失就是一个经典的例子。
  summary: |
    自然科学对象不受主观意志影响，归纳法有效；社会科学对象是人，主观意识同样决定
    结果——同样场景下人可能因想法不同而行为不同。故"从现象总结规律、用规律预测"
    的纯归纳方法在经济社会中必然失败，经济数据呈现的统计规律必须以有别于自然科学的
    方式理解。运用：分析经济社会时，任何归纳出的规律都要加一句"这规律依赖什么行为
    假设，行为变了它还成立吗"。
  tags: [方法论, 归纳法, 主观能动性]

- id: Cp05
  title: 内生/外生的划分取决于经济含义，是建模的第一难点
  type: principle
  source_chapter: 第6讲 6.2.1
  source_quote: |
    在分析不同问题，以及在分析同一个问题的不同层次时，弄清哪些变量是内生的、
    哪些变量是外生的很重要。这是宏观经济模型分析的难点。……变量究竟是外生的
    还是内生的，取决于其经济含义。
  summary: |
    一个变量在优化问题中是内生（主体可影响、问题内决定）还是外生（主体不能控制、
    问题外决定），不由数学而由经济含义决定。同一变量在不同主体、不同层次问题中角色
    不同：税收对消费者是外生（不能讨价还价），企业利润对消费者外生则对应"两权分离"
    的制度假设；市场价格对完全竞争厂商外生、对垄断竞争厂商内生。运用：建模出错最
    常源于此处，每写一个优化问题先列清内生与外生变量及其经济理由。
  tags: [内生变量, 外生变量, 建模]

- id: Cp06
  title: 现实世界必处于均衡：不均衡的状态转瞬即逝
  type: principle
  source_chapter: 第6讲 6.3.1
  source_quote: |
    不均衡的现实世界转瞬即逝。稳定长存的状态，也是我们能够观察到的状态，
    就一定是均衡的状态。
  summary: |
    均衡是所有参与人都无动力偏离的状态；若现实不在均衡中，必有人有动力且会去改变它。
    因此我们能观察到的稳定长存状态就一定是均衡状态——这就是用均衡分析现实世界的
    合法性来源。运用：观察到一个持续存在的经济现象（如长期消费占比偏低、长期利差）
    时，把它当均衡来解释——找出使所有主体都不愿偏离的约束与激励组合，而不是当成
    随时会被纠正的"失衡"。
  tags: [均衡, 稳定性, 分析合法性]

- id: Cp07
  title: 求解个体优化时不能预先代入市场出清条件
  type: principle
  source_chapter: 第6讲 6.3.2
  source_quote: |
    尽管在达到均衡时劳动力供需量相等，但
    在求取消费者和企业最优化问题时，不能把这个条件代人。
  summary: |
    微观主体实现理性时只考虑自己：居民提供劳动只看当前工资率下自己愿意供给多少，
    不考虑企业需要多少。供需各自的优化必须分别求解，市场出清是在第二步才施加的
    协调条件。运用：这是均衡求解的纪律——"先各自最优化、再出清协调"两步不可混；
    把均衡条件提前塞进个体优化问题，等于让主体拥有了不属于它的信息或权力，会扭曲
    结论（也常是初学者的隐蔽错误）。
  tags: [求解纪律, 个体理性, 市场出清]

- id: Cp08
  title: 帕累托最优是效率标准，不是伦理标准
  type: principle
  source_chapter: 第6讲 6.4.1
  source_quote: |
    帕累托最优不是一个伦理学的判断标准。……在把经济分析运用到其他领域的时候，
    一定要注意避免经济分析的滥用。
  summary: |
    帕累托最优只回答"还有没有不损害任何人就能改进的空间"（效率），对分配公平不做
    任何承诺——极端不平等甚至"一人独占、他人饿死"也可以是帕累托最优。福利评价
    还须引入伦理判断，经济分析不能替代。运用：听到"这个政策是帕累托改进/帕累托
    最优"时，只把它读作"有效率"，公平问题要另立标准；把经济分析用于其他领域时
    警惕其抽离人性与道德维度的局限。
  tags: [帕累托最优, 效率, 伦理边界]

- id: Cp09
  title: 理性只是假设与信念，其推论（如有效市场）不是事实
  type: principle
  source_chapter: 第5讲 5.5.2/5.5.3
  source_quote: |
    但要注意，理性只是经济学引入的一个假设，并非真理。……而只是相信这种收敛会发生。
  summary: |
    理性人假设的辩护（市场竞争淘汰非理性）中的收敛路径、时间、是否必然发生都未知，
    它是经济学家的信念；其真理性只能靠融贯论与实用论辩护（与经验信念网络一致、
    "管用"）。因此基于它的推论（如有效市场）至多是对现实的较好近似。运用：用均衡
    经济学分析时保持这一自觉——结论的可靠性与"理性近似"的成立程度绑定；涉及明显
    非理性人群或市场的场景要标注前提，勿把推论当铁律。
  tags: [理性假设, 有效市场, 方法论自觉]

- id: Cp10
  title: 非理性不能任意假设，否则理论什么也解释不了
  type: principle
  source_chapter: 第5讲 5.5.3
  source_quote: |
    如果行为偏差是可以任意假设的，那么任何可能的经济现象
    都可以用某种行为偏差来解释。但这样一来，看似能解释一切的行为经济学其实什么也
    解释不了。
  summary: |
    行为经济学之所以有意义，是因为其"非理性"仅取自大量心理学实验证实的普遍行为
    偏差，具有非任意性。任意假设行为偏差会沦为"什么都能解释"的同义反复。运用：
    用非理性解释任何现象前，先问"这个偏差有无独立证据、为何在此场景成立"；凡
    事后找偏差的说法都要警惕。作者并指出更深的道理：对非理性的最优反应是变理性，
    故知名的行为偏差会随知晓而消失——行为经济学有自我打败倾向。
  tags: [行为经济学, 可证伪性, 假设纪律]

- id: Cp11
  title: 福利定理不成立时，中央计划者捷径禁用
  type: principle
  source_chapter: 第6讲 6.4.2
  source_quote: |
    对这种模型的分析就不能再走中央计划者问题的捷径了，而只能老老实实地按步
    骤求取均衡。因为在这种情况下，均衡求解的结果与中央计划者问题的结果并不一致。
  summary: |
    中央计划者问题与市场均衡的等价由福利两定理保证；存在信息不对称等使定理失效的
    结构时，两者结果不一致，此时若仍用计划者问题求"均衡"，得到的其实是计划者最优
    而非市场均衡，会系统性高估市场效率。运用：用计划者捷径前先核对其成立条件
    （完全竞争、无外部性/信息不对称等）；条件不满足时回到"分别求解+出清"的标准
    流程。
  tags: [中央计划者, 福利定理, 适用条件]

- id: Cp12
  title: 模型的解释力以其整体数量表现与真实世界的相似性衡量
  type: principle
  source_chapter: 第6讲 6.5
  source_quote: |
    其解释力强弱应该以模
    型整体的数量表现与真实世界的相似性来衡量。也就是说，我们要以模型能否产生在宏
    观经济数据中看到的整体特征来衡量模型，而并不太看重模型的某一部分是否接近现实。
  summary: |
    一般均衡模型对应的是整个世界，评价标准是"能否复现宏观数据的整体特征"（如波动
    的标准差与交叉相关结构），而非某一局部设定或单一系数是否逼真。这决定了校准而非
    计量估计是宏观模型的对接方式。运用：构造或批评一个宏观模型时，问"它能匹配哪些
    整体特征事实"，避免陷入"某条假设不现实"的局部指责（弗里德曼式的假设无关性在此
    的模型版）。
  tags: [模型评价, 校准, 整体特征]

- id: Cp13
  title: 连消费函数都不稳定，就不能想当然认为宏观变量间存在数量关系
  type: principle
  source_chapter: 第5讲 5.1.2
  source_quote: |
    如就连一个看似简单的消费与收人之间的关
    系，都会因为牵涉了消费者的预期和行为而变得相当复杂，那么恐怕就不能想当然地认为
    宏观经济变量之间存在什么数量关系了。
  summary: |
    从"估计不出稳定消费函数"这一具体事实提炼出的元规则：任何两个宏观变量之间的
    稳定数量关系都不是默认成立的，因为关系内嵌于行为人的预期。消费与收入这个最
    简单、最符合直觉的关系尚且如此，其他关系更须逐一检验其行为基础。运用：见到
    任何"X 与 Y 的经验规律"（包括各种经济指标间的历史相关性），先问"这规律背后
    的行为假设是什么，预期变化会不会打破它"。
  tags: [消费函数, 数量关系, 警示]
