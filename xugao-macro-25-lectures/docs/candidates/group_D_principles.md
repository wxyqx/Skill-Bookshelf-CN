# 候选·原则（principle）— 第7-9讲 消费与储蓄三部曲

- id: Dp01
  title: 事实与价值判断必须分离："偏低/偏高"不等于"不足/过剩"
  type: principle
  source_chapter: 第7讲 7.1.2-7.1.3
  source_quote: |
    中国消费占比低是一个数据表现出来的事实。但是，说中国消费不足，则是一个价值判断，意味着中国当前消费占比要比中国应有的消费占比水平低。而要这么说，必须首先回答：中国消费占比应该是多少？
  summary: |
    可套用规则：在给出"应该是什么"的评价标准之前，禁止从"占比低"直接推出"不足"。
    "偏低""偏高"是数据相对于参照系的客观描述；"不足""过剩"隐含规范判断，必须先明确
    标准从何而来。适用于一切"某指标过高/过低"的宏观争论：先问参照系，再问标准，最后
    才谈改善。
  tags: [方法论, 事实与价值]

- id: Dp02
  title: 消费与储蓄是同一枚硬币的两面
  type: principle
  source_chapter: 第7讲 7.1（开篇）
  source_quote: |
    由于消费和储蓄是一个硬币的两面（消费加储蓄等于总收入），消费不足也就等价于储蓄过剩。未来我们会逐步看到，对消费不足的分析是理解中国经济的关键。
  summary: |
    可套用规则：储蓄≡收入−消费是会计恒等式，讨论消费即讨论储蓄。因此"促消费"与
    "降储蓄"是同一问题的两种说法；任何只谈其一的政策论述都应被还原到另一面检查一致
    性。推论：消费占比低⇔储蓄占比高⇔（开放经济）净储蓄为正⇔经常账户顺差，可沿恒等
    式链条追踪。
  tags: [储蓄, 会计恒等式]

- id: Dp03
  title: 私有制下，财富在居民与企业部门间的分配不影响消费与储蓄
  type: principle
  source_chapter: 第7讲 7.3.4；第8讲 8.2.1
  source_quote: |
    这是因为如果企业由居民所拥有，企业的储蓄也是居民财富的一部分。居民的总储蓄由居民的偏好及资本回报率所决定，与储蓄在企业与居民部门之间的分布无关。
  summary: |
    可套用规则（"刺穿企业帷幕"的操作化）：只要企业所有权在居民手中且企业最大化股票价
    值，收入流向哪个部门不改变居民的总消费。推论一：居民储蓄与企业储蓄在跨国数据中负
    相关；推论二：主流宏观模型假设企业每期清算、不做储蓄是"无害"简化。反向用法：一旦
    观察到居民与企业储蓄双高（如中国），立即可推断"刺穿企业帷幕"在该经济体失效。
  tags: [刺穿企业帷幕, 储蓄]

- id: Dp04
  title: 经济增长的最终目标是提升居民福利，故消费储蓄决策应由居民做出
  type: principle
  source_chapter: 第7讲 7.2.1；第9讲 9.1
  source_quote: |
    什么样的消费流能够给居民带来最高的总效用（以贴现效用和来计算），居民说了才算。所以，经济资源中多少拿来消费、多少拿来储蓄（用以增加未来的消费），应该由居民来决定。
  summary: |
    可套用规则：以居民贴现效用和为终极目标函数，则"多少收入用于消费、多少用于储蓄"
    的答案只能来自居民的跨期最优化，而非政府、企业的判断。这一原则是全书评价经济结构
    的锚：任何主体（含国企、政府）替居民做跨期配置决策，都需要特别论证其正当性。
  tags: [福利, 居民决策]

- id: Dp05
  title: 资本是否为居民所拥有是判断经济结构是否最优的标准
  type: principle
  source_chapter: 第8讲 8.3
  source_quote: |
    因此，如果我们接受经济增长是为了提升居民福利这个最终目标，那么资本是否为居民所拥有便是判断经济结构是否最优的一个标准。这是因为实现最优消费与投资比例的市场化调节机制需要建立在居民对资本的所有权之上。
  summary: |
    可套用规则：总产出被资本与劳动两种要素回报分割，劳动回报天然归居民，只有资本回报
    也归居民，居民才支配全部产出。所以检查一个经济体的收入分配结构，先查资本所有权的
    分布（谁持有企业股权、居民实际拿到多少分红）。离开居民对资本的所有权，就离开了
    "无人知道最优消费投资比例"的市场化答案。
  tags: [资本所有权, 收入分配, 评价标准]

- id: Dp06
  title: 最优消费投资比例对应跨期边际效用比与资本回报率的平衡
  type: principle
  source_chapter: 第8讲 8.3
  source_quote: |
    为了最大化消费这一序列带给消费者的总效用，消费者对不同时间消费的主观偏好与资本回报率之间需要取得平衡。这样，最优的消费与投资比例就对应着消费者跨期边际效用比与资本回报率之间的平衡。
  summary: |
    可套用规则：欧拉方程的经济含义——消费与投资配比恰当的判据是"居民愿意接受的回报
    率（主观）=投资能提供的回报率（客观）"。判断投资是否过度：比较真实资本回报率与
    居民要求回报率（可由资产价格反推）。低于则投资过度、应向居民分红转化为消费；高于
    则投资不足。这是把抽象福利标准落成两个可比比率的操作化方法。
  tags: [欧拉方程, 资本回报率, 评价标准]

- id: Dp07
  title: 储蓄是流量，财富是存量；总储蓄不等于资本存量
  type: principle
  source_chapter: 第7讲 7.1.1；第8讲 8.2.1
  source_quote: |
    要注意，全社会总储蓄并不等于第2期期初的资本存量。这是因为其中的一部分来自第1期期初的资本。储蓄等于资本的增量。储蓄是一个流量概念，而资本是一个存量概念。
  summary: |
    可套用规则：谈论储蓄时严格区分流量（本期收入中未消费部分）与存量（累积的财富/资
    本）；储蓄=资本的增量。混用流量与存量是宏观讨论常见错误（如把"居民存款余额"当作
    "当年居民储蓄"）。企业储蓄口径同理：经济分析中的企业储蓄大于会计利润，因为资本性
    开支在会计中计为成本，在经济分析中计入储蓄。
  tags: [流量存量, 储蓄口径]

- id: Dp08
  title: 资金总从净储蓄为正的部门流向净储蓄为负的部门
  type: principle
  source_chapter: 第8讲 8.2.2
  source_quote: |
    部门的净储蓄就等于该部门的净金融投资。……各个部门的净储蓄状况对应着金融资金的净流向——资金总是从净储蓄为正的部门流向净储蓄为负的部门。
  summary: |
    可套用规则：想知道资金从哪里来、到哪里去，看各部门净储蓄（总储蓄减投资）的符号；
    储蓄转移本质是实物资料转移，金融资产/负债是其对应物。国家层面同理：正净储蓄⇒经常
    账户顺差⇒对外净借出。用法：读资金流量表和国际收支表时，先用净储蓄给部门/国家定性，
    再解释资金流向，而不是从金融表象直接猜。
  tags: [净储蓄, 资金流向, 国际收支]

- id: Dp09
  title: 价格连接宏观与微观：求解模型时不能把均衡条件代入微观优化
  type: principle
  source_chapter: 第7讲 7.4.1
  source_quote: |
    在第一步中，一定不能把均衡条件代入微观主体的优化求解中。……价格联接了宏观和微观。微观主体在做决策的时候虽然只考虑自己面对的微观价格，但这些价格本身已经包含了宏观信息。
  summary: |
    可套用规则：微观主体是价格接受者，其约束只在微观层面；宏观总量（如股份总数=1）
    不是微观主体的约束。求解必须先微观优化、后宏观出清两步走。经济含义：市场主体不必
    理解宏观经济，价格已替他们汇总了宏观信息——这也是"个体理性不等于总量善"的一般
    均衡直觉。适用于一切含代表性个体的模型。
  tags: [一般均衡, 价格, 求解纪律]

- id: Dp10
  title: 理性预期不是行为假设，而是均衡应满足的条件
  type: principle
  source_chapter: 第7讲 附录7.B
  source_quote: |
    理性预期这个假设（就像"效用极大化"假设一样）并不是一个"行为假设"。也就是说，它并不试图描述人们怎样理解环境、怎样学习、怎样处理信息等这些方面。它更应该是一种结果（近似上）应该满足的性质。
  summary: |
    可套用规则（卢卡斯1978）：不要把理性预期理解为"人人都精于预测"，它是激烈竞争中
    预期错误的主体被淘汰后人群行为收敛的极限，是均衡条件。操作含义：动态模型中可以假
    设主体知道未来并据以决策，这是把"预期与未来相一致"当作均衡条件来解的取巧办法。
    相对地，静态预期（预期未来=当前）产生蛛网震荡，是应当避免的失败设定。
  tags: [理性预期, 预期形成]

- id: Dp11
  title: 储蓄回报率变动同时引发替代效应与收入效应，方向取决于孰强孰弱
  type: principle
  source_chapter: 第9讲 9.1
  source_quote: |
    储蓄回报率的上升究竟是让储蓄增加还是下降，取决于这两种效应孰强孰弱。由于从宏观经济数据中可以看到储蓄率与储蓄回报率之间的正相关关系，所以替代效应应该是占上风的——更高的储蓄回报率带来更高的储蓄率。
  summary: |
    可套用规则：分析利率变化对储蓄的影响时必须同时算两笔账——替代效应（回报高了多存）
    与收入效应（未来收入高了多花），净效应不定。经验锚点：宏观数据中储蓄率与回报率正
    相关，故通常替代效应占上风。用法：任何"降息促消费/加息促储蓄"的单向论断都要先过
    这条双重效应检查。
  tags: [利率, 替代效应, 收入效应]

- id: Dp12
  title: 离开资本市场定价，没有人（包括政府）知道恰当的分红比率
  type: principle
  source_chapter: 第9讲 9.4.1、9.5.1
  source_quote: |
    事实上，每个企业应该分红多少，只有企业所有权的竞争市场才知道。离开了这个市场，谁也不知道各个企业的分红比率应该是多少。而不知道恰当的分红比率，就更谈不上通过强制分红来推进消费转型了。
  summary: |
    可套用规则：企业该不该分红、分多少，取决于产业、生命周期与居民偏好，这些信息只有
    通过所有权竞争市场中的资产定价才能汇集。行政手段（一刀切强制分红比率）既不知道答
    案，还会遭遇信息不对称（高分红率诱发国企低报利润）。推论：凡是"由政府替市场定价"
    的资源配置方案，都要回答"政府从哪里获得定价所需的信息"。
  tags: [分红, 信息不对称, 市场定价]

- id: Dp13
  title: 居民自愿的高储蓄不应强制调整，企业强加的低消费必须纠正
  type: principle
  source_chapter: 第9讲 9.5
  source_quote: |
    如果中国的低消费完全是因为居民部门的储蓄意愿强，那么从居民福利的角度来看，不应通过政策来强制调整居民自愿选择的高储蓄。但国企所导致的低消费则会严格降低居民福利，因而有必要加以纠正。
  summary: |
    可套用规则：同样是低消费，福利含义截然不同——居民基于自身偏好选择的高储蓄是福利
    最优的一部分，政策强行压储蓄反而损福利；而企业目标偏离居民偏好导致的低消费是严格
    福利损失，应予纠正。这条原则给出政策介入的边界判据：看消费/储蓄结果是否出自居民
    自主的跨期最优化，而不是看比率本身的高低。
  tags: [福利判断, 政策边界, 消费转型]

- id: Dp14
  title: 模型无法描述其假设所排除的现象（稻田条件与"资本过剩"）
  type: principle
  source_chapter: 第8讲 8.4
  source_quote: |
    事实上，当我们利用新古典的稻田条件，假设资本的边际回报率总为正时，资本过剩（边际回报率为负）的现象甚至根本无法在模型中被描述出来。这并不代表这样的现象不会在现实世界中发生，只是这里的模型因为其所做出的一些假定，而根本无法描述这样的现象。
  summary: |
    可套用规则：在用模型下"某现象不可能发生"的结论前，先检查该现象是否被假设直接排
    除——被假设排除的"不可能"是同义反复而非发现。推论：想让模型能讨论某现象，必须放
    松排除它的假设（如讨论资本过剩须放弃稻田条件）。这是使用任何标准模型前必做的假设
    清单检查。
  tags: [模型边界, 稻田条件, 假设检查]
