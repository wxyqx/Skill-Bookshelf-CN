# 第10-11讲 框架候选（group E / frameworks）

- id: Ef01
  title: 国民收入恒等式 S-I=CA：内外失衡的桥梁
  type: framework
  source_chapter: 第10讲 10.1.3
  source_quote: |
    S-I=CA……它表明，一个国家的经常账户顺差等于这个国家国内的总储蓄减去其国内总投资。从经济道理上来讲，就是一个国家的储蓄只能拿来做投资。国内投资如果用不光国内的储蓄，那就需要把剩余下来的储蓄借给外国，从而形成经常账户的顺差。
  summary: |
    解决的问题：如何把一国国内的问题（储蓄、投资）与对外的问题（国际收支）联系起来。
    核心逻辑：由支出法 GDP 恒等式 Y=C+I+CA 变形而来。总产出减总消费即国民总储蓄 S=Y-C，故 S-I=CA。储蓄与投资都是国内概念，经常账户是对外概念，这个恒等式把两者刚性绑定：储蓄用不光必然外流，投资超储蓄必然借入。
    怎么用：诊断任何一国经常账户失衡时，先看其国内储蓄-投资缺口，而不是只盯汇率或贸易政策；这也是后续全球失衡、国际收支危机、次贷危机分析的恒等式基础。
  tags: [国民经济统计, 恒等式, 内外失衡]

- id: Ef02
  title: BOP+IIP：流量-存量配对的完整国际账户体系
  type: framework
  source_chapter: 第10讲 10.1.1-10.1.2
  source_quote: |
    描述一国对外经贸联系的最重要统计指标是国际收支平衡表（BOP）……有流量就有对应的存量统计——国际投资头寸表（IIP）……国际投资头寸表本质上是一个国家对外的资产负债表。
  summary: |
    解决的问题：如何系统地阅读一国的对外经济往来数据。
    核心逻辑：BOP 按复式记账记录一定时期内的对外收支流量，分经常账户、资本账户、金融账户三大项，加净误差与遗漏后总和为零；IIP 记录某时点的对外资产负债存量（净头寸=资产-负债）。BOP 的流量持续改变 IIP 的存量。
    怎么用：分析一国对外失衡时，流量看 BOP（逆差持续多久、多大），存量看 IIP（净头寸还剩多少缓冲），两者结合才能判断"外债是否到了不可持续"的临界点；同时注意 IIP 存量还受汇率估值影响。
  tags: [国民经济统计, 国际收支, 数据分析]

- id: Ef03
  title: 全球失衡框架：顺差国与美国的镜像结构
  type: framework
  source_chapter: 第10讲 10.2
  source_quote: |
    全球经济是一个封闭经济体。有国家存在经常账户顺差，就必定有国家存在经常账户逆差；有国家有富余储蓄向外借出，就必定有国家储蓄不足需要从外借入资源。因此，世界上必然会有国家与中国形成镜像……这个国家就是美国。
  summary: |
    解决的问题：如何理解 2000-2008 年中国、亚洲、石油输出国大量顺差而美国大量逆差的格局。
    核心逻辑：把全世界当作一个封闭经济，各国失衡必然相互抵消。顺差国向美国输出商品并借出富余储蓄，增加美国国内储蓄总供给、压低真实利率；美国以逆差和对外负债镜像地吸收这些储蓄。顺差国的国内失衡（消费不足）由此"镶嵌"进全球失衡的大图景。
    怎么用：分析任何一国外部失衡时，先找它的镜像对手方；评估失衡的可持续性要看储蓄流动的方向是否符合经济学直觉（资本应流向回报高的欠发达地区），不符合则持续性存疑。
  tags: [全球失衡, 镜像分析, 开放经济]

- id: Ef04
  title: 过剩储蓄假说（伯南克 saving glut）的徐高版改造
  type: framework
  source_chapter: 第10讲 10.2-10.3
  source_quote: |
    当中国由于国有部门的大量存在而有过剩储蓄时，这些过剩储蓄的一部分就会流向别国，并压低全球的资本回报率（真实利率）。因此，我们就看到了资本从相对不发达的国家流向发达国家，并伴随全球利率水平的走低。
  summary: |
    解决的问题：为什么资本会从发展中国家流向发达国家——这个与经济直觉相反的现象。
    核心逻辑：伯南克 2005 年提出全球储蓄过剩压低美国利率、催生泡沫。徐高把储蓄过剩的根源进一步推进到企业所有制结构：本国存在不分红的企业部门（刚性储蓄者），居民拿不到企业储蓄的收益，导致消费不足、储蓄过剩；开放后过剩储蓄外溢，压低全球利率，形成"发展中国家补贴发达国家"的格局。
    怎么用：解释低利率环境、贸易顺差、资本外流时，从国内收入分配/所有制结构找根源，而不是停留在汇率或贸易政策层面。
  tags: [过剩储蓄, 全球失衡, 企业所有制]

- id: Ef05
  title: 开放两期一般均衡模型（本国+外国）
  type: framework
  source_chapter: 第10讲 10.3
  source_quote: |
    假设世界上就存在两个国家：本国与外国。本国中存在一个不由消费者所拥有的企业部门……而外国的企业部门则完全由外国居民部门所拥有（外国是一个私有制的市场化经济）。本国与外国之间的劳动力不能自由流动，但资本可以。
  summary: |
    解决的问题：如何在严格的一般均衡框架下模拟全球失衡（跨国资本流动）。
    核心逻辑：两期模型，两国生产技术与劳动禀赋相同，仅企业所有制不同（本国企业不分红、追求规模最大化，是刚性储蓄者）。均衡时国际资本市场出清（b+b*=0），第 2 期两国资本回报率相等，故两国第 2 期资本存量相等。本国企业掌握的初始资本份额 θ 越大→本国消费越低、全球利率越低、本国向外借出资本越多、本国福利越低而外国福利小幅提升。
    怎么用：第 9 讲封闭模型的直接拓展；通过调节 θ 做数量模拟，把"企业不分红"这一制度细节变成可计算的外部失衡来源；也是第 11 讲引入"国际支付工具"的底座。
  tags: [一般均衡, 两期模型, 数量模拟]

- id: Ef06
  title: "国际支付工具"Z 的拓展模型
  type: framework
  source_chapter: 第11讲 11.1.2
  source_quote: |
    现在我们假设，在第2期期初，外国获得了Z的"国际支付工具"（而非产品），可以用来支付其外债……Z只是国际支付工具，不是产品。因此，我们还需要假设 Z≤[1+AF(k0,L)][1+AF(k1,L)]θk，即支付工具的总量不超过本国厂商手中将会在第2期期末灭失的产品量。
  summary: |
    解决的问题：现实中美国用"印出来的纸片"（美元）而非真实产品偿债，原模型无法刻画，需要拓展。
    核心逻辑：外国第 2 期获得 Z 的支付工具用于偿债（受物理约束：Z 不超过本国企业将灭失的产品量）。Z 越大，外国第 1 期借入越多、消费越高、福利提升越大；本国福利小幅受损。Z 可分别赋值为：资产价格泡沫预期、美元（储备货币）、纸黄金，一个装置解释三类现象。
    怎么用：这是全书少见的"一鱼三吃"式建模：同一个数学结构，换 Z 的内涵就得到资产泡沫理论、国际货币体系理论和危机理论，示范了模型复用的方法论。
  tags: [模型拓展, 国际支付工具, 美元]

- id: Ef07
  title: 资产价格泡沫的形成与破裂机制
  type: framework
  source_chapter: 第11讲 11.2
  source_quote: |
    当一国居民存在本国资产价格泡沫预期时，会基于这种预期做出乐观的消费路径设计，并通过在国际资本市场更多借入债务来提升其当前的消费水平。而在资产价格泡沫预期破裂之后……反而会因为需要偿付其国际债务而大幅降低消费。
  summary: |
    解决的问题：资产价格泡沫如何产生，以及为什么泡沫破灭的代价比从未有泡沫更大。
    核心逻辑：把 Z 解读为泡沫预期（如房产资本利得）。预期存在时，外国居民设计更高消费路径并借入更多国际资本；泡沫破裂后预期资本利得消失，只能用消费品还债，第 2 期消费降到比"从没有泡沫"时更低。数量结果：泡沫期效用最高，破灭后效用低于无泡沫基准——"前高后低"。
    怎么用：判断一国（或居民部门）的乐观消费/借贷是否建立在尚未实现的资产增值预期上；该模型是国际经济学"突然停止"理论的简化版，可用来预判资本流入骤停的后果。
  tags: [资产价格泡沫, 突然停止, 预期]

- id: Ef08
  title: 国际收支危机模型：外债累积—被动抽贷—急剧调整
  type: framework
  source_chapter: 第11讲 11.3
  source_quote: |
    经常账户逆差是一个流量概念。这个流量的逆差会导致这个国家资产负债表的恶化，表现为该国国际投资头寸表中净头寸……的下降。而如果经常账户逆差持续的时间比较长，该国就会有比较多的对外负债。而对外负债终究要用本国的产出来还。
  summary: |
    解决的问题：国际收支危机的本质与爆发条件是什么。
    核心逻辑：Y-(C+I)=CA，内需超过产出（投资超过储蓄）→经常账户逆差→IIP 净头寸持续恶化→外债累积。还债时必须压缩内需、制造富余储蓄；若债权人抽贷使调整被迫在短期内剧烈发生，就是国际收支危机。泡沫兴起-破裂只是诱因之一，任何原因造成的过度外债都可能引爆。
    怎么用：诊断一国危机风险：先看储蓄-投资缺口是否长期为负，再看外债存量与偿付能力；危机的实质是"外债太多而不可持续"，货币大幅贬值只是表象。
  tags: [国际收支危机, 外债, 流量-存量]

- id: Ef09
  title: 欧债危机的重诊断：表现为主权债务危机的国际收支危机
  type: framework
  source_chapter: 第11讲 11.3.3
  source_quote: |
    欧元区内部的失衡有两个重要原因：欧元区内部竞争力差异的扩大，以及欧洲边缘国家借债冲动的增加。而这两点都与欧元区的成立有直接关系……核心国家生产，欧元区边缘国家消费。核心国家相应累积起了对边缘国家的大量债权。
  summary: |
    解决的问题：为什么债务负担不算最重的国家（西班牙国债占 GDP 仅 70%，低于德国）反而危机最惨烈。
    核心逻辑：欧元区内部复制了全球失衡——德国等核心国家顺差、边缘国家逆差，互为镜像。两个机制：统一货币使德国成本优势不再被本币升值抵消；欧元降低边缘国家借债成本，借来的钱未投入制造业而支撑高消费与房地产泡沫。次贷危机冲击欧洲银行、资本流动链条中断→民间危机传导为政府债务危机；边缘国家已无独立货币主权，无法多发货币偿债。
    怎么用：遇到"主权债务危机"标签时，先检验是否实为国际收支危机（看经常账户与 competitiveness），再看货币主权是否完整，这决定危机的化解路径。
  tags: [欧债危机, 国际收支危机, 货币联盟]

- id: Ef10
  title: 过度特权框架：美国为何不受国际收支危机约束
  type: framework
  source_chapter: 第11讲 11.4.1
  source_quote: |
    美国可以用自己的货币支付进口、偿还外债，从而不会发生国际收支危机——因此美国是唯一不会面临外部调整压力的贸易逆差国……而美国要让其货币流向全世界，就必然会在经常账户下持续有逆差——美国不是无偿地把美元交给其他国家的。
  summary: |
    解决的问题：为什么全球失衡中只有美国能长期大规模逆差而不爆发危机。
    核心逻辑：美元是全球主要储备货币（COFER 数据超 60% 外储为美元），美国以本币借外债，永无无法偿付之虞；但美元要流向世界，必须用美元换回产品和服务，即持续经常账户逆差，对应国内消费过剩、储蓄不足。这就是"过度特权"（exorbitant privilege），凸显国际货币体系弊端。顺差国借钱给美国、美国买顺差国产品，各取所需，顺差国并非"冤大头"。
    怎么用：判断一个逆差国的危机风险前，先问它是否储备货币发行国；分析全球失衡时把国际货币体系地位作为结构性变量而非背景板。
  tags: [过度特权, 储备货币, 全球失衡]

- id: Ef11
  title: 次贷危机的宏观再解释：全球失衡收缩的传导链
  type: framework
  source_chapter: 第11讲 11.4.2
  source_quote: |
    可以说，次贷危机是因美国房地产泡沫破灭所引发的金融危机。次贷危机令美国非金融私人部门加杠杆的进程快速逆转为去杠杆，美国国内需求因而明显走低，美国经常账户逆差随之减小，全球失衡相应急剧收缩。
  summary: |
    解决的问题：次贷危机为何不只是美国国内的金融故事，为何会重创中国等顺差国。
    核心逻辑：金融逻辑只讲一半（房价下跌→次贷违约→衍生品崩塌→雷曼倒闭）；另一半是宏观逻辑：顺差国富余储蓄流入美国→压低利率、支撑美国私人部门加杠杆（美国经常账户逆差与非金融私人部门债务增量高度相关）→房价回落刺破泡沫→去杠杆→逆差收缩→全球失衡收缩→顺差国外需骤减。次贷危机由此成为全球失衡从扩张到收缩的分水岭。
    怎么用：分析全球性危机时，把金融部门的导火索与跨国储蓄流动的放大器分开讲；评估一国外需风险要看其主要逆差对手方的杠杆周期。
  tags: [次贷危机, 全球失衡, 去杠杆]

- id: Ef13
  title: 危机前后的中国增长逻辑切换：外需引擎→内需（政策）引擎
  type: framework
  source_chapter: 第11讲 11.4.2
  source_quote: |
    在危机之前，外需是中国经济增长的重要引擎。而在危机之后，内需（尤其是投资）成为经济增长的主引擎。与外需不同，国内投资高度受国内宏观政策影响。于是，次贷危机之后中国经济形势对国内政策高度敏感，呈现出"政策市"的局面。
  summary: |
    解决的问题：次贷危机如何改变中国宏观运行的结构，为什么此后中国对政策高度敏感。
    核心逻辑：危机前中国富余储蓄输出美国，换成外需回来，支撑过热增长；危机后这条循环中断，富余储蓄留在国内，由"四万亿"等政策刺激转化为国内投资，同时推升内债更快累积，引发债务持续性担忧。增长引擎的切换决定了宏观经济波动来源从外部周期变成国内政策周期。
    怎么用：研判中国宏观形势时，先定位当前处于哪一种引擎格局；解读"政策市"现象需回溯到储蓄出口中断这一结构性变化。
  tags: [中国宏观, 外需, 政策市]
