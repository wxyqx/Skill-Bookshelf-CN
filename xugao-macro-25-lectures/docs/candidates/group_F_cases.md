  title: 中国政府"四本账"与广义财政收入规模
  type: case
  source_chapter: 第12讲 12.1.1
  source_quote: |
    如果把公共财政收人和其他三项收人加在一起（不考虑其中的重复计算问题），中国政府收人占GDP的比重就从只考虑公共财政的21%上升到了广义的约35%。
  summary: |
    绑定主题：研究财政政策先认识对象（原则"研究第一步是认识研究对象"）。中国财政
    不止公共财政一本账，还有政府性基金（土地出让收入占其近4/5）、社会保险基金、
    国有资本经营三本账；2016年公共财政收入16.0万亿（占GDP约21.5%），广义口径约
    35% GDP。方法论要点：跨国财政比较若只看公共财政口径会系统性低估中国政府规模；
    且账目间有调入调出的重复计算，不可简单相加——度量口径的选择本身就是分析结论的
    一部分。
  tags: [中国财政, 度量口径, 广义政府]

- id: Fc02
  title: 国企利润上缴率极低与地方政府融资平台（LGFV）
  type: case
  source_chapter: 第12讲 12.1.1
  source_quote: |
    2016年中国国有企业总资产超过120万亿元，其中所有者权益约为40万亿元。而这40万亿元的国有企业股权仅带来了2609亿元的国有资本经营收人，回报率算下来大概只有0.6%。
  summary: |
    绑定主题：政府与国企的关系不是完全市场意义的股东-企业关系，财政边界因此模糊。
    40万亿所有者权益只产生0.6%的国有资本经营收入，因为利润大头留在国企内部；次贷
    危机后地方又设立大量LGFV筹资搞基建，行政色彩更重。方法论要点：把国企收支也算
    进政府收支的话，广义财政比35%还要高得多——判断"政府规模"与"财政政策"必须
    先界定政府边界，这是"认识研究对象"原则在制度维度的延伸。
  tags: [国企, 融资平台, 政府边界]

  type: case
  source_chapter: 第12讲 12.1.2
  source_quote: |
    2011年欧债危机爆发后，欧洲边缘国家因为来自德国等欧元区核心国家的压力，被迫紧缩其财政政策来削减国债。这样的政策加重了这些国家的经济下行压力，引发了这些国家民众的极大不满。
  summary: |

    危机前靠外国银行信贷支撑增长，危机后民间信贷收缩，政府本应扩张财政对冲资本
    流入减少，却因债务压力被迫紧缩——财政从稳定器变成放大器，下行压力加重。方法论
    要点：稳定器功能不是自动保证的，财政空间与外部融资约束会逆转政策方向；判断
    财政政策要先看它顺周期还是逆周期。

- id: Fc05
  title: 中国以间接税为主体的税制结构及其累退性
  type: case
  source_chapter: 第12讲 12.1.1
  source_quote: |
    在中国，间接税是税收的大头。……企业所得税和个人所得税合起来只占24%，还不到增值税这一种间接税所占的比例（29%）。如果把关税等其他间接税加上，中国间接税占总公共财政收人的比重超过一半。
  summary: |
    绑定主题：最优税收与税制结构的收入分配含义。间接税易征收，故发展中国家以间接
    税为主；但间接税累退（穷人税负占收入比重高于富人），不利收入分配调节。2016年
    中国增值税一项占29%，超过所得税合计24%。方法论要点：把"征管能力—税制结构—
    分配后果"连成一条因果链，是"认识对象→提出问题"工作规程的示范；中国消费不足
    的分配根源与此税制特征相互印证。
  tags: [税制结构, 间接税, 收入分配]

- id: Fc12
  title: 美国奥肯法则与失业率-通胀率的顺时针螺旋
  type: case
  source_chapter: 第14讲 14.3
  source_quote: |
    如果用美国1950一2017年的年度数据来估算，美国的失业率每下降1个百分点，对应的美国的产出缺口上升约0.8个百分点。这一关系被称为奥肯法则（Okun's law）。
  summary: |
    绑定主题：总供给曲线到菲利普斯曲线的转换桥梁及其美国验证。1950-2017年美国
    数据给出奥肯法则系数约0.8（R²=0.45），把产出缺口映射为失业率缺口，从而把
    总供给曲线翻译成附加预期菲利普斯曲线；美国失业率-通胀率平面上清晰可见的顺时针
    螺旋，验证了"预期上调使菲利普斯曲线上移"的机制。方法论要点：经验规律（奥肯）
    与理论机制（预期调整）分工——前者提供数量桥梁，后者解释曲线为何移动。
  tags: [奥肯法则, 顺时针螺旋, 美国数据]

  type: case

  summary: |
