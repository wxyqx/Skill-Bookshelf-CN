# 候选·原则（principle）— 第12-14讲 财政政策与货币经济

- id: Fp01
  title: 财政支出乘数大于1，税收乘数小于0
  type: principle
  source_chapter: 第12讲 12.3
  source_quote: |
    由上式可以看出，财政支出每增加1元钱，经济的总产出会增加超过1元钱（增加1/(1-c)元）。这便是财政支出的乘数效应。……税收乘数是 -c/(1-c)。
  summary: |
    在边际消费倾向 0<c<1 的凯恩斯交叉模型中：支出乘数=1/(1-c)>1，税收乘数
    =-c/(1-c)（绝对值小于支出乘数，因为减税只有 c 比例进入消费）。例如 c=0.6 时
    支出乘数2.5、税收乘数-1.5。使用前提是经济存在闲置资源（供给非瓶颈）。
  tags: [财政乘数, 凯恩斯, 可套用规则]

- id: Fp02
  title: 财政政策有效性由产能闲置程度决定
  type: principle
  source_chapter: 第12讲 12.5
  source_quote: |
    经济越接近充分就业，产能利用率越接近常规水平，李嘉图等价对财政政策的约束就越明显，财政政策就越不容易发挥效果。相反，经济如果越是偏离充分就业水平，经济中越是存在资源的闲置……财政政策就越是有效。
  summary: |
    凯恩斯与李嘉图不是对错关系，而是适用域不同：资源越闲置，经济越接近凯恩斯假设，
    乘数越真实；产能利用率越接近常态，居民越会把财政扩张预期为未来税负，李嘉图
    约束越紧、挤出效应越强。裁决两派的操作指标就是偏离充分就业的程度。次贷危机后
    全球产能过剩故财政呼声高；中国因消费不足造成长期产能过剩，财政政策成为稳增长的
    关键工具。
  tags: [财政乘数, 李嘉图等价, 适用边界]

- id: Fp03
  title: 财政盈余顺周期，财政政策天然是逆周期稳定器
  type: principle
  source_chapter: 第12讲 12.1.2
  source_quote: |
    一般来说，一个国家的财政盈余是顺周期的（pro-cyclical）——经济增速快时财政盈余较多，经济增速慢时财政盈余较少。也可以把这种状况说成是逆周期的财政政策（counter-cyclical fiscal policy）。
  summary: |
    判断财政立场的规则：财政盈余（赤字）顺周期变化=财政政策在逆周期调节。收入侧
    顺周期（税基随景气扩张），支出侧逆周期（衰退期补贴自动增加），两者叠加使盈余
    顺周期。政府可主动放大这一稳定器（衰退期加码支出），也可反向操作（衰退期紧缩
    =顺周期政策，加重下行，如欧债危机后边缘国）。
  tags: [财政政策, 顺周期, 稳定器]

- id: Fp04
  title: 政府债券不是净财富（巴罗之问）
  type: principle
  source_chapter: 第12讲 12.4.6
  source_quote: |
    居民会内生化政府的预算约束，从而清楚地知道自己持有的政府债券未来都是要靠自己多缴纳的税款来偿付的。因此，居民并不会把持有的政府债券视为净财富。
  summary: |
    回答"政府发债越多、民间财富越多、经济越好吗"：否。理性居民把政府预算约束纳入
    自己的决策，国债只是未来税负的另一种记法；持有债券增加的当期"资产感"会被未来
    增税预期精确抵消，消费与储蓄决策不变（李嘉图等价的推论）。成立前提是理性预期、
    非扭曲税制、政府长期预算平衡。
  tags: [李嘉图等价, 国债, 净财富]

- id: Fp05
  title: 边际消费倾向由对未来收入的预期决定，无法可信估计
  type: principle
  source_chapter: 第12讲 12.5
  source_quote: |
    决定边际消费倾向的关键因素是消费者对未来收入的预期。这个预期的维度显然是凯恩斯理论所没有考虑到的。当然，这不仅仅是凯恩斯理论的问题，也是所有理性预期革命之前的宏观理论的问题。
  summary: |
    凯恩斯乘数的关键参数 c 不是稳定常数：消费者若认为收入变化是暂时的（持久收入
    假说），消费几乎不反应，c 估计值很小；若认为是永久性的，消费敏感，c 很大。
    因此大量文献得不到令人信服的 c 估计值——这一努力注定徒劳。任何依赖"边际
    倾向"类行为参数的政策测算，都必须先问预期维度（暂时 vs 永久）。
  tags: [持久收入, 边际消费倾向, 预期]

- id: Fp06
  title: 理论不完善不代表现实问题不存在（长颈鹿原则）
  type: principle
  source_chapter: 第12讲 12.5
  source_quote: |
    我记得曾经读到，人们现在仍然不完全明了长颈鹿是怎样把足够多的血液一路向上输送到它的头部的。但是，很难想象有人会因此得到结论说长颈鹿没有长脖子。
  summary: |
    索洛名言，经作者升格为原则：不能因某现象尚无严密理论刻画就否认现象本身。凯恩斯
    乘数虽不符合理性预期标准，但财政乘数显著非0的经验事实不因此消失。配套表述是
    "理论只是渡河之舟"——学习目的是获得直达本质的穿透力，选合适的船，而不是上了
    某条船就被它带向任意方向。
  tags: [方法论, 理论与现实, 索洛]

- id: Fp07
  title: 扭曲性税收有净福利损失，一次总付税没有
  type: principle
  source_chapter: 第12讲 12.4.2, 附录12.A
  source_quote: |
    这种会改变经济主体对价格的认知的税收就叫做扭曲性税收（distortionary tax）。相反，一次总付税并不改变价格信号，而只是带来收人分配的变化，因而并不会因为扭曲经济主体的行为而产生福利损失。
  summary: |
    税收分类的判定标准是"是否改变主体感知的相对价格"：一次总付税只转移收入，价格
    信号不变，无谓损失为0；从价税改变回报率或商品价格，引发行为偏离，私人损失超过
    政府收入，产生净损失（附录算例：同样征0.5单位，从价税需100%税率，福利损失0.69
    大于税收0.5）。
  tags: [税收, 扭曲, 无谓损失]

- id: Fp09
  title: 引入新因素不推翻旧结论，研究要有继承性
  type: principle
  source_chapter: 第12讲 12（开篇）
  source_quote: |
    在模型中引人新的因素尽管会带来新的逻辑线索，但并不会让我们之前得到的结论失效。我们在收获了新的答案之后，也没有必要扔掉老的答案。……而不是像猴子玉米一样看到一个新现象就跳到一个新的逻辑体系中。
  summary: |
    知识增长的方式：新模型是老模型的扩展而非替换——把货币、财政引入拉姆齐框架后，
    老结论（如消费储蓄的决定）在更大范围内仍然成立，新因素只在其起作用的边界上
    修正结论。反对"逐新癖"：见一个新现象就换一套逻辑体系，等于没有积累。
    操作上：新分析完成后应回头检查老结论哪些保留、哪些被修正、修正的条件是什么。
  tags: [方法论, 知识继承, 模型扩展]

- id: Fp10
  title: 纸币的价值来自政府命令；货币由银行体系无中生有创造
  type: principle
  source_chapter: 第13讲 13.1.1, 13.2
  source_quote: |
    纸币的价值并非来自它本身——纸币不过是一些用很低的成本就能印制出来的彩色纸片而已——而是来自政府规定将其作为支付工具的命令。……当银行向非金融企业和居民发放贷款时，货币就从无到有地产生了出来。
  summary: |
    两条关于货币本性的事实性原则： fiat money（法定货币）的价值基础是政府命令而非
    内在价值；现代货币主体是存款，由银行发放贷款、购买债券、购入外汇等业务在会计
    上"无中生有"地创造（贷款即存款），故M2增量≈贷款+债券融资+外汇占款增量。
    分析货币问题时先分清"央行基础货币"与"银行体系创造的广义货币"。
  tags: [法币, 货币创造, 银行体系]

- id: Fp11
  title: 真实利率由资本回报率决定，货币只影响名义利率
  type: principle
  source_chapter: 第13讲 13.4.2
  source_quote: |
    真实利率r2是由实体经济中资本的回报率所决定的，与货币无关。货币能影响的只是名义利率R2，而且是通过通货膨胀率对名义利率产生间接影响的。
  summary: |
    利率决定的分工规则：r=MPK（实体经济），R=r+π^e（费雪方程，货币经由预期通胀
    进入）。推论：判断货币政策松紧不能只看名义利率——高名义利率可能只反映高通胀
    预期而真实利率很低。费雪方程中的通胀是预期（前瞻）概念，现实中用过去通胀替代。
  tags: [费雪方程, 利率, 货币政策]

- id: Fp12
  title: 微观预算约束与宏观资源约束是两个层面的账
  type: principle
  source_chapter: 第13讲 13.3.5
  source_quote: |
    前者是微观层面居民的预算约束，后者是宏观层面消费品总量的约束式，是站在不同层面考虑的不同问题，故前者包含m1，而后者不包含。
  summary: |
    加总时的层面纪律：居民个体的预算约束里，货币是资产、可以买消费品，必须出现；
    但站在全社会看均衡，货币的使用只是消费品在居民间的再分配，不增加消费品总量，
    故宏观资源约束不含货币存量。混淆两个层面会凭空"造出"或"漏掉"财富。
    用法：任何加总（货币、债务、资产）都要问：这个量在个体层面是真实的，在总量
    层面还是不是？
  tags: [加总, 均衡分析, 层面区分]

- id: Fp13
  title: 关注真实货币存量，不要被名义货币蒙骗
  type: principle
  source_chapter: 第13讲 13.4.3
  source_quote: |
    它告诉我们真正重要的是真实货币存量，而不是名义货币存量。……研究货币时不要被名义货币蒙骗而产生幻觉，而要看到用价格缩减后的真实货币存量才是需要关注的关键。
  summary: |
    货币分析的单位规则：一切与福利、购买力相关的判断都应以 M/P（价格缩减后的货币
    存量）为准。名义量可以完全误导——通缩中名义货币减少但真实货币存量反而增加
    （价格跌得比货币快）。与弗里德曼最优货币数量互为表里：名义利率为0时真实货币
    存量趋于无穷大。
  tags: [真实变量, 货币幻觉, 单位选择]

- id: Fp14
  title: 最优货币数量不可行，现实央行以温和通胀为目标
  type: principle
  source_chapter: 第13讲 13.4.3
  source_quote: |
    真实世界中没有任何一个国家以最优货币数量为货币政策调控目标。……各国中央银行往往以温和的通货膨胀（每年物价上涨2%）为货币政策调控目标。这样既不会因过高的通货膨胀而损失福利，又与通货紧缩留出了一定的安全距离。
  summary: |
    理论最优（名义利率0、负通胀）与现实目标的差距给出操作规则：央行目标应是与通缩
    保持安全距离的温和正通胀（约2%）——既避免高通胀的福利损失，又避开通缩下的
    价格下调刚性、债务实际负担加重等陷阱。"不是通胀越高越好，也不是越低越好"。
  tags: [通胀目标, 弗里德曼规则, 政策实践]

- id: Fp15
  title: 效用函数不可随意更改
  type: principle
  source_chapter: 第13讲 13.2
  source_quote: |
    经济分析一般都不会改动效用函数，而只会用几种常用形式。原因很简单，只要选用了不同的效用函数，我们便能解释我们想解释的一切。但这实际上什么也解释不了。所以，凡是要更改效用函数的形式，都必须有非常合理的解释。
  summary: |
    建模纪律：偏好是经济分析的基石，效用函数形式决定一切结论；若允许随意改写，任何
    结果都能"解释"，模型便丧失内容。规则：效用函数取标准形式；确需改动（如MIU
    把货币放进效用）必须给出独立的微观故事（货币节省搜寻时间=闲暇）。可用于审稿式
    检验：任何模型若靠非常规偏好才得出结论，其说服力就要打折。
  tags: [建模纪律, 效用函数, 方法论]

- id: Fp16
  title: 宏观供需曲线中的价格是总体价格水平，不是相对价格
  type: principle
  source_chapter: 第14讲 14.1
  source_quote: |
    宏观供给曲线中的价格是以货币计价的"总体价格水平"，而非商品间的"相对价格"。宏观供需分析中讨论的是经济的真实总供给及总需求与总体价格水平之间的关系。
  summary: |
    概念 hygiene 规则：微观供需曲线的纵轴是相对价格（必然向上倾斜），宏观总供给
    曲线的纵轴是总体价格水平，两者不能互相推导。宏观曲线的形状（垂直还是倾斜）是
    关于价格灵活性与货币中性的实质判断，不是几何直觉。
  tags: [总供给曲线, 相对价格, 概念区分]

- id: Fp17
  title: 货币政策对实体的影响来自超预期，短期有效长期无效
  type: principle
  source_chapter: 第14讲 14.3
  source_quote: |
    货币政策对于实体经济的影响来自"超预期"。但民众不会永远被货币政策所欺骗。货币政策对实体经济的短期"有效"终将被长期"无效"所取代。
  summary: |
    附加预期菲利普斯曲线的直接推论：产出缺口取决于 π-π^e（通胀超出预期的部分），
    故货币刺激的效力=民间被"愚弄"的程度；预期一旦调整到位（π=π^e），产出回到
    自然水平，回到货币中性。政策含义：靠持续宽松维持超潜在增长不可能，只会累积
    通胀。
  tags: [理性预期, 货币中性, 菲利普斯曲线]

- id: Fp18
  title: 央行应只盯通胀，捆住自己的手脚反而福利更高
  type: principle
  source_chapter: 第14讲 14.4
  source_quote: |
    尽管货币政策在短期内有影响实体经济的能力，但决策者不应该动用这种能力，而只应把货币政策调控的目标聚焦在稳定通货膨胀上面。甚至，决策者还要捆住自己的手脚，让自己没有能力通过货币政策来刺激经济，这样反而能够获得更高的社会福利水平。
  summary: |
    动态不一致理论给出的规范结论：有能力≠应该用。保留相机刺激权位的央行会被理性
    公众预期出通胀偏差，结果产出不变、通胀更高；可信承诺零通胀（或低通胀）反而
    福利更高。实现方式：通胀目标制、央行独立性、鹰派行长声誉。注意适用边界：面对
    外生冲击仍需政策对冲平滑波动，约束不等于不作为。
  tags: [动态不一致, 承诺机制, 货币政策]

- id: Fp19
  title: 基于生产技术的关系不受卢卡斯批判（奥肯法则）
  type: principle
  source_chapter: 第14讲 14.3
  source_quote: |
    奥肯法则是基于生产函数的，反映的是劳动力这种投人要素与产出之间的关系。这种关系不因人的行为的改变而变化，因而不会受到卢卡斯批判的影响。
  summary: |
    区分两类经验规律能否用于政策评估的标准：奥肯法则（失业-产出缺口）基于生产函数
    的技术关系，行为变化动不了它，可放心使用；而菲利普斯曲线原始形式这类依赖主体
    预期与行为的数量关系，政策一变即失效。判据：关系式里是否含有可通过政策改变
    的行为参数（预期、边际倾向）。
  tags: [卢卡斯批判, 奥肯法则, 经验规律]

- id: Fp20
  title: 现代货币政策是调控预期的艺术：清晰沟通取代出其不意
  type: principle
  source_chapter: 第14讲 14.4
  source_quote: |
    央行传统的、神秘主义的、追求出其不意的货币政策调控思路，已经让位于通过清晰沟通来主动引导市场预期的现代调控方式。带来这一转变的，就是这一讲中所介绍的现代货币政策理念。
  summary: |

    利率并列的两大政策工具之一。判读央行行为时，声明与沟通本身就是政策操作。
