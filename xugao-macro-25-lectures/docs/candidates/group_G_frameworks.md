- id: Gf01
  title: 货币政策传导两环节路径图（央行→商业银行→实体）
  type: framework
  source_chapter: 第15讲 15.1.1节
  source_quote: |
    货币政策传导包含两个主要环节——从中央银行到商业银行体系的第一环节，以及从商业银行
    体系到实体经济的第二环节。……当前的商业银行实行的都是部分准备金制度。
  summary: |
    解决"央行投放的货币如何变成企业与居民手里的钱"的问题。核心逻辑：央行是货币的终极
    创造者，但只把基础货币直接投放给商业银行体系；商业银行在部分准备金制度下，以基础
    货币为"种子"按货币乘数（1/RRR）数倍放贷，创造广义货币（企业与居民存款）；实体
    经济再用这些存款完成支付循环。用法：分析任何货币政策（降准、再贷款、公开市场买入）
    时，先定位它作用在哪个环节、改变的是基础货币还是货币乘数，再判断它对实体融资的
    传导是否顺畅。这也是后续市场分割分析的"地图"。
  tags: [货币政策, 货币创造, 基础设施级框架]

- id: Gf02
  title: 银行资产负债表货币创造分析法
  type: framework
  source_chapter: 第15讲 15.1.1-15.1.3节
  source_quote: |
    央行发放贷款的同时就创造了存款。……商业银行的贷款直接创造了存款。而存款就是企业
    可以用来支付的货币。所以商业银行就创造了实体经济中的货币。
  summary: |
    解决"货币从哪里来、一笔支付对银行体系意味着什么"的问题。核心逻辑：全部用 T 型资产
    负债表追踪——央行放贷款即凭空创造商业银行在央行的存款（基础货币）；商业银行放贷
    即凭空创造企业存款（广义货币）；储户提现消耗超额准备金；银行间存款转移只改变超额
    准备金在银行间的分布、不创造货币。用法：判断任何金融操作（提现、跨行支付、降准、
    结汇）对资金面的影响时，逐笔画资产负债表变化即可，无需凭直觉猜测；这也是理解
    "超额存款准备金是经济终极支付工具"和钱荒机制的操作性基础。
  tags: [货币创造, 资产负债表, 分析工艺]

- id: Gf03
  title: 市场分割模型（CIA两期模型与流动性效应的生成机制）
  type: framework
  source_chapter: 第15讲 15.3节
  source_quote: |
    这里有一个至关重要的假设——居民在选择好了F之后，无法再对其进行调整。也就是说，
    居民在一开始决定好了现金在金融资产和消费品之间的分配比例后，不管情况如何变化都不
    能再改变。
  summary: |
    解决"为什么央行增发货币有时压低而非推高名义利率"的理论问题（费雪方程式与现实
    落差）。核心逻辑：居民须在货币增量（μ）实现之前把现金不可逆地分配到消费品市场和
    金融市场（两个CIA约束）；增量货币只进入金融市场，货币超预期时金融市场货币富集、
    其CIA乘子λf下降（约束更松弛、影子价格更低），导致名义利率被压到费雪方程式水平
    之下、名义股价被推高。用法：把"市场分割程度"操作化为两个CIA乘子之差（λf−λm），
    凡是货币在经济中非均匀分布且短期不可再配置的场景，都可用此机制预测利率与资产
    价格的反常变动。
  tags: [市场分割, 流动性效应, 模型]

- id: Gf04
  title: 修正的费雪方程式：费雪效应与流动性效应的角力
  type: framework
  source_chapter: 第15讲 15.4节（及附录15.A.4）
  source_quote: |
    在名义利率的决定中，有两个力量在发挥作用。第一个是"费雪效应"（也可叫做通货膨胀
    预期效应）……第二个是"流动性效应"……市场分割程度越高，流动性效应越大。
  summary: |
    解决"利率如何决定"这一货币政策最关键问题。核心逻辑：名义利率 = 费雪效应项
    （(1+π)(1+r)，通胀预期推升）与流动性效应项（与市场分割程度成正比，压低）之和；
    真实利率由实体资本回报率决定，央行通过两条渠道影响名义利率——传导顺畅时费雪效应
    占上风（放水→利率升），传导阻塞时流动性效应占上风（放水→利率降）。用法：预测
    央行宽松后的利率走向时，先诊断"央行→金融→实体"传导链哪里堵了、堵得多严重，
    而不是机械套用"放水=利率降"或"放水=通胀升"的单一结论。
  tags: [利率决定, 费雪效应, 流动性效应]

- id: Gf05
  title: 水系比喻：央行放水与流动性"堰塞湖"机制
  type: framework
  source_chapter: 第15讲 15.2.3节
  source_quote: |
    经济中的货币就是水……央行就是一个大水龙头……如果水流流向实体经济的渠道有阻塞，
    那么央行在银行间市场这个水池中放水就未必会提升实体经济这个池子中的水位。
  summary: |
    解决"如何直观判断宽松货币政策的效果"的传播性问题。核心逻辑：货币是水、央行是
    水龙头、经济是多个相互连通的池子（银行间市场、各金融市场、实体经济）；渠道畅通时
    放水使所有池子水面持平（通胀、普涨）；流向实体的渠道阻塞时，水在金融市场池子里
    积成"堰塞湖"，资产价格涨而实体仍"干旱"（融资难）。用法：作为向非专业者解释
    货币政策非对称效果的思维模型，并给出操作清单——找阻塞点（行政管制、需求错配、
    银行放贷能力不足）、判断水会淤在哪、预测哪个池子水位先涨。
  tags: [流动性堰塞湖, 直观模型, 货币政策传导]

- id: Gf06
  title: 2015年A股大牛市的堰塞湖解释
  type: framework
  source_chapter: 第15讲 15.5节
  source_quote: |
    2015年A股这波大涨归根结底是货币政策传导不畅在金融市场上产生的"流动性效应"。
    一个明显的例证是……社会融资总量——长期处在同比少增的格局……银行间市场的成交量
    却大幅增加。
  summary: |
    解决"为什么经济越弱股市越涨"这类反常现象的解释问题。核心逻辑：用两组数据的反差
    锁定传导阻塞——社融同比少增（实体拿到的钱在萎缩）与银行间成交量暴增（金融体系
    资金泛滥）同时发生，说明"央行→金融→实体"链条在金融到实体一环断裂；定向宽松
    （压地产基建融资、向三农小微倾斜）造成"要钱的地方不给、给钱的地方给不出去"的
    错配，流动性淤积成堰塞湖，催生股价泡沫，泡沫终会破灭（2015年6-7月股灾）。用法：
    判断牛市性质时先看它由盈利驱动、杠杆驱动还是流动性淤积驱动，并检查实体融资指标
    与金融市场资金指标是否背离。
  tags: [A股牛市, 流动性堰塞湖, 案例解释框架]

- id: Gf07
  title: 预算软约束模型（Dewatripont-Maskin式的政府项目博弈）
  type: framework
  source_chapter: 第16讲 16.2节
  source_quote: |
    政府的补贴带来了预算软约束问题——项目的投资者可以不为自己的失败买单。考虑到政府
    会来兜底，政府项目在融资时就会更加激进一些，让那些本来不应被启动的项目也启动起来。
  summary: |
    解决"为什么低回报项目反而能挤占高回报项目的融资"的金融市场扭曲问题。核心逻辑：
    政府项目（如基建）有外部性E，政府出于社会总收益会在项目失败后提供再融资兜底；
    项目好坏是项目经理私人信息，政府只能"全救或全不救"；兜底预期让"坏"项目也敢
    伪装启动，软约束因此内生且无法靠承诺消除。用法：识别任何"事前激进、事后等救助"
    的融资主体（融资平台、部分国企），分析其如何扭曲资金定价与配置；模型给出三个
    可检验条件（见Gf08）判断软约束是否存在。
  tags: [预算软约束, 博弈模型, 挤出效应]

- id: Gf08
  title: 政府行为三条件（事后再融资/事前不经济/政府参与）
  type: framework
  source_chapter: 第16讲 16.2.1节
  source_quote: |
    这意味着在面对失败的政府项目时，政府总是愿意提供再融资来让项目完成。……失败的
    政府项目就算获得了再融资而完成，带来的社会总收益F+E也抵不过项目所使用的总融资。
  summary: |
    解决"软约束为什么会顽固存在、为什么政府的承诺不可信"的机制刻画问题。三个条件
    构成完整的逻辑闭环：（1）事后再融资条件 F+E−1>L——项目启动后，救助比清算好，
    兜底必然发生；（2）事前不经济条件 F+E<2——明知社会总收益覆盖不了两轮融资，
    项目本不该上马；（3）政府参与条件——若政府事先承诺不救，连"好"项目也无人启动，
    外部性全失，故政府无法退出博弈。用法：判断某类主体是否陷入软约束陷阱——看是否
    同时满足"事后必被救、事前不划算、政府不能不救"三条件；这正是"事前承诺不可信"
    时间不一致问题的教科书式呈现。
  tags: [时间不一致, 不可信承诺, 软约束诊断]

- id: Gf09
  title: 融资市场部分均衡与挤出效应分析
  type: framework
  source_chapter: 第16讲 16.3节
  source_quote: |
    当融资供给收紧（a下降），导致均衡利率上升时（R上升），融资市场中政府项目会占据
    更大的份额。
  summary: |
    解决"信贷紧缩时谁受损"的配置问题。核心逻辑：政府项目因有兜底，给融资方的是无风险
    回报F；民间项目有失败风险，须承诺更高成功回报（F'>F）才能吸引资金；用供给曲线
    Q=a+bR 与两类项目需求曲线求均衡可得——资金供给收紧、利率上升时，软约束的政府
    项目在总融资中占比反而上升，对民间项目的挤出加强。用法：分析去杠杆、流动性收紧
    时期"国进民退"式融资结构变化；推论是紧缩未必惩罚低效主体，反而可能奖励它，
    这与"市场纪律会淘汰劣者"的直觉相反。
  tags: [挤出效应, 部分均衡, 融资配置]

- id: Gf10
  title: 刚性兑付→无风险利率抬升→民企被挤出的传导链
  type: framework
  source_chapter: 第16讲 16.4.1节
  source_quote: |
    投资者清楚，城投公司背后有地方政府的隐性担保……当无风险利率被城投公司推升到这个
    高位时，民营企业发债就需要付出更高的利息率。
  summary: |
    解决"利率市场化后民企为何反而更难过"的悖论。核心逻辑：隐性担保让城投债在投资者
    眼中变成无风险资产，其6%的高票息变成事实上的无风险利率基准；无风险利率被抬高后，
    真正有风险的民企债必须在此基础上再加风险溢价，融资成本进一步上升；经济下行期民企
    利润率下滑、利率承受力降低，只能退出融资市场。用法：分析债市定价时区分"名义票息"
    与"含担保后的无风险属性"，警惕被软约束主体污染的无风险利率基准；这也是评估利率
    市化改革成效的结构性标尺。
  tags: [刚性兑付, 无风险利率, 所有制歧视]

- id: Gf11
  title: "融资贵"的软约束解释（利率敏感性失衡机制）
  type: framework
  source_chapter: 第16讲 16.4.2节
  source_quote: |
    由于城投公司存在预算软约束，因而对利率的敏感度较低。当城投公司在整个融资中的占比
    上升后，实体经济融资需求并不会因为高利率而下降得足够多，利率向"合适水平"回归的
    力量就没那么强。
  summary: |
    解决"利率为何长期高于与实体利润率匹配的合适水平"的定价问题。核心逻辑：利息归根
    结底来自实体利润，利率过高时正常主体会减少融资、把利率拉回合适水平——这一回归
    机制的前提是融资需求对利率敏感；软约束主体对利率不敏感（反正有人兜底），其占比
    越高，需求曲线越缺乏弹性，均衡利率越高且越难回落。用法：用"合适利率"计量基准
    （费雪方程式回归拟合值）识别利率失衡时期，再从融资主体结构（软约束占比）找原因，
    而不是笼统归咎于央行放水太多或银行贪利。
  tags: [融资贵, 利率敏感性, 合适利率]

- id: Gf12
  title: 利率市场化改革的"前提条件"分析框架
  type: framework
  source_chapter: 第16讲 16.4.1节
  source_quote: |
    利率市场化改革的前提应当是消除金融市场中预算软约束的存在，让所有融资主体都站在
    同一起跑线上公平竞争。
  summary: |
    解决"放开利率管制后为何改革目标落空"的制度诊断问题。核心逻辑：利率市场化要奏效，
    前提是所有融资主体预算约束硬化、公平竞争；软约束未消除前放开价格，只会让软约束
    主体凭不公平优势抢走更多资金，配置效率不升反降。化解之道不在金融端而在财政端：
    政府项目的外部性该由财政（发国债）承担初始融资与再融资，把融资平台从金融市场
    剥离（地方债置换即此思路）；财政不接手，清理平台就是"按下葫芦起了瓢"。用法：
    评估任何价格市场化改革时，先检查市场参与者是否对决策负全责这一前提是否成立。
  tags: [利率市场化, 财政与金融, 改革次序]
