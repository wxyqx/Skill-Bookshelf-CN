  title: 一价定律与实际汇率框架（名义汇率 vs 真实商品兑换率）
  type: framework
  source_chapter: 第20讲 20.1.2节
  source_quote: |
    如果商品可以跨境自由流动，不同地点的商品应该符合一价定律（law of one price）。
    ……以E表示直接标价法记的外国货币兑本国货币的名义汇率……那么一价定律可以写成
    如下公式 P=EP*。
  summary: |
    解决的问题：区分"货币之间的兑换比率"与"商品之间的兑换比率"，为一切汇率
    分析提供基准关系式。名义汇率 E 是金融变量，实际汇率 EP*/P 是真实变量。
    核心逻辑：若商品可跨境自由流动，套利力量会迫使同一商品在两地价格符合
    P=EP*，此时实际汇率恒为 1；对式子取对数差分可得"汇率变化率=两国通胀差"。
    怎么用：分析汇率问题先问商品套利是否顺畅（贸易品/非贸易品），套利顺畅处用
    一价定律定锚，套利受阻处（如非贸易品、巴拉萨-萨缪尔森效应）实际汇率偏离 1，
    恰是结构分析的入口。
  tags: [汇率, 一价定律, 实际汇率]

  type: framework

  summary: |

    变量），求解一阶条件，得到消费跨期欧拉方程与债券持有条件；模型中名义价格灵
    活，古典两分法成立。怎么用：作为推导利率平价的母模型；也是检验"某种汇率
    学说是否真的出自均衡分析"的模板。

- id: If03
  title: 无抛补利率平价（UIP）：汇率变动的决定方程
  type: framework
  source_chapter: 第20讲 20.3.1节
  source_quote: |
    即本国和外国的名义利率之差等于本国和外国的通货膨胀之差。……ΔE/E=R−R*，
    这叫做无抛补利率平价（uncovered interest rate parity），反映的是在本国名义
    资产和外国名义资产之间的无套利关系。
  summary: |
    解决的问题：给本币汇率的变动方向一个均衡决定式。核心逻辑：从两国债券最优
    持有条件推出"持有本币债券与外币债券实际回报无差异"，结合一价定律得
    ΔE/E=R−R*；若本国利率更高，必须伴随本币贬值预期，否则人人抛外币资产买本币
    资产，均衡无从达成。怎么用：（1）判断利率变动对汇率的压力方向；（2）作为
    蒙代尔不可能三角的推导起点——等式本身成立的前提就是资本自由流动，四个因素
    （ΔE、R、R*、等式成立）中本国只有两个自由度；（3）用现实数据检验其适用性
    （在人民币身上并不适用，见反例）。
  tags: [利率平价, 无套利, 汇率决定]

  title: 灵活价格下货币冲击对汇率的影响（一次性贬值到位基准情形）
  type: framework
  source_chapter: 第20讲 20.3.2节
  source_quote: |
    当货币政策传导完全顺畅且价格完全灵活变化时，基础货币超预期的一次性扩张会瞬
    时反映到总体价格上。价格水平会从之前的位置一次性地跳升到一个更高水平，并在
    那里稳定下来。
  summary: |
    解决的问题：建立货币冲击→汇率反应的"理想基准"，为引入摩擦后的汇率超调提
    供对照。核心逻辑：传导顺畅+价格灵活时，一次性货币冲击即时体现在物价上，通
    胀预期与名义利率（费雪方程）均不变，汇率随物价一次性跳升（贬值到位）后稳定，
    一价定律时时成立。怎么用：四变量（货币、物价、利率、汇率）联动图是分析任何
    一次货币扩张的标准底稿；现实汇率若"贬过头再回调"，即说明存在传导阻塞或价
    格黏性，应转向超调框架。
  tags: [货币冲击, 汇率, 基准模型]

- id: If05
  title: 汇率超调框架（多恩布什 1976）
  type: framework
  source_chapter: 第20讲 20.3.3节
  source_quote: |
    在存在货币传导阻塞和价格黏性时，汇率面对超预期的货币总量一次性扩张就不是一
    次性贬值到位，而会先向一个方向走过头，然后再回调一定幅度。这就是多恩布什……
    提出的汇率超调（exchange rate overshooting）。
  summary: |
    解决的问题：解释外汇市场为何过度波动、为何汇率走势常与宏观基本面脱节。
    核心逻辑：货币扩张初期流动性效应压低本国名义利率，为维持利率平价必须出现
    本币升值预期；而长期看货币扩张终将带来贬值，于是本币必须一开始就"贬过头"
    （超过新长期均衡水平）才能制造出随后的升值预期——先贬值、再升值。怎么用：
    观察到汇率大幅偏离基本面后回调，可用超调解释；同时它提示"汇率波动并不完全
    由宏观经济的长期基本面因素决定"，这是评估均衡汇率概念适用性、反对仓促自由
    浮动的理论根据之一。
  tags: [汇率超调, 多恩布什, 过度波动]

- id: If06
  title: 蒙代尔不可能三角（三元论）：利率平价四因素的自由度分析
  type: framework
  source_chapter: 第20讲 20.4.1节
  source_quote: |
    它说的是在开放条件下，在本国货币政策独立性、固定汇率和资本自由流动这三个目
    标中，政策最多只能同时满足两个。
  summary: |
    解决的问题：开放经济中一国货币与汇率政策的选择空间到底是什么。核心逻辑：
    把无抛补利率平价式 ΔE/E=R−R* 拆成四个因素——汇率变化、本国利率、外国利率、
    以及等式本身（资本自由流动）；外国利率不受本国控制，剩下三个只能选二：资本
    自由流动下，要利率独立就得让汇率浮动，要固定汇率就得放弃利率独立；三者兼得
    只能管制资本流动使平价式不成立。反向论证：固定汇率+高利率引发资本流入倒逼
    基础货币扩张，固定汇率+低利率引发资本外流耗尽外汇储备直至汇率危机。怎么用：
    为任何"既要……又要……"的开放经济政策组合做可行性体检，并为外汇冲销框架
    （If07）提供突破口的识别。
  tags: [不可能三角, 三元论, 政策选择]

  title: 外汇冲销下的"可能三角"：外汇干预+冲销的两步资产负债表分析
  type: framework
  source_chapter: 第20讲 20.4.2节
  source_quote: |
    所谓外汇冲销（foreign exchange sterilization），是指央行通过货币政策工具来
    回笼或锁定发放出去的外汇占款，以避免外汇占款对国内金融市场形成冲击的操作。
  summary: |
    解决的问题：不可能三角是否绝对？顺差国如何同时稳汇率、保货币政策独立、容
    纳资本流入。核心逻辑：两步走——第一步外汇干预，央行按目标汇价买入流入的外
    汇、发放本币（外汇占款）；第二步冲销，用央票发行或提高存款准备金率把发放的
    基础货币收回或锁定，使国内流动性 unaffected。资产负债表上表现为"私人部门
    的外汇变成央票/准备金"。怎么用：判断一国能否突破三元论——经常账户盈余国
    （持续资本流入）可行，逆差国（资本流出要消耗外汇储备）面临硬约束；这也是
    评估"中国是否必须让汇率自由浮动"主张的关键分析工具。
  tags: [外汇冲销, 外汇占款, 不可能三角]

  title: 均衡汇率概念的适用性检验框架（理论 vs 数据的落差诊断）
  type: framework
  source_chapter: 第20讲 20.5节
  source_quote: |
    在大量回顾了学术研究成果后，该章作者得到的基本结论是在浮动汇率制下，没有什么
    宏观变量对汇率走向有解释力，汇率变化具有极强的随机性。
  summary: |
    解决的问题："汇率高估/低估了没有"这类流行判断有没有可靠的学理基础。核心

    汇市场天量交易中非基本面投机占比高（全球日均外汇交易超 5 万亿美元 vs 一年
    GDP 70 多万亿）、非常规货币政策引发的大幅震荡。怎么用：对任何"均衡汇率估
    算"先做适用性体检；在汇率脱离基本面严重的市场中，主张政府保有对汇率的掌控
    力就有了依据。

- id: If14
  title: "831大限"式制度断点分析：土地垄断供给→房价上台阶
  type: framework
  source_chapter: 第21讲 21.3.2节
  source_quote: |
    "831大限"之前的1998—2004年，中国全国土地供应年均增速接近30%，房屋完工

    约束而非笼统的"货币"或"投机"。

  title: 地方政府财政与房价的联动辨析框架（财权事权与卖地行为解耦）
  type: framework
  source_chapter: 第21讲 21.4节
  source_quote: |
    土地财政因地方政府垄断土地供应而生，与地方政府财权与事权是否平衡没有太大
    关系。就算地方政府财权与事权是平衡的……面对能卖出高价的土地，地方政府也会
    高价卖地。无他，经济规律使然。
  summary: |
    解决的问题：高房价能否归咎于分税制造成的财权小于事权、"平衡财权事权"能否
    遏制房价。核心逻辑：卖地是垄断供应者追求垄断收益的行为，有没有收支缺口都会
    高价卖地——财政缺口不是房价的因；再正面论证财权集中的三重合理性（中央制衡
    地方、财政收入稳定、跨地区转移支付，并与欧元区无财政联盟的教训对照）。怎么
    用：遇到"某制度安排导致某恶果"的流行因果链，先做行为主体的反事实检验（去
    掉所谓的原因，行为是否照旧）；同时为财政体制评价引入国家治理维度而非只算
    经济账。
  tags: [土地财政, 分税制, 因果辨析]

- id: If16
  title: 债务可持续性分析框架（dratio 恒等式与四条出路）
  type: framework
  source_chapter: 第22讲 22.3.1节
  source_quote: |
    债务占GDP比重的变化率，等于名义债务的增长率减去通货膨胀率，再减去经济的
    实际增长率。……如果这三点都做不到，就只有最后一条路，在债务占GDP比重的
    上升过程中爆发债务危机。
  summary: |
    解决的问题：一个经济体会不会爆发债务危机。核心逻辑：国际通行框架——债务/
    GDP 比重不可能无限上升（比重越高债权人要求的回报越低，最终停止融资）；其
    变化率 = 名义债务增速 − 通胀率 − 实际增速，故出路只有四条：削减名义债务、
    通胀稀释、高增长稀释、或在上升过程中爆发危机。怎么用：先套框架算账（作者也
    承认"这一思路框架内部不存在逻辑问题"）；再用第二层框架（If17）检查其前提
    假设是否成立——这正是本讲示范的"框架适用性"分析法。
  tags: [债务可持续性, 杠杆率, 宏观恒等式]

- id: If17
  title: 债务方-债权方双边分析框架（刚性储蓄者对标准框架的修正）
  type: framework
  source_chapter: 第22讲 22.3.2节
  source_quote: |
    （22.1）式所代表的分析框架中只包含对债务方行为的分析，而没有包含对债权方
    行为的讨论。……中国经济中存在着大量刚性储蓄者（国有企业及许多民营企业）。
    这些储蓄者只储蓄、不消费，因而对储蓄的回报率不敏感。
  summary: |
    解决的问题：标准债务可持续框架为什么在中国失灵。核心逻辑：框架的隐含假设
    是"债权人在乎回报率，回报太低就停止融资"；但中国收入分配结构造就只储蓄不
    消费的刚性储蓄者（债权方），储蓄率不随投资回报率下降而降，融资供给对回报率
    缺乏弹性，债务比重的"市场约束"不再自动生效。证据：全球储蓄率未随 GDP/资本
    存量比率下降，且刚性主要来自中国。怎么用：分析任何债务问题先问"债权方是谁、
    他们的目标函数是什么"；对储蓄者=消费者的经济体标准框架适用，对存在刚性储蓄
    者的经济体必须改造框架——这是"检验前提假设再套模型"的方法论示范。
  tags: [刚性储蓄, 债权方行为, 前提假设]

- id: If18
  title: 储蓄-投资-融资的内生货币金融框架（S=I+CA 落到金融体系）
  type: framework
  source_chapter: 第22讲 22.1节、22.3.3节
  source_quote: |
    从理论上来说，货币金融体系内生于实体经济状况。有什么样的实体经济结构，就应该
    有什么样的货币金融运行状态。
  summary: |
    解决的问题：把实体结构失衡与金融变量（债务、M2、社融）接通。核心逻辑：恒
    等式 S−I=CA 决定储蓄的去向——外需受阻时更多储蓄须转化为国内投资；转化必
    须经金融体系，而中国融资由债权型主导（股权融资占社融不足10%，根源在 A 股
    股东对管理层缺乏支配力→分红不足→股票缺投资价值→炒小炒新→ IPO 受限），债
    权融资既创造债务又创造货币（M2/GDP 上升）。怎么用：见到任何金融总量指标异
    动，先还原到实体储蓄-投资格局找因；预测金融走势=预测实体结构（储蓄过剩是
    否持续）+ 融资结构（债权/股权比例）的乘积。
  tags: [S=I+CA, 内生货币金融, 融资结构]

- id: If19
  title: 金融乱象生成机制框架：储蓄过剩×去杠杆的"猫鼠博弈"
  type: framework
  source_chapter: 第22讲 22.1节、22.4.3节
  source_quote: |
    融资能堵一时，但堵不了一世。政府对信贷等传统融资方式的管控反而给金融市场参
    与者带来了更强的规避监管动力，导致新的风险更高的融资通路被创设出来。
  summary: |
    解决的问题：次贷危机后中国金融"乱象不断"（影子银行、钱荒、股灾）有没有统
    一解释。核心逻辑：把储蓄比作水位难降的池子——调节机制（储蓄↔消费）因收入
    分配而失灵，流向国外又受阻，储蓄向投资转化的势能持续存在；去杠杆堵住一条融
    资通道，储蓄就改道更隐蔽、风险更高的通道；监管再堵，博弈再升级，乱象就在
    "猫鼠博弈"中层层涌现（票据→影子银行→股市杠杆→债市杠杆）。怎么用：识别
    类似矛盾驱动的金融演化——先找"不可阻挡的势能"（资金流向的根本动力），再
    找"堵的政策"，推演改道路径；治理思路也由此得出：疏（容许透明低风险的信贷
    转化）优于堵。
  tags: [金融乱象, 猫鼠博弈, 去杠杆]

- id: If20
  title: 城投公司商业模式分析框架（微观回报 + 社会外部性 + 隐性补贴）
  type: framework
  source_chapter: 第22讲 22.3.2节
  source_quote: |
    城投公司所从事的基本都是公益性的基础设施投资项目，项目微观层面的现金回报率
    的确不高。但这些项目还有很大一部分回报表现为外部性，体现在社会层面。……
    政府通过隐性补贴来支持这些公益性项目从金融市场获取融资就有其合理性。
  summary: |
    解决的问题：城投 ROA 覆盖不了票息率，是不是庞氏骗局、该不该断其融资。核心
    逻辑：公益性基建的回报分两层——微观现金回报（卖票收入）低，但社会层面外部
    性回报（地铁推升周边地价房价、活跃经济、创造税收）大且只能由政府获得；政府
    以隐性补贴（含注入土地）支持城投融资因此合理，土地升值也解释了城投资产负债
    率长期稳定。怎么用：评估准公共主体偿债能力时，把项目回报扩展到"项目现金流
    +财政可捕获的外部性"两个账户；判断其可持续性=外部性是否真实落入政府资产
    （土地价值）而非空转。
  tags: [城投, 外部性, 预算软约束]
