# 中国货币政策实践与利率市场化：读懂人民银行的约束审计仪

> 来源：徐高《宏观经济学二十五讲：中国视角》第19讲（第16、17讲呼应）

---

## R：原理（Rationale）

徐高把"人民银行为什么这么操作"归结为一个约束问题，概念链条如下：

### 财政主导 vs 货币主导：政府跨期预算约束下的两种配合
- 政府支出靠税收与铸币税两个收入源支撑，财政与货币政策必有一主一从，不可能同时"自由"。
  > 原文引用：「财政政策与货币政策需要有主次之分。一个政策工具被确定了下来，另一个就只能被动地调整。」（19.2.1）
- 货币主导：财政靠税收自我平衡，央行自由设定量价；财政主导：赤字由铸币税填补，通胀随赤字起舞。判断标尺是**融资方式**（是否透支央行），不是赤字规模。

### 恶性通胀机制：铸币税追逐的正反馈
- 实际铸币税=货币增速×实际货币存量；增速过高时物价跑赢货币、实际存量反降，政府被迫以超越民间预期的速度发钞，预期随之水涨船高，加速发散——恶性通胀不可能是稳定状态。
  > 原文引用：「政府为了保证收到足量的实际铸币税，必须持续以超过民间预期的速度发行货币。」（19.2.3）
- 总根源在财政：税收撑不住支出才依赖铸币税，治理必先修财政（萨克斯治玻利维亚）。

### 中国特色货币政策框架：三大特征
- ①存贷款基准利率直接管制、变动温和（不符合泰勒准则）；②银行间市场缺政策锚定的短端基准利率；③M2目标、信贷额度、窗口指导等数量型工具广泛使用——"短端利率→市场→实体"的标准传导路径不显著。
  > 原文引用：「对存贷款利率的直接管制、金融市场短期基准利率的缺失以及数量型工具的广泛使用。」（19.3.1）

### 政策分析两步法（元方法论）
  > 原文引用：「外人看起来的昏招，很可能是决策者在约束条件限制下的无奈之举。」（19.3.2）
- 第一步：解释政策在当前约束下为什么"对"；第二步：研究如何放松约束。跳过第一步的建议隔靴搔痒。

### 两大成因与双重困局（利率市场化转型的中间态）
  > 原文引用：「第一是在中国的金融和经济体系中缺乏货币政策传导所需的市场力量；第二是政策性负担在货币政策传导路径中形成了扭曲。」（19.3.2）
  > 原文引用：「数量型调控方式逐步失效……市场型价格调控工具又无法充分发挥效果。」（19.4）

**关系**：财政/货币主导是宏观制度定位 → 两大成因解释微观约束来源 → 两步法是分析纪律 → 双重困局是转型期所处阶段；四者合起来回答"央行操作为何如此、往何处去"。

## I：指令（Instruction）

面对人民银行的任一操作或中国货币政策议题，按四步审计：

### 第一步：分清财政主导还是货币主导（谁被动配合谁）
- 问"财政赤字靠什么融资"：透支/铸币税 → 财政主导，通胀风险随赤字走；国债融资+法律禁令 → 货币主导，央行有独立空间。
- 警惕"赤字大=货币超发"：1995年后赤字更大、货币反而更稳——关键在融资机制，不在规模。
- 格局切换点（1995年立法禁止透支）往往是宏观数据的断点。

### 第二步：用政策分析两步法
- 第一步（解释）：这个操作在当前约束下为什么"对"？找出它回应的真实约束。
- 第二步（改进）：针对约束本身提放松方案；约束不放松，"更优政策"就不可行。
- 自检：说不出"为何当下是对的"，就没有资格提改进建议。

### 第三步：识别中国特色工具的历史成因（市场力量不足+政策性负担）
- 看到数量型工具（信贷额度、窗口指导、M2目标），先查两条成因：市场套利力量是否足以支撑价格传导？融资主体是否背着政策性负担（利率须温和以免高通胀下国企大量倒闭；基准利率保护国有银行息差）？
- 两约束未松动前，"行政工具落后"的批评不成立。

### 第四步：跟踪利率市场化转型的中间态（数量型失灵+价格型受阻）
- 中间态=双重困局：影子银行等金融创新绕开额度使数量管控失效；软约束主体对利率不敏感使价格调控失灵且劣币驱逐良币。
- 利率市场化两层含义：放开利率管制只是手段，让自由浮动的利率引导金融资源配置才是最终目标。
- 评价改革：不能用转型乱象否定方向（同不能用改革开放中的新问题否定改革开放）。

## A1：应用场景一 — 书中案例

### 案例一：影子银行扩张与2013年"钱荒"（数量调控失效）
- 背景：四万亿退出后在建立项融资需求旺盛，银行以"买入返售"等影子业务绕开信贷额度变相放贷——数量管控被金融创新架空。
- 央行反制：收紧基础货币以控社融，恰逢QE3退出全球流动性收紧；央行明确拒绝放水，利率飙涨、"钱荒"爆发，6月25日公告投放流动性后平息。
- 两面评价：一面，最后贷款人职责的迟疑放大了波动，确有可议；另一面，「我们也需体谅人民银行，看到人民银行在"钱荒"时的不得已」——压影子银行情有可原。（19.4.1）
- 方法论落点：这是双重困局的标准样本——数量工具失灵逼央行动用价格手段，而价格传导又被软约束阻塞。

### 案例二：1985年财政透支（财政主导的第一手史料）
- 1984年赤字50亿元，「这一年的财政赤字，待决算编成后，准备向中国人民银行透支来弥补」（19.2.2）——透支即印钞，经货币乘数放大，是中国两次高通胀的财政根源。
- 对照：1995年立法禁止透支后，赤字更大而货币更稳——财政主导切向货币主导的制度断点。

## A2：应用场景二 — 未来触发：解读央行操作与政策评论

### 场景一："人民银行的操作为什么和教科书不一样？"
1. 第一步定位：1995年后是货币主导，央行并非受财政挟持，问题出在微观传导约束。
2. 两步法第一步解释：基准利率变动温和回应国企政策性负担；数量管控是市场力量不足下的替代。
3. 落点：不是"央行不懂现代理论"，而是约束使然——改进从放松约束入手。

### 场景二："怎么解读降准/逆回购/MLF？"
1. 先折算对超储的净影响（含外汇占款、财政存款等被动因素），再判断松紧——单一工具动作不足为凭（2006-2008年连续提准实为对冲外汇占款）。
2. 放进双重困局定位：该工具是在补数量型失灵（如MLF补基础货币缺口），还是在试探价格型传导（如利率走廊建设）？

### 与关联 skill 的区分（路由规则）
- **monetary-policy-toolbox**：通用原理与非常规工具（QE、零下限、伯南克路线图、泰勒准则的模型推导）→ 用它；本 skill 处理中国约束下的实践变形。问"QE是怎么回事"走 toolbox，问"中国为什么没搞QE/逆回购利率为何偏离市场利率"走本 skill。
- **soft-budget-constraint**：约束机制本身（软约束三条件、刚兑激励、挤出推演）→ 用它；本 skill 处理这些约束如何塑造货币政策进程与利率市场化节奏。问"城投为何能高息发债"走 s-b-c，问"城投挤出如何让价格型调控失灵、改革怎么走"走本 skill。
- **second-best-transition**：转轨节奏与阵痛处理的通用方法论 → 用它；本 skill 是其在货币政策领域的实例化。

## E：边界与反例（Edge Cases）

### E1：两条"错误归因"陷阱
- 「有人可能认为这代表了人民银行的工作人员在现代货币政策理论知识方面的欠缺。显然这不是事实」——把"与教科书不符"等同于"不懂/错了"是政策分析第一大忌；央行看到的约束，外人往往感受更浅。（17.4，19.3.2重申）
- 「他们的建议就只能是隔靴搔痒，不具有可操作性」——用斥责决策者愚蠢代替约束分析，是伪政策分析的标志：有判断无第一步。

### E2：照抄西方（制度移植谬误）
- 「不能说西方发达国家有一套货币政策调控体系，中国就一定需要照抄」——"人家都这么做"是诉诸权威不是论证；正确路径是比较两种体系的优劣机理，再核对前提（市场力量、政策性负担）是否具备。（19.4）

### E3：赤字与通胀的两个机械等式
- "赤字大必然货币超发"：1995年后赤字更大、货币反而更稳——总量变量与融资机制必须分开看。
- "直升机撒钱=恶性通胀"：同为赤字货币化，「在发生恶性通货膨胀的经济体中，财政赤字的货币化是被动的，是政府走投无路的选择」；主动的、走出通缩即停的撒钱与之机制本质不同。（19.2.3）

### E4：改革评价的对称错误
- 「绝对不可以用金融市场中出现的乱象来否定利率市场化」；但也别把过程性代价当目标本身——乱象是发现约束的信号，每一轮乱象应催生制度补丁（43号文→股灾→地方债置换）。（19.4.3）

## B：适用边界（Boundary）

### ✅ 适用场景
- 解读人民银行具体操作（降准、逆回购、MLF、窗口指导）的松紧含义与真实意图
- 回答"中国货币政策为何与教科书不同"类问题；评估利率市场化进程与方向
- 审查中国货币政策评论的质量（有无第一步的约束分析）
- 判断财政赤字与通胀的关系（融资机制视角，而非规模视角）

### ⚠️ 谨慎使用
- 转型是动态过程：书中"中间态"描述截至写作时点，需对照最新制度变化（利率走廊、LPR改革等）更新——框架不变，事实要换
- 两步法解释现状≠为现状辩护：第一步的目的是让第二步的改进可操作
- 涉及财政与央行关系的政治经济学判断，区分制度分析与政策站队

### ❌ 不适用场景
- 通用货币政策原理与海外央行分析（QE机理、零下限、泰勒规则估计）→ monetary-policy-toolbox
- 预算软约束、刚性兑付的机制本身 → soft-budget-constraint
- 具体投资操作建议（"降准了该买什么"只做信号解读，不做仓位建议）
