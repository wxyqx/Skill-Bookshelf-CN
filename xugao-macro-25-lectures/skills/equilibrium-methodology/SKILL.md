# 均衡宏观经济学方法论：一般均衡建模的纪律

> 来源：徐高《宏观经济学二十五讲：中国视角》第 5-6 讲（立论与主体）、第 7 讲（求解纪律重申）、第 23 讲（微观基础范式引用）

---

## R：原理（Rationale）

卢卡斯批判之后，宏观分析只能建在经济中最深层的"不变"之上。徐高把这套现代范式落成一条可操作的建模纪律。

### 1. 微观基础：从唯心到客观优化
理性人假设是方法论的桥梁——它把无从捉摸的主观意识变成可计算的优化问题：
> 原文引用：「人的主观意识和行为这样唯心的课题，就变成了一个在客观约束条件之下的客观优化问题。」（5.5.2）

宏观变量间的统计关系（消费函数、菲利普斯曲线）都内嵌于行为与预期，偶然而易变；可依赖的只有理性：
> 原文引用：「宏观分析的基础需要构建在经济中最深层的"不变"——也就是人的理性——之上。」（5.4）

### 2. 均衡概念：刻画现实的限定条件集
> 原文引用：「均衡意味着两点——所有微观主体都达到其最优以及所有市场都出清。」（6.2）

均衡之所以能刻画现实，是因为不均衡状态不稳定：
> 原文引用：「不均衡的现实世界转瞬即逝。稳定长存的状态，也是我们能够观察到的状态，就一定是均衡的状态。」（6.3.1）

思想渊源：霍布斯看自利人只见到全民战争（须交剑主权者），斯密则看到自利行为经"看不见的手"（价格机制）协调共存——
> 原文引用：「所以，斯密说的"看不见的手"其实就是价格机制。」（6.3.2）

### 3. 建模三段论与求解两步法
> 原文引用：「宏观一般均衡模型分析一般包括三大块内容——模型设定、均衡定义以及模型求解。」（6.2.4）

求解的铁律是两步分离、顺序不可颠倒：
> 原文引用：「在求取消费者和企业最优化问题时，不能把这个条件代人。」（6.3.2）

> 原文引用：「第一步先在微观层面求解各个微观主体的优化问题……再进入第二步，通过均衡条件（主要是市场出清条件）来求取均衡。」（7.4.1）

### 4. 规范边界与模型评价
福利经济学两大定理连接均衡与帕累托最优，并给出求解捷径（中央计划者问题）；但等价有前提：
> 原文引用：「帕累托最优不是一个伦理学的判断标准。」（6.4.1）

> 原文引用：「对这种模型的分析就不能再走中央计划者问题的捷径了，而只能老老实实地按步骤求取均衡。」（6.4.2）

卢卡斯批判之下，模型靠校准对接数据、靠整体数量表现接受检验：
> 原文引用：「所谓校准，就是将模型中的参数设为符合现实世界的数值，然后观察模型产生的模拟数量结果。」（6.5）

**关系**：微观基础（凭什么建模）→ 均衡定义（建模成什么样）→ 求解纪律（怎么解才不错）→ 校准与规范边界（怎么对现实、怎么不越界），四环构成一条完整的建模工艺链。

## I：指令（Instruction）

面对"建模、解题或评判一份宏观分析"的任务，按四步走：

### 第一步：分清内生与外生（建模第一难点）
- 判据是**经济含义**而非数学：主体能影响 → 内生；只能接受 → 外生。
- 同一变量随主体与问题变角色：税收对消费者外生（不能讨价还价）；市场价格对完全竞争厂商外生、对垄断者内生；企业利润对消费者外生对应"两权分离"的制度假设。
- 每写一个优化问题，显式列出内生/外生清单及其经济理由——这是出错率最高的一步。

### 第二步：搭一般均衡模型（设定 + 定义）
- **设定**：有哪些决策主体（居民、企业、政府）、各自目标函数与约束、如何互动、各时点知道什么。
- **定义均衡**（程式化两条件）：所有主体达到最优 + 所有市场出清。
- 自检：逐项问"每个主体都在最优化吗？每个市场都出清了吗？"——缺一即不是一般均衡分析。

### 第三步：求解纪律（两步法，顺序不可混）
1. **微观优化先行**：站在价格接受者立场解各主体问题，把行为表示为价格的函数；主体只考虑自己，不看他人约束。
2. **禁忌——不预先代入均衡条件**：出清条件（n^s=n^d、股份总数=1 等）属宏观协调层，提前塞进个体优化等于赋予主体其现实不具备的信息与权力。
3. **宏观出清在后**：用市场出清条件联立解出价格与全部内生变量。
4. 主体间联系分两类：通过**价格**的间接联系不进个体优化；**直接联系**（如股东控制企业）必须进。
5. 捷径有条件：福利两定理成立（完全竞争、无信息不对称/外部性）时，可解中央计划者问题间接求均衡；不成立时回到标准两步。

### 第四步：校准对照现实 + 守住实证/规范边界
- **校准**：参数取现实值（如按资本回报占比取 α=0.4），以模型能否复现宏观数据的整体特征（波动标准差、交叉相关结构）论高下，不苛求某条局部假设逼真。
- **出具可检验含义**：模型推出候选驱动因素的可观测预测 → 数据裁决。
- **帕累托≠伦理**：帕累托标准只答"还有无不损害任何人就能改进的空间"，对公平沉默；福利评价须另立伦理标准。
- 求解顺序即认识顺序——"米开朗基罗"式：每加一个均衡条件就把现实的可能范围缩小一圈，得到想要的性质即可停笔。

## A1：应用场景一 — 书中案例：中国波动的来源是财政支出吗（6.5.2）

**问题**：政府支出波动大且可控，是不是中国经济波动的主要来源？平滑财政支出能否稳增长？

三步检验（模型产生可检验含义 → 数据裁决）：
1. **建模**：在第 6 讲一般均衡模型中引入财政支出 g，推导其作为波动主因的可观测含义。
2. **推含义**：若财政支出主导波动，则财政支出应顺周期，且工资率与居民消费应**逆**周期（政府花钱挤走居民消费、压低工资）。
3. **对数据**：表 6-1 显示三者在中国**皆顺周期**——与模型结论不符，假说被否。
> 原文引用：「用财政支出作为驱动因素来解释经济周期并不成功。」（6.5.2）

两个后续推论：平滑财政支出并不能有效降低波动（工具可控≠有效，先确认它是波动主因）；政府支出虽拉动总产出、却压低居民消费与工资率——评价刺激必须在均衡框架里算全部内生变量的账，不做单变量的免费午餐账。对照组：技术冲击的模型含义（GDP、消费、工资同升）与数据吻合，对应 RBC 路线。

**人性观补充**（6.1）：这套均衡方法背后是斯密式人性观（自利可经价格协调），对立面是霍布斯式（自利即战争，须主权者统辖）；瓦尔拉斯"数方程个数"式的存在性证明曾被作者点名为错，直到不动点定理才严格化。

## A2：应用场景二 — 未来触发：审查政策分析 / 亲手建模

**场景一：判断一份政策分析靠谱吗**
某报告用历史回归弹性测算"刺激拉动 GDP 多少"。四道体检：
1. 微观基础：结论从主体最优化推出，还是直接建立在宏观变量数量关系上？
2. 结构完整：所有主体最优化？所有市场出清？有没有漏算一般均衡后果（只记 GDP 账，不记消费与工资账）？
3. 内生/外生：关键变量的划分有经济理由吗？
4. 求解流程：有无偷跑——预代入清、滥用计划者捷径？
**与 expectations-lucas-critique 的分工**：报告拿历史关系外推政策效果，核心病灶是"预期未内生化"，属政策评估问题 → 用 expectations-lucas-critique；本 skill 审的是模型**结构纪律**（设定—定义—求解是否规范）。两者常需先后触发：先查结构，再查预期。

**场景二：自己动手建模或解题**（研究生作业、DSGE 入门、写模型章节）
按 I 段四步执行：先列内生外生清单 → 写全主体优化与约束 → 微观优化先行、出清在后 → 校准或推可检验含义。模型解不出具体数字不等于没解完——均衡条件逐步缩小现实可能范围，拿到所需性质即可停笔。具体到跨期消费储蓄的欧拉方程推导，转 ramsey-consumption-savings。

## E：边界与反例（Edge Cases）

### E1：内生/外生误设——"宏观建模和分析极易出错的地方"
把消费者控制不了的变量（税收 t、转移利润 π）让它去"选择"，或把本可影响的变量（垄断者的价格）误设为外生。划分标准是经济含义且随层次变化；每个优化问题必须显式交代划分依据。

### E2：预先代入市场出清条件
均衡时劳动供需相等 ≠ 个体决策时知道并服从这一点。居民只按工资率决定自己供给多少，不替企业盘算需求；把出清条件塞进个体优化，破坏了"各自理性、价格协调"的均衡结构。纪律：严格"分别最优化 → 出清联立"两步。

### E3：把帕累托最优当伦理标准
> 原文引用：「一个经济中所有资源都归于一人，而让其他所有人都饿死，是一个帕累托最优」（6.4.1）

帕累托只衡量效率，对分配沉默；用基数效用加总"社会总效用"更要预设人际权重，而权重选择可辩护任何分配。听到"这是帕累托改进"只读作"有效率"，公平另立标准。

### E4：福利定理不成立时仍走中央计划者捷径
存在信息不对称等结构时，计划者问题的解与市场均衡解不一致；此时用捷径求出的"最优"并非市场会呈现的结果，会系统性高估效率。捷径是求解手段，不意味作者认为现实存在中央计划者。

### E5：只见支出推 GDP，不见压消费压工资
> 原文引用：「政府支出就增加了全社会的总产出，但压低了居民消费和工资率。」（6.5.2）

只盯"GDP 被拉动"的局部账本会漏掉一般均衡代价。评价任何支出/刺激政策，须在均衡框架里算产出、消费、工资、价格的**全部**变化；同理，"平滑一个可控变量"不等于"减弱波动"——先确认它是波动主因。

### E6：直觉式"条件凑齐所以成立"
瓦尔拉斯见方程数与未知数相等就断定方程组有解——被证明是错的。重要断言（如均衡存在性）需要匹配的数学工具；"数量对上了"式推理不可靠。同理，理性只是假设与信念而非真理，非理性更不能任意假设（事后编偏差可"解释一切"即什么也没解释）。

## B：适用边界（Boundary）

### ✅ 适用场景
- 审查一份宏观政策分析/研究报告的结构质量（微观基础、出清、内生外生、求解流程）
- 自己构建或求解一般均衡模型时的流程指导（三段论 + 两步法）
- 教学/自学中理解均衡概念、价格机制、福利定理与中央计划者捷径的适用条件
- 为"模型—数据"对话提供工艺：校准、可检验含义、整体数量特征评价

### ⚠️ 谨慎使用
- 理性只是假设与信念：结论的可靠性与"理性近似"成立程度绑定，涉及明显非理性场景须标注前提
- 本 skill 管建模纪律，不含中国特有约束的引入方法（国企、软预算等转中国系列 skill）
- 校准与模型评价涉及具体参数与数据处理时，须回到原文献与数据，本 skill 只给方法论
- 均衡分析不等于"现实总是均衡的"——它是对稳定状态的刻画工具，不是世界观的免检印章

### ❌ 不适用场景
- 政策效果评估、预期内生化、卢卡斯批判的具体展开（用 expectations-lucas-critique）
- 跨期消费储蓄模型、欧拉方程的具体推导与应用（用 ramsey-consumption-savings）
- "分析中国该用哪套经济学"的元态度问题（用 china-macro-perspective）
- 计量估计的技术细节（软件、识别、标准误）——本 skill 只在"该不该信经验关系"层面介入

## 关联 Skill

- `expectations-lucas-critique`：同一理性预期革命的两翼——本 skill 管"模型怎么建才对"（结构纪律：设定—定义—求解），彼 skill 管"政策改变后预期与行为怎么变"（评估纪律：内生化预期、反事实模拟）；先查结构后查预期。
- `ramsey-consumption-savings`：两步法与均衡定义在跨期消费储蓄问题上的展开（欧拉方程、刺穿企业帷幕）——本 skill 的流程纪律在那里的实例化。
- `china-macro-perspective`：抽象模型如何接入中国——"标准模型 + 一个中国约束 = 中国模型"的元态度与水石头方法论。
- `gdp-welfare-analysis`：帕累托≠伦理的延伸——GDP 是手段不是目的，福利评价须回到终极关切标尺。
