# 货币政策传导与流动性堰塞湖：宽松效果的诊断仪

> 来源：徐高《宏观经济学二十五讲：中国视角》第15讲

---

## R：原理（Rationale）

徐高用"传导路径 + 市场分割"解释为什么央行放水有时压低利率、推高资产价格，却救不了实体：

### 传导的两环节地图
- 央行是货币终极创造者，但只把基础货币投给商业银行体系；银行在部分准备金制度下按乘数放贷，创造企业与居民的存款（广义货币）。
  > 原文引用：「货币政策传导包含两个主要环节——从中央银行到商业银行体系的第一环节，以及从商业银行体系到实体经济的第二环节。」（15.1.1）
- 超额存款准备金是银行间清算的终极支付工具，央行由此握住总闸门。
  > 原文引用：「超额存款准备金事实上是经济中的终极支付工具。」（15.1.3）

### 水系比喻与堰塞湖
- 货币是水，央行是水龙头，经济是多个连通的池子（银行间市场、各金融市场、实体经济）。
  > 原文引用：「如果水流流向实体经济的渠道有阻塞，那么央行在银行间市场这个水池中放水就未必会提升实体经济这个池子中的水位。」（15.2.3）
- 渠道阻塞时，水淤在金融市场池子里成"堰塞湖"：资产价格涨、实体仍"干旱"（融资难）。

### 市场分割模型（流动性效应的生成机制）
- 关键假设：居民在货币增量实现之前，已把现金不可逆地分配到消费品市场与金融市场。
  > 原文引用：「居民在一开始决定好了现金在金融资产和消费品之间的分配比例后，不管情况如何变化都不能再改变。」（15.3）
- 增量货币只进金融市场 → 该市场货币富集、约束更松弛 → 利率被压低、资产价格被推高。

### 修正的费雪方程式：两效应角力
- 名义利率由费雪效应（通胀预期，推升）与流动性效应（与市场分割程度成正比，压低）共同决定。
  > 原文引用：「市场分割程度越高，流动性效应越大。」（15.4）
  > 原文引用：「如果从金融到实体的传导环节不顺畅……更高的基础货币增长反而让名义利率下降。」（15.4）
- 锚：真实利率由实体资本回报率决定，央行只通过这两条渠道影响名义利率。

### 堰塞湖定性法
  > 原文引用：「2015年A股这波大涨归根结底是货币政策传导不畅在金融市场上产生的'流动性效应'。」（15.5）
- 判据：实体融资指标（社融）与金融体系资金指标（银行间成交量）背离 → 涨的不是基本面，是淤积的流动性。

## I：指令（Instruction）

面对"央行放水之后会怎样"类问题，按四步诊断：

### 第一步：画传导路径图，逐环找阻塞
- 画出"央行 → 商业银行 → 实体"两环节路径，逐环检查：银行放贷能力/意愿是否受损？实体融资需求是否存在？是否有行政管制或定向错配？
- 用银行资产负债表逐笔追踪资金：货币创造只发生在央行投放基础货币与银行放贷两处；银行间存款转移不创造货币。
- 定位阻塞点后，预测水会淤在哪个池子——离央行最近、渠道未断的市场先涨。

### 第二步：超储视角看央行着力点
- 央行高掌控力的是基础货币（超储）；广义货币是央行、银行、实体三方博弈的结果。
- 看宽松力度别只看 M2，先看超储与银行间资金利率；看宽松是否落地，看广义货币与社融有没有响应。

### 第三步：修正费雪方程，判断利率方向
- 传导顺畅 → 费雪效应主导：放水带动广义货币与通胀，名义利率上升。
- 传导阻塞 → 流动性效应主导：增量货币淤积金融市场，名义利率反而下降。
- 绝不默认"放水=利率降"或"放水=通胀升"的单一方向；先答"这次水能不能流进实体"，再下结论。
- 看到真实利率逆周期大幅波动，多半是传导阻塞造成的名义/真实利率背离，而非央行直接操纵了真实利率。

### 第四步：资产上涨定性——基本面还是堰塞湖
- 检查两组指标是否背离：实体融资指标（社融、贷款）萎缩 vs 金融体系资金指标（银行间成交量、超储）泛滥 → 堰塞湖驱动。
- 若两指标同向（融资扩张、金融成交温和），才谈得上基本面/盈利驱动。
- 对叙事性解释（"改革牛""国家意志"）保持警惕——先查流动性淤积证据，再谈故事。

## A1：应用场景一 — 书中案例：2015年A股大牛市与股灾的堰塞湖定性

**问题**：经济下行压力加大，上证综指却从2014年下半年起暴涨，为什么？（15.5）
- **背离证据一**：上证综指与财新PMI此前近十年高度正相关，2014下半年起背道而驰——"股市是经济晴雨表"的正相关失灵。
- **背离证据二**：社融长期同比少增（实体拿到的钱在萎缩），银行间市场成交量却大幅增加（金融体系资金泛滥）——传导在"金融→实体"一环断裂。
- **阻塞成因**：定向宽松把总量政策当结构性政策用——地产调控加码、43号文压城投融资，最大资金吸纳方（地产+基建）被挤出融资市场，而政策倾斜的三农、小微吸纳能力有限，"要钱的地方不给、要给钱的地方又给不出去"。
- **结果**：流动性淤积成堰塞湖，催生股价泡沫；2015年6-7月股灾随之而来。作者2014年文章《牛市与流动性堰塞湖》事先给出此论断。
- **对照案例（2013年钱荒）**：同一闸门的反向运用——央行为清查影子银行大幅收紧基础货币，隔夜回购利率盘中达30%的历史纪录，证明超储闸门收放皆可瞬间冻结资金面。

## A2：应用场景二 — 未来触发：两组易混问题的分诊

**场景一**："降准降息后股市涨了、债市火了，但实体没好转，怎么解读？"
1. 用本 skill 四步诊断：画路径找阻塞（行政错配？银行惜贷？需求不足？）→ 看超储 → 判利率方向 → 用"社融 vs 银行间成交"反差给行情定性。
2. **与 money-neutrality-analysis 的区分**：问"货币总量与通胀/名义变量的长期关系、M2 该怎么校准"→ 用 money-neutrality-analysis（交易方程式+两层账）；问"这一轮宽松为什么没传到实体、增量货币淤在哪、资产为何涨"→ 用本 skill。前者是数量论层，后者是传导层。

**场景二**："民企融资难融资贵，是不是银行嫌贫爱富？"
1. 先分辨问题层次：问"谁在抢资金、为什么价格机制对它失灵（城投软约束、利率不敏感、挤出民企）"→ 用 soft-budget-constraint（第16讲，融资需求侧的主体激励分析）。
2. 本 skill 管的是供给侧路径：水从央行出来后堵在哪、会淤到哪。二者常需连用——43号文清理融资平台既是软约束治理（soft-budget-constraint 的题），又客观上阻塞了传导、催生堰塞湖（本 skill 的题）。
3. 若问"传导阻塞后央行还有什么招（QE、非常规工具）"→ 交给 monetary-policy-toolbox。

## E：边界与反例（Edge Cases）

### E1：误区"央行放水必然刺激实体经济、推升通胀"
- 传导存在摩擦（银行放贷能力不足、实体需求不足、行政错配），增量货币可能淤积金融市场成堰塞湖，实体反而"融资难"。
- 同理，"宽松必然带来广义货币扩张"也不成立：商业银行不用足货币乘数时，基础货币再多 M2 也起不来——欧央行2011年后大量流动性积压在央行账户即为国际例证。央行高掌控力的只是基础货币。

### E2：误区"利率方向想当然"
- "放水之后利率必然升"（教科书费雪效应）与"放水之后利率必然降"（现实直觉）各对一半，单取其一都错。方向取决于传导顺畅度对应的两效应强弱。任何利率断言都应先换成"传导是否顺畅"的条件判断。
- 附带警示：中国真实利率逆周期波动，不是说央行控制了真实利率——那是传导阻塞下名义与真实利率的背离，勿把观测失真当控制力。

### E3：误区"经济好股市才涨"
- 流动性效应主导时，"股市是经济晴雨表"的正相关会失灵（2015年上证与PMI背离为证）；"改革牛"等叙事解释也没抓住本质。
- 给牛市定性时，叙事与基本面都不是默认正确——先检查实体融资指标与金融资金指标是否背离。

### E4：堰塞湖定性自身的边界
- 堰塞湖不等于"所有资产上涨都是泡沫"：定性依据是指标背离，不是涨跌幅；背离不显著时勿强行套用。
- 阻塞终会以某种方式化解（政策纠偏、泡沫破灭、渠道打通），堰塞湖水位是状态不是永态——用它判断短期方向，不外推长期均衡。

## B：适用边界（Boundary）

### ✅ 适用场景
- 评估降准降息/宽松政策的效果：水放了多少、堵在哪、会淤到哪
- 解读"资金空转""脱实向虚"、资产价格与基本面背离的现象
- 给牛市/某类资产上涨定性（基本面驱动 vs 流动性淤积驱动）
- 预判宽松周期中的利率方向与不同市场回报率的分化
- 撰写/评价关于货币政策传导的评论文章（检查是否犯了机械传导观）

### ⚠️ 谨慎使用
- 涉及"谁抢走了资金、利率为何降不下来"的配置问题，须与 soft-budget-constraint 连用，单用本 skill 只见路径不见主体
- 投资应用（摩擦将破未破处找回报率收敛机会）只提供分析视角，不构成操作建议；摩擦何时破极难预测
- 中国管制利率下的数据失真（真实利率逆周期）需先识别，再套用框架

### ❌ 不适用场景
- 货币数量论本身：M2 与通胀/名义变量的长期关系、"货币超发"的总量判断（用 money-neutrality-analysis）
- 软约束主体的激励结构、刚性兑付、挤出效应的机制分析（用 soft-budget-constraint）
- 利率到零后央行工具箱与 QE 路线图（用 monetary-policy-toolbox）
- 无货币传导问题的纯财政、增长、汇率问题

## 关联 Skill

- `money-neutrality-analysis`（上游）：交易方程式与"两层账"回答货币总量与名义变量的关系；本 skill 接续回答"增量货币在传导中去了哪"
- `soft-budget-constraint`（姊妹）：需求侧主体激励（谁抢资金、价格机制为何失灵）；与本 skill 的供给侧路径分析互补，43号文案例是二者的接合部
- `monetary-policy-toolbox`（下游）：传导阻塞且利率触及下限后，央行的非常规工具与 QE 路线图
